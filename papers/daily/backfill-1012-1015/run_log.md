- 对账发现 **10-12 / 10-14 / 10-15 三个公告日完全漏跑**（10-13 周二经 7 分类 listing 核实当日无公告，arXiv 服务波动期）。

## 数据源与对账方法
- 探针：export.arxiv.org 与 arxiv.org/api/query 均 **429 限流**（上午审计起持续）；改走 `arxiv.org/list/{cat}/recent`（按公告日分组，h3 含条目总数声明）。
- 审计脚本 `scripts/audit_gap_listing.py`：7 分类 × show=500 分页 + 逐日完整性校验（表头声明数 vs 实采数）+ 分类级整体重试；关键词过滤 `scripts/filter_missed_xr.py`。
- 踩坑规避：单位数日期无前导零（`\d{1,2}`）；show=2000 响应体约 2MB 被静默截断；高频请求被限流降级（间隔 8s+重试）；跨分类交叉列表论文全局去重假象（以 per-category 自检为准）。
- API 恢复后一次性拉取 60 篇候选完整元数据（标题+摘要+分类+提交日）→ data/backfill_meta.json。
