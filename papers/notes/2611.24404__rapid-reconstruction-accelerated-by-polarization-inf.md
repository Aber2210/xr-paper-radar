# RAPID：用偏振先验深度加速 2D 高斯泼溅重建（方法名 Pol2DGS）

## 一句话结论
用偏振法线经 log-depth 积分与 TSDF 融合得到稠密深度先验，再按主曲率自适应布点初始化 2DGS，优化时间 21.3→4.3 分钟。

## 要解决的问题
2D Gaussian Splatting（2DGS）用有向圆盘表示局部表面，但模型构建时间与渲染速度是两种不同的效率指标：从稀疏点云起步仍要反复调整圆盘位置、朝向、尺度并持续 densification 才能建立表面覆盖，优化开销很大。更棘手的是反射与弱纹理区域——跨视角颜色变化几乎给不出可靠的几何线索，颜色监督在这些区域近乎失效，于是渲染质量与几何精度难以兼顾。已有的偏振方法各有缺口：PANDORA、NeRSP、PISR 属神经隐式路线，训练需 12 小时以上或 24.5 分钟，无法用于快速建模；PhyGaP 用偏振延迟渲染做反射分解与重光照，平均 21.3 分钟，但其重光照组件主要提升新视角合成、并不显著改善网格质量，还额外增加算力。另一层困难是偏振法线本身只给切平面朝向、不给沿视线的位置：透视投影下法线只约束 log-depth 的梯度，积分只能恢复相对深度，跨视角尺度不一致会把反投影点放到不同深度层，直接污染高斯初始化。

## 方法详解
输入为多视角 RGB、AoLP/DoLP 偏振观测、前景与偏振有效掩码、固定标定与特征轨迹。第一步恢复表面：由法线 n 与视线 r 定义入射面法向 m=n×r，预测偏振方位 α=atan2(−m_y, m_x)（式 1）；针对线偏振的 π 模糊与漫/镜反射正交带来的 π/2 模糊，定义周期角差 h=min_j|α−φ−jπ/2| 与惩罚 C_k=[(e^{−k(1−4h/π)}−e^{−k})/(1−e^{−k})]^2（式 2），以 DoLP 加权并拒识不可靠观测，附加朝向约束与邻域法线平滑。第二步把法线转成透视 log-depth 梯度 g_u=−n_x/(f_x(n_x x+n_y y+n_z))、g_v=−n_y/(f_y(·))（式 3），用重三角化特征轨迹加 visual hull 参考深度作为稀疏几何锚点，求解 ℓ̂=argmin Σ(ℓ_q−ℓ_p−Δ_pq)^2+λ_A Σ(ℓ_a−log Z_a)^2（式 4），LSQR 解算后指数化得深度；跨视角等权 TSDF 融合并做多视支持与连通域检查得到统一表面。第三步初始化：在局部切平面 (ξ,η) 拟合二次曲面 ζ=½aξ²+bξη+½cη²+dξ+eη+f，Hessian 特征值即主曲率 κ1、κ2，特征向量为主方向；沿主方向的采样间距 h_j=clip(√(8ε/(|κ_j|+δ))·1/√(1+(θ/θ0)²), h_min, h_max)（式 6），取 ε=0.5v、h_min=v、h_max=5v、θ0=15°，再做变半径 Poisson-disk 拒绝（半径 r=√(h1h2)），按二面角检测锐边并在两侧分别采样；初始化 μ=p、R=[t1,t2,n]、尺度 γ(h1,h2)（γ=0.8）、opacity 0.1、零阶 SH 取自融合表面颜色。第四步替换 2DGS 原生 Clone 为 Insert/Split/Merge/Prune：Insert 用偏振法线与可靠边界深度补低覆盖区并需≥2 视角支持；Split 只沿切平面主轴生成两子（μ±=μ±0.45 s_max t_max，s_max,±=0.65 s_max，o±=1−√(1−o)）；Merge 以覆盖率损失 E_cov=Σmax{A_old−A_new,0}/ΣA_old ≤ τ_cov 为准则；Prune 按 opacity。损失为 ℒ=ℒ_rgb+λ1ℒ_normal+λ2ℒ_p2pl+λ3ℒ_mask+λ4ℒ_smooth（λ=0.5/0.3/0.1/1），15000 迭代、前 1500 步冻结几何。

## 实验与结果
- PISR 数据集四个场景（BlackLoong/RedLoong/LayingRabbit/StandingRabbit）平均优化时间 4.3 分钟，对比 PhyGaP 21.3 分钟、2DGS 25.2 分钟、PISR 24.5 分钟，约 5× 加速（结论称 5–10×）
- BlackLoong 网格：CD 1.95、F-score 40.46%，优于 PhyGaP（2.22 / 33.69%）与 2DGS（2.46 / 26.54%）
- RedLoong 网格：CD 1.95、F-score 48.06%，PhyGaP 为 2.15 / 40.74%
- LayingRabbit CD 1.43 亦优于 PhyGaP 1.53
- StandingRabbit 退化：CD 1.66 vs PhyGaP 1.41、F-score 49.28% vs 58.22%，说明并非全场景占优
- 新视角合成 PSNR：LayingRabbit 26.45 为全场最高（PhyGaP 26.36），但 BlackLoong 20.50 低于 PhyGaP 21.04、RedLoong 23.59 低于 23.76
- 消融（BlackLoong）：仅 2DGS 的 CD 2.46/PSNR 20.03
- 加偏振表面先验 2.09/20.51
- 全套 Insert+Split+Merge+Prune 1.97/20.50
- 初始化策略对比：自适应采样 267 s/CD 1.95，稠密深度 349 s/2.04，COLMAP 稀疏 291 s/2.19

## 创新点与贡献
- 真正的转向是把偏振从“训练期监督”改成“训练前布点”：既有 PISR/NeRSP 用法线去约束隐式场或作为损失项，PhyGaP/PolarGS 把偏振用在反射分解或深度补全后反投影加高斯，而 Pol2DGS 用法线积分出的深度经 TSDF 融合得到显式表面，再用主曲率与主方向同时决定每个 2D 高斯的中心、旋转与两个切向尺度，使优化一开始就具备表面覆盖
- 配套的曲率自适应 Poisson-disk 间距与“锐边两侧分别采样”处理了深度采样密度与基元密度不匹配的问题
- 另一个反直觉发现是 Table 4：把偏振法线继续当监督目标反而使法线 MAE 变差（B.Loong 27.351° vs 去掉约束的 23.257°），即偏振只适合做初始化、不应贯穿训练

## 局限与风险
- 评测仅两个真实采集数据集共 7 个场景（PISR 4 + PANDORA 3），场景数偏少且都是物体级中心构图，没有大尺度室内或户外场景，也未做噪声/低 DoLP 条件下的敏感性分析
- StandingRabbit 上 CD 与 F-score 均不及 PhyGaP，PSNR 在 4 个场景中有 3 个低于 PhyGaP，说明“精度持平”依赖场景
- 方法需要偏振相机、前景掩码与偏振有效掩码，真实 AR 眼镜上的分焦平面偏振传感器并不普及
- 深度积分依赖特征轨迹三角化出的稀疏锚点与 visual hull 兜底，弱纹理物体若两者都失败则尺度自由度无法确定
- 作者也承认加密初始采样点不一定提升质量、反会引入开销
