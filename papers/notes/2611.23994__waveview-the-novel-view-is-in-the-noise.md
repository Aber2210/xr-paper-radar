# WaveView：新视角就藏在噪声里

## 一句话结论
把 warp 后的源图注入预训练生成器的初始噪声相位（DT-CWPT 局部分解），不改架构即约束极线与遮挡区，Hard covisible +0.84 dB、比 MetaView 快 2.1×。

## 要解决的问题
生成式新视角合成（NVS）要在目标相机位姿下同时满足两件事：源图本来可见的内容必须落在几何规定的位置，未被观测的内容必须补得合理。显式 warp 方法（ViewCrafter、GEN3C、Voyager）先用估计深度把源图重投影，再交给视频扩散模型补全；warp 固定了布局，但生成器并不知道哪些像素可信，深度误差、拉伸表面与遮挡边界的锯齿会被带进输出，而且常为得到单帧而生成整段视频，比本文慢 3.6–27 倍。隐式方法（PE-Field、MetaView）把相机参数乃至 3D 特征编码进位置编码或并联注意力，输出干净，但视角变化增大时布局会漂移——同一个例子中 ViewCrafter 几何扭曲、MetaView 把大厅放到了 warp 本可提供的布局之外。两类方法都要追加模块与推理开销，布局仍常偏离真值。核心问题是：能否不改生成器架构、几乎不增加推理开销，把新视角的几何先验交给预训练模型？作者从“相位保持扩散”得到启发——预训练生成器会跟随初始噪声相位携带的结构，而幅值保持高斯，于是布局可以由噪声相位指定、修正自由留给随机幅值；他们进一步挑战各向同性，因为深度误差只会让像素沿极线移动。

## 方法详解
静态 NVS 的生成器用 Qwen-Image-Edit，只用 LoRA 适配结构化噪声，架构完全不动；动态 NVS 用 AnyView 并保留其 Plücker 条件，在结构噪声上微调。第一步，warp 与位置不确定性：单目深度估计器（Depth Anything 3，与 MetaView 共用）给源像素深度 d^src，沿射线抬升并按相对位姿 (R,t) 变换 X^tgt=d^src·R·r^src+t，投影得目标像素；相对深度误差建模为零均值、相对标准差 ρ·d^src，一阶传播 σ_depth=ρ·d^src·R·r^src，其在图像上的像 J·σ_depth 落在该像素的极线上，故目标处位置协方差为 Σ=(Jσ_depth)(Jσ_depth)^T/η²（η 为编码器 stride，协方差在 latent 像素上表达），是秩一矩阵，垂直极线方向方差为零——这正是 EWA splatting 的一阶协方差传播用在单射线支撑上。第二步，各向异性相位注入：对位置 q 与频带 l，把局部内容平移 δ 会使该带相位旋转 π·f_l·δ 而幅值不变，故对 δ~N(0,Σ) 的相干性为 h_l(q)=exp(−½π²·f_l^T Σ(q) f_l)；因 Σ 随 ρ² 缩放且沿极线拉伸，ρ 只压低频率方向沿极线的频带、跨极线频带不受影响。再乘各向同性底 φ_l=exp(−½π²γ²‖f_l‖²) 吸收相机参数不准等 warp 自身误差（等价于 Wavelet Phase Diffusion 的截断 F，但只压各向高频）。保留掩码 M_l(q)=1 当且仅当 φ_l·h_l(q)≥τ；在频率平面上保留的频带填满 φ_l=τ 圆内的一个椭圆——γ 单独决定跨极线长轴，ρ 进一步缩短沿极线短轴。第三步，注入与可见性：∠Ĥ_l=v·M_l·∠H_l(x)+(1−v·M_l)·∠H_l(ε)，幅值一律取噪声；最低频实包按可见性混合 L̂=v·L(x)+(1−v)·L(ε)，其中 L(x) 先标准化到 L(ε) 的均值与方差，于是粗布局来自 warp 而统计量来自噪声，遮挡区（v=0）保持纯高斯噪声。分解与重构用 Dual-Tree Complex Wavelet Packet Transform（DT-ℂWPT）：与傅里叶不同，其系数只覆盖小邻域单一频带，双树结构让每个复系数带一个方向，因此不同角度的结构落入不同系数，截断可随位置变化且各方向独立——这是相对 NeuralRemaster 的径向掩码与 Wavelet Phase Diffusion 的空间变化截断的关键差异（后两者在每个位置各方向共享同一截断）。逆变换得初始噪声 ê，作为反向扩散初态。动态扩展：每帧各自保留深度、目标相机、重采样源与协方差，逐 latent 帧独立注入（同一 latent 帧内共享掩码），鱼眼相机按标定模型算源射线与投影，极线方向经投影雅可比映射到像素。推理设置 40 步、guidance scale 4、960×528；深度估计与噪声构造合计仅增 0.46 s，默认 ρ=0.03（实测深度误差）、γ=0.6。

## 实验与结果
- DL3DV Hard（covisible）：PSNR 14.82 vs MetaView 13.98（+0.84 dB）、SSIM 0.401 vs 0.349、LPIPS 0.471 vs 0.501
- 全图 PSNR 13.71 vs 13.12（+0.59 dB）、SSIM 0.386 vs 0.353
- DL3DV Easy / Medium（covisible）：PSNR 21.08 / 16.69，较共享生成器的 MetaView（19.72 / 15.99）提升 1.36 / 0.70 dB
- SSIM 0.656 / 0.478，较最强基线 GEN3C 与 ViewCrafter 高 0.053 / 0.039
- 三个 bin、全图与 covisible 六组设置全部最优
- 运行时间（单张 B200、每视角）：17.9 s，对比 PE-Field 22.0 s、MetaView 38.0 s、ViewCrafter 64.1 s、GEN3C 168.7 s、Voyager 474.7 s
- 相对同生成器的 MetaView 快 2.1 倍（两者同为 40 步、guidance 4、960×528）
- 动态 NVS（AnyViewBench zero-shot 平均）：PSNR 11.58→12.35 dB、SSIM 0.331→0.372、LPIPS 0.621→0.587，五个数据集三个指标全部提升，Argoverse 最多 +1.57 dB
- 含训练中未出现的鱼眼数据集 Ego-Exo4D（13.02→13.31 dB）
- 控制实验：同配方改用高斯噪声微调 AnyView 只得 11.35 dB / 0.327 / 0.641（zero-shot）与 17.40 dB / 0.518 / 0.453（in-distribution），说明增益不只来自额外微调
- in-distribution 平均 17.56 vs AnyView 17.61 dB，SSIM/LPIPS 略优
- 消融（DL3DV Hard covisible，ρ=0.03、γ=0.6）：各向同性变体低 0.24 dB / 0.014 SSIM，把 Σ 旋转 90° 低 0.50 dB / 0.025
- 差距随 ρ 从 0.03 增至 0.09 放大到 0.46 与 0.89 dB
- 只注入低频包 L 的 low-pass 变体（类 WAVE）12.85 dB，比本文低 1.97 dB 且低于 MetaView

## 创新点与贡献
- 第一次把“深度误差只沿极线移动像素”这一几何事实变成噪声相位的方向性注入规则：用一阶协方差传播给出秩一的 Σ，用 exp(−½π²f^TΣf) 的相干性在 DT-ℂWPT 的每个位置、每个方向、每个频带上独立决定是否保留 warp 相位，再加各向同性底 γ 兜住 warp 自身误差
- 这与既有相位保持扩散（NeuralRemaster 的径向掩码、Wavelet Phase Diffusion 的空间变化但各向同性截断）和 WAVE 的低频混合都不同：截断形状从“圆”变成“椭圆”，且椭圆长短轴分别由 γ 与 ρ 控制
- 工程上也真正做到了零架构改动——不加几何编码器、不加并联注意力、不生成视频，只在初始噪声上花 0.46 s，从而在同生成器条件下同时赢过精度与速度

## 局限与风险
- 作者自述：Σ 只建模单目深度沿每条射线的局部误差，不覆盖全局尺度错误、相机参数不准，以及“warp 被遮挡但目标视角可见”的表面
- 源图无像素处完全交给生成器的学习先验，没有任何几何约束
- 可从实验看出：静态结果只在 DL3DV（MetaView 协议）上评测，动态主要在 AnyViewBench，缺少真实机器人/XR 端在线闭环或大视角外推的压力测试
- ρ、γ、τ 为固定值（只在测试时扫 ρ 与 γ），未与深度估计器不确定性做自适应耦合
- LoRA 需在 MetaView 训练集上训练，“换生成器是否仍成立”只验证了 Qwen-Image-Edit 与 AnyView 两例
- in-distribution 平均略低于 AnyView（17.56 vs 17.61 dB），且在 AnyView 训练过的 Lyft 与 Ego-Exo4D 上落后
