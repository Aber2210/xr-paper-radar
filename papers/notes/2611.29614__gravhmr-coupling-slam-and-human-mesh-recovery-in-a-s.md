# GravHMR：在共享重力坐标系中耦合 SLAM 与人体网格恢复

## 一句话结论
把问题从「精修 R/t」改为「在 SLAM 与 HMR 之间选择性迁移信息」：只从相机几何取 heading、从 HMR rollout 取重力相对 tilt，training-free 插件：EMDB-2 W-MPJPE100 154.0 mm，相对 GVHMR 降 44.3%。

## 要解决的问题
从单目视频恢复全局一致的 3D 人体运动在动态相机下仍困难：SLAM 给相机几何、HMR 给人体运动先验，二者互补，但直接组合会产生朝向不一致与轨迹漂移。几何上合法的 camera-to-world 变换并不保证物理一致的人体重建——相机几何与 HMR 运动参考之间的差异会表现为错误的人体朝向（heading）与累积轨迹漂移。直接采纳相机推导的全身朝向会丢掉 HMR（如 GVHMR）带来的重力参考 tilt，而只靠 HMR rollout 又保留错误 heading 与漂移；且二者相互作用：错误的 heading 会污染后续运动先验与几何约束。

## 方法详解
GravHMR 是 training-free、plug-and-play 框架：ViPE 提供内参 $K_t$、相机旋转 $R_t^{c\to w}$ 与中心 $C_t^w$，GVHMR 初始化人体运动；相机系重力 $g_t^c$ 由 GeoCalib 独立于 HMR 估计，聚合到 SLAM 世界得竖直轴 $n^w$，再整体旋转到重力系（$y$ 轴）。YAOO（Yaw-Aware Orientation Optimization）先把相机系人体朝向提升为 $\tilde R_t=R_t^{c\to g}R(\Gamma_t^c)$，取它相对 rollout 的绕重力轴 yaw $\psi_t=\mathrm{Yaw}_{n^g}(\tilde R_t (R_t^{roll})^\top)$，只把该 yaw 作用到 rollout 朝向与位移——保留 rollout 的 tilt 与步态幅值，只改水平方向（作者验证直接用 $\tilde R_t$ 全量朝向会降低精度）。GATO（Gravity-Aware Trajectory Optimization）先做 per-frame 2D root solve 得视线方向 $r_t$，深度取 HMR 回归的 $z_t^{HMR}$ 初始化 $X_t^0=C_t^g+z_t^{HMR}R_t^{c\to g}r_t$，再解 $\mathcal{X}^*=\arg\min \mathcal{L}_{reproj}+\mathcal{L}_{human-scale}+\mathcal{L}_{dynamic}$，三项均用 Cauchy 罚 $\rho_\sigma(r)=\log(1+r^2/\sigma^2)$、不加权求和，$\sigma$ 由对 per-frame 2D root solve 的 MAD 自校准而无需 GT。最后 FATC（复用 HTD-Refine 的细化式、以 PVA-Net 的关节速度/加速度为目标）在 GATO 解上正则时序导数，只去高频抖动与脚滑，不负责恢复全局轨迹。

## 实验与结果
- EMDB-2 W-MPJPE100：154.0 mm（ViPE）/189.8 mm（masked DROID-SLAM），对比 GVHMR 276.5、GVHMR+HTD-Refine 192.4、TRAM 222.4、GENMO 210.9
- 相对 GVHMR 降 44.3%，相对 GVHMR+HTD-Refine 降 20.0%（同 HMR backbone，EMDB-2）
- 与 TRAM 完全相同的 masked DROID-SLAM 相机与 GT 内参下，比 TRAM 降 14.7%、比 TRAM+HTD-Refine 降 7.4%
- RICH W-MPJPE100 109.1 mm，比 GVHMR+HTD-Refine 降 11.9%（14.7 mm）、比 GVHMR+PVA-Net 降 8.4%
- WA-MPJPE100：EMDB-2 57.4 mm、RICH 65.5 mm；RTE 1.3%（EMDB-2）/2.1%（RICH），仅 GENMO 的 1.0% 更低
- FATC 的时序收益：EMDB-2 Jitter 32.1→8.4、FS 7.8→5.2 mm；RICH Jitter 33.8→3.5、W100 119.0→109.1 mm
- 朝向分析：E_dir 11.8°→5.4°；P7_61 上 body-axis 中位误差 12.4°→4.9°；skateboard 序列平均水平误差 17.3 m→1.3 m

## 创新点与贡献
- 把问题从「如何精修 R/t」改为「如何在 SLAM 与 HMR 之间选择性地迁移信息」：只从相机几何取 heading、从 HMR rollout 取重力相对 tilt，且重力由图像侧 GeoCalib 独立估计，使同一套流程对有无 gravity-view 表示的 backbone 都可用
- GATO 把 2D 重投影、人体尺度隐式深度、自运动先验三项以 Cauchy + MAD 自校准联合，无需 GT 调参也无需重训 HMR

## 局限与风险
- 方法效果强依赖 HMR backbone 与 SLAM 尺度：作者自己的 Tab.3 显示换成无 gravity-view 的 VIMO 后 W100 仅 197.9→196.3，几乎无收益
- FATC 是沿用 HTD-Refine/PVA-Net 的既有细化，不算本文贡献
- 全流程单目、无 loop closure，EgoBody 这类强截断场景仍是 ~123 mm
- 比较并非严格受控（ViPE 与 DROID-SLAM 两种相机输入混用），且所有参考均为数据集提供的 ARKit 派生位姿而非独立 GT
