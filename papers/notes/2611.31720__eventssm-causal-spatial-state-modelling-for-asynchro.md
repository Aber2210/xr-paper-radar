# EventSSM：面向异步事件的事件级深度估计因果空间状态建模

## 一句话结论
把 SSM 式的持久状态搬到事件平面：状态转移同时依赖真实经过时间（指数保留）、学习式图像平面 backward transport 与局部事件支撑门控，输出域是单个事件而非整幅像素——MVSEC outdoor_day1 AbsRel 0.286 vs ScaleEvent 0.357（−19.9%）、RMSE 4.745 m vs 6.353 m。

## 要解决的问题
事件相机异步输出对数亮度变化，但 metric depth 监督只在稀疏参考时刻可得，把事件聚合成 count image、time surface 或 voxel 虽便于学习，却把预测绑定在采集窗口与时间分箱上，抹掉原始事件流的时间结构。事件本身不携带深度：活动强度取决于运动、局部对比度与传感器特性，重复观测集中在运动纹理边界，邻近平滑面几乎不产生事件，因此需要跨不规则时间间隔持续存在的空间上下文。评测条件被压到很窄：约 50 ms 参考区间、至少 10,000 个自然事件下采样到 7,500 个，还要给出每个事件的 metric depth。

## 方法详解
把参考区间切成 K 个有序不重叠 packet，递推 M_k=F_θ(M_{k-1},E_k,Δt_k)、d̂_k=G_θ(M_k,E_k)，因果性体现在 packet 边界：可用包内后到事件，不能用后续 packet。极性感知观测：事件 token 由归一化坐标、包内时间 τ_i 与极性嵌入成 64 维，空间 stem 按极性分别池化 token 均值 μ_k^p 与 log(1+n_k^p)，拼成 130 维后投影为 64 通道 O_k，并用支撑指示 S_k(u)=1[n_k^+ + n_k^- >0] 限定注入位置。状态转移先做有界学习式 backward transport：f_k(u)=v_max·Δt_k·tanh(F_θ([M_{k-1},O_k])(u))，v_max=800 px/s，M̃_{k-1}=Sample(M_{k-1}, u+f_k(u))；再按物理时间衰减 α_k=exp(-rΔt_k) 与门控注入组成 M_k=α_k⊙M̃_{k-1}+(1-α_k)⊙S_k⊙σ(G_θ(O_k))⊙tanh(V_θ(O_k))。读出侧从 M_k 派生 s∈{1,2,4,8} 四级金字塔与轻量 coarse-to-fine decoder，每个事件在每级取中心加四邻域共 20 个 key，做局部 cross-attention，再经残差 MLP 输出标量映射到有界对数深度 d̂=exp(log d_min+σ(ℓ)(log d_max-log d_min))，户外用 0.25–30 m。监督用 target-time 几何渲染：把事件抬成 X_i=d̂_i K^{-1}u_i，用插值位姿 X_r=T(t_r)^{-1}T(t_i)X_i 投影回参考视角，可微 splat 成 D̂_r 后与参考深度算 SiLog 损失。训练分两段：先用冻结 DINOv3 ViT-S/16 的 2/5/8/11 层特征做 20 epoch 表示初始化（SmoothL1+cosine+spatial relation），再训深度头，推理只用事件与记忆。

## 实验与结果
- MVSEC outdoor_day1：AbsRel 0.286 vs ScaleEvent 0.357（-19.9%）、SqRel 1.413 vs 3.174（-55.5%）、RMSE 4.745 m vs 6.353 m（-25.3%）、MAE 3.152 m vs 3.964 m（-20.5%）
- 三个 held-out night 序列相对最佳基线 SqRel 降 16.8–30.1%、RMSE 降 7.7–15.1%
- 模型仅 69.5k 参数，packet 推理 5.58 ms / 179 calls/s，对比 E2Depth 11.88 ms、EReFormer 44.86 ms、ScaleEvent 15.76 ms，参数量约为最小全窗基线的 1/154
- 跨模态初始化把深度误差从 2.724 m 降到 2.331 m（-14.4%）
- MAE@20 / MAE@30 在全部四个序列上领先，相对最佳对手降 4.4–33.0% 与 6.4–20.5%
- temporal core 对比中误差比 Spatial RNN/LSTM/bi-Mamba 低 1.0–2.5%，参数少 5.6–29.4%，packet 延迟快约 4.0–5.0×

## 创新点与贡献
- 把 SSM 式的持久状态搬到事件平面：状态转移同时依赖真实经过时间（指数保留）、学习式图像平面 backward transport 与局部事件支撑门控，输出域是单个事件而不是整幅像素
- 用 20-key 常邻域局部注意力替代事件流上的全对注意力，使读出成本随事件数线性而非平方
- 配套的 target-time renderer 把事件时刻的预测搬回标注参考视角，让异步预测可以直接吃帧时刻的 metric 监督

## 局限与风险
- 只在 MVSEC 一个数据集的四个户外序列上验证，缺少跨传感器、跨场景与真实机器人闭环
- 监督依赖静态世界假设，训练时必须裁掉含独立运动物体的区域，遮挡与可见性变化也会让投影失效
- packet 细分不保证更好精度（K=3–24 无单调趋势），K=6 是时延与更新成本的工程折中
