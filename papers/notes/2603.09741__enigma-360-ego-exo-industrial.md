# ENIGMA-360：面向工业场景人类行为理解的自我–外部视角数据集

## 一句话结论
ENIGMA-360 在真实工业实验室采集 180 段自我中心与 180 段外部视角同步视频（34 名被试、平均 18.59 min、合计 111.54 h、68 类 keystep、14,556 段时序标注、12,597 帧 HOI 标注、25 类物体），给出 TAS/Keystep/HOI 三套基线：同视角最优 FACT 在 EGO→EGO 上 F1@10 78.7、Acc 70.8；跨视角最好仅 C2F-TCN 的 EGO→EXO F1@10 7.2，ASFormer 的 EXO→EGO F1@10 20.9，量化出现有模型的 ego-exo 崩塌。

## 要解决的问题
工业行为理解既需自我中心视角的手–物细节，又需外部视角的环境与流程上下文，但公开数据长期缺这一组合。现有工业类数据集多用替代场景：MECCANO 是 20 段带 gaze/深度的第一人称视频、IndustReal 用玩具车装配、Assembly101 是无线索纹理玩具车的拆装，均缺真实工具与流程；Ego-Exo4D、H2O、LEMMA、IKEA ASM 虽多视角，却不针对工业维修。缺口有三：①没有在真实工业实验室同步采集 ego+exo 的数据；②缺同时具备 keystep 级时序与手–物空间标注（框、手侧、接触态、关联）的体系；③没有跨视角评测协议，无法判断模型学到行为还是过拟合某一视角的外观。

## 方法详解
在自建 ENIGMA 实验室（25 类固定/可移动工业对象）设计高/低压两块板的两套维修流程，每套 4 个版本，共 68 个 keystep。用 Unity 开发的 HoloLens 2 应用以 gTTS 音频 + 混合现实图片逐步下指令，替代纸质手册。ego 流为 HoloLens 2 RGB 2272×1278@30 fps，exo 流为 ZED 672×376@15 fps，用工作台灯泡亮起做时间对齐；34 名被试，平均 18.59 min，共 111.54 h，划分 103/29/48。标注：以应用日志时间戳为初值，用定制 VIA Subtitle Annotator 修正起止，得 14,556 个 keystep；14,036 个交互关键帧，物体为 (class,x,y,w,h,state) 五元组共 275,135 个，手框用 100DOH 类模型出伪标签再人工修正手侧与关联共 56,473 个；HOI 子集 12,597 帧、17,363 只手（10,043 接触）、9,342 个 active object。附加 SAM-HQ 的 197,814 手掩码与 1,435,006 物体掩码、DINOv2-large 1024 维特征、Matterport + ARTEC EVA 的 3D 模型。基线：TAS 用 C2F-TCN、MSTCN++、LTContext、ASFormer、DiffAct、FACT ；Keystep 用 TimeSformer 8 帧窗口；HOI 用 VISOR HOS 与 Leonardi 2025/2024，报 COCO Mask AP。

## 实验与结果
- 规模：180 ego + 180 exo 同步视频、34 名被试、平均 18.59 min、合计 111.54 h；ego 2272×1278@30 fps（HoloLens 2），exo 672×376@15 fps（ZED），划分 103/29/48。
- 标注量：68 类 keystep、14,556 段时序标注（均长 7.92 s）、14,036 个交互关键帧、275,135 个物体框、56,473 个手框、12,597 个 HOI 帧（17,363 只手，10,043 接触，9,342 active object）、197,814 手掩码 / 1,435,006 物体掩码。
- TAS 同视角（Table 3a）：EGO→EGO 最优 FACT 为 F1@10/25/50 = 78.7/73.2/59.5、Edit 84.6、Acc 70.8、AccB 72.7；EXO→EXO 最优 FACT 72.8/66.5/50.4、Edit 76.6、Acc 63.3、AccB 68.2。
- TAS 跨视角（Table 3b）：EGO→EXO 最优 C2F-TCN 仅 7.2/5.5/3.5、Edit 13.1、Acc 5.6、AccB 29.7；EXO→EGO 最优 ASFormer 20.9/19.0/13.6、Edit 22.8、Acc 22.7、AccB 49.0。
- Keystep（Table 4）：TimeSformer-EGO 为 P 0.75 / R 0.74 / F1 0.74 / Acc 0.83 / IoU 0.62；TimeSformer-EXO 为 0.50 / 0.47 / 0.46 / 0.47 / 0.32。
- HOI（Table 5）：VISOR HOS 掩码 Overall 63.84（Hand 85.01、H+S 81.05、H+C 52.32、Object 51.35）；加标签传播后 64.55（85.75 / 82.51 / 52.59 / 53.24）；框基线 Overall 仅 46.24（Hand 90.81、H+S 90.35）。
- 跨视角协议：每个基线分别在 ego 与 exo 训练子集训练后，在两种测试集上各评一次，用于量化视角域 gap，而非只报单视角成绩。

## 创新点与贡献
- 首个在真实工业实验室采集的同步 ego-exo 数据集（180+180），用真实示波器、焊台、电路板替代玩具/无线索纹理替代场景。
- 建立 keystep 级时序 + 手–物级空间的联合标注体系（68 类、14,556 段、12,597 HOI 帧、手侧/接触/关联五元组），并附 SAM-HQ 掩码、DINOv2 特征与全场景 3D 模型。
- 首次系统给出跨视角（EGO↔EXO）的 TAS/Keystep/HOI 基线，用同一协议量化「同视角 78.7 → 跨视角 7.2」的域 gap。
- 用 HoloLens 2 混合现实应用替代纸质手册下发步骤指令，并借应用日志半自动生成时序标注初值，降低长流程采集与标注成本。

## 局限与风险
- （作者承认）数据来自单一实验室，布局固定、光照受控、工具与流程仅两套，被试数量有限，向其他工厂/流程/工种的泛化受限。
- （我在正文发现）跨视角 TAS 近乎失效（F1@10 最低 0.3、Acc 0.9），但正文未分析失败机理，也未给出任何跨视角对齐/域适应基线。
- （我在正文发现）划分按视频（103/29/48）而非按被试，正文未说明是否 subject-disjoint，存在同一被试跨集导致高估的风险。
- （我在正文发现）空间标注只在 ego 子集做（「we identified the interaction key frames within the egocentric subset」），exo 侧没有对应手–物框，限制真正的双视角 HOI 监督。
- （我在正文发现）全部为单次运行结果，无多 seed 方差或显著性检验，方法间 1–2 个点的差异不可判读。
- （我在正文发现）本次全文为 v2（2026-03-11）只含 3 项任务，而 arXiv v3 摘要另列 Video-Grounded Cross-View VQA，正文缺少该任务章节，版本内容不一致。

本文是作者团队前作 Ragusa et al.（2024）ENIGMA 的扩展：新增 129 段 ego 与全部 180 段 exo，补齐时序与空间标注。横向与 MECCANO（Ragusa et al., 2023）、IndustReal（Schoonbeek et al., 2024，玩具车装配）、Assembly101（Sener et al., 2022）划界——后者均非真实工业对象；与 Ego-Exo4D、H2O、LEMMA、IKEA ASM 相比，差异在工业维修流程与 keystep 级标注。基线覆盖 C2F-TCN、ASFormer、LTContext、MSTCN++、DiffAct、FACT、TimeSformer 与 VISOR HOS/Leonardi 系列。本篇为旧稿 v2/v3 再公告（v1 未入馆），按首次入馆处理。
