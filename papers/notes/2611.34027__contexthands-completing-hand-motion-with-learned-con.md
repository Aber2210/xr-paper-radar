# ContextHands：用学习到的上下文与关节级身体运动学补全手部动作

## 一句话结论
承认「身体动作不能唯一确定手」，用「手别-时间分配的文本 + 每手共享条件变分潜变量」建模 p(H|B,T,A)——OakInk2 MinMPJPE 22.809 mm（MLD 25.725）、腕旋转 16.93°（18.98°）、FHD 0.276（1.226），150 帧 2.83 s，多样性接近 GT（9.043 vs 9.397）。

## 要解决的问题
手部动作补全要由已观测的身体序列与「按手、按时间段分配」的文本描述生成腕与手指旋转，核心困难是身体动作不能唯一确定手：相似的手臂运动可对应不同手指构型，两只手也可能各自开合。OakInk2 提供了带手别-时间标注的操作描述，但现有方法要么分别训练 body→hand 与 text→hand 再融合（BOTH2Hands），要么在冻结的 body-hand 先验上挂语义适配器（Prior-First）。在该数据集上适配后的最强基线 MinMPJPE 为 25.725 mm（MLD）、FHD 0.805（HandX）、腕旋转误差 18.26°（MDM），细节仍明显不足。

## 方法详解
任务为建模 $p(H\mid B,\mathcal{T},A)$，其中 $H\in\mathbb{R}^{T\times2\times16\times6}$ 是每手 1 个腕 + 15 个指关节的 6D 局部旋转（相对父关节，腕相对前臂），身体与腕位置固定，前向运动学得手部几何。Hand Context Encoder（HCE）：Transformer 身体编码器给逐帧每手特征，冻结 DistilBERT 的 token 特征经可训练 attention 聚合，按分配 $A$ 放到对应手与帧（无描述处置零），相加得上下文 $c$；再用条件变分形式 $p_\phi(z\mid c)$（对角高斯，每手一个 $z_h$ 跨该手所有帧共享），特征解码器把 $z$ 的投影加回 $c$ 并做跨手/跨时 attention 得 $U$。训练时另有后验 $q_\psi(z\mid c,H)$，先验与后验样本分别经同一解码器得 $U^p=D_\eta(c,z^p)$、$U^q=D_\eta(c,z^q)$，走同一生成器的两次前向。辅助手部预测给上下文特征直接目标：每手拟合固定 PCA 基，共享线性头从 $U^q$ 回归 16 个标准化系数，MSE 监督，梯度经解码器回流。Joint-Query Kinematic Encoder（JQKE）：逐帧空间 attention（带解剖关系偏置）+ 三支时间分支（短卷积、膨胀卷积、全序列 attention）门控融合得 $F_t$，再池化出 5 个解剖部位摘要 $P_t$ 与 3 个尺度摘要 $S_t$，组成 $E_t\in\mathbb{R}^{30\times256}$（22 关节 + 5 部位 + 3 尺度，均加类型嵌入）；32 个手关节 query（关节与侧别身份 + 同侧腕/臂特征 + 全身摘要）经残差 cross-attention 读整个 bank（含对侧）得 $C_t\in\mathbb{R}^{32\times256}$，只依赖 $B$，扩散采样前算一次。生成器：每关节一个 token，$U_{t,h}$ 投到该手 16 个 token，去噪块用残差 MLP 注入 $C_{t,j}$ 与扩散步，接时间与手内 self-attention，100 步 cosine 噪声表、DDPM 100 步反向，损失含经前向运动学的几何项。训练目标 $\mathcal{L}=\alpha\mathcal{L}^p_{hand}+(1-\alpha)\mathcal{L}^q_{hand}+\lambda_{rec}\mathcal{L}_{coef}+\beta\bar{D}_{KL}(q_\psi\|p_\phi)$，$\alpha$ 用 virtual-update 的有限差分自适应（两次扰动权重的虚拟更新后恢复状态再做真实步）。

## 实验与结果
- OakInk2：MinMPJPE 22.809 mm（MLD 25.725、HandX 29.239），AvgMPJPE 30.711 mm（MLD 34.051）
- 腕旋转误差 16.93°（MLD 18.98°、BOTH2Hands 22.52°），FHD 0.276（HandX 0.805、MLD 1.226）
- Diversity 9.043（GT 9.397，MDM 9.724），MModality 2.498（BOTH2Hands 2.337）
- 推理：150 帧序列 2.83 s（RTX 4090，不含冻结文本编码），快于 MDM、BOTH2Hands、HandX
- 数据：308 训练录像 / 3,842 clips、70 验证 / 728、157 测试 / 1,709；测试手-帧对中 51.69% 带描述

## 创新点与贡献
- 相对 BOTH2Hands 的「body 与 text 两个生成器分别出结果再融合」，ContextHands 用单个扩散生成器同时接收「手内共享的概率上下文 $U$」与「逐关节身体条件 $C(B)$」，并用辅助手部预测给上下文特征一个直接学习目标，使上下文特征被生成任务塑形
- 相对 Prior-First 用含噪手状态导出的 kinematic query，它的关节 query 在去噪前只由观测身体算出，且身体/文本上下文与生成器从零联合训练，而不是在冻结先验上适配

## 局限与风险
- 作者承认需要完整身体序列与人工给定的手-时间分配，使用了未来帧，只能做离线补全
- 评测只覆盖 OakInk2 的双手物体操作，未验证其他活动类型与自由书写描述，也没有用户研究评估自然度与描述一致性
- 方法不建模物体几何与手-物接触，扩展到新物体能力受限
- 描述只覆盖 51.69% 的测试手-帧对，无描述区间的误差可能被身体先验掩盖
- 单数据集也让跨数据集泛化未知
