# GAAFormer：用于点云去噪与上采样联合任务的几何锚定注意力 Transformer

## 一句话结论
把「几何锚定 + 交替偏移的固定体素窗口」引入生成式八叉树解码器，使注意力成员关系在输出支撑集变化时保持一致：同一套权重同一参数量同时做去噪与上采样，HD 降 19.34%。

## 要解决的问题
点云去噪要去扰动同时保住有效表面区域，上采样要把几何证据扩展到稀疏区，两者都要求预测点贴近真实表面并覆盖表面。生成式八叉树解码器由粗到细预测占据时会不断重建节点序列，剪枝一个分支就可能让存活节点跨越序列化分组边界，即使坐标未变也改变了用于预测占据与点位置的上下文；而一次错误的粗层占据判断会删掉全部后代采样，后续细化无法挽回。

## 方法详解
GAAFormer 是统一的生成式八叉树 Transformer，解码器把注意力分组锚定到空间坐标而非序列位置：每个 cell 归入固定的 4×4×4 voxel 窗口，相邻 block 交替窗口偏移以跨边界交换信息。固定深度与偏移下分组只依赖坐标，删除节点不会重排幸存节点，作者据此给出 deletion-consistency 性质。去噪与上采样共用同一 encoder–decoder、同一预测头与同一 checkpoint，参数量与序列化注意力骨干完全相同，不需任务特定重设计。

## 实验与结果
- PUNet 去噪平均 CD = 6.0643×10^-5（Serial-OUFormer 6.2743×10^-5，−3.35%）
- PUNet 去噪平均 HD = 0.6655×10^-3（Serial-OUFormer 0.8251×10^-3，−19.34%）
- 上采样 CD = 0.8475 / 1.7057 / 1.0147（×10^-5，PU-GAN / PU1K / Sketchfab）
- 邻域稳定性 Jaccard = 1.000（规则/膨胀 Morton 分组为 0.608 / 0.546）
- 参数量 = 10,623,997（与 Serial-OUFormer 完全相同）
- 10k 去噪峰值显存 = 1,043.3 MiB（Serial-OUFormer 1,273.7 MiB）

## 创新点与贡献
- 把「几何锚定 + 交替偏移的固定体素窗口」引入生成式八叉树解码器，使注意力成员关系在输出支撑集变化时保持一致（并给出删除一致性性质），从而用同一套权重、同一参数量同时服务去噪与上采样

## 局限与风险
- 去噪增益集中在高密度高噪声（50k 点、2.5% 噪声），在 10k 点 2% 噪声上反不如序列化骨干（CD +3.43%）
- 上采样在 PU1K 上三项指标均略降（CD +0.41%、HD +0.48%、P2F +0.97%），加权 141 个输入后 CD 与 P2F 仍分别升 0.33%、0.71%
- 推理延迟相对骨干略增（131.02→135.79 ms）
