# 重访单目手持物体扫描：数据集、位姿估计与表面重建

## 一句话结论
用 4K 60fps 手机自然「把玩」重建手持物体：手部实例分割后只在物体像素上跑 SfM，再按固定角位移分段跑子序列 SfM，用多对跨序列帧的 Umeyama 拼接——ToysRU F1 93.80、CD 0.74、0.5 h（Color-NeuS 81.75 / 2.24 / 12 h），VGGT 直出仅 19.74、MASt3R-SfM 23.06。

## 要解决的问题
用普通手机做手持物体扫描（IHOS）能让非专家完成 3D 数字化，但现有研究被数据卡住：HOPE、HO3D 本是给机器人操作与 6DoF 位姿估计用的，分辨率低（1080p/480p）、物体几何简单、还要求「紧握」——手永久遮住部分表面，重建必然不完整。换成自然「把玩」（toying）后，动态手遮挡又让 SfM 失效：帧间基线太小会深度估错、轨迹漂移，采样太稀又匹配不足、SfM 提前终止。3D 基础模型在此也不灵，VGGT 的 F1 仅 19.74、CD 138.22，MASt3R-SfM 为 23.06 / 114.85。

## 方法详解
先建数据：ToysRU 含 40 个几何复杂的摆件，用手机拍 4K UHD（3840×2160）60 fps、约 30 秒（约 1800 帧），单手举机、另一手把玩；真值由转台多视角摄影测量 + KIRI Engine 生成网格，归一化到单位尺度、ICP 对齐后评几何。方法分两步。CamStitch 先用手部实例分割模型与 SAM2 分割并跟踪手、前景物体与背景，只在目标物体像素上跑 SfM；针对「小基线 vs 匹配不足」的两难，改为在按固定间隔（本文取 5 帧，30 s/60 fps/两圈 720° 下约 2° 角位移）均匀采样的子序列上并行跑 SfM，得到多条子轨迹与点云；再用 Umeyama 估相似变换 $\mathbf{T}=(\mathbf{R},\mathbf{t},s)$ 逐对拼接——关键观察是单对跨子序列帧匹配虽少，但多对跨序列帧的 2D 匹配加上子序列内 SfM 给出的 2D–3D 对应，合起来足以形成大量 3D 对应；全部拼完后做全局 Bundle Adjustment 精化位姿与点云。OA-2DGS 在此轨迹上重建着色表面：以前景掩码为目标不透明度 $\mathbf{A}$，以手部掩码的补集为逐像素权重 $\mathbf{W}$（手区为 0），损失为 $\mathcal{L}_c=(1-\lambda)(\|\mathbf{W}\odot(\hat{\mathbf{I}}-\mathbf{I})\|_1+\|\mathbf{W}\odot(\hat{\mathbf{A}}-\mathbf{A})\|_1)+\lambda\mathcal{L}_{\text{D-SSIM}}(\mathbf{W}\odot\hat{\mathbf{I}},\mathbf{W}\odot\mathbf{I})$，$\lambda=0.2$，另加 2DGS 原有的法向–深度一致性正则，最后 Marching Cubes 提面。完整管线称 Castoags。

## 实验与结果
- 数据集：40 个摆件、4K UHD 60 fps、每段约 30 秒（约 1800 帧），真值由 KIRI Engine 摄影测量生成
- ToysRU 主结果：Castoags acc 94.23 / compl 93.39 / F1 93.80 / CD 0.74 / PSNR 17.68 / SSIM 0.75 / LPIPS 0.29，耗时 0.5 h
- 次优 Color-NeuS：82.88 / 80.67 / 81.75 / CD 2.24 / PSNR 14.16 / SSIM 0.65 / LPIPS 0.39，耗时 12 h
- 3D 基础模型直出：VGGT F1 19.74（CD 138.22）、MASt3R-SfM 23.06（114.85）、MapAnything 35.52（97.07）、MAtCha 31.49（137.35）、Dynhor 28.46（45.81）、ForeHOI 28.51（57.14）
- SfM 消融：naive SfM F1 1.46 / CD 6.86k / 6.0 h → 仅前景 95.47 / 0.50 / 2.0 h → CamStitch 97.90 / 0.36 / 0.3 h
- IHO 位姿：mRE 1.11→0.54 px、ATE 0.48→0.10 m、RPE$_r$ 0.45→0.10°、RPE$_t$ 1.80→1.73 m，耗时 3.25→0.44 h
- OA-2DGS 消融：无 A/W 时 F1 56.71 / CD 114.59 → 加 A 63.99 / 1.86 → 加 A+W 96.31 / 0.63

## 创新点与贡献
- 相对 HOD/IHO 的小规模或紧握设定，ToysRU 是首个「4K、自然把玩、非日常定制物体、手持拍摄、且带摄影测量真值」的 IHOS 基准，直接改变了任务难度分布
- 方法上不是把 SfM 换个特征，而是先解释它为何失败（小基线与长程匹配不足的固有矛盾），再用「子序列并行 + 多对帧 3D 对应 + Umeyama 拼接 + 全局 BA」绕开矛盾
- OA-2DGS 相对原 2DGS 的新意是把「前景不透明度」作为显式监督、并用权重把手部像素从损失里剔除，而不是把手当透明区一并优化掉

## 局限与风险
- 作者自述：ToysRU 因单段视频超 300 MB、40 个物体合计逾 11 GB 而未随论文发布，只提供代码
- 评测限于手机屏幕/摆件，未验证其他物体类别
- 我们另看出：管线前置依赖手部分割与 SAM2 跟踪质量，分割失败会直接污染 SfM 与不透明度监督
- 2DGS 仍假设静态场景，把玩中的物体相对运动靠「只取前景 + 掩码手」规避，而非显式建模
- PSNR 17.68 的着色保真度仍偏低（反照率渲染下），不足以支撑高保真贴图
- Dynhor 为复现版本（原模型已弃用），对比不完全等价
