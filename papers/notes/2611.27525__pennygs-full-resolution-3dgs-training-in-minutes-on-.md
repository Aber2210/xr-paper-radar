# PennyGS：在消费级 GPU 上数分钟完成全分辨率 3DGS 训练

## 一句话结论
不靠单点 kernel 优化，而是逐阶段消除「冗余像素 / 冗余字节 / 冗余 pass」：RTX 3060 上全分辨率 Mip-NeRF 360 单场景 6m25s（LiteGS 34m08s，3.9–5.8×），平均峰值显存仅 1.04 GB。

## 要解决的问题
3DGS 已能被高分辨率采集喂饱，但训练仍在降采样分辨率（1.0–1.6 MP 或宽于 1600 px 即缩小）与科研级 GPU 上进行；现有快速训练器的加速在消费级显卡和 4K 分辨率下基本消失，RTX 3060 上 9 个 SOTA 中有 4 个实际跑不动全分辨率场景。

## 方法详解
按「每步每个阶段都要更便宜」的思路逐阶段去冗余：用平面 RGB + 方向锥不透明度（14/18 参数替代 59）压缩 splat 并在投影阶段直接剔除；把投影与 key 生成融合成单 kernel（warp 内前缀和 + 一次原子预留缓冲）、key 由 64 位缩短为 32 位（14 位 tile + 18 位深度）；前向光栅化用 1/4 步进像素采样（32×32 tile，偏移循环覆盖全部像素）与 sub-tile 命中表；用不重叠 tile 的近似 SSIM（闭式梯度、前后向融合成单次 dispatch）；反向光栅化改为 warp-per-splat 的 per-chunk 遍历加 chunk 剔除与算术优化；反向投影与稀疏 Adam（bf16 动量）融合。

## 实验与结果
- RTX 3060 全分辨率 Mip-NeRF 360 单场景 = 6m25s（LiteGS 34m08s，LichtFeld 38m35s）
- 相对次快方法加速 = 3.9–5.8×（30k 步，两个数据集、四种 GPU 全为最快）
- RTX 4090 单场景 = 1m29s（Mip-NeRF 360）
- 平均峰值显存 = 1.04 GB（最大 1.76 GB，bicycle 场景）
- Mip-NeRF 360 PSNR = 28.96 dB（LiteGS 29.30 dB，LichtFeld 29.14 dB）
- 损失阶段耗时 = 0.23 ms/步，比 fused-ssim 少 8.5×（1.99 ms）

## 创新点与贡献
- 不是单点 kernel 加速，而是识别出「冗余像素 / 冗余字节 / 冗余 pass」三种冗余并在每一步逐阶段消除，使 4K 全分辨率训练在消费级显卡上从半小时级压到分钟级

## 局限与风险
- 质量仍略低于最高 PSNR 方法（28.96 对 29.30 dB）
- 训练用近似 tile SSIM（评测仍用标准 11×11 SSIM）
- 主机峰值内存均值 9.89 GB、最大 13.5 GB
- 代码待录用后发布
