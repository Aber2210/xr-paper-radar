# 面向第一人称视频的拓扑感知 4D Gaussian Splatting（Topo-4DGS）与 TopoEgo 基准

## 一句话结论
在自建 TopoEgo（24 段、4,618 帧、36 个动态物体、34 个拓扑事件）上，Topo-4DGS 在全部 8 个「数据集×事件族」分组中排名第一，相对各组最强基线最高提升 1.26 dB；拓扑物体整体 +0.92 dB，事件后帧从最强基线的 19.83 dB 提升到 24.30 dB（+4.47 dB），全场景 27.95 dB / SSIM 0.885 / LPIPS 0.179。

## 要解决的问题
从单目第一人称视频重建日常操作物体是 embodied AI 与 AR 的基础，但现有 4DGS 依赖形变固定表示，在切割、装配、开合等拓扑事件下同时违反两个持续性假设：（1）运动结构会变——原本一起运动的区域在事件后各自独立，而 canonical 形变方法（Deformable 3DGS、4DGS）连续形变固定几何、EgoGaussian 给每物体单一刚体运动，都无法让部件在事件后分叉；（2）表面支撑集会变——表面被创建、暴露或遮盖时，持久 canonical 基元产生缺失几何或 ghosting。作者统计这类事件出现在 68.8% 的 Ego4D 与 80.0% 的 EPIC-KITCHENS 标注视频中。已有基准要么依赖同步多视角或深度的受控采集，要么只做运动分割（EPIC-Diff），没有基准系统评测真实第一人称视频中的 fission/fusion/open/close。

## 方法详解
输入为单目第一人称视频、标定相机、物体与手部掩码及事件规格（事件族、事件时间 τ_m、终端件数 K、事件树）。Motion Bifurcation：每个物体 j 的终端件 k 各跟刚体轨迹 T_k(t)=(R_k(t),d_k(t))，每个 canonical 高斯带路由分布 P_{i,k}(t)，形变中心 μ_i(t)=Σ_k P_{i,k}(t)(R_k(t)μ_i^can+d_k(t))。路由由 Spacetime Clustering Field 给出：空间支路 z_i^sp=h_φ(γ(μ̄_i^can))∈R^K（低通位置编码 + K-means 热启动）；时间支路用事件门 g_m(t̄)=σ((t̄−τ̄_m)/β)，β=0.25；最终 P_i,k(t)=[Softmax((z_i^sp+B g(t̄))/λ)]_k，B 为可学事件偏置。时间只经事件门进入，路由在事件间稳定。Topological Boundary Resolution：件 p、q 分离时以互近邻找接触区、对匹配高斯中心拟合平面，投影后填二维凸包，生成绑定各自运动支路的新面；每个高斯带可微激活窗 W_i(t)，不透明度 α_i^t=α_i W_i(t)，新建或暴露面在事件时刻给激活边界、废弃或被遮表面给失活边界，最后小幅精修且约束 a_f≥a_s。优化：先按 EgoGaussian 逐物体估位姿、插值得粗轨迹，再联合精修 canonical 表示、运动、件轨迹与路由场；损失含掩码光度、轮廓与空间相干项，相干项对 canonical 位置加扰动后要求路由分布一致。最后联合精修只更新外观与不透明度。

## 实验与结果
- TopoEgo：从 EPIC-KITCHENS 与 Ego4D 策展 24 段（每个「数据集×事件族」3 段）、4,618 帧、36 个动态物体、34 个事件，比现有动态/第一人称基准多 1.5–6× 评测序列；提供事件时间、事件族、终端件数 K、事件树、相机内外参（EPIC Fields 或 COLMAP）、SAM 3 掩码。
- 主结果（Tab. 1，物体区域 PSNR）：本文 8 组全胜（EPIC：23.84 / 27.33 / 20.31 / 24.48；Ego4D：25.33 / 23.82 / 20.80 / 22.23），最强对手为去手变体的 Def-3DGS，最大领先 1.26 dB；6 段无拓扑变化的 Rigid Objects Control 上仍最佳（27.92/0.833/0.174）。
- 分区结果（Tab. 2）：全场景 27.95/0.885/0.179；拓扑物体 23.52/0.740/0.212（+0.92 dB）；事件后 24.30/0.742/0.227，相对最强基线 19.83 提升 +4.47 dB；其他动态刚体 25.90/0.786/0.189。
- 组件消融（Tab. 3，8 段子集）：单刚体基线 21.11 → 多物体 21.72 → 加 Motion Bifurcation 23.84（事件后 19.07→23.05，+3.98 dB）→ 加逐件边界构建 23.92 → 加事件条件时间激活 25.32（事件后 26.77、SSIM 0.786、LPIPS 0.158）。
- 设计选择（Tab. 4）：MLP 替代事件门（UT-MLP）事件后 19.41，比完整模型低 7 dB 以上；冻结 K-means 分区 19.59；去时间精修 18.26；去联合场景精修 18.57；去空间正则 20.80。
- 资源（附录 H）：单张 A100 上中位 10.9 h/段（3.6–22.8 h），8 段可比设定下为 EgoGaussian 的 1.28×；联合渲染 5.2–7.4 FPS；检查点中位 55.5 MB；边界解析与联合精修合计占训练时间中位 34%。
- 附加评测：4 段短视频上对 HyperNeRF 全面领先（全场景 31.86 vs 21.11 dB）；自动拓扑发现模块终端件数正确 26/36（72.2%）、事件族正确 16/24（66.7%）、34 个事件匹配 24 个、时间中位误差 16 帧。

## 创新点与贡献
- 首次把「拓扑变化下的第一人称 4D 重建」定义为独立问题，并给出首个覆盖 fission/fusion/open/close 的真实场景基准 TopoEgo（24 段、34 事件、含事件树与终端件数标注）。
- Motion Bifurcation：用事件门调制的 Spacetime Clustering Field 把单刚体先验扩展为事件条件的分段刚体路由，路由只随事件变化、事件之间稳定，避免逐帧 MLP 路由的伪运动。
- Topological Boundary Resolution：把 TED-4DGS 的可学激活窗改为由拓扑事件初始化，并用互近邻 + 平面拟合 + 凸包填充为新暴露或新生成表面构造真实几何，而非仅淡入淡出已有基元。
- 给出空间相干正则（对 canonical 位置扰动后路由分布的一致性约束），在无件标签下防止路由碎片化。

## 局限与风险
- （作者承认）假设部件可近似为分段刚体，拉伸、揉捏软材料等强形变交互超出假设（附录 K 图 9 给出失败案例）。
- （作者承认）依赖外部相机内外参、物体/手掩码与事件规格，位姿或标定误差会传播；自动拓扑发现目前只是独立预处理而非端到端组件。
- （作者承认）只覆盖四类离散事件，不处理渐变或复合结构变换；小部件、长时间手部遮挡、仅短暂可见的新暴露面存在几何歧义。
- （我在正文发现）24 段基准规模仍小，消融仅在 8 段子集上做，正文未报随机种子、方差或显著性，+0.92 dB 这类小幅领先的稳定性未知。
- （我在正文发现）训练成本高（中位 10.9 h/段、最长 22.8 h），渲染仅 5.2–7.4 FPS，且依赖人工标注事件树与件数，离实用采集管线仍有距离。
- （我在正文发现）TED-4DGS 与 DP-DeGauss 因无公开实现被排除，而 TED-4DGS 正是激活窗参数来源，缺少这一直接对照削弱了「事件条件化」增益的归因。

## 与文献库的关系
本文把 EgoGaussian 的每物体单刚体先验推进为事件条件的分段刚体，是对第一人称重建这条线的直接改进：相对 DeGauss（静态/动态分解）、DP-DeGauss（语义背景/手/物体分支）、Def-3DGS（MLP 形变场）、4DGS（HexPlane），它增加了件级运动分叉与表面支撑更新；相对 Dynamic 3D Gaussians 的持久基元跟踪，它允许基元在事件时被创建与退休；相对 HyperNeRF（Park 等 2021）用高维嵌入处理连通性变化，它在单目第一人称、无同步视角与深度的条件下工作，并在 4 段序列上以 31.86 vs 21.11 dB 领先。激活窗参数取自 TED-4DGS（Ho 等 2026），但把无结构监督地学时间窗改为由拓扑事件初始化再精修，这是关键区别。
