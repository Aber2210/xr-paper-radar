# Stream4D：通过因果 KV 缓存注意力实现免训练运动解耦的流式 4D 重建

## 一句话结论
首个面向因果流式骨干的免训练 4D 重建模块：发现并利用 KV Cache 中隐式编码的时序运动线索（高方差-低均值）做动态分割，再以 soft key masking 抑制动态信息在历史聚合中的累积——DAVIS-all J_M 43.06（较最强流式基线 +9.86），200 帧 93.1s 近线性扩展。

## 要解决的问题
现有流式重建方法默认静态场景假设，动态物体破坏光度一致性与对极几何，导致长序列位姿漂移与鬼影残留。已有的免训练动态分割方法（VGGT4D 依赖全局双向注意力、Easi3R 只捕获邻帧关系）与因果流式架构不兼容，且无法阻止动态信息随时间在 KV Cache 中累积。

## 方法详解
免训练、可插拔到因果骨干（StreamVGGT、Stream3R）：发现因果注意力的 KV Cache 隐式编码时序运动线索（动态物体呈高方差-低均值模式），跨浅/中/深层与时间窗自适应聚合显著性 S=(1-μ̄)⊙σ̄；与深度先验（前景量化先验 + 时窗深度变化）融合，经时序平滑、Otsu 阈值与形态学处理生成动态掩码；再用 soft key masking 直接修改缓存键 K̃_i=K_i⊙(1−γ·M_i)（作用于前几层解码器），抑制动态区域在历史聚合中的干扰；光度/几何一致性损失限制在静态区域，静态点云增量更新。

## 实验与结果
动态分割（DAVIS，流式单遍因果）：J_M 在 DAVIS-2016/2017/all 上分别为 43.39/46.45/43.06，较最强流式基线 StreamVGGT*（34.91/37.33/33.20）绝对提升 +8.48/+9.12/+9.86；J_R 39.34/42.90/41.32 vs 23.52/33.86/29.24；离线上界 VGGT4D 为 62.12/56.45/50.75。DyCheck 位姿（vs Stream3R）：ATE 0.014（↓6.7%）、RTE 0.017（↓5.6%）、RRE 0.539（↓1.1%）。效率（512×384，单卡 A100，序列 10–200 帧）：Easi3R 在 N=100 达 260.0s 且在 200 帧前 OOM；Stream4D 在 N=200 为 93.1s，与 StreamVGGT 84.1s 相当（约 +10% 开销），近线性扩展。

## 创新点与贡献
1. 首个面向因果流式架构的免训练 4D 重建框架（区别于全局双向的 VGGT4D 与成对的 Easi3R）
2. 揭示并利用 KV Cache 中因果注意力隐式编码的时序运动线索，跨层跨窗自适应聚合
3. 直接在 KV Cache 上做 soft key masking 解耦动态/静态，无需重训练或改结构，显著抑制长序列鬼影

## 局限与风险
- 当前聚合主要依赖注意力统计与深度先验，作者计划引入跨尺度时序模式与语义感知显著性
- 仅输出动态掩码与静态场景重建，动态物体本身的重建留作未来工作
- 评测限于 DAVIS/DyCheck，未覆盖更广泛的流式场景类型

## 与文献库的关系
作为即插模块改进 StreamVGGT/Stream3R 等因果流式骨干；把 VGGT4D/Easi3R 的免训练动态分割思想首次适配到因果流式设定，并以二者离线结果为性能上界。

## 可复现性
免训练集成于预训练因果骨干，实验在单卡 NVIDIA A100 完成；正文未声明代码发布计划。
