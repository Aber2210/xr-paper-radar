# DEFDVO：面向等距柱状投影图像的可变形深度视觉里程计

## 一句话结论
球面可变形特征+接缝一致 BA+球面梯度选块，TartanAirV2 ATE 0.201→0.042 m（4.8×）。　球面可变形特征 + 接缝一致 BA + 球面梯度选块，TartanAirV2 平均 ATE 0.042 m（360DVO 0.201，4.8×），8 条序列全部 <0.12 m。

## 要解决的问题
360° 相机每帧覆盖全视球，大旋转下仍保有重叠，但 ERP 带来三重几何问题：纬度相关畸变使固定矩形卷积采样失配；方位角周期却在左右边界被人为断开，跨接缝轨迹会断；每像素张开的立体角按 cosφ 变化，均匀采样过度代表极区。360DVO 采样固定不随内容自适应、未显式处理周期性与非均匀采样；CubeDVO 以立方体重采样换来面边界不连续。

## 方法详解
在 DPVO 的稀疏 patch 图上改几何。相机模型：θ=(u−c_x)/f_x、φ=(v−c_y)/f_y，f_x=W/2π、f_y=H/π，单位视线 n=(sinθcosφ, sinφ, cosθcosφ)ᵀ；结构用逆欧氏距离 d=1/‖P‖（而非逆 z 深度，后者在侧向与背后失效）。投影：x_kj=R_ij n_k+d_k t_ij，θ'=atan2(X,Z)、φ'=atan2(Y,ρ)、u'=(f_xθ'+c_x) mod W。接缝：wrap(δ)=((δ+W/2) mod W)−W/2 用于残差与光流损失；相关查询在 7×7 窗、两级金字塔上按特征图宽度取模水平索引，编码器用循环 padding。BA：最小化 Σ‖r_kj‖²_diag(w)，球面雅可比 J_Π 的行范数为 f_x/(s cosφ') 与 f_y/s，故极区测量权重被放大，需配合选块。特征：q_κ(p)=p+p_κ+Δ^sph_κ(v)+Δ^net_κ(p)，Δ^sph 为冻结的 SphereNet 解析偏移（随纬度约 1/cosφ 横向扩张），Δ^net 为 DCNv2 学习的纬度条件残差，零初始化使训练起点等价球面卷积，调制门 m_κ=2σ(ℓ_κ)。选块：p(φ)∝cosφ 且 |φ|≤75°，3× 过采样后按 s(p)=g(p)·cosφ(p) 排序（前者校正候选密度，后者抑制病态高纬测量）。损失 L=0.1L_flow+10L_pose，pose 在 Sim(3) 对齐后计算，flow 用 wrap_{W/4} 的水平位移。训练 120k 步、0.5 尺度、H100 约两天；推理 192 patch、7.1 FPS。

## 实验与结果
- TartanAirV2 Set1（360DVO 划分）：平均 ATE 0.042 m vs 360DVO default 0.202 / fast 0.201（4.8×），是唯一在 8 条序列上 ATE 均 <0.12 m 的方法。
- 最难 OldTownNight hard：ATE 从 360DVO 的 1.260 m 降到 0.116 m；RPE(t) 0.008→0.006 m/frame、RPE(r) 0.043→0.026 °/frame（对 360DVO fast）。
- TartanAirV2 Set2（CubeDVO 划分）：平均 ATE 0.088 m，优于 360DVO default 0.142（1.6×）、DPVO 2.318（26×）、CubeDVO 1.02（>10×）。
- 真实 360DVO 数据集：Easy 3.26 m / Hard 3.29 m，对比 360DVO default 3.60/6.06、fast 5.94/3.45、DPVO 7.83/6.92。
- 跨难度一致性：Easy 与 Hard 仅差 0.03 m；速度 7.13 FPS（1920×960），360DVO default 5.96、fast 16.62。

## 创新点与贡献
- 与 360DVO 的固定球面采样比：首次把「冻结解析球面先验 + 学习纬度残差」的可变形卷积引入 ERP VO，并把方位周期性贯通特征、相关、BA 残差与损失；与 CubeDVO 比不重采样、不引入面边界。
- 对比基线：360DVO（default / fast）, CubeDVO, OpenVSLAM, DPVO（针孔）, DROID-SLAM, MASt3R-SLAM, VGGT-SLAM

## 局限与风险
- 只有 VO，无回环与全局优化；DCNv2 编码器占每帧耗时 67%（1920×960，94/140 ms）到 82%（全分辨率，369/450 ms），限制实时；真实集上部分序列仍有 >20 m 的失败（如 seq06 22.20 m）。
- 消融：逐步叠加（360DVO 数据集 ATE）：Equirect. DPVO 4.36 → S-ResNet 4.02 → 接缝感知 3.95 → DCNv2 零初始化 3.82 → 几何初始化 3.69 → 球面梯度选块 3.27（最大单项增益）。训练/评测选块不一致会显著变差：S-Grad 训练改用 Grad 评测，ATE 3.27→5.72。
