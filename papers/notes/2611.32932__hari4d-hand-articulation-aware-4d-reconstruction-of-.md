# HARI4D：感知手部关节运动的四维人-物交互重建

## 一句话结论
首次把「全身—手臂—腕—手指」的操作层级写进单目 4D HOI 重建：物体作固定锚点、ReachNet 在身体/手臂层把人拉到物体旁、TouchNet 在指级依时序局部表面几何定形抓握，并把运动历史以 FiLM 注入物体位姿精化——ARCTIC 物体 CD 6.40 cm vs CARI4D 14.55（−56%），手部接触 F1 0.866→0.921。

## 要解决的问题
从单目 RGB 视频重建度量尺度的 4D 人-物交互（HOI）对游戏、VR 与机器人学习都很关键，但涉及关节化手部时尤其困难：深度歧义使人与物体的相对摆放欠约束，运动又带来持续变化的遮挡，且越靠近接触点视觉证据越弱——身体占据大片像素，而手腕与手指可能只有几个像素并在操作中被物体遮住。已有全身 HOI 方法（CARI4D、InterTrack）把手当作无精细关节的末端，导致手穿入物体或悬空（CARI4D 在 ARCTIC 上手指接触精度仅 0.794、穿透 15.77mm）；手-物方法虽恢复关节化手，却丢掉支撑性的全身姿态，而腕部是否合理恰恰依赖手臂与身体。

## 方法详解
按操作的自然层级由粗到细重建。初始化：MoGe-3 估计度量深度与内参（首帧估计后固定），SAM 3D Body 逐帧恢复人体并转 SMPL-X；用可见身体顶点深度与深度图中位数差 δ_t 做时序平滑的深度对齐；在静止区间内用 HOI-DETR 找到“手-物接触且深度重叠”的帧 A 估计物体度量尺度，用物体可见面积最大的静止帧 B 经 SAM 3D 重建规范网格，再用 FoundationPose 在 A 帧定尺度。History-conditioned Object Tracking：给 FoundationPose 精化器加 FiLM 历史调制，把前 H=90 帧的相对位姿特征 δ（旋转轴角/ρ 与平移/r 归一化后 clip±5，按可用性二值掩码）作为运动历史，逐通道 scale/shift 注入旋转与平移解码器，再配速度卡尔曼滤波与失败重注册，得到稳定的物体锚点，且该轨迹在后续人体精化中固定。ReachNet（Refinement around contact hints）：在人体与物体上取锚点并查询最近点 q 与法向 n，用 Fourier 特征 g=[γ(p),γ(q-p),γ(n)] 编码局部几何，把手部 token 加上 HOI-DETR 的图像接触标志嵌入；身体与手臂 token 拼接后过时空注意力（先时间后空间），双头分别输出身体与手臂位姿增量，损失含旋转/顶点 L2、速度加速度 L1、射线方向惩罚（保投影、放开深度）与接触项，推理迭代 3 次。TouchNet（Temporal Object sUrface Contact for Hands）：对每只手的指关节/指尖锚点取物体表面 M=64 个最近点（相对位置、法向、<4cm 指示，均在关节局部系），PointNet 聚合 + 手腕系位置嵌入 + 接触/可见标志嵌入，两个时空 transformer 块交替在时间与锚点维自注意力，回归手指位置偏移与腕部朝向更新，经 IK 转回 SMPL-X 手部参数；损失为位置/加速度 L2 与基于六个手部部件 SDF 的 Huber 表面损失（接触则拉向表面、否则惩罚穿透）。

## 实验与结果
- ARCTIC（训练未见）：物体 CD 6.40cm vs CARI4D 14.55（降低 56%）、联合 CD 5.21 vs 9.13（降低 42.9%）
- ARCTIC 接触质量：手部接触 F1 0.866→0.921（精度 0.794→0.886、召回 0.952→0.960），穿透 15.77→3.80mm，悬空 2.90→1.43mm，MJ2O 22.69→10.13mm
- ARCTIC 人体/物体加速度：0.074 / 0.104 cm/frame²，远低于 CARI4D 的 0.336 / 0.748
- BEHAVE：联合 CD 7.42→6.55cm（−11.8%）、人体加速度 −57.8%（1.385→0.585）、物体加速度 −54.0%（1.024→0.471）、穿透 28.80→18.38mm
- 与图像法 GraspHOI 在 1fps 关键帧对比：F1 0.897→0.918、穿透 11.97→3.71mm、MJ2O 18.76→10.17mm
- 效率：单帧 1.97s（RTX 5090），对比 CARI4D 4.83s、InterTrack 12.64s、GraspHOI 47.5s（逐图优化）

## 创新点与贡献
- 首次把“全身—手臂—腕—手指”的操作层级显式写进单目 4D HOI 重建流程：先用物体作为固定锚点，再由 ReachNet 在身体/手臂层面依据局部几何 + 图像接触证据把人拉到物体旁，最后由 TouchNet 在指级依据时序局部表面几何定形抓握，从而同时具备全身支撑与关节化手指
- 技术上把运动历史以 FiLM 注入物体位姿精化器（而非仅靠卡尔曼平滑），并用部件级 SDF 表面损失在有接触标志时拉向表面、无接触时只罚穿透，避免了“一味拉向物体”造成的高召回低精度

## 局限与风险
- 假设物体为刚性，因此在 ARCTIC 上不得不筛掉物体关节变化超过 5° 的片段，无法处理可动物体（抽屉、笔记本电脑）
- 依赖多个外部基础模型与输入掩码（SAM 3D Body、MoGe-3、HOI-DETR、SAM 3D、FoundationPose），误差会逐级传导，1.97s/帧也远非实时
- 评测依赖每 300 帧窗口与 GT 对齐后再算指标，长时序全局一致性未被单独度量
- 手部接触标签来自 HOI-DETR 的二值判断，接触漏检会直接影响 TouchNet
