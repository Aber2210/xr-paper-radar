# TacHOI：第一视角视频中接触感知的物体重建与跟踪

## 一句话结论
把「已标定手 + 空间分离的实测接触」当物理卡尺，无模板、无深度、无训练即破解单目尺度—深度歧义：ARCTIC ADD-S* 3.6 cm（最近基线 15.6 cm）、相对尺度误差 4.0%（SAM 3D 先验 12.0%）。

## 要解决的问题
第一视角视频是可扩展的机器人示范来源，但单目恢复公制物体几何与运动受尺度—深度歧义和手部遮挡困扰；仅由图像推断的接触与形状先验（掩码、2D 轨迹、生成先验）在数学上无法唯一确定公制尺度与深度。

## 方法详解
免训练框架：先用现成模型初始化手（YOLO + HaMeR/MANO）、物体（Qwen3-VL + SAM 3 出模态掩码、Diffusion-VAS 补全非模态掩码、SAM 3D Objects 出规范网格）、相机轨迹（ViPE）与稀疏 2D 轨迹（CoTracker3）。把 16×16 压力图转成两类公制几何约束：对应无关的触觉接触项（在 84 个 DexGraspNet 候选接触点上取软最小值）把物体表面拉到手附近以定沿射线深度；「手当卡尺」约束比较对置接触块之间的手部距离与对应物体表面距离之差来校正各向异性尺度，另有接触展布尺度下限作为防缩项。这些与轮廓对齐、掩码吸引、稀疏轨迹、静场景先验联合优化手姿态、物体逐帧位姿与各向异性尺度。

## 实验与结果
- ARCTIC ADD-S* = 3.6 cm（最近基线 Do As I Do 15.6 cm，BundleSDF 21.4 cm）
- HO3D ADD-S* = 2.8 cm（BundleSDF 3.3 cm）
- ARCTIC 沿射线误差 = 1.8 cm（基线 17.5 cm），质心误差 5.6 cm（基线 16.4 cm）
- ARCTIC 相对尺度误差 = 4.0%（SAM 3D 先验 12.0%）
- ARCTIC F@5mm = 47.3%（SAM 3D 先验 45.0%），HO3D F@5mm = 77.4%

## 创新点与贡献
- 首次把「已标定手 + 空间分离的实测接触」当作物理卡尺，在无物体模板、无深度、无训练的条件下破解单目尺度—深度歧义，并同时定深度与各向异性尺度

## 局限与风险
- ARCTIC/HO3D 的触觉是按真值位姿合成的，OpenTouch 上常失败且缺乏独立物体位姿/尺寸真值
- 只调各向异性尺度而不细化网格形状，几何大多继承 SAM 3D
- 片段内抓握变化少，触觉能提供的形状信息有限
