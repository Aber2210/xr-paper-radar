# FIRE3D：一分钟内完成的前馈交互式三维场景重建

## 一句话结论
把实例感知与物体级生成合成一条前馈批处理流水线，用层级压缩潜表示让多物体并行解码在单卡可行：2.66 s/物体（Boxer 136.24 s）、iTHOR 重建 CD 1.38 cm（SAM3D 4.63 cm）。

## 要解决的问题
游戏与交互应用需要可独立编辑的物体级三维资产，而现有方法要么依赖逐场景优化或迭代搜索，要么需要预分割、点击提示或逐物体串行推理，在杂乱场景中难以规模化。

## 方法详解
输入单张 RGB 或随手视频，先估计位姿 RGB-D 观测。实例感知感知网络预测每个物体的 OBB、掩码与点云；用 SC-VAE 加 HC-VAE 把物体压到 256 KB 级紧凑潜表示，再以实例点云为条件用固定 12 步流匹配批量生成带纹理网格，按预测位姿拼装成场景（含静态背景实例）。

## 实验与结果
- 网络推理 = 2.66 s/物体（Boxer 136.24，EFM3D 61.88，SceneScript 6.27）
- iTHOR 感知 mAP = 0.52，mIoU = 0.41（Boxer 0.36 / 0.16）
- iTHOR 重建 CD = 1.38 cm，F1 = 0.71，PSNR = 23.85 dB（SAM3D 4.63 / 0.48 / 21.35）
- 单图重建 3D-Front CD = 11.24 cm（SceneGen 14.90，MIDI 20.21）
- 整体流水线 = 12 个带纹理实例在 1 分钟内完成

## 创新点与贡献
- 把实例感知与物体级生成合成一条前馈批处理流水线，并用层级压缩潜表示让场景级多物体并行解码在单卡可行

## 局限与风险
- 仅限静态室内场景
- 网络接口要求已标定 RGB-D，纯 RGB 依赖外部几何预处理
- 质量受深度、位姿、尺度与实例解析影响，不保证水密、物理稳定、可重光照与关节
