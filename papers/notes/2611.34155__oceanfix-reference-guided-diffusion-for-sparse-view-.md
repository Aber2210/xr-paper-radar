# OceanFix：参考引导扩散的稀疏视角水下三维重建

## 一句话结论
把「介质建模」与「稀疏视角补全」接在一起：用带参考路由与介质描述子的单步修复器在渲染图上学水下外观，再蒸馏回高斯——NUSR 5 视角 PSNR 23.23 / FID 25.81（SeaSplat 23.14 / 39.11），3 视角 20.67（20.27），SeaThru-NeRF 3 视角 19.86（19.82）。

## 要解决的问题
水下稀疏视角重建同时受三重约束：视角少导致几何欠约束、波长相关的光衰减与背散射把外观与介质耦合在一起，因而在新视角出现伪影与细节丢失。现有路线各自只解一半——SeaThru-NeRF、WaterSplatting、SeaSplat 把介质写进场景建模，却不解决观测不足；RegNeRF、FSGS、DNGaussian 用几何/深度正则补稀疏视角，却不建模介质。把 Difix3D+ 这类「渲染-修复-蒸馏」直接搬到水下也不行：参考特征与目标视角在空间上不对齐，且修复像素对不同颜色通道的监督可靠性不等。实测在 SeaThru-NeRF 的 5 视角设置下，SeaSplat 为 23.14 dB / 0.7274 SSIM / FID 39.11，微调后的 Difix3D+ 也只有 22.90 dB / FID 23.12。

## 方法详解
给定带位姿的水下观测 $\mathcal{O}=\{(I_i,K_i,P_i)\}$，重建高斯参数 $\theta$ 与介质参数 $\phi$，渲染 $\widetilde{I}_t=\mathcal{R}(\theta,\phi;\pi_t)$。修复器以预训练单步 Difix 为骨干，输入渲染图、参考观测 $I_r$、参考辅助图（轴向深度 $D_r$、累积物体不透明度 $A_r$、介质贡献 $B_r$、介质占比 $f_r$）与两台相机，输出保持水下外观的修复图 $\hat{I}_t$。第一阶段做介质外观适配：在四个 U-Net down-block 上加 reference router，目标特征作 query、参考 RGB 特征与介质描述子 $b_r=[B_r,f_r]$ 作 key，注意力为 $p_{ij}=\mathrm{softmax}_j(q_i^\top k_j/\sqrt{d_h}+\log\rho_j)$，支撑权重 $\rho_j=f_{r,j}v_{r,j}^{\mathrm{image}}$ 屏蔽无支撑 token，检索到的描述子按最大支撑缩放后经零初始化残差与 sigmoid 门注入；损失 $\mathcal{L}_{\mathrm{RGB}}=\mathcal{L}_2+\lambda_P\mathcal{L}_{\mathrm{LPIPS}}+\lambda_G\mathcal{L}_{\mathrm{Gram}}$，$\lambda_P=1$，$\lambda_G$ 在全局第 2000 步由 0 切到 1。第二阶段冻结全部外观参数，只训四个 geometry adapter：用相对位姿 $(R_{tr},t_{tr})=P_t^{-1}P_r$ 把参考像素按 $X_r=D_r(u_r)K_r^{-1}\tilde{u}_r$、$u_t=\pi(K_t(R_{tr}X_r+t_{tr}))$ 投到目标视角，前向 z-buffer 保留最近有效投影，支撑权重 $m_t=A_r(1-f_r)$；adapter 融合对齐后的参考特征、目标特征、相对相机嵌入、投影深度与支撑图，并以 $m_t$ 加权注入残差。几何监督用冻结的 Depth Anything V2 Large 估计修复图与训练目标的相对逆深度，标准化后取支撑加权 Smooth L1，$\mathcal{L}_{\mathrm{stage2}}=\mathcal{L}_{\mathrm{RGB}}+0.05\mathcal{L}_{\mathrm{depth}}$；推理时既不需要目标视角深度也不需要深度估计器。蒸馏侧把修复视图按「几何修复需求 × 通道可观测性」加权回灌：几何需求由归一化 alpha 贡献下相机空间高斯深度的相对离散度 $s(p)=\sigma_z/\mu_z$ 给出 $G(p)=s/(s+s_0)$；可观测性 $K_c(p)=A(p)T_c(p)$ 为通道透射率乘累积不透明度；权重 $w_{p,c}=(1+G K_c^2)/Z$ 归一化到均值 1，保留监督下限。场景损失为 $\mathcal{L}_{\mathrm{scene}}=\mathcal{L}_{\mathrm{obs}}+\lambda_1\mathcal{L}_{1,w}+\lambda_S\mathcal{L}_{\mathrm{SSIM}}$，修复器在迭代中冻结，伪视图与权重周期性刷新。训练对由 SeaSplat 构造：三/五视角重建 30,000 迭代、12k/16k/20k 欠拟合 checkpoint、位姿聚类互补重建三种退化方式，每数据集四个 leave-one-scene-out 折。

## 实验与结果
- NUSR 5 视角：PSNR 23.23、SSIM 0.7326、LPIPS 0.2283、FID 25.81（SeaSplat 23.14 / 0.7274 / 0.2296 / 39.11）
- NUSR 3 视角：PSNR 20.67、FID 30.79（SeaSplat 20.27 / 44.89；Difix3D+† 19.01 / 33.38）
- SeaThru-NeRF 5 视角：PSNR 23.21、SSIM 0.7659、LPIPS 0.2274、FID 22.96（Difix3D+† 22.90 / 0.7316 / 0.2409 / 23.12）
- SeaThru-NeRF 3 视角：PSNR 19.86、SSIM 0.6387（Difix3D+† 19.82 / 0.6125）
- BVI-Coral 零样本（5% 输入）：PSNR 18.56、FID 18.80（SeaSplat 18.43 / 23.25）
- 跨渲染器鲁棒性（SeaThru-NeRF 5 视角）：3DGS 21.30→21.99 dB、LPIPS 0.3376→0.2833；WaterSplatting 22.70→22.79 dB
- 修复加蒸馏分解（IUI3-RedSea，5 视角）：输入 21.69/0.7344/41.64 → 仅直接修复 23.57/0.7575/17.16 → 仅蒸馏 21.93/0.7491/40.98 → 蒸馏加修复 23.64/0.7579/16.40

## 创新点与贡献
- 相对 Difix3D+ 的通用「渲染-修复-蒸馏」：一是把修复模型拆成两阶段训练，先适配水下介质外观、再冻结外观只学位姿对齐的几何 adapter，使参考特征在空间上真正对齐目标视角且推理不需要目标深度
- 二是蒸馏权重不再均匀，而由深度离散度刻画的几何修复需求与通道透射率刻画的可观测性共同决定，把监督集中到「需要修且看得见」的区域
- 相对 SeaThru-NeRF / WaterSplatting 这类只建模介质的路线，这里补的是稀疏视角下的观测不足
- 相对 RegNeRF / DNGaussian 这类只做几何正则的路线，这里补的是介质耦合

## 局限与风险
- 增益幅度本身有限：NUSR 5 视角 PSNR 只比 SeaSplat 高 0.09 dB（23.23 vs 23.14），SeaThru-NeRF 5 视角高 0.83 dB，主要收益体现在 FID（39.11→25.81）
- 蒸馏加权项在消融中仅值 0.01 dB，说明「介质感知加权」这一卖点的实证支撑偏弱
- 零样本 BVI-Coral 上 PSNR/SSIM 提升仅 0.13 dB / 0.0011，属边缘改进
- 评测全是静态水下场景的渲染指标，没有几何精度（Chamfer/深度误差）与真实机器人下游任务
- 每个数据集只取四个场景、每场景单一 3/5 视角配置，未见多随机种子或视角选择的方差
- 方法依赖 SeaSplat 提供参考深度与介质描述子、依赖 Depth Anything V2 做相对深度监督，上游误差会传导
