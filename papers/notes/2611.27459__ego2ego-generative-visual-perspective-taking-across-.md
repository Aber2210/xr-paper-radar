# Ego2Ego：跨协作者的生成式视觉视角采择

## 一句话结论
首次把协作者间的视觉视角采择表述为 ego 到 ego 的条件视频生成（无外部相机、无协作者图像或姿态），用共享 3D 场景坐标 + 跨视角 ray-space 注意力 + 他视角视觉记忆注入任意视频扩散骨干：PSNR 提升 1.19–2.50 dB、布局 mIoU 15.9→20.7。

## 要解决的问题
视觉视角采择此前被简化为状态估计、几何重建或离散问答；现有跨视角视频生成要么只从输入视频推断目标视角，要么需要外部相机观测目标人物。真实协作中两人常相对而立或各自关注工作区的不同区域，被生成视角的人往往根本不在 ego 相机视野内，且存在极端视角变化、动态遮挡与稀疏视觉重叠。

## 方法详解
Ego2Ego 给预训练视频扩散 Transformer 加三个 backbone-agnostic 几何模块：其一 dense geometric rendering 把场景点云光栅化成每个视角的 scene coordinate map，同一 3D 点跨视角取同值，作为共享空间参照并显式给出表面深度；其二 relative geometric attention 把单轨迹的 ray-aligned attention 扩展到两条独立相机轨迹之间，按每个 query token 的 ray frame 对齐 key/value 的几何分量并共享时间 rotary 编码；其三 visual memory 把 ego 人过去帧按最大覆盖（子模贪心，1−1/e 保证）选出若干帧作历史上下文，补回当前 clip 之外区域。所有条件经冻结 VAE 编码后与噪声 latent 组成单一 token 序列。

## 实验与结果
- PSNR = 18.57 dB（Wan2.2-5B，WorldWander 15.94 dB，+2.50 dB）
- PSNR = 18.89 dB（Wan2.1-14B，EgoX 17.70 dB，+1.19 dB）
- PSNR = 19.57 dB（AnyView 骨干，基线 18.23 dB，+1.34 dB）
- Layout mIoU = 20.7 / 26.1 / 23.6（基线最高 15.9）
- FVD = 181.2 / 164.7 / 177.1（AnyView 基线 228.0）
- 相对最强基线的 LPIPS 降幅 = 23%–30%，FVD 降幅 22%–26%

## 创新点与贡献
- 首次把协作者间的视觉视角采择表述为 ego-to-ego 条件视频生成任务（既无外部相机，也无协作者图像或人体姿态），并用「共享 3D 场景坐标 + 跨视角 ray-space 注意力 + 以他人视角为导向的视觉记忆」三件几何模块把该能力注入任意视频扩散骨干

## 局限与风险
- 作者自述四点：ego 相机从不观测自身，故 ego 人进入协作者视野时缺乏外观参照
- 点云中不存在的表面（如窗玻璃）在 coordinate map 中成空区，会被填错
- 点云是静态的，协作过程中环境变化不被捕获
- 只在室内场景训练与评测，户外泛化未验证
