# InitFree-SfM：当无初始化 Bundle Adjustment 遇上学习式 Structure-from-Motion

## 一句话结论
给 OSE 只加一项相对深度残差（保持 variable projection 可分性），并让 metric depth 贯穿对应过滤、随机初始化与联合精化——ETH3D 位姿 AUC@20° 85.81% vs pOSE 13.91%，去掉 joint metric refinement 即跌到 31.99%，说明「代理目标」并非精度主因。

## 要解决的问题
现有 initialization-free BA（pOSE/expOSE/pOSE+rot）在 $\mathbb{R}^{3\times4}$ 松弛相机矩阵上最小化代理 Object Space Error，目标值降得很低却给不出准确重建：ETH3D 上 pOSE 的位姿 AUC@20° 仅 13.91%、AUC@5° 11.43%，后续 metric upgrade 也不稳定。根因是 OSE 只约束方向（landmark 必须落在观测视线上），对沿视线的位置没有任何约束，几何信息不足，优化收敛与重建精度之间存在系统性缺口。

## 方法详解
把 OSE 残差写成 $r^{\mathrm{OSE}}_{ij}=P_{i,1:2}\tilde{X}_j-(p_{i,3}^{\top}\tilde{X}_j)m_{ij}$，并加一项相对深度残差得到 depth-augmented OSE：$\mathcal{L}_{\mathrm{dOSE}}=\sum_{(i,j)}c_{ij}\|r^{\mathrm{OSE}}_{ij}\|_2^2+\lambda_d\sum_{(i,j)}c_{ij}\rho\left(q_{ij}^{\top}y_{ij}/d_{ij}-1\right)$，其中 $y_{ij}=R_iX_j+t_i$，$q_{ij}^{\top}y_{ij}$ 是把 landmark 正交投影到观测射线后得到的深度，除以 $d_{ij}$ 使残差为相对量、$\rho$ 为 Huber，$\lambda_d=30$ 用 5%/25%/100% 三阶段 continuation 逐步加上。dOSE 保持可分结构，于是用 variable projection 闭式消去 landmark：$v^{*}(u)=G(u)^{\dagger}z(u)$，以 Ruhe–Wedin 近似 $J_u^{*}=(I-J_vJ_v^{\dagger})J_u$ 求位姿增量，并在 $SE(3)$ 上直接更新（大问题改用 Weber 等的 inverse-expansion 截断幂级数），因此完全不再需要 metric upgrade。前端用 MoGe-2 逐帧预测 metric depth 与内参；对每对图像把预测深度反投影成 3D 点集做 RANSAC 相似变换，再与本质矩阵给出的旋转交叉校验（$\tau_R=15^{\circ}$），只保留两者一致的对，随后把保留下来的对应拼成多视 track。最后做 joint metric refinement：给每帧一个深度尺度 $\alpha_i$，联合最小化归一化重投影残差 $r^{\mathrm{img}}_{ij}$、相对深度残差 $r^{\mathrm{depth}}_{ij}$，以及相对旋转/平移/对数尺度残差 $r^{\mathrm{rot}}_{kl},r^{\mathrm{t}}_{kl},r^{\mathrm{s}}_{kl}$，再加平滑 cheirality 罚与尺度正则，用 Levenberg–Marquardt（30 步 warm-up + 至多 120 步）求解。平移项先在 metric 形式下约束、后期切换为方向约束，以降低对单目深度绝对尺度误差的敏感性；所有相机位姿从随机初始化出发（旋转在 $SO(3)$ 均匀采样、平移零均值高斯 $\sigma=0.5$）。

## 实验与结果
- ETH3D 位姿 AUC@20° 85.81%，GLOMAP(LoMa) 77.18%、pOSE 13.91%
- LaMAR 位姿 AUC@20° 80.99%，GLOMAP(LoMa) 67.93%、pOSE 10.10%
- 低重叠 ETH3D Minimal 子集 AUC@20° 75.31%，专为该场景设计的 MP-SfM 为 76.55%，但运行时间显著更低
- 去掉 joint metric refinement：ETH3D AUC@20° 从 85.81% 跌到 31.99%
- 深度一致性过滤使 ETH3D AUC@20° 提升 10.30 个百分点（75.51%→85.81%）
- 三个随机种子 ETH3D AUC@20° 85.46±0.34、LaMAR 80.76±0.77

## 创新点与贡献
- 把 metric depth 贯穿对应过滤、初始化与精化三处，并给出 dOSE 这一最小改动（只加一项相对深度残差、保留 VarPro 可分性）
- 更关键的是结论层面的新意：仅靠几何约束的 joint refinement 从随机初始化就能得到可用重建，说明代理 OSE 目标并非精度主因，这直接挑战了此前 InitFree BA 以目标函数设计为中心的路线

## 局限与风险
- 强依赖已知相机标定，用 MoGe-2 估计内参时 LaMAR AUC@20° 从 80.99% 降到 63.44%
- 作者也把无标定重建与大场景扩展列为 future work
- 严格阈值仍弱于传统 SfM（ETH3D AUC@1° 44.40% vs COLMAP 57.88%），低重叠 SMERF 上落后 MP-SfM 更多
