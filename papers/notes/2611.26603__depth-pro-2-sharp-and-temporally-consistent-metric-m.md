# Depth Pro 2：锐利且时序一致的度量单目深度估计

## 一句话结论
单一网络同时给出锐利、时序一致、度量准确的深度：11 个数据集零样本平均排名第一，Jitter 1.39 对 π³ 2.13，1080p 流式 53 fps。

## 要解决的问题
单目深度估计长期存在「边界锐利」与「时序一致」的取舍。作者在 Figure 1 用一段狐獴视频给出具体失效：单帧方法 InfiniDepth 能勾出毛发等细节，但逐帧独立推理会把狐獴放在不同距离上，depth 随时间跳变；视频方法 π³（π-cubed）能把狐獴稳定在同一距离，却在低于输入分辨率上运算，毛发被抹平。Figure 2 在 Sintel 与 Spring 上把这一现象量化为两个聚类：单帧方法占据「Boundary F1 高、Jitter 高」的左上角，多帧方法占据「稳定但边界模糊」的右下角。作者进一步指出失效机制：多帧方法靠长时序 attention（VGGT、π³）、视频扩散先验（DepthCrafter、ChronoDepth、VDA）或大视角联合优化来换稳定，这类设计需要长时序上下文与高显存，只能降分辨率处理，平滑因此发生在遮挡边界上；单帧方法则在帧间缺少任何对齐约束，度量尺度随帧漂移。另一处工程缺口来自 Depth Pro 的视场（field-of-view）估计器过重，无法支撑高帧率流式视频，使得「度量深度 + 流式」难以同时成立。训练侧，已有工作依赖多阶段课程（Chen 等、Chou 等、Lin 等、Wang 等），流程复杂且难以把图像与视频混合训练。

## 方法详解
架构为多视角 ViT + DPT 解码器，输入 1 至多帧并联合处理，每帧输出一张逆深度图。骨干从 DINOv3 ViT-S/16、B/16、L/16、H+/16 初始化，patch 16×16，每个 patch 一个 token；位置编码用 2D 旋转位置编码（RoPE），但两个轴都除以长边 max(h,w)，即 y′=2(i+1/2)/max(h,w)−1、x′=2(j+1/2)/max(h,w)−1，从而保留长宽比信息，且刻意不编码帧序号，使网络对帧置换等变，可直接复用单图预训练权重而无需新增跨视角 block。前 1/3 的 L 层只做帧内 self-attention，其余 2L/3 层交替帧内与跨帧 attention；跨帧层不增加参数。DPT 解码器在若干中间层抽取 token 重组为多尺度特征图，投影到统一通道后融合，上采样用转置卷积替代双线性插值。网络预测按焦距归一化的逆深度，再乘已知或估计焦距得到度量深度。视场估计器独立且轻量，基于 DINOv3 ViT-S/16 共 23.5M 参数，在带 EXIF 焦距的 Flickr 照片上端到端微调，预测短边视场再换算焦距；多帧输入取各帧估计的中位数；对 1080p，它只给 S/B/L/H+ 增加约 8%/3%/1%/0.5% 计算。训练用 19 个数据集，以合成 GT 为主，刻意不对 GT 深度做插值或缩放，避免深度不连续处产生 flying pixels；图像视为长度 1 的 clip，视频与多视角 clip 最多 32 帧；数据集采样概率 p_i ∝ n_i^(1/T)，T=2，并对小数据集设权重上限。按 token 组 batch，每 GPU 预算 73,728 token，例如 18 帧 1024×1024。总损失为 L = L_mae + L_ssi + L_mge + L_mvc 的无加权和：L_mae 是在焦距归一化逆深度上的 trimmed L1，只用于有度量 GT 的源；L_ssi 先把预测与 GT 各自归一化到零中位数、单位平均绝对偏差再做 trimmed L1，用于全部数据；两者按图像丢弃损失最大的 τ 比例像素，合成数据 τ=1%、真实数据 τ=10%；L_mge 在 M=3 层高斯金字塔上匹配一阶梯度，只用于合成数据。L_mvc 是多视角自一致项：把像素 p 用预测深度反投影、用 GT 位姿重投影到帧 j 得 (p′,z′)，惩罚逆深度偏差 L_mvc=(1/|P|)Σ|1/z′−1/Ẑ_j(p′)|，只在一定比例随机像素子集 P 上计算；遮挡与运动物体用 GT 深度一致性过滤，若重投影深度与目标处 GT 深度相差超过 2% 则丢弃，因此可用于动态场景。优化为 100K 步、128 张 B200、AdamW、峰值学习率 5e-5、5% warmup 后余弦退火。推理支持两种流式：buffered 把视频切成 N 帧 clip、相邻 clip 重叠 K 帧并线性混合；unbuffered 用因果跨帧 attention，过去帧的 K/V 固定存入 FIFO cache，每帧只看自身与前 C−1 帧，仅跨帧层使用 cache。模型族参数为 24.3M/96.5M/334.0M/872.1M。

## 实验与结果
- 单帧零样本度量深度在 11 个数据集（iBims、Middlebury、Booster、HAMMER、ETH3D、DIODE、KITTI、nuScenes、Sintel、Spring、DyDToF）上，GT 内参与预测内参两种条件下平均排名均为第 1
- KITTI δ1 达 98.2（GT）/87.9（预测）
- 视频设定（KITTI、Sintel、Spring、DyDToF，统一 50 帧 clip）平均排名第 1：KITTI 98.1/97.2、Sintel 51.2/41.4、Spring 51.7/45.0、DyDToF 86.2/94.8
- 边界锐度：单帧平均排名 1.6（Depth Pro 为 5.4，InfiniDepth 为 3.0）
- 视频平均排名 1.3（Sintel 43.4、Spring 16.8、DyDToF 34.4，次优 InfiniDepth 为 2.7）
- 时序一致性 Jitter（乘 100）：Sintel 1.39、Spring 0.86，平均排名 1.5
- 次优 π³ 为 2.13/1.04，Depth Pro 为 11.26/8.99
- 焦距估计：6 个数据集 δ25 平均 88.6%，对比 Depth Pro 71.7%、UniDepthV2-L 48.8%、DA3-NGL 56.5% 量级，全部排名第 1
- 估计器 118 fps @1080p
- 流式吞吐：Depth Pro 2-S 在单张 B200 上 1080p 达 53 fps（高于 30 fps 录制帧率），Depth Pro 2-H+ 为 8 fps，参数量跨度 24M 至 872M
- 训练不做 resize 的受控实验使边界精度相对 Depth Pro 的缩放方案提升超过 5 个百分点
- 消融确认：原生分辨率、跨帧 block 数量、buffered 的 N/K 选择与 unbuffered 的 cache 窗口 C 均单独影响锐度、抖动与延迟的 Pareto 位置

## 创新点与贡献
- 用单一 ViT 同时处理 1 至 32 帧并在原生分辨率输出，靠无参数跨帧 attention 获得时序稳定，而不是靠视频扩散先验或长时序模块。
- 位置编码不编码帧序、双轴共用长边归一化，使网络对帧置换等变，可直接继承单图 DINOv3 权重，避免为多视角新增随机初始化 block。
- 多视角自一致损失用 GT 位姿替代光流做重投影，并用 2% 深度一致性剔除遮挡与运动像素，使一致性约束可用于动态真实场景。
- 图像当作长度 1 的 clip 与视频、多视角混合训练，让单帧也能学到度量尺度，避免多阶段课程。
- 给出 buffered 与 unbuffered 两种流式推理（后者带 FIFO KV cache），并配套一个 118 fps 的轻量视场估计器，形成精度-延迟的模型族 Pareto 前沿。

## 局限与风险
- 作者强调已消除锐度与一致性的取舍，但代价是训练期必须依赖 GT 相机位姿来计算 L_mvc，未标定或位姿漂移的手持视频无法直接受益
- 零样本表里 Sintel、Spring 的 δ1 仍明显低于 UniK3D、UniDepthV2 等专用方法，说明跨域度量精度并非全面领先
- 评测以每段前 50 帧、单次仿射对齐后的 Jitter 为主，长视频与累积漂移只在附录用 E.3 的受控实验讨论，缺少大规模真实长序列统计
- 最大模型 872M、1080p 仅 8 fps，移动端与头显端部署仍不现实
- 训练以 19 个合成数据集为主，真实数据 τ 放宽到 10% 也暗示噪声标签的依赖
- 边界 F1 绝对值仍低（Sintel 约 40），毛发级边界只是相对改善
