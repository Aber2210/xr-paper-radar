# AVI-HT：面向手套式 3D 手部追踪的自适应视觉–IMU 融合

## 一句话结论
AVI-HT 把 12 个手套 6-DoF IMU（200 Hz，14 帧窗口 14×23×3）与头显单目图像（60 Hz，512×640）经带运动学先验掩码的层级跨传感器注意力融合，在自建 DexGloveHOI（100K+ 帧、2.4M IMU 样本、4 名被试、17 类任务、3.5 h）上把 UMETrack 的 MKPE 从 12.342 mm 降到 10.359 mm（−16.1%）、指尖 F.MKPE 从 17.478 降到 13.253 mm（−24.2%），MANO 下 PA-MPJPE 13.754→10.519 mm（−23.5%），接触丢失率降 8.5%。

## 要解决的问题
第一人称手部追踪的核心矛盾是：抓握越紧，手越被物体遮住，而 AR/VR 与遥操作恰恰发生在接触最密集的时刻。纯视觉方法（HaMeR、METRO、MeshGraphormer）泛化好，但遮挡下可解释的 kinematic 构型集合过大，误差骤增；纯 IMU 方案多用密集 9-DoF 阵列，磁力计受室内电磁干扰，6-DoF 虽避开磁干扰却缺绝对朝向并累积陀螺漂移，无法给出全局腕部位姿。视觉–IMU 融合在全身动捕（DIP-IMU、TransPose）已证明有效，但细粒度手部几乎空白，原因被作者归为两点：缺少适合自然操作的无创 IMU 手套硬件，以及缺少同步 ego 视频 + 密集 IMU + 3D 真值的数据集。已有手部数据集（HOI4D、HOT3D）或为纯视觉、或受控棚拍，均不含惯性信号，因此无法判断融合带来真实增益还是仅增加复杂度。

## 方法详解
硬件与信号：Meta Quest 单目灰度相机 60 Hz、512×640；全手覆盖手套 12 个 6-DoF IMU，四指近/远节各一、拇指与手背各一，200 Hz。每个视频帧对齐最近 IMU 时间戳，取此前 14 个样本，每样本由 6-DoF 算重力向量并与 3 轴陀螺拼接，得 14×23×3 窗口。真值由光学标记动捕给出，先解为 UMETrack 位姿，再用 Levenberg–Marquardt 转 MANO。模型：IMU 编码器把 3 维线性映射到 69 维、加 14 步正弦位置编码、2 层 transformer，取末步经两层 MLP 得 F_imu∈R^{23×d}；视觉编码器分两版——UME 用 ResNet + FTL（把 2D 特征经 SE(3) 提升为相机解耦 3D 表示）+ 卷积 RNN，MANO 用 ViT-Huge 编码 256×192 crop 得 N×1280 patch token。融合：Z=[F_vis*,s_1,…,s_12]∈R^{13×d}，运动学先验掩码 M_ij=−α·d_geo(i,j)，一级注意力 softmax(QK^T/√d_k+M)V；因单视觉 token 面对 12 个 IMU token 易被淹没，二级把 12 个传感器 token 池化为 s̄，与视觉 token 组成 2×d 序列做自注意力再校准。输出：UME 头解码 22 维关节角、腕部 (R,t)∈SE(3) ，用 landmark NLL + 关节角损失经可微前向运动学得 3D 点；MANO 头解码 θ、β、相机 π，用 3D/2D + 对抗损失。

## 实验与结果
- DexGloveHOI：4 名被试、每 session 17 类精细操作任务、45–55 min 可用采集、共 3.5 h，产出 100K+ ego 帧、2.4M IMU 样本、720 GB 同步记录；训练用另一份约 8M 图像的私有手套数据，被试/场次/任务与评测完全不相交。
- UMETrack 表示（Table 4）：UMETrack 12.342 / 17.478 / 9.359 / 17.798 / 76.059 / 81.433；UMETrack+EKF 15.406 / 18.658 / 7.891 / 14.232 / 70.903 / 84.210；IMU-Tracker 仅 7.151 / 12.923 / – / 85.769；AVI-HT 10.359 / 13.253 / 7.021 / 12.785 / 79.315 / 85.859（MKPE/F.MKPE/MKPE.T/F.MKPE.T/P.A/P.A.T）。
- MANO 表示（Table 5/6）：HaMeR 13.754 / 12.736 / 0.516 / 0.882 → AVI-HT 10.519 / 9.265 / 0.628 / 0.936（PA-MPJPE / PA-MPVPE / F@5 / F@15），降幅 23.5% 与 27.3%。
- 融合消融（Table 1）：early concat 11.928、late fusion 12.139、pooled IMU token 11.956、fusion-1 only 11.113、w/o k-prior 10.901、full 10.359（MKPE）；去运动学先验 +0.54 mm、去二级注意力 +0.75 mm。
- 遮挡分层（Table 3）：按每帧被遮挡关键点数分箱，UMETrack 的 F.MKPE 从 16.525 涨到 21.741（+5.2 mm），AVI-HT 从 13.034 到 15.539（+2.5 mm）；优势由 3.5–3.9 mm 扩大到 6.2–7.5 mm。
- 跨被试（Table 2）：四名留出被试 MKPE 8.852–11.266 mm、P.A 77.486–82.333，每人六项指标均优于聚合的 UMETrack。
- 接触保持（Table 7，15 个木块 session）：Disp. 9.91→8.96 mm、Ret@5 56.60→59.41、Ret@10 84.12→86.73、Capt. 58.09→61.20、Longest 50.13→53.84、Loss/s 0.911→0.834。

## 创新点与贡献
- 用「逐指 IMU 手套 + 头显单目」这一互补组合解决抓握遮挡，并给出同步采集 + 动捕真值的完整数据链路，填补手部视觉–惯性融合的数据空白。
- 提出带运动学先验掩码的层级跨传感器注意力：M_ij 用骨架跳数编码物理邻近性，使遮挡时注意力自动转向对应 IMU；二级 2-token 自注意力纠正 1 视 vs 12 IMU 的 softmax 失衡。
- 把注意力首行 a_vis 直接解释为「每个 IMU 的信任度」，并用逐指/逐活动热图验证对角线效应，给出可解释的融合证据。
- 同时覆盖实时 AR/VR（UMETrack，22 关节角 + SE(3) 腕）与离线重建（MANO，θ/β/π）两种表示，证明融合设计与骨干无关。

## 局限与风险
- （作者承认）数据手套改变手部外观，对期望裸手图像的下游管线存在 domain gap，需手部 avatar 渲染弥补。
- （作者承认）只验证了一种手套，对其他传感器布局、形态与 IMU 规格的泛化未知。
- （我在正文发现）摘要把 24.2% 归为「wrist-aligned 变体」，但 Table 4 中 24.2% 对应的是指尖 F.MKPE（17.478→13.253），腕对齐 MKPE.T 实为 9.359→7.021（−25.0%），指标口径表述不一致。
- （我在正文发现）未声明 DexGloveHOI 与代码是否公开，训练还依赖约 8M 图像的私有手套数据，外部无法复现。
- （我在正文发现）仅 4 名被试、单一 Quest 头显与单一手套硬件，缺少跨设备/跨光照/跨手型实验。
- （我在正文发现）未报告推理延迟、功耗或端侧算力占用，而「实时 AR/VR」是其核心卖点之一。

## 与文献库的关系
视觉侧以 UMETrack（Han et al., 2022）与 HaMeR（Pavlakos et al., 2024）为骨干基线，分别代表 AR/VR 实时关节角回归与 Transformer 大规模手网格回归；上游可追到 METRO、MeshGraphormer 的自注意力网格建模。惯性侧与 IMU-Tracker（Sarker et al., 2026）的 6-DoF 纯惯性方案对照。融合承接全身动捕的 DIP-IMU（Huang et al., 2018）与 TransPose（Yi et al., 2021），手部与 UMETrack+EKF（Lei et al., 2023）这类后验滤波直接比较。数据侧对标 HOI4D、HOT3D 等纯视觉手–物数据集，差异是加入 12 路同步 IMU 与动捕真值。本篇为旧稿 v2 再公告（v1 未入馆），按首次入馆处理。

## 可复现性（代码/数据/硬件）
代码与 DexGloveHOI 数据集均未见公开声明，正文只描述采集协议与附录 A/B 的实现细节（含动捕布置）；训练使用约 8M 图像的内部手套数据集，评测集与训练集在 subject/session/task 上不相交但不可获取。硬件为 Meta Quest 单目灰度相机 + 自研 12 路 6-DoF 手套 + 光学标记动捕，复现门槛高。基线（UMETrack、HaMeR、IMU-Tracker、UMETrack+EKF）均在同一训练集上微调。
