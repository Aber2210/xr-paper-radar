# 面向点云上采样的多速率流匹配

## 一句话结论
冻结流模型、按patch在线优化积分步数；PU1K 16倍上采样CD 1.6346，比PUFM++的2.2119低26%。　冻结流模型、按 patch 在线分配积分步数，PU1K 16× 上采样 CD 1.6346（PUFM++ 2.2119，−26%）。

## 要解决的问题
流匹配上采样器用固定时间离散化，整形状共享同一求解预算，但同一形状内局部重建难度差异很大：平滑区只需粗轨迹，边界、薄结构与稀疏邻域需更细细化。PUFM++只重排共享全局时间网格，Grad-PU对点坐标求梯度而非求解预算，PatchScaler按图像块难度分组，TG-MSFM做全局多尺度门控，都没有从冻结上采样器的响应出发选patch专属预算；曲率或密度也无法反映流在该patch上的实际行为。

## 方法详解
先把稀疏点云切成重叠局部patch（64点）并确定性插值到目标点数，得到初始稠密patch；共享的rate-conditioned速度场以PointNet++编码几何、6层Mamba预测速度，时间/速率嵌入由(τ_i, Δt_i)调制，Euler更新为 x^{s+1}=x^s+Δt·v(x^s,τ,Δt)，Δt=1/K_i、τ=s/K_i，故只有数值分辨率变、学习到的输运不变。速率选择把整数预算K_i∈[1,25]松弛为连续κ_i，展开25步软rollout，每步用sigmoid活动门 a=σ(α(κ−(s+1/2))) 平滑控制该步贡献，端点P_i(κ_i)对κ可微。引导能量只用稀疏输入，不用稠密真值与法向：有向平方集合差异L_cov（把生成点吸向观测支撑，避免对称项惩罚合法中间点）、点面残差L_surf（KNN=12的邻域协方差最小特征向量为法向，允许切向填补空隙）、间距正则L_rep（低于参考中位近邻距离才惩罚）。对κ做12次梯度下降（学习率1.0），网络参数、几何特征与参考集全冻结，梯度经端点敏感度S=∂P/∂κ回传；随后把κ投影到最近整数预算，从初始patch用标准Euler重跑，变换回原坐标并合并重叠输出。

## 实验与结果
- PU1K 4倍：CD 4.0434对PUFM++ 4.1887，P2F 1.5498对1.6167，JSD 2.4754对2.6230，三项最优。
- PU1K 16倍：CD 1.6346对PUFM++ 2.2119，P2F 1.5663对1.9847，JSD 1.0670对1.4091。
- PUGAN 4倍：CD 10.044对PUFM++ 10.066；PUGAN 8倍HD 9.5972对12.375最优。
- ScanNet真实数据：CD 1.2112（1e-3）对PUFM++ 1.2305、PUFM 1.4490。
- 代价：平均NFE 16.48（PUFM与PUFM++均为5），延迟936.10ms，峰值显存0.1413GB。
- 同预算随机置换（平均16.48步、总Patch-NFE相同，10次重排）明显劣于MRFM的分配。

## 创新点与贡献
- 相对PUFM/PUFM++（改全局路径或共享时间网格采样位置），改为patch级求解预算，并由冻结模型的响应而非曲率密度启发式决定，无需单独训练router。
- 对比基线：PU-GCN, Grad-PU, PUDM, PDANS, RepKPU, PUFM, PUFM++

## 局限与风险
- 精度导向，软rollout与在线优化带来显著额外开销（NFE 16.48、936ms），整数投影仍是近似；尖边与退化邻域上局部平面不可靠。
- 消融：预算置换实验证明增益来自分配位置而非步数分布；500patch上步数与CD@8的Spearman ρ=0.4812，高于曲率0.3161、稀疏度0.2575、P2F@8的0.1412、非均匀性0.0602；用MLP或RK45替代梯度引导均更差（CD 4.0863、4.0712对4.0434）。
