# HIBS：面向在线重建的分层增量 Beta 泼溅

## 一句话结论
HIBS 将有界 beta kernel 形状参数用作几何置信度 Dial：深度可观测性+MVS/单目一致性初始化固/软原型，误差驱动重定位回收濒死原型，闭式矩匹配实现形状保持 LOD 合并；MipNeRF360(otf) PSNR 27.47（较 i3DGS +0.81 dB）、优化时间最多省 40%，CityWalk 25.81 dB（+4.1 dB over OtF NVS），可扩展至 2000 帧。

## 要解决的问题
在线 3DGS 每关键帧只 spawn 一次原型并仅优化几十次迭代，无法依靠 clone/split densification、opacity reset 或长优化修复劣化初始化——spawn 出来什么基本就是最终模型，关键决策必须在初始化时基于可测证据做出。高斯原型仅中心全不透明、其余半透，实心表面需大量重叠与长优化；naive 直接 spawn 固实 kernel 又有害（错误深度的近不透明基元挡住透射、抑制其后梯度），且低光度误差不保证几何正确（小三角化基线下多深度解释性等价）。

## 方法详解
①Beta kernel：α=o·B(x;b), B=(1−x)^{β(b)}, β(b)=4e^b, x=r²/9, r≤3；b=0(β=4) 近高斯，低 β 平顶近 surfel，高 β 松软；球-beta 颜色基 C(v)=c_0+Σ_k a_k max(0,d_k·v)^{4e^{b_k}}，波瓣零初始化+随机朝向。②Observability-aware spawning：三角化角 c_z=clamp((B/z)/2°,0,1)，MVS 与对齐单目先验的反深度一致 c_mvs=clamp(1−|i_mvs−i_mono|/r_mvs,0,1)，c=(c_mvs·c_z)^4；o_spawn=0.1+0.2c，β_spawn=5−4c（β∈[1,5]），无 MVS 支持时 o_floor=0.02；尺度按半高足迹 u_1/2(β)=1−2^{−1/β} 补偿。③固化控制器每关键帧以 EMA(η=0.3) 统计主导像素误差均值/方差，按 b±0.4 硬化（老≥10 帧、o>0.7、>20 像素且≥3 视图、ē<0.03）或软化（视图不一致高误差）。④误差驱动重定位：濒死原型（o<0.10）传送至 top-10% 误差归因活原型，渲染保持堆叠+小抖动+优化器重置。⑤30 迭代 burst+FasterGS 式 fused rasterizer（Garden burst 287→170ms，总运行时 −16%）；β 专用 tile culling 界 x_cut=max(0,1−(255o)^{−1/β})。⑥LOD：4 个 <0.5px 原型按矩匹配合并——收缩因子 ξ(β)=4.5/(β+2.5)、Mardia 峰度 κ(β)=15(β+2.5)/(β+3.5)，β*=15/(15−κ̂)−3.5，质量/协差/不透明度闭式守恒。

## 实验与结果
基准：MipNeRF360(otf) 3 场景、TUM 3 场景、StaticHikes 3 场景、3DGS benchmark、SmallCity/CityWalk；对比 MonoGS、S3PO-GS、LongSplat、OtF NVS、i3DGS、BetaSplatting(7K)、FasterGS(7K/30K)、H3DGS、Octree-GS。在线协议：TUM 25.94/0.868/0.175/1:44（i3DGS 25.36/0.858/0.188/1:24；LongSplat 26.51 但 ~1.5h）；MipNeRF360(otf) 27.47/0.852/0.204/1:18（i3DGS 26.66/2:09）；StaticHikes 22.49/0.710/0.259/2:02（i3DGS 22.17/2:53）。3DGS benchmark：MipNeRF360 25.19/0.731/0.264/1:17（i3DGS 24.75/1:59）、T&T 23.00/0.803/0.200/1:18、Deep Blending 26.49（i3DGS 27.16 更优）。大规模：SmallCity 24.45/0.808/0.285/3:47（Octree-GS 24.18 但 ~1h）、CityWalk 25.81/0.857/0.239/42:43（i3DGS 22.03、OtF NVS 21.71）。消融（9 个 otf 场景）：Full 25.30 dB/101s；w/o relocation 25.09；w/o regularizers 24.98；w/o fused rasterizer 120s；CityWalk w/o moment merge 仅 23.54（−2.27 dB）；kernel 消融 Full 25.30 vs Gaussian 25.09、β frozen 25.06。峰值显存 8.6–10.3GB（RTX 5090 32GB）。

## 局限与风险
正文自述：3DGS benchmark 上与充分优化的离线方法仍有质量差距（在线位姿精化为正交方向）；矩匹配对 out-of-band 组与渲染贡献仅为近似；乱序输入会掉质（Bonsai −2.50 dB）并增加运行间方差（σ=0.74 vs 0.16 dB）与约 1.5× 运行时；Deep Blending 上不如 i3DGS（换 SH 可回升 ~0.3 dB）。

## 与文献库的关系
库内有大量 3DGS/在线重建论文（SplaTAM、MonoGS、OtF NVS、i3DGS、LongSplat）。本文属 i3DGS 作者生态（Würzburg/Drettakis 组）的后续，将 Deformable Beta Splatting 的 kernel 从离线紧凑性用途改造为在线置信度机制，与 OtF NVS/i3DGS 直接竞争（+0.8 dB、−40% 优化时间）。
