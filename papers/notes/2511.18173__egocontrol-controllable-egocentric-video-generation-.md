# EgoControl：基于 3D 全身姿态的可控自我中心视频生成

## 一句话结论
首个 3D 全身姿态可控的自我中心视频生成：差分头部 + pelvis 相对关节表示，AdaLN 与 cross-attn 双通路注入，FID 50.68 对 PEVA 61.10。

## 要解决的问题
面向具身智能的自我中心视频生成需要按身体运动做细粒度控制，但现有生成模型只支持文本提示或相机轨迹这类高层条件，无法直接控制拍摄者自身的关节化身体。这在第一人称下是结构性缺口：相机运动由头部的全局平移与旋转产生，而手臂、手、腿的局部关节运动才制造出定义第一人称画面的遮挡与物体交互。缺少全身姿态序列，模型就无法可靠模拟“伸手”“边走边转身”“手物操作”这类具体动作的视觉后果。已有人体姿态控制方法都工作在第三人称：主体大体可见、相机运动有限，且只用 2D 骨架，经 cross-attention、拼接或 ControlNet 式模块注入，无法迁移到强视角变化、频繁自遮挡的第一人称场景。并发工作 PEVA 是朝此方向的第一步，但它自回归地按每步 3D 上半身姿态生成单帧，时间与空间分辨率都很有限。

## 方法详解
EgoControl 以 Cosmos（cosmos-predict2，2B、480p、16 FPS）这一 latent 条件视频扩散模型为底座，采用 EDM 参数化：以连续噪声级 σ 扰动干净 latent，网络直接预测 z₀，损失为 w(σ)·‖z_θ(z,σ,c) − z₀‖²，去噪器为 DiT。条件 c 同时包含过去帧 x 与未来姿态序列 P。姿态表示是本文的核心设计：每个 3D 姿态含 J=23 个相对全局帧的变换矩阵，为保证体现视角而非绝对位置，头部用帧间相对变换 ΔH_i = H_i·H_{i−1}⁻¹ 并转成 6D 向量 Δh；再以 pelvis 为根关节计算其帧间相对运动 Δr；其余 21 个关节则表达为每帧相对 pelvis 的变换 J。三者拼接得 P = [Δh, Δr, J] ∈ R^{M×23×6}，同时编码自我中心相机动态与关节化身体运动。控制机制有两条互补通路。第一条是调制：把 P 展平成 (M·23·6) 维全局向量，经两层 MLP g_e 与 g_m 得到嵌入与 shift/scale/gate 向量，分别作用于 DiT 每个 block 的 self-attention、cross-attention 与 MLP 的 AdaLN 与残差门控；扩散步 t 经正弦嵌入与另一两层 MLP 产生同构调制量，二者按元素相加后再注入，使姿态与噪声级共同调制归一化与残差动态。第二条是 cross-attention：保留 P 的时间结构，把每帧姿态 P_m ∈ R^{23×6} 经 LayerNorm(GELU(W_p·P_m)) 投到 D_p 维，加正弦位置编码后作为 M 个 pose token 构成 cross-attention 的上下文，提供帧级局部化控制。训练用 45 帧片段，13 帧作条件、生成 32 帧（2 秒），上下文帧以 0.2 概率随机丢弃以支持无分类器引导；Cosmos-Tokenizer 把输入压到 12 个 latent 帧；全局 batch 1024、学习率 1.1e-5、在 H100 上训练 30k 迭代，推理用权 2 的视频引导；长视频靠把最后生成的帧回灌条件自回归拼接，960² 分辨率只需再微调 2k 迭代。

## 实验与结果
- Nymeria 主实验（186 段视频、约 50 小时、45 帧切片）：全身控制取得 SSIM 58.60、LPIPS 26.71、DreamSim 8.54、FVD 20.18、TransError 4.90、RotError 2.96、臂部掩码 mIoU 52.13、臂可见性 Acc 96.33%，全面优于仅头部控制的 56.94 / 29.71 / 10.22 / 22.68 / 5.16 / 3.29 / 33.70 / 91.14 与仅用过去帧微调的 Cosmos 47.47 / 45.74 / 18.14 / 40.70 / 9.93 / 13.65 / 25.13 / 85.20
- 相对仅头部控制，mIoU 提升近 55%（33.70→52.13），且全身条件还反过来改善了相机视角与头部姿态的一致性（TransError 5.16→4.90，RotError 3.29→2.96）
- 对 PEVA XXL（同为 2 秒后、224²、15 帧上下文、单帧生成）：LPIPS 24.3 对 29.8、DreamSim 11.3 对 18.6、FID 50.68 对 61.10，且 EgoControl 用的上下文更短
- 对相机控制方法 CAMI2V（只比前 16 帧）：SSIM 58.87 对 43.28、TransError 2.22 对 4.60、RotError 1.33 对 3.79、mIoU 56.85 对 24.72
- 控制机制消融：仅 AdaLN 的 mIoU 33.44 / FVD 29.14，仅 cross-attention 为 37.84 / 29.28，两者合用为 37.40 / 27.51 且 SSIM 最高（52.60），即 AdaLN 利于外观与全局运动、CA 利于关节对齐、合用兼得
- 姿态表示消融：头部用累积表示时 TransError 12.31，差分表示降到 6.75
- 全身用逐关节差分 Δj 时 mIoU 31.85，改为 pelvis 相对表示后为 37.40（+5.55）
- 换 VGGT 而非 VIPE 提取相机位姿复核，全身控制的 TransErr/RotErr 仍为 2.40 / 2.76（基线 6.89 / 12.29）

## 创新点与贡献
- 第一次把自我中心视频生成显式地接到拍摄者 3D 全身姿态上，并且产出的是一段有时间一致性的视频而非单帧：相对 PEVA 的逐帧自回归上半身条件，它在分辨率（480p 对 224²）、时长（32 帧）与身体覆盖（23 关节全身）上都换了量级
- 方法上的真正新意是把“相机运动”与“身体运动”在同一表示里解耦又联合：头部与 pelvis 用帧间差分（避免长序列数值膨胀），其余关节用 pelvis 相对坐标（避免逐关节差分导致身体失去整体连贯），这一组合被消融证明同时利于相机精度与肢体对齐
- 控制上不是单纯加一个 ControlNet，而是把全身姿态同时作为全局 AdaLN 调制量与帧级 cross-attention 上下文，并证明两者互补：一个管外观与全局轨迹，一个管关节级对齐
- 评测上也补了此前缺失的维度——用 SAM2 传播臂部掩码算 mIoU 与可见性准确率，把“生成是否真的跟着姿态走”变成可量化指标

## 局限与风险
- 作者明确承认 Nymeria 不提供手部姿态标注，当前模型不显式建模细粒度手指关节，全身条件只能改善手臂与粗粒度手部运动
- 训练数据偏置明显，全部来自鱼眼支架加动捕服的特定采集设置，对日常视角、服装与传感器配置的分布外泛化可能下降
- 从实验看还有几处局限：训练与定量评测只在 Nymeria 一个数据集上，Ego4D 仅用 250 段（200/50）微调 1k 迭代做定性展示
- 生成长度固定 32 帧 2 秒，长视频靠自回归回灌，未报告长时程的漂移或一致性指标
- 身体控制评测只覆盖视野内可见的手臂，且只在随机子集上做
- 分辨率 480p 对 960² 只做了短微调
- 当给定姿态序列物理上不可行（穿过桌子、穿窗）时会出现物体与手臂消失等强伪影，作者把自动检测不可行姿态列为未来工作
