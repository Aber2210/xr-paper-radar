# 自我中心视频语言模型是否同时捕捉了手部与物体线索？

## 一句话结论
用实体掩码与 HDA 解码器迫使自我中心 VLM 同时学手与物体线索，并给出像素级线索隔离基准 DEHOI；揭示「纯 ego 数据训练→手偏置」的实证。

## 要解决的问题
识别手物交互（HOI）需要同时捕捉手部动力学与物体状态变化，二者互补，是区分视觉上相似的操作（如 take 与 knead 面团）的关键。但只用自我中心视频训练的视频语言模型倾向于过度依赖手部外观，靠手与物体外观之间的相关性做判断，而没有充分编码手如何动、物体如何变，于是把 knead 误认成 take。既有改进多走语言侧监督，用相似但不同的动词或描述作负样本、用 LLM 增强 caption，却没有回答两个更基础的问题：如何在视觉编码器内部更好地学到手中心与物体中心线索，以及如何系统地评估编码器到底在用哪一类线索。现有的 HOI 基准都把两类线索放在同一段视频里联合评测，因为它们在像素上共现；已有的线索解耦工作要么压制静态场景上下文，要么分解标签空间（动词/名词组合），都无法揭示模型究竟依赖手部还是物体的视觉证据。

## 方法详解
方法由训练范式与评测基准两部分组成。训练侧第一块是 hand-object masked training：沿用 VideoMAE 的时空 tubelet 掩码与重建框架，用现成 HOI 检测器取得每帧手与操作物体的框，把同一空间位置跨时间的 token 归为一个 spatial tubelet，若某 tubelet 与手框（或物体框）在至少一帧的 IoU 超过 50% 则标记为手相关（或物体相关），其余为背景 B。据此定义三种掩码：手中心掩码 M = H ∪ B^h，即遮住全部手 tubelet、只在背景里补足到比例 τ，从而保证物体可见；物体中心掩码 M = (O ∖ H) ∪ B^o，因检测到的手通常挡在物体前面，故排除手 tubelet、只补背景，保证手可见；背景掩码 M = B^b。编码器只处理未掩码 tubelet，轻量 Transformer 解码器（1 层、4 头）在嵌入层以 MSE 重建被掩码 token。第二块是 HOI-dynamics-aware（HDA）解码器：DETR 式结构，含 2 个手 query、K 个物体 query 与 1 个视频 query（均 512 维），cross-attend 到编码后的视觉 patch 并相互 self-attend，得到手中心 e^h、物体中心 e^o 与视频级 e^v 三种嵌入。e^h 与 e^o 拼上可学习帧嵌入后经 MLP 头回归逐帧手/物体框，匈牙利匹配后优化 L1 与 GIoU；语义头上，手与物体嵌入都被对齐到动词语义（多动词有效时全部作正样本），物体嵌入额外用余弦匈牙利匹配对齐名词并施加 NCE。视频级嵌入则用 EgoNCE 与叙述对齐，共享至少一个名词与动词的样本作额外正样本、同视频不同时间段的叙述作 hard negative。总目标为 L_Total = λ_vt(L_EgoNCE^{v→t} + L_EgoNCE^{t→v}) + λ_Noun·L_Noun + λ_Verb·L_Verb + L_BBox + L_Rec，权重取 0.2 / 0.5 / 0.3。骨干为 EgoClip 预训练的 LaViLa（视频与文本编码器），编码器与 HDA 均用 LoRA 微调（rank 8、α=4），每段均匀采 4×244×244 帧，训练 2 epoch、batch 256、AdamW lr 1e-5、τ=0.5，每个样本以 0.8 概率走实体掩码、0.2 概率走背景掩码，实体内部手/物体掩码概率为 0.1/0.9。推理时不加任何掩码、编码整段视频，只把 HDA 的视频级嵌入投到联合视觉-文本空间用于下游任务，手/物体嵌入不参与。评测侧提出 CI-HOI（Cue-Isolated HOI）：在像素层面选择性移除手或操作物体，只留一类线索，要求模型在给定目标物体名的条件下预测交互动词；配套 DEHOI 测试台从 EPIC-KITCHENS-100 取视频、用 VISOR 掩码并以 SAM2 传播补全时序、再用 ProPainter 分别 inpaint 掉手或物体，共 2,652 段线索隔离视频，动词空间为 97 类。

## 实验与结果
- DEHOI 零样本 Top1（原视频 / 手中心 / 物体中心）：本文 26.9 / 19.2 / 19.5，Helping Hands 23.8 / 15.7 / 14.2，LaViLa 18.5 / 12.7 / 10.3
- Top5 对应 55.3 / 42.4 / 38.8 对 48.4 / 33.5 / 28.3
- 物体中心条件下相对 Helping Hands 提升约 37%
- 线索依赖的不对称性：EgoClip 系模型（LaViLa、Helping Hands）去掉物体时掉得更多（LaViLa −5.8 对手 −8.2，HH −8.1 对 −9.6），而用更多非自我中心数据训练的 EgoVideo 与 MLLM 相反（EgoVideo −8.8 对 −6.5），本文两者接近（−7.7 对 −7.4）
- 人机对比（96 段、16 动词、10 选 1、18 名被试）：人类原视频 73.6±5.8，手中心 63.9（−9.7），物体中心 70.5（−3.1），且在物体中心条件报告 85.1% 依赖物体线索，说明人类更依赖物体
- 模型在该 10 选 1 设置下为 56.2 / 53.1 / 44.8，三种条件均优于 LaViLa（52.1 / 43.8 / 34.4）与 Helping Hands（55.2 / 49.0 / 38.5）
- STATUS Bench 物体状态：状态变化识别 30.0，Helping Hands 26.5、LaViLa 24.7
- 物体状态识别 49.4 对 49.1 / 48.4
- 图像检索 50.7 与基线持平
- 模块消融（手中心 / 物体中心 / 原视频 Top1）：去掉掩码训练为 18.0 / 16.9 / 26.0，去掉 dynamics 语义监督为 16.3 / 16.8 / 24.6，完整为 19.2 / 19.5 / 26.9
- 掩码比例 75% 降到 26.0（原视频），随机掩码为 18.4 / 18.4 / 26.0
- 97 类候选的 96 段困难设置：本文 39.6 / 29.2 / 29.2（原视频 / 手中心 / 物体中心），Helping Hands 25.0 / 18.8 / 12.5，LaViLa 27.1 / 21.9 / 11.5
- DROID 机器人操作零样本动词分类左视角 4.7 对 4.0 / 2.9

## 创新点与贡献
- 把线索解耦从标签空间搬到像素空间：不是分解动词/名词，也不是压制背景，而是用实体感知的掩码让编码器在“手可见但物体被遮”与“物体可见但手被遮”两种条件下互相重建，从结构上强迫它学跨线索关系而不是共现捷径
- HDA 再把每一种线索显式锚定到位置与动词语义，使手中心与物体中心嵌入各自带空间与动力学含义
- 评测上的新意是 CI-HOI：用 inpainting 真正移除一类线索来做受控视觉消融，从而能测出“模型依赖哪一类证据”，这是联合评测基准做不到的
- 由此得到的实证结论也不只是分数：仅用自我中心数据训练的 VLM 存在手中心偏置，而掺入更多非自我中心数据的模型偏置方向反转，本文的双线索监督把两者的落差压平，并在原视频上仍保持增益

## 局限与风险
- 作者未单列 limitations，可自实验设计看出多处约束
- DEHOI 只来自 EPIC-KITCHENS-100 的厨房场景与 97 个动词、且用验证集（测试集未公开），结论向其他场景与动词体系的迁移未验证
- 线索隔离依赖 VISOR 掩码、SAM2 传播与 ProPainter 修补，作者用模糊/扭曲与背景修补做了伪影对照（性能基本不变），但真实移除仍可能留下痕迹
- 评测时把目标物体名作为输入，属于受限设定，不是开放词表识别
- 任务只做动词，不评名词
- 训练依赖现成 HOI 检测器，框平移 14/28 px 或丢弃一半检测都会掉点（原视频 26.9→26.4/25.9/26.3），说明对检测质量敏感
- 绝对精度仍低（最好的原视频 Top1 仅 26.9%），骨干只有 566M
- STATUS Bench 仅 404 组图
- 在 EgoMCQ 上比基线低约 0.5%，EK-MIR 的 mAP 略降
- 人机研究 18 人、96 段，样本有限
- 正文未提供代码或 DEHOI 发布地址
