# 掩码不等于物体：面向三维高斯分割的体监督

## 一句话结论
直接监督深度簇内全部高斯，Removal-3D 上 mRDE 由 39.31 降至 27.34。　指出「掩码只覆盖可见表面」是 3DGS 分割的系统性偏差，改为监督深度簇内全部高斯，Removal-3D mRDE 39.31→27.34、mIoU 52.87→60.90。

## 要解决的问题
现有 3DGS 分割以渲染出的 2D 掩码准确率来训练与评测，但掩码正确并不代表底层三维选择完整。其根源是渲染式特征监督按每个高斯的 alpha 混合贡献分配梯度：主导贡献的高斯即可渲染出正确掩码，同一物体中被遮挡或低贡献的高斯只得到微弱甚至零梯度，移除后仍残留目标体，导致编辑不干净。

## 方法详解
提出 VODA 可插拔监督目标。深度感知光栅化器关闭透射率早停，收集每像素贡献者的深度与 alpha；以相邻深度间隔中位数自适应阈值 tau=clip(gamma*median(dz), tau_min, tau_max) 切分深度簇，取总贡献最大的簇 C*。再用完整渲染特征 F(p) 按 alpha 加权聚合成高斯级伪目标并 detach，对簇内每个高斯直接施加平方 L2 损失（LaGa 用余弦），使梯度绕过渲染权重；另加像素级 push 损失，惩罚不同掩码像素对余弦相似度超过 margin 0.3。总损失为基线损失加 lambda_direct=0.5、lambda_push=0.1，gamma=15，阈值限 [0.05,1.0]。几何、特征表示与推理流程不变，推理零开销；前两个基线在特征阶段启用，后两个追加 5000 步特征微调。

## 实验与结果
- Removal-3D 平均：OpenGaussian mRDE 39.31→27.34、mIoU 52.87→60.90；LaGa mRDE 36.93→21.66、mIoU 75.93→79.07。
- LERF select-then-render：Gaussian Grouping mIoU 22.75→43.73、mAcc@0.25 42.14→76.27；ILGS mIoU 30.00→49.62。
- ScanNet 19/15/10 类：LaGa mIoU 32.20→33.20、37.19→37.21、43.06→45.53，10 类 mAcc 61.31→65.24。
- 低贡献分析：被恢复高斯的 max w<1/255 占比在三个场景高 10.2–15.9 个百分点；8.5–18.7% 的恢复高斯在所有训练视图贡献为零。
- 开销：1000 次迭代在 RTX A5000 上为 OpenGaussian 增加约 10 分钟、Gaussian Grouping 约 20 分钟，推理无额外成本。

## 创新点与贡献
- 相对 Gaussian Grouping、OpenGaussian、LaGa、ILGS，指出梯度按渲染贡献分配的结构性偏差，改用深度簇直接监督全体成员；并提出 Removal-3D 与 RDE，把评价从渲染掩码转向体完整度。
- 对比基线：OpenGaussian, LaGa, Gaussian Grouping, ILGS, LangSplat, LEGaussians, Segment then Splat

## 局限与风险
- 深度聚类会把相互接触的物体并簇、把内部稀疏的物体切碎，push 仅部分缓解；遮挡高斯缺特征级真值，只能经下游选择与移除间接评估；精确体评测需成对的全场景与去物体深度图，仅 3 个合成场景具备。
- 消融：同簇改走渲染路径时 Gaussian Grouping 的 LERF mIoU 仅 12.40，直接监督升至 43.73；push 主要降 mRDE（32.63→27.34）；Normalize、Clamp、KNN 均不及 VODA。
