# FACET：数据高效的区域化参数化人头模型

## 一句话结论
把区域 PCA 明确定位为绕开 N−1 秩上限的数据效率机制而非仅编辑便利：held-out 中性拟合 0.23 mm（全局 PCA 1.95 mm，8.3×），身份系数容量 11,072 对 346。

## 要解决的问题
影视级面部管线需要可 FACS 控制、可绑定的参数化人头模型，但高质量配准头部扫描采集成本高，制作方身份池只有数百人。全局 PCA 在 N 个身份下最多只有 N−1 个模态，加扫描数量无法突破该秩上限。

## 方法详解
把头部划分为 16 个解剖区域，每区域分别拟合位置与 Laplacian 坐标的 PCA 基，并以带重叠权重的加权最小二乘无缝拼装为单一可编辑网格。表达层用可学习 FACS 动作单元 blendshape，配 hash-grid 编码与 FiLM 调制的逐身份神经个性化，另有 AU 组合修正项。再加独立颈/肩区域，把姿态变化限制在下半身，避免反解姿态时泄漏到上面部。

## 实验与结果
- held-out 中性拟合 V2V 误差 = 0.23 mm（全局 PCA 基线 1.95 mm，约 8.3× 更低）
- 身份系数上限 = 11,072（全局 PCA 为 346，训练池 347 身份）
- 表达拟合误差 K=1000 = 1.47 mm（全局表达 PCA 1.67 mm，通用 AU 1.56 mm）
- 眼睑 V2V K=1000 = 1.09 mm（全局表达 PCA 1.31 mm）
- 上面部反解姿态位移 = 0.16 mm（全局 PCA 消融 0.50 mm，约 3.1× 降低）

## 创新点与贡献
- 把区域 PCA 明确定位为绕开 N−1 秩上限的数据效率机制而非仅编辑便利，并用受控实验反驳「FACS 过于完备难以拟合」的既有论断

## 局限与风险
- 作者自述评测池很小（59 身份、59×19 表情）
- 且完全依赖固定身份池与自建拓扑，未在同一数据上与公开大规模模型对比
