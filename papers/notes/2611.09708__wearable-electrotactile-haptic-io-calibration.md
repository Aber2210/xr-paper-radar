# 可穿戴触觉输入/输出接口学习个性化触觉感知模型

## 一句话结论
36 通道电触觉阵列与电容触摸感知共坐标注册的可穿戴 I/O 设备，在 24 名被试上揭示了具有电极对特异结构、但个体差异显著的触觉/热感知图，并据此实现个性化逆向渲染与四类应用演示。

## 要解决的问题
可穿戴触觉设备按执行器位置施刺激，但用户实际感知位置会大幅偏移，尤其在电触觉与参照热觉（referred thermal）等新兴反馈方式中，执行器坐标与感知坐标不一致。缺乏在同一身体参照系内同时记录刺激位置与报告感知位置的手段，也就无法为个体建立可逆的感知模型，导致渲染出的触觉图案在不同用户身上落点错位。

## 方法详解
研制可穿戴触觉输入/输出（I/O）一体设备：36 通道 electrotactile array 负责刺激输出，叠加 capacitive touch sensing 记录用户手指触摸位置，使刺激坐标与报告感知坐标落在同一 body-referenced coordinate frame 内。用该平台在 24 名被试上测绘 electrotactile 与 referred-thermal 两类感知图，分析跨被试变异度与电极对（electrode-pair）层面的空间结构，并检验触觉与热觉感知位置之间的空间对应关系。基于个体差异大但结构可学的观察，提出 human-in-the-loop calibration framework：把 forward-prediction 策略适配到单个用户，生成 personalized perceptual model。该前向模型支持 inverse rendering——给定目标感知位置，反解出最可能产生该感知的刺激图案；最终在 haptic-guided robot teleoperation、visual-to-haptic sensory substitution、interpersonal haptic communication 与 VR 四类场景中演示个性化渲染。

## 实验与结果
• 用户规模：24 名被试完成感知测绘，覆盖 electrotactile 与 referred-thermal 两种模态。
• 主要发现：两种模态的感知图均存在显著的被试间差异，但仍保留电极对特异的空间结构（electrode-pair-specific spatial structure），说明个体模型可学而非纯噪声。
• 跨模态：触觉与热觉感知位置存在空间对应，但对应强度因人而异。
• 应用演示：基于个性化逆向渲染，在机器人遥操作触觉引导、视觉-触觉替代、人际触觉通信与 VR 四类场景中给出演示。
• 量化缺口：摘要未给出定位误差、标定收敛速度、渲染延迟或各应用的用户研究指标，无法核实性能增益幅度。

## 创新点与贡献
1) 把刺激与触摸感知做进同一设备与同一身体参照坐标系，使「施在哪」与「感觉在哪」可直接配对测量，替代以往分离式标定。
2) 同时刻画 electrotactile 与 referred-thermal 两类感知图，并报告二者的空间对应及其个体差异。
3) 以 human-in-the-loop 的 forward-prediction 加 inverse rendering 闭环，把感知测绘转化为可按用户定制的触觉渲染管线，并跨四类应用验证可迁移性。

## 局限与风险
1) 仅有摘要级证据，正文方法与实验细节未核实（无基线、无统计检验、无误差指标）。
2) 36 通道阵列的空间分辨率与可穿戴覆盖面积有限，能否支撑复杂图形化触觉信息未说明。
3) 个体标定需要多轮人机交互，标定成本、稳定性与长期漂移未量化。
4) 电触觉与热觉涉及安全与舒适度边界，摘要未给出刺激参数范围与受试者耐受性数据。

## 与文献库的关系
属于感知-建模-渲染闭环的可穿戴触觉方法族，与 electrotactile / thermal display 的感知映射研究、以及 haptic retargeting 与 sensory substitution 一脉相承；差异点在于把标定从离线查表升级为可在线适配的个性化前向模型，从而支持逆向渲染。
