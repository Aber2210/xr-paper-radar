# ZipSplat：更少的高斯、更好的泼溅

## 一句话结论
ZipSplat 用紧凑场景 token 预测无约束高斯、把图元放置与 2D 像素网格解耦：DL3DV 6 视图仅 62K 高斯即 25.34 PSNR，比 per-pixel 基线（393K/23.42 PSNR）高约 2 dB 且高斯数少 6 倍；RE10K 免位姿 26.20 PSNR 超 YoNoSplat 1.2 dB、超有位姿 DepthSplat 2.0 dB；token 测试时优化 50 步（单 4090 约 3s）再加约 5 dB。

## 要解决的问题
现有前馈 3DGS 多为 pixel-aligned：沿视线把 2D 预测 uplifting 成每像素一个高斯，高斯数量随相机分辨率膨胀，容量分配与场景 3D 复杂度无关，大预算下仍受 2D 网格束缚。ZipSplat 要在稀疏多视图输入下以更少高斯达到 SOTA 免位姿新视角合成，并支持推理时连续调节高斯预算。

## 方法详解（含关键公式/架构，保留原文术语）
前馈 3DGS 架构：以紧凑场景 token 集合预测 unconstrained Gaussians，primitive placement 与 2D pixel grid 解耦，容量按 3D 几何复杂度而非相机分辨率分配（token 聚类决定高斯数量，构成 adjustable Gaussian budget）；可选接受相机先验（pose/intrinsics，仅贡献约 0.1 dB）。token test-time optimization（TTO）：有 GT 位姿时冻结解码器、在固定高斯预算下仅优化场景 token，即可大幅提质——50 步（约 3s/单 4090）加约 5 dB PSNR，完全收敛达 5.8 dB、24 视图 LPIPS 减半，说明 token 表示仍有大量余量、改进前馈预测是有前景方向。

## 实验与结果（表格化关键数字）
DL3DV（140 测试场景，context N∈{6,12,24}，farthest point sampling，最大帧间隔 50/100/150）与 RE10K（1600 测试场景，N=6）；各留 8 个目标视图；统一 252×252 渲染评测，预测高斯先对齐 GT 目标视图再算 PSNR/SSIM/LPIPS；基线含免位姿 AnySplat/C3G/YoNoSplat、NoPoSplat（需 GT 内参）、有位姿 MVSplat/DepthSplat，及同 backbone 的 pixel-aligned DA3。DL3DV：ZipSplat 62K 高斯 25.34/0.810/0.169，124K 24.37，249K 24.23；MVSplat 393K 22.66、DepthSplat 393K 23.42、DA3 1.5M 23.99、YoNoSplat 301K 24.10、AnySplat 951K 21.70、C3G 2K 18.70，NoPoSplat 从 22.77 跌至 17.86；对 DA3 增益 1.5–2.5 dB 且高斯少 24 倍，AnySplat 落后超 3.2 dB、YoNoSplat 落后 1.1–2.1 dB；TTO 后 62K 即 28.99/0.892/0.106，249K 达 30.03/0.907/0.097。RE10K：26.20（免位姿）/27.19（带相机先验），超 YoNoSplat 1.2 dB、超有位姿 DepthSplat 2.0 dB。跨数据集 Mip-NeRF360：32→128 视图 21.72→22.29 PSNR 稳步提升，而 per-pixel DA3 从 20.94 下滑。唯一例外为稀疏视图 LPIPS：per-pixel 方法把输入颜色直接拷入首个高斯通道保留高频色彩，ZipSplat 从聚合 token 预测颜色。

## 创新点与贡献
① token 化场景表示，primitive 放置与像素网格解耦，按 3D 几何复杂度分配容量；② 推理时连续可控的高斯预算；③ 对同 backbone 的 pixel-aligned 头（DA3）以 24× 更少高斯取得 1.5–2.5 dB 增益，隔离出 token 解码器贡献；④ token 级 TTO：仅优化 token 即恢复大量质量，指向改进前馈预测的研究方向；⑤ 作者指出紧凑表示利于语义场景理解（逐高斯特征不爆显存）并向 4D 动态场景（token 跨时空聚类）扩展。

## 局限与风险
稀疏视图 LPIPS 仍输 per-pixel 方法（高频颜色复制问题）；digest 未报告运行时/显存对比；跨数据集增益依赖视图覆盖度（32→128 视图才稳步提升）；高斯数量仍随输入视图数增长（62K→249K）。

## 与文献库的关系（新增 / 改进 / 取代 X）
位于库内 3DGS 效率/压缩线（2610.22778 dGS、2605.25563 CodecSplat 等）与前馈重建线（2610.23039 VGGT+TokenGS、VGGT-BC/AnySplat/TokenSplat/DepthSplat/MVSplat/DA3）的交汇点：既是对前馈 3DGS 的 token 化改造，也以更少高斯切入压缩主题。
