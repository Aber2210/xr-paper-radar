# Vorch-Streamer：实时长时文本到音视频流式化身生成

## 一句话结论
后训练框架把双向音视频模型改造为因果实时流式生成：混合 Teacher Forcing + Diffusion Forcing 训练因果生成器 + 长程 Self Forcing（DMD 蒸馏）+ LLM 25Hz 言语规划 token；27.12 FPS 实时、WER 7.92%（基线外推法 94–98%）。

## 要解决的问题
实时长程化身音视频生成的两个两难——自回归复用生成块导致暴露偏差/误差与视觉漂移累积；全局语音文本无法指示因果生成器「下一段该说什么」。

## 方法详解
80K 合成化身片段（12–21s，768×512@24FPS）；混合 TF+DF 训练；长程 Self Forcing + DMD 蒸馏保持教师质量；外部 LM 预测离散 25Hz（40ms 规划单元）言语规划 token 条件化音频扩散分支；四步去噪。

## 实验与结果
对比 JoyAI-Echo/OmniForcing/Hallo-Live/LTX2：WER 7.92% 接近离线 LTX2；消融显示全程文本条件化 WER 184% → 短文本段 62.77% → 规划 token 7.92%；27.12 FPS、较 JoyAI-Echo 快 14.8×；长程身份保持与 Drift 分析。

## 创新点与贡献
① 言语规划 token 显式控制语音进程；② 长程 Self Forcing 解决暴露偏差；③ 免参考首帧/免外部音频的纯文本驱动。

## 局限与风险
合成数据训练（sim-to-real 差距未充分量化）；长程身份保持仍有 Drift；实时但非高保真路线；未给 VR 集成延迟数据。
