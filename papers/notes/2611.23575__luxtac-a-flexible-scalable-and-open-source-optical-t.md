# LuxTac：面向触觉机器人学习的柔性可扩展开源光学 taxel 阵列与分布式三轴力感知

## 一句话结论
3.5 mm 厚、全件开源的光学 taxel 阵列，用彩色硅胶壁把剪切编码进色度，实现每点三轴力感知；插销入孔成功率 40%→87%（n=15）。

## 要解决的问题
机器人要学会操作，必须先知道是否抓住、抓得多紧、手指遮挡时接触在哪里，但现有两条路线各有硬伤。压阻式阵列（3D-ViTac、FlexiTac 等）便宜、薄、可铺满，却每个 taxel 只输出一个数：它测的是聚合物复合材料的接触电阻，因此只能感知压力而不能感知剪切，并且这种电阻会漂移、早早饱和、依赖加载历史、垫与垫之间不一致，一离开实验台就不可靠。相机式传感器（GelSight、DIGIT、TacTip）能以亚毫米分辨率重建弹性体变形场，代价是体积、带宽和高维观测，光路沿视轴使得它很厚、难以在夹爪上密铺；TacScope、MVP-Tac 等小型化设计缩小了感应面，但相机光路仍让厚度沿视轴堆叠。折中方案是把离散 LED-光电探测器埋在弹性体里，可已有工作（Patel 与 Correll 的接近觉传感器、Piacenza 的多曲率手指、SpectraTac 用 12 个颜色通道回归整块传感器的一个三维力）要么只测接触与法向力，要么依赖耦合通道的学习模型，整块只给一个力而不是每个 taxel 各自的力；OpenTac 用 bump overlay 把剪切转成跨多个 taxel 的差分压力，uSkin 用霍尔阵列加磁体测三轴力却怕外部磁场。因此缺少的是一种既薄、可任意铺排、又能在每个 taxel 上独立分辨剪切的三轴力阵列。

## 方法详解
硬件：传感头是 21.8 × 23.8 mm 的四层 0.2 mm 厚柔性 PCB，布 16 个 TCS34725 RGBC 光-数字转换器，列距 4.42 mm、行距 4.80 mm，配 9 颗 0603 白光 LED 排成 3×3，每颗 LED 位于四个相邻光电二极管中间。每个转换器内部集成红外截止滤光片、光电二极管阵列和每通道 16 位积分 ADC，模拟信号不出封装，工作在最短 2.4 ms 积分时间与 4 倍模拟增益。所有 TCS34725 共用同一固定 I2C 地址，所以通过窄颈接到两片 TCA9548A 八通道 I2C 开关，让每个传感器独占一个总线段与 4.7 kΩ 上拉；开关再经两条独立 I2C 总线连 Teensy 4.1，单颗 NMOS 统一门控 9 颗 LED 以便采集 LED-off 环境光帧。整帧 RGBC 扫描的 I2C 时序约 5.5 ms，理论上限约 180 Hz，本文以 100 Hz 串流。传感原理：每个 taxel 是半透明白色硅胶（d = 2 mm，XP-565 15:1、0.04 wt% 白色色浆）加一层不透明黑膜，压缩时吸收膜靠近探测器、回散射光单调下降；黑膜同时挡环境光。归一化按两点标定：s_i = clip((b_i - x_i)/(b_i - x_i^min), 0, 1)，并在 b_i - x_i < 3σ_i 时置零，抵消 taxel 间偏置与增益差异。剪切墨盒（Mode 2）把白层切成每 taxel 一个立方体，列间壁交替绿/红、行间壁交替黄/蓝，剪切使壁倾斜、改变各色光到达探测器的比例，于是亮度编码法向变形、色度编码剪切方向与大小，无需相机、磁体或 bump overlay。力回归：对 taxel i 取 clear 通道亮度变化 p_i = (b_i^C - C_i)/b_i^C 与色度变化 Δr、Δg、Δb（r_i = R_i/C_i 等），每个 taxel 一个两层 64 单元感知机，输入其 3×3 邻域特征，输出该 taxel 三轴力；整垫另用 kernel ridge regression 估总力与接触位置。训练/测试划分一律按位置或按 session，避免泄漏。仿真：在 IsaacGym 中用 TacSL 建模仿真垫，每 taxel 是胶体表面一个采样点，按物体 SDF 读压入深度 δ_i，令 D_i = α_i δ_i^β_i 并输出 ŝ_i = clip(α_i δ_i^β_i / D_i^max, 0, 1)，只需每 taxel 四个数（α、β、D^max、σ/b）。策略：用 ACT（Action Chunking Transformer），观测为外部 RGB、16 个 taxel 读数组成的平坦向量与机器人状态，预测未来 H 步动作块。

## 实验与结果
- 法向墨盒 240 次按压（5 个 session × 15 遍）：0.1–5.8 N 内线性 R² = 0.999，灵敏度 0.170 FS/N，检测阈值 104 ± 49 mN，重复性 2.0 ± 0.3% FS，迟滞 5.9 ± 1.1% FS，饱和未达（> 5.8 N）
- 归一化把 taxel 间变异系数从原始 34–40% 降到 21% / 10% / 5.9% / 3.0%（对应 0.5 / 1.5 / 3 / 5.5 N），中心、边缘、角上的 taxel 变得不可区分
- 剪切墨盒留出 session 测试（9 个 session 轮流留一，三种压头联合训练）：各 taxel 三轴力 R² = 0.92 / 0.93 / 0.94（x/y/z，RMSE 0.06 / 0.05 / 0.14 N），求和后 0.96 / 0.96 / 0.92，剪切方向误差中位 4.8°，未见位置接触定位误差 0.56 mm
- 通道消融：仅亮度 R² = 0.70 / 0.73 / 0.83（方向误差 9.8°），仅颜色 0.84 / 0.89 / 0.90（6.4°），两者合用 0.92 / 0.93 / 0.94（4.8°），说明颜色承载大部分剪切信息、亮度补法向
- 仿真-真实对齐：12 次抓取 × 50 帧，真实与匹配仿真的帧余弦相似度 0.942（同一次抓取两帧上限 0.9994），而均匀垫 0.763、不同物体 0.674、同物体不同朝向 0.642、打乱 taxel 0.594
- 45° 抓取沿错对角仿真时从 0.946 掉到 0.264
- 真机 ACT（每任务 50 条人类示教，15 次试验，95% Wilson 区间，Fisher 精确检验）：插销入孔从 6/15（40%）提升到 13/15（87%），p = 0.021
- 方块分拣 5/15（33%）到 6/15（40%），p = 1.0 不显著

## 创新点与贡献
- 真正的新意不是「又一个低成本触觉垫」，而是把每个光学 taxel 的测量量从「力」改成「局部压入深度」，并用颜色编码把剪切搬进同一个数字探测器：四面彩色硅胶壁让列间红-绿平衡随 Fx、行间黄-蓝平衡随 Fy 变化，于是亮度管法向、色度管剪切，不需要相机、磁体或 bump overlay，作者称这是首个能在单个 taxel 上分辨剪切的光学 taxel 阵列
- 这一改动带来两个连带好处：每个 taxel 是独立数字器件、独占总线段，换阵列尺寸只需加多路复用器而不改读出，所以 8×8、4×8 与原型共用同一套电子学
- 而「测深度」使真实与仿真共享同一个几何量，仿真只需四个标定常数就能一对一把深度映射到归一化信号，避开了 FlexiTac 那种调刚度阻尼去凑力响应、OpenTac 那种逐传感器标定的路线
- 相对 uSkin 的磁体方案，它也不受外部磁场干扰

## 局限与风险
- 作者自述与实验设计可见的局限有六点
- 一是硅胶在持续载荷下会蠕变，阶跃式协议只表征了准静态响应，动态接触与滑动摩擦未覆盖
- 二是 LED 输出随温度漂移，基线需在每个 episode 开始时重估
- 三是力估计依赖接触形状：同样力下尖锐物压得更深，只用大于一个 taxel 的接触训练时对单元大小的圆头完全不迁移（R² ≤ 0.18），训练集必须包含最小预期接触
- 四是剪切墨盒有代价：同一 4.5 mm 压头下 1.8 mm 处 clear 通道跌幅从 21.9% 降到 15.9% 基线，迟滞从 5.9% 升到 9.1% FS（部分因剪切协议在加载与卸载之间滑动了压头）
- 五是只验证了三种平面压头，曲面、尖锐与可变形物体未测
- 真机策略只用了压力、尚未把每 taxel 剪切作为输入，仿真中的剪切与仿真内策略训练也留作未来工作
- 六是真机证据偏薄：每任务仅 15 次试验、单一平台单指，方块分拣无显著提升（p = 1.0），作者归因于 4.4–4.8 mm 的 taxel 间距可能粗于表面纹理尺度
