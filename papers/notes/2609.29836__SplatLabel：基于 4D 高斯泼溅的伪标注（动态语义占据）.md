# SplatLabel：基于 4D 高斯泼溅的伪标注（动态语义占据）

## 一句话结论
SplatLabel 是一条自动化伪标注流水线：用 4D 高斯表示提取带预测置信度的 LiDAR 分割与任意体素分辨率的语义占据栅格，并通过显式"时间流形"建模单个 3D 基元的轨迹与寿命，精确追踪运动主体、严格界定物体出现/消失，从而**彻底免去预标注的 3D 边界框**。

## 要解决的问题
2D 视觉基础模型可自动化 3D 语义伪标注，但把先验转成稳健 3D 表示通常需复杂启发式或多模型集成；动态环境下物体出现/消失与运动追踪尤其困难。

## 方法详解
- **4D 高斯表示 + 时间流形**：显式建模每个 3D 基元的轨迹与寿命；
- **动态追踪**：精确跟踪运动主体，严格定义物体何时出现/消失；
- **伪标注输出**：LiDAR 分割（带预测置信度）+ 任意体素分辨率的语义占据栅格；
- **免 3D 框**：完全不需要预标注 3D bounding box。

## 实验与结果
- 在动态场景语义占据/LiDAR 分割基准上，相对需要 3D 框或朴素时序聚合的方法，在一致性与时序边界上更优（具体指标见论文）；
- 消融验证时间流形与置信度机制各自贡献。

## 创新点与贡献
把"动态时间流形"作为 4DGS 伪标注的核心组件，是对 3D 语义自动标注流程的清晰简化（去 3D 框）。

## 局限与风险
- 依赖 4D 高斯对动态场景的拟合质量，高密度/快速运动物体可能拟合不稳定；
- 置信度校准与真实标注的偏差未充分讨论。

## 可复现性
流水线描述具体，但无公开代码；依赖 4DGS 与 2D 基础模型，复现中等。

## 行动建议
