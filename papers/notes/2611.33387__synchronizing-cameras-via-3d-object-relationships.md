# 通过三维物体关系同步相机

## 一句话结论
放弃像素级对应，改用「物体间三维关系只差一个尺度」做跨视角对齐（Pearson 相关 + VLM 命名身份）——EgoHumans 44.5 ms（VisualSync 122.1）、CMU Panoptic 11.1 ms（112.6）、3D-POP 1.7 ms（114.7）；线索消融 333.1→44.5 ms。

## 要解决的问题
多相机视频的时间同步通常依赖像素级证据：跨视角点对应、或与动态辐射场/3D 高斯联合估计偏移。但动态场景里携带时间信息的恰恰是运动区域，其快速运动与频繁遮挡使跨视角匹配很不可靠。现有最好方法 VisualSync 在 EgoHumans 上平均偏移误差 122.1 ms、CMU Panoptic 112.6 ms、3D-POP 114.7 ms，Sync-NeRF 在 CMU 与 3D-POP 上平均误差都超过 900 ms。此外基于人体姿态的方法只适用于人。

## 方法详解
核心假设：物体之间的三维关系（如两人间距离、球的速度）在所有视角下只差一个尺度，因此可在每个相机内独立测量后互相对齐。线索：由物体三维中心 $p_{i,o}(t)$ 算位移 $Δp$、速度 $v$、物体对距离 $q_{ab}$，另用 CoTracker3 的点轨迹平均位移幅值作为 2D 运动线索兜底。尺度不变性：若各相机深度只差常数尺度 $α_i$，则 $v_{i,o}(t)≈(α_i/α_j)v_j,o(t+θ_i−θ_j)$，距离同理，故用 Pearson 相关而非直接比数值。身份与三维位置：把每个相机的首/中/末帧一次性交给 VLM（GPT-5.4），要求输出覆盖所有相机的 JSON 物体描述列表（如 man in a pink checkered shirt）；再用 SAM 3 以文本提示分割跟踪、用 Video Depth Anything 的度量深度取掩码中值反投影得质心。同描述多实例（如鸽群）用「到其他物体的距离排序向量」$h_{i,a}(t)$，在候选偏移 $d∈[−50,50]$ 帧上匈牙利匹配并联合搜索偏移。求解：按 3D 运动、物体间距离、2D 运动三组，先对每条 3D 线索按 3 倍 MAD 截断，相关值过 atanh 后取去 10% 的截尾均值，再对三组分数在候选偏移上标准化为 z-score，按 $S=z_mot+z_dist+0.25·z_2d$ 取峰得成对偏移；全局用 Cauchy 损失、以 $w_ij=max(S_ij,0)$ 加权、θ₁=0，加权最小二乘初始化后 IRLS 至多 10 次。

## 实验与结果
- EgoHumans 全局平均/中位偏移误差 44.5 / 15.0 ms，VisualSync 122.1 / 46.6 ms
- CMU Panoptic 11.1 / 0.0 ms（VisualSync 112.6 / 41.5）；3D-POP 1.7 / 0.0 ms（114.7 / 77.8）
- UDBD 8.7 / 0.0 ms（VisualSync 20.2 / 5.9，Sync-NeRF 0.4 / 0.2）
- 同身份成对比较：平均误差 246.2 ms 对 SeSyn-Net 511.1 ms，A@100 45.8 对 8.1，A@500 70.3 对 31.1
- 线索消融（EgoHumans 平均）：仅 3D 位移 333.1 ms、加 3D 速度 178.3 ms、加物体间距离 147.7 ms、四类全用 44.5 ms
- 去掉「把佩戴者放在自中心相机原点」后 EgoHumans 平均误差 71.1 ms（中位 5.0），成对误差 307.0 ms

## 创新点与贡献
- 不做跨视点像素/点匹配，而是回到「物体是相机全局推理的可靠线索」这一传统思路并用基础模型现代化：身份由 VLM 一次性跨相机给出、分割跟踪交给 SAM 3、三维位置交给单目视频深度，再把物体间三维距离与速度的时间曲线做相关对齐
- 相对 VisualSync 只把物体用于限制点匹配，这里物体关系本身就是线索
- 相对姿态类方法只适用人，这里任何能用短描述命名的类别都行

## 局限与风险
- 假设相机已标定（用真值内参）、所有相机同帧率、偏移为整数帧，作者自述离散框架无法给亚帧精度也不能跨帧率
- 整条链路由现成基础模型驱动，误差受 GPT-5.4 / SAM 3 / 深度估计支配
- 依赖场景中有可命名的运动物体，物体太少或描述无法区分实例时只能靠匈牙利匹配兜底
- 评测的「未同步」是人工裁剪合成，裁剪方式与 VisualSync 不完全相同（作者自己报告了五个种子的标准差）
