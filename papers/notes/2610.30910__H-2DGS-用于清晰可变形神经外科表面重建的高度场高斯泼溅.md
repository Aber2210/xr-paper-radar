# H-2DGS：用于清晰可变形神经外科表面重建的高度场高斯泼溅

## 一句话结论
H-2DGS 三阶段把体积 3DGS 转为薄表面（可微 ray-wise density concentration → TSDF 融合 → 弯曲高度场 Gaussian），面向神经外科皮层-MRI-tractography 统一可视化：5 例 MVDC 1e-5~4e-5 显著低于 2DGS/QGS，模型恒定 7.97MB、29-42ms/帧（RTX 3050）。

## 要解决的问题
神经外科导航通常以 2D MRI 切片呈现术野，难以与手术显微镜下暴露的皮层表面建立直观对应。常规 3DGS 在显微镜视频有限的视角覆盖下，会把不透明度铺成厚而几何模糊的密度带，遮挡皮层下方的纤维束与 MRI 解剖结构。因此需要一种既照片级真实、又具有清晰几何边界的皮层表面表示，并可与全脑 MRI 和 diffusion tractography 融合，同时支持术后组织切除后的形变对齐。

## 方法详解
提出三阶段管线，把体积化的 3DGS 逐步转换为薄表面：Stage I 用常规 3DGS 加 adaptive densification 做 photometric bootstrap 建立外观（λ=0.2 的 L1+SSIM 目标）；Stage II 提出可微的 ray-wise density concentration 目标，用 soft 1%/99% 分位数度量每条相机射线上的有效厚度 Δt 并收缩向零目标厚度（λthick=5.0，5000 迭代 warm start 后再跑 1000 迭代），在不改变 primitive 类型的前提下去除深度歧义；Stage III 把多视角深度融合进共享 TSDF，在零水平集上放置 curved height-field Gaussian primitive：每个 patch 有 tangent frame、Gaussian-basis height field（5 个高度基）、独立的 20 个 opacity 基与 50 个 color 基，ray-surface intersection 用少量 Newton 迭代求解，直接产出显式表面交点与 camera-linear depth。术后对齐用 MRI 网格渲染的深度监督表面形变（opacity 固定为 0.999），tracked-color self-preservation 把初始颜色绑定到变形后的 patch 上，几何窗口与外观窗口交替优化防止对齐破坏皮层纹理。

## 实验与结果
数据：5 例真实神经外科视频（3 术前 + 2 术后），每例从视角覆盖最全的连续片段均匀采样 60-80 帧训练；硬件为 NVIDIA RTX 3050 4GB + i7-12700H + 32GB 内存；每例固定 2400 个 primitive。基线：2DGS、3D-HGS、QGS（默认设置）。指标：PSNR/SSIM/LPIPS、MVDC（按场景范围归一化的多视深度不一致性）、模型大小、每帧时间。关键结果：H-2DGS 的 MVDC 在 5 例上均为 1e-5 ~ 4e-5，显著低于 2DGS（3e-5 ~ 1e-4）、QGS（5e-5 ~ 1.4e-4）与 3D-HGS（1.0 ~ 1.57）；模型恒定 7.97 MB、每帧 29-42 ms；光度分较低（PSNR 21.54-25.20、SSIM 0.745-0.839、LPIPS 0.161-0.218），而光度最优的 QGS（PSNR 最高 40.07、SSIM 最高 0.986）需 78.93-142.01 MB 与 120.68-188.04 ms。术后实验中深度监督把切除腔重建拉向术后 MRI 形态，外观窗口恢复纹理，叠加配准在各视角成立。

## 创新点与贡献
1. 三阶段 volumetric→TSDF→height-field 转换管线，附带可微 ray-wise thickness 目标，把外观获取与表面构造解耦
2. 弯曲高度场 Gaussian primitive：几何、颜色、不透明度使用分离基函数，patch 可局部弯曲以贴合皮层曲率
3. 深度监督的术后表面形变 + tracked appearance preservation + 几何/外观交替优化
4. 面向 tractography 与 MRI 解剖融合的锐利皮层边界，纤维束不再被弥散体积 opacity 遮挡

## 局限与风险
- 光度保真度不及基线：薄显式表面损失高频高光表现，PSNR/SSIM 差距明显（如 Preop 3 上 25.20 vs QGS 40.07）
- 依赖 SfM 恢复的相机位姿；生理性皮层搏动使位姿混淆组织运动，已导致 1 条序列重建失败
- 每例固定 2400 primitive 预算，未与体积型基线的 primitive 数量对齐，比较口径不完全一致

## 与文献库的关系
在 2DGS、3D-HGS、QGS 等表面化高斯表示路线上，针对外科有限视角场景提出先浓缩密度、再融合 TSDF、最后初始化曲面 patch 的新范式；是首个面向神经外科皮层-tractography-MRI 统一可视化的锐利可形变表面工作。
