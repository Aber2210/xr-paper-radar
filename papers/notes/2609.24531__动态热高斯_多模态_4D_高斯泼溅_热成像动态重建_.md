# 动态热高斯：多模态 4D 高斯泼溅（热成像动态重建）

## 一句话结论
Dynamic Thermal Gaussians 提出多模态 4D 高斯泼溅，对热成像场景做高保真时空重建（外观 + 温度），在热与 RGB 双模态达到 SOTA（32.24 dB PSNR / 0.947 SSIM / 0.119 LPIPS，超最强基线 +1.52 dB），但应用面向热成像/军事，XR 相关度偏弱。

## 要解决的问题
热成像在军事与热分析中重要；3D 热重建已从 2D 扩展到 3D，但现有工作假设静态温度分布，忽略热量随时间演化的动态特性。

## 方法详解
- 把多模态 4D Gaussian Splatting 用于热成像动态重建；
- 联合建模外观与温度随时间的演化；
- 分辨率一致配对处理（640×480 / 320×240）。

## 实验与结果
- 热与 RGB 双模态 SOTA；
- 32.24 dB PSNR、0.947 SSIM、0.119 LPIPS，超最强基线 +1.52 dB PSNR；
- 在动态场景中优于静态多模态方法。

## 创新点与贡献
把 4DGS 扩展到热成像多模态动态重建，是 4DGS 技术谱系的应用拓展。

## 局限与风险
应用为热成像/军事，与 XR 显示/交互直接关联弱（故 XR 相关度评级偏弱，IMP=3、TRL=2）；真实散热物理建模有限。
