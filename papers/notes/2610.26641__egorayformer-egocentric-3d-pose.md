# EgoRayFormer：射线空间立体精化的第一视角 3D 人体姿态估计

## 一句话结论
在 UnrealEgo2（123,480 测试帧）与 UnrealEgo-RW（24,012 测试帧）两个双目鱼眼基准上，EgoRayFormer 仅用约 12 cm 基线的下视双目鱼眼图像与标定，经 3 级共享 3D 假设的射线空间立体精化加因果时序建模，估计设备坐标系 16 关节 3D 姿态，推理不使用 GT 根位置、场景深度或头姿；配对消融支持几何分支整体有效。

## 要解决的问题
第一视角（头戴设备）3D 人体姿态估计中，单目估计深度歧义大，而多数立体方法又依赖场景深度、头姿等推理期 GT 输入。头戴 rig 的双目下视鱼眼几何特殊（约 12 cm 基线、强畸变），如何把立体图像采样与姿态精化耦合在同一空间、并在零 GT 输入下输出设备相对坐标，是尚未解决的问题。

## 方法详解（含关键公式/架构，保留原文术语）
问题设定：头戴 rig 载两台下视鱼眼相机 v∈{1,2}，基线约 12 cm，采用 Scaramuzza 多项式全向标定，设备中心 c=(o1+o2)/2，每帧预测设备坐标系 J=16 关节位置。编码器为 fisheye-native stereo encoder，输出 stride-4、C=128 通道特征图。解码器以共享 3D 假设为立体特征聚合单元：proposal 层对双视图特征图做 camera-conditioned cross-attention（每个 query 加学习相机 embedding，线性融合两视图输出），再接 token self-attention、causal temporal attention 与 FFN；每个精化阶段 l=1..3 将同一 3D 假设投影进两个已标定视图、聚合配对特征，输出学习式位姿更新；第二条路径预测图像平面修正并对修正视线 ray 求交（regularised ray-intersection update），与学习更新混合。时序上采用 causal temporal modelling：track-prior token 嵌入上一帧预测位姿，序列起始用 learned null token；训练时上一帧 GT 位姿加 σ=3 cm 高斯扰动并以 0.3 概率替换为 null token；cached image features 支持逐帧流式推理。backbone 可选 R18（ResNet-18 @ 256²）或 ViT-S+（DINOv3 ViT-S+/16 @ 384²）。

## 实验与结果（表格化关键数字）
数据集：UnrealEgo2（合成双目鱼眼 rig，12,139 训练序列/1,002,671 帧、1,545 验证序列/127,937 帧、123,480 测试帧）与 UnrealEgo-RW（实物头戴 rig，402 训练序列/79,705 帧、96 验证序列/30,083 帧、24,012 测试帧）；RW 上分别报告仅 RW 训练与 UE2+RW 混合训练（后者以同 seed UE2 模型初始化）。标定：UE2 用单一合成 rig；RW 保留数据集 intrinsics，将每个会话的 camera-from-device 变换拟合到训练集标注（验证/测试标注从不使用），未见测试会话借用时间最近会话的 rig。协议与指标：官方 device-relative 协议（16 关节相对设备中心），推理不使用任何 GT；报 MPJPE 与 PA-MPJPE（mm，rigid alignment with scale 后），用基于公开 EgoPoseFormer 评估代码的统一 scorer；消融另报 MPJVE（mm/frame）。每条序列以单个因果流 FP32 处理；附录含按距离的误差/gate 统计、协议缺口分析与 root-relative 数值参考。

## 创新点与贡献
① 以共享 3D 假设为解码单元，把 stereo image sampling 与 pose refinement 通过 ray-local frame 直接耦合，而非两阶段流水线。② 修正视线求交提供几何候选更新并与学习更新混合，几何分支作为整体在配对消融中被支持。③ 鱼眼原生立体编码器 + 因果时序注意力 + 缓存图像特征，实现逐帧流式、零 GT 输入的设备相对估计。④ 在 UnrealEgo2/UnrealEgo-RW 双基准、多 backbone 与多推理条件下系统对照（含 root/device-relative、预测根/GT 根的配对协议实验）。

## 局限与风险
digest 结论仅为本地评估（local evaluations），摘要与结论段未给出主表 MPJPE 数值，实际增益幅度需查原文表格。RW 有一个测试会话不在训练数据中、需借用时间最近会话的 rig，泛化到全新 rig 的能力未验证。推理依赖相机标定，对标定误差的敏感性 digest 未量化。逐帧 FP32 因果流的实时性（附录 I 有效率测量）digest 未含数字，是否满足头戴端要求需核实。
