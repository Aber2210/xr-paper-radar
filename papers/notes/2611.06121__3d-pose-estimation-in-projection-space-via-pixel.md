# 基于像素级可见光通信投影空间的三维位姿估计

## 一句话结论
首次把 PnP 三维位姿估计引入 Pixel-level VLC：设备上 4 个共面光电传感器经 PVLC 解码的 2D 像素坐标作为 image points、其已知 3D 布局作为 object points，实现约 8 ms 延迟、Kalman 滤波后 3D 位置 RMSE 19.2 mm（160 mm 布局 50 mm/s 时 13.5 mm），且误差随速度仅增约 20–33%，远小于相机 AR 标记的 3–4 倍增长。

## 要解决的问题
PVLC 通过投影仪逐像素高速亮度调制把隐形位置码嵌入投影画面，无需外部传感与投影仪-传感器校准即可本地化，但其固有传输的只是平面 2D 像素坐标，因此以往只支持在地面上运动的设备，无法估计空中机器人等三维空间设备的 3D 位姿。另一方面，相机/动捕等外部感知方案需要相机-投影仪标定并经单独信道回传位置，带来部署复杂度与延迟；传统投影式跟踪还要在画面中预留专用跟踪区，既占内容面积又限制设备速度。

## 方法详解
把投影仪当作逆相机：4 个共面光电传感器（80 mm 或 160 mm 方形排布）各自解码照亮它的投影仪像素坐标 p_i∈R²，与预先测定的传感器 3D 布局 P_i∈R³ 组成对应点，解 s·p_i=A[R|t]P_i 得到设备相对投影仪的 3D 位姿；A 为投影仪内参（焦距与主点，由投影仪-相机标定系统获得）。因共面 4 点可用 Homography Decomposition（最少 4 点）求解，并用“设备始终朝向投影仪”的约束在两组解中取正确者。PVLC 数据结构沿用 Hiraki 等的方案：一帧为一个传输单元，含 12 bit 同步帧组（全屏相同）、32 bit Gray 码数据帧组（抑制像素间串光，尤其抑制运动中的误差扩散）与 106 bit 亮度调整帧组；投影仪为 DLP LightCrafter 4500，1140×912 分辨率、125 Hz 周期。硬件端：S2506-02 光电二极管 + OPA2353UA 运放做电流-电压转换、放大与比较，高通滤波抑制荧光灯等低频环境光，NUCLEO-F303K8 单片机解码后串口发给 ThinkPad X13 上的 PC，用 OpenCV 的 Homography Decomposition Python API 求解。后处理用常加速度模型 Kalman 滤波（18 维状态含位置/旋转向量及其一、二阶导数，Δt=40 ms，观测噪声 R_ν=diag(0.02²,0.02²,0.16²,0.8²,0.8²,0.8²)，网格搜索确定）。

## 实验与结果
实验系统把传感器设备装在 xArm5 机械臂末端（重复定位 ±0.1 mm，其运动学解算位置作为真值），机械臂基座放 ArUco 标记（DICT_4X4_50，4×4）定义原点，投影仪侧 RealSense D415 相机（1920×1080@30 fps、自动曝光）观测该标记做坐标系对齐；全部实验在开灯室内进行。对比方法为相机式 ArUco 标记位姿估计（OpenCV）。变量为布局尺寸（80/160 mm，两方法点间距一致）与速度（50/100/200/400 mm/s，各 5 圈、4 条轨迹，统一下采样到 40 ms）。Table I（3D RMSE±SD，mm）：PVLC 160 mm 为 13.5±7.3 / 14.2±7.9 / 15.3±8.5 / 17.9±10.0，PVLC 80 mm 为 23.4±13.9 / 25.1±15.2 / 25.3±14.9 / 28.1±17.1；AR 160 mm 7.0±2.6 / 8.0±2.8 / 14.0±5.3 / 26.7±13.5，AR 80 mm 9.8±3.7 / 11.5±4.4 / 19.7±9.0 / 30.3±17.6；角度误差 PVLC 160 mm 7.4°→6.8°、AR 160 mm 2.4°→6.1°。50→400 mm/s 下 PVLC 3D 误差仅增约 33%（160 mm）/20%（80 mm），AR 增 3–4 倍；400 mm/s 时 PVLC 160 mm（17.9 mm）已低于两种 AR 标记。布局从 80→160 mm 使 PVLC 50 mm/s 处 3D 误差降约 40%、角度降约 65%（AR 仅降约 30%）。延迟：AR 标记 40.2 ms，本方法 8.0 ms。PnP 求解器对比（Table II，80 mm）：HD 23.0±13.2 mm / 22.2±15.8° / 0.22±0.06 ms，IPPE 22.8±13.2 / 24.2±16.4 / 0.01±0.01 ms，P3P 29.6±18.2（有离群值）/ 0.02 ms，EPnP 121.0±62.3 mm / 0.03 ms。Kalman 平滑（Table III，80 mm 全速聚合）：3D 25.4±15.4→19.2±12.1 mm，2D 10.2±6.6→9.0±5.9 mm，角度 22.0±15.9°→16.0±9.2°，且 ±3σ 误差带全程包住实际误差。理论下界（f≈1570、d=1.7 m、N=4）：σ_2D≈0.54 mm（两布局），σ_3D 80 mm 约 11.5 mm、160 mm 约 5.8 mm，角度 0.67°/0.34°；实测约为下界 2 倍，对应有效解码不确定度约 2 像素。

## 创新点与贡献
首次将 PnP 3D 位姿估计应用于 PVLC，以多传感器解码像素坐标反演设备三维位姿，把 PVLC 定位从 2D 扩展到 3D。实现内容显示区与跟踪区天然重合（每个像素都带码，无需专用跟踪区、设备不会离开跟踪区），无需外部传感基础设施。在 50–400 mm/s 真实运动范围内系统评测，达到 cm 级精度与 8 ms 延迟，并给出理论误差下界与“实测≈2 倍下界=有效 2 像素不确定度”的定量解释。

## 局限与风险
速度上限 400 mm/s：更快的设备在一个码周期内会跨多个像素，预计解码误差增大（需缩短码周期或运动感知解码）。设备尺寸与几何受限：深度与角度误差与基线 b 成反比，小型化需更高分辨率投影仪或更多传感器补偿；非平面（曲面）设备不能用 HD/IPPE 这类共面假设求解器，而 P3P/EPnP 在本实验中精度差且 EPnP 达 121 mm，需加传感器或与 IMU 做 EKF 融合（z 轴最需要）。工作区域被限制在投影仪投影体内。角度误差的大 SD 暗示平面位姿两解之间的跳变；2D 误差超下界则与标定误差及投影微斜有关。论文定位为可行性验证。

## 与文献库的关系
开辟 PVLC 从 2D 到 3D 位姿估计这一新问题，是 PnP 框架在投影式 SAR 中的反向应用（相机图像平面换成投影仪像素平面）；与相机式 AR 标记、动捕等外部感知路线互补——用投影内容本身完成定位，换取无需标定与 8 ms 级低延迟，代价是绝对精度低于相机标记（低速时）。

## 可复现性（代码/数据/硬件）
全文未述及代码或数据发布；但硬件与参数交代完整：DLP LightCrafter 4500 投影仪、S2506-02 光电二极管、OPA2353UA 运放、NUCLEO-F303K8 单片机、ThinkPad X13 Gen 2（Ryzen 5 PRO 4650U/16 GB）、xArm5 与 RealSense D415，PnP 求解用 OpenCV Homography Decomposition Python API，滤波观测噪声经网格搜索确定，复现门槛主要在原型电路制作。

## 行动建议
做 SAR/投影引导空中机器人的从业者可直接复用该 PnP+PVLC 管线，优先选共面假设求解器（HD 或 IPPE，IPPE 快 20 倍且精度相当），并尽量加大光电传感器基线（80→160 mm 使 3D 误差降约 40%），再用常加速度 Kalman 滤波压制 z 轴抖动。
