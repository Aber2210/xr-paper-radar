# EgoHSI3R：第一视角视频的在线 4D 手-场景交互重建

## 一句话结论
EgoHSI3R 以 CUT3R 循环场景表征为底座，融合 WiLoR 手部先验与交互感知接触建模，用单一在线前馈网络联合恢复相机运动、稠密场景几何、世界空间双侧 MANO 手与逐顶点接触，在 ARCTIC 取得最优 W-MPJPE 108.80 mm（较最强基线 StableHand 降 15.79 mm），端到端 10.07 FPS。

## 要解决的问题
第一视角视频蕴含丰富手-物交互信息，但相机系方法只恢复相机坐标系手姿而无世界坐标位置，世界空间方法靠外部 SLAM 估相机轨迹却不重建场景几何、不建模接触，两者都不完整。把专用预测拼成完整 4D 重建通常需要逐序列离线优化，难以满足机器人示教、人机协作等在线更新场景；且独立估计的手与场景常出现浮空手或穿模，需在预测阶段本身建模手-场景空间关系。

## 方法详解
EgoHSI3R 以 CUT3R 循环场景状态为底座（持久累积几何与相机证据，提供共享世界空间与尺度），把 WiLoR 裁剪式手部先验（M=18 token：16 姿态+形状/全局平移）注入解码器。Hand Prompt Builder 用在线检测框经 RoIAlign 提取局部场景特征并池化为上下文，以特征门控 g=σ(φ_g([q;s])) 融合：P=φ_mix(q+g⊙s)，缺失手用学习 mask token 保持固定双手布局。Interaction-Aware Contact Builder 以固定 MANO skinning 矩阵 W∈R^{778×16} 把 16 个关节 token 传播到 778 个顶点，顶点查询对同框场景上下文做多头交叉注意力输出接触概率，并经门控 α 残差反馈精化手部 token，形成接触→手闭环。训练损失 L=L_rec+L_MANO+0.3(L_focal+0.1 L_part)，MANO 项含参数、相机系、腕相对与 2D 重投影监督。

## 实验与结果
训练用 HOT3D、ARCTIC、TACO、H2O、HOI4D、DexYCB 六个第一视角手-物数据集（接触标签按 1 cm 几何阈值生成）。世界空间手重建（ARCTIC，150 帧片段）：W-MPJPE 108.80 mm、WA-MPJPE 25.82 mm 均最优，较 StableHand 降 15.79/6.84 mm；相机系（p-free 协议）PA-p 7.025（ARCTIC）/6.312 mm（HOT3D）最优；接触估计（ARCTIC/DexYCB）precision 52.15/51.62 超 HACO，但 recall 45.02/50.38 偏低；H2O 场景重建 Abs Rel 0.027、δ<1.25 0.993 最优。消融：WiLoR 微调使 ARCTIC MPJPE 22.916→19.952 mm，接触反馈再降 W-MPJPE 4.495 mm。效率：端到端 10.070 FPS、峰值显存 6.650 GiB、参数 1470.25M。

## 局限与风险
论文自述：因果推理无法做未来帧平滑，AccEr（16.91）与 MRRPE（120.77 mm）偏高；时间抖动高于专做运动平滑的方法；接触 recall 低、预测偏保守；手重建与接触联合训练存在优化不稳定。客观看：WiLoR 先验原本只针对右手；接触标签为几何距离生成而非力或人工标注；参数 1470.25M 偏大；代码尚未发布。

## 与文献库的关系
位于前馈几何基础模型线（DUSt3R/VGGT→Spann3R/SLAM3R/CUT3R 的序列化路线）与第一视角手部重建线（HaMeR/WiLoR 相机系，HaWoR/Dyn-HaMR/StableHand 世界空间系）的交叉点，并首次把稠密接触估计（HACO、ContactPose 一系）纳入统一前馈框架；与 MINT（相机+手轨迹）、UniSH/Human3R（第三人称 SMPL）互补，对标并超越 HaWoR、StableHand、HandFlow 等世界空间方法。

## 可复现性（代码/数据/硬件）
原文称「正在准备代码公开」（preparing the code for public release），截至撰写时未发布，未承诺数据集开源；实验设置、数据划分、训练细节与硬件（单卡 NVIDIA H200）在正文与附录给出，项目页 https://pmz-enterprise.github.io/egohsi3r-page/ 。

## 行动建议
具身/XR 手-场景交互理解的在线重建底座：ARCTIC W-MPJPE 108.80 mm 最优（较 StableHand 降 15.79 mm）、端到端 10.07 FPS、峰值显存 6.65 GiB，可作 VR 遥操作/第一视角助手的实时手-物状态估计上游；接触 recall 偏低（45-50%）、参数 1470M 偏大、无未来帧平滑（AccEr 16.91 偏高）、接触标签为几何距离生成而非力标注、代码尚未发布是主要缺口。
