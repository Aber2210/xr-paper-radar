# EgoActionBench：第一视角人类视频稠密动作描述基准

## 一句话结论
EgoActionBench 含 1,407 个 episode、41,132 条人工精修标注（总时长 7.982 小时，动作时长中位数 0.60 秒；左手 17,319/右手 19,758/双手 4,055 条）。20 个基线系统评测显示：最强模型 GPT-6 Astra 的 EgoActionScore 仅 59.6，人类专家达 90.4；GPT-6 Astra 的 m-tIoU 为 40.6 vs 人类 88.4。经自动标注数据上的 SFT+GRPO 适配后，Qwen3-VL-4B 的 EgoActionScore 达 41.8（比未适配基线高 15.9 分）、LLaVA-OneVision-2-8B 达 47.9（高 23.2 分），均超过所有开源基线；时长小于 0.5 秒的动作上两个基座 m-tIoU 不足 4，短暂动作边界恢复是核心瓶颈。

## 要解决的问题
从连续第一视角视频恢复细粒度人类操作，需同时满足 action atomicity（把连续操作分解为原子动作）、temporal precision（含亚秒级动作的起止边界）与 hand–action association（左右手/双手轨道）三项要求，而现有 benchmark 只覆盖其中部分能力；且密集预测评估协议常把时间分割误差与语义误差混为一谈。

## 方法详解
数据表示为左手/右手/双手三条独立轨道上的时间局部化原子动作（标注 verb、object、tool）。5 阶段 human-in-the-loop 标注：CaRe-Ego 提取左右手掩膜并渲染高亮、VLM 滑窗（1 秒）生成 per-hand 草稿并按时间邻接+文本相似度合并、人工校正、agentic QC（依据 hand–object contact、hand–motion phase、object–state change 三视觉线索提修订）、最终人工验证。渐进式评估协议：先按时间合格性检索候选预测，再按内容一致度（Qwen3-32B 裁判评 Verb/Objects/Tools/Motion 四字段）为每个 ground-truth 选一个预测，联合评 semantic fidelity、temporal overlap（m-tIoU）与 hand 标签；另以一对一正内容匹配的 micro-averaged F1 度量 action precision/recall。EgoActionScore = mean(Temporal=m-tIoU 与 F1 的均值, Semantic)。

## 实验与结果
数据源：Ego4D（451 clips/16,774 动作/3.130h）、EgoLife（485/13,306/2.676h）、EPIC-KITCHENS-100（471/11,052/2.176h），覆盖 6 大活动组、17 类场景。对比 20 个模型系统：GPT-5.6 Sol（EgoActionScore 49.8）、GPT-6 Astra（59.6）、Gemini 3.1 Pro（34.8）、Qwen2.5-VL-72B（24.7）、Qwen3-VL-32B（29.2）、InternVL3.5-8B（20.4）、VideoLLaMA3-7B（14.2）、EgoGPT-7B、Flora（9B segmenter+27B captioner）等；人类基线由 3 名标注员独立标注评测集。消融：GRPO 使 Qwen3-VL-4B 40.6→41.8、LLaVA-OV2-8B 46.9→47.9；模型排名对候选 overlap 阈值（0.3/0.5/0.7）稳健；输入帧 2→5 fps 提升、10 fps 增益有限；裁判 Qwen3-32B 与两名人工评审一致率 88.89%/89.03%，且与 GPT-5.6 Sol 裁判给出相同模型排名。评测：2 fps、temperature 0、seed 42。

## 创新点与贡献
['首个联合评估动作原子性、时间精度与手-动作关联（独立手部轨道）的第一视角 dense captioning benchmark', '渐进式评估协议把语义保真度与时间分割误差解耦，可分别诊断 what/when/which-hand', '5 阶段人机协同标注流水线，其中 agentic QC 用三类视觉线索做密集标注质检', '在自动标注训练 episode 上做 SFT+GRPO 适配，验证目标粒度监督可在不改架构的前提下显著提升']

## 局限与风险
['论文自述当前模型在动作原子性、时间精度、手-动作关联上均与人类差距巨大，短暂动作（<0.5s）边界恢复是核心难点', '评测依赖 LLM 语义裁判，存在裁判偏差风险（论文以一致性与跨裁判稳定性部分缓解，但无法完全消除）', '数据以室内场景为主，室外与跨域泛化未充分验证', '人类基线仅 3 名标注员；自动标注训练数据的质量依赖 VLM 与 agent 质检能力']

## 与文献库的关系
谱系上游为 ActivityNet Captions、EPIC-KITCHENS-100、Ego4D/Ego-Exo4D、HD-EPIC、EgoYC2 等第一视角与 dense captioning 基准；直接对标 WGO-Bench（指令条件时间戳子任务标注）、Flora/DenseCaptionBench 与 HanDyVQA（手-物 QA）。本文定位为把 dense captioning 推进到原子动作+独立手部时间线的通用 benchmark，填补三要求无法联合评估的空白；基线覆盖闭源/开源 VLM、视频 captioning 与第一视角专用模型四大类。

## 行动建议
做具身智能人类数据筛选时，用原子动作+手部轨道标注替代粗粒度 activity label，可直接复用其 5 阶段标注流水线与渐进式评估协议；把 <0.5 秒短暂动作的边界回归作为专项优化方向；采用 SFT+GRPO 的目标粒度适配作为低成本提升手段。
