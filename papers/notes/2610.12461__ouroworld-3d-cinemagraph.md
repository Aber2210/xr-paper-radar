# OuroWorld：将任意 3D 高斯场景变为多样、无缝循环的动态 3D 电影图

## 一句话结论
OuroWorld 将任意静态 3D 高斯场景自动转化为多视角无缝循环、含多样运动的 3D 电影图（cinemagraph），无需遮罩。

## 要解决的问题
现有 3D 世界模型生成的场景是'冻结在时间中'的静态可探索场景，缺乏让场景生动循环运动的能力；多数方法需遮罩或只能产生短暂/不连贯循环。

## 方法详解
mask-free 框架：VLM 推断合理动力学并引导视频模型合成参考视频 → 提升到多视角视频 → 提出 Inconsistency-Robust Periodic 4DGS（傅里叶级数表示周期运动）学习；引入 scene-view consistent optimization（SVCO）与 VLM 过滤缓解不完美监督带来的不一致；提出 ground-truth-free 的 Vividness 指标（Motion/Illumination/Visual Variation）。

## 实验与结果
39 个评估场景（Mip-NeRF 360 / HY-World 2.0 / Marble / Lyra 2.0）。Vividness 全面超越 Gaussians-to-Life / 3D Cinemagraphy / LoopGaussian / 3D-MOM——Illumination Variation 0.0518 vs 各基线 ≤0.0248、Motion Variation 0.0413 vs 0.0588（Gaussians-to-Life 仅循环 0.5s 故 MV 高但 MALF 低）。消融：去除 grounding 主要降低 Motion Variation（0.0413→0.0324）；去除 SVCO 一致性/清晰度最差。含用户研究。

## 创新点与贡献
首个 mask-free 的 3D cinemagraph 框架；周期性 4DGS 表示；无真值生动度指标。

## 局限与风险
受视频生成先验约束，不合理生成会传播到最终场景（VLM 过滤缓解）；单参考视频在宽视角范围产生更大遮挡与不一致；生成多参考视频是改进方向。
