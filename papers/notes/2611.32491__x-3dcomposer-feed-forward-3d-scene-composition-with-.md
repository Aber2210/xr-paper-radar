# X-3DComposer：任意资产、任意视角的前馈 3D 场景合成

## 一句话结论
把「布局预测」重构为「多视图相机预测」：asset render 当额外 view，物体位姿由预测相机与已知 render 相机闭式相除，因此复用 VGGT-Ω 预训练先验、只加极少量参数且无需 3D encoder——IndoorMix CD-S 7.29 vs SceneMaker 12.86（−43%），单次前向约 1 s 联合放置全部物体。

## 要解决的问题
从图像组装可编辑 3D 场景需要「每物体一个 asset」加「一套布局」，asset 已可由 3D 生成或 CAD 检索获得，布局却缺通用解：场景生成方法把布局与几何生成耦合、布局无法迁移到别处；物体位姿估计逐物体处理、假定真实尺寸 CAD、常需 depth 并靠 render-and-compare 迭代；独立布局模型多依赖迭代采样、稠密对应或逐场景优化，且多数只吃单图。量化上，SceneMaker 单目下 CD-S 12.86、耗时 5.8 s，SceneGen 的 native 布局 CD-S 高达 66.07。

## 方法详解
输入 S≥1 张场景图、每个目标物体的 mask 与任意来源 asset（mesh），输出每个物体的 (R_i, t_i, s_i)，共 9 DoF；asset 先归一化到 bounding box 居中、最长边为 1 的 asset frame，输出位姿表达在首帧相机系。核心是 objects as views：不把 asset 几何喂进网络，而是在 asset frame 内用已知相机 L_{i,m} 渲染 M 张图，把 scene views、object crops（从原分辨率场景图裁 c 个方形区域，补回小物体丢失的细节）、asset renders 三类 view 一起送进由 VGGT-Ω 改造的多视图几何模型，camera head 为每个 view 回归相机。物体身份由 identity embedding e_i 承担：把 e_i 加在各 view 的 mask 位置上，把 mask、crop 与 render 绑到同一物体，因此即便场景里有两个相同物体也能区分（互换 embedding 即交换 asset）。位姿读取是闭式的：在缩放后的 asset frame 中第 m 个 render 的相机为 V_{i,m}=[L^R_{i,m} | diag(s_i)L^o_{i,m}]（各向异性下按约定缩放中心），而模型预测其在场景系为 P̂_{i,m}，于是 [R_{i,m}|t_{i,m}]=P̂_{i,m}V_{i,m}^{-1}；尺度必须先于位姿：s_i=exp(mean_m ℓ_{i,m})，由每 render 的 per-axis log-scale 给出；多 render 的平移取均值、旋转取矩阵均值再 SVD 投影回 SO(3)。内参 K、相机位姿 P 与深度 D 是可选几何条件，有则定绝对单位（估计一个全局缩放因子同时乘 t_i 与 s_i），无则用「场景点到首相机平均距离=1」的归一化单位。训练监督相机、尺度与位姿，并加对称性、grounding 与物理（穿透）约束。

## 实验与结果
- IndoorMix 单目生成 asset：CD-S 7.29 vs SceneMaker 12.86（-43%）、F-S 92.98 vs 84.27、IoU-B 0.616 vs 0.433；SAM3D mesh 组 CD-S 3.43 vs native 6.08
- 3D-FUTURE：CD-S 9.22 vs SceneMaker 11.23（-28%）、F-S 91.10 vs 88.14、IoU-B 0.591 vs 0.504
- 相对 SceneMaker 的场景级 Chamfer distance 在 IndoorMix 低 52%、在 3D-FUTURE 低 28%（无深度输入条件下）
- 五个场景生成方法的 mesh 固定、只换布局时，本方法布局均优于其 native 布局（如 SceneGen CD-S 6.49 vs 66.07、MIDI 7.29 vs 57.79、FIRE3D 8.95 vs 11.40）
- 0.91 s/场景、峰值显存 5.2 GB vs FoundationPose 7.5 s/4.3 GB、PoseGAM 6.8 s/15.5 GB、SceneMaker 5.8 s/13.6 GB
- GT CAD 无条件下 CD-S 0.85；改用估计的 K+P+D 反而恶化到 75.95（真值条件下为 0.52）

## 创新点与贡献
- 把「布局预测」重构为「多视图相机预测」：asset render 作为额外 view，物体位姿由预测相机与已知 render 相机闭式相除得到，因此可直接复用 VGGT-Ω 的预训练先验、只加极少量参数，也不需要任何 3D encoder
- 方法因此接受任意来源 asset（无需真实尺寸 CAD、无需 depth）、任意视图数，并在单次前向约 1 s 内联合放置全部物体
- per-axis scale 处理资产比例失真，identity embedding 处理相同物体与 mask-crop-render 绑定

## 局限与风险
- 必须输入物体 mask，作者明确将「模型内预测 mask」列为未来工作
- 只在室内场景训练与评测，室外、开放词汇与极端遮挡未验证
- 对不准确的估计几何条件高度敏感（估计 K+P+D 使 CD-S 从 0.85 恶化到 75.95），物理约束只降穿透、不保证物理可行
