# WildHSR：基于 3D 基础模型的度量前馈 4D 人-景重建

## 一句话结论
WildHSR 问：一个"只到尺度（up-to-scale）"的 3D 基础模型，能否通过轻量适配同时补齐度量人-景重建缺的两个输出——**度量尺度**与**持续人体身份**？用精选网络视频中的人体给出近似闭式尺度伪标签预训练 Scale Readout，再以真实视频精确度量监督微调轻量适配器，推理时头部直接从基础模型 token 预测度量尺度、无需标尺。

## 要解决的问题
3D 基础模型单前向恢复视频相机与几何，但最强模型只到尺度；联合人-景重建还需要度量尺度与持续人物身份两个缺失输出。精确度量标签稀缺，而未经标注的野生视频海量。

## 方法详解
- **伪标签初始化**：用精选网络视频中的人体——一个带位姿的度量身体 + 2D 关键点给出近似的闭式尺度伪标签；
- **Scale Readout 预训练**：用上述伪标签预训练尺度读出头；
- **轻量适配器 + 精确监督微调**：用标准真实视频训练划分的精确度量监督，与轻量适配器一起微调；
- **推理**：头部从基础模型 token 预测度量尺度，无需标尺/标定。

## 实验与结果
- 在野生/真实视频的人-景度量重建基准上，相对只到尺度的基线显著恢复度量尺度与持续身份（具体指标见论文）；
- 验证伪标签预训练 + 精确微调两阶段的有效性。

## 创新点与贡献
把"尺度歧义"用极廉价的闭式伪标签 + 轻量适配解决，是"基础模型 up-to-scale → 度量重建"的实用路径，对野生视频 4D 人-景重建直接可用。

## 局限与风险
- 伪标签来自网络视频人体，对无清晰人体/极端姿态场景尺度恢复退化；
- 身份持续性在多人交叉/长时序重识别上的鲁棒性未充分量化。

## 与文献库的关系
库内"重建与SLAM"方向（DAVIO、KYS-SLAM、FMCW-LIO 等侧重定位/建图）新增"前馈度量人-景重建"子方向；与 4D 人体（Ego-Exo4D-HM）共享人体重建主题但方法（基础模型适配 vs 数据集重建）不同，互补。

## 可复现性
给出两阶段训练协议，但无公开代码；依赖 3D 基础模型与真实视频基准，复现较高。

## 行动建议
做 4D 人-景/野生视频重建时，WildHSR 的"闭式尺度伪标签 → 轻量适配器"应作为比重训练更省力的基线；关注其在无清晰人体场景的退化。
