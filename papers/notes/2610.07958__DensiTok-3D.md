# DensiTok：让前馈式 3D 高斯泼溅“看见”比输入更多的视角

## 一句话结论
DensiTok 指出前馈式 3DGS（单前向重建）质量受输入视角数限制，但瓶颈不是像素而是“几何 token”——于是用流匹配（flow-matching）在潜空间直接合成缺失视角的几何 token，而非用扩散模型生成更多像素再重拟合。在 AnySplat 骨架上把被遮挡/未观测视角“补”出来，ETH3D/ScanNet/Mip-NeRF360 上 PSNR 普遍提升约 1–3 dB（ScanNet 双视图 19.60→22.51），且可在单步微调下保持质量、降低推理成本。

## 要解决的问题
前馈 3DGS 用网络跨场景训练、单次前向预测高斯；其质量随输入视图数增加而提升，但获取更多视角成本高。现有补救（多视图/视频扩散生成额外输入视图、或修复渲染后再重拟合）要跑大模型 + 二次编码，且像素不是共享 3D 表示、跨视图一致性只能“鼓励”无法“强制”。

## 方法详解
核心洞察——重建只需要缺失视角的几何 token，而非像素。DensiTok 把“几何 token 增强”限制在视角插值（在首末观测相机间插值虚拟相机），用流匹配 DiT 在潜空间预测未观测视图的 token；观测视图走干净分支、未观测走加噪分支，AdaLN 注入噪声水平与相机信息；Gaussian head 再用这些 token 解码高斯。训练用 flow-matching 预训练 + 单步微调，推理时 NFE=1 即可。

## 实验与结果
在 ETH3D、ScanNet、Mip-NeRF360 评测，输入视角 2/3/5/7；+DensiTok 在三数据集 PSNR 普遍 +1~3 dB，ScanNet 增益最大（双视图 19.60→22.51，七视图 23.25→25.20），相机/深度精度同步改善；表 9/10 给出多数据集一致改进与单步微调效果（N=16、NFE=1 即 22.56 PSNR），并在训练集外数据集也受益。

## 创新点与贡献
把“补视图”从像素空间（扩散生成图像）转到几何 token 潜空间，避免运行大模型与二次几何编码，且 token 是共享 3D 表示、一致性可被强制；与 LoCoSplat 等前馈 3DGS 路线互补（后者加速推理，DensiTok 提升少视图质量）。

## 局限与风险
当前仅做视角插值，不支持超出观测相机区间的外推（extrapolation）；虚拟相机仅在首末观测之间插值；训练依赖 AnySplat 类骨架（LAM-VAE + 相机条件 DiT）。

## 与文献库的关系
库内前馈 3DGS 线有 LoCoSplat（2610.04351，无 3D 网络极速前向）、PocketSplat（移动端预算重建）、SCION（组合基元）；DensiTok 解决“少视图质量塌陷”这一互补痛点，与 LoCoSplat 的“快”形成“质量 vs 速度”双维度增益，非取代。
