# VolFill：体素流匹配的单图 amodal 场景重建

## 一句话结论
提出以混合 3D VAE + 潜空间流匹配 DiT 生成完整 TUDF 体素网格的单图 amodal 场景重建框架 VolFill：SCRREAM 上完整场景 CD 3.03、FS_0.02 54.83（×10²），显著优于 LaRI（5.19/30.85）与 NOVA3R（3.43/45.12），NRGB-D 上 FS_0.02 63.92 亦领先；RTX 4090 推理仅 1.4 s/图、峰值显存 3.0 GB。

## 要解决的问题
从单张 RGB 图恢复包含被遮挡结构的完整 3D 几何本质欠定；前馈方法受 pixel alignment 硬约束只能重建可见表面，优化式方法需稠密采集与逐场景优化（数小时），大重建/生成模型多面向物体级场景；场景级 amodal 方法中 LaRI 的固定层数对密集遮挡欠表征且产生 layered artifacts（multiple wall 效应），NOVA3R 的点云输出噪声大、结构碎裂，且非结构化表征无法直接等值面抽取。

## 方法详解
输入单图 I∈R^{H×W×3}，输出视锥对齐的 256³ TUDF 网格 V(p)=min(dist(p,𝒮),τ)（τ=3 voxels，无符号以适应非水密室内场景）。混合 3D VAE：稀疏卷积编码 16× 下采样至 16³×C=16 稠密潜空间并经 KL 正则；解码先稠密上采样至 64³、由 occupancy head 预测掩码（监督自 GT occupancy，IoU 99.8%）再稀疏卷积至 256³，损失 ℒ_VAE=L1+λ_bce BCE+λ_dice Dice+λ_kl KL。潜 DiT（12 blocks、768 dim、12 heads、AdaLN 时间步条件、QK-RMSNorm）以 rectified flow 训练：z_t=(1-t)ε+t z_1，ℒ_gen=E‖u_Φ(z̃_t,t,F_GFM)-(z_1-ε)‖²。双条件策略：冻结 MoGe2 的全局特征 F_GFM 经 cross-attention 注入各 DiT block；可见几何转 TUDF 后经冻结 VAE 编码为 z_vis，以零初始化 MLP 加性融合 z̃_t=z_t+MLP_zero(z_vis)。训练用 3D-FRONT 18k 场景构 96k 图像-TUDF 对 + ScanNet++ 46k 样本，2 阶段共约 5.5 天（2×A6000/L40S）；推理 50 步 Euler ODE、CFG scale 3.0、条件 drop 概率 0.1。

## 实验与结果
基准：SCRREAM 460 样本与 NRGB-D 137 样本（9 场景，按 amodal-enrichment ratio ≥0.2 过滤）；指标 CD/APD_γ/FS_γ/FPD（×10²，评测前以 7-DoF Sim(3) 对齐，协议与 NOVA3R 一致）。SCRREAM 完整场景：VolFill CD 3.03、FS_0.1 95.03、FS_0.02 54.83，对比 LaRI 5.19/85.43/30.85、NOVA3R 3.43/95.26/45.12、MoGe2 5.74/83.96/45.84；遮挡区 CD 3.46 优于 LaRI 5.23 与 NOVA3R 3.56。NRGB-D：完整 CD 6.44、FS_0.05 63.92 vs LaRI 9.79/43.47、NOVA3R 8.19/49.92。度量几何（Table 3）：CD 3.88、FS_0.02 44.90、FPD 4.86 vs NOVA3R 6.56/22.23/16.50。消融：dual conditioning（MoGe2+Add）CD 3.03/FS 54.83 > 仅 MoGe2 3.81/46.80 > 仅 DINOv2 5.46/35.98；VAE hybrid decoder L1 0.43、0.07 s、1.7 GB，优于 dense-only 0.49/0.63 s/9.2 GB；5 个随机种子下 complete CD 3.11±0.08、FS_0.02 54.2±0.5。

## 局限与风险
正文 §5 设独立 Limitations：重遮挡区域偶尔残留小孔；可见面因联合生成而略钝于 MoGe2（可用 training-free visible reinstatement 或显式 3D 监督缓解）；训练与评测仅限室内场景，域外 KITTI 街景与 Sintel 合成帧失败（图 12）；网格固定 256³，512³/1024³ 需重训 VAE 与 DiT；迭代采样 1.4 s/图慢于单次前馈回归；附录 A.5 另指出大场景体素尺寸增大但评测范围内精度未降。

## 与文献库的关系
属库内 amodal/完整场景重建线（LaRI/NOVA3R/MoGe2 一脉）：首次将体素流匹配生成框架用于场景级 amodal 重建，TUDF 结构化表征支持阈值直接提点云与经 MeshUDF 抽网格；混合稀疏-稠密 3D VAE 实现 16× 空间压缩（occupancy 引导 dense-to-sparse 解码，1.7 GB vs dense-only 9.2 GB），几何基础模型双条件（全局 MoGe2 token+可见几何 latent inpainting，加性零初始化融合优于拼接），无符号 TUDF 规避室内非水密几何歧义。

## 可复现性（代码/数据/硬件）
项目页 ngoductuanlhp.github.io/VolFill；推理代码与预训练权重已公开，训练/评测/数据处理代码及处理后的 TUDF 数据与 split 文件声明将发布（NeurIPS checklist 第 5 题答 No）；硬件：训练 2×RTX A6000 或 2×L40S（48 GB），本地工作站 RTX 4090 + Core i9 + 64 GB RAM；总计算约 1,680 GPU 小时；依赖开源 MoGe2 与公开 3D-FRONT、ScanNet++。
