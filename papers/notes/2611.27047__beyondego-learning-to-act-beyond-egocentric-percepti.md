# BeyondEgo：通过人形机器人 Ego-Exo 预见学习超越自我中心感知的动作

## 一句话结论
把双视角未来 DINOv3 特征仅作训练期 privileged 监督、经 adapter 固化进观测接口，部署时预测模块可整体移除：分布内 92.0%（基线 48.0%）、200 个 held-out 场景 65.0%（23.5%）。

## 要解决的问题
人形 loco-manipulation 需协调全身运动完成操作，但自我中心 VLA 策略难以获得身体-场景空间关系线索（手臂或搬运物遮挡、看不到脚下与侧向），且仅靠动作模仿缺乏对未来场景演化的显式监督。现成 ego-exo 数据集是人的离线数据，机器人多视角基准又只针对桌面操作。

## 方法详解
空间上引入同步 exocentric 视角，用冻结 DINOv3 编码后与自我中心 VLM token 拼接，直接送入 action expert（而非塞进 VLM）。时间上把双视角 0.6 s 后的观测作为 privileged supervision：foresight expert 回归双视角冻结 DINOv3 特征，梯度经 zero-initialized 残差 adapter（4.2M 参数）回传，action expert 仍用 flow matching 训练。部署时删除 foresight expert，只保留 adapter。另建 HELM 闭环人形 loco-manipulation 基准（5 个全身任务、ego-exo 同步视角、5 类分布偏移）。

## 实验与结果
- 分布内成功率 = 92.0%（Ψ0 基线 48.0%，VLM fusion 74.0%，Feature fusion 84.0%）
- 200 个 held-out 场景成功率 = 65.0%（Ψ0 23.5%，VLM fusion 49.5%，Feature fusion 55.0%）
- 分布内提升 = +44.0 百分点（相对 Ψ0）；泛化提升 = +10.0 百分点（相对 Feature fusion）
- foresight 离线余弦相似度 = 0.963（ego）/ 0.984（exo），对 0.6 s 后的 DINOv3 特征
- T1 三个训练种子 15 次评测 = 78.2% ± 1.0%（全部落在 75.0–82.5%）
- 外置相机居中放置泛化成功率 = 77.5%（右侧 72.5%，左侧 60.0%）

## 创新点与贡献
- 把双视角未来 DINOv3 特征仅作训练期 privileged 监督，经 adapter 固化进动作专家所读的观测接口，部署时可完全移除预测模块
- 同时给出首个带 ego-exo 同步视角的闭环人形 loco-manipulation 基准

## 局限与风险
- 作者自述需外置相机覆盖与同步双视角，大范围移动会限制外置视角、双视角示教采集成本高
- 实验限于一个机器人（Unitree G1）与五个仿真任务
