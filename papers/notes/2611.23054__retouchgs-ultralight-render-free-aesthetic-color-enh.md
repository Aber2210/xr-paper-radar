# ReTouchGS：面向 3D 高斯泼溅的超轻量免渲染美学调色与迁移

## 一句话结论
免渲染的 3DGS 美学调色：解析一阶更新 + 44.7K 参数残差网络，ΔE76 5.50 优于 BilaRF 6.30，耗时 23 s 对 123 s。

## 要解决的问题
现有 3DGS 颜色迁移与交互编辑都由参考图或用户显式指定的色彩调整驱动，但很多创作场景只想要“自动变得更好看”且跨视角色彩一致。把 2D 图像自适应增强逐视图套用会产生视角间不一致；把非线性颜色变换直接作用到每个 Gaussian 又与 alpha 混合不可交换，导致像素颜色与目标不符；基于渲染的逐场景优化（BilaRF、SAAD）即使只调颜色也要反复渲染，代价高昂。这一“无参考的美学增强”任务此前无人处理，也缺少带场景一致目标的三维评测基准。

## 方法详解
整体把“决定场景颜色”与“在 Gaussian 参数上实现该决定”解耦：输入已训练 3DGS 资产与相机参数，先得到一个场景级颜色算子 T（默认 17³ grid LUT，Θ 存相对 identity 的位移，三线性插值 + 截断），再把它烘焙进 SH 颜色，输出仍是标准 3DGS 资产，几何与 opacity 完全不动。参考无关增强网络 E_φ 把 Gaussian 中心投影到粗图像网格，编码视图相关 SH 颜色、opacity、相对尺度并按 opacity 与深度加权池化，CNN encoder 汇总空间特征，RGB 与 luma 分位数描述色彩/色调分布，逐视角融合后 mean pool 成单一场景描述符；由于专家 LUT 高度相关，对训练 LUT 做 PCA，网络只回归标准化系数再按 μ+B(σ⊙z) 重建 LUT。参考引导迁移则渲染一次参考视角原图，用带 identity-centered ridge 惩罚的拟合求 grid LUT（14,739 个值），使单一编辑视角可定义场景级映射。为实现免渲染更新，先用 blended color context m_i（在粗投影网格上按 opacity/soft depth 池化 SH 颜色再聚合到该 Gaussian 投影处）对 T 做一阶展开，权重 a_i=exp(-||c_i-m_i||²/δ²) 在“context 处展开”与“自身颜色处展开”间过渡，同时用局部 Jacobian 变换高阶 SH 系数使视图相关变化跟随同一调整。残余的算子曲率与混合偏差由 44.7K 参数的 blend-aware 网络修正：在 3D 最近邻图上做两层 residual propagation，输入三类算子残差（direct、context、Jacobian）与 blending discrepancy b_T(a,b)=T((a+b)/2)-(T(a)+T(b))/2（节点用 b_T(u_i,m_i)，边用 b_T(u_i,u_j)），预测三通道共享的标量传播系数，输出 DC 修正 d_θ,i；identity 算子下所有残差为 0，构造上保持原色。训练分三段：美学网络 20K 步；refinement 先用渲染式 color solver 蒸馏 DC 目标 16K 步，再用渲染微调 12K 步并以 λ_corr 把学习修正拉回解析初值。基准 ReTouch3D 用 NamedCurves(MIT5K-DPE) 在重建视角生成增强图后联合拟合单一场景级 LUT 作为一致目标，28 个 DL3DV + 9 个 Mip-NeRF 360 场景，主指标为每场景 16 个 off-trajectory 视角的 ΔE76。

## 实验与结果
- 美学增强（37 场景平均）：ΔE76 5.50 vs BilaRF 6.30、SAAD 6.18、ReparamGS 11.65
- PSNR 28.08 vs 27.05
- LPIPS 0.0561
- 耗时 22.97 s vs BilaRF 122.54 s、SAAD 3,461.78 s
- 网络参数 180.2K vs 0.99M 以上
- 参考引导迁移：ΔE76 4.03 vs BilaRF 5.73、SAAD 15.46、ReparamGS 11.44
- PSNR 29.49 vs 27.87
- 19.32 s，网络仅 44.72K 参数
- 换用 VeraRetouch 目标（refinement 权重冻结、只重训美学网络或重拟合 LUT）：增强 ΔE76 5.13 vs BilaRF 6.03，迁移 3.08 vs 4.52，PSNR/SSIM 亦最优
- 视角泛化：参考视角 3.81 ΔE76、held-out 视角 3.85（37 场景平均），off-trajectory 差距很小
- 消融（增强/迁移 ΔE76）：去 blended context 与 refinement 6.417/5.299 → 去 refinement 5.911/4.649 → 去 residual propagation 5.594/4.189 → 去 blending discrepancy 5.563/4.147 → 完整 5.502/4.035
- 交付时间（含资产加载、编辑、导出）：DL3DV 5.6 s、Mip-NeRF 360 32.8 s（中位，RTX 5090）

## 创新点与贡献
- 首个面向已训练 3DGS 资产的 reference-free 美学色彩增强框架，并同时支持参考引导迁移，两者共享同一 LUT 表征与同一免渲染更新阶段
- 关键洞见是把非线性算子与 alpha 混合的不可交换性显式建模为 blending discrepancy 特征，再配合解析一阶更新 + 极轻量残差传播，使网络只需 44.7K 参数即可完成原本需要逐场景渲染优化的任务
- 同时贡献 ReTouch3D：用联合拟合的场景级 LUT 生成视角一致目标，并首次在 off-trajectory 视角上评颜色保真与跨视角泛化

## 局限与风险
- 只支持场景级全局颜色映射，无法做局部/逐物体或空间变化的编辑（正文把算子定义为跨视角共享的单一 LUT）
- 几何与 opacity 固定，不处理光照、材质或几何改动，属于纯后处理式调色
- 输入视角几乎未覆盖的 Gaussian 误差明显偏高：Table 13 中未观测区域 ΔE76 为 6.30（DL3DV 增强）与 4.62（Mip-NeRF 迁移），高于整体 5.50/4.03
- 参考迁移只用单个 edited view 拟合，颜色覆盖不足处依赖 ridge 锚回 identity，可能压制合理的大幅调整
