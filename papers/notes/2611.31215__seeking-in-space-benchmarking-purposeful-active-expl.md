# 在空间中寻找：评测视觉语言模型面向空间推理的目的性主动探索

## 一句话结论
把「证据获取」从评测中显式分离：固定同一模型为 reasoner、只替换观测来源（自身策略 / 同预算随机游走 / oracle 路径）：994 问题 / 234 episode / 72 真实扫描场景 / 23 个 VLM，Claude Opus 5.5 主动 74.0% 对 Blind 44.1%、Passive-40 76.4%。

## 要解决的问题
人类在陌生空间中有目的地探索，直到收集到空间问题所需的证据；而现有 VLM 空间推理 benchmark 的观测在查询前就已被标注者或走过场景的人固定好，只测「给定证据后如何推理」，不测「证据如何获得」。因此失败无法归因于是没找到证据还是误用证据，成功也不能说明模型能否自己找到证据。VLM 正被用作具身智能体与可穿戴助手的推理核心，此时无人预先挑选信息量大的视角，模型必须自己决定看哪里、何时看够。

## 方法详解
提出 ActSpace-Bench：场景表示为视图图 $\mathcal{G}=(\mathcal{V},\mathcal{E})$，节点是真实采集帧，边是运动动作集合 $\mathcal{A}$。episode 从节点 $v_0$ 与问题 $Q$ 开始，每步策略 $a_t=\pi(Q,o_{0:t})$，$a_t\in\mathcal{A}\cup\{\texttt{answer}\}$，最多 $B=40$ 步；观测 $o_i$ 为帧加相对 $v_0$ 的位姿，上下文保留起始帧与最近 8 帧、完整动作/位姿文本历史。答案 $Y^\star$ 来自对齐 3D 标注，每题都构造成起始视图看不到全部相关物体、但 $B$ 步内存在路径可见。为区分「找证据」与「推理」，固定同一模型为 reasoner，把其自身策略 $\pi_M$ 与同预算随机游走 $\pi_{rw}$、观察全部必需物体的最短 oracle 路径 $\pi_{or}$ 比较，定义 $\Delta_{RW}=S(\pi_M)-S(\pi_{rw})$、$\Delta_O=S(\pi_{or})-S(\pi_M)$。任务分类沿两轴：Metric（T1 绝对距离、T2 相对距离）与 Directional（T3 视角采择、T4 起始相对方向、T5 多跳），并加入同一次探索后的多问题、逻辑关联问题与「证据被移除」的不可答问题。构建管线：ARKitScenes + ScanNet++ 的 RGB-D/位姿/网格/物体标注；校验位姿后取清晰关键帧建视图图并保留最大强连通分量；对每个物体-关键帧做投影与网格/传感器深度遮挡测试，标 visible/partial/invisible；采样物体簇不能单视图看全的 episode；问题由模板改写并经文本分类器剪枝至纯文本不可高于随机；三名专家标注员复核。评分 $S=(1-u)\mathrm{AR}\cdot\mathrm{Sel}+u\mathrm{Rej}$，把「答率 × 选择性正确率」与「正确拒答率」分开。

## 实验与结果
- 994 个问题、234 个探索 episode、72 个真实扫描室内场景；23 个 VLM；步预算 B=40；超过 95% 抽样问题经人工确认为正确
- 人类在 oracle 视图上参考分 82.5%，AR 98.4%，Rej 83.9%
- Claude Opus 5.5：主动 74.0% vs Blind 44.1%、Passive-40 76.4%、RW-40 70.1%、O-Route 85.6%；Δ_RW +3.9、Δ_O 11.6
- GPT-6.1 Sol：主动 68.7% vs RW-40 61.8%、O-Route 89.7%；Δ_RW +6.9、Δ_O 21.0
- GPT-6.1 Terra：主动 55.1% 低于同预算随机游走 61.4%（Δ_RW −6.3），尽管其被动视图 76.9%
- 匹配记忆窗口后（RW-8）：Opus Δ_RW 由 +3.9 升至 +12.3，Sol 由 +6.9 升至 +25.6，Terra 由 −6.3 转为 +17.3
- 17 个开源/专用模型中 12 个显著低于同长度随机游走，最多低 43 个百分点
- Opus 在 37.4% 的 episode 中明知物体未见过仍作答，拒答率 0；23 个模型中 20 个距离预测中位数低于真值

## 创新点与贡献
- 把「证据获取」从评测中显式分离出来：固定同一模型为 reasoner，只替换其观测来源（自身策略 / 同预算随机游走 / oracle 路径），从而把主动探索能力量化为 Δ_RW 与 Δ_O
- 构造上保证每题起点视图不足、且存在预算内可达的证据路径，并用遮挡感知的可见性标注与 3D 标注生成答案，避免 2D 标注歧义
- 加入 masked-evidence 不可答题与逻辑关联题，使「知道自己没看到」与「答案自洽」可被单独度量

## 局限与风险
- 从正文看：场景均为静态室内扫描，无动态人物、光照剧变或户外
- 运动被离散为视图图上的跳转，不建模连续控制、碰撞与真实运动代价
- 步预算固定 40，长程探索与多楼层未覆盖
- 专有模型仅各家族少量版本，结论对模型版本敏感
- 部分设置因截断/上下文溢出被排除排名（>15% 截断），且总分会奖励「明知没看到仍猜」的策略，作者只能另报 Rej 缓解
- 作者未单列 Limitations 章节，上述为正文与附录可见的边界
