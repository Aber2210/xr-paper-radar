# UltraTex：对齐物理知识的高保真 PBR 纹理生成

## 一句话结论
把 VLM 中间层材质 token 与受控光渲染表征对齐引入 PBR 生成，补上 metallic-roughness 的语义与物理监督，FID 144.3 且专家评分优于五家商用产品。

## 要解决的问题
从单张参考图为 3D 网格生成 PBR 纹理本质上是病态的：观察到的外观把材质身份、表面反射率、几何与光照纠缠在一起，同一处高亮可能来自抛光金属、清漆电介质、被烘焙进去的光照，或只是局部的颜色图案。这种歧义在 metallic–roughness（MR）估计上最严重，因为目标是抽象的内在参数而不是自然 RGB 图像。早期的 inverse rendering 靠同轴闪光等受控采集暴露高光线索，在受限环境下有效，却无法泛化到任意 in-the-wild 图像。近来的生成式方法借助扩散与多视图先验合成纹理再反投影到网格，显著改善了 albedo，但对 MR 仍不可靠：常把 metallic 赋给错误区域，或产出过度保守、缺少细尺度变化的 roughness。作者据此判断，仅靠外观先验不够，模型还必须理解每个部件由什么材料构成、该材料应如何响应光照。

## 方法详解
UltraTex 是级联式两阶段多视图扩散流水线，输入一张参考图与一个网格，输出跨视图一致的 PBR 贴图，两个阶段各自训练，均以图像扩散骨干为底座，MR 被表示为单张 RGB 图像的两个通道（沿用 Hunyuan3D 的做法）。Stage 1 联合预测正交视图的 albedo 与世界空间 shading normal：每个视图先用 MM-T（Multi-Modal DiT）融合条件 token 与含噪视图 latent，几何法线经冻结 VAE 编码为 T_geo，参考图取 VAE latent 与 DINOv2 特征拼接为 T_img，做视图内自注意力；再由 MV-T（Multi-View DiT）丢弃全部条件 token、只保留 N 个视图的 latent 拼成 NL×C 序列做全局自注意力，以 flow matching 目标 L_alb 训练。关键设计是复用几何法线通路预测世界空间 shading normal：它不依赖 UV 参数化，避免旋转或翻转 UV 岛造成的不一致切线框架与接缝；实现上以几何法线 latent 作为起点学习残差微几何，L_normal 监督 T_geo 与 T_sn 之差，总目标为 L_joint = L_alb + λ_normal·L_normal。Stage 2 沿用同一 MM-T/MV-T 结构，但把几何法线条件换成 Stage 1 生成的 albedo，并加入两个物理知识对齐模块。其一是 VLM 引导的内在材质 adapter：取冻结 Qwen3.5-4B 第 {8,16,24} 层的视觉 token 按通道拼接，经两层 MLP（12288→4096→3072，SiLU）投影为 1D intrinsic material token T_mat，在冻结图像扩散模型的去噪块里做 token-wise 拼接；该 adapter 单独训练，VLM 与扩散模型都冻结，只让 adapter 以 flow matching 重建 GT metallic/roughness。其二是光度表征对齐：把 GT 材质在与相机同位的受控点光源下渲染成辅助光度响应 x_pm，用冻结 DINOv2 提取目标表征 y，再用 MLP h_φ 把 MR 生成过程中的中间 transformer 特征投影后做 patch 级余弦相似度对齐（L_REPA），理由是直接把抽象 MR 图对齐自然图像编码器是 ill-posed 的。最终 L_total^MR = L_flow^MR + λ_R·L_REPA。数据为 Objaverse-XL 与 TexVerse 的 130K 物体，每物体在随机相机与环境图下渲染 32 张参考图，六个 1024² 正交视图提供 albedo/metallic/roughness、几何与 shading normal 以及光度图监督；每视图 768² 训练，两模型各用 32 张 A100 训练约 2 天。推理先生成六视图 albedo，再条件生成 MR，全部经超分模块升到 1536² 后映射为 4K UV 贴图，正交投影未覆盖区域用 LumiTex 的新视图合成模型 inpaint。

## 实验与结果
- 主表（152 个 held-out Objaverse-XL 物体，1024²）：FID 144.3，优于 TRELLIS.2 的 158.7 与 LumiTex 的 159.5
- CLIP-FID 12.92（LumiTex 14.98）、CMMD 1.081（TRELLIS.2 1.351）、CLIP-I 0.9510（LumiTex 0.9439）、LPIPS 0.1106（LumiTex 0.1286）
- MR 精度（MSE×10⁻³）：metallic 46.77，对照最优基线 Hunyuan3D-2.1 的 50.04
- roughness 16.57，对照 LumiTex 的 25.96，约降 36%
- 消融中 w/o joint 版本为 53.03 / 16.49，即去掉联合法线后 roughness 略优而 metallic 明显变差
- 环境重光照（152 物体 × 4 视图，采样环境图与 GT 渲染对比）：FID 111.2，LumiTex 144.4、TRELLIS.2 158.4
- LPIPS 0.0988 对 0.1110 / 0.1213
- 31 名职业 3D 建模师盲评（1–5 分）：总分 4.31，Seed3D 2.0 为 3.20、Meshy 6 为 3.13
- metallic 4.21 对 3.36，roughness 4.11 对 3.17，渲染 4.55 对 3.36
- 模块消融（MSE_M / MSE_R，×10⁻³）：去掉 VLM token 为 54.85 / 22.50，去掉光度对齐为 52.32 / 18.45，去掉视觉条件为 55.46 / 28.23，完整模型 46.77 / 16.57
- 编码器探针（同设置只训 adapter）：VLM 的 MSE_M 27.93 / MSE_R 15.79、LPIPS(ORM) 0.2065，明显优于 DINOv2 的 43.76 / 32.09 / 0.3592 与图像 VAE 的 58.04 / 34.01 / 0.4085
- 366 张 MR 视图上 RGB 预训练 VAE 重建为 PSNR 38.656、SSIM 0.9839、LPIPS 0.0051

## 创新点与贡献
- 把“物理知识”拆成两类可注入信号，而不是继续堆外观先验：语义侧用冻结 VLM 的中间层隐表征经 adapter 变成 1D 内在材质 token，为 MR 估计提供部件级材质锚点（注意力可视化显示 token 自身无空间坐标，却能在 DiT 内定位到金属饰件、扣具等区域）
- 训练目标侧则放弃对抽象 MR 图做表征对齐，改为先把 GT 材质在受控同轴光下渲染成光度响应，再让 MR 扩散的中间特征去对齐该渲染的 DINOv2 表征，使高光强度、镜面锐度与局部反射对比成为可学的物理线索，且不需要显式光照监督
- 另一处结构性改法是把世界空间 shading normal 与 albedo 联合估计，绕开切线空间法线对 UV 岛朝向的依赖，并把几何法线通路直接当作残差学习起点，从而在不增加通路的前提下补足高频表面结构
- 整体不是新骨干，而是对“材质语义条件 + 材质-光交互监督”这两处缺口的针对性设计

## 局限与风险
- 作者自陈两类失效：高度风格化的 UGC 资产把 metallic 当外观控制量（小丑头发与角色服装同时高 metallic 高 roughness），从外观反解本身无解，预测可能物理自洽却与作者意图不符
- 超出现有 PBR 参数化的效果无法表达，如透明挡风玻璃，以及宝石的透明、半透、焦散等，根源是训练数据只有 albedo/metallic/roughness 三个通道
- 从实验设计还能看出：MR 以 Stage 1 的 albedo 为条件，albedo 的烘焙光照或结构错误会直接传播到 MR
- 评价集中在 Objaverse-XL/TexVerse 一类合成或扫描资产，真实输入只有 Sketchfab 3 例与 DTC 2 例，不足以外推
- 用户研究仅 31 人且只覆盖商业方法对比
- 联合法线在 roughness MSE 上并未带来收益（16.57 对 16.49），说明该辅助任务主要利于 albedo 细节而非全部 MR 通道
- 正文未给出推理时延与显存，也未开源代码
