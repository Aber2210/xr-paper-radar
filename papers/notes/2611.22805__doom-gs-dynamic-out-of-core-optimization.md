# DOOM-GS：面向海量高斯泼溅的动态外存优化

## 一句话结论
时空块外存训练 + 4D Morton 重排 + 可学习 point splatting，DynamicMatrixCity 上较 Dynamic TideGS +9.2~13.9 dB、训练时间 −28~46%。

## 要解决的问题
3DGS 训练默认所有 primitives 常驻 GPU，城市级场景的 primitive 数量远超显存容量。现有 out-of-core 训练（CLM-GS、TideGS、A LoD of Gaussians）只处理静态场景，其两条隐含前提在动态场景失效：一是“空间邻近的 Gaussian 始终一起访问”，但动态 Gaussian 会移动且只在有限时间区间活跃，静态空间分组随时间丧失局部性；二是“单视图可见 primitive 能放进显存以便排序与 alpha 混合”，而大场景单视图可见量本身就可能超显存。因此需要一套面向时空 primitives 的外存训练与渲染机制，并缺少相应的大规模动态评测数据。

## 方法详解
沿用 GraphiXS 的显式时空高斯：每个组件含均值/协方差/opacity/SH，外加时间中心 g_i、时长 u_i 与 v/a/j/s 四阶运动系数，opacity 随时间按高斯衰减。SSD 上以 B=4096 定长 block 存储（59 个静态 + 14 个动态参数），CPU 作 cache，只把当前 batch 可见 block 载入 GPU。时空块剔除由 κ=sqrt(-2lnε) 得每个 Gaussian 的活跃半宽 δ_i、由最大位移 ρ_i 扩张包围球半径 R_k、并由 g_i 与 Δ_k 得块时间支撑 S_k，块仅当时间活跃且视锥可见时进入 working set K(C)。训练中在线维护块布局：cloning 按 3D 位置梯度与 opacity 的组合分数采样并沿用 3DGS-MCMC 分裂；relocation 把不活跃槽位（opacity<0.005，或 <0.01 且 2000 iter 无位置梯度）复用给新目标，带 Morton cell 与“一个中位块直径”局部性约束，每步最多迁移 5%；每 2000 iter 做一次 4D Morton repacking，长寿命 Gaussian 用空间 Morton、其余按时长分四类。相机调度用视锥占用体素的 Jaccard 相似度做全局贪心：每 pass 每相机只选一次，再取最少使用且时间最近的帧，以提升 block 复用并保持视角/时间多样性。渲染改用 sort-free 的 Gaussian Point Splatting 并给出可学习梯度估计：把期望颜色按 Gaussian i 之前/自身/之后三段拆分，推出 ∂L/∂sh=o_iT_ig 与 ∂L/∂o=T_ig(sh_i-c̄^b_i)，其中“i 之后的期望颜色” c̄^b_i 用 framebuffer 中第二近点的颜色 c_2(q) 做无偏估计。流式训练把 working set 切 chunk：前向逐 chunk 渲入每相机独立 framebuffer，反向重放同批采样点并与所有相机 framebuffer 对齐累加梯度，使峰值显存与单视图可见 Gaussian 数解耦。实验在 20M Gaussian、4 图 batch、1800 block（约 7.4M Gaussian）预算下训练，Corner/Block 40K iter、District 200K iter。

## 实验与结果
- DynamicMatrixCity 原生动态对比（同一 GraphiXS 表征、同一初始化）：PSNR Corner 24.93 vs Dynamic TideGS 15.60（+9.3 dB）、Block 23.19 vs 9.28（+13.9 dB）、District 19.35 vs 10.19（+9.2 dB）
- SSIM Block 由 0.344 升至 0.721、District 由 0.286 升至 0.658
- LPIPS Corner 由 0.570 降至 0.293
- GPU hit rate Block 78%→89%
- 训练时间相对 Dynamic TideGS 降低 46%（Corner）、31%（Block）、28%（District）
- District 峰值显存 20.5→12.6 GB，Block 18.9→16.8 GB
- 与逐帧静态基线（Corner/Block，120 帧各训 2.5M 模型，合计 300M）相比，单一 2.5M 动态模型在 Block 上 PSNR 高 1.3 dB（对最强逐帧基线）、高 3.5 dB（对 TideGS），Gaussian 数少 120 倍
- Corner 上 CLM-GS 的 PSNR 反而高 0.37 dB，但本文 SSIM/LPIPS 更优
- 时间一致性：flicker 相对最稳定基线降低 7.1 倍（Corner，2.79 vs 19.84）与 6.3 倍（Block，2.89 vs 18.24）
- 消融（20M）：去 space-time repacking 的 PSNR 变化 ≤0.28 dB，但 hit rate 降 31-38 点、训练时间增 1.7-6.7 倍
- 去局部性约束 relocation 的 hit rate 降 24-28 点
- 换随机 batch 调度 PSNR 降 0.95 dB（Corner）/0.37 dB（Block），时间增 2.1-7.7 倍

## 创新点与贡献
- 首个面向大规模动态场景的 out-of-core GS 训练框架，把外存范式的组织单位从“空间块”改为“时空块”，并配套 4D Morton 重排与保局部性的槽位复用
- 把原本只能前向的 Gaussian Point Splatting 扩成可学习模型，用第二近点 framebuffer 估计被遮挡背景色从而绕开深度排序，使单视图 primitive 数不再受显存约束
- 同时贡献 DynamicMatrixCity 城市级动态多视数据集，填补“大规模 + 动态 + 稠密多视”三者兼具的评测空缺

## 局限与风险
- 方法绑定显式运动表征（四阶多项式 + 有限时间支撑），无法直接支持 implicit deformation 类动态表示
- 完整模型必须常驻 SSD，作者明确指出极端规模下存储开销会显著上升
- 评测只在自行合成的 DynamicMatrixCity（MatrixCity 加程序化行人车辆）上进行，无真实采集
- 对比基线是把 GraphiXS 表征塞进 TideGS 的自行改造版本，并非原生动态外存方法，增益幅度存在被放大的风险
