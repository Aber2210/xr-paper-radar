# VLSplat：经场景图的视觉-语言引导物体中心 3D 高斯泼溅

## 一句话结论
VLSplat 把 codebook 式 3DGS 语义提升推进到类别感知的物体级：用场景图 + VLM 语言先验引导 intra-node refinement 与 inter-node acquisition。ScanNet++ 渲染级 thing mIoU 69.81/mAcc 70.31（Unified-Lift+Ours 64.42、LangSplatV2 39.94）；Replica thing mIoU 68.59；点级 ScanNetV2 全场景 mIoU 40.49，ROI 限制评估 61.89/mAcc 79.12；Replica 点级 mIoU 64.03、PRQ(T) 47.87。

## 要解决的问题
现有 2D-to-3D 语义提升依赖 SAM 掩膜监督，视图不一致与多层级预测会把同一物体拆碎或把异类区域合并，学到的表示由局部掩膜证据驱动而非整体物体结构，缺乏物体级先验。

## 方法详解
SAM3 按类别文本提示生成主要室内物体掩膜、SAM2 填补剩余区域，构成混合 2D 监督；Gaussian 特征与可训练 object-level codebook 按点积关联成组；以组为节点构建 ROI 场景图（各向异性协方差几何边 + 特征相似度 + VLM 生成描述 + CLIP 优化）。intra-node refinement 按特征置信度拆分可靠核与不确定集，inter-node acquisition 从邻近背景候选回收缺失部件；候选经合成物体视图上的可学习标量门 q_i 以 CLIP 相对提升为目标评估，随后只更新 Gaussian 特征方向、不改几何。

## 实验与结果
ScanNet++（10 场景）渲染级 thing mIoU 69.81、stuff 67.79；Replica（8 场景）thing 68.59、stuff 67.75。点级 ScanNetV2：全场景 mIoU 40.49 vs OpenGaussian 29.73（PanoGS 54.50 更高），ROI 评估 61.89/79.12、PRQ(T) 46.18；Replica 点级 64.03/74.34、PRQ(T) 47.87。消融：场景图加入特征相似度使 mIoU 40.49→58.51，再组合各向异性连接达 61.89；intra/inter 均单独有效（69.31→69.81 合并）。单卡 NVIDIA RTX 3090 24GB，每场景单次运行。

## 创新点与贡献
['首次把 codebook 分组从类别无关实例聚类扩展为类别感知的物体表示学习', '把场景图用作 3DGS 优化过程中的先验骨架，而非仅作输出抽象', '语言引导 Gaussian gating：以 gated 渲染相对 base 渲染的 CLIP 提升为目标', 'SAM3 类别提示 + SAM2 补全的混合 2D 监督，兼顾类别感知与密集覆盖']

## 局限与风险
['自述：依赖初始 lifting 形成合理粗分组，罕观测或罕检测物体难以建成可靠节点', '自述：对 SAM3、VLM、CLIP 等基础模型选择的敏感性未系统研究', '自述：评测聚焦室内 thing 类别；refinement 的离线优化成本随目标节点数增长', 'stuff 类提升小甚至略降，大面积布局区域未直接精化']

## 与文献库的关系
上游为语言嵌入 3DGS（LangSplat/LangSplatV2、OpenGaussian、Feature3DGS、LegGaussian）与 panoptic 方法 PanoGS；直接基线为 Unified-Lift（codebook 提升）与 OpenGaussian。场景图谱系中 Hydra/ConceptGraphs 等多把图当推理基底，本文首次将图结构作为优化器内部先验用于 Gaussian 精化。

## 可复现性（代码/数据/硬件）
代码与模型开源：vlsplat.github.io。评测 ScanNet++/Replica/ScanNetV2；单卡 RTX 3090 24GB；基于 Unified-Lift 15k 迭代结果再做 15k-30k 迭代图引导精化。

## 行动建议
做语义 SLAM 与机器人场景理解者可将物体级场景图 + CLIP 门控精化挂到自有 3DGS 管线；对罕观测物体需补 SAM3D 或视频扩散等更强先验，并评估对基础模型版本的敏感性。
