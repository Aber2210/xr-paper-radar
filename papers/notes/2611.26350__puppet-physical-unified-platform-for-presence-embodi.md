# PUPPET：面向临场感、具身化与遥操作的物理统一平台

## 一句话结论
把物理机器人实验室映射成持续同步的 VR 复制品并内置试次校验：30 人组内实验完成时间比 2D 快 27.7%，验证就绪率 +19.6 点。

## 要解决的问题
远程访问机器人硬件本身并不保证得到可用的实验数据：一次遥操作试次可以成功完成任务，却同时留下不完整或前后不一致的记录。现有远程实验室（Robotarium、CloudGripper）与数字孪生/VR 遥操作平台（TELESIM、IMMERTWIN、OpenVR、LeVR）主要按算法执行、基准测试、教学或示范采集来设计，评估维度集中在任务性能、界面可用性或控制质量，几乎没人把「访问方式是否影响所产出实验数据的质量与可复用性」当作研究问题。具体失效机制有三类：其一，传统 2D 遥操作只给分离的相机视图，用户必须自行在心智中重建工作空间的三维关系，空间不确定性直接转化为碰撞、绕行与反复试错；其二，以机器人为中心的虚拟界面会丢失环境上下文——作者以布料折叠示范为例，仅记录机械臂轨迹并不足以描述示范，布料构型、其在桌面上的位置以及操作的 spatial context 同样属于实验数据，物体、夹具、障碍等状态一旦缺失，数据便无法被理解或复用；其三，物理感知本身会掉数据，实测中物体状态缺失影响 10.3% 的现场试次与 6.7% 的 2D 试次，时间戳断档只出现在 2D（3.3%），动捕 marker 丢失造成 6.7% 的跟踪异常，而这些故障在 2D 界面上不可见、在 VR 中却能被用户即时看到。综上，既有平台缺少「具身访问 + 记录校验」一体化的设计，也没有把记录质量作为独立结果指标来度量。

## 方法详解
PUPPET 是网络-物理测试床：物理实验室经持续同步的 VR 复刻开放给远程用户，工作流内嵌试次校验。硬件侧为 Meta Quest 3 加带振动触觉与摇杆的控制器腕带（头显 6-DOF、双手追踪），位姿与按键流到服务器，服务器以 100 Hz 闭环渲染虚拟实验室并托管控制接口，命令经 WiFi 6 到 TIAGo（差速底盘 + 7-DOF 力矩臂，头部 RGB-D、关节编码器、板载 ROS）。独立于机器人自估位姿，OptiTrack 以 120 Hz、亚毫米精度跟踪，底盘与任务物体上的刚体 marker 提供 6-DOF 位姿，既做物理-虚拟对齐也直接当物体轨迹记录；NatNet ROS 驱动加 ROS-TCP connector 把位姿转为 Unity 变换实时摆放物体，物理到虚拟端到端均值 7.27 ms（中位 7.15 ms），VR 指令到运动反馈中位 30.6 ms。虚拟实验室（Unity 2022.6.3f1 + Meta VR SDK）手工复刻墙体、地面、桌、货架、TIAGo 与任务物体。交互为具身式：追踪手位姿直接驱动末端（运动规划施加关节限位），夹爪离散开合，头显朝向驱动机器人头（可看向一处而伸向另一处），摇杆驱动底盘。数据层每试次写一个 ROS bag（关节状态、指令速度、底盘里程计、夹爪、末端位姿、机器人与物体 OptiTrack 位姿、元数据、30 fps 多视角视频），采集在机器人侧运行、与访问方式解耦。校验把质量操作化为四维——完整性、时间连续性、信号合理性、执行一致性与完整性——落地为六族规则：R1a 记录完整性（缺元数据/文件/话题/遥测列/最小样本数则 Fail）、R1b 校验元数据缺失、R2 遥测连续性（必需流缺 >50%、末端位姿缺 >90%、时间戳间隔 >1 s）、R3 物体跟踪（成功试次路径 <0.02 m 或全轴位移 <0.005 m）、R4 机器人运动（各部件运动过小或关节 jerk >5×10^4）、R5 技师干预（超过两次轻微、T2–T3 重大干预或元数据不一致）、R6 跨试次一致性（完成时间、路径长度、夹爪抖动、jerk 波动超限），除 R1a 外均输出 Review。

## 实验与结果
- 30 名被试组内三条件（现场/2D/VR）重复三次：学习后完成时间 VR 68.66 s vs 2D 94.96 s，降低 27.7%（W=109.00, p=.011, r=−.531），与现场 72.10 s 统计不可区分（χ²(2)=6.10, p=.047）
- 验证就绪率 VR 85.6% vs 2D 66.0%（W=21.00, p=.012, r=.691）
- 三条件均无 Fail，所有被标记试次都落在 Review，即问题是部分缺失或不可信而非不可恢复
- 无技师干预试次 VR 89.7% vs 2D 67.2%（现场 93.1%），W=24.50, p=.007, r=−.680
- 故障画像：物体状态缺失 现场 10.3%、2D 6.7%、VR 0%
- 时间戳断档仅 2D 出现（3.3%）
- 近平面物体跟踪 6.9%/5.6%/6.7%（三条件相近，说明属物理传感属性而非访问方式）
- 用户体验：NASA-TLX 2.26 vs 2.81（W=73.00, p=.009, r=−.584）
- SUS 归一化 3.78 vs 2.43
- 任务信心 4.43 vs 3.50（W=31.50, p<.001, r=.806）
- VR 能动感（sense of agency）总体 4.31/5（SD 0.53, Mdn 4.33），显著高于中点 3（W=0.00, p<.001, r=1.00）
- 轨迹形状：T2–T3 对齐后横向峰值偏差 VR 0.713 m、2D 0.925 m、现场 1.028 m（χ²(2)=5.15, p=.076，未达显著）
- T2–T3 重复性在 RMS 距离、DTW 距离（均 p=.956）与路径长度差（p=.312）上 VR 与 2D 无差异
- 学习曲线：T1 时 VR 147.7 s、2D 181.2 s、现场 174.3 s
- T2→T3 VR 由 71.7 s 稳到 65.6 s，2D 仍在由 104.2 s 改进到 85.7 s

## 创新点与贡献
- 把「实验记录质量」提升为与任务性能并列的结果指标，并论证「任务成功 ≠ 实验成功」这一被忽视的分离现象。
- 提出面向遥操作机器人数据的四维质量模型（完整性/时间连续性/信号合理性/执行一致性与完整性）与六族可执行校验规则，含具体阈值（>50%、>90%、1 s、0.02 m、0.005 m、jerk 5×10^4）。
- 将机器人与环境物体在同一虚拟空间中连续同步，使虚拟实验室本身成为数据记录的在线校验器：物体冻结/消失在试次中即可被用户看见，直接消除 VR 组的物体状态缺失。
- 以受控组内设计隔离「访问方式」这一单一变量（同机器人、同任务、同 ROS 管线、平衡拉丁方六序），并区分学习试次 T1 与学习后 T2–T3。
- 同时报告任务效能、记录可靠性与主观体验三条互相独立的证据链，并用跨试次变异系数刻画示范数据的一致性。

## 局限与风险
- 作者自述：比较的是完整交互方式而非单个组件，2D 用键盘 + 摇杆、VR 用同步三维空间 + 具身臂控，故空间可视化与具身控制的贡献无法分离
- 只用一台机器人（TIAGo）、一个结构化桌到架任务、一个实验室，泛化性受限
- 虚拟实验室需手工建模且依赖外部动捕，只能部署在已装备的实验室，marker 丢失是 VR 数据问题的主因（6.7% 跟踪异常）
- 研究只证明同一装置内的可重复性，未证明跨实验室、跨平台、跨操作者的可复现性
- 从实验设计看：质量规则的阈值是人工设定、面向本用例，未经第三方标注或与下游策略学习性能的相关性验证，Review 判定带有主观性
- 85.6%/66.0% 的差距可能部分来自 VR 条件下用户被虚拟物体「提醒」而更谨慎，即存在行为混淆而非纯感知优势
- 2D 条件的低分也可能混入键盘控制的低效，使 VR 相对优势被高估
- 样本为 30 名 STEM 背景成人，缺新手/专家分层
- 未报告失败试次的排除比例对结论的敏感性
