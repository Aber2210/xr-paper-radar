# SplatLab：面向 3DGS 研究的自主科学发现

## 一句话结论
首个在活跃 CV 子领域端到端运行的自主研究系统：36 agent 六阶段管线，全部候选变自已验证复现的 splatify 插件，以真实 GPU PSNR 做 grounding-conditional Elo 排序；16 次运行全部超复现目标 +0.18~+3.78 dB，天文星云场景 +3.78 dB 为此前 3DGS 方法空白。

## 要解决的问题
复现一篇已发表 3DGS 论文需要数周专家工程；已有自主研究系统依赖未经外部验证的 LLM 重实现、模板短、不可执行、数字不可追溯（PaperBench 上最强 agent 对 ICML 2024 论文平均复现率仅 21.0%），且从未在活跃 CV 子领域完成端到端验证。

## 方法详解
六阶段管线 + 36 个 agent（Professor/PhD 协调/本科叶子三级层次，无固定 DAG）：Stage 1 Grounding 读文献生成 L-IDs 局限条目，并在已验证 splatify 插件上 profile 训练瓶颈生成 B-IDs；Stage 2 以七类 3DGS novelty taxonomy 做 grounded ideation，经 Precedent/Novelty/Saturation/Orthogonality 四项检查与 LLM-judge Elo 括号赛预排名（不训练）；Stage 3 在已验证匹配目标的 splatify 插件上按 9 个 EVOLVE-BLOCK 钩子生成结构化 diff 并通过 100 迭代 smoke test；Stage 4 cascade-weighted Elo 锦标赛（smoke/probe/multi-scene/full 四级权重 0.2/0.5/1.0，K=32，按 (B,L) 条件评分，八岛五算子变异，常驻 falsifier 每次失败扣 30 Elo，ReEvo 式 verbal gradients 回流）；Stage 5 六项完整性审计（provenance、faithfulness、novelty、compute match、cross-codebase port、claim check）；Stage 6 reviewer-driven 手稿合成，审稿面板可触发重新训练。

## 实验与结果
16 次运行、198 个实验分支：5 个验证正例、5 个带限定声明的边际结果、5 个非 PSNR 贡献、1 个记录失败。基准：Mip-NeRF 360（9 个无界场景）与 LLFF，每第 8 张留出测试，全部 30k 迭代、NVIDIA A6000；另自采 3 个 OOD 场景（nebula、bubble、diamond）。结果：每篇手稿比复现目标高 +0.18 ~ +3.78 dB PSNR，最大增益在天文星云场景（32.58→36.36 dB，SSIM 0.914→0.945，LPIPS 0.278→0.201，此前无 3DGS 方法涉足）；代表对比：FastGS 29.12→TileFocalGS 29.69；splatfacto@50s 20.53→View-Curriculum-GS 23.36；MSAA-3DGS 25.35→MSAA-Bilat 26.19；DWTGS 18.68→DWTGS-Patch 21.09。多种子：GNS-AA 26.18±0.05 vs GNS 25.95±0.07 dB（+0.23±0.09）。创意盲评（1-10）：SplatLab Stage-2 综合 5.8 vs 博士生 5.1、已接收预印本 6.0。手稿评分（0-100）：SplatLab 90 vs 人类 GT 93、PaperOrchestra 79、SingleAgent 38、AI Scientist-v2 32、GPT-5 ET 17。同行评审：多 agent 审稿 3.6 vs 人类 3.5；人类图形学审稿人给 SplatLab 3.5（边缘）vs 人类论文 4.1（明确接收），新颖性 3.5 vs 3.1。3 篇手稿被 CVPR 2026 workshop 接收（AttDis & Friends、NeedleSwap、AuditSplat）。成本：每次运行 24-48 小时、约 113M API token、1000-1500 次 LLM 调用、2-36 GPU 小时、$150-250。消融：去掉 claim-backed 审计则 16/16 手稿含无据数字（完整管线 0/16）；去掉 falsifier 则 5/16 冠军通不过 held-out 攻击；taxonomy 引导 +3.78 vs 无分类 +3.45 dB，token 消耗 47.5M vs 85.5M（+80%）。

## 创新点与贡献
1. 首个在活跃 CV 子领域端到端运行的自主研究系统，全部候选都变异自已验证复现的 splatify 插件
2. 以真实 GPU PSNR 做 grounding-conditional、cascade-weighted Elo 排序，取代 LLM 评审假说分数
3. 常驻 falsifier 与选择机制耦合（失败扣 Elo），把压力测试生存变为选择信号
4. claim-to-log 绑定与六项完整性审计，闭合既有管线遗留的幻觉/不可追溯失效模式

## 局限与风险
- 单次运行成本高（24-48 小时、约 113M token、$150-250 API 费用、2-36 GPU 小时）
- 已验证复现骨干的构建偏向预工程化、资源充足的子领域，小领域迁移需专家投入
- 人类专家评审仍认为其在 soundness 与 presentation 上不及顶会人类论文；存在论文洪水与评审负担风险（作者在 broader impacts 中自述）

## 与文献库的关系
在 AI Scientist、AI co-scientist、AlphaEvolve 等自主研究/程序搜索路线基础上，以已验证复现骨干、全环精炼与 claim-log 绑定补齐领域框架、验证基线、全环精炼、声明-测量绑定四大缺口；是首个同时满足全部五项能力轴的自主研究系统。

## 可复现性
系统、全部生成手稿、实验账本与跨运行论文库公开于 seemandhar.github.io/splatlab；复现骨干基于作者此前的 splatify/nerfify 与公开 gsplat 生态。

## 行动建议
3DGS 研究自动化探索的样板（系统/账本/手稿全公开）；claim-to-log 绑定与 falsifier 耦合设计可迁移到其他领域。边界：单次 24-48h/约 $150-250，soundness 仍不及人类顶会论文，存论文洪水风险。
