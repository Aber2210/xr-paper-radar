# EgoLink：第一人称语言-视觉交互网络知识挑战赛总结

## 一句话结论
ACM MM 2026 第一人称社会推理与工具交互挑战赛总结：4,030 题 / 1,055 段视频，Track 2 最佳 joint 0.844。

## 要解决的问题
现有第一人称基准多集中在前景物体与活动识别，无法检验模型能否解读情绪与社会线索、消解视觉指代，并把用户请求转成可验证的工具调用动作。作者指出两类反复出现的失败：社会性回答在语言上合理却缺乏视频/音频证据支撑；交互 agent 回复流畅但调错工具、使用未落地的实体，或在未验证前置条件前就改动数据库状态。两者都是 evidence–decision 耦合薄弱。

## 方法详解
EgoLink 作为 ACM MM 2026 挑战赛设两条互补赛道。Track 1（Social Reasoning in Egocentric Video）把 E³ 视频重构成统一 MCQ 协议，覆盖情绪感知与时间定位、社会因果推理、行为意图预测、第一人称语义摘要四类能力。其数据构建是多阶段流水线：从多模态片段生成题干与选项，模板引导生成 chain-of-thought 理由，再用 LLM-as-a-judge（Qwen3-235B-A22B）按答案一致性、干扰项质量、语言流畅度、推理逻辑、简化推理质量五个维度做五分制打分并据此过滤，最后做 Video-Contribution Filtering 剔除不看视频也能答对的题以抑制模态捷径。发布评测集为 4,030 道 MCQ 配 1,055 段 E³ 视频；规则要求参赛者用 EgoLink 标注替代原始 E³ 标签，Track 1 禁止任何外部视频数据用于训练、微调、蒸馏、校准或伪标签构建。Track 2（Interactive Agent Challenge）基于 EgoBench 的 user-agent-tool 沙箱，覆盖 retail、kitchen、restaurant、order 场景，agent 需在首视角视频流、用户指令、场景数据库与官方工具之间完成指代落地，并决定回答、请求澄清还是调用工具，数据库更新必须由视觉证据与工具观测支撑。Track 2 以 joint success 为主排序指标（同时通过工具调用过程评测与数据库结果评测才算成功），辅以 call 级 micro accuracy 及 result/tool 两个分项成功率来暴露过程与结果的错配。

## 实验与结果
- Track 1 官方榜（top-1 MCQ accuracy）：GXU-LIPE 0.9263、Lai 0.9246、TeleAI 0.9132、EgoMinds 0.9092、wjdd 与 MR-CAS 均为 0.9089
- 数据规模：Track 1 评测集 4,030 道 MCQ / 1,055 段第一人称视频
- Track 2 最终发布 309 个任务（retail6、retail10、kitchen4、restaurant5、order2），官方计分使用 96 个任务的公共子集（retail6/retail10/order2 各 20，kitchen4 与 restaurant5 各 18）
- Track 2 官方榜：MediaLab joint 0.844 / micro 0.916 / result 0.875 / tool 0.854
- GML-MM Group 0.823 / 0.914
- BigVisionAgentGoGoGo 0.781（result 0.896 但 tool 仅 0.802）
- uestc_goat 0.729
- EgoMinds 0.604
- MediaLab 消融：去掉 correction agent，Joint 由 0.844 降到 0.781
- 再去掉 scenario rules 进一步降到 0.646
- Lai 消融：process-aware reward 达 91.98%，完整 option-perturbed 设置验证集 92.75%、官方挑战赛 92.46%
- GXU-LIPE 报告验证集 92.89%、官方测试 92.63%

## 创新点与贡献
- 把“第一人称社会认知”与“闭环交互执行”放进同一个基准，用离线 MCQ 与状态改变式的工具交互两种协议共同检验感知-推理-决策是否仍然耦合，这是相对只测识别或只测规划的既有基准的实质差异
- Track 1 的构建把贡献度过滤（Video-Contribution Filtering）与五维 LLM 判分作为数据集质量门控，直接针对社会问答里“不看视频也能答对”的捷径问题
- 挑战赛总结还把过程正确性（tool-based）与最终状态正确性（result-based）分开报告，使“回复流畅但流程错”的失败模式显式可测

## 局限与风险
- 作者明确说明所总结的结果尚未建立对已发布场景之外的泛化性（原文 'generalization beyond the released scenarios is not established'）
- Track 2 的评测只覆盖已发布场景，未涉及未见场景、更长交互与可恢复的工具失败
- Track 1 的模态捷径风险未被实验排除，modality-dependence 测试、选项顺序扰动与时间证据评测都被列为未来工作
- 此外论文只分析了主办方提供的四份技术报告（Track 1 的 GXU-LIPE、Lai，Track 2 的 MediaLab、GML-MM Group），并非全部提交，结论代表性受限
