# OMG4：面向高效动态场景表示的优化最小 4D Gaussian Splatting

## 一句话结论
OMG4 用 SD-Score 采样、双阈值剪枝与可学习权重合并三级缩减高斯，再叠加时间条件隐式外观与分阶段 3D→4D SVQ，在 N3DV 上把 Real-Time4DGS 从 2087 MB 压到 3.59 MB（约 99%），PSNR 31.85 对 31.96、FPS 由 57 升到 129（2.26×）；同等质量下比 GIFStream 的 10.0 MB 少 65%，并可迁移到 FreeTimeGS（61.04→3.07 MB）与 STG（172→11.17 MB）。

## 要解决的问题
4D Gaussian Splatting 以百万级带时间属性的显式高斯基元换取高保真动态重建，Real-Time4DGS 在 N3DV 单场景即占 2 GB 级存储，直接阻碍移动端、流式与 VR/AR 部署。已有压缩工作各有缺口：4DGS-1K 用 lifespan 重要性剪枝后仍在 50 MB 量级；GIFStream 以特征流做运动感知剪枝，但只在自身表示上验证；Light4GS、ADC-GS 面向形变式动态高斯（context/anchor），4DGS-CC 是面向 4DGS 的熵编码框架，而 OMG 的 SVQ 只针对静态 3DGS。更关键的是，4D 高斯的冗余在静态区与动态区异质，时间属性又与空间几何、外观强耦合，一次性量化全部属性会破坏优化稳定性——正文指出的「先缩减、后量化」顺序问题此前未被系统处理，也缺少跨 RT-4DGS/STG/FreeTimeGS 的通用性验证。

## 方法详解
输入为预训练 4D 高斯集合 P={(x_i,f_i,a_i)}，x 为参考位置、f 为外观、a 含不透明度/尺度/旋转/时间参数，方法对三种时间参数化通用。①Sampling：SD^(i)=N_minmax(S_grad)·N_rank(T_grad)，S_grad=Σ_j||∇_{u_ij}L_j||_2 为全部图像上对投影坐标的梯度累积（静态区稀疏持久，微小扰动即影响多帧损失），T_grad=Σ_j∇_{μ_ti}L_j 为带符号时间梯度累积，符号频繁翻转者在归一化前相互抵消，充当一致性滤波；按 τ_GS 采样后优化 1000 次。②Pruning：P_GP={G_i | N(S)≥τ_S ∨ N(T)≥τ_T}，阈值取 p 分位数（中等模型 0.8），只剔双低象限。③Merging：4D 时空体划网格，仅同 cell 内聚类，S(G_i,G_j)=-(||x_i-x_j||²+λ||f_i-f_j||²)，按 τ_sim 成簇并去重为极大簇；代理 x̄_q=Σw_i^x x_i、f̄_q=Σw_i^f f_i，其余属性取自位置权重最大者（尺度/旋转/时间非线性，平均不稳定），重复 M 次并放大网格。属性压缩沿用 OMG 的 MLP 并对不透明度与颜色加时间条件；SVQ 保留 4D 均值全精度、只量化其余属性，先 3D 后 4D 分阶段（4000 步训 MLP、9000 步开 3D、10000 步开 4D，共 11000 步），末端 Huffman+LZMA。

## 实验与结果
- 数据集与硬件：N3DV（1352×1014）、SelfCap（6 场景、每段 60 帧，遵循 FreeTimeGS 协议）、ENeRF-Outdoor（1200 帧长序列），另有 N3DV 1024×768 补充设置；RTX 4090，11000 次迭代 45.17 min（Table 14）。
- N3DV 主结果（Table 1）：Ours–M 为 PSNR 31.85 / SSIM 0.941 / LPIPS 0.060 / FPS 129 / 170,044 高斯 / 3.59 MB；基线 Real-Time4DGS 为 31.96 / 0.946 / 0.051 / 57 / 3,397,510 / 2087 MB。
- 对比 GIFStream-L：存储 10.0 MB→3.59 MB（-65%）、PSNR 31.75→31.85；低码率档 Ours–T 31.54 dB / 2.18 MB 优于 4DGS-CC(4DGS)-S 的 30.97 dB / 2.30 MB；BD-rate 相对 GIFStream −71.65%、相对 4DGS-CC(Saro-GS) −83.79%。
- 跨表示：FreeTimeGS 61.04 MB→3.07 MB（Ours–M，PSNR 32.80→32.62）；SelfCap 122 MB→4.06 MB（Ours–T，PSNR 26.74 对 GIFStream-S 25.56 / 5.52 MB）；STG 172 MB→11.17 MB，比 CSTG 少 27% 内存。
- ENeRF-Outdoor：RT-4DGS 8,059 MB / 24.40 dB → Ours(RT4DGS) 11 MB / 24.30 dB；FTGS 488 MB / 25.04 dB → Ours(FTGS) 53.44 MB / 24.70 dB，且可单次跑完 1200 帧（GIFStream 需 20 个分块模型、共 17 h）。
- 消融：未缩减直接做属性压缩即 OOM；同时 3D/4D 量化 31.54 dB vs 分阶段 31.85 dB（+0.31）；采样与剪枝合并为一步掉 0.15 dB；动态分数改绝对梯度 31.65 dB（-0.20）；改用光流 27.19 dB（-4.56）；合并时额外学习协方差/时间权重分别降到 31.72 / 31.75 dB。

## 创新点与贡献
- 把 4DGS 压缩拆成「静态–动态显著性采样 → 双阈值剪枝 → 局部时空合并」的可微三级缩减，并以消融证明阶段不可合并（合并后 -0.15 dB）。
- 提出 SD-Score：屏幕空间梯度（静态）与带符号时间梯度（动态）经极值/秩归一化后相乘，带符号累积同时充当时间一致性滤波（优于绝对梯度 0.20 dB、优于光流 4.56 dB）。
- 把 SVQ 扩展到 4D 属性并提出 3D→4D 分阶段量化，论证量化可行性依赖前级高斯缩减（全量直接压缩 OOM），分阶段比同时量化高 0.31 dB。
- 同一流程可插到 Real-Time4DGS、STG、FreeTimeGS 三种时间参数化，均取得 27%–99% 存储下降。

## 局限与风险
- （我在正文发现）方法为 post-hoc 压缩，必须先有百万级高斯的预训练 4DGS 模型，正文未报告与压缩联合训练或从零优化的结果。
- （我在正文发现）ENeRF-Outdoor 上即便 Ours(FTGS) 仍有 1,999,800 高斯 / 53.44 MB（N=1,F=1200），压缩率远低于 N3DV 的 99%，长序列场景收益有限。
- （我在正文发现）SelfCap 上 PSNR 26.74 略低于 FTGS 的 26.96，LPIPS 0.254 明显差于 0.194（Ours–T），强非刚性运动下以保真度换存储。
- （我在正文发现）τ_GS、分位数 p、合并轮数 M、网格缩放均按数据集与模型档位分别设定，正文未给出跨数据集统一配置的敏感性分析。
- （我在正文发现）无主观/感知评测，也没有真实流式传输或端侧解码实验，「可实用」主要由存储与 FPS 推断。
- （我在正文发现）多数基线数字引自原论文（∗ 为复现），仅部分方法复现，跨论文比较口径不完全一致。

## 与文献库的关系
静态侧继承 OMG（Lee et al., 2025）的 SVQ 与隐式属性 MLP，并与 LightGaussian、LP-3DGS、HAC、Scaffold-GS 等剪枝/锚点/上下文方法对照；动态侧以 Real-Time4DGS（Yang et al., 2024）为主干，与 STG（Li et al., 2024）、FreeTimeGS（Wang et al., 2025）共享显式高斯基元抽象，故可跨表示复用。相对 4DGS-1K 的 lifespan 剪枝、GIFStream 的特征流剪枝、MEGA 的内存高效表示、Light4GS/ADC-GS 的 context-anchor、4DGS-CC 的熵编码，本文差异是把基元级缩减与属性级量化串成一条流水线，并强调缩减是量化前提。本篇为旧稿 v2 再公告（v1 未入馆），按首次入馆处理。
