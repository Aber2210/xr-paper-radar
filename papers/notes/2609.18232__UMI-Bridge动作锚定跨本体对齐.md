# UMI-Bridge：用"动作等价"而非"像素相似"对齐人机表征

## 一句话结论

以手持式 **UMI（Universal Manipulation Interface）** 作为**中间域**，把人类操作数据（第一人称视频 + UMI 演示）与机器人数据按**动作等价**而非像素相似对齐：先用 UMI 动作监督把潜表征锚定到末端运动与夹爪行为，再冻结其 wrist teacher 与动力学模型去正则化 VLA 后训练。**3 个真机任务平均成功率 91.7%（Naive Co-training 73.3%）**；在仅用 **25% 机器人演示**时即达到 77.5%，**超过全量数据的 Robot-only 基线（62.5%）15 个百分点**。

## 要解决的问题

VLA 模型依赖"视觉观测 + 任务指令 → 可执行动作"的配对演示，而获取机器人演示需要机器人与操作员投入，构成新任务的数据瓶颈。

替代思路是用**无需机器人的人类操作数据**（第一人称视频、手持 UMI 演示）。但三类差异构成障碍：

| 差异 | 后果 |
|---|---|
| 视角（viewpoint） | 人手视角 vs 机器人头/腕视角 |
| 本体（embodiment） | 人手 vs 夹爪 |
| 动作监督可用性 | 人类视频无动作标注，UMI 有 |

**核心挑战**：应该让这些域共享什么信息？——**同一个操作动作，由人手或夹爪执行、从不同的视角观察，会产生完全不同的视觉变化**。按像素相似对齐必然失败。

## 方法详解

### 总体：两阶段

- **Stage 1**：在**仅 Ego + UMI 数据**（无机器人演示）上训练双视角潜动作模型（LAM）
- **Stage 2**：冻结 LAM 的 wrist latents 与前向动力学模型，用它**正则化 VLA 在 UMI + 机器人数据上的后训练**

关键设计：**共享的 wrist 接口**使训练时监督可跨域进行，同时**保持策略的标准推理架构不变**（推理时不增加额外分支）。

### Stage 1：动作锚定的潜空间对齐

**在冻结的 DINOv2 特征空间而非像素空间**中放置 IDM/FDM（继承 latent action model 的逆/前向动力学脉络）。

- **逆动力学模型（IDM）**：视角无关，读取相邻特征

```
z_t^v = Q_φ(f_t^v, f_{t+Δ}^v),   v ∈ {E, UH, UW}
```

其中 E = Ego，UH = UMI head，UW = UMI wrist。

- **前向动力学模型（FDM）**：从潜变量 + 视角嵌入 `e_v` 预测未来特征残差

```
Δf̂_t^v = F_ω(f_t^v, z_t^v, e_v),   Δf_t^v = f_{t+Δ}^v − f_t^v
```

**三个刻意的设计选择**：
1. IDM **不使用 VQ codebook、不做语言条件化**
2. 腕部图像**保留其鱼眼投影**，不引入可训练的视觉适配器
3. Stage 2 中**冻结 LAM 与视觉编码器**，固定 teacher 映射

**三类损失**
| 损失 | 作用 |
|---|---|
| `L_dyn` | 特征空间动力学（残差损失 `ℓ_f(a,b) = ‖a−b‖₁ + β(1−cos(a,b))`，β=0.2） |
| `L_U` | **UMI 动作回归**——把表征锚定到末端运动与夹爪行为 |
| `L_EH` / `L_HW` | 配对 Ego-UMI head 片段上的潜交换、同步 UMI head-wrist 片段上的对齐 |

### Stage 2：潜空间正则化的 VLA 后训练

- arm queries 对高层 VLM 特征做注意力，预测 `ẑ`
- 由**冻结的 wrist teacher** 通过 `L_align` 监督
- 由**冻结的 FDM** 通过 `L_policy-dyn` 监督
- `L_R` 在 UMI 与机器人数据上监督标准动作专家
- 虚线框内的分支**仅训练时存在**，推理架构不变

## 实验与结果

**平台**：Tianji Marvin 半人形双臂机器人，两条 7-DoF 手臂，各装与 UMI 数据采集时**相同的 3D 打印 UMI 夹爪**；3 个 RGB 相机（1 个头戴 + 2 个腕部），224×224。每个任务-策略组合评估 **20 次 rollout**，所有方法共享任务特定的二值成功判据。

### Q1：LAM 正则化是否有效？

| 方法 | 3 个真机任务平均成功率 |
|---|---:|
| Naive Co-training（匹配的 UMI + 机器人数据） | 73.3% |
| **UMI-Bridge** | **91.7%** |

**Stage 1 消融的关键发现**：
- 移除 `L_U`（保留两个对齐损失）→ 腕部 RMSE 升至 **0.224 / 0.280**，HW R@5 从 **0.180 掉到 0.039**
- **结论：视觉可预测性本身不能保证动作锚定（action grounding）**。动作监督同时改善动作解码与 head-wrist 对应。

### Q2：能减少多少机器人演示？（数据效率）

| 机器人数据预算 | Ours | Robot-only | 增益 |
|---|---:|---:|---:|
| 25% | **77.5%** | 35.0% | **+42.5 点** |
| 50% | **80.0%** | 47.5% | **+32.5 点** |
| 100% | **95.0%** | 62.5% | **+32.5 点** |

**最关键的一行**：仅用 **25% 机器人演示 + UMI 数据**即达 77.5%，**超过用全量数据的 Robot-only（62.5%）15 个百分点**。

分任务同样成立：Stain Wiping **65% vs 60%**；Produce Sorting **90% vs 65%**。

定性观察（Produce Sorting，倾斜物体摆放）：**Ours 在抬起过程中保住蔬菜并完成两次放置；全量数据的 Robot-only 反复尝试抓取但两个物体都留在桌上。**

### Q3：能否做 UMI→机器人的任务迁移？

在**没有目标任务的机器人演示**的条件下：

| 任务 | 成功率 |
|---|---:|
| Cup Placement on Coaster | **85%** |
| 另一迁移任务 | **90%** |

## 创新点与贡献

1. **按"动作等价"而非"像素相似"对齐**：这是本文的范式主张，也是解决跨本体/跨视角问题的正确抽象层级。
2. **UMI 作为中间域的选择**：UMI 同时具备人类可采集性与动作标注，天然是人与机器人之间的桥梁。
3. **不牺牲推理架构**：额外的监督分支只在训练时存在，部署无成本——这是工程上很干净的设计。
4. **数据效率的数量级证据**：25% 数据超全量基线，是本文最硬的量化结果。

## 局限与风险

- 8 页短文，细节展开有限（如 UMI 数据规模、Ego 数据来源未充分说明）。
- 真机实验在**单一机器人平台**（Tianji Marvin）上完成，且夹爪与 UMI 采集时**相同**——这削弱了"跨本体"主张的强度：真正的跨本体应包含不同夹爪形态。
- UMI-Bridge 依赖能拿到 UMI 数据；纯第一人称视频（无动作标注）场景的上界未单独给出。
- 任务集较小（3 + 2 + 2 个任务）。

## 行动建议

1. **机器人 / 遥操作团队**：若已在用 UMI 采集数据，本文的两阶段方案可直接套用，且**推理架构零改动**——这是低风险高回报的改进。
2. **XR 视角的独特价值**：本文证明"第一人称人类视频 + 轻量动作锚定"可大幅替代机器人演示。对 XR 而言，这意味着**头显采集的日常第一人称数据**具备成为机器人训练数据的潜力——关键是要有一个"动作锚定"的中间域。
3. **最值得跟进的空白**：跨夹爪形态的泛化。本文的夹爪与 UMI 采集时相同，若换成不同形态夹爪，"动作等价"如何定义是真正的开放问题。
