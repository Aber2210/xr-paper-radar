# SceneDesigner++：面向 T2I 与 T2V 生成的统一 9 自由度位姿控制框架

## 一句话结论
把 9-DoF 位姿条件拆成绝对（CNOCS 图序列注入）+ 相对（VPRoPE 把帧间位姿写进 RoPE）两路，统一 T2I 与 T2V 的朝向可控性——T2I Rot.Err 0.24（3D BBox 1.10），T2V US_mot 8.1（去相对编码 6.2），新增 16,561 图 / 31,540 视频，40 人主观评测。

## 要解决的问题
现有位姿可控生成方法要么只做 text-to-image（T2I）要么只做 text-to-video（T2V），在朝向可控性与时序一致性上均有缺口：2D/3D BBox 条件无法编码物体朝向，隐式位姿嵌入（IPE）缺乏空间感知。以同骨干对比为例，T2I 上 3D BBox 的 Rot.Err 为 1.10、IPE 为 0.58，而目标是同时把位置、尺寸、朝向压到更低。T2V 侧把 CNOCS map 逐帧直接喂入虽能定位，却会产生僵硬、刚体式的运动，w/o Rel. 设置的用户运动连贯性评分仅 6.2。核心矛盾是：帧级空间定位与帧间运动建模未被解耦，且缺少带 9D 位姿标注的视频监督。

## 方法详解
以 Wan-T2V-1.3B 为冻结骨干，将 9D 位姿 $\mathcal{P}=(\mathbf{l},\mathbf{s},\mathbf{r})$ 的时序序列作为条件。绝对位姿编码把 CNOCS map 序列经 MLP $\Phi^{\text{cnocs}}_{\theta}$ 投影后与噪声潜变量 $\hat{\mathbf{z}}$ 通道拼接，再由 $\Phi^{\text{proj}}_{\theta}$ 映射回骨干输入空间，替代原版 ControlNet 式分支以省显存。相对位姿编码 VPRoPE 把帧间位姿写进 RoPE：VPRoPE-G 用相机到物体的 $\mathbf{T}_{\text{c2o}}$ 构造分块旋转矩阵，使注意力分数依赖 $\mathbf{T}^{m}_{\text{c2o}}(\mathbf{T}^{n}_{\text{c2o}})^{-1}$；VPRoPE-L 进一步取 CNOCS 逐像素归一化坐标的方向角 $\phi^{(a)}=\operatorname{atan2}(\sqrt{\|\mathbf{v}\|^2-(\mathbf{v}^{\top}\mathbf{e}_a)^2},\mathbf{v}^{\top}\mathbf{e}_a)$，离散化为位置索引后保留 RoPE 的多频结构。两者以 $f_{\text{final}}=f_{\text{RoPE-3D}}+\lambda_{\theta}\mathbb{I}_{\text{obj}}f_{\text{global/local}}$ 融合，$\lambda_{\theta}$ 初始化为 0，仅作用于物体 token。每个注意力头引入可学习正交变换 $\mathbf{H}_{\theta,h}=\exp(0.5(\mathbf{W}_{\theta,h}-\mathbf{W}^{\top}_{\theta,h}))$，在保持特征范数的同时让不同头捕捉互补几何关系。训练分两阶段：Stage I 只在 T2I 数据上优化绝对编码参数（6K 迭代），损失为 flow matching 加区域损失 $\gamma\mathcal{L}_{\text{region}}$，$\gamma=0.3$；Stage II 注入 VPRoPE，仅优化新增参数并使用 T2V 数据（12K 迭代）。推理时可外接独立训练的 UCPE 相机控制模块，实现物体与相机运动的分离或联合控制。

## 实验与结果
- T2I 位姿误差：Trans.Err 0.06、Size.Err 0.19、Rot.Err 0.24（T2IVPoseEval，Ours）
- T2I 位姿误差：Trans.Err 0.09、Size.Err 0.28、Rot.Err 1.10（3D BBox 基线）
- T2V 位姿与运动：Trans.Err 0.08、Rot.Err 0.29、US_pos 8.5、US_mot 8.1（Ours + VPRoPE-L）
- T2V 去掉相对编码：Trans.Err 0.11、Rot.Err 0.35、US_mot 6.2（w/o Rel.）
- 数据集规模：新增 16,561 张图像与 31,540 段视频（ObjectPose9D++）
- 评测规模：255 个 T2I 与 326 个 T2V 测试用例，40 名用户参与主观评测（T2IVPoseEval）
- 消融：去掉正交约束后 FVD 由 297.9 恶化到 584.7（T2V）
- 消融：头共享正交变换使 Trans.Err/Size.Err/Rot.Err 由 0.08/0.27/0.29 变为 0.14/0.32/0.36

## 创新点与贡献
- 相对作者前作 SceneDesigner（仅 T2I、ControlNet 式重分支），本文把 9D 位姿控制统一到 T2I 与 T2V，并用输入级拼接替换重分支
- 相对 3DTrajMaster、Free-Form Motion Control 等，新意在于把「帧级绝对定位」与「帧间相对运动」显式拆成两套编码：CNOCS 序列负责前者，VPRoPE 把相对位姿写进 RoPE 的旋转矩阵负责后者
- VPRoPE-L 用逐像素方向角保留多频结构，加上头级正交变换，是相对普通 RoPE 与全局位姿广播的实质性架构改动

## 局限与风险
- 作者自述 image-to-video（I2V）能力受底层预训练模型的图像条件能力限制，尚未展开
- 实验只在自建 T2IVPoseEval 上做同骨干对比，缺少与 3DTrajMaster、CineMaster 等异构系统的直接数值比较，泛化性证据偏内部
- 绝对位姿依赖 CNOCS 的立方体代理，对非刚体、细长或严重遮挡物体可能失真
- VPRoPE 仅在物体 mask 内生效，mask 估计误差会直接传导
- 训练数据含大量合成与内部数据，复现门槛较高
