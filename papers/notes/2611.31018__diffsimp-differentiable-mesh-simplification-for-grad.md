# DiffSimp：面向梯度式低多边形建模的可微网格简化

## 一句话结论
不放松离散坍缩决策，而是固定坍缩历史、只对由此确定的顶点位置映射求导，把简化误差回传给上游几何参数：低多边形重建 K=1000 CD 1.26e-5 对 QEM 1.92，逆渲染 K=2000 PSNR 27.29 dB 对 QEM 25.43，已实现前反向 CUDA 并接入 FlexiCubes。

## 要解决的问题
可微网格提取让基于梯度的几何优化能覆盖逆渲染、场景重建、生成式 3D 建模，但这些管线通常输出稠密网格，下游却需要紧凑网格。常见做法是先重建/生成高细节网格，再做 QEM 后处理简化，这使几何优化与最终部署网格解耦：目标函数在稠密中间网格上评估，简化引入的误差拿不到梯度，上游优化器无法补偿。直接降低可微提取分辨率又会限制细节恢复。在激进简化下，QEM 也会产生显著几何畸变。

## 方法详解
DiffSimp 是 training-free、drop-in 的可微网格简化层，建立在 QEM 并行边坍缩之上，优化目标为 $\min_\theta \mathcal{L}(\mathcal{S}_K(\mathcal{M}_\theta))$。前向扩展 PaMO 的并行边坍缩：多 pass 逐步提高代价阈值 $\tau_p$ 直到达到顶点预算 $K$，每 pass 开始时按 memoryless simplification 重算面/顶点 quadric，并使用面积加权面 quadric $K_f=w_f p_f p_f^{\top}$、$w_f=a_f/\bar{a}$；顶点放置用正则化 QEM $v_e=-(A_e+\lambda_e I)^{-1}b_e$，退化时回退到边段或中点，共三种 placement 分支。由于离散边选择与连接更新不可全局微导，作者固定坍缩历史 $\sigma$（记录每轮坍缩边集、pass 边界、存活/删除端点、placement 分支），把顶点位置映射视为局部可微的 collapse map $\mathcal{C}_\sigma:V^{(0)}\mapsto V^{(R)}$，于是 $\nabla_\theta\mathcal{L}=(\partial V_\theta/\partial\theta)^{\top}(\partial\mathcal{C}_\sigma/\partial V_\theta)^{\top}\nabla_{V^{(R)}}\mathcal{L}$。反向采用 factorized 方案：把顶点 quadric 当作可微中间变量，使同一轮内多个坍缩可并行算 VJP；跨轮则沿 quadric reduction forest 做加性合并反向，避免重复的面级微分。前向与反向均以 CUDA 实现，并配合 progressive vertex-budget schedule 嵌入迭代优化。

## 实验与结果
- 低多边形重建 K=1000：CD mean 1.26×10⁻⁵ vs QEM 1.92、TriFlow 2.53、PaMO 4.96；F1 0.26 vs QEM 0.21；NC 0.97
- K=250：CD 10.76 vs QEM 14.88、ACVD 36.59；梯度带来的绝对增益由 K=2000 的 0.05 增至 1.34
- 逆渲染 K=2000：PSNR 27.29 dB vs QEM 25.43、TQEM 22.47、ADS 25.71，稠密参考 29.02
- Stage 1 仅保留稠密网格 3.9% 顶点（2,000 / 51,512），PSNR 仅低 1.32 dB
- 端到端优化时间为未简化基线的 1.00–1.25×
- 前向算子较 CPU QEM 加速 61.3×–319.1×；反向较 Autograd 加速 37.3×–61.8×
- 跨前端 K=1000：DMTet CD 1.23 vs QEM 1.82；DiffMC 1.03 vs 2.07；Large Steps 6.47 vs 7.35

## 创新点与贡献
- 不放松离散坍缩决策，而是固定坍缩历史、只对由此确定的顶点位置映射求导，从而在保持 QEM 前向质量的同时把简化误差回传给上游几何参数
- 把顶点 quadric 提升为可微中间量，配合 quadric reduction forest 做并行 VJP，使「每次迭代都简化」在工程上可行（反向较 autograd 快 37–62×）
- 并证明优化部署网格与优化稠密网格会分道扬镳：Forward-only 降低 raw 目标却不改善 deployed 目标

## 局限与风险
- 作者承认：效果依赖优化过程中中间网格的质量，若上游产生碎片化几何或内部壳层，过早简化会放大缺陷甚至导致优化失败
- 激进简化下坍缩映射的多对一特性会让部分中间几何约束不足，产生漂浮伪影
- UV 对应仍由独立流程处理，未纳入简化器的 collapse cost 与 seam 传播
- 从正文看，评测集中在合成/扫描形状与 NeRF-synthetic，真实拍摄大场景与纹理接缝场景覆盖有限
- 实现依赖自定义 CUDA 算子
