# PixGR：像素空间生成解码的快速前馈 3D 重建

## 一句话结论
把轻量像素空间生成建模嵌入前馈 3DGS 重建：场景潜表示条件化噪声目标视图的生成解码，像素空间 flow matching 实现端到端可微优化，超最强竞品 MVSplat 1.13 dB PSNR。

## 要解决的问题
前馈 3D 重建的 VAE 潜空间压缩累积误差、限制生成解码质量；确定性解码无法表达遮挡/未观测区域的场景不确定性。

## 方法详解
上下文观测一次性编码为场景潜表示；以重建引导的去噪（reconstruction-based denoising）从噪声目标视图生成共享 3DGS；可微渲染直接像素空间生成监督，避免 VAE 潜空间；解码 tokenizer patch size 8（VGGT 为 14），条件图 resize 448 对齐 token 数。

## 实验与结果
视角插值/外推标准基准 + ACID 域外评估：较 MVSplat PSNR +1.13 dB 且 SSIM/LPIPS/FID 同步提升；256×256 A100 训练，含效率分析。

## 创新点与贡献
① 像素空间生成解码避免 VAE 潜压缩与误差累积；② 重建引导去噪；③ 前馈重建中显式建模场景不确定性。

## 局限与风险
绝对 PSNR 水平仍受前馈范式制约；生成解码计算开销；附录 D 自述局限（域外与效率边界）。

## 与文献库的关系
属库内前馈 3DGS 重建线（LINGO 2609.22849 / RLSplat 2610.27712 / VGGT 系）的生成式变体；与 budgeted 压缩线（Budgeted-GS 2610.03162 / RLsplat）互补。

## 可复现性（代码/数据/硬件）
摘要级未明示代码；PyTorch 实现细节附录齐全。
