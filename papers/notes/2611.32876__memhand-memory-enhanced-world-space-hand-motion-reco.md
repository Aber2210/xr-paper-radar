# MemHand：基于记忆增强的第一视角视频世界坐标系手部运动重建

## 一句话结论
把「有效利用时序上下文」建成记忆问题：短期事件记忆按遮挡/出视野事件自适应决定读取长度，长期尺度记忆把稀疏但可靠的尺度证据（度量深度 + 静态手掌视差）压进有界状态，出视野补全搬到世界系做手-头协同——ARCTIC W-MPJPE 41.46 mm vs StableHand 91.25（−57%），HOT3D 14.20 vs 46.76。

## 要解决的问题
从第一视角视频恢复双手连续的世界坐标运动（人到机器人的策略迁移、AR 的关键接口）不能只靠逐帧重建，因为一帧所需上下文往往分布在时间上，尤其在遮挡与手离开视野前后。现有视频方法多从固定长度窗口取上下文，隐含假设该窗口总能覆盖足够信息，但实际上上下文分布不均且位置取决于手的状态：离开视野的手需要“离开处”与“回来处”，被遮挡的手需要遮挡前后，而度量尺度只由视频中任意位置的少数时刻决定。窗口受限时无法可靠获取每帧真正需要的上下文，导致遮挡/出视野段的世界坐标误差极大（HaWoR 在 ARCTIC 出视野手 W-MPJPE 达 650mm）。

## 方法详解
把时序上下文的利用重构为记忆问题，按上下文“寿命”不同设两种互补记忆。Hand Localizer 用冻结 V-JEPA 2.1 特征的 slot attention（左手/右手/背景三个 slot）判断每帧手的存在状态 π_t∈{∅,L,R,LR}，CenterNet 式热图定位 2D 关键点并由峰值概率质量给出置信度 m（同时用于触发事件），再用位移头 + RTS 平滑做时序细化，出图关键点则用相机位姿把最近可见位置投影过来再由偏移头修正。Short-Term Event Memory 以事件为单位组织上下文：遮挡事件区间 O=[a,b) 由手部关键点平均置信度低于阈值判定（无需标签或学习门控），由于长度未知，维护 w_max 的滚动缓冲，置信度恢复后取 w=clip(b-a,w_min,w_max) 得到前/后文 C⁻、C⁺，完整事件 S=C⁻∪O∪C⁺；解码时 MANO Decoder 读整个事件而非固定窗口，并额外引入 Hand Feature Prediction（HFP）模块——在 V-JEPA 特征空间预测遮挡下的特征增量 Δ=F(Ĩ)[B]-F(I)[B]（Ĩ 为把 GT MANO 渲染到原视频得到的参考视频），因为遮挡时另两路输入主要编码遮挡物。对出视野事件，则在世界坐标系中补全（相机系里头的头部运动与手运动纠缠），用前后文插值/外推初始化，再由注入头部运动的补全模块细化（每个注意力头一半通道按逐帧相机旋转调制、一半按时间戳调制）。Long-Term Scale Memory 在全片范围内维护两类观测（Metric3D 深度与 DPVO 逆深度的中位数比值；静态手掌与头部运动形成的视差，用 Σ‖T_t q_t - Tq̄‖²=0 闭式最小二乘解尺度），每个观测带数值 s_i 与对数精度 ℓ_i，精度由轻量网络从深度块、位置、相机运动或手掌轨迹与拟合残差预测；记忆库只保留精度最高的 K=32 个观测，尺度按 softmax(ℓ) 加权对数均值读出，状态有界。

## 实验与结果
- 世界坐标（StableHand 基准）：ARCTIC W-MPJPE 41.46mm vs StableHand 91.25（降低 57%）、PA 5.67 vs 7.56、MRRPE 35.27 vs 88.56
- HOT3D：W-MPJPE 14.20mm vs StableHand 46.76（降低 70%）、PA 3.19 vs 3.40、MRRPE 15.54 vs 47.36
- 对 HaWoR：ARCTIC 全帧 W 41.46 vs 157.21、PA 7.23 vs 9.81；HOT3D W 35.51 vs 89.81；零样本 HOI4D W 88.33 vs 103.07（PA 10.35 vs 11.23）
- 相机系：ARCTIC MPJPE-p 14.07 vs ACE-Ego-Hand 15.26、EPE-p 8.72 vs 9.18、出视野 OW-p 103.76 vs 119.32；HOI4D 零样本 MPJPE-p 24.54 vs 26.14
- 尺度记忆：HOT3D 上 W 从 40.1（Metric3D）降到 35.5mm，真值尺度为 32.8mm；长视频尺度中位误差 5s 时 9.2% → 60s 时 3.4% → 全片 2.9%
- 效率与主观：端到端 13.7 FPS（WiLoR-SLAM 8.5、HaWoR 3.5、Dyn-HaMR 1.1），53 名被试的 400 段视频偏好率 66.2%

## 创新点与贡献
- 把“有效利用时序上下文”明确建模为记忆问题，并按上下文的寿命长短拆成短期事件记忆与长期尺度记忆：事件记忆以遮挡/出视野事件为单位自适应决定读取长度（而非固定窗），且出视野补全被搬到世界坐标系做手-头协同
- 尺度记忆则把全片稀疏但可靠的尺度证据（度量深度 + 静态手掌视差）压进有界状态并学习每个观测的精度
- 技术上 HFP 在 V-JEPA 特征空间预测“被遮挡手应产生的特征增量”，是对遮挡特征被遮挡物污染这一问题的直接建模

## 局限与风险
- 存在明显解码时延：因为整窗/整事件闭合后才解码，50% 的手在 101 帧后才输出、95% 需 193（ARCTIC）/145（HOT3D）帧，作者也承认尚未实时，这对闭环机器人策略不利
- 依赖多个外部组件（V-JEPA、WiLoR、DPVO、Metric3D），任一环节失效会传导
- HOI4D 因官方片段列表未公开而自采样，比较严谨性受限，HOT3D 上 ACE-Ego-Hand 的训练/测试重叠也只能“仅供参考”
