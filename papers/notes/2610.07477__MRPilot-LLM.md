# MRPilot：通过混合现实监督与介入 LLM 驱动的多机器人团队

## 一句话结论
MRPilot 是一套通过混合现实（MR）界面监督与介入 LLM 驱动的多机器人团队的框架，归纳出 8 类干预类型（信息澄清/计划优化/授权访问/失败恢复/能力缺口协助等）。用户研究（含配对统计）显示，MRPilot 在 7 类干预事件的完成时间上短于基线，系统支持的交互型任务完成最快。

## 要解决的问题
用 LLM 以自然语言指挥异构多机器人系统（MRS）时，任务解释、机器人分配、协同困难；人类需要可干预的监督手段。

## 方法详解
MRPilot 把 LLM 规划/执行与 MR 可视化结合，把干预事件形式化为 8 类（T1–T8），支持人类在任务执行中澄清、重规划、授权、失败恢复、能力缺口协助等；MR 界面提供情境化的任务/机器人状态与干预入口。

## 实验与结果
用户研究，9 类干预事件；用 Shapiro–Wilk 检验正态性后，正态数据报均值±SD + 配对 t 检验，非正态报中位数±IQR + Wilcoxon；MRPilot 在 7 类干预完成时间上显著短于基线（如信息澄清 Mdn 102.24→67.49，W=23, p<.01, r=-0.78）。

## 创新点与贡献
把 MR 作为 LLM-MRS 的“可变自主性（variable autonomy）”干预层，并系统化干预类型学；实用 HCI 贡献。

## 局限与风险
以用户研究为主，缺乏大规模/真实部署；MR 界面的认知负荷与长时可用性的量化有限；依赖具体 LLM-MRS 栈。
