# SynerGest：双人对话的时空协同手势生成

## 一句话结论
双人对话的协同手势生成（ACM MM '26 接收）：以 Contrastive Flow Matching 联合条件于听者与说话者的 48kHz 双声道语音，在 Audio2Photoreal 与 Seamless Interaction 两个双人对话数据集上，以 FGD/BC/Div/推理耗时 T_inf 四项指标对比 4 个基线（EMAGE、GestureLSM、TalkSHOW 与唯一双人基线 A2P）。

## 要解决的问题
共语手势生成既有工作几乎全是单人说（monadic）设定，忽略对话中听者与说话者的交互节律；双人设定缺少联合建模双方音频、并显式控制「动什么 / 何时动」的生成框架。

## 方法详解（含关键公式/架构，保留原文术语）
① 条件生成：listener 与 partner 两路原始波形经冻结 AudioRhythm Encoder 独立处理并拼接为基础声学特征 F_a（wav2vec 2.0 骨干 + mel 特征，双通道独立）；为适应不同动力学特性，flow estimator 分离身体与表情双通路（PoseOnly / FaceOnly）。② Guide Transformer 从音频自回归预测离散 RVQ token，解码为引导关键帧（guide key-frame generation）。③ Dyadic-conditioned flow estimator：学习步长条件速度场 v_θ(x_t,t,d,c)，把高斯先验传输到经验分布；固定初始噪声与音频时从 t=0 积分到 1 得确定性 ODE 轨迹，更换初始样本则得到同一音频的另一个合势力势（context injection 与 condition vector 投影注入对话条件）。④ ITSA（Impulse-Trend Synergistic Attention）：Trend Feature Gating 决定「动什么」、Impulse Temporal Gating 决定「何时动」，再加可学习软混合 MHA。⑤ 训练目标为 Contrastive Flow Matching。

## 实验与结果（表格化关键数字）
数据集：Audio2Photoreal（工作室录制双人对话 + 写实 Codec Avatar 资产，48kHz 双声道分别含说话者/听者波形）与 Seamless Interaction Naturalistic 子集（无脚本自发录制，单声道按参与者配对、重采样 48kHz、对齐时长后堆叠为双声道）。指标：FGD（动力学真实感）、BC（Beat Consistency，音频-动作同步）、Div（动作方差）、T_inf（每样本平均推理耗时）。基线：EMAGE、GestureLSM、TalkSHOW（三个单人说框架适配到双人协议）+ Audio2Photoreal（A2P，唯一双人基线），同数据处理公平对比。digest 未包含 Table 1 的具体数值。

## 创新点与贡献
① 面向双人对话的 CFM 手势生成框架，联合条件于听者/说话者双方音频；② 身体/表情解耦双通路 + Guide Transformer 的 RVQ 关键帧引导；③ ITSA 显式分解「动什么」（trend gating）与「何时动」（impulse temporal gating）；④ 步长条件速度场支持确定性 ODE 推理与同音频多样化采样。

## 局限与风险
目标化身建模为 listener 角色（joint-modeling 场景下），speaker 侧生成未覆盖；依赖对话双方音频的配对与时间对齐；digest 未报告定量结果与运行时数值，也未给出失败模式分析。

## 与文献库的关系（新增 / 改进 / 取代 X）
隶属「化身与人体」手势/表情动画线：基线 EMAGE/GestureLSM/TalkSHOW/A2P 均为共语手势生成代表，A2P 的 Codec Avatar 资产与库内 3DGS 化身族（LAM/GAGAvatar/FlexAvatar、2602.11693 OMEGA-Avatar）同属「参考资产驱动」路线；与 Stable Signer V3（2610.24926）互补——后者做手语（语言级精确动作），本文化做对话伴随手势（语用级节律），可与 SynerGest 的输出共同驱动 XR 社交化身。
