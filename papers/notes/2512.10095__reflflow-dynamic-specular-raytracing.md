# ReflFlow：几何引导光线追踪的动态高光重建

## 一句话结论
在 NeRF-DS 七个动态高光场景上，ReflFlow 用 2DGS 的免近似法线、残差材质增广、动态环境高斯与光栅/光追混合管线，把平均 PSNR 从 SpectroMotion 的 24.17 提到 24.91（+0.74 dB）、SSIM 0.8522→0.8880、LPIPS 0.1778→0.1471；代价是 HyperNeRF 上 22.47 dB 低于 4DGS 的 24.89，且训练 2.8 h、推理 32 FPS。

## 要解决的问题
动态高光的两个物理前提——精确反射方向与可信反射模型——在单目 3DGS 体系里都不成立。3DGS 不显式表达表面，法线依赖近似（GaussianShader、SpectroMotion 等），误差会经 d_out=d_in−2(d_in·n)n 放大到高光颜色；环境贴图只能近似远场照明，受分辨率限制且无法表达近场反射（正文以 Press 场景镜中苹果未被重建为例）。NeRF-DS 用逐帧表面朝向条件化辐射场，7DGS 把方向纳入 7D 高斯，SpectroMotion 引入动态环境贴图并分解漫反射/高光，EnvGS 用环境高斯做静态视角相关外观——但没有方法同时解决「动态几何的法线精度」与「动态环境的近场高光」。此外仅监督最终颜色会使漫反射/高光分解病态，动态场景下缺少稳定化方案，训练早期易收敛到退化解。

## 方法详解
以 2DGS 为几何载体：基元有中心 p_k、切向 t_u,t_v、缩放 S=(s_u,s_v)，P(u,v)=p_k+s_u t_u u+s_v t_v v，G(u)=exp(−(u²+v²)/2)，法线由 t_w=t_u×t_v 直接给出，故不必估法线即可算 d_out=d_in−2(d_in·n)n。每个 2D 高斯另加可学习 specular tint s_tint∈[0,1]，并用时间条件残差网络 ΔG^t=F_θG(p,t) 预测 (Δp,Δs,Δr,Δo,Δs_tint) 加到基准属性。几何监督两项：L_norm=(1/N_p)Σ(1−n_i^T N_d(u_i))，N_d 由深度梯度叉积归一化；另用 NormalCrafter 扩散先验法线 N_e 构造 L_tc-norm=(1/N_p)Σ(1−n_i^T N_e) 抑制闪烁。反射用 Dynamic Environment Gaussian G_env，同样以 F_θenv(p,t) 预测时间偏移；颜色分解 C=(1−α_spec)C_diffuse+α_spec C_specular，α_spec=Σ_i s_tint,i α_i Π_{j<i}(1−α_j) 由一次额外光栅化得到。混合渲染：C_diffuse 走 2DGS 光栅化，C_specular 由光追对每条反射射线取最多 k 个交点，C_specular=Σ_{i=1}^k T_i·G_i(H_i^{-1}x_i)·c_i。训练 60k 步三阶段：0–9k 仅漫反射、9k–15k 冻结漫反射只训高光、15k–60k 联合微调。

## 实验与结果
- 数据与设置：NeRF-DS 七个单目动态高光场景（As/Basin/Bell/Cup/Plate/Press/Sieve）加 HyperNeRF，均用数据集自带 points.npy 初始化；指标 PSNR / SSIM / LPIPS(VGG)。
- NeRF-DS 平均（Table 1）：Ours 24.91 / 0.8880 / 0.1471，SpectroMotion 24.17 / 0.8522 / 0.1778，NeRF-DS 23.24 / 0.8384 / 0.2402，4DGS 22.79 / 0.8235 / 0.2115，Deformable 3DGS 23.43 / 0.8284 / 0.2201。
- 单场景：Sieve 27.95 对 SpectroMotion 25.22；Press 27.39 对 26.49；Plate 21.10 对 20.84；As 26.73 略低于 26.80。
- HyperNeRF（Table 2）：Ours 22.47 / 0.6328 / 0.3106，4DGS 24.89 / 0.6781 / 0.3422，NeRF-DS 23.65 / 0.6405 / 0.3972；LPIPS 最优但 PSNR/SSIM 非最优。
- 模块消融（4 场景均值，Table 3）：base 16.29→加 F_θG 18.97→加 F_θenv 20.25→加 L_norm 22.12→加 L_tc-norm 25.23；LPIPS 0.4126→0.2389→0.2313→0.2149→0.1536。
- Coarse-to-fine 消融：去掉后 15.28 / 0.5782 / 0.4471，完整 21.10 / 0.8415 / 0.1821（4 场景）。
- 效率（RTX 6000 Ada）：60k 步 2.8 h、32 FPS；SpectroMotion 40k 步 1.1 h、33 FPS。

## 创新点与贡献
- 用 2DGS 的切向叉积直接给出法线，从表示层面消除「法线近似→反射方向偏差」的误差链，而不是在网络里补偿估计误差。
- 把 specular tint 做成逐高斯的可学习材质参数，并用一次透射率加权光栅化得到 α_spec，使漫反射/高光混合权重既视角相关又几何相关。
- 以 Dynamic Environment Gaussian 替代环境贴图，支持时间变化照明与近场反射，配合光追查询实现物理可信的高光合成。
- 给出针对动态高光的三阶段 coarse-to-fine 调度，把「仅监督最终颜色」的病态分解稳定下来（去掉后 21.10→15.28 dB）。

## 局限与风险
- （作者承认）单目动态重建本身病态，细粒度运动与非刚性形变下几何模糊会直接削弱法线与反射方向可靠性。
- （作者承认）只处理单次反射；多次互反射在单目下不可辨识。
- （作者承认）空间变化 BRDF 的光泽材质仍困难，材质与光照分解欠约束。
- （我在正文发现）HyperNeRF 上 PSNR 22.47 明显低于 4DGS 的 24.89、SSIM 0.6328 低于 0.6781，泛化到非高光动态场景时不如纯动态重建方法。
- （我在正文发现）训练 2.8 h 是 SpectroMotion 1.1 h 的约 2.5 倍，且依赖 NormalCrafter 外部法线先验，其误差会经 L_tc-norm 传入几何。
- （我在正文发现）代码仅承诺「接收后 release」，当前无仓库，复现需自备 2DGS、EnvGS 光追器与 NormalCrafter 三套组件。

## 与文献库的关系
本文站在三条脉络交汇处：几何侧继承 2DGS（Huang et al., 2024）的射线–splat 求交与法线一致性损失，替代 3DGS（Kerbl et al., 2023）的近似法线；反射侧对标 GaussianShader（Jiang et al., 2024）、GS-IR（Liang et al., 2024）、EnvGS（Xie et al., 2025）的「漫反射/高光分解 + 环境表示」路线，并把 EnvGS 的静态环境高斯扩为带残差网络的时间变化版本；动态侧与 NeRF-DS（Yan et al., 2023）、Deformable 3DGS、4DGS、SpectroMotion（Fan et al., 2024）对比，差异在用 2D 面元保证法线精度、用光追而非环境贴图取高光。本篇为旧稿 v2 再公告（v1 未入馆），按首次入馆处理。
