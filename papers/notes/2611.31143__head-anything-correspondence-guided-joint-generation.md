# Head Anything：由少视图对应引导联合生成 3D 头部

## 一句话结论
在原生 3D latent 生成器内部、而非 2D 图像空间做对应路由的联合去噪（每个 3D token 只 attend 其他帧中同一头部点的少量 token）：NPHM 头部 Chamfer 4.83→3.27 mm（−32%），跨帧一致性 9.48→5.03（−47%），8 图约 2.3× 单图耗时。

## 要解决的问题
大型 image-to-3D 生成器能从单张照片恢复细节丰富的头部，但把每张图当作新对象：同一个人的多张图（表情、视角变化）会被各自独立地幻想未见区域，互不利用信息。学习多图先验又极难：高质量头部扫描只有数百人，远少于通用生成器的数十万物件；同一头部点在表情/姿态变化下落到各图不同位置，全局跨图 attention 难以从如此少 identity 中学到对应。参数化头模型能融合多帧但几何粗糙、缺头发与细节；前馈方法只给可见表面；视频/多视图扩散只在 2D 图像间传信息。

## 方法详解
Head Anything 不训练多图先验，而是把预训练单图生成器 Pixal3D（原生 3D latent）改造成联合生成器：所有帧的 latent 作为一个联合样本同步去噪，每帧保留自己的噪声、条件 $c_f$、token 与 S2 占据体素，因此每个 mesh 仍与自己的图像像素对齐。在两条 flow 的每第 3 个 block 后插入轻量 correspondence-attention adapter：$H_f\leftarrow H_f+\gamma(t)W_o\mathrm{Attn}_\ell(H_f,\{H_g\}_{g\neq f},\Phi)$，$W_o$ 零初始化、$\gamma(t)$ 为时间步门控，故初始时联合生成器严格等于单图生成器。对应映射 $\Phi_{f\to g}(p)=A_g\varphi_{f\to g}(A_f^{-1}p)$，其中 $A_f$ 是头模型坐标到 latent grid 的映射，$\varphi_{f\to g}$ 由参数化头模型的配准给出；S1 是稠密 $16^3$ grid，key/value 在三线性采样；S2 稀疏，取对应位置 $K=4$ 个最近占据 token，key 中嵌入偏移 $\delta_{ij}$ 与两帧深度特征 $d_i,d_j$，并加一个可学习 null key-value 对以忽略遮挡/错误对应。每 token 只 attend $(n-1)K+1$ 个 key 而非 $(n-1)T$，复杂度降 $T/K$。对应在测试时由生成器自身输出 bootstrap：先用 Pixel3DMM 拟合 FLAME 得到稠密模板对应与相似变换 $A_f$，再把一个 MonoNPHM 以共享 identity code、逐帧 expression code 与相似变换拟合到全组 mesh（SDF 损失 + 先验正则）。训练同时使用真值配准对应与拟合对应，使 adapter 对拟合误差鲁棒。

## 实验与结果
- NPHM 头部 Chamfer 3.27 mm vs 最强 image-to-3D 基线 Pixal3D 4.83（−32%），vs 同骨干 Pixal3D-FT 3.86
- NPHM 跨帧一致性 5.03 vs Pixal3D 9.48（−47%），vs Pixal3D-FT 6.73
- NPHM F-score 50.9 vs Pixal3D 38.0；EMD 11.8 vs 17.3
- FaceVerse Chamfer 4.65 vs Pixal3D 6.15、Hunyuan3D-2.1 6.72；一致性 7.87 vs 11.09
- 真实图 NeRSemble：IoU 0.953 vs Pixal3D-FT 0.942，Chamfer 3.10 vs 3.29，一致性 3.30 vs 4.37
- 真实图 AVA-256：IoU 0.915、Chamfer 3.13、一致性 3.12（Pixal3D-FT 0.905 / 3.36 / 4.22）
- 下游 FLAME 跟踪 Chamfer 4.26 vs Pixel3DMM 4.86，F-score 52.4 vs 46.1
- 8 张图联合生成耗时约为逐张生成的 2.3×

## 创新点与贡献
- 在原生 3D latent 生成器内部、而非 2D 图像空间做对应路由的联合去噪：每个 3D token 只 attend 其他帧中「同一个头部点」的少量 token，使 adapter 从第一步训练就知道该看哪里，绕开「从数百 identity 学全局跨图 attention」的样本瓶颈
- 对应不依赖测试时真值，而是把神经参数化头模型拟合到生成器自己的单图输出上 bootstrap，并用真值+拟合对应混合训练来吸收拟合误差

## 局限与风险
- 作者承认：方法专门针对人头，因为对应来自参数化头模型，不能直接推广到全身或通用物体
- 重遮挡或仅小部分人脸可见时参数化拟合不可靠
- 假设各图头几何一致（仅表情变化），跨时间发型/配饰变化的照片集超出范围
- 依赖昂贵的 diffusion image-to-mesh 生成器，实时应用不可行
- 从正文看，评测 identity 数（各 10 人）与输入视图数（8）有限，跨身份泛化与更多视图的扩展性未充分验证
