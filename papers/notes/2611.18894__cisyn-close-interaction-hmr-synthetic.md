# CISyn：用物理仿真合成数据做近距离交互中的人体网格恢复

## 一句话结论
碰撞仿真生成 25,000 段近距离交互（30 万帧），Hi4D MPJPE 61.2→52.3 mm。　用碰撞仿真生成 25,000 段、30 万帧近距离交互数据，Hi4D 上 MPJPE 61.2→52.3 mm，PA-MPJPE 45.9→39.3。

## 要解决的问题
近距离人-人交互的单图 HMR 缺少大规模精确标注：实拍昂贵，Hi4D（100 段）、CHI3D（631 段）动作种类有限；pGT 数据近接触帧稀少且重叠处标签噪声大；AGORA、BEDLAM、SynBody 等合成集把每个人独立摆放，接触、碰撞响应与姿态纠缠先天缺失，而这正是最需要数据的区间。

## 方法详解
两段式管线。仿真：Genesis 引擎 480 步/秒、标准重力与刚体碰撞，导出 12 帧@30 FPS（0.4 s，围绕碰撞窗）；人偶用 SMPL-X 的近似刚体模型（体密度 1000 kg/m³，设关节限位、关闭部分自碰撞）；随机化体型 β∈ℝ¹⁰（1100 个资产不放回抽样）、初始姿态 θ∈ℝ⁵⁵ˣ³（AMASS）、圆上初始平移（最小间距约束）、朝向（偏航全范围，俯仰/滚转小高斯）、线速度（朝场景中心，含标准与高速两档）、角速度。渲染：XRFeitoria/Blender + 1100 套服装 FBX + LBS，随机 HDR IBL（室外取自 BEDLAM2、室内 Poly Haven），相机距交互中心 2–5 m、高约 1.4 m、FoV 42°–110°，三种分辨率（1280×720 / 940×1280 / 1280×1280）。标注 SMPL-X 与 SMPL 参数、内外参，另发深度与分割。数据：24,000 训练 + 1,000 测试序列，共 300,000 帧。模型在 MA-HMR（DINOv2 ViT-B/14 + SAT 三尺度 token + 6 层 DAB-DETR 解码器 50 query）上加两处：逐关节遮挡权重 w_j=1−0.9o_j（o_j 由他人 SMPL 网格深度排序投影得，w_j∈{0.1,1.0}）；每关节 σ_j 头，把 L1 换成 Laplacian NLL：L_j=√2·e^{−σ_j}·w_j·‖p̂_j−p_j‖₁+σ_j，用于 2D 与 root-aligned 3D 关节，其余 7 项损失沿用。从 MA-HMR 检查点初始化，在 Base（AGORA+BEDLAM+DTO-Humans）+CISyn 上微调 6 epoch。

## 实验与结果
- Hi4D：MPJPE 61.2（MA-HMR）→52.3 mm，PA-MPJPE 45.9→39.3，PVE 77.2→65.6；PromptHMR 为 63.9/39.2。
- CHI3D：MPJPE 47.2→44.9，PVE 55.7→53.4；Harmony4D：77.5→74.4，PVE 91.9→88.5（均低于 Multi-HMR 的 117.9/135.3）。
- 与真实近距离数据集同预算对比：Base+Hi4D 在 CHI3D 为 45.1 MPJPE、Harmony4D 75.4；Base+CISyn 为 44.9、74.4，两基准均最优。
- 换骨干验证：Multi-HMR 加 CISyn 后 Hi4D 81.3（Base+CHI3D）→74.2，CHI3D 64.2→60.3。
- 通用域 3DPW：加入 CISyn 后三项指标不变或略升。
- 消融：把物理仿真换成 DualHuman 运动后三项指标全面变差（Hi4D 52.3→55.4）；去遮挡权重或去 σ 头同样变差。

## 创新点与贡献
- 与 AGORA/BEDLAM/SynBody 的独立摆放、与 RL 追踪参考动作的多人体合成比：首次让刚体碰撞动力学本身产生接触、互遮挡与姿态纠缠，无需参考动作或人工设计，管线可扩到更多人。
- 对比基线：MA-HMR（Base 与 Base+CISyn）, Multi-HMR, PromptHMR, Hi4D / CHI3D / Harmony4D（作为训练数据对照）, BEDLAM / AGORA / DTO-Humans（Base 混合）, DualHuman（消融替代运动）

## 局限与风险
- 演员是被动刚体、无运动控制，不建模有目标的双人协同，尽管增益可迁移到舞蹈等类别；模型端无互穿约束，困难交互下两具预测网格会穿插。
- 消融：三项消融（物理仿真、遮挡权重、不确定性头）中任一项移除都在三基准上变差；不确定性头的 σ_j 在遮挡与重建最差关节处峰值最高，说明其学到了可靠度而非恒定权重。
