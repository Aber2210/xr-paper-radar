# 注视世界模型

## 一句话结论
首个同时检测与预测第三人称视频中指定人物 typed semantic gaze target 转移的模型，把注视建成 world modeling 问题（冻结 V-JEPA 2.1 上联合 latent scene prediction 与 person-conditioned gaze 监督）：四类 shift AP 76.09 vs PaGE-H+ 66.32，二类 shift F1 82.17 vs 74.42。

## 要解决的问题
现有 gaze target estimation 基本逐帧运行：输出每帧一个注视点，注视转移只作为逐帧标签或事后单独检测器处理，模型既不建模也不预测两个语义目标之间的 typed transition。注视转移往往由场景中的动态事件驱动（例如新物体进入），而远端事件可能只引起头部或眼部极小的变化，单帧特征难以捕捉这种弱因果。量化上，最强基线 PaGE-H+ 的四类 shift AP 只有 66.32，且 1.7B 参数仍无法给出未来注视与转移。

## 方法详解
任务定义把 gaze shift 形式化为：两个不同目标 A≠B 各稳定停留至少 T_dwell、中间过渡不超过 T_trans，正类只含 human-to-human、human-to-other、other-to-human 三类。场景用冻结 V-JEPA 2.1 编码 16 帧（8 fps，2 s），tubelet 跨 2 帧，得 T_o=8 个观测位置、T_f=4 个未来位置、每 tubelet P=32×32=1024 个 patch。SIM（来自 PaGE 的 scene–head interaction）把 scene 流与 head crop 流各加 1 个 in/out token + 4 个 register token，用 head box 的平均位置给 head token 分配 RoPE 坐标，经 5 层双向 cross-attention 注入人物条件并在视频阶段冻结。Temporal trunk 用 3D RoPE (t,y,x) 与 SwiGLU 做联合自注意力，未来 query 由最后一个观测 bundle 复制并加 learned future embedding 初始化，attention mask 保证观测 query 只看观测、未来 query 可看全部，因此未来位置不含任何未来像素。World predictor 再加两层 RoPE block，用 latent prediction 监督未来 patch 特征：ẑ=A·LN(u)+b+LN(观测均值)，A、b 零初始化，损失为按时间特征变化加权的 L1（λ_lat=0.1），目标来自同一冻结编码器、无 EMA teacher。读出头三组：64×64 heatmap + in/out logit；shift detection 把 5 个 prefix token 均值、heatmap 注意力池化的 patch、7 个标量（soft-argmax、峰值、in/out 概率、Δx、Δy、位移幅值）与 head token 均值拼成 summary，经 transformer 输出 1+3 logits；shift forecasting 用同一 summary 设计但读 12 个 tubelet、输出 2 类。训练两阶段：图像阶段训 SIM 与注视读出，视频阶段先联合训 trunk/world/gaze，再冻结后训两个 shift head。

## 实验与结果
- VideoAttentionTarget/ChildPlay 四类 shift AP：GWM-L 76.09 vs PaGE-H+ 66.32（+9.8），GWM-g 75.91
- 二类 shift：GWM-L AP 88.65、F1 82.17，vs PaGE-H+ 78.38 / 74.42
- GWM-B 仅 105M 参数，在四项 shift 指标上全面超过 1.7B 的 PaGE-H+（85.34/78.50/72.45/71.80）
- 未来注视 L2：GWM-g 0.104（VAT）/0.125（ChildPlay）vs SAGE+PaGE 0.123/0.145；相对 persistence 误差降 15.6% 与 11%
- 未来 shift AP 76.18 / F1 74.68 vs SAGE+PaGE 66.23 / 66.67
- jitter 0.012（VAT）/0.013（ChildPlay）vs PaGE-H+ 0.015/0.020，flicker 0.019/0.027 亦最低

## 创新点与贡献
- 首个同时检测与预测第三人称视频中指定人物的 typed semantic gaze target 转移的模型，此前工作或只从逐帧注意力图检测单一转移类型、或只预测未来注视点而不建模转移
- 把注视建模成 world modeling 问题：在冻结 V-JEPA 2.1 上把 latent scene prediction 与 person-conditioned gaze supervision 共同训练，并证明 latent 目标本身能改善 shift 检测与定位
- 配套构建了带事件级转移标注的数据集，覆盖检测与预测两种评测

## 局限与风险
- 只预测转移类型与是否发生，不预测精确事件边界，也不给 target instance identifier
- 观测 2 s、预测 1 s 的设定较短，长时程与多人交互未覆盖
- 未来 tubelet 的 head token 用 learned placeholder 代替，subject conditioning 在预测侧被弱化，作者亦将 target 表示与标注一致性列为局限
