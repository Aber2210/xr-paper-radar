# Re-JEPA：耦合表征预测与信号重建的状态条件化 EMG 跟踪

## 一句话结论
把表征空间预测与信号空间幅值/相位重建串在同一条计算路径上让梯度回传编码器，从理论上排除条件完全坍缩：三个划分 MAE 6.91°/9.04°/9.36°，相对 vemg2pose 降 10.3–19.3%。

## 要解决的问题
从 sEMG 提升连续手部跟踪需要跨用户、跨动作泛化，同时又要对细微动作保持敏感。JEPA 类方法通过上下文预测学习隐空间，但跟踪效果取决于表征保留了哪些运动相关细节、以及这些细节如何随手部状态演进被解读；纯表征匹配并不要求保留编码运动增量的细微观测差异。

## 方法详解
Re-JEPA 在无运动学标签的预训练中先从可见 EMG patch 预测多层级连续隐表征（EMA 目标、L3/L6/L9/L12 融合、Smooth L1），再把四层预测融合还原成完整 token 网格，用幅值与相位解码器重建被掩蔽区域的傅里叶对数幅值与单位圆相位，使重建梯度穿过 predictor 回到在线编码器。下游跟踪用 Gated Persistent Motion（GPM）解码器：以循环状态 token、上一帧位姿与运动增量条件化读取 EMG token，经门控更新状态并预测增量位姿。作者还给出重建风险低于成对下界即可排除条件完全坍缩的命题。

## 实验与结果
- 跨用户/跨动作/联合划分 MAE = 6.91° / 9.04° / 9.36°（全量微调 + GPM）
- 相对 vemg2pose = 降低 10.3% / 19.3% / 14.9%（三个划分）
- 相对 LaBraM+GPM = 降低 4.9% / 9.7% / 6.5%
- J+R vs 仅 J（同 Fusion+GPM96 接口）= 降低 4.6% / 8.4% / 7.0%
- 冻结编码器读出路 = 相对冻结 LaBraM 降低 8.1% / 16.1% / 12.0%
- 动作分类准确率 = 37.18%（LaBraM 26.11%，latent-only JEPA 27.68%）

## 创新点与贡献
- 把「表征空间预测」与「信号空间幅值/相位重建」串在同一条计算路径上，让重建梯度回传到编码器，从理论上论证可排除条件完全坍缩，并用状态条件化的 GPM 解码器衔接连续跟踪

## 局限与风险
