# 缓解 GPU 上 3D 高斯泼溅的 SM 级负载不均衡

## 一句话结论
在大尺度城市场景 Hier-3DGS 上把 alpha blending 平均加速 2.93×、最不均衡帧最高 5.64×（摘要写作 5.6×），24 个场景相对原渲染器的画质差最多 0.0015 dB PSNR，且无需重训练或改动场景表示。

## 要解决的问题
3DGS 的 tile-based 光栅为每个 16×16 tile 分配一个 256 线程 CTA，但各 tile 的 Gaussian 数差异极大：标准基准最大/最小比 55–605×，大尺度场景超过 6,100×。硬件 CTA 调度器以 CTA 为粒度且不知 tile 负载，少数极重 tile 会在其他 CTA 早已结束后继续运行，形成长执行尾并让大量 SM 空转——测得 3DGS train 最重 tile 是每 CTA 均分份额 1.7× 时平均 SM 活跃度仅 49.2%，Hier-3DGS 达 6.8× 时降到 24.9%。已有工作集中在两端：算法层剪枝与预算致密化需重训练，难以用于已重建场景；专用加速器能效高但缺乏对 2DGS、3DGUT 等演进变体的灵活性，且仿真环境需 GPU 同时跑渲染与 VLA 推理。系统层软件优化几乎空白。

## 方法详解
核心是把「何时执行」与「执行多久」分开处理，整体为软件定义 GPU 调度，不改场景表示也不改 alpha blending 公式。（1）LPT 加 persistent kernel：启动 K 个 CTA（K 为 GPU 可并发数）的常驻 kernel，每个 CTA 通过一次 atomicAdd 从软件队列 Q 取下一个 tile，队列按 tile 投影 Gaussian 数 N_t 做基数排序降序（不搬动 Gaussian 数据），计数与排序开销低于 alpha blending kernel 时间的 1%。（2）深度分块加 saturation signaling：把极重 tile 的按深度排序的 Gaussian 列表切成 k 个连续 chunk，各由独立 CTA 以单位初始透射率混合，得部分色 C_p 与透射率 T_p，再由 reduction kernel 按 C = Σ C_p Π_{q<p} T_q 合成——这是可组合性 C = C_A + T_m·C_B 的推广（类似 Flash-Decoding 的归约，但需逐像素色与透射率）。独立执行破坏了透射率阈值 1e-4 的 early termination，故用全局内存 flag 记录最早整体饱和的 chunk（atomicMin），后续 chunk 每 256 个 Gaussian 检查一次并停止；因透射率沿深度单调递减，跳过是安全的。（3）选择性分块加流共执行：只对最重的一小部分 tile 分块，其余仍走 LPT，两 kernel 放在不同 CUDA stream 由硬件调度器分配 SM，最后用 CUDA event 同步再 reduction。（4）每帧在线策略：用管线已有的 per-tile Gaussian 数构造启发式代价 T̂(h,k) = max((N_total + λhk)/K, ℓ) + βℓ，ℓ = max(N_1/k, N_{h+1})；在 k 属于 {2,4,8,16} 上递增 h 搜索最小 T̂，仅当估计代价比 LPT-only 低至少 ε=10% 才启用分块。

## 创新点与贡献
['首次把 3DGS 渲染瓶颈定位为「SM 级 tile 负载不均衡导致的长执行尾」，并用 Nsight Compute 的 SM 活跃度给出可证伪量化（49.2% 与 24.9%），而不只是报告 tile 数偏度。', '用 alpha blending 的可组合性做深度分块并行，并用 saturation signaling 把 early termination 跨 CTA 恢复——这是与 Flash-Decoding 式归约的关键差异（需逐像素透射率），也是优于 CaT-GS 均值阈值切分的主因。', '把「分多少 tile / 切多深」变成每帧在线决策的轻量代价模型，只依赖管线已有的 Gaussian 计数，无需离线配置搜索或场景调参，且正交于 SwiftGS/HiGS 等光栅器优化。']

## 局限与风险
['作者承认：只针对推理期 alpha blending，收益随每帧 tile 不均衡程度缩放；Waymo 与两段 PandaSet 这类均衡负载只有 1.03–1.10×，此时策略几乎不分块。', '作者承认：代价模型用一套跨所有负载的常数 λ、β 与投影 Gaussian 计数，按 GPU 校准或在线学习常数可进一步逼近 oracle。', '我在正文发现：只报告了 alpha blending 阶段的加速，未给端到端帧率，也未测量与 VLA/DNN 共置时的相互干扰——而这正是其动机场景。', '我在正文发现：正文未给代码或工件链接，实验集中在两种 NVIDIA GPU 与同一代 CUDA 生态，跨厂商或移动 GPU 的外推性未知。']

## 与文献库的关系
与 3DGS 的 tile-based 光栅器、Scaffold/Octree/Hier-3DGS 等「减少 Gaussian 数」的算法层优化、以及 Lee/Feng 等专用加速器路线相对；方法上借 persistent kernel（Gupta 等，以及 LLM 侧的 FlashAttention-3/FlashInfer/MPK）与 Flash-Decoding 的分块归约思想；直接对标并优于 CaT-GS 的均值阈值切分，也可与 SwiftGS、HiGS 叠加。
