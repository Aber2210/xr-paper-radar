# PhysForce：交互式视频世界模型的物理感知力控制

## 一句话结论
用结果不可知的力场编码替代轨迹先验，并把「力—响应」归因显式化为可复用区域监督再接到自监督 RL 奖励：OOD DCS 0.782 对 0.575、力定位 IoU 0.3956 对 SAM 的 0.2488。

## 要解决的问题
交互式视频世界模型需按施加力的位置、方向与幅值预测物理合理的状态变化，但现有方法用力轨迹表示会引入错误运动先验，内部表示无法可靠定位力引起的状态改变，且带力标注数据稀缺导致新场景泛化差。

## 方法详解
两阶段框架。SFT 阶段用 Latent Force Intervention Encoder 把力的位置、方向、幅值编码进视频潜空间且不暴露未来位移，再用 Physics Attribution Network 把力条件潜响应与时间差分对齐，定位响应区域。RL 阶段用 Physics-Aware RL，以 V-JEPA 自监督动力学先验构造归因引导的物理奖励，并加 Dynamic Gate 过滤静止或伪影等退化 rollout。

## 实验与结果
- OOD DCS = 0.782（Force Prompting 0.575）
- OOD MRR = 0.952（Force Prompting 0.810）
- ID GT80 DCS = 0.697（最强基线 0.464）
- ID ST-IoU = 0.332（最强基线 0.255）
- PAN 定位 IoU = 0.3956（SAM 0.2488，光流 0.0389）
- 去掉 OOD 数据后 OOD DCS 降至 0.622

## 创新点与贡献
- 用结果不可知的力场编码替代轨迹先验，并把力—响应归因显式化成可复用的区域监督，再接到自监督 RL 奖励上

## 局限与风险
- 只在二维视频潜空间建模，不显式表示深度、三维几何与出平面力
- 离线双向去噪使力条件无法在生成中更新
- 不显式约束动量守恒，多体碰撞仍出现提前传能
