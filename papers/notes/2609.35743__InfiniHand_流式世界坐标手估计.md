# InfiniHand：自中心视频的流式世界坐标手势运动估计

## 一句话结论
InfiniHand 是端到端流式前馈框架：直接从无标定自中心视频联合估计 MANO 参数、相机轨迹与手部位置，用持久时空记忆 + 以手为中心的视觉特征把相机运动与局部手几何耦合；约 5000 小时自中心数据预训练，ARCTIC PA-p 较 ViDiHand 降 21.4%，世界坐标漂移大幅缓解，11.19 FPS（吞吐 >2× HaWoR），野化泛化稳健。

## 要解决的问题
世界坐标手运动估计需同时恢复 3D 关节手与相机自运动；现有方法级联独立手姿态估计 + SLAM，误差累积、管线复杂、计算开销大。

## 方法详解
- 统一架构同时输出 MANO 参数、相机轨迹、手部位置；
- 持久时空记忆（persistent spatiotemporal memory）+ 以手为中心的视觉特征，显式耦合相机运动与局部手几何；
- 两阶段训练：先学稳健相机空间手先验，再扩到流式世界空间重建。

## 实验与结果
- 基准 ARCTIC / HOT3D / EgoDex / InterWild；世界坐标 W-MPJPE 达最低（如 ARCTIC 16.43、HOT3D 33.64 等），相机空间 PA-p 亦最低；
- ARCTIC PA-p 较 ViDiHand 降 21.4%；11.19 FPS，超 HaWoR 两倍以上吞吐。

## 创新点与贡献
单モデル流式世界坐标手 + 相机自运动联合估计；持久记忆机制；5000h 预训练；前馈无 SLAM 级联。

## 局限与风险
单目自中心（无立体），极端遮挡/快速运动待验；TRL=3。
