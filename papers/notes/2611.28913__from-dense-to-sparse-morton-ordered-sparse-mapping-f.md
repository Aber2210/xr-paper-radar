# 从稠密到稀疏：面向高效三维网格生成的 Morton 序稀疏映射

## 一句话结论
把稀疏 SDF 的离散 token 与可逆、offset 条件化的三维 BPE 结合，在序列化前按面邻接图合并不再依赖 1D 邻近：LLM 完整序列平均长度 6,873→3,753 token（−45.4%），Objaverse captioning METEOR 21.50 对 LEO 20.91。

## 要解决的问题
统一 3D 理解与生成需要一个既紧凑、又保留可解码空间结构的几何词表。稠密体素 token 数随分辨率立方增长，把编码限制在表面带虽降低了占用，却没有消除活跃位点之间的重复局部模式。1D 序列化会把空间邻居拆散，仅按序列邻近做压缩会漏掉三维重复结构。隐式坐标又把几何绑死在序列位置上，使变长 token 组合与可逆合并都变困难，而一个短序列只有在其 token 仍能指明几何位置与拼接方式时才有用。

## 方法详解
Sparse SDF VQ-VAE 在 R=256 的归一化 SDF 上取窄带输入（$\eta_w{=}4.0$、$\eta_e{=}0.5$），用 Direct3D-S2 的稀疏 3D U-Net 编码到 8× 下采样的 $32^3$ 潜网格、$C_z{=}16$，以 $K{=}8192$ 码本量化，得到显式坐标的近表面 leaf token 集合 $\mathcal{M}=\{(c_i,k_i)\}$。训练分两阶段：先冻结编解码器、用 EMA 与 K-means 重初始化只学码本，再联合微调；重建监督按 surface/feature/context 三类分层并按各自样本数归一化（$\lambda_{\mathrm{surf}}{=}\lambda_{\mathrm{feat}}{=}\lambda_{\mathrm{ctx}}{=}1$、$\lambda_c{=}0.25$），以防稀疏特征被规则表面样本淹没。3D-BPE 在 face-adjacency 图上以相对偏移学习可逆 merge，把反复出现的面邻接模式合成 macro token，且每个 macro 可精确展开回其 leaf token 与坐标，使压缩不依赖序列化的邻近性。随后按 Morton 序序列化，由同一个 Qwen3-4B LLM（词表新增 8192 distance、8192 macro、32768 Morton 坐标 token）读取几何做 captioning，或自回归预测 token 做 text-to-3D。生成侧先把预测的 macro 展开为 leaf 与块坐标，经 VQ-VAE 解出 sparse SDF，再由 Marching Cubes 直接出网格。LLM 训练两阶段：先冻结 VQ-VAE 与主干只训新嵌入与输出投影，再混合 UltraChat 全参微调以保留语言能力。

## 实验与结果
- LLM 完整序列平均长度 6,873.2 → 3,753.1 token（−45.4%），P95 14,675.1 → 8,483.2（−42.2%），统计于 43,180 条 text-to-3D 记录
- Objaverse captioning：METEOR 21.50 vs LEO 20.91；SimCSE 62.20 vs 最强基线 Qwen2.5-VL-7B 50.86
- text-to-3D：FD 23.7 vs ShapeLLM-Omni 25.9；KD 0.22 vs 0.25；CLIP 24.4 vs Morton 1D-BPE 23.4
- 3D-BPE 消融（Objaverse）：CLIP 22.1→23.4→24.4、FD 28.4→26.9→23.7（w/o BPE→Morton 1D→SPAC）
- 相对 Morton 1D-BPE：FLOPs 56,299.82→41,122.05 G（−27.0%），latency 262.93→171.69 s（−34.7%）
- 编码器 R=256 时 137.98 GFLOPs / 85.04 ms，vs ShapeLLM-Omni 稠密 41.38 TFLOPs / 4227.84 ms
- 等 8,192 merge 预算下序列长度比 0.754，低于 Morton 1D 0.803、Hilbert 1D 0.820、Random 1D 0.998
- 语言能力：MMLU 69.5、MMLU-Pro 47.9、GSM8K 86.1、BBH 73.4（BBH 由骨干 72.5 提升）

## 创新点与贡献
- 把稀疏 SDF 的离散 token 与可逆、offset 条件化的三维 BPE 结合，在序列化之前按面邻接图合并，使压缩不再依赖 1D 邻近
- macro token 能精确展开回 leaf token 与坐标，因此压缩不破坏坐标–码字映射，这一点区别于 Morton/Hilbert 序的 1D BPE 与基于八叉树的 Uni-3DAR 压缩
- 同时让理解与生成共享同一套稀疏词表，生成路径从 LLM 预测直通 Marching Cubes

## 局限与风险
- 只建模几何与文本，输出为无纹理网格，图像条件与表面外观需额外表征
- 细节上限由 SDF 分辨率、码本与解码器容量决定，薄结构与少见形状的 tokenization 仍待改进
- 近二次编码器扩展的结论依赖固定规则表面、固定体素带宽与局部邻域假设
- 训练覆盖仅 50k 网格，混用更大规模 2D–3D 数据与 4D 时序扩展均未验证
