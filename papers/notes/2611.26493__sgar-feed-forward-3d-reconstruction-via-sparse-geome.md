# SGAR：基于稀疏几何引导注意力的前馈三维重建

## 一句话结论
把前馈重建的稠密全局注意力换成「几何嵌入检索 + 块稀疏掩码」的稀疏注意力：1000 视图 26.1 s 对 DejaView 319.6 s（12.2×），AUC@30 仅降 1.9 点。

## 要解决的问题
前馈重建模型（VGGT、DejaView 及其后继）用一次前向就输出所有视图的相机、深度与点图，其核心是全局注意力：所有视图的 token 共同处理，任一视图都在其余视图的语境下被解释。这正是能力来源，也是代价来源——全局注意力开销随视图数二次增长。实测 DejaView 在 100 视图只需几秒，到 1,000 视图则达 319.6 s（单张 A100），VGGT-Ω 需 303.8 s 且显存 22.9 GiB；这直接把前馈模型挡在机器人导航这类时敏应用之外，也无法为优化式重建管线提供快速初始化。作者的关键观察是这份计算高度冗余：在 NRGBD 场景上对 DejaView 用真值几何挑 oracle top-k keys，即便把 99% 的注意力权重置零，大部分位姿精度仍能保留。已有加速工作却几乎都从「注意力本身的近似」出发——token 合并（FastVGGT、Co-Me）、把每视图压成少量描述子（FlashVGGT）、测试时训练蒸馏 KV 集（VGG-T³、ZipMap）、在粗分辨率上估注意力图只留最强块（Block-Sparse、SAF3R、AVGGT、Speed3R）。它们推断相关 key 的依据是注意力近似而非视图间的几何关系，而重建恰恰依赖后者，于是精度显著退化或长序列直接崩：1,000 视图下 FastVGGT 的 AUC@30 掉到 3.2、Co-Me 35.4、SAF3R 出现 kernel 编译错误、AVGGT 与 FlashVGGT 显存溢出、ZipMap 亦 OOM。本文因此换一个提问方式：从经典 SfM 视角看，除少数锚定全局坐标系的 token 外，一个 patch token 真正需要的 key，就是其它视图中观测同一 3D 表面区域的 token；key 选择因而等价于几何特征检索，可用真值几何直接监督，且求解时不必计算稠密注意力。

## 方法详解
记输入 V 图，每图 P 个 patch 加 1 相机 token 与 4 register token（合称 5V 个 special token），N=VP。几何嵌入：共享 block 在 frame attention 后带投影 W_adj∈R^{C×C}，输出去全样本均值 μ 后 L2 归一化 e_i=(W_adj x_i−μ)/‖W_adj x_i−μ‖，相似度即余弦，等价于学习度量下的归一化 Mahalanobis 内积；去均值避免共享分量主导。对比损失用多正例 InfoNCE：查询取 1024 个有真值的 patch，正例为其对应 patch，候选为其它视图全部 patch 但排除落在对应 patch 五邻域内却不对应者：L_con=−(1/(L|Q|))Σ_lΣ_i log[Σ_{P_i}e^{τ⟨e_i,e_j⟩}/Σ_{A_i}e^{τ⟨e_i,e_j⟩}]，τ 初值 20、上限 100，投影走 stop-gradient，只训 W_adj 与 τ。对应真值：i 的像素用 GT 深度反投影再投到 v，落在一像素内且深度差 <5%。选 key：用 k-means++ 播种的球面 k-means 把 {e_i} 聚成 M=√N 簇，每簇选质心最近的 m=4 簇（含自身），patch i 关注 I(i)={j:c(j)∈N(c(i))}；按簇而非按 patch 选，使同簇查询共享 key、得以 128 token 密块在 tensor core 上运行，聚类每层重做。稀疏注意力：special token 对全 VT 稠密；每 patch 由同一 (q,k,v) 算四项注意力、各 softmax 后求和过 W_o：x_i←x_i+W_oΣ_{K∈{S,R,M(i),I(i)}}softmax(q_i^Tk_j/√D+b_j)v_j，M(i) 为其余簇摘要。每 patch 平均关注 5V+P+5√N 个 key，复杂度由 O((VT)²D) 降为 O(N(V+P+√N)D)，k-means 每轮 O(N^1.5C)；1,000 视图×972 patch 时约 11,000 个 key（约 1%）。训练：从 DejaView 或 VGGT-Ω 微调，新增参数仅 W_adj 与 τ；L=L_recon+λ_con L_con（λ=1）；18 个公开数据集，V=2~32 视图，预训练权重 lr 1e−5、新参数 1e−4，AdamW、4×H100、50k 步。

## 实验与结果
- 1,000 视图 ScanNet 长序列（scene0770_00，3,383 帧）：SGAR(DejaView) 26.1 s vs DejaView 319.6 s，加速 12.2×，AUC@30 84.6 vs 86.5
- SGAR(VGGT-Ω) 40.5 s vs 303.8 s，加速 7.5×，AUC@30 83.5 vs 85.3
- 稀疏度：1,000 视图×972 patch 下，每个 patch 平均只关注约 11,000 个 key，约为总 token 的 1%（5V special + P 参考 + 5√N），取代了 VT 的全量
- 复杂度：全局注意力由 O((VT)²D) 降至 O(N(V+P+√N)D)，每轮球面 k-means 为 O(N^1.5 C)，故随视图数近线性增长
- 固定时间预算的几何完整度（ScanNet，coverage@5cm）：1 s 预算下 SGAR(VGGT-Ω) 80.7%、SGAR(DejaView) 77.3%，对 VGGT-Ω 71.0%、DejaView 73.8%
- 20 s 预算下 95.9%/94.1%，对 92.4%/91.3%
- 短序列 K=100：平均 AUC@30 SGAR(VGGT-Ω) 81.2 对 VGGT-Ω 84.2，耗时 1.65 s vs 2.27 s
- SGAR(DejaView) 78.2 对 82.3，耗时 1.32 s vs 2.10 s，为所有高效方法中最准
- 深度（7-Scenes/LaMAR/NRGBD 等权，δ1.25）：SGAR(VGGT-Ω) 96.5 与 VGGT-Ω 96.4 基本持平（7-Scenes 98.4、LaMAR 91.1、NRGBD 99.9），是高效方法中最优
- SGAR(DejaView) 91.3 略低于其稠密版本 94.8
- 消融（DejaView，K=100 与 1,000 视图的 AUC@30）：稠密 82.3/86.5、per-query top-256 检索 68.8/75.1、在原始 token 上 k-means 65.3/71.9、去掉参考视图 R 74.1/84.7、去掉簇摘要 M(i) 76.3/83.5、两者都去掉 65.1/79.2、完整 78.2/84.6
- 两项粗粒度 key 集合计只增 5–9% 时间
- 其它高效方法在 1,000 视图集体失效：FastVGGT AUC@30 仅 3.2（257.0 s）、Co-Me 35.4（203.4 s）、ZipMap / FlashVGGT / AVGGT / Block-Sparse 显存溢出、SAF3R kernel 编译失败

## 创新点与贡献
- 把「全局注意力的 key 选择」重构为几何特征检索问题：从经典 SfM 的「视图由稀疏 2D 对应关联」出发，论证所需 key 就是观测同一 3D 表面的 patch，从而可用真值几何直接监督，无需近似注意力图。
- 提出用对比学习得到的几何嵌入 + 球面 k-means 聚类来做 key 选择：以多正例 InfoNCE 训练 W_adj，使同表面 patch 在嵌入空间靠近，再以 M=√N 簇、每簇探 m=4 近邻簇的方式把选择做成块稀疏掩码，天然适配 tensor core。
- 四项分解式稀疏注意力：special token 全局稠密 + 参考视图全 patch + 最近簇全 patch + 其余簇摘要，既保住全局坐标系锚定，又把复杂度压到近线性，并给出每个 patch 的 key 数上界 5V+P+5√N。
- 方法具有模型无关性：仅新增一个投影与一个温度，即可把 DejaView（117M）与 VGGT-Ω（1144M）两种规模/设计的稠密模型微调成稀疏版本，二者均取得高效方法中的最优精度。
- 提出「固定时间预算下的重建完整度」评测口径，把加速比直接换算成同等时间内可覆盖的场景面积，证明速度红利可转化为几何完整度。

## 局限与风险
- 作者自述：稀疏化相对稠密注意力仍有小幅精度下降，缩小这一差距是后续方向
- 代码与模型尚未发布
- 从实验设计看还有几点：其一，聚类每层重做且 M=√N 随 N 增长，k-means 的 O(N^1.5 C) 在极大视图数下会成为新瓶颈，论文只测到 1,000 视图，未给出更远处的拐点
- 其二，方法依赖从稠密模型微调，等于继承了原模型的训练数据分布与偏置，冷启动（无合适稠密底座）时是否仍成立未验证
- 其三，几何嵌入的监督需要真值深度/位姿来构造 patch 对应，训练数据门槛高，且 5% 深度一致阈值与「五 patch 邻域排除」都是手工设定，对深度噪声大的数据集可能敏感
- 其四，评测集中于位姿/深度/覆盖率，缺少下游任务（如导航、抓取）验证，也缺少与回环/全局优化结合后的表现
- 其五，固定预算实验只在一个 ScanNet 场景上做，单场景结论的统计强度有限
- 其六，SGAR(VGGT-Ω) 在 LaMAR 的深度从 91.8 降到 91.1、在 Mip360 与短序列均有 1–3 点 AUC 损失，说明在视野分散、重叠弱的照片集上稀疏假设（同表面 patch 聚成簇）更容易失效
