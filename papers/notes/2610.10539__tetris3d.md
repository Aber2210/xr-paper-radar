# Tetris3D：物体严丝合缝的 3D 场景生成

## 一句话总结
一个物体中心 3D 场景生成框架：显式把每个物体的生成条件于"邻近几何 + 物理关系"，并用 VLM 推断依赖顺序自回归生成，产出几何与物理都严丝合缝的场景。

## 问题背景
- 单图 3D 场景生成常独立生成物体或隐式耦合，缺乏对相邻物体细粒度空间兼容的引导 → 穿透、不稳定等物理无效配置。

## 方法
- **Pose-Aligned 物体生成**：从深度图定义物体网格，沿相机射线把图像特征反投影进网格，直接在场景空间（输入相机坐标系）生成位姿对齐的形状（免去单独位姿估计/后对齐）。
- **Object Interaction-Aware**：空间上下文（邻物几何排布，避免穿透）+ 关系类型（目标与邻物物理关系）双重条件。
- **V2I（Visible-to-Invisible）交叉注意力**：用可见令牌聚合信息补全被遮挡区域。
- **ComOb**：基于仿真的大规模场景数据集，含物理稳定配置与交互标注。
- **推理**：VLM 推断物理依赖顺序，按依赖自回归生成（先生成所依赖的邻物）。

## 实验与结果（关键数字）
- 训练物体源与 Toys4K 不交叠；用 ComOb 组合评估场景（均给真值深度）。
- 真实/接触丰富场景：Picasso、MessyKitchens（用 MoGe3 估计深度 + VLM 推断关系）。
- 三视角评估：场景级质量（CD-S/F1-S/IoU-B）、物体级质量、物理稳定性（穿透深度 PD、峰值动能 E_peak，在物理引擎中仿真是否掉落/漂移）。
- 对比 SAM-3D / ShapeR / WorldSculpt / SceneMaker / SceneGen / MIDI / Amodal3R+FoundationPose：在重建质量与物理一致性上改善。

## 贡献与局限
- 贡献：把"物理/几何兼容"显式做成生成条件；提出 ComOb 仿真数据集与 V2I 遮挡补全；自回归依赖顺序生成。
- 局限：依赖深度估计与 VLM 关系推断质量；复杂多物体长程依赖仍挑战。
