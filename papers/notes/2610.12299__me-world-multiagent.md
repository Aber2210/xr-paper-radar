# Multi-Agent Egocentric World Model：细粒度具身交互的多智能体第一视角世界模型

## 一句话结论
ME-World 将多智能体第一视角世界模型建模为共享世界中多 agent 经细粒度动作交互的同步 ego-stream 生成，联合去噪多流、共享环境记忆，提升共享世界一致性/动作控制/视频质量。

## 要解决的问题
现有第一视角世界模型多为单 agent；多 agent 世界模型只用粗粒度动作（移动/相机/离散指令），细粒度具身交互未充分探索；需跨视图动作一致性、共享环境一致性、交互引发状态更新的传播。

## 方法详解
在共享 token 序列联合去噪多 ego 流；每流条件于所有 agent 的目标视角位姿；共享环境记忆（SEM）grounding 生成。基于 Cosmos-Predict2.5 2B 微调 DiT（冻结 VAE/文本编码器，rectified-flow，A100×4 训练，35 步推理、CFG 7.0）。

## 实验与结果
真实+合成多 agent 数据；提出共享世界一致性指标（环境/更新/身份一致性）；对比多视图视频生成（GEN3C/AnyView-DVS）、单 ego 世界模型（EgoSim/JointControlVideo）、通用世界模型（DreamX-World/LingBot-World）及多 agent 基线（MultiWorld/Solaris/γ-World/MetaWorld）。ME-World 全部指标最优；消融：SEM + Joint Gen + Shared Action 逐步提升（Senv 0.456）。

## 创新点与贡献
细粒度具身交互的多 agent 第一视角世界模型；共享环境记忆；新一致性指标。

## 局限与风险
基于扩散 Transformer，算力重；真实数据规模有限；交互种类受数据集约束。
