# HAP：手往哪儿去，头就往哪儿转——把这件事建模出来

## 一句话结论

把**未来 6-DoF 头动预测**形式化为"以观测到的手部运动与推断的目标上下文为条件"的主动感知问题，提出 HAP：先从手部运动与物体几何推断各候选目标的置信度，构建动态的 **P-TAOG（Predictive Target-Centric Amodal Occlusion Graph，预测性以目标为中心的非模态遮挡图）** 表达候选目标间当前与潜在的遮挡关系，用有向图 + 因果时序推理编码演化的感知状态，最后用 horizon-wise gate 把学习到的轨迹与常速先验混合。同时发布 **Bottle**——一个带协调头手运动、目标可见性变化的面向目标操作的第一人称 RGB-D 数据集。

## 要解决的问题

第一人称运动预测的研究重心长期在**手**与**被操作物体**上，**未来头动**被相对忽视。但头动不是手轨迹的副产品：

- 操作过程中，头会**主动重新朝向目标**以获取任务相关的视觉证据
- 头同时与身体、手部运动协调

因此这是一个**独特的主动感知问题**，而非手轨迹预测的二阶推论。作者明确指出：即便是联合建模手与头动的 Uni-Hand，也**没有显式建模"指向目标的感知需求"作为未来头动的驱动因素**。

**为什么这件事对 XR 重要**：头动直接决定**未来会获取到哪些任务相关的视觉证据**。能预测头动 = 能预取视口 = 直接影响注视点渲染、带宽调度、内容预加载的预算。

## 方法详解

### 问题形式化

用刚性安装的第一人称 RGB-D 相机姿态表示头动。`T_t ∈ SE(3)` 为时刻 t 的相机姿态，目标是预测到未来各步的**相对头动**：

```
ΔT_{t,h} = T_t^{-1} T_{t+h},   h = 1, …, H
```

每个相对变换用平移 `p_{t,h} ∈ ℝ³` 与 **6D 旋转向量** `θ_{t,h} ∈ ℝ⁶` 表示：

```
θ_{t,h} = [ (r_{t,h}^{(1)})ᵀ, (r_{t,h}^{(2)})ᵀ ]ᵀ ∈ ℝ⁶
y_{t,h} = [ p_{t,h}ᵀ, θ_{t,h}ᵀ ]ᵀ ∈ ℝ⁹
```

6D 旋转表示经正交化转为合法旋转矩阵。

**基础特征** `b_τ`（每个观测时刻 τ 的协调手头运动）：

```
b_τ = [ h_τ, h_τ − h_{τ−1}, ρ(T_{τ−1}^{-1} T_τ) ] ∈ ℝ¹⁵
```

其中 `h_τ ∈ ℝ³` 为重建的手部位置，ρ(·) 施加式(2) 的平移与 6D 旋转表示。每个片段首帧，相对头动初始化为单位、手部位移置零。

### 三个核心模块

**① 手部驱动的目标意图估计（Hand-Driven Target Intention Estimation）**
从观测的手部运动与目标物体几何推断每个候选目标的置信度。保留**接触前候选目标之间的歧义**（此时手部轨迹仍与多个物体相容），而不是过早做硬指派。

**② 动态 P-TAOG 构建**
为每个候选目标，用 SAM 3D Objects 的 Stage 1（首帧 RGB + 物体 mask 输入，4 次去噪）得到补全的稀疏点集；每帧把最多 **1,024 个点**变换到当前相机坐标系，以 4 像素半径光栅化，估计可见性并构建**动态非模态遮挡图**。

**③ 有向图 + 因果时序推理 + horizon-wise gate**
- 有向图编码候选目标间的遮挡关系
- 因果时序推理编码"以目标为条件"的演化感知状态
- 与手、头运动历史融合
- **horizon-wise gate** 决定每个预测步应多大程度**偏离常速先验**

### 实现细节

| 组件 | 选择 |
|---|---|
| 相机轨迹估计 | Depth Anything 3（DA3），平滑后作为头动的可观测代理 |
| 物体检测与跟踪 | YOLO11 + SAM 2 |
| 3D 手部位置 | WiLoR 关键点 + 对齐深度 |
| 目标意图估计器 | 在 curated EgoPAT3Dv2 片段上预训练，Bottle 实验中固定 |
| 训练 | 20 epochs，AdamW，batch 64，lr 1e-3，weight decay 3e-4，rotation loss weight 0.25 |

## 实验与结果

**评测**：公开数据集 + 自建 **Bottle**（第一人称 RGB-D，面向指定目标的操作，含协调的头手运动与目标可见性变化）。

**主要结论**
- HAP 在公开数据集与 Bottle 上均取得**低于代表性基线的头动预测误差**
- 基线覆盖状态空间、循环、变分、注意力与扩散五类形式；CVH 为外推观测轨迹平均速度的基线

**消融要点**

| 发现 | 解读 |
|---|---|
| **gated P-TAOG 优于 Motion Gated Direct**（平移与旋转的平均与最终误差） | 遮挡图 + 门控有效 |
| **未加 gate 的版本反而落后于纯运动模型** | **gate 是决定性的**——它控制每步应多大程度偏离常速先验 |
| 保留候选目标歧义优于硬指派 | 接触前的**不确定性本身携带有用信息** |
| 目标意图估计器（仅用接触前观测前缀）在 curated EgoPAT3Dv2 验证集上 **top-1 准确率 92.79%** | 观测到的手部状态与手-物几何中**确实包含关于交互目标的先行信息** |

> 最后一条是本文最有价值的发现：**在手接触目标之前，仅凭手部状态与几何就能以 92.79% 的准确率预测目标**——这为所有需要"提前预判用户意图"的 XR 系统（预加载、预渲染、主动提示）提供了可行性证据。

## 创新点与贡献

1. **把头动预测确立为独立问题**：明确论证它不是手轨迹预测的副产品，而是主动感知问题。
2. **P-TAOG**：用非模态（amodal）遮挡图表达"当前与潜在"的遮挡关系，是对可见性/遮挡的动态结构化建模。
3. **Bottle 数据集**：填补"面向指定目标的操作 + 协调头手运动 + 变化的目标可见性"这一数据空白。
4. **horizon-wise gate 的关键性**：消融证明去掉 gate 会不如纯运动基线——这是一个反直觉但重要的工程发现。

## 局限与风险

- **增益幅度未充分量化**：文中表述为"lower errors than representative baselines"，但摘要与正文均**未给出相对基线的具体百分比**，难以判断改进幅度是否实用。
- **无系统级验证**：论文停留在"预测更准"，**未验证其下游收益**——即更准的头动预测究竟能省多少带宽/算力。这是从算法到 XR 系统落地之间缺失的一环。
- 头动由 DA3 估计的相机轨迹代理，估计误差会传导到训练与评测。
- 代码尚未发布。

## 行动建议

1. **XR 系统团队应重点跟踪**：头动预测是注视点渲染、视口预取、云渲染带宽调度的直接输入。92.79% 的接触前目标准确率意味着**预取窗口可以显著提前**。
2. **补齐缺失的一环**：本文最大的空白是"更准的预测 → 省了多少带宽/算力"。谁先做出这个系统级量化，谁就把这篇算法论文变成了可落地的 XR 技术。
3. **horizon-wise gate 的教训要记住**："学习轨迹 + 常速先验混合"的门控设计，其收益可能大于复杂的图结构本身。做时间序列预测时应先验证这类简单基线的门控是否到位。
