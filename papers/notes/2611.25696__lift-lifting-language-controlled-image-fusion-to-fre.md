# LIFT：将语言控制图像融合提升到自由视角三维场景

## 一句话结论
把语言控制图像融合从 2D 抬到自由视点 3D 场景：PSNR 13.54 对 ReCoFuse 11.98，重投影 MAE 降约 80%，跨视角一致。

## 要解决的问题
多模态图像融合（MMIF）长期在二维空间定义：给一对已配准的可见光/红外图像，输出单张融合图。这种 2D-IF 范式有三重结构性缺陷。第一，融合结果绑定在拍摄视角的像素排布上，遮挡面、视场外区域、物体背面全无表示，无法把场景当整体感知。第二，扩展到多个离散视角也不成立：各视角独立融合的图像之间没有显式空间联系，形不成统一表示，且新视角上拿不到成对源观测。第三，最直接的替代方案「先用 3DGS 从任意视角渲染各模态图像、再套 2D 融合」仍是逐视角独立融合，信息没进三维表示，同一区域在不同视角会出现不一致与 ghosting。更深一层是任务适配：同一场景在不同意图下需要的模态配比不同——机器人清洗锅时可见光更能看出残留污渍，用同一口锅烹饪时红外更能反映温度分布；固定融合比例无法覆盖多样感知目标，而语言是表达这种高层意图最自然的接口。要把融合搬进三维并接受语言控制（L3D-IF），有两个硬挑战：语言描述语义目标与其期望外观，三维场景却是一堆没有语义对应的空间原语，必须建立跨视角持久的语义-空间对应；即使目标找对，随视角变化可见部分与各模态可用信息都在变，期望外观不一定能保持，且不同指令、视角下没有参考渲染图可监督。

## 方法详解
底座沿用 ThermalGaussian 的 OMMG：N 个原语共享中心 μ_i、协方差 Σ_i 与不透明度 o_i∈[0,1]，可见与红外各有一套三阶球谐 H_i^vis,H_i^ir∈R^{16×3}。给定已配准 (V_j,I_j,C_j)，先以 RGB 拟合几何、不透明度与可见 SH（含致密化与剪枝），再固定几何拟合红外 SH，两阶段均用 L1+SSIM。视方向 v_i(C)=(μ_i−o_C)/‖μ_i−o_C‖，按 0.5 偏移与非负截断求 SH 得 c_i^vis、c_i^ir；两模态共享几何贡献 ρ_i^C(p)（投影 alpha × 前序透射率）。语义场：每个 Gaussian 带 512 维可学特征 f_i，冻结 CLIP 给单位化短语嵌入 e(t)，CLIPSeg 给短语条件概率 S_j(p;t)（有标注处替换）。响应 q_i(t)=σ[τ(f_i^T e(t)/max(‖f_i‖,ε_f)−b)]，τ=clip_{[5,80]}(e^ℓ)，ℓ 与 b 可学。把特征与响应按覆盖度 A_j(p)=Σρ_i^{C_j}(p) 投影回训练视图得 F̂_j、Ŝ_j，用置信度加权 BCE 与 MSE 监督 f_i 与 ℓ,b；同一组特征被多视图共同约束，语义证据沉淀到共享三维表示。可选证据缓存按 ν_i=Σ_jΣ_p ρ_i^{C_j}(p) 聚合 CLIPSeg 概率为 q_i^ev(t)，对蒸馏查询在未观测 Gaussian 上置零；融合用连续分数，仅做目标投影时取 q_i^eff≥0.5 并保留原不透明度。SMB：输入冻结 CLIP 指令 token 与最多 128 个采样语义特征，经投影与类型嵌入进 Transformer 编解码；K=4 个 query 预测有序的（短语, 红外比例）槽 (t_k,a_k)，第 5 个预测默认比例 d，模式头区分可见（a_k=0）、红外（a_k=1）、混合与非激活，span 头切短语，数值指针绑定百分比，query 均值给 LCGA 的条件 z(u)∈R^{256}。区域赋值按序凸更新 w_i^(k)=(1−q_ik)w_i^(k−1)+q_ik a_k，初值 w_i^(0)=d，保证 w∈[0,1]，后序规则仅在语义支撑为 1 时完全覆盖，支撑缺失处退回默认比例。LCGA：把 f_i 的 64 维投影与 z(u) 经 FiLM 调制后过 MLP，预测残差 A_i(u)∈R^{3×4}，缩放 tanh 限在 ±0.05，输出层零初始化；方向编码 ψ(v)=[1,v_x,v_y,v_z]^T；门控 g(w)=4w(1−w) 在端点归零以保源色。最终 c_i^{u,C}=[(1−w_i)c_i^vis+w_i c_i^ir+g(w_i)A_i(u)ψ(v)]_+，再以共享 ρ_i^C 泼溅得 ξ̂(u,C)。MVLS：15 个场景、79,854 个指令-图像-相机三元组、1,526 个标定视角、32,414 个视图-规则实例。目标离线合成：对 CLIPSeg 概率图套用有序规则得参考权重 w̃，再按五种细节策略 D_{n,m}（线性、多尺度活性、最大细节、加权增强、CDDFuse 引导）合成 T=Clamp[(1−w̃)⊙V+w̃⊙I+g(w̃)⊙D]，每场景用训练视图选一种并跨划分固定。训练 L_joint=E[L_app+λ1L_grad+λ2L_SMB+λ3L_res]，前两项为置信度加权 L1（分母分别 3 与 6 倍置信像素量），λ1=0.2、λ2=0.05、λ3=0.001；场景与编码器冻结，逐场景独立拟合。

## 实验与结果
- 15 个场景 217 个视角的定量对比（等比例 RGB-IR 指令）：MSE 0.049、PSNR 13.542 dB、CC 0.524，对比最强 2D 方法 ReCoFuse 0.072 / 11.979 / 0.513，以及 3DGS+CrossFuse 0.076 / 11.670 / 0.386
- 跨视角一致性：Reproj. MAE 在三个场景的目标/背景区均低于 2D teacher——Building 0.015 / 0.023 对 0.077 / 0.202，Lion 0.026 / 0.022 对 0.093 / 0.047，Pan 0.033 / 0.027 对 0.082 / 0.049
- 区域控制精度：Pan 场景目标区 Regional MAE 0.232，优于 2D teacher 的 0.454
- 但 Building 场景 0.267 反而差于 teacher 的 0.183，说明边界处多 Gaussian 混合带来投影偏差
- 遮挡下的语义记忆（58 个含遮挡测试视角）：Recall 89.576、Precision 21.641、IoU 19.616，对比 Grounding DINO-T 84.213 / 16.840 / 15.594、OWLv2 62.494 / 22.226 / 19.359、CLIPSeg 16.021 / 21.609 / 8.380
- 消融（217 视角）：完整模型 13.542 dB
- 去掉 SMB 场景记忆（Model I）13.377、去掉 LCGA 语言条件（A_i≡0.05，Model II）骤降到 4.261 dB / CC 0.117、把 MVLS 换成纯 CDDFuse 监督（Model III）12.858 / CC 0.522
- 数据集规模：MVLS 含 79,854 个三元组、15 个场景、1,526 个标定视角、32,414 个视图-规则实例，五种融合目标合成策略
- 语言控制的端点保持：门控 g(w)=4w(1−w) 在 w=0/1 时为 0，残差消失，纯可见/纯红外端点严格回退源色
- 残差限幅 ±0.05，避免语言条件改写源辐射

## 创新点与贡献
- 提出 L3D-IF 新任务并把融合从逐视角 2D 输出搬进统一三维高斯表示：模态权重挂在 Gaussian 原语上而非像素上，因此天然跨视角持久。
- SMB 把语言指令解码成有序的（语义短语, 红外比例）规则槽，再用凸更新逐条覆盖到 Gaussian 权重，使重叠指令有确定的优先级语义。
- LCGA 用门控残差把源色混合与语言/视角条件修正解耦：门控在端点归零保证保真，±0.05 限幅保证不篡改源辐射。
- 构建 MVLS：用有序规则加五种细节策略离线合成指令相关目标，解决不同指令/视角没有参考渲染的监督缺口。
- 语义场与几何共享同一套投影覆盖度，使被完全遮挡的物体仍可定位，把 3D 表示变成跨视角的语义记忆。

## 局限与风险
- 论文未设独立局限章节，只在方法里承认：不确定的语义支撑会阻止权重到达精确模态端点
- 多 Gaussian 共同贡献像素使投影权重在区域边界有偏差（Building 目标区 MAE 0.267 确实差于 teacher 的 0.183）
- 从实验设计看：融合目标 T 是离线用 CLIPSeg 加五种手工策略合成的，不是真实偏好或任务真值，模型上限被教师与策略锁死
- 监督本身来自 2D 语义模型，训练场景外的新类别短语（OOD 语义）未评估
- PSNR 仅 13.5 dB，且指标以通用重建指标为主，与融合文献惯用的信息量指标不完全可比
- 只在 15 个 RGB-T 静态场景（建筑、雕像、锅具）验证，无动态、无夜间行人等安全关键场景，也无下游任务收益
- 每场景独立拟合、需多视标定采集，部署成本高
- 未给代码与数据下载地址
