# HandRSI：手部姿态估计的递归自我改进

## 一句话结论
编码 agent 递归改写推理 harness 并按信息源蒸馏回网络，配合十指标无回退门，HOT3D MPJPE-p 12.97→8.37 mm（−35%）、jitter −52%。

## 要解决的问题
第一人称 3D 手部姿态估计在图像边界漏手、遮挡时深度错位、指尖抖动，现有做法靠手写推理后处理（harness）加网络微调两步修补，但两步分别调参且彼此耦合：网络一旦更新，原有修正可能冗余甚至有害。3D 感知的质量又是多维的（检测、3D 位姿、2D 对齐、放置、平滑度互相 trade-off），只对一个指标设门会放进损害其他维度的改动。作者要回答的是：能否让编码 agent 递归地同时改进 harness 与网络，而每次改动都不牺牲任何一项指标。

## 方法详解
系统被定义为估计器 theta 与可执行推理 harness H^I 的组合 S=(theta, H^I)；harness 是一串只读预测、帧与内参、绝不接触 GT 的确定性模块，每个模块只看一个 81 帧片段。Loop A 让 8 个编码 agent（4 个 Claude Opus 5.5/Claude Code、4 个 GPT-6-sol/Codex）并行改 harness 四小时，各领一个方向：检测、root 放置、朝向、手指、图像证据、时序、2D 关键点、出画手。提交先在 dev 免费预检，再在 val 上过 G_A=G_0.3%：十个指标（七个误差列加 FAcc/Recall/F1）逐项算相对改进并 clip 到 ±5%，取均值得 Delta，要求 90% paired bootstrap 下界 L_Delta>0、Delta 不小于阈值，且任何指标不得在显著时退化超过 2%、无条件退化超过 5%。通过的模块在 dev 上按 val 增益贪心合并，集成 agent 消解重叠，再用一次 val 比较在最佳提交、贪心合并与集成链之间选出 H^{I,star}。Loop B 把 GT 微调后的网络 C^1 加精炼 harness 当作教师，按信息源拆分监督：3D GT 监督 2D、腕相对、root、朝向与存在性，教师只在无 GT 帧与无标注视频上监督存在性与时序（关节速度与加速度的 Huber，delta=5 mm）。学生只训 rank-32 LoRA（DiT block）与预测头，lambda_GT=2、lambda_KD=0.25、lambda_e=0.5、lambda_R=0.25，lr 1e-4、LoRA+ 比例 4、batch 8 个 85 帧窗口、500 或 2,000 步，过了网络门 G_B 才替换 theta。随后在 dev 上对每个 harness 模块做 leave-one-out 成对消融，把冗余、显著有害或使单条录制 EPE 恶化两倍以上的模块联合剔除，再过回合门 G_1%。Loop C 由规划 agent 读取档案（门结果、val 聚合、dev 诊断与全部提交，永不见 test）产出下一轮 guidance 与至多两个白名单 Loop B 设置。最后在 val 上搜索 harness 子链，用 (log FPS, Delta) 上的 epsilon-dominance 与 hypervolume 选出 Lite/Medium/Heavy 三个嵌套部署档。

## 实验与结果
- HOT3D 上 MPJPE-p 从 ACE-Ego-Hand 的 12.97 mm 降到 8.37 mm（-35%），ARCTIC 留出 subject s05 上 15.58→13.85 mm（-11%）
- jitter 分别 2.82→1.34 与 2.58→1.45 mm/frame^2（-52% 与 -44%）
- 相对在相同 GT 上微调的 ACE-Ego-Hand（C^1，HOT3D MPJPE-p 9.91 mm），HandRSI 再降 MPJPE-p 16%、EPE 2D-p 27%、jitter 51%
- 对九个复跑的已发表方法（WiLoR、HaWoR、EgoForce、HaMeR、Hamba、WildHands、InterWild、OmniHands 与 ACE-Ego-Hand），在 HOT3D 与 ARCTIC 的全部十个指标上均为最优
- HOT3D 上 FAcc 0.982、Recall 0.996、MPJPE-p 8.37 mm、EPE 2D-p 4.07 px、CT-p 0.013 m
- 三个部署档 Lite/Medium/Heavy 分别为 41.1/34.0/20.7 FPS（HOT3D MPJPE-p 9.06/9.04/8.41 mm），Lite 只比网络本身慢约 4%，仍全面优于所有已发表方法
- 零样本 HOI4D（498 段）上 3D 位姿类指标最低（MPJPE-p 22.77 mm、jitter 1.01 对比 ACE 的 2.10），但 2D 误差 18.61 px、CT-p 0.064 m 落后于 ACE-Ego-Hand
- 五轮共 156 次提交、73 次通过 G_A
- 蒸馏在第 2 轮后饱和，第 3 至 5 轮所有学生都以 1.7%–9.3% 的 2D/朝向/召回损失换 1%–3% 的 jitter，Delta 转负（-0.8% 至 -2.7%）

## 创新点与贡献
- 把「编码 agent 改 harness、按信息源蒸馏进网络、网络更新后重验 harness」做成闭环，并用十指标 no-regression 门把多维 3D 感知的质量约束进搜索，避免单指标门控引入的 trade-off
- 首次把 harness 优化从「产出文本或程序」搬到度量 3D 感知上，并显式区分「harness 带来的增益」与「蒸馏进权重的增益」，配合逐轮 GT-only 与 harness-only 控制把两者拆开
- 除了精度，还给出超参数量与速度分档、以及可复现的评测器与结果文件

## 局限与风险
- 蒸馏在第 2 轮后饱和：后续十二个学生 checkpoint 都以 1.7%–9.3% 的 2D/朝向/召回损失换 1%–3% 的 jitter，Delta 转负，作者归因为 LoRA 预算下 harness 仍能提供的放置与关节拟合无法被学生吸收
- 第 1 至 2 轮操作者曾参考 test 分数做三个决定（Loop B 配方与两条门规则），第 1 轮还在 HOT3D FAcc r=-5.6% 超过 5% 上限时被人工接受，test 并非完全隔离
- 评测器是作者按 ACE-Ego-Hand 附录重写的（官方未公开），EPE 2D-p 因 miss 罚则定义不同而有偏差
- HOI4D 上 2D、放置与检测仍落后于基线，增益主要来自 HOT3D/ARCTIC 相机
