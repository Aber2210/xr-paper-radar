# TOMAS：面向自我中心手部预测的拓扑感知操作建模与自适应阶段划分

## 一句话结论
把「物体」与「操作」因式分解推理、再做有序自适应阶段与阶段级几何子目标，三个基准七配置 ADE 最优，领先 Uni-Hand 7%–23%。

## 要解决的问题
从自我中心视频预测未来手部运动是理解人类意图与手物交互的基础能力，但观测到的运动并不能唯一确定手将往哪里去：同一个物体可以支持抓取、推动、拉取等不同操作，每种操作对应不同的手部构型与未来路径；即使交互目标已知，不同操作的时序长度与中间空间约束也不同（抓取需要接触前的预备调整，推动可能是更直接的接近加持续位移）。既有方法各推进一面——OCT 联合预测手部轨迹与交互热点、USST 引入不确定性感知的状态转移、Diff-IP2D 用扩散建模手物交互、MADiff 引入运动感知的状态空间建模、Uni-Hand 统一多模态/多空间表示——但“要执行哪种操作”始终隐式地留在预测过程之外：条件化往往依赖单一全局运动表示，无法表达同一物体下的多操作分支；也缺少对操作内部时序组织（阶段数与时长不均）与阶段级几何目标的显式建模。作者把问题拆成三个相连挑战：交互歧义（手部运动与物体外观必须联合判别目标与操作）、时间演化（操作是分阶段的进程而非单一运动状态）、空间实现（不同阶段需要不同中间几何目标，端点相近的轨迹可以走完全不同的路径）。

## 方法详解
问题设定：给定自我中心视频 I^p 与历史手心轨迹 H^p，构造观测上下文 X，含 21 个手关节 J^p（H2O 用官方标注，EgoPAT3D-DT/EGTEA 用 Uni-Hand/ViTPose 流程估计）、相机运动 E^p、候选物体轨迹 O^p，输出 d∈{2,3} 维未来手心轨迹 Ĥ^f。模块一，拓扑感知手物联合推理：关节构成解剖图 G=(V,E_G)，逐关节编码 root-relative 位置、时间位移、骨段位移与骨段时序变化，图传播捕捉解剖依赖、时序聚合刻画与手心运动解耦的手指构型演化；候选物体由 CLIP 语义、Mask R-CNN 提议、ConvNeXt 帧级 RGB、分割掩码与运动线索编码，每个候选 o_i 与手相对的空间/时间特征拼成 object token z_i^obj 与 relation token z_i^rel，query q_i=E_o(z_i^obj,z_i^rel) 对记忆 M（手心、拓扑、自运动、RGB 四流）做 CrossAttn，得 z̃_i^int=q_i+CrossAttn(q_i,M,M)，并设可学习 null 选项表示“没有合适候选”，使不同候选能在同一场景内各自强调不同的时间与模态证据。模块二，联合物体-操作推理：两个头分别估计 p_i=P(o_i|X) 与 q_{k|i}=P(a_k|o_i,X)，联合分布按 P(o_i,a_k|X)=p_i·q_{k|i} 因式分解，既表达候选目标之间的竞争，也表达同一物体上的多种隐操作；取高分的物体-操作对编码为交互条件 token c_ik，每个 c_ik 定义一个独立的未来轨迹生成条件。模块三，交互条件自适应阶段：用 c_ik 初始化未来运动特征并注入观测运动学与自运动，接 MADiff 式 Mamba 时序骨干做长程状态传播，得 f_{ik,t}；由条件化 stage query 预测正时长分数 ρ_s^ik，归一化 Δ_s=ρ_s/Σρ_r，累积得有序切换位置 β_s=Σ_{r≤s}Δ_r，再由此构造可微 stage 权重 α_{t,s}（非负、对 s 求和为 1、在边界附近平滑重叠），未来表示 z_t^stage=Σ_s α_{t,s} z_s。该累积参数化显式保持阶段顺序，区别于无约束 softmax 时间注意。模块四，阶段级几何子目标与轨迹生成：g_s^ik=a_i+G_sub(z_s^ik,π_s^ik,z_i^rel,c_ik)，以观测候选锚点 a_i 为原点输出相对偏移，π_s^ik 描述阶段内隐操作分量的混合；条件残差细化 f̃_{ik,t}=f_{ik,t}+Σ_s α_{t,s} R_s(f_{ik,t},g_s^ik,π_s^ik,c_ik)，最后经层级解码器在运动学初始化上回归，ĥ_t=h_t^init+D_traj(f̃)，因此子目标给的是连续几何引导而非硬性必经路点。训练：L_motion=L_traj+λ_tail L_tail+λ_ego L_ego+λ_end L_end（L_end 为选中物体-操作对轨迹的终点误差），总目标再加 λ_intent L_intent；H2O-PT 用训练集动作标注监督目标分布（定义在观测候选索引上）与动词分布，λ_intent=0.1；EgoPAT3D-DT 与 EGTEA Gaze+ 取 λ_intent=0，选择概率靠概率加权轨迹损失与可微解码条件优化。主模型训练 350 epoch、3 个随机种子取平均，EgoPAT3D-DT/H2O-PT 用各种子最佳验证检查点，EGTEA 用第 350 epoch 末检查点；消融 A1–A9 单种子。评测协议：观测占 60%、未来占 40%，主窗口至多 40 帧；3D 误差以米、2D 以归一化图像坐标，报 ADE/FDE。

## 实验与结果
- 3D 预测（Table I）：EgoPAT3D-DT(seen) ADE 0.158 / FDE 0.324，优于 Uni-Hand 0.170/0.336
- unseen ADE 0.103 / FDE 0.174 vs Uni-Hand 0.118/0.189
- H2O-PT ADE 0.025 vs Uni-Hand 0.030，FDE 0.050 与 Uni-Hand 并列最优
- 六个 3D 指标全部最优（含并列）
- 2D 预测（Table II）：EgoPAT3D-DT(seen) ADE 0.053 / FDE 0.092 vs Uni-Hand 0.064/0.109
- unseen 0.042/0.075 vs 0.052/0.087
- H2O-PT ADE 0.035 最低，但 FDE 0.069 略逊 Uni-Hand 的 0.065
- 六个 2D 指标中五个最优
- EGTEA Gaze+ 短时域协议（Table III）：ADE 0.140 / FDE 0.165，对比 Uni-Hand 0.181/0.208、OCT 0.160/0.160、USST 0.200/0.233，ADE 相对 Uni-Hand 降低约 22.7%
- H2O-PT 验证集原生目标排序（Table VII）：2D 全模型 Top-1 72.82%、3D 77.61%
- 去掉手关节输入（A1）分别降到 63.68% 与 74.63%，即下降 9.14 与 2.98 个百分点
- 1735 个窗口中 1608 个带派生交互目标，候选关联覆盖 100%
- 消融（Table VI，EGTEA）：去掉手关节（A1）退化最大，ADE/FDE 由 0.140/0.165 升到 0.159/0.185
- 去全局交互条件（A5）为 0.147/0.175、去阶段操作条件（A8）为 0.145/0.173
- A5 与 A8 在全部七个评测设置上 FDE 均高于全模型
- 阶段与几何诊断：学到的阶段切换点位于预测时域 0.411、0.752、0.949 处，段落长度不等
- 固定权重与 MAP 假设、仅关掉最后一遍相对子目标坐标输入，单样本 ADE/FDE 由 1.805/4.032 降到 1.685/3.755（相对降 6.66% 与 6.88%）

## 创新点与贡献
- 把“操作”从隐含条件变成可推理、可监督、可分解的中间变量：先用图网络编码的手部关节拓扑与候选物体语义/相对几何做因式分解的物体×操作联合分布 p_i·q_{k|i}，让同一物体上的多种操作各自产生一个条件 token，而不是把所有证据压成单一全局运动表示
- 再用累积归一化的正时长分数给出有序、可微、无需阶段标注的自适应阶段边界，并把每个阶段连到一个以候选锚点为原点的相对几何子目标，通过 stage 权重做残差细化
- 这三段（操作假设 → 有序阶段 → 阶段几何）构成一条从“猜要做什么”到“何时做、走到哪”的通路，是相对 OCT/USST/Diff-IP2D/MADiff/Uni-Hand 的结构性改动，而非单纯换骨干或加注意力

## 局限与风险
- 作者未单列 Limitations 段，但可从实验设计看出：全模型是 3 seed 平均，而 A1–A9 消融只有单种子，两者不同分布，多数退化幅度仅 0.001–0.005（如 H2O-PT ADE 0.025→0.027），接近种子噪声，消融结论只能读作趋势
- EgoPAT3D-DT 与 EGTEA 的手部输入是 ViTPose/Uni-Hand 估计的 2D 关节而非真值，误差会前传
- H2O-PT 的目标排序标签由动作标注 + 0.25 投影中心距阈值几何关联派生，作者自己声明未经人工核验手部特异性，100% 关联覆盖也不等于检测召回
- 相对最强基线 Uni-Hand 的增益多在 7%–13%，H2O-PT 的 2D FDE 仍落后
- 阶段数 K_s 与隐操作分量数（图中出现 4 个分量）的选择没有敏感性分析
- 未报告推理时延、真机在线部署或与 XR 头显的实时集成结果
