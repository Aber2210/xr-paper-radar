# EgoMyo：融合第一视角视频与腕部肌电的手部物理状态估计

## 一句话结论
把运动学 / 接触 / 力统一到 MANO 网格面（逐顶点法向力 + 接触标签，按七区聚合），视觉给场景上下文、腕部 sEMG 给发力——MPJPE 3.26 mm（HBridge 5.42，−39.8%）、区域力 MAE 0.86 N（−18.5%），跨场次 5.35（10.69）、跨被试 7.84（14.41），数据集 33,989 trials / 50 人 / 53.3 h。

## 要解决的问题
手部交互的真实状态由三部分耦合构成：运动学（构型）、接触（在哪里碰）、交互力（压多大力）。但近乎相同的外观可以对应无接触、轻触或用力按压，视觉只能看到外部表现；腕部表面肌电（sEMG）能感知神经肌肉驱动、其激活随发力增长，却缺场景上下文且跨场次漂移。已有组合都是片面的：PiMForce 以外部捕获的姿态为条件从 sEMG 估压、ForceBand 让 sEMG 管力、视频管动作、EMGFormer 只用两模态做姿态，没有人联合估计三者。基准层面也缺数据——现有数据集最多覆盖其中一部分（Tab. 1），且没有重复佩戴（repeated donning）来度量 sEMG 变异。

## 方法详解
把整个物理手部状态放在 MANO 网格面上：$S_t=\{M_t,c_t,f_t\}$，$M_t=\mathcal{M}(\theta_t,\beta_t)$，每个顶点 $v$ 带法向力 $f_t(v)\ge0$ 与接触标签 $c_t(v)\in\{0,1\}$，并按七个手部区域聚合出 $F_{t,r}=\sum_{v\in r}f_t(v)$、$C_{t,r}=\max_{v\in r}c_t(v)$。模型 $\hat{S}_t=\Phi(V_{t-W_V:t},E_{t-W_E:t})$。先做三项受控分析确立设计：单模态对比显示 sEMG 单独 MPJPE 12.40 mm（视觉 7.39 mm）、接触 F1 0.706（视觉 0.843），但在接触区上力估计更准（5.33 vs 6.35 N），给定真值接触后总力误差 5.62 vs 7.31 N；加 sEMG 后各区接触 F1 提升 1.2 到 7.6 点、力 MAE 降 1.01 到 7.34 N，且绝对增益与视觉误差的秩相关为 1.00（接触）与 0.93（力）；把预测幅值放到真值接触上，总力误差由 5.25 降到 4.48 N，而原始幅值在 88.7% 的帧里把超过 0.1 N 放到非接触区。MyoBridge 据此分三段：粒度匹配编码（GME）——冻结 WiLoR 视觉编码器给 patch token $Z^v_t$，18 通道 sEMG 用因果卷积 stem 加残差 TCN 加通道嵌入得 $Z^e_t=\mathrm{LN}(\mathrm{Mean}_\tau[X^e_t+f_{\mathrm{TCN}}(X^e_t)]+B_{\mathrm{ch}})$，sEMG 编码器先在训练窗口上用对称 InfoNCE（温度 0.07，同 trial 窗口互不为负）对齐冻结视觉特征；两路 token 交给 MoT 共享注意力、各保留独立 FFN。区域门控融合（RGF）——把两路 token 均值拼接经 MLP 得七个区域状态加一个全局状态 $H^{(0)}_t$，再为每个状态产生 sEMG 残差 $E_{t,r}$ 与自身标量门 $g_{t,r}=\sigma(f_{\mathrm{gate}}(h^{(0)}_{t,r}))$，$\tilde{h}_{t,r}=h^{(0)}_{t,r}+g_{t,r}E_{t,r}$，并做 $h=0.9\tilde{h}+0.1\mathrm{LN}(\tilde{h})$ 的温和拉平。区域到表面解码（RSD）——运动学头回归 $(\hat{\theta}_t,\hat{\beta}_t)$ 得网格与关节；每个顶点以 $q_{t,v}=e_v+h_{t,r(v)}+\mathrm{PE}(\hat{M}_t(v))$ 为 query、在 $[Z^v_t;Z^e_t;H_t]$ 上注意力得 $z_{t,v}$；接触支撑力场先由区域接触门控幅值 $\hat{F}_{t,r}=\hat{C}_{t,r}\,\mathrm{softplus}(D_m(h_{t,r}))$，再在区域内按 $\hat{f}_t(v)=\hat{F}_{t,r(v)}\hat{p}_t(v)$、$\hat{p}_t(v)=\tilde{c}_t(v)e^{s_t(v)}/\sum_{u\in r}\tilde{c}_t(u)e^{s_t(u)}$ 分配，推理时低于接触阈值的顶点力严格为 0（训练用软概率）。损失用同方差不确定性加权 $\mathcal{L}=\sum_{k\in\{M,c,F,p\}}(\frac{1}{2\sigma_k^2}\mathcal{L}_k+\log\sigma_k)$，网格与区域力用 $\ell_1$、接触用 Dice、区域内力分布用交叉熵，把「压多大力」与「压在哪」分开监督。骨干为冻结 ViT-H/16，可训练任务参数 9.41 M，B200 上 20 轮对齐加 20 轮任务训练、AdamW $5\times10^{-4}$、batch 256。

## 实验与结果
- Cross-trial：MPJPE 3.26 mm、PVE 3.30 mm、区域接触 F1 0.95、区域力 MAE 0.86 N、表面接触 F1 0.88（最强基线 HBridge 5.42 / 5.36 / 0.94 / 1.06 / 0.87；视觉-only WiLoR 6.16 mm）
- 相对最强基线的降幅：MPJPE 降 39.8%、区域力 MAE 降 18.5%
- Cross-session：MPJPE 5.35 mm（MoT 10.69），相对最佳融合基线提升 49.9%
- Cross-subject：MPJPE 7.84 mm（MoT 14.41），提升 45.6%
- 数据集规模：5.75M 视频帧、33,989 trials、50 名被试（100 只手）、53.3 小时、34 种接触构型、两次独立佩戴
- 单模态对比：sEMG 单独 MPJPE 12.40 mm / 接触 F1 0.706 / 接触区力 5.33 N；视觉 7.39 mm / 0.843 / 6.35 N；给定真值接触后总力误差 sEMG 5.62 N、视觉 7.31 N
- 力泄漏：原始幅值在 88.7% 帧把超过 0.1 N 放到非接触区，限制到预测接触后降到 12.7%
- 计算成本：可训练 9.41 M 参数、0.712 GFLOPs、0.0284 ms/帧（不含视觉编码）
- sEMG 窗长：100 到 750 ms 使力 MAE 降 6.4%，接触 F1 变动小于 1%；窗移到 [−1000,−750] ms 使力 MAE 升 29.4%，用帧后信号升 12.5%

## 创新点与贡献
- 相对 emg2pose、EgoEMG 这类只给姿态或只给肌电的数据集，EgoMyo 是第一个把第一视角视频与腕部 sEMG 同裸手姿态、接触、法向力对齐的基准，且用「压力图配准到重建手网格」绕开了手套或手戴传感器对自然接触的破坏，并用两次独立佩戴量化 sEMG 变异
- 相对 EMGFormer / HBridge 这类整手级融合，MyoBridge 把「手部区域」作为融合单位：每个区域用自己的门吸收 sEMG 残差，力只落在预测接触顶点上并按区域幅值求和，把接触-力耦合写进解码结构而不是靠后处理

## 局限与风险
- 作者自述覆盖范围窄：只有裸手按压平面，抓握、曲面物体与切向力都未覆盖
- 跨佩戴与跨用户的 sEMG 漂移仍是开放问题（cross-session MPJPE 5.35、cross-subject 7.84 mm，明显高于 cross-trial 的 3.26）
- 力的真值依赖 Sensel SDK 换算、未对参考载荷做独立标定，绝对值带 SDK 转换误差
- 另有一名被试因未标定峰值力超出 1.5 IQR 被剔除
- 指标上顶点力 MAE 0.29 N 仍略逊 HBridge 的 0.28 N，说明「区域内如何分配」尚未解决——区域准确不等于表面力场准确
- 数据采集需要四台环绕相机加同步硬件加压力面，属实验室装置，离可穿戴日常采集有距离
