# 面向多视图空间理解的 Seek-and-View 推理

## 一句话结论
把「主动取景」本身当作中间推理目标，用重力对齐的 3D 基础模型 + 离散动作集把语义意图稳定落到几何变换，从而真正合成原观测之外的新视角且零微调：六个 VLM × 六个基准共 5,496 题平均绝对提升 8.2%，GPT-5.4 总体 47.0%→59.0%，Qwen3.6-27B 59.2%→73.0%。

## 要解决的问题
多视图空间推理受限于稀疏且固定的视角：VLM 只能在给定视图上做隐式跨视图对齐，语义推理强并不保证几何一致，把几何压成语言描述又会丢失细粒度空间信息，形成 geometry-to-language 瓶颈。于是模型在 MindCube 一类任务上远低于人类，且易产生幻觉式关系判断。

## 方法详解
提出 Seek-and-View 范式：先寻找一个让被问空间关系直接可见的视角，再在该视角上作答；Vantage 是其零训练、模型无关的两阶段实现。阶段一视角锚定推理：VLM 结合由 3DFM 位姿导出的重力对齐相机关系 c_cam，选出参考视图 v_r，识别 anchor 实体并建立语义方向框架（默认 v_r 前向为北），把问题中的方向关系解析为「观测需求」，再从 17 种相机动作（旋转/平移/混合）× 小中大三级幅度（如右转 30°/60°/90°）中选择 Δv=(π,μ)，同时生成分析上下文 c_ana 与解读指引 c_guide。阶段二几何锚定证据增强：用同一 3DFM（G3T）重建的点云 Z 与位姿 P，把 Δv 映射为相对 p_r 的 6-DoF 变换并重投影得到 v_s=R(Z, p_r⊕Δv)，再把 v_s、c_ana、c_guide 与原始视图一并送入 VLM 完成最终 VQA。合成视图只重排已观测像素，故是补充而非替代输入视图。

## 实验与结果
- 六个 VLM × 六个基准、共 5,496 题，平均绝对提升 8.2%，全程零微调
- GPT-5.4：MindCube-tiny 44.2% → 72.8%，总体 47.0% → 59.0%（+12.0）
- Qwen3.6-27B：63.0% → 85.5%，总体 59.2% → 73.0%（+13.8）；Gemma-4-31B 总体 +10.6
- 小模型：Qwen3-VL-4B +7.1、Qwen3-VL-8B +3.8、InternVL3-8B +1.8
- 上下文消融：仅加 c_cam 为 30.5 → 加 v_s 33.9 → 加文本上下文 35.9 → v_s 加 c_ana/c_guide 达 38.8（总体 +8.3）

## 创新点与贡献
- 把「主动取景」本身当作中间推理目标，并用重力对齐 3DFM + 离散动作集把语义意图稳定落到几何变换
- 与 think-with-image 的缩放画线不同，它确实合成了原观测之外的新视角，且不改模型参数

## 局限与风险
- 合成视图只能重排已观测像素，未覆盖区域为空，因此无法回答完全缺观测支撑的关系
- 效果上限受 VLM 自身规划能力限制（小模型多错在分析与选视角），跨模型替换规划器虽有提升但仍有限
- 仅评估静态场景，未涉及动态或仿真环境
