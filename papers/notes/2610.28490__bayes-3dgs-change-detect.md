# 从自动 3DGS 编辑中学习在线贝叶斯场景变化检测

## 一句话结论
从参考 3DGS 自动编辑学习场景特异性证据模型，经广义贝叶斯在线融合做变化检测：PASLCD 67.64% mIoU、17.2 FPS，为在线方法中最快。

## 要解决的问题
在线场景变化检测要在参考场景基础上，随新图像到达不断更新哪些区域已改变的判断。难点在于：图像差异混合了物理变化、渲染伪影与光照变化，难以直接解释；变化的先验概率与证据模型事先未知；数值贝叶斯推理计算代价高；且带标注训练视图获取成本高。本文要解决的是：如何从参考场景自身自动获得监督（无需人工标注），离线拟合场景特异性证据模型与有效像素先验，再以闭式局部贝叶斯因子实现高效的因果在线证据累积与变化掩码输出。

## 方法详解（含关键公式/架构，保留原文术语）
将变化预测形式化为广义贝叶斯更新（Bissiri et al., 2016）：后验 odds = 先验 odds（有效像素先验 π）× 当前 odds C_t × 历史 odds H_t，中性证据（C_t=H_t=0.5）时后验等于先验。五个组件全部离线拟合、在线推理时固定：响应抑制器 T 与对数似然比映射 ℓ_img 由初始差异响应 R_t^0 构建当前证据 C_t；未变响应模型 (μ_g, τ_g², c) 提供闭式证据累积统计以支撑 H_t；轮廓滤波 ℓ_contour 用于后续掩码精炼。监督来自参考 3DGS 的自动编辑（生成带标注视图）与未变参考观测。在线阶段，C_t 结合映射图像证据 P_t 与高斯聚合支持 S_t，与 π、H_t 融合得像素级后验 Q_t^pixel，再经 object-guided refinement 得最终掩码；闭式局部贝叶斯因子以学习到的响应统计为参数，更新累积的 3D 高斯场，无需在线反向传播与历史图像。

## 实验与结果（表格化关键数字）
主基准为真实世界 PASLCD（20 个场景实例，常规 4× 下采样），辅以四个合成 CCS3D 场景（2× 下采样，共 18 个 query）；沿用 O-SCD 掩码定义（涵盖变化前后状态，含腾出与新占区域），报告阈值 0.5 下 Ours (pixel) 与 Ours (full) 的前景 mIoU 与 F1，对比官方代码 O-SCD 及其他已发表在线/离线基线（部分结果引自 GS-Diff），每配置 500 个 query、两次完整运行平均。完整方法在 PASLCD 上两次运行均达 67.64% mIoU，最大单实例差 0.019 个百分点。计时覆盖完整查询序列（含帧间工作与输入等待）：pixel 模式 27.88/27.98 FPS，full 模式 17.15/17.19 FPS（每模式两次运行，共 1000 帧）。摘要另报 CCS3D 75.82% mIoU，完整管线在 PASLCD 上 17.2 FPS、为所评在线方法中最快。与各基线的逐项对比数值 digest 未含具体数值（原文有表）。

## 创新点与贡献
- 以参考 3DGS 自动编辑为自监督来源，拟合场景特异性证据模型，免人工标注
- 广义贝叶斯证据融合：先验 odds × 当前 odds × 历史 odds 的因果在线更新
- 响应抑制器 + 对数似然比映射 + 未变响应统计 + 轮廓滤波四组件分工，实现闭式局部贝叶斯因子与 3D 高斯场累积
- 全组件离线拟合、在线零反向传播，PASLCD 67.64% mIoU 且 17.2 FPS 为所评在线方法最快

## 局限与风险
- 附录 D 指出参考覆盖不足（insufficient reference coverage）为局限之一
- 场景特异性模型需逐场景离线拟合，跨实例复用（附录 G.1 有研究）效果可能受限
- 训练视图由自动编辑生成，编辑分布与真实变化分布之间可能存在差距
- 在线处理含位姿估计与特征提取，整体吞吐受预处理影响
