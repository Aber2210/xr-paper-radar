# 异步多尺度 MR-VR 协作中桌面化化身注视控制的远程专家评估

## 一句话结论
29 名远程专家在 Same Machine / Twin Machine 两项故障检测任务中评估三种化身注视控制（VR 全沉浸+头部直接控制 / 浮动屏+头部控制 / 化身屏+触控板控制），每人 36 trials（2 任务 × 3 方法 × 2 难度 × 3 重复）：VR 条件取得最强总体任务表现与用户体验，桌面化身边身协作设置亦获好评（VRST '26）。

## 要解决的问题
多尺度异步 MR-VR 协作中，远程专家虽有 exocentric MR 视角与桌面 World-in-Miniature（WIM），但缺少厂内 egocentric 视角；行业访谈显示专家侧需要「进入」厂区、与操作员同尺度共享第一视角才能真正协作——如何在保留桌面全局概览的同时控制化身注视，缺乏实证比较。

## 方法详解（含关键公式/架构，保留原文术语）
集成系统：远程专家（MR exocentric）用 Tangible User Interface（TUI）在缩放 WIM 中精确定位/旋转化身；WIM 内化身与现场操作员同尺度共享 egocentric 视角，专家同时保留桌面全局概览。三种交互-可视化组合：VR（全沉浸 + 头部直接控制）、Head（浮动屏 + 头部直接控制）、Touch（化身上屏幕 + 触控板控制）；网络层用 Unity Netcode for GameObjects。被试内设计 + 拉丁方平衡顺序；任务难度按需检查的错误贴纸数分 2 级，系统跟踪已检查贴纸并动态设置解答位置。

## 实验与结果（表格化关键数字）
29 名参与者（均任远程专家）完成 2 任务 × 3 方法 × 2 难度 × 3 重复 = 36 trials/人；T1 Same Machine（两人同机细检）vs T2 Twin Machine（异地同型双机并行注意）。假设：H1（T1 中 VR 优于 Head/Touch，依据沉浸-可视化空间对齐降低心理努力）、H2（T2 中 Head/Touch 因保留桌面视野优于 VR）、H3（桌面化身控制整体有效）。digest 未含结果表，摘要级结论：VR 条件总体表现与 UX 最强、桌面化身设置协作接受度好；因每条件为「可视化×显示×控制」捆绑配置，无法归因到单一维度。

## 创新点与贡献
① 面向工业远程专家的多尺度异步 MR-VR 集成场景（MR 桌面 WIM + TUI 化身 + 共享 egocentric 视角）；② 系统比较三种化身注视控制的交互-可视化捆绑配置；③ 用受控难度与拉丁方平衡的任务设计分离协作需求（同机 vs 双机）；④ 参与式设计阶段行业访谈提炼出「专家侧 egocentric 视角」这一真实需求。

## 局限与风险
条件为可视化/显示/控制捆绑，无法做单因子因果归因；29 名样本量有限；digest 结果部分提取不完整，逐任务/逐指标数字待补；故障检测为受控拼图式任务，与真实工业任务的生态效度待验证。
