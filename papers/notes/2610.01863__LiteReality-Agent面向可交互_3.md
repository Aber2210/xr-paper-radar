# LiteReality-Agent：面向可交互 3D 室内场景重建的智能体系统

## 一句话结论
从 RGB-D 扫描 + 检测结果出发，经布局智能体、物体重建与场景程序生成'可仿真（simulation-ready）'的可交互室内场景，并用证据工具 + 质量门控保证几何与支撑合理性。

## 要解决的问题
真实到仿真（real-to-sim）需要既视觉逼真、又具物体级可交互性与物理合理性的室内场景；现有重建多产出静态网格，缺物体级可交互性与物理元数据，难以直接用于仿真/VR 内容。

## 方法详解
输入 RGB-D 扫描 + 检测；场景初始化（Layout Agent 推断房间布局关系、Object reconstruction 生成带物理属性的网格、scene program 组装层级场景图）；Agentic Authoring：证据工具（三级图像选择、渲染对比、墙体缝合与测量、创作 harness）、预算控制（budgeted control，限制大模型调用成本）、几何与支撑门控（geometric & support gates，校验悬浮/穿插）；Simulation-Ready Export 导出可直接导入仿真器的场景。

## 实验与结果
10 个场景 vs Fable 5.1（RGB-only / +Scan）、GPT-6（RGB-only / +Scan）。几何一致性与合理性（表3，611 帧深度 MAE + 近接触支撑率）：LiteReality-Agent ours SSIM 0.6105 / PSNR 14.129 / RMSE 0.2033 / LPIPS 0.5392，优于 Fable 5.1 RGB-only（0.5307/10.681/0.3008/0.7197）与 GPT-6 +Scan（0.6004/12.967/0.2323/0.6250）；含人类与智能体感知评估、扫描数据对通用智能体影响的消融。

## 创新点与贡献
① 把'逆向图形（inverse graphics）'做成带证据工具与质量门的智能体循环，而非一次性前馈；② 物体级物理属性与碰撞几何，直接对接仿真；③ 预算/门控使大模型智能体可控、可审计。

## 局限与风险
依赖检测与扫描质量；物体重建仍需重试/拒绝；未见大规模多房间或动态场景；仿真导出格式有限。
