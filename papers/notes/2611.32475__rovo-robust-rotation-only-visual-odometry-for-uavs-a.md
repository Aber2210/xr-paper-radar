# ROVO：面向低空与中空无人机的鲁棒纯旋转视觉里程计

## 一句话结论
把「平移不可观时只估旋转」从工程取舍上升为完整在线系统（滑窗旋转平均 + 共享帧对齐 + 有界信息融合），全程不初始化尺度也不三角化地标，并用「历史视图对同一入射帧的预测一致性」做联合测量选择：轨迹仿真朝向误差仅为常规 SfM+PnP+BA 的 10.7%，3 px 噪声下 1.68°（链式相乘 25.12°）。

## 要解决的问题
无人机在 120–3000 m 高度飞行时，相机基线相对场景深度极小，平移引起的视差几乎被图像噪声淹没；同时长焦镜头为保留地面细节而收窄 FoV，进一步压缩视差方向分布。此时特征坐标的亚像素误差会被放大为巨大的平移方向误差（仿真中 3 px 噪声下 five-point 的平移方向误差达 25.61°，而旋转误差仅 1.65°），并经由三角化与 PnP 反向污染后续位姿。传统 VO/SLAM 把旋转与平移、结构耦合优化，缺少一种在平移不可观时仍稳健输出姿态的方案。

## 方法详解
ROVO 把标定单目图像流映射为带时间戳的相机朝向，轨迹状态只保留 SO(3) 朝向，从根源上切断不确定的地标深度向后续估计传播。前端用 SIFT 提取并按空间均匀采样控制特征预算，一对一描述子匹配后要求至少 15 个独立匹配才进入相对旋转估计。每条边先生成两个候选：Nistér five-point（OpenGV）给出基线解 R̂(0)，再由 RANSAC/本质矩阵分解假设排序，并用以 Kneip–Lynen 迭代特征求解器精化得到 R̂(1)；两者都在拟合集与预留验证集上做去旋转 bearing 一致性、正深度与双视图重投影（2 px）检验。核心创新是联合选择：对入射帧 k，用历史关键帧 i、j 的已存朝向构造 H_ij，计算候选间不一致度 ε_ij^(k)(a,b)=d(R̂_ik^(a), H_ij R̂_jk^(b))，在 Huber(δ_sel=3°) 下最小化 J_k(s)=Σρ(ε)，只保留多视图一致的解释，从而在弱视差下自适应挑选旋转测量。滑窗内用 HARA 做层次化初始化（三视图一致性 ζ_ijℓ），再以 ℓ1/2 损失的 IRLS（四元数，≤250 次迭代）求解旋转平均，锚定首帧消除规范自由度。窗口间通过共享帧的一致集投票 + SO(3) 上的加权矩阵均值与 Huber 迭代对齐，得到 ΔR；随后以信息权重做有界融合 R_wc,i^new = R_wc,i^prev Exp(α_i e_i)，α_i 受最大修正角 θ_max 截断，信息量上下界 (I_min,I_max)=(0.1,4) 防止相关估计过度自信。

## 实验与结果
- 轨迹仿真中滑窗 ROVO 的平均朝向误差仅为常规 SfM+PnP+BA SLAM 基线的 10.7%
- 3 px 像素噪声下，eigensolver 的窗口/全局旋转平均朝向误差为 3.39°/1.68°，直接链式相乘为 25.12°
- Bell412 原始焦距 RRE RMSE 0.511/0.444/0.687°，与 ORB-SLAM3（0.511/0.432/0.600°）、DPVO（0.510/0.428/0.594°）相当
- 3× 焦距窄 FoV 下 RRE 0.918/0.652/0.789°，相对各自次优方法降低 31.3%/69.4%/19.7%
- VPAIR 上覆盖 2681/2706 帧（99.1%）、8 个跟踪段，own-pair RMSE 3.767° 较 DPVO 5.583° 降低 32.5%；公共帧对 2.631° vs 2.639°
- MATLAB R2023b 实现中，旋转平均+窗口对齐融合平均仅 8.6 ms/窗口更新（Intel i5-12600KF）

## 创新点与贡献
- 把「平移不可观时只估旋转」从工程取舍上升为完整在线系统：滑窗旋转平均 + 共享帧对齐 + 有界信息融合，全程不初始化尺度也不三角化地标
- 联合旋转测量选择用「历史视图对同一入射帧的预测一致性」作为判据，等价于在候选图上做三帧闭环一致性检验，可在启动阶段无窗口解时工作

## 局限与风险
- 输出只有朝向，不含平移，无法独立用于定位与建图
- 作者明确把与 IMU/平移测量的融合列为未来工作
- MATLAB 原型离线处理，实时性与嵌入式部署未验证
- 在原始宽 FoV 条件下相对 ORB-SLAM3/DPVO 并无优势（Bell412-4、-5 略差）
