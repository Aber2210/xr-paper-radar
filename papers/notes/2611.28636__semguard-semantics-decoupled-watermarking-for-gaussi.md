# SemGuard：面向高斯泼溅的语义解耦水印

## 一句话结论
把「语义干扰处理」从按资产的后处理前移到共享预训练阶段（无 watermark 场景图造干扰 + 渐进课程），使同一冻结解码器覆盖多个语义相近高斯资产：16-bit 静态 PSNR 41.55→50.29 dB、32-bit Bit Acc 99.52%，无需 Guard4D 式资产级优化。

## 要解决的问题
高斯泼溅资产需要版权保护，水印必须能从不同视角/时刻的渲染图中稳定提取，同时尽量不改变原始外观。GuardSplat 用 CLIP 文本特征预训练通用消息解码器，但预训练只见文本、抽取时输入的是含场景语义的 CLIP 视觉特征，形成「语义纠缠鸿沟」，在保真度约束下会削弱消息恢复。Guard4D 虽用 TMSD 模块抑制动态资产的语义干扰，但该模块需按资产生成优化，增加抽取流水线开销。核心矛盾是：既要处理场景相关语义干扰，又要保持解码器可跨资产复用。

## 方法详解
两阶段框架。阶段一做语义干扰感知的解码器预训练：把二值消息 $\mathbf{m}$ 映射为 CLIP 文本 token 得到 $\mathbf{F}_T$，同时从无 watermark 的语义图像池取图得到 $\mathbf{F}_I$，在共享 CLIP 空间混合 $\mathbf{F}_{mix}=(1-\rho)\mathbf{F}_T+\rho\mathbf{F}_I$，归一化后送入轻量解码器 $\mathbf{o}=D_\psi(\mathbf{F}_{mix}/\|\mathbf{F}_{mix}\|_2)$，用 BCE 监督。为避免强干扰早期破坏消息映射，采用渐进课程 $\rho_e=\rho_{min}+(\rho_{max}-\rho_{min})e/E$，先学可靠消息表示再逐步适应语义干扰。阶段二冻结 CLIP 编码器与消息解码器，只优化每个高斯资产的球谐偏移 $\Delta\mathbf{H}^{dc},\Delta\mathbf{H}^{rest}$ 以嵌入消息，几何与形变参数不动。嵌入目标为 $\mathcal{L}=\lambda_{msg}\mathcal{L}_{msg}+\lambda_{recon}\mathcal{L}_{recon}+\lambda_{off}\mathcal{L}_{off}$，其中重建项含 MAE、$1-\mathrm{SSIM}$ 与 LPIPS，偏移正则用 MSE 抑制过大外观扰动；动态资产在视角序列内对 CLIP 特征做时间平均后再解码。

## 实验与结果
- 16-bit 静态：PSNR 41.55→50.29 dB，SSIM 0.9957→0.9993，LPIPS 0.0017→0.0004，Bit Acc 99.64%→99.97%（Blender+LLFF）
- 32-bit 静态：PSNR 39.40→43.72 dB，Bit Acc 99.04%→99.52%
- 48-bit 静态：PSNR 38.90→42.32 dB，Bit Acc 98.29%→98.72%
- 动态资产 32-bit：PSNR 40.35→45.41 dB，Bit Acc 76.06%→91.91%（D-NeRF+HyperNeRF）
- VAE 攻击下 16-bit Bit Acc 95.26% vs GuardSplat 82.35%；旋转 97.01% vs 94.56%，JPEG 96.53% vs 94.70%

## 创新点与贡献
- 把「语义干扰处理」从按资产的后处理模块前移到共享的预训练阶段：用无 watermark 场景图构造可控干扰，并配渐进课程，使同一个冻结解码器覆盖多个语义相近的高斯资产，避免 Guard4D 式的资产级额外优化

## 局限与风险
- 语义图像池必须覆盖目标资产的视觉语义，池外场景的泛化未系统验证
- 动态资产收益明显小于静态（32-bit 才到 91.91%），且引入静态图并不总提升动态恢复
- 鲁棒性只测图像空间失真，未覆盖模型参数级攻击
- 保真度提升部分来自更强约束，可能与容量/消息长度存在权衡
