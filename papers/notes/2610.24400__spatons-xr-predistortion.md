# Spatons：空-色调局部化神经算子用于高效 XR 预畸变补偿

## 一句话结论
空-色调局部化神经算子：G-Res 在混合几何畸变场景 PSNR 37.5 dB / SSIM .987（Sc.3）、34.9 dB / .975（Sc.4），领先全部 UNet++ 变体约 8 dB，以约 250× 更少参数把与 CompenNet++ 的差距压到约 1.5 dB；公式无关模式下 8.5K 参数 NN2 在真实投影仪-相机数据上把约 10.3 dB 基线拉到 22.23 dB / 0.816 SSIM。

## 要解决的问题
XR 近眼显示/投影需要实时预畸变补偿（预先扭曲待显示图像以抵消光学畸变），但真实畸变是几何与色调在空间上非均匀耦合的，且常缺少可微畸变公式导致无法反传训练；既有学习式补偿网络（CompenNet++、Patch2Pixel、UNet++）参数量大，难以部署在端侧。

## 方法详解（含关键公式/架构，保留原文术语）
Spatons 用空-色调局部化神经算子直接学习补偿映射，几何变体 G-Res/G-Hybrid 处理 keystone/fisheye/barrel 等几何畸变，C-Res 处理色调畸变。核心是两阶段公式无关方案：先从图像对拟合一个 forward-mimic 网络 NN1，再把可部署的 NN2 通过冻结的 NN1 训练，从而摆脱对手工可微畸变管线的依赖。训练用 AdamW + cosine annealing + warm restarts + AMP（Images.cv 256×256：batch 32、lr 1e-3→min-lr 1e-6、weight decay 1e-4、warmup 5 epochs、100 epochs）。论文另含视频预畸变、量化分析与解析式资源/时延模型。

## 实验与结果（表格化关键数字）
Images.cv（26k 图、3×256×256、70/15/15 划分）为主基准，CelebA-HQ（28k 人脸）做零样本跨数据集测试。Sc.1/2（色调混合：色平衡、亮度对比、 elevated black、暗角、模糊、色边等）：C-Res 22.3/21.4 PSNR，Patch2Pixel-v2 (p=3) 27.4/23.0，UNet++-Large 29.4/23.5，CompenNet++ 29.4/23.3。Sc.3/4（几何混合 keystone+fisheye / keystone+barrel+fisheye）：G-Res 37.5/34.9 PSNR（SSIM .987/.975）、G-Hybrid 37.4/34.8、UNet++-Large 29.2/28.7、CompenNet++ 39.1/36.3；G-Res 领先全部 UNet++ 约 8 dB PSNR，以约 250× 更少参数进入 CompenNet++ 约 1.5 dB 内。公式无关验证：Sc.5 全空-色调下 8.5K 参数 NN2（经冻结 CompenNet++ mimic 训练）达 26.59 dB / 0.926 SSIM，距已知公式上界 0.9 dB 内；真实投影仪-相机数据（Huang and Ling 2019，lavender_np，700 对）从约 10.3 dB 提到 22.23 dB / 0.816 SSIM；空间非均匀四区域算子（keystone/fisheye × blur/contrast）下同样有效。

## 创新点与贡献
① 空-色调局部化神经算子统一处理几何+色调耦合畸变（G-Res/C-Res 家族），在混合场景大幅超越通用 UNet++ 架构；② 两阶段「先拟合 mimic、再蒸馏可部署小网」方案摆脱对可微畸变公式的依赖，任意黑盒光学系统均可被补偿；③ 8.5K 参数即可在真实数据上取得约 +11.9 dB 的修正，比 mimic 小 2–3 个数量级，面向端侧实时。

## 局限与风险
主基准为 256×256 合成数据，更高分辨率/更多数据集的适用性见附录但 digest 未给数值；真实数据验证仅一个投影仪-相机数据集（700 对）；公式无关模式需先训练 NN1 mimic，两步流程增加部署前成本；digest 未报告在头显实际光学链路上的端到端验证。

## 与文献库的关系（新增 / 改进 / 取代 X）
隶属「渲染与显示」XR 显示补偿线：与基线 CompenNet++/Patch2Pixel-v2/UNet++ 同属学习式预畸变家族；其「大模型冻结为 mimic、小网蒸馏」思路与库内 3DGS 效率/压缩线（2610.22778 dGS、2605.25563 CodecSplat 的紧凑/前馈参数化）共享「大模型→可部署小模型」范式；与全景内容线（2610.21297 GeoPano、2604.00852 PanoAir）目标不同——本文化解决显示端光学畸变补偿而非内容生成。
