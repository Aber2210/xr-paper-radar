# OrdiHand-GS：面向数字手语者的序数引导跟踪与手部精化高斯化身

## 一句话结论
用相对深度与外观尺寸两路证据投票解手部前后序歧义，再以序数残差驱动高斯化身的手部精化——腕序 balanced accuracy 48.9→76.9%（准确率 32.9→77.3%），代价仅 +0.39 px 与 +1.6°，interaction crop PSNR 16.91→17.35，365 个重叠手帧人工标注。

## 要解决的问题
数字手语化身靠动画虚拟人传达手语，手势、位置与双手相对前后关系承载词汇与语法信息，因此手部错误对聋人观众极其显眼。单手交叉时有两个失效点：其一，单目 expressive-human 跟踪存在前后序歧义，两只手都能满足同一组 2D 关键点；在 How2Sign 的 365 个已标注重叠手帧上，原始 EHM 拟合在 93.2% 的帧里把右手腕放在前面，腕序 balanced accuracy 仅 49.8%（等于随机），而人工判定左手在前有 252 例。其二，即使几何修正，神经渲染出的手部外观仍然模糊，interaction crop 的 LPIPS 停在 0.319 附近。

## 方法详解
两部分解耦处理。C1 序数引导的 EHM 精化：冻结的 Video Depth Anything 给出相对深度 $d_t$（越大越近），对每只手由关键点构造膨胀凸包并去掉两包交集，得互不重叠支撑区 $S_L,S_R$，计算 $δ_t=(med_{S_L}d_t−med_{S_R}d_t)/(P95−P5)$；当支撑太小、分母近零或 $|δ_t|$ 低于阈值时深度线索弃权，否则以 $s_d=sign(δ_t)$、$c_d=min(1,|δ_t|/κ_d)$ 投票。外观尺寸线索用 $r_t=log(A_L/A_R)$ 给出 $s_a$、$c_a$，融合 $v_t=c_d s_d+c_a s_a$，$s_t=sign(v_t)$、$c_t=min(1,|v_t|)$（冲突则权重下降，正好抵消则不施加惩罚）。约束施加在每只手 MANO 关联顶点的视空间深度中值 $z_{h,t}$ 上：$L_ord=Σ_t c_t[m+s_t(z_{L,t}−z_{R,t})]_+/Σ_t c_t$，$L_fit=L_EHM+λ_ord L_ord$，取 $m=0.03$、$λ_ord=100$，用基线 EHM 优化器续跑 240 步（手部姿态学习率 $10^{-4}$），梯度经 SMPL-X 参数化回传，因此是跟踪阶段精化而非孤立的手部姿态修正。C2 手部 UV 高斯残差：源重建网络给出冻结的 UV 特征图 F 与网格绑定高斯的局部位置 $p_i$，3 层卷积头（221,571 参数，末层零初始化）预测三维位置残差，经连续手部归属权重 $w_i=Σ_k b_{ik}h(v_{ik})$（h 为 1 表示 MANO 手部顶点）调制后 $p'_i=p_i+w_i[f_φ(F)]_i$，残差在绑定三角形局部系中施加，只动手部高斯；backbone、解码器与神经精化器全冻结。渲染损失为全图 $ℓ_img=L1+0.05·LPIPS$、0.25 倍的头部 crop 项与两手 crop 的 $ℓ_hand$（含 0.1·L1、0.005·LPIPS、0.01·(1−SSIM)），训练 40,000 次残差更新；同一残差 checkpoint 不加训练地用于原始跟踪与融合跟踪，从而构成 2×2 因子评测。

## 实验与结果
- 腕序准确率 32.9% → 77.3%，balanced accuracy 48.9% → 76.9%（同一预算的 matched control 对比，修正 184 例、新增 22 例）
- 代价：手部重投影误差 +0.39 px，臂链旋转约 +1.6°
- 随机符号 placebo 只涨 9.3 个百分点（BA 48.6%），无实质增益
- interaction crop：LPIPS 0.3174（C0）→ 0.3065（仅跟踪 C1）→ 0.3155（仅残差 C2）→ 0.3047（C3），PSNR 16.91 → 17.35
- 与 GUAVA 比较：hand crop LPIPS 0.3236 对 0.3454，interaction crop 0.3026 对 0.3190，PSNR 17.60 对 16.95
- 标注集：365 个重叠手帧来自 171 个 How2Sign clip（重叠 ≥0.30，隐藏重复标注 κ=0.91）

## 创新点与贡献
- 相对 GUAVA、SignSplat 等手语化身工作，它们不约束双手前后序、只在像素层面优化
- OrdiHand-GS 把序数深度证据做成「手级中值深度 hinge」并塞回 EHM 优化器（而非单独改手部姿态或加局部关键点 margin），保证满足约束时整条臂链一起动
- 再用 ownership-gated 的 UV 位置残差只精化手部高斯，backbone 与渲染器冻结，从而能把「跟踪错了」与「渲染糊了」两类误差分开归因

## 局限与风险
- 中值深度统计既不强制刚体运动也不处理接触与穿模
- 相机与共享身份参数也参与更新，因此无法隔离出纯姿态机制
- 残差只改 UV 局部位置且不受保留正则约束，并与新增的手部 SSIM 项一起评测，收益难以完全归因
- 标注来自单一标注者，How2Sign 无 3D 真值，轮廓 IoU 与手-身穿插未测
- ordinal 线索本身也会引入新的顺序错误（22 例）
- 训练与评测按视频而非按手语者划分，渲染只在标注的交互帧上评估，跨 backbone 迁移与真实手语可读性未验证
