# 物理驱动的单目视频动态流体资产提取：生成式 3DGS

## 一句话结论
在单目视频上把「恢复流体」改写为「反解仿真器参数」：优化后速度场量级由 ×10^-1 收敛到 ×10^-3（重建尺度 10^-2 m，Table 1），随机参数仿真会溢出地形而完整损失可复现视频动力学，15 名 3D 从业者/研究生在 8 个样例上对「相似度 / 真实感 / 美感」三项 1–5 评分整体优于 TriplaneGaussian 逐帧生成。

## 要解决的问题
从视频生成动态 3D 内容的主流做法是逐帧形变场或位移场，用像素级重建损失拟合。这对闭合系统（弹性体、可变形固体）有效，但流体是开放系统：物质持续从入口进入、从出口离开，拓扑自由变化，跨帧不存在稳定点对应，逐点形变既难定义也无法外推时长；隐式位移/速度场还往往违反不可压缩与动量守恒，缺乏时间可扩展性。另一侧，物理仿真路线（PhysGaussian 把 MPM 参数主观赋给重建高斯、GaussianSplashing 用 PBD 驱动物理高斯流体、PhysDreamer 用可微 MPM 优化材料、BAGS 学高斯椭球神经界的权重）多针对闭合可变形体，没有解决「从单目视频反解开放流体参数」；单视图流体工作又受限于特定流体类型或依赖新视角视频合成。缺口是一个能从任意网络单目视频自动产出「仿真就绪、可编辑、可延时长」3D 流体资产的管线。

## 方法详解
两阶段五步。Stage 1（几何与运动）：(a) 用图生 3DGS（默认 TriplaneGaussian，另测 TRELLIS）对输入帧生成高斯；(b) 单视角快速精化，损失 λ1·L_img + λ2·L_aniso + λ3·L_vol + λ4·L_scl + λ5·L_lumi（各向异性与体积项沿用 GaussianSplashing，L_scl 取三尺度几何均值促细化，L_lumi 抑制 SH 过饱和），并按背景色剪枝去掉水面礁石误检；(c) 去噪 + 密化：剪掉低不透明度或极端拉伸协方差，再把空间划网格，若格心在流体内部（向外随机射线与外壳交点过半为奇数）就插高斯；(d) 跨帧一致：对 N 个连续帧的 3DGS 取并集，N ∝ MSE(PSNR(f, f+1)) 动态决定，保证河床等不动结构一致、内部不留空腔。(e) 表面速度：光流给屏幕 2D 速度并结合深度得 v_z；对光流失效区（均匀水体纹理）做主流修正——先按主流方向 n_k 与邻域动能做方向加权插值 v_k=Σ w(i)·max(0, n_k·v_i/|v_i|)·v_i，再用无散约束 ∇_2D·v_2D=−(1/z)(u∂_u+v∂_v+2)v_z 做投影修正，且只施加在失效区以保留原有湍流；最后按相机参数反投影得 3D 表面速度 V_surf。(f) 体积速度：包面速度 V_encl=V_surf∪V_base，河床用 CFD 壁函数三次多项式 |v_base|/V_∞=1.5(y/δ)−0.5(y/δ)³ 给阻尼（δ 按流体类型取，河流厚、烟雾压到亚格子），再用拉格朗日乘子约束投影迭代解出无散 3D 速度场。Stage 2（可微 APIC 参数优化）：把速度搬到网格（P2G 时 C=0），在网格上解 ∂v/∂t=−∇p/ρ+∇·(2νS)+g；Poisson 压力方程改用改造的 PeRCNN（卷积核学离散算子 + 外循环模拟隐式迭代）替代 Jacobi 迭代，以保持可微并更快收敛；对流加 stable fluids 回溯保证无条件稳定，但因索引与舍入不可微，改用解析梯度 ∂v/∂v_i'=−dt·∂v/∂i 配 upwind 一阶离散。待优化参数为入口/出口体速度 v_in、v_out、入口脉动 ṽ_in、密度 ρ、粘度 ν、边界反弹 b 与阻尼 d、重力 g、时间步 dt；损失是 gridMask 加权的方向项 α(1−cos)+β·L2，单样本最多 25 个连续仿真步、每步约 100 个循环子步，靠合理初始化（常量出入口速度、非零重力、单位松弛、满足 CFL 的 dt）与 upwind 梯度代理缓解梯度消失；参数经 exp/sigmoid 归一化后映射到物理尺度。输出：用优化参数重仿真，仿射矩阵更新形变梯度 F=(I+dtC)F、协方差 A=F·A₀·F^T，实现高斯与仿真的双向耦合；渲染可保留 SH 直接 splat（适合粘性/外观均匀流体）或用 GaussianShader 重光照 + 透明吸收做更高分辨率。

## 实验与结果
- 参数收敛（Table 1，重建尺度 10^-2 m）：优化后 v_3D 由 ×10^-1 降到 ×10^-3、压力 p 由 ×10^1 降到 ×10^-3、重力与 dt 由 ×10^-2 降到 ×10^-3 / ×10^-1，说明从任意合理量级初始化都能落到稳定值。
- 优化必要性（Fig. 10）：随机物理参数仿真出现流体溢出地形；只用 MSE 的部分损失与完整损失对比，只有「方向项 + L2」的完整损失能匹配视频速度场，且物理仿真还能修正视频估速中的伪影。
- 合成真值对比（Fig. 11）：两条由已知仿真生成的视频（river / honey），把重建 3D 速度投影回 2D NDC 与真值比较；物理优化后噪声下降并恢复边界碰撞、蜂蜜入口应变等细节——注意这是定性对比，全文未给 EPE 等数值误差。
- 流体类型泛化：7 个示例覆盖无粘液体（a–e）与粘性液体（f–g），水面礁石可被检测并随几何保留；粘性流体可直接用重建 3DGS splatting 渲染，无粘流体用重光照更贴合流动纹理。
- 生成器泛化：TriplaneGaussian（a, c–g）与 TRELLIS（b）都能接入；前者贴合输入但分辨率低，后者分辨率更高但与输入偏离明显（高 CFG 仍偏离）。
- 用户研究：15 名全职 3D 艺术家或 3D 设计方向研究生，8 个样例，按「与输入视频相似度 / 真实感 / 美感」三项 1–5 打分，本文方法三项整体更高（原文只给 Fig. 12 热图，未给均值、方差或显著性）。
- 运行时间：仿真参数优化占主要开销，耗时随输入视频长度与网格密度增长（Fig. 14 为对数坐标，未给绝对秒数）。

## 创新点与贡献
- 把「从视频恢复流体」重述为「反解仿真器参数」的逆问题：输出的是带物理参数的资产，因此天然可编辑、可交互、可延长时间，而不是一次性 4D 重建。
- 光流失效区的两级主流修正：主流方向 + 邻域动能的插值补洞，再用无散约束投影，把只有波浪/飞溅的稀疏观测补成物理可用的表面速度场，并且只改失效区以保留湍流。
- 可微网格速度演化：改造 PeRCNN 替代 Poisson 隐式求解、对流项改用解析梯度配 upwind，使 APIC 的网格速度计算可端到端反传，且兼容通用 grid/hybrid 求解器。
- 生成式 3DGS 的流体化预处理：单视角精化、按背景剪枝、内部填充、按帧间 PSNR 自适应并集，把稀疏表面高斯变成能承载体积速度的致密流体体。

## 局限与风险
- 作者承认：要表现复杂飞溅必须提高网格分辨率并缩小 dt，成本对实时/交互应用不可行；长视频 + 高流速流体因优化复杂度与收敛问题会失败。
- 作者承认：与速度无关的颜色变化（如温度导致的熔岩变色）会污染光流速度估计；方法不追求外观精确重建（开放系统 + 单视图生成补全 + 流体无定形），只求动力学一致。
- 作者承认：目前主要面向液体，气体需进一步改造；河床阻尼用层流外流假设，会丢掉细尺度边界层细节。
- 我在正文发现：全文没有任何像素级或速度场定量误差（无 PSNR/SSIM/EPE），合成真值对比只有定性图；唯一「定量」是 Table 1 的参数尺度与 15 人主观评分，且评分只给热图、无均值与显著性——证据强度不足以支撑「物理忠实」这一强主张。
- 我在正文发现：相机内参、位姿与单目尺度如何获得，正文完全没交代，而反投影 v_surf=(S∘(PW)+T)^{-1}∘v_2D 显式依赖 P、W、S、T；同时管线对上游生成器极敏感（TriplaneGaussian 低分辨率、TRELLIS 偏离输入），N 由 PSNR 相似度决定也缺敏感性分析。这两点是复现时最大的未知。

## 与文献库的关系
与文献库的流体/可仿真资产线直接相邻：SplashSplat 做飞溅液体的重建，DELUGE 解决粒子流的压缩与实时传输，RIE 与 yubi-real2sim 关注「重建结果→可移动/可仿真资产」的转换，simuscene 做仿真就绪场景组装。本文与它们的差别是把物理参数当显式输出，用可微 APIC 反解 ν、ρ、b/d、v_in/v_out，因此资产可改材质、改重力、加交互物。与 PhysGaussian、GaussianSplashing、PhysDreamer、BAGS 相比，它针对开放系统（有出入口、物质进出）而非闭合可变形体，且不优化逐点形变。在 3DGS 动态重建主线（4DSurf、Stream4D、Hand-4DGS 一类）里，它属于「放弃逐帧形变、改走仿真」的分支：重建负责几何与外观，仿真负责物理与可编辑性。

## 可复现性（代码/数据/硬件）
