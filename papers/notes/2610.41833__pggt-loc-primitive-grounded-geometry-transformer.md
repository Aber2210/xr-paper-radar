# PGGT-Loc：基元接地的几何 Transformer 前馈相机定位

## 一句话结论
Pggt-Loc 以 DUSt3R 式双分支跨模态 Transformer 把查询图像 patch 直接 grounding 到平面地图基元，单次前馈输出 6-DoF 位姿：ScanNet 上（0.2m,10°）召回 69.0%、中位误差 2.7°/0.14m，较 PlanaReLoc+Refine 三项召回平均相对提升 28.6%，并在最小 layout 模型上以无需穷举渲染与 FoV 先验的方式全面超过 SPVLoc。

## 要解决的问题
现有相机定位多依赖需昂贵构建、存储与维护的专用地图（structure-based 2D-3D 匹配、mesh/NeRF/3DGS 渲染）；而紧凑且人类可读的高层基元地图（平面表面图、layout 模型）与视觉观测间存在显著 modality gap，潜力未被利用。PlanaReLoc 依赖外置 plane recovery 模块且其三阶段流水线无法用于 minimal layout models；SPVLoc 的 render-and-compare 需穷举采样视点渲染并丢失结构信息。目标：无需显式对应求解或穷举渲染、可泛化到未见环境的 feed-forward 6-DoF 定位。

## 方法详解
Pggt 继承 DUSt3R 双分支互联 decoder 架构：查询图像经冻结的 DINOv2 ViT-Large patch 化为 l_q 个 patch token；平面基元集合经可训练 primitive embedder（PointNet 3D 编码器 + MLP 平面参数位置编码，每基元采 1024 点）化为 l_m 个 token；每层 cross-attention 实现跨模态交互，query 分支接 Dual-DPT 层（聚合第 2/5/8/11 层 token）产出像素对齐稠密特征。四个预测头：patch-primitive 软分配矩阵（描述子相似度 × 置信度，confidence 超阈值 τ 后取 argmax 赋值）、逐像素平面参数图 P∈R^{3×H×W}（预测 n/d，锚定于 query 坐标系）、逐像素 camera ray 图 R∈R^{6×H×W}（[d;o] 过参数化隐式编码位姿与内参）、prepended camera/map token 直接解码位姿。位姿推断三条通路：Param.-based（用分配矩阵做点对平面 registration）、Ray-based（ray origin 平均得 t、ray direction homography 分解得 q）、Token-based。多任务损失 L=L_assign+L_param+L_ray+L_pose。训练用约 400K query-map pairs（ScanNet/ScanNet++/Matterport3D/MP3D-Habitat，4000+ 场景），N=12 层、l_q=1200、AdamW 峰值 lr 2e-4、125K 迭代、batch 128、8×H20 约 2 天。Layout 任务另加 Semantics Injection（wall/floor/door/window/ceiling 五类语义嵌入 + 辅助分割监督）与 Isolation Injection（房间级 attention mask），在 3250 个 Structured3D layout 上从头训练（每基元 256 点，FoV 45°–135°）。

## 实验与结果
稠密表面图：ScanNet 测试集 7735 图/303 场景，Ours(Ray) 中位 Δq=2.7°、Δt=0.14m，三档召回 69.0/92.7/95.4%，大幅优于 PlanaReLoc+Refine（3.8°/0.20m，48.5/73.1/81.8%）、PlanaReLoc（37.1/69.8/79.8%）、MeshLoc、MASt3R、MatchAnything、NOPE-SAC、Plana3R、PlaneRecTR++、GeoTransformer、FreeReg；12Scenes 跨域 1023 查询中位 3.6°/0.15m，召回 68.6/90.1/93.8%，基元匹配 F1 76.0%、AP 92.4%。Layout：S3D-official（6405 图/250 场景）中位 2D 误差 11.2cm/0.42°，1m&30° 召回 93.5%，优于 SPVLoc（12.9cm/1.26°，84.2%）；S3D-resampled 90°FoV（3426 图）10cm 召回 56.0% vs SPVLoc 50.1%，120°FoV 91.7% vs 88.0%。消融：去掉 L_assign 或 L_param 明显掉点（62.0→54.7/54.9），语义单独加入反而掉点、与 isolation 联合协同；显式平面参数主要提升细粒度精度；Integrated Rooms 多房间合并随规模扩大召回显著下降。平面恢复副产品 RI 0.94、depth RMSE 0.16，超 PlaneRecTR/ZeroPlane/MoGe-2+RANSAC。

## 局限与风险
论文明示：surface map 与 layout 两类任务需分别训练、尚未统一；仅限由平面基元构成的地图，不适合非结构化或非平面场景；主要在房间尺度室内训练，多房间合并地图上召回随规模显著下降，未验证真实大型建筑或室外；失败案例源于运动模糊/低光照、结构细节有限或高度重复模式、无信息查询观测。客观不足：部分案例中 Ray 通路不如 Param.-based；深度估计准确不等于定位成功（重复模式歧义）；全图推理方式限制大规模地图扩展。

## 与文献库的关系
处于 DUSt3R 式前馈几何 Transformer 与高层地图相机定位两条线的交汇：架构上承接 DUSt3R/MASt3R/VGGT 一系可扩展多视图 Transformer 范式；任务上直接对标并大幅改进同组前作 PlanaReLoc（CVPR 2026，平面基元 region matching，数据管线亦沿用其工作流）与 SPVLoc（ECCV 2024，layout render-and-compare），并与 MeshLoc、F3Loc、LASER 等 render-and-compare 及 GeoTransformer/FreeReg 等 I2P 基线比较。对 XR/AR 谱系而言，它把无纹理、紧凑、可人工编辑的结构地图纳入实时 6-DoF 定位的可选项。

## 可复现性（代码/数据/硬件）
代码与模型已开源：https://github.com/3dv-casia/PGGT-Loc ；训练数据由公开数据集（ScanNet、ScanNet++、Matterport3D、Structured3D）按 PlanaReLoc 工作流处理，论文附录 A.1/A.2 给出数据统计与完整实现细节；训练约需 8×H20 GPU 2 天。

## 行动建议
AR 设备端重定位的前馈新范式：ScanNet（0.2m,10°）召回 69.0%（PlanaReLoc+Refine 48.5%）、中位 2.7°/0.14 m，免显式对应求解/PnP/穷举渲染且不依赖相机内参先验，代码与模型已开源；仅限平面基元构成的地图、多房间合并地图召回随规模显著下降、surface/layout 两类任务需分别训练是落地缺口；与库内 SplitGS-Loc（高斯特征场定位）构成「结构基元 vs 高斯特征场」两条设备端定位路线。
