# DUALingo：面向三维物体可供性定位的双手指令引导数据集

## 一句话结论
首个把「自由文本任务 + 双手协作角色 + 3D 表面热图」三者结合的数据集：角色与左右手解耦，使同一标注可映射到任意机器人构型，标注侧用首步 token logit 差做视角置信度、角色对比式 SAM2 分割，全流程零人工标注——71K 物体 / 271K 任务，Dual-Espresso-3D 上 aIoU 10.3→37.8。

## 要解决的问题
可供性定位要回答智能体应在物体何处交互，但大量日常操作需要双手扮演互补协作的角色（如一手拧瓶盖、一手反向握瓶身），而现有 3D 可供性数据集（3D AffordanceNet、LASO、Affogato、DualAfford、DA²）基本只定位单一交互区域，把两次接触之间的关系留作隐式；双手数据集（ARCTIC、OakInk2、GigaHands、2HANDS）又多为动捕或 2D 掩码，缺少自由文本任务条件下的三维协作角色标注。人工标注双手协作接触无法扩展，这一空白直接限制了协作机器人与具身智能体的可供性推理。

## 方法详解
构建全自动标注流水线，仅用开源权重基础模型，四阶段完成。Stage 1 用 Gemma-4-26B-A4B 在 8 个语义视图（1 俯视 + 1 仰视 + 6 斜视）上筛选适合双手日常操作的对象，并输出（部件, 用途）对集合 C_i。Stage 2 生成对象级/部件级/功能级三类多粒度任务（占比 38.74%/39.30%/21.95%），并把每个任务分解为两个与左右手无关的协作角色 r∈R_hand={hold, lift, push, pull, press, slide, rotate, squeeze}，同时按模板填出指向查询“Point to ⟨contact region⟩ where a robot hand should ⟨role⟩ it to ⟨function⟩”。Stage 3 用 pointing VLM Molmo2-8B 在 40 个视图上预测候选接触点集合 S，并提出自适应多点定位：取首个解码步 <points> 与 “There are none” 的 logits 之差做视角置信度 c=σ(ℓ_point-ℓ_none)，既过滤被遮挡视角又保留同目标多实例（如滑板四个轮子）；再用 SAM2 以另一角色的点为负提示做对比式分割，抑制跨角色泄漏。Stage 4 对每个像素的多个掩码取均值合并，按深度与相机参数投影到点云，并按置信度加权跨视图融合 h*(p)=mean_{j∈V(p)} w·M̄，其中 c≥0.9 时 w=1，得到一对角色热图。

## 实验与结果
- 规模：71K 个 3D 物体、271K 条自由文本双手任务、542K 张角色专属表面热图
- 基准：Dual-Espresso-3D 把 aIoU 从零样本 10.3 提到 37.8（>3×），AUC 从 53.7 提到 79.5，SIM 39.8→62.8，MAE 0.331→0.191
- 零样本迁移失败：三个原模型 AUC 仅 50.4–53.7（随机基线 50），两个角色热图 top-10% 的 IoU 约 0.6，几乎定位同一区域
- 角色准确率：最佳 78.8%（Dual-PointRefer 79.1），全部模型仍低于 80%、AUC 低于 80
- 标注质量：全库 LLM 评判 92.5/95.7/89.7（任务/角色/热图），与 1K 人工专家评分差 0.8/0.8/0.6，AC1 判官-专家 0.82/0.93/0.74 与专家间一致度相当
- 机器人演示：ManiSkill3 中未见物体上完成抬锤约 15cm、笔记本开合 45°→110°、平底锅倾斜 96°，标注共耗 1,060 GPU-hours（<1 GPU-分钟/物体）

## 创新点与贡献
- 首个把“自由文本任务 + 双手协作角色 + 三维表面热图”三者结合的数据集：角色与左右手解耦，使同一标注可映射到任意机器人构型，这是此前 3D 可供性数据集与双手数据集都不具备的组合
- 标注侧提出自适应多点定位（用首步 token logit 差做视角置信度）与角色对比式 SAM2 分割，解决了单点定位在多实例与被遮挡情形下的漏标和跨角色泄漏，且全流程零人工标注、可扩展

## 局限与风险
- 绝对性能仍低：最佳 aIoU 37.8、角色准确率 78.8%、AUC 未过 80，说明双手角色推理仍是开放问题，现有单区域模型加角色嵌入的适配方式明显不足
- 数据全部来自合成 3D 资产渲染（Objaverse 系），与真实场景的材质、光照、遮挡分布存在域差
- 机器人验证仅在 ManiSkill3 仿真中用脚本控制器完成，未做真机闭环，也未评估接触力/滑移等物理可行性
