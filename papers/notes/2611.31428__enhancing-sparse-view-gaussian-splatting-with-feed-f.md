# 基于频域融合与蒸馏的稀疏视角 Gaussian Splatting 前馈先验增强

## 一句话结论
把「前馈先验 vs 稀疏高斯」的取舍转成频域可靠性问题，用实测近似 1/f 律的一参数低通核解释权重，再「融合成 teacher → 蒸馏回 Gaussian」（推理期不引入任何额外网络）——StereoGS / DropGaussian / FSGS 分别 +1.01 / +1.01 / +1.18 dB，且弱先验会自动得到接近 0 的 f0。

## 要解决的问题
稀疏视角 3DGS 在训练视角附近清晰，但在输入未覆盖的远处区域质量急剧退化；feed-forward NVS 先验虽能跨场景重采样，却比 Gaussian 渲染慢 10 倍以上，并在 out-of-domain 场景产生高频伪影。在 Mip-NeRF 360 garden 的 12 视角设置上，LagerNVS 平均仅 21.20 dB，反而低于 StereoGS 的 21.38 dB，因此把先验直接当监督信号会失败。

## 方法详解
作者先在频域逐环测量两种渲染与 GT 的相关性，发现先验在低频更准、Gaussian 在高频更准，两条误差曲线只交叉一次。把融合写成频域加权和 C=w(f)P+(1-w(f))G，并按环给出最小二乘闭式解 w*(f)=Σ Re⟨Y-G, P-G⟩_f / Σ‖P-G‖_f²。测得的最优权重噪声大且需要 GT，因此用单参数一阶低通核 K(f)=1/(1+f/f0) 参数化，f0 为权重 0.5 的交叉频率，仅在 development set 上拟合一次。用该核生成 fused teacher：T=K(|f|)P+(1-K(|f|))G，并把直流项强制 K(0)=0 以避开先验的全局色偏。teacher 位姿在相邻输入相机间插值（t∼U[0.15,0.85]，slerp 旋转，加 0.1·d̄ 高斯扰动），采样 M=512 个位姿各渲染一次。最后把 teacher 图像与真实输入图像以 λr:λt=1:1 混合，用标准 3DGS 光度损失 ℓ=0.8ℓ1+0.2(1-SSIM) 继续优化 Gaussians 12k 步（不增密），teacher 项先减去逐通道均值以只监督结构。推理时只跑 Gaussian，前馈模型完全移除。

## 实验与结果
- Ours-Teacher 在 StereoGS/DropGaussian/FSGS 上平均提升 1.22/1.60/1.62 dB PSNR；蒸馏后 Ours-Distilled 仍提升 1.01/1.01/1.18 dB
- StereoGS 全 42 设置均值由 23.15 dB/.754/.199 提升到 24.16 dB/.766/.184，渲染 917 FPS（基线 882 FPS），无额外 Gaussian
- Ours-Teacher 33 FPS，Ours-Distilled 相对其快 28×，质量接近
- 一阶核拟合 R²=0.993（StereoGS）、0.989（DropGaussian）、0.991（FSGS），仅一个参数
- 拟合交叉频率 f0=0.041/0.062/0.077 cycles/pixel（StereoGS/DropGaussian/FSGS），方法越弱 f0 越大
- 蒸馏单场景约 3 分钟（Fern-3 2.5 min、Garden-12 2.9 min），仅增加 6%–8% 训练时间

## 创新点与贡献
- 把「前馈先验 vs 稀疏 Gaussian」的取舍转化为频域可靠性问题，并用经典线性估计的相对可靠性给出可解释的一参数低通核（实测相对可靠性近似 1/f 律）
- 提出「融合成 teacher 再蒸馏回 Gaussian」的 plug-and-play 流程，推理期不引入任何额外网络，因而同时拿到先验的低频布局与 Gaussian 的高频细节
- 方法对先验模型与基座方法都通用，DepthSplat/AnySplat 这类弱先验会自动得到接近 0 的 f0 而基本不干预

## 局限与风险
- 有效性依赖「先验低频确实优于 Gaussian」这一前提：DepthSplat 与 AnySplat 拟合出的 f0 约 1e-4，teacher 反而带来 -0.02/-0.04 dB
- 基座模型训练极差时只能减轻而不能消除 artifacts（room-24 仍有 floaters）
- f0 需按基座方法在 development set 上拟合一次，且蒸馏需约 3 分钟额外优化，不是零成本后处理
