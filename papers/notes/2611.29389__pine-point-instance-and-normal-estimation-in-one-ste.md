# PINE：单步扩散模型中的点图、实例与法向联合估计

## 一句话结论
为 DiT 补上三处结构性缺口（token 流 + stream mask 处理置换不变目标、射线位置编码替代像素索引、DINOv3 亲和度注入实例监督），单步同时出点图/法向/实例：点图 Rel^p 4.16（无内参），深度 Rel^d 2.79 优于 MoGe-2 2.87。

## 要解决的问题
场景理解同时需要几何（点图、法向）与语义（实例），但现有方案要么用两个独立网络串行推理、延迟与显存叠加，要么用通用模型多次前向（DICEPTION 每张图一次前向，OneDiffusion 每张图多步采样）。更根本的是 Diffusion Transformer 为 RGB 设计，三个假设被打破：实例图在颜色置换下等价、没有可去噪的固定目标；点图沿相机射线放置深度而 transformer 按像素索引 token，导致全图与裁剪图给同一场景点两个位置；法向与实例在表面/物体上恒定，但注意力仅从 token 难以恢复分组。此外点图模型可输入内参、扩散法向估计器却只吃图像，各图不共享同一相机。

## 方法详解
PINE 是一个单步 Omni Diffusion Transformer，把三张图表示为三条 token 流 $X=[X_p;X_n;X_i]$（共 3L 个 token），经 DiT block 处理，adaLN-Zero 以各流自己的 timestep 为条件。几何流用 flow matching：$z_s=t_s x_s+(1-t_s)\sigma\epsilon_s$，网络预测干净图并由 $\hat v_s=(\hat x_s-z_s)/(1-t_s)$ 回归速度；实例流固定 $z_i=0,t_i=0$，从图像特征一步回归，用聚类损失监督（沿用 gen2seg）。Stream mask 写入注意力 logits，几何两流互相可见、与实例流双向屏蔽，使实例图成为图像的确定性函数而不受几何噪声影响。Camera-aware ray encoding 用 $[u',1]^\top=K_{ref}K^{-1}[u,1]^\top$、$\rho_j=u'_j/p-1/2$ 把 patch 位置换成参考相机上的射线落点，替换 sine-cosine 与 2D RoPE，使注意力看到射线偏移而非像素距离；内参未知时用默认相机加学习 embedding，事后由点图以最小二乘恢复焦距。Grounding attention 把冻结 DINOv3 特征的亲和度 $b_{jl}=(Ug_j)^\top(Vg_l)$ 加到法向/实例流内部注意力 logits，把注意力约束回查询 patch 所属区域（点图流不加，因为深度依赖全局布局）。总损失 $\mathcal{L}=\mathcal{L}_{vel}+0.1\mathcal{L}_{rel}+0.5\mathcal{L}_{grad}+\mathcal{L}_{sink}+0.02\mathcal{L}_{inst}$，从 PointDiT 权重初始化，用 139K 合成 + 24K 真实图像训练 20 epoch。

## 实验与结果
- 点图平均 Rel^p：PINE-H 4.16（无内参）/3.33（有内参），对比 MoGe 4.21、MoGe-3 4.79、PointDiT-H 4.45（7 数据集 3,444 图）
- 深度平均 Rel^d：2.79（无内参）/2.65（有内参），对比 MoGe-2 2.87、UniDepthV2 2.87
- HAMMER 上 Rel^p 从 PointDiT-H 的 3.51 降到 2.96（约 16%）
- Sintel 法向平均角误差 25.6° vs MoGe-3 26.4°，11.25° 内精度 32.5% vs 29.1%
- 实例：大目标 COCO_exc mIoU 超 SAM 17.6、DRAM 超 10.7；小目标 COCO 仅 9.2 vs SAM 57.2
- FOV 平均误差 5.35° vs FoundationGeo 6.70°、PointDiT-H 13.46°；HAMMER 3.70° vs 19.30°
- 比 MoGe-3+SAM 快 5.7×、比 SAM 单独快 3.1×；1.85B 参数 137 ms vs Marigold V2+SAM 22.3B/1399 ms

## 创新点与贡献
- 真正新意不在「三任务一个网络」，而在为 DiT 补上三处结构性缺口：用 token 流 + stream mask 处理置换不变目标、用射线位置编码替代像素索引同时兼容有无内参、把 DINOv3 亲和度直接写成注意力偏置来注入分组先验
- 其代价极低：仅 139K 合成图训练，点图仍超过用 890 万帧训练的 MoGe-3 的法向平均排名

## 局限与风险
- 作者承认点图缺少 metric scale，且在中/小目标实例上仍明显落后 SAM（COCO 小目标 9.2 vs 57.2 mIoU），未来想把 metric scale 与语义类也做成新流
- 正文可见的局限还有：137 ms 推理（约 7 FPS）仍不足以支撑强交互
- 法向并非全面最优（NYUv2 15.3° vs MoGe-3 14.7°）
- 训练数据以合成为主（139K synthetic vs 24K real），实例仅 87K 图，跨域真实性未单独评估
