# PriorGS：先验引导的单曝光 HDR 新视角合成

## 一句话结论
PriorGS 以伪 HDR 监督、base-gain 高斯表征与 DoRF 先验约束的可学习 CRF 解决无 HDR GT 的单曝光 HDR-NVS，真实场景重曝光 LDR PSNR 24.31/23.00 dB、合成场景 HDR-NVS PSNR 31.22 dB，较全部基线提升约 4-8 dB。

## 要解决的问题
单曝光 LDR 视图作为唯一直接监督源时，高光裁剪与阴影噪声造成的信息丢失使 HDR 重建在数学上欠约束，缺先验的方法能复现训练曝光却恢复错误辐射度。同时单曝光只能监督 CRF 在有限 unsaturated 区间内的行为，现有 MLP-CRF 泛化差且不保证单调性，启发式固定 CRF 又有响应失配风险。此外逐视图生成的伪 HDR 目标存在跨视图不一致，直接编码为高斯颜色会引发严重颜色与几何伪影。

## 方法详解
PriorGS 基于 3DGS，每个高斯携带两组 RGB SH 系数：β^c 编码 LDR base 颜色、β^g 编码 log-gain，HDR 辐射度 h=(l+δ)⊙2^g−δ（δ=1/64，l 为反 gamma 线性值），同一几何分别渲染 LDR base 与 HDR 视图。训练前用 2D 单曝光 HDR 方法（主选 IntrinsicHDR）为每个训练视图生成伪 HDR 目标施加先验。CRF 为 f(E)=t(η(E))：t(x)=(1+σ)x^n/(x^n+σ) 取 DoRF 201 条曲线平均响应的双参数单调近似，η(E)=sigmoid(a·ln(E+ε)+b) 为可学习软归一化，逐场景学习四参数、RGB 三通道共享、构造上严格单调；拟合 DoRF 平均 MSE 2.081e-5（较双参数响应降 63.6%）。闭环重建要求 HDR 渲染经 CRF 重曝光后匹配输入 LDR；总损失 L=L_base+0.5L_HDR+0.5L_ReExp（HDR 项 μ-law 压缩，μ=5000）。base-gain 表征另支持以系数 ρ 缩放 gain field 做视图一致的 3D HDR 外观编辑。

## 实验与结果
在 HDR-NeRF（4 真实+8 Blender 合成）与 HDR-Plenoxels（4 真实）按单曝光协议评测：每场景 5 个曝光、只训 1 个、其余 4 个做重曝光并取平均；18 训练/17 测试视图（HDR-NeRF）、27/13（HDR-Plenoxels）。真实场景重曝光 PSNR 24.31/23.00 dB、SSIM 0.9248/0.9021、LPIPS 0.064/0.092，超 GaussHDR（16.28/17.73）与 SeHDR（13.75/14.21）约 7-8 dB；合成 HDR-NVS PSNR 31.22 dB（基线最高 26.96）、重曝光 22.96 dB（基线最高 15.76）。消融：去先验跌至 18.39；直接编码在 HDR-Plenoxels 跌至 15.05；固定 gamma CRF 跌至 14.87。训练曝光处 LDR-NVS 亦最优（真实 36.10 dB），且对 4 种 2D HDR 方法均鲁棒。

## 局限与风险
论文自述：受 2D HDR 重建方法质量限制，伪 HDR 目标中丢失纹理恢复不佳会拖累重建；跨视图不一致仍可能被编码为虚假视角相关外观。客观看：数据集小（每数据集 4-8 个场景）且仅静态场景；真实场景性能对所选 2D HDR 方法敏感（GMNet 变体在 HDR-Plenoxels 的 PSNR 不及 GaussHDR）；HDR 指标依赖逐场景亮度校正与 μ-law 协议；伪 HDR 按全场景最大辐射度归一化引入额外假设。

## 与文献库的关系
位于 HDR-NVS 主线：从多曝光的 HDR-NeRF/HDR-GS/GaussHDR 到单曝光的 SeHDR、Mono-HDR-GS 演进线，直接对标这两个同期单曝光工作。其伪 HDR 先验承接 2D 单曝光 HDR 重建（Eilertsen、IntrinsicHDR 一系），base-gain 表征对应 2D 域 LDR-gain 格式（ISO 21496-1、Ultra HDR、Gain-MLP），CRF 先验源于 DoRF 数据库与 Eilertsen 双参数近似，是把 2D 逆色调映射知识系统迁移进 3DGS 框架的代表工作。

## 可复现性（代码/数据/硬件）
实现基于公开的 HDR-GS 代码，使用公开 HDR-NeRF/HDR-Plenoxels 数据集与公开 IntrinsicHDR；作者声明发表后将在 GitHub 公开实现；单张 RTX 3090（24GB）可复现全部实验；CRF 初始化（DoRF 平均响应）与超参见附录 A.3。
