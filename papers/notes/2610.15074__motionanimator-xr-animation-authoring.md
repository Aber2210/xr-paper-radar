# MotionAnimator：XR 中部分结构化 3D 资产的语义到运动推理动画创作

> 批次：2026-10-19 补漏批次（公告日 2026-10-10，拉取日 2026-10-19，积压补漏非当日新提交）。

## 一句话结论
把「XR 里让 3D 资产动起来」重构为语义运动接地问题：语义理解代理（SUA）+ 运动规划代理（MPA）把用户意图解析为部件级参数化运动计划，再生成 Unity C# 代码在运行时编译执行；Quest 3 实测 SUA 物体身份 97.78%/部件标注 96.90%/方向框架 99.26%，端到端人评 IMA 5.83±1.16（ICC(2,5)=.794），去掉 MPA 得分从 5.57 崩到 2.54。

## 要解决的问题
3D 数字资产（教育/仿真/设计/沉浸式内容）大多只有几何与部件结构、缺语义标注与可执行行为；动画仍需手工 rigging、模板或编程，门槛高。MotionAnimator 让未标注资产在 XR 里边想边动。

## 方法详解
意图 + 结构化 XR 场景上下文 + 目标聚焦捕获 → ① SUA 识别物体与功能部件、推断部件级运动 affordance（含语义方向框架 grounding）；② MPA 构造对象级/部件级协同的参数化运动计划；③ 生成 Unity C# 代码，运行时编译成可执行 XR 动画。实现：Unity 2022.3.58f1 + Meta XR All-in-One SDK/OpenXR，部署 Meta Quest 3，语音经 OpenAI 转录。

## 实验与结果
技术评估：SUA 三指标 97.78/96.90/99.26%；MPA MPF1 99.16% 但 MAA 87.77%（「哪些部件该动」易、「怎么动」难，Aerial Mobility 运动轴错误率最高 75%）。人评动画：5 名独立评估者（2 VR 开发+2 教师+1 学生）×30 case-level means，OLM/PLM/MD/OPC 四维 7 点量表，Full 5.77±1.15（Avg 5.57±1.35）；消融：w/o MPA 2.54、w/o SUA 4.14、SUA w/o SF 4.83、MPA w/o GE 5.07；Wilcoxon 配对 + Holm 校正；编译成功率 100%。

## 创新点与贡献
① 把 XR 动画创作定义为「语义运动接地」新任务；② 意图→计划→运行时代码的闭环（而非预制模板）；③ 人评+编译成功率+消融三重证据。

## 局限与风险
① 运动轴/关节接地的精确度是主要失败源（MAA 87.77%，复杂几何行为更难）；② 依赖 LLM 语义先验，领域外资产可能误判 affordance；③ 单场景/单用户评估规模有限（n=30 case means）；④ 无长期创作工作流研究。
