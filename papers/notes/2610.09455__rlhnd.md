# RLHND：视频基础模型驱动的物理接地手部追踪

## 一句话总结
基于预训练视频基础模型（Cosmos 3 + LoRA）的物理接地手部追踪器：同时输出 MANO 姿态与逐顶点接触/力信号，使手部追踪具备物理一致性，直接提升机器人策略训练质量。

## 问题背景
- 现有手追踪多从裁剪帧回归姿态，对手部运动与物体交互先验有限，且缺少接触/力等物理线索 → 估计不准确、物理不一致。
- 机器人策略训练依赖高质量人类视频手追踪标签，物理不一致会拖累策略。

## 方法
- **清洁潜变量编码器**：用 Cosmos 3 预训练编码器的 conditioning 接口（非空噪声去噪接口），LoRA 微调 patch embedding 与生成通路，得到确定性时空特征网格。
- **Pose Expert Stream（阶段1）**：从视频特征预测 MANO 参数（shape β^、articulation θ^、全局腕旋转）、度量相机空间平移 τ^、每帧手部存在/可见性。
- **Tactile Expert Stream（阶段2，冻结 pose）**：从同一视频特征以独立权重预测逐顶点触觉——接触概率 c^（778 MANO 顶点）与力 f^，解耦触觉与姿态预测。

## 实验与结果（关键数字）
- 姿态：HOT3D/ARCTIC held-out + EgoDex zero-shot；触觉：OpenTouch / PressureVisionDB（PVDB）测试拆分，及 HOT3D/DexYCB/ARCTIC 网格派生接触标签（仅接触）。
- 手腕深度中位偏差 2.3 cm，比 HaWoR 低 17.8%。
- 取得 SOTA 运动重建与触觉估计；跨 5 种灵巧手平滑重定向；DPP + RLHND 在无人工标注下超越原 tracker。
- 将释放实现与预训练权重。

## 贡献与局限
- 贡献：把"视频基础模型的强运动/交互先验"转成确定性手部特征；首次在前馈手追踪中联合输出接触与力；即插即用于机器人策略。
- 局限：依赖预训练视频 backbone 规模；触觉精度受标注数据量限制；跨域（非手部交互）通用性待验证。
