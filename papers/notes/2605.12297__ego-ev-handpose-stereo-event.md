# EgoEV-HandPose：双目事件相机的第一视角三维手部姿态与手势识别

## 一句话结论
在新建 EgoEVHands 的跨被试（HETER）设置下，EgoEV-HandPose 取得 30.54 mm MPJPE 与 86.87% 手势识别准确率，比 HandMvNet 低 57.5%、比 Ev2Hands 低 73.5%。

## 要解决的问题
第一人称的 3D 手部姿态与手势识别是人机交互与动作理解的基础，但困难重重：基于帧的相机在快速手部运动下产生运动模糊、动态范围有限；事件相机虽具高时间分辨率与宽动态范围，却面临头部自运动产生的背景事件干扰、单目事件的深度歧义（双手互遮时尤甚）、以及缺少带姿态级标注的真实立体事件数据。MANO 等参数化手模型提供解剖先验，但先验只约束构型空间，不能替代来自观测的显式几何约束。现有工作要么只做手势语义、不给运动学姿态，要么在单目设置下受深度歧义与尺度变化困扰，要么依赖合成数据训练。立体事件数据集的缺失进一步阻碍了几何感知的双手感知研究。

## 方法详解
输入同步左右事件流，输出 J=42 个关节的三维位置与 38 类手势之一。事件以时间窗 ΔT 内的 Locally-Normalized Event Surfaces（LNES）表示（H×W×2），左右视图共享权重的 EgoBlaze 骨干（EROS 时序缓冲 + Blaze 卷积编码器，通道 16/32/64/128/192，瓶颈为两层 192 维 Mamba，含抑制背景响应的 Confidence Gate）输出热图 H、分割 A 与中间特征 F（式 3）。热图分辨率 180×320，对每个关节做空间 softmax（β=100）后取可微期望并乘 4 还原到 1280×720 坐标（式 4），得到 Û^l、Û^r。解析立体初始化不含任何学习：先用标定参数做 5 次径向畸变迭代校正，每点定义一条射线 r_j^v(t)=c^v+t d_j^v（式 5），因定位误差两射线一般不交，求最近点对 (t^l*, t^r*) = argmin‖c^l+t_l d^l − c^r − t_r d^r‖²（式 6），取中点得 p_j^(0)（式 7），并对退化配置、负深度、不可见与非有限解置无效掩码。KeypointBEV 在此基础上做 3 次学习更新：把两视图特征池化后 1×1 卷积投到 D=512 并拼成全局记忆 M（式 8）；维护 J 个关节查询，用归一化位置编码经 sigmoid 门调制得几何编码（式 9）；把当前三维假设投影到两视图并按特征图尺度归一化，双线性采样得到与假设相关的局部证据 h_j^v,(k)，左右融合成 H^(k)（式 10–11）——这与无条件拼接立体特征的关键差别在于采样位置随三维假设移动；随后 TransformerDecoder(Q+Ẽ+H, M)（单层、8 头、FFN 2048，式 12）输出，经 512→256→3 回归头得 Δp，按 p^(k+1) = p^(k) + α^(k)·clip(s_Δ Δp^(k), −τ^(k), τ^(k)) 做有界更新（式 13），三次更新共享解码器与回归头。训练分阶段：先以热图 MSE + 分割 BCE 预训练 EgoBlaze，冻结后 warm-up KeypointBEV，再用缓存 2D 序列初始化时序分类器，最后全网络联合微调（含分类梯度回传到姿态估计）。损失含三维 SmoothL1(β=10 mm) 只监督最终步、每步重投影 L1、分类交叉熵；手势侧把最终姿态重投影到两视图，每帧 2×42×2=168 个坐标送入时序 Transformer。

## 实验与结果
['1) 数据集：EgoEVHands 含 2,498 对标注立体事件序列、10 名被试、38 类手势，双 Prophesee EVK4（1280×720、4 mm 广角）+ RealSense D435 刚性同装，覆盖正常光与低光、单手/双手无遮挡/自遮挡/互遮挡四组交互。', '2) 主结果：HOMO 22.03 mm、HETER 30.54 mm MPJPE；HETER 低光 29.50 mm 反优于正常光 31.49 mm，双手交互 29.86 mm，互遮挡 31.02 mm（HOMO 22.13 mm）。', '3) 与 SOTA 对比（均在 EgoEVHands 上重训）：HETER 30.54 mm vs HandMvNet（低光子集 82.43 mm）低 57.5%、vs Ev2Hands 115.13 mm 低 73.5%，MPJPE 与 PA-MPJPE 均优于 EvHandPose 与 EventEgo3D。', '4) 固定 2D 骨干的 lifting 对比：EventEgo3D（单目）51.27 mm；BEVFormer 稠密 BEV 32.03 mm 但需 374.14 GFLOPs，KeypointBEV 30.54 mm 仅 19.86 GFLOPs，约 1/19 算力且跨被试更优。', '5) 迭代细化消融：误差从初始化 52.72 mm 降到三次更新后 30.54 mm；PCK AUC（0–50 mm）由三角化基线 0.436 提到 0.589。', '6) 跨数据集/跨架构：把 KeypointBEV 接到 DEV-Pose 上在 DHP19 上把 MPJPE 从 55.53 降到 47.88 mm；全系统 8.44 M 参数、19.86 GFLOPs、13.6 FPS。']

## 创新点与贡献
['EgoEVHands：首个面向自我中心 3D 双手姿态与手势识别的大规模真实立体事件数据集，在 EgoEvGesture 录制基础上补齐密集 2D/3D 关键点、跨视投影、分割掩码、关节级可见性与有效权重（含插值权重 0<w<1 的显式区分）。', 'KeypointBEV：把 BEV 的「统一三维空间推理」思想压缩成稀疏关节查询——不做稠密体素，而是用当前三维假设驱动两视图特征采样，再加全局立体记忆做 cross-attention，几何锚定与特征融合职责分离。', '无需光线求交即可让立体几何闭环：解析三角化给出可解释初值 + 有界残差更新 + 每步重投影监督，使 3 次迭代把误差降 42%（52.72→30.54 mm），并能即插即用地提升 DEV-Pose 在 DHP19 上的表现（55.53→47.88 mm）。']

## 局限与风险
['必须使用自制头戴式双事件相机rig与标定参数，普通 RGB/单目设备无法直接迁移；数据与代码虽承诺在 https://github.com/ZJUWang01/EgoEV-HandPose 发布，但写作时尚未上线。', '姿态标注依赖 RealSense 深度 + Grounded-SAM + MediaPipe 的半自动流水线，含人工筛校与 ≤5 帧线性插值，深度缺失处用邻域深度补偿，标注本身存在误差与主观性。', '仅 10 名被试、38 类手势、单一采集装置；13.6 FPS 未达实时高帧率优势（事件相机本可更高），且手势分类基于重投影 2D 坐标序列，未直接用事件时序。', '双手互遮虽给出 31.02 mm，但仍显著差于单手与无遮挡场景；模型对极端遮挡与快速运动的失效边界未系统刻画。']

## 与文献库的关系
承接三条线：帧基自我中心手部感知（HandMvNet 的立体 RGB 三角化、POEM、LFIENet 类）受运动模糊与动态范围限制；事件基手部感知（Ev2Hands 的双手事件估计、EvHandPose 的单手事件、EventEgo3D 的单目全身）缺立体几何或真实数据；立体融合范式（稠密体素 lifting、两阶段三角化、BEV 投影）中，作者指出既有工作用隐式特征 cross-attention 而非以三维关节假设为中心。KeypointBEV 的 sparse query + 时空融合直接受 DETR3D/Sparse4D 一类稀疏检测启发，把「检测查询」换成「关节查询」。

## 可复现性（代码/数据/硬件）
数据与代码承诺发布于 https://github.com/ZJUWang01/EgoEV-HandPose ；EgoEVHands 将包含立体事件流与时间戳、RealSense 红外/深度、2D/3D 关键点、事件视图投影、分割掩码、标注权重与有效标志、标定参数、手势标签与官方划分，并附预处理与标注转换脚本；底座 EgoBlaze 与 DEV-Pose 为既有工作。

## 行动建议
建议精读 §4.3 解析三角化（最近点对中点初始化 + 无效掩码处理）与 §4.4 的「假设驱动采样」（式 9–13），这两处是性能提升的主要来源；§5.5 的 52.72→30.54 mm 与 PCK AUC 0.436→0.589 是判断其增益的关键证据。若做 XR 头显手部交互，这是目前少有的「立体事件 + 双手 + 真实数据」组合；引用时注意其数据尚未实际开源，且 13.6 FPS 与事件相机潜力不匹配。
