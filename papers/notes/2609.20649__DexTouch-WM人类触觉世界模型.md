# DexTouch-WM：用人的手，去喂机器人的触觉世界模型

## 一句话结论
核心洞察是：**只要把触觉观测与动作空间做成兼容，人类与机器人的操作就共享可迁移的接触动力学**。在真机监督固定（5 小时）的前提下，把人类交互数据从 0 增到 100 小时，**留出机器人域的视觉、几何与接触预测均获显著改善**，且人机任务集**完全不相交**。

## 要解决的问题

富接触的灵巧操作由**无法从图像直接观测**的物理交互状态决定：视觉上相似的运动可能对应完全不同的接触压力、滑移或即将发生的卡死，尤其当手遮挡物体时。**触觉对感知与控制这类交互是必要的**。

只预测视频的世界模型**无法表示决定操作结果的接触动力学**。已有的视觉—触觉世界模型虽然联合预测视觉与触觉观测，但数据获取是主要障碍：**绝大多数通过机器人遥操作采集触觉轨迹，把每个数据集绑定到特定本体与传感器配置**。

问题的结构性约束在于：**每一条训练样本都需要在接触界面上部署物理传感器**——人类的手是廉价的、可规模化的，机器人的手不是。

## 方法详解

### 问题形式化
给定初始 RGB 观测 $\mathbf{v}_0$、双侧触觉图 $\mathbf{x}_0$、语言指令 $\ell$ 与未来位姿序列 $\mathbf{a}_{1:T}$，学习：

$$p_\theta(\mathbf{v}_{1:T}, \mathbf{x}_{1:T} \mid \mathbf{v}_0, \mathbf{x}_0, \mathbf{a}_{1:T}, \ell)$$

### 跨本体兼容的三个关键设计
1. **共享传感布局**：在人手与灵巧机器手上部署**柔性压阻阵列**，采用相同的传感布局；
2. **动作空间重定向**：把人手运动重定向到机器人本体，**两个域使用相同的 67 维位姿表示**（双侧腕部运动 + 双侧 20-DoF 手部构型 + 头部相机运动）；
3. **解剖感知触觉 token（anatomy-aware tactile tokens）** + 对齐的动作条件。

### 架构
视觉专家由 **Wan2.2-TI2V-5B** 及其 video VAE 初始化，配一个轻量触觉专家。遵循 Mixture-of-Transformers：两个流在**每一层 Transformer** 通过带掩码的联合 self-attention 交换上下文，同时**保留各自模态专属的前馈通路**。初始 RGB 帧由冻结的 video VAE 编码。

### 三种下游用法
1. 视觉 + 触觉联合预测；
2. 作为**策略评估的替代环境**（surrogate environment）；
3. 作为**合成轨迹生成器**，产出数据用于真机策略学习。

## 实验与结果

**核心实验设计（本文最值得学的地方）**：真机监督量**固定 5 小时**，把人类交互数据从 0 增到 100 小时，观察留出机器人域的性能变化。人类与机器人任务集**完全不相交**——因此任何改善都不能归因于任务重叠。

结果：在留出的机器人域上，**视觉、几何与接触预测均获显著改善**。

**与 Astronex-World 的关系**：两者都以 Wan2.2-TI2V-5B 为视觉先验起点，DexTouch-WM 在其上追加触觉专家——说明该基座正在成为触觉/视觉世界模型的事实起点。

## 创新点与贡献

1. 把"人类触觉"确立为一条**可规模化的互补数据轴**，而非机器人数据的廉价替代品——论文强调的是 complementary data axis，不是 replacement。
2. 给出了跨本体触觉迁移的**可操作配方**：共享传感布局 + 动作空间重定向 + 统一 67 维表示。
3. 实验设计（真机监督固定、人机任务集不相交）**排除了任务泄漏**，使结论可信。
4. 同时验证了预测、策略评估、合成数据生成三种用途，不局限于单一指标。

## 局限与风险

- 仍需在人手与机器手上**部署压阻阵列**——并未实现"零仪器"（对比同批 `arXiv:2609.20414` TouchSight 用纯自我中心视觉预测力，无需采集端仪器）。
- 录用为 **IROS 2026 Workshop 的 Lightning Talk**，并非主会论文，篇幅与评审深度有限。
- 论文给出的多为"显著改善"的定性表述，本轮抽取的全文段落中未见完整的分档数值表。
- 人类与机器人动力学毕竟不同（手指尺寸、皮肤刚度、驱动方式），重定向误差未量化。
- 未开源。

## 与文献库的关系

**新增 + 取代一个数据采集范式**。

- 取代证据：`arXiv:2609.20649` §I —— "Most existing approaches collect tactile trajectories through robot teleoperation, coupling each dataset to a specific embodiment and sensor configuration." 本文以共享传感布局 + 动作重定向打破该耦合，并在真机监督固定的受控实验中验证收益。

**互补关系**：`arXiv:2609.20414`（TouchSight）走的是**完全无仪器**路线（纯自我中心视觉 → 力），本工作走**轻量仪器 + 规模化**路线。二者是同一问题的两种解法，**不构成取代**；XR 场景若要求零佩戴，优先 TouchSight。
