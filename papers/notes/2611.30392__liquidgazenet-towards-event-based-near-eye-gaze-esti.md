# LiquidGazeNet：面向低光照条件的纯事件近眼视线估计

## 一句话结论
把极性分离的 spike-latency 表示与 LTC 启发的门控 Euler 递归单元结合，用于纯事件低光近眼视线估计：Gaze-FELL 跨被试平均方向误差 3.75°、跨场景 2.41°，首次系统评估不依赖灰度引导帧的纯事件设置。

## 要解决的问题
夜间低光照下的近眼视线估计很困难：在 Gaze-FELL 这类仅靠显示的照明条件下，灰度帧有效可用率只有约 2–3 FPS，运动模糊破坏空间细节，基于均匀帧率的时序模型随之失效。主动红外方案能补光，但需要额外硬件、受部署几何约束且降低便携性；低光图像增强又会引入处理延迟与重建伪影，损害视线轨迹所需的时间保真度。事件相机动态范围高、时间分辨率微秒级，但已有纯事件方法多在受控采集下评测，Gaze-FELL 上的既有工作仍使用灰度引导帧，纯事件可达到的性能缺乏系统考察。

## 方法详解
LiquidGazeNet 是纯事件框架。首先做极性感知的 spike-latency 编码：为正、负极性各维护一张指数衰减时间表面，窗口间按 $S^{\pm}\leftarrow S^{\pm}\exp(-\Delta T/\tau_s)$ 衰减（$\tau_s=50$ ms），窗口内事件把对应像素刷新为 1；再把表面映射为连续延迟 $L^{\pm}=\mathrm{clip}(T_{\max}-CS^{\pm},0,T_{\max})$，其中 $T_{\max}=30$ ms、$C=25$，并把两极性堆叠为 2 通道张量。取 $\Delta T=33$ ms、$T=3$ 个连续窗口，形成 $[B,3,2,260,346]$ 的因果序列，监督最后一个窗口的视线坐标。共享卷积编码器把每个窗口映射为 128 维特征；两层 LTCi 递归单元做时序积分：$q_t=[x_t;h_{t-1}]$，候选态 $\phi_t=\tanh(\mathrm{LN}(Wx_t+Uh_{t-1}+b))$，门 $g_t=\sigma(Gq_t+c)$，正时间常数 $\tau_t=\mathrm{Softplus}(Tq_t+d)+10^{-3}$，更新为 $h_t=h_{t-1}+g_t\odot\Delta t\odot(\phi_t-h_{t-1})/\tau_t$（$\Delta t=1$）。回归头输出归一化屏幕坐标，损失为 $\alpha\mathcal{L}_{\mathrm{px}}+(1-\alpha)\mathcal{L}_{\mathrm{ang}}$，其中 $\mathcal{L}_{\mathrm{px}}$ 为 SmoothL1、$\mathcal{L}_{\mathrm{ang}}=1-\tilde{v}_{\mathrm{pred}}^{\top}\tilde{v}_{\mathrm{gt}}$、$\alpha=0.8$。

## 实验与结果
- Gaze-FELL 跨被试平均方向误差 3.75°
- 跨场景平均方向误差 2.41°（五名被试 2.30°–2.55°）
- 校准参考设置 1.43°（仅作个性化参照，不与无校准跨被试直接比较）
- EV-Eye stateful 配置 5.09°，约 0.37 M 参数（GazeSCRNN 6.03°/2.30 M）
- 消融：binned events + LTCi 8.63° → spike latency + LTCi 3.75°；spike latency + CNN-only 4.78°
- 窗口长度消融：10/20/33/50/66 ms 分别为 5.12°/4.31°/3.75°/4.08°/4.67°
- LTCi 369,522 参数、2.552 ms/batch（B=8）；GRU 2.008 ms、LSTM 1.980 ms
- 跨场景逐被试像素误差均值 29.4 px、中位数 20.2 px

## 创新点与贡献
- 把极性分离的 spike-latency 表示与 LTC 启发的门控 Euler 递归单元结合，用于纯事件低光近眼视线估计
- 在 Gaze-FELL 上首次系统评估不依赖灰度引导帧的纯事件设置，并用屏幕坐标回归加中心参考方向一致性构成混合目标

## 局限与风险
- 作者承认评测仅限 5 名被试、4 个场景组、单一事件传感器与一种近眼采集配置
- 跨被试仍是主要瓶颈
- 所谓方向误差是屏幕中心参考的 2D 向量夹角，并非校准后的 3D 视线射线误差，不能与眼动仪角度误差直接等同
- LTCi 在 GPU 上比 GRU 慢约 27%，且未做嵌入式设备的延迟/功耗测量
- 只有 Gaze-FELL 与 EV-Eye 两个数据集，泛化性有限
