# Wait for It：VR 中 LLM 智能体延迟反馈机制的组件级分析

## 一句话结论
VR 中 LLM 智能体延迟反馈的组件级拆解（N=18 被试内）：具身手势（思考动画）显著提升感知活性（4.22 vs 视觉旋转 3.39/言语填充 3.44，Holm 校正后 p≤0.034）；显式视觉指示分散注意且显著降低人味感知。

## 要解决的问题
AI 响应延迟严重损害沉浸 VR 体验；既往证明反馈可降低等待感知，但不知哪类组件有效、为何有效。

## 方法详解（含关键公式/架构，保留原文术语）
三组件隔离：言语填充（um/hmm）、视觉指示（加载旋转）、具身手势（思考动画）；Unity 6 + Quest 2（Air Link PC-VR）；ReadyPlayerMe 化身 Alex（IK 全身+待机/说话动画）；Gemini 2.5 Flash + Cloud STT/TTS（系统往返约 2.0s）；咖啡馆「找童年朋友聊天」任务；不显示文字转录以强制依赖言语线索。

## 实验与结果（表格化关键数字）
N=18（平均 21.28 岁，61.1% 无 VR 经验）；Godspeed 量表 + 自定义测量；Friedman + Wilcoxon + Holm 校正；延迟一致性核验（各条件实测延迟 χ²(3)=1.13, p=0.769）排除网络方差混淆；活性/拟人/喜爱/感知智能/分心/自然度多维分析。

## 创新点与贡献
三组件隔离比较设计 + 延迟一致性核验方法（把感知差异归因于反馈机制本身）。

## 局限与风险
N=18 偏小；单场景单化身；模拟固定延迟（2s 级）；未测长时程社会化影响。

## 与文献库的关系（新增 / 改进 / 取代 X）
