# ViewDreamer：摆脱固定相机配置的机器人世界模型

## 一句话结论
把逐视角生成与跨视角交互解耦、用块间共享 slot 取代拼贴与全注意力：变数量变顺序相机下仍保持一致，3 视角 FVD 25.41 对 32.93、真机 Franka 闭环 67.5% 对 30.0%。

## 要解决的问题
机器人演示由数量、位置、顺序各异的同步相机采集，而现有视频世界模型要么逐视角独立生成导致跨视角不一致，要么把多视角固定拼贴，牺牲分辨率或让注意力开销随视角数二次增长。另有方法依赖固定相机几何。

## 方法详解
用共享权重的预训练单视角视频 DiT 逐视角生成，在块间插入 Cross-View Interaction 模块，通过 K 个共享 slot token 做 READ/MIX/WRITE 交换跨视角信息，开销随视角数线性增长。Cross-View Slot Agreement 用冻结 DINOv2 与 VGGT-Ω 教师关系监督 last-block READ 的 slot 分配。View-Count Curriculum 从单视角逐步增加视角数以稳定训练。

## 实验与结果
- 3 视角 SSIM = 0.687（Wan2.2-5B 微调 0.662）
- 3 视角 FVD = 25.41（Wan2.2-5B 微调 32.93）
- 3 视角 CVC = 75.693（Wan2.2-5B 微调 69.316）
- LIBERO-Plus 成功率 = 74.9%（FastWAM-Joint 70.0%）
- 真机 Franka 平均成功率 = 67.5%（FastWAM-Joint 30.0%）
- 同 slot 相邻 patch 占比 = 87%（无 CSA 为 39%）

## 创新点与贡献
- 把「逐视角生成」与「跨视角交互」解耦，用块间共享 slot 而非拼贴或全注意力，从而在变数量、变顺序相机下保持一致性且成本线性

## 局限与风险
- 快速运动的腕部相机视角仍难保持一致
- 仅验证到四相机、仅用 Wan2.2-5B 单一骨干，真正任意相机配置未验证
