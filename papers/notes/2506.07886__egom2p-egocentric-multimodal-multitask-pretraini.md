# EgoM2P：第一人称多模态多任务预训练

## 一句话结论
EgoM2P 是首个面向 4D 第一人称数据的多模态多任务大模型：以统一 temporal tokenizer 将 RGB/depth/gaze/camera 四模态离散化，基于 T5-Base 做 multimodal masked pretraining（4B token 库上采样 400B 训练 token，约 400M 参数），在 camera tracking、gaze estimation、单目视频深度与条件视频合成上匹配或超越 specialist SOTA，且推理快一个数量级（60 帧相机轨迹 0.18 s、300+ FPS；深度 0.8 s vs 基线 37–90 s）。

## 要解决的问题
第一人称数据的模态覆盖高度异构：不同设备缺失 depth/gaze，深度流常掉帧，而 gaze 与相机轨迹等缺失模态缺乏有效伪标注器，标准监督学习难以扩展。第三人称视频模型难以应对第一人称的相机快速运动与复杂人机交互，图像域多模态基模型（4M）又缺乏时序一致性，且每样本视频 token 数远超图像（>5000）、模态比例严重失衡（视频 token 约为 gaze 的 170 倍）。

## 方法详解
数据侧汇总 8 个数据集（EgoExo4D、HoloAssist、HOT3D Aria/Quest、ARCTIC、TACO、H2O 与 EgoGen 合成数据）：用 RollingDepth 生成像素对齐深度伪标签，并用 EgoGen 在 Replica 与 GIMO 场景合成约 30 h、30 FPS 数据。统一标准化为 30 FPS、inverse depth（逐序列归一）、gaze 重投影为 2D 平面动点、camera-to-world（OpenCV 约定、首帧参考）。Tokenizer：RGB/depth 采用 Cosmos tokenizer（时间压缩 4×、空间压缩 8×）；gaze/camera 采用统一 Transformer VQ-VAE 架构（Conv Nd 沿时间 2× 下采样 + 位置编码 + 12 个 Transformer block，cosine similarity 量化，损失为重建项 + commitment 项）。视频降采样至 8 FPS 使 token 数降至 1/3；每个 2 s clip（视频 16 帧、非视频 60 帧、256×256）中 RGB/depth 各 5120 token、gaze/camera 各 30 token。预训练沿用 4M 的 masked modeling，但把可见 input/target token 上限从 256 提高到 2048（消融显示平均损失 5.80→4.93）且两者互斥；数据集按样本量比例采样，模态 token 按 Dirichlet 浓度参数（0.01/0.1/1/10 四档均匀浓度）采样；缺失模态以 placeholder 掩蔽（Alg. A.1）。主干为 T5-Base（encoder/decoder 各 12 block、隐维 768、12 头），encoder 对可见输入 token 自注意力，decoder 以 cross-attention 接 encoder 输出并做同模态 masked self-attention，损失为 cross-entropy。推理为 order-agnostic autoregressive 并行解码：线性调度 n 个目标 token 于 s 步，逐步以 classifier-free guidance（ŷ=(1+ω)·ŷ_cond − ω·ŷ_uncond）融合条件/无条件分布并以 nucleus sampling 生成。训练用 AdamW（lr 1e-4、bs 1024、warmup 10B tokens、cosine decay、bf16），256 张 NVIDIA GH200 训练 16 小时，tokenizer 亦从零训练。

## 实验与结果
camera tracking（EgoExo4D val 200 段、未见 ADT 200 段）：EgoM2P ATE/RTE/RRE=0.017/0.004/0.429 与 0.032/0.006/0.490，对比 DROID-SLAM 0.018/0.005/0.506 与 0.034/0.010/0.316、ACE-Zero 0.028/0.007/0.672、Align3R 0.019/0.006/0.762；单序列 0.18 s（基线 2.7–426 s），post-training 后 ADT 0.026/0.005/0.480。gaze estimation（EgoExo4D val 1000 段，归一化 MSE）：0.0162，优于 Huang et al. 0.0255 与 Lai et al. 0.0175。单目视频深度（H2O test 236 段、未见 HOI4D 100 段）：Abs Rel/δ1.25=0.055/96.0 与 0.061/98.0，对比 RollingDepth 0.087/90.5、Align3R 0.074/91.8；推理 0.8 s（至少 30× 加速），post-training 后 H2O 0.041/99.0。depth→RGB 视频合成（HoloAssist 142 段、未见 ASE 100 段）：FVD*/SSIM/PSNR/LPIPS=0.759/0.592/15.163/0.336 与 1.336/0.308/6.923/0.715，优于 Control-A-Video（2.309 与 2.226）与 ControlVideo（1.363 与 1.392）；ASE post-training 后 0.525/0.594/16.924/0.520。EgoGen 消融（Supp. B）：去掉 EgoGen 后 camera tracking ATE 0.017→0.028（ADT 0.032→0.053），depth H2O Abs Rel 0.055→0.062、HOI4D 0.061→0.067。另在 4D 重建上 2 s 视频 <1 s 完成（MegaSaM 需 71 s）；tokenizer 量化误差分析显示 Euclidean 数据上量化不是瓶颈（ATE 0.005），但旋转 RRE 0.272 偏高。

## 创新点与贡献
提出首个 egocentric 4D 多模态多任务模型，支持 RGB/depth/gaze/camera 的 any-to-any 预测与统一训练。把 4M 的多模态掩码建模从图像域扩展到视频域，系统性解决时序一致性、单样本 token 海量（>5000）、模态比例失衡（170×）与缺失标注四大障碍。设计统一 temporal tokenizer 架构，并以 2048 可见 token + 并行解码把推理提速一个数量级，使实时第一人称应用成为可能。

## 局限与风险
合成视频视觉质量受当前 SOTA 视频 tokenizer（Cosmos）量化损失制约，作者建议后续引入 diffusion decoder。RRE 相对偏高，反映 VQ 在非欧几里得旋转空间的量化困难。模型面向离线训练，可穿戴设备算力受限下的部署优化列为 future work；未整合 hand motion、audio、text 等模态。真实深度标注稀缺，训练依赖 RollingDepth 与 EgoGen 的伪/合成标签质量；视频 8 FPS 下采样可能损失高频动态。

## 与文献库的关系
该工作与 EgoGen 同团队一脉相承并直接消费其合成数据（Supp. B.3 量化了增益），构成库内“第一人称数据生成→统一多模态预训练”链路的关键一环。方法上把图像域 4M 的 MMM 范式扩展到 egocentric 视频域，与库内第三人称视频基模型及 egocentric QA 类工作互补，其任意到任意预测与并行推理也可为后续 world model / VLA 研究提供 4D 感知基座。

## 可复现性（代码/数据/硬件）
项目页 egom2p.github.io，论文承诺 fully open-source（写作时尚未释放，全文未述及具体发布时间）。复现资源：训练需 256 张 NVIDIA GH200（16 小时）、约 400M 参数模型、4B token 数据库、400B 训练 token、bf16 与 AdamW（lr 1e-4、bs 1024、warmup 10B tokens）；评测需 EgoExo4D、ADT、H2O、HOI4D、HoloAssist、ASE 等数据集。

## 行动建议
构建第一人称多任务模型时可采用“统一 temporal tokenizer + 缺失模态 placeholder 掩蔽 + 2048 可见 token + 按数据集大小比例采样”的成熟配方，并用 EgoGen 类合成数据补齐稀缺的精确 3D GT 模态，同时提升相机跟踪与深度估计。
