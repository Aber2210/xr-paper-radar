# STATIC：表面法线引导的双分支对齐与时序集成（视频单目深度一致性）

## 一句话结论
两帧输入 + 表面法线相似度模块（SNS）+ 掩码静态模块（MS）实现视频单目深度时序一致性：相对时序一致性（rTC）较此前最佳 +1.76%，RMSE 较 MAMo 改善约 0.60% 且仅用两帧（MAMo 用更多帧）。

## 要解决的问题
单图 MDE 模型跨帧深度不一致；传统时序模块内存高、动态/不规则运动下退化。

## 方法详解
差异掩码（静态/动态分离）+ 表面法线相似度跨帧对齐 + 掩码静态模块；KITTI/NYUv2/MPI-Sintel 训练评估（20 epochs，lr 4e-5 线性衰减）。

## 实验与结果
KITTI、NYUv2（464 室内环境）、MPI-Sintel；rTC +1.76%；消融：去 MS 模块 RMSE -1.57%、去 SNS 模块 -0.61%。

## 创新点与贡献
表面法线作为跨帧对齐的几何先验 + 差异掩码驱动的动静分离。

## 局限与风险
增益幅度温和；两帧输入限制长程一致性；AR/VR 仅为列举应用之一（主战场自动驾驶）。

## 与文献库的关系
补强库内视频深度/时序一致性薄处；与 3DGS/场景流方向互补（门① max Jaccard 0.042）。

## 可复现性（代码/数据/硬件）
实现细节附录齐全；代码释放摘要级未明示。

## 行动建议
XR 场景深度流管线可评估其两帧轻量方案；注意其主战场为自动驾驶。
