# CoTL：3D 场景表示的紧凑 token 学习

> 批次：2026-10-19 补漏批次（公告日 2026-10-13，拉取日 2026-10-19，积压补漏非当日新提交）。

## 一句话结论
从无位姿多视图学紧凑场景 token：编码器每视图产出少量与分辨率无关的 token 形成场景记忆，场景无关高斯 query 解码器从记忆解码显式 3DGS；RealEstate10K→ACID 零样本迁移成立，token 空间可作流匹配生成 3DGS 场景的潜空间。

## 要解决的问题
3D 场景表示要么逐场景优化（不可迁移）要么大而全；缺少「显式信息瓶颈」式紧凑且可作生成潜空间的场景记忆。

## 方法详解
编码器（几何基础模型初始化）→ 相机 token + n 个场景 token/视图 → 相机信息锚定 → 查询经交叉/自注意力解码 → 高斯头；渲染监督端到端优化。

## 实验与结果
C3G 协议（NoPoSplat 索引插帧 6/12/24/36 视图）；PSNR/SSIM/LPIPS 对比无位姿通用 NVS 基线；紧凑性量化 + 流匹配生成 POC + 锚定/归一化消融。
