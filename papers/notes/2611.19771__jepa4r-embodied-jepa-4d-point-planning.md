# JEPA4R：面向具身智能的 JEPA 世界模型与 4D 点云规划

## 一句话结论
点云JEPA世界模型：MetaWorld 98.4%、Adroit 88.0%居首，200步想象误差<1.1cm　把 JEPA 从 2D 图像潜空间搬到单深度相机的 4D 点云潜空间，MetaWorld 98.4%、Adroit 88.0%，200 步想象误差 <1.1 cm。

## 要解决的问题
JEPA 世界模型多以 2D 图像输入，度量几何与外观纠缠，须自行推断深度；点云 JEPA 多只做无动作预训练或预测 LiDAR 占据，几何难进入决策。再者潜变量只被训成可预测、不可重建，想象的三维场景不可见，难以调试与实机安全检查；评测也限于仿真的短时程规划，不检验其能否支撑策略学习。

## 方法详解
观测为单深度相机点云，去背景后按 5 mm 体素合并、采 1200 点（xyz+rgb）。编码器为 PointNet（6→1080→4320，192 维），加宽至 5.51M 对齐 ViT-tiny，整模型 18.0M；预测器为 6 block transformer，经 AdaLN-zero 注动作、因果关注 3 个历史潜变量。损失为潜变量 L2 误差加 λ=0.09 的 SIGReg 防坍缩；训 10 epoch、batch 128、AdamW。策略头训练于冻结潜变量。解码器基于 PAGE-4D（DINOv2 主干加 DPT 点图头），256 个 query 经 z 的 FiLM 调制进入主干；损失 CD+SW₂²+0.1·L_rgb，LP-FT 两阶段，Stage B 加 rank-4 LoRA 使误差 0.87→0.79 cm。想象 rollout 自回归预测并解码为 4D 点云。

## 实验与结果
- Cube-Single 78.4%，对比 LeWM 24.4%、PLDM 46.8%
- Cube-Double 41.6%、Cube-Triple 18.4%，同类基线分别 ≤1.2% 与 0%
- Scene 五任务均值 64.8%，对比 LeWM 40.8%、PLDM 46.1%
- MetaWorld 均值 98.4%，对比 R3M 96.0%、VC-1(ViT-L) 88.8%
- Adroit Relocate 88.0%，对比 R3M 65.3%、最佳 2D JEPA 40.0%
- 解码 4096 帧 NN 距离 0.79 cm；200 步想象点误差 ≤1.1 cm，立方体位置误差 1.39 cm

## 创新点与贡献
- 相对 DINO-WM、LeWM、V-JEPA 2-AC 等 2D 输入 JEPA，首次把单相机彩色点云引入预测-规划-执行闭环；相对只解码到图像，用 PAGE-4D 派生解码器把冻结潜变量还原为 4D 点云，使想象可查。
- 对比基线：LeWM, PLDM, LeJEPA, VISReg, V-JEPA 2 / 2.1, R3M, MVP, VC-1 (ViT-B/L), CLIP, STP

## 局限与风险
- 作者自述仅研究单相机点云、单场景策略学习，跨场景/跨机器人通用世界模型需大规模 3D 机器人数据，超出范围。实机仅展示三任务各一次、未报成功率；Cube-Quadruple 上所有编码器（含本方法）为 0.0。
- 消融：换 VGGT 0.79 cm、Depth Anything 3 0.75 cm，200 步 0.85–0.89 cm，说明几何来自潜变量；PointNet 最优 64.8；上下文 3 帧饱和；batch 256 升至 68.5。
