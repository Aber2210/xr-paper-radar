# RoMo Hands：大规模、组织丰富的文本到手部动作数据集

## 一句话结论
把纯手部文本-动作数据推到 541,929 段 / 884 h（CLUTCH 时长的 10.6×），提 393 维双手冗余表示与五级层级描述，并系统揭示「语义对齐」与「运动学合理性」之间的排序分裂：MoMask 上 R@1 0.547 vs MANO-102 0.395，说明纯手生成不能只用检索类指标评价。

## 要解决的问题
文本驱动的身体动作生成已成熟，但纯手部动作合成长期受数据瓶颈限制：现有数据集要么把手当作刚性末端执行器（Motion-X、MotionMillion 等），要么仅有数小时且无自由文本（GRAB 3.8h、InterHand2.6M 24h、BOTH2Hands 8.31h、HandX 54.2h、CLUTCH 83.3h）。手部自由度高度集中、自接触频繁，指间穿插等细微伪影立刻可见，而面向粗粒度身体动力学设计的指标难以捕捉。规模与文本监督的缺失，使现代生成架构难以系统迁移到灵巧手部。

## 方法详解
沿用 RoMo 的野外视频采集与分层动作分类管线，并增加三个手部专用阶段。先用 WiLoR 逐帧检测双手并回归 MANO 参数（手腕轴角、15 个手指关节旋转、弱透视相机），再与 RoMo 的 SMPL 手腕轨迹做逐帧锚定：两者在阈值内则平均，否则以 WiLoR 为准并对身体手臂链求解 IK，从而锁进时间一致的世界坐标；检测失败帧在轴角空间线性插值，仅允许 ≤5 帧空洞，更长则切分或丢弃。随后施加检测率过滤（每手高置信帧占比）与灵巧度过滤（15 指关节平均旋转速度 + 指尖两两 ℓ2 距离的指间姿态变化），并均在标注前执行以节省 VLM 预算。用 Qwen3.5-27B 以单一结构化 prompt 生成 L0–L4 五级描述（2–4 词标题 → 全段描述，词数 3.5→149.3）。提出 393 维双手表示 R_hand：9 维根帧（合成根 = 双腕中点、XZ 平面速度、世界 y 高度、6D 朝向）+ 32 关节位置 96 + 速度 96 + 6D 旋转 192，其中朝向由腕间轴偏航 ψ_t=atan2(-(p^R-p^L)_z,(p^R-p^L)_x) 定义，仅做绕上轴偏航规范化以保留世界高度；因多通道近零方差，改用类型感知归一化（高斯基通道 z-score、Stiefel 流形上的循环通道直通）。最后在统一 R_hand、冻结 T5-v1.1-base、AdamW 下重训扩散（Kimodo M、MDM）、掩码 token（MoMask）、自回归（MotionMillion）四类生成器，并用 RoMo Hands 上训练的 TMR 评测器（剥离位置/速度后仅评关节）计算语义与物理两族指标。

## 实验与结果
- 数据集规模 541,929 段 / 884.17 小时 / 95.5M 帧 @30fps，平均 5.9s；为 CLUTCH 时长的 10.6×、HandX 标注量的 5.6×
- 表示消融（MoMask）：R@1 0.547 vs MANO-102 0.395 vs CLUTCH-198 0.368，FID 0.153 vs 0.221 vs 0.269
- 表示消融（Kimodo M）：R@1 0.665 vs 0.646（MANO-102/CLUTCH-198），MM-Dist 0.868 vs 0.896/0.882
- 基准语义：MoMask R@1 54.00 / R@3 78.62 / FID 0.129；Kimodo M R@1 53.82 / FID 0.087；MotionMillion R@1 31.26 / FID 0.314（GT R@1 63.77、FID 0）
- 物理：Kimodo M 双手穿插 1.06%、HF 功率 0.0077、指内 jerk 22.9；MoMask 指内 jerk 265.2（约 18× GT 的 14.3）；MDM 双手穿插 2.19%
- 活动度：静态占比 0.2%、活跃 53.7%、平均动态分 0.330，对比 GigaHands 20.4%/14.2%/0.136 与 GRAB 0.0%/65.6%/0.658

## 创新点与贡献
- 首个把纯手部文本-动作数据推到身体动作量级（884h，比前作大一个数量级），并配套五级层级化描述与三层动作分类法
- 提出 393 维双手冗余表示，把身体 272 维模板按关节数重新索引（12J+9），并用合成腕中点根与腕间偏航解决手部无骨盆、无骨架根的问题，可作为通用模板实例化
- 系统性揭示语义对齐与运动学合理性之间的排序分裂，指出纯手生成不能只用检索类指标评价

## 局限与风险
- 野外视频带来遮挡与运动模糊残留噪声，250 段人工审计仅为五点量表、无法替代对真值 3D 手姿的重建误差评估
- 灵巧度过滤引入对“清晰可见且活跃”动作的选择偏差，数据集继承源视频池的人口与地域分布
- 基准中各模型适配并不对等（MDM 为前缀条件 60 帧、MotionMillion 仅 150M、MoMask 第二阶段未完全收敛），架构级排名仅为指示性
- 检索指标依赖单一在 RoMo Hands 上训练的 TMR 评测器，只能做相对比较
