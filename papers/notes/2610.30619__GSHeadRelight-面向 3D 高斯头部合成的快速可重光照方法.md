# GSHeadRelight：面向 3D 高斯头部合成的快速可重光照方法

## 一句话结论
在生成式 3D 高斯头部（GSGAN）上实现统一神经辐射传输：每个高斯分配视角条件的 SH 传输系数，一次前向合成后重光照无需再评估生成器——243 FPS，比既有 3D 感知人像重光照快至少 12×，且无需 light stage 数据。

## 要解决的问题
3D 感知的人像重光照需要同时满足照片级真实感、实时渲染和对未见主体的一次性泛化。现有方法要么依赖昂贵且通常不公开的 light stage 数据，要么基于生成式 NeRF，存在 3D 一致性差、实时性能低的问题；且每次更换光照都需要重新进行神经网络评估，难以实时。

## 方法详解
以生成式 3D 高斯骨干（GSGAN）为基础，提出 Unified Neural Radiance Transfer 光照模型：为每个高斯椭球分配球谐系数表示辐射传输，并将传输向量设为视角方向的函数，从而统一建模漫反射与低频镜面反射。训练时采用白光假设（单通道光照标签）缓解 albedo 与光照的歧义；由于辐射传输对入射光呈线性响应，测试时可按通道外推到彩色光照。所有成分均为与光照无关的高斯属性，合成只需一次前向推理，重光照无需再次评估生成器。

## 实验与结果
训练数据 FFHQ（15M 图像，4×NVIDIA H800）。生成质量与速度（512 分辨率，Table 1）：Ours FID 5.71 / KID 0.151 / 243 fps；对比 NeRFFaceLighting FID 4.16 但仅 2.8 fps，ShadeGAN 0.5 fps，Volux-GAN FID 59.79 / 21 fps，GSGAN 5.60 / 245 fps；重光照速度比此前 3D 感知人像重光照工作快至少 12×（H800 上约 240 FPS）。光照质量（Table 2，1000 样本均值）：Ours Lighting Error 0.6213 / Lighting Stability 0.1537，优于 NeRFFaceLighting（0.6377/0.1455）、ShadeGAN（1.0714/0.2149）。空间一致性（Table 3，30 个主体）：Ours PSNR 35.57 / SSIM 0.9521 / 身份相似度 0.7538（身份相似度为所有方法最高）。真实人像重光照（Goliath 子集，VGGFace 余弦相似度）：Ours 0.443 vs NeRFFaceLighting 0.298。消融（Table 4）：去掉辐射传输 Lighting Error 升至 1.2296，去掉视角条件为 0.7019，完整模型 0.6520。

## 创新点与贡献
1. 在 3D 高斯上实现统一神经辐射传输：每个高斯的 SH 传输系数以视角方向为条件，同时覆盖漫反射与低频高光，且免去了逐光照的网络评估
2. 用白光假设从 in-the-wild 图像蒸馏出合理的 albedo 与光传输函数，无需 light stage 数据，并靠线性响应泛化到彩色光照
3. 重光照速度比既有 3D 感知人像重光照方法快至少 12×，且空间一致性（身份相似度）最优

## 局限与风险
- 受球谐基限制，主要建模低频与漫反射效果，对高频反射表达力不足，albedo 中可能残留高光（右脸颊案例）
- 来自面部的自下而上光照在 in-the-wild 图像中稀少，此类重光照可能不合理
- 训练依赖 FFHQ 与 DPR 提取的单色三阶 SH 光照标签，对域外数据的效果未验证

## 与文献库的关系
改进生成式 NeRF 路线（NeRFFaceLighting、LumiGAN 等）的实时性与 3D 一致性，将预计算辐射传输思想引入生成式 3D 高斯头部合成，替代对 light stage 监督的依赖。

## 可复现性
项目主页公开（geometrylearning.com/GSHeadRelight），训练使用 FFHQ 与 4×NVIDIA H800；正文未明确声明代码与模型权重是否开源。

## 行动建议
实时化身重光照（telepresence/社交 Avatar）的当前速度标杆；白光假设+线性外推解决 in-the-wild 训练的光照歧义是可迁移技巧。边界：球谐基限低频、albedo 可能残留高光、代码/权重公开状态未明。
