# FLEG：经紧凑语义表示的任意视角前馈语言嵌入高斯泼溅

## 一句话结论
FLEG 在 2 视角 ScanNet++ 上 mIoU 46.61/mAcc 71.18/PSNR 28.14，超过 Uni3R（39.54/58.59/24.95）与 LSM（39.36/58.35/19.87）；ScanNet 2 视角 mIoU 48.01/mAcc 73.59。32 密集视角下 ScanNet mIoU 60.97 显著高于 per-scene 优化的 LangSplat（41.24）。DGLE 稀疏语义高斯仅用 73.89K 个 embedding（密集像素对齐 2.012M 的约 3.7%，论文表述为不足 5%）、存储 18.04 MB vs 491.3 MB，语义保真度相当。消融：去掉 instance-guided contrastive learning mIoU 从 46.87 跌至 40.22；去掉几何蒸馏跌至 18.56、训练不稳定。

## 要解决的问题
前馈 language-embedded 高斯重建此前面局限于固定 2 视图输入或需要相机参数；给每个高斯挂语言 embedding 造成语义冗余，embedding 数量随输入视图线性增长、存储开销大；3D 几何+语义标注稀缺限制训练规模与数据多样性，难以支撑可扩展的前馈语义重建。

## 方法详解
网络沿用 VGGT 式大 transformer（DINOv2 patchify + 可学习 camera token + 4 个 register token，24 层 global/frame-wise attention，深度与相机头），DPT-based Gaussian head 预测 μ/s/r/σ/SH 颜色与 D 维语义 emb，体素化聚合成标准高斯 G={μ,s,r,σ,c}。双分支蒸馏免 3D 标注：几何分支用 frozen VGGT 做 novel-view-based distillation（按 context views 点云投影覆盖率阈值 τ 选 target views， photometric+LPIPS 与深度/相机伪标签监督，防止对输入视角过拟合）；语义分支用 SAM2 实例掩膜 + CLIP 实例特征对齐，并以 instance-guided contrastive learning（anchor-pixel 相似度，复杂度 O(Np·K) 替代逐像素 O(Np²)）增强实例判别。DGLE 用更大 voxel 把语言 embedding 软加权融合成稀疏语义高斯 G_sem={μ,s,r,σ,emb}（各向同性协方差由 moment matching 近似、旋转固定单位四元数），与标准高斯解耦。

## 实验与结果
ScanNet + ScanNet++ 训练（与 LSM/Uni3R 相同数据以公平对比），输入视角 2–16（另测密集 32），约 1B 参数，8×NVIDIA H200 训练约 2 天；指标 mIoU/mAcc（LangSplat 开放词汇分割协议）/PSNR/SSIM/LPIPS。基线：AnySplat、LSM、Uni3R（前馈）、LangSplat、LangScene-X（per-scene 优化）、LSeg/SAM2+CLIP（2D）。超参：λ1=2.0、λ2=1.0、λ3=0.5、λ4=0.05、η1=0.5、η2=0.2，蒸馏深度 MSE 权重 0.1、相机 Huber 10.0，输入长边最大 518 像素。消融（ScanNet++，2/4/8/16 视角平均）：w/o sparse(voxel) 1.625M emb/396.7MB、w/o sparse(pixel) 2.012M/491.3MB、w/o novel distill PSNR 24.77、w/o geo distill 18.56。

## 创新点与贡献
['任意数量、无标定无姿态多视图输入的前馈语言嵌入高斯重建（2 到 30+ 视角同一模型）', 'novel-view-based distillation：无需相机真值即获新视角监督，缓解输入视角过拟合、保训练稳定', 'instance-guided contrastive learning 以 O(Np·K) 复杂度获得实例级语义判别', 'DGLE 解耦稀疏语义高斯：不足 5% 的 embedding 数量保持语义保真，大幅降低资产存储']

## 局限与风险
['论文自述：几何精度受 VGGT 蒸馏上限约束（VGGT 数据与算力远大于本文）', '跨数据集泛化主要在室内场景验证（训练限于 ScanNet/ScanNet++），室外数据待扩展', '语言 embedding 仍占额外 GPU 显存，难以处理数百至数千张输入图像（需压缩或流式重建）', '语义稀疏性结论基于当前任务，语义极密/极稀场景的表现未充分测试']

## 与文献库的关系
谱系：per-scene optimization 一线为 LangSplat、FastLGS、DF-3DGS；前馈重建上游为 PixelSplat、MVSplat、SelfSplat、AnySplat 与 3D 基础模型 VGGT；直接对标前馈语义重建 LSM（两视角）、Uni3R（多视图但需相机参数）与实例级点图 IGGT。本文位置：首个支持任意无位姿多视图 + 稀疏语言 embedding 的前馈语言高斯框架，面向机器人导航/操作的开放词汇 3D 交互。
