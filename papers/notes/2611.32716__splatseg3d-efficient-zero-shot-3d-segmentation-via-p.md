# SplatSeg3D：基于点云面元化与泼溅的高效零样本 3D 分割

## 一句话结论
在纯点云、无图像、无位姿、无 3D 训练、无监督提议五个约束同时成立下做零样本 3D 分割：面元化 + 泼溅自造虚拟视图，把视角选择形式化为深度检验下的 k 覆盖问题，再用 2D 掩码投票聚类——Replica mIoU 36.2 vs Ov3R 31.9，是唯一仅用 3D 模态且零训练的参赛者。

## 要解决的问题
开放词汇 3D 分割几乎都依赖与点云配准的图像序列来做 2D 基础模型特征抬升，但 LiDAR 或地面扫描仪往往只有纯点云，没有图像与位姿。能处理纯点云的方法又需要语义标签训练 3D 网络或类无关掩码提议模块（如 Mask3D），无法零样本部署。直接把原始点投影成图像则过于稀疏、背景伪影严重，2D 分割器难以准确工作。

## 方法详解
SplatSeg3D 的输入只有彩色点云与类名词表，全流程无任何 3D 训练。第一步面元化：对每个点用 k_n=12 近邻协方差最小特征向量求法向并按点云质心定向，半径取 k_r=6 近邻平均距离并截断在 1–99 百分位，使相邻圆盘重叠填补空隙；每个面元是法向平面上的 2D 高斯（不透明度 0.99，携带点色），由 2DGS 光栅化器按前到后合成 C_c=Σw_j c_j、D_c=Σw_j z_j、A_c=Σw_j。第二步视角选择：在占据栅格约束的自由空间网格（h=1 m）上，以 8 个偏航 + ±20° 俯仰两层生成候选，先按 η(c)≥5% 过滤；可见性判据 vis_c(x)=[u∈Ω]∧[A_c>0.05]∧[z≤1.05D_c]，再按地采样距离 z/f≤g 分宽松 g_len=0.020 与严格 g_str=0.010 两档。算法 1 是 k=2 的覆盖耦合贪心：增益 = 未覆盖点（宽松档）数 + 已覆盖但未解析点（严格档）数，每轮取最大增益视角，增益低于样本 0.5% 即停止；先跑水平层收敛再跑俯仰层补足，用尽量少的视角最大化覆盖。第三步对选中视角用文本提示分割器（SAM3）得到掩码 m=(M_m,y_m,s_m)，每个点在自己经深度检验的像素上「读取」掩码，投票 V_iy=Σ_c Σ_m s_m[vis∧M_m(u_c(x_i))]，argmax 定标签，无票点若距最近有票点 ≤3r̃ 则继承、否则留空。第四步实例化：每类点先 5 cm 体素化取 26 邻接连通分量，再用逐视角掩码把连通分量按「同掩码 vs 异掩码」的视角票数建边权 w_ab=Σ_c(2[μ_c(a)=μ_c(b)]−1)，用 GAEC 相关聚类切分，从而分开同类相邻物体。

## 实验与结果
- Replica（51 类，纯评测集）mIoU 36.2 / mAcc 47.2，超过 Ov3R 31.9 / 42.3 与 OVIO-MAP 26.5 / 32.2，且为唯一仅用 3D 模态、零训练的参赛者
- ScanNet++ 验证集 mIoU 27.3 / mAcc 43.7，高于 GoDeep 16.8 / 39.1 与同协议下 SceneSplat 26.4 / 41.4（SceneSplat 自报 28.4 采用自重建高斯上的不同协议）
- S3DIS Area 5 新类实例 AP50：B8/N4 42.5、B6/N6 59.6，超过 JOPP-3D(f) 38.1 / 41.9 与 PoVo 29.1 / 33.4
- ScanNet v2 新类实例 AP50：B8/N9 23.9、B10/N7 32.5，在无基类训练方法中领先
- 效率（Replica）：模型加载+单场景 14.4 s（Open-YOLO 3D 31.5 s、Open3DIS 130.1 s），6.3×10¹³ FLOPs，峰值显存 2.3 GB（比 Open-YOLO 3D 少 7.6×）
- 消融：面元渲染 mIoU 27.3，原始点 z-buffer 22.9、球状高斯 23.7、单一全局半径 25.9

## 创新点与贡献
- 把「纯点云、无图像、无位姿、无 3D 训练、无监督提议」四个约束同时满足：用面元化 + 泼溅自造高质量虚拟视图，把视角选择形式化为深度检验下的 k 覆盖问题（宽松/严格双分辨率档耦合），再用 2D 掩码投票 + 相关聚类得到语义与实例
- 相较 OpenIns3D 仍需训练好的类无关 3D 提议模块，本方法彻底去掉了 3D 监督环节

## 局限与风险
- 上限由分割器决定：分割器不认识的类（如冰箱、浴缸）在任何视角配置下都检不出，细粒度类常被判为粗类
- 实例边界仍弱于 Mask3D 等有监督提议器，标签会泄漏到邻近物体
- 几何假设偏室内：法向朝质心定向假设从场景内部观察，相机固定在检测地板上方 1.6 m 眼高，室外/大场景需改造
