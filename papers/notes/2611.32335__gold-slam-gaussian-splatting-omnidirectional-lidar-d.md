# GOLD-SLAM：高斯泼溅全向 LiDAR-深度 SLAM

## 一句话结论
把跟踪与建图都放进同一个球面域：位姿更新、协方差投影、渲染与深度一致性共用一套 ERP 几何，实测 LiDAR 深度当监督、预测深度只用于盲区补洞——相对 ODGS-SLAM / PanoGS-SLAM 平均 PSNR 提升 9.10 / 5.56 dB，Hilti-Oxford ATE 0.059 m（FAST-LIVO2 0.064）。

## 要解决的问题
全景相机单帧覆盖近整个球面视野，但其覆盖范围与 LiDAR 视场严重不匹配：ERP 图像上大片区域没有 LiDAR 深度支撑（盲区按立体角加权占比高），导致高斯难以初始化；同时 ERP 投影在球面上采样不均、两极拉伸剧烈，增量建图中已有高斯的高累积不透明度还会挡住新观测表面的插入，产生漂浮物。现有 LiDAR-视觉基准又多来自地面机器人或背包，缺 UAV 运动。

## 方法详解
统一球面几何：对点 $\mu^C$ 定义半径 $R=\|\mu^C\|_2$、经度 $\varphi=\mathrm{atan2}(x,z)$、纬度 $\lambda=\mathrm{atan2}(y,\rho)$，ERP 投影为 $\pi(\mu^C)=[\frac{W}{2\pi}(\varphi+\pi),\ H(\frac12-\frac{\lambda}{\pi})]$，反投影为 $\mu^C=R\,d(u,v)$，$d$ 为单位方位向量；高斯协方差经 $J_{\pi}$ 投到 ERP 平面 $\Sigma^{\mathrm{img}}_g=J_{\pi,g}\Sigma^C_gJ_{\pi,g}^{\top}+\epsilon I$，前端位姿更新与后端渲染共用同一套 Jacobian。前端沿用 FAST-LIVO2 的误差状态滤波，融合 IMU 传播、LiDAR scan-to-map 与全景视觉更新。为补 LiDAR 盲区，在盲区提取角点并用金字塔光流跟踪、前后向一致性剔除误匹配，视差足够时用历史方位射线三角化，得到切平面残差 $r_{ik}=B_{ik}(\hat{d}_{ik}-d_{ik})$，按视差与历史位姿不确定性传播出 $\Sigma_{r,i}$，汇总信息矩阵 $\Lambda_V=\sum_iH_i^{\top}\Sigma_{r,i}^{-1}H_i$，并用 $\eta=\min(1.4,\ \gamma/\lambda_{\max}(L^{\top}\Lambda_VL))$ 限制视觉相对信息量。LiDAR 有覆盖区域改用 Patch Brightness Uncertainty：把整块 patch 共享的增益/偏置扰动建模进残差协方差 $C_{\mathrm{photo}}=\sigma_n^2I+\sigma_\alpha^2i_{\mathrm{ref}}i_{\mathrm{ref}}^{\top}+\sigma_b^2\mathbf{1}\mathbf{1}^{\top}$，白化残差与 Jacobian，避免把整体亮度变化误判成运动。建图侧每关键帧用 DAP 预测全景径向深度 $D_P$，以有效重叠区中位比值 $s$ 对齐到 LiDAR 深度 $D_L$，融合为 $D_F$（LiDAR 优先、盲区用 $sD_P$），采样 LiDAR 点与盲区最小有效深度像素反投影初始化高斯。DAEP 解决新表面插入：候选点满足 $A(u)<\tau_\alpha$ 或 $\hat{D}(u)-d>\max(\delta_0,\beta d)$ 才插入（后者允许在累积不透明度很高时仍接纳更近的观测），冲突插入用更高初始不透明度与尺度并按深度差加权 Adam 更新 $\Delta\theta_g=w_g\Delta\theta_g^{\mathrm{Adam}}$；每轮再按关键帧深度一致性剪掉「不透明度高且中心明显在观测表面前方、且局部深度连续」的高斯。地图损失 $\mathcal{L}_{\mathrm{map}}=(1-\lambda_s)\mathcal{L}_{\mathrm{RGB}}+\lambda_s(1-\mathrm{SSIM})+\lambda_d\mathcal{L}_{\mathrm{depth}}$，深度项只在有效 LiDAR 像素上算径向误差，盲区靠多视光度监督补几何。

## 实验与结果
- 相对全景基线 ODGS-SLAM / PanoGS-SLAM：平均 PSNR 提升 9.10 / 5.56 dB，Depth-L1 降低 71.9% / 83.9%
- ATE：Hilti-Oxford 0.059 m（FAST-LIVO2 0.064）、M3DGR 0.344（0.346）、M2DGR 0.360、Oxford Spires 0.077（FAST-LIO2 0.075）
- 长走廊 Corridor02 端点漂移 0.274 m，FAST-LIVO2 为 1.319 m
- WHOLE 弱几何 / 高动态组端点漂移相对 FAST-LIVO2 分别降低 34% / 43%
- 消融：去掉盲区视觉更新或 PBU，ATE 0.100→0.161 / 0.158 m，PSNR 25.42→23.08 / 24.92 dB
- WHOLE 上 Depth-L1 比 Gaussian-LIC2 低 20–33%；Jetson Orin NX 在线运行，PSNR 仅降 5.80 dB

## 创新点与贡献
- 把跟踪与建图都放进同一个球面域：位姿更新、协方差投影、渲染、深度一致性检查共用一套 ERP 几何，因此盲区视觉约束与高斯初始化能直接对接
- 相对 ODGS-SLAM/PanoGS-SLAM 只用 ERP 图像、无 LiDAR 度量约束，它把实测 LiDAR 深度当监督、把预测深度只用于盲区补洞
- 相对 Gaussian-LIC2 等透视系统，它用全景视野换来盲区与弱纹理下的位姿鲁棒性

## 局限与风险
- 渲染与深度只在共享前视 97° 区域评测，全景范围的定量证据较弱
- 建图开销明显高于 Gaussian-LIC2（600 帧 95.4–201.6 s，地图 0.50–1.41 M 高斯），说明全向覆盖的代价未消
- 前端仍依赖 LiDAR-IMU 标定与足够 LiDAR 几何，完全失去 LiDAR 时 Depth-L1 恶化到 9.8 m
