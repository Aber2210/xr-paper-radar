# InstantHand：单图前馈可动画 3D 高斯手部化身重建

## 一句话结论
InstantHand 单图前馈生成 MANO 锚定的高斯手部化身，免测试时优化即达优化基线水平：InterHand2.6M 上 PSNR 26.21 dB/SSIM 0.866，HanCo 零样本差距≤0.14 dB，构建 2.84 秒、渲染 161 FPS。

## 要解决的问题
手是精细交互与灵巧操作的核心界面，但现有高保真手部化身依赖多视角采集、单目视频逐主体拟合或推理时优化 inversion，可扩展性差；而直接套用为头部/身体开发的前馈高斯化身方法到手失败：手薄、自遮挡多、关节高度灵活，高斯位置/尺度/朝向的微小误差会产生过膨胀、重叠与厚度伪影；同时单图外观信息不完整，直接从图像特征回归颜色会退回到学习先验，丢失肤色等输入特有线索，而未观测区域又必须合理补全。

## 方法详解
输入单图 Is 与现成的 MANO、相机、mask 估计。几何侧：以冻结 DINOv3 编码器提取密集图像特征 Fs；将 MANO(β, θ_mean) 网格 k=3 细分的表面顶点作为 query anchors（N=49,281），经 point embedding 成 query tokens Q，与图像 tokens（K/V）通过两串流条件 transformer Φg/Φa 融合为几何与外观 tokens；高斯以表面锚定残差参数化：中心 xi=qi+Δxi（offset 限制在锚点局部邻域）、各向同性尺度 si=ρ(fs)、固定 opacity α0 与规范旋转 r0，颜色 c⁰i 由外观 token 回归。几何约束去掉各向异性拉伸等不稳定自由度，防止模型用任意高斯密度补偿重建误差。Soft Alpha Band 正则 L_band=η(n)(λout Lout+λin Lin)：对真值轮廓膨胀得外带 Bout 惩罚 alpha 泄漏、腐蚀得内部 Bin 保证覆盖不足惩罚，用 Huber 罚函数并按训练步调度权重。外观侧 Reliability-gated Appearance Transfer：先把规范高斯动画到源位姿渲染，得到每个高斯的投影 footprint Ωi 与累计渲染贡献 Ci；可靠性 γi=min(√(Ci·mi)/Pζ({√(Cj·mj)}),1)·1[i∈O]，其中 mi 为 footprint 内前景支持，O={j: Cj>κ·med(C+), mj>τm}，(κ,τm,ζ)=(0.5,0.5,95) 先验固定、确定性计算不学习；在 footprint 上聚合源图/渲染残差/DINO 特征作局部证据，另聚合全局 source appearance identity token；经 Prior Refinement、Identity Conditioning、Appearance Prediction 后按 c*i=c⁰i+gi·γi·(c^obs_i−c⁰i)+Δ_said 仅更新颜色（gi 为可学习外观门）。训练分两阶段：Stage-1 学规范表示（L_rec+λsil·L_sil+L_geo+L_band），Stage-2 冻结 Stage-1 全部（含颜色头）只训外观模块（源视图 L1/LPIPS+特征统计对齐 L_stat+新视角 L1/LPIPS）。

## 实验与结果
训练数据为 InterHand2.6M、HO3Dv3、Goliath、Hand Appearance、PALM（每样本一张源图+同主体多目标帧，裁剪为手中心 256×256；缺标注处用 SAM 3 与 WiLoR 估计 mask/MANO/相机），外观阶段另加按 Zhao et al. 协议合成的源-目标对。InterHand2.6M 单图协议下：PSNR 26.21、SSIM 0.866、LPIPS 0.133，持平最强逐主体优化基线 OHTA（26.11/0.864/0.129），PSNR/SSIM 第一、LPIPS 第二；对比 HandAvatar/LiveHand/HARP/Handy/BIGS 全面占优。HanCo 零样本（无训练无优化）：PSNR 20.18/SSIM 0.836/LPIPS 0.188，距最优拟合基线≤0.14 dB/0.007/0.002，而采集时间 2.84 s、160.71 FPS、1.79 GB 显存，对比 OHTA 3360 s/0.26 FPS/47.8 GB、HandAvatar 5579 s、BIGS 1380 s，成本低 400 倍以上。消融：去 SAB 降至 23.89 dB，去可靠性门 γ 23.18、去外观门 gi 24.52、完全去外观迁移 26.01，说明双门必须同时存在；去合成数据 26.13。输入换为估计量（SAM 3 mask/WiLoR MANO）PSNR 仅降 0.09/0.14 dB，全估计 25.99（-0.22 dB）。与把头/身体配方（LAM/LHM 模板换 MANO）移植相比：head-recipe 掉 2.61 dB、边界 F 从 0.698 跌至 0.299、alpha 泄漏从 0.234 升至 0.608，证明失败定位于薄轮廓而非手部内部。位姿分层显示手指articulation 越强质量越差（InterHand2.6M 掉 2.69 dB），视角变化影响小（≤0.97 dB）；时序上帧间变化平均超出真值 4.7%。

## 局限与风险
继承单图歧义：严重自遮挡下被遮表面只能靠先验补全，弱观测薄结构保真度下降；上游 WiLoR 位姿在侧视/背视下变差，观测集边界穿过薄结构（如背视拇指）时源驱动色与先验补全色相遇会形成可见接缝。所有高斯属性前向一次后固定，不建模姿态相关外观（褶皱、强关节下的阴影变化），源图中可见皱纹仅作纹理迁移；化身止于 MANO 模板手腕处、无前臂，360° 旋转时开放腕边界可见；强屈指下蒙皮拉伸锚点间距但 splat 不跟随放大，指节出现细条纹（可用 k=4 致密化后处理大部分消除，代价是参数 3.4→13.4 MB）。

## 与文献库的关系
库内已有 AniGS（2607.18539，单图可动画高斯化身）、LAM/LHM 类前馈化身及大量 3DGS 论文，InstantHand 与它们构成直接竞争且定位更窄更深：其 Table 4 的头/身体配方移植实验量化了通用化身方法迁移到手的失效模式，反证手部专用设计（SAB+可靠性门控）的增量价值；相对库内逐主体优化基线（HandAvatar/OHTA 等）属于替代型改进（400 倍采集加速下质量持平）；对 XR 手部交互/遥操作方向，是首个可在头显端实时渲染的单图个性化手部化身来源。
