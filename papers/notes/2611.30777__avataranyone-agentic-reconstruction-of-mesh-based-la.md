# AvatarAnyone：从 YouTube 视频智能体重建基于网格的分层化身

## 一句话结论
把 VLM 智能体用于「决定重建结构」而非仅生成资产：智能体回答服装/层序问题并据此为每人搭建不同初始化与优化计划，输出身体/头发/每件服装/鞋各自独立网格：100 个扫描 CD 1.92→1.36 cm（−29%），可直接加载 Blender / Unreal / MuJoCo。

## 要解决的问题
可动画 3D 人体现多靠多相机扫描或美术手工制作，成本高、难扩展。多数应用需要的不是一张融合表面，而是分层化身：身体、头发、每件服装各自独立成网格，且身体在衣服下面完整存在，才能做虚拟试衣与布料仿真。3DGS 化身渲染好，但引擎无法直接加载，也没有可供接触/仿真的表面；网格方法要么形变单一人体模板，要么输出一张融合表面，衣服无法单独移除、替换或仿真。分层之所以难，是因为重建依赖这个人穿什么：宽松外套与紧身上衣需要不同初始化，裙子与裤子不同，塞进裤腰的衬衫与放出来也不同，固定管线无法覆盖所有组合。

## 方法详解
输入一段随手拍的 YouTube 视频，先用图像模型补全正面规范视图，再用视频扩散生成该人物在规范姿态下的 360° 视频；对每个视角用现成模型给出逐像素服装类别标签、法线与 SMPL-X 姿态，作为优化目标。核心是「把人物结构表示为一组视觉问题」：VLM 智能体查看规范视图、四个侧面以及腰部/脚部特写，回答固定问卷（穿连衣裙还是上下两件、衬衫是否塞入、长裤与鞋如何衔接、头发长短与覆盖关系等）。答案形成层计划 $\mathcal{P}$：确定层集合 $\mathcal{K}\subseteq\{0,\dots,4\}$（身体、头发、上衣、下装、鞋）、每层的语义、初始化模型、优化项以及腰部/肩部的层序。智能体还充当门控：若生成的初始化带有头部等脏几何（例如衬衫初始化把脑袋带进来），则拒绝并重试，直到干净。随后一个联合优化把所有层拟合到 360° 视频的标签、法线与姿态目标；每层拥有独立顶点、纹理与蒙皮权重，用 SMPL-X 骨架做线性混合蒙皮，因此可整体动画。

## 实验与结果
- 100 个扫描上 Chamfer distance 从最佳网格基线 1.92 cm 降到 1.36 cm（-29%）
- 静态 X-Humans：CD 1.18→1.06 cm（vs Pixal3D），PSNR 比最佳外观基线 HumanNOVA 高 1.2 dB
- YouTube 留出帧渲染 PSNR 15.64 vs Pixal3D 15.50；LPIPS 0.193 为最低
- 感知研究得票 79.81%，SyncHuman 12.50%，其余基线 0.00–7.05%
- 消融完整 CD 1.40；去掉智能体且输出单表面 1.99；去掉自适应优化 1.80；去掉智能体检查初始化 1.76
- 约 150 个 YouTube 视频用于定性/感知评估
- 单个化身约 3 美元 API 调用成本，单 GPU 拟合约 2 小时
- 四数据集各 25 个扫描：THuman2.1、CustomHumans、2K2K、CAPE

## 创新点与贡献
- 把 VLM 智能体用于「决定重建结构」而非仅生成资产：智能体回答服装/层序问题，据此为每个人搭建不同的初始化与优化计划，解决了固定分层管线无法覆盖服装组合的问题
- 输出是身体、头发、每件服装、鞋各自独立的带纹理网格，可直接进 Blender/Unreal/MuJoCo，支持换装、布料仿真与接触建模，而不仅是渲染

## 局限与风险
- 作者承认每人只有一层上衣和一层下装，夹克与内搭衬衫会被合并成一层
- 方法依赖专有图像与语言模型，单个化身约 3 美元、单 GPU 约 2 小时
- 真实人物化身存在滥用风险
- 从正文还可看出，输入依赖生成式 360° 补全，背面未见区域可能被幻觉
- 评测以扫描重投影与短片段感知为主，未量化长时动画漂移或布料仿真精度
- 分层语义来自 VLM 问卷，问卷未覆盖的服饰组合可能退化
