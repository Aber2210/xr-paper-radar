# GlassGround：超越原生截图的穿戴第一视角 GUI 定位基准

## 一句话结论
把「同一状态、同一指令、同一目标」在原生截图与穿戴相机实拍间配对，使观测方式成为唯一变量，再用 Resized/Warped/Rectified 三级把落差归因到像素来源——536 状态 / 3,250 任务 / 8,576 张物理图，十个开源模型均值 94.8%→48.5%，像素来源落差 29.2–31.7 点远大于呈现方式 14.7–17.1 点，PairDistill+ReGround 回到 69.62%。

## 要解决的问题
智能眼镜助手只能用相机看手机屏幕，拿不到截图与界面状态；此时界面在画面中占比小、带透视畸变，还叠加反光、摩尔纹与显示屏–相机成像效应。现有 GUI grounding 基准几乎都在原生截图上评测，而相机拍屏数据集（如 PC-Restore）只服务图像复原，不做指令条件定位。作者用同一 GUI 状态、同一指令、同一目标配对截图与穿戴相机观测后发现：十个开源模型平均从 94.8% 掉到 48.5%，单模型跌幅 36.1–56.2 个百分点，闭源三模型跌幅 26.9–67.1 个百分点。

## 方法详解
任务写成三元组 $(s,q,e)$，观测 $I$ 给出实例 $(I,q,y)$，模型只看 $I$ 与 $q$、输出点 $\hat{p}$，落在目标多边形 $y$ 内即正确。构造上把同一张截图全屏显示在原手机上，用 4 台穿戴设备（Aria Gen 1、Aria Gen 2、Quest 3、Galaxy XR）× 4 种光照（Indoor-Dark / Indoor-Lamp / Outdoor-Shade / Outdoor-Sun）拍 $K=16$ 次，得到 clean 与 physical 的配对，差异只来自观测过程（observation shift）。任务只在 clean 截图上建：OmniParser + OCR 提候选、打 Set-of-Mark 标号、Claude Fable 5.1 逐候选判断并写指令（不预测框），再由人工逐条核验目标有效性与框精度。物理侧真值用 YOLO11n-pose 检屏幕四角（人工逐帧修正）估单应 $H_k$，把 clean 目标框投到相机图：$c_j^{(k)}=\pi(H_k\tilde{c}_j)$，保留为多边形以维持透视几何；交叉复核带来的精度变化不超过 0.16 pp。分析路径构造三级中间观测：Resized（缩放到与目标面积一致）、Warped（用单应投到屏幕上、保留真实背景）、Rectified（逆单应拉正、保留相机像素），从而把「像素来源」与「呈现方式」分开。PairDistill 用冻结教师看 clean 图、LoRA 学生看 physical 图，按目标区域面积加权池化视觉 token：$\operatorname{Pool}_R(F)=\sum_j w_j\mathbf{f}_j$，$w_j=|R\cap\Omega_j|/\sum_k|R\cap\Omega_k|$，减去全图均值得 $\mathbf{z}_c,\mathbf{z}_p$；损失 $\mathcal{L}_{\mathrm{PD}}=\mathcal{L}_{\mathrm{SFT}}(I_p,q,a)+\lambda(1-\cos(\mathbf{z}_p,\mathbf{z}_c))$，$\lambda=1$，$\lambda=0$ 即纯坐标监督。训练数据独立于基准，来自 AMEX 的 Android 截图在手机上显示后用固定支架重拍，4636 对图、76224 个目标、4 种设备–光照组合；LoRA 同时作用于语言模型与视觉编码器（含 patch merger），按 WiSE-FT 做 $\alpha=0.5$ 权重插值，3 个种子。

## 实验与结果
- 基准规模：536 个 GUI 状态、102 个应用（iOS 303 / Android 233）、3250 个任务、8576 张物理图、52000 个任务–观测实例
- 开源模型均值：Clean 94.8% → Physical 48.5%（Resized 85.4%、Warped 77.7%）
- Warped→Physical 落差 29.2 pp，远大于 Clean→Resized 的 9.4 pp 与 Resized→Warped 的 7.7 pp
- 像素来源改变带来 29.2–31.7 pp 落差，呈现方式改变只带来 14.7–17.1 pp
- ReGround：Physical 48.5% → 59.4%；自动矫正单次调用 63.0%，接近 Oracle 63.1%
- PairDistill：UI-Venus-2-9B 55.13 → 64.48（+9.4），MAI-UI-8B 45.80 → 57.96（+12.2）
- PairDistill + ReGround：69.62% / 64.36%；自动矫正下 69.7% / 65.2%
- 消融：纯 SFT 60.49 / 53.44，加目标对齐再 +3.6 / +3.7；尺度增强仅 0.4–1.3 pp

## 创新点与贡献
- 相对 ScreenSpot / ScreenSpot-Pro / OSWorld-G 等只看数字截图或渲染界面的基准，GlassGround 首次把「同一状态、同一指令、同一目标」在原生截图与真实穿戴相机观测间配对，使观测方式成为唯一变量，并用 Resized/Warped/Rectified 三级中间观测把落差归因到像素来源（29.2–31.7 pp）而非呈现方式（14.7–17.1 pp）
- PairDistill 相对 ReMoDiffuse 式「检索示例」或纯坐标 SFT 的新意在于：用干净视图的目标级表征监督物理视图的对应表征，推理时不需要截图，属于跨视图目标对齐蒸馏而非输入增强

## 局限与风险
- 作者自述：只评静态单步定位，不覆盖完整交互序列
- 只测手机屏幕，其他物理显示未验证
- Warped→Physical 的落差无法归因到具体成像因素（模糊、反光、ISP），留待后续
- 我们另看出：训练数据来自固定支架的 Android 重拍，与基准的自然手持分布仍有域差
- 闭源模型只在 500 clean + 8000 physical 的子集上评测，与开源全量结果不可直接横比
- 最好结果 69.6% 距 clean 的 94.8% 仍差 25 pp，方法只是缩小而非弥合落差
- 基准构建依赖 Claude Fable 5.1 生成指令，虽有全人工复核，指令风格可能带模型偏好
