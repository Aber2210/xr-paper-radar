# 融合事件与结构先验的动态高斯场景重建

## 一句话结论
指出「证据来自表示自身」的循环：用事件这一与高斯覆盖、光度收敛都无关的外部观测同时决定「哪里需要新支持」与「谁是可靠运动参考」：dPSNR +1.02（合成）/+1.45（真实），动态高斯总数降 8.5%，代码与数据公开。

## 要解决的问题
事件驱动的动态高斯重建在支持增广与可靠性估计上都依赖隐含假设：其一，已有高斯能吸收重建误差（3DGS 的 densify 靠屏幕空间位置梯度触发克隆/分裂，没有高斯的区域无法产生候选，误差只能由邻近高斯反复分裂承担）；其二，光度优化已收敛到可用解析方差估计可靠性（如 USplat4D，但它是两阶段、需先预训练到收敛）。快速运动下两者同时失效：缺支持区无法增广，未收敛区被整体判为不可靠而剔除掉恰恰需要的运动参考。更深的困难是「评估表示所用的证据来自表示自身」。此外即便支持与参考都到位，帧级形变与端点插值也无法解释帧间快速运动，平均化会产生边界模糊与 ghosting。

## 方法详解
ESC-DGR 在 E-D3DGS 表示上、单次优化内完成三件事。EDSA（Event-guided Dynamic Support Augmentation）用事件定位需要新增支持的位置：把正负事件按校准阈值累计 $A_f$，在时间窗 $\mathcal{T}_f$ 内三角加权平滑得 $\bar A_f$，以 $M^{sup}_f=\mathbb{I}[\bar A_f>\tau_{sup}\max\bar A_f]$ 取候选，再由活动 $\tilde A_f$、Sobel 边缘 $g_f$ 与瞬时差可靠性 $r^{temp}_f$（$\lambda_g=\lambda_c=0.5$）合成分数 $\psi_f$；候选经有效渲染深度（>1e-4）反投影、3 cm 体素聚合、Top-$N_{sup}$ 配额，仅动态标签者一次性注入 $\mathcal{G}^d_{sup}$。CCSMG（Contribution-Confidence Structural Motion Graph）用一次辅助渲染 pass（属性向量 $z_i=(z_{i,1},z_{i,2},z_{i,3})$ 作颜色输入）反传得到累计贡献 $\kappa_i$、贡献加权残差均值 $\bar e_i$ 与二阶矩 $m_{2,i}$，得 dispersion $\upsilon_i=\sqrt{\max(m_{2,i}-\bar e_i^2,0)}$ 与 $\zeta_i=\mathrm{clip}(\bar e_i+0.25\upsilon_i,0,1)$，贡献可靠性 $U_i=\min(o_i/n_0,1)C_i\exp(-\bar\zeta_i/b_{err})$；据此选 Key，用图把 Key 位移按置信权重传播到弱观测邻域：$\Delta\tilde\mu^L_{i,f}=\Delta\mu^L_{i,f}+\eta_G(k)b^G_{i,f}(\Delta\mu^G_{i,f}-\mathrm{sg}[\Delta\mu^L_{i,f}])$。EHMR（Event-conditioned High-frequency Motion Refinement）由 $M_{i,f}\rho^{hi}_i>\tau_{act}$ 取候选、按活动分数 Top-$B_f$ 选 active 集，构造 16 通道事件特征，经 KAN 残差块 + 两个 MLP 残差块预测位置残差，用最小轴向尺度定义的半径 $\ell_i=\mathrm{clip}(0.75s^{min}_i,0.001,0.05)$ 做范数裁剪，非 active 高斯残差置零。总损失 $\mathcal{L}=\mathcal{L}_{rgb}+\lambda_{evt}(k)\mathcal{L}_{evt}+\lambda_{th}\mathcal{L}_{th}+\lambda_G(k)\mathcal{L}_G+\lambda_d\mathcal{L}_{dyn}+\lambda_b\mathcal{L}_{edge}+\lambda_{art}\mathcal{L}_{art}+\lambda_{mag}(k)\mathcal{L}_{mag}$；训练按依赖分阶段（静态 warm-up 供深度约束注入支持 → 联合优化与密度控制 → 密度控制结束后开图引导 → 统计稳定后再开残差分支），全程单次优化、无外部 tracker。

## 实验与结果
- dPSNR（vs E-D3DGS）：合成 23.46→24.48 dB（+1.02），真实 +1.45 dB；全图 PSNR 合成 +0.42 dB
- 八合成场景动态高斯总数 378,030→345,887，降 8.5%（8 个中 7 个减少，Lego 与 Materials 各降超 1/5）
- 渲染速度：合成 202→159 FPS（约 -21%）、真实 209→158 FPS（约 -25%），12 个场景全部 >80 FPS
- vs FastEventDGS：全图 PSNR/SSIM/LPIPS 在 12 个场景全部更优（FastEventDGS 平均 24.41/26.08 dB、132/155 FPS）
- 消融累积：dPSNR 22.77→23.27（+EDSA）→23.60（+CCSMG）→23.94（+EHMR）dB；全图 PSNR 31.13→31.26→31.44→31.58 dB
- 去 EDSA 使 12 场景平均 dPSNR 降 0.62 dB（三项移除中最大）；把 CCSMG 换成适配的 USplat4D 图，dPSNR 23.94→23.68 dB
- 反例：Waterwheel 动态高斯多 1.6% 却换来 dPSNR +2.19 dB；Celestial globe/Hotdog/Materials 仅 +0.57–0.77 dB

## 创新点与贡献
- 明确指出并打破「证据来自表示自身」的循环：用事件这一与高斯覆盖、光度收敛都无关的外部观测，同时决定「哪里需要新支持」和「谁是可靠运动参考」，从而摆脱 densify 的梯度依赖与解析方差对收敛的依赖
- 工程上把支持放置、参考选择、残差精修放在同一次优化的同一高斯集合上（非两阶段、非外部 tracker），并用有界残差 + 分阶段调度避免残差吸收本应由低频场建模的运动

## 局限与风险
- 作者承认：速度下降约 21%/25%
- 全模型推理需时间对齐的 target-time 事件，缺失时须关闭 EHMR，此时 12 场景平均 dPSNR 为 23.60（vs 完整 23.94）
- 当误差由外观/纹理而非支持不足或帧间快速运动主导时收益很小（0.57–0.77 dB）
- 稀疏事件在弱纹理/低对比区可能把运动高斯排除出 active 集
- 残差界限制了超出局部尺度的错位修正
- 此外单目 + 已知位姿、无 loop closure，消融未做种子显著性，整体 dPSNR 增益约 1.17 dB 属中等幅度
