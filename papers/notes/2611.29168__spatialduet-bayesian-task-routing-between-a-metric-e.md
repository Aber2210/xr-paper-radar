# SpatialDuet：在度量专家与几何专家之间的贝叶斯任务路由

## 一句话结论
不在权重上做文章，而把「模型路由」落到题型粒度并用经验贝叶斯闭式估计权重：VSI-Bench 全 5,130 题 64.07%（最佳 ≤4B 已发表 60.9%），面向 T4/fp16 的 3B+4B 端侧组合。

## 要解决的问题
具身助手与可穿戴设备受硬件限制只能用小型空间 VLM，而不同训练路线给出能力互补的模型：在大规模空间问答集上训练的模型擅长估物体与房间尺寸，带 3D 几何编码器的模型擅长判相对方向与绝对距离。已发表方法都选择训练单一模型覆盖全部空间任务，放弃了这种互补性。此外，数据驱动模型的实际推理与其训练、评分协议之间存在三处错配——官方评测每秒抽一帧（中位仅 82 帧）而末段训练用 128 帧、数值题用贪婪解码、按题型存在系统性尺度偏差（房间面积高估约 20%）——使报告分数低估其真实能力。

## 方法详解
双专家全部冻结。度量专家 A = Cambrian-S-3B 加三个免训练模块：训练对齐采样 TAS 统一取 $\Phi_{\mathrm{align}}(V)=\mathrm{linspace}(0,N-1,128)$；度量感知最小贝叶斯风险解码 M-MBR 用 16 个采样（温度 0.7、nucleus 0.95）加贪婪答案构成候选集 $C$，返回 $\hat{y}_{\mathrm{MBR}}=\arg\max_{c\in C}\sum_{y\in C}\mathrm{MRA}(c,y)$；按题型度量校准 PMC 在开发集上网格搜 $s_t\in[0.50,2.00]$（步长 0.01）最大化 MRA，并取 $\hat{y}'=s_t\hat{y}_{\mathrm{MBR}}$。几何专家 B = SpatialStack-4B（VGGT 编码器特征堆叠进语言模型），按发布协议（32 帧、贪婪）运行，数值题型同样做逐型尺度校准。贝叶斯任务路由器 BTR：以题型为单位（题型在测试时已知，且专家强弱在型内稳定），在开发集上算 $\hat{d}_t=\mathrm{mean}(s_B-s_A)$，对场景做 200 次 bootstrap 得 $\sigma_t$，假设 $\hat{d}_t\sim\mathcal{N}(d_t,\sigma_t^2)$、$d_t\sim\mathcal{N}(\mu_{g(t)},\tau^2)$，按基准自带的能力组 $g(t)$ 做 normal–normal 收缩：$\tilde{d}_t=(\tau^2\hat{d}_t+\sigma_t^2\mu_{g(t)})/(\tau^2+\sigma_t^2)$，$v_t=\tau^2\sigma_t^2/(\tau^2+\sigma_t^2)$，权重 $w_t=\pi_t=\Phi(\tilde{d}_t/\sqrt{v_t})$，即「专家 B 在该题型更好的后验概率」。池化按答案格式分开：数值答案在对数空间做加权几何平均 $\log\hat{y}=(1-w_t)\log\hat{y}_A+w_t\log\hat{y}_B$（与相对误差度量匹配），选择题对选项分布加权 $\hat{y}=\arg\max_o(1-w_t)p_A(o)+w_tp_B(o)$。路由器无任何通过优化拟合的参数，权重由开发集差距闭式给出。

## 实验与结果
- VSI-Bench 全部 5,130 题：64.07%，比最佳已发表 ≤4B 模型 SpatialStack(60.9%) 高 3.17，比同评测代码的 Cambrian-S-3B(57.17%) 高 6.90
- VSI-Bench 测试集 2,459 题：57.41 → 59.11(TAS +1.70) → 60.68(+PMC +1.57) → 61.74(+M-MBR +1.05) → 64.28(+BTR)，相对 Cambrian-S +6.87（[4.88,9.15]）
- 相对 Cambrian-S 的逐型提升：room size +22.05、relative direction +10.80、route planning +9.28、object size +1.11
- CV-Bench 全部 2,638 题：82.64% vs SpatialStack 81.2（+1.44）；2D 77.79 / 3D 87.50
- VSTI-Bench 相机六型（3,253 题）：57.23% vs 专家 A 55.87（+1.36）、Cambrian-S 53.82（+3.42）；九类官方总分 62.73 vs SpatialStack 61.16
- VSI-Bench-Debiased（1,160 题）：56.46% vs Cambrian-S 49.72（+6.74），增益不因去除非视觉捷径而缩小
- 路由权重：counting 0.01、object size 0.00、relative distance 0.00；absolute distance 0.94、relative direction 0.92、route planning 0.98；混合型为 appearance order 0.39、room size 0.53
- 混合带来的超额收益：appearance order 87.94%（比更优专家高 3.90）、room size 68.89%（高 1.39）

## 创新点与贡献
- 不在权重上做文章，而把「模型路由」落到题型粒度并用经验贝叶斯闭式估计权重：把逐题型增益向能力组均值收缩，使「差距大且样本多」的题型直接跟随单一专家，而「差距小或噪声大」的题型自动变成 0.5 权混合——这正好利用了两预测器加权可优于更优者的经典结论
- 同时按答案格式分别池化（数值在对数空间做几何平均、选择题在选项分布上加权），使融合与 MRA 的相对误差度量对齐，而非在原始数值上做算术平均

## 局限与风险
- 每道题都要跑两个专家，推理成本加倍
- 路由器需要题型标签与一个小型标注开发集
- 作者列出的下一步是：$\pi_t$ 为 0 或 1 时跳过第二专家、用分类器预测题型、按单题而非按题型路由
- 从正文亦可看出，增益主要来自冻结专家的能力互补与协议对齐，不涉及任何训练
- CV-Bench 上排除了同源模板数据训练的 MM-Spatial-3B（91.2%），横向可比性受限
- 跨基准的题型体系与能力组划分依赖各基准自带 taxonomy
