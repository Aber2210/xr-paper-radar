# LFX：融合形态灵活的光场建模用于稠密语义分割与显著目标检测

## 一句话结论
在 DUTLF-V2 上用同一套框架、同一组权重，LFX 在子孔径与焦栈两种光场表征下分别把 SOD 的 MAE 降到 0.029 与 0.027（相对前最佳提升 12.12% 与 20.59%），并在 UrbanLF 上取得 83.77 mIoU。

## 要解决的问题
光场相机一次曝光记录多视角，但既有方法都绑定某一种光场表征：以视差为中心的子孔径图像（S.Aperture）显式编码跨视像素位移，以重聚焦为中心的焦栈（FS）则把角度变化重参数化为空间对齐的多张重焦图。两类表征的辅助视图与各自成像特性强耦合（视差驱动的几何位移 vs 重聚焦引起的空间响应变化），导致模型无法跨表征复用，领域缺少统一学习框架。已有做法或依赖昂贵的视差图预处理（LFIENet 系列），或假定焦栈近似平面对齐（TENet、LFTransNet、LFSODNet），都无法同时吃两种输入。要统一，必须先找到一个跨表征不变的结构：同一三维场景在不同视角下的测量，其全局投影差、局部邻域散度、语义一致性是共享的，可用来解耦辅助视图与具体参数化。

## 方法详解
先做表征不变性分析：对同一场景分别生成 S.Aperture 与 FS，用 PCA 观察辅助视图相对中心视图的全局特征差（投影差）、patch 级差（邻域散度，集中在物体边界与遮挡展开处），以及 ResNet 编码后的特征分布（上下文一致性，语义身份基本保持）。据此提出 Field-of-Parallax Angular Subspace Modeling（FoP-ASM），插在 backbone 编码与跨分支融合之间，逐 stage 作用于 {X_s}_{s=1..S}。第一步 FoP Marker：以中心视图 X_c=X_1 为锚，算逐视图差 D_s = X_s − X_c（式 5），该差直接刻画结构化跨视位移而与具体光场参数化无关；再沿通道做均值 A_s = (1/C)Σ D_s^(c) 与温度 τ=0.07 的 softmax 池化 P_s = τ log Σ exp(D_s^(c)/τ)（式 6），拼成 2×H×W 的角度嵌入 Φ_s = Concat(A_s, P_s)，作为该视图的「角度标记」；经 W_q 投影为 Z_s 后与 X_s 拼接，过 down-up 投影与激活得条件角度残差 r_s（式 9），把角度线索只注入辅助视图而不引入视图间依赖。第二步流形子空间建模：把全部辅助残差与中心特征一起送入共享的 down/up 投影子空间 r_s^S = W_up^S(W_down^S(r_s*))（式 10），在统一语义空间内隐式建立中心—辅助依赖；随后 Dropout 与 AvgPool 低通滤波得 r̃_s^S，以可学习尺度 γ 残差回写 X̂_s = X_s + γ r̃_s^S（式 13），保留原语义内容。第三步子空间正则：L_reg = (1/|Ω|)‖r_s − r_s^S‖_F²（式 14），总损失 L_total = L_task + λ L_reg（式 15），四个 stage 的正则项求和。整个模块只增加 0.248 M 参数与 1.043 GFLOPs，输出交给 CMNeXt 解码器，SOD 与分割共用同一范式。

## 实验与结果
['1) DUTLF-V2 子孔径表征 SOD：MAE 0.029（前最佳 CDINet 0.033），相对提升 12.12%；F-measure 0.922（+4.77%），S-measure 0.890 略低于 CDINet 的 0.905，平均排名 1.75 与 CDINet 并列最佳。', '2) DUTLF-V2 焦栈表征 SOD：MAE 0.027（前最佳 0.034），提升 20.59%；且 LFX 只用 5 张焦栈切片就超过使用 12 张切片的对手。', '3) UrbanLF 语义分割（5 个 S.Aperture 输入）：mIoU 83.77、mAcc 88.87、Acc 93.69、Avg.R 2.00，超过使用 9 视角的 CMNeXt（83.22）与 OAFuser（82.69）。', '4) 核心组件消融：去掉 FoP Marker 掉 1.24% mIoU，再去掉流形秩约束与正则进一步下降；同时去掉 FRM 与 FFM 掉到 71.89% mIoU。', '5) 辅助视图数与插入 stage 消融：分割 mIoU 随 Aux.2→Aux.5 从 75.07 升到 76.45，Aux.9 基本持平，Aux.33 达 77.34 mIoU / 85.50 mAcc；FoP-ASM 只插 Stage1 为 74.96、插 1–2 为 75.21、四阶段全插为 76.45（基线 74.13）。']

## 创新点与贡献
['首个把视差中心与重聚焦中心两类光场表征放进同一学习框架的尝试，用「角度标记 + 流形子空间」而非表征特定网络来吸收异构性。', 'FoP Marker：以中心视图为锚的逐视图差值经通道均值与 softmax 池化生成 2 通道角度嵌入，既保留角度多样性又不引入视图间串扰，且与具体参数化无关。', '共享流形子空间 + 子空间正则：把中心特征与辅助残差联合投影后回写，用 L_reg 显式惩罚残差偏离子空间，以极低参数代价（+0.248 M / +1.043 GFLOPs）换取跨表征一致的语义调制。']

## 局限与风险
['增益幅度有限：SOD 的 MAE 绝对改善仅 0.004–0.007，分割 mIoU 相对基线提升 2.32 点；S-measure 在子孔径下反而低于 CDINet（0.890 vs 0.905），作者承认个别指标略降。', '评测面窄：仅 DUTLF-V2 与 UrbanLF 两个数据集、仅 SOD 与语义分割两个任务，均为闭集设定，稀有类别（如帽子）识别失败。', '依赖 SegFormer backbone 与 CMNeXt 解码器，角度子集固定为 2×2、焦栈固定 4–5 片；辅助视图从 5 增到 9 时性能不再涨，说明角度冗余与局部视差不一致会带来波动。', '摘要称代码将公开于 https://github.com/FeiT-FeiTeng/LFX ，但正文写作时仍为「will be made publicly available」，可复现性未落地。']

## 与文献库的关系
对位两类前作：视差中心路线（PANet 把子孔径当光流、CNINet 低秩选视图、LFIENet/LFIENet++ 两阶段估视差再投影）都需要视差预处理且不兼容焦栈；重聚焦路线（TENet、LFTracy、LFTransNet、FESNet、LFSODNet）假定焦栈近似平面对齐、缺乏对视点位移的显式建模。方法上借鉴参数高效适配（adapter、ST-Adapter）与多模态特征校正（CMNeXt、OAFuser）的思路，但把「模态」换成「光场表征」，并用流形子空间代替跨模态 cross-attention。

## 可复现性（代码/数据/硬件）
部分可复现：承诺开源 https://github.com/FeiT-FeiTeng/LFX ，数据为公开的 DUTLF-V2 与 UrbanLF；训练用 4×RTX 3090、batch 1/GPU，主实验 SegFormer-B4、消融 SegFormer-B2，超参（τ=0.07、λ）正文给出。

## 行动建议
可略读方法细节、精读 §III-B 的表征不变性论证与 §V 消融。价值主要在「一个模块吃两种光场表征」这一命题与低成本适配设计；若做光场/多视图感知，FoP Marker 的「中心锚 + 差值嵌入」可直接借用。注意其增益是十几个百分点的相对值而非绝对量级，且 S-measure 未全面领先，引用时不要夸大。
