# PostMesh：基于自奖励偏好的流式艺术家网格生成后训练

## 一句话结论
以 MeshFlow 为基座、用「艺术家网格奖励」做自举偏好优化（只训 LoRA），把四边形 / 边环结构从奖励里学出来——Quad strip 0.804（MeshFlow 0.466、MeshAnything 0.756）、CD 2.697（2.760）、缺陷面 0.121（0.206），并保持 2 s 级并行生成。

## 要解决的问题
艺术家网格（artist mesh）是紧凑、四边形为主、按边环布局的网格，便于编辑、绑定与展 UV，但只能手工制作、昂贵。自动生成目前以自回归（AR）为主——MeshAnything、MeshAnything V2、Mesh Silksong、FastMesh 逐 token 解码，每个网格需 26.98 到 471.84 s。扩散与流式生成器（PolyDiff、TriFlow、MeshFlow）一次并行出全部隐变量，MeshFlow 只需 2.17 s，但网格质量不达标：长而薄的三角形、碎片化部件，这些缺陷只存在于解码后的网格里，flow-matching 损失根本看不到。AR 侧的进展主要来自基于 token 似然的偏好优化或 RL（DeepMesh、Mesh-RFT、QuadGPT、Mesh-Pro），但流式模型没有可用的 token 似然，且其输出经过冻结、不可微的解码器，因此此前无人对扩散或流式艺术家网格生成器做过后训练。

## 方法详解
以 MeshFlow 为基座：MeshVAE 把艺术家网格编码为逐顶点隐变量 $z_0$，rectified-flow transformer 在 $z_\sigma=(1-\sigma)z_0+\sigma\epsilon$ 上预测 $\epsilon-z_0$，条件 $c$ 为稠密输入网格的表面采样，冻结解码器把 $z_0$ 还原为顶点、边与 3-clique 面。训练完全自举：对每个稠密输入采一组 16 个样本，逐个解码并由「艺术家网格奖励」打分，门控算法选出一个胜者与若干加权败者，用偏好损失只更新 LoRA 适配器，下一轮换新输入。奖励分两类。形状一致性（对稠密输入渲染与输出渲染比较，固定视角、按包围盒对角线归一）：silhouette IoU $|S_O\cap S_I|/|S_O\cup S_I|$ 抓缺失或多余部件，深度 $L_1=\frac{1}{|S_O\cap S_I|}\sum_p|d_O(p)-d_I(p)|$ 抓表面内凹外凸——两者都只看渲染，因此不偏向任何三角化方式。结构项：先把相邻三角对合成为四边形（共面 10° 内、并集为凸四边形且四角在 45° 到 135°），贪心按最小角降序；quad strip 分数 $\mathrm{QS}=\frac{1}{|\mathcal{Q}|}|\{q\in\pi:\pi\ \text{成环或}\ |\pi|\ge4\}|$ 衡量四边形是否延续成边环；tessellation 用 Mesh-RFT 的 $\mathrm{TS}=0.4\tau_1+0.2\tau_2+0.3\tau_3+0.1\tau_4$（四边形占比、直角分数、对边等长、邻面相似）；sliver 项按面积占比惩罚最小角小于 5° 的针状三角形；valence 项惩罚度数不大于 2 或不小于 10 的顶点占比；tiny/stray 项分别用 $\log(1+n_{\mathrm{tiny}})$ 与碎块面积占比；再加面数界 $r_{fc}=\mathrm{clip}(1-|\log_2(F/F_t)|/b,0,1)$ 防止策略靠减面上分或照抄稠密输入。总奖励为九项加权和（权重和为 1）。门控算法把相对同组不可信的样本判为失败（Chamfer 或 Hausdorff 远高于组中位数、翻转面或小碎块多于同组、真实部件数明显偏少、解码失败），失败样本一律权重 1 计为败者；通过门控但比胜者低半个组标准差的也计为败者，其权重为与胜者的奖励差除以组内最大差。若胜者在保真度、覆盖率、面数或居中上劣于某败者，则丢弃该对，避免教模型牺牲这些性质。偏好损失把去噪误差当似然代理：$\ell_\theta(z_0)=\frac{1}{|z_0|}\lVert v_\theta(z_\sigma,\sigma,c)-(\epsilon-z_0)\rVert^2$，同一输入内胜者与所有败者共享同一 $(\epsilon,\sigma)$；边际相对冻结参考模型计算 $d_j=(\ell_\theta(w)-\ell_{\mathrm{ref}}(w))-(\ell_\theta(l_j)-\ell_{\mathrm{ref}}(l_j))$，只保留「微调真正带来的改善」；多负样本损失 $\mathcal{L}_{\mathrm{DPO}}=\sum_j\omega_j\phi(d_j)/\sum_j\omega_j$，软损失为 $\phi(d)=\mathrm{softplus}(\frac{\beta}{2}d)$；再加 RPO 项 $\mathcal{L}=\mathcal{L}_{\mathrm{DPO}}+\gamma\ell_\theta(w)$ 防止两边误差一起升。训练数据为 Objaverse 中不超过 100k 面的对象，两轮自训练、每轮 1000 迭代与 1000 个对象，只训 LoRA。

## 实验与结果
- Quad strip 分数 QS：0.804（MeshFlow 0.466、MeshAnything 0.756、MeshAnything V2 0.776、Mesh Silksong 0.790、FastMesh 0.035）
- Tessellation 分数 TS：0.706（MeshFlow 0.575、Mesh Silksong 0.708、MeshAnything 0.746）
- 缺陷面占比 DFF：0.121（MeshFlow 0.206、MeshAnything 0.319、Mesh Silksong 0.090）
- Chamfer 距离 CD：2.697（MeshFlow 2.760、MeshAnything 5.055、Mesh Silksong 2.981）；Hausdorff HD 6.089（MeshFlow 6.169）
- 碎片化 Frag.：0.647（MeshFlow 0.743、MeshAnything 0.317、Mesh Silksong 0.533）
- 速度：2.53 s 每网格（MeshFlow 2.17 s；AR 基线 26.98 到 471.84 s，单张 L40S）
- 面数：728（MeshFlow 609、MeshAnything 439、Mesh Silksong 2344、FastMesh 12490）
- 盲测 VLM 偏好：对 FastMesh 92.5%、MeshAnything 82.5%、MeshFlow 80.0%、MeshAnything V2 72.5%、Mesh Silksong 62.5%（60 个独立对象、双向呈现）
- 细分与拓扑侧效应：Loop 细分两级后翻转与自交面约减半，非流形边不到一半

## 创新点与贡献
- 相对 Mesh-RFT、DeepMesh、QuadGPT 这些在 AR 模型上做 token 级 DPO 或 RL 的工作，本文第一次在「流式加冻结不可微解码器」的艺术家网格生成器上做后训练，用去噪误差作为似然代理绕开没有 token 概率的问题，并用相对冻结参考的边际消除「本来就容易」的样本
- 相对把奖励当过滤器再 SFT（RAFT）或用 GRPO，这里的多负样本加权偏好把一组 16 个样本的信号都用上
- 奖励设计上，形状一致性只通过渲染比较（不偏好任何三角化），结构项则用四边形条带与环和 tessellation 度量「边环是否延续」，避免了只数四边形比例的漏洞

## 局限与风险
- 作者自述：艺术家网格没有统一标准，不同艺术家偏好不同，奖励不是金标准
- 评测本身主观，自动指标与 VLM 评审都不能完全代表艺术家判断
- 实际数据上，碎片化仍明显劣于 AR 基线（0.647 vs MeshAnything 0.317），说明 tiny/stray 项只缓解未解决
- ECD 8.123 也差于 Mesh Silksong（5.654）与 FastMesh（5.736），作者归因于面数只有其三分之一到十七分之一
- 奖励项与 QS/TS/DFF 指标部分重叠，虽用 Loop 细分、非流形边、UV 展开做了旁证，仍不足以完全排除「优化了指标」
- VLM 评审用 Claude Opus 5.5 代替专业艺术家，作者明确说真人研究代价过高
