# 中央凹压缩：面向 Token 高效 VLM 的选择性高分辨率保留

## 一句话结论
把人类视觉系统的“中央凹（fovea）”机制引入 VLM 视觉 token 压缩：把每 9 个原生 token 对应的图像区域划分为 9 个粗粒度单元，学一个“中央凹选择器”预测哪个单元值得保留原生分辨率。基于 Qwen2.5-VL-7B，仅用 11.11% 的原生视觉 token 即可保留 86.1% 在原生分辨率下正确的预测；并给出跨 37,610 个样本的分辨率敏感性分析，证明任务对压缩的敏感度差异巨大（ChartQA 38.8% vs POPE 94.3%）。

## 要解决的问题
VLM 的视觉 token 是推理成本主要来源，简单下采样仍是很强的基线；但不同任务/区域对高分辨率的敏感度差异显著，均匀下采样会丢失关键信息。

## 方法详解
把图像按原生 token 块划分为 9 个粗单元；Foveated Selector 用原生 token 均值、压缩 token、二者差值、空间位置四类描述子（512 维）经轻量注意力 + 卷积 + MLP 预测每个单元是否需要原生分辨率；推理时仅对选中单元保留高分辨率，其余用压缩 token，做单次 prefill-free 的选择。

## 实验与结果
在 Qwen2.5-VL-7B 上冻结主干训练 merger，在 GQA/TextVQA/DocVQA 等训练后用固定 K=1 选择器标签；评测 GQA/MMBench/MME/POPE/MMStar/OCRBench/ChartQA，几何匹配预处理；统一中央凹压缩用 11.11% token、K=1 用 20.99%；2,000 次配对 bootstrap 量化显著性（如 Foveated Selector − Matched-Budget Downsample −1.378，CI [−2.062,−0.707]）。

## 创新点与贡献
把“中央凹/注视点”这一 XR 渲染核心概念系统引入 VLM token 效率；给出可学习的单遍选择器与大规模分辨率敏感性诊断（任务级差异）。

## 局限与风险
仅做 3×3 九宫格单元的空间选择，粒度有限；选择器基于冻结主干、未端到端联合优化；结论聚焦 VLM 而非 XR 渲染，但机制可直接迁移到注视点渲染（foveated rendering）省 GPU。

## 与文献库的关系
