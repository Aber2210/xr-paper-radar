# CADENCE：保留表达性手部动作的时序连贯全身人体网格恢复

## 一句话结论
把多率滤波落到 SMPL-X 旋转空间的逐关节逐帧核选择，首次量化「平滑是否把手速抹掉」：加速度误差 17.4→5.4 mm/s²，手语手速峰值幅度 0.98 对通用平滑器 0.35。

## 要解决的问题
全身 SMPL-X 估计器逐帧用于视频会产生抖动；通用平滑虽能压抖，但强到能稳住躯干的带宽会把承载语义的快速手指笔画一起抹平，而仅测身体的基准测不到这一半代价。

## 方法详解
单帧估计器用共享的 C-RADIOv4-SO400M 编码器加结构化查询/关键点 token 解码 341 维 SMPL-X 参数并做粗到细残差更新。高分辨率手部通路用同一编码器权重重编码手部裁剪，在 ViTPose 2D 关键点处双线性采样特征后预测手指姿态（只改手指旋转，其余参数保留）。离线时序精修器在 SMPL-X 旋转空间建 token，先做逐关节时间自注意力、再做受运动学树掩码（树距离 ≤2）的关节自注意力，为每个关节每帧在 4 个对称零相位滤波核上预测 softmax 混合权重，实现逐关节逐帧的多率平滑。

## 实验与结果
- 3DPW 加速度误差 = 17.4 → 5.4 mm/s²（五种通用平滑器 6.2–7.7）
- 3DPW PA-MPJPE = 41.9 → 40.2 mm，MPJPE 61.7 → 58.1 mm
- 手语序列手速峰值幅度 Peak-A = 0.98（SmoothNet-WB 0.35，单率变体 0.50）
- EHF 全身 P-MVE = 25.7 mm，手部 P-MPJPE = 8.3 mm，手部 P-MVE = 12.2 mm
- A100-80GB bf16 全系统吞吐 = 13.1 FPS（batch 1）/ 71.5 FPS（batch 32）

## 创新点与贡献
- 首次把多率滤波思想落到 SMPL-X 旋转空间的逐关节逐帧核选择，并提出 Peak-R / Peak-A 两个能量化「平滑是否抹掉手速」的指标

## 局限与风险
- 时序精修器离线、在固定长度窗口上运行，非因果、不能直接用于流式
- 只处理单个跟踪框内的人
- 手在运动模糊、手物接触与手手遮挡下最不稳，且依赖外部 2D 关键点检测器
