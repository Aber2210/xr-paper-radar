# 基于可合并辐射场的多视角重光照

## 一句话结论
按基光照训练共享几何 + 独立外观网络，参数线性合并即完成重光照：真实 OLATverse 24.35 dB 与 RNG 持平且 SSIM/LPIPS 更优。

## 要解决的问题
NeRF 与 3DGS 把拍摄时刻的光照烘焙进外观，换光就要额外机制。既有路线各有代价：逆渲染（NeRD、NeRFactor、TensoIR、SVG-IR、ReCap）要显式估计几何、材质、法线与环境光，生成式路线（IllumiNeRF、Neural Gaffer）依赖大扩散先验，推理昂贵且不保证多视一致；PRTGaussian 需预计算逐高斯传输、RNG 与 OLAT Gaussians 是点光方法、要逐光源渲染再合成。本文指出的核心失效机制是一个数学事实：光传输对光照是线性的，但辐射场对参数是非线性的，即 f_{Σ_i β_i φ_i} ≠ Σ_i β_i f_{φ_i}，所以把不同基光照下独立训练的两个辐射场参数直接相加，得到的不是两幅图像的加权和。实测该失败极其彻底：独立初始化时参数合并后的渲染比逐光渲染加权和低 14.6 dB（合并结果仅 9.81 dB），几乎崩坏。第二条失效是图像空间混合必须对每个基光照各渲一次，成本随 K 线性增长（K=42 时每视角 42 次），无法做到换光只渲一遍。作者还指出真正需要的是让「参数空间的线性」与「图像空间的线性」对齐，

## 方法详解
核心表示：一幅与光照无关的共享辐射场（InstantNGP 哈希编码 NeRF 或 3DGS 高斯集合）提供几何与每点特征 z∈R^D，K 个基光照各配一个小外观 MLP，颜色 c_i(z,d)=f_{φ_i}(z,γ(d))，γ 为位置编码；网络为两层隐层 ReLU + softplus 输出，保证 HDR 非负无上界。NeRF 下像素 C_i(p)=Σ_j w_j f_{φ_i}(z_j,γ(d_j))，w_j=T_j(1-e^{-σ_jδ_j})；3DGS 下同式，权重改为 w_j=a_j∏_{l<j}(1-a_l)，并把球谐颜色替换为特征 z_j。两者统一为「像素=光照相关 MLP 输出的加权和」，因此同一套合并策略通用。合并依据：权重 w_j 与特征 z_j 都与光照无关，故 Σ_i β_i Ĉ_i = Σ_j w_j Σ_i β_i f_{φ_i}(z_j,γ(d_j))；用 φ_M=Σ_i β_i φ_i 替代内层求和，即得单次渲染，但由非线性知二者不等（式 8）。为此两项措施：其一，K 个外观 MLP 用同一份随机初始化复制，保持隐单元对齐；其二，merge-aware 训练，每步除了基光照样本（随机抽一个 i，渲染 φ_i 与 I_i 做光度损失），还加混合样本：在单纯形上随机抽 k 个基光照与权重 β，渲染 φ_β=Σβ_iφ_i，监督目标 I_β=Σβ_i I_i——由光传输线性，这恰是混合光照下的真图，故不需要额外采集。总目标 L=(1/G)[Σ_{g∈S}D(Î,i_g)+Σ_{g∈M}D(Î_β,I_β)]，两项都是各表示自带的光度损失（NeRF 用 InstantNGP、3DGS 用原版）。混合规模取 k∈{2,4,8,16}，因为实测一张目标环境图通常激活 26–40 个基光照。重光照阶段：对目标 HDR 环境图 L_A 逐通道（R/G/B）做球面非负最小二乘 α_c*=argmin_{α≥0}∫(L_A^c-Σα_{i,c}L_i)^2dω，再把强度与分布分离 s_c=Σα*、β_{i,c}=α*/s_c，每通道得一个合并网络 φ_{M,c}=Σβ_{i,c}φ_i，最终 Ĉ_A[c]=s_c Σ_j w_j [f_{φ_{M,c}}(z_j,γ(d_j))]_c。这样每像素只需 3 次外观 MLP 求值（每通道一次），与 K 无关；换光只需重做最小二乘与一次参数线性组合，无需优化场景。变体：把颜色放进基（每个基光照训三种色偏，486 个基）时只需一次拟合、一个合并网络渲三通道，3DGS 在合成数据上用此变体。可选自蒸馏：以图像空间混合 Σβ_i Î_i 为教师，初始化学生 φ←φ_M，在训练视角 V 上最小化 Σ_v D(Î_φ^v, Σβ_i Î_i^v)，只更新学生，3000 步；渲染成本不变但每个目标光照需一次短优化。基光照为无色 von Mises-Fisher 瓣，中心取二十面体细分 0/1/2 次的顶点（K=12/42/162），κ 随间距（半高宽 38°/19°/9°），A 使各瓣积分辐射相同。配置：NeRF 用 K=42，MLP 宽 64、16 维特征（每个仅 7,171 参数），256×256，每步 G=14 批×512 条光线（6 批单基、8 批混合），315k 迭代（OLATverse 30k）；3DGS 用 162 宽瓣×3 色偏=486 基，MLP 宽 128、32 维特征，60k 迭代、每步 G=24 图（半数为混合），OLATverse 上改用 42 瓣、宽 64、16 维、30k 迭代、G=12（半数为两光混合）；混合样本同时更新共享表示。

## 实验与结果
- 合成 Neural Gaffer 物体（6 物体×4 未见环境图×30 留出视角）：MergeableRF(NeRF) 23.38 dB/SSIM 0.800/LPIPS 0.035，为全部对比方法第二，比自家 3DGS 版（22.21）与 TensoIR（22.20）高 1.2 dB
- ReCap 26.62 dB 第一
- 真实 OLATverse（6 物体×5 环境图×6 留出相机）：3DGS 版 24.35 dB/0.836/0.048，与 RNG 的 24.32 dB 持平但 SSIM 与 LPIPS 更优，比 ReCap（22.53）高 1.8 dB
- NeRF 版 23.63 dB
- 合并间隙消融：独立初始化下合并渲染 9.81 dB（比逐光和低 14.6 dB），仅共享初始化降到 16.01 dB（间隙 8.5 dB），加两光混合降到 21.83 dB（2.3 dB），加三元组 22.46 dB（1.7 dB），加 k∈{2,4,8,16} 达 22.81 dB（1.4 dB，30k 迭代）/23.38 dB（1.2 dB，315k）
- 自蒸馏把 NeRF 从 23.38 提到 24.36 dB（逐光渲染和为 24.54 dB），3DGS 从 22.21 提到 24.70 dB（逐光和 24.68 dB），代价是每个目标光照 3,000 步优化
- 基光照数消融：K=12 上界仅 21.22 dB（基近似误差主导），K=42 上界 27.96 dB（+6.7 dB）但合并间隙从 0.4 增到 2.4 dB
- K=162 同宽基上界不再提升，合并反而降到 22.60 dB（每光训练更新变少）
- 3DGS 去掉混合样本时逐光渲染和反而更高（26.21 dB）但合并崩到 16.19 dB
- 加混合后合并 22.21 dB
- 锐利瓣上界比宽瓣高 4.5 dB，但可拟合性差（逐光和 21.84、合并 20.34 dB）
- 渲染成本：合并后每像素只做 3 次外观 MLP 求值，与基光照数无关
- 图像空间混合需 K 次渲染（K=42 或 486）
- OLATverse 上误差主要来自逐光渲染而非合并：逐光和比捕捉基图上界（33.51 dB）低 9.5 dB，而合并只再损失 0.4 dB（NeRF）/1.1 dB（3DGS）

## 创新点与贡献
- 把「模型合并」从分类器迁移到重光照：用参数空间的线性组合直接构造目标光照下的辐射场，绕开材质估计与重光照网络。
- merge-aware 监督：利用光传输线性生成混合光照的免费真值（Σβ_i I_i），显式训练参数组合复现图像组合，无需额外采集。
- 证明 NeRF 与 3DGS 可统一为「光照无关权重×光照相关 MLP」形式，使同一合并策略对两种表示同时成立。
- 把重光照成本与基光照数解耦：合并后每像素固定 3 次 MLP 求值，换光只需一次 NNLS 拟合加一次参数加权。
- 给出误差分解方法（基近似误差/拟合误差/合并间隙），把「合并」这一操作本身变成可测量的量。

## 局限与风险
- 作者自述：方法要求多视角、已知基光照的采集（光台），消费级拍摄不满足
- 平滑的 von Mises-Fisher 基无法重建锐利光源与镜面反射，头盔与熨斗的高光缺失
- 更细的基可缓解，但合并网络变多会降低合并精度，留给未来
- 从实验看还有四点
- 一是合成数据上明显落后 ReCap（23.38 对 26.62 dB，差 3.2 dB），说明无材质分解在强镜面/互反射场景仍有系统劣势
- 真实数据上只是与 RNG 打平（24.35 对 24.32），并非全面领先
- 二是 self-distillation 需对每个目标光照做 3,000 步优化，与「换光零优化、单次渲染」的核心卖点冲突，实际部署要在这两者间取舍
- 三是评测只在 256×256 物体级裁切上做，无场景级、无时序/多视一致性指标，也无用户感知实验
- 四是 3DGS 版在合成数据用 486 个基网络，显存与训练成本随 K 线性增长，论文未报告具体开销
