# 3D 高斯泼溅的统一损失感知密度控制

## 一句话结论
把 3DGS 自适应密度控制重构为逐操作的局部损失削减决策：归一化联合 position-scale 分裂（6×6 分裂矩阵最小特征对）、surrogate 引导克隆（η=-g/h）与选择性 opacity decay。Mip-NeRF360 PSNR 27.72（3DGS 27.35、SteepGS 27.05）且仅 1.9M Gaussian（3DGS 3.4M）；Tanks&Temples 24.20（23.39）/1.0M（1.8M）；Deep Blending 29.79（29.52）/1.3M（3.0M），三数据集 PSNR 全面第一。

## 要解决的问题
标准 ADC 依赖 view-space 梯度阈值、尺度阈值与全局 opacity reset 等启发式规则，不评估 split/clone/opacity 操作对训练损失的影响，导致已充分区域产生冗余 primitive、欠重建结构被遗漏、全局透明度重置扰动训练。

## 方法详解
训练中在光栅器内累积逐 Gaussian Taylor 代理统计。分裂：S_φ=E[∂L/∂α·∇²_φ α]，φ=[p; log s] 为 6 维，经 J=[L 0; 0 I/√2] 归一化到联合坐标后取最小特征对，λ_min<0 且位姿/尺度近静止才分裂，子代沿 v_min 继承扰动。克隆：用图像空间效应 Δ_dup 的二次代理得 η_dup=-g_dup/h_dup，仅在 0<η≤1e-2 小扰动区间复制子代。opacity decay：η_dec=g_dec/h_dec，只降低预测有害的 primitive 的透明度，替代全局 reset。

## 实验与结果
Mip-NeRF360 PSNR 27.72/SSIM 0.818/LPIPS 0.219/1.9M；Tanks&Temples 24.20/0.853/0.174/1.0M；Deep Blending 29.79/0.906/0.245/1.3M，PSNR 均第一且 Gaussian 数少于 3DGS。较最相关基线 SteepGS 全面更优（27.05→27.72，2.1M→1.9M）。消融（Mip-NeRF360）：SteepGS 27.05 → +joint split 27.10 → +cloning 27.37（1.6M）→ +opacity decay 27.72/0.818/0.219。代价：训练 47.5 min（3DGS 32.5）、峰值显存 11.32 GB（9.91）、FPS 232（157）。单卡 NVIDIA A6000，5 次重复取均值±标准差。

## 创新点与贡献
['loss-aware 视角首次统一覆盖 split、clone、opacity 三类 ADC 操作', '从 position-only 分裂扩展到归一化联合 position-scale 分裂空间，子代同时适应位置与尺度', '克隆与 opacity decay 的逐 Gaussian 二次代理，附小扰动区间与强度阈值约束', '选择性 soft opacity decay 替代全局 reset，训练轨迹更稳定']
