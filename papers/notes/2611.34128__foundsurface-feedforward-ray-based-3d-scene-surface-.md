# FoundSurface：从无位姿图像前馈式射线法重建 3D 场景表面

## 一句话结论
把 pointmap 的离散点接到连续射线场：query-view 投票选视角 + 粗射线表面回归 + 精化，无位姿输入直接出连续表面——ScanNet++ ADE 0.132 m（PriorDA 0.198、RayletDF 0.179），Tanks&Temples 1.233 m（3.970），5 视角 0.370 m（0.635），9 训练集 / 6 未见测试集。

## 要解决的问题
从无位姿图像重建精确 3D 表面仍是基础难题：NeRF/3DGS 依赖精确位姿且需逐场景优化、表面精度有限；DUSt3R/VGGT 类 pointmap 方法摆脱位姿，但输出本质上是离散稀疏点，缺连续高频细节；RayDF/RayletDF 类射线法能出连续高保真表面，却仍需精确位姿或稀疏点云作为输入。基线 VGGT 直接投影在 ScanNet++ 上 ADE 0.580 m、AbsRel 0.360，PriorDA 补洞后降到 0.198 m，仍与高保真表面有差距。

## 方法详解
四段式、从离散到连续。① 用预训练 VGGT 输出逐图像素对齐 pointmap $\mathbf{P}_i$、位姿 $\mathbf{T}_i$、内参 $\mathbf{C}_i$，并取第 4/11/17/23 层 patch 特征经两层 MLP 融合为视觉 token $\mathbf{F}_i$。② Query-view-centric selection：把所有输入 pointmap 按目标位姿投影并用 z-buffer 得伪深度 $\mathbf{D}^{target}$，划成 surfel；候选视图 pointmap 同样划 surfel 投到目标视角，像素深度差 $<\delta_{depth}$ 记一票，surfel 内正票比例超过 $\tau_{vote}$ 记为匹配，按匹配 surfel 占比排序取 top-$k$，避免无关视角引入噪声。③ Coarse ray-surface regressor：以目标视角建局部坐标系，候选视图用相对变换 $\mathbf{T}^{rel}_j=\mathbf{T}_{target}^{-1}\mathbf{T}_j$ 生成稠密 Plücker 射线图，卷积成 ray embedding $\mathbf{m}_j$，与 $\mathbf{F}_j$ 经 MLP 条件化得 $\hat{\mathbf{F}}_j$；目标射线 embedding 作 query、候选条件特征作 key/value 做 self-/cross-attention 交替的 Transformer，得到 $\mathbf{F}^*_{target}$ 并解码为射线-表面距离图，表面点 $\mathbf{p}=\mathbf{p}_{target}+D\cdot\mathbf{r}$。这一步把离散点升级成连续粗表面并处理遮挡。④ Raylet-based refinement：把 pointmap 体素化并用 3D sparse convolution 建特征体，取稀疏卷积产生的 anchor 及其局部特征；对每个粗 raylet 找 $S$ 近邻 anchor，输入近邻特征均值、欧氏距离 $e_{n,s}$ 与单位方向 $\mathbf{v}_{n,s}$，回归距离残差 $\Delta d_n$，$\mathbf{p}^*_n=\mathbf{p}_n+\Delta d_n\mathbf{r}_n$，恢复高频细节；由于是射线距离场，可由闭式导数直接得解析法向，避免数值差分噪声。训练两阶段解耦：粗阶段 $\ell_{coarse}=|\mathbf{D}_{gt}-\mathbf{D}|+\|\nabla\mathbf{D}_{gt}-\nabla\mathbf{D}\|$；细阶段对粗预测 stop-gradient，$\ell_{fine}=|\mathbf{D}_{gt}-(\mathrm{sg}(\mathbf{D})+\Delta\mathbf{D})|$，只训 raylet 模块以稳定全局结构。

## 实验与结果
- ScanNet++：ADE 0.132 m（PriorDA 0.198、RayletDF 0.179），RMSE 0.259、AbsRel 0.079、δ 0.910
- 7Scenes：ADE 0.123 m（PriorDA 0.154）；MultiScan：0.205 m（RayletDF 0.331）
- Replica：ADE 0.064 m（RayletDF 0.071）、δ 0.981；Tanks&Temples：1.233 m（RayletDF 3.970）
- 法向（ScanNet++）：mean 29.83°、med 21.21°，11.25° 内 29.2%（CUT3R 16.8%）；Replica mean 20.72°
- 稀疏视角（ScanNet++）：5 视角 ADE 0.370 m（PriorDA 0.635），100 视角 0.121 m（0.180）
- 训练成本约 288 A800 GPU 小时；9 个训练数据集、6 个未见解见测试数据集

## 创新点与贡献
- 相对 DUSt3R/VGGT 系列只给离散 pointmap，FoundSurface 用「pointmap 提供空间锚、射线距离场提供连续表面」的耦合把前馈重建推到连续高保真，并顺带得到解析法向
- 相对 RayDF/RayletDF 依赖位姿或点云，它把位姿与几何先验换成 VGGT 的估计，可直接在无位姿图像集上前馈推理
- surfel 投票式的查询视图选择与逐 raylet 的 anchor 残差回归是两个具体新模块，二者共同解决「直接把 RayletDF 套到 VGGT 点图会初始化不准、出现多表面与空洞」的问题

## 局限与风险
- 强依赖 VGGT pointmap 质量，论文专设敏感性实验说明先验误差会传导（Table 7）
- 训练需约 288 A800 GPU 小时，消融只能在 ScanNet 上小规模重训，主结果缺少同等预算下的逐组件拆分
- 评测以室内为主：6 个测试集中 4 个室内，室外仅 Tanks&Temples 且绝对误差仍 1.233 m
- 单视图设置虽已评测，但 query 取相邻帧，真正单图新视角质量仍受限
