# EvoGS：用演化树构建连续分层高斯泼溅的可扩展 3D 流式传输

## 一句话结论
用演化树把离散分层换成连续分层、以小波式不对称残差让细层修正祖先，冗余率 65.83%→24.92%、存储 −33.6~−53.3%，PSNR 仅 +0.31 dB。

## 要解决的问题
流式传输 3D Gaussian Splatting 需要高度可扩展的渐进式表示，但现有渐进方法都采用离散分层（discrete layering）：每一级 LOD 是一套独立 splat 集合，训练时在冻结低层的前提下过拟合目标分辨率。层间关系是组合式而非演化式，只有 2D 视觉混合，没有参数级或结构级联系，于是派生出四个问题。其一是误差累积：低分辨率训练欠监督，基础层锁定了几何错误，高层只能加新 splat 而不能修正被冻结的祖先，错误贯穿所有质量级。其二是 splat 冗余：高层必须过度加密以掩盖低层误差，即使用动态不透明度把低层 splat 淡出，在 LOD 3 仍有 65.83% 的 splat 完全透明（Layer 0 有 93.82% 被淡掉），却继续占用存储、传输与显存。其三是质量跃变不受控：相邻层质量增量不规则，率失真曲线非均匀，无法细粒度适配带宽。其四是层间相关性未被利用：基于集合的构造让任何编解码器只能把每层当独立实体，仅能做层内压缩。空间层次（octree、voxel）只服务渲染时的视锥选择，粗层数据对细层不可复用，同样不支持渐进传输。

## 方法详解
EvoGS 提出连续分层（continuous layering）：所有质量级的 splat 通过显式父子血缘连成一棵 Evolution Tree，子节点结构化地修正祖先误差而非叠加遮蔽。作者先做设计空间分析，比较四种父子参数化：A 为子节点独立参数（等价标准 3DGS 致密化，粗层不可靠且每次分裂 2D 参数）；B 为独立残差（初始偏向父节点但可任意漂移，仍 2D 参数）；C 为对称共线残差 C₁=P+ψ、C₂=P−ψ，即 Haar 小波提升格式，父节点恰为两子节点的均值，在均方误差下是粗层最优 L² 近似，每次分裂只需 D 参数，且 ψ 在局部平滑处稀疏；D 为不对称共线残差 C₁=P+ψ、C₂=P−α⊙ψ，α∈R^A（A=5，对应位置、旋转、尺度、不透明度、SH）是逐属性学习的不对称因子，每次分裂 D+5 参数，保留共线性但放弃精确均值保持，类似 JPEG2000 用双正交滤波器换表达力。作者在合成 Blender 场景上验证 C 与 D 的 ψ 能量集中度都满足“不足 20% 的系数承载 90% 以上能量”，最终选 D。树的组织是：根节点存基线几何 P_root，内部节点存学习到的细化量 ψ 与 α，叶节点是可渲染 splat；叶子参数由根到叶累加得到 S = P_root + Σ_{k=1..ℓ} s_k ⊙ ψ_k，其中 s_k ∈ {+1, −α_k} 表示走哪一支。节点角色是动态的：粗质量级下它当可渲染叶子，细质量级下它变成内部节点把参数传给子节点，因此一棵存储树可服务多个质量档。训练是渐进多级优化：对全分辨率多视图集建 8×/4×/2× 图像金字塔得 D_0…D_N；L_0 用标准 3DGS 在 D_0 上训练 30k 迭代，每个 splat 成为根（ψ=0、α=1）构成叶集 F_0；之后每级把上一级叶集当作可训练前沿，只解冻前沿节点的 ψ 与 α，祖先参数固定，子节点按 Eq.4 相对父节点定义，因此梯度更新是在修正父表示；损失为 L1 与 D-SSIM 的组合（λ=0.2），按 2D 位置梯度超过阈值做自适应分裂，分裂是梯度驱动而非均匀施加，树因此不平衡且空间自适应，叶集按 F_{i+1} = (F_i ∖ S_i) ∪ C(S_i) 演化；每级训 30k 迭代、每 3k 致密化一次至 15k。流式传输时先发 F_0，之后只发真正分裂区域的 ψ 与 α；渲染时把树截断到任意深度即得有效场景，内部节点参数在结构重建时被消耗、不占渲染显存，所以存储量与渲染占用可以分离；由于是树遍历，还支持同一次 pass 内混合 LOD（如 VR 中中央凹走到 L_N、周边停在 L_j）。

## 实验与结果
- 四个标准 3DGS 数据集（Blender、Mip-NeRF360、Tanks&Temples、Deep Blending）四级 LOD 上，PSNR 相对最强离散分层基线平均 +0.31 dB，最高 +0.69 dB（T&T 的 L_1）
- SSIM 与 LPIPS 同向
- 体量与显存：Blender 上 L_2/L_3 累计传输量降 33.6% / 53.3%、渲染显存降 73.5% / 82.1%，Deep Blending 的 L_3 为 39.1% / 67.6%，四个数据集方向一致
- 对 LapisGS 只需其 40.5% 的存储（DB L_3）与 17.9% 的渲染占用（Blender L_3），对 L3GS 为 60.9% 与 16.3%
- 冗余率：LOD 3 全透明 splat 占比从 LapisGS 的 65.83% 降到 24.92%（对称消融版为 38.85%），对应摘要中“从 65% 以上降到 25% 以下”
- 压缩性（表 5，全数据集平均）：L_3 未压缩 347.36 MB 对 LapisGS 801.80 MB
- 用 8-bit 均匀标量量化加 zstd 熵编码后降到 91.75 MB，为 LapisGS 的 11.5%（约 8.7×），PSNR 仅损失 0.10 dB
- 对称/不对称消融（表 2）：不对称版 PSNR 在 L_0 为 29.66 对 28.84（+0.82 dB），L_3 为 27.73 对 26.72（+1.01 dB），代价是 L_2–L_3 存储增加 0.83%–1.94%
- Blender L_3 具体点：EvoGS 32.71 dB / 62.59 MB，LapisGS 32.52 / 133.90 MB，L3GS 32.31 / 147.13 MB
- Monolithic 上界为 33.72 dB，但需为每级独立传输，Mip-360 上累计达 1.9 GB，Single 在 T&T 的 L_0 崩到 17.33 dB

## 创新点与贡献
- 这是表示范式层面的替换，而非在 LapisGS 上打补丁：把“每级一套独立 splat + 冻结祖先”改成“一棵父子可追溯、子节点修正父节点”的演化树，使细层第一次能结构性纠正粗层几何，从而在原理上同时消掉误差累积与幽灵 splat
- 技术支点是把小波提升格式接到 splat 参数上：对称版给出可证明的粗层最优 L² 近似，不对称版用逐属性 α 放松刚性对称、换回表达力，同时保住 ψ 的稀疏性，使层间信号天然可压缩——这一步把“表示设计”与“码率收益”打通，而不是后接一个编解码器
- 派生的能力也是离散分层结构上做不到的：传输中途任意截断都有效、质量随字节平滑单调上升、同一次渲染里可按区域混合 LOD（中央凹/周边不同深度）
- 作者还给出四选项设计空间与能量集中度实证，把选型从经验变成可论证

## 局限与风险
- 正文没有单列 limitations 章节，以下部分可由方法本身与实验设置看出
- 它是逐场景优化：每级 30k 迭代、共 4 级，在 H100 上完成，没有前馈或跨场景泛化能力，重建成本随级数线性增长
- 客户端必须支持树遍历与 ψ/α 解码，属于非标准表示，落地需要播放器改造
- 评测只覆盖传输量（Stor.）与显存（Mem.）两个代理指标，没有端到端网络流式实验（带宽抖动、丢包、解码时延、首帧时间），也没有真实头显上的主观质量或晕动评估
- 质量仍低于 Monolithic 上界（Blender L_3 32.71 对 33.72 dB），L_0 的存储甚至略高于 LapisGS（21.25 对 18.98 MB，Δ 为 +10.7%）
- 基线只有 LapisGS 与 L3GS 两个离散分层方法，金字塔固定为 4 级，α 只有 5 个属性维度
- 平滑过渡主要靠 20 个中间快照的率失真曲线与单例可视化支撑，缺用户实验
