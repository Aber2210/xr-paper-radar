# MAGS-SLAM：单目多智能体高斯泼溅 SLAM

## 一句话结论
MAGS-SLAM 单目 RGB 多智能体高斯泼溅 SLAM：ReplicaMultiagent 上 PSNR 43.24/42.83/36.28/38.99、SSIM 0.99/0.99/0.96/0.98、LPIPS 0.02/0.02/0.06/0.04，超过用 RGB-D 的 CoMA-SLAM（42.77/42.28/33.86/34.59）与 MAC-Ego3D；AriaMultiagent 真实数据 ATE RMSE 平均 0.29–0.46 cm、渲染 PSNR 29.03/31.02 亦优于 RGB-D 基线。

## 要解决的问题
多智能体 SLAM 多依赖 RGB-D 与重通信/集中式架构；如何仅用单目 RGB 让多个智能体协同完成跟踪定位、联合高斯场景建图与高质量新视点渲染，是开放问题。

## 方法详解（含关键公式/架构，保留原文术语）
digest 以实验表格为主：系统为单目 RGB 输入的多智能体 3D Gaussian Splatting SLAM（标题即 multi-agent GS SLAM），多个 agent 各自采集单目视频，联合输出可用于新视点渲染的 3DGS 场景表示，同时优化跟踪（ATE）与渲染质量（PSNR/SSIM/LPIPS）；digest 未展开具体架构模块、通信与融合细节。

## 实验与结果（表格化关键数字）
ReplicaMultiagent（多 agent 渲染质量，PSNR/SSIM/LPIPS）：Office-0 43.24/0.99/0.02、Apartment-0 42.83/0.99/0.02、Apartment-1 36.28/0.96/0.06、Apartment-2 38.99/0.98/0.04；对手含 RGB-D 的 CP-SLAM（32.61/32.16/27.42/25.12）、MNE-SLAM（28.27/27.46/25.45/26.16）、MAGiC-SLAM（39.32/36.96/30.01/30.73）、MAC-Ego3D（42.43/42.83/36.28/38.59）、CoMA-SLAM（42.77/42.28/33.86/34.59）。AriaMultiagent 真实数据（ATE RMSE cm）：Office-0 平均 0.29、Apartment-0 0.46、Apartment-1 0.46、Apartment-2 0.31；MAGiC-SLAM 0.27/0.16/0.26/0.32、MNE-SLAM 0.31/0.48/1.02/0.59、Swarm-SLAM 1.42/1.80/5.56/5.61；渲染 PSNR 29.03/31.02 vs MAGiC-SLAM 23.45/21.78、CoMA-SLAM 25.41/21.80。Room-0/Room-1 上 ATE 0.86/0.54 vs MultiSlam-DiffPose 1.05/0.85、MAGiC-SLAM 1.15/0.65。

## 创新点与贡献
① 单目 RGB 即可的多智能体 GS SLAM，摆脱 RGB-D 依赖；② 渲染质量超过多个 RGB-D 基线（ReplicaMultiagent 全面领先 CoMA-SLAM/MAC-Ego3D）；③ 在真实多智能体数据集 AriaMultiagent 上跟踪与渲染双优；④ 表格支持多 agent 扩展（Agent 1/2/3、Ag.1/Ag.2/Ag.3 列）。

## 局限与风险
digest 缺方法细节与消融实验；单目固有尺度问题未讨论；与 RGB-D 最优（MAGiC-SLAM）跟踪精度仍有差距（0.27 vs 0.29/0.46）；通信/同步开销未分析。

## 与文献库的关系（新增 / 改进 / 取代 X）
属库内 SLAM 线的多智能体/分布式分支，与库内 3DGS-SLAM 线互补；与同批 SGM-SLAM（2606.16881，LiDAR+相机场景图匹配的分布式路线）构成单目 GS 与 LiDAR 场景图两条多机路线，可对照分布式/多机 SLAM 线与 FLoTS-SLAM（2610.23496）阅读。
