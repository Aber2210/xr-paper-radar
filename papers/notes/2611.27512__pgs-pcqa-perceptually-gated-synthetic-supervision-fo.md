# PGS-PCQA：面向无参考点云质量评估的感知门控合成监督

## 一句话结论
不改质量特征而改监督信号：用源域合成失真的层内顺序补上缺失失真类型的监督、以渲染感知距离软化排序目标：SJTU 到 WPC 跨库 SRCC 0.709（0.595），且不碰目标域数据、不生成伪 MOS。

## 要解决的问题
无参考点云质量评估（NR-PCQA）在单数据集内 SRCC 常超 0.9，但跨数据集急剧下降：按失真类型拆解后可见，对训练集中缺失的编码类失真，模型把严重度排序打到接近随机甚至反向（G-PCC Trisoup 上 within-type SRCC 约 0、去 PGS 版本 −0.18）。根因是训练数据的失真覆盖不足，而常规按内容交叉验证让训练与测试共享失真类型，掩盖了该问题。

## 方法详解
PGS-PCQA 以 CLIP-PCQA 为基座，在 MOS 监督之外加入同类型严重度排序监督：对每个源参考点云离线生成 84 个合成版本（19 个 G-PCC、5 个 V-PCC、60 个通用几何与颜色退化），在同一参考、同一失真类型内取轻/重两级 (a,b) 构成配对，用 σ((s(a)−s(b))/τ) 的概率形式做排序损失。由于更重并不总等于更差，引入 perceptual gate：用 VGG19 多层特征在六视图上算两者到参考的渲染距离差，构造软目标 p=σ(max(d(b)−d(a),0)/τd)，距离差小或反向时 p=0.5 只拉近两分数而不强加顺序。合成样本与参考只在训练期使用，推理仍是无参考；测试期另用前景加权 4×4 多区域测试扩大空间覆盖。

## 实验与结果
- SJTU-PCQA → WPC 跨库 SRCC = 0.709（DSP-PCQA 0.595）
- SJTU-PCQA → BASICS 跨库 SRCC = 0.751（DSP-PCQA 0.723）
- 参考不相交交叉验证 SRCC = 0.955（SJTU-PCQA）/ 0.934（WPC）/ 0.906（BASICS）/ 0.791（LS-PCQA Part I）
- 仅用中心裁剪时 SJTU → WPC SRCC = 0.677（此前最佳 0.595）
- 缩减合成库后保留的增益 = 全库 SRCC 增益的 58%–65%
- 推理耗时 = 约 0.15 s → 约 1.2 s/样本（单张 RTX 2080 Ti）

## 创新点与贡献
- 不改质量特征而改监督信号：用源域合成失真的层内顺序补上缺失失真类型的监督，并以渲染感知距离把排序目标变软（只放松、不反转），从而在不使用任何目标域数据、不生成伪 MOS 的前提下提升跨库泛化

## 局限与风险
- 作者自述三点：合成库对基于学习的 GeoCNN 编解码器帮助很小（0.422→0.484）
- 迁移到 SJTU-PCQA 受跨物体标定限制
- 前景加权 4×4 测试把推理成本抬到约 8 倍
- 排序监督只约束内容内关系，跨内容分数标定留作未来工作
