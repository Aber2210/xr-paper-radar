# 面向优化的隐式神经表示超网络的可扩展化

## 一句话结论
用 attention 替换 MLP 主体后，该超网络在 CelebA-HQ 上把 PSNR 从 LDMI 的 24.8 dB 提到 27.7 dB（+2.9 dB），在 Pre-trained NeRF 的 images-only 设置下达到 28.8 dB（全表最高），并把核心模块参数量从 HyPoGen 的 O(n_i²·d²) 降到 O(d²)，可在 HyPoGen 显存耗尽的 width=1024 上继续扩展。

## 要解决的问题
INR 的代价是 per-instance 优化：每个信号要数千步梯度、跨信号不共享计算。超网络一次前向生成参数可摊销这笔成本，但两条路线各有硬伤：single-pass 方法直接回归每层权重，把参数当扁平输出，丢弃了产生这些权重的链式法则结构；optimization-oriented 方法把优化过程展开进架构、逐层预测更新，保留了层间依赖，但其 MLP 实例化每层每次精修的参数量随目标网络宽度四次增长，把行压到低维潜码也只能去掉一个因子。于是最需要摊销的大 INR 反而被挡在门外。

## 方法详解
核心论点是四次成本属 MLP 实例化的结构性属性，而非优化导向原则本身：MLP 成本同时依赖权重矩阵的行数与行维度，注意力通过在 token 轴共享参数去掉行数依赖，行维度则由 tokenization 吸进固定嵌入维。据此三个设计。其一，以输出神经元为中心 token 化：每层权重按输出神经元（行）切 token，第 j 个 token 对应第 j 个输出神经元。其二，信息流一致性：注意力输出是 V 行的凸组合、行数继承自 Q，故 V 与 K 必须由已处于输出应有角色的输入占据，Q 为剩余输入，该规则统一决定五个模块的 QKV 分配。其三，token 空间迭代展开：把目标 INR 一步优化要算的五个量——一个激活、两个局部雅可比、传播的损失信号、参数梯度——一对一实现为五个交叉注意力，前向链产出伪激活 token，反向块依次产出两个雅可比、损失信号与梯度；参数按 ω←ω−λ∇L 更新，步长由条件向量预测，T 步后解码回权重矩阵。

## 实验与结果
['1) 五个 benchmark：CelebA-HQ（30,000 图，28K/2K，64×64）、ImageNet ILSVRC2012（1.28M 训练/50K 验证/100K 测试，256×256）、ERA5（8.5K/1.1K/2.4K，46×90）、ShapeNet Chairs（6,778 椅子，32³ occupancy）、Pre-trained NeRF（103K 物体，98.6K/4K，每物体 36 视角）。', '2) CelebA-HQ：PSNR 27.7 / SSIM 0.8635 / LPIPS 0.0296；对比 LDMI 24.8/0.6947/0.0556、VaMoH 21.3/0.6303/0.1332、HyPoGen 16.2/0.4550/0.1463（塌陷）。', '3) ImageNet：22.9 dB（LDMI 20.7、VaMoH 19.6、HyPoGen 13.2 不收敛）；ERA5：49.3 dB / SSIM 0.9991 / LPIPS 0.0001（LDMI 44.6）。', '4) ShapeNet Chairs：occupancy accuracy 97.9%、PSNR 23.8（LDMI 97.3%/22.4、VaMoH 96.8%/15.6、HyPoGen 95.2%/19.0）。', '5) Pre-trained NeRF：weights-only 22.0 dB（HyPoGen 19.9、LDMI 19.3、HyperDiffusion 20.0）；images-only 28.8 dB（LDMI 26.2、HyPoGen 24.9）；weights&images 27.8 dB / SSIM 0.948 / LPIPS 0.0742。', '6) 效率（batch=16）：Pre-trained NeRF 参数 482.5M vs HyPoGen 1049.9M、显存 2.51 GB vs 14.51 GB、推理 2018 ms vs 2382/2541 ms；ImageNet 124.5M vs 578.7/544.9M。', '7) 宽度扩展：width 128→1024，HyPoGen 参数暴涨并在 1024 显存耗尽，本方法 PSNR 26.5→28.8 dB，HyPoGen 全程约 16 dB。', '8) 数据扩展：10%→100% NeRF 训练数据，本方法 +3.2 dB、LDMI +2.5、HyPoGen +1.8；与 LDMI 差距从 0.6 扩到 1.3 dB。', '9) 稳定性：5 个随机种子，NeRF 27.76±0.05 dB、CelebA-HQ 27.66±0.10、ERA5 49.26±0.23。']

## 创新点与贡献
['把 optimization-oriented 超网络的可扩展性瓶颈诊断为 MLP 实例化的结构性属性（O(n_i²d²)），并用 attention 主体把核心参数量降到 O(d²) 同时保留链式法则结构。', '提出 information-flow consistency 这一单一设计规则，从“输出应占据的角色”反推每个 cross-attention 的 QKV 分配，使一步优化的五个量一对一映射为五个模块（对调 Q 与 K/V 掉 4.2–4.9 dB）。', 'output-neuron-centric tokenization 让 token 轴与输出神经元轴对齐，是五个逐层量能在 token 空间正确聚合的前提（换成列式 token 化掉 2.4–3.1 dB）。']

## 局限与风险
['作者承认 batch=1 的单实例推理延迟在较小 benchmark 上高于 MLP 版 HyPoGen，因 cross-attention 常数因子更大。', '作者承认成本对目标层数 L 线性、对 attention 序列长度二次，远超 3–5 层 SIREN/NeRF 的更深更宽目标网络会被这两项主导。', '作者承认只在 5 个数据集中的 3 个做了多种子统计，全配置多种子超出算力预算。', '我发现：所有任务的目标网络都被限定在 3–5 层，所谓“可扩展”主要体现在宽度而非深度；ImageNet 上 SSIM 仅 0.6064，大尺度 2D 信号的重建质量仍偏低。']

## 与文献库的关系
直接对标 HyPoGen（同守 optimization-oriented 原则、换主体）与 LDMI（同样用 attention 但不保链式法则），与 weight-space 生成（HyperDiffusion）、INR-VAE、modulation 类（VaMoH）、NeRF 专用超网络并列；思想上承 SIREN 等 INR 表达力工作与 meta-learning / learned optimizer 的摊销范式。
