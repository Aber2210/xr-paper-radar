# RoboMoCap：面向机器人学习的第一视角全身动捕大规模数据集

## 一句话结论
发布 200+ 小时、14 人、291 个动作协议（8 大类）的第一视角 + 120 Hz 光学动捕数据；基准显示现有方法最好 MPJPE 80.8 mm（EgoAllo）、足部接触 F1 90.5%，仍低于 GT SMPL-X 的 93.6%。

## 要解决的问题
人形机器人要在人类环境中协调移动与操作，从人类演示学习需要「全身运动 + 第一视角视觉」配对，尤其下肢与足部落点在第一视角常不可见。现有第一视角数据集要么缺高保真光学动捕，要么对移动-操作行为覆盖不系统。而仅用头手稀疏跟踪或头戴相机推断全身存在根本歧义：相似头部轨迹可对应完全不同的步态，头部朝向也不等于身体朝向或行进方向，在转向、侧行/后退、动态姿态转换与搬运时尤其严重。缺少带度量真值的基准，就无法量化这些方法的真实差距。

## 方法详解
采集系统：RoboCap 头戴平台（6 路硬件同步全局快门 RGB，1920×1080@30 Hz，含前视/下视鱼眼立体对 + 两路侧向广角；2 路 IMU 200 Hz + 磁力计 100 Hz），双腕 RoboWrist（广角 RGB + IMU + 磁力计），1 路第三人称相机，NOKOV 光学动捕（53 反光标记、120 Hz），头显上 4 个标记构成 Tracker0 做 6-DoF 头部位姿与时空配准基准；物体用 iPhone LiDAR 扫描 + 4 标记做 120 Hz 6-DoF 跟踪；另有麦克风。场地为 7×7 m 动捕棚，支持直线、转向、圆形、8 字、往返等连续运动。标注管线：30 fps 视频与 120 Hz 动捕时间对齐，局部手部姿态估计与腕部跟踪位姿融合，身体关节与刚体位姿由动捕重建，输出 SMPL-X 与标定相机观测。分类法为 8 类 291 个协议（移动原语 44、姿态动力学 60、移动-操作 86、静态操作 44、长时组合 11、动态恢复 15、人人协作 14、环境耦合全身 17）。

## 实验与结果
['规模与质量：200+ 小时、14 人（中位 13.67 h，范围 9.79–21.95 h，最大贡献者占 11.4%），会话中位 127 s；动捕有效率 99.81% 骨架帧、99.74% 标记可见率，SMPL-X 拟合中位标记重投影误差 4.78 mm；移动原语+姿态动力学+移动-操作合计 161 h（≈80.6%）。', '第一视角全身重建（Table 3，均用官方预训练权重不微调）：EgoAllo 最低 MPJPE 80.8 mm、MPJVE 14.5 cm/s、加速度误差 214.5 cm/s²、抖动 72.06 m/s³；AGRoL 最低 W-MPJPE 95.4 mm 与 WA-MPJPE 64.9 mm；EgoEgo 最差（MPJPE 130.9 mm、头部位置 138.2 mm）。', '足部接触与落点（Table 6）：EgoAllo 接触 F1 90.5%、Footprint 85.1 mm、Step 154.1 mm、滑移 54.8 mm/s、穿透 8.5 mm；EgoEgo/AGRoL 滑移达 291.1/273.7 mm/s；GT SMPL-X 参考 F1 93.6%、滑移 43.6 mm/s。', '人到 Unitree G1 重定向（543 个测试会话 ≈18 h）：OmniRetarget 匹配关键体 34.8 mm、足 49.5 mm、手/腕 29.3 mm，但测地误差 0.470 rad、成功率仅 53.6%；GMR 足部滑移 12.3%、自碰 10.7%、成功率 7.4%；PHC 成功率 79.6% 但穿透帧占 20.9%、最大穿透 37.1 cm。', '标注链路校验：Tracker0 提供头显 6-DoF 参考，四类传感器流时间对齐后再融合，手部局部估计与腕部位姿对齐后写入 SMPL-X 表示。']

## 创新点与贡献
['首个把「第一视角多相机 + 120 Hz 光学全身动捕 + 物体 6-DoF + 双手」在移动-操作场景系统配对的大规模数据集（200+ h / 291 协议）。', '以移动为中心的动作分类法，覆盖转向、侧行/后退、窄道、坡道楼梯、搬运越障、扰动恢复等第一视角难以推断的行为。', '建立三个可复现基准（第一视角全身重建、足部接触与落点、人到人形重定向），暴露「局部姿态准 ≠ 全局运动对 ≠ 足部物理合理」的三重落差。']

## 局限与风险
['数据在装备化动捕棚内采集，环境与地形多样性远低于真实世界。', '标记遮挡与人体模型拟合误差仍影响标注（虽标记可见率 99.74%，仍有残余）。', '参与者、物体与交互场景数量有限，不能代表人类运动全分布。', '人与人形在形态、运动学与能力上差异大，动作无法直接迁移，需重定向与控制适配；下游真机执行效用未验证。']

## 与文献库的关系
相对传统动捕数据集与以头手跟踪为主的第一视角人体数据集，本文补上「高保真全身 + 下肢可见真值」；与 EgoEgo/EgoAllo/EgoPoser/AGRoL 是提供评测基准的关系，与 GMR/PHC/OmniRetarget 是被评测对象。定位类似「第一视角版 AMASS + 人形学习试验台」，与 RoboCap/RoboWrist 硬件线同源。
