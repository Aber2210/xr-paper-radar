# ViTacLab：面向机器人操作物理一致的视触觉仿真、基准与表征学习

## 一句话结论
把触觉生成从「穿透深度后处理」改为「接触求解器锚定 + 法向刚度对齐 + 滑/黏解耦切向重建 + 保力矩摩擦锥投影」，在不牺牲 GPU 并行下同时修好法向饱和与切向欠定——法向力 RMSE 2.31→0.42 N（−81.8%），触觉流水线 56.0→2,482.9 FPS（256 环境）。

## 要解决的问题
接触密集操作依赖触觉，但视触觉框架长期在「物理保真但不可扩展的仿真器」与「GPU 并行但接触响应不一致的近似」之间取舍：后者由原始穿透深度推导触觉，法向响应会在求解器深度上限处饱和、破坏形变-力一致性，切向力在相对速度趋零的静摩擦区又变成欠定。评测侧现有触觉基准多局限于两指夹爪与单一视觉/触觉主导区间，无法回答「视觉退化时触觉何时接管」；策略侧常绑定固定传感器数量与布局，并把稠密力阵列与触觉图像简单拼接而不做物理对齐。

## 方法详解
ViTacLab 由三部分组成。ViTacSim 以 PhysX 接触求解器输出为锚，而非穿透深度，构建三模态触觉原语：全局稀疏接触力格 T_sparse=P(C)、局部稠密力阵列 T_dense={φ_n(x),φ_t(x)}、以及触觉图像 T_img。法向修正先由邻域稀疏接触估计局部刚度 k_local(x)=RobustMean(F_{n,i}/(d_i+ε))，再按参考刚度缩放修正位移 δ_corr=d_raw·k_local/k_ref，输出 φ_n=k_ref·δ_corr，k_ref 取有效力深比的滑动中位数，从而消除高载饱和。切向重建按切向速度把 patch 分为滑动区 Ω_sl 与黏着区 Ω_st，滑动区用稀疏锚点比例 γ(x) 校准并投影到 Coulomb 摩擦盘 φ_t^sl=Π_{μφ_n}(γ φ_t,d)，黏着区用高斯权 w_i∝exp(−‖x−c_i‖²/σ²)（σ=1.5 倍接触半径）插值稀疏静摩擦锚点再施加同一摩擦界；最后做联合投影 φ*=argmin_{φ∈K}‖φ−φ̃‖² s.t. Aφ=w_PhysX，K={φ: φ_n≥0, ‖φ_t‖≤μφ_n}，既保住稀疏求解器的合力/合力矩，又不让稠密场违反局部摩擦锥，且全程只有局部投影、插值与 scatter，保持 GPU 并行。ViTacBench 按「本体复杂度 × 模态依赖」两轴组织 15 个任务：平行夹爪（peg insertion、gear meshing、nut threading）、灵巧手（桌面抓取、in-hand 操作、双稳态传递、灵巧插孔、盲抓、目标抓取）、双臂（交接、开瓶、扭转、低光协同、双臂书写），并分 vision-dominant / visuo-tactile cooperative / tactile-dominant 三档，Level 3 完全遮掉腕部相机并刻意遮挡全局视角。ViTacPolicy 用 3D 位置 + 6D 朝向的位姿 embedding P_i=MLP(X_i) 加到各触觉编码特征上得 Z_i=h_i+P_i，经 Transformer 编码与池化得 h_tac，与 RGB 特征、本体状态一起条件化策略，从而支持任意数量与布局的触觉输入；预训练用共享码本的双流 VQ-VAE，对两种模态在池化前的特征图做量化（共享 C_vq），损失 L_pre=L_vq+λ_align·MSE(h_dense,h_img)，既在特征图级学局部接触基元，又在全局 embedding 级对齐两种模态。

## 实验与结果
- 法向力 RMSE 从 2.31 N 降到 0.42 N（−81.8%，对 Hertzian 压痕参考），切向力 RMSE 从 1.85 N 降到 0.53 N（−71.4%，对真实传感器滑动实验）
- 触觉流水线吞吐从 1 环境的 56.0 FPS 升到 256 环境的 2,482.9 FPS（44.3×），与 TacSL 的差距从 26.7% 收窄到 6.4%；256 环境显存 20,184 MiB，仅高 376 MiB（1.9%），512 环境两者均超 24 GB
- 仿真：Peg 24.0% / Gear 69.0% / Nut 44.0% / Grasp 90.0%，对 DP（16.0/39.5/38.5/29.0）与 ViTacFormer（Grasp 31.0）全面领先；但 Blind Grasp 所有方法 ≤3%
- 真实夹爪迁移（每任务 50 trial）：完整系统平均 61.3%，无预训练 48.7%，仅穿透基线 44.7%；Peg 由 20% 提到 38%（+18 点），CMH 共同优势比 1.82（95% CI [1.11,2.98]，p=0.018）
- 共享码本 vs 单模态 VQ：Gear 18 / Bottle 24 / L3 Peg 12，优于最强的单模态变体（14/18/5）
- 数据缩放：L3 Peg 从 100 条示范的 6% 升到 500 条的 22%

## 创新点与贡献
- 把触觉生成从「穿透深度后处理」改为「接触求解器锚定 + 法向刚度对齐 + 滑/黏解耦切向重建 + 保力矩的摩擦锥投影」，在不牺牲 GPU 并行的前提下同时修好法向饱和与切向欠定两个物理缺陷
- 基准首次把本体复杂度（夹爪/灵巧手/双臂）与模态依赖（视觉主导→触觉主导）做成二维网格，使「视觉退化时触觉何时接管」成为可测问题
- 策略侧用位姿条件化 + 共享码本双流 VQ-VAE 解决异构触觉布局与跨模态对齐

## 局限与风险
- 未建模可变形物体、粘附、磨损与传感器老化，触觉图像仍依赖简化光学渲染模型
- Level 3（盲抓等纯触觉主导）任务成功率 ≤3%，500 条示范也只到 22%，说明纯触觉控制远未解决
- 真实迁移仅在三个夹爪任务上做统计检验，灵巧手与双臂部署为定性结果，per-task 显著性不足（Fisher p=0.126/0.176/0.537）
