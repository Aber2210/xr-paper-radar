# CognitiveReality：机器人无关语义高斯映射与沉浸式协同 VR 遥操作

## 一句话结论
CognitiveReality 合 Gaussian-TSDF 语义建图、LLM 路由与 VR 交互：工具匹配 81.24%(规则基线 48.33%)，实机导航 26/30、重观测 20/20。

## 要解决的问题
3DGS 遥操作场景虽逼真但被动：操作者难以理解场景内容、各物体观测质量，也难把指向与语音转为机器人动作；开放词汇高斯映射多不维护持久物体 ID 与质量属性，agent 与操作者无法引用同一实体，语言解释与执行缺乏验证分离；机器人定位中断时的地图连续性亦难保证。

## 方法详解
沿用 GPS-SLAM 的 Gaussian-SDF 设计：位姿源可插拔(机器人SLAM/运动学/动补/内联ORB-SLAM3切换)，陀螺仪门控加噪声加权深度融合，异步高斯优化；影子跟踪器桥接定位中断，双失效时对最近 3 个 RGB-D 关键帧做 PnP-RANSAC 注册，地图不重置。Label Splats 将几何一致的语义像素置于 SDF 表面，携带语义 ID 但不进光度光栅化(office0 覆盖 47.6%→100%)。异步双速率语义：2-3Hz 快环+0.5Hz 发现环(中位延迟 0.6s，本地 VLM 验证+同义词门控)，每 2s 导出版本化 Scene Model(类/ID/质心/框/质量)；agent 侧预路由+Qwen3-VL-8B 模式约束路由产出 typed 决策，后置校验参数/物体存在/合并 ID，机器人动作需确认；VR 支持 RSIS/3SLR。

## 实验与结果
重建：较 GPS-SLAM 基线各平台 PSNR +2-8dB(四足26.54vs22.86、UR10 24.23vs22.83、手持22.17vs21.50、动补21.91vs16.11)，720p 达 51-66FPS。语义：Replica 51 类零样本分割闭词表 mIoU 29.53vs29.93、mAcc 46.63vs43.60、f-mIoU 65.73vs57.00(HoloAgent)。VR：Pico 4 Ultra 上 RSIS 54-84fps/25-46ms，3SLR 66-85fps、PC-HS 36.7dB。Agent：1,471 案例工具匹配 81.24%vs48.33%、完整调用 72.88%vs42.96%、效果 84.70%；重放 117/167 集重定向 101 个合并 ID；实机导航 26/30、重观测 20/20(质量+2-5dB)。

## 创新点与贡献
①机器人无关在线 Gaussian-SDF 映射：位姿源可插拔加影子跟踪/PnP 桥接定位中断；②Label Splats 实现 100% 语义覆盖并向真几何中心纠偏；③版本化 Scene Model+typed tools+确认门把语言、指向与机器人动作统一到持久物体 ID，多平台实机验证。

## 局限与风险
集中式 GPU 工作站计算，未测分布式部署；确认门在提议后不再对照后续地图更新重校验(40 例挂起确认保持旧引用)；VLM 与地图标签一致率不等于独立视觉识别；共享 GPU 下命令率使高斯往返时延+12.7%；导航失败可源于噪声高斯导致地面点偏移。
