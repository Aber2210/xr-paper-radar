# BitC-3DGS：位压缩 token 化的高容量 3DGS 水印

## 一句话结论
BitC-3DGS 用“位压缩 token 化”突破 CLIP 77 token 对 3DGS 语义水印约 75 bit 的容量上限，配合双分支解码器与难样本采样，在 Blender/LLFF 上实现 128 bit 水印，恢复比特精度 90.59%（[Random]）/91.42%（[In]），与先前方法 64 bit 水平相当，且 PSNR 34.32、LPIPS 0.0068 保持高保真。

## 要解决的问题
3DGS 资产在 AR/VR、数字孪生、机器人等大规模内容管线中流通，需要高容量水印以嵌入版权、来源与认证等丰富元数据。现有低层信号扰动方法（GaussianMarker、3D-GSW）随消息变长性能骤降；基于 CLIP 的 bit-to-token 语义水印（GuardSplat）受 CLIP 固定 77 token 上下文与学习式位置编码限制，扣除首尾 token 后一位一 token 最多 75 bit，容量存在硬上限；且固定消息子集训练使解码器偏向已见消息，容量增大后泛化恶化。如何在固定 token 预算内编码远超 77 bit 的信息并可靠恢复，同时不损害渲染质量，是核心挑战。

## 方法详解
三大组件。(1) 位压缩 token 化：将 L bit 消息切成 ⌈L/n⌉ 个 n bit 块，每块对应 2^n 个离散值之一，经位置感知查找表（由 CLIP 词表剔除保留位后随机置换构建）映射为单个语义 token，序列零填充至 77，容量上限由 75 bit 升至 75n bit。(2) 双分支解码器：冻结 CLIP 文本编码器输出 512 维嵌入经共享可训练投影后分两路——chunk 分支用两层 MLP 加可学习位置嵌入与四头 Transformer 预测 C 个离散块索引（交叉熵损失），并经固定二进制码簿边缘化得到投影比特 BCE 损失；bit 分支用 G 个并行线性头加门控自注意力直接预测每个比特（BCE），两分支联合训练。(3) 难样本消息采样：维护 K=2048 条消息缓冲与在线准确率记忆（指数平滑），冻结前每 epoch 按线性升温比例选取历史低准确率难样本并无放回补充未见消息，冻结后固定为准确率最低的 K 条。水印嵌入阶段冻结解码器，仅优化 SH 系数偏移，损失含比特恢复、SSIM+L1 与 LPIPS 保真及偏移正则。

## 实验与结果
在 Blender（8 合成物体）与 LLFF（7 真实场景）测 16–128 bit。32/48/64 bit [In] 精度 99.71/99.17/97.90，均超 GuardSplat（99.04/98.29/95.07）；96/128 bit 为 94.27/93.97 与 91.42/90.59，GuardSplat 加装同款 token 化仅 90.57/88.41 与 84.45/80.84。128 bit [In] PSNR 33.01→34.32、LPIPS 0.0099→0.0068。未见消息差距远小于基线：32/48/64 bit 为 0.08/0.60/1.10 对 0.70/3.77/4.29。鲁棒性：32 bit 七种 2D 扰动全优；96 bit 较基线高 3.12–5.63 个百分点，组合攻击 88.02% 对 82.39%；模型空间删/克隆 20% 高斯与 SH 噪声下 96 bit 为 94.18/92.93/86.03。消融：BCT 单独仅 95.13，配 DBD 达 98.10，HMS 将 [Out] 90.78 提至 93.76。

## 创新点与贡献
① 提出位压缩 token 化，把 CLIP 77 token 硬限制改写为 75n bit 容量上限，首次在 3DGS 语义水印中支持 128 bit 级容量；② 设计 chunk/bit 双分支解码器，以块结构先验加直接比特监督兼顾压缩表示与可恢复性；③ 提出难样本消息采样策略，缓解固定子集偏差、显著改善未见消息恢复；④ 在不牺牲渲染保真的前提下实现容量-精度-视觉质量平衡，128 bit 的恢复精度仍与先前方法 64 bit 相当；⑤ 在 2D 图像扰动与 3D 模型空间扰动两类攻击下系统验证鲁棒性。

## 局限与风险
实验显示容量越大解码越难：128 bit 精度降至约 91%；n=8 的过度压缩因块空间 2^8 过大而持续变差，n=2 仅适合 32–96 bit、n=4 才利于 128 bit；难样本调度过激（初始难样本过多或终值接近 1.0）会损害多样性。方法依赖冻结 CLIP 的语义空间与 SH 偏移嵌入机制，未验证其他高斯表示或需大幅编辑的场景；实验仅覆盖 Blender/LLFF 两类数据，缺少大规模室外 3DGS 资产测试。
