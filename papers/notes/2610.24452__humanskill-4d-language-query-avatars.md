# HumanSkill-4D：可动画高斯化身的免训练时空语言查询

## 一句话结论
HumanSkill-4D 免训练赋予冻结 MLLM 查询高斯化身的技能：离线构建语义记忆（16 类身体部位/服饰类别关联高斯区域）、运动记忆与跨化身共享的算子注册表，在线由冻结 MLLM 选类别、确定性执行器跑运动程序，产出 3D/4D 时空选择掩码；配套构建 ZJU-Refer-3D/HuMMan-Refer-4D/ZJU-Refer-4D 三个基准（各 20 条指代查询），以 mIoU、vIoU/tIoU 等评估。

## 要解决的问题
可动画高斯化身的结构（持续存在的高斯基元加驱动位姿序列）对语言模型不透明，导致哪里/何时类时空语言查询难以直接回答；现有方法多需训练专用分割头，跨化身复用性差。如何在免训练前提下把高斯化身结构暴露给冻结 MLLM，实现对部位/服饰/穿着关系/功能的 3D 指代与某运动条件成立时段的 4D 指代，是本文要解决的问题。

## 方法详解（含关键公式/架构，保留原文术语）
离线阶段：① 语义记忆 M_semantic——以 3DGS-Avatar（Qian et al., 2024）重建的 canonical Gaussians 为对象，用冻结 2D 人体解析器 Φ_parse（Sapiens2）对注册相机帧对 (v,t) 的人物像素打标并映射到身体部位/服饰类别集合 K，按类别分数 p_ic 关联到高斯，同时用 Φ_MLLM 从多视图图像生成类别级外观描述；② 运动记忆 M_motion——存储每条驱动位姿序列的关节与 root 轨迹；③ 算子注册表 R——跨化身共享的位姿/运动条件检查模板加时序关系（条件如何重叠或相继）。在线阶段：冻结 MLLM Φ_MLLM 读取查询 q 与类别名/描述选出目标类别 C_q，其存储分数决定空间掩码 s_q（Where，3D 查询的完整输出）；4D 查询 additionally 读取注册表 text cards，将算子组合成运动程序 Π_q，由确定性执行器在 M_motion 上运行得到时序掩码 h_q（When），两者给出时空选择 Y_q。示例：程序识别双臂同时外展区间，StateAtEnd 算子保留末帧双臂水平的区间。

## 实验与结果（表格化关键数字）
自建三个基准：ZJU-Refer-3D（扩展 ZJU-MoCap，密集部位标注加 20 条指代查询，覆盖部位名/外观/穿着关系/功能，16 类）、HuMMan-Refer-4D（扩展 HuMMan，将其细粒度部位运动描述转为 20 条查询）、ZJU-Refer-4D（扩展 ZJU-MoCap，同格式 20 条查询）。指标：部位分割报 mIoU/OA/mAcc；3D 指代分割报查询级 mIoU；4D 指代分割报 vIoU（区域加时序联合，惩罚错掩码与多余/漏选帧），另报 tIoU、precision、recall。含 3D/4D 评估的消融与计算分析（5.3）及更小 MLLM 的讨论（附录 D.1）；digest 未包含表 1/表 2 具体数值。

## 创新点与贡献
① 提出 avatar referring segmentation 任务定义：同时选择化身区域与满足查询姿态/运动条件的时段。② 免训练框架：把高斯化身结构作为技能教给冻结 MLLM，不训练任何分割/理解模块。③ 语义-运动记忆分离加跨化身共享算子注册表的设计，使查询能力可迁移到新化身。④ 用确定性执行器解释 MLLM 组合出的运动程序，规避 MLLM 时序推理不可靠问题。⑤ 配套构建三个带人工标注的指代基准（构造细节在补充材料）。

## 局限与风险
依赖冻结 2D 解析器（Sapiens2）的部位类别覆盖度，未见类别/细粒度服饰可能无法查询。空间掩码由类别分数决定，边界精度受解析与高斯-像素关联质量限制。4D 时序选择由模板化算子拼装，表达力受注册表算子种类约束。digest 未给出具体指标数值，相对基线增益需查原文；MLLM 推理成本与延迟（5.3 计算分析）digest 未含数字。

属库内化身研究线（2602.11693 OMEGA-Avatar、2610.23772 VDA、LAM/GAGAvatar/FlexAvatar）的语言交互延伸：那些工作侧重化身重建/驱动/压缩，HumanSkill-4D 补上自然语言查询化身结构与运动的能力。其高斯-语义关联思路与库内 3DGS 场景理解线互洽；运动程序加时序关系的设计可视为化身版的时空语言接地（spatio-temporal grounding）。

## 行动建议
