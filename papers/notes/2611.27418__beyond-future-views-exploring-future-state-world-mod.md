# 超越未来视角：探索面向视觉语言导航的未来状态世界模型（FS-Nav）

## 一句话结论
把 world model 的预测目标从「未来视角」换成目标导向的空间状态（waypoint–corridor），以确定性渲染而非像素生成接入 VLM：R2R-CE Val-Unseen SR 60.7、预测 66.7 ms/次（比像素生成快约 500 倍）。

## 要解决的问题
VLN 要求具身智能体在未见 3D 环境中按指令导航，而目标空间常位于当前观测之外。现有 navigation world model 以像素或 latent 预测「未来视角」，需重建与导航无关的外观细节，且仍以「智能体会看到什么」定义未来。作者据此追问：预测未来视角是否是表示未来的终极形式。

## 方法详解
受预测性认知地图（hippocampus 前瞻性表示目标与路径中间位置）启发，用短时域 waypoint 与中时域 corridor 组成未来状态 S=(W,C)，描述「下一步去哪」与「路线如何展开」。Future State World Model 从累积空间地图与指令预测二者：waypoint 用高斯热图 + soft-argmax，corridor 用路径带 mask（BCE/Dice/clDice/TV）加有序点回归与曲率惩罚。Future State Renderer 确定性地把同一预测渲染为 top-down canvas 与 first-person overlay 两种接口。Future-State-Guided Navigator 基于 Qwen2.5-VL-3B-Instruct，在指令、观测历史与渲染引导条件下自回归输出动作 chunk。

## 实验与结果
- R2R-CE Val-Unseen SR = 60.7（OSR 66.1，SPL 55.9，NE 4.84）
- RxR-CE Val-Unseen SR = 55.1（SPL 46.5，nDTW 62.7，NE 6.03）
- 未来状态预测耗时 = 66.7 ms（单张 RTX 4090，batch size 1）
- 预测速度快于 500 倍（相对 Wan2.2-TI2V-5B 生成五帧未来观测）
- oracle GT→GT SR = 72.3（同一设定下 Pred→Pred 为 44.4）
- ADE 降低 = 16.5%（world model 额外加入 ScaleVLN 轨迹训练）

## 创新点与贡献
- 把 world model 的预测目标从「未来视角」换成目标导向的空间状态（waypoint–corridor），并以确定性渲染而非像素生成接入 VLM，同时保持闭环动作决策能力

## 局限与风险
- 作者指出未来状态预测质量仍是主要瓶颈（Pred→Pred 44.4 与 GT→GT 72.3 差距大）
- 需依赖 depth、odometry 与预测语义维护空间地图，且仅在 VLN-CE 仿真基准验证
