# Ego4Gen：生成几何锚定的运动 token 作为世界-动作接口

## 一句话结论
把「几何 + 运动」潜变量而非视频或隐动作当作世界—动作接口，同一表征可解成点图与场景流又能直接回归动作：RoboTwin Hard 51%/37%（LAM 与视频潜变量基线皆为 0%）。

## 要解决的问题
视觉世界模型用 RGB 视频预测未来，但视频把任务相关状态变化与颜色、纹理、光照、背景等外观因素混在一起，形成控制器必须额外容忍的外观漂移；隐动作模型（LAM）的紧凑表征也会编码与控制无关的视觉变化，紧凑本身不足以保证鲁棒。

## 方法详解
基于 Cosmos3-Nano 的 Mixture-of-Transformers，冻结骨干并新增几何与运动分支，用模态路由 LoRA（视觉 r=32、几何/运动 r=64）与非对称注意力（RGB token 只看文本与 RGB；点/流 token 看全部模态，但对 RGB 的 K/V 用 stop-gradient 隔离梯度）联合去噪三模态。接口取 MotionCrafter 4D VAE 的几何—运动潜空间：视觉 96 帧 @24 FPS、几何/运动各 48 帧 @12 FPS，用模态相关时空 patchification 与 3D MRoPE 对齐（运动模态时间偏移 0.25）。再用两阶段训练的轻量逆动力学网络 FlowInverse（卷积编码 + 动作查询跨注意力，关节增量为主监督、末端位移为辅助）把潜变量映射为机器人动作，实现闭环控制。

## 实验与结果
- Place Empty Cup / Pick Diverse Bottles 的 Hard 成功率 = 51% / 37%（LAM 与视频潜变量基线均为 0%）
- 五个 RoboTwin 任务闭环平均成功率 = 46.6% Easy / 15.2% Hard（π0 41.0 / 21.4）
- 无动作标签视频后训练后 Hard 平均成功率 = 15.2% → 26.4%（Easy 46.6% → 37.2%）
- TACO 两秒点图 δp = 73.62%（4DNeX 50.80%），Rel_p = 23.21%
- TACO 四秒 RGB PSNR = 14.83 dB（Cosmos3-Nano 14.69 dB，Wan2.2 13.69 dB）

## 创新点与贡献
- 把「几何 + 运动」潜变量而非视频或隐动作潜变量作为世界—动作接口，同一表征既能显式解码成点图与场景流，又能直接回归动作，并在分布外外观下比 LAM/视频潜变量更稳

## 局限与风险
- 无相机参数预测分支，需外部内参与逐帧外参
- 混合视频后训练后 Easy 成功率从 46.6% 降到 37.2%，作者归因于生成器更新后潜变量与 FlowInverse 训练时的不匹配
- 4D 生成 PSNR 仍略低于 RynnWorld-4D（16.06 对 16.27 dB）
