# LightFuse：多扫描融合与二维高斯光线追踪的可重打光交互式场景重建

## 一句话结论
把几何与 PBR 材质跨状态共享、状态间只差物体刚体变换与光照，用 2D 高斯 surfel + 光线追踪做多扫描融合——新状态重打光 PSNR 25.89 / SSIM 0.873（比最强基线 IRGS 高 6.01 dB），真实场景 24.35 dB（ReCap +1.55）但 SSIM 略低（0.821 vs 0.903）。

## 要解决的问题
交互式场景重建要从不同物体摆位的多次扫描中建出可编辑 3D 模型，使新布局能在新光照下渲染。现有 GS 路线（IGFuse、RecurGS、LTGS）把外观直接从图像优化进高斯，材质与光照纠缠在一起，导致两种失败：不同状态的外观被烘进同一份共享表示，产生光度不一致；新布局下烘死的阴影、高光与间接光跟着物体走，物理上不成立。逆渲染路线（IRGS、ReCap、GauUpdate）能做材质-光照分解，却假设所有拍摄共享同一份静态几何，无法关联「同一表面在不同状态、不同位置、不同光照下被观测」这件事。量化差距很明显：新状态重打光下 IGFuse 只有 14.88 dB、ReCap 15.39 dB、IRGS 19.88 dB。

## 方法详解
LightFuse 用 2D Gaussian surfel 表示共享背景 $\mathcal{B}$ 与 $M$ 个可动物体 $\mathcal{O}_o$，每个 surfel 存 $(\mu_i,\mathbf{q}_i,\mathbf{s}_i,\alpha_i,\mathbf{a}_i,m_i,r_i,\mathbf{f}_i)$：前三项是几何，后三项是 PBR 材质，$\mathbf{f}_i$ 只是逆渲染前的辅助 splatting 颜色。几何与材质跨所有状态共享，状态 $k$ 之间只差物体刚体变换 $\mathcal{T}_{k,o}$ 与环境图 $E_k$（$256\times128$ HDR），即 $\mathcal{S}_k=(\mathcal{B}\cup\bigcup_o\mathcal{T}_{k,o}(\mathcal{O}_o),E_k)$。第一阶段在参考状态用 RGB 加几何监督重建，用 SAM 3 掩码与 GaussianCut 分出背景与物体，把参考状态的物体位姿定为 canonical frame，再估其他状态的 $\mathcal{T}_{k,o}$。跨状态补全只借几何证据：把每个组件在每个状态的每个视角渲染出来，凡渲染深度落后观测深度超过 $\tau_D$ 的像素 $\mathcal{H}=\{p:\hat{D}(p)-D^*(p)>\tau_D\}$ 视为被遮挡，用观测深度与法线反投影成新 surfel、经 $\mathcal{T}^{-1}_{k,o}$ 回到 canonical frame，颜色先填 $\mathbf{f}_i$。第二阶段做面向光线追踪的几何优化：surfel 作为有限支撑的有向求交原语，有效不透明度 $\tilde{\alpha}_j=\alpha_j\exp(-\tfrac{1}{2}\|\boldsymbol{\xi}_j\|^2)$ 截断在 0.99，按平面交点深度排序后前向合成 $T_j=\prod_{\ell<j}(1-\tilde{\alpha}_\ell)$、$w_j=T_j\tilde{\alpha}_j$，同一套权重同时给出位置/深度/法线/材质的合成值，保证几何与材质对齐；再加覆盖率正则 $\mathcal{L}_\alpha$（补洞）与尺度正则 $\mathcal{L}_s$（限制 surfel 尺寸，避免补洞后虚假遮挡自由空间射线），然后用追踪器本身做 refinement。第三阶段固定几何，做多状态逆渲染：可微单次反弹路径追踪，每条路径一次 NEE 环境采样加一次 BSDF 续接并用 MIS 合并，至多一次二次命中加四次环境采样，共享材质与逐状态 $E_k$ 联合优化，spp 从 8 逐步升到 16（第 7500 迭代）与 32（第 12000 迭代），共 15000 次迭代、每次从一张图采 16384 像素。编辑时对目标刚体变换重跑追踪，阴影与互反射随新布局重算。

## 实验与结果
- 新状态重打光（4 个合成场景 × 11 张未见环境图）：PSNR 25.89 dB / SSIM 0.873，比最强基线 IRGS 高 6.01 dB 与 0.131 SSIM
- 同设定下 IGFuse 14.88 dB / 0.714、ReCap 15.39 dB / 0.713、IRGS 19.88 dB / 0.742
- 真实场景新状态合成（Captured 1/2）：PSNR 24.35 dB 最高，比 ReCap 高 1.55 dB，但 SSIM 0.821 低于 ReCap 的 0.903
- 几何消融（4 合成场景）：AO MAE 0.0434→0.0272（加跨状态补全），PSNR 23.28→24.21 dB；再加 $\mathcal{L}_s$ 到 25.51 dB，最后光线追踪 refinement 到 25.90 dB / SSIM 0.875，法线 MAE 降到 1.695°
- 逆渲染消融（固定几何）：去间接光 25.90→22.54 dB，去 MIS 降到 19.86 dB
- 采样策略：固定 32 spp 25.97 dB / 3.01 h，渐进 8→16→32 为 25.90 dB / 1.59 h，固定 8 spp 25.66 dB / 1.08 h
- 环境图规模 256×128，逆渲染 15000 迭代、每次 16384 像素，单卡 RTX 4090

## 创新点与贡献
- 相对 IGFuse/RecurGS 这类「融合但不分解」的交互式重建，LightFuse 把材质与光照从外观里拆出来，且共享材质、逐状态环境图，编辑后重算可见性与光传输
- 相对 IRGS/ReCap 这类逆渲染，它允许几何在不同扫描间被重排：同一份 surfel 材质被多个状态的不同光照共同约束，这既是补全几何的证据，也是缓解材质-光照歧义的约束
- 面向追踪的几何正则（覆盖 + 尺度）与 refinement 是针对「splatting 优化出的表面在追踪下漏光/虚遮挡」这一具体缺陷设计的

## 局限与风险
- 只有单次反弹，长路径全局光照、焦散、透射与镜面链都无法忠实恢复
- 追踪与优化仍昂贵（逆渲染 1.59 h），所谓 interactive 指的是可重排可编辑，不是实时帧率
- 几何分解依赖多视角掩码与 GaussianCut，分割错误会经冻结几何直接传到材质与光照，作者列为第一条局限
- 真实场景只有 2 个、且因真实光照无 GT 只评合成不评重打光
- 真实场景 SSIM 还低于 ReCap，作者归因于蒙特卡洛噪声与去噪模糊，但这意味着在解析着色基线面前感知质量并未全面占优
