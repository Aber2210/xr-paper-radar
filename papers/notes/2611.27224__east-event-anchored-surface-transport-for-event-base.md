# EAST：面向事件相机高斯重建的事件锚定表面传输

## 一句话结论
给出事件监督下 appearance-gradient 与 depth 补偿的局部可辨识性分析，并提出「相对冻结参考场的有界中心传输」：PAEv3D CDsum 0.051 对 Event-3DGS 0.127。

## 要解决的问题
事件监督的高斯重建兼具事件相机的高时间分辨率、高动态范围与显式渲染效率，但恢复连续表面很难：事件只记录对数亮度的阈值变化，缺少绝对外观约束，渲染外观（颜色、不透明度、投影足迹）的调整能补偿深度误差而仍保持预测亮度变化，形成 appearance–depth 补偿。仅靠亮度变化一致性无法定出表面沿射线的位置。

## 方法详解
EAST 把受事件约束的 SDF 与高斯渲染耦合：时序立体沿标定事件射线给出带支持计数的三维候选，作为零水平集的软锚点（confidence 加权、要求射线对三角化支持）；同时从事件时间拟合仿射时间平面测得 edge-normal flow，在给定相机运动下约束射线–表面交点深度，其深度敏感性与可调的渲染梯度无关。耦合采用 reference-relative transport：在每个当前 Gaussian 中心同时评估 live 场与冻结的初始参考场，由二者描述子差产生有界位移——初始化时修正为零，但对 live 场保持可微，于是图像残差可经同一通道回传细化共享边界。

## 实验与结果
- PAEv3D 平均 CDsum = 0.051（Event-3DGS 0.127，EventNeRF 0.11）
- PAEv3D 参考视角 PSNR = 13.573 dB（Event-3DGS 13.007 dB）
- PAEv3D LPIPS = 0.306（Event-3DGS 0.321）
- NeRF Synthetic 平均 CDsum = 0.028（EventNeRF 0.026 最低，EAST 次低）
- NeRF Synthetic PSNR / SSIM = 17.551 dB / 0.881（Event-3DGS 17.383 / 0.843）
- Chair 表面提取耗时 = 1.94 s（EventNeuS 4.88 s，Event-3DGS 15.79 s）

## 创新点与贡献
- 给出事件监督下 appearance-gradient–depth 补偿的局部可辨识性分析（雅可比行列式为 γρα，说明法向流与亮度响应可分离外观梯度与逆深度），并提出「相对冻结参考场的有界中心传输」，使图像梯度能穿过耦合去细化受事件约束的 SDF，而不在初始化时移动基元

## 局限与风险
- 作者自述：依赖外部提供的标定与相机位姿
- 法向流只在投影平移沿测得边缘法向有非零分量时提供深度信息，纯旋转与切向运动须靠其他几何证据
- 耦合把每个 Gaussian 的 support 权重与传输半径在初始化时固定，无法随表面估计演化自适应
