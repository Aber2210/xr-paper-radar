# Vibe Coding XR：用 XR Blocks 与 Gemini 加速 AI+XR 原型开发

## 一句话结论
Vibe Coding XR 用自然语言 vibe coding+XR Blocks+Gemini 加速 AI+XR 原型：约束式生成输出单个 index.html、全部逻辑在 class extends xb.Script 内（init/update 托管循环、onSelectStart/onSelectEnd/onSelecting 交互），digest 给出防幻觉系统提示词（锁死依赖版本、y-up/z-forward、3D 空间 UI、troika-three-text、xb.ModelViewer、Gemini API key 挂 ai 模块）。

## 要解决的问题
XR 原型开发门槛高：XR 会话管理、渲染循环、3D UI、交互事件等样板代码繁多；通用 AI 代码生成在 XR 领域易幻觉 API、乱用新版本库。目标：让非专家用自然语言快速生成可运行的 XR 原型，压缩 AI+XR 想法的验证周期。

## 方法详解（含关键公式/架构，保留原文术语）
XR Blocks 约束式 WebXR 开发范式（digest 主体为系统提示词工程）：① 输出单文件 index.html，逻辑全部在 class MyScript extends xb.Script 内，init() 做初始化、update() 做主循环，不手写 requestAnimationFrame——XR Blocks 托管 XR 会话、窗口 resize 与渲染循环；② 交互用 onSelectStart/onSelectEnd/onSelecting；③ 坐标约定 y-up、z-forward，物体初始化于 z=-this.user.objectDistance；④ 空间 UI 用 XR Blocks 3D UI 而非 2D overlay div；⑤ 文本用 troika-three-text，3D 模型包进 xb.ModelViewer；⑥ 用 Gemini/AI 时以 const API_KEY="" 并把 key 挂到 ai 模块使 Gemini Canvas 自动填充；⑦ 依赖管理写死特定版本、只导入所需库（如不用手势就不导入 TensorFlow）；⑧ 生成代码前先规划 xb.Script 类结构、成员变量与 init/update 流程。digest 另提示完整 prompts 共享于 xrblocks.github.io/prompts。

## 创新点与贡献
① 面向 vibe coding 的 XR Blocks 约束式代码生成范式（单文件+类结构+托管循环）；② 防幻觉的依赖版本锁死与按需导入规则；③ XR 专属编码标准（3D 空间 UI、y-up/z-forward、XR Blocks 交互回调）；④ 与 Gemini 的原生集成路径（ai 模块+Gemini Canvas）。
