# HairDeck：单图生成可动画程式化头发卡片

## 一句话结论
HairDeck 把发型视为艺术家 primitive 的无序集合：每张 card 编为一个 token，set DiT 一次生成全部 192 个 card，另一 set DiT 生成 48 条弹簧骨链。CHARM 测试集上 Chamfer 距离降 44%（0.0066 vs 0.0117）、朝向误差降逾半（16.8° vs 40.0°）、快 33 倍（1.01 s vs 33.7 s）。

## 要解决的问题
游戏与 avatar 的程式化头发由艺术家摆放的 hair cards（菱形/三角形变截面缎带，几何即可见头发）构成，并以弹簧骨链每帧模拟驱动。现有方法均不产出该资产：strand 生成器输出写实发丝；image-to-3D 输出单一融合网格；唯一生成程式化 hair cards 的 CHARM 逐控制点自回归解码数百至数千 token，把无序集合当有序序列，慢且不准。需要从单图直接生成可动画、可导出的 hair card 资产。

## 方法详解
卡片沿用 CHARM 控制点折线（位置/宽度/厚度），新增截面类型（菱形 -1/三角 +1）与艺术家网格读取的根法向，用 Bishop 旋转最小化框架传播宽度方向并扫掠成面。Card VAE：transformer 编码器（控制点带弧长分数 + [CLS]）产 32D latent，解码器预测点数 n 并在等弧长处以傅里叶特征 + adaLN-Zero 求值；损失为世界单位平方误差 + 点数交叉熵 + KL。Card token 40 维，共 192 槽，空槽 e=-1。Set DiT（12 层 768 宽，181.3M）无位置编码、置换等变，flow matching 训练（根位置与存在标志权重 4），dropout 0.1 支持 CFG（γ=2、50 步 Euler）。单图条件：SAM 3 裁头发/面部方图，冻结 DINOv3 ViT-L/16 出条件 token；head frame 按面宽与面顶锚点归一化角色。训练 8 视图渲染 + 随机姿势与弹簧骨状态，风格增强 + Qwen-Image-Edit 重风格化（p=0.33）。Chain DiT（30.5M）以 card token 为条件生成 27D 链 token 共 48 槽；固定几何蒙皮 + UniVRM 弹簧骨模拟，导出 VRM 就绪格式。

## 实验与结果
点云输入（CHARM 100 测试发型）：CD 0.0066 / EMD 0.0084 / HD 0.0242 / IoU 0.867 / 朝向 16.8° / 1.01 s，全面优于 CHARM（0.0117/40.0°/33.7 s）与 MeshAnything V2/DeepMesh/BPT；同参数自回归对照 0.0078/16.6°/6.91 s，set 快 6.8×。单图（76 角色 + 40 野外图）：aligned CD 0.0089、IoU 0.725、失败率 3.5%/10%、1.33 s，优于 CHARM 图像模型（0.0186、34.2%/50.0%）、TRELLIS.2、Hunyuan3D-2.1、DiffLocks。弹簧骨（58 发型）：recall 0.625 vs 检索 0.289，运动相关 0.702 vs 0.538，拟合 0.953。消融：无根法向 16.8°→26.4°；无 head frame 对齐前 CD 0.0136→0.0189。

## 创新点与贡献
①“一 primitive 一 token、彼此无序”的资产生成规则：card token 保留截面类型与根法向，card VAE 按弧长解码变长控制点，平滑度媲美艺术家卡片；②无位置编码 set DiT + flow matching + 存在标志联合生成全部 card，数量在去噪中沉降，较自回归更准更快；③脸部锚定 head frame 与重风格数据提升单图跨画风鲁棒性；④第二个 set DiT 生成弹簧骨链 + 几何蒙皮 + VRM 模拟，输出 engine-ready 可动画资产；⑤配方可推广至其他艺术家 primitive 资产。

## 局限与风险
论文自述：训练自程式化 VRoid 发型，极短发与写实发的 alpha-textured cards 不在分布内；只生成几何与 UV，不生成纹理；部分 VRoid 角色用 hair cards 建模蝴蝶结/帽子，输入可见时会作为 card 生成；chain DiT 遵循 VRoid 常见链布局，对异常布局（如头顶辐射多链）生成链偏少；附录展示失败案例。

## 与文献库的关系
属库内程式化角色资产生成线（直接对标 CHARM，与 strand 系 DiffLocks/HairGPT、image-to-3D TRELLIS.2/Hunyuan3D 及 set diffusion 方法同域）：首次面向可动画资产结构，把发卡与弹簧骨作为两重无序集合生成（一 primitive 一 token + set DiT + flow matching + 脸部锚定 head frame），服务库内 VR/AR avatar 与游戏角色头发资产生成空白。

## 可复现性（代码/数据/硬件）
项目页 hyzcluster.github.io/HairDeck；论文未明确代码发布承诺。单张 A6000：card VAE 4 h、点云模型约 10 h、图像模型约 27 h。数据用公开 CHARM 数据集，依赖 DINOv3、SAM 3；采样 50 步 Euler。
