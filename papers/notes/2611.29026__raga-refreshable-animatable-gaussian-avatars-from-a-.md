# RAGA：单张照片生成可刷新的可驱动高斯化身

## 一句话结论
把「刷新」放在解码器输入端而非参数端：累积 canonical UV 观测的加权 running sum 再用单图训练的解码器重解码，刷新无需多图训练也不存图：163 个 clip 刷新后 +0.49 dB，≥135° 帧上 +0.68 dB，RTX 3080 Laptop 创建 1.08 s、48.1 ms/帧。

## 要解决的问题
单图化身在创建完成的那一刻就被固定：照片从未展示的区域（如衣物背面）由先验幻觉生成，此后无论看到多少该人的画面都不会改变。多图前馈方法能把多张图一起用，但要求创建时图像齐备，新图到达需整段重建；逐人优化方法在视频上优化化身需分钟到小时。头部的可增帧方法（FastAvatar/FFAvatar）与单目流的表演捕获（GenFusion）已有先例，但没有方法能让一个可被新动作驱动的全身化身随新观测持续刷新。此外，已报告的创建与动画时间通常假设体姿、相机与抠图已给定，掩盖了真实流水线成本。

## 方法详解
以 GUAVA 前馈架构为骨干（冻结 DINOv2 特征 + 可训练投影头 + vertex 与 UV 两条高斯分支 + StyleUNet 图像 refiner），改为原生 SMPL-X 全身/头部处理（替换 GUAVA 插入的 FLAME 头）、逐图透视投影与全身训练。每个新观测 $I_i$ 经逆纹理映射写入 canonical UV：$U_i(u)=v_i(u)[I_i\oplus A_i^{UV}](\pi_{C_i}(x_i(u)))\in\mathbb{R}^{35}$，即 RGB 加 32 维特征。融合权重为可见性乘视角余弦 $w_i(u)=v_i(u)|\mathbf{n}_i(u)^\top\mathbf{d}_i(u)|$，只累积加权和 $S_n=S_{n-1}+w_nU_n$、$W_n=W_{n-1}+w_n$（源图权重为 2），融合图为 $\widetilde{U}_n=S_n/\max(W_n,\epsilon)$，因此无需保留历史图像。刷新时仅用不变的 UV 解码器重新解码 UV 高斯：$G^{UV}_{k+1}=D_{UV}(\overline{U}_k,z_0^{UV},e_0,B^{UV})$，vertex 分支与所有网络权重保持固定，全程无梯度步。由于每帧贡献只依赖该帧本身，融合与帧序无关，批量融合等价于任意顺序的在线累积。驱动由 ViTPose++-Small 与 PEAR 式 transformer 回归器给出 articulation/expression/camera，会话形状 $\beta_0$ 锁定，在被跟踪点上做迭代拟合。训练损失 $\mathcal{L}=\mathcal{L}_{\mathrm{rec}}+\mathcal{L}_{\mathrm{reg}}+0.05\mathcal{L}_{\mathrm{id}}+0.5\mathcal{L}_{\mathrm{cloth}}+0.5\mathcal{L}_{\mathrm{edge}}+0.5\mathcal{L}_{\mathrm{sil}}$，且训练时始终只用单图构建化身，解码器从未见过融合图。

## 实验与结果
- 163 个 clip（五数据集）：单图 23.79 dB / 0.902 SSIM / 0.078 LPIPS，刷新后 24.28 dB / 0.908
- 刷新总体 +0.49 dB PSNR；在相对源图转过 ≥135° 的 1,576 帧上 +0.68 dB，UV 覆盖由 41% 升至 85%
- 同样给 16 张图：RAGA 23.79→24.27 dB（+0.48），LHM++ 20.97→21.12（+0.15），RAGA 领先 3.15 dB
- 三个留出数据集 33 个 clip：25.89 dB，vs LHM 24.53、LHM++ 24.09、IDOL 23.94（领先 1.36/1.80/1.94 dB）
- 创建 1.08 s（含检测 0.04 s、源拟合 0.81 s、预处理 0.03 s、网络 0.20 s），动画 48.1 ms/帧 = 20.8 FPS（RTX 3080 Laptop，含位姿估计与抠图）
- 融合帧比例消融：0/25/50/100% → UV 覆盖 40%/53%/59%/78%，PSNR +0.29/+0.41/+0.49 dB
- ≥135° 视角上 UBC-Fashion 比 GART 高 1.29 dB；留出集 GART 仍高 1.94 dB，500 步微调后 RAGA 反超 0.69 dB
- GUAVA 每帧 7,280 ms（其中 tracker 7,250 ms）vs RAGA 48.1 ms

## 创新点与贡献
- 把「刷新」放在解码器的输入端而不是参数端：累积的是 canonical UV 观测的加权 running sum，再用同一套只在单图上训练过的解码器重新解码
- 因此刷新不需要多图训练、不需要存图、与帧序无关，且学习到的补全先验会自动作用在合并后的证据上
- 相对 GenFusion 这类单目流方法，输出的是可被任意新动作驱动的持久化身，而非对当前帧的新视角重渲染

## 局限与风险
- 刷新会让照片已覆盖视角的 LPIPS 略升（0.078→0.079），作者诊断为轮廓处侧视 texel 经 matte 边界渗入背景色
- 用估计体参时质量远低于给定参数（19.89→20.26 对比 23.79），且该设定下未评测基线
- 逐人微调与刷新不叠加（−0.55 dB）
- 在线 worker 的帧/texel 门控启发式未在任何报告结果中验证
