# Physicl Scenes：面向感知与动作学习的艺术家手工 3D 数据集

## 一句话结论
在「艺术家手工 + 可仿真 + 部件标注」三者交集上把规模推高一个量级，并用同一套部件标注同时支撑材质/实例感知与 affordance-aware 抓取，把 affordance accuracy 作为独立指标引入移动操作基准：6,499 场景 / 115K 资产 / 567,506 实例，约为次大艺术家数据集的 5.7 倍。

## 要解决的问题
学习可泛化的感知与动作需要带细粒度真值的真实感 3D 场景，但真实扫描噪声大、遮挡缺失，无法提供 albedo、粗糙度、光照、未观测几何与部件级标注；合成数据虽天然具备真值，规模化却很难——程序化与 agentic 方法受规则与生成资产质量限制，艺术家建模更真实但规模与场景类型受限。同时具身学习还要求场景 simulation-ready（米制尺度、物理属性、真实布局），并要求部件级标注以指导「抓哪里」，而同时满足大规模、可仿真、带部件标注的艺术家场景几乎不存在。

## 方法详解
构建 6,499 个艺术家手工创建并审核的 3D 场景（6,299 室内 + 200 室外，室内含 4,999 个家庭房间与 1,300 个公共室内空间），总地面面积 3.32M m²，覆盖 1,600 个类别、567,506 个实例、115K 个资产与 56 万+ 次摆放，按 5,849/325/325 划分 train/val/test。所有资产由受训的专职 3D 艺术家依真实参照建模并遵循统一规范（几何、米制尺度、pivot、朝向、PBR 材质、命名），入库前经自动技术校验与人工视觉/尺寸/物理合理性复核；场景按真实世界逻辑而非程序规则编排，并经建筑与技术双重审核。每个场景再做 simulation-ready 处理：计算碰撞 hull、由逐部件材质推导质量与惯量、由艺术家 emitter 材质定义显式光照，因此同一场景可在不同光照下渲染。基于部件标注构建移动抓取放置任务：Franka Panda + 三自由度全向底座，反足抓取采样后经力闭合与碰撞检查并用仿真 rollout 验证稳定性；把向上表面按高度分组成放置面；把碰撞体栅格化为 2D 占据图并按机器人半径膨胀后规划最短路；在 MuJoCo 中闭环执行并只保留成功 episode，共产出 30,084 条专家示范、10M 帧、139.9 小时仿真。对 29% 抓取位置敏感的对象，用部件标注给每个抓取打上接触部件标签，从而定义 affordance accuracy。

## 实验与结果
- 6,499 场景 / 3.32M m² / 1,600 类 / 567,506 实例 / 115K 资产，规模约为次大艺术家数据集（3D-FRONT 578.5K m²）的 5.7 倍，且唯一同时具备 PBR、3D、部件标注与移动操作基准
- 跨数据集零样本泛化：真实照片（MAW）上 albedo 误差最高降低 47%，重建 Chamfer 距离最高降低 39%，3D 实例分割 AP 最高提升 5.9 点（论文口径）
- 内参分解：Marigold-IID 训练于 Physicl Scenes 后 MAW intensity 误差 0.322（InteriorVerse 0.538、SAGE-10k 0.754）；Infinigen 上 albedo si-PSNR 21.06（18.81）
- 重建：GenRecon 在 Replica 上 Chamfer 6.47 cm（3D-FRONT 7.99、SAGE-10k 7.36），ScanNet++ 上 8.85 cm（9.96/10.41），F@10cm 0.801/0.824
- 移动操作基准：最强 VLA π0.5 在 held-out 场景成功率仅 15.2%（Reach 69.1、Pick 20.6、Surface 18.3），affordance accuracy 75.6%
- real-to-sim 迁移（SimNet++ / ScanNet++）：π0.5 用 Physicl Scenes 训练 13.8% vs MolmoSpaces 5.6%；MolmoBot 12.8% vs 9.5%

## 创新点与贡献
- 在「艺术家手工、可仿真、带部件标注」三者交集上把规模推高一个量级（6.5K 场景、115K 资产），并用同一套部件标注同时支撑 perception（材质/实例）与 action（affordance-aware grasp）
- 把 affordance accuracy 作为独立指标引入移动操作基准，使「抓对了但抓错部位」这类失败第一次可被计量

## 局限与风险
- 艺术家创建与审核成本高，扩展性弱于程序化或 agentic 生成
- 场景静态且物体均为刚体，不含行人等动态与布料等可变形体
- 操作任务只覆盖 pick-and-place，不含开抽屉、清理桌面等更长程或抽象任务
- affordance 标签与任务无关，而真实指令下「该抓哪一部分」会随任务变化
