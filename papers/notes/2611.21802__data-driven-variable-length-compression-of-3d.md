# 数据驱动的三维表示变长压缩

## 一句话结论
在冻结自编码器 latent 上训练前缀可解 hyper-autoencoder，实现逐形状可变码率的三维压缩；结论全以 R-D 曲线呈现，无量化表。

## 要解决的问题
三维形状在不同应用中复杂度差异极大，但体素、网格等表示按全保真存储，开销与复杂度无关；传统编解码器（Draco、V-PCC、V-DMC 等）绑定特定表示，既不能开箱适配新表示，也无法利用训练集统计。per-shape 神经表示（SDF、位移场逐形状拟合）虽率-失真更好，却不能共享跨形状先验，且推理时需要昂贵的逐形状优化。数据集级学习的压缩器则把压缩率写成训练前固定的超参，所有形状同一比例，牺牲了变复杂度下的率-失真折中。

## 方法详解
方法假设已有冻结的预训练信号自编码器 E:S→Z 与解码器 D:Z→S（mesh 用 MeshGPT latent，SDF 用 3DShape2VecSet latent），只在其 latent 空间上加装一个轻量 hyper-autoencoder，不重训底座，因此只学到 latent 到有序 token 序列的映射。hyper-encoder 用 Perceiver 式 cross-attention：key/value 来自 latent token 序列 z_{1:Z}，query 来自训练后固定的可学习向量集 Q^(e)，输出 K 个 hyper-token；随后接因果 self-attention，使 token 顺序由 query 固有顺序与因果掩码共同决定，前期 token 被鼓励尽量承载全局粗结构。hyper-decoder 反向再做 Perceiver cross-attention，以另一组固定 query Q^(d) 从任意前缀 t_{1:k}（k≤K）重建长度恒为 Z 的 latent z̃^(k)，所以丢后缀不改变输出维度、只降低保真度。训练分两段自监督：先最小化 latent 空间 MSE，避免梯度穿过信号解码器、并在早期更稳定；再用信号空间损失（如 SDF 采样 MSE）微调，使 hyper-decoder 可直接被几何损失监督——这是 regression 解码器相对 flow 解码器的关键优势。推理时用前缀截断或 suffix dropout 得到任意码率，用户可按形状或 latent 空间的质量指标逐形状决定保留多少 token，更复杂的形状分配更多 token，全程仅前馈、无逐形状优化。

## 实验与结果
- 在 ShapeNet 上，mesh（MeshGPT latent）与 SDF（3DShape2VecSet latent）两种模态的 rate–distortion（Chamfer distance vs 压缩率）曲线均落在 Pareto 前沿，且不劣于其派生来源的定长自编码器
- 正文只给曲线，未报告具体 Chamfer distance 与压缩率数值
- 与 per-shape 方法和数据集级定长压缩两类基线对比，作者声称取得更好的率-失真折中（'state-of-the-art rate–distortion'），但正文未给出量化对比数字，全部结论以 Figure 2 曲线支撑
- 消融（仅 Figure 4 曲线，正文未报告具体 dB 或 Chamfer 数值）：regression hyper-decoder + 信号空间损失优于同结构仅用 latent 损失的解码器，也优于 FlexTok 式 flow 解码器
- 低 k 时 flow 解码器给出更锐利但错误的形状，高 k 时 regression 解码器更忠实
- token 数 k 与重建 Chamfer distance 呈反比（Figure 2 第 2、4 列）
- 达到同一 latent MSE 阈值所需 token 数随形状几何复杂度上升（Figure 3），即实现了按复杂度分配码率的定性目标，阈值具体数值正文未报告

## 创新点与贡献
- 把“变长 tokenization”从图像生成迁移到三维压缩，并把问题形式化为：在冻结自编码器的 latent 上训练一个前缀可解的 hyper-autoencoder，使压缩率成为推理期可逐形状选择的变量而非训练期超参
- 与 FlexTok 的实质差异是用 regression hyper-decoder 替代 flow 解码器，从而能在信号空间反传几何损失
- 作者指出 3D 领域缺少像图像那样感知对齐的强 latent，这一步是性能提升的主要来源
- 相对 per-shape 神经压缩与定长学习式压缩，它同时拿到跨形状先验与变码率两个性质，且换 backbone 不改底座

## 局限与风险
- 所有结论都在未量化（unquantized）设定下成立，作者在正文中标注量化版 MeshGPT 的曲线会整体右移，因此该方法与真实部署码率不可直接比较
- 评测只在 ShapeNet 单一数据集、两种表示（mesh 与 SDF）上完成，未覆盖点云、NeRF/3DGS 等表示，也没有真实传输或存储系统实验
- 结果全部以图呈现，缺少数值表格，第三方难以复算改进幅度
- 此外每换一个 backbone 都需重训 hyper-autoencoder，跨模态的额外训练成本未被量化
