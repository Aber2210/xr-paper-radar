# Instant NuRec：面向驾驶场景仿真的前馈三维高斯重建

## 一句话结论
Instant NuRec 单次前向把 10–20 s 多相机驾驶日志重建为分层 3DGS 世界，约 1.5 s 完成，而逐场景优化的 NuRec 约需 75 min（超过 3 个数量级加速）；Waymo 验证集全图 PSNR 28.26、SSIM 0.859，比最强基线 DGGT 的 26.25 高 2.01 dB，动态区 24.93 对 21.76；140 个场景闭环 rollout 中五种策略排序与 NuRec 完全一致。

## 要解决的问题
闭环仿真是自动驾驶开发与验证的核心工具，要求同时成立三件事：照片级渲染、场景显式分解为静态背景与动态体、能自由重摆自车位姿并重定时序以评估反事实。3DGS 让渲染变便宜，OmniRe 一类逐场景优化已能忠实复现真实日志，但每段 clip 要数十分钟到数小时优化、需精调超参，还依赖 LiDAR、语义掩码、cuboid 轨迹等辅助输入，无法承载车队每天百万级 clip。驾驶世界模型（latent diffusion、video-GPT）能生成逼真视频，但只输出 2D 像素，planner 不能重摆位，也不给出可仿真状态。前馈重建（STORM、DrivingForward、DepthSplat、DGGT）解决速度，但输出是裸 RGB 高斯，不含静态/动态分层、语义与 ISP 校正，不能直接喂给仿真器。缺口即：能否一次前向产出与逐场景优化同格式、可被 NuRec/AlpaSim 消费的分层世界。

## 方法详解
输入 V×T 张 RGB（2–4 Hz）加每张 6-DoF 位姿 T_{v,t}∈SE(3)、内参 κ_{v,t}。输出四件：静态层 G^s（高斯属性加世界法向 n 与 road/non-road 语义）；动态层 G^d（位置改为 3 节点分段线性轨迹，不透明度按 exp(−x^10) 淡入淡出）；天空 cubemap I^sky；每相机 ISP 仿射 {A_v}。编码器用 Depth-Anything-3 的交替注意力 ViT，输出 latent F。解码挂轻量头：DPT 头出深度、法向、语义；3DGS 头从深度抬升 query 点 Q，与 F 交叉注意力后回归高斯参数；运动头复用 Q，以 AdaLN 按 t_tgt 条件化回归两个 3D 位移。query 分 Dense 与 Selective（步长 s、p×p 聚 token）：s=2、p=8 时单视图约 88 K 高斯，比 Dense 的 351 K 少 4×。长 clip 用重叠 chunk：按 α<1e−2 剪枝并转世界系后做视锥归属剪枝——高斯 g 在 chunk i 到最近光心距离 D_gi，仅当 D_gi ≤ min_j D_gj + δ（式1）保留。损失 L=L_context+L_motion+L_render（式2）：context 监督深度、法向、语义；motion 为前后向 3D flow；render 在留出视角算 L1+LPIPS。三阶段课程：Stage 1 复现 DA3 预训练；Stage 2 开天空、深度、运动头微调编码器；Stage 3 冻结编码器只训 ISP 与 GS 头。

## 实验与结果
- Waymo Open Dataset 验证集，沿用 STORM 协议：每样本 2 s 窗口、20 帧 @10 Hz，输入 4 帧 context（间隔 0.5 s），指标在 240×160 上计算；基线 DepthSplat、STORM、Depth-Anything-3、DGGT 均用发布 checkpoint 不再微调（DGGT 不取位姿，先做轨迹对齐）。
- 表 1 全图：Ours 28.26/0.859，DGGT 26.25/0.805，DepthSplat 22.48/0.645，STORM 21.88/0.752，DA3 20.30/0.557；深度 AbsRel 0.076、δ₁ 0.937（STORM 0.123/0.870，DGGT 0.135/0.841）。
- 表 1 动态区：Ours 24.93/0.793，DGGT 21.76/0.652，STORM 19.89/0.556，DepthSplat 18.59/0.391；动态区 AbsRel 0.085、δ₁ 0.922。
- 内部数据（约 40K clips，最多 5 相机、300–600 帧 @30 Hz）：Selective 把高斯预算从约 351 K/视图降到约 120 K（18 帧场景 6.3 M 降到 2.2 M，约 3×），图像与深度仅轻微下降；Dense 与 Selective 均约 1.5 s 重建，对比 NuRec 约 75 min。
- 闭环仿真：140 个场景、每场景 20 s、每 500 ms 重规划、6 次独立试验，5 种策略（VaVAM、Alpamayo R1、Alpamayo 1.5 的 1/2/4 相机版），指标取 Collision（前、侧、后）与 Offroad 的平均；Instant NuRec 下的策略排序与 NuRec 完全一致。
- 消融（表 2，内部验证集）：完整模型 29.93/0.793/0.069/0.950；单阶段训练 27.65/0.751/0.077/0.955；天空改用 MLP 26.73/0.692；去 LPIPS 26.81/0.705；去深度损失 28.92/0.782 但 AbsRel 0.103、δ₁ 0.862；去视锥归属合并 26.10/0.648/0.098/0.891。
- 训练：PyTorch 加 3DGUT 可微渲染，DDP 跨节点、每卡有效 batch 1–2 clip，V∈{1,3,5}、T∈{8,12,18}，余弦退火加线性 warmup 至 1e−4，三阶段共约 6 天、8 节点。

## 创新点与贡献
- 单次前向直接产出仿真可用的分层世界（静态、动态、天空、ISP），而不只是裸 RGB 高斯，格式与 NuRec、AlpaSim 对齐。
- 把高斯与像素解耦，用深度抬升的 query 点加 Selective 聚类把高斯预算降约 4×，质量基本保持。
- 运动头直接回归分段线性轨迹，重建时无需逐 actor 的 cuboid 轨迹输入。
- 视锥归属的 chunk 合并策略按「谁看得最近」决定高斯归属，显著抑制长序列的 floater。
- 几何监督与渲染监督解耦的三阶段课程，使 40K clip 规模训练稳定可行，并用闭环策略排序验证仿真可用性。

## 局限与风险
- （作者承认）高斯数量与质量存在固有张力：追平逐场景优化需要很多基元，预算小则细结构欠采样；测试时训练微调是可能的补法。
- （作者承认）泛化受训练语料限制，低安装位或纯鱼眼等与训练差异大的 rig 需微调。
- （作者承认）三段关键帧的分段线性轨迹无法表达亚秒级非刚性运动（如行人关节运动），需更密关键帧。
- （我在正文发现）训练依赖 NVIDIA 内部约 40K clips 与内部 cuboid 自动标注器，外部无法复现训练；Waymo 评测仅 240×160、4 帧 context，分辨率与视角数偏低。
- （我在正文发现）「策略排序完全一致」只说明相对排序，正文未给碰撞率与越界率的绝对数值及置信区间，无法判断差距是否在噪声内。
- （我在正文发现）1.5 s 重建的硬件型号与批设置未在实验节标明（只说训练用 8 节点），跨平台速度不可直接比较。

## 与文献库的关系
论文站在三条线交汇处。逐场景神经重建：NeRF 与 3DGS 的城市级扩展、Neural Scene Graphs 的「静态背景加刚性前景」分解、显式高斯化的 Street Gaussians 系列，以及 OmniRe（分解扩展到非刚性行人与骑行者）；渲染器侧是 3DGRT 与 3DGUT（原生支持畸变相机与 secondary rays），本文用 3DGUT。前馈重建：单物体 LRM 系列到场景级可泛化高斯，以及面向动态驾驶的 STORM 与 DrivingForward；还有把高斯与像素解耦的 TokenGS。生成式世界模型：latent diffusion 街景生成、长时程自回归与 video-GPT、跨具身世界基础模型，以及「重建器加生成器」联合方案。本文定位在重建侧，作为生成式修复与联合模型的快速 3D 主干；工业侧继承 NuRec 与 AlpaSim 的输出格式与仿真栈。

## 可复现性（代码/数据/硬件）
