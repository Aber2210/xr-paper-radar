# PointForward：点对齐表示的前馈驾驶场景重建

## 一句话结论
在 Waymo 上 PointForward 取得全图 PSNR 28.48 / SSIM 0.861、动态区域 PSNR 25.01，比 DGGT 分别高 1.1 dB 与 2.2 dB；零样本迁移到 nuScenes 得 26.54 PSNR（+1.2 dB），微调后 27.50。

## 要解决的问题
驾驶场景的高保真重建对自动驾驶至关重要。逐场景优化的 NeRF/3DGS 需数小时，前馈 3DGS 把重建压到亚秒级，但存在两个结构性缺陷。其一是逐像素高斯预测：每个视图独立从像素解码高斯，同一物理点在不同视图会被预测到略有差异的三维位置，产生冗余高斯基元与多视图不一致，在细结构处表现为分层（layering）与鬼影。其二是动态建模靠稠密光流：用二维动态掩码标注动态性再逐高斯回归三维运动流，而二维掩码无法刻画三维实例的真实范围，像素级独立运动预测也缺乏实例级的连贯表示，导致碎片化运动。两者共同指向一个需求：把「在哪里、属于哪个实例」的决策从像素空间提升到世界空间的三维查询上。

## 方法详解
以世界空间稀疏三维查询替代逐像素高斯。输入 V 张图像、可选稀疏 LiDAR 深度、内外参；用预训练 EfficientNetV2 提特征、冻结的 InfiniDepth 出稠密深度。先构造稠密查询集 Q0：每个查询是 12 维向量（三维坐标 + RGB + 6 维 Plücker 坐标），坐标由像素深度与相机参数反投影得到，即把像素「提升」到三维。随后用场景图做动态分解：对每个动态实例 i 有按时间排序的三维框序列 B_i，以最早帧的框 b_i,1 建立规范空间；点 p 落在框内的判据是 |(p−c)(R^B)ᵀ| ⪯ m/2（式 1），落入任一框的查询标记为动态并变换到规范坐标 p̃ = (p−c_ij)(R_ij^B)ᵀ R_i1^B + c_i1（式 2），静态查询留在世界系。为控算力，每视图采样 N_s 个静态查询、每实例采样 N_d 个动态查询，总数 N = V·N_s + O·N_d。时空融合阶段：把查询投影到所有输入视图采样特征 f_i，并计算查询深度与该像素深度的绝对差 d_i 作为几何一致性权重；先做 f_{s,i} = φ([φ(f_i); φ(d_i)])（式 3），再引入时间线索 f_{t,i} = [f_q ⊙ f_{s,i}; t==t_i; t]（式 4）——动态查询先由规范空间变回目标时刻世界系再投影，若静态查询落入某视图的动态掩码区则特征置零；用 softmax(φ(f_{t,i})) 得跨视图融合权重，同时由逐视图标量池化再聚合得到 lifespan 参数 σ（式 5），融合特征 f = Σ ω_i f_{t,i}，最终 q′ = φ([φ(q); φ(f); φ(t); φ(σ)])（式 6）。渲染时把 q′ 解码为高斯 (c, μ, r, s, o)，颜色用 128 维特征而非直接 RGB（沿用 UniSim/SplatAD），渲染出特征图后经轻量 UNet 转三通道；跨时刻不透明度按 o_t′ = o·exp(−½((t′−t)/(σ+1))²)（式 7）衰减，从而支持任意时刻渲染。损失为 L1 + λ·LPIPS。

## 局限与风险
['动态建模仅限三维框描述的刚性实例，行人等高度非刚性运动效果差，作者在 Limitation 中明确承认。', '主实验依赖 GT 三维框轨迹（虽给出预测轨迹下仅掉 0.30/0.25 dB 的鲁棒性验证），实际部署仍需检测+跟踪链路。', '训练成本高：8×H20、45K 迭代、全局 batch 8；查询预算 N_s=100K、N_d=10K，显存与算力门槛不低。', '外推视角 FID 虽大幅领先，但绝对数值仍高（6 m 位移 65.99），远视角几何仍会退化；评测限于 Waymo/nuScenes 前视三相机设定。']

## 与文献库的关系
直接对标逐像素前馈路线：pixelSplat/MVSplat 的双视图编码与代价体、DepthSplat 的深度联合建模、DrivingForward 的逐图预测后聚合、STORM 的像素对齐高斯 + 运动场、DGGT 的无位姿联合预测 + lifespan。作者指出 SparseSplat（熵采样）与 C3G（可学习 query token）已尝试非像素对齐，但只在小规模室内验证；PointForward 把这思路做到大规模室外动态场景。动态建模一侧继承 OmniRe/Street Gaussians/DrivingGaussian 的场景图与规范空间思想，只是从逐场景优化搬到前馈一次推理。

## 可复现性（代码/数据/硬件）
项目页 https://wm-research.github.io/PointForward （正文给出），未见代码仓库承诺；数据为公开 Waymo Open Dataset 与 nuScenes；训练细节（8×H20、45K iter、lr 5e-4、AdamW、图像 576×768、多分辨率 350×518/576×768/700×1036、N_c=128、λ=0.2）齐全，可依此复现。

## 行动建议
值得精读。核心在 §3.1 的查询构造（12 维含 Plücker 坐标）与 §3.3 的融合权重设计（把深度差 d_i 作为几何可信度、用 t==t_i 指示符区分同时刻视图），以及式 7 的 lifespan 不透明度衰减；§4.4 的「去 LiDAR 仍 SOTA」与「预测框轨迹仅掉 0.3 dB」两条消融最能说明方法的实用性。若做驾驶仿真/闭环测评数据生成，这是当前前馈类首选基线；注意其非刚性动态是明确短板。
