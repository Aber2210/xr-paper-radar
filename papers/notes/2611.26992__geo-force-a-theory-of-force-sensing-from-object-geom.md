# Geo-Force：从物体几何进行力感知的理论

## 一句话结论
首个把「从几何预测触觉力」形式化为渲染到触觉到力的三映射复合，给出等变/归零/误差界与刚度不可辨识极限：正文无实验（作者明确声明为理论工作），价值在设计约束而非数值。

## 要解决的问题
机器人操作易损物体需要接触力，但触觉传感器脆弱且难以集成；深度相机（RGB-D）便宜普及，用「虚拟触觉」从几何预测力看似可行，却没人说清它究竟计算了什么、输出何时可信、什么时候必然失效。

## 方法详解
把 Geometric Force 定义为三个共享像素网格的映射的复合：把待触表面从虚拟传感器视角渲染成深度块（Φ_render，隐藏面可用形状补全 + 6D 跟踪实现）、用学习或仿真的 touch map 由深度块预测触觉信号（Φ_touch）、再由预训练解码器（如 SPARSH）从信号估计每个 taxel 的力（Φ_force）。证明三条结构性质：坐标系改变时力矢量只旋转（等变）；脱离接触时力严格为零（接触门控 touch map）；Lipschitz 映射下力误差至多随三映射误差线性增长，而渲染误差又由点采样填充距离、采样精度与传感器位姿误差线性界定。最后证明刚度极限：同形状不同刚度的物体几何相同，任何 touch map 都无法区分，剩余误差是偶然误差（aleatoric）；在弹性地基模型下所有物体相关信息都集中在 touch map 里。

## 实验与结果
- 理论结构 = 3 个映射复合（Φ_render → Φ_touch → Φ_force，共享像素网格）
- 被证明的性质 = 3 条（坐标系等变、无接触则力为零、误差线性有界）
- 枚举的失效情形 = 6 类（浅接触、隐藏面、边缘与陡面、刚度差异、学习映射不可靠、模型外效应）
- 实验验证 = 正文未给出（作者明确声明本文为理论工作，实验留待未来工作）

## 创新点与贡献
- 首个把「从几何预测触觉力」形式化为三映射复合，并给出等变/归零/稳定性界限、渲染误差界定与刚度不可辨识极限的统一理论，同时导出对深度相机与物体的选型要求

## 局限与风险
- 分析是准静态的，忽略动力学、软物体粘弹性、摩擦与剪切
- 界在轮廓/剪影处不成立
- 全部结论未经实验验证
