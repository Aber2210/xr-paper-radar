# Facet-SLAM：实时三角泼溅 SLAM

## 一句话结论
首个实时三角泼溅 SLAM：tracker 只定位质心、mapper 在非平移子空间优化，RGB-D 下 113 FPS（Jetson 36 FPS），Delaunay chamfer 1.55→0.86 cm。

## 要解决的问题
基于 3D 高斯泼溅的稠密 SLAM 能建出照片级逼真的地图，但表面几何很差：要拿到可用网格还得后处理提取、引入中间表示，或改用 2DGS 一类表面对齐基元再做体积融合。三角泼溅（differentiable triangle soup）的基元本身就是面元，直接对其现有顶点做三角化就能得到连通网格，无需中间表示或单独融合阶段，因此天然适合既要渲染又要几何的具身智能应用。TS-SLAM 是首个用三角基元的稠密 SLAM，验证了上述几何优势并给出照片级地图，但它沿用了早期 3DGS SLAM 的光度跟踪，精度虽好却只有每秒几帧，既限制部署灵活性，也无法在设备上一边建图一边定位。改用快速几何配准看似是自然替代，但单靠它并不够：mapper 的优化会通过渲染损失间接监督顶点，噪声与偏置会把三角形推离实际观测表面，即使在平坦区域也如此，于是三角形不再是可靠的配准目标。作者进一步发现，直接用三角形自身法向做点到面配准在真实深度上并不可靠，因为三角形的朝向是为最小化复合的 mapper 代价而设的，并非几何真值；同时，如果把每个三角形当作独立平面，其顶点只被渲染损失间接监督，用它构造目标协方差同样不可信。

## 方法详解
系统双进程并行：mapper 在 GPU 上渲染并优化三角地图，把三角形质心发布给 tracker；tracker 在 CPU 上把每帧深度配准到这些质心，再把关键帧与位姿回传。每个三角形 j 有顶点 v_j1, v_j2, v_j3、颜色 c 与不透明度 o。跟踪：用 GICP 把观测点 a_i 配到地图点 b_i，各自视为 N(a_i*, A_i) 与 N(b_i*, B_i) 的采样、b_i* = T a_i*，解 T* = argmin Σ_i d_i^T (B_i + R A_i R^T)^{-1} d_i，d_i = b_i - T a_i，得 SE(3) 上的极大似然估计。关键设计是目标协方差不用三角形自身几何，而用其质心 K 近邻的散布加各向同性噪声底：B_i = (1/K) Σ_{l∈K_i} (μ_l - μ̄_i)(μ_l - μ̄_i)^T + σ_f² I；观测协方差 A_i 同样由深度点局部散布得到。由于三角形质心与跟踪关键帧关联且不被 mapper 平移，系统另对最近 N 个关键帧做仅位姿的窗口优化，用重叠关键帧之间的几何与光度残差，并把关联三角形随修正刚性移动，这在长序列上带来 ATE 的小幅改善。建图：三角泼溅按原论文光栅化，φ_j(p) 是像素 p 到投影边的有符号距离、s_j 为内心，窗口 w_j(p) = max(0, φ_j(p)/φ_j(s_j))^σ 从内心处的 1 衰减到边上的 0，σ 控制锐度；像素颜色按深度序 alpha 合成 Î(p) = Σ_j c_j(p) o_j w_j(p) Π_{i<j}(1 - o_i w_i(p))，c_j 为顶点颜色的重心插值、o_j 为平均顶点不透明度。地图用复合损失优化：E_photo = E_rgb + λ_d E_dep + λ_n E_norm + λ_e E_reg，其中表面位置只被各项间接监督，这正是光度梯度噪声把三角形推离观测面的根源。作者用「职责分离」解决：tracker 把每个三角形的质心设为关联关键帧深度观测的滑动均值，mapper 只优化外观、形状与朝向。mapper 侧通过线性变量替换强制质心固定：对每个坐标轴，令 x ∈ R³ 堆叠三个顶点的该坐标、μ 为对应质心坐标，定义 x = μ1 + Qe，e ∈ R²，Q ∈ R^{3×2} 的列是垂直于 1 的正交基（实现取 (1,-1,0)^T/√2 与 (1,1,-2)^T/√6）。Adam 优化 e，梯度 ∇_e E = Q^T ∇_x E，正是去掉平移分量的顶点梯度，而损失本身与 E_photo 完全相同。这样三角形只能改变大小与朝向，质心始终钉在深度观测上，从而成为可靠的 GICP 目标。

## 实验与结果
- TUM RGB-D 三个标准场景 ATE 1.76 cm（SplaTAM 3.3、GS-SLAM 3.7、MonoGS 1.61、GS-ICP 3.16、Photo-SLAM 1.21、TS-SLAM 1.57），桌面 RTX 4090 上 113 FPS，Jetson AGX Orin（MAXN）上 36 FPS
- 相对光度跟踪的 TS-SLAM（1.5 FPS）提速超过 20 倍，同时渲染质量相当
- 在 Jetson 上也是唯一能与 Photo-SLAM（23 FPS）比速度且几何更好的三角泼溅方案（TS-SLAM 在 Jetson 上不可运行）
- TUM 几何：深度 L1 在 desk / xyz / office 为 3.14 / 6.37 / 6.95 cm（TS-SLAM 4.66 / 9.96 / 10.60，MonoGS 6.67 / 15.26 / 14.78）
- chamfer 2.62 / 6.42 / 1.65 cm（TS-SLAM 3.45 / 5.32 / 2.60）
- office 上 2 cm 内完整度 70.3% vs 61.4%
- Replica：TSDF chamfer 0.67 cm vs TS-SLAM 0.95、GS-ICP 1.94
- Delaunay 网格 chamfer 从 TS-SLAM 的 1.55 降到 0.86 cm（降约 44.5%），F-score@1 cm 73.6% vs 54.1%，@2 cm 98.2% vs 93.0%
- ATE 平均 0.17 cm（TS-SLAM 0.42、GS-ICP 0.18）
- 渲染（TUM 平均）：PSNR 19.98 dB / SSIM 0.727，与 TS-SLAM 的 19.36 / 0.724 相当，但低于 3DGS 类 MonoGS 的 23.67 / 0.787，作者归因于 0 阶球谐与更保守的致密化等效率取舍
- 消融：配准度量上点到点 ATE 4.50 cm、点到面（用三角形自身法向）8.49 cm，GICP 1.76 cm
- mapper 上「自由优化」ATE 5.11 cm、「自由优化后重心回中」1.87 cm、子空间约束 1.76 cm，且子空间方案在 Replica 上表面朝向一致性还略好 0.5–1°

## 创新点与贡献
- 新意是把三角泼溅做到实时 SLAM，并给出一个干净的「职责分离」：tracker 用融合深度决定每个三角形的质心、mapper 只在非平移子空间里优化形状与朝向，于是同一批基元既当可靠的多尺度 GICP 目标、又当可微的渲染载体，两者不再互相破坏
- 两个技术判断值得注意
- 第一，目标协方差不取三角形自身几何而取邻域质心散布，这正面回应了「顶点只被渲染损失间接监督、其朝向不可信」的问题
- 消融里点到面配准在 TUM 上 ATE 反而恶化到 8.49 cm，佐证了这一点
- 第二，非平移约束用变量替换 x = μ1 + Qe 实现，梯度 Q^T∇_x E 天然剔除平移分量，比「先自由优化再把重心搬回质心」更正确——后者会让 Adam 的一阶/二阶矩继续累积那些被丢弃的平移梯度，实测也略差（1.87 vs 1.76 cm）
- 相比 GS-ICP SLAM 复用高斯协方差、或用高斯均值做配准目标，三角基元带显式面与法向、又能直接三角化成连通网格，在「实时 + 几何可用」这个组合上是新的

## 局限与风险
- 作者自述最主要的局限是建图质量低于 3DGS 类方法，部分源于为计算效率做的取舍（使用 0 阶球谐、更保守的致密化），部分源于三角泼溅用于 SLAM 仍相对新、不如已被长期优化的 3DGS 成熟
- 后续可研究在保持基元空间鲁棒性的同时提升建图质量的优化技巧
- 从实验设计还能看出：跟踪精度并未超过 TS-SLAM（1.76 vs 1.57 cm），也未超过 Photo-SLAM（1.21 cm）与 MonoGS（1.61 cm），其卖点是速度与几何而非绝对位姿精度
- ScanNet 上平均 ATE 19.5 cm 虽优于 TS-SLAM 21.8 与 GS-ICP 22.1，但该类场景整体误差都在十几到几十厘米量级，说明大尺度、纹理弱、运动快的场景仍是弱项
- 渲染 PSNR 19.98 dB 明显低于 MonoGS 的 23.67 dB，若下游需要高质量新视角合成则不适用
- 验证范围限于室内静态 RGB-D 场景（TUM、Replica、ScanNet），需已知内参与深度
- 真机实验（办公室隔间、手持 D435 在 Jetson 上在线建图）只给定性结果，没有定量精度与重复性
- 代码为「将发布」，正文未给出可核验的实验配置细节（如关键帧策略、K 的取值、各 λ 的具体数值）
