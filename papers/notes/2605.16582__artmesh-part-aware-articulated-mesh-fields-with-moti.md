# ArtMesh：带运动一致动力学的部件感知铰接网格场

## 一句话结论
用部件感知三角网格场 + 运动一致动力学，从两个关节状态重建铰接物体并直接给出带部件边界的网格——Articulate-100（给 GT 掩码）轴角 3.49°、CD-m 15.01 mm（最强基线 57.45 / 58.66，改善 +42.44 mm），6+ 部件档轴角 6.90°（GaussianArt 33.05°）。

## 要解决的问题
从图像重建铰接物体要同时给出部件级几何、各活动件的关节运动，以及下游可直接消费的显式表面资产。隐式路线（PARIS 等）渲染好，但优化的是体场，网格只能事后等值面提取，关节处边界与拓扑被抹平。3DGS 路线（ArtGS、GaussianArt、ReArtGS++）继承无结构点式几何，没有三角形连通性也没有显式部件边界，只能靠 TSDF 融合补网格，关节处一个跨越抽屉缝的错误连接会同时毁掉几何与运动估计；其监督也弱：图像损失只间接约束关节轴，2D 特征匹配、canonical 高斯匹配在弱纹理家具上不可靠。评测侧同样缺位：多数铰接基准只有两个部件（如 PARIS），部件数一多，拓扑、部件分离与运动一致性才真正吃紧的区间没人测。

## 方法详解
ArtMesh 用两个关节状态 $t_1,t_2$ 的多视角 RGB-D 重建一对部件感知三角网格加每部件刚体运动。网格场 $\mathcal{M}(t)=(V(t),F(t))$ 的每个顶点存位置 $x_i$、SH 颜色 $c_i$、不透明度 $\sigma_i$ 与 $K+1$ 类部件 logits $s_i$（1 个静态基座 + $K$ 个活动件），$w_i=\mathrm{softmax}(s_i)$ 在重建后期硬化为 $p_i=\arg\max_k w_{i,k}$，据此把顶点分成 $V_k(t)$。关键一步是 part-aware restricted Delaunay remeshing：先丢弃顶点跨部件的面 $F_k(t)=\{f=(i,j,l):p_i=p_j=p_l=k\}$，再在每个部件内部独立跑 rDel，$F^\star_k(t)=\mathrm{rDel}(V_k(t),F_k(t))$，最终拓扑取并集，于是每个活动件是一块连通子网格、没有任何跨部件三角形，刚体变换不会剪切拓扑。关节场给每个部件前向刚体 $(R^+_k,P^+_k,T^+_k)$，$g^+_k(x)=R^+_k(x-P^+_k)+P^+_k+T^+_k$；反向运动不做独立学习，取解析逆 $g^-_k(y)=(R^+_k)^\top(y-b^+_k)$，保证双向自洽（revolute 时 $T^+=0$，prismatic 时 $R^+=I$）。监督是双向运动一致性：vertex-wise 项把顶点按所属部件搬运到另一状态，只在同部件子网格 $F^\star_{p_i}(t_2)$ 内找最近三角形，用重心坐标插值目标位置/颜色/不透明度并回归（含有效性掩码 $\eta_i$）；pixel-wise 项把搬运后的网格从目标状态相机渲染，与真实图像做 $\mathcal{L}_1$+SSIM。总目标 $\mathcal{L}_{motion}=\lambda_{VMC}(\mathcal{L}^{1\to2}_{vtx}+\mathcal{L}^{2\to1}_{vtx})+\lambda_{PMC}(\mathcal{L}^{1\to2}_{pix}+\mathcal{L}^{2\to1}_{pix})$。训练分两阶段：先优化顶点位置/辐射/不透明度/部件 logits，硬化后做 per-part rDel，再短训一轮固定拓扑精修；关节阶段冻结几何，只优化刚体参数，用 RGB 与 vertex-wise 一致性监督。部件掩码缺失时用作者微调的 PArtSAM（基于 PartSAM，加入跨状态位移与可动性两通道，零初始化首层）预测。

## 实验与结果
- Articulate-100（给 GT 部件掩码）：Axis Ang 3.49°、Axis Pos 0.03（0.1 m）、Part Motion 3.64、CD-s 18.98 mm、CD-m 15.01 mm，五项聚合全部最优
- CD-m 相对最强基线改善 +42.44 mm（15.01 vs 57.45/58.66 mm），2/3/4-5/6+ 部件分桶增益分别 +19.27/+29.57/+35.23/+27.69 mm
- 多部件退化：6+ 部件桶 Axis Ang 6.90°，对比 GaussianArt 33.05°、ArtGS 14.37°、ReArtGS++ 22.02°
- 无 GT 掩码（Ours-PArtSAM）：Axis Ang 12.26°、CD-m 60.69 mm，2 部件仍与 GT 掩码档持平
- PARIS 合成集：Axis Ang 0.68°、Axis Pos 0.02、Part Motion 0.54、CD-s 19.59 mm、CD-m 12.44 mm；真实集 2.37° / 0.07 / 0.66 / 27.25 / 50.84
- 消融（Articulate-100）：去反向传播最伤，Axis Ang 3.49→10.79°、CD-m 15.01→29.06 mm；去顶点颜色一致性 6.02°、去顶点不透明度一致性 6.87°、用全局 Delaunay 7.10°
- 网格质量：自穿透深度 SPD 0.0224（占包围盒对角线比例），Gaussian 类基线无直接网格（N/A，需 TSDF 提取）

## 创新点与贡献
- 相对 ArtGS/GaussianArt 这类在无结构高斯上做铰接的工作，ArtMesh 把几何、拓扑与关节绑成互相约束的一体：per-part rDel 让每个活动件成为真正连通、无跨部件面的刚体网格，训练用的表面就是导出用的表面，不需要事后 TSDF
- 相对 PARIS 这类隐式路线，关节直接在三角网格顶点与渲染像素两个层面被监督，反向运动取解析逆而非另学一张网络
- 相对最接近的 StructureGS（加部件有向包围盒与接触约束），它给出的是可导出的连通拓扑而非结构化先验
- 附带贡献是 Articulate-100：100 个物体、16 类、部件数从 2 到 6+，把「多部件才吃紧」的区间显式测出来

## 局限与风险
- 输入被限定为两个离散关节状态，连续关节角度、多状态序列与运动轨迹都未覆盖，prismatic/revolute 之外的关节类型（如螺旋、球窝复合）未处理
- 部件数 $K$ 需预先给定，主要数字依赖 GT 部件掩码
- 用 PArtSAM 时 3–5 部件桶的 Axis Ang 反超 ArtGS（19.79° vs 15.42°），说明分割噪声会直接污染运动估计
- Articulate-100 由 PartNet-Mobility 物体渲染而来，真实采集只有 SplArt 的 9 段与 PARIS 的 2 个真实物体，泛化证据偏薄
- 每个物体都要跑两阶段优化，不是前馈推理
