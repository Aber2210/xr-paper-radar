# WorldExpand：用稀疏联合全景扩展构建连贯三维世界

## 一句话结论
从单张全景扩出四个方向的新观察中心：覆盖度引导选视点（未见区像素数打分 + 90° 象限方位分配）+ 四视点联合去噪——UE 基准 PSNR 20.16（Matrix-3D 17.30）、AUC@3° 49.79（29.38）、F@5cm 29.02（20.32），零样本 RealSee3D 18.06 / 41.44，最高 8.6× 加速。

## 要解决的问题
单张全景图只能覆盖一个观察中心，遮挡物背后、拐角之后与门外完全没有观测；要扩展就得移动观察中心并在新位置合成全景。现有全景视频路线（GenEx、Matrix-3D）用稠密序列生成来扩大覆盖，但相邻帧高度冗余、长轨迹误差累积、多方向独立 rollout 在重叠区互相矛盾。在自建 UE 合成基准上，Matrix-3D 的 PSNR 只有 17.30、相机位姿 AUC@3° 仅 29.38、点云 F-score@5cm 20.32，说明「把视频生成输出直接当中转表示」与三维重建目标不匹配。作者因此换表示：不用稠密帧，而是生成少量稀疏、互补、高分辨率的新视点全景。

## 方法详解
三步流水线。① Coverage-Guided View Selection：把源全景 $I_0$ 与深度 $D_0$ 反投影为点云 $\mathcal{P}_0$，在相机高度的水平网格切片上提取场景边界，在同心环上采样候选相机并剔除碰撞/越界者；用 Gaussian splatting 把 $\mathcal{P}_0$ 投到候选视点 $v$，收到点的像素为已见区 $\mathcal{S}_v$、未收到点的为未见区 $\mathcal{U}_v$，覆盖分 $c_v=|\mathcal{U}_v|$。为防四个目标挤在同一个开阔方向，把方位角分成四个 90° 象限，并用 $\theta^\star=\arg\min_{\theta\in[0,\pi/2)}\sum_{k=0}^{3}d_{\mathrm{bnd}}(\theta+k\frac{\pi}{2})$ 旋转分割十字使其对齐最近的墙，再在每个象限取 $v_i^\star=\arg\max_{v\in Q_i(\theta^\star)}c_v$（$N=4$）。② Joint Panoramic Diffusion：以 flow-based 图像扩散为骨干，把每个点当各向同性 Gaussian splat，按目标位姿渲染 $(W_i,M_i)=\mathrm{Render}_{\mathrm{ERP}}(\Delta\mathbf{T}_{0\to i}\mathcal{P}_0)$，$W_i$ 提供像素级对应、$M_i$ 标出需幻觉的 disocclusion；把文本、源全景、N 个噪声目标视点、N 个 warp（$\mathrm{VAE}(W_i)+\phi(M_i)$）拼成一个全局 token 序列 $\mathbf{H}^{global}$ 做联合去噪，训练时对每个视点的 warp 独立扰动以缩小「干净 warp / 估计几何」的差距。③ Diagnostic-Guided 全局-局部注意力：在 fully-global 模型上逐层把某一层换成 per-view 局部注意力、不微调，测 ΔPSNR，取最不敏感的 30/60 层改为局部并再微调，训练与推理各约 1.77×/1.79× 加速。最后把源与生成的有位姿全景送入 HY-World 2.0 的 WorldMirror 2.0 + 3DGS 重建管线得到显式高斯场景。

## 实验与结果
- UE synthetic PSNR：20.16（Ours）vs 17.30（Matrix-3D）vs 15.18（GenEx），SSIM 0.658 / LPIPS 0.256
- UE synthetic 相机位姿 AUC@3°：49.79 vs 29.38（Matrix-3D）vs 4.58（GenEx）
- UE synthetic 点云 F-score@5cm：29.02 vs 20.32（Matrix-3D）vs 12.95（GenEx）
- RealSee3D（零样本）：PSNR 18.06 vs 17.44，AUC@3° 25.00 vs 8.33，F@5cm 41.44 vs 35.04
- 四方向生成相对 SOTA 全景视频方法加速最高 8.6×
- 联合四视点 vs 单视点独立去噪：四视点平均 PSNR 18.27→20.16 dB（+1.89），SSIM 0.560→0.658
- Gaussian splatting 渲染 warp 成本：4 视点 1K 0.72 s / 2K 0.89 s，点云渲染 4.21/4.51 s，网格约 60/73 s
- 实验规模：每个基准 64 个 anchor、每个扩 4 个目标视点，共 256 张生成全景

## 创新点与贡献
- 相对 GenEx / Matrix-3D 这类稠密全景视频扩展，把「扩展」重新表述为生成少量稀疏、互补、高分辨率的有位姿全景，从表示层面去掉邻帧冗余并把省下的预算换成分辨率
- Coverage-Guided 的自适应象限选择（让分割十字对齐墙面）与基于 disocclusion 面积的覆盖分是新的「看哪里」策略
- 逐层敏感性诊断驱动的全局-局部注意力调度，是新的「怎么便宜地联合生成」手段

## 局限与风险
- 只处理静态场景，动态 4D 扩展被列为未来工作
- 公开可比方法极少，作者只找到 GenEx 与 Matrix-3D 两条全景视频基线，且都必须跑四次独立轨迹再把关键帧对齐到目标视点，协议对基线略不利
- 重建依赖 HY-World 2.0 / WorldMirror 2.0 这一外部管线，端到端质量不完全由本方法决定
- in-the-wild 输入的源深度由 DepthMaster 估计，误差会传到 warp 与重建
