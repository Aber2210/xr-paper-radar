# ChronoReplay：流式空间智能的因果回放监督组织

## 一句话结论
ChronoReplay 使同一 Qwen3-VL-8B 的 OVO-S/OST/UCS 三基准齐升（+4.91/+13.41/+7.44，均分 56.86 最佳），时序对齐贡献 2.41 分。

## 要解决的问题
单接口后训练会把改进集中到该读出格式而损害其他接口（接口锁定）：分类-only 训练 OVO-S 达 58.03 却把 OST 从 50.52 压到 47.48，轨迹-only 训练 OST 亦无起色。且度量/时间目标脱离有效因果前缀即歧义：同样前移一步，面北与面东起步对同一旧问题答案不同。

## 方法详解
两阶段。Causal Replay construction：保留各源接口原生目标格式（选项语义、单位与精度、时间戳），把监督按 episode 视频时间轴顺序回放，每个目标绑定其合法因果前缀；嵌套前缀使一个 episode 产出 m_i 个共享起点的监督状态，直接训练「累积」本身，不新增地图/记忆模块。Family-balanced learning：preservation 族 33,180 条单轮样本（30,635 分类 + 2,545 数值）与 trajectory 族 6,381 个有序 episode（45,006 个监督轮次）各自族内归一化风险，按 α=0.5 显式配比（轨迹族占 1/3 损失质量），并以答案长度归一化防止长回答主导。仅训练语言模型与视觉 merger（视觉编码器冻结）。

## 实验与结果
统一 Qwen3-VL-8B-Instruct 起点、固定观测访问：OVO-S 48.98→53.89（+4.91，12 个任务族全升，数值接近 Qwen3-VL-235B-A22B 的 53.64）；OST（场景不相交）50.52→63.93（+13.41，15 个子类全正，Direction Est. +26.86）；UCS（8,114 个时间戳因果题）45.33→52.77（+7.44，quantity +10.73）。单族诊断：分类-only 均分 50.74、轨迹-only 50.76，均远低于完整版 56.86。机制对照：时序打乱 -2.41 OST；普通 token SFT 均分 54.10、自然轮次加权 55.57；α=0.5 最优；4 GPU 复现差 0.34。自适应帧选择再 +4.09（OVO-S 57.98，平均 80.50 帧）。

## 创新点与贡献
①实证命名并诊断「接口锁定」现象；②因果回放构造：原生格式 + 时序对齐，把每个目标绑回有效历史；③族平衡目标显式控制两族损失质量，优于普通联合 SFT 与自然轮次加权；④把观测访问（自适应帧选择）作为正交因子单独分解训练与推理收益。

## 局限与风险
仅室内场景与三个基准，机制归因基于匹配 Qwen3-VL-8B 对照；2.41 分的时序贡献是整体构造层面，未分离潜在起源表征；单族对比因来源/任务覆盖差异不能单独归因于答案接口；未新增记忆机制，长时程上限仍存；L4 仍最难。
