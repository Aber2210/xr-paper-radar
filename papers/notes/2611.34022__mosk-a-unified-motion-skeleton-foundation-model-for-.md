# MoSk：面向人体动作理解与生成的统一动作-骨架基础模型

## 一句话结论
用 joint-name embedding（CLIP 编码关节解剖名与侧别）把 motion 与 skeleton 两类语料统一进一个 ViT 掩码自编码器，使理解与生成共用同一表示——1.47M clips / 2,175 h；NTU-60 X-View 线性 94.0%、仅 1% 标注 77.0%；文生动作 FID 32.19→28.36、RoMo 15.35→9.68。

## 要解决的问题
人体动作缺一个可同时支撑理解与生成的基础模型：motion 数据集规模大（MotionMillion 595,422 clips / 819.6 h，RoMo 766,864 clips / 1,166.2 h）却几乎没有动作类别标注与识别协议；skeleton 数据集（NTU RGB+D 60/120、PKU-MMD II、ETRI-Activity3D）有标签与成熟评测协议，但规模小、动作集固定、采集环境受控。结果两条线各自训练专家模型：skeleton 自监督方法如 MAMP 在线性评测 NTU-60 X-View 上 89.1%，而生成模型的表示完全不复用。

## 方法详解
把两类数据统一到同一几何-时间格式：$\mathbf{X}=\mathcal{A}_k(S_k)\in\mathbb{R}^{T\times J_k\times 3}$，$T=64$ 帧，y 轴向上、地面 $y=0$、初始朝向 +z，但保留各数据集原有关节集 $J_k$。编码器是 ViT：每 $P_T=4$ 帧一个 patch，线性投影到 $C_e$；关键设计是 joint-name embedding——用冻结 CLIP 文本编码器分别编码关节解剖名（wrist、knee 等）与侧别（left/right/middle），经可训练投影后沿时间重复并加到 patch token 上，为不同关节定义提供共同解剖参照。掩码建模：先以 0.5 概率随机丢弃 0–40% 关节（全帧一致），再做 token 掩码，语义 tube 掩码（SLiM）与均匀随机掩码各半，总掩码率 90%；编码器只处理可见 token（MSA + 1D 时间 RoPE，FFN 用 SwiGLU）。解码器用「共享可学习 query 向量 + joint-name embedding」构成查询，经 cross-attention 从编码特征重建被掩码位置，线性头输出 patch。监督不是原始坐标而是帧间位移 $\mathbf{Y}_{t,j}=\mathbf{X}_{t+1,j}-\mathbf{X}_{t,j}$，损失为运动能量 focal 加权的 MSE，只算被掩码位置。下游两条：动作识别用线性头 + stop-gradient（半监督/全微调时去掉 sg）；生成侧把 MoSk 当冻结教师，按 REPA 对齐生成 backbone 中间特征 $\mathcal{L}_{REPA}=\mathbb{E}[\ell_{align}(\mathrm{MLP}(h_\theta(\mathbf{X}_\tau,\tau,c)),\mathbf{F})]$，总损失 $\mathcal{L}=\mathcal{L}_{flow}+\lambda\mathcal{L}_{REPA}$，$\lambda=0.5$，只在训练期生效。网络为 24 层 ViT / 1024 维 / 16 头 + 4 层解码器 / 384 维 / 8 头，训练 75 epoch（93,750 步），AdamW lr $4\times10^{-4}$、weight decay 0.05、bf16、梯度裁剪 3.0，batch 256，2×B200 约 12.8 h、单卡 23 GB。

## 实验与结果
- 语料：1,465,105 clips / 2,175.4 h，3 种骨架格式（SMPL 22、KIT 21、Kinect v2 25 关节）
- 线性评测：NTU-60 X-Sub 88.5%、X-View 94.0%（SLiM 87.9/93.2），PKU-MMD II 69.4%（SOfA 67.1）
- 半监督 NTU-60 X-Sub：仅用 1% 训练数据 77.0%（AMR、Path-JEPA 均 72.2%），10% 时 91.4%
- 全微调：NTU-60 X-Sub 94.1 / X-View 98.7、NTU-120 X-Sub 90.3 / X-Set 92.4、NW-UCLA 97.2
- 未见格式线性评测：UT-Kinect 98.0%（SOfA 97.0）、Florence-3D 96.5%（SOfA 91.7，+4.8 点）
- 生成：MotionMillion 无条件 FID 71.71→61.96（-9.75）、文生动作 FID 32.19→28.36（-3.83）；RoMo 15.35→9.68（-5.67）

## 创新点与贡献
- 首个把 motion 与 skeleton 语料合成单一自监督语料的人体动作基础模型
- 相对 SOfA 只统一骨架格式，MoSk 用 joint-name embedding 同时进入编码器输入与解码器查询，把解剖语义变成跨格式的共同参照，使同一编码器既做跨格式识别（含 3D 训练、2D 17 关键点迁移）又当生成侧的表示教师
- 相对 MAMP/SLiM 等数据集专用专家，它用一个模型在多数识别协议上更好，并在 16 个生成设置里 15 个降低 FID

## 局限与风险
- 作者自述语料消融只比较 motion、skeleton 与二者合并，没有逐数据集（如 NTU、RoMo）拆分贡献，各数据集对理解与生成的作用仍不清楚
- 默认 MoSk-L 有 304M 参数，微调的计算与显存开销大，缩到 MoSk-S/M 会掉识别精度
- 生成收益不均：16 个设置中 15 个改善，KIT-ML 上部分指标变差，HumanML3D 增益很小（FID 0.052→0.046），说明强生成 backbone + 大数据集时对齐的边际收益有限
- 识别只用 joint 流，未融合 bone/motion 流，与全监督多流集成并非完全同条件比较
