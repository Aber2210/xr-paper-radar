# forth：以仅前向的代理-控制配对夯实触觉 VLA 执行

## 一句话结论
把触觉 VLA 的适配与滑移门控全部压在纯前向路径上（Forward-Forward + 零阶），冻结 4-bit 骨干：LIBERO 97.6% 追平反传，峰值显存仅 334 MB（1/7.12）、延迟 58.8 ms（1/2），滑移门控夹持力 0.77 N 对 reflex ramp 22.43 N（1/29）。

## 要解决的问题
触觉 VLA 普遍假设「代理损失下降即意味着物理力接地」，该假设在三个部署层面失效：冻结视觉骨干丢弃接触几何、下游损失掩盖 token 级梯度对齐、离散指标触发优化崩溃。同时领域缺少把每层优化目标与其物理可观测量成对报告的评测约定。

## 方法详解
提出 forth 仅前向的测量与执行框架，三层各自配对「代理量-物理量」。表示层：两层 Forward-Forward 的层局部触觉 trunk，只让标量 goodness 跨块传递，不做端到端反传。更新层：token 并行的 zeroth-order 低秩（rank 8）adapter 挂在 action head，用对称差分方向导数在激活空间更新，16 次前向替代一次反传。控制层：SlipGuard 一类剪切比门控 ρ=F^s/F^n，阈值 τ=ρ̄+3σ_ρ、两步去抖、有界比例力修正。另给出 floor→readout→validity→mechanism 四步配对评测协议。

## 实验与结果
- LIBERO 平均成功率 = 97.6%（Spatial 99.3 / Object 98.6 / Long 94.8；OpenVLA-OFT 96.8）
- 峰值激活显存 = 334 MB（反传 2381 MB，7.12 倍）
- 单次前向延迟 = 58.8 ms（反传 117.5 ms，2.00 倍）；能耗 28.9 J（57.2 J，1.98 倍）
- SlipGuard 峰值夹持力 = 0.77 N（同一壳体的 reflex ramp 22.43 N，29 倍）
- 物体损伤降低 = 1.59–3.42 倍（相对手调 reflex ramp，N_crush=F_req 约定）
- 故障恢复 = 160/160 回合（恒力策略 68/160，给真值质量与摩擦的 oracle 145/160）

## 创新点与贡献
- 把「代理指标-物理量必须同向」提升为跨三层的评测约定，并用纯前向组合（Forward-Forward + zeroth-order）在冻结 4-bit 骨干上完成触觉适配与滑移门控，使每层都可测且可纠正

## 局限与风险
- 门限由经验标定而非物理推导，真实传感器上存在预触发误报（力级统计 0.024、比值统计 0.031）
- 部署需成对剪切/法向传感器、无故障标定集与策略不可抬升的力上限
