# CoBranchMR：混合现实中并行设计与冲突解决的支撑系统

## 一句话结论
CoBranchMR 是一个让分布式协作者在不同地点并行编辑"同一物理对象的数字表示"的混合现实系统：用户把对象分支为可编辑虚拟副本、独立定制后合并回共享对象，合并时在表面显示潜在冲突并提供多种解决选项（选其一 / 混合两者 / 撤销合并），把分支-合并工作流与冲突协商引入具身 MR 协同。

## 要解决的问题
远程创意协作中，多人需对同一数字-物理对象做并行修改并解决冲突，但现有 MR 协同缺乏"并行分支 + 冲突可视化解决"的机制。

## 要解决的问题（细化）
如何在不覆盖他人工作的前提下支持并行设计，并让表面级冲突可见、可协商。

## 方法详解
- **分支-合并**：对象可拆分为可编辑虚拟副本，各自独立定制后合并；
- **冲突解决**：合并时在对象表面高亮潜在冲突，提供"选一/混合/撤销"三类解决选项；
- **具身协同**：把 CSCW 的协调/觉察/共享工件/冲突协商延伸到 MR 场景。

## 实验与结果
论文以原型（prototype）形式呈现，侧重交互模型与系统构建；未给出大规模量化用户研究或基线对比（实验强度偏弱）。

## 创新点与贡献
把成熟的"分支-合并"软件工程工作流映射到具身 MR 远程创意协作，是一个清晰的系统/交互贡献，填补了 MR 并行设计空白。

## 局限与风险
仍属早期原型：无严格用户研究、无量化性能/可用性对比；冲突解决仅表面级（几何/语义深层冲突未涉及）；实际工程化与多用户规模化未验证。

系统型原型，未提供开源；复现需重建 MR 应用与分支-合并引擎，门槛中等。

做 MR 远程协作/协同设计产品时，CoBranchMR 的"分支-合并 + 表面冲突解决"可作交互范式参考；需补做用户研究验证可用性增益。
