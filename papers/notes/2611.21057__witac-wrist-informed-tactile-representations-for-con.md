# WiTac：面向富接触操作的腕部信息触觉表示

## 一句话结论
把触觉与腕部视觉在策略注入前融合成连续接触表示，并用掩码视觉恢复与力旋响应预测约束该表示：GR00T N1.7 四任务 66.3%（纯视觉 37.5%、无腕部变体 47.5%），π0.5 58.8%，USB 拔出 95% 对 50%。

## 要解决的问题
相似的触觉接触在不同手-物-目标构型下需要不同修正。把触觉与腕部视觉分别送入策略会让触觉缺乏视觉空间参照，接触表示不准确，细对齐任务尤其容易失败。

## 方法详解
在动作生成之前预训练触觉编码器：以机器人状态与腕相对指尖运动学汇总每指触觉历史，再通过交叉注意力查询腕部 patch 特征，形成指级 contact token。预训练联合监督接触状态与历史重建、掩码腕特征恢复、动作条件力旋响应预测。下游用轻量门控交叉注意力把冻结编码器接入 VLA。

## 实验与结果
- GR00T N1.7 四任务平均成功率 = 66.3%（vision-only 基线 37.5%，+28.8）
- 同骨干下比无腕部变体 WiTac-NW = 47.5% 高 18.8
- π0.5 平均成功率 = 58.8%（基线 43.8%，+15.0；WiTac-NW 51.3%）
- 电池对位失败次数 = 1（GR00T 7，WiTac-NW 4）
- USB 拔出成功率 = 95%（GR00T 50%）
- 触觉噪声下特征漂移降低 = 35.6–44.1%

## 创新点与贡献
- 把触觉与腕部视觉在策略注入之前深度融合成连续接触表示，并用掩码视觉恢复与力旋响应预测约束该表示保留物理细节

## 局限与风险
- 仅特征级交叉注意力，未在共享三维空间做视觉-触觉深度对齐
- 只用当前腕图，未显式建模联合时序演化
- 仅四任务单一平台，跨手型、传感器与相机配置未验证
