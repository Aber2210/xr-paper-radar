# EgoJev：通过读取 VLM 决策在第一人称视频中定位证据帧

## 一句话结论
把 VLM 对候选帧的标签概率整体当作时间先验、用 W1 最优分位数放帧，免训练即把 QAEgo4D 从 51.2% 提到 62.0%。

## 要解决的问题
智能眼镜要回答“我把剪刀放哪了”“我从冰箱里拿了什么”这类问题，但受三重约束：每题只能看极少数帧（端侧算力小、上传视频耗带宽且涉隐私）；只能用一个小模型（再挂一个逐帧扫描的网络会额外吃内存与功耗）；答案还应附上证据发生的时刻，因为用户问的是过去、想回看那一刻。长视频的答案往往取决于一瞬，例如手放下物体的那一秒，而均匀采样几乎必然错过。现有 training-free 选帧路线都不合这三条：相似度法（AKS/BOLT/FOCUS）需要额外的 CLIP/BLIP 模型逐帧打分，只把帧与问题文本比对；逐帧打分法（SeViLA 式“Yes”概率、UG-Sample 熵）每帧一次前向，帧与帧之间从未被比较、分数也不同尺度；写时间法（TCoT 写帧 ID 或时间跨度）定位命中率最低，且要解码文本、多数还需训练。

## 方法详解
核心观察：让冻结 VLM 在带编号的候选帧里“选一个”，并从输出分布读出这个选择，定位效果优于逐帧打分或写时间跨度，且一次决策比较了全部候选。定位输入构造为 X_loc=[ℓ1,v1,…,ℓN,vN,q,O,u,“Segment: [”]，ℓ_i 是“Segment i:”标签，v_i 是该帧视觉 token，u 是“哪一段展示了回答问题所需内容”。读出头：标签 i 记作“i]”的多 token 串，其概率取各 token 条件概率之积 P(i)∝∏p_θ(c_{i,l}|X_loc,c_{i,<l})，再在 N 个标签上归一化（式 2）；标签统一以“]”结尾，避免“1]”吞掉“17]”的概率；只做一次前向加少量缓存步，不生成文本、不用隐状态或注意力。粗到细两级：先把视频切成 N=32 等段、每段取中间帧作几十 token 的缩略图，得到粗分布 P^c；再把视频切成 W=4 窗口、每窗口内再分 N 个细段，对粗概率最高的 k=3 个窗口用同一提示读稠密缩略图；被选窗口内 P^f 按窗口粗概率缩放，未选窗口把粗概率均摊到细段；两级用几何平均合成 P*_s∝√(P^c_{j(s)}·P^f_s)（式 3），平方根等价于在对数空间取平均，用直乘会把证据计两次并使分布过尖（实测降 4.0 点）。放置规则：把 P* 均摊到段内得到时间分布 μ 与 CDF F，第 b 帧放在 t_b=F^{-1}((b−1/2)/B)（式 4），即分位数；该放置是 W1(μ, (1/B)Σδ_{t_b}) 的最小化解（附录 A 有证明），模型确定时帧密集堆在证据段、不确定时铺开、分布平坦时退化为均匀采样，无需阈值也不需按数据集调 sharpness（温度 τ=1）。回答：8 个答案帧各加“Frame b:”标签，选项字母为标签，ŷ=argmax p_θ(c_y|X_ans)（式 6）。证据时刻：在同一上下文追加“哪一帧展示了回答问题所需内容？”，读 B 个帧标签概率取最大者，仅增加 41 个文本 token、零视觉 token。开销为 1+k 次定位前向加 1 次回答前向；因缩略图先于问题产生，录制时即可编码进 VLM 自身 KV cache（每 15 秒一张，8 分钟仅 8.2 秒）。

## 实验与结果
- Qwen3.5-4B、8 答案帧：QAEgo4D 准确率 62.0% vs 均匀采样 51.2%（+10.8 点，相对 +21%），MyEgo 42.6% vs 36.1%，EgoSchema 65.2% 与均匀持平，三数据集均值 56.6% vs 50.8%
- 同候选对照（32 张缩略图）：单级 EgoJev 57.2%/42.2%/65.2%，均高于同缩略图下的 AKS（54.8/40.0/63.2）、BOLT（53.0/39.3/62.6）与 Write IDs（55.8/39.8/64.8）
- 定位机制对照（16 候选，QAEgo4D/MyEgo 段落命中率）：选择 28.0%/18.5%，逐帧“Yes” 18.2%/13.5%，写时间跨度 15.8%/12.6%，BLIP（AKS）19.0%/12.9%，CLIP（BOLT）15.6%/12.0%，随机 8.9%/6.2%
- 选择只需 1 次前向 0.44 s，逐帧需 16 次 1.41 s
- 证据时刻：QAEgo4D 上 33.6% 的问题预测时刻落在证据 ±8 s 内（AKS 27.8%、BOLT 22.8%、随机 5.9%）
- 答案帧落在证据 ±8 s 内的比例为 67.2%（QAEgo4D）与 66.7%（MyEgo），基线最高 59.2%/58.0%
- 跨模型：三个数据集均值相对更强基线（AKS/BOLT 取优）分别提升 2.2 点（Qwen3-VL-8B）、1.2 点（GLM-4.1V-9B）、0.8 点（MiniCPM-V-4.5），Qwen3.5-4B 上为 3.6 点
- 端侧：Mac（4-bit、6 GB 上限）录 8 分钟 + 回答共 18.8 s，对比 BOLT 38.7 s、AKS 67.4 s
- B=4 时 14.0 s 且准确率升到 59.6%
- iPhone 15 Pro 录制 18.3 s、提问 8.0 s、峰值 5.6 GB

## 创新点与贡献
- 把“VLM 作为决策模型、从标签概率读出选择”的做法（Jev 一系）第一次用于长第一人称视频的帧预算分配，并且不是取 argmax 选一帧，而是把整个归一化分布当作时间先验：粗到细两级读数相乘（几何平均）后，用该分布的 W1-最优分位数放帧
- 这带来三点真正的新意：其一，一次前向就完成全部候选的比较，取代逐帧独立打分导致的尺度不可比
- 其二，不生成任何文本，避免写时间/写 ID 的解码开销与低命中
- 其三，放置规则自适应——确定时聚集、不确定时铺开，均匀采样成为无信息时的特例，因此不需要 BOLT 那种按数据集手调的 sharpness
- 另外用灰帧红方块实验量化了“分成带标签图片 vs 输入成一段视频”的差异（16/16 vs 3/16），解释了为何必须逐帧加标签

## 局限与风险
- 方法上限受冻结 VLM 自身定位能力约束：单级在 EgoSchema（整段语义题、无证据标注）上只能与均匀采样持平，甚至 k=3 时从 65.2% 掉到 62.8%，说明“找一刻”的机制对“概括整段”的任务无益
- QAEgo4D 上 k=4 反而降到 59.2%，粗到细的窗口数是敏感超参
- 依赖多选题形式与选项文本（无选项时 QAEgo4D 59.0%，略降），依赖 VLM 输出概率可读（闭源 API 若不给 logprob 即失效）
- 评测均为多选基准、无开放式问答与真实用户任务
- MyEgo 只取提问前视频
- 端侧实验为 4-bit 量化、6 GB 上限的单机结果，仅有 10–20 题量级的中位数延迟，未给功耗与热约束
