# SceneAgent：从 3D/4D 采集到仿真环境的智能体管线

## 一句话结论
以智能体编排经模拟器视觉检查与修复把 3DGS/摄影测量/LiDAR/AI 生成 3DGS/4D 视频转为可交互仿真环境：GraspClutter6D 杂乱箱 F1@1cm 最佳 60.75%（SimFoundry 6.9%），4DCodeBench 动态 IoU 0.86%→99.09%。

## 要解决的问题
视觉采集转为交互仿真环境需要物体重建、物理建模与中间错误纠正，现有 real-to-sim 管线（如 SimFoundry）在杂乱遮挡场景重建质量低，且生成策略评估环境缺乏物理/铰接/可变形建模与演示数据。

## 方法详解
智能体编排：输入准备与场景表示（3DGS/摄影测量/LiDAR/AI 生成 3DGS/4D 视频）→ 物体分割与背景补全 → 物理属性（质量/摩擦/刚性）估计、部件分解、铰接与断裂仿真 → 3D 到 4D（动态场景）→ 场景导出与编辑 → 数字孪生与「digital sisters」变体 + 脚本演示生成（策略自动研究循环、初始状态随机化、专家与回合过滤、策略微调）。全链经模拟器视觉检查发现几何不一致并修复。

## 实验与结果
MessyKitchens 厨房场景 + GraspClutter6D scene hard/000091（20 个 YCB 物体堆叠遮挡、13 视图 1920×1080）：多种 coding agent harness 带/不带 SceneAgent skills 配对转换，按 Chamfer 距离报告 CD 与 F1@τ；所有 agent 配置超 SimFoundry（最佳 60.75% vs 6.9%）。4DCodeBench 三个动态场景：Gemini 4 Argon 平均动态 IoU 0.86%→99.09%。附定性场景/物体转换与初步真机策略迁移。

## 创新点与贡献
①把 real-to-sim 转换组织为「智能体编排+模拟器视觉检查修复」闭环；②统一处理 3D 与 4D（动态）采集输入；③生成多样化物体变体（digital sisters）与脚本演示直接服务策略学习。

## 局限与风险
转换需反复 VLM 调用与外部 GPU 工作站，慢且易错；视觉检查无法建立隐藏几何/物理参数精度；质量/摩擦/刚性/铰接参数未对标实测机器人交互；高斯保留原光照，重光照与合成可出现阴影不一致；评估仅一个厨房+一个杂乱箱+三个动态场景，每配置仅转换一次。

## 与文献库的关系
