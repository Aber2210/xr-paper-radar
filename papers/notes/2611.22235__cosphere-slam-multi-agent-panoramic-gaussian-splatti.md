# CoSphere-SLAM：带球面回环的多智能体全景高斯泼溅 SLAM

## 一句话结论
把回环改成 S² 上的 SO(3) 相关并用三 agent 全局 Sim(3) 一致拒绝对称假回环，全景多机 SLAM 单机 ATE 1.610→0.150 m、多机 1.353→0.082 m。

## 要解决的问题
多智能体稠密建图需要全景相机，但把全景高斯 SLAM 扩到多 agent 有三个耦合难题。任意 pitch/roll 下 equirectangular 的 yaw 是循环移位、tilt 会按纬度扭曲，平面匹配失效；全 3D 旋转搜索会把对称房间匹配成「互相一致的错误变换」，整片区域支持同一对称时成簇 outlier 无法被成对 robust kernel 拒绝；单目尺度持续漂移会让刚性合并的子图在重访墙处裂开，短基线深度噪声又按场景深度放大、扭曲回环平移方向。

## 方法详解
每个 agent 把 equirectangular 重采样成六个共享光心的 90 度 cube face，用冻结的 DROID-SLAM 前端以 T_i R_f^T 联合跟踪六面，得每关键帧一个 SE(3) 位姿 T_i。在更宽的重叠面上预测单目深度，按面做 log-scale 线性最小二乘对齐成球面深度 D_i；深度只约束前若干关键帧，之后靠多视光流与 agent 内回环。同时把水平面特征按行平均成 128x32 的 ring descriptor（8.1 KB），与位姿一起上传；服务端把六面稠密特征重采样到 HxW 单位方向网格，得球面特征图 F_i: S^2 到 R^C，把回环写成 F_j(x) 约等于 F_i(R_ij x)。先用 ring descriptor 的循环互相关做全部对的粗筛（yaw 化为列移位、对 tilt  tolerant），只对 top 对请求面与深度。球面相关把 R 分解为水平轴 tilt Q 与竖轴 yaw R_z(psi)，固定 Q 后沿经度做 1D 循环互相关，用一次逆 FFT 求出所有 yaw；粗到细扫 N_Q=108 个 tilt（7.5 度到 30 度，再 3 度精化），复杂度 O(N_Q C H W log W)，覆盖 360 度任意朝向。以 R* 初始化做六面 6-DoF 光流精化，把置信对应反投影成 3D 点对，用加权 Umeyama 解 Sim(3)，同时得到相对尺度、旋转与平移。全局 Sim(3) consensus 把每个候选变换按局部位姿转成 agent b 到 a 的相似变换并聚类，在「每对至多选一个簇」约束下最大化支持度，要求任意三 agent 闭环的乘积约等于 I（tau_t=1.0 m、tau_R=5 度），用至多 729 个 CPU 状态穷举，从而拒绝整片区域服从同一对称 G 的假簇。定向全局优化给每关键帧一个 Sim(3)，残差含旋转、局部系平移与 log-scale 三行；odo 边令 s 的观测为 1，使 log s 沿轨迹随机游走、在两次相遇间线性插值；回环平移取 Umeyama 的模长与光流的单位方向，信息矩阵沿该方向与垂直方向各给 lambda 平行、lambda 垂直，DCS 权重再按 1/m_ij 平衡长相遇与短相遇。全向高斯融合用射线式高斯求值（低通 A=(Sigma+kappa^2 ||mu||^2 I)^-1，解析最大响应 tau* 与闭式 alpha(d)）避免极点拉伸与接缝断裂；每个高斯按所属关键帧的 S_i 变换（协方差乘 s_i^2）；最后固定尺度，用立体角加权的 |I-I_hat| 加 SSIM 联合精化高斯与位姿，并对 SSIM 窗口施加随机 3D 旋转以避开极点。

## 实验与结果
- Holo360D 45 个测试场景：单 agent per-agent ATE 0.150 m、100% tracked，对比 DROID-SLAM 1.610、DPVO 1.576、MASt3R-SLAM 0.651、OpenVSLAM 0.543、ODGS-SLAM 1.613
- 多 agent 0.082 m，对比 MAGS-SLAM 1.353、CoMo3R-SLAM 0.606、OpenVSLAM-M 0.715
- 45 场景 joint ATE 0.152 m，对比 MAGS-SLAM 3.165、CoMo3R-SLAM 5.054、OpenVSLAM-M 1.882
- 五个最长测试场景 mean ATE 在 0.053 到 0.300 m
- 渲染：共享视角 PSNR 28.25 dB 与 LPIPS 0.235，对比 MAGS-SLAM 的 26.09/0.318
- 对 ODGS-SLAM 为 27.92 对 17.67 dB
- Scene 009 novel-view WS-PSNR 28.95 对 PFGS360 的 21.20，full-scene 27.80 对 24.28（Ours Single）
- 回环：dev 1 m 内相遇恢复 3,950 个回环、95.6% 精度、连上 69.7% 的相遇，前脸匹配只有 1,152 个与 28.9%
- 45 个测试场景在 33,815 个回环中连上 23,382 个重访，其中 55.3% 的朝向差超过 45 度
- 360Loc 跨昼夜 18 条会话：多 agent 100% tracked、平均 ATE 0.30 m（四栋楼 joint 0.22 到 0.44 m），对比单 agent 0.88、MAGS-SLAM 2.04（83%）、MAC-Ego3D 23.59、ODGS+RICP 16.39（67%）
- 多 agent 对齐耗时 3,113 s，比 ODGS+RICP 的 15,132 s 快 4.9 倍
- 建图 4.3 GPU-hours/agent，PFGS360 为 27.9

## 创新点与贡献
- 首个多 agent 全景高斯 splatting SLAM，把回环从平面图像匹配改成 S^2 上的 SO(3) 相关：tilt 分解加经度 FFT，使任意 heading 都能在 O(N_Q C H W log W) 内匹配，且不会像针孔相机那样裁掉视野
- 用三 agent 闭环的全局 Sim(3) 一致性拒绝「整片对称区域共同支持」的假回环，这是成对 robust kernel 在结构上做不到的
- 把单目尺度漂移建成每关键帧 Sim(3) 的 log-scale 随机游走，并把回环平移的方向（光流）与模长（深度）分开加权
- 融合端用射线式高斯求值同时消掉极点拉伸与接缝断裂

## 局限与风险
- 作者明确假设静态场景且存在共享视野，纯视觉建图不处理动态物体，未来才做球面动态建模与惯性/测距融合以获得 metric scale 与机载部署
- 系统是离线服务端式的：输入仅 1.0 FPS，服务端对齐 3,113 s，建图在单张 A100 上完成，离在线机载还有距离
- 实验以 ATE 与 PSNR 为主，无用户研究
- 正文只给项目页、没有代码仓库
- 360Loc 上单 agent 0.88 m 与多 agent 0.30 m 的差距也说明跨会话仍依赖多 agent 相遇
