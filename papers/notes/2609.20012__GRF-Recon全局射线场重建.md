# GRF-Recon：把前馈 3D 重建从"一段一段"变成"一条到底"

## 一句话结论
针对前馈 3D 重建在**长单目序列**上的三大瓶颈（显存爆炸、局部几何退化、长程轨迹漂移），给出"粗到细轨迹对齐 + 轻量几何先验注入 + 混合权重稀疏射线场优化 + 射线误差联合优化的轨迹拼接"的统一框架，在保持可与代表性 SLAM 系统竞争的轨迹精度的同时维持全局一致的 3D 重建。

## 要解决的问题

前馈（feed-forward）3D 重建提供了从图像序列高效建模场景的范式，但向**大规模单目场景**扩展时受三个约束：
1. **GPU 显存占用过大**；
2. **局部几何退化**；
3. **长程轨迹漂移**。

已有的 chunk-based 优化策略提供**有限的几何约束**，且**无法在长轨迹上维持全局一致性**。

## 方法详解

### 1. 粗到细轨迹对齐 + 轻量几何先验注入
作者观察到：DA3 虽在大规模数据上预训练，直接用于序列重建常出现**几何过平滑**与**遮挡边界附近退化**（对细结构如电线杆、树叶、车辆结构尤其明显）。

对策借鉴 Fin3R，采用**重归一化 LoRA（Re-normalized LoRA, r=8）**微调 DA3 编码器，注入高频单目几何先验，同时保持模型的多视角匹配泛化能力。

为避免单目蒸馏引起的**特征范数漂移**（与冻结解码器期望的输入分布不匹配），对更新后的有效权重做重归一化约束：

$$\mathbf{W}' = \frac{(\mathbf{W}_0 + \mathbf{B}\mathbf{A}) \cdot \|\mathbf{W}_0\|_F}{\|\mathbf{W}_0 + \mathbf{B}\mathbf{A}\|_F}$$

其中 $\|\cdot\|_F$ 为 Frobenius 范数。该策略**增加的可训练参数 < 1%**（论文另处表述为总量 < 3%），却保持了原始权重范数，稳定了特征激活分布。

- 冻结解码器，只在 DINOv2 编码器注意力的 Q/K/V 投影插入低秩适配器；
- 只更新图像编码器与深度头；
- 单张 RTX 3090，AMP，batch 16，15 epoch（≈14 小时）。

### 2. 混合权重稀疏射线场优化（Hybrid-weight Sparse Ray-Field Optimization）
利用高频几何特征引导局部点云精化，并强制**帧间射线约束一致**。与 chunk-based 方法不同，这建立了**强跨帧几何耦合**，同时保持可扩展性。

### 3. 射线误差联合优化的高效轨迹拼接
显式降低累积漂移。

## 实验与结果

**数据集**：KITTI、Waymo Open Dataset（轨迹估计与场景重建）；ETH3D、SINTEL、DIODE（深度估计）。

**硬件**：i9-13900K + 128GB RAM + 单张 RTX 3090（24GB）——明确在 **24GB 显存预算**下工作。

**指标**：ATE RMSE（全局一致性/累积漂移）；深度用 Rel ↓ 与 $\delta_1$ ↑；点云用 Accuracy ↓ / Completeness ↓ / Chamfer ↓；NVS 用 PSNR / SSIM。单目尺度歧义通过全局 Sim(3) 对齐到 LiDAR 真值后计算。

**深度改进（DA3 + Ours，Table 1）**：

| 数据集 | Rel ↓ | $\delta_1$ ↑ |
|---|---|---|
| KITTI（原始 DA3） | 5.14 | 92.4 |
| KITTI（Ours） | **4.50** | **97.1** |
| ETH3D / SINTEL / DIODE 平均（Ours） | 6.95 | 91.4 |
| MoGe（教师） | 4.39 / 2.10 | 97.2 / 99.8 |

相对全量微调，LoRA 方案**有效缓解过拟合**，同时产出锐利、高保真的局部几何。

**效率**（论文给出）：
- 跨 chunk 射线匹配 ≈ 0.16 s / 关键帧；chunk 对齐 ≈ 0.15 s / chunk；
- 主导的前馈推理 ≈ 8 s / chunk，因此前两者的开销被**流水线并行完全隐藏**；
- 即使超过一千帧的序列，完整 Levenberg–Marquardt 优化**约 10 秒内收敛**。

论文结论：在无标定单目设置下，GRF-Recon 在多数序列上取得一致的 Accuracy / Completeness / Chamfer；射线场表示施加的全局约束**主动缓解了长轨迹上的点云分层与鬼影**。

## 创新点与贡献

1. **重归一化 LoRA**——用 Frobenius 范数约束解决低秩适配中"特征范数漂移导致冻结解码器失配"这一具体问题，代价 <1% 参数。这是可独立复用的技巧。
2. 混合权重稀疏射线场建立了 chunk-based 方法缺失的**强跨帧几何耦合**。
3. 明确在 24GB 消费级显存预算下完成长序列重建，工程约束清晰。
4. ECCV 2026 Spotlight。

## 局限与风险

- 评测数据集以**室外驾驶**为主（KITTI / Waymo），论文未充分覆盖室内 AR 场景。
- 前馈推理 8 s / chunk 仍偏慢，未达到实时。
- 与 LiDAR 真值做 Sim(3) 对齐后计算指标，实际无真值场景下的表现需另行评估。
- 未开源。
- 论文给出的定量对比多为"在多数序列上一致"的定性表述，缺少一张汇总的 ATE 对比主表（KITTI Table 2 的完整数值在抽取文本中被截断）。
