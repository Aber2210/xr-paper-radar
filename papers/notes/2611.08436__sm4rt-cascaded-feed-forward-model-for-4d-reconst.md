# SM4RT：先几何后运动的级联前馈 4D 重建

## 一句话结论
SM4RT 是基于 DUSt3R 的级联前馈模型：先重建 3D 几何，再以预测结构引导运动估计，用各相机系下的 object flow 解耦相机与物体运动，并以体素化弱监督 Chamfer 损失、EMA 静态蒸馏与 shrink-and-perturb 适配稀疏运动标签。Waymo object flow EPE 0.014（较次优 DPM 0.020 降约 33%），Kubric-F 与 Point Odyssey 多数指标 SOTA，五个数据集双视图深度保持竞争力。

## 要解决的问题
从 RGB 视频同时恢复精细几何与运动是动态场景重建的核心难点：运动估计依赖各时刻可靠的 3D 点位置，而几何重建依赖 3D-2D 一致对应，动态运动破坏静态假设使两任务强耦合。现有前馈方法把两帧的点图预测在单一相机坐标系，模型必须同时表征全局相机运动与局部物体运动，存在歧义且未来/过去点图独立预测导致时空不一致；同时真实数据（Waymo 等）的 3D 运动标签稀疏，仅用全监督回归会使同一物体内的 object flow 估计不一致。

## 方法详解
几何分支：DUSt3R backbone（ViT 编码+交叉注意力）对有序帧对 (I1,I2) 预测点图 P1(t1,π1)、P2(t2,π1)。运动分支：更新后的 token G1/G2 送入 transformer decoder 做交叉注意力，将每个 token 对应 patch 内预测 3D 坐标的平均值经 rotary positional embeddings（RoPE）编码相对 3D 位置注入注意力层，再经 DPT head 输出 object flow F1(t1,t2)=P1(t2,π1)-P1(t1,π1)（静态点天然为 0）；反向 flow 通过交换输入顺序再前向一次获得。训练损失：confidence-weighted 全监督回归 L_conf（DUSt3R 式，含逐像素置信度）；弱监督 Chamfer 损失 L_CD 将一帧点按预测 flow 变换后约束其靠近另一时刻已标注点，用每轴 1000 分辨率（N=1000³）体素化近似最近邻并借占据交集过滤遮挡无效匹配，权重 λ 以 sigmoid 调度从 0 增至 4；EMA teacher 仅在静态像素上做几何自蒸馏 L_SD；flow head 由预训练 depth head 初始化并按 shrink-and-perturb 周期性注入可塑性。点图与 flow 用同一尺度因子 g 归一化。微调自 MASt3R checkpoint，encoder 冻结；训练 200 epochs、初始 lr 5e-5、4×NVIDIA ADA 6000 共 40 小时，帧对间隔 K∈[1,15]，分辨率 512×288/336/384/512 随机。

## 实验与结果
运动估计（各 1000 帧对）：Kubric-F 上 SM4RT object flow EPE 0.018/0.017、相对位姿 rot 0.193/trans 0.085（DynaDUSt3R 为 3.507/0.357）；Waymo 上 EPE 0.013/0.015（DPM 0.020），位姿 0.193/0.168（MonST3R 0.787/1.048）；Point Odyssey 上 EPE 0.072/0.074。几何重建（双视图深度，Sintel/Point Odyssey/Bonn/Kubric-F/KITTI）：Kubric-F Abs Rel 0.044 为全部方法最优，Sintel 0.367 与 KITTI 0.089 逊于 MonST3R/DPM，总体 competitive。消融（Waymo）：去掉 Chamfer 损失 L_rel 从 0.075 升至 0.151、EPE 0.006/0.007 升至 0.038/0.037；把 3D 位置换成 2D 像素坐标（去 3D RoPE）L_rel 0.147/0.146、EPE 0.039/0.038。附录另证 object flow 训练优于 scene flow（EPE 0.088 vs 0.106，Point Odyssey）。

## 创新点与贡献
['以各相机系 object flow 表示运动，从表示层面解耦相机运动与物体运动，静态点零运动简化相机运动估计', '“先几何后运动”的级联前馈结构，用预测 3D 位置（RoPE 注入）引导运动解码器', '体素化弱监督 Chamfer 损失，在无逐点对应的稀疏标签下正则化未标注点运动', 'EMA 静态几何蒸馏 + flow head shrink-and-perturb，在适配动态任务同时不遗忘静态重建能力', '级联模块与 backbone 解耦，可作为即插即用动态模块挂接到 VGGT、DA3 等多帧模型']

## 局限与风险
仅处理两帧输入，长时程视频建模未解决（作者列为未来工作）；依赖 DUSt3R backbone，动态物体运动下几何重建本身会退化；深度指标在 Sintel 与 KITTI 上不及 MonST3R/DPM；训练成本高（4×ADA 6000、40 小时）；论文未提供代码或项目页链接。
