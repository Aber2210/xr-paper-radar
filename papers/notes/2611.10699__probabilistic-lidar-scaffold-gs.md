# PLS-GS：概率激光雷达脚手架驱动的紧凑表面对齐高斯泼溅

## 一句话结论
在 GauU-Scene V2 五个大尺度室外场景上，PLS-GS 把平均 precision（几何精度）从 0.330 提到 0.484、Chamfer 距离从 0.820 m 降到 0.703 m，同时 anchor 少 2.8×、模型体积为基线 42%、帧率 1.7×，代价是平均 PSNR 从 27.10 降到 25.45 dB。

## 要解决的问题
机器人/测绘平台同时给出相机与高精度 LiDAR，但主流 3DGS 只由图像监督：基元可以冗余、偏离真实表面，存储随场景尺度增长。已有两条路线各缺一半——Scaffold-GS/Octree-GS 用体素或八叉树提升紧凑度，但支撑结构离散、由光度梯度播种与生长，与实测几何无关，还存在单元边界的量化问题；LI-GS/GS-SDF/ARSGaussian 改善了与实测点的贴合，但每个 Gaussian 仍自带位置、协方差、透明度与球谐系数，基元在光度优化下仍可漂移，致密化与逐基元存储也不受约束。结果是尚无方法同时做到紧凑与锚定在实测表面上。

## 方法详解
PLS-GS 把彩色点云拟合成连续的 6D 分层高斯混合（Hierarchical Gaussian Mixture Model, HGMM），并把这个混合模型本身当作渲染脚手架。构造：每点写作 [x, c] 属 R^6 并标准化，从单根节点起以分支因子 K=8 逐层 EM，节点内点数超阈才继续分裂，故分辨率随局部密度自适应而非固定网格；叶节点空间均值成为 anchor 位置，协方差作特征分解 Σ_j = U_j diag(λ_j) U_j^T，前两个特征向量张成局部切平面、最小者对齐法向，U_j 即「表面坐标系」，sqrt(λ) 初始化各向异性尺度，颜色均值初始化 anchor 颜色。几何与颜色联合拟合是关键：只拟合空间无法分开空间相邻但外观不同的表面（如路面标线与沥青）。渲染沿用 Scaffold-GS 的 anchor 解码 neural Gaussian，但把世界轴 offset 换成表面坐标系 offset：μ = x_v + U_v(o ⊙ s)，使两个大轴的铺展贴合切平面。约束为 Mahalanobis 支撑损失 L_support = (1/M) Σ δ̃²/(λ+ε)，位移沿高方差切向便宜、沿低方差法向昂贵，把基元压在表面薄层内；总损失 L = L_photo + λ_s·L_support，λ_s = 1e-3。生长：以视图空间位置梯度均值超阈的神经高斯为残差区，对其位置与颜色再拟局部 6D HGMM 并把叶节点实例化为 anchor，混合深度有上限、梯度随覆盖下降而自限，因此只长 1.1×（Scaffold-GS 为 2.6–2.7×）。初始 anchor 位置与坐标系在训练中固定，只优化特征、offset、尺度、颜色与共享 MLP。

## 实验与结果
['数据集：GauU-Scene V2 五个室外场景——Campus（80M 点/670 相机）、Village（27M/424）、College（59M/1215）、Modern Building（94M/713）、Russian Building（28M/563），面积 0.8–1.56 km²；图像长边降到 800 px，每第 8 张作测试视图。', '基线：Scaffold-GS 分别用 SfM 点与 survey LiDAR 初始化（同一发布配置、同一 anchor 数），并额外设「匹配容量」对照：用 PLS-GS 最终 anchor 集初始化 Scaffold-GS 且关闭生长。', '主结果（Table 1 均值）：精度 0.484 对 LiDAR 基线 0.330、SfM 基线 0.312；Chamfer 0.703 m 对 0.820 m；anchor 460K 对 1308K（2.8× 少）；体积为基线 42%；帧率 190.4 对 114.4；PSNR 25.45 对 26.48/27.10，落后 1.03–1.65 dB。', '匹配容量（Table 2）：anchor 完全相同时精度 1.54×、recall 1.40×、F1 1.45×、Chamfer 降 40%，渲染差距由 1.03 dB 收敛到 0.21 dB，SSIM 差不超过 0.004、LPIPS 不超过 0.007；但帧率降到 190 对 272 FPS。', '消融（College，τ=0.333 m）：只加表面坐标系旋转而不加支撑损失几乎不改善（0.225 对 0.234），叠加支撑损失后精度 2.27×、Chamfer 2.95×；λ_s 由 1e-4 到 1e-3 同时提升 PSNR/SSIM/LPIPS 与精度；概率生长只增 1.06× 容量，同脚手架的光度生长增 3.23×（模型小 2.56×）。', '阈值鲁棒性：在每个 recall 与 τ 上都优于 LiDAR 基线，逐点误差分布整体更紧而非只在尾部。']

## 创新点与贡献
['首次把 Eckart 等人的分层 GMM 从「几何表示」改造成「渲染脚手架」：混合分量既给 anchor 位置，又用特征向量给出表面坐标系，取代体素/八叉树的离散分区。', '在表面坐标系内解码 neural Gaussian 并配 Mahalanobis 支撑损失，使贴合实测表面成为优化中的约束，而非事后剪枝（对比 ARSGaussian 的距离阈值剪枝、GS-SDF 的神经 SDF 正则）。', '生长机制由离散网格上的克隆/分裂改为「对高残差神经高斯拟合局部 HGMM 并实例化叶节点」，容量有上界、触发自限，生长倍率从 2.7× 压到 1.1×。']

## 局限与风险
['作者承认：渲染质量仍低于无约束光度生长的 Scaffold-GS，计划靠分层细化与压缩弥补；Mahalanobis 损失与标准 rendered-depth 损失的对比留待未来。', '作者承认：LiDAR 覆盖不到相机可见处（航空 LiDAR），需用 SfM 点补齐，这部分不计入几何贡献。', '我在正文发现：几何评测定义为「解码后神经高斯均值」，与网格采样后报告的数字不可直接比较；recall 与 F1 随容量增长，跨方法比较须看 precision 与 Chamfer，作者自己也承认这点。', '我在正文发现：匹配容量下帧率反而下降（190 对 272 FPS），说明「更快」主要来自更少 anchor 而非渲染形式更高效；训练时间也更长（17:45 对 11:42）。']

## 与文献库的关系
直接建在 Scaffold-GS 之上（替换世界轴 offset、加支撑损失、关闭 per-image appearance embedding），与 Octree-GS/VastGaussian/CityGaussian 的「离散分区换扩展性」路线相对；与 2DGS/SuGaR/CityGaussianV2 的「训练期几何正则」路线并行；与 LI-GS、GS-SDF、ARSGaussian、Gaussian-LIC、GS-LIVO 等 LiDAR 监督路线相比，差别在于支撑结构本身由实测几何给出，而不是在自由基元上加约束。

## 可复现性（代码/数据/硬件）
高。代码 https://github.com/k-harikumar/PLS-GS ，数据为公开 GauU-Scene V2，超参在正文与补充材料给全（K=8、叶层 7、协方差正则 1e-4、χ² 0.99 门限、λ_s=1e-3、k=10、30k 迭代、单张 24 GB GPU）。作者指出 LI-GS 与 ARSGaussian 当时无公开实现，故未直接对比。

## 行动建议
先对照 Table 1 与 Table 2，区分「容量带来的 recall」与「放置带来的 precision」；再看 §6.3 中「表面坐标系单独无效、配支撑损失才有效」这一条，这是方法成立的关键。风险：几何指标不能跨论文比较、PSNR 落后 1 dB 以上、匹配容量下反而更慢。
