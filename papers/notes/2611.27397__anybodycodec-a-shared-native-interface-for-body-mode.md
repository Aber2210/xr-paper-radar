# AnyBodyCodec：用于人体模型转换、扩展与人形控制的共享原生接口

## 一句话结论
把「原生格式转换」当作学习共享运动表示的手段，把几何保真与冻结策略下的动作一致性拆开评估：九条转换路径统一 MPJPE 16.801 mm、单帧 7.43 ms（官方工具的 5.6–6.5 倍），三格式全动作成功率 60.78%。

## 要解决的问题
MHR、SMPL-X、SOMA 等参数化人体模型暴露互不兼容的姿态与形状控制，使转换工具与人形策略输入被绑定到特定格式，换感知前端就得重训策略。

## 方法详解
为每个模型配原生编码器，把 root-local 控制映射到 8×64 对齐 slot，由两层 Transformer 与 LayerNorm 产生共享潜表示，目标查询与原生头解码回目标格式，世界位姿用固定尺度 Kabsch 恢复。训练配几何损失、形状与局部姿态辅助损失、slot 余弦一致与有序 slot 匹配。新模型 ANNY 只在冻结主干外训练接口；下游把冻结 slot 当运动指令接 SONIC 式 PPO 控制器。

## 实验与结果
- input-reference MPJPE = 16.801 mm（1.090M 参数，覆盖九条路径）
- 2.887M Transformer bank = 16.390 mm；同参数 1.090M 版本 = 18.866 mm
- 单帧延迟 = 7.43–7.67 ms（官方工具 41.8–49.4 ms，5.59–6.49×）
- 三格式全动作成功率 = 60.78%（关节坐标 57.45%，无配对 slot 56.98%）
- 160 小时训练验证成功率 = 66.10%（SONIC 62.59%）
- ANNY 扩展动作偏差 = 0.472（未对齐父模型 5.130，低 90.8%）

## 创新点与贡献
- 把「原生格式转换」当作学习共享运动表示的手段，并把几何保真与冻结策略下的动作一致性拆开评估

## 局限与风险
- 转换精度只对齐到成对拟合输入而非独立测量真值
- 真机部署仅定性，未给端到端延迟与任务成功率
