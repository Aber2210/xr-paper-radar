# 事件相机结构光的投影仪时间图校准

## 一句话结论
时间图既不假设理想光栅也不再依赖另设标定平面，而是直接从被测录制中与时钟/几何自标定一并解出：拟合残差 5.07 μs、墙面重建 3.07 mm rms（理想光栅假设 8.88 mm）。

## 要解决的问题
事件相机加激光扫描投影仪的结构光常用两个理想假设求稠密对应：投影仪按平行光栅扫描、传感器逐像素独立打时间戳。实际谐振扫描镜使扫描线呈扇形且逐行反向，高分辨率事件传感器按行读出使同一时间戳对应一段扫描线，两者都让对应与深度系统性出错。

## 方法详解
用时间编码（3×3 方点、16-bit ID 加 CRC、64 块移相）直接标识投影仪像素，因此无需任何先验标定即可得到投影仪-相机对应。把投影仪时间图作为投影仪图像上的光滑图显式标定（三次模型），并用一次录制数秒前导的时空自标定同时恢复系统几何与相机/投影仪时钟偏移。

## 实验与结果
- 实际扫描相对理想光栅偏差 = 最大 457 μs
- 时间图拟合残差 = 5.07 μs rms
- 自标定重复性 = 相对旋转 0.11°，主平面法向 0.08°，|t|/d 1.0%
- 球体参考误差 = 1.39 mm rms（理想光栅 1.72 mm）
- 墙面重建 = 3.07 mm rms（理想光栅 8.88 mm）
- 同步残差 = 6.83 μs 标准差（95 分位 16 μs）
