# TTB：面向 decoder-only 视角合成模型的测试时烘焙加速渲染

## 一句话结论
TTB 把 TTT 快速权重的内循环目标由「复现值 token」改为「拟合 cross-view attention 输出」，在 DL3DV 64 视角 960p 下以 30.20 dB PSNR、23 FPS 渲染，对照 DVSM 的 31.11 dB 但仅 1 FPS（60 s），实现最高 23× 加速；启用 local-duplicate 后达 31.33 dB，与 DVSM 持平。

## 要解决的问题
Decoder-only 大型视角合成模型（LVSM/DVSM）用 KV-cache 作全局场景状态，质量最好，但每个 novel-view token 都要对 KV 做线性注意力，视角一多渲染即不可用：DL3DV 64 视角下 DVSM 仅 1 FPS。LaCT 用 TTT 层替换 cross-view attention，渲染降到 O(1)，代价是质量明显下降，即使从 DVSM 权重微调差距仍在。作者指出现有解释只把 TTT 当作线性注意力近似，未分析质量损失来源，也未意识到 context prefilling（图像加位姿）与 novel-view rendering（仅位姿）的模态错配，使烘焙出的 fast-weight MLP 需在两种分布间泛化。缺口：如何在保持 O(1) 渲染的同时，把 cross-view attention 的全局场景信息尽量无损写进固定容量 MLP。

## 方法详解
沿用 DVSM 的 L 个重复块（IntraAttn、FFN、CrossAttn、FFN，式3），context 视图在每层 CrossAttn 预填 KV-cache，novel view 查询该 cache。输入用 Plücker ray 嵌入，context token 含位姿与 RGB，novel token 仅位姿（式4）。核心是把 TTT 的内循环目标换掉：TTT 为 θ←θ−η∇L(f_θ(W_k X), W_v X)（式6a），TTB 为 θ←θ−η∇L(f_θ(W_k X), g(X*))（式6b），取 g=CrossAttn，让 MLP 拟合注意力输出、与注意力协作而非取代。为消除模态错配，把每个 context 视图拆成 X⁰(ctx-gt)=LN(PE_ray+PE_rgb) 作映射目标、X⁰(ctx-rend)=LN(PE_ray) 作 TTB 输入（式7）；烘焙后的 MLP 共享给两路并回馈 ctx-gt。层内用单头 SwiGLU-MLP（隐维 3072）、per-token 学习率 0.01、Muon 加 weight normalization，T=3 步，损失为残差 MSE：θ_{t+1}=θ_t−Muon(∇‖f_θ(W_k X^{ctx-rend})−W_v(CrossAttn(X^{ctx-gt})−X^{ctx-rend})‖₂)（式8）。容量饱和用推理期 local-duplicate：按位姿 k-means 分 K=V/B 组（B=16），每组独立烘焙，novel view 路由到最近质心，渲染仍 O(1)。

## 实验与结果
- DL3DV-10K（140 个 held-out 测试场景，960p）：16/32/64 视角下 Ours 为 27.00/28.92/30.20 dB，对应 DVSM 26.86/29.13/31.11 dB、LaCT 24.70/26.90/28.30 dB；渲染恒为 23 FPS，DVSM 为 4/2/1 FPS。
- Re10K 两视角 512×512：Ours 31.28/0.926/0.127（PSNR/SSIM/LPIPS），DVSM 31.17/0.924/0.129，Decoder-only LVSM 29.53/0.904/0.141，Efficient-LVSM 29.86/0.905/0.147。
- In-the-wild 64 视角 960p：MipNeRF360/Free/Hike 上 Ours(duplicate) 为 25.05/26.82/25.37 dB，DVSM 为 24.76/25.57/23.10 dB，均为 65 s 重建、23 FPS 对 1 FPS；对 LagerNVS 质量大幅领先且渲染快 3.1–9.5×。
- 结构消融（表 4，DL3DV，V=32）：纯 TTT 替换 23.12 dB → 加 context pairing 23.78 → 加 MSE 与 T=3 为 24.22 → 目标换成 cross-view attention 24.84 dB；重建时间 0.439→1.998 s，渲染维持约 50 FPS。
- 内循环消融（表 5）：TTT 的 dot-product 损失 23.12 → TTB– 改 MSE 提升 +0.44 dB（TTT 只 +0.27）；T 从 1 增到 5 单调但递减，取 T=3 为折中。
- 层设计消融（表 6）：feedback 与 residual 各自贡献约 +0.43/+0.44 dB，合并 +0.52 dB（24.32→24.84）。
- 训练配置：768 通道、12 个 decoder block、patch 8，从 DVSM checkpoint 初始化，DL3DV-10K 上 64 张 A100，340p 训 100K iter 后依次在 480p/720p/960p 各微调 10K iter，感知损失权重 λ=0.2。

## 创新点与贡献
- 把 TTT 的 fast-weight 内循环目标从 value token 改为 cross-view attention 输出，使 MLP 与注意力协作而非替换，渲染复杂度仍为 O(1)。
- 发现并显式解决 context prefilling 与 novel-view rendering 的模态错配，用 ctx-gt 与 ctx-rend 成对 token 让映射两端同分布。
- 将烘焙内循环解释为潜空间光场优化，由此推出多步 MSE 加残差学习的收敛式配方。
- 推理期 local-duplicate（k-means 分组加最近质心路由）在保持 O(1) 渲染的同时缓解固定容量饱和。

## 局限与风险
- （作者承认）fast-weight MLP 容量固定，V 增大后质量饱和；local-duplicate 路由是启发式，训练期学习留作未来工作。
- （作者承认）内循环中的 cross-view attention 使重建复杂度随 V 二次增长，单次或少次重建场景不划算。
- （作者承认）方法基于重建而非生成，只在 context 视角之间插值，不能外推到未观测视角。
- （我在正文发现）表 1 中 32/64 视角 PSNR 仍低于 DVSM（28.92 对 29.13；30.20 对 31.11），「持平」主要靠 16 视角与 duplicate 变体；且 64 视角重建耗时 65 s 反高于 DVSM 的 60 s。
- （我在正文发现）23 FPS 与消融中约 50 FPS 出自不同设置（patch 8 与 patch 16），正文未在同一表内统一硬件与分辨率口径。

## 与文献库的关系
论文把自身放在 geometry-free 前馈视角合成线上：起点是 LVSM（ICLR'25）的 decoder-only 变体（效率低），DVSM 用 KV-cache 预填一次成为质量与效率上限，但 KV 随 token 线性增长；LaCT（ICLR'26）用 TTT 层替换 cross-view attention 把渲染做到常数复杂度，代价是质量，而 TTT 的 KV-binding 变体已被指出等价于线性注意力，这正是本文要突破的解释框架——TTB 把内循环目标改成注意力输出，因此不再是线性注意力特例。相关工作还包括 LongLRM 与 LongLRM++（输出规模随视角增长）、tttLRM、Efficient-LVSM，以及 TTT3R、ZipMap、ViT³ 等把 TTT 用于 3D 的尝试；作者还把内循环对应到经典光场与隐式辐射场重建。
