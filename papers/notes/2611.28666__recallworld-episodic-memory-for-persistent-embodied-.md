# RecallWorld：面向持久具身视频世界模型的情节记忆

## 一句话结论
把「记忆粒度」本身当设计变量：以段为单位联合重建、跨段几何隔离，再用覆盖度检索 + 几何可见性解析压进固定条件预算，部分重访 PSNR +2.6 dB、完整回环 +3.9 dB，LPIPS 降 43.2%/46.3%。

## 要解决的问题
具身探索要求世界模型在观察离开近期上下文后仍记得某地的几何与外观，智能体可能从新方向回到同一地点。相机可控生成器只保证局部连贯，不保证重访一致；记忆类方法会检索旧视图或投影已存三维内容，但「记忆应以什么粒度 consolidated」没有答案：逐视图独立重建丢弃近邻约束，反复重建整段历史又会让后来生成的内容改写早期几何，且条件长度随历史增长。

## 方法详解
在 SANA-WM 主干上挂一个 ControlNet 式空间条件分支，按相机轨迹分块自回归生成：$\hat{\mathbf{V}}_k=\mathcal{F}_{\theta,\phi}(\mathbf{I}^{init}_k,\mathcal{Q}_k;\mathbf{C}_k)$，下一段起点取上一段末帧。相机感知射线提升把透视与原生鱼眼（Kannala–Brandt）像素沿校准射线用径向距离 $\rho_i(\mathbf{x})$ 抬到共享世界系 $\mathbf{X}_i(\mathbf{x})=\mathbf{R}_i[\rho_i\mathbf{r}_i]+\mathbf{t}_i$，保留透视视场外表面。每完成一段，取 5 个均匀关键帧用 π³X 联合重建为一个 Scenelet，Scenelet 一旦写入即固定，跨 episode 几何独立，避免后续误差回写。条件构造分两步：先做覆盖度贪心检索，按「相对当前已选集合新增覆盖的目标格数」选最多 K=4 个 Scenelet（集合覆盖为单调子模，贪心有 $1-1/e$ 保证）；再做可见性解析，按目标相机深度取 $D_{min}(p)$，仅保留 $D_g(p)\le(1+\delta)D_{min}(p)$ 的投影，按有效外观加权融合 $\mathbf{C}(p)=\sum w_g\mathbf{A}_g/\sum w_g$，无有效外观处置零。训练只优化复制的空间条件块，用条件流匹配损失；另用 $L_1$+LPIPS 微调解码器提升重建保真度。

## 实验与结果
- 部分重访 PSNR 比最强基线高 2.6 dB，完整回环高 3.9 dB；LPIPS 分别降低 43.2% 与 46.3%（GrandTour、M2DGR、TartanGround、DL3DV）
- 记忆组织消融（GrandTour）：独立视图 16.41/16.27 dB，全局记忆 17.02/17.80 dB，无可见性解析的 Scenelet 20.72/20.27 dB，完整模型 20.82/20.84 dB（部分/完整重访）
- Scenelet 相对全局记忆提升 3.7 dB（部分重访）与 2.5 dB（完整回环）
- 完整模型相对独立视图记忆降低 LPIPS 11.8%（部分）与 7.1%（完整）
- Scenelet 使峰值重建内存相对全局重建降低 19.7%
- 导航子集上超过 NWM 全部四项指标，SRC 从 0.554 提到 0.880
- 64 秒 GrandTour 回环、K=4 固定预算下，互补检索在最长历史处 LPIPS 低于「最近选择」

## 创新点与贡献
- 把「记忆粒度」本身作为设计变量：以段为单位联合重建、跨段几何隔离，再用覆盖度检索+几何可见性解析把历史压进固定条件预算
- 相比只扩大上下文或检索最近帧的方法，它同时避免「独立视图丢约束」与「全局重建被后验改写」

## 局限与风险
- 作者承认长程自回归会累积预测误差，需要不确定性感知的 consolidations 与跨 episode 校验
- Scenelet 是静态的，无法建模移动物体、光照变化
- 鱼眼仅用于记忆输入，尚未原生生成鱼眼视图
- 从正文看，所有 Scenelet 都由生成帧重建（仅首段来自真实观测），生成误差仍会进入记忆
