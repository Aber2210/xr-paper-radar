# ReferClaw：以澄清提问消解用户意图的第一视角流式助手

## 一句话结论
三智能体显式表示时空 grounded 候选并按信息增益-成本提问：BuddyVQA 上 Full 答案准确率 74.3%，超 Clarify-or-Answer（58.5%）15.8 点，提问率仅 18.6%、每问 20.6 token、人类 5.1 s 作答；零样本迁移与学习闭环均有效。

## 要解决的问题
第一视角助手的用户问题短且 ego-deictic，视频与对话历史常同时支持多个所指（同一物体两次遭遇、同类物体不同时刻出现），现有 VideoQA 直接锁定单一解释，答案可能与视频兼容却不符合用户真实意图。已有澄清方法多基于图像与单次观测，难以处理视频流中的时空竞争解释；同时必须限制提问轮数、长度与选项数，避免无尽澄清和一次性超级问题压倒用户。需要把是否问、问什么、答什么统一到有界信息获取框架下。

## 方法详解
三 agent 共享 grounded 候选（问题改写+时间区间+box track）与后验信念：IGA 基于 GroundVQA 时序提议、Grounding DINO 1.5 Pro 检测与 SAM 2 传播生成≤8 张证据卡，合并后保留≤4 个候选，按支持度初始化信念并预留未覆盖质量 z∅；CCA 提议≤6 个对比性问题，用 Qwen3.5-9B 预测 respondent（每对 8 次采样）估计回答类别分布，以期望信息增益（Shannon 熵下降）减成本（努力/时延/失败率加权）选问题；EFA 从选中证据生成答案并经 verifier 校验（区分 video/user 声明，允许一次修订）。controller 限制 Tmax=2 轮、Lmax=24 token、Mmax=4 选项。学习用 MetaClaw 双循环：快循环把已验证失败蒸馏为 intent-specific skill（触发-拓扑-决定性对比，BGE-M3 top-3 注入）；慢循环以过程奖励 R_proc（含目标进展 Δ*）经 GRPO 只更新责任 agent 的 LoRA，promotion 需过验证探针。

## 实验与结果
BuddyVQA 6,240 题（1,197 歧义题）。Frozen Base 66.2% vs Clarify-or-Answer 58.5%；关提问回放 60.5%（净增益 5.7 点）；Full 74.3%、Skills 70.1%，优于 Reflexion 式记忆 67.4% 与 MetaClaw 式 69.5%；Acc@GQA 41.8%。零样本迁 EgoBlind：答案 60.7%、GQA 31.6%，较 EG-Reasoner 高 5.9/4.0 点。ClearVQA 41.5→48.1%、ContextClarify 42.9→54.8%。时间分离歧义增益最大（G2 +19.1、G3 +16.1）；paired-intent 71.3%（基线 38.8）。10 人用户研究：intent resolved 80.0%、答案 72.0%；复发率 34.2%→10.7%。

## 创新点与贡献
['把第一视角意图消歧形式化为时空 grounded 候选上的有界信息获取问题（含效用函数与交互预算约束）。', '三 agent（IGA/CCA/EFA）+ 确定性 controller 的协同架构，共享候选同时驱动提问选择与证据选择。', '成本感知对比提问：IG−λC 净效用，配人类响应模型校准（Brier 0.31→0.22）与响应时间回归（R²=0.61）。', 'intent-specific skills 与 agent-attributed process reward 双循环学习，失败复发率 34.2%→10.7%。', '增强 BuddyVQA/EgoBlind 的歧义、目标意图、证据区间/框标注及 paired-intent 测试集。']

## 局限与风险
作者自述与数据：标注目标意图为回溯指定，结果应读作相对标注意图的准确率；500 例错误审计显示 31% 严重遮挡/运动模糊、23% 前缀信息缺失，残差失败主要在感知而非澄清回路；G5（目标不在提议内）仍最弱；模拟 respondent 比人类乐观 0.8–1.7 点；用户研究仅 N=10；系统为研究原型，不应用于安全关键辅助；代码与标注承诺接收后发布。
