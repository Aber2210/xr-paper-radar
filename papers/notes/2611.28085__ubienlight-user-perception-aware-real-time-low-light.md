# UbiEnlight：面向手机与智能眼镜的用户感知感知实时低光视频增强

## 一句话结论
用「幅度管光照、相位锚结构」的频谱先验替代光流式时序约束，并把去噪步数与注意力复用交给用户感知容差驱动的运行时控制器：SDSD-indoor TSSIM 0.86（次优 0.81）、0.07 s/帧，已在 Pixel 7 / Jetson Orin / Xiaomi 17 Ultra / XREAL 上部署。

## 要解决的问题
手机与可穿戴设备低光拍摄时，动态光照与用户运动耦合，产生噪声、运动模糊与闪烁；先逐帧复原再补时序约束的“事后一致性”会残留闪烁与运动伪影；图像式扩散增强逐帧处理会闪，视频生成式扩散偏向合理性且可能漂移或幻觉结构；端侧算力与能耗又严格限制扩散步数与模型规模。

## 方法详解
频域解耦是核心：对亮度代理 $Y=\psi(x)$ 做 2D FFT 得幅度 $\mathbf{A}_{in}$ 与相位 $\mathbf{P}_{in}$，Spectrum Prior Network（4 个 Fourier Processing block，FFT–处理–IFFT，幅度/相位分支各用 1×1 卷积、3×3 卷积回空间域并加残差）预测空间变化幅度变换图 $\mathbf{M}$（sigmoid 约束到 $(0,1)$），按 $\mathbf{A}_{out}=\mathbf{A}_{in}\odot\frac{1}{\mathbf{M}+\varepsilon}$ 调制幅度、保持相位，逆变换得结构保真的 $Y^{(s1)}$，并以 $\mathcal{L}_{freq}=\||\mathcal{F}(Y^{(s1)})|-|\mathcal{F}(Y_{gt})|\|_2^2$ 监督；$\mathbf{M}$ 与 $\mathbf{P}_{in}$ 经投影器变成条件 token $c$。第二阶段在潜空间用 DiT 式时空 Transformer 去噪（空间自注意力 + 时间自注意力 + 频谱引导条件注入），潜编码降分辨率 4–8×。三个稳定机制处理传播不稳、采样随机与长程漂移，其中频谱门控时间复用用相位（稳定）与幅度（随光照变化）差异调节复用强度。系统层做层次化复用与跳帧、关键帧缓存、注意力复用、运行时开销 profiler 与资源感知控制器，按用户感知容差在运行时调整去噪步数预算。

## 实验与结果
- SDSD-indoor：TSSIM 0.86（最高，次优 0.81）、SSIM 0.75（最高）、PSNR 16.22、0.07 s/帧
- DRV：PSNR 19.34、SSIM 0.67、0.06 s/帧
- 相对 FourierDiff 快 >20×、相对 SDSDNet 快 >25×（DRV）
- 相对 Zero-DCE++ 在 DRV 上 PSNR +4.87，时延相当
- 动态/极端光照与运动条件下时序稳定性最高提升 54.76%
- 消融：去频谱先验 NIQE 9.214/8.736、TSSIM 0.621/0.772；去第二阶段 DiT NIQE 5.278/4.271、TSSIM 0.648/0.899；完整 TSSIM 0.762/0.953
- 用户调查 53 人（21–68 岁）：71.7% 认为闪烁比轻微帧瑕疵更难接受，96.2% 接受 <100 ms 延迟，79.2% 偏好端侧处理
- 20 人模式对比：Adaptive $U_{pref}=3.92$ vs Fixed HQ 3.37 / Fixed LC 2.96，偏好率 65.0%，UVE 提升 61.3%/32.7%

## 创新点与贡献
- 用“幅度管光照、相位锚结构”的频谱先验替代光流式时序约束，把低光视频的时序稳定问题转成频域条件问题
- 并把去噪步数、注意力复用与帧缓存交给用户感知容差驱动的运行时控制器，在手机与 AR 眼镜上同时取得稳定性与实时性

## 局限与风险
- 正文未单列 limitation 节，但从结果看：PSNR 明显低于全监督视频方法（16.22 vs SDSDNet 21.26），卖点在 SSIM/TSSIM
- 评测分辨率 270×480、20 FPS，未覆盖高分辨率
- XREAL 走“帧串流到配对手机再回显”方案，端到端时延未单独报告
- 20 人模式对比为描述性统计，未做检验效能分析
