# Anchor3DGS：紧凑锚基表示的前馈 3D 高斯泼溅（免位姿）

## 一句话结论

把前馈 3DGS 从「逐像素预测一个高斯」改为「信息熵引导放置 3D 锚点 + 遮挡感知多视角聚合 + 锚点解码为局部高斯」：稀疏视角（3/6 视图）在 VR-NeRF/MipNeRF360/DL3DV 上全面最优（MipNeRF360 与 DL3DV PSNR +2 dB 以上），且每场景仅需 0.26M 高斯（比像素对齐少一个数量级），还免输入位姿。

## 要解决的问题

已有前馈 3DGS 采用像素对齐范式：每个输入像素预测一个高斯，导致（1）高斯数量与输入分辨率/视图数耦合；（2）无纹理区域产生冗余高斯、几何复杂区域覆盖不足；（3）多数方法依赖已知相机位姿。如何让前馈预测的表示规模由场景内容而非输入规模决定，是核心问题。

## 方法详解

1. **免位姿几何初始化（pose-free geometry initialization）**：不依赖输入位姿，先构建几何感知的场景脚手架（scaffold）。
2. **熵引导锚点采样（entropy-guided anchor sampling）**：按视觉信息熵在场景中放置一组 3D 锚点——高复杂度区域多放、简单区域少放，同时保持广泛空间覆盖。
3. **遮挡感知多视角锚点聚合（occlusion-aware multi-view anchor aggregation）**：每个锚点从多视角聚合图像特征（考虑遮挡关系），并通过锚点间自注意力把上下文传播到观测不足的区域，缓解像素对齐方法的「空洞」。
4. **锚点到高斯的解码与渲染**：每个锚点解码为一组局部高斯，表示规模由锚点预算控制，与输入视图数解耦。

## 实验与结果

- **稀疏视角（3/6 输入视图）**：VR-NeRF、MipNeRF360、DL3DV 三个基准上 PSNR/SSIM/LPIPS 全面最佳；MipNeRF360 与 DL3DV 上较最佳基线 PSNR 提升 **2 dB 以上**；每场景仅 **0.26M** 高斯。
- **稠密视角（32 输入视图）**：与 SOTA 像素对齐基线质量相当，但高斯数少一个数量级、存储足迹更小；#GS 不随视图数增长（恒 0.26M），而像素对齐方法产出数百万高斯且无对应质量增益。
- **效率**：VGGT+3DGS 每场景需数分钟优化，Anchor3DGS 单次前向直接预测（附录含渲染速度分析）。

## 创新点与贡献

1. 前馈 3DGS 的表示范式转移：从像素对齐到「内容决定的锚点表示」，高斯数量与输入规模解耦。
2. 熵引导放置 + 遮挡感知聚合 + 锚点间自注意力的组合，直接针对无纹理冗余与观测空洞两个失效模式。
3. 免位姿 + 紧凑（0.26M）+ 前馈三者兼得。

## 局限与风险

- 稀疏视角增益大，但 32 视图稠密设定下仅为「质量相当 + 更紧凑」，颠覆性有限。
- 0.26M 高斯的紧凑性以锚点预算为上界，极复杂场景的保真度上限待考。
- 与库内 PocketSplat（世界空间潜分配）/ Budgeted-GS（因式分解 LOD）未同基准对比，「紧凑前馈表示」家族内部优劣未定。

## 与文献库的关系

- **并列（新路线）**：与库内 PocketSplat（2610.03192，S 4.28，世界空间潜分配）和 Budgeted-GS（2610.03162，S 4.65，因式分解 LOD）共同构成「紧凑前馈 3DGS 表示」家族；Anchor3DGS 的区分点是锚点 + 熵引导 + 免位姿。另与 VoxelTTO（2609.21498，体素对齐前馈 3DGS + 测试时优化）在「前馈 + 紧凑」上相邻但机制不同。
- **取代**：无（门① max Jaccard 0.353 vs VoxelTTO，同族非取代）。
