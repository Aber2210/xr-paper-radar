# SpatialArena：几何基础模型究竟走到了哪一步

## 一句话结论
用同一套指标与同一套对齐规则同时评 5 个几何任务 × 52 个模型，把「对齐」从实现细节变成可测量的偏差来源（最高 2.6×），并以自采真实场景证明「公开集饱和但真实场景未饱和」：VGGT-Ω 总榜 87.4 / 平均排名 2.6 居首，π³-X 84.3 第二。

## 要解决的问题
3D 感知正从任务专用 pipeline 转向几何 foundation model（单目深度网络、前馈 3D/4D 重建、预测几何的 VLM），但其进展无法可靠度量。各论文自行采样帧、设定分辨率与测试划分，报告数字不可比；几乎所有模型只预测到未知尺度，评测必须经过对齐，而对齐本身的影响可能超过模型差距——在错误的深度空间做拟合会让 AbsRel 接近三倍，最小二乘拟合让强多视角模型的 AbsRel 升高 50% 以上，常用的相机中心闭式对齐会把失败方法的误差低估最多 2.6×。此外现有评测很少覆盖长序列、动态场景与航拍视角。

## 方法详解
提出统一 arena：5 个任务（MonoDepth、VideoDepth、MVRecon、SfM、SLAM）× 23 个公开数据集（418,929 张图像）+ 自采 Spatial Arena（30 个场景，手持 LiDAR 与三相机 rig，13 室内/17 室外，行走 18 m–1 km），共 34 个 task-dataset 对、456 个 evaluation case。把几何先验显式作为协议轴：rgb / rgbc（给 GT COLMAP 相机）/ rgbd（给 GT 深度），且只有先验不平凡泄露预测目标时才评测该 (task, track)。深度对齐改为在模型原生输出空间（深度或视差/逆深度）拟合、且像素域仅由 GT 决定（有限、落在有效范围、在 mask 内）：(a*,b*)=argmin Σ_i Σ_{p∈Ω_i} ρ_δ((a x̂_i(p)+b−x_i(p))/m)，ρ_δ 为 δ=0.05 的 Huber、m 为 GT 中位数，用 IRLS 从最小二乘解出发闭式迭代至收敛，避免学习率与预测尺度依赖。轨迹对齐改用 pose-aware 相似变换：E(S)=Σ_i w_i(‖r_i^R‖²/σ_R²+‖r_i^t‖²/σ_t²)，r_i^R=Log(R R̂_i^T R_i)、r_i^t=sR ĉ_i+t−c_i，用 LMedS-RANSAC 两帧最小样本初始化 + 全帧 Cauchy 权 IRLS 重拟合 + scale-collapse 回退。MVRecon 按下游用户方式把 Sim(3) 对齐后的深度与位姿做 TSDF 融合；SLAM 按输入长度分 short/long/large 三档（最长 18,846 帧），并新增严格指标 δ_1.03 与由对齐深度导出的法向角误差以区分已饱和的 δ_1.25。排名前先做数据泄漏审计，把模型训练过的数据集排除出总榜。

## 实验与结果
- 总榜第一 VGGT-Ω：Score 87.4、平均排名 AR 2.6、415 个计分单元中 1121 次单格第一，并在 MonoDepth、VideoDepth、SfM 三项第一；π³-X 84.3/AR 5.0 第二，DA3-G 77.2 第三
- MonoDepth 的 AbsRel 在公开数据上最好 4.03%，在 Spatial Arena 上最好 14.18%（逐模型中位比值 3.28，范围 1.29–4.23），而 GT 与 LiDAR 深度自身一致度为 3.6%
- VideoDepth 最好 AbsRel 从 DUSt3R 的 45% 降到 VGGT-Ω 的 6.5%，已优于最好的专用视频深度模型 GenCeption-Depth 的 14.0%
- MVRecon 最好 F-score 公开数据 0.628，Spatial Arena 上仅 0.197；七个排名数据集中有六个不同模型各拿最佳
- 严格指标 δ_1.03 最好仅 62%（δ_1.25 已达 96%），加入 Spatial Arena 后两者分别跌到 46% 与 87%
- 对齐敏感性：最小二乘深度拟合使 VGGT-Ω 与 DA3-G 的 AbsRel 升高 55–59%，深度空间拟合使 Lotus-D 近 3 倍；标准 Umeyama 轨迹对齐把失败方法误差低估最多 2.6×

## 创新点与贡献
- 首个用同一套指标、同一套对齐规则同时评 5 个几何任务与 52 个模型的开放 arena，把「对齐」从实现细节提升为可测量的偏差来源，并用受控实验量化其量级（最高 2.6×）
- 自采 Spatial Arena 补齐了公开集缺失的大尺度、非受控、含侧视滚转相机的真实场景，使「公开集饱和但真实场景未饱和」这一结论可被直接观测

## 局限与风险
- 不自带新模型，结论依赖被评模型的实现与作者对其接口的适配（如 VLM 通过 API 查询、部分模型只跑通 rgb track），跨家族比较仍可能受预处理差异影响
- Spatial Arena 的稠密深度来自 3DGS 渲染的伪标签，虽经 LiDAR 校验（98.3%/98.2% 在 ±25% 内），但在无 LiDAR 回波处（近相机浮空、反射、弱纹理）存在系统性盲区
- 评测成本高（商业 VLM 按 API 计费），且长序列与大尺度档位只有少数系统能跑完，覆盖率不均衡
