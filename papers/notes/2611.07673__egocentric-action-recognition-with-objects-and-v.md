# 物体与视觉语言可供性引导的第一视角动作识别

## 一句话结论
在 MECCANO 上把 frozen SlowFast 视频专家与注意力物体专家 late fusion，物体 token 融合 ViT 裁剪、DistilBERT 类名/位置与 VLM zero-shot affordance，并用同一 VLM 的 interaction affordance 在测试时滤除未被手操控的检测框。检测框设置下 Top-1 从视频专家 44.9% 升至 49.9%（Top-5 82.5%、macro-F1 24.1），超 SlowFast 与 G3Ego/HOCL+OSL；分析表明标注框到检测框的落差中 48% 来自非活动检测。

## 要解决的问题
第一视角动作很大程度上由所操控的物体定义（徒手 vs 用螺丝刀拧螺丝手势相似），但主流方法仅学整段 RGB/深度特征，不显式建模物体。已有少数物体方法把物体当额外监督或与 gaze 结合，不建模物体“能做什么”（affordance）。评测层面更被忽视：MECCANO 等数据集只标注参与动作的活动物体，用标注框测试等于告知模型哪些物体相关；而真实检测器会引入在场但不参与动作的物体，精度下降，现有工作很少量化这一落差及其成因，导致物体方法的实用性存疑。

## 方法详解
双专家结构：视频专家为冻结的 SlowFast R50 (8×8)（32 帧+3 个 256×256 空间 crop）。物体专家每段选 K=4 个“物体类别集合相对前一候选帧变化最大”的帧；每个物体 token x_i=[v_i;c_i;b_i;φ(a_i)]∈R^3072，由 ViT-B/16 [CLS] 裁剪特征、DistilBERT 编码的类名/归一化位置/affordance 文本四部分拼接（φ 为 768→768 的 Linear+LN+ReLU 投影），经 512 维投影、4 头 MHA 自注意力、平均池化与 MLP（512/256）出 logits，N=0 时用可学习 token；仅这些轻量模块与编码器可训练。VLM（Gemini 3.1 Flash-Lite，temperature 0）零样本承担两类查询：object affordance（输入类名+红框全图+裁剪，输出限定于数据集动词-物体词表的逗号分隔列表）与 interaction affordance（先描述手的位置，再回答 yes/no/unsure 是否被手持/触碰/操控）；过滤规则 D'_t={r(d)≠no}∪{argmax 检测分数}，unsure 保留，每帧至少保留最高分检测。最终预测为对数概率 late fusion：ŷ=argmax_k[α log p_v(k)+(1-α) log p_o(k)]，α 在验证集按 0.05 步长选取。训练全程只用标注框（检测器在训练视频上 AP 94.3 近饱和，无法教模型处理检测误差），测试才启用检测器与过滤器。

## 实验与结果
MECCANO（20 段组装玩具摩托车的 egocentric 视频，61 类=12 动词×20 物体，11/2/7 划分，5057/977/2820 段）。检测设置下 Video+objects+VLM 达 49.87±0.47 Top-1、82.54 Top-5、24.06 macro-F1：比 MECCANO 官方 SlowFast RGB 基线（45.16）高 4.7 点、比自研视频专家（44.93）高 4.9 点且 macro-F1 相对提升约 24%，优于 HOCL+OSL（44.81）与需 gaze 的 G3Ego（46.48）；UCF Swin3D-B Top-1 更高（50.8）但属不同骨干。标注框上界为 68.38。落差分解：非活动检测致 -9.2 点（占 48%）、漏检 -7.3 点（38%），理想过滤器可达 58.3。消融：affordance +0.50、interaction filter +0.50、合用 +0.84（95% CI 排除 0），affordance 输入以 text+frame+crop 最优（text-only 亦 +0.35）；测试集过滤器移除 12.1% 非活动与 3.7% 活动检测。融合策略对比中 late fusion（49.04）优于全部 learned fusion（最佳 48.31）；检测设置下各帧选择策略差异 <1.2 点。测试集共 53,748 次 VLM 查询（每段约 19 次、每次 2300-2400 token）。

## 创新点与贡献
['冻结视频专家 + 注意力物体专家的 late fusion 架构，物体 token 显式包含外观、类名、位置与 affordance', 'VLM 零样本生成 object affordance 文本作为物体表示，免训练注入语言知识', 'interaction affordance：同一 VLM 判定手是否操控该检测框，测试时过滤非活动检测', '定量分解标注框→检测框的 Top-1 落差（48% 源于非活动检测），推动以检测框评测物体方法']

## 局限与风险
增益幅度有限（合用仅 +0.84 点）；interaction filter 召回低（仅移除 12.1% 非活动检测），模糊帧会误删活动物体，最常见失败模式是对手边物体一律答 yes；仅验证 MECCANO 单数据集；依赖 Gemini VLM 离线批量查询（非在线部署），且检测器仅在含活动物体的候选帧上运行，与全视频部署有差距。
