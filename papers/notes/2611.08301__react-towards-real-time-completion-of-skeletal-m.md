# REACT：骨骼运动信号的实时补全（S4 多候选融合）

## 一句话结论
REACT 以 S4 骨干+Data/Phys/Ref 三路候选融合实时补全流式骨骼信号：最优变体 MPJPE 7.75 cm、AUJ 25.57，优于 GRU/RPM 基线；RTX 3090 上延迟约 22 ms，超 30 fps 但未达 60/90 Hz。

## 要解决的问题
交互式应用（VR/XR 中的流式动捕）中，骨架信号常因遮挡、标记丢失与旋转噪声而残缺，传统滤波器（1€ filter、卡尔曼）在缺失段只能外推，而学习式补全方法又常过度平滑、在掩码出现/消失的更新区间产生抖动，难以兼顾重建精度与更新稳定性。本文面向实时流式场景，解决骨骼运动信号的逐帧补全问题：在部分关节不可靠时检测并补全，同时保持交互级延迟与低抖动的更新 regime。

## 方法详解
据补充材料：REACT 维护多个持久状态与历史 buffer——预测 buffer（T=31 帧自回归上下文）、观测 buffer（原始含噪/缺失测量）、S4 长期上下文状态（复数域 C^{H×N}，H=256、N=32 modes）、defiance buffer（按关节的信任历史/迟滞，置信低则升否则降）与 rolling buffer（Tr=10，PCAF 类时序修正）；骨架 J=23 关节，旋转用 6D 表示（F=6）与展平旋转矩阵（Fr=9），帧率 Δt=1/60，MLP 多为低秩分解。骨干为 S4 连续状态空间模型（x˙=Ax+Bu, y=Cx+Du）：变体包括双并行 S4 层与 partitioned S4（2S4，共享 N/2 modes、每个输出头各私有 N/4，通过对 C_phys/C_data 的 mode 分量 zero-padding 实现，并可施加低频/高频初始谱偏置）。三个候选分支：Data 用长时程上下文回归未来序列，Phys 用 ODE 启发的参数化做反应式短期预测，Ref 为跳跃连接式精化；融合模块用学习门或静态门（静态门由误差信号能量 logits z_coarse、基于速度 EMA 的运动先验 b_filt 与小型可学习卷积 g_θ(E_n) 组成，经 softmax 归一化）加权合并。训练时数据增广模拟关节遮挡与旋转噪声，推理时网络逐帧预测关节可靠性概率并经 defiance buffer 非线性积分（不对称升/降以减少假阳性），再经 geodesic PCAF blending 用遮挡概率调节更新修正幅度。评测配置分两 buffer 输入（预测+观测）与单 buffer 输入两种。

## 实验与结果
补充材料报告：复杂度（RTX 3090、batch 1、序列长 31、FP32）显示 REACT-learned 1.05M 参数、延迟 21.65-22.98 ms、222 MB；REACT-learned-2S4 1.10M、21.94-23.71 ms；REACT-static 1.05M、22.55-24.12 ms；对比 RPM（6.75M、4.03-4.30 ms）与 GRU-ctx（0.38M、0.57-0.64 ms）——REACT 超过 30 fps，但达不到 60/90 Hz，且延迟相当部分来自非融合自定义 CUDA kernel。补全指标上 REACT 变体在姿态级重建一致优于基线、旋转误差提升最大；最优 REACT-learned-2S4-r 的 MPJPE 7.75±6.29 cm、P-MPJPE 5.87±4.20 cm、MPJLAE 12.21±6.56°、MPJAE 19.62±15.41°、MPJPVE 42.35±43.97 cm/s、MPJAVE 60.21±76.35 °/s，PJ 1.41±1.94、AUJ_T→S 25.57±5.69；RPM 在更新区间指标（AUJ 25.36/26.40）最有竞争力但 MPJPE 11.12±6.89 更差，体现重建-稳定性权衡；GRU 类基线帧级误差低但转换时抖动大（AUJ 约 105）。掩码严重度实验（训练/测试 M_max∈{25,50,75,100}%）显示 REACT 对训练-测试掩码范围失配的脆弱性更低。内部分析：遮挡下 Ref 分支胜出率从 0.60 降至 0.23、Phys 升主导，融合熵降低更果断；遮挡分类平衡准确率对根部关节接近随机、轴向中等、四肢关节高（0.83-0.97）；PCAF 混合权重遮挡时从 0.70 升至 0.75（更保守）。
