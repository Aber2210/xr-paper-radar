# 4D Reconstruction with Events & RGB（事件-RGB 融合的 4D 重建）

## 一句话结论
在 MonST3R 上增加轻量事件体素分支后，RGB+事件融合在 Sintel/Bonn/KITTI 三个基准上平均降低 Abs Rel 3.4%，且在高物体运动场景下 Log RMSE 额外降低 0.327，证明非侵入式事件融合即可提升 4D 重建鲁棒性。

## 要解决的问题
单目视频的 4D 重建在快速或非均匀的相机/物体运动下会受运动模糊和时间混叠影响，而现有前馈方法（MonST3R 等）仅使用 RGB 帧，继承了这些失效模式。事件相机以微秒级异步报告亮度变化，恰好能提供对模糊免疫的运动线索，但事件流能否无需大规模架构改造就融入 RGB 4D 重建管线仍是开放问题。本文初步研究这一问题。

## 方法详解
方法是对 MonST3R 的最小扩展：事件流 E(t,t+Δ)={e_i=(p_i,x_i,y_i,t_i)}（极性 p_i∈{-1,1}）按 Eq.(2) 累积为 B=5 个时间 bin 的体素网格 E_V(b,x,y)；两视图的 3 通道 RGB 与 5 通道事件体素拼接成 8 通道输入，经一个轻量单层卷积 adapter 投影到 3 通道以适配预训练 ViT 编码器，再经共享 Siamese ViT 与原版 MonST3R 解码器输出逐窗口 pointmap，其余架构不变。由于 Sintel/Bonn/KITTI/PointOdyssey 无原生事件数据，用 V2E 模拟器（先插帧提升时间分辨率、再模拟亮度变化生成事件）合成训练事件；训练沿用 MonST3R 配置，数据集为 PointOdyssey、TartanAir、Spring 加合成事件。

## 实验与结果
评测 Sintel、Bonn、KITTI、PointOdyssey；基线为 RGB（原始预训练权重）、RGB(HyperE2VID)（事件重建 RGB）、Ev.Vox.（仅事件体素重训）、RGB+Ev.Vox.（融合重训）。

相机位姿（Sintel，Table 1）：RGB ATE 0.108 / RPE-t 0.042 / RPE-r 0.732；RGB(HyperE2VID) 0.132 / 0.067 / 0.767；Ev.Vox. 0.154 / 0.076 / 0.532；RGB+Ev.Vox. 0.106 / 0.038 / 0.476（三项全优）。

视频深度（Table 2，Abs Rel↓ / δ<1.25↑）：Sintel RGB 0.345/56.2 → 融合 0.331/58.1；Bonn 0.065/96.3 → 0.064/96.4；KITTI 0.106/89.3 → 0.101/90.6。

敏感性分析（PointOdyssey 子集，Fig.3）：相机运动分 Low/Medium/High 三级，融合均降 Log RMSE；物体运动分 Low/High 两级，高物体运动下 Log RMSE 低 0.327，增益最大。

## 创新点与贡献
['首次将事件体素分支以最小改动接入 MonST3R：仅新增一个 8→3 通道卷积 adapter 与事件体素输入，无需其他架构改动。', '证明 RGB（空间信息）与事件（运动线索）互补：融合优于 RGB-only、事件转 RGB 翻译（HyperE2VID）与事件-only 三种变体。', '在变化的相机/物体运动下做敏感性分析，定位事件融合的最大增益区间为高物体运动场景。']

## 局限与风险
正文未设独立 Limitations 节（据 Discussion & Future Work 与实验设置推断）：①评测所用事件均由 V2E 模拟器合成而非真实事件相机采集，真实数据验证缺失；②融合仅为拼接，未建模 RGB 同步/事件异步的模态差异；③基于 MonST3R（已非最强前馈 4D 模型），结论向 VGGT/PAGE4D 等新骨干的泛化性未验证；④实验仅覆盖 Sintel/Bonn/KITTI/PointOdyssey 四个数据集，属初步研究。

## 与文献库的关系
在库内前馈 4D 重建（MonST3R 一脉）上做最小事件融合扩展（8→3 通道卷积 adapter+事件体素输入）；证明 RGB（空间信息）与事件（运动线索）互补：融合优于 RGB-only、事件转 RGB 翻译（HyperE2VID）与事件-only 三种变体；与库内事件相机里程计（DEVO/TLEIO）共享事件-运动互补思想。
