# GraftRay：路径追踪的物理一致网格插入高斯场景

## 一句话结论
在 FIPT 合成场景上，GraftRay 以 ΔPSNR 35.17、阴影 IoU 0.76（DiffusionRenderer 版；RGB↔X 版为 34.29/0.77）刷新 mesh 插入高斯场景的 SOTA，大幅超过 IRGS（28.40/0.50）与 EAG-PT（24.26/0.40）等基线，且单卡 RTX 3090 上每帧插入仅需 1.6 min（同采样量下 EAG-PT 约 12×）。

## 要解决的问题
将虚拟 mesh 物体插入 2D/3D 高斯泼溅（2DGS/3DGS）场景时，物体既要被场景光照正确照亮，又要向场景投射物理一致的阴影并贡献间接光。现有图像空间 harmonization 方法牺牲多视图一致性；环境图（environment map）方法无法显式表示窗户、灯具等近场面光源及其与几何的遮挡；联合 inverse rendering 引入超出插入所需的未知量，且 LDR 观测难以区分自发光体与高反表面。

## 方法详解
流程分四步。① 材质与法线估计：从高斯场景渲染 V 个虚拟视角，用内在图像扩散模型 RGB↔X（或 DiffusionRenderer）加 S 个随机种子预测 albedo/roughness/metallic/normal；按透射率定义可见表面深度 z（累积透射率首次低于 1/2 处），仅当 |r−z|/z<τ_z 时把预测反投影到该高斯；先对接受视图按种子平均，再跨种子取逐通道中值，得到场景级材质并在光照估计中固定不变。② 发射器初始化：用户用 SAM 在少数视图标记窗、灯等光源，反投影得 3D 点集，拟合单侧解析矩形 E_j（RANSAC 加权亮高斯定平面 + PCA 细化），贴墙发射器轴向对齐水平/垂直方向。③ 高斯场景路径追踪：每个高斯用 3σ 轴对齐包围盒表示，峰响应求交 t_i*=−p·q/‖q‖²、m_i²=‖p‖²−(p·q)²/‖q‖²，当 m_i²<9 时命中，有效不透明度 α_i=o_i·exp(−m_i²/2)；any-hit 以概率 α_i 随机接受（随机透明），首个被接受概率 w_i=α_i∏_{j∈F_i}(1−α_j)；阴影射线用独立 ray type 确定性累积透射率、低于 5×10⁻³ 终止；光传输遵循 Mitsuba 式路径积分，Cook–Torrance/GGX BRDF + 解析矩形上的 NEE + BSDF 采样经 MIS（power heuristic）组合，Russian roulette 终止。④ 发射器辐射度估计：几何与材质固定时 I(L)=Σ_j L_j B_j（B_j 为仅 E_j 单位辐射度的基图，渲染时剔除 E_j 附近薄板内亮高斯）；饱和通道（阈值 τ=0.98）只提供下界，目标函数对未裁剪观测直接拟合、对裁剪观测用单边惩罚 [τ−g(B^TL_c)]_+²，每通道解非负最小二乘（J 个未知数通常 <20，GPU 上 Levenberg–Marquardt 解 J×J 法方程）；最后差分合成 I_out=M·k·I_with+(1−M)·I_3dgs⊙clip(I_with/I_without,0,c)（c=3，k 为背景像素 I_3dgs/I_without 比值的中值以补偿曝光）。

## 实验与结果
数据集：4 个 FIPT 房间 + 2 个 NFINITE（合成，路径追踪 GT）、2 个 FIPT-Real + 5 个 ScanNet++（真实）、5 个 SpAItial 平台生成的 3DGS 场景；所有方法用相同物体、放置与灯光，每场景 3 个视角。有 GT 报 ΔPSNR/mask PSNR/阴影 IoU/阴影 RMSE，无 GT 报无参考 VQAScore ratio（LightHarmony3D）。

FIPT 合成场景主结果（Table 1）：
| 方法 | ΔPSNR↑ | Mask PSNR↑ | 阴影 IoU↑ | 阴影 RMSE↓ |
| Ours (DiffusionRenderer) | 35.17 | 29.14 | 0.76 | 0.08 |
| Ours (RGB↔X) | 34.29 | 28.49 | 0.77 | 0.07 |
| IRGS（最强基线） | 28.40 | 22.56 | 0.50 | 0.15 |
| EAG-PT | 24.26 | 21.19 | 0.40 | 0.29 |
| ComGS | 13.09 | 8.27 | 0.26 | 0.33 |

材料恢复（Fig. 5，FIPT 四房间平均）：Ours 对齐后 albedo 19.9 dB，EAG-PT 20.2 dB 但仅恢复 diffuse albedo；GS-IR/GI-GS 把阴影与窗光烘进 albedo，低 6–8 dB；GS-IR 全零 metallic 得分尚可，因仅约 1–6% 像素为金属。

效率（单卡 RTX 3090）：bedroom 重建 22 min；DiffusionRenderer 先验 1.5 h/seed；反投影 6 min；辐射度拟合 13.5 min；插入一帧 1024×576@256 spp 1.6 min（含两次路径追踪）；EAG-PT 在其 1024 spp 下 14.4 min/帧，等采样量约 12×。

消融（bedroom，Table 2；格式 ΔPSNR/Mask/IoU/RMSE）：完整 35.4/31.6/0.80/0.08；点光源 26.5/20.5/0.51/0.12；环境图 27.6/27.4/0.56/0.55（PT/3DGS）；反弹 1/2/3/4 次 ΔPSNR 25.7/30.8/32.9/34.0（4 次与完整追踪器差 1.4 dB 内）；GT 窗口几何 35.4/31.7/0.80/0.08；窗口尺寸 ×0.8/1.25/1.5 → 34.2/35.4/35.4；位移 5/10/20 cm → 35.4/35.1/34.3（IoU 均 0.80）；shadow only / one-way IoU 降至 0.58/0.00；emissive 3DGS IoU 0；灰 albedo mask PSNR 腰斩至 15.6；去掉差分合成 ΔPSNR 跌至 24.8。

## 局限与风险
正文 4.3 节明示两条主要局限：① 光源必须手动标记——用户需用 SAM 在一个或少数视图中框选窗户与灯具（只需近似 mask）；② 依赖先验信息——albedo、roughness、metallic 与法线来自 2D 估计器（RGB↔X 或 DiffusionRenderer），先验误差会传导到拟合灯光与插入效果。另实验中观察到 metallic 通道会溢到漫反射表面（Fig. 5），且真实/生成场景的无 GT 指标 VQAScore 几乎无法区分方法。

## 与文献库的关系
与库内高斯场景物体插入（IRGS/EAG-PT 一脉）及 inverse rendering 环境光估计同域；差异在扩展 OptiX 路径追踪器联合追踪随机透明高斯与插入 mesh（3σ AABB+峰响应求交），并把饱和像素视为删失观测、以路径追踪单位辐射度基图+非负最小二乘估计发射器强度，免传统联合优化。
