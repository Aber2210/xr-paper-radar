# Tri-DNO：面向 3D 人–物交互的三边扩散噪声优化

## 一句话结论
把 DNO 从文本条件 HOI 扩展到 TriDi 的三边多模态分布，在不重训、不加 guidance 的前提下直接优化初始噪声，并新增朝向损失针对「接触与穿透都满足但手背贴物」：GRAB 严格判定有效抓握 11%→41%，PEN-X（>15 mm 穿透）26.3%→12.3%。

## 要解决的问题
生成可信的 3D 人–物交互（HOI）对 AR/VR 与角色动画很重要，但手部抓握的几何一致性极难：轻微悬空、手指穿模或接触位置语义错误都会立刻破坏真实感。现有 TriDi 等多模态扩散模型能按人或物条件采样，却依赖 classifier-based guidance；guidance 强度过大会产生分布外抓握，过小则不满足物理约束，且不稳定、泛化差。直接物理优化能得到稳定抓握，但不顾语义（例如握杯底而非杯柄）；已有 DNO 工作又只面向文本条件的 HOI，不能用于 TriDi 这种可选模态的多模态采样。

## 方法详解
保持 TriDi 预训练权重不变，把采样器换成 DDIM 确定性 ODE，并优化初始噪声 $z_{HOI}$ 而非直接改姿态或加 guidance：$z_{HOI}^{*}=\arg\min_{z_{HOI}}\mathcal{L}_{\mathrm{Tri-DNO}}(\mathrm{ODESolver}(\mathrm{TriDi}(\cdot),z_{HOI},T_{HOI},\mathcal{C}_{\mathcal{O}}))$。优化目标由三项组成：掩码接触损失 $\mathcal{L}_{\mathrm{cont}}=\sum_j\phi_{\mathcal{I}j}d_j$，只在扩散场景认为应接触的人体顶点上惩罚其到最近物体点的距离；穿透损失 $\mathcal{L}_{\mathrm{pen}}=\frac{1}{|\mathcal{V}_{\mathcal{O}}|}\sum_i\max(0,s_i)$，其中 $s_i=-(v_{\mathcal{O}}^i-v_{\mathcal{M}}^{j_i^*})^{\top}n_{\mathcal{M}}^{j_i^*}$ 是物体点到最近手部顶点的有符号距离，仅惩罚进入手内的点；朝向损失针对手背与手指背两个区域，取 $\mathcal{L}_{\mathrm{ori},r}=\max(0,c_r-\tau)^2$、$\mathcal{L}_{\mathrm{ori}}=\max(\mathcal{L}_{\mathrm{ori,finger}},\mathcal{L}_{\mathrm{ori,back}})$，要求手背法向背离物体，专门排除「手背贴物体但不穿模」的伪有效抓握。总损失按 $\lambda_{\mathrm{cont}},\lambda_{\mathrm{pen}},\lambda_{\mathrm{ori}}$ 加权；每步对归一化梯度做下降并加小高斯扰动鼓励探索。用 characteristic function 决定哪些模态被采样、哪些作为条件，因此人姿、物体位姿、交互隐码的任意组合都可优化。

## 实验与结果
- GRAB 严格人工判定：有效抓握比例 11%→41%（论文表述为相对提升 370%）
- PEN-X（穿透深度 >15 mm 的场景比例）26.3%→12.3%
- 平均穿透深度 PEN 0.51→0.49，PEN-norm 3.55→2.96
- MPJPE 16.16→15.42 cm，MPJPE-PA 11.32→11.25
- 512 个场景生成约 16 s（RTX 5090），与 TriDi 推理时间相当
- 消融 MPJPE：仅接触 15.60 → 接触+穿透 15.46 → 完整 15.42
- 消融 COV：0.383 → 0.394 → 0.388；MMD：1.045 → 1.019 → 0.998
- 生成分布指标 1-NNA 0.847→0.881（越接近 0.5 越好，故生成多样性略降）

## 创新点与贡献
- 把 DNO 从文本条件 HOI 扩展到 TriDi 的三边多模态分布，在不重训、不加 guidance 的前提下直接优化初始噪声
- 新增的朝向损失针对「接触与穿透都已满足但手背贴物」的语义失败，是接触/穿透项之外的必要约束
- 由于改用 25 步 DDIM，迭代优化后总推理时间仍与基线相当

## 局限与风险
- 作者在补充材料承认细长物体（long and thin objects）是优化难点
- 方法一次只优化一只活跃手，未处理双手协同
- 有效性主要靠 80 个场景的人工严格判定，接触/穿透指标对细微手指偏差不敏感，生成分布指标甚至略变差（1-NNA 远离 0.5）
- 实验以物体位姿为条件，其他条件设置只在补充材料
- 无代码发布说明
