# GazeLens：注视驱动的自适应 token 缩减高效第一视角视频问答

## 一句话结论
GazeLens 编码前选帧+注视池化+问题门控，每帧仅 2 token；StreamGaze 准确率超全网格与削减基线，但 EgoExo 上固定帧采样更准。

## 要解决的问题
智能眼镜需小型 VLM 在有限算力内保留有用证据：冗余帧消耗视觉预算，激进空间压缩又丢弃相关细节；注视点出穿戴者焦点，但问题证据可能在注视之外的周边场景。已有 token 削减多在模型内部（FastV/PyramidDrop）或编码前（LLaMA-VID），注视引导工作（GazeLLM/Voila-A/GazeVLM）多在编码后选 token 或学注视条件表示，未在编码前选帧或按问题分配 token。GazeLens 要在编码前压到含信息帧，并在每帧 2 token 预算内平衡聚焦与上下文证据。

## 方法详解（含关键公式/架构，保留原文术语）
三段式框架，每帧输出 2 个视觉 token：① 动态帧选择（编码前）——用 HOG 帧间转换与图像清晰度线索过滤连续视频流，丢弃小变化与模糊帧，得到动态输入序列 V，减少编码前的时序冗余；② 注视感知聚合——每帧编码为空间特征，结合注视点 (x_t,y_t) 经 Gaussian pooling 生成聚焦 token g_t、非聚焦 token c_t 与全局 token m_t；③ 问题条件语义门控——问题 token 嵌入均值池化并 L2 归一化为 t，经两层 MLP 将聚焦/非聚焦摘要按问题相关性融合为主 token，连同全局场景 token 保留聚焦与上下文证据。训练目标自适应。backbone 为 SmolVLM2-256M/500M（表内另列 Mobile-VideoGPT 对照）。

## 实验与结果（表格化关键数字）
在 StreamGaze（Combined/Ego4D/EgoExo）上对比帧选择器与模型前向计算量，并迁移至 EgoGazeVQA。Combined：Uniform T16 15.72 帧/56.84，T7 58.10、T8 58.02，GazeLens 选择器 5.74 帧/57.71；Ego4D：T16 51.30，GazeLens 5.83 帧/52.17 最高；EgoExo：T16 61.48，GazeLens 5.67 帧/62.35，但 T7/T8 63.23 更准。选择器在两来源均超 Uniform T16 且平均 <6 帧。SmolVLM2 三 seed Macro 均值：256M 0.509±0.017、500M 0.539±0.015，Past 方差最大。作者称准确率与 FLOPs 优于所评 token 削减基线（FLOPs 数值 digest 未含）。

## 创新点与贡献
- 把 token 削减前移到视觉编码之前：HOG 转换+清晰度动态选帧，避免编码冗余帧的计算
- 注视感知聚焦/互补池化加全局场景 token，每帧仅 2 token 平衡注视内外证据
- 问题条件门控按问答相关性混合聚焦与非聚焦摘要
- 在 SmolVLM2-256M/500M 小 backbone 上验证，平均 <6 帧即超 Uniform T16

## 局限与风险
- EgoExo 上固定 T7/T8（63.23）仍高于 GazeLens 选择器（62.35），帧选择收益依赖数据源
- Past 类问题跨 seed 方差最大（256M SD 0.053），小 backbone 稳定性有限
- digest 未含与 GazeLLM/Voila-A/GazeVLM 的定量对比（仅有能力覆盖表）
- 跨帧 token 复用尚未实现（作者列为 future work），长时序交互存在重复计算

## 与文献库的关系（新增 / 改进 / 取代 X）
属库内注视引导视觉理解线（GazeLLM/Voila-A/GazeVLM 为参照）：前者在编码后做 gaze token 选择或学注视条件表示，GazeLens 把削减前移到编码前（帧选择），并以问题条件门控分配注视内外 token，是该线的效率向分支。

## 可复现性（代码/数据/硬件）
digest 未提及代码链接；用公开 StreamGaze/EgoGazeVQA/Ego4D 数据集；backbone 为 SmolVLM2-256M/500M。

## 行动建议
在智能眼镜等算力受限设备上部署第一视角 VQA 时，采用「编码前选帧（HOG 转换+清晰度）+注视聚焦/互补池化+问题门控、每帧 2 token」的级联设计；在自有数据上验证选择器准确率，并注意 EgoExo 类来源上固定帧采样可能更准。
