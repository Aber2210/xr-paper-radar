# MaskedVGGT：掩码多视图 Transformer 是可扩展的 3D 学习器

## 一句话结论
把 3D 预训练分工为「图像表征完全交给冻结 2D 基础模型、自监督只学跨视图交互」，并在同等更新数与架构下证明无标注预训练 + 有监督微调能超过单阶段监督：S 规模 DL3DV 位姿 AUC@30° 54.23% vs 直接监督 VGGT-Ω 35.89%，1.144B 规模 ETH3D 49.26% vs 40.66%。

## 要解决的问题
多视图前馈模型随规模增长很强，但依赖昂贵的几何标注（相机位姿、深度），标注成了数据扩展的瓶颈。现有 3D 自监督要么做跨视图补全（CroCo、MuM、Muskie），要么做新视角合成（RayZer、E-RayZer），通常把图像表征与跨视图交互一起从零学；VGGT-Ω 自己也承认其自监督路线仍必须先有监督预训练模型。结果既浪费了 2D 基础模型的持续进步，也没证明「无标注预训练能独立撑起 3D」。

## 方法详解
冻结预训练 2D 编码器（DINOv3）逐图独立编码得 patch token $\mathcal{X}=\{E_{\phi}(I_i)\}$，只训练新加的多视图聚合器 $A_{\theta}$（VGGT-Ω 架构：帧内注意力与全局/register 注意力交替，含相机 token 与 register token）。预训练用掩码师生自蒸馏：教师 $A_{\theta_{\mathrm{teacher}}}$ 是学生的 EMA（$\theta_{\mathrm{teacher}}\leftarrow\mu_t\theta_{\mathrm{teacher}}+(1-\mu_t)\theta_{\mathrm{student}}$），吃完整 token；学生吃非对称掩码后的 $\mathcal{X}_{\mathrm{mask}}$——每路以概率 $p_a=0.2$ 整帧作为可见 anchor（每场景至少 1 个），其余视角以 $\rho=0.95$ 的比率把 patch 特征替换为可学习 mask token $e_m$。教师在掩码位置给出目标：取最后 $K=8$ 个 block 的特征做 LayerNorm 后平均 $y_{ip}=\frac1K\sum_{\ell=L-K+1}^{L}\mathrm{LN}(g^{\ell}_{ip})$ 以免高幅层主导；再按 CAPI 的做法在线聚类，用 $M$ 个原型 $C$ 打分 $u_{ip}=C\,y_{ip}/\|y_{ip}\|_2$，经 3 次 Sinkhorn–Knopp 得到平衡目标 $\hat{q}_{ip}$；该平衡在每个 patch 位置上跨视角归一，专门防止学生靠空间坐标走捷径。$\mathcal{L}_{\mathrm{cluster}}$ 只更新原型 $C$（教师特征与目标都 detach），学生在掩码位置用线性头 $W$ 预测簇分配并最小化 $\mathcal{L}_{\mathrm{pred}}=-\frac{1}{\max(1,|\mathcal{M}|)}\sum_{(i,p)\in\mathcal{M}}\hat{q}_{ip}^{\top}\log s_{ip}$，该损失更新学生聚合器、mask embedding 与预测头。预训练 60k 步只用 RGB，随后按 VGGT-Ω 的相机+深度监督微调 60k 步，总更新数与直接监督基线对齐，以保证比较公平。

## 实验与结果
- S 规模 DL3DV 位姿 AUC@30° 54.23% vs 直接监督 VGGT-Ω 35.89%，ETH3D 9.28% vs 4.15%
- L 规模（1.144B）DL3DV 92.56% vs 91.32%，ETH3D 49.26% vs 40.66%，TUM-Dynamic 58.83% vs 37.41%
- 同为自监督：E-RayZer 46.87%、Muskie 42.68%、RayDer 42.95%（DL3DV AUC@30°），均低于 54.23%
- 下游 9 项指标全胜：MegaDepth EPE 32.85 vs Muskie 33.65，ScanNet-1500 PCK@3 37.69%
- 消融预测目标：簇标签 77.33% vs DINO 特征 71.65% vs RGB 像素 58.09%
- 追加无标注视频：+RE10K 使 DL3DV AUC +7.94、TUM-Dynamic +7.75 个百分点

## 创新点与贡献
- 提出「分工」式 3D 预训练：图像表征完全交给冻结的 2D 基础模型，自监督信号只用来学跨视图交互
- 这与 CroCo/MuM（学编码器）、Muskie/E-RayZer（联合学）形成明确对照，并首次在同等更新数、同等架构下证明「无标注预训练 + 有监督微调」能超过单阶段监督训练，且该结论跨 4 种重建架构与 1B 参数成立

## 局限与风险
- 预训练仍要 16 张 A800 跑 20 天才能到 L 规模，成本高
- 收益随规模收窄（L 规模在 DL3DV 上仅 +1.24 个点，主要靠未见数据集拉开差距）
- 冻结编码器意味着上限被 2D 模型锁死（换弱编码器立刻掉到 22–25%），且对无视频先验的弱纹理/无序图像集不如视频预训练变体
