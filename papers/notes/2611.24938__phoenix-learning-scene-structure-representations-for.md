# Phoenix：为可泛化世界–动作模型学习场景结构表征

## 一句话结论
几何与时空双教师蒸馏 + 因果 CS-VAE 的场景结构表征，LIBERO-Plus 94.8%、RoboTwin 2.0 C2R 72.4%，跨具身迁移优于 InternW0-Δ。

## 要解决的问题
世界–动作模型（WAM）要联合预测未来观测与机器人动作，把环境建模与控制连起来，因此视觉表征同时决定“观测怎么编码”和“模型预测什么”。但主流做法用面向重建的视频 VAE 潜空间：重建保真度高并不保证潜变量抓住操作所需的空间组织、物体状态变化及其与动作的因果联系，已有受控比较也显示重建保真度不能决定规划质量。另一方面，视觉基础模型（DINOv3、VGGT、V-JEPA）含有丰富的几何与时空语义，但它们是逐帧或片段级的判别特征，维度高、无生成先验，不能直接当扩散模型的潜空间用。于是存在一个具体缺口：如何把几何知识（度量深度、跨视一致）与时空语义（运动、交互动力学）蒸馏进一个可生成、可压缩、保留 patch 空间布局的潜表征，并让动作 token 与场景 token 以正确的因果方向耦合。此外，跨本体（单臂/双臂/灵巧手）与预训练数据效率也缺少在统一表征下的对照研究。

## 方法详解
三阶段。表征预训练（3.1）：以 VGGT-Ω 中的 DINOv3 ViT-L/16 初始化学生，逐帧出场景特征，同时向两个冻结教师蒸馏。几何侧用几何适配器把逐帧与跨视特征对齐到 VGGT-Ω 的中间层，ℒ_align=Σ_{s∈S}λ_s Δ(Ĉ_s,C_s)（式 1，Δ 为 smooth-L1），并加置信度加权的 log-depth 损失匹配教师深度，得 ℒ_geo=ℒ_align+ℒ_depth，全程不用 GT 深度。时空语义侧用 JEPA 适配器与预测头映射到 V-JEPA 2.1-L 特征空间，教师看完整片段、学生对所有帧施加一致的 spatial mask，ℒ_tmp=(1/|M|)Σ_{i∈M}Δ(Q_i,Z_i)+(λ_ctx/|V|)Σ_{i∈V}α_iΔ(Q_i,Z_i)（式 2），可见位置的权重 α_i 随其到最近被遮位置的距离衰减，以迫使模型从上下文推断。两个教师按各自预训练目标交替更新，最终只保留 EMA backbone 用于策略训练与部署。因果聚合与压缩（3.2）：CS-VAE 逐帧先过 spatial Transformer，再两级因果时序压缩，把 9 帧特征 F_0…F_8 压成 3 个潜帧 z_0,z_1,z_2 并保留 patch 网格；z_0 只依赖 F_0，后续每个潜变量聚合以其时刻结尾的因果窗口，从而把当前观测保留为条件、把其余序列组织为时序聚合的预测目标。训练时从高斯后验 q(z|F) 采样，解码器重建 F̂=D(z)，目标 ℒ_CS-VAE=ℒ_MSE(F̂_t,F_t)+ℒ_cos(F̂_t,F_t)+βD_KL(q(z|F)‖N(0,I))（式 3），特征重建保场景信息、KL 把后验拉向标准高斯。联合视觉–动作建模（3.3）：CS-VAE 场景潜变量与 Wan VAE 外观潜变量按通道拼接（48+48=96 通道），视频扩散 Transformer 建模视觉 token、动作扩散 Transformer 建模动作块，各层用非对称掩码的 masked joint attention 耦合——当前帧视觉 token 只看彼此，未来视觉 token 可看全部视觉但不看动作，动作 token 可看全部视觉与动作；动作流还交叉注意 T5 指令、机器人状态与按臂索引的 soft prompt token。用 flow matching 训练，当前视觉潜变量保持干净、未来潜变量与动作块加高斯噪，两专家各回归自己的流场，ℒ_WAM=0.5ℒ_appearance+0.5ℒ_feature+ℒ_action（式 4），动作项只在本质体提供的控制维度上计分。推理时固定当前视觉潜变量，从高斯噪声联合去噪未来潜变量与动作块（10 步）。预训练/后训练（3.4）：从 54,413 小时筛出 39,306 小时，机器人示教、第一人称视频、UMI 数据分别占 31.09%、63.58%、5.33%；阶段 (a)(b) 用全部数据，阶段 (c) 只用机器人示教；跨本体把状态与动作映射到共享 80 维接口，每个臂 ID 选 8 个可学 soft prompt token；预训练冻结 Phoenix Encoder、CS-VAE 与视频 VAE，只更新视频/动作专家、状态投影与 soft prompt；后训练用目标任务示教，冻结/可训模块保持一致。

## 实验与结果
- LIBERO-Plus 总体成功率 94.8%，超 InternW0-Δ（92.8%）2.0 点，7 类扰动中 5 类领先
- RoboTwin 2.0 Clean2Random 72.4%，超 InternW0-Δ 0.5 点、超 π0.5（46.0%）26.4 点
- Bench2Dex 26 个任务–本体设置、12 种臂–手组合：总体 45.6%，超 GR00T N1.5（28.3%）17.3 点，无扰动/等变/不变/组合四条件全部第一（54.2/38.5/44.1/45.6）
- RoboDojo-RealWorld 真机：ARX X5 33.3%、Piper 31.7%、Piper X 25.0%，均值 30.0%，超 OpenWAM-α（24.4%）5.6 点、π0.5（12.8%）17.2 点
- 另 LIBERO-Pro 66.5%、RoboCasa-GR1 82.7%
- 表征消融（LIBERO-Plus，均无 WAM 预训练）：VAE-only 76.9%
- Phoenix Encoder+PCA48 84.4%，高于 DINOv3+PCA48（74.4%）与 V-JEPA 2.1-L+PCA48（83.2%）
- 换 CS-VAE 再升到 88.2%，机器人初始化一项从 70.2% 升到 90.2%
- 冻结特征探针（InsScene-15K/ScanNet++）：平均排名 1.80 最优，direct prediction 34.42%（DINOv2-L 23.73%、V-JEPA 2-L 6.25%），depth 0.1411、instance 1.5738、cross-view 96.18%
- 数据缩放与效率：预训练数据 25%→100%，Phoenix 提升 27.0 点而 VAE-only 基线（Fast-WAM）仅 11.4 点
- 用 50% 数据得 67.7%，超过基线用全量数据的 47.7%
- 后训练只用 25% 示教时 LIBERO-Plus 91.1%（全量 94.8%，差 3.7 点）、C2R 58.6%（超基线全量 10.9 点）
- 未来视频预测 PSNR：C2R 上 26.30 vs Fast-WAM 16.51，LPIPS 0.16 vs 0.39

## 创新点与贡献
- 真正的转向是“先把场景结构学进表征，再做生成”：既有 WAM（UWM/OpenWAM/Fast-WAM/ImageWAM/InternW0）多在视频 VAE 潜空间上做联合预测，或用语义特征做对齐/辅助监督
- Phoenix 把几何（VGGT-Ω 的跨视一致与深度）与时空语义（V-JEPA 2.1-L）双教师蒸馏进 DINOv3 骨干，再用一个“因果”VAE 把 9 帧压成 3 帧潜变量——z_0 只见当前帧、后续潜变量聚合因果窗口，使当前观测天然是条件、未来是预测目标，而不是把整段视频对称压缩
- 配合非对称注意力掩码（动作可看视觉、视觉不看动作）与 96 通道场景+外观双潜变量，动作与场景演化被显式对齐
- 这带来可验证的表征收益：探针 direct prediction 34.42% 远超 DINOv2/V-JEPA，且缩放收益 27.0 点对基线 11.4 点，说明新意落在数据效率而非单点刷分

## 局限与风险
- 主要增益集中在 Bench2Dex（+17.3 点）与真机均值（+5.6 点），而两个最常被引用的基准优势很小：LIBERO-Plus +2.0 点、RoboTwin C2R +0.5 点，且 LIBERO-Plus 的 camera 一项（89.9%）与 Qwen-RobotManip-Context 持平、robot 一项（94.0%）低于 InternW0-Δ 的 91.1% 之外仍有若干分项被对手领先，说明“全面 SOTA”依赖聚合口径
- RoboDojo-RealWorld 上 Piper（31.7%）低于 OpenWAM-α（36.7%），真机仅 10 trials/task、60 trials/配置，方差未充分报告
- 真机成功率绝对值 25–33% 仍偏低
- 训练成本高：39,306 小时数据、WAM 预训练 global batch 4,480、每数据规模一个 epoch，未给出总算力与碳排放
- 表征阶段依赖两个大教师与 110k 步 EMA 检查点，复现门槛高
- CS-VAE 的 9→3 帧压缩比与 96 通道配置未做敏感性扫描，长时程任务的时间分辨率可能不足
