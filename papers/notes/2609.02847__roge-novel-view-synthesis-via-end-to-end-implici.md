# RoGe：端到端隐式重建与生成的新视角合成

## 一句话结论
RoGe 以相机条件 VGGT 的射线查询隐式特征条件化视频扩散并端到端联训，DL3DV PSNR 20.92、LPIPS 0.124、TSED 0.9977、FVD 58，超重建/生成/混合基线。

## 要解决的问题
稀疏位姿图像的新视角合成既需观测视图的几何 grounding，又需未观测区域的生成先验；现有混合方法以渲染图或显式 3D(点图/高斯)桥接两者，生成器只看到有损投影并继承误差，重建侧又收不到生成信号的纠正，模块解耦导致次优。

## 方法详解
稀疏观测与目标轨迹统一用 Plücker 射线图表示；相机条件 VGGT(内外参 MLP 投成 1024 维 token 加入相机 token，末层局部+全局注意力 token 拼为 2048 维场景 token)构建隐式场景表示，不实例化深度/点云/高斯；射线编码器(8×8 patch+4 个 register token)对上下文与目标视图编码，经 L=12 个 ray-scene 交叉注意力块(前 11 块双向、末块单向)查询场景 token，输出目标视图逐视图几何特征 F_r。混合 VAE 保持上下文置换不变与目标时序先验；几何适配器(1×1 卷积降至 384 通道+双线性重采样+Pack4 对齐)与像素 unshuffle 射线图经 3D patch 嵌入注入 DiT；联训损失 L=L_FM+0.1·L_render(FM 仅计目标 slot，渲染头 MSE 辅助)。

## 实验与结果
DL3DV 10 条 SEVA 选定序列：PSNR 20.92、SSIM 0.642、LPIPS 0.124、DreamSim 0.087 均第一(LagerNVS 20.90/0.193/0.122，SEVA 18.63/0.158/0.089)；视频级 TSED 0.9977、MEt3R 0.0771、FID 23、FVD 58、TransAPE 0.0403、RotAPE 2.5121°(LagerNVS FVD 206、GEN3C 281)。消融：无几何 19.01 dB，裸 VGGT token 18.50，相机条件化 19.35，渲染 RGB 20.35，射线查询 20.59，联训 20.92。训练 M=6 上下文、N=81 目标，Wan2.1-I2V-14B-480P 加 LoRA，16×H20 312,500 步；ScanNet 轨迹外插验证。

## 创新点与贡献
①去除显式 3D 中间表示，以前馈重建网络的射线查询隐式特征直接条件化视频扩散；②提出 ray-scene 交叉注意力与 latent 对齐几何适配器，桥接重建特征与视频 VAE 潜空间；③端到端联训使生成目标反塑几何条件，图像与视频级指标全面 SOTA。

## 局限与风险
正文未设专列局限节；稀疏输入下大范围未观测区域本质欠约束，效果依赖 Wan2.1 生成先验；上下文视图数固定为 6；训练与评测集中于 ARKitScenes/DL3DV 等室内外分布，其他域泛化未测。

## 与文献库的关系
承接库内 LagerNVS（VGGT token 直接渲染）与 SEVA/FrameCrafter（生成式 NVS），与 GEN3C/NeoVerse/Difix3D+ 等解耦两阶段混合方法直接对比；ray-scene 交叉注意力+端到端联训是差异化内核。

## 可复现性（代码/数据/硬件）
项目页 https://jerry-locker.github.io/roge/；PyTorch，16×H20 训练；前馈模块初始化自 LagerNVS，生成骨干 Wan2.1-I2V-14B-480P；训练数据 ARKitScenes/BlendedMVS/DL3DV/MVS-Synth/WildRGB-D 均公开。

## 行动建议
稀疏位姿 NVS 新 SOTA（FVD 58 vs LagerNVS 206/GEN3C 281）；「无显式 3D 中间表示的射线查询条件化」思路可迁移；16×H20 训练成本高。
