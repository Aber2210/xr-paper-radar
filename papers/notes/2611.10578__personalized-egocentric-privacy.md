# EgoVeil：第一视角视频的个性化隐私推理

## 一句话结论
在 10 名智能眼镜用户的跨用户时序协议下，EgoVeil 取得 91.93% 平衡准确率与 84.42% Mask 召回（最强基线 Base Privacy Reasoner + Memory 为 85.23% 与 73.99%），偏好记忆从空到完整前序历史时平衡准确率由 56.57% 升到 95.75%。

## 要解决的问题
智能眼镜的常驻第一人称摄像与 VLM 辅助能力带来根本张力：下游 AI 需要丰富视觉上下文，而「哪些内容算隐私」高度个体化且依赖情境。已有做法有三类不足：采集期阻断（机械快门、光照调制）在源头减少泄露，却把后续分析与分享所需的信息一并删除；采集后选择性遮挡以预定义隐私类别或属性定义敏感性，无法覆盖同一物体在不同情境下敏感性不同；个性化路线主要依赖用户事先显式给出的偏好或设置，而真实用户无法预先穷举偏好。作者的野外研究进一步显示：隐私判断由区域揭示了什么信息决定而非物体类别（同一台电脑屏空白时可不遮挡、显示邮件时必须遮挡），且偏好是逐步被发现与修正的。

## 方法详解
EgoVeil 把视觉定位、语义解释、个性化决策三段解耦。（1）与用户无关的区域级语义理解：每帧复用 Semantic-SAM（Swin-L，semantic level 2）加 SAM（ViT-H）补齐的区域集（平均 16.38 个可选区域、覆盖 93.03% 画面），按 Set-of-Mark 编号，把编号图与原始图一次性送入本地部署的开源 VLM，为每区域产出结构化 observation（Region Type / Visual State / Visible Information / Scene Context）；prompt 明确禁止做隐私判断。（2）偏好记忆与检索：每用户维护 M_u = {(o_j, a_j, ρ_j)}，用冻结的 E5-base-v2 编码，cosine 相似度取 TopK 不超过 3、阈值 τ=0.7；历史 embedding 入库时算好复用。（3）偏好奖励建模：把决策写成成对比较（Bradley-Terry），L_RM = −(1/M)Σ log σ(r_θ(o_i,a⁺) − r_θ(o_i,a⁻))；主干 Qwen3-8B 加可训练线性 reward head，LoRA（r=8、α=16、dropout 0.05）加在自注意力的 q/k/v/o 投影上，输出标量分数而非生成文本。（4）不确定即问：Δr_i = r(a*) − r(ā)，若大于 δ 直接执行 a*，否则置 Ask 交用户确认；确认结果按 Repeated / Contextually Distinct / Conflicting / Unrelated 四类做记忆维护（冲突项保留但标 inactive）。连续视频上用 SAM 2.1 mask prompt 跟踪区域，命中活跃轨迹则复用决策，但设推理视野 H=2 s 强制重算，以防同一物体语义变化（如屏幕由地图切到 Instagram）后仍沿用旧决策；轨迹消失则终止，重新出现按新区域重跑全流程。整条管线的可用性依赖两个经验量：cosine 阈值 τ=0.7 与决策阈值 δ，前者控制记忆召回的松紧，后者控制主动询问的比例，作者用后者扫描出 5% 至 40% 五档请求率来做权衡实验。

## 实验与结果
['数据：10 名参与者（8 女）用 Ray-Ban Meta 眼镜自发拍摄，平均 36.6 段（SD 7.68）、约 6.1 小时、30 fps/1080p；每段约 1,800 帧，关键帧选择平均 56.24 帧每分钟；共 12,000 条以上区域级隐私标注、每用户约 100 个效用问答。', '协议：10 折跨用户时序模拟，每人轮流作「新用户」、其余 9 人训练；按拍摄时序处理，初始记忆为空，只用更早片段的偏好，当前片段预测先记录再入库。', '主结果（Table 3，宏平均，平衡准确率/精确率/召回/F1）：EgoVeil 91.93/58.01/84.42/63.02；Base Privacy Reasoner + Memory 85.23/24.34/73.99/31.37；Shared LoRA 76.17/16.01/61.56/21.33；Base 74.59/15.65/60.17/19.24；Generic VLM 53.85/43.02/7.93/7.29；Generic VLM + Memory 62.10/17.60/25.35/19.36。', '偏好历史消融：同一批留出片段上，从无记忆到四组完整前序历史使平衡准确率 56.57% 到 95.75%、精确率 3.73% 到 39.86%、召回 25.10% 到 92.22%、F1 3.53% 到 50.53%。', 'Ask 机制：5% 请求率下，被选中决策的「本会出错率」为 39.64%，随机选择为 15.94%（随机在各请求率下稳定约 16%）；同等确认次数下 Ask 选出的偏好带来更好的后续表现。', '效用：每用户抽 5 段共 50 段、150 个问答；Qwen3-VL-8B 从原始 49.33% 降到遮挡后 42.67%，InternVL3.5-8B 从 55.33% 降到 52.00%。', '训练开销：LoRA 8 个 epoch、4 张 RTX A5500；本地部署 VLM 与推理模型以降低云端泄露风险。']

## 创新点与贡献
['首次用野外研究刻画「区域级、语义驱动、可演化」的个性化视觉隐私决策，并据此给出 12,000 条以上标注与每用户约 100 个效用问答的数据集，把「物体类别不足」这一论断实证化。', '把隐私决策拆成与用户无关的语义观察、共享 LoRA 奖励模型、显式用户偏好记忆三者，使跨用户可迁移的推理模式与个体证据分离，新增偏好无需重训（对比参数化个性化与纯检索个性化各自的局限）。', '用 reward margin 作为不确定性信号驱动选择性询问，并给出「同等确认预算下 Ask 优于随机」的证据（5% 请求率下 39.64% 对 15.94%），把减少打扰从设计口号变成可测量指标。']

## 局限与风险
['作者承认：仅 10 名用户、约 6.1 小时视频，且隐私标注只覆盖选定关键帧而非密集全视频，未报告全视频隐私准确率。', '作者承认：系统算力开销大、评估为离线模拟；Ask 的用户响应由既有标注模拟，无法反映真实交互负担与响应意愿；实时与端侧部署未优化。', '作者承认：依赖区域定位与语义解释的正确性，定位漏检或观察未覆盖的信息不会被后续推理发现；固定 H=2 s 的重算视野会漏掉两次重算之间的语义变化。', '我在正文发现：Mask 精确率仅 58.01%，约四成被遮挡区域用户本可保留；作者也自述奖励模型「对整体隐私预测只有有限增益」，真正增益主要来自记忆检索，说明学习式推理的边际贡献有限。']

## 与文献库的关系
处在三条线交汇：视觉隐私的捕获期阻断与采集后选择性遮挡（Orekondy 2018、PrivObfNet、Ilic 2024）；可穿戴相机的隐私管理（PlaceAvoider、PrivacEye）；LLM 个性化（LaMP 的检索式、PReF 与 Poddar 的参数式、VisualLens/PLVM 的多模态检索）。本文站位是「检索加轻量任务适配」的组合，与 Salemi 与 Zamani 关于两类机制互补的观察一致，但把证据粒度下沉到视觉区域。
