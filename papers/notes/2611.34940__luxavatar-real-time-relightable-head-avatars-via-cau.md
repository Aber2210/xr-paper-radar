# LuxAvatar：基于三维本征代理因果神经着色的实时可重光照头部化身

## 一句话结论
把头像拆成「可动画三维本征高斯代理 + 因果自回归神经着色器」：UV 流形上每个高斯带法向 / base color / roughness，少步自回归替代多步扩散——VFHQ PSNR 21.32（LCVD 14.75）、CSIM 0.739（0.506），12.46 FPS（优化后 20.31），着色 4.19 s vs 556.51 s（132.8×），982 帧长序列仅降 0.27 dB。

## 要解决的问题
从单张人像做可动画、可重光照的头像要同时解决三维可控性与复杂光照传输（次表面散射、高光、软阴影）。传统光场舞台/标定设备能采到，但硬件成本高；单目逆渲染在未知光照下病态，常留下烘焙进外观的阴影残差，且解析着色器表达不出真实光传输；前馈高斯头部模型（GKE/GAGAvatar/UIKA 等）只能做烘焙环境光下的动作控制，不可重光照；二维条件扩散（CapHuman、LCVD 等）难以精确控三维且多步去噪延迟高——LCVD 在 VFHQ 上 PSNR 14.75、仅 0.846 FPS，Relit-LiVE 单独跑 57 帧需 556.51 s（0.10 FPS），无法交互。

## 方法详解
把头像合成分解为「可动画三维本征高斯代理 + 因果自回归神经着色器」。① 本征高斯代理：在恒等 FLAME 模板锚定的 UV 流形上组织 $N$ 个高斯 $\mathcal{G}^c=\{(\boldsymbol{\mu}_i,\mathbf{s}_i,\mathbf{q}_i,\alpha_i,\mathbf{n}_i,\mathbf{a}_i,r_i)\}$，即除几何外每个原语带单位法向、base color 与 roughness；用冻结的稠密对应预测器把人像前景映到 UV 网格（texel 内取均值、未观测区补零）得部分纹理 $I_{\mathrm{uv}}$，$I$ 与 $I_{\mathrm{uv}}$ 共享冻结 DINOv3 ViT-L/16 主干、经各自 adapter 融合多层特征，UV 锚定的可学 query 用 transformer 整合两路 token、DPT 式解码器出稠密规范特征图 $\mathbf{F}$，再由两个解码头分别回归几何 $D_{\mathrm{geo}}(\mathbf{F}(\mathbf{u}_i))=(\Delta\boldsymbol{\mu}_i,\mathbf{s}_i,\mathbf{q}_i,\alpha_i,\mathbf{n}_i)$ 与材质 $D_{\mathrm{mat}}(\mathbf{F}(\mathbf{u}_i))=(\mathbf{a}_i,r_i)$，中心 $\boldsymbol{\mu}_i=\mathbf{v}_i+\Delta\boldsymbol{\mu}_i$。驱动时按目标 FLAME 的表情 blendshape + LBS 变形（材质属性不变），在目标相机下可微泼溅出 PBR 缓冲 $\mathcal{C}_t=(\mathbf{A}_t,\mathbf{R}_t,\mathbf{N}_t)=\mathcal{R}_{\mathrm{attr}}(\mathcal{G}_t,\pi_t)$；损失 $\mathcal{L}=\mathcal{L}_{\mathrm{L1}}+0.1\mathcal{L}_{\mathrm{SSIM}}+0.5\mathcal{L}_{\mathrm{LPIPS}}+0.1\mathcal{L}_{\mathrm{off}}$，$\mathcal{L}_{\mathrm{off}}$ 约束高斯贴近 FLAME 锚点。② 两步因果神经着色器：基于 Wan2.1-1.3B + TAEHV 轻量视频自编码器，把着色写成条件视频生成——PBR 各通道与噪声 latent 按通道拼接保住空间对齐，环境图 $\mathbf{E}_t$ 用 LDR/log-HDR/方向三张图经通道拼接 + 交叉注意力注入（配合 posed 空间法向 $\mathbf{N}_t$），参考图作为全局 token 前缀锚定身份，背景协调时再加背景板前缀并由 DiffusionLight 从背景估 $\mathbf{E}_t$。先用 Relit-LiVE 多步双向教师做 ODE 轨迹预热，再在自回归 rollout 上做 DMD 蒸馏到「每 chunk 两步」的因果学生，KV cache 复用全局前缀与历史 chunk（自注意力只看当前+前一 chunk 与最多两个均匀采样的早期 chunk）。③ 混合重光照数据：DiffusionRenderer 产生本征标签与重光照视频对；用「反向配对」——保留原始 VFHQ 视频作真值、只编辑参考帧——避免过拟合合成伪影；FaceOLAT 上用光传输线性性做 360° 旋转环境图的 OLAT 基图线性组合，补上物理可信的连续光照。最后用 $\mathcal{L}_{\mathrm{pair}}=\mathcal{L}_{\mathrm{latent}}+\mathcal{L}_{\mathrm{L1}}+0.5\mathcal{L}_{\mathrm{LPIPS}}+0.01\mathcal{L}_{\mathrm{adv}}$ 在配对人像数据上微调。

## 实验与结果
- VFHQ PSNR/SSIM/LPIPS：21.32 / 0.710 / 0.168，对比最强基线 LCVD 的 14.75 / 0.582 / 0.321
- FaceOLAT PSNR：27.83 vs 16.87（LCVD）；LPIPS 0.132 vs 0.387
- 身份保持 CSIM：VFHQ 0.739 vs 0.506（UIKA+Relit-LiVE）、0.484（LCVD）
- 吞吐：单张 RTX 5090 D 上 12.46 FPS，推理优化后 20.31 FPS，双卡 26.02 FPS（57 帧 clip）
- 着色器单独计时（57 帧）：4.19 s（Ours）vs 556.51 s（50 步 Relit-LiVE），即 132.82× 加速；再加优化到 2.42 s / 23.55 FPS
- 长序列稳定性：982–984 帧、五个序列，81 帧 rollout 到全程 rollout 前景 PSNR 仅降 0.27 dB（21.00→20.50 全图）

## 创新点与贡献
- 相对 UIKA / GAGAvatar 等前馈高斯头像，把外观显式拆成本征 PBR 缓冲（base color + roughness + 法向）而非烘焙光照，从而第一次在「单图前馈、无逐主体优化」的前提下支持重光照
- 相对 URAvatar / RelightAnyone 这类仍需测试期反演或逐主体训练的通用高斯头像，把重建与着色彻底解耦
- 相对 LCVD 这类视频重光照/渲染框架，用「本征代理提供 4D 一致几何与材质 + 两步因果蒸馏」替代多步去噪与叠窗，把延迟压到可交互量级，并把环境图重光照与背景协调统一到同一个生成器的共享光照条件上

## 局限与风险
- 身份与外观仍主要来自参考帧，强表情变化下的皱纹等细节靠生成先验「补」出来（作者以 NeRSemble 上额头皱纹与眼镜框刚性为例说明这是生成而非重建）
- 训练需要 32 张 H20、每阶段数千步，数据由 DiffusionRenderer / UniRelight / Qwen-Image-Edit 合成，存在把上游模型偏差带入的风险
- 定量只在 VFHQ 与 FaceOLAT 两个测试集，VFHQ 的目标光照由 DiffusionLight 估计、可能与真实光照不符，作者因此补充用户研究
- RelightAnyone 与 URAvatar 因无公开实现被排除对比
- 长序列背景漂移部分归因于 GT 视频自身相机抖动
