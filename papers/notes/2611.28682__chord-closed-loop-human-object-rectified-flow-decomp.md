# CHORD：闭环人-物整流流分解

## 一句话结论
把接触校正从外部 guidance 搬进生成器速度场，用整流流闭式干净估计做表面测量、零额外 NFE 回写到 part token：InterAct FID 0.114 对 LIGHT 0.170，手部接触 F1 0.730→0.834。

## 要解决的问题
文本驱动的三维人-物交互生成要同时合成 6-DoF 物体轨迹与含手指的全身运动，并让接触贯穿全程。现有生成器要么把决定交互的三个核心变量（物体位姿、接触区域、肢体姿态）与几十个从属关节混在一起，要么只规划末端执行器或粗轨迹而把肢体姿态留空。更关键的是，生成过程中没有任何阶段以「既已定又可观测」的形式持有交互：接触要么交给外部 guidance/后处理精修器，要么交给没有表面测量的内部引导，导致物体与身体在运动中漂移、悬浮或穿透。

## 方法详解
两阶段整流流。Draft 把每 K=4 帧打包成一个时间片，用 12 个 part token（1 个物体 + 11 个规划关节）联合生成 48 维计划 $\mathbf{x}^{Draft}(t)=[\mathbf{o}(t),\mathbf{p}_{world}(t),\mathbf{r}(t),\tilde{\mathbf{p}}_{root}(t)]$ 与 8 个身体区域二值接触 $\mathbf{c}(t)\in\{0,1\}^8$；每个 token 只嵌入自己的通道，并在每个 block 用自身 query 对指令词做交叉注意力（带 part anchor 与时序偏置），实现「每个部件读与自己相关的词」。闭环接触反馈嵌在速度场里：每个 flow step 由闭式干净估计 $\hat{\mathbf{x}}_1=\mathbf{x}_s+(1-s)\mathbf{v}_\theta$ 解码出各接触区期望位置与物体位姿，转到物体坐标系 $\hat{\mathbf{q}}_m=\hat{\mathbf{R}}^\top(\hat{\mathbf{p}}_m-\hat{\mathbf{o}}_{trans})$，找最近表面点得偏移 $\boldsymbol{\delta}_m$，组成 11 维测量（偏移、模长、帧间差、尺度归一化表面点、可用标志），经零初始化线性通路路由回对应 part token；因为复用该步已有的干净估计，不增加网络评估。训练用两遍法：90% 样本先在前一更噪时刻做 stop-gradient 前向得到反馈，再在当前时刻带梯度更新；10% 无反馈以匹配首步。Full 冻结物体轨迹与 11 个规划关节，只补 13 个剩余身体关节与 28 个手指关节（手指表示为相对手关节的偏移），条件含 12 个计划 token 与 Draft 预测的表面关系/接触概率。损失为分组 FM + 接触 BCE + 物体系关系锚定 + 肢长 + 脚滑 + 静止物体约束。

## 实验与结果
- InterAct 上 FID 0.114 vs LIGHT 0.170（降低约 33%），MM Dist 2.154 vs 2.427
- 手部接触 F1 0.834 vs LIGHT 0.730，精度 0.855、召回 0.846；接触比例 0.190（GT 0.208）
- R-Precision top-3 0.779 vs LIGHT 0.690、InterAct 0.692；穿透 Pene 0.941 vs LIGHT 0.953
- 采样成本：32 步 Draft + 8 步 Full，CFG 下共 72 次网络评估，无梯度引导、无辅助网络
- 训练 170k updates，结果取 10 个采样种子均值；片段最长 300 帧、30 fps

## 创新点与贡献
- 把接触校正从「外部 guidance/后处理」搬进生成器的速度场：利用整流流的闭式干净估计做表面测量，零额外 NFE 地回写到责任 part token
- 同时用「12 个 part token 的紧凑计划」把交互变量从几十个关节中分离出来，Full 不再改动计划，保证已定的接触不被后阶段破坏

## 局限与风险
- 作者承认反馈只作用于规划关节，手指是在规划手位周围补全、没有自己的闭环
- 只支持单个刚体物体，片段长度受限（L≤300 帧），铰接物体与更长序列未覆盖
- 从正文看，方法依赖物体 mesh、body shape 与文本，缺少这些输入时无法运行
- Full 阶段仍可能产生手-物穿插，只是不破坏计划
