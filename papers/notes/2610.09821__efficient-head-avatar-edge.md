# 面向边缘设备的高效 3D 高斯头部化身

## 一句话总结
一个高效生成器架构，把 3D 高斯头部化身的合成计算降 94% FLOPs、70% 参数、81% 模型大小，使完整合成可在 CPU/移动端浏览器完成，无需 GPU。

## 问题背景
- 生成式 3D 高斯头部化身渲染质量高、效率高，但"合成高斯表示"本身计算昂贵，难部署到资源受限/边缘设备。

## 方法
- **高效生成器**：参数高效合成块 + 深度可分离卷积。
- **FLAME 几何先验**：高斯采样于 FLAME 网格表面，零卷积预测偏移 → 软几何正则，鼓励跨视角/位姿一致头几何。
- **高斯属性图（UV map）**：StyleGAN2 backbone 以潜在码 z + 相机位姿 p 生成；C=13（最终）/ C=22（含一度球谐视相关）。
- **部署**：ONNX 导出 + 移动端 CPU 推理；动画由 SVD 基 + onnx runtime + FLAME 数据驱动。

## 实验与结果（关键数字）
- 训练/评估：FFHQ（70k 人脸，MODNet 去背景）。
- 指标：FID、FLOPs、推理延迟、文件大小、FID_3D、PSNR_MV/SSIM_MV。
- 对比 AGORA：参数量 −70%、FLOPs −94%、模型大小 −81%；512² FID 4.15 vs AGORA 3.17（质量略降但可接受）。
- 完整合成在 CPU/移动端浏览器（无 GPU/专用软件）；转移大小 75.59 MiB / 24 文件，缓存后重启快。

## 贡献与局限
- 贡献：首次把"生成新 3D 高斯头部化身"做到边缘端完整合成；FLAME 软几何正则保一致性。
- 局限：质量略低于重 backbone（FID 4.15 vs 3.17）；依赖 FFHQ 类前脸数据，大姿态/遮挡泛化待验。
