# HaNDF：物体条件化的几何神经手部距离场

## 一句话结论
HaNDF 用物体条件化的黎曼神经距离场统一建模手部可行配置，在 HOI4D 补全上把 Δq 从 16.60° 降到 12.57°、FID 从 0.156 降到 0.060，生成任务 FID 0.5466 远优于 LatentHOI 的 2.7843，且 200 步推理仅 12 ms。

## 要解决的问题
手-物配置空间高度受约束、依赖物体、且非欧氏，微小扰动就会造成穿模或失去接触，因此需要一个可查询的“给定物体哪些手姿合理”的先验。现有方案两头不讨好：VAE/扩散（HMP、G-HOP、LatentHOI、Text2HOI）在欧氏潜空间里算距离，几何无意义；NDF 系（PoseNDF、NRDF）虽在流形上建模，却只针对人体、无条件、且手部关节与物体无关，无法编码交互约束；物体条件方法又多退化为任务专用管线，牺牲几何一致性。

## 方法详解
把手部姿态表示为 (S^3)^15 / SO(3) 乘积流形上的点，物体由 DeepSDF 潜码（PCA 降维后可检索）编码为条件信号，学习一个条件标量场，其零水平集即“给定物体下合理的手姿流形”。网络输出到该流形的测地距离，因此距离本身有几何含义；推理时对（可掩码的）关节做 Riemannian 梯度下降把姿态投影回流形，同一个场即可支撑 generation（从噪声投影）、denoising、part completion 与 reconstruction，下游只需叠加任务数据项。物体侧还可反过来优化——用同一场推断交互物体，并用最近邻检索 + 可选优化精修物体网格。整套设计把“先验”与“重建管线”解耦，可直接插进 EasyHOI、AlignSDF 等系统作为手部正则项。

## 实验与结果
HOI4D（219 物体/63K 姿态训练，30 个未见物体/7.5K 测试，仅保留接触帧）、DexYCB（s0 划分，582K 帧）、OakInk（53 训练/14 未见物体）。部件补全：Δq 12.57° vs H-NRDF 16.60°、dNN 5.44° vs 8.01°、APD 20.79°、FID 0.0596 vs 0.1558；缺整指设定下 6.60° vs 8.47°、FID 0.0106 vs 0.0453。生成：FID 0.5466、dNN 4.77°，优于 LatentHOI（2.7843/6.41°）、G-HOP（0.7316）与 Text2HOI（7.05）。野外手部恢复：EasyHOI 的 MPVPE 16.64→13.98、AlignSDF 10.40→10.22（HOI4D）。手-物联合：Δq 14.77→9.60、MPJPE 12.08→11.50、MPVPE 11.90→11.30，加物体检索后 obj-F@2% 0.1187→0.1568。运行时（L40S）：LatentHOI 1000 步 64.5 ms，HaNDF 200 步 12 ms 且 FID 更低。

## 创新点与贡献
1) 首个几何感知、物体条件化、且提供有意义测地距离的手部姿态先验，把条件信息做成对流形的调制；2) 单一距离场统一 generation / denoising / completion / reconstruction / 物体推断五种用法，无需为每个任务重训；3) 直接作为插件提升 EasyHOI、AlignSDF 等重建基线，并给出 5 倍以上的推理加速。

## 局限与风险
依赖相当准确的物体几何，物体形状偏差会直接污染条件信号与投影结果；作者明确说它不是真正的抓取先验——没有建模手-物联合 NDF，也未纳入接触动力学，因此无法保证力闭合或稳定抓握。实验限于单手 + 刚性物体，双手协同与可变形/可关节物体未覆盖，动态场景仅是展望。论文自评承认大量实验未给误差棒、置信区间或显著性检验，部分增益（如 AlignSDF MPVPE 10.40→10.22）幅度很小需要谨慎解读。

## 与文献库的关系
是 NDF 家族（NDF → PoseNDF → NRDF → NRMF）从“人体无条件”向“手部 + 物体条件”的延伸，同时与手部生成先验（HMP、G-HOP、LatentHOI、Text2HOI）和单图手-物重建（IHoI、EasyHOI、AlignSDF）两条线对接；在方法论上与同期的黎曼流匹配/流形生成工作共享“把关节姿态放在乘积流形上”的核心信念。

## 可复现性（代码/数据/硬件）
代码与项目页公开：circle-group.github.io/research/HaNDF ；HOI4D、DexYCB、OakInk 均为公开数据集，网络结构与训练算法在补充材料 C 给出，评测协议（含统一提供 GT 物体的公平比较）描述清楚。

## 行动建议
做手-物重建或机器人抓取预训练的研究者应把 HaNDF 作为可插拔正则项接入现有管线并测穿模率；若要用于真实抓取，还需自行补接触力/动力学约束，别直接当作 grasp prior。
