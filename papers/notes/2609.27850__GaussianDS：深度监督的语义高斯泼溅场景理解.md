# GaussianDS：深度监督的语义高斯泼溅场景理解

## 一句话结论
GaussianDS 把"语义提升"当作监督对齐问题而非简单投影：用深度监督 + 几何锚定抑制 3DGS 语义漂移与边界泄漏，在从零联合优化 RGB 外观、渲染深度、紧凑语义的同时，借助 SAM2 在"位姿感知伪视频轨迹"上传播视图一致掩码；在语义场景理解上优于仅做 2D 提升的基线，且保留高保真重建与实时渲染。

## 要解决的问题
给高斯附加语义属性做开词汇场景理解时，把视图相关的 2D 基础模型输出提升到 3D 会带来跨视图不一致与弱几何锚定，导致严重语义漂移与边界泄漏。

## 方法详解
- **伪视频轨迹**：把无序多视角图像按位姿组织为"伪视频"，用 SAM2 传播视图一致掩码；
- **联合优化**：从零联合优化 RGB 外观 + 渲染深度 + 紧凑语义；
- **几何锚定**：尺度-位移对齐的单目深度监督 + 深度全变分正则稳定几何；
- **边界锚定**：深度边缘感知细化损失把语义跳变显式锚定到物理几何不连续处。

## 实验与结果
- 端到端框架在保留高保真 3D 重建与实时渲染的同时，语义理解显著优于基线（具体 mIoU/边界指标见论文）；
- 关键消融验证深度监督、伪视频掩码传播、深度边缘感知损失各自贡献。

## 创新点与贡献
"语义提升 = 监督对齐 + 几何锚定"的提法，比"2D→3D 直接投影"更系统；深度边缘感知损失把语义边界钉在几何不连续上，是抑制泄漏的实用手段。

## 局限与风险
依赖 SAM2 掩码质量与单目深度估计精度；"伪视频"构造对位姿噪声敏感；开词汇语义的评测协议未充分展开。

## 与文献库的关系
库内"感知与认知"方向（此前多为晕动/眼动用户研究）新增"语义 3D 场景理解"技术方向；与库内 3DGS 重建类（CADSplat 等）共享表示但目标不同（理解 vs 重建）。

## 可复现性
方法自洽、描述具体，但无公开代码链接；依赖 SAM2 与单目深度模型，复现中等。

## 行动建议
