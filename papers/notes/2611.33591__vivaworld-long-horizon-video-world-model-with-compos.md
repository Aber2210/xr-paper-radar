# VivaWorld：带组合式三维先验的长时程视频世界模型

## 一句话结论
给长时程视频一个组合式几何记忆（点云背景 + 生成网格前景 + mesh-seeded 连通域过滤），把相机误差限制在局部 chunk——单 chunk PSNR 21.24（Lyra 2.0 20.01），1,000 帧 13.92（12.85）、相机评分 79.51（65.09），RotErr −23.4%、TransErr −38.8%。

## 要解决的问题
长时程视频生成是交互式世界模型、具身智能与空间推理的基础，但缺少显式 3D 接地时会出现相机漂移、几何畸变与物体形变，单帧看着真实、连起来就崩。现有做法有两种都不够：用输入视角重建的点云作 3D memory，只能覆盖被观测区域，未观测区域没有可靠先验；相机表示（含 Plücker 射线）定义在全局坐标，误差随序列累积。实测中长视频段普遍退化——Lyra 2.0 的 RotErr 9.022、TransErr 0.098，Voyager 的 PSNR 从单段 18.60 掉到 8.62，AnyRecon 的相机评分从 94.75 掉到 27.37。

## 方法详解
构造组合式混合表示 $\mathcal{W}_{\mathrm{geo}}=\{\mathcal{P},\mathcal{M}\}$：背景用前馈重建的点云（Pi3 预测度量深度，ViPE 估位姿，按 chunk 反投影得局部点云再聚合），前景用生成式网格（SAM3 分割物体，RecGen 或 GPT-6 Astra 生成 mesh，再用带各向异性尺度的 ICP 配准 $T^k(\mathbf{x})=R^kD^k\mathbf{x}+\mathbf{t}^k$ 对齐到观测点）。聚合多视角点云会产生悬浮碎片，作者提出 mesh-seeded connected-region filter：把点云与网格体素化，从网格占据体素做 BFS 洪泛，只保留可达体素内的点，从而删掉与配准网格不连通的成分。相机表示是组合式的：全局 Plücker 坐标 $\mathbf{p}^{\mathrm{scene}}_{t,u,v}=(\mathbf{d}_{t,u,v},\bar{\mathbf{o}}_t\times\mathbf{d}_{t,u,v})$，$\bar{\mathbf{o}}_t=(\mathbf{o}_t-\mathbf{c}_{\mathrm{scene}})/s_{\mathrm{scene}}$；再对每个已配准网格中心 $\mathbf{c}^k$ 加一路物体锚定 moment $\mathbf{m}^k_{t,u,v}=\frac{\mathbf{o}_t-\mathbf{c}^k}{s_{\mathrm{scene}}}\times\mathbf{d}_{t,u,v}$，拼成 $\mathbf{c}_{\mathrm{cam}}\in\mathbb{R}^{T\times(6+3N)\times H\times W}$。模型侧冻结 Wan 2.1-T2V-14B，在 VACE 上搭组合式控制适配器：点云与网格的 RGB-D 渲染分别过冻结 VAE 后拼接，mask 与相机嵌入过一个轻量时空卷积编码器，得到 $\mathbf{z}_{\mathrm{ctrl}}=[\mathcal{E}_{\mathrm{RGBD}}(I^{\mathcal{P}})\|\mathcal{E}_{\mathrm{RGBD}}(I^{\mathcal{M}})\|\Phi_{\mathrm{cam}}([\mathbf{b}\|\mathbf{c}_{\mathrm{cam}}])]$，patch 化后与视频 token 一一对齐，在冻结 DiT 的若干块注入残差，共享时间步与文本条件；只训适配器（3.05B）与相机编码器。长视频按 chunk 自回归生成，新生成帧回写更新点云，支持单图与稀疏多图输入。

## 实验与结果
- 单 chunk：PSNR 21.24 / SSIM 0.570 / LPIPS 0.173（Lyra 2.0 20.01 / 0.528 / 0.227）
- 长视频（1,000 帧）：PSNR 13.92 / SSIM 0.376 / LPIPS 0.529，相机评分 79.51（Lyra 2.0 12.85 / 0.343 / 0.582 / 65.09）
- 长视频相机误差：RotErr 6.908、TransErr 0.060（Lyra 2.0 9.022 / 0.098，相对降 23.4% / 38.8%）
- 由生成视频重建三维：长视频 SSIM 0.447 / LPIPS 0.598（Lyra 2.0 0.423 / 0.658）
- 消融（长视频）：无引导 PSNR 10.03、Cam 3.17 → 仅点云 12.41 / 71.34 → 点云+高斯 13.60 / 79.95
- 评测规模：DL3DV-10K 20 个场景约 200 段 + Tanks and Temples，832×480，长视频取前 1,000 帧（T&T 240 帧）

## 创新点与贡献
- 相对只用重建点云当 3D memory 的方法，这里把「重建的保真」与「生成的完整」组合起来，让 360° 新视角都有几何依据
- 相对全局 Plücker 射线，加入以已配准网格为锚的 moment 通道，显式建模相机—物体相对运动，从而抑制长序列漂移
- 两者都通过轻量适配器注入冻结 14B 视频扩散模型，主干不需重训

## 局限与风险
- 依赖 14B 主干与一长串外部大模型（Pi3、ViPE、SAM3、RecGen / GPT-6 Astra），复现与算力门槛高，且上游位姿/深度/配准误差会传导到生成（附录有误差分析）
- 通道数随物体数线性增长
- 没有开源
- 具身应用仅作展示，未给机器人闭环的定量指标
- 长视频仍取前 1,000 帧，超长序列的漂移未被彻底消除
