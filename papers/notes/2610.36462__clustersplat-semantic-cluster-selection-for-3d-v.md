# ClusterSplat：3DGS 视觉定位的语义簇选择

## 一句话结论
ClusterSplat 把 3DGS 视觉定位从逐 primitive 分数过滤重构为场景自适应簇上的离散选择：ScanRefer 10 场景上 2D mIoU 39.72%、3D mIoU 23.33%/mAcc@0.25 43.38% 均为对比 3DGS 基线最优（ReferSplat 31.30/4.05/0.10），Ref-LERF 平均 mIoU 31.14% 亦最佳，且每查询仅 19.55 ms。

## 要解决的问题
现有 3DGS 语言定位方法对稠密 primitive 级相关分数施加全局阈值或 top-ratio 过滤来提取 3D 目标；这些分数分布随场景上下文与 prompt 复杂度（组合属性、空间关系）大幅波动，尺度敏感超参导致定位不稳定——top-ratio 过滤会把选中 primitive 散布到目标与邻近干扰物上，且稠密相关场常缺乏清晰决策边界，固定比例下目标被漏检或与背景合并。同时室内场景在物体数量、尺度、杂乱度与同类干扰物上差异大，簇候选粒度应适应场景结构；而现有评测（如 Ref-LERF）场景多样性受限、类名 prompt 无法唯一指定同类多物体中的目标，缺少联合评估渲染 2D 掩码与显式 3D 高斯目标集的协议。

## 方法详解
两阶段框架，把单目标指代重新表述为场景自适应候选簇上的离散选择（k_q*=argmax_k S_{q,k}，S_target=G_{k*}）。Stage 1：① Instance-aware Gaussian feature learning——沿用 OpenGaussian 式目标，用训练视图 SAM 多视实例掩码监督，每高斯学习可学习特征 f_i∈R^{D_f}，按与 3DGS 相同的 opacity-aware compositing 渲染特征图，损失为掩码内聚 L_coh（归一化特征拉向掩码原型 ψ_{v,m}）与掩码间分离 L_sep（不同掩码原型推开，距离秩加权），得几何对齐特征场。② Scene-adaptive clustering——按场景归一化中心体素索引 + ℓ2 归一化实例特征的主导有符号维度做初始过分割 seed voxel；每 seed voxel 计算归一化特征原型 φ_a 与质心，在 whitened 特征-位置描述符空间建 MST 限制候选合并边；以 MDL 启发描述长度成本 D_gmdl(S)=RSS_feat(S)/(2σ_f²)+λ_gmdl·½(D_f+1)log N_eff（RSS_feat=|S|−‖Σ_{a∈S}φ_a‖₂）加 BIC 式分量惩罚，仅当 Δ_gmdl(A,B)=D(A)+D(B)−D(A∪B)>0 时合并相邻分量，得到场景特定簇数 K_s≪N（10 场景为 53–143，平均 87.3），Stage 2 中分配固定。Stage 2：③ Query-conditioned cluster scoring——冻结 CLIP 文本编码指代表达得 token 矩阵 E_q，簇 token c_k 加质心 μ̄_k 的正弦位置编码初始化，经 Transformer decoder 自注意力（建模全局空间-语义上下文，抑制仅有局部外观相似而缺关系支撑的假阳性簇）后与 query tokens 交叉注意力得 H_q；scorer 以余弦相似度 token attention β_{q,k,ℓ}=softmax(cos(h_{q,k},t_{q,ℓ})/τ) 生成 query 摘要 y_{q,k}，两层 MLP（隐藏 128 维）从 [h_{q,k};y_{q,k};h⊙y;|h−y|] 预测分数，保持相对排序决策而非阈值。④ Cluster-level mask rendering——每高斯继承所属簇分数 ℓ_{q,i}=S_{q,a(i)}，以相同高斯光栅化渲染并经 sigmoid 得掩码，Stage 2 用 focal+Dice（λ_D=0.5）监督。

## 实验与结果
数据集：ScanNet v2+ScanRefer（沿用 OpenGaussian 的 10 场景子集，官方标注+指代表达，同场景报类名定位与指代分割）与 Ref-LERF（ReferSplat 提出，细粒度小场景，用其置信度加权 IoU 伪掩码规则监督）；基线 LangSplat、OpenGaussian、Dr.Splat、ReferSplat，分数基线在 top-ratio {0.01,0.02,…,0.10} 扫参报 per-method oracle 最优，ClusterSplat 用 Top-1 簇选择、不调任何逐查询/逐场景阈值。

## 局限与风险
正文第 5 节 Discussion and Limitations：① 主要局限在候选池本身——过合并邻近相似物体或把一个物体拆到多簇会限制保守 Top-1 选择的完整性（故类名 mAcc 46.60% 强而 3D mIoU 29.21% 更严格：选中簇可与正确物体足够重叠以匹配，却仍遗漏物体范围或纳入邻近碎片）；② 只处理单物体指代表达，复数/可变数量实例的定位留作未来工作；③ 实验仅覆盖 10 个 ScanNet v2 场景 + 4 个 Ref-LERF 场景且每场景单独准备，更广场景覆盖与未见场景迁移未测；④ 训练依赖标注实例掩码与生成描述，每个新场景需离线准备才能处理查询；⑤ 未来方向为不确定性感知的多簇选择以处理碎片化候选。

## 与文献库的关系
属库内 3DGS 开放词汇定位线（LangSplat/OpenGaussian/ReferSplat/Dr.Splat 及 GaussianGraph 关系推理）：把 3D 目标选择从 primitive 级分数过滤重构为场景自适应候选簇上的离散选择，MDL（描述长度）+BIC 式惩罚指导聚类（簇数 53–143），query-conditioned cluster scoring（自注意力场景上下文+CLIP query 交叉注意力+余弦 token attention），彻底免除逐查询/逐场景阈值。
