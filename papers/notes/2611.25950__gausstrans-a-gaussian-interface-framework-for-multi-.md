# GaussTrans：面向多层折射光传输的高斯界面框架

## 一句话结论
高斯界面 + 传输耦合细化显式建模多层透明折射：同存储下落点误差降 95%–98.9%，几何仅 82.85 KiB（同输入网格的 1/25.8）。

## 要解决的问题
多层透明界面（多层玻璃壳、高重叠角透明物体、实验器皿、多元件光学系统）的难点不在单层拟合，而在误差沿光路耦合：上游界面的位置或法向偏差会改变下游交点与入射方向，局部近似误差被逐层放大，最终背景落点与成像全错。既有路线各有回避：DRT、NeTO、RCTrans、TNSR 把光路限制在两次折射（TNSR 最多两次折射加一次反射），TransparentGS 也假设两层折射加一次全内反射；另一些只建模水平透明平面；可微渲染框架虽支持递归多次交互，但「多追几次」并不自动消除界面间的几何误差耦合；把透射、折射、反射分开建模的做法扩展到多层会让复杂度爆炸。表示层面同样两难：3DGS 把外观与几何混在体积原子里，2DGS/QGS 用平面或二次曲面表达力不足，TSGS 只做首表面提取；显式网格在同存储下曲率精度低，密网格虽准但存储与求交代价高。求交也不可靠：融合场沿射线一般不再是多项式（权重随位置变化），粗采样容易漏掉薄壁或掠射交点，产生硬失败像素。归结起来，多层折射缺一个紧凑、可求交、误差不随层数累积的界面表示。

## 方法详解
输入为粗糙界面几何（带朝向网格）、已知折射率、标定相机与背景模型。表示层：元素 i 由网格给中心 c_i 与单位法向 n_i^0，加两切向量构成 R_i=[t_iu,t_iv,n_i^0]；查询点变换到切坐标 (u_i,v_i,z_i)=R_i^T(x−c_i)。局部曲面取多项式残差零点 d_i(x)=z_i+Σ_{2≤ℓ+m≤N} a_{i,ℓm}u_i^ℓ v_i^m，常数与线性项因中心与切平面已固定而省略，系数数 M_N=(N+1)(N+2)/2−3，默认 N=3 即 7 个系数，由邻域样本与拟合权重 ω_ih 的加权最小二乘求得（含量纲归一化与秩检查）。影响范围用残差坐标高斯核 w_i=α_iψ_i exp[−½(u_i²/s_iu²+v_i²/s_iv²+d_i²/σ_in²)]，随曲率而非世界椭球伸缩。界面场 F_k=Σw_i d_i/(C_k+ε)，C_k=Σw_i 为支撑度量；该式等价于对 ζ 最小化 Σw_i(ζ−d_i)²+εζ² 的闭式解，无需迭代。梯度 ∇F_k=[Σ(w_i∇d_i+(d_i−F_k)∇w_i)]/(C_k+ε) 保留权重导数，法向取 ∇F_k 归一化，求交与折射共用同一场。界面为 F_k=0 且 C_k≥τ_C。细化层：S 个壳共享 θ=(θ_1,…,θ_S)，每壳一个局部形变控制量同时驱动内外两层；γ_i(θ)=U_i(M^0,θ_s(i))=(c_i,R_i,a_i)，即网格样本随形变移动、重建局部系、按上式重解系数，得到 θ 相关的场、支撑与法向。观测 q 的光路递推为 (k,t)=Q(r,μ;θ)、x=r(t)、v←Snell(v,n,ρ)，法向均取自当前场梯度，状态全依赖 θ，故任一界面改动传播到后续交点与背景落点 b̂_q(θ)。监督用多视背景对应：ℓ_q=‖b̂_q−b_q‖²（有效路径）或常数 κ（无效路径，要求完成指定界面序列并正向到达背景），总目标 L=(1/|D|)Σℓ_q+λ‖θ‖²，在坐标模式搜索中评估某壳候选时他壳固定于当前已接受控制量，实现跨壳联动，且只用训练观测选参、留出光路评测。求交层：把射线代入局部多项式得 P_i(t)=d_i(r(t))（次数 ≤N），用切向支撑包围矩形裁剪区间，取其实根、驻点与支撑边界作引导样本，与粗采样合并后二分；候选须满足 |F_k|≤τ_F、C_k≥τ_C、‖∇F_k‖≥τ_g，再按介质相容与 t>t_min 排除自交，取最小 t。成像时把同一套有效交互扩展到 Fresnel 加权反射/透射，按 C_res=Σβ_π⊙L_π 累加。

## 实验与结果
- RefRef 玻璃球（100 个测试视角、512×512）：PSNR 23.49、SSIM 0.9085、LPIPS 0.0665，几何仅 82.85 KiB
- 同输入网格 23.45 / 0.9068 / 0.0838 但占 2140.17 KiB，约为其 1/25.8 存储
- 同存储容量下（每界面 100–1600 个元素、五档近似字节匹配、六壳场景）：GaussTrans 与 Smooth QEM 都完成 65/65 条路径，前者平均背景落点误差降低 95.1%–98.9%
- 阶数消融（每界面 400 个原语）：二阶落点误差 2.564e−3 → 三阶 1.498e−3，降 41.6%，65 条光线中 54 条改善
- 六阶与八阶反而回退，线性面只有 61/65 完成路径
- 跨壳耦合细化（六壳椭球、10 条合成背景对应、25 次搜索评估）：相对各壳独立校正，完整更新在两套输入上把未见视角平均落点误差降 27.4% 与 36.0%，39/39 条配对光线全部改善
- 相对初始化降 29.7% 与 33.3%
- 引导求交：六壳场景已有 8 个硬失败像素降到 2 个
- 41 次掠射扰动中，33 个已有观测交点的情形下恢复数从 20 升到 33
- RefRef 圆环（非凸、含四次穿越区）：核心几何 96.88 KiB（QEM 96.82 KiB）下，公共像素 MAE 界 [0.0749,0.0753]，QEM 平滑法向版为 [0.0884,0.0890] 且 768 个硬失败像素、四穿越区 137 个，GaussTrans 两项均为 0
- 内存效率对照：六层旋转偏心椭球上，三次 Gaussian、二次 Bézier、三次 Bézier 各约 861–863 KiB 均完成 65 条路径，平均落点误差 0.001498 / 0.003337 / 0.005653
- 完整 Fresnel 成像（六壳、512×512、同一传输预算）：解析参考、GaussTrans、稠密源网格的前景未解析权重平均约 5.3%，说明结果仍是带区间的未收敛传输

## 创新点与贡献
- 用「高斯加权的局部多项式隐式面片」做界面：曲率由多项式表达、空间影响由高斯核组织，无需存储面片间连接关系，且同一场既提供零点也提供法向，天然支持求交与折射。
- 把细化从逐层独立拟合改为按完整光路评估的跨壳联动：所有壳共享一组控制量并在他壳当前已接受状态下评估候选，直接针对误差沿光路耦合这一失效机制。
- Primitive-Guided 求交：用局部多项式在射线上的实根/驻点/支撑边界作为引导样本加密采样，再回到未修改的融合场做校验，兼顾不漏交与场的自洽。
- 把表示精度、存储与运行时显式做成可调三角：阶数 N 控制局部表达力，元素数控制覆盖，并给出同存储与同每层容量两种对照。
- 同一框架从主透射路径推广到 Fresnel 多分支累加成像，并显式报告未解析能量比例，而不是假装收敛。

## 局限与风险
- 作者自述：精度依赖输入几何质量与局部覆盖，薄壁、相邻面、曲率剧变区域仍会出现位置/法向偏差，甚至多出或漏掉交点，这些误差在连续折射中会被放大
- 引导求交提出的候选只是局部多项式根，未必是融合场零点，仍需逐点校验，因此有额外开销，目前只用于困难查询
- 实验层面：几乎全部评测建立在已给定粗糙网格与已知折射率之上，属表示与细化而非从图像端到端重建，采集流程未验证
- 真实场景只用了 RefRef 的球与环，六壳、椭球、四次曲面均为合成
- 画质上 R3F 的 PSNR 更高（24.54 对 23.49），TNSR/R3F 的物体区 MAE 更低，说明优势主要在几何精度与存储
- 5.3% 未解析能量说明完整成像尚未收敛
- 无代码，单机构作者，baseline 输入先验不统一（折射率固定 1.5 对 TransparentGS 学习 1.46854）
