# StrucPhysVideo：物理不是"看多了就会"，是"标注对了才会"

## 一句话结论

用一套**物理导向的数据策管管线**（运动感知分割 + 质量/内容过滤 + 物理相关性验证 + 物体/材质/时序局部化交互的结构化标注，并显式解耦相机运动与物体行为）产出监督信号，训练稀疏 MoE 的 TI2V 模型；在 **Physics-IQ Verified 上以 45.5% 位列 17 个模型第一**（超 Cosmos3-Super-Image2Video 2.8 点、超最强闭源对比 MiniMax H3 Max 9.3 点），并扩展出**四步蒸馏的交互式 IA2V 世界模型**。

## 要解决的问题

视频世界模型要真正服务具身 AI，必须建模**物理动力学**——物体如何移动、交互、改变状态。但现有视频生成模型的训练信号里，物理是被"顺带"学到的：

- 通用 caption 描述"发生了什么"，不描述**接触、形变、状态转移**
- 相机运动与物体行为混在一起，模型分不清"是物体动了还是镜头动了"

结果就是模型能生成"看起来合理"的视频，但物理上不成立。

## 方法详解

### 数据管线（本文的第一贡献）

| 环节 | 做法 |
|---|---|
| 运动感知视频分割 | motion-aware video segmentation |
| 过滤 | quality + content filtering |
| 物理相关性验证 | physical relevance verification |
| 结构化标注 | 物体、**材质**、**时序局部化的交互** |
| **解耦** | 显式分离**相机运动**与**物体行为** |
| 显式描述 | **接触（contact）、形变（deformation）、状态转移（state transitions）** |

核心主张：这套管线提供的是**锚定在可观测物理事件上的监督**。

### StrucPhysVideo-TI2V（文本-图像到视频）

- 骨干：**LingBot-Video 30B** 稀疏 MoE，从官方 checkpoint 起步
- 训练：81 帧片段，15 fps，480×832
- **课程学习（curriculum）**：通用域池 / 物理聚焦池的采样比例按阶段变化

| 训练阶段 | 通用域 : 物理聚焦 |
|---|---|
| 前 60% | 70% : 30% |
| 中间 30% | 40% : 60% |
| 最后 10% | 20% : 80% |

即**渐进强调物理动力学，同时保留通用域视频数据**——避免物理微调导致通用能力崩塌。

### StrucPhysVideo-IA2V（交互式图像-动作到视频）

在 TI2V 基础上扩展为**机器人末端指令 → 视觉结果**的预测：

- 动作条件化
- **因果自回归生成**
- **少步蒸馏**：仅需 **4 次去噪**即可做增量机器人 rollout

## 实验与结果

### TI2V：Physics-IQ Verified

评测口径说明：Verified 协议修正了歧义提示与虚假参考运动，并对每个样本取平均分；分数**等权结合**空间 IoU、时空 IoU、加权空间 IoU 与经配对视频变异归一化的反向归一化像素 MSE。基准快照日期为 **2026-09-16**。

| 模型 | Physics-IQ Verified |
|---|---:|
| **StrucPhysVideo（LingBot-Video-30B 骨干）** | **45.5%** |
| Cosmos3-Super-Image2Video | 42.7%（−2.8 点） |
| MiniMax H3 Max（最强闭源对比） | 36.2%（−9.3 点） |

**caption 消融（跨两个骨干，验证"物理导向标注"本身的价值）**

| 骨干 | 无 caption / 原始 | + raw captions | + physics-focused captions |
|---|---:|---:|---:|
| Wan2.2-5B | 24.8% | 31.0% | **33.2%** |
| LingBot-Video-30B | 37.9% | 43.9% | **45.5%** |

关键读数：
- 加 raw captions 已有巨大增益（24.8→31.0、37.9→43.9，即 **+6.2 / +6.0 点**）
- **物理导向 caption 在 raw caption 之上再 +2.2 / +1.6 点**
- 结论在两个不同规模/架构的骨干上一致 → **不是骨干特定的巧合**

### IA2V：交互式预测

对比 DreamDojo-AgiBot，**在所有评测指标上一致更优**：帧级保真度（PSNR / SSIM / LPIPS）更高、运动误差更低，且**轨迹准确率高得多（0.8330 vs. 对照）**。

另在 A2World 默认设置（21 帧、256×256/视角、前 21 帧、5 fps）下做了同口径重算。

### Teacher Dropout 与 Guidance 消融（Table 4）

1. **即使不用 CFG，仅对动作条件做 dropout 也不会掉点**
2. **动作 CFG 显著改善动作条件化与 IA2V 生成质量**

## 创新点与贡献

1. **把"数据策管"提升到与模型架构同等地位**：本文最硬的证据是 caption 消融——同一骨干、仅换标注策略，Physics-IQ 就能涨 7~8 点。这说明物理能力的瓶颈**在数据不在架构**。
2. **显式解耦相机运动与物体行为**：这是物理监督能否成立的前提，很多工作忽略了。
3. **课程学习比例的具体配方**：70/30 → 40/60 → 20/80 的三段式，可直接复用。
4. **从 TI2V 到 IA2V 的完整路径**：四步蒸馏 + 因果自回归，使交互式 rollout 可行。

## 局限与风险

- 无代码发布声明（仅项目页）。
- 主实验集中在 Physics-IQ 单一基准；无真机闭环控制实验，IA2V 的"交互式 rollout"仍是开环预测层面的验证。
- 30B MoE 骨干算力门槛极高，绝大多数团队无法复现训练过程。
- 相对最强基线的增益为 **+2.8 点**，属"稳健 SOTA"而非数量级突破。

## 行动建议

1. **最值得抄的是数据管线，不是模型**：即使只有 5B 骨干，"运动感知分割 + 物理相关性过滤 + 显式描述接触/形变/状态转移 + 解耦相机运动"这套标注策略也能带来 +6~8 点。这是性价比最高的部分。
2. **课程学习配方直接复用**：70/30 → 40/60 → 20/80 的三段式可迁移到任何"通用能力 + 专项能力"的微调场景。
3. **XR 仿真应用**：把 StrucPhysVideo-IA2V 接进机器人/虚拟人仿真，用末端指令驱动视觉演化，可低成本生成大量物理合理的交互数据。
4. **跟进空白**：开环预测 → 闭环控制。本文的 rollout 仍是预测层面，真正的物理世界模型需要在闭环中验证动作后果。
