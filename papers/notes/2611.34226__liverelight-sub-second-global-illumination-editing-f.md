# LiveRelight：高斯室内场景的亚秒级全局光照编辑

## 一句话结论
预计算「几何光交换」而不是「光照响应」，把反射率与光源构型解耦，使编辑回路里只需一次廉价传输求解——Kitchen 35.95 dB / 0.244 s（EAG-PT 28.08 / 147.2 s），Living room +10.74 dB，八个重打光条件平均 +5 dB、延迟降三个数量级。

## 要解决的问题
从单光照条件下的多视图像重建出的 3D 高斯场景只能重现采集时的光照；要重新打光，基于物理的逆渲染必须对每次编辑从零求解多次弹射光传输，代价高到无法交互。在 540×360、1024 spp 的设置下，EAG-PT 单次编辑需 134.5 到 184.4 s 才能看到第一帧；预计算「每盏灯的响应」虽可线性重组，但那份解把反射率与光源空间构型一起编码进去，改材质或挪灯就失效。因此编辑器拿不到近实时反馈，只能盲调。

## 方法详解
关键取舍是预计算「几何光交换」而不是「光照响应」，从而在编辑回路里保留一个廉价的传输求解。场景用 EAG-PT 从线性辐射度图像重建为有朝向的 2D 高斯（中心、切向尺度、法线、不透明度、采集辐射度、albedo、emissive 权重），假定 Lambertian 且发光体不反射。直接光在高斯上做 next-event estimation：每像素沿主射线 alpha 合成深度、albedo 与朝向相机的着色法线（累积不透明度到 0.95 前截断）得到接收点 $\mathbf{x}$，抽 $M=8$ 个发光高斯样本，估计 $\hat{\mathbf{L}}_d(\mathbf{x})=\frac{\boldsymbol{\rho}(\mathbf{x})}{\pi M}\odot\sum_m\frac{\boldsymbol{\ell}_{i_m}\alpha_{i_m}(\mathbf{y}_m)V g_{i_m}}{p_{i_m}q_{i_m}}$，几何因子 $g_i$ 为两侧余弦与距离平方之比，阴影透射率 $V$ 沿线段累乘 $\prod(1-\alpha_i)$；按 $p_i\propto\bar{\ell}_iA_i$（$A_i=2\pi o_is_{i1}s_{i2}$）与 $q_i=\gamma_i/2\pi s_{i1}s_{i2}$ 采样使 $\alpha_i/q_i=A_i$ 解析抵消高斯衰减，再用 OptiX HDR 去噪。间接光交给代理网格上的稀疏 radiosity：TSDF 融合渲染期望深度后抽取一次三角网格（属性感知简化，保材质边界），三角面从深度一致的 albedo 投影得反射率；用 hemicube（64 分辨率）在质心间积分可见立体角得稀疏 form factor 矩阵 $F$，令 $T_\rho Z=\boldsymbol{\rho}^M\odot(FZ)$，解 $B=E+T_\rho B$、保留 $B_{\mathrm{ind}}=\sum_{b=2}^{K}T_\rho^bE$（$K=8$，因为高斯那一支已供发射与一次反射）。投影 $P\in\mathbb{R}^{N_G\times N_T}$ 把三角面辐射度映射回高斯：借助可微高斯渲染器缓存每次命中的合成权重 $w_h=\alpha_h\prod_{h'<h}(1-\alpha_{h'})$，构造 $[W_v\mathbf{f}]_r=\sum_h w_h\mathbf{f}_{i(h)}$ 与 $[S_vz]_r=\sum_{h\in\mathcal{H}^{\mathrm{valid}}}w_hz_{t(h)}$，以投影拟合损失加 capture 约束、循环一致与先验正则联合优化，行做 softmax 归一保常量辐射度，拟合一次不需逐编辑优化。合成 $I_v=S^e_v+(1-w^e_v)\odot[\mathcal{D}(\hat{\mathbf{L}}_{d,v})+W^{\mathrm{ind}}_vPB_{\mathrm{ind}}]$。单面发光体是另一处关键：EAG-PT 把发光高斯当双面，光会从吊灯背面打到天花板，材质恢复只能靠压暗附近 albedo 补偿；本文在恢复 albedo 之前先用「多数训练相机中心位于发光侧」的符号投票 $\mathrm{sign}[\mathbf{n}_i^\top(\mathbf{x}_v-\boldsymbol{\mu}_i)]$ 定向每个发光高斯（必要时翻转法线与第二切向，保持足迹），背面保不透明度但不发光。编辑侧：发光体与 albedo 编辑只改 $\boldsymbol{\ell}_i$ 与 $\boldsymbol{\rho}_i,\boldsymbol{\rho}^M$，复用同一 $F$ 与 $P$ 重解；灯具几何编辑是 $\mathrm{Sim}(3)$ 相似变换直接作用在高斯装配上（$\boldsymbol{\mu}'=\mathbf{p}_f+aR(\boldsymbol{\mu}-\mathbf{p}_f)+\mathbf{t}$、尺度乘 $a$、切向帧乘 $R$），不做重拟合，再用 emitter re-injection 在临时追踪场景里打约 $10^6$ 条光线重算该灯具的一次反射注入，保留其余发射体的一次反射 $d_{\neg f}=T_\rho E_{\neg f}$，得 $B'_{\mathrm{ind}}=\sum_{b=1}^{K-1}T_\rho^b(d_{\neg f}+\hat{d}'_f)$。

## 实验与结果
- Kitchen Relit 1：35.95 dB / SSIM 0.983 / 0.244 s（EAG-PT 28.08 / 0.955 / 147.2 s）
- Living room Relit 2：33.22 dB（EAG-PT 22.48），+10.74 dB，为本表最大差距
- 八个合成重打光条件平均：较路径追踪基线 +5 dB PSNR，编辑延迟最多降三个数量级
- Bitterli-Kitchen Relit：30.78 dB / 0.153 s（EAG-PT 28.89 / 183.5 s）；Bitterli-Livingroom 32.51 / 0.149 s（29.23 / 160.9 s）
- 真实场景首次合成：FIPT-Classroom 0.40 到 0.47 s、FIPT-Conference 0.36 到 0.52 s
- 消融（Kitchen Relit 1/2/3）：仅发射加 NEE 22.02 / 21.72 / 20.26 dB；仅 radiosity 32.84 / 35.52 / 35.96 dB；完整 35.95 / 36.99 / 36.96 dB
- 代理网格预算：100k 三角面降 0.12 到 0.44 dB、编辑时间 0.17 到 0.23 s；400k 不提升质量但时间升到 0.41 到 0.49 s
- 投影拟合：拟合 $P$ 比最近质心分配高 0.37 到 0.79 dB、比未拟合初值高 0.20 到 0.65 dB
- 预计算开销：200k 代理的 $F$ 需 9 到 11 min、压缩后 3.4 到 4.1 GB、显存 6.5 到 8.1 GiB、载入约 20 s；抽网格加拟合 $P$ 需 26 到 31 min
- 高分辨率：1080×720 延迟 0.38 到 0.53 s、1620×1080 为 0.65 到 0.99 s（EAG-PT 同期每视图路径追踪 654 到 723 s 与 1445 到 1607 s）

## 创新点与贡献
- 相对 LuxRemix 这类「预计算每盏灯的贡献再线性重组」，本文预计算的是与发射、反射率解耦的几何交换算子，因此改发光强度、改 albedo、甚至移动灯具都能进入一次新的稀疏求解而不必重算传输——这是把经典 two-pass radiosity 的「视角无关解加视角相关渲染」搬到高斯重建上的新组合
- 相对 RadiosityGS 直接在半透明高斯面元上解 radiosity、Hu et al. 依赖屏幕空间复用，这里用不透明代理网格承担高阶间接光、用「在 alpha 合成图像形成下拟合的稀疏投影」把解搬回高斯，正是为了跨过「面求解器认几何面元、高斯成像按视角混合」这一域差
- 相对生成式重打光（SyncLight、LightBridge），这里支持指定灯具几何变化与 albedo 变化并同步更新阴影与色溢

## 局限与风险
- 作者列出的限制很实在：假定 Lambertian 与「发光面直接可见」，隐藏光源需要更丰富的表示，插入光源需要给定几何与发光
- 光源指派依赖人工 fixture mask 与发光面面积
- 代理网格离散化限制间接精度
- $P$ 无法修正缺失几何或传输误差，分数发光覆盖时合成式只是近似
- 预计算与存储随表面交互数增长
- 编辑范围也有限：改动接收体几何或不透明度会使传输矩阵失效
- emitter re-injection 只更新被编辑灯具到接收体的可见性，其他发射体之间与接收体之间的可见性、以及移动后灯具外壳上的间接光都不更新
- 几何编辑只覆盖缩放与平移
- 保真度还受 EAG-PT 的单次弹射入射光估计影响，对采集光照条件敏感
- 真实场景（FIPT）只有定性结果，无参考图
