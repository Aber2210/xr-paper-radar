# 结合事件相机与帧图像的任意点 3D 跟踪

## 一句话结论
首个单目 RGB + 同址事件的 3D 任意点跟踪器：把「相机诱导刚性运动」作为迭代内的运行期参照而非一次性预处理，使 IMO 分割与轨迹精化互为条件——帧间时刻 3D EPE 0.148 m vs Track4World+插值 0.284 m，可在没有 RGB 帧的时刻输出 200 Hz 轨迹。

## 要解决的问题
RGB 帧之间的盲区内，快速运动点会严重运动模糊，标准相机又受带宽—延迟权衡约束：低帧率模糊、高帧率带宽爆炸。已有 3D 点跟踪器（SpatialTrackerV2、Track4World、Trace Anything 等）只在帧时刻给出位置，帧间只能线性插值；事件相机虽能提供微秒级帧间信息，但现有事件式 3D 跟踪要么需要双目事件（E-3DTrack）、要么需要 4 路 RGB + 2 路事件阵列（MER-Tracker）、要么需要输入深度图（E-TraMamba），尚不存在单目 RGB + 同址事件的 3D 任意点跟踪器。

## 方法详解
TrackAnyMotion 以 Track4World 为骨架、以冻结的 DA3 提供点图与相机位姿，输入单目 RGB 帧与同步事件，输出帧时刻与任意帧间时刻的 2D/3D 轨迹及独立运动概率。事件侧把最多 40 万个前置事件堆成 10 通道表示，经 TAPFormer 编码器得到 stride-8 特征 E_k；时序融合用卷积 GRU 维护瞬态状态，RGB 时刻由 RGB 上下文重置，帧间则用事件更新，再用 7×7 局部交叉注意力以源 RGB 上下文查询得到事件修正 δ_k。查询外观按 α_k 双线性混合前后帧特征并加上门控残差：F̃_k^a=(1−α_k)F_{k⁻}^a+α_kF_{k⁺}^a+g_a⊙ψ_a(δ_k)，零初始化保证初始等价于纯 RGB。帧间几何由两部分合成：先用 SLERP/线性插值得到 T̄_k，再由池化特征与相对相位预测 twist 修正 T̂_k=T̄_k exp(ξ_k^∧)；同时卷积头预测世界位移场 ΔX^w_{k,i}，构成伪点图 P̃_{k,i}=T̂_k⁻¹(T̂_s P̂_{s,i}+ΔX^w_{k,i})，按软深度权重前向泼溅填补空洞，为迭代精化提供目标几何。核心机制是独立运动反馈：以刚性参考 P^rig_{t,i}=T̂_t⁻¹T̂_sP̂_{s,i}、u^rig=π_t(P^rig) 为零假设，每次 2D 更新后计算图像残差 a=û−u^rig 与世界位移 b=T̂_tP̂_t−T̂_sP̂_s，归一化后与源/目标置信度、几何有效性一起送入共享空间解码器；再沿源锚定轨迹做双向时序注意力（不混空间位置），输出 IMO logit 与概率，阈值 0.5 得掩码。两个零初始化适配器把 [z,p] 转为 2D/3D 残差特征回灌到下一轮更新，使分割使用演化中的对应估计、并把运动信息反馈给轨迹精化。训练在 N=4 次迭代上逐层加权（γ=0.8），含 2D/3D 轨迹 L1、可见性/置信度 BCE、空间平滑、IMO BCE，以及帧间分支的位姿与粗位移损失。

## 实验与结果
- 帧间时刻（K 轴）：2D EPE 0.132 px，对比 Track4World+线性插值 1.470 px、TAPFormer 0.497 px；3D EPE 0.148 m，对比 0.284 m / 0.382 m
- RGB 帧时刻（S 轴）：3D EPE 0.166 m vs Track4World 0.318 m（降约 48%，论文摘要口径为 70% 的端点误差下降），2D EPE 0.646 vs 1.219 px
- HyperEvent 上 2D EPE 0.728 px 优于 TAPFormer 1.224 px；真实事件 DSEC 上 1.605 vs 1.932 px
- PointOdyssey L-50 EPE3D 0.091 m（Track4World 0.121）、ADT L-50 0.044 m（0.064）、KITTI 0.076 m（0.077）
- 独立运动分割 mIoU 81.36 / pIoU 72.82，远超 Event Suppression 48.83 / 23.56 与 Un-EVIMO 45.75 / 14.79
- 消融置零事件：整体 2D EPE 1.961→3.136 px（+59.9%），高速运动组 7.629→15.435 px（+102.3%）

## 创新点与贡献
- 首个单目 RGB + 同址事件的 3D 任意点跟踪器：无需深度输入、无需多相机，可在无 RGB 帧的时刻输出 3D 位置（200 Hz 轨迹自 25 Hz 帧）
- 把「相机诱导刚性运动」作为迭代内的运行期参照，而非一次性预处理的残差，使 IMO 分割与轨迹精化互为条件、互相增强
- 配套 HyperEvent 是首个同时含高频 3D 轨迹、几何与独立运动标签的事件—帧数据集

## 局限与风险
- 依赖单目几何（冻结 DA3）的尺度与精度，3D 结果只在归一化坐标下给出对齐后的残差，不保证绝对度量尺度
- 真实事件验证有限（仅 DSEC 的 2D 跟踪，3D 与 IMO 均在合成数据上评测），HyperEvent 的规模与真实感仍有差距
