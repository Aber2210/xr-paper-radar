# GazeDiT：让扩散模型生成的眼睛，"眼神"真的对得上标签

## 一句话结论

针对眼动追踪合成数据"图像看着真实、但瞳孔/虹膜几何与给定注视标签对不上"这一致命缺陷，GazeDiT 构造一个**内部空间条件**——把全局的 4D 双眼注视标签"落地"到局部的瞳孔/虹膜几何上，再让扩散模型在该几何条件下生成外观。在 **3 档训练队列（500 / 1,000 / 2,000 受试者）× 465 名独立留出用户**的严格评测下，下游眼动仪最难样本的 gaze 误差从 **3.05° 降到 2.80°**，且 E50U50 与 mean E95 的增益在每一档都统计显著（**p < 2×10⁻³**）。

## 要解决的问题

扩散模型做合成训练数据的通用难题：**低维连续标签 → 局部精细几何**的控制精度不够。

- 文本条件生成只判"宽泛的提示一致性"；
- 但监督训练要求"每张图 ↔ 其数值标签"精确对应。

在眼动追踪上这件事尤其难：4D 双眼注视是通过**极微弱、空间局部化的瞳孔与虹膜几何**表达的。"生成的图看着完全真实，但描绘的是另一个注视方向"——这样的样本对追踪器训练毫无价值。

**现实驱动力**：AR/VR 头显的近眼数据采集跨用户成本极高（Cheng et al., 2024; Jiang et al., 2026），而 gaze 是头显最核心的输入模态之一。

## 方法详解

### 核心思路：把全局标签"落地"成局部几何

不是让模型直接从 4D 数字去猜眼睛长什么样，而是**显式构造一个中间的空间条件**（pupil/iris mask），让几何与标签严格绑定。

**训练阶段**
- 用**冻结的 SegFormer** 从多样化的真实近眼图像中提取瞳孔/虹膜几何
- 扩散模型学习"在该几何条件下生成真实外观"
- 基础模型：SD3.5（gaze-conditioned）

**推理阶段**
- 用**物理眼睛渲染器（physical eye renderer）**采样与注视一致的几何——通过变化解剖参数与相机状态实现
- 因此**不需要源图像**即可合成，多样性由解剖/相机采样保证

### 条件注入方式的选择（8 种变体消融后确定）

在同一种 gaze-conditioned SD3.5 内，对比了：

| 方式 | 结果 |
|---|---|
| Channel concatenation（**GazeDiT 采用**） | 精度与算力权衡最优；Δp90 一致最低；**不引入任何控制网络或 mask token** |
| ControlNet（Zhang et al., 2023） | 训练成本 **1.5×** |
| OminiControl（Tan et al., 2025b） | 训练成本 **3.7×** |
| ControlNet++（Li et al., 2024） | 同上族 |
| Gaze-only（无空间条件，仅 4D 标签） | **Δp50 / Δp90 远差于任何 gaze+mask 方法**，且下游无可靠增益 |

> 注：ControlNet / OminiControl / ControlNet++ 在本文中是作为**掩码注入机制的替代消融**，不是下游基线方法。

mask 保真度：GazeDiT **84.92%** mask mIoU > OminiControl 84.53% > ControlNet 83.05%。

## 实验与结果

**评测设计的严谨程度是本文最大亮点：**

| 设计 | 做法 |
|---|---|
| 三档训练队列 | (i) 500 受试者 / 5M 帧；(ii) 1,000 受试者 / 7M 帧；(iii) 2,000 受试者 / 5M 帧 |
| 合成臂 | 每臂先在 **2M 生成图像-注视对**上预训练，再在对应真实队列上微调 |
| 留出测试 | **465 名留出用户**，与所有训练队列**互斥** |
| 冻结评测器 | 在**独立受试者池**上训练，与生成器训练/追踪器训练/测试受试者全部互斥 |
| 统计检验 | 配对 bootstrap，联合重采样用户后重算 Δ，双侧检验（hierarchical bootstrap 95% 半宽） |

**核心结果**

| 指标 | 数值 |
|---|---|
| 下游 gaze 误差（0.5K 队列，最难样本 E95U95） | **3.05° → 2.80°** |
| 显著性 | E50U50 与 mean E95 增益在**全部三档队列**均显著（**p < 2×10⁻³**） |
| 尾部标签误差 | 显著低于其他扩散基线，**逼近同一冻结评测器在真实图像上的误差** |

**关键消融发现**

- **Gaze-only 的问题**：尽管拿到了完整的 4 维注视标签，其 Δp50 / Δp90 在每一档都远大于任何 gaze+mask 方法，且下游相对 real-only **无可靠增益**。→ **光有标签不够，必须落到空间几何上。**
- **FID 会骗人**：Gaze-only 在 0.5K 队列上 FID 与 GazeDiT 相差不到 0.6，但**标签误差更差，整条管线没有可靠增益**。这说明在合成数据场景，外观指标（FID）无法替代标签保真度指标。
- OminiControl 的 E95U95 为 3.04° vs. real-only，**基本无增益**——进一步佐证"注入机制选择"是关键变量。

## 创新点与贡献

1. **问题定义精准**：把"扩散合成数据的标签保真度"从模糊诉求变成可测量的 Δp50 / Δp90（生成 vs. 真实的注视误差差）。
2. **label + geometry 双条件范式**：用物理渲染器在推理期采样几何，天然解耦"外观多样性"与"标签精确性"。
3. **实证的贡献分离**：用 8 种条件化变体 + 三档队列 + 配对 bootstrap，把"扩散是否有用"与"是否需要空间条件"两个问题干净地分开回答。
4. **对 XR 的直接价值**：眼动是头显核心输入模态，合成数据可显著降低跨用户标定成本。

## 局限与风险

- 增益幅度温和（3.05° → 2.80°，约 8%），主要来自**最难样本**；整体指标提升不以数量级计。
- 依赖物理眼睛渲染器与冻结 SegFormer 的质量，两者误差会传导。
- 仅在近眼双眼图像上验证，未展示跨设备泛化（不同头显的光学/相机布局差异大）。
- 无代码发布声明。
