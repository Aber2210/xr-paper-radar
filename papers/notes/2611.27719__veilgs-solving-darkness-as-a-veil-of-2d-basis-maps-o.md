# VeilGS：以二维基图「面纱」在 Retinex 3DGS 上求解暗光退化

## 一句话结论
首个「求解而非存储」每视图暗光退化的低光 3DGS：退化留在 Gaussians 之外的粗基上逐视图闭式 rank-one 求解并让训练穿过求解，NIQE 2.63 对 4.15、MOS 4.15 对 3.44，且不需配对正常光监督。

## 要解决的问题
暗光场景中亮度衰减在图像内空间非均匀（取决于各表面相对少量光源的位置），既有低光 3D 重建要么对整幅视图施加同一条色调曲线（灯旁暗物与暗角亮物得到相同校正），要么把暗度存进 3D 表示而与场景细节纠缠。逐图跑 2D 低光增强再重建又会破坏多视图一致性，产生 floaters 与颜色漂移。

## 方法详解
VeilGS 把退化建模为覆盖在清晰场景上的面纱：每个 Gaussian 以 albedo 与 shading latent 取代球谐，按 Retinex 分离表面颜色与光照；每个视图的暗化是一个空间变化 gain 后接全局 tone curve，gain 由一个小网络从观测读出粗基，其系数不学习而用可微 bilinear rank-one solver 逐视图求解。重建损失穿过该 solve 反传（variable projection 思路），使 Gaussians 无法吸收本可由 veil 解释的部分；另加 exposure/gray-world/Retinex 与单目深度先验，全部权重跨场景跨 benchmark 固定，且不使用任何配对正常光监督。

## 实验与结果
- Gaussian-DK 平均 NIQE = 2.63（Gaussian-DK 4.15）
- Gaussian-DK 平均 CLIP-IQA = 0.518（Gaussian-DK 0.487）
- Gaussian-DK 用户研究 MOS = 4.15（Gaussian-DK 3.44，p < 10^-9）
- LOM 平均 PSNR = 22.96 dB（I2-NeRF 22.87 dB）
- LOM 平均 LPIPS = 0.220（LITA-GS 0.233）
- LOM 渲染速度 = 407 FPS（Luminance-GS 397 FPS，同 GPU 同分辨率）

## 创新点与贡献
- 首个「求解而非存储」每视图暗光退化的低光 3DGS：把退化留在 Gaussians 之外的粗基上、逐视图闭式 rank-one 求解，并让训练穿过求解以阻止暗度被烘焙进几何，因此无需配对正常光监督、也不存 per-view 参数

## 局限与风险
- veil 是单一无彩 gain，无法去除彩色光源造成的色偏
- 低纹理场景下穿过 solve 的训练可能不稳定
- albedo–shading 分解不完美，暗区 albedo 可能残留绿色偏
- 作者也指出在 piano/snowman 上用户更偏好 Gaussian-DK，说明无参考指标漏掉了局部颜色伪影
