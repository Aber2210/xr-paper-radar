# Ref2Light：从单张图像生成可交互的裸眼 3D 角色

## 一句话结论
把合成目标直接定义到面板子像素几何（K<V 的 angular anchor + 可微三线性采样）而非追求更逼真的生成：消费级 GPU 上 1440×2560 面板 34–40 FPS、显存 1.23 GiB，VRoid 域内 LPIPS 降 20.12%–55.62%、Nat-RMSE 降 40% 以上。

## 要解决的问题
在光场显示器上驱动角色插画需要同时满足相干双眼视差、实时姿态articulation与细粒度表情控制，还要能快速切换角色，现有三条路线各自缺一项：单图 2D 动画器只输出单视图，直接广播到多视会失去视差、显得扁平（Problem 1）；subject-specific 3D avatar 需逐角色多视采集、3D 拟合与驱动蒸馏（Problem 2）；feed-forward 单图 3D 生成虽免采集，仍需先产出逐角色 3D 资产与 rigging 才能驱动（同 Problem 2）。此外现有光场管线在 subpixel interlacing 前必须渲染全部全分辨率视图，而每个视图只有稀疏子像素贡献到面板，造成大量计算与显存冗余（Problem 3）。

## 方法详解
把任务写成 $\hat Y=\mathcal{F}(R,p;\kappa)$：输入单张正面 A-pose 插画 $R$ 与 14 维控制 $p$（头/身旋转、眼/嘴开合、嘴曲率、眉高/间距/曲率、2D gaze），输出 $H_n\times W_n$ 的 native raster，$\kappa$ 为固定面板标定。核心是把光场合成分解为静态身份、视角相关视差、控制驱动articulation，并用 $K=12$ 个有序 angular anchor 近似 $V=40$ 个视图（约 40° 视锥）。共享编码器 $E_\theta$ 在 onboarding 时把参考图编码为多尺度特征并缓存，严格满足 $\partial F/\partial p=\partial F/\partial k=0$，下游经 U-Net skip 读取，实现换角色只付一次编码成本。解码器 $D_\theta$ 由 $p_g$（全局姿态，局部表情轴置中性）经 control MLP 与有界 FiLM 调制，联合预测 backward offset $U_k$、直接颜色 $D_k$ 与混合权重 $\alpha_k$，得 $A_k=(1-\alpha_k)\odot W_k+\alpha_k\odot D_k$，其中 $W_k$ 是用 $\mathrm{clip}(g+U_k)$ 对参考图双线性采样得到的纹理搬运，$D_k$ 负责斜视角新暴露区域。局部控制利用同一 $U_k$ 把像素映回 canonical 坐标、与缓存的 source range $\Omega_r$ 匹配来定位眼/眉/嘴 box（免逐帧检测器），共享 regional controller 预测 2D flow 与 RGB 残差，经平滑 mask $M$ 写回，保证 box 外零改动；零初始化头 $H_\psi$ 依 6 个头部角度对嘴闭合端点做 $\Delta Q_p$ 修正。输出端把 calibrated subpixel interlacing 写成对 $A^*$ 的参数无关三线性查找，全程可微，因此可直接用 native raster 监督。训练为 $\mathcal{L}_{pair}=\mathcal{L}_{rgb}+\lambda_f\ell_{M_f}(U,U^{gt})+\lambda_d\ell_{M_d}(D,I^{gt})+\lambda_n\mathcal{L}_{native}$ 加跨参考 replay 损失 $\mathcal{L}_\Delta$，总目标 $\mathcal{L}_{global}=0.2(\mathcal{L}_o+\mathcal{L}_a+\mathcal{L}_e)+0.4\mathcal{L}_{rep}$，三阶段（预训练冻结局部控制器、warm-up 修正头、联合 16k 步）+ 2,000 步 native 细化。

## 实验与结果
- VRoid 域内（N=48 未见身份）head-body：LPIPS 降 20.12%–55.62%、Nat-RMSE 降 40.42%–54.39%（vs 四个基线）
- 零样本 Genshin head-body（N=22）：Nat-RMSE 比 THA4+Depth 降 16.84%（19/22 身份改善）、比 THA4+Fixed Plane 降 21.37%、比 LHM-1B 降 30.44%
- Genshin LPIPS 比 THA4+Fixed Plane 降 5.01%、比 LHM-1B 降 33.98%；面部控制（N=24）Nat-RMSE 比 THA4+Depth 降 15.55%
- 10 身份局部集：Eye/Mouth Closure MAE 0.1324/0.0812，比 fixed-plane THA4 降 31.34%/67.91%
- 连续驱动（8 身份 × 3 条 32 帧轨迹）：head-body LPIPS 比 THA4+Fixed 降 22.51%、比 LHM-1B 降 55.05%、比 CharacterGen 降 52.58%
- 1440×2560 native raster 上 34.02–40.09 FPS，mean peak 1.226 GiB（LHM-1B 为 12.894 GiB）；8 个预对齐输入切换中位 0.661 s
- 直接 native 采样比「先展开 40 个全分辨率视图再 interlacing」快 3.42×

## 创新点与贡献
- 新意在于「display-native」而非「更逼真的生成」：把合成目标直接定义到面板的子像素几何，用 $K<V$ 的 angular anchor 加可微三线性采样替代 V 视图全渲染，使 native raster 监督能端到端回传到全局与局部模块
- 对应复用让面部编辑在 anchor 空间 in-place 完成，从结构上消除「表情与头姿耦合」导致的非目标纹理漂移

## 局限与风险
- 依赖固定 lenticular 标定 $\kappa$ 与预对齐输入（切换仍需 0.661 s，并非任意图即插即用）
- $K=12$ 是保真—成本折中，$K=40$ 时 LPIPS 仍为 0.1736，说明该表示的保真上限有限
- 全帧重建指标略逊 monolithic 解码（作者承认其全运动吞吐更高）
- 主体实验以 3D 资产渲染的 GT 视图为准，真实屏拍摄仅见附录示例
- 控制空间限 14 维且参考必须是正面 A-pose，无手部/道具交互
