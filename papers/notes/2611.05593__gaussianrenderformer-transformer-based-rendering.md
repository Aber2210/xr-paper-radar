# GaussianRenderFormer：基于 Transformer 的无光栅化器 3D 高斯渲染

## 一句话结论
GaussianRenderFormer 是首个渲染路径中不含光栅化器的 3D 高斯前馈神经渲染器：在 26,820 个 Objaverse 对象上训练后，对 300 个全新对象的 28 个视图渲染达 38.08 dB PSNR，而同一 20,000 高斯剪枝输入经 gsplat 光栅化为 44.02 dB；作者诊断该 5.9 dB 差距非泛化问题，证据指向视图解码器瓶颈（显式给出投影 footprint 可再涨 1.4 dB），且不排除训练不足。

## 要解决的问题
3D Gaussian Splatting 的每张图像都由手写光栅化器产生（投影、深度排序、逐像素 alpha 混合），现有针对 Gaussians 的学习模型只负责生成或修改高斯，最终仍交给 3DGS 光栅器渲染，尚无以高斯为输入、网络为唯一渲染器的前馈渲染器。此外，网格学习渲染器（RenderFormer）的做法能否迁移到高斯并不明确：高斯没有表面和材质、半透明且高度重叠，一个对象通常需要数万个高斯，而 RenderFormer 只在最多 4,096 个三角形的场景上训练过。

## 方法详解
每个高斯用 14 维向量 g_i=[μ_i, s_i, q_i, c_i, o_i]（中心 3、尺度 3、旋转四元数 4、颜色 3、不透明度 1）表示，经线性层 A∈R^{768×14} 加 RMSNorm 与共享可学习嵌入得 token t_i=e+RMSNorm(Ag_i+b)；视图无关的 scene encoder 为 12 层 self-attention（16 个 register tokens，对高斯中心施加 3D RoPE），每对象只跑一次。视图相关 view decoder 把图像切成 4×4 像素 patch（RenderFormer 为 8×8，射线方向最近邻上采样到 8×8 以复用预训练 ray embedding），6 层 cross-attention 到高斯 token 加 self-attention，末端接 DPT head 输出图像。相对 RenderFormer 的三处改动：(1) 对每个高斯投影到图像的 (u_i, v_i)（以 patch 为单位）施加 2D rotary embedding，每头每轴旋转 8 个 channel pair、8 个频率（0.25–1.75 rad/patch）；(2) 更小的 4×4 patch 使 token 数变 4 倍；(3) 把投影 footprint Σ'_i=J_i Σ_i J_i^T+0.3/p² I（0.3 平方像素为 gsplat 低通滤波项）用 4 个数（两个对数标准差与 (cos2θ, sin2θ)，裁剪到 [-6,6]）经零初始化线性层加到 cross-attention 的 key 上（共 23,040 个新参数）。训练从 RenderFormer 预训练权重出发，四阶段：先只训新输入层（33.5k 步、256 分辨率），再全模型（402k 步、256），短暂开启三处改动恢复（3k 步），最后 512 分辨率加 LPIPS（385k 步）；损失为 (1-λ)L1^w+λ·LPIPS(VGG)，λ=0.5，背景权重 0.05，AdamW weight decay 0.01，8 GPU 每卡 8 视图。

## 实验与结果
数据取自 Objaverse_Splats（ShapeSplat 子集，PSNR≥32 dB、LPIPS≤0.06、恰有 50,000 高斯的 splat），过滤后 26,820 训练 / 1,806 验证；用 LightGaussian 式重要性分数剪枝到 20,000 高斯并微调 1,500 步（L1+0.2 D-SSIM，每对象约 10 秒），训练目标是复现完整 splat 的渲染。评测分 300 个 fresh held-out、300 个 development held-out 与 300 个训练对象，指标在物体裁剪区内计算。主结果（对未剪枝渲染，28 视图）：Ours 38.08 dB PSNR / masked 32.68 dB / SSIM 0.9814 / LPIPS 0.0113，gsplat on the input 为 44.02 / 39.19 / 0.9954 / 0.0046；4 视图@1.7 处为 38.36 对 44.97；差距随相机距离从 1.15 处 3.9 dB 到 1.7 处 6.8 dB；训练对象上 38.25，与 held-out 仅差 0.17 dB，证明非泛化差距。1,000 对象消融线（held-out PSNR 34.42 起）：去 footprint -1.71±0.07 dB、去 2D RoPE -5.20±0.18 dB、8×8 patch -3.05±0.10 dB、windowed cross-attention 仅 +0.20 dB、footprint 去 0.3 像素²项仅 -0.08 dB、footprint 同时加 key+value +0.68 dB、换随机种子 +0.02 dB；全尺度下去 footprint 为 36.67（低 1.4 dB）。256 分辨率全量消融显示先只训输入层比全程联合训高 3.1 dB，随机权重则塌缩为全黑。效率：单视图 275 ms（场景编码器 151 ms + 视图解码器 124 ms）、峰值显存 2.8 GB、195M 参数（编码器 113M、解码器 82M），gsplat 渲染同输入 <1 ms；640,000 高斯时模型需 75 s / 23.7 GB 而 gsplat <3 ms / 0.1 GB。训练总耗 1,327 GPU-hours，最终 run 每翻倍步数仍涨约 0.9 dB。

## 创新点与贡献
提出（自称）首个对给定 3D 高斯集合、渲染器中完全无光栅化器的前馈神经渲染器 GaussianRenderFormer。系统地把网格渲染器的视图解码器改造以适配高斯：投影位置 2D rotary embedding、投影 footprint 加在注意力 key 上、更小 patch，三处改动均在中尺度和全尺度分别消融。给出与光栅化差距来源的完整诊断：非泛化差距（训练对象同样差 5.9 dB）、与视图解码器瓶颈一致、footprint 可推断却显式给仍涨 1.4 dB，同时如实保留训练不足的可能性。报告训练设定之外的行为（分辨率、FOV、距离、更密输入、真实 Mip-NeRF 360 区域捕获）与失败分析。

## 局限与风险
质量与速度均不实用：比光栅化同输入低数 dB、慢数百倍、显存高一个量级，且时间随高斯数近似平方增长。只做对象级、相机在物体外的设定，完整场景（相机在场景内）未解决。仅在单一相机配置（512×512、45° FOV、距离 1.15–2.45）下表现好，256/1024 像素掉到约 33 dB、过远相机 24.09 dB、40,000 高斯掉 3.1 dB（光栅化反涨 4.6 dB）。仅用视图无关颜色，无法渲染球谐视图相关效果，也不能重光照。输入准备仍用光栅化器（剪枝打分与微调）。受 RenderFormer 设计束缚：只有零初始化增量改动有效，未能找到从随机权重训练的配方，更不自由的重新设计无法评估。

## 与文献库的关系
属于新问题：文献库中前馈重建、语义、生成类工作都以高斯为输出并仍用光栅化渲染，本文首次把高斯当输入、图像当输出；与 RenderFormer/LVSM 等无光栅化学习渲染器构成同一路线的对象级延伸，但输入是显式高斯而非网格或图像，因此可与同一输入的光栅化直接对比。

## 可复现性（代码/数据/硬件）
代码、训练权重、stage-2 检查点、对象清单与全部实验脚本在 GitHub（SVLwoof/gaussianformer，MIT 许可），三个模型在 HuggingFace（shahafvl/gaussianformer-v22 最终模型、v21 无 footprint、gaussianformer-256px），paper/README.md 给出每个表图的命令与预期数字。训练需多 GPU（8 GPU、batch 8 视图）与约 1,327 GPU-hours（L40S/A40/RTX Pro 6000 混合）；从公开的 stage-2 检查点起可精确复现阶段 3+4（约 620 GPU-hours），从 RenderFormer 权重端到端四阶段有文档但作者未完整跑过。

## 行动建议
做高斯渲染的从业者若跟进此方向，应把预算优先投给视图解码器的训练量与显式几何提示（2D RoPE 与 footprint 的配合已被证明是差距主因），并明确只在受训相机配置内部署，同时准备 8 卡级算力复现或继续训练。
