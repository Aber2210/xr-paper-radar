# SpatialMem：以分层记忆构建定量空间推理智能体

## 一句话结论
分层记忆 + 可编排视觉专家做定量空间推理，MetricBench 整体较最佳 VLM 提升 32%（室外 75.5% vs Gemini-3.1-Pro 40.3%）。

## 要解决的问题
VLM 在相对位置、远近比较等定性空间任务上已较强，但涉及精确米制距离与物体尺寸的定量推理仍差。现有做法让 VLM 智能体调用外部视觉工具，却通常把每个功能需求绑定到单一预定义专家，隐含形成固定而僵硬的工具流水线；例如深度估计永远用同一个模型，检测永远用同一个检测器。实际中同一功能可由多个专家承担，不同流水线与组件在几何条件、室内外场景和任务类别上的有效性差异很大，单一专家严重限制适应性。若允许自由组合，搜索空间又呈组合爆炸，智能体难以选出最优流水线与专家。与此同时，既有空间推理基准存在引用歧义、实例被截断、物体模糊等质量问题，场景类型与任务覆盖也有限，导致结论不可靠。论文要解决的是：如何让智能体从历史执行中积累工具使用经验，在分层记忆引导下为不同场景与任务自适应编排专家，并给出质量可控的定量基准。

## 方法详解
把异构工具空间组织为 P 个功能组 G={G_1,…,G_P}，同组专家功能相同但适用条件互补，例如深度组 G_depth={UniDepth, DepthPro, MoGe-2}，总工具集 T 为各组并集，覆盖点云、分割、2D 定位、3D 定位与指向。任务形式为多轮工具增强问答：给定图像 I 与查询 Q，智能体逐步调用专家并输出数值答案 A。SpatialMem 建两級记忆树：第一层按环境 s∈{Indoor,Outdoor} 划分，第二层按任务 c∈{OO Dist.,OC Dist.,Obj. Size} 划分，每个 (s,c) 对应独立记忆池 Mem(s,c)。感知模型 M_perceiver 先预测 (s,c) 完成路由；执行器 M_executor 产生轨迹 Γ={r_1,t_1,o_1,…,r_n,t_n,o_n,a}，含推理、工具调用、视觉输出与答案；以真值核验得到 r∈{0,1}，摘要器 M_summarizer 抽取纯工具序列 τ={t_1,…,t_n}，并把 r 追加到经验向量 r_τ(s,c)。失败时进入演化态：摘要器分析完整轨迹与中间视觉输出，诊断错误，再通过同功能替换与重排合成候选 τ+；同一记忆池同时最多一个演化中轨迹，τ+ 在随后 N 次同类别查询中被强制作为检索先验，期满记录得分序列并决定是否并入确认池。检索时按经验均值准确率取 top-K 注入执行器上下文。超参取 N=5、K=1。数据侧构建 MetricBench：从 Omni3D 的 SUNRGBD、KITTI、nuScenes 取 658 题，覆盖 81 类、20 cm 到 50 m；只保留类别在图中唯一的实例以避免歧义，可见度阈值 0.9，剔除与图像边界相交的截断框，按类别与真值区间分层采样，再人工清洗。评委用 GPT-4o 抽取数值并统一单位，预测落在真值 0.80 到 1.25 倍内记为成功；执行器、感知器与摘要器均基于 GPT-5.4-Nano。

## 实验与结果
- MetricBench 共 658 题、81 类、跨度 20 cm 到 50 m
- offline 版本室内 61.8%、室外 75.5%，无记忆智能体为 49.0%/68.9%，绝对提升 12.8 与 6.6 个百分点，平均 9.1
- 相对最佳 VLM 基线整体提升 32%
- MetricBench 室外纯 VLM 最好的 Gemini-3.1-Pro-Preview 为 40.3%，SpatialMem 达 75.5%
- 室内三类任务：OO 距离 57.8% 对无记忆 36.8%，OC 距离 89.2% 对 79.3%，尺寸 38.6% 对 31.1%
- SpatialRGPT-Quantitative 宽度从 57.9% 提到 84.2%，垂直距离从 63.2% 提到 81.1%
- QSpatial-ScanNet 的 OO 距离从 41.2% 提到 69.6%
- 消融：去任务级记忆降至 51.6%/65.5%，去场景级 58.2%/72.3%，去领域结构 51.7%/65.5%，去轨迹优化 49.0%/67.9%，其中室内 OO 距离由 57.8% 跌到 33.3%
- 演化周期 N 从 1 增到 5，室内/室外由 54.5%/69.1% 升到 61.8%/75.5%
- N=7 反而下降
- K=1 最优，更大 K 引入相互冲突的先验
- 远距离鲁棒性：RoboRefer-8B 从近距 84.5% 跌到远距 12.0%，SpatialRGPT-8B 近距之外接近 0
- SpatialMem 在远距仍保持 75% 以上
- 路由基线：Random 室内 47.3%、Majority 54.3%、Per-task Oracle 67.0%
- SpatialMem 61.8%，接近穷举 oracle 而上限并不需要任务级搜索

## 创新点与贡献
- 把「功能组内多专家选择」与「流水线编排」显式建模为组合优化问题，并用经验记忆替代穷举搜索。
- 两级记忆树按室内外与三类定量任务硬隔离，减少跨域检索污染；消融显示任务级分区比场景级更关键。
- 双态记忆：构建态记录成功轨迹及经验得分，演化态对失败轨迹做诊断式改写，并以有限试用期验证后再晋升。
- 发布 MetricBench，用唯一类别、0.9 可见度、去截断与分层采样修正既有基准的歧义与长尾偏置。

## 局限与风险
- 作者自述记忆层级依赖预定义的场景与任务类别，难以直接迁移到非空间或纯文本的长程任务
- 记忆演化依赖足够交互经验与可靠反馈
- 实验进一步显示，使用 VLM 自身反馈时所有记忆方法都退化，说明框架在无真值场景下并不稳
- MetricBench 仅 658 题，成功阈值只有 0.80 到 1.25 倍这一档，无法区分 5% 与 20% 的误差
- 训练集虽与测试集分场景，但仍同源 Omni3D，跨数据集分布偏移只在 QSpatial++ 上部分体现
- 系统由 GPT-5.4-Nano 与多个大模型工具串成，延迟与 API 成本未报告，在线演化还会把错误策略短时强加给后续查询
- 方法不涉及真实机器人闭环
