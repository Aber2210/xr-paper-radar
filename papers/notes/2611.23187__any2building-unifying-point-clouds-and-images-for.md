# Any2Building：以共享空间查询统一点云与图像的建筑物重建

## 一句话结论
以共享 3D 空间查询 + 完整表面占用监督统一点云补全与影像生成，low-poly F-score 80.14→94.27。

## 要解决的问题
LoD2 建筑重建的观测天然异质：部分点云给出不完整的 3D 表面测量，正射影像给出 footprint、屋面布局与屋顶构筑物的视觉线索但高度与遮挡面不确定。然而点云补全与图像生成长期被当作两个任务，现有方法都绑定单一观测设定：BuildAnyPoint 的体素对齐条件不便接入图像，SatSkylines 的噪声空间注入难以扩展到点云且会模糊细节，通用生成器（Axolotl3D、Hunyuan3D-Omni）直接拼接视觉与几何 token，把跨模态结构对齐和缺失几何推断都丢给生成器。缺的是一个把异质观测与完整建筑结构在 3D 上对齐的共享表示，从而支持任一模态或组合，并产生跨任务正迁移。

## 方法详解
在 16³ 低分辨率 3D 网格上放 N=16³ 个 shared spatial queries，所有输入、查询与输出 64³ 体素共用一个归一化建筑坐标系，该坐标系与地理参考正射影像绑定，因此纯影像模式下结果也能反算回真实位置。tokenizer 分模态：点云用 4 级 EdgeConv（16 近邻）加 FPS 采样 2048→1024 中心，位置与局部特征经两个 MLP 相加得 1024×1024 token；影像用冻结 DINOv3 的 patch token；LoD0（三维 bbox）或 LoD1（footprint 按高度拉伸）先验体素化成 64³ 表面占用网格（内部留空），对每个对应 16³ cell 的 4³ block 计算表面占用存在 s_j、边界存在 b_j、占用率 ρ_j，经 MLP 编码。query 由位置编码与全局描述符（各模态均值池化特征 + availability flag，缺失模态补零）初始化；有先验时再以 s_j 与 φ_R(r_j) 做残差更新，且保留全部 query 位置以便生成超出先验占用的结构，训练时用 prior dropout 降低依赖。查询通过 cross-attention 分别读点/图 token，缺失模态读出为零，再拼接 availability flag 经 MLP 与 self-attention 得 Q。关键监督是占用辅助头：把完整建筑的 64³ 参考网格 max-pool 到 16³ 作为 target，用 BCE 监督 Q 的表面占用，迫使 query 在生成前就编码含未观测区的整体结构（该损失只监督 Q，不监督最终体素）。Q 以两条路径进入生成器：QE token（H_QE=H+Attn_back(LN(H),Q,Q)，点图双模时先用图 token 与 512 个可学习补全 query 更新点 token）与 spatial prompt（在选定 DiT block 上按同一 grid index 加零初始化线性投影的残差 h_ℓ←h_ℓ+βP_ℓ(LN(Q))）。主干是 flow-matching DiT，生成 16³ structure latent，速度目标 u_t=(1-σ_min)ε-x_0，损失为 flow MSE 加 λ_occ L_occ 与 λ_geo L_geo（把 x_t 按式 9 系数估回 x̂_0、解码成体素后做 BCE+Dice）。训练等概率采样 (P)、(I)、(P,I)、(I,R) 四种模式，共享 conditioner、generator 与同一完整建筑 target，QE token 与 spatial prompt 联合 dropout 以支持 CFG。LoD2 构建阶段：structure decoder 出 64³ 体素，在占用坐标 Ω 上运行去掉图像条件的 surface latent 生成器（作者发现仅凭预测体素已足够，额外点云条件反而降精度），再用 RoLoPM 做 low-poly remeshing；纹理用 ControlNet 依未贴图渲染与从影像/城市名推断的外观描述合成 facade 参考，再由预训练 texture generator 贴图。

## 实验与结果
- Building-PCC：点云 F-score 96.12%、CD 0.20、EMD 0.07（BuildAnyPoint 91.38%/0.35/0.10）
- low-poly F-score 94.27% vs 80.14%，CD 0.30 vs 0.66，顶点/面数比偏差 e_V=0.08、e_F=0.07（BuildAnyPoint 0.23/0.27）
- BuildingWorld-Image 单模态点云补全：low-poly CD_L1 8.65、F 97.19% vs AdaPoinTr 11.05/92.00%、BuildAnyPoint 12.88/92.00%、UniCo 11.28/91.00%
- 多模态补全（更稀疏点云 + 影像）：low-poly CD_L1 26.00、F 77.41% vs MAENet 46.11/52.00%、Hunyuan3D-Omni 44.52/50.00%、EGIInet 44.98/51.00%
- 单张正射影像生成：CD_L1 38.90、F 62.82%、PSNR 12.63 dB/SSIM 0.34 vs TRELLIS 54.89/49.20%/10.91/0.26、TRELLIS.2 65.09/31.05%、SAM 3D 55.82/44.34%
- 影像 + 粗几何先验：CD_L1 17.23、F 78.64%、PSNR 14.05/SSIM 0.41 vs SatSkylines 33.12/59.62%/11.21/0.28、SpaceControl 34.77/61.93%、Hunyuan3D-Omni 32.46/60.82%
- 消融：去占用监督后 I 由 62.82% 降至 54.83%、I+R 由 78.64% 降至 64.03%
- 去 spatial prompts 时 I+R 降至 57.02%
- 联合训练比四个单任务 specialist 分别高 1.89/5.44/4.50/1.81 点（P/I/P+I/I+R）
- 影像增益随点稀疏放大——2048 点 +3.02 点，41 点随机降采样 +25.65 点，裁剪后 41 点 +27.08 点

## 创新点与贡献
- 用“共享 3D 空间查询 + 完整建筑表面占用监督”把点云补全与图像生成统一成同一条件接口，而不是拼接异构 token 让生成器自己解跨模态关系
- 占用监督使中间表示在生成前就补全未观测结构，这是区别于 SDFusion/CLAY/Hunyuan3D-Omni 的关键
- 一个联合训练生成器覆盖四种输入模式并给出正迁移证据
- 同时贡献约百万级对齐三元组、跨 18 城市的 BuildingWorld-Image
- 并证明仅凭预测体素即可驱动 surface 生成，省去点/图条件

## 局限与风险
- 输出走 64³ 体素 → surface 生成 → RoLoPM 三段式，细节受体素分辨率与 low-poly 简化限制，作者也发现额外点云条件反而降低精度、增加耗时
- 纯影像模式外观质量仍弱（PSNR 12.63 dB、SSIM 0.34），纹理依赖 ControlNet 合成的 facade 参考而非真实观测
- 评测以 Building-PCC 与影像-低模配对的 BuildingWorld-Image 为主，遮挡、多屋面层级、建筑群与错误源轮廓在数据构建中被列为需人工复核的难例，真实城市大场景的泛化未验证
