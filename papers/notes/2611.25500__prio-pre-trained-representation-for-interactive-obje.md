# PRIO：面向 4D 世界可交互物体的预训练表征

## 一句话结论
单次前向预测物体的构型空间（拉格朗日广义坐标），使 4D 世界中的物体可实时按物理规律响应：Chamfer-L1 比 PhysSkin 低 60%、比 VBD 快 7.1×。

## 要解决的问题
3D 世界已能大规模采集、重建与生成，但其中的物体是静止的：枕头按下去不会凹陷、门被拉不会开。要让交互式 4D 世界成立，物体动力学必须同时满足两点——对任意新物体可用，且实时响应。论文指出既有工作只能各拿一半。视频世界模型从图像与动作生成可信未来，但输出是像素而非物体，每步都要跑昂贵生成模型；物理落地的方法（PhysDreamer、PhysCtrl、WonderPlay、RealWonder）接受动作输入，但产生一次运动要 68 s 到 4.6 h，无法闭环。紧凑构型空间（LiCROM、Simplicits、模态约化）用少量坐标描述运动，且是线性的，因此动力学所需量可预计算、交互实时，但每个物体都要从仿真轨迹或弹性势单独构建，换物体就重来，毫无迁移。NeuROK 从大规模 4D 数据学到可迁移的构型空间，补上了迁移，但它的空间是非线性的，导致质量矩阵依赖 q、出现速度相关项，动力学的每一步都必须跑网络。于是形成明确的两难：预训练空间能迁移但不能实时，线性空间能实时但不迁移，而交互式 4D 世界两者都要。论文还指出一个被忽视的次生问题：编码器-解码器式方法只能找到编码器给出的潜坐标。

## 方法详解
表示：物体由 n 个点（网格顶点、点云或 3D 高斯中心）的静止位置 X_1..X_n 描述，称几何 G，并把静止态当作 rest state。构型空间 M_G⊂R^{3n} 用连续线性映射近似：x(X)=X+Φ_G(X)q，q∈R^K（实验中 K=512），把 n 点堆叠得 x=X+Φq，Φ∈R^{3n×K}。因 Φ_G 连续，可在任意点求值，故网格、点云、高斯共用一套公式；关节物体用局部仿射参数化同一形式。架构三分：形状特征——表面采样 N_p 点，MLP 编码傅里叶特征 γ(p_j)，经 N_b 个 DiffusionNet 块用点云拉普拉斯在学习的多时间尺度上扩散得 f_j∈R^C，再用最远点采样选子集，过自注意力得 N_t 个形状 token T；查询特征——Φ_G 需在任意 X 求值，故在 S 个尺度上对 k 近邻做高斯加权插值 h_G(X)=[Σ_{p_j∈N_k(X)} w_s(X,p_j) f_j^{(s)}]_{s=1..S}，权重按学习宽度 σ_s(X) 归一并在邻域边界降为零，保证随 X 连续变化，从而形变空间连贯；解码器——Φ_G(X)=D(γ(X),h_G(X);T)，MLP 与残差交叉注意力块交替，输出头分 B 支各产 K/B 列。关键约束：查询点之间不做注意力，故预测与「还查了哪些点」无关，可任意分辨率求值。学习：因式 1 对 q 线性，最优潜坐标有闭式解 q*=argmin‖Φq−u‖²=Φ⁺u（u=x−X 为形变），即最小范数最小二乘，不需编码器，且梯度可穿过该解直接训练 Φ_G；这样拟合质量度量的是「空间能解释观测的程度」，而非编码器好坏。训练目标 L=(1/ū²)‖Φ′q*−u′‖²+λ_d L_d+λ_q‖q*‖²：第一项在另一组采样点 X̃′（N_r 个，与拟合用的 X̃ 的 N_f 个不必重合）上评估，迫使空间在未拟合点也正确；第二项是平滑项 L_d=Σ_iΣ_{j∈E(i)}‖J(X_i)(X_j−X_i)−(u_j−u_i)‖²/‖X_j−X_i‖²，J=∂(Φ_G q*)/∂X，抑制采样点之间的折皱；第三项约束坐标幅值（类比 DeepSDF 的潜码先验）。动力学：把 q 当广义坐标，欧拉-拉格朗日方程 (d/dt)(∂L/∂q̇)−∂L/∂q=Q_ext，L=E_k−V。因映射对 q 线性，点速度 ẋ=Φq̇，动能 E_k=½q̇ᵀMq̇，M=ΦᵀM_xΦ，M_x 为物理空间质量矩阵；非线性映射下 M 一般依赖 q 并引入速度相关项（NeuROK 即如此），此处 M 与 q 无关，方程退化为 Mq̈+∇_qV(q)=Q_ext，外力投影 Q_ext=Φᵀf_ext，用隐式欧拉积分。实时性来源：∂x/∂q=Φ 恒定、二阶导为零，故 Φ 与 M 可预计算；势能导数用同一矩阵投影 ∇_qV=Φᵀ∇_xV、∇²_qV=Φᵀ(∇²_xV)Φ，每步只解几百维稠密系统再映回全几何，无网络推理，投影与重建可在 GPU 上批处理。预训练只用 4D 轨迹的构型，不需物理标签。

## 实验与结果
- 逆运动学拟合（未见物体）：Chamfer-L1 0.00522、Chamfer-L2 0.000054、IoU 0.975，全面最优
- 次优 PhysSkin 为 0.01299/0.000419/0.886（L1 低约 60%），NeuROK 为 0.04300/0.004487/0.679
- 与 VBD 在同网格、同 GPU、同设置下跑到收敛：PRIO 快 7.1 倍，表面差异平均仅物体尺寸的 0.1%
- 4D 生成对比（VLM 五级评分）：SA 5.00/PC 4.53/VQ 4.94，NeuROK 4.33/3.72/3.97，PhysDreamer 3.33/3.22/3.94，RealWonder 3.39/3.17/3.44，PhysCtrl 2.58/1.89/2.89
- 端到端 36 s 对 NeuROK 34 min、PhysDreamer 4.6 h、RealWonder 2.8 min
- 预训练规模从 266 增至 534/1,068/2,142 个物体（同等约 100k 步预算），未见形状重建误差 2.19%→1.43%
- 真实捕捉 Deform360 上零样本迁移误差随预训练规模 7.71%→7.43%→7.09%→6.98%（10 个随机物体）
- 机器人应用：145k 三角面的枕头单步 7.6 ms
- 人形机器人同时抓取 8 个毛绒玩具（合计近 100 万三角面）平均 25 ms/步
- 实时交互：3D 高斯榕树 125–292 FPS、点云花 155–167 FPS，均无逐步网络推理
- 消融：去掉 shape tokens 重建 1.43%→2.63%、稀疏 IK 6.61%→8.58%
- 去掉 L_d 重建 1.50%、稀疏 IK 8.38%，说明两项设计主要改善未观测区域的填充

## 创新点与贡献
- 首次把「预训练得到的可迁移构型先验」与「线性构型映射」合到一处：网络每物体只跑一次，动力学阶段零推理。
- 给出线性性带来的闭式最优潜坐标 q*=Φ⁺u，从而免去编码器、让预训练直接监督空间本身，并把拟合误差变成对空间的度量。
- 提出双采样点训练（在 X̃ 上拟合、在 X̃′ 上算损失）加雅可比平滑项，保证空间插值与未观测区域外推的连续性。
- 把质量矩阵 M=ΦᵀM_xΦ 证成与 q 无关，使动力学退化为常质量系统并支持一次性预计算，是把「实时」变成结构性质而非工程优化。
- 同一 Φ_G 直接作用于网格、点云与 3D 高斯，并给出关节物体的局部仿射扩展，横向打通重建/生成管线的资产格式。

## 局限与风险
- 作者自述：预测的构型是连续低维的，因此撕裂、断裂等拓扑变化与流体等预训练中未出现的行为都在表达能力之外
- 扩展预训练数据是自然的下一步
- 从实验设计看还有：预训练完全使用仿真 4D 轨迹，真实数据只在 Deform360 上做零样本逆运动学评估（10 个物体），未用真实数据训练，sim-to-real 的材质差异没有被量化
- 每个物体仍需一次前向加一次 M 的组装，物体数很多时这部分成本未被讨论
- VLM 评分的 4D 对比只有 3 个物体 3 个动作，且 VLM 评判本身带偏置，SA/PC/VQ 都缺人类基线
- 稀疏 IK 误差（6.61%）远高于稠密重建（1.43%），说明只给少量约束点时空间填充能力有限
- 质量、弹性等物理参数如何取得（假定均匀？）在正文未交代，直接影响动力学可信度
- 代码未发布
