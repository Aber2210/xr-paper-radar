# InterGS+：几何感知 Transformer 预测与自适应残差编码的帧间 Gaussian Splatting 压缩

## 一句话结论
把 SH 的外观建模整体搬到共享 PCA 域（预测、transformer 训练与残差 VQ 共用同一紧凑空间，无需序列级变换信令），并把几何结构显式注入 attention：10 条 MPEG 动态序列平均 BD-rate 相对 G-PCC Amd.1 降 45.48%、相对 InterGS-Lite 降 7.78%，BD-PSNR 分别 +9.98 / +1.10 dB。

## 要解决的问题
动态 3DGS 每帧都是无序、不规则的高维 Gaussian 集合（56 维属性：48 维 SH + 不透明度 + 3 尺度 + 4 元四元数），存储与传输开销巨大；而 Gaussian 原语跨帧不保持固定身份，无法像视频那样直接做运动补偿。已有的 lightweight KNN/双边预测没有利用高维 SH 的结构，非 SH 属性又在未经渲染激活的原始参数域上做残差，保留了与渲染无关的冗余。

## 方法详解
InterGS+ 是一个 post-hoc 帧间编解码器，GOP 首帧为 I 帧，后续 P 帧只参考前一重建帧。先用 G-PCC 编码当前帧量化几何并重建，再把参考帧几何用 Q_t(Q_{t-1}^{-1}(·)) 映射到当前帧量化格点，保证编解码端邻域一致。SH 先经固定全局 PCA 从 48 维降到 38 维（保留约 99.99% 方差，基与均值离线学习、全序列共享、不传输），预测与残差编码都在该域进行。预测端保留 InterGS-Lite 的 8 个 KNN 候选与几何亲和加权双边候选，另加一个轻量几何感知 SH transformer：取 K_T=32 个参考邻居，token 为 [38 维 SH-PCA; 3 维几何偏移]∈R^41 并按亲和度 a_ik 门控；PE-Block 在 token 与 attention logit 两级注入几何（邻居秩嵌入 ρ_k、几何偏移嵌入 φ_geo、多频 Fourier 特征 φ_F、成对相对位置偏置 φ_bias），单头注意力 + 64→128→64 GeLU FFN，仅 53,964 参数。每个 Gaussian 在 10 种 SH 模式与 9 种非 SH 模式间做自适应选择，打包成 90 个符号（≤7 bit）。残差按属性定制：SH 创新在 PCA 域按 3+35 分组做 42/8 中心 VQ 加标量细化；不透明度与尺度先过原生激活（sigmoid / exp）再做 gamma companding 后求差并均匀量化；旋转先做尺度-旋转联合规范化、四元数归一化与符号对齐，再用每帧 32 中心 VQ + 标量细化联合编码 4 维创新。码流用 7z/LZMA 无损压缩，解码端从重建参考重新生成预测。

## 实验与结果
- 10 条 MPEG 动态序列平均 BD-rate 相对 G-PCC Amd.1 降低 45.48%、相对 InterGS-Lite 降低 7.78%；BD-PSNR 分别提升 9.98 dB 与 1.10 dB
- 相对 G-PCC 的最大降幅：Musical 67.08%、Makeup 66.59%、Trio 64.38%；训练未见过的 ManWithFruit-tracked 仍降 14.05%（+1.97 dB）
- 解码复杂度平均 0.049 ms/Gaussian（仅解码，不含渲染），学习推理只作用于 SH 且仅 53,964 参数
- SH 从 48 维降到 38 维 PCA，保留约 99.99% 方差；24/28 维会引入高码率 PSNR 上限
- 最高码率点总码率 84.8–319.6 bits/Gaussian，对应 PSNR 47.3–64.9 dB

## 创新点与贡献
- 把 SH 的外观建模整体搬到共享 PCA 域，使预测、transformer 训练与残差 VQ 共用同一紧凑空间，且不需要序列级变换信令
- 首次在 Gaussian 压缩中把几何结构显式注入 attention（秩嵌入、偏移嵌入、Fourier、相对位置偏置），并保留逐 Gaussian 模式回退
- 非 SH 残差按属性的渲染语义定制（激活域 companding、四元数符号对齐与联合 VQ），比统一在参数域做差更能压掉与渲染无关的冗余

## 局限与风险
- 仍依赖前一重建帧的单参考因果结构，长时依赖与多参考预测留作未来工作，快速运动或遮挡切换时预测会失效
- 几何用 18-bit G-PCC 单独编码且占比不小（22.9–39.8 bpp），未与属性联合优化
- 消融多以 RD 曲线图呈现，缺少逐模块的完整 BD-rate 表
- VQ 码本与 PCA 基为离线固定，跨内容适应性有限
