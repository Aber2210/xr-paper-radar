# InterBand-EMG：面向可泛化手部姿态估计的跨频带基础模型

## 一句话结论
用频带特异量化 + 跨频带重建 + 结构化掩码码预测把「频带间互补」变成预训练目标，并发布 8 通道 / 499 用户 / 约 1,228 小时的 SynapMyo：三划分 MAE 7.28°/9.70°/10.00°，降幅 0.3–4.3%。

## 要解决的问题
表面肌电（sEMG）可做连续手部姿态估计，但学习跨用户、跨动作可泛化的表征很难：解剖结构、电极位置与皮肤接触因人而异；而现有自监督方法多以离散码预测或信号重建为目标，未必保留连续跟踪所需的细微运动差异。

## 方法详解
提出 InterBand-EMG：先按频带做独立量化得到 band-specific 码本，再用跨频带重建（由其他频带推断被掩蔽频带）与结构化掩码码预测学习可迁移的 EMG 表征，随后用这些离散码重训一个宽带编码器用于连续姿态估计。同时发布 SynapMyo：8 通道 EMG-姿态数据集，统一关节角表示并固定留出用户/动作划分。训练解码器以 50 Hz 输出 250 个姿态估计，评测 20 个关节角平均绝对角误差与 17 个 UmeTrack 关键点距离。

## 实验与结果
- emg2pose User 划分 MAE = 7.28°（NHN 7.30°，vemg2pose 7.70°）
- emg2pose Stage 划分 MAE = 9.70°（NHN 10.12°，vemg2pose 11.20°）
- emg2pose User+Stage 划分 MAE = 10.00°（NHN 10.16°，vemg2pose 11.03°）
- MAE 相对最强基线降低 = 0.3–4.2%（emg2pose）、16.2–24.2%（SynapMyo）
- SynapMyo 规模 = 1,227.74 hand-hours、499 users、68 movement categories（8 通道）
- 关键点距离 = 8.81 mm（User）/ 11.95 mm（Stage）/ 12.73 mm（User+Stage）

## 创新点与贡献
- 用频带特异量化 + 跨频带重建 + 结构化掩码码预测做 EMG 预训练，把「频带间互补」显式作为预训练目标
- 并发布 8 通道、499 用户、约 1,228 小时的 SynapMyo 数据集与固定划分

## 局限与风险
- 增益幅度在 emg2pose 上仅 0.3–4.2%（相对最强基线），提升有限
- 8 通道 SynapMyo 与 16 通道 emg2pose 存在通道数与采集域差
- 电极位置与皮肤接触差异仍是跨用户泛化的主要障碍
