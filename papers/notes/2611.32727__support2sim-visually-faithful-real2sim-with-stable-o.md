# Support2Sim：具有稳定物体支撑关系的视觉保真 Real2Sim

## 一句话结论
把「支撑图」提为连接感知与仿真的中心数据结构，同一张 DAG 同时决定落座顺序、多支撑物体的位姿采样约束与细化优先级，多支撑用成对接触点加解析 roll 的闭式候选替代随机采样：50 场景 10 s 后 source-mask IoU 51.7% vs 最强基线 40.7%，intended supports 实现 87.1%。

## 要解决的问题
从单张 RGB 重建可用于物理仿真的场景，需要同时恢复空间布局与支配行为的支撑关系；而不同 3D 位姿可以投影出几乎相同的轮廓，深度或位姿的小误差就会让本应接触的表面出现缝隙或穿插。物体位姿彼此耦合：把一个支撑物挪去补缝，会破坏另一处接触，重力沉降还会把场景整体推离观测布局。量化上，最强基线 SimFoundry 在 10 s 后 source-mask IoU 仅 40.7、Picasso 只有 16.4，且 agentic 方案推理成本随规模变得不可承受。

## 方法详解
把问题写成带预算的优化：max (source fidelity, support realization, stability) s.t. T_gen(S)≤B。感知链为 VLM 给物体标签与 box → SAM 3 出实例 mask → Depth Anything 3 估深度与内参 → SAM 3D Objects 逐实例重建带纹理 mesh，VLM 再给每物体质量估计。支撑图是中枢数据结构：VLM 看原图与叠加 mask 轮廓和 ID 的副本，推断直接静置关系，形成 DAG G=(V,E)，i→j 表示 i 放在 j 上；目标物体与其直接支撑 S_i 构成 support group，支撑图同时决定落座顺序、多支撑位姿采样约束与细化分组。RANSAC 拟合地面或台面点得重力对齐世界系，FoundationPose 用 RGB、深度、mask 与内参把 mesh 注册成 SE(3) 位姿。Graph-guided seating 按逆拓扑序落座：单支撑时用支撑 footprint P_j 与质心投影，要求质心落在 P_j 内且距边界至少 η_j=min(10 mm, 0.8 r_j)，在候选位移中取满足 ρ(v)≥0.9ρ_max 的最小位移，再按 Δz=ε-min g(u)（ε=0.1 mm）抬升留缝，最后查穿模。多支撑物体走 contact-guided 初始化：物体外碰撞面取 96 点、每支撑朝上取 64 点，按距离一致性 |‖a_2-a_1‖-‖b_2-b_1‖|≤τ_i（τ_i=min(0.01L_i, 1 mm)）配对，从输入旋转出发把物体对方向对齐到 b_1→b_2，再解析求绕接触轴的 roll φ 使两处表面法向最反向，得 T_φ=(Rot(d̂_b,φ)R_0, b̄-T_φ ā)，每场景最多 6,000 个候选；先按凸包近似的 source-mask IoU 排序，再做位姿边界、穿插、支撑间隙与朝上法向检查，最后渲染并按真实 IoU 选优。Coarse-to-fine refiner 用 priority tuple p_i=(f_i, d_i, 1-I_i, m_i)（意外接触、支撑亏空 Σ(1-ℓ_ij)、IoU 缺口、一秒内最大运动）分配固定预算，三档搜索尺度为 ±15%/±7.5%/±3.75% 主轴长配 5°/2.5°/1.25°，每步用短物理 rollout 验收，接受后从新位姿在更细尺度继续搜。

## 实验与结果
- 50 场景 10 s 后 source-mask IoU 51.7% vs 最强基线 40.7%（+21.4 pp，SimFoundry；Picasso 16.4、SAM3D+FP 29.4、SAM3D 22.9）
- intended supports 实现 325/373 = 87.1% vs 基线 73.2%
- mean object drift 45.3 mm vs 79.6 mm；从 t0 的 52.6% 到 t10 的 51.7%，平均 IoU 掉不到 1 pp
- MessyKitchens 25 场景：IoU 61.4%（t0 与 t10 同值）、drift 4.37 mm、0 例严重失败，10.1±1.9 min/场景
- 单物体细化后 IoU 从 64.5% 升到 72.2%，并保留全部 10 条 intended support
- 生成时间按数据集 6.0–18.8 min（含共享的 RGB、DA3 深度与 mesh 预处理）

## 创新点与贡献
- 把「支撑图」提升为连接感知与仿真的中心数据结构：同一张 DAG 同时决定落座顺序、多支撑物体的位姿采样约束与细化分组的优先级，使几何目标在构造阶段就对齐物理目标
- 多支撑物体用成对接触点加解析 roll 的闭式候选生成，替代随机采样，并先按凸包 IoU 粗排再做昂贵检查
- 整个搜索梯度无关、预算显式（B_init 与 B_ref 分开），在固定 wall-clock 内可预测地产出可交互场景

## 局限与风险
- 只处理刚体、只吃单张 RGB，质量受 VLM 支撑图与 SAM3D mesh 限制
- 支撑判据只验证是否承力，不还原真实接触位置与力分布，质量与摩擦来自 VLM 估计
- 作者列为局限的还有：不支持关节物体与变形体，细长或悬空结构的支撑推断容易失效
