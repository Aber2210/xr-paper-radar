# FLoTS-SLAM：光流衍生不确定度的单目动态 SLAM 两阶段优化

## 一句话结论
用「光流与相机运动诱导流之残差」导出逐像素运动不确定性，两阶段优化（低不确定像素固定深度估位姿→高不确定像素用一阶段位姿重投影后联合精化）；DAVIS 动态掩码 DM-IoU 0.72–0.84，大幅领先 MonST3R（0.13/0.21）等基线。

## 要解决的问题
动态场景单目 SLAM 的动态识别依赖渲染残差/多视特征不一致——缺直接运动证据，重建不准或特征歧义时退化；且此类不确定性仅用于 BA 降权，不修复结构。

## 方法详解（含关键公式/架构，保留原文术语）
系统：DROID-SLAM 更新算子 + DINOv2 特征 + Metric3D 深度先验（全部冻结）；不确定性分支：光流残差随帧对齐精度自适应；跟踪分支：两阶段在 Gauss-Newton 迭代内交替（一阶段低不确定像素定深估姿；二阶段高不确定像素按一阶段位姿重投影对应目标后联合精化位姿与深度）。

## 实验与结果（表格化关键数字）
Bonn RGB-D Dynamic + TUM RGB-D 动态序列（定位 ATE RMSE，Sim(3) 对齐）+ DAVIS（掩码质量）；9+ 基线四类：语义/几何动态 SLAM（DynaSLAM N+G）、通用深度 SLAM（DROID-SLAM）、动态 3DGS-SLAM（DG-SLAM/UP-SLAM/ADD-SLAM/Flow4DGS-SLAM/WildGS-SLAM）、鲁棒动态方法（DynaMoN/DROID-W）+ MonST3R 前馈基线；提出 DM-IoU 指标；消融 + 运行时分析。

## 创新点与贡献
运动不确定性的新来源（流残差，直接运动证据）+ 两阶段重锚定把不确定性用于结构修复而非仅降权；DM-IoU 新指标。

## 局限与风险
依赖冻结深度先验的尺度一致性；两阶段迭代的实时性需权衡；单目深度先验失败场景的退化未充分讨论。

## 与文献库的关系（新增 / 改进 / 取代 X）
与库内动态 SLAM 族（DynaSLAM 类/WildGS-SLAM）互补；不确定性导出思路可迁移至库内动态 3DGS 系统。

## 可复现性（代码/数据/硬件）
公开基准 + 协议清晰；实现细节附录齐全。

## 行动建议
动态场景 AR/机器人跟踪可直接采用；DM-IoU 建议作为动态掩码评测标准跟进。
