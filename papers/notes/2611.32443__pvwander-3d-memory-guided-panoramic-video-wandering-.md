# PVWander：路径朝向规范化驱动的 3D 记忆引导全景视频漫游

## 一句话结论
利用 ERP 的水平循环对称把「运动方向相对朝向」的多样性规约成近似前向运动（只做 yaw 循环移位重定向，零参数改动），再用 timestep 相关、per-channel 的门软调节不可靠记忆的注入强度：InteriorGS-OmniRoam 首段 SSIM 0.7935 / PSNR 21.62 vs OmniRoam 0.6930 / 17.35。

## 要解决的问题
长时程全景漫游要从一张 ERP 全景出发，沿用户给定轨迹持续合成 360° 观测。自由轨迹带来极不一致的运动-朝向关系（前向、侧向、后退混在一起），显著加剧伪影与时间漂移；同时在线 3D 记忆由生成观测和估计深度重建，伪影与深度误差会随重投影反复写回并跨段传播。量化上，把单段方法递归推到 8 段（641 帧）后，FID 从首段 16.18 恶化到 23.65、TransErr 从 0.0099 涨到 0.1890。

## 方法详解
维护在线彩色点云记忆 M(s)={(p_j,c_j)}：用 PVMetric 估计的 metric radial depth 把初始 ERP 抬到 3D，每段生成后按估计深度反投影并入世界系；下一段前按对目标视点的几何覆盖挑选互补源观测，把对应点变换到各目标相机并投影到 ERP 平面，得带覆盖空洞的部分全景 render。条件注入沿用 Matrix-3D 的加法式 h_t=h_t^base+h_t^cam+h_t^render：相机侧把 Plücker ray 编码适配到 ERP 几何、复用 Wan 的 camera adapter；render 侧经视频 VAE 与轻量 render adapter 变成 render token，并附投影有效性 mask。Path-Facing canonicalization 针对段内水平相机坐标做 PCA 取第一主轴 v=PCA_1({q_i-q̄})，按时间前进方向定符号，把整段 ERP 朝向 yaw 对齐到 v：利用 ERP 的水平循环对称，只需循环移位即可重定向而不改场景内容，相机位置保持不变，首帧条件、memory 重投影与相机条件都用对齐后的位姿，生成后再旋回原朝向。该操作零参数、零结构改动。Timestep-aware gating modulation 针对不完美记忆：用正弦嵌入 e_t=PE(t) 加两层 SiLU MLP 预测 per-channel gate，在注入前调制 render token，学到的平均 gate 在去噪早期（高噪声、定全局结构）较强、后期（精修局部外观）减弱，用软衰减替代硬截断。深度侧另训 PVMetric（含 cube-rectified temporal modeling）专门产出全景 metric depth。

## 实验与结果
- InteriorGS-OmniRoam 1440×720 首段：SSIM 0.7935 / PSNR 21.62 / LPIPS 0.1750 / FID 16.18 vs OmniRoam 0.6930/17.35/0.3217/22.46、Matrix-3D 0.7404/19.36/0.2709/23.22
- 8 段（641 帧）TransErr 0.1890 vs Matrix-3D 1.1411、OmniRoam 0.2869；RotErr 1.1388 vs 9.4044 / 1.7781
- 8 段 FID 23.65 vs Matrix-3D 82.49、PanoWorld 26.17、OmniRoam 19.88（该项 OmniRoam 更低）
- 960×480 8 段：SSIM 0.6467 vs PanoWorld 0.4546、OmniRoam-P s=1 0.5383、Wan2.1-Fun 0.5492
- 960×480 首段 PSNR 21.92 / LPIPS 0.1656 / FID 16.79，均为该分辨率最佳
- 消融：无 Path-Facing 时长时程 SSIM 0.5280 / FID 29.80，加 gating 0.5806/26.69，两者+在线记忆 0.5867/23.75

## 创新点与贡献
- 利用 ERP 的水平循环对称把「运动方向相对朝向」的多样性规约成近似前向运动：只做循环移位式 yaw 重定向，不引入任何参数或结构改动，因而能直接插到现有全景生成器上
- 用 timestep 相关、per-channel 的门在去噪过程中软调节不可靠记忆的注入强度，取代按时间硬截断，保留粗几何同时抑制局部伪影
- 两者与在线点云记忆组成闭环，是首个同时处理运动-朝向对齐与记忆误差传播的全景长漫游框架

## 局限与风险
- 强依赖深度估计质量，PVMetric 的误差会直接写进 memory 并随重投影传播
- 8 段 rollout 的 FID 23.65 仍高于 OmniRoam 的 19.88，并非全面最优，优势主要集中在 TransErr/RotErr 与高分辨率首段
- 评测限于室内 InteriorGS/Unity_Curve 类场景，室外大范围、动态物体与真实头显交互未覆盖
