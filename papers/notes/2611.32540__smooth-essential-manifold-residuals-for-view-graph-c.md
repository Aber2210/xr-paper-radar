# 面向视图图标定的光滑本质流形残差

## 一句话结论
把秩二 3×3 标定基础矩阵等距映到 2×2，使本质约束从非线性流形条件变成两个线性子空间的隶属问题，得到平方范数恰等于流形距离的光滑两分量残差，同时去掉秩亏与 SVD 开销：ETH3D 焦距中位相对误差 0.24%、AUC@5 0.894（SVD 版 0.886），四个数据集上均不劣于原目标。

## 要解决的问题
互联网照片与异构图像集常缺失或携带错误内参（裁剪、数码变焦会使其失效），而 SfM 在建图时已为每对验证图像估计了基础矩阵。视图图标定要求标定后的 F 成为本质矩阵，即最小化到本质流形的距离；但该距离的常规最小二乘写法把本质矩阵的两个独立约束压成一个标量残差（余维二问题只剩一维残差），导致每边 Gauss–Newton 模型秩亏、呈「条纹」局部模型，收敛慢；且每次迭代每条边都要做 SVD 并对分解求导，开销在大图上不可忽视。

## 方法详解
作者不改目标函数，只改残差的表示。先说明本质流形在秩二基础矩阵空间中是余维二的，单标量残差 r=√ℓ=(σ₁−σ₂)/√(2(σ₁²+σ₂²)) 在可微处只有一行 Jacobian、GN 秩至多 1，且 σ₁、σ₂ 交换序时形如绝对值、在解处不可微。第一步去 SVD：由 σ₃=0 得 ‖A‖_F⁴−‖AAᵀ‖_F²=2σ₁²σ₂²，故 ℓ(A)=1/2−√(½(‖A‖_F⁴−‖AAᵀ‖_F²))/‖A‖_F²，用矩阵乘积与范数精确算出同一标量（每边 57 ns vs 513 ns），但残差形状未变、迭代数不变。第二步等距降维：取 A 的左右单位零向量 a、b 及其正交补基 P_a,P_b∈ℝ²ˣ³，令 C=P_a A P_bᵀ∈ℝ²ˣ²；该映射是到同零空间子空间的 Frobenius 等距，且 dist(A,ℰ)=dist(C,S₊∪S₋)，其中 S₊={[[α,β],[−β,α]]}、S₋={[[α,β],[β,−α]]} 是两个相互正交的二维线性子空间（缩放正交阵）。于是可写出光滑两分量残差 r_ij=1/(√2‖A_ij‖_F)[c₁₁−ηc₂₂; c₁₂+ηc₂₁]，η=sign(det C) 选较近分支；其平方范数严格等于原 ℓ，在解处给出满秩 2×2 Jacobian。实现上零空间不必每步重算：由固定 F_ij 的零向量经 K⁻¹ 传输并归一化，可证明 â_ij 始终落在由 e₃ 与固定向量 w=(a₁−u a₃, a₂−v a₃,0) 张成的平面内，故 n_a∝w×e₃ 在整个定义域正交，P_a 有闭式且方向恒定；η 由正焦距域连通、det C 不变号而只需初始化时定一次。整体流水线用 log-focal 参数化保正，初值取 Bougnoux 闭式两视图估计的逐图中位数（票数不足则退回 COLMAP 先验按场景中位比缩放），再用两阶段鲁棒优化：先 Cauchy（影响函数不消失，可从坏初值进入正确盆地），再热启动 Tukey（超过截断的边影响恰为零，无需显式剔除即可抗外点）。

## 实验与结果
- ETH3D 焦距中位相对误差 0.24%、AUC@5 0.894，SVD 版同目标 0.24%/0.886，COLMAP VGC 0.71%/0.632
- BlendedMVS 0.56%/0.769、IMC2023 1.22%/0.611、IMC2024 2.63%/0.435，四个数据集上本质流形两版 AUC 均最高，代数基线 Geppert 全面更低
- 端到端标定时间：ETH3D 0.04 s（SVD 版 0.10 s、COLMAP VGC 0.22 s），IMC2023 5.37 s（SVD 版 15.47 s），已接近最便宜的代数目标
- 单边求值 47 ns（SVD 标量 513 ns，10.91×）；含 Jacobian 81 ns（548 ns，6.79×）
- 对学习式方法：ETH3D 中位 0.27% vs VGGT-Ω 0.53%、MapAnything 3.25%、AnyCalib 5.73%；IMC2024 2.67% vs VGGT-Ω 8.76%
- 基准规模：167 场景、26,622 张有真值图像、3,966 个不同焦距、1.34M 条视图图边、4.08 亿匹配

## 创新点与贡献
- 给出一个精确的等距降维：把秩二 3×3 标定基础矩阵映到 2×2，使本质约束从非线性流形条件变成两个线性子空间的隶属问题，从而得到「平方范数等于原流形距离」的光滑两分量残差
- 数学上干净（附完整证明：等距性、最近本质矩阵共享零空间、O(2) 分解、分支不可变），工程上同时解决秩亏与 SVD 开销两件事，且不改变目标函数

## 局限与风险
- 仍受成对几何信息量约束：弱基线、临界构型（光轴相交）主导的图无法凭空恢复焦距，任何目标函数重写都无济于事
- 主基准只估每图单一焦距且固定主点（虽然框架可扩展到任意内参）
- 端到端重建的收益小于两视图几何的收益，说明标定只是 SfM 的一环
