# Tacinf：面向机器人操作的统一触觉基础设施

## 一句话结论
把触觉基础模型的「数据金字塔」（遥操作/手持 UMI/仿真）与力–位混合执行接口打通成一套可复现栈，并用同一任务集做仿真–真机配对评测：八个策略变体成功率排序一致性 Pearson r=0.998，仅用仿真微调零样本上真机 99.0%。

## 要解决的问题
力感知操作要求策略从任务语言、视觉与触觉推断合适的交互力——力需求有时显式（「轻一点」「用力」），有时隐含在开容器、擦表面等任务中——但触觉数据因硬件与传感器设计差异而昂贵难采。执行时必须用实时反馈调力，而表现差的策略会损坏物体甚至机器人本身，因此需要低成本、可反复试错的评测平台。已有开源轨迹回放只能复用运动，不能保证接触力与触觉观测可跨仿真器迁移。现有触觉仿真、数据集与基准各自为政，缺少一条从多源采集、基座模型训练到硬件部署贯通的流水线。

## 方法详解
四个模块。Tacinf-Tabero：把 MuJoCo/LIBERO 等轨迹回放到 Isaac Lab，重建场景资产与初始位姿，通过对齐 TCP（调机器人基座位姿）与高增益 PD 跟踪降低回放误差，补渲染腕部与第三人称 RGB-D，并用 Taxim（光学）与 FOTS（marker 位移）生成 320×240 的仿真 GelSight 触觉图与 11×9 marker 网格，按语言副词生成 firm/gentle 力等级数据。Tacinf-VTLA：双指平行夹爪把指尖平面接触分解为 squeeze 与 TCP 六维 wrench，$F_{\mathrm{squeeze}}=\min(\|\mathbf{f}_L^{S_L}\|,\|\mathbf{f}_R^{S_R}\|)$，$\mathbf{F}^T=-(\mathbf{f}_L^T+\mathbf{f}_R^T)$，$\boldsymbol{\tau}^T\approx\frac{p}{2}(f_{L,z}^T-f_{R,z}^T,0,f_{R,x}^T-f_{L,x}^T)^\top$；策略（$\pi_0$/$\pi_{0.5}$ 经 LoRA，flow matching）同时预测末端位姿与六维指尖力设定点，位姿修正 $\Delta\mathbf{p}=-\mathbf{K}_p\mathbf{R}_T^B(\mathbf{e}_L^T+\mathbf{e}_R^T)$、$\Delta\boldsymbol{\phi}=\mathbf{K}_\phi\mathbf{R}_T^B[\frac{p}{2}(e_{L,z}^T-e_{R,z}^T),0,-\frac{p}{2}(e_{L,x}^T-e_{R,x}^T)]^\top$，夹爪走独立 grip 环 $F^{\mathrm{target}}_{\mathrm{grip}}=(1+k_{\mathrm{ff}})F^{\mathrm{pred}}_{\mathrm{grip}}$、$\Delta p=k_p^{\mathrm{adm}}(F^{\mathrm{target}}-\tilde{F})$（带死区与 clip）；损失对 13 个有效输出分量加权，前馈项权重为 1、六个力分量权重 $\lambda_{\mathrm{force}}$、填充维权重 $\lambda_{\mathrm{pad}}$。Tacinf-Tacumi：手持夹爪（DAMIAO 准直驱电机 + Xense 视触觉指尖 + Quest 3 六自由度跟踪），触发器按 $\tau_{\mathrm{trigger}}^{\mathrm{cmd}}=k_{\mathrm{fb}}\hat{\tau}_{\mathrm{gripper}}$ 做主动力反馈，与部署用同一夹爪执行器，降低采集–部署差异。Tacinf-Taco：任务对齐 Real2Sim（深度→压痕标定）加多源数据联合后训练。

## 实验与结果
- 八个策略变体上仿真与真机成功率排序一致性：Pearson r=0.998、MMRV=0.010；去掉两个零成功率基线仍 r=0.961
- 仅用仿真数据微调、零样本上真机：Force D+FS 98.3%(Sim)/99.0%(Sim2Real)，Force E+FS 92.5/98.0，Field+FS(π0.5, no state) 96.7/96.7
- 仿真–真实数据一致性：CLIP 相似度 >0.75（第三人称 0.781–0.794、腕部 0.754–0.770），触觉 SSIM >0.93（0.931–0.941），action MAE <0.074（0.0685–0.0733）
- 多源协同：位置+物体双随机化下平均成功率 20.0%（仅遥操作）→ 60.0%（real+sim+umi = 1:5:1）
- 位置随机化下 real+umi 把 firm 成功率 30.0%→83.3%、gentle 33.3%→70.0%；仅 UMI 训练在两种随机化下均为 0%
- 力监督消融：无触觉无力监督基线完全失败；Img/Field/Force E 在无 FS 时 gentle 成功率仅 0.01；仅 FS 达 gentle 0.45 / firm 0.82
- 力跟随：Dataset A(100%/25%) SR 0.87/0.79、AG 31.3/8.5 N；B(100%/10%) 0.86/0.52、AG 32.4/3.7 N；C(二值) 0.86/0.87 但 AG 35.8/34.6 N（无力调制）
- 回放保留率：LIBERO 四子任务均值 0.85(MuJoCo)→0.76(Isaac 同构)→0.60/0.50/0.36（触觉夹爪 100%/25%/10% 力缩放）

## 创新点与贡献
- 把触觉基础模型的「数据金字塔」（遥操作 / 手持 UMI / 仿真）与力–位混合执行接口打通为一套可复现栈，并用同一任务集、同一语言指令、同一控制器在仿真与真机做配对评测，使「仿真能否预测真机排名」成为可量化的设计目标
- 实证上给出一个有价值的反例：主要增益来自力目标监督与力目标执行接口，而高级触觉表征只带来增量改进——这与触觉 VLA 领域「必须有高分辨视触觉输入」的常见假设相悖

## 局限与风险
- 作者承认受资源限制，数据集与任务规模有限、未做大尺度训练，未来才扩展到更多本体与双臂
- 正文另可见：多数策略在 3 个任务 × 2 个力等级的小规模设置上评测
- Xense 力读数在接触中不够准，4.4 节起改用左右指尖力幅值之和作近似，故力指标是代理量
- 真机成功判定依人工设定的任务成功准则
- 仿真与真机的绝对力值仍有系统性偏差（Table 5 多行为正 gap，如 Cookie 上 +17.66 N）
