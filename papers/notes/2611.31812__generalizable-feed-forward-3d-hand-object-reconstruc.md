# 面向未见物体的可泛化前馈三维手-物重建与由粗到细接触估计

## 一句话结论
物体侧只用冻结位姿基础模型的内部几何特征、不学实例嵌入，接触则由「粗 token 逐关节预测 + 重建 SDF 区域距离细化到掌/背侧」两级落地——DexYCB 物体 AUC 92.88（比 SemiHand 高 10.25），OakInk 未见物体 AUC 93.29 vs SemiHand 40.50，接触 F1@3mm 74.97 vs HACO 68.09。

## 要解决的问题
单目图像中手与物体的三维位姿及接触是操作理解的基础，但现有方法只能部分满足需求：联合前馈估计器依赖预定义物体集合，遇到未见物体泛化差；把各实体基础模型独立组合虽能处理未见物体，却易造成手-物错位，且物体被手遮挡时位姿退化。接触方面，专用估计器（如 HACO）仅凭图像特征预测，缺少显式几何来判定“手指掌侧还是背侧接触”，密集接触预测与重建脱钩、可能自相矛盾。

## 方法详解
提出 Horcrux，一个统一前馈 transformer f(I,{I_h},V_o)=({θ_h,β_h,t_h,c_h},R_o,t_o)。用冻结底座编码器分词：DINOv3 提取场景 token，手部编码器从手裁剪图提取 token，物体侧不学实例嵌入，而是用冻结的物体位姿基础模型（PoseGAM）对输入网格 V_o 渲染参考视图并与图像聚合，取内部特征经可学习投影得到物体 token——因此不绑定训练集物体，且可直接吃图像重建的近似网格。构造序列 Z=[Z_img;{Z_h};z_o;{z_h}] 送入共享 transformer 做全局自注意力，缺手时该手不贡献 token，同一模型同时服务单手与双手。轻量头分别解码 MANO 参数、物体旋转与相对抓握手 a 的平移偏移 t_o=t_a+Δt_o（保证物体留在手中），以及 21 关节粗接触 c_h=σ(φ_c(pool(Ẑ_h)⊕ẑ_o))。细接触阶段把 103 个手部细区域（掌/背侧指段）的顶点经 SDF_o 求到物体距离 d=SDF_o(R_o^T(v-t_o))，汇聚为区域距离 u，与粗接触拼接后用一层 transformer 自注意力解析为 c̃_h。训练分两阶段：先训投影、共享 transformer 与位姿/粗接触头（L=L_h+λL_c+L_o+L_rel，L_rel 用 smooth-L1 监督相对平移以规避单目深度歧义）；再冻结主体训细头（BCE + 区域符号距离回归）。

## 实验与结果
- DexYCB：MJE 10.12、PA-MJE 4.95，物体 AUC 92.88（比最强联合估计器 SemiHand 高 10.25，比仅估物体的 MegaPose 高 8.68）
- DexYCB 联合指标：CDev 9.97，不到最低基线 42.44 的四分之一；SD 3.18、IV 14.15
- HO3D：MJE 23.93、VPE 23.20、PA-MJE 9.57，AUC 87.35（比 HFL-Net 高 8.92；仍低于零样本物体位姿法的 96.42）
- 跨数据集未见物体：OakInk AUC 93.29 vs SemiHand 40.50（+52.79），HOI4D 67.68 vs 15.57（+52.11）
- 接触 F1@3mm：DexYCB 74.97 vs HACO 68.09（+6.88）；OakInk 73.62 vs 59.15（+14.47）；标定 ECE 分别降低 3.4 与 3.1
- 双手：OakInk2 物体 AUC 65.22（比 HOPformer 高 12.77）、MJE 14.29；H2O AUC 97.95（+13.89）、MRRPE 28.03

## 创新点与贡献
- 把“基础模型特征”当作接口：物体只用冻结位姿基础模型的内部几何特征、不用其输出位姿，从而把未见物体泛化与手-物联合对齐统一在一个 transformer 里，且同一模型覆盖单手/双手
- 提出由粗到细的接触估计——粗头从潜在 token 预测逐关节接触以规避重建误差，细头用重建 SDF 区域距离把接触落到掌侧而非背侧，无需单独的接触估计器
- 这种“重建本身作为接触证据”的耦合方式此前未被前馈框架实现

## 局限与风险
- 物体几何以输入网格为前提，实际部署需依赖图像到三维模型（SAM 3D 使 Chamfer 距离从 19.01 升到 27.04，Hunyuan3D 升至 45.20），网格质量直接限制物体精度
- HO3D 上物体 AUC 仍落后零样本物体位姿专用方法（87.35 vs 96.42）
- 评测以抓取帧与离散接触标签为主，缺少长时序视频一致性、动态操作与真实机器人闭环验证
- 细接触的 103 区域划分沿用前人定义，粒度受限于该分区
