# 混合层级光线追踪：高效 3D 高斯渲染

## 一句话结论

面向 3D 高斯渲染的混合层级光线追踪架构 H²-Ray：负载均衡空间 BVH（LB-SBVH）把全局倾斜的高斯分布转为均衡遍历区，射线簇路径复用（RCPR）共享邻射线的遍历，在 RTX A5000 上较 RaySplats 取得几何平均 3.77×（最高 9.26×）加速，PSNR 仅降 0.034 dB。

## 要解决的问题

3DGS 依赖光栅化求速度，但光栅化难以支持二次光照、大形变相机与景深等效果；光线追踪 3DGS 则面临高斯空间分布极不均匀、邻射线遍历冗余、硬件 RT Core 适配三大挑战。

## 方法详解

① LB-SBVH：密度感知的空间划分，把倾斜分布转为均衡遍历区域；② RCPR：邻射线簇共享 BVH 遍历，消除冗余访存；③ 修改版 RT Core 的 cycle-accurate 建模，把微架构行为纳入设计闭环。

## 实验与结果

8 个代表场景（Mip-NeRF 360 + Deep Blending）几何平均加速 3.77×、最大 9.26×（vs RaySplats，RTX A5000）；多视图匹配评测下 PSNR 平均仅降 0.034 dB。

## 创新点与贡献

① 首个针对 3DGS 非均匀分布专门设计的负载均衡 BVH；② 「微架构建模+算法协同设计」的方法论对后续神经渲染系统工作有示范意义。

## 局限与风险

① 收益依赖特定 GPU 架构（RT Core 行为），跨代际硬件的可移植性未验；② 二次光照的实际画质收益未在本工作中端到端展示；③ 场景规模扩大后的内存行为待测。
