# DeformMaster：从视频学习可交互的物理-神经形变物体世界模型

## 一句话结论
物理-神经残差加分布式柔顺驱动，20 条真实序列 IoU 0.748、Chamfer 0.011。　物理-神经残差 + 分布式柔顺驱动，20 条真实序列 IoU 0.748、Chamfer 0.011，全面略优于 PhysTwin。

## 要解决的问题
形变物体世界模型要同时恢复几何、外观与物理动力学。单目视频中线性、平面、体积物体形变维度高、交互含噪。物理数字孪生（PhysTwin、Spring-Gaus）受固定基底与纯参数拟合限制；纯学习动力学数据依赖强、绑定训练分布、新动作长程漂移；物理加生成的混合系统偏生成，难由显式动作控制且易幻觉。

## 方法详解
状态分材料粒子与外观粒子，动作为手或执行器锚点位置与速度。PNPGD 用可微 MPM 推进一帧得 s_tilde，PointNet 编码加坐标条件 MLP 在 Eulerian 网格上预测有界修正 alpha*tanh，按同一 B-spline 权重映回粒子得 delta_v，仅更新位置与速度，F 与 C 继承；残差为帧级扰动。DCA 在执行器邻域内以刚度与阻尼做柔顺耦合，a_p 以 n_p^(-1/2) 归一防力叠加，把稀疏含噪手轨迹转为有限接触面的分布驱动。MoCE 以 P_mix=sum w_k,p P_k 混合 NH、Cor、StVK 专家，权重由 patch 级 logits 插值，E 与 nu 可学。外观用 LBS 把粒子增量运动传给 3DGS。损失含 track、shape、length、RGB 四项；训练三阶段，并用 CMA-ES 选 DCA 增益。

## 实验与结果
- PhysTwin 20 条序列：IoU 0.748 vs 0.734，Chamfer 0.011 vs 0.012，Track 0.024 vs 0.023，PSNR 25.41 dB vs 25.16 dB。
- 对学习型基线：Chamfer 较 Spring-Gaus 0.062 与 GS-Dynamics 0.041 降低 3 倍以上，Track 至少降低 2.9 倍。
- 线性物体（绳索，n=3）：IoU 0.658→0.721，Chamfer 0.007→0.005，Track 0.013→0.010。
- 平面物体（布料与包装，n=9）：IoU 0.738→0.748、Chamfer 持平 0.013，但 Track 0.028→0.032 退化。
- 在线交互 rollout 超过 15 fps；材料场缩至 0.3 倍可产生断裂并支持新视角渲染。

## 创新点与贡献
- 相对 PhysTwin、Spring-Gaus 的固定基底加纯参数拟合，以及 GS-Dynamics、AdaptiGraph 的纯学习转移，把物理 rollout、神经残差、柔顺分布驱动与空间变化本构混合统一，全部从真实视频学得。
- 对比基线：PhysTwin, Spring-Gaus, GS-Dynamics, PAC-NeRF, GIC, PhysGaussian

## 局限与风险
- 粒子网格仿真对极薄单层布不如带固定拓扑的弹簧质点，平面 Track 仍落后 PhysTwin；交互依赖观测到的手部运动，严重遮挡时动作信号不完整；运行时随 MPM 子步数增加，保真度与实时性需权衡。
- 消融：去残差（纯 MPM）动静与外观均降，粒子网格残差优于 MLP 与 GNN；刚性约束 9/20 序列发散（含全部 8 个体积物体），单执行器稳定但降精度；单 Neo-Hookean 专家不如 MoCE；RGB 精化主要提升平面与体积。

## 与文献库的关系
库内世界模型线以刚性与视频生成为主，本篇补「可交互形变物体」；对 XR 中抓取/捏合反馈的物理一致性有意义。
