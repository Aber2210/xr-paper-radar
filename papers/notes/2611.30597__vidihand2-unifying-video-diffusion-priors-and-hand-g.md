# ViDiHand2：统一视频扩散先验与手部几何的野外 3D 手部运动重建

## 一句话结论
把 VDM 手部深度从外观回归改为测试相机射线上的几何约束求解（多关节对距离定尺度）：野外 MPJPE-abs-p 56.55→32.59 mm（−42%），域内 24.46→19.62 mm，检测失败帧占比比 ViDiHand 少 14.57×。

## 要解决的问题
从第一人称人类视频学习机器人操作需要准确的米制 3D 手部运动。detect-then-reconstruct 方法先检测手再在裁剪块上估姿态，单帧法缺时序一致性，运动先验法在遮挡与跟踪失败时仍脆弱。当前 SOTA 的 ViDiHand 与 ACE-Ego-Hand 改用预训练视频扩散模型（VDM）从全帧视频直接重建，能恢复被遮挡的手，但它们从外观直接回归米制深度：这要求网络学会所有可见物体的绝对尺度，对焦距高度敏感，换未见相机就泛化差；同时粗 token 化损失细粒度空间细节，遮挡与画面边界截断又削弱定位线索。

## 方法详解
把 VDM 手部深度估计从「直接回归」改写为「几何约束求解」。网络 $\mathcal{F}_\phi$ 输入单目片段与相机内参，预测 MANO 姿态 $\theta_{1:T}$、形状 $\beta$、带方差与置信度的 2D 关节 $u_{1:T}$。Fine-Grained Geometric Lifting 把每个关节放在其相机射线上，用 MANO 的米制关节对距离作为骨长约束，联合重投影约束与时间约束求解每帧腕部深度；Clip-Level Ray Fitting 进一步在整段视频上联合估计一条腕轨迹，让不可靠帧被邻近帧约束。由于 lifting 依赖 2D 关节，Joint-Heatmap Refiner 在 VDM token 网格 8 倍分辨率上预测热图并回归关节，兼顾遮挡与出界；Confidence-Gated Fusion 用学习门 $g_j$ 在「射线上的几何关节」与「MANO 关节」间按定位置信度融合，避免 MeTRAbs 式硬切换。骨干侧，Multi-Level Latent Encoder 聚合所有适配 VDM block 的多层特征，Hand Latent Decoder 逐 latent 帧解码视频帧，Autoregressive Rollout Adaptation 让每个 chunk 通过 KV cache  attended 前一个 chunk，提升长时序一致性。

## 实验与结果
- 野外 MPJPE-abs-p 从 56.55 mm 降到 32.59 mm（vs 最佳基线 WiLoR，-42%）
- 域内 MPJPE-abs-p 从 24.46 mm 降到 19.62 mm（vs ACE-Ego-Hand，-20%）
- 检测失败或误检仅占域内 0.07%、野外 0.11% 的帧，比 ViDiHand 少 14.57× 与 8.82×
- 运行 57 FPS
- 焦距缩放 0.60–1.60 下保持稳定；直接回归深度野外 81.24 mm，而几何拟合 ≤38.83 mm
- 整段射线拟合把 jitter 从 3.39 降到 1.26 mm/frame²（域内）、3.65 降到 1.61（野外）
- 去掉 Joint-Heatmap Refiner：域内 19.62→32.30 mm，野外 32.59→39.71 mm
- Confidence-Gated Fusion 使 EPE2D 从 5.03 降到 4.67 px、MPJPE 从 9.75 降到 9.50 mm

## 创新点与贡献
- 把 VDM 手部深度从外观回归改为「测试相机射线上的细粒度几何约束求解」，用多个关节对距离而非单一骨长/2D–3D 对齐来定尺度，显著降低对焦距与训练相机的依赖
- 整段射线拟合提供跨帧约束，8× 热图细化与置信门控融合分别处理定位精度与遮挡/截断

## 局限与风险
- 作者承认需要相机内参（第一人称设备通常可提供），且方法离线运行，适合已录制视频而不适合闭环控制
- 正文还显示其依赖 2D 关节定位质量：去掉 8× 热图后误差大幅上升
- 极端截断、严重运动模糊与多手交互未单独量化
- 评测以几何/检测指标为主，未在真实机器人策略中闭环验证
