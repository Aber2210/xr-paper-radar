# 数贡献而非数视角：遮挡感知的 3DGS 致密化

## 一句话结论
用按混合权重贡献计数的平均贡献判据替代视锥计数：纠正遮挡高斯零梯度污染致密化统计，遮挡密集场景图像指标全面提升（LPIPS 至多降 6%），高斯数不足原来一半。

## 要解决的问题
3DGS 依赖 adaptive density control（ADC）增长密集场景，其致密化统计由渲染期间的视锥可见性过滤收集——该过滤只反映高斯「潜在可见」而非「实际观测」。完全被遮挡的高斯（透射率提前饱和）从不参与渲染，其零梯度视图仍进入累积统计：observation count 虚高、最大半径跟踪被更新，对遮挡高斯形成向下的致密化压力。后果是多房间公寓等遮挡密集场景欠致密化与过平滑，且计数随训练持续膨胀。本文要纠正该统计偏差，让致密化判据只计入高斯真正贡献的视图。

## 方法详解（含关键公式/架构，保留原文术语）
构建于 StopThePop（精确逐像素深度排序、消除 popping 伪影的 GS 渲染器），但方法不依赖其逐像素排序，只依赖几乎所有 GS 光栅器都已计算的逐像素混合权重 w_{i,p}=α_{i,p}·T_{i,p}（不透明度乘透射率）。核心改动有二：① 遮挡感知过滤器——把致密化统计限制在高斯「实际贡献」的视图（混合权重非零），完全被遮挡的高斯不再进入统计；② 平均贡献判据——以平均贡献替代原始视图计数作归一化项，附分母下限（无下限则训练发散）。配套研究：contribution-prune 贡献剪枝移除被遮挡高斯、clone 操作与 clone ablation、阈值校准、分母下限分析、空间高斯分配、等训练预算下的可扩展性、贡献与遮挡率相关性；贡献可迁移至 2DGS/3DGS（补充材料 A.2 评测）。

## 实验与结果（表格化关键数字）
评测 Mip-NeRF360（9 场景）、Tanks&Temples（2 场景）、Deep Blending（2 场景）与 Zip-NeRF（alameda/berlin/london/nyc 4 个大公寓场景，遮挡率 0.63，显著高于其他数据集的 0.15–0.48，是既定的遮挡压力测试；用半分辨率、每第 8 张留验的标准协议）。指标 PSNR/SSIM/LPIPS（VGG backbone）/高斯数/训练时间，并报对模糊敏感的 GMSD。结果：遮挡密集场景上相对遮挡盲基线全面提升各图像质量指标，LPIPS 至多降 6%，高斯数不足视图计数归一化所需的一半；更长训练日程下计数保持有界而多数判据发散；较小基准上以竞争对手零头的高斯数保持竞争力。digest 未含逐场景数值表（GMSD、训练时间等具体数字缺失）。

## 创新点与贡献
- 把致密化统计从视锥潜在可见改为按逐像素混合权重 w=α·T 的实际贡献过滤，直接纠正遮挡场景欠致密化
- 提出平均贡献判据替代视图计数归一化，附分母下限保证训练不散
- 构建于 StopThePop 但不依赖其排序，仅需通用混合权重，可迁移 2DGS/3DGS
- 配套贡献剪枝移除被遮挡高斯与克隆分析，系统研究贡献与遮挡率的相关性

## 局限与风险
- digest 未含逐场景/逐指标数值表，定量增益幅度待核（摘要口径：LPIPS 至多降 6%、高斯数减半以内）
- 依赖渲染器提供逐像素混合权重与透射率（StopThePop 式早停），对仅排序最前高斯的 hybrid transparency 兼容性未评
- 分母下限、致密化阈值等超参需按场景校准（无下限训练发散）
- 遮挡率定义与测量依赖作者自有协议，跨数据集可比性待验

## 与文献库的关系（新增 / 改进 / 取代 X）
属库内 3DGS 训练致密化方向的延伸：指出视锥过滤把「潜在可见」当「实际观测」，遮挡高斯的零梯度仍污染致密化统计（observation count 虚高 → 欠致密化）；在 StopThePop 基础上构建、可迁移 2DGS/3DGS；与库内 3DGS 效率/压缩线共享「少高斯、同质量」目标，但切入点在训练统计而非推理裁剪。

## 可复现性（代码/数据/硬件）
digest 未提及代码链接；评测用公开 Mip-NeRF360/Tanks&Temples/Deep Blending/Zip-NeRF 数据集，Zip-NeRF 按半分辨率、每第 8 张留验的标准协议。

## 行动建议
在遮挡密集场景（多房间室内、Zip-NeRF 类公寓）训练 3DGS 时，把视锥过滤的致密化统计替换为按混合权重贡献计数的平均贡献判据；复现优先验证其对高斯总数与 GMSD（模糊）的影响，并关注 integrated baseline 中 clone 操作与贡献剪枝的配合。
