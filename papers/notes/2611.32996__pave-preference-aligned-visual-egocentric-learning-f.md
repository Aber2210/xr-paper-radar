# PAVE：面向盲人与低视力用户的偏好对齐第一视角视觉学习

## 一句话结论
把 BLV 沟通偏好拆成「参考答重构 + 按问句表层形式确定性路由 + 正确性优先的分层 reward 后训练」三段闭环，Filter-GRPO 让「全对但质量有差」的组也能提供梯度：InternVL2.5-8B 67.00% vs EgoBlind 62.88%，BLV Score 3.2878 vs 3.0660，部署时退化为单次 greedy 解码。

## 要解决的问题
现有 BLV 第一视角 VideoQA 的基准与模型只优化与参考答案的语义一致，把视觉辅助退化成事实匹配；一个事实上正确却缺少 ego-relative 方位、可操作步骤或过于冗长的回答，对正在执行任务的用户没有实用价值。偏好研究给出了结构化、方位明确、充分且简洁等原则，却没有转成可训练的监督信号。量化上，统一 prompt 微调会让程序性 How 类问题从 zero-shot 的 60.17 掉到 52.54，说明单一策略反而破坏部分能力。

## 方法详解
以 EgoBlind 的真实 BLV 视频与查询重建参考答案，围绕六条准则（direction accuracy、depth accuracy、safety and actionability、no hallucination、sufficiency、conciseness）与「minimum sufficient assistance」原则；gpt-4o-mini 做 video-grounded 评估给出 J_vid∈[0,100] 与结构化理由，τ=85 直接保留，否则由看不到评分与理由的 gemini-3.6-flash 最多两轮改写重评，仍不达标则从视频直接生成候选再评；接受集 A_q* 去重后每题保留 1–4 条（均值 2），四人团队做全量逐视频核验，保留 |A_q*|≥1 的题。问题形式化为 lexicographic 多目标：max E[U_BLV(C_q(a), S_q(a))] s.t. C ≻ S，即语义正确性优先于表达质量。学习端先做 structured SFT：统一 response policy 含五条操作原则（消解指代、视觉 grounding、以末帧判当前状态与安全、在直读与结构化引导间切换、检查完备性并表达不确定），但监督目标只含简洁最终答案、不含中间推理；损失为 token mask 归一化的交叉熵。推理时用确定性 router 按归一化首词选策略：How/Where→spatial procedural，What→evidence complete，其余→decision consistent，不引入额外网络或延迟。后训练用 Filter-GRPO：reward R=2C+S/5 使正确解落在 [2,3]、错误解落在 [0,1]；每题采样 G=8，仅保留两类组——混合正确性（Regime I，提供事实判别梯度）或全对但 ΔS≥2（Regime II）；Regime II 下常数 2C 在 group-mean centering 后消去，advantage 退化为纯质量信号；同质组丢弃，KL 惩罚 β=0.04、clip ε=0.2，只训 rank-16 LoRA（语言投影 + multimodal connector），视觉编码器与 SFT 权重冻结。

## 实验与结果
- InternVL2.5-8B：67.00% vs EgoBlind 匹配基线 62.88%（+4.12），BLV Score 3.2878 vs 3.0660（+0.2218）
- LLaVA-OV-7B：63.79% vs 59.49%（+4.30），BLV 3.1210 vs 3.0147；Qwen2.5-VL-7B 55.64% vs 54.81%（+0.83）
- 相对最强 zero-shot（InternVL2.5-8B 54.35%）提升 +12.65 pp，LLaVA 上 +12.83 pp
- 输出长度：Qwen 14.71→7.23 tokens（-50.8%）、InternVL 10.36→6.44（-37.8%），端到端延迟 6.97→6.88 s / 2.66→2.52 s
- 用 PA-EgoQA 监督替换原始 EgoBlind 标注：InternVL +7.24 pp（55.64→62.88）、LLaVA +6.42 pp、Qwen +2.66 pp
- How 类问题 63.56% vs zero-shot 60.17%、EgoBlind 52.54%；Tool Use 在 LLaVA 上 +16.39 pp

## 创新点与贡献
- 把 BLV 沟通偏好拆成可执行的三段闭环：参考答重构（六准则 + 视频级评估 + 独立生成器改写 + 四人核验）、推理期按问句表层形式确定性路由、以及正确性优先的分层 reward 后训练，三者共享同一套准则
- Filter-GRPO 的对比式分组筛选让「全对但质量有差」的组也能提供梯度，这是对 GRPO 在主观质量维度上的实用改造，且部署时退化为单次 greedy 解码、零路由开销

## 局限与风险
- 规模偏小（4,762 题、1,302 clips）且只来自 EgoBlind 一个源，领域外泛化未验证
- 评测由 LLM evaluator 按准则打分而非真人盲用户研究，偏好对齐的最终有效性缺直接证据
- RL 阶段增益有限，router 仅按首词硬规则，多意图或口语化查询容易误路由
