# StereoVLM：面向度量 3D 空间推理的双目视觉语言模型

## 一句话结论
首个显式利用标定双目几何、以视差为中间监督的双目 VLM：深度 δ1 95.17%、视差 MAE 3.76 px，物体级均分超出 GPT-6 Astra 19.37 点，并给出「视差监督比直接深度监督泛化更好」的对照证据。

## 要解决的问题
VLM 语义理解强但度量 3D 空间推理弱：现有模型在未知相机标定、无跨视几何约束下从单/多图推断 3D 结构，度量本质歧义，也难以判断其空间预测究竟基于视觉证据还是语义先验。

## 方法详解
以标定双目为输入，按分层范式学习：跨视对应 → 视差估计 → 标定条件化的度量深度 → 语义空间推理。模型基于 Qwen3-VL-Instruct 初始化（2B/8B），同时接收左右图与焦距、基线等标定参数，把视差作为中间几何表示，再由视差反推度量深度。作者构建三级 Stereo3D-Bench（点级几何 → 物体级空间推理），并用右视干预（duplicate/zero/shuffle）检验预测是否真正依赖跨视几何。

## 实验与结果
- 深度 δ1 = 95.17%（StereoVLM-8B，Stereo3D-Bench 主 split）
- 物体级平均分 = 66.98（8B）/ 64.43（2B），超出 GPT-6 Astra 19.37 / 16.82 百分点
- 对应 MAE = 3.80 px（GPT-6 Astra 9.27 px）；视差 MAE = 3.76 px（7.55 px）
- 深度 δ1 = 75.96% → 95.17%（同双目输入协议下相对 GPT-6 Astra）
- 相对单目 DepthVLM-4B = 深度 δ1 提升 58.06 百分点
- 迁移增益 = +3.54 分（五基准 47.94→51.48）；RoboCasa 成功率 38.1%→42.4%（+4.3 百分点）

## 创新点与贡献
- 首个显式利用标定双目几何、以视差为中间监督的双目 VLM
- 并给出「视差监督比直接双目深度监督在未见环境上泛化更好」的对照证据

## 局限与风险
- 作者自述依赖已标定且同步的相机，评测限于受控基准与仿真厨房任务，存在 sim-to-real 差距，对挑战性视觉条件与多样机器人平台的鲁棒性不足
