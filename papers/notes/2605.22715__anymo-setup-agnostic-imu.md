# AnyMo：野外人体运动的几何感知与设置无关建模

## 一句话结论
在 14 个完全未见过的可穿戴 HAR 数据集上，AnyMo 取得平均 Acc 35.7 / macro-F1 29.5 / R@2 57.5，相对最强平均基线 UniMTS（31.9 / 26.4 / 46.9）绝对提升 3.8 / 3.1 / 10.6 点（论文记作 +11.7% / +11.6% / +22.6%）；Nymeria 留出被试的 100 候选检索 IMU→Text MRR 由 10.0 升到 44.6、Text→IMU 由 6.7 升到 46.7，captioning BERT-F1 由 57.3 升到 69.7。

## 要解决的问题
可穿戴 IMU 已成日常生活中连续感知人体运动的现实手段，但惯性信号强烈依赖佩戴设置：身体位置、安装朝向、器件硬件、采样协议都会改变同一动作的波形。结果是模型难以跨设备、跨数据集迁移，可穿戴感知长期停在闭集活动识别。走向通用模型有三重耦合困难：真实 IMU 数据规模有限且碎片化，监督多为粗粒度闭集标签；合成或增广数据要扩大设置覆盖又不能失物理真实性，而现有生成管线仍绑定特定标签或稀疏位置；IMU 与语言的模态鸿沟在传感器数、通道数、身体位置增加时更难跨越，直接提示或简单对比对齐都不够。作者的判断是：设置变化是结构化的——传感器贴在人体表面，信号由体表几何、安装朝向与器件响应共同决定——因此可用几何–物理先验作归纳偏置。

## 方法详解
按 Nymeria 身体模型把运动组织为 23 个解剖段，IMU 窗口记为 x∈R^{T×6}（三轴加速度 + 三轴角速度）。(1) 物理驱动的几何感知仿真：对每段 i 取候选体表顶点集 V_i，算段质心 c_i 与解剖轴 u_i（指向最近的可用子段质心，无子段则取父段反向）；每个顶点 v 用模板网格面法线 n 定义切平面，把 u 投影上去得 t，b=n×t，组成右手传感器系 R_surf=[t,b,n]；再绕法线采样面内旋转 ΔR 并叠加小幅倾斜以模拟不完美贴合，得 R̃_surf。虚拟 IMU 位置 p_imu=p_i(t)+R_i(t)·r（r 为窗口内平均局部偏移），朝向 R_imu=R_i·R̃_surf；加速度由位置二阶导转到局部系并去重力，角速度由朝向轨迹时间变化给出，再叠加从两条真实 Nymeria 流静默段估计的器件噪声先验。全库 2,374 个候选放置、覆盖 831 个样本。(2) 设置无关预训练：把全身 IMU 观测建成时空图（节点 = 段的 IMU 窗口，边 = 运动学树），用 ST-GCN 编码。对同一窗口独立采样两套放置与安装旋转得配对视图 X^A、X^B，每视图只保留 1–5 个可见段节点、其余替换为可学习 mask token。共享编码器输出保留时序的隐变量 z∈R^{T'×d}；六层 Transformer 预测器从 A 的掩码视图预测 B 的全视图隐变量，反之亦然；损失为跨视图预测 InfoNCE（s 为按时间平均的余弦相似度，目标端 stop-gradient），L=L_{A→B}+L_{B→A}，同时要求稀疏→全身恢复、实例判别与保时序。(3) 全身 token 化：冻结编码器，在掩码观测隐变量上训练乘积量化 VAE（P 个码本、每本 K 项），逐时刻切块量化，时间卷积解码器重建，损失 SmoothL1 + 承诺项，码本 EMA 更新并复活死码；token 按时间交错排列，天然支持变长窗口（5 s 窗口约 75 个隐步、150 个码 token）。(4) 运动–语言：扩展 LLM 词表，每个码本向量经投影映射进 LLM 嵌入空间并同向量初始化 LM head 对应行；先做因果 LM 继续预训练，再做多任务对比指令微调——叙述分支（atomic-action 文本，每窗口 5 条增广）与标签分支（AnyMo-180 标签名）各接可学习 soft prompt，用对称 ITC 与监督标签对比，另有指令生成分支做 caption 与多选题，总损失 λ_CE·L_CE+λ_ITC·L_ITC+λ_label·L_label。骨干为 Qwen2.5-0.5B。

## 实验与结果
- 零样本 HAR（14 个未见数据集）：平均 Acc 35.7 / macro-F1 29.5 / R@2 57.5；最强平均基线 UniMTS 为 31.9 / 26.4 / 46.9，绝对差 +3.8 / +3.1 / +10.6。
- 按标签空间分档：easy（<10 类）多在 48–59，hard（>20 类）显著下滑——UT-MHAD（27 类）Acc 16.3、Ego4D（31 类）8.6、MMEA（32 类）8.1。
- 跨模态检索（Nymeria 留出被试，sim-to-real，100 候选）：IMU→Text MRR 由最强基线 10.0 升到 44.6，Text→IMU 由 6.7 升到 46.7；全样本设定仍领先，但正文未给具体数值。
- 跨模态检索（EgoExo4D 零样本 OOD）：所有方法退化，AnyMo 在多数指标为最好或次好。
- Captioning（Nymeria 留出）：BLEU-1 25.0 / BLEU-4 6.5 / ROUGE-L 31.1 / METEOR 33.5 / BERT-F1 69.7；对比最强提示基线 GPT-5.4 Mini 的 ROUGE-L 15.7、BERT-F1 57.3。
- Captioning（EgoExo4D 零样本）：BLEU-1 20.7 / METEOR 30.3 / BERT-F1 67.1，仍高于 GPT-5.4 Mini 与 Gemma 4 26B。
- 消融（Acc/F1/R@2）：去掉几何感知仿真塌到 8.4/3.8/16.3；去掉掩码跨视图预测对比 10.5/4.5/19.0；去掉全部对比微调 23.5/15.8/40.3；去掉标签对比 33.3/27.1/51.4，去掉叙述对比 32.6/23.8/50.1；去掉 MCQ 分支 Acc 反升至 36.0 但 F1/R@2 下降。

## 创新点与贡献
- 把「佩戴设置」从随机扰动改写成结构化体表几何问题：在模板网格顶点上构造面内传感器系并采样安装旋转，一次性生成 2,374 个物理合理的放置候选，而不是只在关节处合成。
- 提出掩码跨视图预测对比（MCVPCL）：用一套放置的稀疏掩码视图去预测另一套放置的全视图隐变量，再在批内做 InfoNCE 判别，把「稀疏→全身」「实例可分」「时序保留」三个要求合成一个目标。
- 全身 IMU token 化：在冻结图编码器的隐变量上做乘积量化 VAE，得到与传感器位置无关的紧凑 token 序列，把输入长度从「传感器数×通道×时间」压到「时间×P」。
- 码本向量直接投影进 LLM 嵌入空间并初始化 LM head，使新词表 token 自带运动语义，再用多任务对比指令微调同时支撑零样本识别、双向检索与 caption 生成。

## 局限与风险
- 作者未设独立局限性章节；正文承认检索与 captioning 在 EgoExo4D 上「all methods degrade」，即 OOD 迁移仍明显掉点（EgoExo4D caption BLEU-4 仅 0.4，Nymeria 为 6.5）。
- 作者在方法里承认约束：所有训练信号只来自 Nymeria 一个数据源（808 个样本、164,387 个文本对齐窗口），真实 IMU 仅用于估计噪声先验与留出评测。
- 我在正文发现：零样本 HAR 的绝对值仍然很低（平均 35.7），hard 档 27–32 类只有 8.1–16.3，相对 32 类随机水平 3.1 的余量不大；论文用「相对提升」表述成绩，容易高估可用性。
- 我在正文发现：预训练要求有参数化人体模型 + 网格（Nymeria 模板），对手机放口袋、耳机、戒指等「非体表解剖段」的设备只能映射到最近的 23 段之一，几何先验会失真，这一点正文未评估。
- 我在正文发现：骨干只有 Qwen2.5-0.5B，caption 目标文本来自 atomic-action 短句，模型学到的是「动作短语复述」而非自由描述；同时表 2 只报了 100 候选的 MRR，全样本设定「clearly ahead」无数字，检索结论的证据完整度不如识别任务。

## 与文献库的关系
在文献库的可穿戴/人体运动线上，本文与 ViMoWear（sEMG-IMU 跨被试拇指手势）、免校准 IMU 相对定向、EgoWholeView/FlowAvatar 一类「少传感器恢复全身」的工作形成对照：那些工作解决几何或识别，本文把稀疏 IMU 直接接到语言空间做零样本识别、检索与描述。相对 IMU2CLIP、ImageBind 的真实传感器–语言预训练，AnyMo 的关键差异是用体表几何合成「任意设置」再以跨视图掩码预测逼出设置不变性；相对 IMUGPT、UniMTS 的关节中心合成，它把合成位置从关节移到体表网格并显式建模安装旋转。与 Nymeria / Ego-Exo4D 生态（Ego-Exo4D-HM、EgoWholeView）互补：那些提供数据与动作标注，本文提供可迁移的表征与 token 接口。

## 可复现性（代码/数据/硬件）
项目页 https://baiyuchen.com/project/AnyMo，正文未见 GitHub 代码链接；训练数据依赖 Nymeria（需自行申请，非本文发布），AnyMo Bench 由作者从 Nymeria 真实 IMU 流构建；超参较完整：ST-GCN 用 AdamW lr 3e-4、batch 64、10 epochs，LM 全参微调 bf16、序列长 1024、lr 1e-4、batch 16、3 epochs，对比指令微调 1 epoch（序列 4096、lr 2e-5、温度 0.05、对比损失权重 2.0、每卡 batch 16 × GradCache 4 步 × 2 卡 = 有效 128），硬件 NVIDIA L40S。
