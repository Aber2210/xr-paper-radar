# ClearForm：透明与不透明场景的共享表面高斯泼溅

## 一句话结论
把几何与外观的 alpha 合成解耦后，ClearForm 在 3D-FRONT-T 上把 Chamfer distance 从 PGSR 复现的 59.18 mm 降到 27.05 mm、F1 从 0.786 提到 0.928，在 TransLab 上达到 1.65 mm CD、0.963 F1 与 40.14 dB PSNR。

## 要解决的问题
透明界面透光又构成边界，重建须同时恢复其几何与透射背景外观。PGSR 等平面化 3DGS 用同一套 alpha 混合平面法向与距离估深度：一旦为显形背景而压低界面 alpha，它在几何合成中的权重也同步下降，即几何-外观合成困境（GACD）。单平面时 alpha 会约掉，但当界面与背景落在同一像素，透明度改变相对权重会使深度偏移，削弱一条局部几何梯度通路，较小贡献还会被逐像素阈值跳过。界面几何因此塌陷、被误判为背景，而 GLINT、TSGS 等依赖二次光线或不做显式 PBR 分解，未处理该冲突。

## 方法详解
在 PGSR 的共享平面 Gaussians 上把合成拆为两条路径。几何路径用不随透明度衰减的权重混合平面属性（法向与距离），使透明界面照常参与深度估计；外观路径用学到的透射率显示背景颜色，并在同一表面表示稀疏反射。两者共用同一组平面 primitives，因此无需额外透射组件或二次光线。配套的透明度感知深度-法向一致性与多视图几何约束监督界面，而不要求界面在 RGB 上遮挡透射光。由于两路径可见性条件不同（界面在几何 pass 中可遮挡背景高斯，但后者对透射 RGB 仍有用），作者提出 Dual-Evidence Lifecycle：只要某高斯在几何 pass 可见，或在多个相机上对 RGB 损失有一阶正贡献就保留，证据沿克隆与分裂血缘继承，避免透明度剪枝与纯几何判据各自的漏删。为验证机理，作者在固定高斯检查点上用真值首表面深度测量界面支撑，发现解耦后首命中平均权重与像素覆盖均提升近一倍，说明共享 alpha 确实在光栅化阶段丢掉了界面贡献。网格由几何 pass 深度经 TSDF 融合提取。

## 创新点与贡献
['显式命名并推导 GACD：证明 alpha 在单平面深度中约掉、但在界面与背景重叠时不约掉，并定位到局部几何梯度通路与 per-pixel 阈值两个具体机制，用固定 checkpoint 的 first-hit 覆盖度量给出量化证据。', '在共享平面 Gaussians 上实现 geometry-preserving dual-opacity：几何与外观分别合成，界面既参与几何又不遮挡透射色，同时在同一表面保留稀疏反射，无需透射组件或二次光线。', 'Dual-Evidence Lifecycle：把“几何 pass 可见”与“对 RGB loss 有一阶正贡献”合并为多视图存活判据，并沿 clone/split 血缘传播，解决双不透明度带来的可见性错配。']

## 局限与风险
['作者承认强反射与缺失透明度引导会显著降低界面重建质量。', '作者承认 single-depth mesh fusion 会把开放容器（杯子、花瓶）错误封口。', '作者承认累积消融评估的是完整 lifecycle，未隔离“证据项”与“血缘项”各自贡献，无法把增益归因到单一梯度机制。', '我发现：依赖 SAM 3 的 “transparent glass” 掩码与 StableNormal 法向先验，掩码漏检时 DEL 的“RGB 正贡献”判据可能保留大量伪界面；且加入 dual-opacity 时 PSNR 反降，说明几何与光度目标仍存在张力。']

## 与文献库的关系
与 PGSR 同源（复用其平面表示与 TSDF 融合），差别在合成规则本身；与 GLINT（分离 interface/transmission/reflection 组件 + 二次光线传输）、TSGS（分离几何学习与透明度外观精修）、TransparentGS（deferred refraction）、RT-Splatting（分离 geometric occupancy 与 optical opacity）同属透明重建一脉，但坚持直线光线 splatting、不显式建模折射路径与折射率；剪枝侧与 LightGaussian、PUP 3D-GS、MaskGaussian 的多视图判据相关，但提出双证据标准。

## 可复现性（代码/数据/硬件）
有项目页 https://hajeongx.github.io/clearform/；基于官方 PGSR 代码库，数据为公开或可申请 benchmark，训练超参与评估协议（TSDF 体素 0.01 m / 0.002 m、F1 阈值 5 cm / 5 mm）写明。GPU 型号正文未述。可复现性较高。

## 行动建议
优先读 §3 的 GACD 推导与 §5.4 的固定 checkpoint 度量，这两节是全文真正的贡献。风险：F1 阈值 5 cm 偏宽松，CD 的巨大改善在薄壁玻璃（TransLab 5 mm 阈值）才见真章；PSNR 与 CD 不同向，选型需按下游任务权衡；DEL 会改变 Gaussian 数量预算，长训练下需重估显存。
