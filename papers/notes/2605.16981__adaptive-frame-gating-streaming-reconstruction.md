# 重思长序列循环三维重建的状态更新门

## 一句话结论
诊断出 TTT3R 类 per-token 门控的记忆视界仅约 3 帧，提出免训练、免参数的帧级门 α_t，长 TUM-RGBD 序列 ATE 降 51%，Bonn 深度 AbsRel 降 13.0%。

## 要解决的问题
DUSt3R/VGGT 一类离线批量方法需要同时载入全部帧并做全局注意力，代价随序列二次增长；CUT3R 用固定大小递归状态实现常数内存，但长期序列上状态漂移严重。TTT3R/TTSA3R/MeMix 等推理时方法只在 per-token 的帧内轴上调制更新，把每一帧都当作同等信息量写入，缺少「这一帧该写多强」的帧级判断。

## 方法详解
先做结构性诊断：在 5 个基准、39 条序列、18.15M 个 (t,n) 采样点上统计 TTT3R 的 per-token 门 β_t，发现其被 L×H×K≈110K 个 cross-attention logit 的平均+sigmoid 压成窄带（中位数 0.31，99% 小于 0.44，最大 0.558，逐序列均值仅在 [0.27,0.34]），且帧间均值标准差 0.024 远小于帧内 0.055。把更新写成凸组合即 EMA 后，等效记忆视界 ≈ 1/β ≈ 3 帧，早期观测在百帧内衰减到 1e-16，这是长序列漂移的结构性根因。修复方式是把更新因式分解为 S_t = S_{t-1} + α_t·β_t⊙ΔS_t：α_t∈(0,1] 是标量帧级门，由基础模型已有特征的帧间变化闭式给出，AFG-Img 用编码器 patch token 的空间均值 g_t 的 L2 差分，AFG-Pose 用 decoder 的 pose token 差分，形式为 σ(κ(‖Δf‖₂-τ))，再乘到 β_t 上。两个门作用在正交轴（token 空间选择 / frame 时间写入强度），不丢帧、不加参数、不做额外前向、不需训练，因而保持常数内存。

## 实验与结果
覆盖 6 个基准、序列长 50–4661 帧：TUM-RGBD / ScanNet / KITTI 做相机位姿，Bonn 做视频深度，7-Scenes / NRGBD 做 3D 重建。基线含推理时门控（TTT3R、TTSA3R、MeMix）、前馈骨干（CUT3R、StreamVGGT、FastVGGT、InfiniteVGGT）与长序列专用方法（LongStream、Keyframe-VO）。长 TUM-RGBD（L≥600）上相对 TTT3R ATE 降 51%；Bonn 深度 AbsRel 降 13.0%；KITTI 上平均 ATE 同时优于 LongStream 与 RL 训练的 Keyframe-VO，三条超 4000 帧序列分别改善 50.8%/38.9%/43.7%，但短序列 04（271 帧）反而恶化 43.9%。ScanNet 1000 帧处 pose ATE：AFG-Pose 0.054 m vs TTT3R 0.109 m（约 -50%），AFG-Img 0.084 m。附录含冗余注入探针，验证门在内容冗余时把更新压低一个数量级。

## 创新点与贡献
- 给出 per-token 门控的结构性诊断（有界、近似帧不变、记忆视界≈3 帧），把长序列漂移从经验现象变成可解释机制。
- 把经典 SLAM 关键帧选择的思想改造成「渐进写入权重」而非二值取舍，用闭式标量门补上时间轴自适应性。
- 完全免训练、免参数、零额外前向即可插到 CUT3R/TTT3R 类骨干，且严格保持常数内存。

## 局限与风险
- 无回环检测，门只能保护本会被覆写的信息，短轨迹或已积累信息很少时几乎无收益（KITTI 04 恶化 43.9%，05/07 也退化）。
- 改善与序列长度只是趋势而非规律，超参 τ、κ 与两个门的组合需逐任务调。
- 依赖基础骨干已产出的特征质量，骨干换架构后门的设计需重新实例化。
- 评测以 ATE/AbsRel 等几何指标为主，缺少下游 SLAM 或建图任务的端到端验证。

## 与文献库的关系
属于 CUT3R → TTT3R → TTSA3R/MeMix 这条「常数内存递归重建 + 推理时门控」脉络，并与 LongStream（重训）、Keyframe-VO（RL 选帧）两条长序列路线正面比较，本质是把 SLAM 关键帧选择以连续权重形式复活。

## 可复现性（代码/数据/硬件）
方法零训练零参数、代码改动仅在状态更新一行，复现门槛低；论文未给出代码仓库链接，但基线均为开源模型。

## 行动建议
任何基于 CUT3R/TTT3R 的在线重建系统都可先加这一行 α_t 乘法做低成本试水，重点看长序列；短片段场景不必启用。
