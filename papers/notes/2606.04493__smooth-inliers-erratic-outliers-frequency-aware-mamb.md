# 平滑内点、跳变外点：面向双视图对应学习的频率感知 Mamba

## 一句话结论
用 cluster 诱导顺序 + 可学习复值低通门让 Mamba 扫描获得频率含义，YFCC100M mAP@5° 73.83%，超 MatchMamba 3.6 点。

## 要解决的问题
宽基线、重复纹理、光照变化下，SIFT/SuperPoint 最近邻得到的 putative matches 大多错误，RANSAC 随内点率下降急剧变慢，因此需要 correspondence pruning 网络先判内点。Mamba 类剪枝器把对应集合当普通序列扫描，留下两个问题：对应本是无序集合，扫描顺序任意，外点的跳变响应会被逐步向后传递；一致性只从粗粒度 4 维坐标推断，网络偏向平滑函数，会抹平区分内点与邻近外点的微小偏移。

## 方法详解
输入 N=2000 组 putative correspondences C∈R^{N×4}，走两个 pruning block（各保留较可靠的一半）加一个 verification block：由可微加权八点法解 Ê，再按极线距离回收被剪掉的内点。每个 block 内先用 ResNet 提特征，按 MS²DG-Net 的稀疏语义距离建 kNN 图，MLP+max pooling 得图特征 F^F。LSGA 的 SGEA 把邻居相对坐标 ΔC 用固定随机高斯投影 B 展成 sin/cos 傅里叶特征以对抗 MLP 的 spectral bias，再注入局部几何注意力：Q 来自 F^F，K/V 为邻居特征加几何嵌入，复杂度 O(NkD)。SSCM 用 DiffPool 软分配到 M≪N 个 cluster，以分配定义的顺序 Π 做 BiMamba 扫描，同时用 BiCSM 精炼 cluster 特征，再经多尺度交互让每个对应查询 cluster 共识。SIGM 复用 Π 排序，前向 Mamba 后用可学习复值频率门 W_gate1 滤波（FFT→逐频逐通道乘门→IFFT，门按序列长度插值），翻转后再过反向 Mamba 与第二道门，残差加 LN 融合；门只改变传播内容、不改 Mamba 状态转移，整体 O(DN log N)。训练目标为 BCE 分类损失加 γ 倍 Sampson 距离几何损失，500k 迭代、单卡 RTX 3090。

## 实验与结果
- YFCC100M Unknown（SIFT，无 RANSAC）mAP@5° 73.83% vs MatchMamba 70.23%（+3.60 点）、重训版 67.60（+6.23）
- Known 62.28 vs 60.09
- SUN3D：Known 28.74 vs 27.23、Unknown 21.97 vs 21.37，两 split 均领先
- SuperPoint（YFCC100M）：Known @5° 50.20 vs 44.12、Unknown @5° 70.10 vs 64.43
- @20° 58.82/81.04 vs 52.19/77.71，两 split 领先均超 6 点
- Outlier removal（SIFT）：YFCC100M F-score 83.16 vs 82.36（P 82.49、R 85.37），SUN3D F-score 81.51 vs 79.15（P 80.05、R 83.49），精度与召回同时上升
- 消融（5 seed，YFCC Unknown @5°）：backbone baseline 55.87 → +LSGA 64.71（+8.84）→ +LSGA+SIGM 73.64（再 +8.93）
- 容量匹配的 point-wise MLP 与固定高斯低通均不如学习门
- 效率：2.01M 参数、5.01 GFLOPs、AIT 4.80 ms、ART 370.42 ms，MatchMamba 为 2.08M/5.15 G/5.03 ms/383.31 ms
- 打乱输入仅改变 ≤1.5% 保留对应，pose 变化 <0.1 点

## 创新点与贡献
- 把“内点平滑、外点跳变”转成沿 cluster 诱导顺序的频域性质，并在 Mamba 双向扫描之间插入可学习复值低通门，使频率在无序集合上获得可定义的含义
- 给出块内置换只产生低能量高频残差的定量解释，从理论上说明门控为何带来顺序不敏感性
- 用容量匹配 MLP、固定低通滤波器与能量重标定三组对照，证明收益来自频率响应而非参数或能量

## 局限与风险
- 前提是一致性呈低频谱结构
- 强重复纹理下成组错配彼此一致时会失效，作者承认这是所有一致性方法的共同问题
- 只对单阶段单门做精确分析，完整两阶段网络的顺序不变性只有经验验证，端到端保证仍是未来工作
- 主表协议不加 RANSAC，未验证与 MAGSAC 等鲁棒估计器组合后的收益
- 无公开代码
