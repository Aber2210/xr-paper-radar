# MIR-Depth：透明物体单视角 RGB-D 深度补全的多区间精化

## 一句话结论
用同预算多区间候选取代单区间回归，并以原始深度残差做度量重锚定：TransCG MAE 6.833 mm（ReMake 8.040），跨相机零样本时尺度不再漂移。

## 要解决的问题
透明物体的镜面反射造成深度缺失，折射又让非零返回值携带背景深度，原始测量不能当表面锚点。在固定采样预算下，于单一搜索区间内精化初始深度要么漏掉大折射偏移，要么牺牲局部细节。

## 方法详解
以先验引导的初始深度为锚，构建坐标感知多区间假设：三维聚合的全局逆深度体，加沿深度轴滤波的逐像素局部体。选择性循环精化用越界查表掩码与有效性掩码 softmax 融合，经多尺度 ConvGRU 迭代更新逆深度。最后用学习到的逐像素空间门控修正全分辨率残差，保留准确初始几何而不把原始读数当硬约束。

## 实验与结果
- TransCG MAE / RMSE = 6.833 / 10.504 mm（ReMake 8.040 / 11.363）
- TransCG δ1.05 = 94.41%（ReMake 93.63%）
- 孔洞 20 mm 内准确率 = 92.32%（ReMake 91.26%）
- >20 mm 外点修复率 = 89.74%（ReMake 88.52%）
- 零样本 ClearPose MAE / RMSE = 122.294 / 238.050 mm（ReMake 309.147 / 378.079）

## 创新点与贡献
- 用同一预算下的多区间候选取代单区间回归，并以原始深度残差做度量重锚定，使跨相机零样本时尺度不再漂移

## 局限与风险
- 只能恢复可见表面，无法给出未观测几何
- 均匀背景下的全透明物体几乎无可见边界时本质上不可解
- 尚未利用时序信息
