# WorldBridge：桥接散乱视角的连贯 3D 世界生成

## 一句话结论
在几何-外观共享 latent 上做条件流匹配，条件分两路（可训 scene encoder 聚全局 token + 冻结 DepthAnything v3 保住单参考细粒度），把低重叠散乱参考生成连贯世界——RE10K 2-view PSNR 20.88（SEVA 18.47），长序列 17.68（GLD 16.43）、ATE 0.657（GAE 1.508）、δ1 71.0（59.4）。

## 要解决的问题
从几乎没有视觉重叠的散乱参考图生成连贯、可探索的 3D 世界是长期难题：几何感知方法在无重叠时几乎失效，图像/视频生成方法能补出未见区域但跨视角几何不一致。现有 benchmark（RealEstate10K、DL3DV-10K）主要评有重叠参考的新视角合成，不覆盖低重叠与轨迹外参考。在自建的低重叠设定下，最强基线整体 PSNR 只有 16.13 dB（GLD），长序列上 PSNR 16.43 dB、AbsRel 0.454、ATE 1.748。

## 方法详解
以 GAE 的几何-外观共享 latent 为底座，训练 conditional flow matching：$\mathcal{L}_{FM}=\mathbb{E}_{\mathbf{z}_0,\epsilon,t}[w(t)\|v_\theta(\mathbf{z}_t,t,c)-(\epsilon-\mathbf{z}_0)\|^2]$，$\mathbf{z}_t=(1-t)\mathbf{z}_0+t\epsilon$。条件分两路：scene encoder $E_{sc}$（LagerNVS 初始化后可训）把带位姿参考聚成全局 scene token $S$；reference encoder $E_{ref}$（DepthAnything v3，冻结）独立编码每张参考得 $\mathbf{z}^{ref}_i$，保住单张观测的细粒度外观。camera-conditioned scene reader 用目标视角的逐 patch Plücker 射线 $r(P_i)$ 查询 $S$，得 $C_i=W_{sc}\mathrm{LN}(\mathrm{Resize}(R_{sc}(S,r(P_i))))$，与视角 latent 一起 patchify 后送 DiT；同时用低分辨率 RGB 监督 scene reader，$\mathcal{L}_{sc}=\sum_{(P,I)\in\mathcal{Q}}\ell_{rgb}(\hat I_{sc}(S,P),I)$，总损失 $\mathcal{L}=\mathcal{L}_{FM}+\mathcal{L}_{sc}$。Temporal/spatial reference attention：参考分为沿目标轨迹、有时间位置的 $R_T$ 与有位姿但无时间位置的 $R_S$；temporal RoPE 只在注意力两端都属于 $\mathcal{G}\cup R_T$ 时施加（掩码 $m_{ij}=\mathbf{1}[i\in\mathcal{G}\cup R_T\land j\in\mathcal{G}\cup R_T]$），涉及 spatial 参考即省略，spatial RoPE 与基于 Plücker 射线的 SCoPE 相机编码对所有对保留，spatial 参考另加可学习 role embedding；训练时随机把部分 temporal 参考降级为 spatial，并以 0.5 概率丢弃 temporal 位置。Latent-reference consistency（LRC，即插即用）：用 MoGe-3 估每张参考的米制点图并前向投影到目标相机，剔除深度边界、用 z-buffer 解冲突，得伪图 $\tilde I_j$ 与 mask；对预测的干净 latent 做一步梯度 $z_0^*=\hat z_0-\eta\nabla_{\hat z_0}\mathcal{L}_{proj}$（RMS 归一化，相对步长 0.01），再按 $\lambda_i(t)=0.1t+(0.5-0.1t)d_i$（$d_i$ 为到最近参考的归一化距离）混入估计噪声与新噪声继续去噪。训练：22k 视频片段、672×378、32 卡 10 epoch、batch 64、lr $5\times10^{-5}\to5\times10^{-6}$；推理 50 步去噪、CFG 2、空文本提示。

## 实验与结果
- RealEstate10K：1-view PSNR 16.71 / SSIM 0.601（GAE 15.77 / 0.557），2-view 20.88 / 0.756（SEVA 18.47 / 0.648）
- DL3DV-10K：1-view PSNR 17.48、2-view 21.33 dB（最佳基线 2-view 18.63）
- WorldBridge-Short 整体：PSNR 18.35（GLD 16.13）、SSIM 0.604、LPIPS 0.333
- WorldBridge-Long：PSNR 17.68（GLD 16.43）、AbsRel 0.345（0.454）、δ1 71.0（59.4）、ATE 0.657（GAE 1.508）
- WorldBridge-Long：RPE_r 3.456、RPE_t 0.397、特征重投影 0.173、几何重投影 0.099、参考误差 0.200、美观分 5.248
- WorldBridge-Agent：ATE 3.278 / 3.303（On/Off，AnyRecon 3.711 / 4.680），几何重投影 0.057 / 0.061
- 模型 0.94B 可训练参数、22k 片段、32 卡 10 epoch；50 步去噪、CFG 2；LRC 增加 18.3% 推理时间

## 创新点与贡献
- 相对 SEVA/AnyRecon 等逐视角生成或 scene-query 方法，WorldBridge 把「全局场景上下文」与「单参考细粒度 latent」解耦为两条条件通路，并用选择性 temporal RoPE 让轨迹外参考不必被硬塞时间位置，从而同时保住全局连贯与局部保真
- 相对已有只评重叠参考的 benchmark，提出低重叠（大量参考对重叠 <1%）、长序列与 on/off-trajectory 三档评测
- LRC 作为推理期即插即用模块，不改训练、不加参数

## 局限与风险
- 作者自述可能缺细粒度与结构几何
- 当目标视角与 spatial 参考几乎没有重叠时，参考提供的指导有限，生成质量下降
- 训练成本高（32 卡 10 epoch、0.94B 可训练参数），LRC 额外增加 18.3% 时延，长序列超出 41 视角需扩展 RoPE 或分段生成
- benchmark 与模型都写明「接收后发布」，当前不可复现
- Agent 子集为合成场景，与真实拍摄分布有差距
- 相机与一致性评测依赖 VGGT-Ω 估计，存在评测器耦合
