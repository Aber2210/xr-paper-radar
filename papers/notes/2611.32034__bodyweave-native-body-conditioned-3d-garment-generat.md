# BodyWeave：原生身体条件的三维服装生成

## 一句话结论
把「身体条件」做成贯穿生成全过程的两级空间参照（GBA 在稀疏结构层定放置与延展、LBA 在潜变量表面细化时用 KNN + 3D RoPE 只聚合邻近身体几何），并用 SDF 余量违规回传到潜空间：GarmentWeave3D CD 6.36 mm、穿透率 0.080% vs Garment3DGen 31.007%。

## 要解决的问题
为数字角色生成 3D 服装需要在保留参考设计的同时适配目标身体的形状与姿态。缝纫纸样方法（SewFormer、DressCode、AIpparel、SewingLDM）依赖纸样表示与训练覆盖，面对陌生素形与精细结构（褶裥、层叠领、袖口系带）时难以还原；图像到 3D 的生成器虽有强形状先验，却缺少显式 3D 身体上下文，只能靠图像空间引导或生成后几何优化补配，导致物体穿插（Garment3DGen 在 A CG 上穿透率高达 27.7%）与合身性差。换言之，生成与试穿被割裂成两段。

## 方法详解
以身体作为整个几何生成过程的空间参照，统一“生成”与“合身”，直接输出身体坐标系下的网格 (M̂_t,Â_t)=F(I_s,B_t)。基于 TRELLIS.2 的稀疏结构 + 结构化潜变量（SLat）由粗到细框架：第一阶段冻结 SS-DiT，在每一 transformer 块后插入 Global Body Adapter（GBA），把冻结稀疏 VAE 编码的身体占据潜变量 b_t^SS（不加噪、作为固定空间参照）与服装特征在空间对齐后做残差注入 h^(n)=h̃^(n)+P_o(SiLU(P_h(LN(h̃))+P_b(b_t^SS)))，P_o 零初始化以保留预训练映射，从而在细化表面前先决定服装的放置与延展范围。第二阶段在 LR/HR 形状生成中插入 Local Body Attention（LBA）：对每个服装位置取 K 个最近身体 token，用 3D 旋转位置编码做 KNN 限制的多头注意力，只让邻近身体几何影响局部形状。并提出 Surface Penetration Loss：用身体 SDF 对解码后顶点计算余量违规 ρ=max(0,m-d(p))（m=2.32mm），按违规点计数归一化后回传穿过冻结可微解码器，弥补潜空间 flow matching 无法显式度量穿插的问题，总目标 L_shape=L_FM+L_pen。最后以生成几何与参考图条件化 PBR 材质合成（base color、metallic、roughness、alpha），全流程无需生成后对齐。数据侧构建 GarmentWeave3D：缝合纸样数据集 + GarmentCodeData v2 的同设计跨身体配对 + 自建高细节资产，共 293.8K 对齐观测、114.7K 跨身体对、约 2.5K 布料材质。

## 实验与结果
- GarmentWeave3D 重建：CD 6.36mm、F@10 83.68、Normal 0.920、穿透率 0.080%、P95 2.58mm，全面优于 Garment3DGen 的 20.19 / 39.40 / 0.770 / 31.007%
- 域外 Artist-Created Garments：CD 16.14mm（比 Garment3DGen 的 21.64 降低 25.4%）、F@10 68.98、Normal 0.867、穿透率 0.856%（基线 27.7%）
- 跨身体适配（16 个定向任务）：CD 8.78 vs Garment3DGen 74.78、AIpparel 58.21；间隙误差 Clr. 4.85 vs 45.11；穿透 0.204%
- 外观合成（共享几何）：PSNR 23.03 / SSIM 0.802 / LPIPS 0.112（FabricDiffusion 13.62/0.495/0.324，TRELLIS.2 15.35/0.658/0.189）；留出视角 LPIPS 比 TRELLIS.2 低 28.9%
- 消融：去掉 GBA 后重建 CD 从 6.36 暴涨到 279.20、间隙误差 4.85→194.10；去掉 LBA 穿透率 0.204%→9.338%
- 数据规模：293.8K 对齐服装-身体观测、114.7K 同设计跨身体对、约 2.5K PBR 布料材质

## 创新点与贡献
- 把“身体条件”做成贯穿生成全过程的两级空间参照，而非生成后的对齐或图像空间的投影引导：GBA 在稀疏结构层决定放置与延展，LBA 在潜变量表面细化时用 KNN + 3D RoPE 只聚合邻近身体几何，二者都是零初始化残差注入，可在保留大规模预训练先验的同时学到服装-身体关系
- 配套的 Surface Penetration Loss 直接把 SDF 余量违规回传到潜空间生成器，并构建了带同设计跨身体配对的 GarmentWeave3D，使“同图不同身体、同设计同材质”的适配可被显式监督

## 局限与风险
- 仍建立在 TRELLIS.2 的稀疏结构与潜变量表示之上，泛化上限受底座先验与训练分布约束
- 域外资产 CD 从域内 6.36 退化到 16.14mm、穿透率升到 0.856%，说明复杂剪影仍有明显差距
- 评测以 CD/F-score/穿透/间隙等几何与渲染指标为主，缺少真实布料材质参数、动态垂坠、多层穿着与人体姿态大幅变化下的验证
- 跨身体任务仅 16 个，规模偏小
