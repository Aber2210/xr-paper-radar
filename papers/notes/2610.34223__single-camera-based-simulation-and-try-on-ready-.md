# 单相机仿真与试穿就绪的化身建模

## 一句话结论
提出物理集成的双层 GS-Mesh 表征，仅用单目视频甚至单张图像即可重建解耦的 3D 穿衣人体化身，实现视觉合理的布料动力学虚拟试穿与新姿态动画（摘要级信息，无量化结果）。

## 要解决的问题
从单目视频或单张图像重建高保真、可动画、试穿就绪的虚拟化身仍困难：①现有方法常用单层表征同时表示服装与底层躯体，忽略二者不同的运动特性；②单相机输入往往无法完整覆盖服装与身体，导致观测不足。

## 方法详解
提出物理集成的双层（double-layer）GS-Mesh 表示，将服装与底层躯体解耦以贴合各自运动特性，从单目视频甚至单张图像重建 3D 穿衣人体化身；2D 生成方法可由给定姿态序列生成视频但难以保持帧间一致，故引入 2D 生成数据补足单相机观测，并把生成数据的帧间不一致显式分解为几何不一致与外观不一致分别约束，使最终重建与渲染兼具 3D 一致性与时序连贯。相比依赖多视图重建的 3D 服装迁移与不做新视角/新姿态合成的 2D 扩散编辑，本方法仅需单目输入即可产出视觉合理的布料动力学试穿与新姿态动画。（依据 ar5iv 摘要页整理）

## 创新点与贡献
①面向单目视频/单图输入的物理集成双层 GS-Mesh 穿衣化身表征；②将 2D 生成数据的帧间不一致分解为几何与外观两类并分别约束；③以单相机输入同时产出合理布料动力学试穿与新姿态动画，优于多视图 3D 迁移与 2D 编辑路线。
