# BudSplat：渲染预算约束下的紧凑前馈 3D 高斯泼溅

## 一句话结论
BudSplat 把紧凑性视为渲染预算约束下的表示学习：从 VGGT 多层 token 残差估计细节重要性并贯穿体素融合与剪枝，RE10K 32 视图下以 5% 保留率仅用 97K 高斯取得 23.08 PSNR（AnySplat 1363K 得 22.69），40% 保留率 545K 达 23.69；同预算消融完整模型较基线 13.23 升至 23.02。

## 要解决的问题
前馈 3DGS 从稀疏输入走向密集多视图时，瓶颈从重建不确定性转向渲染效率：密集输入提供更强几何约束，但候选高斯随视图数快速增长，体素化/池化等抑制机制无法根治 splatting 成本。按不透明度、置信度或全局 top-k 的简单剪枝会让保留集被大面积、被反复观测的平滑区域垄断，而薄结构、遮挡边界与高频纹理在融合中被平均、在剪枝中被删除。现有压缩方法多为重建后处理，未把紧凑性作为预测的一部分，也缺乏可靠的“哪些高斯值得保留”的判据。

## 方法详解
BudSplat 基于 AnySplat 式管线（VGGT 骨干预测稠密几何、置信度与多层 token）。（1）细节感知重要性：对保留 VGGT token（第 {4,11,17,23} 层）做低秩降维-升维重构，残差经线性细节头得 patch 级 logit，多层学习权重融合，以“无门重建渲染残差+光度/几何变化”混合 stop-gradient 目标做 BCE 监督，融合前上采样挂到候选点。（2）保重要性体素融合：logit ℓ_j=1.0c_j+1.5d_j+0.5t_j（置信度、细节、支持先验），softmax 归一后加权融合，高细节少数贡献者不被平滑区多数候选稀释，并记录体素支持数 s_m。（3）质量感知剪枝：r_m=log(α_m+ε)+1.0D_m−0.15log(1+s_m)，可微分门（温度 2.0→0.7、下限 0.2→0 退火）经 straight-through 供梯度、硬选择做前向；再按 patch（主导贡献者 token 单元）做配额重分配——先按候选数给基础配额、再按细节强度与剩余容量分余额，块内仍按 r_m 选。训练含重建、细节 BCE、预算匹配、门熵、自重要性（|∂L_rec/∂α|）与无门教师正则，keep ratio 从 1.0 退火至 0.05 并后期随机采样 {0.05,0.10,0.20,0.40}。

## 实验与结果
在 RE10K+DL3DV 混合训练（采样权重 0.7/0.3），评测 RE10K、DL3DV、ACID（域外），采用 NoPoSplat 式低重叠压力协议（目标视图重叠 <30%），16–72 视图、448×224 渲染，指标 PSNR/SSIM/LPIPS/#GS。RE10K 32 视图：ρ=5% 以 97K 高斯得 23.08 PSNR，ρ=40% 以 545K 得 23.69，均优于 AnySplat（1363K，22.69）与 WorldMirror（1782K，22.85），VolSplat 与 GGN 在 72 视图 OOM；ACID 72 视图 ρ=5% 用 227K 高斯得 22.68，而 AnySplat 需 4557K 才 22.41。RE10K 24 视图同预算消融：AnySplat 式预算基线 13.23 PSNR → 完整 23.02 PSNR，去掉细节 token 分支降幅最大（20.04），其余模块移除均掉点，证明四组件互补。

## 创新点与贡献
（1）首次把前馈 3DGS 的原语增长问题形式化为渲染预算约束的表示学习，重新定义剪枝为“学习型预算分配”而非事后压缩。（2）残差 token 分解估计 patch 级细节重要性，为融合与剪枝提供显式感知质量线索，并有混合目标监督。（3）保重要性体素融合 + 质量感知排序（不透明度+细节−支持冗余惩罚）+ patch 级配额重分配三件套，把有限预算集中到真正影响新视图质量的细节区域。（4）在三个数据集、16–72 视图上系统展示质量-紧凑性-效率的帕累托优势，并以高斯密度可视化诊断佐证预算再分配行为。

## 局限与风险
论文自述：BudSplat 只在 VGGT 几何骨干之后降冗余，不优化骨干显存，极密集输入序列仍可能先受 VGGT 计算限制（24 视图下全流程峰值约 42 GB/卡，骨干约 33 GB，占 79%）；方法依赖预测几何与置信度线索的可靠性；过小预算仍可能在高度复杂区域丢失细节；加权融合受预测几何制约，同一体素内无法完全分离不同表面；未测试专门的稀疏 360° 基准。

## 与文献库的关系
