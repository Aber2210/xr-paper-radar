# 通过测试时潜变量自适应合成表达性人-物交互

## 一句话结论
把「对未知物理属性的试探性适应」本身当作表达性动画来源，测试时调潜变量而不更新网络参数：搬运 98.18%（CooHOI 92.01%）、负载适应 4–40 kg（5–15 kg）、推拉 94.38% 对 42.54%。

## 要解决的问题
与未知物理属性的物体交互时，真人会「试探—过度用力—踉跄—调整」，这种适应过程本身是表达性的；但动捕数据驱动方法缺少这类细粒度数据而只生成僵硬的通用成功动作，RL 物理控制器又因具备物体动力学的特权信息而总输出确定性的最优动作。

## 方法详解
训练期把物体物理属性（质心偏移、惯性、主轴转动、质量、接触/阻尼参数共 23 维，以及地面 4 维）经上下文编码器与信息瓶颈（KL 到 N(0,I)）压成结构化潜变量 z，与可观测状态一起驱动 PPO 训练的对象交互控制器（推/拉/搬运三技能）。测试期物体属性未知，改用 Advantage-Weighted Regression 在并行仿真中做测试时潜变量调优（K=3 次试验、批量 512、权重裁剪 3.0），用试验间的收益加权拟合潜分布；中间试验与真值属性之间的持续失配本身就是表达性用力的来源。再用失败感知的规则状态机协调交互控制器与绕行控制器，形成「放弃—放下—绕行—重试」的完整动画。

## 实验与结果
- 立方体搬运成功率 = 98.18%（CooHOI 92.01%，InterPhys 94.30%）
- 最大负载范围 = [4, 40] kg（CooHOI [5,15] kg，CooHOI 加质量标签 [4,28] kg）
- 推拉任务成功率 = 94.38%（CooHOI 42.54%）
- 姿态多样性 APD = 0.41（Oracle 0.07，RMA 0.18），MOS = 4.2（Oracle 3.3）
- 有障碍场景成功率 = 81.64%（仅 InterCtrl 69.53%），绕行成功率 99.51%（无课程学习 31.31%）

## 创新点与贡献
- 把「对未知物理属性的试探性适应过程」本身当作可提取的表达性动画来源，并用测试时潜变量调优实现无需更新网络参数、无需策略梯度的实时自适应

## 局限与风险
- 未建模灵巧手行为，缺少全局导航与拓扑规划
- 只在规范的大物体搬运/推拉任务上验证，更广场景仍需评估
