# MMotion：面向文本驱动动作生成的跨尺度协同记忆

## 一句话结论
把生成过程按尺度与尺度内位置索引，为每个尺度单独建语义 / 动作双记忆库，使跨样本模式可复用且与已生成历史一致——HumanML3D+MotionHiFlow R@1 0.572（0.563）、FID 0.025（0.032）；KIT-ML 上 R@1 明显提升但配 MoScale 时 FID 反而退化（0.455 vs 0.173），说明记忆收益对解码器敏感。

## 要解决的问题
文本到动作生成要么靠示例检索（ReMoDiffuse、MoRAG），要么靠长上下文（InfiniMotion），很少同时回答「生成什么动作、该怎么演化、如何与已生成历史一致」。多数方法只用文本条件与当前样本的瞬态隐状态，既无法复用跨样本的动作模式，也没有对已生成内容的结构化记录，于是容易漏掉动作细节、产生不自然过渡或逐渐偏离语义。以 MoScale（S=18）为基线，HumanML3D 上 R@1 0.540、FID 0.046、MM-Dist 2.830；MotionHiFlow 为 0.563 / 0.032 / 2.691，提升空间集中在语义对齐与分布保真度。

## 方法详解
把生成过程按尺度 $s$ 与尺度内相对位置 $p_{s,n}$ 索引：next-scale 自回归用原生由粗到细层级，扩散则把 $N$ 步反向去噪按时间切成三段（$s\in\{0.3,0.6,1.0\}$）。语义记忆为每个尺度单独建库 $\mathcal{B}_s^{\text{sem}}=\{(\mathbf{k}_{s,i}^{\text{sem}},\mathbf{v}_{s,i}^{\text{sem}})\}$，查询 $\mathbf{q}_{s,n}^{\text{sem}}=\mathcal{Q}_{\text{sem}}(\mathbf{e},s,p_{s,n})$，取 top-$K$ 后按 $w_{s,n,i}^{\text{sem}}=\text{softmax}(\cos(\mathbf{q},\mathbf{k})/\tau)$ 加权求和得 $\mathbf{m}_{s,n}^{\text{sem}}$，实现「粗尺度给整体动作、细尺度给局部细节」。动力学记忆用因果可得的隐状态差分 $\mathbf{v}_{s,n}=\mathbf{z}_{s,n}-\mathbf{z}_{s,n-1}$、$\mathbf{a}_{s,n}=\mathbf{v}_{s,n}-\mathbf{v}_{s,n-1}$（作者强调这只是隐空间变化、不是物理速度/加速度），由预测器 $\mathcal{D}$ 输出当前动力学 $\mathbf{d}$、下一步变化 $\hat{\mathbf{v}},\hat{\mathbf{a}}$ 与置信度 $c$，再以语义特征为条件检索转移模式，避免选到「平滑但不符合动作」的转移，最后用 GRU 沿尺度传播 $\mathbf{u}_{s,n}^{\text{dyn}}=\text{GRU}(\mathbf{q}_{s,n}^{\text{dyn}},\mathbf{u}_{s^{-},n}^{\text{dyn}})$。工作记忆为样本内缓冲 $\mathcal{C}_{s,n}=\{\mathbf{o},\mathbf{h},\mathbf{z}\}_{\prec(s,n)}$，经 reader 压缩后用门控 $\mathbf{g}=\sigma(\mathcal{F}_{\text{work}}(\mathbf{h},\mathbf{m}^{\text{sem}},\mathbf{u}^{\text{dyn}},\mathbf{m}^{\text{work}}))$ 调节。三路融合后经残差头给有界修正：$\Delta\hat{\mathbf{h}}=\rho\tanh(W_o\mathbf{j})$，$\Delta\mathbf{h}=\Delta\hat{\mathbf{h}}\min(1,\tau_{\max}\|\mathbf{h}\|_2/\|\Delta\hat{\mathbf{h}}\|_2)$，$\tau_{\max}=0.05$ 即最多改动隐状态范数的 5%。训练加信任域蒸馏 $\mathcal{L}_{\text{trust}}=\max(0,D_{\mathrm{KL}}(\pi_{\text{base}}^T\|\pi_{\text{mem}}^T)-\epsilon)$（$T=2$），总目标为原生生成损失加语义/动力学/工作/协同四项辅助损失。三阶段训练：A 冻结主干、关残差、各记忆单独学；B 逐步开启残差与教师监督；C 才开最后几层 LoRA（更小学习率）。检索 top-8、温度 0.06，主干冻结只训记忆模块 5 epoch。

## 实验与结果
- HumanML3D + MotionHiFlow：R@1 0.572（基线 0.563）、FID 0.025（0.032）、MM-Dist 2.675（2.691）、R@3 0.844（0.843）
- HumanML3D + MoScale（S=18）：R@1 0.554（0.540）、FID 0.044（0.046）、MM-Dist 2.794（2.830）、R@2 0.743（0.727）
- KIT-ML + MotionHiFlow：R@1 0.528（0.482）、MM-Dist 2.540（2.552）、FID 0.137（0.135，略差）
- KIT-ML + MoScale：R@1 0.467（0.442）、但 FID 0.455（0.173）、MM-Dist 2.760（2.717），Top-2/3 未提升
- 消融（HumanML3D/MoScale）：C0 全关 54.569 → C1 语义 55.043 → C2 语义+动力学 55.323 → 完整 55.409（R@1，%）
- 对应 FID：C0 0.04588 → 完整 0.04440；打乱语义关联后 R@1 55.065、FID 0.04986
- 检索数量：K=8 时 R@1 最高且 FID 最低（0.04440），K=2/4/16 分别为 0.04878/0.04822/0.04539

## 创新点与贡献
- 相对 ReMoDiffuse（只检索文本–动作示例）、MoRAG（部位感知的多源检索）、InfiniMotion（只保留长时上下文），MMotion 把语义、动力学、历史三种记忆放进同一生成过程，并让它们顺序条件化：语义决定「检索什么转移」，语义+动力学再决定「历史里哪段有用」
- 相对 MoScale/MotionHiFlow 的隐式前缀记忆，它是显式的、可插拔的，且用有界残差（≤5% 范数）加信任域蒸馏保证不改坏预训练先验，因此同一套模块能同时挂在离散自回归与连续 flow matching 上

## 局限与风险
- 作者自述：KIT-ML 上 MoScale 的 Top-2/3 与 MM-Dist 未一致提升，作者归因于离散多尺度解码中检索信息与早期 token 决策竞争
- 增益在部分指标上非单调
- 我们另看出：HumanML3D 上 R@1 仅 +1.6% 相对提升，主要卖点是 FID
- KIT-ML 上 MotionHiFlow 的 FID 反而从 0.135 升到 0.137，MoScale 的 FID 从 0.173 恶化到 0.455，说明记忆注入对分布保真度并非稳定正收益
- 每步都要做三路检索与 GRU 传播，推理开销未报告
- 只在两个数据集、两个主干上验证，无代码
