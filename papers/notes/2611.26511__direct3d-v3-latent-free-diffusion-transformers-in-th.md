# Direct3D-V3：原生体素域中的无潜变量扩散 Transformer

## 一句话结论
丢掉 VAE，在原生 SDF 体素上直接做扩散 Transformer：GSO 单视图 CD 0.0131（TRELLIS2 0.0147），但语义对齐指标仅与 SOTA 打平。

## 要解决的问题
原生 3D 生成几乎被潜空间扩散垄断：先用 VAE 把几何压进隐空间，再在隐空间里做扩散；近年进展集中在更强的 VAE 与更精巧的潜表示（vecset、triplane、结构化稀疏体素、O-Voxel）。这些设计架构各异却共享同一前提——几何必须先被压缩。作者指出该前提带来两个内在缺陷：其一，VAE 重建构成信息瓶颈，编码阶段丢掉的细节下游扩散模型无论如何也恢复不了（头发、胡须、绳结、胎纹这类高频结构最先被抹平）；其二，两阶段管线存在目标错配，VAE 为重建而训练、扩散为匹配潜分布而训练，生成器同时被表示保真度与两套独立目标之间的间隙所约束。作者据此判断：继续打磨潜设计无法消除这两个缺陷。而直接改在原生 SDF 体素上做扩散又会引出新的失效：(a) 稠密 SDF 体积随分辨率立方增长，1536³ 下注意力序列长度不可承受；(b) 失去 VAE 解码器隐含的流形先验后，SDF 值的微小局部扰动会让 Marching Cubes 抽出带开放边界的非水密表面——潜式方法的解码器因学过网格流形结构而在无形中抑制了这类伪影；(c) 常用的 Eikonal 正则要求任意空间点梯度 2-范数为 1，与本文「直接由 GT TSDF 值监督」的设定冲突，会造成优化不稳甚至训练崩溃；(d) Hi3DGen 已尝试用渲染法线监督，但其法线渲染必须先过 VAE 解码，显存开销使其止步 256³。于是问题变成：能否在原生体素域里既保住可扩展性，又保住几何合法性。

## 方法详解
表示为均匀 SDF 体素网格 X∈R^{R×R×R×1}，截断阈值 1/64，刻意用最小表示以证不依赖精巧潜设计。扩散用 flow matching：x_t=t·x_0+(1−t)·ε、v_t=x_0−ε；沿用 x_0 预测，f_θ(x_t,t,c)→x̂_0，v̂_t=(x̂_0−x_t)/(1−t)，L_fm=E‖v̂_t−v_t‖²。稀疏化：切 p³ patch（p=8），先由 vecset DiT 出粗网格得占据表面 patch 集 S，第二阶段只在 S 上扩散。双粒度 DiT：patch 级（17 block、hidden 1536、16 头）用 AdaLN 注入时间步、cross-attention 注入 DINOv2-Large（1022）图像 token，self-attention 建模 patch 关系，输出 s_p；体素级（2 block、D_v=8）把 s_p 映射为逐体素 token 的 AdaLN 参数，并在 patch 内先聚合、再自注意力、再展开，避免对 L·p³ 个 token 直接注意；自注意力全部为 3D shifted-window。三项几何信号：①隐式流形正则 L_imr=(1/|N|)Σ[|X̂_i−X̂_j|−η]_+²，只惩相邻体素 SDF 差超过一个体素长度 η 的情形，属离散 Lipschitz，替代与 GT TSDF 监督冲突的 Eikonal；②x̂_0 经可微稀疏 Marching Cubes 得 M̂，Nvdiffrast 渲法线，L_geo=‖N̂_π−N^gt_π‖_1，无需 VAE 解码故可上高分辨率；③相机分支用物体中心参数 κ=(sinθ,cosθ,φ,log d,log tan fov,c_x,c_y)，相机 token 先 attent s_p 再 attent 图像 token，MLP 回归 L_cam=‖κ̂−κ^gt‖_1。总损失 L=L_fm+λ_imr L_imr+λ_geo L_geo+λ_cam L_cam，λ 取 1e−5/1.0/5e−2。训练：320K Objaverse-XL（可加 200K 私有 mesh），每 mesh 渲 16 张 RGB 与 16 张法线；16×A800、AdamW、bf16、FSDP2，渐进 256³(400K 步)→512³(50K)→1024³(50K)→1536³(10K)，采样 15 步、CFG 4.0。重建：Lotus-2 估输入法线，t<0.8 时先以 mask 标定相机（50 步，只改相机），再走 100 步 L_rec=‖M_I⊙(R_n(MC(x),κ*)−N_I)‖_1，随后按同调度重加噪送回采样器。

## 实验与结果
- 102 张真实照片/网络图/AI 生成图：Uni3D 0.4198、ULIP-2 0.4535，全部优于 TRELLIS2（0.4172/0.4405）、Direct3D-S2（0.4190/0.4485）、UltraShape（0.4185/0.4510）、Hunyuan3D 2.1（0.4187/0.4424）与 Michelangelo（0.3404/0.3605）
- 加约 200K 私有 mesh 后升至 0.4224/0.4547
- GSO 单视图生成式重建：CD 0.0131（TRELLIS2 0.0147、CUPID 0.0141、ReconViaGen 0.0194），F1@0.99 0.6043（TRELLIS2 0.5934），F1@0.95 0.9600，Vol. IoU 0.3815 略低于 TRELLIS2 的 0.3884
- 核心组件消融（Normal-FID，越低越好）：仅 patch DiT 92.96 → 加体素 DiT 75.80 → 加 IMR 73.24 → 再加法线渲染监督 68.97
- 水密性：平均边界边数在 256³ 由 2462 降到 196（−92%），在 1024³ 由 25353 降到 898（−96.5%），剩余小孔可用常规补洞闭合
- patch 尺寸权衡：p=4 得 57.63、p=8 得 68.97、p=12 得 76.21
- 取 p=8 作为保真度与显存/注意力的折中
- 第一阶段 patch 索引来源鲁棒性（512³）：自训 VecSet DiT 76.62，优于 dense latent-free DiT 的 80.61 与 Hunyuan3D 2.1 的 80.43
- 规模与配置：1536³ 原生 SDF 扩散、320K 训练 mesh、16×A800、渐进四阶段（400K/50K/50K/10K 步）、推理 15 步 flow matching + CFG 4.0，用户研究（1–5 分）中获最高偏好

## 创新点与贡献
- 彻底去掉 VAE，在原生 SDF 体素域直接训练与采样，把生成器放到几何最终被评估的同一信号空间，从原理上消除重建瓶颈与两阶段目标错配。
- 双粒度 DiT 把「全局语义」与「patch 内高频 SDF 变化」解耦，并用 patch 特征逐 block 生成体素级 AdaLN 参数，使 1536³ 原生扩散在纯 transformer 下可行（无需稀疏 3D 卷积专用设施）。
- 提出隐式流形正则：以离散 Lipschitz 约束（相邻体素差超过 η 才罚）替代 Eikonal，既补回 VAE 解码器隐含的流形先验，又避免与 GT TSDF 监督冲突导致的训练崩溃。
- 把法线渲染监督从「需 VAE 解码」变为「Marching Cubes 直出」，使原生几何监督在高分辨率（1536³）下显存可行，突破 Hi3DGen 的 256³ 上限。
- 原生 SDF 输出 + 相机分支共同构成生成式重建接口：可在采样轨迹内做 mask 标定相机、法线梯度直接改零水平集，无需反复解码潜变量。

## 局限与风险
- 作者自述两点：其一，生成式重建依赖准确的第一阶段表面 patch 索引，一旦该稀疏支撑漏掉图像可见结构或落到不一致区域，测试时法线引导会过度更新 SDF、把薄结构或歧义轮廓改歪（Fig.13 给出该失败案例）
- 其二，当前只做几何，未联合建模纹理/材质/PBR——虽然原理上可给体素网格加通道，但原生空间里联合建模的稳定性与表面-材质一致性仍需额外设计
- 从实验设计看：主表用 Uni3D/ULIP-2 属语义对齐指标，作者自己也承认它们无法衡量表面规整性、薄结构与局部细节，而恰恰是本文主张的强项，于是核心卖点只能靠用户研究与定性图支撑，量化证据链偏弱
- Normal-FID 只在 256³ 的留出集上做消融，与 1536³ 的最终系统存在分辨率错配
- 增益幅度很小（Uni3D +0.0008~+0.0026、CD 相对 TRELLIS2 仅 −10.9%），且 Vol. IoU 还略输
- 训练用了约 200K 私有 mesh 的版本参与对比，与全开源基线不完全同条件
- GSO 被作者自己指出「扫描物体较简单」，重建结论的外推性有限
- 此外未报告推理时延与显存，难以判断 1536³ 的实用代价
