# GUSH3R：单目视频前馈式动态人体–场景高斯重建

## 一句话结论
GUSH3R 以 Human3R 的点云、SMPL-X 与 token 为先验，加场景与人体两个高斯解码器，在单目视频上以 0.54 s/帧流式前向输出统一 3DGS 表示；MultiEgo 新视角视频 PSNR 14.2（DA3 13.9、StreamSplat 13.2）、warping error 0.0015 最低、8 帧 5.50 s；NeuMan 18.2 dB 低于优化式 HSR 的 20.6，但 EMDB 18.0 高于 16.2，BEDLAM 多人全图 17.0 优于 AnySplat 15.9。

## 要解决的问题
单目人体–场景重建要同时解场景几何、相机运动与非刚性人体，还要能照片级渲染。优化式方法（NeRF/3DGS 系，HSR、Vid2Avatar）质量高但需 per-scene 优化，无法快速或交互式重建；多视角动态方法要求同步多机位。前馈方法（VGGT、MASt3R-SfM、CUT3R、AnySplat、Depth Anything 3）能一次前向出几何，但输出多为点云/网格，不可直接渲染，或对非刚性人体失效；Human3R、UniSH 虽能一次前向给出场景点云 + SMPL-X 人体，输出却是异质表示，需额外外观建模或表示转换才能渲染。作者据此把「统一、可渲染、流式、免 pose 输入」作为缺口：现有前馈工作没有同时满足 streaming、dynamic humans、photo-reality 三项（Table 1）。

## 方法详解
把场景分为跨时间累积的静态高斯 G_t^s 与逐帧的 K 个人体高斯 {G_{t,k}^h}，二者在 Human3R 的同一度量坐标系内直接预测。Human3R 逐帧输出相机位姿 T_t、点图 X_t、SMPL-X 顶点 V_{t,k}与循环状态 [F'_t,z'_t,H'_t]=Decoder([F_t,z_t,H_t],S_{t-1})。场景解码器以点图作高斯中心 μ_{t,i}，用 DPT 式解码器把 F'_t 解为逐像素特征 C^D，与 7×7 卷积的图像特征 C^I 相加，经卷积头 F_G 预测 (α,q,s,c)；新帧先按点置信度与膨胀人体掩码过滤，再按固定体素 Voxelize(G_{t-1}^s,G̃_t^s)，每体素按置信度取舍与加权。人体解码器以 SMPL-X 顶点为锚，定义人体 h、A-pose 规范顶点 V̂、图像 F'、记忆 m 四类 token；HGT 对 h/m/V̂ 自注意力、对 F' 交叉注意力，[m',V̂']=HGT(Q=[h,m,V̂],K=V=F')；顶点特征经 MLP F_H 预测 (α,q,s,c)，在规范空间定义后用 LBS 变换到当前姿态。记忆 m_{t+1}=(1−λ)m_t+λm'_t。冻结 Human3R、分别训练两解码器：L_scene 含 mse、lpips、depth 与尺度比正则（比值>3 受罚）；L_human 含 mse、全图与半身/面部 crop 的 LPIPS、silhouette 与同样的 reg。数据：场景 BEDLAM+DL3DV、人体 BEDLAM+MVHumanNet，每样本 4 帧等间隔。

## 实验与结果
- 单人体（Table 2）：NeuMan 上 Ours 18.2 / 0.57 / 0.29、HSR 20.6 / 0.58 / 0.58（>1 h）、AnySplat 15.2 / 0.33 / 0.42（0.47 s）、AnySplat+LHM+Human3R 13.9 / 0.32 / 0.46（5.5 s）；EMDB 上 Ours 18.0 / 0.57 / 0.40、HSR 16.2 / 0.68 / 0.51；重建时间 0.54 s/帧。
- 多人场景（BEDLAM，Table 3）：全图 Ours 17.0 / 0.53 / 0.34 优于 AnySplat 15.9 / 0.43 / 0.42；背景区 17.5 / 0.59 / 0.30；人体区 14.2 / 0.88 / 0.11，低于 AnySplat+LHM+Human3R 的 14.7 / 0.88 / 0.11。
- 新视角视频（MultiEgo，Table 4）：Ours 14.2 / 0.70 / 0.38、warp error 0.0015、8 帧 5.50 s；DA3 13.9 / 0.68 / 0.45、2.26 s；StreamSplat 13.2 / 0.49 / 0.52、0.0099、5.91 s；MoVieS 12.9（需 pose，2.02 s）；Shape of Motion 12.2（274.3 s）。
- 组件消融（NeuMan，Table 5）：场景去深度损失 19.7→19.3（4-view），去 DL3DV 仅 19.7→19.5；人体去交叉注意力 12.6→11.0（4-view）、13.7→12.4（8-view），去记忆 token 12.6→12.5，去 MVHumanNet 12.6→12.4。
- 长序列（附录 B.3，500 帧）：体素 0.01 m 时累计 16.20M 高斯、234 帧即 OOM；0.03 m 与 0.05 m 可跑完 500 帧，峰值 15.26M / 12.23M，额外显存 3.31 GB / 1.30 GB。
- 运行时（附录 B.4，NeuMan 8 帧均值）：总 540.27 ms/帧，其中 Human3R 推理 264.82 ms（49.0%）、场景解码 73.05 ms（13.5%）、人体解码 39.47 ms（7.3%）、更新与 I/O 162.93 ms（30.2%）。

## 创新点与贡献
- 首个从单目视频前馈、流式输出「照片级可渲染」动态人体–场景统一 3DGS 表示的方法，把 streaming / dynamic humans / photo-reality 三项同时满足。
- 不做「先分别重建再对齐」，而是共用 Human3R 的度量坐标系与 token，从结构上消除分解式管线的拼缝伪影。
- 人体侧以 SMPL-X 顶点为锚、在 A-pose 规范空间预测高斯再用 LBS 驱动，并用记忆 token 维持跨帧外观一致（λ=0.5 指数滑动）。
- 场景侧用体素化 + 置信度加权聚合实现常数级背景增长，使 500 帧长序列仍可在单卡运行（0.05 m 体素仅增 1.30 GB）。

## 局限与风险
- （作者承认）依赖 Human3R 的相机、点图、人体检测与 SMPL-X 拟合，上游误差会传播到最终重建。
- （作者承认）严重人–人遮挡与复杂交互仍困难，单目下身份关联与完整人体几何线索不足。
- （作者承认）面部、手部、衣物在运动模糊/大幅度姿态变化/观测不足时仍有可见伪影；每顶点一个高斯限制头发与宽松衣物的细节。
- （我在正文发现）NeuMan 上 PSNR 18.2 低于优化式 HSR 的 20.6，背景区在 NeuMan 也不及 AnySplat（Table 7），绝对渲染质量仍偏弱。
- （我在正文发现）评测时目标帧 SMPL-X 由对整段序列（含目标帧 RGB）的额外 Human3R pass 估计，虽声明不用于外观，仍引入「用未来帧估姿态」的乐观假设。
- （我在正文发现）人体高斯随帧累积不合并，500 帧即达 12–16M 高斯、1.3–3.3 GB 额外显存，长视频可扩展性受限于此。

## 与文献库的关系
本文直接构建在 Human3R（Chen et al., 2026，ICLR）之上：沿用其循环状态、点图、SMPL-X 与 image/human token，只新增两个高斯解码器，与 Human3R、UniSH 构成「几何先验 → 可渲染表示」的接力。静态前馈侧对标 VGGT、MASt3R-SfM、CUT3R、AnySplat、StreamSplat、Depth Anything 3；动态侧与优化式 Shape of Motion、前馈 MoVieS、4DGT、StreamSplat 比较；人体侧用 LHM 做分解式基线、HSR 做优化式基线，并以 SMPL-X、BEDLAM、MVHumanNet 为表示与数据基础。相较 AnySplat+LHM 的「分别重建后组合」，本文主张共享坐标系联合预测可同时改善质量与速度。本篇为旧稿 v2 再公告（v1 未入馆），按首次入馆处理。
