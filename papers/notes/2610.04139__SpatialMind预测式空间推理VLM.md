# SpatialMind：从观察到预见——视觉语言模型的预测式空间推理

## 一句话结论

博世提出 SpatialMind，一个度量尺度 VLM，把空间推理从"描述已观察到的场景"推进到"预测未观测到的未来空间状态"。其度量深度适配器把推理锚定到真实世界尺度，渐进式状态链以当前空间状态与已观测动态为底座支撑未来预测；给定视频前缀，预测已观测与未见未来帧中的距离、运动方向、空间关系。配套可扩展数据引擎生成 SpatialMind-30K 数据集与 SpatialMind-2K 基准（驾驶 + 日常第一视角，8 任务 3 层级），在基准上大幅超越通用与空间专用模型，并在 VSI-Bench/OSI-Bench/VLM4D 上零样本具竞争力。

## 要解决的问题

预测未来空间状态支撑动态环境中的碰撞规避与及时决策。但现有 VLM 与空间推理基准主要聚焦"已观测场景"，对"超出观测区间的预测式空间推理"探索不足——即给定视频前缀，推断物体未来的距离、运动方向、空间关系变化。

## 方法详解

(1) Metric depth adapter：把空间推理锚定到真实世界尺度（而非相对/像素尺度）。(2) Progressive state chain（渐进式状态链）：先建立当前空间状态与已观测动态，作为未来预测的基础。(3) 给定视频前缀，预测已观测帧与未见未来帧中的距离、运动方向、空间关系。数据引擎：可扩展引擎把实体描述 grounding 到度量几何，生成 QA 对与状态监督，构建 SpatialMind-30K（训练）与 SpatialMind-2K（基准，8 任务 × 3 层级：当前状态理解 / 已观测动态理解 / 未来预测）。

## 实验与结果

在自有 8 任务 3 层级基准上，SpatialMind 大幅超越通用 VLM 与空间专用模型；并在 VSI-Bench、OSI-Bench、VLM4D 上取得有竞争力的零样本表现。项目页与代码已公开。

## 创新点与贡献

1. 把"预测式空间推理"正式立项，区分于纯观测描述，给出度量尺度的可预测框架。
2. Metric depth adapter + progressive state chain 的组合，让预测"grounded in 当前几何与已观测动态"，比专有 VLM 估计更准。
3. 可扩展数据引擎 + 30K/2K 数据集/基准，覆盖驾驶与日常第一视角，填补未来预测评测空白。

## 局限与风险

基准偏驾驶与第一视角日常场景，未见复杂多智能体/室内长程交互；"未来预测"仅在短时程内验证，长程外推误差未量化；依赖度量深度估计质量；零样本仅与少数基准对比，广度有限。

## 与文献库的关系

库内空间计算与UI赛道有 GeoScaffold（2610.02697，重建学习几何潜做 VLN）、Ego2World（2610.02715，第一视角视频编译为可执行世界）、工具增强度量空间推理（2609.29073）等。SpatialMind 补上"预测式/前瞻式"空间推理一环，与 GeoScaffold（几何潜）、Ego2World（可执行世界）可构成"感知几何 → 预测未来 → 规划动作"的链。与 EMBER-Bench（当日 #16，长程具身因果记忆）互补：一个管"未来空间状态预测"，一个管"历史事件如何约束未来动作"。
