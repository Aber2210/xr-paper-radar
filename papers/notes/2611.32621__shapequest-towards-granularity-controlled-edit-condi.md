# ShapeQuest：面向粒度可控的编辑条件 3D 资产检索

## 一句话结论
首次把「编辑条件检索」从图像搬到单体 3D 资产，给出「答案 = 参考 + 精确部件改动」的严格定义、五级表面面积粒度与多真值协议，并用仅训练期存在的重建解码器 + 部件 mask 把「改哪里/保哪里」注入池化向量：operation-macro mAP@10 50.4 vs 同输入 fusion 基线 47.2。

## 要解决的问题
给定一个参考资产与「去掉一个扶手」这类编辑指令，检索器需要找出做了该编辑且保留其余部件的变体；这在图像上已是成熟的 composed image retrieval，但在单个 3D 资产上几乎空白。现有 3D 编辑工作只生成一个新形状并与单一参考比对，3D 检索工作则只用文本描述目标或检索房间中的某个物体，都不要求「答案 = 参考 + 指定部件改动」，也不处理同一资产存在多个竞争性编辑的 gallery。缺少基准使这类能力无法被度量。

## 方法详解
以 PartNeXt 的部件标注纹理网格为基础，构建 87,824 条 query（75,771 单真值 / 12,053 多真值）、50 个类别、50,919 个 gallery 形状（含 40,896 个 target 与 10,023 个同物体干扰项，平均每 query 5.36 个干扰）。流水线七阶段：先做部件面积普查并按面积占比把部件分成 extra fine / fine / medium / coarse / extra coarse 五级；再由 LLM 读部件层级提出 5 条跨粒度编辑并撰写指令（remove / material，材质限定 wood/metal/plastic/leather/glass 并附颜色候选）；随后用确定性 Python 脚本改 glTF 副本实例化目标（删除面或改材质），保证只有被点名部件改变；再用 mask-aware 视角选择，在 17 个候选位姿中挑被编辑区域可见像素最多者渲染配对图像；由 InternVL3-78B 作为 VLM 评委判定「可见变化是否匹配指令」，并用 5 名人工对同一批 500 条盲评校验；多真值由同名对称部件挖掘（如四条腿的桌子「改一条腿为金色金属」产生 4 个正确目标）；最后把一半 remove 反转为 add 以引入 addition 操作并平衡材质/移除数量。模型 ShapeQuester 以 PointBERT 编码源点云，保留全局特征 f_s 与 patch token Z 及每个 patch 中心 C；用 CLIP 文本编码指令，经单层线性映射产生 FiLM 的 γ、β，对 patch token 做 z̃_j = z̄_j ⊙ (1+tanh γ) + β，其中 z̄_j = LayerNorm(z_j) + MLP(c_j)；再加 CLS token x_0 = W_s f_s + W_q e_q 与可选视角 token，经 Transformer 自注意力得到 h_0，检索头输出 r = norm(W_r h_0)，与 gallery 的 norm(f) 做余弦排序。训练时用 multi-positive 对比损失（按每个 query 的有效目标数做 K_i^{-1} 加权），并用仅在训练期存在的解码器从 composed token 重建编辑后点云，损失 L_recon = L_global + λ_a L_add + λ_k L_keep + λ_m L_material，其中 L_global 为 XYZ 与 RGB 的对称 Chamfer，三个 mask 项分别监督新增部件、应保留部件与被换色部件；推理时丢弃解码器。

## 实验与结果
- benchmark 规模：87,824 query / 50 类 / 50,919 gallery 形状 / 126,417 网格，五级粒度、12,053 条多真值 query
- test split 上 operation-macro mAP@10 达 50.4，同输入 fusion 基线 47.2，最强基线 48.6；相对只读指令+点云的 fusion 提升 +3.97（预训练编码器）与 +1.67（从零训练 + nearest 分组）
- 从零训练 PointBERT 时，重建辅助带来 +6.5 点，其中全局 Chamfer 贡献 +3.14、三个 part mask 项再贡献 +3.33；λ_recon 降为 0.1 时增益从 +6.47 缩到 +1.47
- 去掉重建损失后 patch token 反而比只用全局特征低 5.45 点（40.42 vs 45.87），说明局部 token 需要 mask 监督才可用
- 可训练参数 10.2M（从零）/ 42.5M（预训练），均低于 combiner-I 的 111.0M，且不依赖渲染视角仍领先
- 数据质量：三个 VLM 评委在 67% 的三元组上一致，选定评委接受 71.9%，5 名人工对其中 95.5% 表示认可且各级粒度均 >90%

## 创新点与贡献
- 首次把「编辑条件检索」从图像搬到单体 3D 资产，并给出「答案 = 参考 + 精确部件改动」的严格定义、五级表面面积粒度与多真值协议，使检索器必须同时区分源形状与其他竞争性编辑
- ShapeQuester 用仅在训练期存在的重建解码器 + 部件 mask 把「改哪里/保哪里」注入池化向量，在不增加推理成本的前提下超过参数量 10 倍的 combiner 基线

## 局限与风险
- 编辑仅限删除、添加与给部件换五种常量材质，不含几何变形、纹理贴图或更细的材质渐变
- gallery 与 query 同源，OpenShape 预训练数据与 PartNeXt 来源重叠，存在潜在泄漏
- 几何类编辑（add/remove）在所有模型上得分远低于材质编辑，说明方法对形状级改动仍弱
- affordance 与真实设计工作流（如可制造性、装配约束）尚未涉及
