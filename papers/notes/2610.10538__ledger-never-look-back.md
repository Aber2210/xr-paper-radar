# Ledger / Never Look Back：第一视角视频的 3D 物体记忆持久性

## 一句话总结
提出 Ledger——一种持久 3D 物体记忆（几何 + 上下文描述 + 事件记录），从第一视角视频离线构建，使具身助手能回答"当下无法预见、未来才可能用到"的空间问题，且精度不随记录时长下降。

## 问题背景
- 人在日常活动中会遇到"稍后才相关"的物体（如"之前把东西放哪了""容器里是什么"），具身助手需从第一视角视频构建类似记忆。
- 关键问题：为回答未来不可预见的空间问题，应保留哪些证据？区分"表示失败"与"检索/推理失败"。

## 方法
- **Ledger（Long-horizon Egocentric Descriptions, Geometry, and Event Records）**：结合几何观测与上下文描述的持久 3D 物体记忆。
- **离线构建**：从采样的第一视角记录构建（用提供或估计的相机位姿）；开放词汇目标检测；关联与整合；持久化 + 上下文描述；多视图精炼。
- **查询时推理**：回答空间问题——物体位置、内容、运动历史、路径与场所、场景变化。
- 与 ConceptGraphs / 3D-Mem / ReMEmbR / EgoRAG / VL-KnG 等对比，Ledger 在"处理/未处理物体、运动历史、路径场所、RGB、场景变化"等维度全 ✓。

## 实验与结果（关键数字）
- 基准：HD-EPIC、UCS-Bench（206 段记录，3264 问题）、VQ3D（164 查询）。
- UCS-Bench 准确率：Ledger single-shot 39.0% / agent 42.1%；对比 ReMEmbR 41.4%、DirectMe 41.4%、48-frame reader 33.1%、blind 30.1%。
- VQ3D（1m 内定位占比）：Ledger 47.6% / agent 49.4%；基线显著更低。
- **关键发现**：结构化记忆精度不随记录长度下降；而 48-frame reader 每翻倍长度精度下降（EPIC-Kitchens 内 p=0.05）。失败分析：最大损失在 answerer 读记录之前（表示/检索阶段）——给 GT 轨迹 +12 分、命名所依 fixtures +25 分，固定规则仅 +3 分。

## 贡献与局限
- 贡献：系统界定"物体记忆该保留什么"；提出全维度覆盖的 Ledger；用长度扫描实验证明结构化记忆优于帧读取。
- 局限：构建依赖检测/位姿质量；跨天持久性有限（R4DSG 类似）；失败多在检索/表示而非推理。
