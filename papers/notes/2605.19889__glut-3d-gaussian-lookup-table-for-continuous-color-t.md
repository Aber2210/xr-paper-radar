# GLUT：用于连续色彩变换的三维高斯查找表

## 一句话结论
把 3DGS 的显式局部基元范式搬到色彩空间：Hald 图 PSNR 45.47 dB（NILUT 38.84 dB）而参数只有 716（1/47），并保留局部可编辑性。

## 要解决的问题
3D LUT 的规则网格把 RGB 空间离散化，表示容量与显存强耦合，存大量 LUT 时不可行；隐式神经表示虽可扩展，但黑盒、不可解释、难以做局部色彩编辑。

## 方法详解
用一组可学习三维高斯基元在 RGB 空间做软自适应划分，每个基元带局部仿射变换，从而把色彩映射写成连续显式函数。在此之上提出 Conditional GLUT，用一个紧凑生成器预测多个 LUT 的参数以支持风格平滑混合。利用基元的空间局部性，只优化相关子集即可完成定向色彩编辑而无需重训。

## 实验与结果
- GLUT-32 Hald PSNR = 45.47 dB（NILUT 128×2 为 38.84 dB）
- GLUT-32 参数量 = 716（NILUT 128×2 为 33,923）
- GLUT-32 自然图像 PSNR = 45.92 dB（NILUT 128×2 为 40.84 dB）
- GLUT-64 存储 = 9.7 kB（32³ LUT 800 kB，64³ 7.1 MB）
- GLUT-32 计算量 = 0.49 GFLOPs（NILUT 128×2 为 17.78）

## 创新点与贡献
- 把 3DGS 的显式局部基元范式搬到色彩空间，用「高斯权重 + 局部仿射」同时取得紧凑性、可解释性与可局部编辑

## 局限与风险
