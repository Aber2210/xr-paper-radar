# 在像素、世界空间与场景中快速而准确的人体估计

## 一句话结论
直接回归骨架关节与稠密表面点的人体估计器：39.2 fps（SAM 3D Body 8.5 fps）且 3DPW PA-MPJPE 32.7 mm 更优，并新增接触与场景任务。

## 要解决的问题
单目人体姿态与形状估计是动作捕捉、数字人与机器人从视频学习的基础，但现有系统把任务拆成假设互不一致的多段流水线：SAM 3D Body 这类最强逐帧模型用 840M 参数编码器，单人不到 10 fps（即使免训练加速也只有 8.5 fps）；视频与世界坐标方法（WHAM、TRAM、GVHMR）建立在更弱的逐帧估计器上；real2sim 流水线（VideoMimic）把场景与人体分开重建。各段输出彼此拉扯：从参数化网格回归的关键点投影后常与观测到的 2D 关节不一致；大量 3D 监督是继承拟合先验的伪真值，误差被固化。相机空间人体深度与里程计组合还存在尺度不匹配，人体与场景之间用固定比例因子时脚会悬空或陷入地面。接触从未被当作一等输出，人-场景对齐只能靠启发式。机器人真正需要的是度量、重力对齐世界中的运动，而不是贴合图像的网格。论文用 EMDB 的 P3_30 滑板序列说明失效：该序列脚仅 4% 的帧世界固定，静态接触规则却把 80% 的帧判为静止接触。

## 方法详解
FAB 以稠密人体点为中枢输出，把 SAM 3D Body 蒸馏成实时学生。FAB-H 保留其架构，冻结骨干除最后 8 个 block 外的部分，用 BEDLAM（875K 裁剪）、3DPW-train、MOYO、RICH 的 SMPL 做轻量微调，另加稠密点 head。FAB-L 把骨干换成 DINOv3 ViT-L/16，投影到 1280 维嵌入，损失含 token 级特征蒸馏、对 FAB-H 的输出蒸馏与人工标签；训练 40K 步、512×512 裁剪、batch 8、骨干 5e-5、解码器 2e-5、余弦衰减、EMA 0.9998。稠密点 head 在图像 token 上出每点热图，4 倍上采样后与 stride-4 像素 stem 融合；每个点由 pose token 加可学习嵌入查询，soft-argmax 得 2D，热图下特征经 MLP 得深度，再沿相机射线反投影并用闭式 root 平移落位；监督分 70 个图像定义关键点、14 个评估关节与 468 个 SMPL 表面点，2D 与 3D 仅通过重投影耦合。一次性学习拟合先 Kabsch 对齐，经两个学习精化阶段与两步鲁棒 Gauss–Newton，再闭式细化足部，单卡 1020 fps。接触 head 为 2 层 MLP，读 pose token、12 个关键点特征与相机平移，对跟、趾、手、膝预测 static 与 any 两类接触；视频端叠因果 GRU 出残差。世界阶段用一次 ViPE 加 UniDepth 得相机与度量深度，GeoCalib 得重力；场景由 MVS 与体素哈希融合，做自由空间与人体可见性雕刻，TSDF 出网格与高度场。联合人-场景优化只解一个全局对数尺度，鲁棒项为接触 SDF、穿透 hinge、可见处深度一致、root 加速度与脚滑。FAB-Retarget 用方向优先 IK 与 in-model G1 head，目标权重为方向 1、骨盆 1、位置 0.1、稠密点 1000、接触 50、地面 1000、自碰撞 1000、加速度 120，稠密点按柱坐标 (s, theta) 匹配 G1 表面锚点。

## 实验与结果
- 3DPW 相机空间 PA-MPJPE 为 32.7mm，优于 SAM 3D Body 的 33.7mm 与 Fast SAM 3D Body 的 34.1mm，同时端到端 39.2 fps 对 8.5 fps，论文称比 SAM 3D Body 的 body-only 路径快 4.6 倍
- RICH test 上 PA-MPJPE 27.8mm、MPJPE 45.5mm，对比 SAM 3D Body 31.3mm、NLF-L 28.1mm，是表中带计时的最优精度
- SSP-3D 体型 PVE-T-SC：FAB-H 经 MHR 网格转 SMPL 为 10.0mm，FAB-L 为 10.8mm，优于 NLF-L 的 10.9mm 与 SAM 3D Body 的 15.8mm
- 接触 F1：RICH 人体-场景接触 0.97，对 WHAM 0.91、GVHMR 0.90
- MOYO 压力垫 0.89，对 WHAM 0.66、GVHMR 0.61
- EMDB-2 静态接触 0.69 对 GVHMR 0.71
- EMDB-2 世界坐标：FAB-L 的 WA-MPJPE 57.1mm、W-MPJPE 147.2mm，对比 TRAM 93.3mm、328.3mm
- 联合人-场景优化把 RTE 降低约三分之一，改用真值相机运动可再降约五倍
- 自建 FAB-Hard 难例集低光 MPJPE 63.7mm 对 SAM 3D Body 78.9mm（降低约 19%），2D PCK@0.05 在四类难例上均不低于 76.6%
- Unitree G1 参考骨方向误差 11.8 度，对比 SOMA 15.5、GMR 14.7、UMR 18.2、OmniRetarget 21.7 度
- 25 段中仅 4 段跌倒，鞋底滑移 0.13 m/s 对基线 0.26 至 0.39 m/s
- 延迟：单人 39.2 fps、4 人 15.4 fps
- FAB-S 单人 63.8 fps
- FAB-H 逐帧 24.9 fps 且不满足 30 fps 实时

## 创新点与贡献
- 以稠密点作为像素、世界、场景与机器人重定向的共同表示，SMPL 与 G1 都从点云导出，而不是从参数化网格回归后再投影。
- 把跟、趾、手、膝的 static 与 any 两类接触做成一等输出，并用世界系因果 GRU 区分静止支撑与滑板等移动支撑。
- in-model G1 head 与运动级 FAB-Retarget 直接读稠密点，用构造式 G1 表面锚点替代 UMR 的学习对应。
- 联合人-场景优化让场景与相机的度量尺度由人体本身决定，而不是依赖里程计尺度。
- 工程上把 SAM 3D Body 的 eager MHR rig 改为按需求值并整体捕获为 CUDA graph，使解码路径从 10.5 fps 提升到 84 fps。

## 局限与风险
- 作者自述：为速度牺牲绝对精度，FAB-H 只在冻结 body 上训练稠密 head，最大端到端模型仍是 FAB-L
- 瑜伽、体操等挑战姿态会失败
- 重定向只在 MuJoCo 仿真验证，缺少真机实验
- 世界模块会漂移（SLOPER4D 长序列）、静态相机焦距估错会把人体与场景放到错误深度、单一全局尺度可能错误缩放场景
- 从实验设计看，RICH-191 用自检器时在 23 段视频丢失目标，说明检测器召回仍是瓶颈
- 多个基准的训练划分含测试主体（表中以剑号标注），跨数据集泛化被高估
- FAB-Hard 由作者自建，难例选择规则虽声明与误差无关，仍缺少第三方复核
- 接触 F1 在验证集上评估且与训练共享主体，绝对数值偏乐观
