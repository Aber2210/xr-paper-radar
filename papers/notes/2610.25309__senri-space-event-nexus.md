# SENRI：理解真实生活视频中的空间-事件关联

## 一句话结论
SENRI-Bench 用 10 段不间断自录第一视角视频（约 25.3 小时）构建 500 道人工多选题，覆盖 Event→Space / Space→Event 双向六类任务；最强直接感知模型 Gemini 3.7 Flash 仅 52.2%，最强智能体 VideoARM + Gemini 3.7 Flash 为 59.0%；SENRI-Agent 在不改存储记忆的前提下为四组配置带来 2.6-3.8 个百分点提升（如 WorldMM + Gemini 3.7 Flash 58.8%→62.6%）。

## 要解决的问题
人类记忆把事件与空间上下文绑定，AI 助手也应能记住并召回「事件-空间」关联；现有长视频理解基准罕有以该关联为中心、且基于真实不间断第一视角视频的评测，持久记忆方法在该关联上的失败模式也缺乏系统分析。

## 方法详解（含关键公式/架构，保留原文术语）
SENRI-Bench：10 段长时不间断自录 egocentric 视频（约 25.3 h）、500 道人工标注多选题、双向六类任务（Event→Space 从事件线索恢复空间知识；Space→Event 从区域与轨迹检索事件）。SENRI-Agent：构建于 WorldMM/MAGIC-Video 既有记忆与检索接口之上的控制器工作流，核心为 Target-Guided Visual Check（TGVC）——控制器用检索候选提出局部视觉核查任务交给并行 verifiers，并将报告整合进 working memory 辅助推理；配置为最多 5 轮推理 + 1 轮作答、working memory 保留 3 份报告、每报告 4 帧证据、每次验证最多 3 次核查。

## 实验与结果（表格化关键数字）
三类范式横评：直接感知（Gemini 3.1 Pro/3.5 Flash/3.7 Flash、GPT-5/5.5、Kimi K3、Cambrian-S-7B、InternVideo3-8B、VideoChat3-4B、Qwen3.5/3.6/3.8 系列等）、证据寻求（LongVideo-R1、ParaVT-8B、Video-o3、VideoARM）、持久记忆（M3-Agent、Light-Omni、EG-Agent、WorldMM、MAGIC-Video）；ES 方向子指标 L/NP/OC/RR，SE 方向 RER/TER。SENRI-Agent 在 4 组「记忆系统 × 推理模型」配置上全面增益：WorldMM+Gemini 3.7 Flash 58.8→62.6、MAGIC-Video+Gemini 3.7 Flash 58.6→61.8、WorldMM+Qwen3.8-27B 47.6→50.4、MAGIC-Video+Qwen3.8-27B 45.2→47.8（增益 2.6-3.8 pp，作者称 ES 与 SE 双向均改进）。消融（MAGIC-Video+Qwen3.8-27B，完整 47.8%）：去 Target Guidance 45.0%、去并行 verifiers 45.0%、去 working memory 44.0%。

## 创新点与贡献
① 提出并以基准实例化「空间-事件关联（space-event nexus）」这一长视频理解新任务视角；② 首个基于长时不间断自录 egocentric 视频的 500 题人工基准（双向六任务）；③ 指出现有持久记忆方法的代表性失败模式（如检索记忆的歧义性）；④ SENRI-Agent 的 TGVC + 并行验证 + working memory 即插即用地提升既有记忆系统，且不改动其存储。

## 局限与风险
规模有限（10 视频 / 500 题 / 25.3 h），覆盖面与多样性受限；增益幅度小（2.6-3.8 pp）；依赖既有记忆系统的检索接口；digest 结论部分被截断，完整局限论述待补；自录视频存在题材偏差，外推需谨慎。
