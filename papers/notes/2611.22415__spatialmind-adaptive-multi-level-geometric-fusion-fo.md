# SpatialMind：面向多模态大模型空间推理的自适应多层级几何融合

## 一句话结论
任务条件化的多层级几何门控注入 MLLM，VSI-Bench 5B 71.5 / 10B 72.3，均居同规模第一。

## 要解决的问题
MLLM 在 2D 视觉语义上表现良好，但对 3D 空间结构（距离、朝向、场景布局）的推理仍受限。已有把 3D 重建模型接入 MLLM 的工作，要么全任务只用单一几何粒度，要么采用固定不变的多层融合方案。作者通过在 VSI-Bench 上逐层移除几何注入发现：低级感知任务更依赖 shallow 特征，高级推理任务更依赖 deep 特征，因此固定融合无法匹配任务所需的几何粒度。

## 方法详解
骨干为 Qwen3.5-4B，几何侧使用完全冻结的 VGGT-1B，取 VGGT 第 11/17/23 层 patch token 作为 shallow/intermediate/deep 三级几何表示，经 layer-specific geometric merger（stride 2）对齐到 LLM 的 token 数与隐层维度。GeoFus 在每个注入位 s∈{0,1,2} 上为每个几何层配置独立的 position- and layer-specific projector P_{s,l}（LayerNorm + 两层 MLP），从而解耦不同注入深度的投影参数。门控条件由文本、视觉语义、几何三路构成：c_t 用 MaskedAvgPool 只聚合 query token 并排除 padding 与答案 token，c_v,s 对注入位视觉隐状态做 AvgPool，c_g,s 对三级几何描述子做 layer norm 后取均值。三者按可学习缩放因子 alpha_v,s、alpha_g,s 相加，经线性层得到 logits，再用温度控制的 softmax 归一化为融合权重 w_{s,l}。融合表示为投影特征的凸组合 G_s=sum_l w_{s,l} Z_{s,l}，并以残差方式注入视觉 token：V'_s = V_s + G_s。为缓解门控塌缩（权重全压到单层），引入负熵正则 L_gate = -lambda * (1/S) * sum_s H(w_s)，lambda=0.005。训练分两阶段：Stage 1 沿用 SpatialStack 的固定层映射，联合训练 LLM 与几何投影器 1 个 epoch（lr 1e-5）；Stage 2 冻结 LLM 与 LM head，只训练投影器、门控参数与缩放因子（lr 5e-5），目标为 L_LM + L_gate，8x A800 上 5B 约 30h + 15h。

## 实验与结果
- VSI-Bench 上 SpatialMind-5B 得 71.5，居 3-5B 组第一
- 同训练数据的 SpatialStack-5B 为 69.6
- SpatialMind-10B 得 72.3，居 8-10B 组第一，高于同数据 SpatialStack-10B 的 71.3 与 GeoThinker-9B 的 71.9
- 六个空间基准（SparBench/VSI-Bench/SPBench/BLINK/MindCube/SQA3D）平均：5B 70.7（比同数据 SpatialStack-5B 高 2.1），六项中五项第一
- 10B 71.6，四项第一
- 组件消融（VSI-Bench，三次独立运行均值）：固定基线 69.6 -> 文本门控 70.1 -> 加语义与空间条件 70.2 -> 允许跨层选择 70.9 -> 加负熵正则 71.5，累计 +1.9
- 多层级几何消融：移除 shallow 注入使低级任务降 1.43 点（高级仅 0.17）
- 移除 deep 注入使高级任务降 2.07 点（低级 0.66）
- 移除 intermediate 分别降 1.33 与 1.58
- 门控可视化：高层推理任务在 L2 注入位给 deep 特征 46.8% 权重，低层感知任务为 39.3%
- 低层任务在 L0 给 shallow 35.0%，高层为 28.8%

## 创新点与贡献
- 把「不同认知层级的空间任务需要不同几何粒度」从观察提升为设计原则，并用任务条件化的门控在多个 LLM 注入层上做凸组合选择，而非固定层映射或固定层级拼接
- 负熵正则针对门控塌缩这一自适应融合的固有失效模式，属于有针对性的机制补丁
- 整体是在 SpatialStack 式多层注入框架上的架构性改造，而非全新范式

## 局限与风险
- BLINK 上 5B 与 10B 均只排第二，作者归因于该基准含艺术风格、取证、拼图等 2D 视觉逻辑任务，显式几何线索帮助有限
- 训练语料偏空间推理也是原因之一
- SPBench 上 10B 落后同数据 SpatialStack-10B 0.59 分（68.34 vs 68.93），差距集中在 SPBench-SI 的单视图绝对距离与方向估计（60.95 vs 63.50），说明细粒度单视图度量几何仍是短板
- 方法依赖冻结的 VGGT-1B 与 8xA800 两阶段训练，成本不低
