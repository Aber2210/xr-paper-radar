# 以语言弥补盲区：语言约束通信下的去中心化多视角空间推理

## 一句话结论
把语言带宽受限的去中心化多视图推理从「两 agent 单房间」推广到 N agent、六类异构场景与显式词预算：10,007 条 QA、双认证后训练池 5,541 题，集中式→去中心化落差随骨干剧烈变化（Qwen3-VL-8B 38.7→28.7）。

## 要解决的问题
现有多视角空间推理基准几乎都是集中式的：一个模型一次拿到全部视角，测到的是感知与整合的混合能力，无法说明「视角分散在不能共享像素的 agent 上」到底损失多少。语言介导的空间整合此前仅有 COSMIC 做过两 agent、单室内房间的探索。真实部署（V2V 协同感知、协同 AR/VR、居家看护）既受带宽限制又受隐私限制，只能交换抽象语言而非原始视频，且 agent 数可大于 2。因此缺少一个能隔离「真正需要跨视角协同」的问题、并带显式词预算与零视角 listener 的 N agent 基准与系统性实证。

## 方法详解
任务形式化为 $p(a^\star\mid q,\mathcal{O},u_{1:N})$：N 个 speaker 各看一个视角 $v_i$ 与问题 $q$（不给选项），各发一条不超过 B 词的消息 $u_i$ 给一个看不见图像的 listener；与同一冻结模型看全部视角的集中式结果相减即 decentralization gap $\Delta$。基准用双模型认证：blind gate 剔除仅凭语言先验或选项位置即可作答者（按 letter-prior 校正判为 A 层），single-view gate 用同尺寸灰画布替换其余视角逐个试，按（任务, N）分层分位数阈值判为 B 层，两层皆未过者为 C 层（真协同）；用 Qwen3-VL-32B 与 InternVL3.5-38B 各认证一次。划分按场景（共享任一图像文件即连通）做 80/10/10，保证零图像重叠。学习通信：所有 speaker 共享一个 LoRA，listener 冻结，奖励取 listener 对金标的连续概率 $R_k=p_{\mathrm{lis}}(a^\star\mid q,\mathcal{O},u^{(k)}_{1:N})$，团队优势按 GRPO 组内归一化 $A_k^{\mathrm{team}}=(R_k-\mu_R)/(\sigma_R+\epsilon)$。信用分配比较三种：joint（$A^{\mathrm{joint}}=A^{\mathrm{team}}$）、removal（$A^{\mathrm{rem}}=A^{\mathrm{team}}+\lambda(R_k-R_k^{-i})/(\sigma_c+\epsilon)$，即留一发言的差分奖励）、substitution（$A^{\mathrm{sub}}=R_k-\frac{1}{K-1}\sum_{k'\ne k}Q^{i,k'}_k$，用同 speaker 的替代发言作 RLOO 式基线）；比率粒度比较 token 级与 GSPO 序列级 $s_{i,k}=(\prod_t\rho_{i,k,t})^{1/T_{i,k}}$，目标为 clip 后的 $\min(sA,c(s)A)$ 加 KL。训练池只用 B+C，以避免 A 层问题奖励与消息无关的结果（free-riding）。

## 实验与结果
- 基准规模：六个异构来源共 10,007 条 QA，双模型双认证后 B+C 训练池 5,541 题（val 703 / test 677），覆盖 5 个骨干 × 27 种仅推理 agentic 设计模式
- 集中式→去中心化落差随骨干剧烈变化（CoT 评分听众、B+C）：Qwen3-VL-8B 38.7→28.7（−10.0）、InternVL3.5-8B 35.9→32.2（−3.7）、InternVL3.5-38B 33.7→31.5（−2.2），8B 骨干受损最重
- 去中心化代价：10 个 CoT 匹配的 B+C 组合中 9 个落在 4 点以内；最差仍是 Qwen3-VL-8B 在 Qwen 认证集 −10.0，仅替换认证器即收窄到 −2.2
- 唯一正例：LLaVA-OneVision-7B 在 Qwen 认证 B+C 上 +1.5，去中心化优于集中式
- oracle best-of-K 上限：B+C 58.9 vs 集中式 38.7；ALL 63.9 vs 42.6；C 层仅 51.9（A 层 75.3、B 层 75.1）
- RL：预算内最佳 joint 34.7（48.6 词）；removal(LOO) 35.2 但超预算（108 词 vs 60），相对未训练 28.7 与集中式 38.7 弥补 60–65% 差距
- substitution credit 仅 21.9，低于未训练基线 28.7；序列级比率 32.2（同 credit 下改优化器影响更小）
- 仅靠 prompting/protocol 的最佳可行设计 31.2（B+C），约为差距的 1/5；两个认证器仅在 60.9% 题目上一致

## 创新点与贡献
- 把语言带宽受限的去中心化多视角推理从「两 agent、单房间」推广到 N agent、六类异构场景、显式词预算与零视角 listener，并用双认证器把「真正需要多视角」的问题从文本捷径中隔离出来
- 结论层面给出反直觉证据：语言通道造成的损失远小于两 agent 文献的暗示（多数组合在 4 点内，甚至有正向），真正瓶颈不在 B 个词的带宽，而在能否诱导出那 B 个正确的词
- 并证明信用分配方式（removal vs substitution）比优化器粒度更决定成败

## 局限与风险
- synergy 是相对所选认证器定义的：问题因两个特定大模型盲答或单视角答不出才算 C 层，更强的闭源模型可能无需协助即可解出，作者用两个不同家族认证器来界定但无法消除
- 训练用软词预算、奖励不含长度惩罚，最强变体的部分收益来自超预算（108 词对 60 词上限）
- 所有 agent 共享同一骨干，异构团队未覆盖
- 分析为探索性，部分系统级比较未做参与者级配对推断
