# BridgeMVS：通过双向动态融合桥接多视图立体与单目深度

## 一句话结论
把单目深度与 MVS 的关系从「单向引导」改为逐 stage 双向动态更新（也用代价体几何证据反标定 DPT 中间特征）：DTU overall 0.268 mm 对 MonoMVSNet 0.278，ETH3D 测试集 F1 86.78 对 GoMVS 85.91，代码开源。

## 要解决的问题
学习型 MVS 依赖平面扫描代价体与跨视图特征匹配，在弱纹理、反光、重复纹理区域匹配代价不可靠，代价体歧义严重。现有引入单目深度先验的混合方法（如 MonoMVSNet）基本是单向范式，MDE 只作为 MVS 的外部引导，既未充分利用单目结构先验，也使 MDE 无法从多视图几何证据中获益。因此难以同时提升 metric MVS 深度与 relative 单目深度。级联多阶段框架中，各阶段之间的跨分支信息也未被显式传播。

## 方法详解
在级联 MVS 的每个 stage 插入 Bidirectional Dynamic Fusion (BDF) 模块，把 3D U-Net 正则化后的代价体 $\mathbf{R}^{s}$ 与 DPT 单目特征 $\mathbf{M}^{s}$ 双向耦合。先做特征对齐：代价体经 3D 卷积降维并重排到深度维，单目特征双线性缩放、$1\times1$ 卷积投影后沿深度维复制，二者拼接送入轻量融合模块再拆成 MVS/MDE 两支表示。动态聚合借鉴 context-mixing dynamic convolution，用 neighborhood attention 实现：mono-to-cost 方向以代价体为 query、单目特征为 key/value，cost-to-mono 方向反向，亲和矩阵为 $\mathbf{A}=(\mathbf{Q})^{\top}\mathbf{K}$ 后接线性层与 softmax。随后用代价体预测的深度概率体 $\breve{\mathbf{P}}^{s}$ 对单目特征做深度维加权，得到 reduced monocular feature，再经卷积映射回原空间做残差更新。增强后的 $\hat{\mathbf{R}}^{s}$ 与 $\hat{\mathbf{M}}^{s}$ 既用于当前 stage 预测，也向更细 stage 传播。训练上 MVS 分支用深度概率体的 cross-entropy 做 metric 监督，MDE 分支用 scale-invariant loss 做 relative 监督，逐 stage 施加。BDF 只作用于中间特征，可作为 plug-and-play 模块嵌入已有级联框架。

## 实验与结果
- DTU overall error 0.268 mm，优于 MonoMVSNet 0.278 与 RRT-MVS 0.285；高分辨率版 BridgeMVS* 0.262 mm
- Tanks-and-Temples Intermediate mean F-score 69.47，Advanced mean 44.80，均排名第一（21 输入视图）
- ETH3D F1-score：训练集 79.68、测试集 86.78，对比 GoMVS 79.16 / 85.91
- DTU 消融：单目 rel 误差由 Base 8.30 降至 0.92，τ 由 59.6 升至 93.6（ViT-B）
- ViT-B 下 MAE 6.56 vs MonoMVSNet 10.91，推理时间 0.34 s vs 0.35 s，显存 3132 MB vs 3354 MB
- BDF 作为插件接入 MonoMVSNet：Overall 0.278→0.270，仅增加 0.07 s 与 260 MB
- ViT-L 下 Overall 0.266、MAE 6.32，优于 MonoMVSNet-L 的 0.281 / 10.37

## 创新点与贡献
- 把单目深度与 MVS 的关系从「单向引导」改为逐 stage 的双向动态更新：不仅用单目结构先验细化代价体，也用正则化代价体的几何证据反向重标定 DPT 中间特征
- 将 DPT 的多尺度解码与级联 MVS stage 一一对齐并跨 stage 传播融合表示，使粗 stage 的跨分支交互惠及高分辨率深度
- BDF 只操作中间表示，因而具备跨级联框架的可插拔性

## 局限与风险
- 作者承认：cost-to-mono 更新依赖正则化代价体，增强后的单目输出需要多视图输入，不是独立的单图像深度估计器
- 当 MDE 与 MVS 同时不可靠（复杂材质、深度边界）时，双向更新会传播误差，因为 BDF 未显式估计线索可靠性
- 方法假设已知内外参和初始 metric 深度范围
- 正文实验也以离线 benchmark 为主，未报告真机或在线系统验证
