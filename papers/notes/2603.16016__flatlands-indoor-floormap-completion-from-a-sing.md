# FlatLands：单张第一视角图像的室内地板图补全

## 一句话结论
FlatLands 是首个单视角室内 BEV 可通行性地板图补全基准：270,575 条观测来自 17,656 个真实场景（聚合自 6 个数据集），统一为 256×256 BEV 网格、25.6 px/m，每条观测配齐观测地板、未观测掩码、有效性区与真值四张对齐二值图，并设显式 ID 与 OOD 划分（ScanNet++ 仅作测试）。对 11 种方法的统一比较显示：oracle best-of-4 下所有随机生成器超过全部确定性预测器，无 oracle 的 MES 上 FM+XAttn 最优（ID 0.133、OOD 0.095）。边界方差分解进一步表明，FM+XAttn 把不确定性集中在结构歧义的边界（内部方差 0.00006 对边界 0.037，约 600 倍），而 LaMa 四种子集成把种子分歧均匀摊开（比值仅 2.4 倍），说明认知集成无法代理真实的布局歧义。

## 要解决的问题
单张第一视角 RGB 受视场狭窄与遮挡限制，只能观测到很小一部分地板，大部分可通行区域不可见，单视图 BEV 补全因此是本质不适定的逆问题，需要后验采样而非单点估计。既有 BEV 方法多面向室外多摄像头设定，室内方法又通常假设全景、RGB-D、3D 扫描或近全覆盖输入，该单视角室内设定下既无标准化真实基准，也无法度量下游规划所需的不确定性。

## 方法详解
任务被解耦为观测估计与未观测补全两阶段，并形式化为后验采样问题：先用确定性前端（DepthPro 单目深度加 SegFormer/ADE-20K 地板分割）把 RGB 反投影到 BEV，得到观测地板与未观测掩码。条件生成器只在未观测区上预测补全，再通过硬钳制（完整图等于观测地板加未观测掩码逐元素乘以预测）严格保留观测证据；所有损失与指标都只在未观测有效区（未观测掩码与有效性掩码的交集）上计算，确保评分反映视场之外的补全质量。数据集从 6 个室内网格资组合成，在每个相机可行站位采样 24 个朝向，用视场检查与射线遮挡计算可见性，从 423,743 条原始观测按条件信号比不低于 0.10 过滤出 270,575 条，按场景级不相交划分为 215,342 训练、26,890 验证、28,343 测试，ScanNet++ 全程仅作 OOD 测试。评价体系在 IoU 与 F1 之外新提两个指标：UMR（未观测区错分率）与 MES（掩码能量分数，由保真项减去多样性项构成，适配 K 个采样的多假设评测）。另按条件信号比做难度分层与可靠性曲线，使不同观测丰富度下的方法表现可比较。

## 实验与结果
基准覆盖 11 种方法：4 个免训练填充规则（全障碍、全地板、最近邻传播、均匀随机）、3 个确定性模型（U-Net、PConv-UNet、LaMa）、LaMa 四种子集成，以及 Diffusion（50 步 DDIM）、Flow Matching（50 步 Heun）与 FM+XAttn（25 步 Heun，仅在 64×64 与 32×32 粗分辨率注入交叉注意力）三个后验采样器；它们共用掩码 BCE、CFG s=2.0、K=4 与逐步证据钳制，训练用 4×A100 40GB，推理在 RTX 4090。ID 上确定性以 U-Net 最佳（UMR 0.122、IoU 0.763），LaMa 最差（0.209/0.623，与全地板基线相当，因地板占比约 0.80 抬高了 IoU）。oracle 选择下随机生成器全面反超（如 Diffusion ID UMR 0.099、IoU 0.830）。无 oracle 的 MES 以 FM+XAttn 最优（ID 0.133±0.138、OOD 0.095±0.093），Flow Matching 与 Diffusion 接近，LaMa 集成垫底；OOD（ScanNet++）上各方法 IoU 普遍提升且排序保持。端到端单目 RGB 管线验证了真实传感器可行性，但宽遮挡下出现边界泄漏，LaMa 甚至整体崩溃（IoU=0.003）。

## 创新点与贡献
首个单视角室内 BEV 地板补全的真实基准与统一协议：场景级不相交划分、显式 OOD 测试、完整溯源元数据与四张对齐二值图。把补全重定义为证据钳制下的后验采样问题，并提出适配掩码评测的 UMR 与 MES 两个新指标。用边界/内部方差分解揭示认知集成与条件流模型在不确定性定位上的本质差异，且边界集中的不确定性对下游规划可直接利用。

## 局限与风险
只建模二值可通行性，无语义线索。假设简化针孔相机内参，未覆盖真实机器人相机的多样性。未表示楼梯、坡道等分级可通行性。仅限单视角输入，未涉及多视角或时序融合。闭环规划评估被明确排除在基准范围之外。

## 与文献库的关系
与库内第一视角感知与具身导航方向衔接：它把 OccAnt 式占用预期待测与 MapEx、PIPE 式多模态地图补全，收紧到单张第一视角 RGB 的度量 BEV 地板图这一更难设定，并把扩散与流匹配先验从 3D 占用补全迁移到轻量 2D 导航网格。对 XR 具身智能体而言，其补全器可作为每步空间先验，再与时序融合、信念空间规划对接。
