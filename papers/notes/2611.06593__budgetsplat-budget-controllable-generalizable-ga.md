# BudgetSplat：预算可控的通用高斯泼溅

## 一句话结论
BudgetSplat 以单个训练模型按用户指定 preservation ratio ρ∈(0,1] 前馈产出可控规模高斯表示：ScanNet 3 视图 25% 预算 PSNR 26.35 dB/SSIM 0.841、仅 147k 高斯（较 FreeSplat 的 423k 少 61.5%+，PSNR 差 0.38 dB）；10 视图 25% 时 163k 高斯较 FreeSplat 少约 45% 且 PSNR/SSIM 接近（24.91/0.793 vs 25.03/0.800）；5% 极限预算仅 33k 高斯、PSNR 较 100% 仅降 0.22 dB；Replica 零样本 100%→25% 移除约 74% 高斯而画质几乎不变。

## 要解决的问题
pixel-aligned 前馈 3DGS 每像素解码高斯，表示规模随图像分辨率与输入视图数快速增长，重叠观测还产生大量跨视图冗余。固定容量方法（global scene tokens 类）把输出绑死在 token 容量上，更大更复杂的场景需重训高容量模型；post-hoc 压缩（如 LightGaussian）引入额外逐场景处理；EcoSplat 按 opacity 排序选择但不显式推理空间覆盖与跨视图冗余；对常规训练的 pixel-aligned 模型直接套 budget-unaware Top-K 会把高斯过度分配到显著/高 opacity 区域，弱纹理区域覆盖不足。

## 方法详解
整体为预算可控映射 f_θ: ({(I^i,P^i)}, ρ) → {(μ_j, α_j, Σ_j, c_j)}，目标预算 K=⌊ρNHW⌋（几何去冗余后 M≤K，K 为上界，也可经 ρ=K_abs/(NHW) 指定绝对上限）。（1）骨干沿用 FreeSplat 的特征提取、cost-volume 深度估计与高斯预测，去掉其原生 geometric fusion，候选为 NHW 个 pixel-aligned 高斯。（2）Budget-Conditioned Feature Modulation：ρ 空间广播后经轻量卷积嵌入为 budget feature E_i，加到 base feature F_i 上再进 MLP 预测 {α̃, Σ̃, c̃}，使预测 opacity 与属性随预算自适应，而非对固定预测做不同幅度截断。（3）Intra-Cross Mask Supervision：帧内按梯度幅值 g_i 与 (1−ρ_h) 分位数（ρ_h=γρ，γ=0.6）选高频结构像素，剩余像素均匀稀疏采样得低频覆盖，构成 pseudo mask Ω_intra=Ω_high+Ω_low；跨帧把正样本反投影 3D，先帧内粗体素取代表、再跨视图细体素分组，高频代表共享权重 1/|V_i(p)|、低频得固定弱权重 λ_low，以加权 BCE 监督激活 opacity。（4）Coverage-Aware Budget Selection：先 patch-wise 预选过采样高 opacity 候选，再在单视图候选池上做 view-wise global opacity ranking，最后跨视图 3D NMS 去几何冗余。（5）训练两阶段共 600K 迭代：先 300K dense 重建（MSE+LPIPS），再 300K 预算分支（ρ 随机采样并逐步向低比例偏移、top-K 渲染），总损失 L_render + λ_mask·L_mask + λ_alpha·L_alpha，L_alpha 惩罚目标视图渲染 alpha 缺失 |1−A_tgt|。

## 实验与结果
ScanNet（100 训练/8 测试）+ Replica 8 场景零样本；单卡 RTX 4090、Adam lr 1e-4、batch 1、384×512（10 视图评测因部分基线 OOM 改 256×256），300K dense + 300K budget。Table 1（2/3 视图）：BudgetSplat 100% 28.11/0.839/0.228/382k、25% 27.84/0.840/0.250/98k（2 视图），100% 27.13/0.825/0.245/565k、25% 27.07/0.828/0.264/147k（3 视图）；同预算 EcoSplat 25% 仅 19.97/0.672/0.426/98k 与 20.35/0.703/0.420/147k；较 FreeSplat（28.08/278k、27.45/382k）少 60%+ 高斯、PSNR 仅差 0.24/0.38 dB。Table 2（10 视图，256×256）：BudgetSplat 100% 插值 24.90/0.790/0.254、外推 23.70/0.771/0.280、653k GS/147.0 MiB；25% 24.91/0.793/0.295、23.66/0.775/0.318、163k/36.7 MiB（较 FreeSplat 294k 少约 45%，PSNR/SSIM 接近其 25.03/0.800）；5% 24.68/0.789/0.368、23.35/0.771/0.391、33k/7.4 MiB（PSNR 较 100% 降 0.22/0.35 dB），同为 33k 时高于 GlobalSplat 23.13/0.761/0.338。Table 3（Replica 零样本）：3 视图 100% 26.38/0.841/0.211/580k、25% 26.35/0.841/0.235/147k；10 视图 100% 21.08/0.744/0.297/631k、25% 21.14/0.747/0.313/163k（移除约 74% 高斯、退化有限）。Table 4 消融（3 视图、147k）：plain view-wise Top-K baseline 13.02/0.386/0.561；+I 24.80/0.743/0.336；+I+A 26.14/0.810/0.311；+I+C+A 26.38/0.813/0.310；+I+A+S 26.75/0.821/0.279；Full 26.77/0.823/0.275。

## 创新点与贡献
['把预算可控前馈 3DGS 形式化为重要性估计、空间覆盖与跨视图冗余的联合问题，单模型支持任意 ρ∈(0,1] 与任意视图数，无逐预算重训、无逐场景压缩', 'ICMS：帧内高频结构+低频稀疏覆盖 pseudo mask 与跨视图细体素冗余加权联合监督 opacity，使排序依据从裸 opacity 变为预算感知的重要性', 'BCFM：把 ρ 注入高斯预测分支本身而非只做输出截断，使预测的 opacity 与属性随预算自适应', 'CABS：patch-wise 预选 + view-wise global opacity ranking + 3D NMS 三步选择，输出紧凑且空间分布均匀的高斯集']

## 局限与风险
['pseudo 监督依赖图像梯度与估计几何，图像质量退化或深度误差在极紧凑预算下会影响选择', '仍保留 dense pixel-aligned 预测骨干，前向计算量未减，只减最终表示与渲染成本', 'BudgetSplat 100% 的高斯数反而多于 FreeSplat（去掉了原生 geometric fusion），跨方法比较需注意候选集定义差异', '仅室内 ScanNet/Replica 评测；绝对跨数据集性能仍受底层架构强烈影响（VolSplat/GlobalSplat 在不同设定更强）']

## 与文献库的关系
属前馈 3DGS 紧凑表示一线，与 FreeSplat/FreeSplat++（骨干与作者重叠）、ZPressor/GlobalSplat/VolSplat（固定容量路线）、EcoSplat（预算化 compaction 直接对照）、LightGaussian（post-hoc）构成谱系；与库内大量 3DGS 压缩/加速论文互补——它把可控性前移到测试时预算，而非训练容量或事后压缩。

全文未提代码或项目页开源；训练细节完整（Adam 1e-4、batch 1、600K 两阶段、λ_MSE=1.0/λ_LPIPS=0.05/λ_mask=0.1/λ_alpha=1.0、γ=0.6），硬件单卡 RTX 4090，数据为公开 ScanNet 与 Replica，基线多用官方 checkpoint（FreeSplat++ 仅引其 2/3 视图已发表数值）。

## 行动建议
做 3DGS 资产部署或流式分发的从业者可把 ρ 当作显式的质量-体积旋钮（25% 预算画质近损、5% 仍有 24.68 dB），落地时须在目标数据上验证梯度 pseudo mask 对低质量图像的鲁棒性，并核算 dense 骨干前向成本是否被压缩收益抵消。
