# 第一视角视频中的手-物接触转场检测

## 一句话结论
在自建 ContactTransition（4,021 段第一视角视频、8,498 个 touch 与 8,077 个 release 标注）上，OASIS 无 NMS 时取 49.30 mAP、有 NMS 时 51.19 mAP，分别高出最强基线 5.37 与 1.91 mAP；相对 HiCE，release 的 AP@δ=0 由 23.59 升到 29.42（+5.83）。

## 要解决的问题
手-物接触的两个边界（touch 起始、release 释放）界定了一次操作的完整区间，可支撑细粒度动作分割、抓握时长分析、技能评估与示范学习。但现有工作要么把接触当逐帧属性分类（100DOH、ContactHands、Hands23、BodyHands），要么只定位 touch（HiCE 已接近帧级精度），release 完全空缺；Yagi 等虽预测每帧二元接触状态，但只建模状态不定位转换。难点有三：证据只集中在少数几帧，需区分接触前后视觉高度相似的帧；第一视角还有快速运动、运动模糊、频繁遮挡与操作风格差异；更关键的是「把 touch 检测扩成两类」不成立——touch 有接近与抓握成形的手部运动线索，而 release 后手常停在物体附近、手姿变化微弱，判别证据转移到物体侧。此外 touch 与 release 同属一个 episode，可相邻甚至同帧（双手操作），标准 spot 的互斥 softmax 加类共享位移假设在此失效。已有的物体证据引入方案（AOE-Net、UGLF）依赖推理期外部检测器、需预定义物体词表，且在接触瞬间因手部遮挡最不可靠。

## 方法详解
以 HiCE 的 hand-enhanced 特征图 F_enhanced（全局帧特征经 hand-to-frame attention 由手部 patch 增强，保留空间布局）为起点，OASIS 加两支。(1) Object-of-interest 分支：轻量头预测 class-agnostic 热图 S=φ_object(F)∈R^{H×W}，监督信号是把物体/接触物体标注投影到以手为中心的网格得到的软覆盖目标 G∈[0,1]^{H×W}（HOI4D 用自带标注，TACO 用 HOI-DETR 生成的逐帧接触物体标注），损失为前景加权 BCE：L_heatmap=(1/HW)Σ_j w_j BCE(S_j,G_j)，w_j=1+(w_fg−1)G_j、w_fg=10，补偿前景占比极小；把预测概率在空间上归一化后对 F 做 coverage-weighted pooling（CWP）得 f_object，用归一化覆盖权重而非 softmax，以便覆盖物体整体空间延展并支持多候选；再用两层 MLP 从帧表示预测 object-presence 分数 q 做门控，f=f_global+γW_o(q·f_object)，γ 初始化为 0，避免早期噪声物体读出污染主干。(2) Transition-aware spotting：不再用互斥 softmax，而是各类相对共享背景算 margin m_l^c=z_l^c−z_l^bg、p̂_l^c=σ(m_l^c)，c∈{touch,release}，每类各自用 focal BCE（α=0.9、γ_f=2）对各自的软高斯目标回归；位移精化改为类专属，ŷ^d∈R^{L×K}，监督为到最近同类事件的带符号距离（半径 r=4 帧内），推理时按类各自精化，解决「共享 offset 会把一类推向正确、把另一类推离」。总损失 L=L_c+L_d+λ_g L_g+λ_obj(L_heatmap+λ_p L_presence)，其中 L_g 沿用 HiCE 的抓握伪标签正则，λ_g=0.2、λ_obj=0.15、λ_p=0.75、presence 阈值 τ=0.1，端到端联合优化手部增强特征、物体定位、时序推理与双转换预测。训练用 40 帧片段、50 epoch、AdamW、batch 6、每 epoch 5,000 clips、lr 4e-4、3 epoch warm-up 加 cosine 退火，骨干为 RegNet-Y 800MF（ImageNet 预训练），手部 patch 放大 1.2× 后 resize 到 224×224。推理不依赖任何外部物体或 HOI 检测器，但仍沿用 HiCE 的手框输入。

## 实验与结果
- 数据集规模：ContactTransition 共 4,021 段视频 / 16,575 个事件（8,498 touch + 8,077 release）；train 3,234 段（6,837/6,488）、val 138 段（324/323）、test 649 段（1,337/1,266），视频源为 HOI4D 派生片段与 TACO 片段。
- 主结果（无 NMS）：OASIS 49.30 mAP，最强基线 V-JEPA+MS-TCN 43.93（+5.37），HiCE 43.67（+5.63）；有 NMS 时 51.19，高于 TSP+ASFormer 49.28（+1.91）与 HiCE 47.58（+3.61）。
- Release 增益：无 NMS 下 AP@0 29.42 vs HiCE 23.59（+5.83）、AP@1 +6.93、AP@2 +6.13，各容差均为最佳；有 NMS 后 release AP@0 降到 17.97（HiCE 11.32），说明后处理对释放时刻伤害最大。
- Touch 侧：AP@1 44.86、AP@2 61.69 为全场最佳，但帧级 AP@0 16.88 仍略低于两阶段的 V-JEPA+MS-TCN（17.86，无 NMS）。
- 消融（有 NMS mAP）：去 object 分支 51.19→40.89（−10.30，最大跌幅）；去 presence gate 50.11（−1.08，release AP@0 29.42→27.69）；softmax 池化替 CWP 50.37；共享位移替类专属 47.52（−3.67，touch AP@1 44.86→37.81）；HiCE 的 softmax 表述 47.58。
- 互补性验证：在 transition-aware 表述下把 object 分支去掉反而降到 37.43，低于 HiCE 的 43.67，说明「类独立打分」缺了物体证据会失去对歧义事件的抑制，两项必须共存。
- 下游应用：把预测的 touch/release 分数作为时间上下文喂给 Qwen2.5-VL 做 HanDyVQA，均分 58.01→58.49（+0.48），Parts +1.23、State +1.14、Location +0.82，Process −0.82。

## 创新点与贡献
- 提出并定义 hand-object contact transition detection 任务，把「逐帧接触属性」升级为有起止边界的 contact episode，并配套 4,021 段视频、16,575 个事件的帧级双边界基准（含 object-of-interest 监督）。
- 把物体证据从「推理期外部检测器」改成「手条件化的 class-agnostic 热图 + 覆盖度池化 + presence 门控」，物体标注只在训练期使用，推理期不依赖任何物体或 HOI 检测器。
- 针对 touch/release 的耦合且非互斥性重写事件定位表述：类独立 margin 对共享背景打分 + 类专属位移精化，替代互斥 softmax 与类共享 offset，避免双手同帧事件互相抢概率。
- 用消融给出「独立打分」与「物体证据」必须共存的证据（单独去掉任一项都不优于 HiCE），而非简单叠加式改进。

## 局限与风险
- （作者承认）release 标注本身歧义大，遮挡、模糊、证据不足的样本被直接排除，等于在难例上让评估偏乐观；短暂重抓握被并入同一 episode。
- （作者承认）数据集未做 per-hand 归属，双手交互时无法区分事件来自哪只手，作者把 per-hand transition attribution 列为未来工作。
- （作者承认）训练集只人工校验 35% 的 HOI4D 片段（优先含难 release 的视频），其余 release 依赖自动标注策略，标签噪声未量化；共标注 5,126 个 release、复核 1,668 个 touch。
- （我在正文发现）帧级 touch（δ=0）仍不及两阶段 V-JEPA+MS-TCN（16.88 vs 17.86 无 NMS），「端到端统一」在帧精确度上并未全面胜出；且 NMS 后 release AP@0 从 29.42 掉到 17.97，部署对后处理极敏感。
- （我在正文发现）下游收益很小（HanDyVQA 仅 +0.48，Process 还 −0.82），说明「接触边界」作为时间上下文的信息增量有限；数据只来自 HOI4D 与 TACO 两源，第一视角日常操作的域覆盖仍需外部验证。

## 与文献库的关系
直接建立在 HiCE（hand-centric contact onset spotting）之上，把它从单类 touch 扩到 touch+release，并把 HiCE 当作最强端到端基线（无 NMS 时 +5.63 mAP、有 NMS 时 +3.61）；与 100DOH、ContactHands、Hands23、HOT、BodyHands 的「逐帧接触状态/接触区域」路线互补——本文把状态升级为有起止的边界，可与这些 per-frame 方法串联使用；与 Ego4D 的 point-of-no-return 关键帧（每段只给一个状态变化帧）相比，本文要求成对的起止边界；与 EPIC-KITCHENS、HOI4D、ARCTIC、HOT3D 等数据集是互补关系（本文在其视频源上新增 release 标注）；在 spot 方法族里与 E2E-Spot、T-DEED、ASTRM、AdaSpot、UGLF 直接对比，并用 TSP、V-JEPA 两阶段特征配 MS-TCN、ASFormer 做强基线；物体证据侧与 AOE-Net、UGLF 依赖推理期检测器、需预定义词表的做法形成对照；下游接 HanDyVQA 与 Qwen2.5-VL，属「用感知信号增强 VLM 时序推理」的一条支线。

## 可复现性（代码/数据/硬件）
代码 https://github.com/bbvisual/oasis 已公开；数据集 ContactTransition 在正文未见明确的发布/下载声明（仅说明沿用 HOI4D 与 TACO 的视频源及 HiCE 的标注协议），需向作者确认可得性；训练配置写得很细（40 帧、50 epoch、batch 6、lr 4e-4、RegNet-Y 800MF、focal α=0.9/γ=2、r=4），复现门槛中等。

## 行动建议
先读 §4.4（transition-aware 表述与类专属位移）与 §5.5 消融，这是本文真正的贡献点；再读 §3.1 的 release 标注规则以理解标签口径。核三处风险：数据划分是否与 HiCE 的 TouchMoment 划分对齐（否则 mAP 不可跨文比较）；release 排除歧义样本带来的乐观偏差；NMS 前后 release AP@0 差 11 个点的部署含义。若要复用，object 分支的 CWP 与 presence gate 是最值得照搬的两个模块，成本低、消融收益明确。
