# 面向三维虚拟试穿的多视图 Transformer 与几何引导多模态 ControlNet

## 一句话结论
多视图修复 Transformer + 几何引导多模态 ControlNet 解决 3DGS 试穿的跨视角不一致：FID 24.1 对 GS-VTON 38.2（−36.9%），LPIPS −46.5%。

## 要解决的问题
在 3DGS 人体捕获上换装，要求任意渲染视角对同一件衣服的细节保持一致。现有 3D 试穿管线（GS-VTON、GaussianVTON）的三个关键部件是手工设计而非学习得到，因而把不一致烧进三维表示。第一，构建编辑后的训练视图集时各视图基本被独立编辑，再用人工挑选的参考视图拼接 UNet 注意力特征「事后对齐」；参考视图手选、注入结构固定，模型从未显式学习跨视图对应，印花、条纹、文字在视图间漂移模糊。第二，3DGS 编辑阶段扩散模型只以服装外观为条件，必须隐式推断表面朝向、深度序与遮挡边界，在抱臂、手插兜等自遮挡与强躯干旋转处出现错误层序与「贴上去」的平面感。第三，当前视图与参考视图的注意力特征用固定权重融合，等于假设任意机位下每个参考视图都同等有用，而从背面看时最近的参考视图才可信，固定权重在远离训练机位的新视角系统性失准。这些二维层面的小不一致经三维重建放大为纹理漂移、印花模糊与不合理几何。

## 方法详解
问题设定：给定带位姿多视图捕获 I_train={(I_i,π_i)}、服装图 I_cloth 与解析模型给出的服装掩码 M_train，目标是可任意视角一致渲染的换装三维表示。三阶段。①按标准 3DGS 重建主体 G_src，损失 L_recon=Σ_i‖R_rgb(G,π_i)−I_i‖₁+λ_ssim(1−SSIM)。②多视图修复 Transformer（MVT）：采 n∈[4,6] 视图（实验取 4），每视图把图像与掩码通道拼接后 patch 嵌入 T_i=PatchEmbed(Concat(I_i,M_i))∈R^{P×D}（式5），所有视图 token 拼成单序列 T_all=Concat(T_0,…,T_{n−1})∈R^{(nP)×D}（式6），在整条序列上做 softmax(QKᵀ/√d_k)V（式7），任一副块可注意到其他视图任意 patch，跨视图对齐由手工拼接变为可学习对应。服装经冻结 CLIP 得 T_g，以 cross-attention 注入 T_fused=CrossAttn(T_all,T_g,T_g)（式9），Split 后由轻量 CNN 解码。目标 L_stage2=L_rec+λ_perc L_perc+λ_cyc L_cyc：L_rec 为逐视图 L1、L_perc 为 LPIPS、L_cyc=Σ_{i≠j}‖A_{i→j}V_i−V_j‖₂（式12）用注意力子块做循环一致；监督用强 2D 试穿模型的伪目标。③以这批一致视图 LoRA 个性化 SD-inpainting，再做几何引导编辑：每轮渲 I_src、D_src、N_src，三条 ControlNet 分支 F_g=CNet_gar(I_cloth)、F_n=CNet_nor(N_src)、F_d=CNet_dep(D_src)，逐级 ℓ 以 F_fused^ℓ=CrossAttn(F_g^ℓ,Concat(F_n^ℓ,F_d^ℓ),Concat(F_n^ℓ,F_d^ℓ))（式18）融合后残差注入 x_dec^ℓ←x_dec^ℓ+F_fused^ℓ；深度/法向分支冻结，故几何引导不需逐场景训练。编辑限于服装区：I_masked=I_src⊙(1−M)，I_edit=D(Denoise(E(I_masked),M;θ+Δθ,F_fused))。姿态自适应注意力替换固定权重：ΔP_i=‖R_cur−R_i‖_F+β‖t_cur−t_i‖₂（式22），w_i=exp(−ΔP_i/τ)/Σ_j exp(−ΔP_j/τ)（式23），融合比由小 MLP 依位姿预测 λ_dyn=σ(MLP(φ(P_cur)))（式24），F_final=λ_dyn F_cur+(1−λ_dyn)Σ_i w_i F_i（式25）：近训练机位聚焦最近参考，远离时权重摊平且 MLP 可把权重移回当前视图。损失 L_stage3=L_img+L_geo，L_img=λ₁‖I_src−sg(I_edit)‖₁+λ₂LPIPS(I_src,sg(I_edit))，L_geo=λ₃‖N_src−N_ref‖₁ 抑制非服装区几何漂移。数据为 3D-VTONBench 的 60 人、每人 12–16 视图、1024×1024，全程约 75 分钟/（受试者,服装）对。

## 实验与结果
- 3D-VTONBench 主表：FID 24.1 vs GS-VTON 38.2（相对降低 36.9%），KID 0.008 vs 0.023（降 65.2%），LPIPS 0.076 vs 0.142（降 46.5%）
- 跨视角一致性代理指标 LPIPS 0.076，优于通用编辑器最好的 GaussCtrl 0.165（降 53.9%）与 Instruct-NeRF2NeRF 0.231
- 新视角保真：服装掩码外 PSNR 从 GS-VTON 的 21.3 dB 提到 26.2 dB（+4.9 dB），身份、背景与未编辑衣物保持更好
- 几何漂移：非服装区法向图 MSE 从 0.087 降到 0.041（降 52.9%）
- 仅加多模态 ControlNet 时先降到 0.053
- 消融：基线 A=38.2 → +MVT 32.1（单模块最大增益，−16.0%）→ +ControlNet 34.5 → +姿态自适应 36.8 → MVT+ControlNet 27.3 → 全模型 24.1 FID
- 用户研究：25 名被试 × 25 组、每准则 625 次回答，综合偏好 29% vs GS-VTON 18%、GaussCtrl 15%、Instruct-NeRF2NeRF 7%
- 效率：整套三阶段流程约 75 分钟/（受试者,服装）对，阶段三迭代数与 GS-VTON 相同

## 创新点与贡献
- 把 3D 试穿的训练视图编辑从「逐视图独立编辑 + 手工参考拼接」改为单序列全 token 跨视图自注意力，使跨视图对应可学习，并用注意力子块的循环一致性损失显式约束。
- 用「从当前 3DGS 状态渲染的深度与法向」而非拟合好的 SMPL-X 作 ControlNet 几何条件，使引导跟随真实轮廓、头发与宽松衣物。
- 把固定的当前/参考注意力融合权重替换为「softmin 位姿邻近加权 + MLP 预测融合比」的双层姿态自适应机制，显式区分「近训练机位信参考、远机位信生成先验」。
- 提出隐式（注意力对应）+ 显式（几何条件）混合的三维推理分工假设，并用消融定量验证：MVT 主要降跨视图不一致、ControlNet 主要降法向误差。

## 局限与风险
- 作者自述：几何条件从当前 3DGS 渲染得到，而该场景初始穿的是原衣服，当目标服装廓形差异大（短袖换长袖、裤子换连衣裙）时深度/法向会把编辑偏置回旧形状，L_geo 也抵抗合理几何改变，补救是把 L_geo 限制在掩码外、膨胀掩码或混入人体模型几何
- 3DGS 渲染的深度/法向在细结构与头发处噪声大
- 全跨视图注意力对视图数二次增长，阶段二只能处理少数视图
- 长发横跨服装与强自遮挡仍出错
- 评估未含 DGE、EditSplat、VTON 360，一致性只用 LPIPS 代理，未用 MEt3R，也未在服装区算保真度
- 从实验设计看：FID/KID 在渲染图上算分布距离，样本仅 60 人，编辑目标由 2D 试穿模型伪标签监督，上限被教师模型封住
- 主表降幅（FID −37%）在同类 3D 编辑工作中异常突出，而基线全由作者重跑（原论文未报告这些指标），口径缺第三方校验
- 75 分钟/对且需 12–16 视图专用捕获，离消费级试穿很远
- 用户研究只给偏好率、不给置信区间与评审一致性
- 身份保持仅用掩码外 PSNR 近似，脸部与手部在掩码内被改动时无法捕捉
