# ARG-Avatar：以动画-渲染引导实现高效前馈化身重建

## 一句话结论
把模板/LBS/渲染的几何对应写进 attention 的 RoPE 与层内 rendering-in-the-loop，68M 参数在 6 视角 NeuMan 上超 609M 的 LHM++ 2.73 dB。

## 要解决的问题
从随手拍照片或单目视频帧重建可动画 3D 化身，feedforward 方法已把推理压到数秒，但近期路线靠堆模型容量、私有数据与算力（LHM++ 609M 参数、约 300K 视频）。作者质疑这种 scaling-first 是否必要：模板锚定的化身本身有表示上限，而现有架构用通用 attention 从数据里硬学「化身元素对应哪块图像」，浪费了模板、LBS 与渲染已经给出的几何对应。目标是在公开数据与 68M 参数规模下达到 SOTA 的重建质量与效率。

## 方法详解
表示是在 MHR 模板 UV 图上锚定的 3DGS：每个 UV 网格点放一个高斯，位置为重心的插值锚点加学习到的 canonical offset，共 264K 个（定制 UV 光栅化给部分身体更高分辨率）。对每个目标姿态额外预测 10 维 pose-dependent 残差（位移 3、尺度 3、四元数 4），先形变再动画；动画用扩展的 forward LBS，在 UV 锚点处重心插值每顶点变换，得到刚体旋转与位置。网络输入零初始化 UV map 与 V 张图，每张图经冻结 SAM3DBody（给姿态与 ViT 稠密特征）与可训练 ConvNeXt 提特征后相加。核心 FACRoPE 把 UV token 当 query、图像 token 当 key：图像 token 坐标取 (u,v,0)，UV token 坐标取「动画并渲染后的投影位置」FAC=[x, y, z-D]，其中 D 从候选化身在该视角的渲染深度图采样，用 RoPE 让 attention 只依赖相对坐标偏移，从而把 token 精确对准它该看的 patch，遮挡 token 的坐标则被推离像平面。ITR 让这套坐标在中间层就可用：CMLP 从每个中间 token 解一个高斯、PMLP 解形变，合成 posed token-GS 化身，动画渲染后把 FAC 回填给下一层，形成 rendering-in-the-loop。两个 MV-ARGBlock 把 UV token 克隆到 V 个姿态分支、加姿态嵌入，各分支做 FAC 引导的 3D RoPE 交叉注意力，再以 elementwise attention 融回主 token 流，过 self-attention 与 FFN。解码端把 token 重排回 UV 布局，CDec 上采样出 canonical 高斯，PDec 出每个驱动姿态的形变。训练用光度损失，另加 common shell transfer 正则：用 IRLS 估跨视角共享 shell，stop-gradient 强迫共享形变进 canonical offset、视角特有部分留在 pose offset，避免两者解耦失败。只在公开数据（DNARendering、2K2K、4D-Dress、Human4DiT、THuman2.1、HumanVid，6.8K 主体、64K 序列）上训 100K 步、batch 96、AdamW、lr 1e-4 cosine，四张 A6000 约 200 小时。

## 实验与结果
- 分布外 NeuMan 6 视角：30.82 dB PSNR / 0.975 SSIM / 0.016 LPIPS，比 LHM++ 的 28.09/0.972/0.022 高 2.73 dB
- 2 视角 29.17 对 27.97
- 1 视角 27.02 反而低于 LHM++ 的 27.71
- 6 视角下 Multiview Videos 28.83 对 25.68（+3.2 dB）、3D Scans 26.81 对 22.49（+4.3 dB）、HumanVid 25.86 对 22.50（+3.4 dB）
- NeuMan input-pose 重建 33.30 对 28.50（+4.8 dB）
- 视角扩展性：输入从 1 增到 6 视角，ARG-Avatar 提升 3.8 dB，LHM++ 只提升 0.4 dB
- 效率：68M 可训练参数（LHM 的 6%、LHM++ 的 11%，约 9 倍更少），64K 公开序列（约 LHM 的 21%），约 125 H100 等效 GPU-hours（LHM++ 的 7%）
- 6 视角含 SAM3DBody 前向 2.3 s，比 LHM++ 的 14.2 s 快 6.2 倍
- 2^3=8 组组合消融：FACRoPE 在每种配置都提升 PSNR（即使候选化身只是中性 mesh）
- ITR 与 pose deformation 各自有效，两者同时开启时 FACRoPE 增益最大
- 第三层不再涨点，最终用两层

## 创新点与贡献
- 把模板、LBS 与渲染给出的几何对应直接写进 attention，而不是让网络从数据里学 token 到 patch 的对应：FAC 用动画渲染后的投影坐标做 RoPE，遮挡关系由深度差自然编码
- ITR 把这个坐标从一次性先验变成层内可迭代的 rendering-in-the-loop，中间 token 解出的粗糙化身反过来修正下一层的注意力
- 用 68M 参数在多个数据集上超过 609M 的 LHM++，给出「几何先验换 scaling」的一条实证路线

## 局限与风险
- 单视角明显弱于 LHM++（27.02 对 27.71 dB），作者明确说模型没有训练 inpaint 不可见区域，V=1 的落后是预期的，实际使用需要多视角或视频
- 依赖 SAM3DBody 的姿态与 MHR 模板：2K2K 例子中头部区域因跟踪错位出现重影，说明位姿误差会直接进入渲染
- 模板锚定表示本身有上限（作者在引言中承认增加容量无法突破 template-anchored avatar 的表示约束），宽松衣物与长发只能靠 10 维 pose residual 近似
- 全文没有代码或项目页，训练需约 200 小时四张 A6000
