# EgoPathBench：评估视觉语言模型的零样本第一人称 waypoint 决策

## 一句话结论
把「可行性」写进 3D 场景几何而非文字或 2D 像素，用 Point/Embodied 成对设计把「同一动作在不同机身约束下后果不同」变成可测量变量，Intent Path 再把指代解析与具身路径绑定：1,111 道基准题上十个零样本 VLM 最高仅 35.6 分（GPT-6 Astra）。

## 要解决的问题
空间 QA 基准（SpatialVLM、VSI-Bench、3DSRBench 等）只问孤立的空间关系，无法说明模型能否把理解转成可执行动作序列；闭环 3D 导航基准又把单视图推理与建图、记忆、避障、重规划缠在一起，代价高且无法归因。缺的是「同一观测、同一动作词表」下，从局部可走性到完整具身路径的统一度量，尤其是机身间隙这类约束。

## 方法详解
每个样本给一张带编号候选 waypoint 的第一人称 RGB、一句自然语言目标、以及任务特定的可行性图 G，模型输出 JSON 候选集或有序路径。可行性图建在高度滤波的 2D 占据栅格上：Point 图不做足迹膨胀，Embodied/Intent 图按 0.6 m 机身直径外扩 0.30 m；边合法要求直线扫掠走廊无碰撞，终点须落入目标框附近的接受域（d_min+0.10 m）。五个任务递进：Point/Embodied Traversability 判可走点集；Point/Embodied Path 共享视图、目标与候选集，只在可行性图上不同；Intent Path 把显式物体名换成意图加视觉线索，必须先解指代再选具身路径。所有 waypoint、目标区与合法边都在生成语言之前锚定到注册的 3D 场景几何，参考路径只证明解存在、不要求模仿。指标含 VPR（整条路径合法）、SR（还需到达接受终点）与 SPL（相对最短合法参考的长度折扣）。训练侧另发布 EgoPath-SFT，把几何核验过的答案与 Spatial CoT 理由配对。

## 实验与结果
- 规模：31,852 训练（EgoPath-SFT）/1,345 验证/1,111 基准题；基准含 146+146 可走性、309+309 路径、201 意图路径
- 十个零样本 VLM 最高 EgoPath Score 仅 35.6（GPT-6 Astra），其后 Gemini 3.1 Pro 28.3、GPT-5.5 27.3、Grok 4.3 Fast 1.4
- 同一视图同一目标：Point Path SR 41.7% → Embodied Path 10.0%、Intent Path 10.0%；其余九个模型 Embodied Path 均低于 3%（Intent 至多 4.0%）
- Qwen3.5-4B 经 EgoPath-SFT 微调：EgoPath Score 3.9 → 38.9；Isaac Sim 闭环 0/50 → 10/50（+20 个百分点，95% CI 10–30）
- 诊断：合法首边率 96.4%/91.1%/88.8%，但其中 48.8%/90.7%/89.4% 含后续非法边；端点正确率仅 31.4%/5.9%/6.3%
- 人类仅凭 RGB 判断 40 条子路径可走性达 87.5%；同题人类参考 54.2 vs Astra 48.7

## 创新点与贡献
- 把「可行性」写进 3D 场景几何而非文字或 2D 像素，用 Point/Embodied 成对设计把「同一动作在不同机身约束下后果不同」变成可测量变量
- Intent Path 再把指代解析与具身路径绑定
- 配套 SFT 集证明该能力可被注入小模型

## 局限与风险
- 场景限于单房间、无楼梯的合成渲染，waypoint 词表由构造固定，真实长程导航与动态障碍未覆盖
- 基准题量 1,111 偏小，SFT 的 CoT 文本由 GPT-5.5 生成，存在教师模型偏置与语言风格泄漏风险
