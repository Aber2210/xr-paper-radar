# S2D-Splat：层间特征引导的静态优先动态驾驶场景高斯重建

## 一句话结论
把静态/动态分离从基元级提前到相机与几何估计之前的特征级，用非对称层间引导从结构上切断动态更新对静态几何的反向污染：Waymo 全图 25.953 dB、动态区 22.043 dB（StreetForward +1.79）。

## 要解决的问题
驾驶场景中的运动物体会带来跨帧不一致，干扰相机估计与静态几何恢复。现有前馈高斯方法虽在基元层面区分静态/动态，但相机参数与几何仍从同时编码两者的共享 backbone 特征估计，静态重建依旧受动态内容污染；在事故前等剧烈运动场景下这种干扰更致命。

## 方法详解
S2D-Splat 是静态优先的前馈框架：先用冻结 DINOv3 编码 patch token，并用 SAM2 由 2D box 生成动态掩码切分 token；Motion-Static Separator 以把注意力 logits 对动态 key 置 −∞ 的 masked attention 保护静态路径，同时用两路可变形注意力分别提纯动态 token、从边界混合 token 中回收静态分量。静态分支经交替注意力主干估计相机内外参并重建静态 Gaussians，每层的相机与静态 token 缓存进 Tokens Bank；动态分支以非对称层间引导运行——每层后只保留动态 token，与缓存静态 token 重新融合进入下一层，静态表示作固定条件而永不被动态更新修改。最后实例级运动解码器以 (box, timestep) query 在全局融合表示上逐实例解位姿，位姿差直接给出刚体运动，用于运动对齐的高斯融合与时间插值。

## 实验与结果
- Waymo 全图 PSNR = 25.953 dB（StreetForward 25.237 dB）
- Waymo 动态区域 PSNR = 22.043 dB（StreetForward 20.252 dB）
- Waymo 全图 D-RMSE = 2.152（StreetForward 3.017）
- 相机位姿 AUC@3° = 0.714（StreetForward 0.688，DGGT 0.619）
- 动态运动 APD3D = 19.20%（StreetForward 11.47%，DGGT 13.14%）
- 静态区域 D-RMSE = 2.057（StreetForward 2.913）

## 创新点与贡献
- 把静态/动态分离从基元级提前到相机与几何估计之前的特征级，并提出非对称层间引导：静态特征逐层缓存后作为动态分支的固定条件，静态表示只读不写，从结构上切断动态更新对已建立静态几何的反向污染

## 局限与风险
- 作者未设专门局限节，可推断：依赖 SAM2 给出的 2D box 提示与动态掩码，掩码边界与漏检直接限制分离质量（论文亦承认掩码不是硬分隔，混合内容可能经编码器或边界融合回流）
- 训练需 8 帧上下文与 LiDAR 深度监督
- 评测限于单相机设置与三个驾驶数据集，未覆盖非驾驶或室内场景
