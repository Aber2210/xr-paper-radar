# OccamView：对象条件化的帧预算主动 3DGS 重建视角选择

## 一句话结论
用开放词汇检测维护在线对象记忆、以保守隐藏区域代理表示对象周边未解析占用，遮挡感知代理覆盖打分选视角；Geo-Floor 机制把对象重排序限制于几何竞争力候选；Replica/Matterport3D 五档帧预算下 Completion 与 Completion Ratio 一致改善（f40 时 Completion 28.52→16.x cm）。

## 要解决的问题
几何信息增益驱动的主动 3DGS 把对象隐藏区与一般未探索区同等对待，紧帧预算下全局覆盖优先导致对象重建不完整。

## 方法详解
对象记忆 + 隐藏区域代理 + 遮挡感知代理覆盖打分 + Geo-Floor 门控重排序（保留几何驱动探索行为）。

## 实验与结果
Replica + Matterport3D 统一帧预算协议（5 档）；Completion / Completion Ratio / Accuracy（5cm 阈值）；RTX 4090 24GB。

## 创新点与贡献
① 对象条件化代理覆盖打分；② Geo-Floor 在保留几何探索的同时引入对象互补观测。

## 局限与风险
不做形状补全（保守代理）；依赖开放词汇检测质量；增益集中于低帧预算；无真实机器人实验。
