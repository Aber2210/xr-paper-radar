# CVQPG：基于二次相位高斯泼溅的全息图表示

## 一句话结论
提出复值二次相位高斯（CVQPG），为每个 2D 高斯基元叠加可学习的二次相位（曲率）轮廓，首次把 3D Gaussian Splatting 拓展到全息图/近眼显示域，在同等或更少参数预算下提升全息图保真度（PSNR / CVVDP）。

## 要解决的问题
全息显示（CGH/SLM）需要既能被高效优化、又满足衍射物理的可渲染图元。传统 3DGS 的实数颜色/不透明度不足以表达光场相位与焦深；既有全息表示多依赖体素或 NeRF，缺少可学习的'焦距/曲率'自由度。

## 方法详解
1) Complex-Valued Planar Gaussian：把基元表示为复值；2) Complex-Valued Quadratic Phase Gaussian（CVQPG）：在 2D 高斯包络上叠加二次相位项，其曲率 c 为可学习参数，使每个基元天然表达一个局部焦面/波前；3) Scale-Adaptive Curvature Control：按基元尺度自适应约束曲率范围；4) Hologram Rendering & Optimization：将 GS 场景投影到 SLM 平面并优化相位；5) Curvature Warm-Up：训练初期先稳定几何、再放开曲率，避免优化陷入坏局部。

## 实验与结果
在 RGB 20%/10% 与灰度 20%/10% 多档比特率下，与 Baseline / Baseline+ 比较 PSNR/SSIM/LPIPS/FLIP/CVVDP（全息感知质量指标）。例：RGB 20% 时 CVQPG PSNR 29.450 vs 29.265（+0.185），SSIM 0.8364 vs 0.8307，CVVDP 9.203 vs 9.168，且参数更少（30,720 vs Baseline+ 33,280）；灰度 10% 时 PSNR 28.398 vs 28.076（+0.322），CVVDP 8.658 vs 8.548（+0.109）。附录含全息显示原型、运行时/显存、逐场景结果与可视对比。

## 创新点与贡献
① 把相位/焦深显式建模进高斯基元，而非事后用相位检索；② 尺度自适应曲率，让近/远基元自然落在不同焦面；③ 与现有 3DGS 优化/渲染管线兼容，可复用其基础设施。

## 局限与风险
仍依赖 SLM/衍射物理近似；计算随基元数上升；仅在受控场景验证，未见大规模复杂场景或视频时序（4D 全息）评估。
