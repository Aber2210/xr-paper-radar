# GeoScaffold：通过重建学习紧凑几何潜变量以实现高效视觉-语言导航

## 一句话结论
GeoScaffold 在训练时一次性把几何监督“内化”进 VLA 策略（深度 tokenizer + 几何 query tokens 重建深度/连通性/可达性），推理时丢弃脚手架，在连续 VLN 基准上一致优于纯视觉导航器，适合轻量边缘部署。

## 要解决的问题
流式 Video-LLM 导航策略继承 2D 预训练的弱 3D 几何先验；现有几何增强在推理时持续付费（深度传感器/3D 编码器/每步感知调用）。

## 方法详解
训练时学紧凑深度 tokenizer（冻结）；用少量可学习几何 query tokens 微调策略，让其隐状态重建导航关键几何；脚手架（tokenizer/生成器/重建头）训练后丢弃，主干与动作接口不变。

## 实验与结果
VLN-CE 基准一致优于领先纯视觉导航器；推理效率对比几何增强方法；主干通用性；实现细节完整。

## 创新点与贡献
训练时付费、推理时免费的几何内化；脚手架隐喻；边缘部署友好。

## 局限与风险
仍属 VLN（具身导航）而非 XR 直接应用；几何仅重建深度/连通性/可达性；未在真实机器人长时验证。
