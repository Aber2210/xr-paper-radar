# P³-WAM：第一视角灵巧操作的统一世界-动作模型（感知-预测-规划）

## 一句话结论

把「感知-预测-规划」三件事塞进同一个模型：以紧凑结构化 3D 动作表示注入预训练视频扩散 Transformer（mixture-of-transformers 架构），Perceive 从视频重建 articulated 手部运动与相机轨迹、Predict 生成动作条件视觉未来、Plan 联合生成动作轨迹与预期视觉后果；统一训练使三模式互益，三任务均超专用 SOTA，且规划出的人手动作可迁移到真机灵巧手。

## 要解决的问题

第一视角灵巧操作涉及感知（手/相机 3D 运动）、预测（动作导致什么视觉变化）、规划（为达成目标该做什么）三种能力。已有工作各自为政：世界模型善于时空先验但语义推理弱，VLA 善语义但缺世界动态 grounding。如何用一个模型同时具备三能力且互相增强，是开放问题。

## 方法详解

- **耦合视频-动作 Transformer**：把紧凑、结构化的 3D 动作表示（MANO 参数、空间关节位置、时序运动）集成进预训练视频扩散 Transformer，采用 mixture-of-transformers（模态特定适配 + 共享权重）架构；附录详述共享权重、注意力与 token 编码、掩码输入构建与时序模式采样、动作目标。
- **三模式**：
  - **Perceive**：从视频重建 articulated 手部运动与相机轨迹；
  - **Predict**：在给定动作下生成视觉未来；
  - **Plan**：以初始图像 + 语言指令 + 可选视觉目标为条件，联合生成动作轨迹及其预期视觉后果。
- **统一训练**：三模式共享同一模型，实验表明统一训练同时受益于三者。

## 实验与结果

- 先验证统一训练对每个模式的收益（Sec 4.1），再在各自任务上与专用基线对比（Sec 4.2–4.4）：**Perceive / Predict / Plan 三任务均超过 SOTA 基线**。
- 规划生成的人手动作可迁移到真实灵巧机器人执行（机器人部署实验）。
- 附录含附加方法细节与更多实验。

## 创新点与贡献

1. 单一模型内统一 perceive-predict-plan 三模式，且证明统一训练互益（而非互相掣肘）。
2. 结构化 3D 动作表示 + 视频扩散先验的耦合方式（MoT 架构），为「动作条件世界模型」提供了可复用的集成方案。
3. 人手动作 → 真机灵巧手迁移的端到端演示。

## 局限与风险

- 单目视频估计全局 3D 手部位置本质歧义（作者自述）；触觉/深度传感可提供更强几何约束。
- 机器人实验为开环执行；闭环反馈与更长时程鲁棒性待验证。
- 披露：生成式 AI 参与了稿件撰写/编辑、figure 与研究代码开发调试。
