# 细看何时划算？用于细粒度识别的简单 FoVT

## 一句话结论
把 foveated refinement 压成「无特征复用、无蒸馏、无选择调度」的单主干单次非递归 pass，并用每数据集 26 组配置的受控协议把增益拆成 foveation 项与 glance loss 训练项：算力 0.56×、最小目标三分位最高提升 4.18 点，但作者直言换来的是算力而非精度。

## 要解决的问题
细粒度识别依赖输入分辨率，但均匀高分辨率 ViT 对全图每个区域都按该分辨率计算：448px 相对 224px 使投影与 MLP 开销增至 4 倍、注意力乘积增至 16 倍，即使判别性细节只占一个翅膀大小。已有 coarse-to-fine、token 缩减与混合分辨率设计混入特征复用、学习门控、策略网络或外部打分器，且常以单次 run 和不同协议比较，难以判断这些组件是否必要、以及选择性细化在什么条件下才真正有收益。

## 方法详解
FoVT 用同一个 DINOv2 ViT-S/14 主干分两阶段：先将 448px 输入双线性降采样成 224px 的 glance 过 backbone，取最后一层 class token 的 head 平均注意力作为无参数显著性图，选 Top-K 个 cell（训练固定 K=64）；再从 448px 图像重新嵌入这 K 个 cell 对应的 4K 个细 token 替换原粗 token，组成 n+3K 长度的混合分辨率序列由同一主干重分类。训练目标为 CE(ℓf)+λ·CE(ℓg)（λ=0.5、label smoothing 0.1），选择索引 detach 不回传梯度。推理时 K 可无重训改变，并可加 confidence gate 只细化 glance 最不自信的约 19–24% 图像；全部比较采用两 seed、图像级配对 bootstrap 与 Holm 校正的精确 McNemar 审计。

## 实验与结果
- 注意力选 cell 相对随机选择 = 最高 +2.45 points（五个数据集整体）
- 注意力选 cell 相对随机选择 = 最高 +4.18 points（最小目标三分位）
- K=64 的 transformer 成本 = 17.68 GMACs（均匀 448px 的 0.56×）
- A100 上批 32 推理 = 0.56 ms/image（均匀 448px 为 0.75 ms/image，−26%）
- 峰值训练显存 = 4.64 GiB（均匀 448px 为 6.35 GiB，−27%）
- 等成本增益相关性 = Spearman ρ = 0.9（选择增益）/ ρ ≈ 0.87（336px 以上分辨率余量）

## 创新点与贡献
- 把 foveated refinement 压缩到「无特征复用、无蒸馏损失、无选择调度」的单主干单次非递归 pass，并用两 seed、每数据集 26 组配置的受控协议把相对 448px 的增益分解为 foveation 项与 glance loss 训练项，指出 foveation 换来的是算力而非精度

## 局限与风险
- 只用 ViT-S/14 一个主干、两个 seed，区间只反映测试集抽样而非训练方差
- CF-ViT 为移植版且仅在 α=0.25 比较
- rank gate 需要测试池，可部署阈值门实现成本最多超目标 2.7%
- 在 Stanford Dogs 上等成本增益不显著，Aircraft 对推理预算高度敏感（K=128 掉 0.69 points）
