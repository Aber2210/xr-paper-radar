# PointX：通过查询表面点获得多视角一致的本征属性

## 一句话结论
把「多视角一致」从损失项或后处理变成表示层面的必然结果：预测单元是表面点而非像素，沿 track 池化后再解码一次，同一点跨视角分歧按构造为零——ETH3D 逐视角 albedo RMSE 0.095 vs MVInverse 0.161、法向 2.9° vs 9.6°，且精度随视角数增加而提升。

## 要解决的问题
逆渲染要从图像恢复 albedo、roughness、metallicity、normal 与 irradiance，但分解本身有歧义，同一像素可有多种自洽解释。逐像素方法在每张图上独立消歧，导致同一表面点在各个视角得到不同分解：重打光会随视角闪烁、在一张图上的编辑传不到下一张、贴到重建上的材质出现接缝。绑定 3D 表示（per-scene 拟合或网络预测）虽能一致，但所有视角继承该表示的误差，且拟合需数分钟到数小时；多视角/视频网络只做跨视角注意力，仍逐视角独立解码，对应像素照样会分歧。

## 方法详解
PointX 把预测单元从像素换成 3D 表面点，直接学 (a,e,r,m,n)=f(p; I_1..I_N)。几何由冻结的 VGGT-Ω 一次前向给出每视角相机、深度与逐像素置信度，并把所有量重表达到对称的 mean-frame（原点为相机中心均值、前向为视线均值、水平/垂直正交化），使任何视角都不被特殊化；同时去掉 VGGT 的 camera token、所有视角共用同一组 register token，使 transformer 对视角顺序等变。多视角 transformer（VGGT-Ω 初始化后微调）做帧内与全局注意力交替，每像素额外拼入 10 个几何通道（6D Plücker 视线、VGGT-Ω 估计的 3D 点、该点的 log 置信度），经零初始化 patch embedding 加入，保证初始化时预训练特征不变。输出 1/16 分辨率特征，由 DPT 解码器上采样到全分辨率；token map 由「上采样特征线性投影」与「该像素 9×9 RGB 窗口线性投影」相加构成。给定查询点 p，用相机投影得到其在各视角的位置 x_v，并按 c_v=1/(1+δ_v/τ)、δ_v=‖X_v[x_v]-p‖/d_v（τ=1%）估计可见置信度，被遮挡或落在相机后方则 c_v=0。随后沿 track 做置信度加权平均 z=Σ w_v t_v[x_v]，w_v=c_v/Σc_u，这一步无任何可学参数。各属性由独立两层 MLP 从 z 解码一次（albedo/roughness/metallicity 过 sigmoid，irradiance 以 log(1+e) 表示后 softplus，normal 归一化到单位球），要出逐视角法向图时只需把 n 从 mean-frame 旋到该视角相机系。像素查询是特例 p=X_i[q]，track 也可来自稠密匹配器 RoMa-Ω，此时 c_v 再乘匹配置信度。训练只用像素查询，track 随机取自 GT 几何投影、VGGT-Ω 投影与 RoMa-Ω 三类，损失为 albedo/roughness/metallicity/log-irradiance 的 L1、法向余弦距离、以及 16×16 窗口上的多尺度梯度损失；不比较不同视角预测、也不用可见性标签，一致性由构造保证。

## 实验与结果
- ETH3D 逐视角一致性（RoMa-Ω track）：albedo RMSE_r 0.095、irradiance 0.146、normal 2.9°、roughness 0.136、metallicity 0.222；MVInverse 对应 0.161/0.318/9.6°/0.382/0.270，MVID-Ω 法向 6.8°
- 表面点内本征（Table 1）：InteriorVerse albedo PSNR 25.50 / 法向 5.2°、albedo 分歧 0.083 且按构造为 0；Hypersim 上 20.32 dB 与最强基线相当
- 单图 InteriorVerse：albedo 24.09 dB（MVID 23.54）、法向 6.3°（MVID 11.3°）、LPIPS 0.101
- 八图 InteriorVerse：albedo 25.13 dB、法向 5.7°、roughness RMSE 0.084、metallicity 0.077
- 消融去掉 pooling 后精度几乎不变（25.12 dB / 5.65°），但 ETH3D 分歧从 albedo 0.095 恶化到 0.141、法向从 2.91° 到 5.24°
- 8 张 512×336 图像的推理耗时：GT track 1.6 s、VGGT-Ω track 2.0 s、RoMa-Ω track 5.8 s（A100）

## 创新点与贡献
- 把「一致性」从损失项或后处理变成表示层面的必然结果：预测单元是表面点而非像素，沿 track 池化后再解码一次，因此同一点的跨视角分歧按构造为零，无需 consistency loss、无需融合逐视角预测、也无需 per-scene 优化
- 同一模型既可直接查询点云/网格（一次一 texel 即得可路径追踪的 PBR 资产），也可逐像素查询得到逐视角图，且精度随视角增加而提升
- 对几何与对应关系的质量是「免费受益」——换成更准的 track（如 RoMa-Ω）即可提升一致性而不重训

## 局限与风险
- 一致性上限由 track 质量决定：投影 track 受深度与相机误差影响，两视角像素反投影到的本就是相邻而非同一点，thin structure 边缘尤其明显
- 换成稠密匹配器虽更好但仍非精确
- 依赖冻结的 VGGT-Ω 提供几何，几何失败会直接传导到法向与池化权重
- 未处理动态场景与非朗伯/互反射
- 训练中大量使用伪标签真实照片，albedo 与 irradiance 的分解仍受单图先验影响
