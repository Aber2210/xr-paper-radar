# HubEgo-100K：面向机器人学习的野外第一人称技能工作视频数据集

## 一句话结论
10,124 小时 / 72,754 episodes 的野外第一人称技能工作视频，12,227 名贡献者、15,548 个环境，附逐帧 IMU，但尚无策略实验。

## 要解决的问题
模仿学习训练出的机器人策略在训练场景与物体之外泛化很差，而已发表的数据 scaling 研究表明泛化随训练环境与物体多样性增长、每个环境多加演示会饱和。但跨大量环境采集机器人数据极其昂贵：DROID 用 12 个月、50 名采集者才得到 350 小时 / 564 个场景。第一人称人类视频可在野外低成本大规模录制，然而现有 egocentric 数据集多记录日常生活、厨房或实验室脚本任务，缺少真实工作场所中的技能性手工劳动；同时少有数据集同时提供逐帧惯性数据与任务、动作、语言标注。

## 方法详解
HubEgo-100K 让贡献者用头戴手机在自己工作场所或家中录制“已命名但不脚本化”的任务，v1.0 为 10,124 小时 1080p、30 fps 单目视频，配同步原生 IMU（加速度计/陀螺仪中位 99.98 Hz），覆盖 56 种手机型号、99.1% 使用超广角镜头（对角视场中位 114.3°）。采集后走九阶段 curation pipeline：头戴检测剔除未戴在头上的素材；VLM 做稠密时间分割只保留双手执行命名任务的片段；手部可见性门控用两个 VLM 组成的 panel 按 1 fps 标注每帧（无手 / 左手 / 右手 / 双手 / 不确定，不确定按无手计），丢弃手大多出画的录制并剪掉长时间无手片段；隐私检测每 2–6 秒抽帧，命中儿童、他人面部或私密文字则连带 5 秒余量剪除；episode 组装时 30 fps 直接 stream copy、60 fps 重编码为恒定 30 fps，超 30 分钟等分；随后做完整性与同步检查（帧间隔、重复帧、漂移，中位绝对漂移 0.017 s），并把传感器时间戳统一到 episode 首帧的纳秒基准；再按 56 种 task type 重新平衡小时数（中位 69.5 小时）。标注由 VLM 完成：每 episode 一个 task type（归入 30 个 work category）、35 个 action family 之一、18 个 skill group 之一、easy/medium/hard 难度、11 种 setting type 之一，外加平均 7.4 词的描述与平均 35.2 词的 step-level instruction（步骤不做时间定位）。数据按 LeRobot v3 布局发布：每 episode 一个 MP4、逐帧 parquet、一个含全部原生传感器样本的 MCAP，加 catalog 与 annotation 表，全部 episode 以 episode_index 对齐，CC BY 4.0。

## 实验与结果
- 规模：v1.0 共 10,124 小时、72,754 episodes（中位 4.9 分钟、最长 30 分钟）、41,688 recordings、1,093,194,072 帧，43.5 TB 视频 + 1.29 TB 原生传感器流
- 多样性：12,227 名贡献者、15,548 个 environments（11 种 setting type）、30 个 work category、56 个 task type、35 个 action family
- 82.6% 小时在工作场所
- 无单一贡献者超过 0.22% 小时，有效贡献者数 5,666，贡献者中位录制 21.3 分钟（Ego4D 平均约 3.9 小时/人）
- 质量估计（模型估计）：至少一只手出现在 94.7% 采样帧、双手 76.3%，on-task share 96.9%（按小时加权）
- 70.6% 的 episode（占 83.0% 小时）在 ≥90% 采样帧中可见手
- 长尾：描述使用 1,429 个动词词元与 3,709 个名词词元
- 随机顺序下最后 10% 小时仍新增 356 名贡献者、570 个 environments、约 39 个动词与 84 个名词词元
- 34.5% 小时被标为 hard
- 同类对比（Table 1）：其他数据集人数 9–2,087（Ego4D 931、Ego-Exo4D 740、EgoVerse 2,087、DROID 50 名采集者），地点数 45–610，v1.0 为 12,227 人与 15,548 环境
- 没有任何策略学习实验：正文未给出 policy 成功率或下游基准结果，作者把训练基线列为下一步工作

## 创新点与贡献
- 相对 Ego4D、EPIC-KITCHENS-100、Ego-Exo4D 等以日常生活、厨房或实验室脚本任务为主的数据集，它把“真实工作场所的非脚本技能劳动”作为主体（83% 小时在工作场所），并同时给出逐帧 IMU、任务/动作/语言标注与 per-episode 质量信号
- 与 Egocentric-10K/100K 相比，实质差异不是时长而是逐轴量化多样性（贡献者、环境、任务、动作、词汇、设备）并报告 evenness、有效类别数与长尾增长曲线，把“多样性”变成可复算的指标
- 文章还把六个与策略性能相关的数据属性逐一映射到本数据集的测量值，使数据集设计与已发表的 scaling 证据直接对齐

## 局限与风险
- 最关键的是 v1.0 没有任何策略学习实验：作者在 Discussion 中写明下一步才是在数据上训练基线（视觉编码器预训练、与机器人数据 co-training、在 contributor-disjoint 划分上评测），因此多样性对 policy 性能的实际贡献尚未验证
- 手部可见性与 on-task share 都是模型估计而非人工核验
- 采集受限于单目手机（无深度、无 3D 手部位姿，这些被列为后续标注层）
- 隐私处理（剪除儿童/他人面部/私密文字、剔除对他人实施的照护任务、删除音频与位置）会系统性缩小可用数据并可能引入分布偏差
- 按 task type 重新平衡后任务分布不再反映真实世界出现频率，作者明确提醒需在目标使用条件下重新评估
