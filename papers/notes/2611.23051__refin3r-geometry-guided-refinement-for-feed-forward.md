# Refin3R：面向前馈三维重建的几何引导精化

## 一句话结论
把几何引导精化从 3D 点 patch 搬到图像网格的 per-view depth，ScanNet++ AUC@1cm 25.6→33.7（对 GGPT 基线）。

## 要解决的问题
前馈重建模型（DA3、Pi3X、VGGT 等）一次前向即为所有视图输出稠密 point map，速度快、可扩展，但完全由学习先验回归、没有三角化等显式几何约束，导致跨视图不一致且局部精度不足。SfM 有显式多视约束、点准但稀疏，在宽基线/低重叠下脆弱。已有结合方式各有缺陷：几何条件化模型只把位姿/深度当辅助输入，depth completion 逐视图独立处理，GGPT 虽在 3D 空间联合精化，但只精化 SfM 覆盖到的局部立方块，纹理缺失面与单视图可见区域几乎得不到改善。

## 方法详解
输入两路互补重建：冻结的多视前馈 backbone（DA3 或 Pi3X）给出相机与稠密深度 D^ff；GGPT 的 SfM 管线（RoMa v2 匹配 + sparse bundle adjustment + 多视 DLT 三角化）给出部分深度 D^sfm 与有效掩码 M。两者统一表示为沿像素射线的深度并取对数 ζ=log D 以压缩动态范围；每像素几何通道为 [r_i, ζ^ff, ζ^sfm, ζ^sfm-ζ^ff, M]，其中显式给出两路重建的差值。从 backbone 四个中间层取 image token，经端到端训练的 DPT head 融合并上采样成图像分辨率几何感知特征 F。2D 分支是 ConvNeXt block 构成的 6 尺度 U-Net，输入逐像素几何通道拼接 F，预测 log-depth 残差与 confidence logit，输出 ζ^2D=ζ^ff+Δζ^2D，把 SfM 深度沿图像传播到无三角化像素。3D 分支按 MoGe-3 在每个视图的“图像坐标 + log 深度”上建体素网格，把所有视图的 SfM 点体素化进去（仅保留位于相机前方且投影落在图像内的点），用 5 级 residual sparse 3D convolution 的 U-Net 聚合 3D 邻域，逐占用体素预测残差与 confidence，并只在 own voxel（本视图三角化点）读出，因而能引入被本视图遮挡、仅由其他视图三角化的点。两分支在 stride 8 与 16 两个尺度、特征宽度相同时做双向交互：Inject 把像素处图像特征广播给该 pixel column 的所有体素（MLP 融合），Gather 把该列的 own voxel 特征沿深度平均池化、LayerNorm 后以残差加回图像特征（只用 own voxel，排除仅由他视图构成的体素）。Spatial fusion 用动态 SPN 在 linear depth 上迭代 6 轮：SfM 观测像素上以 confidence β 把 D^sfm 与 D^3D 混成 anchor a_i，2D 分支的第二个 decoder 预测 K=5 邻居的 affinity、offset 与 anchoring weight η，最终 D^pred=D^(6) 用 SfM 相机反投影为 point map。损失为 confidence-weighted L1（c=1+exp(ĉ)≥1，α=0.2）监督最终深度与 2D 分支，3D 分支只在 own SfM 像素用纯 L1。训练 200K iter、4×A6000、AdamW lr=1e-4，数据为 ScanNet++/TartanAir v2/UnrealStereo4K/BlendedMVS，按 covisibility 约束随机游走采 3-16 视图。

## 实验与结果
- ScanNet++（域内，AUC@1 cm %）：4/8/16 视图 33.7/39.6/45.2（Pi3X 版）vs GGPT 25.6/29.5/34.8
- DA3 版 31.5/37.5/43.4 vs GGPT-DA3 21.6/27.4/31.8
- ETH3D（跨域）：16 视图 AUC@1 cm 53.3（Pi3X）/53.6（DA3）vs GGPT 39.4/32.6
- AUC@5 cm 76.4 vs 69.1
- Tanks&Temples 4 视图 AUC@1 cm 17.1（Pi3X）/15.6（DA3）vs GGPT 16.1/14.9
- 域外 4D-DRESS @1 cm 80.2 vs GGPT-Pi3X 64.6、VGGT-Ω 42.0
- MV-dVRK @1 mm 72.3（DA3）vs GGPT-DA3 67.0
- 效率（ETH3D，RTX A6000，16 视图）：0.86 s/5.1 GB vs GGPT 12.92 s（约 15 倍）/6.2 GB、Pi3X 1.88 s、Any2Full 3.17 s
- 含 DA3 encoder 时 1.58 s
- 消融（ScanNet++ / ETH3D 平均，AUC@1/@5）：DA3 1.0/6.9、GGPT 27.0/55.5 → 仅几何 2D 分支 34.3/64.7（ETH3D 42.8/67.4）→ 加图像特征 35.4/66.3 → 加 3D 分支与交互 36.7/67.2 → 加 spatial fusion 37.5/67.8（ETH3D 47.6/71.1）

## 创新点与贡献
- 把几何引导精化从“3D 点 patch”搬到“图像网格上的 per-view depth”，从而能借用前馈 backbone 的稠密语义/几何特征，把 SfM 几何外推到其覆盖之外（弱纹理面、单视图区域）
- 用稀疏体素聚合所有视图的 SfM 点，并通过 pixel-column 的 Inject/Gather 双向交互与 2D 分支在同一坐标系对齐，最后用 SPN 把 3D 证据 anchor 后空间传播，形成“稠密先验 + 多视证据 + 自适应融合”的新架构，而非在 GGPT 上调参

## 局限与风险
- 依赖 SfM 前端（RoMa v2 匹配 + BA + 三角化），其失败与外点会直接传入，宽基线/低重叠场景的上限仍受前端约束
- 相机参数固定不优化，精度上限被冻结 backbone 与 SfM 相机限制
- 效率表只计方法本身，不含 SfM 前端时间（正文明确说明各方法共享同一 SfM 输出），因此端到端延迟远高于 0.86 s，仍是离线多视图管线
- 正文未给出失败案例统计与逐场景最差表现
