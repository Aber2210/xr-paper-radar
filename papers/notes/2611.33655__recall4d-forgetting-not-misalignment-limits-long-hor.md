# Recall4D：限制长时程前馈 4D 重建的是遗忘，而不是错位

## 一句话结论
用 oracle 实验证伪「窗口间配准漂移」假说（换 GT 位姿 EPE 1.568 vs 1.569 无差别），把长视频 4D 跟踪的瓶颈定位为「遗忘」，改用持久世界状态 + 存储坐标判可见性——PointOdyssey EPE 1.569→1.168，1,000 帧 0.889（−43%），2,000 帧 4.634 且快 7.6×、显存 < 25 GiB。

## 要解决的问题
前馈 4D 跟踪器能在短视频上一次性回归相机、深度与点轨迹，但把窗口串起来处理长视频就会退化：PointOdyssey 上 Point4D 的生存率随视频变长急剧下降。通常的解释是窗口间 Sim(3) 配准漂移（实测平均旋转差 1.2°、尺度差 3.4%），于是自然的补救是更好的对齐或回环。作者用 oracle 实验证伪了这条路径：把每个窗口间变换换成真值位姿后，EPE 仍是 1.568，与基线的 1.569 无差别；真正的误差来源是「遗忘」——静态点离开视野后仍被反复从看不到它的窗口重新预测，静态点 EPE 从可见时的 1.25 升到 400 帧未见后的 2.30，静态点出框时的 EPE 高达 1.799。

## 方法详解
训练无关框架，冻结 backbone（Point4D），不动网络权重。①持久世界状态：用现成分割模型取首帧前景 mask，mask 外的查询视为静态，$\mathcal{B}=\{i:M_1(\mathbf{u}_i)=0\}$，每点维护 $s_i=(\hat{\mathbf{x}}_i,n_i)$；可见性用「存储的世界坐标」而非最新预测投影判断，$\mathbf{p}_i^t=R_t^{\top}(\hat{\mathbf{x}}_i-\mathbf{c}_t)$，$v_i^t=\mathbb{I}[(\mathbf{p}_i^t)_z>0\land\pi(K_t\mathbf{p}_i^t)\in\Omega]$；每个窗口在 $m=4$ 个均匀关键帧上，对可见点以其存储位置作 3D query 解码得世界坐标观测 $\mathbf{x}_i^{\tau}=G_k^{-1}(\mathcal{D}(\mathcal{E}(C_k),G_k(\hat{\mathbf{x}}_i),\phi_i)_\tau)$，再做 running mean 融合 $\hat{\mathbf{x}}_i\leftarrow(n_i\hat{\mathbf{x}}_i+\mathbf{x}_i^{\tau})/(n_i+1)$；不可见点保持原值，每帧输出直接取状态，从而既省掉对已见几何的重复解码，又避免把新噪声写回已恢复的几何。②稀疏锚点 + 几何蒙皮：每个前景实例用 FPS 选 $A_o\le32$ 个代表锚点（实际 24–32）由冻结解码器跟踪；每个查询取同实例 $H=6$ 个最近锚点，权重 $w_{ij}=\exp[-(d_{ij}/\lambda_i)^2]/\sum_{\ell}\exp[-(d_{i\ell}/\lambda_i)^2]$、$\lambda_i=2\min_\ell d_{i\ell}$，输出 $\mathbf{y}_i^t=\bar{\mathbf{x}}_i^{(k)}+\sum_j w_{ij}(\mathbf{a}_j^t-\bar{\mathbf{a}}_j^{(k)})$；窗口 $L=48$、重叠 8（步长 40），窗口间用剔除前景后的 trimmed Sim(3) 配准，前景 mask 由 SAM 3.1 给出。

## 实验与结果
- 仅保留未见点最后位置（不改模型）：PointOdyssey EPE 1.569→1.168（−26%），SR 0.193→0.260
- Recall4D（1,000 帧）：EPE 0.889（−43%），静态点出框 EPE 1.799→0.433（−76%）
- 2,000 帧：EPE 4.634、SR 0.362、264 s（Point4D 5.334 / 0.178 / 2,019 s，快 7.6×）
- 500 帧：EPE 0.836、74.9 s（Point4D 0.979 / 582.1 s）
- 2,000 帧约 4.4 分钟完成，峰值显存 <25 GiB
- 对照：GT 位姿对齐 EPE 1.568 vs 基线 1.569（0%，证伪配准漂移假说）

## 创新点与贡献
- 相对把长视频退化归因于配准漂移并加回环/更好对齐的路线，本文用 oracle 对齐实验证伪该假设，指出「遗忘已观测几何」是主因
- 再用零训练、零参数的「持久状态 + 少量锚点蒙皮」同时提升精度与速度——不是造新跟踪器，而是修好现有跟踪器的记忆与冗余
- 诊断本身比方法更具迁移价值：同一插件在 5 个 backbone、3 类任务上都成立

## 局限与风险
- 1,500 帧之后所有方法绝对误差仍很高（EPE>4.5），训练无关插件无法修正 backbone 本身的运动预测误差
- 静态/动态划分依赖首帧分割 mask，之后进入画面的前景不会被建立状态
- 可见性只判视锥内、不处理遮挡
- 评测以合成 PointOdyssey 为主，真实视频仅有定性结果
