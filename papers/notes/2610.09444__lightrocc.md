# LighTROcc：基于实例中心 3D 高斯的轻量 4D 占据预测

## 一句话总结
用紧凑的"实例中心 3D 高斯"表示可移动物体，从环视相机历史预测 4D 占据（当前+未来），避免密集体素/BEV 的高成本，并保持实例身份与时间一致性。

## 问题背景
- 环视相机 4D 占据预测以往依赖密集体素/BEV，成本随空间分辨率与预测时域快速增长；且不显式保持物体身份 → 实例一致性差。

## 方法
- **实例中心表示**：用紧凑学习查询集表示可移动物体（GMO），而非密集时空特征；每查询预测置信、深度、高斯混合参数、未来轨迹。
- **注意力引导前向提升（forward lifting）**：把查询定位到 3D；用 3D 高斯混合建模物体；传播到未来帧。
- **Transformer Query Decoder**：共享图像编码器提取多尺度特征；为令牌补 2D 正弦位置、相机参数+自车位姿嵌入、相机 ID 嵌入、时间嵌入；N_q 学习查询经交叉/自注意力精炼。
- 设定：T_p=2 过去帧，T_f=4 未来帧（0.5/1.0/1.5/2.0 s）。连续高斯体光栅化为占据序列。

## 实验与结果（关键数字）
- 数据：nuScenes + nuScenes-Occupancy（700 训练 / 150 评估；序列含 2 过去+1 当前+4 未来占据）。
- 范围 [−51.2,51.2]²×[−5,3] m，512×512×40 网格，体素 0.2 m。
- 指标：体素 IoU + 实例 AP（IoU 0.1/0.2/0.3 均值）；中心定位 AP_ctr / Recall_loc（1m）。单张 RTX Pro 6000 评估。
- 结果：比密集方法更轻量紧凑，定性更准捕捉物体位置与实例一致性。

## 贡献与局限
- 贡献：把"实例中心 3D 高斯"引入占据预测，兼顾轻量与实例一致性；注意力引导提升替代密集特征。
- 局限：主体面向自动驾驶基准；XR 迁移需替换为头显环视/深度输入；长时域（>2s）预测未覆盖。
