# TrajRealm：具有多样动态的大规模点跟踪数据集

## 一句话结论
首个公开的千万帧级合成点跟踪数据集：游戏世界补真实感与交互多样性、具身仿真补机器人与室内导航，带前景物体与环境表面的持久 3D 轨迹：10M 相机帧 / 13,972 序列，微调后 AJ3D 最高提升 7.83 点。

## 要解决的问题
通用点跟踪需要大规模、动态多样的训练数据，但现有数据集难以同时满足丰富动态内容、精确场景几何与足够规模：真实视频标注轨迹与 3D 监督成本高，渲染引擎场景又常出现不自然运动、资产细节不足、室外背景仅用纹理面片代替真实 3D 几何。

## 方法详解
从现代游戏的丰富环境与运动系统（TrajRealm-Game，手工游玩或脚本控制，ReShade 插件采渲染输出、按引擎插件采轨迹而不抽取原始资产）与具身仿真（TrajRealm-Embodied，操作与室内导航数据重渲染）构建统一表示：RGB + 深度 + 相机内外参 + 持久 2D/3D 点轨迹（含前景物体与环境表面）+ 局部 SE(3)。轨迹覆盖单视与多视序列，附有效性/可见性掩码，并用重投影、深度一致与跨视一致性做几何校验。另建 TrajRealm-Bench（Interaction / Locomotion 两大类共 8 子类）。

## 实验与结果
- 总规模 = 10M 相机帧（6.93M 同步帧，13,972 条序列）
- 来源构成 = 7.11M 相机帧（Game）/ 2.89M（Embodied）
- 局部 SE(3) 标注 = 2,927 条序列 / 4,270,937 相机帧
- TrajRealm-Bench = 104,306 帧（8 个子类）
- TAPIP3D 微调后 AJ3D = 最高 +7.83 百分点（Dynamic Replica 53.70→61.53）
- TAPIP3D 微调后平均 = 57.16（原始 51.80，+5.36 百分点）

## 创新点与贡献
- 首个公开的千万帧级合成点跟踪数据集：用游戏世界补足真实感与交互多样性、用具身仿真补足机器人与室内导航场景，并同时给出前景物体与环境表面的持久 3D 轨迹与几何标注
