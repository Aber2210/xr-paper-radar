# EgoHand：从第一人称视频进行单目 3D 手部重建

## 一句话结论
NVIDIA 以 14M 三源语料统一到 SOMA-Hand 表示 + 相机感知双分支（CLIFF+RayPE），把第一视角单目 3D 手重建推到 zero-shot SOTA（H2O MPJPE 13.12mm，较 HaMeR 降约 32%；HOT3D 18.82 vs 58.00），推理 9ms/帧并以 OpenMDW 许可开源。

## 要解决的问题
带 3D 手部标注的第一人称人类视频是 VLA/世界动作模型的可扩展监督来源，但跨多样手部外观、背景、物体与相机配置获得可靠 3D 标注仍困难；推理时还需从裁剪图中恢复相机相对的手部位姿并保持图像对齐，同时效率要足以处理上万小时视频。

## 方法详解
模型采用 SOMA-Hand（配 MHR shape backend，每手 25 关节，骨骼尺度与表面形状解耦）作为参数化表示；DINOv3 ViT-H/16+ 编码 2D 手部裁剪图，3D 分支结合 CLIFF bounding-box conditioning 与 RayPE ray positional encoding 预测 pose、shape 与 wrist translation；独立 2D 关节预测分支通过 2D-3D 对应求解（重投影误差 + 正则项）修正横向平移并保留 3D 分支深度，联合训练把图像对齐与几何耦合。数据侧构建 14M 图像语料：NVIDIA Omniverse 合成（约 49 小时）、授权 in-the-wild 视频（约 63 小时，水平 FOV 101-165°，含针孔与鱼眼）、微 marker 多相机 MoCap 真值（约 16 小时，Noitom/Bones），全部统一拟合到 SOMA-Hand 表示；另提供检测-裁剪-批推理-自适应平滑-世界坐标转换的生产级推理管线。

## 实验与结果
zero-shot 评测（三个数据集均不在训练集）：HOT3D 2.11 小时、H2O 1.06 小时、ARCTIC 0.23 小时，均 30 fps；指标为 mean/p90 的 MPJPE、PA-MPJPE、RTE、2D EPE 与加速度误差。H2O：EgoHand（带平滑）MPJPE 13.12 mm vs HaMeR 19.35 / HaWoR 17.78 / WiLoR 17.77 / Dyn-HaMR 19.32；RTE 25.63 vs 30.70-37.25；加速度误差 1.90 vs 2.82-4.53 mm/frame²；WiLoR 的 PA-MPJPE（6.06 mm）与 2D EPE（8.96 px）最低。HOT3D：MPJPE 18.82 vs HaMeR 58.00 / Dyn-HaMR 58.16，五项指标全优。ARCTIC：MPJPE 17.21 vs HaMeR 26.44 / Dyn-HaMR 26.60；相对 HaMeR 降 34.9%（MPJPE）、51.4%（RTE）、67.5%（加速度）。延迟：RTX PRO 6000 上 9.01 ms/帧（含后处理共 10.87）；L40 上推理 18.35 ms vs WiLoR 27.43、HaMeR 35.31、HaWoR 26.64、Dyn-HaMR 总 177.06 ms。消融（40k 步、无平滑）：RayPE 使 H2O MPJPE 18.45→15.74 mm；CLIFF 18.45→16.06；2D 分支使 MPJPE 15.85→13.31、PA-MPJPE 8.24→6.97、2D EPE 12.67→9.51。人工偏好盲评（3 个公开数据集各 200 片段 × 3 名评分者 = 1800 评）：EgoHand 在 77.0% EgoDex、95.5% Xperience-10M 片段获多数偏好；在高质量标注的 EgoStandard 上 91.0% 为平局/无差异。

## 创新点与贡献
1. 相机感知双分支设计：CLIFF+RayPE 保留裁剪几何上下文，2D 关节对应求解精化相机空间手部放置
2. 14M 三源数据（合成 + in-the-wild + MoCap）统一到 SOMA-Hand 表示的标注拟合管线，兼顾多样性与监督质量
3. 生产级推理管线：鱼眼虚拟针孔重采样、自适应时序平滑、ViPE 相机轨迹驱动的世界坐标转换、OSMO 调度，面向超 10,000 小时视频
4. 以 OpenMDW 许可开源模型与代码，允许免费商用

## 局限与风险
- 单目深度尺度歧义未解决，无外部相机轨迹时输出仅为相机相对坐标
- 严重遮挡下手部重建仍困难
- 依赖手部检测框与相机标定质量，误差会向上游传播
- 部分训练数据为授权视频，无法完整公开

## 与文献库的关系
在 HaMeR、WiLoR、Dyn-HaMR、HaWoR 的单目/视频手部重建路线上，以相机感知 + 数据统一表示实现第一人称场景 SOTA 与约 2 倍于 WiLoR 的推理速度；首次把千万级多源语料统一到 SOMA-Hand 供手部重建训练。

## 可复现性
模型与代码以 OpenMDW 许可公开：HuggingFace nvidia/EgoHand-v1（模型）、NVIDIA IsaacCapture 仓库（推理）、NVlabs/GEM-X（训练）；评测数据集 HOT3D/H2O/ARCTIC 为公开数据，训练用授权视频不公开。

## 行动建议
VLA/世界动作模型的手部监督数据生产可直接采用（HuggingFace nvidia/EgoHand-v1 + IsaacCapture）；XR 手部追踪可关注其 ViPE 相机轨迹驱动的世界坐标输出。边界：单目深度尺度歧义未解、严重遮挡仍困难、授权训练视频不公开。
