# VideoRNG：从生成式视频模型提取可重光照神经高斯

## 一句话结论
视频生成先验 + 可重光照神经高斯 + depth anchoring，首次从文本/单图产出可路径追踪重光照的完整资产：重光照 PSNR 25.47 对 LSRM 22.53，505 人偏好率 57.75%。

## 要解决的问题
现有文本/图像到三维生成被输出表示卡死：要么是带 PBR 贴图（base color、roughness、metallicity）的网格，要么是把光照烘焙进颜色的 Gaussian 辐射场。前者紧凑可解释，却无法表达外观来自细几何与复杂光传输的物体——论文点名毛皮、羽毛、苔藓、密集植被、蜘蛛网；后者换环境光后高光与自阴影全错。神经外观路线（RNA、8DNA）能学方向性响应而不绑定解析 BRDF，但要求网格几何已知；RNG 把神经方向外观挂到 Gaussian 上，却要逐物体用数百张一致观测单独拟合，不能从文本或单图生成；VideoNeuMat 证明视频先验可提供观测，但只处理平面材质样本。训练层面还有失效：把预测深度与外观放进同一渲染损失联合优化时，降误差的梯度既改外观也移动中心，外观变糊，加深度损失也救不回（24.49→25.39 dB）。此外 1024² 下百万级 Gaussian 的显存与多卡负载不均使高分辨率重建工程上不可行。

## 方法详解
两阶段。阶段一用 flow matching 微调预训练 latent video diffusion（Wan），训练集为 22K 条 TexVerse 资产渲染的带字幕转台视频（3 epoch、128 卡）；输入文本或单张正面照片，输出 F=81 帧、1024² 的 RGBA 转台：35 mm 等效焦距（FOV 49.1°）、距原点 1.5、零仰角，物体绕竖轴一周，影棚光固定在世界坐标。阶段二取 29 帧，经因果视频 VAE（时间压缩 4、空间压缩 8）编码为 8 个 16×128×128 latent，每个 latent 一张关键帧定义射线。重建骨干为 1.3B 视频 DiT（30 block、宽 1536），去噪头换成线性像素头：每 token 覆盖 2×2 latent patch，输出 16×16 像素块、每像素 41 通道（1 深度 logit、3 对数尺度、4 四元数、1 不透明度 logit、32 维外观 z_i）；patch embedding 另接 8 通道（6 个 Plücker 坐标 + 方位角 sin/cos），初始化为零。前景 token 只保留含前景的 patch，背景在首个 attention 前删除并保留原 RoPE（前景占 21.6% 像素、24% token，32,768→7,937）。每前景像素沿自身射线发一个 Gaussian：μ=o+d̂r，d̂=d_min+(d_max−d_min)sigmoid(w)，尺度指数化截断、四元数归一化、不透明度剪除 <0.01，8 个 latent 的 Gaussian 直接拼接，1024² 下每物体 1–6M（均值 1.8M）。核心为 depth anchoring：渲染用真值深度 d* 放中心，深度头单独监督，L=L_img(R(d*,η),I*)+λ_d L_d(d̂,d*)+λ_α L_α(α̂,α*)+L_reg；L_img=0.8L2(sRGB)+0.2LPIPS+0.2(1−SSIM)，λ_d=3.0、λ_α=1.0，另加 0.2/0.01 弱二值化正则，参考图与预测在随机灰背景合成。共享解码器 9 层 MLP、宽 512，输入 92 维（两方向局部系切平面分量各 L=6 傅里叶编码共 26 维、半向量 L=1 六维、两方向法向分量 2 维、32 维 z_i），输出 lit/shadowed 两组 RGB，按追踪透射率混合 c_i=Σ_ℓ E_ℓ[T_iℓ f_lit+(1−T_iℓ)f_shd]，比二值选择在 15K 步高 0.96 dB（30.62 vs 29.66）。渲染用无排序随机 Gaussian 光线追踪、训练用其可微版。训练后蒸馏为 4 层宽 64 学生（65,536 样本/步、Adam 6K 步、1e-3→1e-5 余弦，约 2 分钟/物体，师生差 48–49 dB）。LRM 先 256² 跑 422.3K 步再 1024² 跑 443K 步，256 块 A100、每卡一资产、AdamW 恒定 2e-5；按前景 token 数分 4 桶，每步期望最大 Gaussian 数 6.1M→3.1M，吞吐 1.7×。

## 实验与结果
- 深度监督策略消融（256²，预测深度下新视角+新光照）：depth anchoring 29.22 dB / SSIM 0.863 / LPIPS 0.064，对比仅渲染损失 24.49 dB / 0.759 / 0.162、渲染+深度损失 25.39 dB / 0.779 / 0.148，即比联合深度监督高 3.83 dB
- 文本条件生成 105 个物体（四视图）：CLIP-T 28.1、R@1 0.81、R@5 1.00、PickScore 20.59、ImageReward −0.19，全部领先最强基线 LGM（25.9 / 0.74 / 0.99 / 19.76 / −0.73）
- 重光照（50 个复杂验证物体、3 张新环境贴图）：PSNR 25.47、SSIM 0.870、LPIPS 0.097，对比 LSRM 22.53 / 0.834 / 0.125 与 TRELLIS.2-4B 20.68 / 0.793 / 0.154
- 真值视图重建（50 物体）：输入光照 26.25 dB / LPIPS 0.138，新光照 25.99 dB / 0.154
- 对应 TRELLIS image-large 21.20 / 0.264 与 Pixal3D 21.96 / 0.207
- 人类偏好研究 505 名被试、每人 30 题：VideoRNG 获 57.75% 选择，LGM(MVDream) 18.85%，配对 t 检验经 Holm 校正后 p<0.001
- 训练效率：前景 token 使每资产 Gaussian 从 8.4M 降至 1.8M（token 32,768→7,937），4 桶采样把每步期望最大 Gaussian 数 6.1M→3.1M，64 卡吞吐 1.7×
- 渲染性能：1024×1024、64 spp、RTX A6000 上平均 0.872 s/视图（P95 1.436 s）
- 单场景 7 个资产 1280×720、1 spp 约 50 ms/帧
- 透射率混合 vs 二值选择（50 资产受控拟合、4 层宽 64 解码器）：30.62 vs 29.66 dB（15K 步），七个检查点全部更优
- 约 21% 不透明度质量落在 0<T<1 的分数遮挡区

## 创新点与贡献
- 首次把「生成式视频先验」与「可重光照神经 Gaussian 资产」接成端到端任务：文本/单图直接产出含几何与神经方向外观、可路径追踪重光照的完整三维资产，摆脱网格与解析 PBR 的双重约束。
- 提出 rtRNG 表示：把 RNG 的神经方向外观与无排序随机 Gaussian 光线追踪结合，同一资产可在任意光源下算阴影并插入场景参与全局光照，而 3DGS 光栅化做不到。
- depth-anchored 外观学习：训练时用真值深度固定中心、深度头单独监督，把几何学习与外观学习的梯度路径分开，解决联合优化必然导致的外观软化。
- 用透射率 T_iℓ 连续混合 lit/shadowed 两支输出，替代 RNA 的硬阈值选择，使分数遮挡区的两支都能拿到梯度。
- 前景稀疏 token + 按代价分桶的分布式采样，让 1024²、百万级 Gaussian 的 LRM 训练在 256 卡上可跑，且不改变每个资产的边缘采样概率。

## 局限与风险
- 作者自述两点：视频模型跨帧不一致会在重建资产中留下 ghosting
- 锐利镜面高光仍难精确复现
- 从实验设计看还有：监督全部来自 22K 个 TexVerse 合成资产的渲染（128 个监督视图/资产），没有真实拍摄的可重光照真值，合成到真实的材质域差距未检验
- 输入协议锁死为单物体、零仰角、固定影棚光的水平转台，俯视/仰视结构与手持任意视角未覆盖
- 深度锚定造成训练用 d*、推理用 d̂ 的失配，论文只报总体 PSNR 未单独量化
- 每物体 1–6M Gaussian 带来存储与加载成本（资产加载均值 1.81 s、GAS 构建 1.45 s）
- 重光照指标在计算前对每通道拟合增益，可能掩盖整体色偏
- 无开源代码与模型，baseline 亦多无代码
