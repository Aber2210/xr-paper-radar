# TouchAnnotator：特权视图蒸馏的多源触觉标注

## 一句话结论
在 860 段同步手套实测记录上，TouchAnnotator 的时刻精度 63.29→68.67（+5.38 pt）、Volumetric IoU 9.10→14.12（+5.02 pt），优于 TouchAnything；FPHA 零样本裸手接触 F1 0.3658，接近 HACO 的 0.3768。

## 要解决的问题
第一视角视频能大规模记录手物交互，但几乎不含触觉标签：相机常在接触发生的那一刻恰好被物体遮挡手物界面，即使采集时同步了腕部视角也无法在部署时获得。现有视觉触觉预测（PressureVision、EgoPressure、EgoTouch/TouchAnything、EgoTactile、EgoTac）各自传感器布局、空间支撑、尺度与物理含义不同（压力 / 接触 / 形变），难以合并成单一标注器；核心难题是如何把异构触觉源与「训练时才有的特权视角」蒸馏进一个只需 ego RGB 的模型。

## 方法详解
把触觉标注统一到一个双侧 21×21 解剖对齐的 canonical hand field：EgoTouch 的 16×16 手套阵列重映射、HumanTouch 的 360 taxels 投影到同一 217 单元支撑并用数据集级单调映射对齐、几何接触用 MANO 顶点-物体距离 5 mm 阈值插值、T-Rex 机器人指尖形变池化到对应指区，未观测单元置为 invalid，并以样本级 availability flag 生成 task mask。模型以共享 Qwen3.5 video tower 编码 ego 与腕部流，每只手 64 个 learned tactile queries 在 8×8 latent grid 上通过 pose-conditioned soft ROI 做 cross-attention，再经 Qwen3.5 reasoner 输出；压力与接触用独立输出头分离 logits 但共享表征。训练时用 EMA 多视角 teacher（ego + 双腕）蒸馏 hand-local 表征与预测到 ego-only student；部署时仅用 ego RGB + WiLoR 估计的手部姿态。跨 clip 用 past-only causal clip memory 提供历史上下文。

## 实验与结果
1) 训练语料：6 个数据集、3 类具身（人手套 / 裸手几何 / 机器人指尖），共 27,005 段视频、35.0M 同步帧（195.3 小时）；仅 EgoTouch 与 HumanTouch 提供相对压力监督，6 源均提供接触监督。2) EgoTouch（184 seen / 76 unseen episodes）：同一 checkpoint 下加腕部视角使 C.IoU 0.4779→0.5038、V.IoU 0.3821→0.4061，MAE 0.0638→0.0652（seen 上 MAE 反降 0.0479→0.0471）。3) 自采实测队列（860 episodes / 21 任务，共 897 段约 5 小时）：T.Acc 63.29→68.67、T.F1 76.87→81.08、C.IoU 6.89→10.73、V.IoU 9.10→14.12；总体 MAE 略升 0.0830→0.0875，但高触觉价值组由 0.0931 降至 0.0895。4) FPHA 零样本迁移（124 序列 / 10,998 帧，10 mm 顶点距离标签，无微调）：F1 0.3658 vs HACO 0.3768、AUROC 0.7431 vs 0.7376、Recall 0.6169 vs 0.5742，远超 TouchAnything 的 F1 0.1209。5) 消融：5 组配置在 40 个 unseen episodes（37,308 帧）上评估，含蒸馏权重 1–3 epoch 线性升温等。

## 创新点与贡献
1) 用一套双侧 21×21 canonical field 把「手套测压 / 几何推接触 / 机器人形变」三类异构监督合并，靠 source-aware mask 保住各源的有效单元，实现单一模型跨具身输出。2) 把腕部相机当作 privileged training view，用 EMA 多视角 teacher 蒸馏成 ego-only student，从而在只有第一视角的存量视频上做密集触觉标注。3) 加入 past-only causal clip memory 提供跨片段时序上下文，并用双层（压力 / 接触）头分离两类物理量。

## 局限与风险
1) 输出是相对传感器响应而非标定力（N），HumanTouch 的对齐只是统计分布匹配，不建立共同物理单位，因此不能直接用于力控。2) 几何接触依赖 MANO 重建与 5 mm/10 mm 距离阈值，近边界标签本身不确定；ego-only 推理对姿态失败、运动模糊、截断与长时间遮挡敏感。3) 因果性只在 clip 之间强制，clip 内部仍双向处理，故仅适合离线标注，不能做帧级在线反馈。4) 作者自承 EgoTouch 公开 split 与历史初始化无法核验、部分历史训练数据未审计，与 TouchAnything 的对比不能算作 SOTA margin；总体 MAE 还出现退化。

## 与文献库的关系
属视觉-触觉预测族（PressureVision / EgoPressure / EgoTouch-TouchAnything / EgoTac / EgoTactile）的改进型工作，差异点在于跨具身标签统一与特权视角蒸馏；与 OpenTouch 等触觉数据采集硬件工作互补（对方产数据，本文把存量 ego 视频变成标注）；与 Ego-Exo4D、Ego-Exo、多模态蒸馏这条「用特权视角训练 ego 模型」的路线同源，是把该范式首次用于触觉场。

## 可复现性（代码/数据/硬件）
附录 A/B/C 给出了仓库派生配置、数据转换、损失权重（压力 MSE 1.0、L1 0.5、TV 0.01、正压单元权重 3.0 等）与评估协议，透明度较高；但正文未见代码或数据下载链接，自采 897 段手套数据未声明公开；作者明确写出「当前审计无法验证 EgoTouch split 与全部历史初始化」。可复现性中等。
