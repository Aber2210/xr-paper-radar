# World SLAM Model：将 SLAM 范式直接引入下游导航的统一世界建模

## 一句话结论
WSM 把 SLAM 的核心机制（带持久记忆的增量状态更新 + 后端累积误差精修）直接做成可学习的"世界状态模块"，与下游导航端到端联合训练：给定观测与导航目标，预测未来视觉状态并联合估计相机运动与稠密几何，使导航直接从 SLAM 式空间状态获益。

## 要解决的问题
以往把 SLAM 当作只供位姿/地图/令牌的上游模块，与导航割裂；误差在后处理中累积，下游看不到空间一致性。

## 方法详解
- 世界状态随新观测持续更新，提供动作生成与闭环导航的基础；
- **预训练目标三路监督**：RGB 生成（流时间采样 + 钟形加权）、度量深度（截到 [0.2,5] m、对数归一、Wan2.2 VAE、潜空间 MSE）、相机位姿（smooth-L1 作用于平移与单位四元数，同时监督绝对与成对相对位姿，因预测度量位姿无需尺度对齐）；
- 沿用 SLAM-Former 的位姿监督思路。

## 实验与结果
- 两阶段训练（先相机空间手先验，再扩展到流式世界空间）；
- 在导航基准上成功率（SR）/SPL 较"先 SLAM 后导航"模块化管线提升（两阶段 ablation 验证）；原文端到端导航数值以消融表为准，本期抽取段落以预训练目标为主。

## 创新点与贡献
把"SLAM"从冻结上游重构为与导航共训的可学习世界状态模块；持久记忆 + 后端误差精修实现一致世界状态；联合导航-SLAM 目标。

## 局限与风险
用 Wan2.2 VAE 等扩散骨干，重（TRL=3）；评估多在仿真；EXP=4（强但在真实机器人泛化待验）。

## 与文献库的关系
重建与SLAM 赛道；与 Pow3R-SLAM、RRG-SLAM、EgoFound3R、Dyna3、VASC、MVP-SLAM 同批，但唯一走"SLAM 为导航世界模型"范式，属理念级差异。

## 可复现性
REP=3（扩散骨干 + 联合训练，代码待开源）；关注是否放预训练权重。
