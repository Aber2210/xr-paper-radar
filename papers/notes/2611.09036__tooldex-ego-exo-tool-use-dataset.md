# ToolDex：面向创造性工具使用的自我-外部视角演示数据集

## 一句话结论
ToolDex 提供 10,853 条、60 小时的真实 ego-exo 工具使用演示（45 种工具、16 类可变形目标），其统一基准确认最强 VLM 工具选择仅 80%、IoU 0.891，而人类演示经 RL 重定向后机器人平均成功率最高 55.1%。

## 要解决的问题
创造性工具使用要求代理理解可供性、接触几何与任务约束，但现有机器人工具使用基准多为仿真或简化交互，缺少同时包含手、工具与被作用目标（尤其面团、沙、流体等可变形物）的真实数据。已有 egocentric 数据集（如 TACO）只建模工具-动作-物体组合，不显式区分工具与目标，因而无法评估接触力学与长时序形变。

## 方法详解
构建大规模 egocentric-exocentric 演示数据集：8 台标定 Intel RealSense 435 RGB-D（1280×720、30 Hz）环绕工作台，加 Apple Vision Pro 上挂载的 ZED Mini 立体 ego 相机，AprilTag 加多视图 bundle adjustment 标定。以 hand–tool–target 三角色分解建模任务，形式化为 goal-conditioned MDP，动作分为 tool action（6-DoF 工具位姿，embodiment-invariant）与 agent action（MANO 手姿加腕轨迹，供 retargeting）。离线自动标注产出逐帧 6-DoF 工具位姿、双手 MANO、目标/工具/手多视图分割掩码。基准覆盖三层能力：(i) VLM 的工具选择、空间 grounding、行为规划；(ii) 稀疏视角 3DGS/4DGS 新视图合成（InstantSplat 加 Difix3D / GSFix3D 两阶段配方）；(iii) 从人类演示学习机器人策略（运动学重定向、BC、ManipTrans、Dex-X RL）。

## 实验与结果
• 规模：10,853 条 trial、60 小时；60 个 (tool, action, target) 高层组合、168 个变体；45 种工具、23 种支撑物、16 类可变形目标、16 种动作；单条平均 18.92 s / 567.58 帧；含零样本（留出工具/目标/动作）与组合泛化划分。
• VLM 推理：工具选择最高 80%（GPT-6-Astra、Claude-Sonnet-4.6、Claude-Opus-4.7 并列）；空间 grounding 最佳 GPT-6-Astra IoU 0.891，而 Gemini-3.1-Pro 仅 0.010、Qwen-3.6-27B 0.004，呈语义强、空间弱的分裂；行为规划评估成功率最高 89.4%（GPT-6-Astra），Gemini Robotics ER 轨迹误差最低。
• 重建（留出 cam 6）：静态 3DGS 用 IS+Difix3D 达 20.45 PSNR / 0.779 SSIM / 0.364 LPIPS / 55.11 MUSIQ，比 InstantSplat 高 0.5 dB、比 SplatFormer（13.09 dB）高约 7 dB；动态 4DGS 达 69.92 MUSIQ（较 IS-4D 提升 18.92），但 PSNR 下降 3.6 dB，量化了感知质量与光度保真的分离。
• 机器人策略：Kinematic Retarget 平均成功率 14.0%、BC 4.6%、ManipTrans 40.5%、Dex-X RL 55.1%；接触密集任务差距最大（pestle crushing 16.8% 升至 46.7%，squeegee collecting 12.6% 升至 57.5%）。
• 评测子集：180 条人工校验轨迹、32 个任务变体用于 VLM 行为规划；动态 4DGS 另在 20 个场景、8 相机全观测下评估。

## 创新点与贡献
1) 首个显式区分 hand / tool / target 三角色、并系统覆盖可变形目标（面团、沙、颗粒、流体）的真实 ego-exo 工具使用数据集，填补 TACO 等仅有工具-物体组合的空白。
2) 用 8 相机标定采集支撑留出一台相机做真值的稀疏视角 3DGS/4DGS 评测，使静态保真度与 4D 光度-感知分离第一次在桌面工具场景中可量化。
3) 单一采集同时服务三类基准（VLM 物理推理、新视图合成、机器人策略学习），并给出零样本/组合泛化划分与 embodiment-invariant 的 6-DoF 工具动作表示。

## 局限与风险
1) 场景限于桌面（tabletop）与 16 类目标，未覆盖移动操作、多代理或户外长时序任务。
2) 标注依赖离线管线，遮挡与复杂接触配置下仍可能引入噪声；可变形物体缺乏物理参数真值。
3) 机器人实验使用特定灵巧手与重定向管线，成功率绝对值受硬件与策略实现影响，跨平台可比性有限。
4) 数据仅以非商用许可面向研究开放，且涉及人类行为数据，下游机器人部署存在误用风险。

## 与文献库的关系
属于真实世界 hand-object interaction / ego-exo 演示数据集族（与 TACO、OakInk2、HOT3D、GigaHands 同列比较），但把工具与被作用目标显式分离；基准侧同时对接 VLM 物理推理基准（PhysToolBench、PHYRE）、稀疏视角 3DGS 重建（InstantSplat、SplatFormer、Difix3D）与人类演示到机器人的策略学习（ManipTrans、Dex-X、AnyTeleop）。

## 可复现性（代码/数据/硬件）
数据集与基准可视化已在 https://tooluse-dataset.github.io/ 发布，研究用途非商用许可；采集硬件（8 台 RealSense 435 加 ZED Mini 加 Vision Pro）与标注流程描述详尽，策略训练配置见附录 A.5，但代码与完整标注管线是否开源未明确。

## 行动建议
若研究 VLM 的物理工具推理或人类演示到机器人的迁移，可把 ToolDex 作为可变形目标加工具替代的压力测试集；引用其成功率时注意区分重定向/BC 与 RL 两类基线，不要跨硬件直接比较绝对值。
