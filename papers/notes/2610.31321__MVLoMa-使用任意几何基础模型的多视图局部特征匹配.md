# MVLoMa：使用任意几何基础模型的多视图局部特征匹配

## 一句话结论
MVLoMa 首次在星图上做联合稀疏匹配：一次前向输出全部中心-邻居匹配并保留逐边得分矩阵，复用冻结几何基础模型（DA3-Giant）末层跨视图 token 作描述子，配极线几何负样本损失；四基准 AUC@1° 58.65 三档全优，25 视图匹配较顺序成对快 2.20×。

## 要解决的问题
成对匹配器的计算单元（图像对）与下游几何所需的证据单元（互相重叠的视图组）不匹配：星图（参考图+检索邻居）中每条边都要重算参考描述子，且在看不到其他边证据前就提交匹配。同时，多视图几何基础模型的末层 token 已编码跨视图几何上下文，但局部匹配通常另起一路冻结的 2D 描述子骨干，造成信息浪费。

## 方法详解
LoMa 的多视图星图扩展：用冻结多视图几何基础模型（默认 DA3-Giant，另评 π³、VGGT、VGGT-Ω）的末层空间对齐 token 替换 DINOv2-L 冻结流，与可训练 VGG 流经卷积细化器/MLP 融合为描述子（每图 4096 DaD 关键点）；星图注意力按视图内自注意力（RoPE）→ 中心查询全部邻居 → 全部邻居查询更新后中心的双向中心-邻居交叉注意力堆叠，邻居间不交互，每条边仍输出常规 dual-softmax 得分矩阵供 RANSAC；监督采用 RoMa v2 可见性过滤正样本（深度有效、重投影在图内、遮挡/深度一致性），并引入几何负样本损失：挖掘互相最大且置信过阈但极线误差 >3px 的匹配逐层惩罚（权重 1/(N−1)）。

## 实验与结果
25 视图星图协议（frame 0 为中心，24 条边），PoseLib RANSAC 2.5px，AUC@1°/5°/10°。784 分辨率 MVLoMa 宏平均 58.65/85.41/90.99，为所有方法三档最优；HyperSim 53.90 vs LoMa-L 51.99（+1.91）、ScanNet++ 38.44 vs 37.68（+0.76）；Mip-NeRF 360 上稠密 RoMa 的 AUC@1° 仍最强（75.42），T&T 上 LoMa-L 最佳，MVLoMa 差距很小。消融（四视图训练、784 测试，HyperSim AUC@1°）：完整 52.84；去 GT 过滤 51.93；去几何负样本 51.04。骨干消融：DA3-G 较 DINOv2-G 在四个子集 AUC@1° 提升 +1.16/+11.44/+0.41/+0.65；编码器消融：DA3-G 在 HyperSim AUC@1° 超其他编码器 1.62–2.40。视图数：2 视图宏平均 62.21/86.63/91.34（较最佳低约 0.8），25 视图 62.92/87.45/92.17，非单调。复杂度：25 视图星图匹配较顺序成对减少 37.0% Transformer FLOPs、实测延迟降 54.6%（2.20×），峰值显存 979 MiB vs 176 MiB。

## 创新点与贡献
1. 首次在星图上做联合稀疏匹配：一次前向输出全部中心-邻居匹配且保留逐边得分矩阵接口
2. 复用冻结几何基础模型的跨视图融合 token 作为描述子输入（默认 DA3-Giant），免训编码器
3. 可见性过滤 GT + 极线几何负样本损失，直接抑制高置信错误匹配对 RANSAC 的伤害

## 局限与风险
- 依赖冻结基础特征质量，弱纹理/不确定区域仍会产生稀疏或歧义匹配
- 中心-邻居拓扑不做邻居间信息交换；显存随关键点数与视图数增长
- 训练仅 2–8 视图而评测 25 视图，外推非单调；仅验证相对位姿估计，未接入完整 SfM 系统

## 与文献库的关系
将 LoMa 从成对匹配扩展为星图多视图匹配，区别于 CoMatcher/MV-RoMa 的密集或成组输出；作为匹配原语与 SfM/定位流水线互补。

## 可复现性
基于公开 LoMa 组件与多视图几何基础编码器构建，作者承诺发表后发布实现与评测配置；训练用单卡 A800、200k iterations。

## 行动建议
SfM/视觉定位前端的匹配原语升级（PoseLib RANSAC 接口兼容）。边界：未接入完整 SfM 系统验证、中心-邻居拓扑无邻居间交互、训练 2-8 视图外推 25 视图非单调。
