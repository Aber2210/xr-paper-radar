# GAVEL：出错时不急着再问一次 LLM

## 一句话结论
用**显式图世界模型**在 LLM 生成动作序列后、执行前做前向推演，把"可从世界模型直接推出的修复"本地解决，只把需要语义推理的错误回抛给 LLM。BEHAVIOR-1K 上（Qwen3-8B）单任务成功率 **41.2% → 91.8%**，多任务 **19.9% → 92.6%**，且分布信念推理使移动距离再降 **≈5.4%**。

## 要解决的问题

LLM 作为独立规划器并不可靠，**失败率随规划视界增长**，对面向边缘部署的紧凑模型尤其严重。

场景图方法（如 SayPlan）采用 propose-and-check 循环：结构化环境模型符号执行候选计划，不可行动作返回 LLM 重试。但这里有一个被忽视的浪费：

> **从错误中恢复并不总是需要调用 LLM。** 例如抓取因距离不足而失败，恰当的恢复动作直接由被违反的前置条件决定。既然检测失败的图已经确定了修正方式，再调 LLM 只是增加成本与风险。

## 方法详解

### 图世界模型的三个组成部分
1. 相关**物体—关系**；
2. 动作的**前置条件与效果**；
3. 对**未观测物体位置的概率信念**。

### 流水线（Algorithm 1）
1. 指令 $\mathcal{I}$ 分解为任务 $\{\mathcal{I}_i\}$；
2. `Task understanding` 抽取初始化图所需的实体、关系与目标；**RSN** 为不确定物体分配房间位置信念 $B_0$；
3. **单次** LLM 查询产出每个任务的动作计划 $\pi_i$；
4. 图世界模型前向 rollout，`Repair` 修复**模型可推导的失败**，`Validate` 检出剩余违例；
5. 未解决的违例最多回抛 LLM $T$（默认 5）次；
6. 验证通过后，按当前信念下的代价函数（Eq. 7）对计划排序；
7. 每完成一个任务，用新观测更新信念并**在线重排**剩余任务。

### 两个关键设计
- **修复分级**：模型可推导 → 本地修复；需语义推理 → 才回抛 LLM。
- **分布信念推理**：对多任务指令，在可能的物体位置**分布**上推理以重排子任务，最小化期望搜索代价。

## 实验与结果

**平台**：BEHAVIOR-1K，符号动作层面（论文明确说明聚焦高层任务规划而非低层操作）。为大规模评测，作者实现了轻量级 2D 执行器，保留原始平面图、物体属性、任务谓词与导航几何。

**规模**：100 个单长程任务 + 500 条多任务指令。

| 配置 | 单任务成功率 ↑ | LLM 调用次数 | 移动步数 |
|---|---|---|---|
| Qwen3-8B 仅 LLM | 41.2 ± 1.2 | 1.00 ± 0.0 | 13.3 ± 6.4 |
| Qwen3-8B + sayplan | 76.4 ± 1.5 | 2.7 ± 1.7 | 24.6 ± 15.8 |
| Qwen3-8B + gavel-basic | 76.2 ± 1.2 | 1.00 ± 0.0 | 13.5 ± 6.4 |
| **Qwen3-8B + gavel** | **91.8 ± 1.3** | 1.5 ± 1.1 | 15.5 ± 9.4 |

- **多任务**：19.9% → **92.6%**。
- **分布信念推理**：相对静态变体，移动距离降低 **≈5.4%**。
- 对比 sayplan：成功率 +15.4 个百分点，而 **LLM 调用次数从 2.7 降到 1.5**，移动步数从 24.6 降到 15.5——**在更少调用下取得更高成功率**，这是"修复分级"设计的直接收益。

## 创新点与贡献

1. **识别并量化了"不必要的 LLM 重规划"这一浪费**——这是本文最有价值的洞察，且具有普适性（不限于机器人）。
2. 把概率信念（未观测物体位置）显式纳入图世界模型，并在多任务排序上做分布推理。
3. 给出了完整算法伪代码与代价函数形式化。
4. 在紧凑模型（Qwen3-8B）上验证了效果，对边缘部署有意义。

## 局限与风险

- 评测在**符号动作层面**的轻量 2D 执行器上进行，**未在真实机器人或高保真仿真上验证**低层操作可行性。
- 图世界模型需要**手工/先验定义**物体关系、前置条件与效果——扩展到开放世界仍需解决知识获取问题。
- 仅报告 Qwen3-8B 的详细表；"compact local and frontier hosted LLM" 的跨模型结论需看完整表。
- 未开源。
- XR 直接相关度中等：价值在于具身智能的任务规划层，可迁移到 MR 助手的长程指令执行，但本文未做 XR 评测。

## 行动建议

- **做 LLM Agent / 具身规划**：直接采用"修复分级"原则——先判断错误是否可从本地模型直接推导，再决定是否回抛 LLM。这在成本敏感场景下收益立竿见影。
- **MR 语音助手的长程指令**：可借鉴信念分布推理做子任务排序，减少用户等待。
- **谨慎外推**：符号层面的成功率不代表真实执行成功率，落地前需在高保真环境中复测。
