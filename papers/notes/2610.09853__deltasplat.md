# DeltaSplat：免位姿前馈 3DGS 的迭代高斯精炼

## 一句话总结
给"免位姿前馈 3DGS"加一个轻量迭代精炼模块：把图像空间渲染残差通过几何引导（Plücker 射线 + 渲染深度）提升为 3D 更新，仅 ~2.2% 额外参数即显著提升质量。

## 问题背景
- 免位姿前馈 3DGS 从稀疏无位姿图像单 pass 预测全局场景与相机；相机估计误差会传播进预测高斯，叠加几何/光度误差。
- 单 pass 预测与上相机误差共同导致质量瓶颈。

## 方法
- **迭代高斯精炼**：以 backbone 前馈输出 G^(0) 初始化，逐步渲染上下文视图得到残差 r_i^(k)，精炼模块 h_φ 渐进改进高斯集。
- **几何引导残差编码**：将 2D 残差条件于每像素 Plücker 射线与渲染深度，把 2D 证据提升为 3D 更新。
- **Delta Decoder**：双分支 mixer + 逐属性头，更新位置 μ、不透明度 α、颜色 c。
- 全前馈推理路径，仅约 2.2% 额外参数。

## 实验与结果（关键数字）
- 训练 DL3DV-10K，测试 140 场景，224²，6/12/24 上下文视图。
- 6 视图已知内参 PSNR 26.64 dB，比 YoNoSplat（同协议）高 +1.75 dB，且超过所有"给真值相机"的基线（26.64 vs 最好 24.72 dB）——精炼收益大于 backbone 获得精确相机的收益。
- 全无校准（内参也预测）：6 视图 25.69 dB，仍高于所有给真值相机基线；随视图增多优势扩大（+1.16→+1.49 dB）。
- ScanNet++ 跨数据集泛化（32/64/128 视图）有效。

## 贡献与局限
- 贡献：即插即用的质量精炼阶段，对任意免位姿前馈 backbone 通用；几何引导残差避免 2D 残差直接回灌的歧义。
- 局限：尚未扩展到更高分辨率与其他前馈 backbone（文末指明为下一步）。
