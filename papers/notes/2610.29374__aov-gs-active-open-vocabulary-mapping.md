# AOV-GS：主动开放词汇语义建图（3DGS）

## 一句话结论
AOV-GS 以 SplaTAM 3DGS 为 backbone、ActiveGS 式主动规划：coarse stage 0 用 SAM+CLIP 嵌入新颖性重排几何候选视角，stage 1+ 退回纯几何；离线在采集嵌入上训 LangSplatV2 语言场支持开放词汇查询。Replica 语言场 mIoU 34.6%（较纯几何 +1.3 pp）、MP3D 23.1%（+1.8 pp），+CorrCLIP 达 35.6%；新视角 PSNR 与几何基线相当、Replica depth L1 改善，代码开源。

## 要解决的问题
人本环境中的机器人需要同时支撑几何导航与开放词汇语义查询的地图，且不能依赖人工标注分割掩码或闭集语义类别。几何驱动主动建图只最大化覆盖，把语义当作采集轨迹的被动副产物；主动语义建图又通常依赖有监督语义分割。问题在于：如何用 frozen SAM/CLIP 在探索阶段就把候选视角偏向语义信息丰富的区域，在不引入人工标注的前提下提升地图的语言场质量，同时保持新视角重建质量不降。

## 方法详解（含关键公式/架构，保留原文术语）
系统分在线/离线两阶段（Fig. 1）：在线侧 posed RGB-D 持续更新高斯地图、planner 据此选择 NBV、关键帧并行抽取 CLIP mask 嵌入；离线侧训练语言场并响应文本查询。重建 backbone 为 SplaTAM 的各向同性 3D 高斯，可微渲染以 RGB 与 depth L1 损失约束轮廓像素；Habitat 提供同步 RGB-D 帧与 GT 相机位姿（两数据集均以 oracle SLAM 输入）。沿用 ActiveGS 式基础设施维护体素探索地图做无碰撞候选位姿采样，所选视角由 RRT 局部 planner 执行。粗探索按两阶段（仿 ActiveGAMER）：stage 0 = 几何 + 语义新颖性，stage 1+ 起语义项关闭、完全退回 ActiveGS 纯几何准则。几何分对每个候选位姿 v 渲染当前地图、统计未见轮廓像素 N_v^S，I_v^geo = σ(log N_v^S)（σ 为候选间 softmax 归一化），再以距离 l_v=||T_x^v−T_x^t||_2 加权：w_v^geo = (1−σ(l_v))·I_v^geo。语义新颖性对 w^geo top-K 候选渲染 RGB 视图，SAM 出实例掩码、CLIP 编码得嵌入 {e_i}∈R^512，与关键帧嵌入库 B 比余弦相似度：I_v^sem = Agg_i(1 − max_{b_j∈B} sim(e_i, b_j))；候选嵌入仅瞬时用于当前候选集打分、不入库，库内只含已执行轨迹到达的关键帧观测嵌入——语义打分与几何分支信息对齐。离线阶段在采集到的 CLIP mask 嵌入上训场景特异 LangSplatV2 语言场，文本查询即在新视角分割；CorrCLIP 变体在候选掩码重排与关键帧嵌入库两端同时施加。

## 实验与结果（表格化关键数字）
设置：Habitat 模拟器；Replica 8 场景（office0–office4、room0–room2，2000 步探索预算，RGB-D 680×1200，held-out novel views 评测语义）与 Matterport3D 5 场景（GdvgFV5R1Z5、gZ6f7yhEvPG、HxpKQynjfin、pLe4wQe7qrG、YmJkqBEsHnH，5000 步，沿用 ActiveSGM/ActiveGAMER/NARUTO 协议）；所有对比方法接收同一 GT 相机位姿，无估计位姿或 SLAM 定位噪声。主指标为 held-out novel views 上开放词汇语言场 mIoU（类别名作文本查询，数据集语义标注供 binary GT mask）。结果（摘要口径）：AOV-GS 平均语言场 mIoU 较纯几何主动规划 +1.3 pp 于 Replica（34.6%，8 场景）、+1.8 pp 于 MP3D（23.1%，5 场景）；AOV-GS+CorrCLIP 在 Replica 达 35.6%，高出匹配的 Geometry-based+CorrCLIP 基线 2.0 pp；新视角 PSNR 两数据集与几何基线相当，Replica depth L1 改善。基线构成（同一 SAM-CLIP 感知栈受控）：Passive（固定 NVS 轨迹 + SAM-CLIP 抽取 + 离线语言场训练，仅 Replica）；Geometry-based（geometry-only ActiveGS planner + 同一 SAM-CLIP/语言场管线）；Geometry-based+CorrCLIP（CorrCLIP 只施加于 accepted keyframe，候选仍按几何排序）；ActiveSGM traj.+LangSplatV2（回放 ActiveSGM 录制位姿序列与关键帧日程，注意回放含 868 步 vs AOV-GS 956 步，未完全隔离轨迹质量）；ActiveSGM（逐场景 OneFormer 微调，仅作背景非开放词汇基线）。4.2 节另设 failure modes、语义探索何时有益、轨迹迁移等分析，digest 未含其数值；Replica 增益随场景变化，per-scene 明细与 4.4 计算成本 digest 未含。

## 创新点与贡献
- 把 frozen SAM-CLIP 的 mask 嵌入新颖性引入主动 3DGS 建图的 NBV 规划：stage-0 语义重排 + stage-1+ 纯几何，免人工标注与闭集
- 语义打分只用当前地图已表示的外观（候选视角渲染→SAM→CLIP），与几何分支信息对齐，候选嵌入瞬态使用、不入关键帧库
- 离线 LangSplatV2 语言场直接拟合采集到的 CLIP mask 嵌入而非标注掩码，支持新视角开放词汇文本查询分割
- 同感知栈受控对比（passive / geometry-only / +CorrCLIP / ActiveSGM 回放），把轨迹质量贡献与感知栈贡献分离
- Replica/MP3D 双基准 mIoU 增益（+1.3/+1.8 pp）且新视角重建质量不降（Replica depth L1 改善）

## 局限与风险
- 依赖 Habitat oracle 相机位姿，未在估计位姿或 SLAM 定位噪声下评测
- 语义新颖性只作用于 coarse 阶段，fine 阶段无语义引导；『语义探索何时有帮助』的 failure-mode 分析在 digest 中被截断
- MP3D 协议下无已建立的 passive 语义基线，被动对比仅在 Replica 报告
- digest 未含计算成本数值与 per-scene 明细；mIoU 增益幅度（1.3/1.8 pp）不大

## 与文献库的关系（新增 / 改进 / 取代 X）
库内重建与SLAM 线以通用 VI-SLAM 与 3DGS 重建为主线（HexVIO 4.58、AMB3R-SLAM 4.50、DAVIO 4.05），主动开放词汇语义建图子方向空白：本文基线家族 ActiveGS/ActiveSGM/NARUTO/ActiveGAMER 均不在库，库内未见同工作。与库内神经渲染线 NormLift 4.12（3DGS 语义特征提升）共享『3DGS+语言语义』主题但路线互补：NormLift 在既有表示上研究特征提升，AOV-GS 从采集端（NBV 偏置）解决语义质量并用 LangSplatV2 语言场替代提升式语义。

## 可复现性（代码/数据/硬件）
代码开源：https://github.com/OptimusFaber/AOV-GS（摘要声明）。依赖 Habitat 模拟器、SplaTAM backbone、frozen SAM/CLIP、LangSplatV2 语言场；数据为 Replica（8 场景、2000 步）与 MP3D（5 场景、5000 步）标准协议，RGB-D 680×1200，GT 相机位姿；语义评测用 held-out novel views 的语言场 mIoU。

## 行动建议
做开放词汇 3DGS 语义地图时，直接复用 AOV-GS 开源代码，把 stage-0 SAM-CLIP 新颖性重排插入现有 SplaTAM/ActiveGS 管线；优先复现 Replica 8 场景 mIoU 对比（34.6%，较纯几何 +1.3 pp）与 CorrCLIP 35.6% 配置；注意其评测用 oracle 位姿，迁到真实 SLAM 前需自测位姿噪声敏感性；库内与 NormLift 4.12 并列为 3DGS 语义线『采集端 vs 提升端』参照。
