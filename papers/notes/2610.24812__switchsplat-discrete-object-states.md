# SwitchSplat：从随手捕获场景学习离散物体状态

## 一句话结论
从 Insta360 X4 随手拍摄的 12 个场景（10 个 casual + 2 个 golden）学习状态感知 3DGS：场景拆成共享静态基座 + 每物体一个 slot（on/off 双状态，softmax 至 1+2K 通道），推理时可自由组合捕获中从未共现的物体状态；slot 表由 VLM 初始化并经可微渲染端到端精化，全程无人工标注。

## 要解决的问题
既有动态场景表示（4DGS 等）以时间为条件，推理时无法自由组合物体状态；articulation 类方法又需额外结构假设。随手拍摄的 360° 视频中，交互物体的 on/off 状态与相机轨迹、时间纠缠在一起，缺少一种免标注、可自由状态组合的场景表示。

## 方法详解（含关键公式/架构，保留原文术语）
① State-aware Gaussian Splat：每个高斯附加可学习 logit 向量 ℓ，softmax 到 1+2K 个通道——1 个 static base 通道 ℓ[0]，加每 slot 一对 off（ℓ[2k-1]）/on（ℓ[2k]）通道；每 slot 用双通道而非单通道，使 softmax 把每个高斯唯一指派到一个配置，不相交的高斯子集得以分别建模同一物体两种状态的几何与外观（关/开的门占据不同空间，单条共享基元无法表达）。渲染时用户指定各状态激活与否，按 Eq.(1) 计算每个高斯的出现概率 ω(p̃)。② Differentiable slot table：slot 由 VLM 初始化，训练时渲染联合精化。③ 训练目标含 sparsity loss 与 compactness loss，促使高斯指派稀疏、紧凑。预处理：FullCircle 抹除拍摄者、COLMAP 标定、双鱼眼去畸变为 pinhole；每第 8 帧留出测试，剔除状态切换瞬间的帧以降指标噪声（这些帧仍保留在训练集内）。

## 实验与结果（表格化关键数字）
自采 Insta360 X4 双鱼眼 360° 数据集：standard set 10 个 casual 场景（8 室内 + 2 室外，每场景 3–9 次物体交互）；golden set 2 个场景带受控测试序列，评测 novel camera trajectories 与训练中未见过的 state combinations（泛化到训练配置之外）。基线：FullCircle（其 3DGUT 架构，静态）、4DGS、DeGauss（动态）。评估遵循标准 NeRF 流程（每 8 帧留出）。digest 未包含 Table 1 的具体数值。

## 创新点与贡献
① 把「场景状态」从「时间」解耦：slot + static base 分解使推理时可自由组合物体配置，包括捕获中从未共现的组合——这是时间条件动态方法（4DGS/DeGauss）根本做不到的；② 每 slot 采用 off/on 双 softmax 通道，保证两种状态由不相交高斯子集独立建模几何与外观；③ VLM 初始化 + 可微渲染端到端精化，全流程免人工标注。

## 局限与风险
每物体仅支持二值状态（on/off）；slot 发现质量依赖 VLM 初始化；测试协议显式剔除状态切换帧，切换瞬间的渲染质量未被量化；golden set 仅 2 个场景，泛化结论统计力有限；digest 未报告与基线的定量对比数值。

## 与文献库的关系（新增 / 改进 / 取代 X）
隶属 NeRF/3DGS 场景表示线：静态基线 FullCircle/3DGUT、动态基线 4DGS/DeGauss；与库内 3DGS 效率/压缩线（2610.22778 dGS、2605.25563 CodecSplat）同属「3DGS 表示改进」但目标不同（状态可控性 vs 参数效率）；其 360° casual 捕获预处理（FullCircle、双鱼眼→pinhole）与全景内容线（2610.21297 GeoPano、2604.00852 PanoAir）共享采集处理流程。
