# 硬件感知校准聚类注意力（高效 VGGT）

## 一句话总结
把 VGGT（视觉几何接地 Transformer）的 24 个全局注意力层替换为"校准块聚类注意力（BC attention）"，在几乎无损精度下大幅压缩序列长度、降低延迟，使其可部署到边缘/XR 设备。

## 问题背景
- VGGT 首次单 pass 联合推断相机位姿、深度、密集几何，但全局注意力层需极长序列 → 高延迟瓶颈，难在资源受限设备运行。

## 方法
- **块聚类注意力（BC attention）**：用校准超平面（calibrated hyperplane）对 query 聚类，分块计算注意力，压缩 query 长度（压缩因子 γ）。
- **硬件感知**：考虑块大小与延迟的协同选择；误差补偿 + 块大小选择消融。
- 将预训练 VGGT-1B 的 24 个全局层替换为 BC attention，其余不变。

## 实验与结果（关键数字）
- ETH3D 点图估计（深度+相机头解投影到 3D）：γ=3（query 长度 ×3 压缩）总体损失 ~1%；γ=4 损失 <5%；**随机超平面**则损失 >17%（说明校准是关键）。
- DTU（结构光毫米级真值）：校准 BC 注意力损失 <0.05 mm。
- 与 ToMeSD 对比：校准 BC 在精度-压缩权衡上更优。
- 延迟显著降低（边缘部署可行）。

## 贡献与局限
- 贡献：把"聚类注意力"用于 VGGT 且用校准超平面保精度；硬件感知的块大小/延迟协同。
- 局限：是 VGGT 的增量加速方案，不改进上游精度；极端压缩（γ 更大）精度损失上升。
