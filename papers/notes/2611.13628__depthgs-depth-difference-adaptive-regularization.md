# DepthGS：深度引导与自适应正则的高质量表面重建高斯泼溅

## 一句话结论
由「无偏深度与渲染距离之差」推出重建误差上界，并据此做自适应法向权重与跨视图深度一致性正则，DTU 平均 Chamfer 降到 0.51 mm（PGSR 0.53 mm），Mip-NeRF360 总体 LPIPS 0.175 为对比最低、PSNR 27.72 dB。

## 要解决的问题
3DGS 用显式各向异性高斯和可微 α-blending 换来实时高保真渲染，但基元不规则，难以精确贴合真实表面，容易产生几何伪影，因此被大量扩展到表面重建。现有两条路线：几何感知表示（2DGS 的平面盘、GOF 的不透明度场、GFSGS/GSDF 的几何场、GS-Pull/GS-UDF 的距离函数、GSPrior 的自约束先验）与深度/法向先验（DN-Splatter、VCR-GauS 的视图一致深度-法向正则、PGSR 的无偏深度渲染）。缺口在于：无偏深度与渲染距离反投影出的三维点，其相对真值表面点的重建误差从未被显式刻画；两种深度表示在邻视图间的一致性也缺少分析。结果是正则强度只能凭经验设定，无法判断哪些区域该信、哪些该弱化。

## 方法详解
先做单视图误差分析。同一像素射线上，无偏深度 D_u=D_D/(N·v) 与渲染距离 D_D 反投影得 X_u、X_D，二者欧氏距离恰为 |ΔD|=|D_u−D_D|，由三角不等式得 ε_u ≤ ε_D+|ΔD|，加权平方积分给出总体上界 E_sv ≤ ∫w(ε_D+|ΔD|)²。展开可见压低 |ΔD| 会收紧上界。据此不直接最小化 |ΔD|，而把它当局部可靠性度量，映射为 W_ΔD=1−(|ΔD|−ΔD_min)/(ΔD_max−ΔD_min+σ)，深度差越小权重越大；法向约束为 L_svgeo=mean(W·‖N_d−N‖₁)，W=W_ΔD·(∇Ī)²，后者沿用 PGSR 的边缘感知调制。多视图侧给出引理 2：把当前视图的两种深度经 (R,t) 变换后投到邻视图目标射线，定义残差 r_Δ=‖ΔD^{Vn}v^{Vn}−RΔD^{Vc}v^{Vc}‖，可证 E_mv ≤ 2Σ[(ε_D^mv)²+r_Δ²]。工程上取当前视图与最近邻配对，用联合有效性掩码（双向投影在图内、深度>τ_d=0.1）过滤，对邻视图深度双线性采样得 δ_u、δ_D，正则项 L_mv_D=mean[αδ_u+(1−α)δ_D]，α=0.8。总损失在 PGSR 的 L_rgb、L_s、L_mvgeom 外加入 L_svgeo 与权重 λ5=0.008 的 L_mv_D，30k 迭代后融 TSDF 取网格。

## 实验与结果
- DTU 15 个场景的 Chamfer 距离：平均 0.51 mm，PGSR 0.53 mm、2DGS 0.79 mm、GSDF 0.80 mm；GSPrior 原文 0.50 mm（作者复现为 0.52 mm），本文在对比方法中平均精度排第二；单场景训练 17.6 min，GSPrior 42 min、PGSR 17 min。
- Tanks and Temples 平均 F1：0.503（PGSR 0.495、GSPrior 0.507、QGS 0.500）；分场景 Barn 0.64、Caterpillar 0.43、Truck 0.63、Ignatius 0.81。
- 新视角合成（Mip-NeRF360）：总体 PSNR 27.72 dB、SSIM 0.841、LPIPS 0.175；室外 LPIPS 0.199、室内 30.68 dB/0.933/0.151，总体 LPIPS 为全部对比方法最低（GSPrior 0.178）。
- DTU 消融：PGSR 0.53 mm → 仅加 L_mv_D 0.52 → 仅加 W_ΔD 0.51 → 两者全开 0.51；显存均值/峰值由 6.41/7.12 GB 升到 6.77/7.50 GB。
- Mip-NeRF360 消融：基线 27.45 dB/0.841/0.181 → 仅加 W_ΔD 27.75/0.842/0.175 → 仅加 L_mv_D 27.51/0.842/0.180 → 全模型 27.73/0.841/0.175。
- 优化动力学（7k/10k/15k/20k/25k/30k 采样）：counter 最大训练/测试增益 0.38/0.37 dB，bonsai 0.36/0.33 dB；平均增益 counter 0.27/0.28、bonsai 0.26/0.23、garden 0.18/0.08 dB；bicycle 训练 +0.04 dB 但测试 −0.05 dB。
- 跨视图一致性诊断：以式 (39) 的 E_MVC 衡量，DTU 与 Mip-NeRF360 上带 L_mv_D 的均值曲线整体低于不带（仅给曲线与标准误，正文无表格数值）。

## 创新点与贡献
- 把「无偏深度与渲染距离之差」严格等同于两反投影点的欧氏距离，并据此给出单视图与多视图的重建误差上界，使深度差从经验启发式变成有界的可靠性度量。
- 用该上界指导权重设计：深度差越大权重越小，避免在不可靠几何上强行施加法向约束，与 PGSR 的边缘权重相乘形成双重门控。
- 把跨视图深度差残差分解为标量项 (Δδ)² 与角度项 (ΔD^{Vc})²sin²θ，并据此构造只需双线性采样的可微正则 L_mv_D，计算开销可控。
- 在 PGSR 骨架上以最小改动（新增两项损失、一个新超参 λ5）同时提升重建与感知指标，工程可嫁接性强。

## 局限与风险
- 作者承认：bicycle 这类复杂光照、大视角变化、碎片化几何场景下测试 PSNR 反而下降 0.05 dB，方法对深度/法向估计可靠性敏感；未来工作指向强光照、噪声几何与非结构化室外场景。
- 作者承认：DTU 平均 CD 只排第二（GSPrior 0.50 mm），T&T F1 也低于 GSPrior 0.507，因此全文用「competitive」而非 SOTA。
- 我在正文发现：绝对增益很小（CD −0.02 mm、PSNR +0.27 dB），且全模型 PSNR 27.73 略低于仅开 W_ΔD 的 27.75、CD 相同，说明两组件在渲染指标上接近冗余。
- 我在正文发现：理论上界由三角不等式给出、只保证「压 |ΔD| 会收紧上界」，并不保证 ε_u 本身下降；权重用批内 min/max 归一化，对离群像素敏感且缺鲁棒统计。
- 我在正文发现：表 I 混用「原文报告值」与「作者复现值」（GSPrior 0.50 vs 复现 0.52），横向比较口径不完全一致；未报告多 seed 方差。

## 与文献库的关系
是 PGSR 的直接增量：沿用其无偏深度渲染、边缘感知权重、λ1–λ4 设置与 TSDF 融合流程，只替换法向权重并新增跨视图深度项。同路线对照包括 VCR-GauS 的视图一致深度-法向正则（同样耦合深度与法向，但无误差上界推导）、DN-Splatter 的深度/法向先验、2DGS 的平面基元、GSPrior 的自约束几何先验，以及 GS-Pull/GS-UDF/QGS 等几何表示改造。库内 refinesplat（重建引导的新视角合成）与 dpgs-slam（高斯地图）同属「用 GS 提升几何质量」的一条线，但前者面向合成、后者面向在线建图，本文专注离线高保真表面。
