# 作为原生潜在动作模型的世界模型

## 一句话结论
把预训练视频世界模型直接当 LAM：同一 DiT 兼任 IDM 与 FDM，dynamics registers 是唯一接口，不新增 encoder/decoder：LARY 动作分类 top-1 71.77% 对 WLA3 70.75%，RoboTwin 2.0 成功率 93.6% 对 π0.5 79.8%，并有 AgileX NERO 真机闭环。

## 要解决的问题
大规模异质视频（第一视角人类视频、不同机器人录制）富含动力学，但要么没有动作标签，要么动作空间不共享。现有 latent action model (LAM) 从零训练 inverse-dynamics model (IDM) 与 forward-dynamics model (FDM)，目标在像素重建与 latent 容量/精度之间权衡，训练脆弱：瓶颈过松会泄漏未来帧，过紧无法描述运动，介于两者之间又会漂移到相机运动或与智能体无关的干扰物。预训练视频世界模型本身是强 FDM，但其动力学稠密地纠缠在每层隐状态与外观中，没有可供读取动作的紧凑接口。

## 方法详解
Native LAM 不设独立 encoder/decoder，让同一个预训练视频 diffusion transformer（Kairos 3.1 4B）以 IDM/FDM 两种模式运行，二者之间只由一小段可学习 dynamics registers $\mathbf{r}$ 作为因果桥。IDM 模式把 $\mathbf{r}$ 追加到干净 clip 的 token 序列，在只读 attention mask 下让 registers 读取全部视频 token（视频 token 不反读），输出经 MLP 得到 $\hat{\mathbf{a}}=\mathrm{MLP}_{out}(G_\theta(\mathbf{v}_{0:N},\mathbf{r})_{\mathbf{r}})$。FDM 模式用同一网络，从首帧 $\mathbf{v}_0$ 与 $\hat{\mathbf{a}}$ 重建未来，$\hat{\mathbf{a}}$ 经 $\mathrm{MLP}_{in}$ 取代原世界模型的 text/action 条件，以原 flow-matching 损失训练：$\mathcal{L}_{fm}=\mathbb{E}_{\tau,\epsilon}w(\tau)\|u_\theta(\mathbf{v}^{\tau}_{1:N},\tau|\mathbf{v}_0,\mathrm{MLP}_{in}(\hat{\mathbf{a}}))-(\epsilon-\mathbf{v}_{1:N})\|^2$。为避免后验坍缩，构造 counterfactual temporal pairs：同一素材经时间重映射 $\phi$ 得到 $x'=x\circ\phi$，共享首帧但运动不同，两段在 FDM 中共享噪声与 $\tau$，唯一能解释差异的只有 latent。对 AgiBot World 与 DROID 额外加 kinematic head 预测末端 waypoints，损失 $\mathcal{L}_{kin}$ 权重 0.1、前 2000 步 warm-up。PAWlicy 阶段冻结 Native LAM 作为 dynamics teacher，为 46 路视频打 latent 标签，VLA 由共享 attention 的 VLM、latent action DiT、action DiT 组成，先重建过去一组 latent 再预测未来三组，从而对齐到 teacher 的 latent 空间；训练与推理都不生成视频。

## 实验与结果
- LARY 动作分类平均 top-1 71.77% vs 最强先前 LAM WLA3 70.75%；控制回归 MSE 0.25 vs 0.37
- LARY 真实机器人集：RoboCOIN 0.36 vs WLA3 0.55，AgiBot-Beta 0.41 vs 0.57
- RoboTwin 2.0 平均成功率 93.6% vs π0.5 79.8%、RotVLA 89.1%、DM0.5 93.5%（3.8B 模型）
- RoboTwin 2.0 仅用 clean 示范：PAWlicy 74.02% vs π0.5+past+aug 68.54%
- 真机 AgileX NERO：叠三块 76.7% vs 66.7% vs 23.3%；放鞋入盒 90.0% vs 80.0% vs 33.3%（各 30 次）
- 表示压缩：3,456 个 2,560 维视频 token → 32 个 128 维 latent action token
- 推理延迟 106 ms/step vs Fast-WAM 103 ms、Kairos-WAM 194 ms（RTX 6000 Ada）
- dynamics 模块训练算力较 Wan 2.2 降约 387×、较 Kairos 3.1 降约 1,270×

## 创新点与贡献
- 把预训练视频世界模型直接当作 LAM：同一 DiT 兼任 IDM 与 FDM，dynamics registers 是唯一接口，不新增 encoder/decoder，因而不把学习信号花在像素渲染上
- 用「共享首帧、仅运动不同」的反事实时间对，把「必须依赖 latent」变成结构性约束，解决预训练 FDM 忽略新初始化 latent 通路的后验坍缩
- PAWlicy 只蒸馏世界模型的动力学、丢弃其渲染，训练与推理都不生成视频，策略侧仍是标准规模 VLA

## 局限与风险
- 作者承认：范式只在 Kairos 3.1 上建立，未来需测试其他 video DiT
- 46 路源中仅 2 路有 kinematic grounding，其贡献未分离
- 迁移实验保持初始几何、只改变 embodiment/scene/domain，更大幅度的几何变化与更多机器人待评估
- 从正文看，RoboDojo 的 Memory 维度因缺少记忆模块未参与比较
- 真机仅两个任务、每任务 30 次试验，统计功效有限
- 方法仍依赖一个 4B 级世界模型做离线标注，预训练成本不低
