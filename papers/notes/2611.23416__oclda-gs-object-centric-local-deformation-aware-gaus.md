# OCLDA-GS：以对象为中心、局部形变感知的高斯流式重建

## 一句话结论
用光流引导的锚点重分配 + 同组内运动传播 + 刚体运动条件残差，提升流式 3DGS 的对象边界一致性，但相对 IGS 仅 +0.17–0.20 dB。

## 要解决的问题
任务是在线流式 3D 高斯（streaming 3DGS）下的自由视点视频重建：多视角视频逐帧到达，需要在有限算力与存储下持续更新场景表示并保持画质。现有省时省存储的方法（IGS 用最远点采样 FPS 选锚点并在关键帧周期精化，ReConGS 用自适应层级组织锚点并逐步精化）都假设相邻高斯共享同一条 3D 形变轨迹，靠锚点邻域插值传播运动。这一假设在对象边界处失效：正文以 N3DV 为例，厨师的手在静止桌面旁移动时，通过锚点邻域插值会把不相容的运动传给属于静止桌面的高斯，产生拖影与边界撕裂。其次，FPS 与层级采样并不反映场景的真实运动分布，在锚点预算固定时会把过多支撑分配给静止区域，真正大幅运动的物体反而欠采样。第三，已有对象/运动感知的控制点方法（H3D-DGS、ComGS 等）只部分缓解该问题，在精化次数受限时仍难以维持对象一致的运动。第四，物体内部运动往往由共享的刚体分量与局部非刚体形变（如衣服褶皱）叠加而成，只建模其中一项都会在有限精化预算下产生误差累积。

## 方法详解
整体沿用 IGS 的 keyframe-to-target 预测范式：以稀疏锚点把高斯运动从最近精化过的关键帧 k 传播到目标帧 t，仅在关键帧做高斯精化，中间帧全靠神经预测。记关键帧高斯集合为 G^k={G_i^k}，每个高斯有中心 μ_i^k、四元数 q_i^k 等属性，锚点集 J={1..M}，映射 ρ(j) 给出锚点对应的高斯索引，源位置 a_j^k=μ_ρ(j)^k。冻结的光流条件模型 Ψ_φ（IGS 的 AGM-Net，输入四路视角）为锚点预测运动特征，插值得到逐高斯特征 f_i^{k→t}，线性运动头 h 解码平移与旋转增量：(Δμ,Δq)=h(f)，μ̂=μ+Δμ，q̂=norm(q⊗Δq)，锚点预测位置 â_j^t=μ̂_ρ(j)^t。（1）对象分组：用 SAGA 在第 0 帧对高斯泼溅做分割，得到语义嵌入 s_i 与对象标签 g_i∈{-1,0..O-1}（-1 为未知），锚点继承其高斯的组标签，A_o={j | g_ρ(j)=o}。（2）锚点重选（Anchor Reselection）：在每次关键帧精化时按“尺寸×运动”重新分配固定预算 M。对每组 o，用上一个精化区间内的光流估计归一化运动分 ω_o∈[0,1]：先对每个视角取组内流幅值的 75 分位 d_{o,v}，减去可靠像素上的分量中位流以扣除全局相机运动，再对视角取中位 r_o=median_v [(d_{o,v}-τ)_+/D_v]（τ=0.5 px，D_v 为图像对角线），最后 ω_o=min(1, r_o/Q_{0.95})，其中 Q_{0.95} 取所有正 r_g 的 95 分位；仅统计至少 8 个可靠可见投影像素的视角。分配权重 β_o=sqrt(N_o)(1+ω_o)，按比例分预算并受组内人口上限约束，组内再用 3D FPS 选点。（3）对象级刚体运动估计：对该组参与形变的高斯子集 F_o，用 Kabsch 算法解析求解最小二乘 argmin_{R∈SO(3),t∈R³} Σ||R a_j^k+t-â_j^t||²，得到主导刚体变换 (R_o,t_o)。（4）局部形变：计算光流预测与刚体拟合之间的残差 d_j=R_o^T(â_j^t-(R_o a_j^k+t_o))（用逆旋转回到源帧轴），以中心化位置 p_j=a_j^k-ā_o^k 做位置编码，把 (f_j, φ(p_j), d_j, s_ρ(j), c_o, τ^{k→t}) 送入共享残差网络 D_θ（两个 256 宽隐层、SiLU），只在 j∈F_o 时输出锚点级平移修正 δ_j，否则为 0。（5）运动与修正传播：为阻止跨对象混合，把参与插值的锚点限制在与该高斯同组，取同组 8 近邻 N_8(i)=KNN_8(μ_i^k,{a_j^k|j∈A_{g_i}})，权重 w_ij=exp(-||μ_i^k-a_j^k||)/Σ_l exp(-||μ_i^k-a_l^k||)，用其插值运动特征并传播修正 δ_i^loc=Σ w_ij δ_j，最终 μ_i^{t,pred}=μ̂_i^t+R_{g_i} δ_i^loc。（6）训练目标：L=L_photo+λ_mag L_mag+λ_smooth L_smooth，光度项为 α||Î-I||₁+(1-α)(1-SSIM)，幅度项对 δ/ε 做 L2，平滑项在同对象相邻锚点边上用空间-语义亲和 γ_jl 加权。实现：PyTorch + A100 80GB，M=8192 锚点、每高斯 8 个同组邻居，AdamW lr=4e-4、weight decay 0.05、α=0.8、λ_mag=0.01、λ_smooth=0.001；每 5 帧精化一次，N3DV 100 步、Meeting Room 200 步、Google Immersive 300 步，IGS 与本方法共享初始化与精化预算。

## 实验与结果
- N3DV 留出场景：PSNR 33.046 dB、DSSIM 0.019，对比 IGS 的 32.877 dB / 0.020，提升 0.169 dB
- 参数量 27.27M vs IGS 21.90M
- Google Immersive：23.798 dB vs IGS 23.599 dB（+0.199 dB）
- 三数据集等权平均 29.045 dB / DSSIM 0.042，优于 IGS 的 28.855 / 0.043
- 跨域 Meeting Room（仅用 N3DV 训练、不重训神经权重）：30.290 dB vs IGS 30.088 dB（+0.202 dB）
- 平均 PSNR 29.045 dB 只用 594 次精化，QUEEN 以 29.486 dB 领先但用了 2,994 次精化（约 5.04 倍）
- 关键帧间退化：0→4 帧的平均 PSNR 跌幅从 0.622 降到 0.565 dB（N3DV，-9.2%），从 1.927 降到 1.662 dB（Meeting Room，-13.8%）
- 锚点预算消融：Meeting Room 上仅 1,024 锚点即 30.201 dB，比 IGS 的 29.860 dB 高 0.113 dB（少 8 倍锚点）
- N3DV 1,024 锚点 32.822 vs 32.741
- 精化效率：N3DV 用 100 步达 32.995 dB / 2.13 s/frame，IGS 用 200 步为 32.952 dB / 2.95 s/frame（省 27.8% 时间）
- Meeting Room 200 步 29.777 dB，与 IGS 400 步相差 0.057 dB 而省 33.5% 时间
- 注意：全表最高 PSNR 仍是 QUEEN（N3DV 33.512 dB、平均 29.486 dB），本方法在在线方法中排第二
- 运行时间 2.30 s/frm（N3DV）与 2.18（MR），高于 IGS 的 2.00 / 1.96

## 创新点与贡献
- 把“锚点预算分配”“运动传播范围”“局部非刚体修正”三件事统一到对象粒度上，而不是各自独立优化：锚点不再按空间覆盖（FPS）或层级（ReConGS）分配，而是用已完成区间的实测光流为每个对象组算运动分，再以 sqrt(N_o)(1+ω_o) 重新分配固定预算
- 传播不再跨对象插值，而是硬约束在同组 8 近邻内，从机制上消除边界处的运动串扰
- 修正项也不再是纯学习的残差，而是以 Kabsch 刚体拟合为条件，让网络只学“刚体之外”的那一小部分形变，从而在不增加精化次数的前提下补上褶皱这类局部非刚性
- 相对 H3D-DGS、ComGS 这类同样讲对象/运动感知的工作，本文的新意在于把刚体估计当作残差学习的条件变量（rigid-conditioned），并给出与之配套的组内受限传播与运动加权预算三者耦合的完整流式管线

## 局限与风险
- 作者自述三点：其一，方法依赖对象分组质量，SAGA 分组不准会直接限制对象感知的运动传播
- 其二，刚体机制假设每个对象组存在一个有用的主导刚体变换，对铰接物体（articulated objects）会失准
- 其三，学习到的局部形变只更新高斯位置，不修正朝向、尺度与外观
- 从实验设计还能看出：增益幅度很小（0.169–0.202 dB），作者自己也承认各组件的收益并非可加，完整模型在 N3DV 与 Meeting Room 上分别比最佳单项配置低 0.013 dB 与 0.002 dB，说明提升接近噪声量级
- 代价是每帧多 0.22–0.30 s 与更多参数（27.27M vs 21.90M），且全表最高 PSNR 仍由 QUEEN 取得
- 对象组只在第 0 帧分割一次，长时间流式下分组是否会漂移未做评估
- 训练/测试场景仅 5 个留出场景，缺乏用户主观实验
