# 带纹理物体的水密网格优化

## 一句话结论
在水密三角网格上联合优化几何与视角相关外观：DTU Acc 1.10 mm 最优，且是唯一同时流形/水密/无自交的输出（AR 1.19 vs 3.63）。

## 要解决的问题
从图像重建可用于 XR 内容生产、动画与物理仿真的 3D 资产，需要同时满足几何精度、可渲染外观与网格自身品质（连通、流形、水密、三角形形状良好），但既有方法总是顾此失彼。3DGS 与 2DGS 只有光度损失，primitive 互不连通，必须用 TSDF 融合或 Poisson 重建提取表面；这种后处理是破坏性的——Triangle Splatting 的 PSNR 从直接渲染的 33.32 dB 掉到融合后的 19.10 dB，2DGS 从 32.49 dB 掉到 19.78 dB，且常出现孔洞与细节丢失。MeshSplatting 用 restricted Delaunay 给三角形汤加连通性，但输出非流形：DTU 上 NMVR 0.34、NMER 0.21、自交比 SIR 0.83，在 AriaDTC 的 angle 与 bird-vase 两个场景甚至完全产生不出可测几何（作者因此只能对 6 个场景取平均）。而直接优化连通网格并不平凡：图像空间梯度噪声大、空间不一致，顶点位置会震荡、收敛差，必须用极小学习率并叠加与主目标相互竞争的正则。Nicolet 等人的 Laplacian 预处理能缓解这一点，但其实验仅限于恒定反照率的合成场景，扩展到真实纹理物体、同时还要维持三角形形状，一直未被解决。

## 方法详解
输入为 RGB 图像、SfM 位姿与稀疏点，先取稀疏点凸包作为初始水密网格 M=(V,F,C)，V∈R^{N×3}，每顶点存到 d=3 阶实球谐系数 C∈R^{N×B×3}（零阶为视角无关颜色）；额外用一个同外观模型的 skybox 网格充当背景梯度汇，从而在完全不用分割掩码的前提下让前景网格专注物体。几何在微分坐标下优化：取组合 Laplacian L=D−A（A 为邻接矩阵、D 为度对角阵），定义 M=(1−α)I+αL，0≤α<1，U=MV，V=M⁻¹U，即 Nicolet 的 I+λL 的缩放形式（λ=α/(1−α)）。对 U 施加 Adam：m_t=β1 m_{t−1}+(1−β1)G_t，s_t=β2 s_{t−1}+(1−β2)(G_t⊙G_t)，用偏置校正后的 m̂_t、ŝ_t 更新 U_{t+1}=U_t−η_t·m̂_t/(max_{i,c}√ŝ_{t,ic}+ε)，再解 V_{t+1}=M⁻¹U_{t+1}；分母对全部动量分量共享，以保持各分量相对幅值，因此无需显式 Laplacian 平滑罚项。连通性不变时缓存稀疏 Cholesky 分解，重网格后重建 M、重算 U 并重置优化器状态。重网格沿用 Botsch–Kobbelt 各向同性流程（split / collapse / edge flip / 切向松弛），并耦合曲率自适应尺寸与显式面预算：由一环法向差与边长估计 κ_i=[mean_j‖n_i−n_j‖²/‖v_i−v_j‖²]^{1/2}，面积加权均值 κ̄=(1/A)Σa_iκ_i；给定面预算 B，目标边长 h_i=sqrt(4A/(√3B)·(1+wκ̄)/(1+wκ_i))，w=0 退化为均匀，w 越大高曲率处边长越短；边目标长度取两端平均，达到预算后禁止分裂，从而在不加角度/长宽比硬约束的情况下逼近等边三角形。损失为 L=λ_ssim·L_ssim+λ_ncc·L_ncc，其中 L_ssim=(1−η)|Î−I|+η(1−SSIM)；L_ncc 不用平面单应，而是用网格的真实深度把参考图 patch 逐像素 warp 到支持视图（双线性采样），仅当全部像素都命中网格且落在源图内时该 patch 计入，L_ncc=(1/|P|)Σ(1−NCC)。训练配置：nvdiffrast 光栅化，5000 次迭代，batch 4，每 150 次重网格、第 4500 次停止，λ_ssim=1.0、λ_ncc=2.0，全图半分辨率，单卡 NVIDIA TITAN RTX。

## 实验与结果
- DTU 七个场景（scan055/065/106/110/114/118/122）：Chamfer 精度 Acc 1.10 mm 为全部方法最优（MeshSplatting 1.38 mm、2DGS 后处理 1.15 mm），整体 Ovr 0.90 mm 仅次于 MeshSplatting 的 0.88 mm，完成度 Comp 0.70 mm
- 网格内禀质量：平均归一化长宽比 AR 1.19（接近等边的 1.0），SIR、BER、NMVR、NMER 全为 0
- MeshSplatting 对应为 AR 3.63、SIR 0.83、NMVR 0.34、NMER 0.21，即 MODL 是唯一同时流形、水密、无自交的输出
- AriaDTC 八个真实物体场景：Ovr 1.06 mm，对比 MeshSplatting 8.56 mm（降低 87.6%）
- PSNR 26.04 dB 对比 16.95 dB（+9.09 dB），SSIM 0.858 对比 0.612
- 外观上并不全面领先：DTU 上 PSNR 25.33 dB / SSIM 0.888，低于 MeshSplatting 的 28.92 dB / 0.901，但远高于经 TSDF 后处理的 2DGS（19.78 dB）与 Triangle Splatting（19.10 dB）
- 消融去掉多视 NCC：Ovr 从 0.90 mm 恶化到 2.66 mm（约 3 倍），Acc 1.10→3.01 mm，证明表面重投影一致性是主要几何约束而非可有可无的正则
- 消融改用 Dunyach 等人的自适应重网格：Ovr 1.79 mm、PSNR 22.13 dB、AR 2.24，说明本文的曲率-面预算尺寸场在几何与外观上都更优
- 消融去掉 skybox：PSNR 从 25.33 dB 降到 21.63 dB（−3.70 dB），Ovr 0.90→0.97 mm，验证无分割条件下背景梯度汇的必要性
- 原语数量 497K，比 2DGS 后处理的 825K 少约 40%、比 MeshSplatting 的 776K 少约 36%，同时几何更准且无自交

## 创新点与贡献
- 首个仅用 RGB、位姿与稀疏点，不要分割掩码、深度、法向或 alpha 混合，直接在真正不透明的水密连通网格上联合优化真实纹理物体的几何与视角相关外观。
- 把 Laplacian 预处理的微分坐标优化与曲率自适应重网格、显式面预算耦合：既获得跨面传播的空间一致梯度（可重建仅在少数视角可见的部位，如兔子耳朵），又避免分辨率失控与劣质三角形。
- 以网格真实深度逐像素 warp 的多视 NCC 替代平面单应假设，使遮挡与深度不连续处的一致性度量仍然成立。
- 提出 skybox 作为无分割条件下的背景梯度汇，让前景网格在没有掩码时也能收敛。
- 用统一的可渲染表示避开后处理导致的光度崩塌（33.3→19.1 dB），把渲染、几何与网格工艺统一到一个优化过程。

## 局限与风险
- 作者自述：重网格保持初始网格拓扑，因此无法改变 genus，凸包初始化把可表达的拓扑锁死，拓扑变化留作未来工作（不过深凹结构如头骨眼窝仍能重建）
- 从实验设计看：验证规模很小，仅 DTU 7 个物体与 AriaDTC 8 个物体，没有场景级、室内大尺度或多物体组合
- 对比基线只有 2DGS、Triangle Splatting、MeshSplatting 三个，未与 NeuS2、Neuralangelo、MILo、T2-Splat 等更强几何方法同台
- DTU 相机只覆盖物体前半球，方法对 360 度覆盖的依赖在 AriaDTC 才被满足，覆盖不足时的退化未量化
- 外观指标明确落后（PSNR 低 3.6 dB），作者未讨论这一取舍在内容生产中的可接受边界
- 未报告运行时间、显存与单场景耗时，5000 次迭代加半分辨率难以判断可用性
- 仅项目页，无代码，可复现性受限
