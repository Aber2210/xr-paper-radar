# reVISit-XR：让 XR 进入可嵌入、可追踪、可回放的可视化研究

> 批次：2026-10-19 补漏批次（公告日 2026-10-06，拉取日 2026-10-19，积压补漏非当日新提交）。

## 一句话结论
把 WebXR 刺激做成 reVISit 研究生命周期的一等组件：XR 场景契约 + 语义 provenance 捕获 + 语义状态再水化回放，使 XR 可视化研究可嵌入、可追踪、可回放；NSF 资助，基于开源 reVISit 生态。

## 要解决的问题
XR 日益成为实证可视化研究场景，但研究相关状态分散在头显/手柄位姿、场景配置、选择、空间布局、AR 锚点里；现有工具只覆盖工作流片段（场景创作/交互/会话分析之一）。

## 方法详解
Stimulus Build Package 构建 WebXR 刺激 → Study Integration Package 嵌入 reVISit 研究 → 交互中收集响应与语义 provenance → 会话经 semantic state rehydration 回放检查。

## 实验与结果
用法示例 + 部署/数据管理说明；工具论文，证据以系统能力与可复用性为主。
