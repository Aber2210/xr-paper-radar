# TFD-SfM：无轨迹稠密运动恢复结构

## 一句话结论
从严格冷启动（相机位姿取单位阵、FOV 取 45°、深度与方差全设 1.0）联合优化外参、焦距与几何，在 ETH3D 上取得 RRA@5°=97.9、RTA@5°=91.4、ACC@5cm=69.9、COMP@5cm=44.0，其中 RTA@5° 高于 COLMAP 的 91.2 与把 DKM 稠密匹配硬塞进 COLMAP 的 65.5；DTU 为 99.4 / 90.0，Mip-NeRF 360 为 100.0 / 99.2。

## 要解决的问题
经典 BA/SfM 依赖精确的 metric 初始化与已知内参，并把 2D 观测当无噪测量；现代稠密匹配器（DKM、RoMa、LoFTR）能给出高召回对应，但刚性 track-building 启发式在其噪声下崩溃——把稠密特征直接灌进 COLMAP 会淹没优化（COLMAP+DKM 在 ETH3D 的 RTA@5° 从 91.2 掉到 65.5）。已有 initialization-free 路线（pOSE 的伪物体空间误差、expOSE 的指数深度参数化、Building Rome with Convex Optimization 的凸松弛加学习深度先验）扩大了吸引域，却仍依赖手工超参，且不能可靠处理尺度漂移与镜像（深度反转）歧义；端到端回归路线（DUSt3R、MASt3R-SfM、VGGSfM、VGGT）鲁棒、但更像黑箱，缺几何透明度且大场景易 OOM。缺口是一个既无位姿/内参先验、又能直接吃稠密匹配、并显式建模不确定性与镜像歧义的几何求解器。

## 方法详解
三阶段：LoFTR 建 view graph 与其最小生成树、DKM 提稠密对应（下采样到 64×64 网格）、在稀疏视图图上从冷启动迭代优化边权与全局场景。(1) 运动学参数化：固定 MST 根相机 r 为单位阵，其余相机只优化相对父节点 P(i) 的 6-DOF δ_i，T_{P(i),i}=exp(δ̂_i)，绝对位姿沿路径连乘 T_{ri}=∏exp(δ̂_j)；用 parallel prefix scan 把绝对位姿计算从 O(N) 降到 O(log N)，树上的链式传播天然平滑优化景观。(2) 概率路标：每个匹配 u_i 提升为各向同性 3D 高斯 G(p_i, σ_i²I)，均值 p_i=π^{-1}(u_i,d_i,K_i)，深度 d_i 与方差 σ_i² 由可优化 32×32 参数图采样；刻意用各向同性（而非各向异性）避免早期对错误位姿/内参/几何快速过拟合，旋转不变性把 loss basin 压平、收敛半径更大。(3) 统一 NLL：2D 重投影项 L_2D=½·r^T Σ_2D^{-1} r + ½·log det Σ_2D + log 2π，Σ_2D=J Σ_3D J^T，J 为投影雅可比；3D 软空间约束 L_3D=‖p_{i→j}−p_j‖²/(2(σ_i²+σ_j²)) + 3/2·log(σ_i²+σ_j²) + 3/2·log 2π，不强制共享同一 3D 点，而是最大化两个高斯的重叠——对应点要么靠近、要么放大方差，从而吸收离群匹配。(4) 自适应边权：按每条边 NLL 相对其节点邻域做 z-score 归一化，w_ij=0.5·sigmoid(−L̄_ij)+0.5·sigmoid(−L̄_ji)；再用 EMA 平滑成 W^(t)（t≤5000 时 α=0，之后 0.0001，保证几何先稳住再剪边），并对 W 做 stop-gradient，防止优化器把权重压到 0；最终 L_world=Σ sg(W_ij)·L_ij。(5) 镜像对称正则：并行优化主世界与镜像世界（M=diag(−1,−1,1,1)，T^mir=M·T·M），前 2000 步用 λ_mir 从 100 线性衰减到 0 把次假设拉向反射轨迹，收敛后取 L_world 更小者，从而跳过深度反转的局部极小。(6) 自定义 CUDA 求解器，AdamW 迭代 30,000 步。

## 实验与结果
- ETH3D（13 场景）平均：RRA@5° 97.9 / RTA@5° 91.4 / ACC@5cm 69.9 / COMP@5cm 44.0；对照 COLMAP 91.4 / 91.2 / 56.3 / 5.8，COLMAP+DKM 67.5 / 65.5 / 26.7 / 6.5，COLMAP+RoMa 67.3 / 59.1 / 32.1 / 6.7，VGGT 96.2 / 81.1 / 68.5 / 21.9。
- DTU（15 个物体中心场景）平均：RRA@5° 99.4 / RTA@5° 90.0；Mip-NeRF 360（7 个 360° 场景）平均：RRA@5° 100.0 / RTA@5° 99.2，证明冷启动可扩展到 360° 与物体中心两类极端几何。
- IMC2021（野外、内参不一致、近平面）：RRA@5° 77.3 高于 COLMAP 66.3，但 RTA@5° 50.0 低于 COLMAP 62.7；作者归因于 scale–focal 歧义（平面场景缺视差，f 与 Z 可同比例缩放而重投影不变）。
- 组件消融（ETH3D / DTU，RRA@5° / RTA@5°）：仅相对位姿（RP）不收敛 3.6/1.6 与 18.8/8.3；加软空间约束（SSC）53.9 → 再加 RP 86.4 → 再加自适应边权（AEW）91.4 → 再加镜像正则（MSR）97.9；MSR 使 DTU RTA@5° 由 18.4 跃到 90.0。
- 图密度与 3D 权重：N_neig 从 MST 增到 5 时约束不足、精度最低，增到 20 后饱和；W_3D=0 时所有图配置近乎零精度（优化完全失败），W_3D=1.0 在各密度下均为峰值，故默认 N_neig=20、W_3D=1.0。
- 效率：单张 L40S、30k 迭代下 ETH3D 收敛耗时 400–1200 s；COLMAP+DKM/RoMa 在 facade 等大场景因稠密 track 合并膨胀到数千秒；VGGT 前馈延迟最低。MASt3R-SfM 在 L40S 上 7 个场景只跑通 4 个，且在 Mip-NeRF 360/ETH3D 出现 OOM。
- 收敛行为：前约 15,000 步 RRA/RTA 已接近最优，后 15,000 步只换边际提升，呈现一阶优化的「长尾」，因此统一采用 30,000 步。

## 创新点与贡献
- 用各向同性 3D 高斯 + 统一 NLL 取代刚性 track：把 2D 匹配置信度显式传播成 3D 体积不确定性，不可靠匹配自动获得大方差、对损失贡献趋零，噪声被吸收而不是被丢弃。
- 运动学相对位姿参数化：MST 上的 6-DOF 链式传播 + parallel prefix scan（O(log N) 算绝对位姿），让冷启动的梯度沿树流动，避免全部相机独立优化时的停滞。
- 双假设镜像正则：并行维持主/镜像两个世界，用退火把次假设约束到反射轨迹、收敛后按 NLL 选优，直接消解单目 SfM 的深度反转歧义（DTU RTA 18.4→90.0）。
- 自适应边权（局部 z-score + EMA + stop-gradient）在稀疏视图图上抑制错误拓扑，绕过 O(N²) 全匹配，同时保持全局循环一致性。

## 局限与风险
- 作者承认：一阶求解器有明显「长尾」，需 30,000 步才收敛，比 Levenberg–Marquardt 慢；这是为避开 Hessian 的 O(N³) 内存、避免稠密 BA 的 OOM 而做的取舍。
- 作者承认：scale–focal 歧义在近平面场景（IMC2021 的建筑立面）会同时放大 f 与 Z 而保持重投影不变，导致 RRA 高、RTA 低（50.0 vs COLMAP 62.7）；因为 ProBA 是全局冷启动，没有 COLMAP 那种「强视差图像对 + PnP 锁尺度」的机制。
- 作者承认：为了纳入每一个观测（而非像 COLMAP 那样丢弃歧义对应），全局优化必须容忍更高噪声与几何歧义，偶发以 metric 精度换场景完整性。
- 我在正文发现：根相机被硬固定为单位阵，全局尺度与坐标系完全由 MST 结构与根选择决定，但正文没有报告不同根/不同 MST（LoFTR 相似度阈值）下的方差，复现时的随机性未量化。
- 我在正文发现：Table 1 中 COLMAP 在 DTU 与 Mip-NeRF 360 两列数值完全相同（61.0/100.0/100.0/51.6/88.7/96.2），疑为排版或复制问题；引用该表的对比结论前需回原文核对。此外 v2 命名 ProBA、v3 改名 TFD-SfM，摘要说「competitive … leads on ETH3D」应与 IMC2021 RTA 落后 COLMAP 的事实并读，不宜表述为全面领先。

## 与文献库的关系
在重建与 SLAM 主线里，前馈几何基座一支（VGGT 及其注意力改造、HyVGGT-VO、F2SLAM、SURE_Map、Metric-GS 的度量尺度选择、DUET4D 的稀疏视角）走「学先验 + 回归」，本文走「几何 + 概率优化」：不预测点图，而把稠密匹配的概率不确定性显式优化。二者可串联——把 TFD-SfM 当作 3DGS/NeRF 的冷启动 BA 后端，替代 COLMAP 的 track-building；相对 COLMAP-Free 3DGS 一类免 SfM 方案，它仍显式输出内参与度量位姿，适合量测型数字孪生。相对 pOSE、expOSE 等 initialization-free BA，关键差异是「软 3D 共享 + 双假设镜像正则」；相对 MASt3R-SfM/VGGSfM，它保留几何透明度且内存可控。
