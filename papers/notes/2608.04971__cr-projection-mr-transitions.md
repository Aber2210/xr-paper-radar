# 探索投影与头显之间的跨现实转场：面向沉浸式数字艺术

## 一句话结论
在 N=24 的被试内实验中，把投影–MR 的空间/外观/时延一致性人为劣化（10 cm 偏移、10° 旋转、15% 放大、投影饱和度与对比度各降 50%、同步加 100 ms 延迟）后，presence 由 4.82 掉到 3.85（Wilcoxon p<.001, r=.88）、NASA-TLX 由 23.47 升到 36.32（ΔM=12.85, p<.001）、Scene 1 精密交互耗时由 212.67 s 增到 295.58 s（多 82.92 s, p=.0015），说明跨显示不一致沿「动作–结果可预测性」「审美一致性」「响应感」三条通路损害体验。

## 要解决的问题
沉浸展陈里大幅投影与 MR 头显常并列存在，但把两者当作同一个体验来设计 transition 的实证依据很少。已有 hybrid user interface 研究多关注功能协同（沉浸式分析、专家工作流），CR transition 文献又集中在游戏娱乐或框架层；object-level 与 environment-level transition 通常分开评估，且很少落在「体验驱动」的投影–MR 场景。具体缺口有三：哪些线索（空间对齐、外观、跨设备时延）主导感知到的 transition 质量不明；这些线索如何影响 presence 与 workload 缺量化证据；数字艺术常用的 static mesh、skeletal mesh、particle 三类资产对同一不一致是否敏感度不同未知。作者据此提出 RQ1–RQ3。

## 方法详解
系统分三层：投影端两台吊装投影仪（wall 1920×1200 / 3.45×2.17 m，floor 1920×1080 / 4.2×2.37 m，i9-14900HX + RTX 4090 Laptop + 64 GB）；MR 端为 Meta Quest 3 一体机；中间是校准–同步层，UE5 C++ 双实例 + 自定义 UDP client–server 同步物体状态、交互事件与校准数据。空间校准把每块投影面与 MR 中同尺寸平面 proxy 对齐：记录参考标定物在投影系与 HMD 系的位姿 T_PC、T_HMD，得 T_PC→HMD = T_PC^-1·T_HMD；其余屏幕按 T_screen_i^(PC) = T_screen_i^(HMD)·T_HMD→PC 并入同一混合坐标空间，运行时用 T_obj^(HMD) = T_obj^(PC)·T_PC→HMD 变换物体与相机。物体级 transition 用「空间分割渲染」：物体穿过投影面时，面内部分只在投影上画、面外部分只在 MR 里画，标定一致时两部分被看成同一物体；交互为射线选取加近距抓取/推动。场景级 transition 有两种：投影–AR 之间用局部扩张效果逐步替换场景以保住空间连续；AR–VR 之间用 portal 让人与动画资产一起穿行。实验对照 calibrated 与 bundled inconsistency：对 AR 相对投影加 10 cm 右移、10° 顺时针、15% 放大；投影端饱和度与对比度各降 50%；同步通道加 100 ms 延迟。作者明确声明这些量级只作诊断性对比，不构成感知阈值或硬件指标。四个场景依次为刚性球精密击打、粒子云加蝴蝶与花、大尺度动画加 AR→VR portal、VR 终点。

## 实验与结果
- 被试与设计：N=24（7 女 / 17 男，23–36 岁，M=27.7，SD=4.0），被试内两条件、顺序按 G1/G2 两组平衡，21 人完成半结构访谈，全程约 40 min。
- Presence（PQ 19 项 7 点均值）：calibrated 4.82±0.53 → inconsistent 3.85±0.70；差值非正态（Shapiro–Wilk p=.002），Wilcoxon W=0.00, p<.001, z=-4.29, r=.88。
- 任务负荷（Raw NASA-TLX 六分量均值，0–100）：23.47±11.19 → 36.32±15.85；t(23)=4.33, p<.001, dz=0.88，ΔM=12.85，95% CI [6.71, 18.99]。
- Scene 1 精密任务完成时间：212.67±124.40 s → 295.58±166.15 s；t(23)=3.60, p=.0015, dz=0.74，平均多 82.92 s（95% CI [35.29, 130.54]）。
- 线索显著性（21 位受访者计数）：外观不匹配 20/21 最常被察觉，空间错位 13/21，延迟 10/21；错位在球体精密交互中最突出（12/21），色彩差异在花等细节静态资产上被点名 9/21。
- 资产类型敏感度：静态网格最易暴露不一致（12 人指球体、9 人指花）；骨骼网格较弱且混合（8 人认为蝴蝶/鲸鱼两场次「基本一样」）；粒子效果最宽容，仅个别人察觉拖回投影时「3D 感变 2D 感」。
- 整体连通感：6 人报告整体连贯、5 人在低一致场次报告割裂；7 人明确称赞 portal，8 人比较两场次时只在扩张式场景切换上察觉平滑度/延迟差异。

## 创新点与贡献
- 把 object-level 与 scene-level transition 放进同一个体验驱动的沉浸艺术装置联合考察，而不是分开做受控实验，补上「投影–MR 混合场景里两类 transition 共同作用」的实证空白。
- 以过渡可供性（transitional affordance）拆出空间对齐 / 外观一致 / 时延响应三维线索，并把它们分别接到 presence、workload 与任务时间上，给出线索→机制（动作–结果可预测性、审美一致性、响应感）的解释框架。
- 引入「资产类型」作为调节变量，给出 static / skeletal / particle 三类资产对同一不一致的差异化敏感度证据：静态最诊断、骨骼转向运动印象、粒子充当感知缓冲。
- 开源 Unreal Engine 插件 HUICRSync（GitHub 仓库 + Zenodo 归档 DOI），把双实例状态同步与投影–HMD 标定做成可复用组件。

## 局限与风险
- 作者承认：三条线索被打包成 bundled 条件，无法归因到单一线索，结果不能当作标定误差、色差或时延的可接受阈值与硬件指标。
- 作者承认：单一硬件与单一应用、单人使用、仅 wall+floor 两块投影面；Quest 3 passthrough 残留模糊、锐度下降、曝光与色偏无法消除；标定物随用户移动会轻微漂移；calibrated 基线本身也带有可感知的渲染–同步延迟。
- 作者承认：样本性别偏斜（17 男 / 7 女），定性结论依赖事后自陈，未做多轮适应或行为指标（命中率、错误率）。
- 我在正文发现：presence 的 r=.88 与 TLX 的 dz=0.88 效应量很大，但这是三条线索同时劣化的叠加结果；全文没有单因素消融，也没有剂量–反应曲线，因此三条机制目前只是访谈归因，不是因果识别。
- 我在正文发现：HUICRSync 只声明同步物体状态、交互事件与校准数据，论文未报告同步频率、抖动分布或端到端延迟实测值；「100 ms」是注入量而非系统本征延迟，复现注入条件需自行反推 UDP 参数。

## 与文献库的关系
在文献库的「混合显示一致性 / CR 体验评估」线上，本文与投影补偿类工作互补：vacomp 做视角感知的投影补偿、splatxr 做头显端多层工具包，它们解决单侧显示的正确性，本文解决跨两侧切换时的感知连续性。相对 CR transition 主线，Feld et al. 评估任务驱动下 cut/fade 的效率偏好，Husung & Langbehn 比较 portal 与 orb，Gottsacker et al. 讨论空间认知残留，本文把评估对象下移到 object-level 的跨显示一致性，并新增资产类型这一调节维度；相对 Fischer et al. 的投影仪↔AR 眼镜虚拟物体过渡，本文用分割渲染而非路径动画，并给出 N=24 的 presence/workload 量化与访谈计数。
