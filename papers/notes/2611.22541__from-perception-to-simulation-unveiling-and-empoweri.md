# 从感知到模拟：揭示并增强多模态大模型中的心理空间动力学

## 一句话结论
把无中间视觉反馈的多步空间状态推演形式化为 SSP/FSP/DPT 三档基准，SpatialWalker-3B 从 12.54% 提到 46.35%，仍低于人类 74.73%。

## 要解决的问题
现有 MLLM 空间推理研究与基准基本假设静态环境，只需对输入图像/视频做单次感知即可定位物体。真实环境是动态的：给定语言描述的动作序列后，模型必须在不看中间画面的情况下推演空间状态如何演化（作者称为 spatial simulation），而这一能力缺乏系统评测。已有心理模拟工作多局限于孤立物体或受限视角，未覆盖长程状态转移。

## 方法详解
构建 MentalGrid 基准：用 Habitat-Sim 从 ReplicaCAD、ArchitecTHOR、iTHOR、ProcTHOR、RoboTHOR 采集 349 个场景，渲染 1,100 张多视角图，生成 3,356 个 QA。状态定义为 S_i=(P_i, v_i, o_i)，P_i 为物体 2D 坐标集合，v_i 为 agent 位置，o_i 为 agent 朝向；动作为平移 f_t 与旋转 f_r 两类映射。按状态下标划分三任务：SSP（i=0，静态感知基线）、FSP（i=n，预测终态）、DPT（0<i<n，追踪任意中间态及相邻转移）。查询分 Distance-Object、Object-Distance、Direction-Object、Object-Direction 四类，并区分 allocentric（ALLO）与 egocentric（EGO）参考系。质量控制包括剔除占图像像素 <0.1% 的物体、去除重复/近义类别场景、以距离阈值排除 2D 投影垂直重叠。训练侧构造 16k QA（5,368 SSP / 5,289 FSP / 5,294 DPT），刻意排除 ArchitecTHOR 与 iTHOR 作域外测试；用 GPT-5-mini 逐步推理生成 CoT，仅保留准确率 >0.9 的轨迹。采用三阶段课程：Stage 1 在 SSP 上 SFT 建立感知锚定；Stage 2 在 FSP+DPT 上联合 SFT，用终态目标与过程目标互补；Stage 3 在 DPT 上用 GRPO 强化学习，奖励由格式模板分与预测状态对 ground truth 的准确分组成。基座为 Qwen2.5-VL-3B，得到 SpatialWalker-3B。

## 实验与结果
- MentalGrid 上 12 个 MLLM 评测：最佳 Gemini-3.1-Pro 仅 58.93%，低于人类 74.73% 约 16 个百分点
- 开源模型多在随机水平附近
- SpatialWalker-3B 总体 46.35%，比基座 Qwen2.5-VL-3B 的 12.54% 提升 33.81 个百分点，并超过 Gemini-3-Flash 的 45.24%
- 域内平均 47.79%（+35.63）、域外平均 44.35%（+31.29）
- 域外 DPT 达 49.01%（+44.09），为各模型最高
- 外部基准（MindCube / OmniSpatial / STARE）总体 41.42%，比基座高 4.92
- OmniSpatial 动态推理（DR.）单项提升 18.81
- 消融：去掉 Stage 2 总体掉 15.5%
- 去掉 Stage 3 掉 3.2%
- 去掉 Stage 1 静态感知掉 6.8%，但 DPT 反升 3.4%
- 诊断实验：物体数 >20 时 SSP 准确率急剧下降，而 FSP/DPT 对场景复杂度不敏感
- 动作步数增加时 FSP 明显退化并收敛回原始输入水平

## 创新点与贡献
- 把「无中间视觉反馈的多步空间状态推演」形式化为可评测任务，并用 SSP/FSP/DPT 三档下标统一定义静态感知与动态模拟，使感知误差与模拟误差可分离（相对 drop 率）
- 基准的场景、动作序列与答案由模拟器真值程序化生成，避免了真实采集无法获得任意旋转平移真值的问题
- 训练侧把诊断结论（低复杂度受感知制约、高复杂度受长程推理制约）直接映射为三阶段课程，形成诊断到课程的闭环

## 局限与风险
- 任务刻意不考虑物体位姿、材质、碰撞等物理因素，因此不能覆盖真实世界中带物理约束的空间模拟
- 由于需要对物体与 agent 做任意旋转平移、真实采集成本过高，全部场景均为仿真生成，作者仅以域外实验结果论证向真实场景的迁移
- 此外绝对水平仍低（46.35%），与人类 74.73%、Gemini-3.1-Pro 58.93% 差距明显
