# FastWild-GS：紧凑逐图外观自适应的分钟级野外高斯泼溅

## 一句话结论
在 PhotoTourism 三场景上以 8.8 分钟/场景（单张 RTX 5090）达到 25.52 dB PSNR / 0.874 SSIM / 0.1461 LPIPS，LPIPS 为对比方法最低且比 LPIPS 次优的 AsymGS 快 23 倍；NeRF-OSR 四场景 9.7 分钟达 26.00 / 0.856 / 0.152，三项指标均最优。

## 要解决的问题
互联网照片集里同一场景的曝光、白平衡与光照逐图变化，行人等瞬态物体只出现在部分照片中，一套共享的高斯颜色无法解释全部图像，这就是 in-the-wild 设定。NeRF-W 奠定的做法是给每张图一个外观嵌入并按半图协议拟合测试图外观；沿此路线，WildGaussians 用逐图 code 加逐高斯特征与小颜色 MLP，WilLaGS 把 tri-plane 外观场条件化到逐图隐码，AsymGS 走非对称双分支，但普遍是小时级逐场景优化。另一条加速路线 FastGS、DashGaussian、Speedy-Splat 把训练压到分钟级，却假设采集光度一致。真实缺口是两者的交集：既要在外观不一致的照片集上工作，又要分钟级收敛；而且这些加速方法的稠密化误差评分会把曝光差当成几何误差，在已经重建好的表面上反复新增高斯。

## 方法详解
场景仍是标准 3DGS 高斯集合，训练 30k 迭代、每次一张照片。外观模块三件套：① 每张训练图一个 128 维 Photo Appearance Token（PAT），零初始化，与高斯联合优化；② 每个高斯一个 32 维特征 f_g 加视线方向构成 Splat Descriptor，共享的小 MLP（PAT Decoder，两个 128 宽 ReLU 隐层，sigmoid 输出，视线不做位置编码）从 [f_g, e_i, d_g,i] 预测该高斯在该图中的颜色，取代球谐；③ 光栅化后对整幅渲染做逐通道仿射 exp(s_i)⊙R_i+b_i（s_i、b_i 各 3 维），以恒等变换起步用 Adam 优化。三者合计 128+6=134 个参数/图，外观状态不随场景规模增长。损失为 0.6×光度（L1 与 RMS 的均值）+0.4×(1−SSIM)+深度项+10⁻⁴‖e_i‖²；深度项是渲染深度对数与 Depth Anything 3 单目先验对数之间的 smooth-L1，先验按 SfM 点尺度对齐，权重 500 迭代前为 0、2k 线性升到 0.05、15k 后线性降到 0.005，提供与照片颜色无关的几何约束。密度控制沿用 FastGS 的多视角一致稠密化与剪枝，并加增长调度：12k 前阈值不放大、12k 起乘 0.651，另在 5.9k/8.9k/11.9k/14.9k 加四次剪枝，使早期高斯数保持很低。关键的 color-matched densification scoring：评分用的 10 个视角不渲染 PAT 颜色，而用该高斯 SfM 点色作固定球谐系数，再把该视角训练得到的 (s_j,b_j) 施加到评分渲染上，然后才计算与照片的误差；此路径无梯度、不更新变换、不额外渲染，从而避免把曝光差计入几何误差。最后 100 个迭代（28k–29.98k，每 20）做参数平均。测试时冻结高斯、特征与 MLP，只拟合 137 个参数（测试 PAT 128 + (s*,b*) 6 + 径向增益 v 3），在左半图跑 512 步 Adam，再渲染右半图评分。

## 实验与结果
- PhotoTourism 三场景（Brandenburg Gate / Sacré-Cœur / Trevi Fountain，官方测试视角 10/21/19，右半图评分，5 seeds 均值）：25.52 dB / 0.874 SSIM / 0.1461 LPIPS；AsymGS 25.62/0.872/0.150（3.50 h），WilLaGS 25.51/0.883/0.151（作者重实现 30.8 min），WildGaussians 24.65/0.851/0.179（5.65 h）。
- 训练时间：8.8 分钟/场景均值（6.1–11.8，随 0.30M→0.68M 高斯变化），为表内最短；比 AsymGS 快 23 倍；K-Planes 虽仅 15.9 分钟但 PSNR 低 4.42 dB。种子标准差 0.15 dB / 0.0017 LPIPS。
- NeRF-OSR 四场景（europa/lwp/st/stjohann，官方 mask 内右半图）：26.00/0.856/0.152，9.7 分钟；WilLaGS 25.79/0.855/0.207（27.6 min），GS-W 23.79/0.792/0.217（1.77 h），SWAG 23.00/0.801/0.270。
- 消融（PhotoTourism 均值）：去 PAT 降到 21.22 dB（−4.30），去 PAT Decoder 21.18，去 Splat Descriptor 23.53，去 channel transform 24.94，去 color-matched scoring 24.80，去深度损失 24.86；LPIPS 相应升到 0.1882/0.1867/0.1660/0.1491/0.1491/0.1498。
- 测试时拟合消融：去径向增益 v 降 0.32 dB（25.20），去 (s*,b*) 降 0.71 dB（24.81）；128/256 步为 25.13/25.45，1024 步 25.51（相对 512 步无增益）。
- 外观模块插到 6 个公开骨干（2DGS / Mip-Splatting / 3DGS-MCMC / Taming-3DGS / StopThePop / Scaffold-GS，均 30k 迭代）：PSNR 提升 6.4–7.7 dB、LPIPS 降低 0.050–0.172，例如 2DGS 17.65→24.68 dB、LPIPS 0.2618→0.1604。
- PAT 与特征维度敏感性：PAT 64/256 分别 −0.26/−0.30 dB，f_g 16/64 分别 −0.06/−0.29 dB，说明 128+32 已足够，加大不涨点。

## 创新点与贡献
- 把逐图外观状态压到 134 个参数（128 维 PAT + 6 参数通道仿射），用「共享解码器 + 逐高斯特征」把全局 token 变成高斯特异颜色，避免逐图高容量外观场。
- 提出 color-matched densification scoring：同一组 (s_j,b_j) 既用于训练渲染也用于密度评分渲染，使外观差异不被误判为几何误差，且零额外渲染、零梯度、不更新变换。
- 与生长调度（延迟降低阈值 + 四个早期剪枝位点）结合，把 in-the-wild 逐场景优化从小时级压到 8.8 分钟，23 倍于同卡复跑的 AsymGS。
- 跨骨干验证：外观模块不绑定特定密度控制，在 6 个公开 3DGS 骨干上一致提升三项指标。

## 局限与风险
- 作者承认：PAT 与通道变换是 image-global 的，只靠解码器产生空间变化，单张照片内的局部效应（如阴影扫过立面）只能被近似。
- 作者承认：不显式分离瞬态内容，仅靠多视角优化抑制；未使用不确定性或 mask 类鲁棒机制，声明与 RobustSplat 等互补。
- 作者承认：训练时间随高斯数线性增长（6.1 min@0.30M → 11.8 min@0.68M），更大集合需要比当前生长调度更强的数量上限。
- 我在正文发现：均值最优主要靠 stjohann 一个场景（30.31 dB，GS-W 26.23、WilLaGS 26.13）拉高，europa 仅 23.79 dB 低于 WilLaGS 25.50，st 23.89 也低于 WilLaGS 24.45，逐场景稳定性不如均值所示。
- 我在正文发现：Table 1/2 的 baseline 多数直接引用各自论文（不同 GPU 与迭代数），只有 WildGaussians、AsymGS、NexusSplats 用官方代码同卡复跑，WilLaGS 为作者重实现（无公开代码），因此「23×」对复跑时间敏感。

## 与文献库的关系
与 WildGaussians 共享同一条件接口（逐图 code + 逐高斯特征 + 小颜色 MLP），但把 code 压到 128 维并把全局曝光/白平衡外移到 6 参数仿射——这一仿射形式与 Splatfacto-W、hierarchical 3DGS 的曝光补偿同源，区别是本文把它同时用于密度评分渲染。相对 WilLaGS 的 tri-plane 外观场、DAVIGS 的 3D 一致特征变换、MW-GS 的 micro-macro 小波融合，本文走「极简参数化 + 共享解码」的相反方向。加速侧直接复用 FastGS 的 rasterizer 与多视角一致稠密化，借鉴 DashGaussian 的「早期少高斯」调度和 Speedy-Splat 的剪枝位点。对 AsymGS、SpotLessSplats、RobustSplat 的鲁棒性路线是互补而非替代。库内 2611.10013（video→digital twin 的 in-the-wild GS）与 2511.20348（Material-informed GS）同样面向非受控采集，但目标是数字孪生资产而非分钟级优化。
