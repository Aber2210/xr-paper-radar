# 4D 无需位姿：从未知位姿多视角视频前馈重建动态高斯

> **backfill-1024**：旧稿（replace 再公告，首次入馆），公告日 2026-10-23，非 10-24 当日新提交。

## 一句话结论
NoPo4D 首个同时满足前馈+免位姿+多视角+动态+一般场景的 4D 重建系统：velocity decomposition 用 SEA-RAFT 伪真值光流直接监督 2D 运动分量，绕开位姿依赖渲染；ExoRecon 29.15 PSNR（DGGT 20.44），post-opt 31.95 超过需位姿的 per-scene SOTA MonoFusion（30.43），快数个数量级。

## 要解决的问题
尚无前馈（feed-forward）方法同时满足动态场景、多视角输入、未知相机位姿与一般场景内容：动态前馈方法要么需要精确位姿（4DGT）要么只接受单目（NeoVerse/MoVieS），免位姿多视角方法仅处理静态场景（NoPoSplat/FLARE/AnySplat），DGGT 限于驾驶域，per-scene 优化方法每场景需分钟到小时。作者要填补这一空白象限。

## 方法详解
NoPo4D 为首个在该空白象限工作的前馈系统：以 Depth Anything 3（冻结 depth/camera heads，微调 16 层 alternating attention）为几何骨干，每像素每帧实例化一个 4D 高斯。核心是 velocity decomposition：把高斯运动分解为 per-pixel 图像平面位移 (Δx,Δy) 与深度变化 Δd，从而可直接用 SEA-RAFT pseudo ground-truth optical flow 监督 2D 分量，绕开需位姿的可微渲染与 3D 运动真值；双向 motion encoder 对跨相机跨时刻 token 做联合自注意力聚合；view-dependent opacity（球谐系数）作为学习到的置信度，缓解跨视角跨时刻高斯错位；另附可选 100 步 post-optimization。

## 实验与结果
训练约 2,900 个 Ego-Exo4D 场景（796×448），DA3 Large 骨干，4×GH200，两阶段各 20,000 步（先单相机后 1–4 相机 16 帧 batch，时间步长 4–8 预热）。ExoRecon（分布内）：NoPo4D 29.15 PSNR/0.886 SSIM/0.125 LPIPS，大幅超 DGGT(EgoExo4D) 20.44；post-opt 31.95/0.928/0.075 超过需位姿的 per-scene SOTA MonoFusion 30.43/0.930/0.060。OOD：Immersive Light Field 21.63 vs DGGT 20.65（post-opt 24.04）；Kubric 23.61 vs 20.14（post-opt 28.17）；N3DV 输入视角 28.43 vs NeoVerse 24.50（领先最强 FF 基线近 +4 PSNR），中等新视角 26.79，极端新视角 19.36。消融：去 motion branch -6.2 PSNR、去 opacity SH -7.5、去分解 -1.5、去时间编码 -1.7、去分解+去 flow 训练直接发散；去 distill -3.24、去 flow -0.96、去 consistency -1.13。扩展性：输入相机数 2→12 仅降约 4.7 PSNR（NeoVerse 约 6.9），12 相机时 <27 GB/<5 s（DGGT 约 50 GB/约 15 s）。

## 创新点与贡献
1. 系统论证并首个填补 FF+unposed+MV+dynamic+general 空白象限
2. velocity decomposition 使 optical flow 可直接监督 2D 运动分量，摆脱位姿依赖渲染与 3D 运动真值
3. 双向 motion encoder 跨视角跨帧聚合 + view-dependent opacity 处理错位
4. 可选 post-opt 超过需已知位姿的 per-scene 优化方法，速度快数个数量级

## 局限与风险
- 假设静态相机 rig，相机自身运动时质量退化（per-camera 位姿平均失效）
- 依赖 SEA-RAFT 等预训练模型的 pseudo GT，训练质量受教师模型上限约束
- 需要多路时间同步视频流；单目/异步采集与高阶时间运动仍是开放问题

## 与文献库的关系
相对 NoPoSplat/FLARE/AnySplat（静态免位姿多视角）、4DGT（需位姿单目）、NeoVerse/MoVieS（单目）、DGGT（限驾驶域）与 Shape-of-Motion/MonoFusion/Dyn3D-GS（需位姿 per-scene 优化），是首个在全部四个维度同时满足的前馈 4D 重建方法。
