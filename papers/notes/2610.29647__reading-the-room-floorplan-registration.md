# Reading the Room：稀疏 VSLAM 地图到户型图的尺度模糊语义注册

## 一句话结论
Reading the Room 用单一鲁棒、可微、类平衡的语义-几何能量函数统一全局初始化与局部精修，把尺度模糊的稀疏语义 VSLAM 地图注册到部分建成户型图：3 站点 33 轨迹，带 anchor 时 Site A 组 ATE 2.68/1.41 m，平均 ATE 较最强基线改善 4.5×（无约束）至 7.6×（带 anchor）；SIFT 32/33 失败。

## 要解决的问题
施工进度跟踪等应用需要把传感器轨迹注册到先验 2D 户型图。视觉采集低成本、易获取，但 VSLAM 地图到户型图的对齐困难多重叠加：VSLAM 只把几何恢复到未知相似变换（尺度模糊），稀疏点云与符号户型图跨模态，采集时站点仅部分建成，工地视觉重复既损伤地图质量又抹掉判别性特征。既有方法至多解决其中两项，本文要在一个框架内同时应对尺度模糊、稀疏、跨模态与部分建成四类挑战。

## 方法详解（含关键公式/架构，保留原文术语）
RR 是 global-local 注册框架，把尺度模糊、稀疏、跨模态的语义 VSLAM 地图对齐到部分建成户型图。核心思想是定义单一鲁棒、可微、类平衡的语义-几何能量函数，支配管线全部阶段——全局初始化候选的生成与局部精修都相对同一能量函数：两种初始化方案产出初始候选后，直接优化该能量函数完成局部精修，单一能量函数贯穿全管线是方法主线。两种全局初始化：① 利用用户提供的单个不准确对应（anchor）；② 用跨模态匹配网络全局估计初始化——后者直接回应 VSLAM 只恢复到未知相似变换的尺度模糊性。语义侧类集 C={wall, window, stairs}，地图标签按正文 IV-A 流程获得，与符号户型图共享类集，使跨模态对齐在同一语义空间进行。输入地图来自 OpenVSLAM 的等距圆柱（equirectangular）变体；采集设备为同步 LiDAR + 360° 影像的自建装置，LiDAR 点云仅用于估计真值轨迹，并由专家手工对齐到户型图。对齐输出为恢复的变换 S*，把 VSLAM 估计轨迹映射到户型图坐标系，支撑进度跟踪等下游应用。轨迹定位指标 ATE=sqrt((1/N)Σ_{j=1}^N ||t̂_j−t_j^GT||_2^2)，其中 t̂_j=π(S*T_j)∈R^2 为施加恢复变换 S* 后关键帧 j 的估计位置。站点按难度递进：Site A（Medium，平均 1073.5 m²、每图房间较少）、Site B（Advanced，2750.1 m²、覆盖率 88.8%）、Site C（Hard，3974.7 m²、覆盖率 28.7%，覆盖区结构对称致多个候选对齐看似合理）。

## 实验与结果（表格化关键数字）
数据：3 站点 33 条轨迹、14 楼层、2 国；Site A/B/C 难度递进（面积 1073.5/2750.1/3974.7 m²；Site B 覆盖率 88.8%、Site C 28.7%，Site A 未报）。表 I 按 ATE[m]/Recall[%] 四组栏位如实转述（digest 表头缺站点标签与 recall 阈值定义）。RR+Anchor：Site A 组 ATE 2.68/1.41、Recall 10.5/73.7/89.5；Site B 组 8.03/0.90、57.1/85.7/85.7；Site C 组 5.73/4.37、0.0/14.3/57.1；总体 4.46/1.89、18.2/63.6/81.8。RR 无 anchor：Site A 组 7.18/2.67、21.1/52.6/68.4；Site B 组 7.40/1.92、42.9/71.4/71.4；Site C 组 42.98/35.04、Recall 全 0；总体 14.82/4.34。Oracle 性能下界：Site A 组 1.46/1.01、Site B 组 0.71/0.85、Site C 组 0.59/0.26、总体 1.12/0.85。基线：SIFT+RANSAC 32/33 运行失败，唯一成功运行在 Site B（ATE 53.80 且 Recall 全 0），其总体列 53.80/53.80 系该唯一成功运行计入总体的结果；Shahbandi & Magnusson 仅 10/33 运行得有效变换（Site A 6、B 4、C 0），其 Site A 组 18.93/18.18、Site C 组全零系 0 次有效运行所致；RoMa+MatchAnything Site A 组 13.94/16.12、Site B 组 40.63/42.41、Site C 组 42.15/42.44；ICP+Anchor Site A 组 16.48/15.72、总体 24.26/21.59；Semantic ICP+Anchor Site A 组 13.50/13.40、Site B 组 21.61/11.23、总体 20.23/14.43——均逊于 RR+Anchor。无 anchor 与 +Anchor 的行间差即 anchor 消融：增益集中于 Site C（42.98→5.73）与 Site A（7.18→2.68），Site B 组第一个 ATE 数略升（7.40→8.03）而 Recall 三档全升（42.9/71.4/71.4→57.1/85.7/85.7）。摘要口径：一般无约束设置平均 ATE 较最强基线改善 4.5×，提供 anchor 时增至 7.6×。

## 创新点与贡献
- 单一鲁棒、可微、类平衡的语义-几何能量函数支配全局初始化候选生成与局部精修全部阶段
- 双全局初始化：单个人工 anchor 或跨模态匹配网络，均相对同一能量函数生成初始候选
- wall/window/stairs 语义类集把符号户型图先验注入点云注册，应对施工场地的重复结构与低判别性
- 33 轨迹/3 站点/14 楼层/2 国真实部分建成工地评测，含 Oracle 下界与运行级失败统计（SIFT 32/33 失败）

## 局限与风险
- Site C（最难：3974.7 m²、覆盖率 28.7%、结构对称）无 anchor 时 ATE 42.98/35.04 m、Recall 全 0，加 anchor 后 5.73/4.37 仍远差于 A/B
- 真值依赖 LiDAR 轨迹 + 专家手工对齐户型图，真值获取本身不可规模化
- digest 表头缺站点标签与 recall 阈值定义，跨模态匹配网络与能量函数细节需正文补齐
- 仅测 OpenVSLAM 等距圆柱变体前端，其他 VSLAM 输入的鲁棒性未知
