# SSA-3DGS：无监督去除 3D 高斯泼溅中的屏幕空间伪影

## 一句话结论
区分屏幕空间伪影与世界空间瞬态，无监督联合分解 scene/overlay，合成 Mip-NeRF 360 平均 +2.9 dB、Dashboard 类最高 +7.5 dB。

## 要解决的问题
3DGS/NeRF 假设输入是干净、多视角一致、已定位的图像，而真实采集常违反该假设：传感器坏点、镜头罩上的雨滴或泥点、手指遮挡、行车记录仪的仪表台、水印与 UI overlay。这些伪影固定在 2D 像平面而非 3D 世界，随相机运动相对场景“移动”，会被 3DGS 烤进几何成为近相机 floaters。现有 world-space transient 方法（SpotlessSplats、DeSplat、RobustNeRF）针对 3D 中变化的干扰物，逐帧 2D 修复或水印去除则缺 3D 知识、跨帧不一致且需人工 mask，都不对症。

## 方法详解
在 3DGS（gsplat 实现，ADC 与 MCMC 两种致密化都测）之上把成像写成 C(u)=A(u)·W(u)+(1−A(u))·Ĉ_3D(u)：W∈R^{H×W×3} 为伪影颜色图、A∈R^{H×W×1} 为 alpha matte，二者存为无约束张量经 sigmoid 映射，在像素坐标定义且对所有视角共享，因而与 3D 高斯的投影几何解耦。每轮先渲染干净 3D 场景得 Ĉ_3D，再叠加 overlay 与 GT 算 L1+SSIM；测试时丢弃 overlay、只渲染 Ĉ_3D。由于该分解欠约束，引入 L_sparse=mean|A(u)|（λ=0.05；对大面积遮挡的 mud 与全部真实场景用 0.01），把像素尽量交给 3D 几何解释，抑制两类退化解：把跨视角近静态的场景内容吸进 overlay，以及 overlay 退化成低不透明度均匀曝光层。初始化不用常数而用训练集逐像素统计：W(u)=μ(u)、A(u)=exp(−σ(u)/s)、s=5×10⁻²，使跨视角稳定的像素（疑似伪影）起始近不透明、变化大的像素（疑似场景）起始近透明。全流程无监督、无 mask、无预训练模型，30k 迭代，overlay 用 Adam、lr 5×10⁻³，λ_ssim=0.2；方法对致密化策略不敏感，可分别配 ADC 或 MCMC。

## 实验与结果
- 合成 Mip-NeRF 360（7 场景 × 5 类伪影，ADC）：平均 PSNR 27.398 dB / SSIM 0.773 / FLIP 0.138，对比 3DGS 24.473/0.731/0.187、SpotlessSplats 25.742/0.759/0.167、DeSplat 25.506/0.810/0.171、RobustNeRF 24.163、Difix3D+ 22.997/0.644/0.218
- 干净参考上界 27.760/0.779/0.132
- 换 MCMC 致密化后平均 29.000 dB / 0.869 / 0.122，距干净参考 29.461 dB 仅 0.5 dB
- 逐类 28.3–29.4 dB，且 MCMC 在干净场景下的不稳（bicycle 发散）被 overlay 吸收后消失
- 单类最大增益：Dashboard 20.756→28.305 dB（约 +7.5 dB）、Mud 23.210→28.947 dB、Rain spots 26.077→28.938 dB，对应摘要所称最高约 8 dB
- 自采真实数据（15 场景，ADC）：Finger 16.67 vs 最强基线 RobustNeRF 13.89 dB、Mud 19.25 vs DeSplat 16.15 dB、Occlusion 17.66 vs DeSplat 16.45 dB
- 总体 18.14 vs vanilla 3DGS 15.34 dB，DeSplat/SpotlessSplats/RobustNeRF/Difix3D+ 均在 15.3–15.6 dB
- 消融：稀疏正则使合成平均 +1.93 dB（27.075→29.000）并把渲染平均色偏 Δc̄ 从 6.43 降到 3.19
- 统计初始化换常数在合成 −1.31 dB（主要掉在 Dashboard 28.31→23.12）、真实 −1.56 dB

## 创新点与贡献
- 首次把 screen-space artifact 与世界空间 transient 明确区分并形式化：与视角无关的 2D overlay 与 3D 场景联合优化，靠运动视差和几何一致性在无监督下解耦
- 用稀疏正则把解释权优先交给 3D 几何、再用跨视角统计初始化把优化推离退化解，两个设计都是针对该分解的病态性提出的
- 副产品是恢复出的伪影层本身，可解释、可复用

## 局限与风险
- 依赖多视角共识，需要足够密集的采集，否则 3DGS 会用不被重叠视角惩罚的 view-dependent 效应去解释伪影
- overlay 假设伪影严格固定在像平面，只能部分捕捉近静态遮挡（如实拍 Occlusion 类别），完全视角相关的遮挡仍是开放问题
- 对 λ_sparse 敏感：0.05 在合成 mud 上损失 1.3 dB，0.01 在 rain 上损失 3.3 dB，需按伪影类型手调
- 真实场景绝对 PSNR 仅 18 dB 量级
