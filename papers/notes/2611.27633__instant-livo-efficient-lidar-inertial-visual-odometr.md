# Instant-LIVO：紧凑几何与有界单参考帧地图的高效 LiDAR-惯性-视觉里程计

## 一句话结论
用「有界单参考帧」视觉地图替代持续增长的地图，并以 Schmidt 不确定性融合保持参考位姿相关性：摘要级结果显示 32 个基准上平均提速约 2.3×（X86）/2.1×（ARM）、峰值内存降至 1/20 与 1/13（正文不可核，仅摘要级证据）。

## 要解决的问题
[证据等级 PARTIAL，摘要级评估] LiDAR-惯性-视觉里程计（LIVO）是自主系统的基础技术，但受物理条件限制，在资源受限平台上部署困难（算力、内存不足）。需要在保持精度的同时大幅降低计算与内存开销。

## 方法详解
提出紧耦合、高速实时的 Instant-LIVO。地图侧引入基于空间哈希 OctVox 的紧凑几何地图，并用带 cache 辅助的启发式分级 KNN 搜索加速局部邻域检索与平面拟合；视觉侧采用有界单参考帧视觉地图，按跟踪状态自适应更新参考帧，并以 Schmidt 型不确定性感知光度融合维持参考位姿与当前状态之间的相关性；多传感器融合按 IMU 预测 → LiDAR 几何校正 → 视觉光度校正的顺序串行执行。

## 实验与结果
- 平均处理速度提升 = 约 2.3×（X86 平台）与约 2.1×（ARM 平台）
- 峰值内存降至 = 约 1/20（X86 平台）与约 1/13（ARM 平台）
- 评测规模 = 32 个公开基准与自采集数据集

## 创新点与贡献
- 用「有界单参考帧」视觉地图替代持续增长的地图，并以 Schmidt 不确定性融合保持参考位姿相关性，从而在资源受限平台上同时取得提速与数量级的内存下降

## 局限与风险
