# 在流中思考：视觉语言模型的主动空间推理

## 一句话结论
把因果估计的几何编码注入 VLM 中间层、以 KV cache 当空间记忆，做流式主动空间推理：timely 71.8% / abstain 87.3%（SFT 基线 68.1/84.8）。

## 要解决的问题
人在房间中行走时只看到局部，却能不断更新对整体布局的心理模型。现有 VLM 空间评测大多在预定义查询时刻作答，模型只需判断「此刻看到什么」，而不必决定「何时该回答」。Stream3D-Bench 虽允许提前给出请求，但多数问题直接规定等待时长，把时间决策外包给了标注者。真实助手场景如「当我回到这个房间时提醒我拿包」，要求模型在流式视频中自行判断空间条件是否成立，条件不成立时保持沉默；这需要跨视角维护并更新空间知识，而不是单帧识别。零样本 VLM 在该设定下及时响应率仅 17.6%，接近随机，人类为 83.1%；失败主要是过早响应与漏响应，且模型会把相似椅子或另一间浴室误认成目标，说明它们依赖外观与局部上下文，缺少可持续的空间状态。

## 方法详解
任务定义为：episode 由空间请求 q 与视频流 V=(v_0,…,v_T) 组成，模型提前收到 q，逐帧因果处理，在每步只依据已到观测决定等待或响应。首次响应时刻 t̂∈{0,…,T}∪{∞}；正例存在有效窗口 W=[t_s,t_e]，t̂<t_s 为过早、窗口内为及时、t_e<t̂<∞ 为延迟、t̂=∞ 为漏检；反例 W 为空，t̂=∞ 才算正确弃答，任何响应为误报。ProSpace-Bench 含九任务三组：物体组（Object Finding、Object Re-finding、Object Direction）、相机组（Ego Rotation、Origin Return、Visual Homing）、场景组（Place Transition、Place Entry、Place Revisit），共 3,636 个 episode、242 个真实室内场景、18 栋房屋、约 61 小时、1 fps。数据来自 ScanNet、ScanNet++、CA-1M 的官方验证集与 Matterport3D 验证/测试房；由真值位姿与场景网格导出每帧可见性、相对方位、相机运动与房间归属，据此确定响应窗口，并加入同类干扰物或「接近目标房间但未进入」的难负例。ProSpace-Train 含 100K 正例与缺席流，来自官方训练 split，与评测无场景重叠，并打乱请求时刻与窗口起点以防利用时间捷径。ProSpace-VLM 以 Qwen2.5-VL-7B 为基座：每帧由视觉编码器出 token，CUT3R 因果估计三维点图与相机位姿，点图重采样到视觉 token 网格，使 token j 对应三维点 x_{t,j}；几何编码 g_{t,j}=[φ(x_{t,j}),ψ(c_t,R_t)]，φ 为傅里叶特征，ψ 同时编码相机中心与连续 6D 旋转。编码以逐元素加法注入早到中层：h̃_{t,j}^{(ℓ)}=h_{t,j}^{(ℓ)}+f_ℓ(g_{t,j})，f_ℓ 为轻量 MLP；几何感知的 key/value 随帧累积进 KV cache，模型用因果注意力读取该空间记忆。旧帧按体素做 token 选择：每体素保留最早缓存 token，必要时增大体素直到满足预算，近期帧全保留。决策用 next-token 预测在 wait 与 respond 间选择，仅训练几何投影 MLP 与 LoRA，损失 L_resp=-Σ log P_θ(y_t|q,v_{0:t},y_{<t})；推理时 t̂=min{t≥t_q: P_θ(respond|q,v_{0:t})≥τ}，否则保持沉默。

## 实验与结果
- 人类在 900 个 episode 上 timely 83.1%、correct abstention 94.8%
- 最佳零样本 Claude Opus 5.5 仅 30.6%/45.0%，GPT-4o 24.5%/54.6%，随机时间基线 17.6%
- ProSpace-VLM 平均 71.8%/87.3%，优于 SFT 的 Qwen2.5-VL-7B 61.7%/78.7% 与 Stream3D-VLM-8B 68.1%/84.8%
- 消融：SFT 基线 61.7/78.7，加相机位姿 67.8/84.4，加点图 70.5/85.7，多层注入 70.9/85.9，全量 71.8/87.3
- 零样本迁移到 VSI-Bench、OST-Bench、UCS-Bench、OVO-S-Bench 平均 39.1，SFT Qwen2.5-VL-7B 为 37.7，Stream3D-VLM-8B 为 36.6
- 效率：5.8 FPS、峰值 21.2 GB，1,024 帧时 36.4 GB
- Stream3D-VLM-8B 仅 3.2 FPS、39.5 GB 且在 1K 帧 OOM
- 加体素 token 选择后 6.7 FPS、19.3 GB、1K 帧 19.4 GB，timely/abstention 为 70.8%/87.9%
- 基准规模：3,636 个 episode、242 个场景、18 栋房屋、约 61 小时 1 fps 视频
- 训练集 100K 条流
- 物体恒存性：目标离开视野后，由决策 token 状态线性解码的方位误差随时间低于基线
- 长流下及时率更稳，缺席流每秒误响应概率更低

## 创新点与贡献
- 提出流式视频中的主动空间推理任务，把「是否响应、何时响应、何时保持沉默」与空间理解联合评测，而非在固定时刻答题。
- 把显式三维点图与相机位姿编码注入 VLM 中间层，使原生 KV cache 直接成为带三维锚点的空间记忆，无需额外检索模块或快速权重。
- 利用 token 与三维点的对应做跨帧体素化 token 选择，在长流上同时降内存并维持实时。
- 构建九个物体/相机/场景任务、含难负例与反时间捷径设计的 100K 训练集与 3,636 episode 基准，并用线性探针与三维注意力可视化验证空间心理模型。

## 局限与风险
- 作者自述只关注响应时机，不联合评估高层推理或物理动作
- 规则化 episode 构建难以覆盖真实世界的全部空间条件
- 从实验看，1 fps 与记录式室内场景仍远离连续机器人视频，CUT3R 的位姿漂移会直接污染空间记忆，论文未报告漂移量与失败传播
- 九任务均为单一条件、单次触发，缺少多条件并发与需要长期规划的请求
- 方法只在 Qwen2.5-VL-7B 上验证，未给出 32B 或更大基座的 scaling
- LoRA 与注入层选择虽做了单层对照，但阈值 τ 的敏感性、校准与多次运行方差未系统报告
- 基准与代码未 release，复现成本高
