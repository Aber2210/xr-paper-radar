# TouchBench：视觉语言模型能感知不可见的物理属性吗

## 一句话结论
把「视觉可答性」做成基准里的受控变量，从而把「缺触觉」与「任务难」分开：四个 VLM 在不可见物理属性上 Tier B 相对准确率仅 49.8%（近随机），而可解释统计量的文本接口零样本即 62.9%、留一被试微调后 73.1%。

## 要解决的问题
视觉语言模型越来越多用于具身感知与推理，但物理理解评测几乎都构造「从图像可回答」的问题。填充量、柔软度、贴合纹理等对操作至关重要的属性只能靠触摸获得，缺少能把「缺感知」与「任务难」区分开的受控评测。

## 方法详解
构建第一视角视频 + 同步 137 通道全手触觉手套的基准 TouchBench（900 段、5 名被试、11 个任务、6 个属性维度），每个问题按视觉可答性标为 Tier A（属性可见）或 Tier B（被遮挡/在手下方），同一属性在两层共用题干与选项、只改采集条件。提出 Tactile-as-Prompt（TaP）：把 34 个可解释触觉统计量（力 14、空间 8、频谱 10、腕部 2）按固定精度与顺序序列化为一行文本插入 prompt，无需训练触觉编码器，可用于闭源模型。与学习型触觉 token 编码器在同一监督数据、同一骨干（Qwen3.5-9B + LoRA）下对比，并做留一被试微调、未见物体与 20 小时网络语料验证。

## 实验与结果
- 四个 VLM 平均 Tier B 相对题准确率 = 49.8%（Tier A 66.4%，chance 50%）
- TaP 零样本 Tier B 相对准确率 = 62.9%（仅视频 49.8%）
- 留一被试微调后 视频+TaP = 73.1%（仅视频 67.4%，学习型 token 67.3%）
- 网络规模接触问答准确率 = 67.1% → 75.5%（17,544 道评测题）
- 去掉力描述符组后 Tier B = 68.4%（全 34 维 72.9%），shuffle 掉幅从 13.0 降到 1.5 分

## 创新点与贡献
- 首次把「视觉可答性」做成基准中的受控变量以分离缺感知与任务难度
- 并证明可解释统计量的文本接口在免训练条件下可超过专门训练的触觉编码器

## 局限与风险
- 900 段/5 名被试、单只右手手套，规模小
- 跨被试增益在 0.0–12.0 分间波动
- 在同时含两层的维度上微调后 TaP 不如仅视频
- TaP 不校准绝对判断，98 Hz 采样使手机振动始终处于 chance
