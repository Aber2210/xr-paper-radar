# 金属指骨约束下电容式指尖阵列统一近距-触觉观测的机理分析

## 一句话结论
在「金属指骨 + 薄硅胶 + 共享 CDC」约束下给出显式多导体观测算子与可量化屏蔽失配门限，并用 FEM 量化双阵列对接触材料交叉敏感的抑制：接触响应 4.6 fF 到 370 fF（0.05 到 0.5 mm），远场 20 到 5 mm 仅 15.9 fF。

## 要解决的问题
电容电极可同时用边缘场感知厘米级导体目标、用介质压缩感知接触力，适合做指尖共享近距-触觉前端。但贴在金属指骨与薄硅胶下时，电极-人体寄生电容比有用近距增量大 1–3 个数量级，串扰与 TDM 建立时间又使 CDC 读数无法等同于电极-目标电容。

## 方法详解
把指尖阵列建模为多导体系统（感应电极、驱动屏蔽节点、指骨地、外部目标），由 Maxwell 电容矩阵推导 CDC 观测量，并把每个非活动电极的端接（CIN / 驱动屏蔽 / 地）显式写进观测算子。分析三条耦合机理：驱动屏蔽如何让屏蔽支路位移电流对 CDC 不可见、增益/相位失配如何以等效电容漏回；远场边缘场与近场压缩为何需要不同观测算子；TDM 建立时间如何随屏蔽负载增长成为帧率上限。提出双阵列叠层：接触时外层阵列接地作法拉第屏、内层阵列读硅胶间隙压缩，并用 ANSYS Maxwell 3D 静电场 FEM 在 Far/Mid/Contact 三种算子下验证。

## 实验与结果
- 接触压缩响应 = 4.6 fF @ 0.05 mm 至 370 fF @ 0.5 mm（1.08 pF 基值，斜率 92→2320 fF/mm）
- 远场增量 = 15.9 fF（20 mm→5 mm，raw）、3.1 fF（20 mm→10 mm）
- 电极-屏蔽耦合 C_eS = 1.467 pF（Far）/ 10.2 fF（Contact）
- 屏蔽失配 |ε_A| = 10^-3 时漏电 = 1.47 fF（约为 20→10 mm 增量的一半）
- 材料泄漏 = ≤0.3 fF（nylon vs metal，当前网格/打印分辨率，1.08 pF 基值）
- TDM 16 槽接触帧 = 约 40 ms（400 S/s，≈25 Hz）/ 约 160 ms（100 S/s，≈6 Hz）

## 创新点与贡献
- 在「金属指骨 + 薄硅胶 + 共享 CDC」约束下给出显式多导体观测算子与可量化的屏蔽失配门限，并用 FEM 量化 Faraday 双阵列对接触材料交叉敏感的抑制
- 作者明确不主张发明驱动屏蔽或双模电容本身

## 局限与风险
- 结论均为解析推导与 FEM 证据（部分网格未收敛、L2 屏按理想连续导体建模），力映射 G、机械串扰、真实屏缝隙漏电、跟随器实际失配与帧率均待台架测量
- 切向力在本结构下不可观测
