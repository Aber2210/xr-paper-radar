# MRxD：混合现实跨设备交互的使用模式框架

## 一句话结论
从 4,857 条记录经 PRISMA 流程筛出 238 篇论文、284 个 usage episode：63%（180/284）为 Focused 注意、97%（275/284）任务相关，其中 53%（145/275）认知对称；由此得六个模式，Clone（90）与 Proxy（84）最多、Standby（6）与 Partition（3）最少；三作者两两 Cohen's κ 均 > .70，工作坊（n=6）显示框架能暴露设计盲点。

## 要解决的问题
MR 跨设备（头显 + 笔电/平板/手机）设计困难，核心是用户须在角色异构的设备间协调工作流，而现有知识组织方式不足。其一，主流框架以设备与组件配置为中心：Brudy 2019 给出六维分类学，Hubenschmid 2026 的 MR-HUI 综述再加 interaction dynamics 与 anchoring，但描述的都是系统如何被组装，无法解释同一套硬件为何需要不同设计——HMD+手机既可是普通手机（Zhu 2025）、空间控制器（Liang 2016），也可是文本输入设备（Chen 2019）。其二，已有使用模式研究只覆盖非沉浸式生态：Yuan 2022 提炼 integrating/cloning/expanding/partitioning/migrating 五模式，Li 2025 用于跨设备学习，均未涉及沉浸式组合。其三，系统导向框架虽点出注意切换与知觉同步，但背后的使用模式未被明确化，设计者缺少「从预期活动出发」的中间层。

## 方法详解
语料（Sec. 3）。检索 ACM DL、IEEE Xplore、Wiley、SpringerLink 得 4,857 条（2015–2025，检索日 2026-04-28），查询含 cross-device、hybrid user interfaces 与设备词、AR/VR/MR/XR。去 160 条重复与 1,206 篇短文余 3,491 条，摘要筛除 3,154 条、全文再排 99 篇，最终 238 篇。

框架（3.3）。沿 Nickerson 2013 迭代分类学，meta-characteristic 为「用户在一个 usage episode 内如何协调两类设备」，分析单元是 usage episode。维度须是用户侧推论、可从报告流程编码且互不重叠；演绎抽候选、归纳由三人对 20% 子集开放编码后归并。最终三维度二值化：User Attention（Focused/Fragmented，仅外显视觉注意）、Task Relatedness（Related/Unrelated）、Cognitive Symmetry（Symmetric/Asymmetric，源自 Hutchins 1985 的 semantic distance）。编码前三人对 15% 子集校准，两两 κ > .70；策略用 Braun & Clarke 主题分析。

结果与验证（4–5）。三维度交叉得六模式：Clone 90、Proxy 84、Extend 55、Complement 46、Standby 6、Partition 3；Cognitive Symmetry 对 Unrelated 不适用，故为 6 而非 8 种组合。每模式归纳策略（同步内容、扩展工作空间、输入重映射、互补表征协调）。形成性工作坊 n=6（23–29 岁，4 学术 + 2 工业），改编 design sprint：自选案例（VR 课堂 n=2、AR 家装 n=4），先自设计再引入 MRxD 重做，结尾访谈。

## 实验与结果
- 语料流程：4,857 条 → 去 160 条重复与 1,206 篇短文 → 3,491 条摘要筛选（排除 3,154）→ 337 篇全文筛选（排除 99）→ 238 篇；检索日 2026-04-28，覆盖 2015-01 至 2025-12。
- 维度分布（284 个 episode）：Attention Focused 180（63%）/Fragmented 104（37%）；Task Relatedness Related 275（97%）/Unrelated 9（3%）；Cognitive Symmetry 仅在 275 个相关 episode 上定义，Symmetric 145（53%）/Asymmetric 130（47%）。
- 模式分布：Clone 90、Proxy 84、Extend 55、Complement 46、Standby 6、Partition 3，前两者合计约 61%，说明「聚焦注意 + 同任务」是主流形态。
- 编码信度：三名作者在随机 15% 子集独立编码，两两 Cohen's κ 均 > .70（substantial agreement）；维度开发阶段另用随机 20% 子集做开放编码。
- 工作坊 n=6（23–29 岁；两案例 n=2 与 n=4）：引入框架后被试补上初版缺失的多用户支持（P1、P2、P5、P6）与缺失的输入/输出组件（P1、P3、P4、P6）。
- 工作坊行为转变：被试从整机角色分配（电脑编辑、AR 显示、手机记笔记）转为按能力（输入、输出、感知、传输）拆解设备；P1/P3 转向在 VR 内复用键盘输入，P6 从「手机记笔记」转为「手机作放置家具的代理控制器」。
- 示例诊断：MaRginalia（Qiu 2025）的克隆平板界面属 Clone、笔到 MR 光标的重映射属 Proxy，据此指出其「笔按下激活按钮 vs 捏笔截屏」的映射不一致会带来局部摩擦（被试改用点击小圆点截取转录为旁证）。

## 创新点与贡献
- 把「使用模式」视角从非沉浸式生态（Yuan 2022；Li 2025）扩展到 MR 跨设备，并以 238 篇语料给出首个面向 HMD + 非沉浸式设备的模式框架。
- 提出第三维度 Cognitive Symmetry（源自 semantic distance），以「表征/动作-效果是否需重新解释」为独立设计轴，从而区分 Clone 与 Proxy、Extend 与 Complement——这是既有配置型分类学无法表达的差异。
- 以维度组合而非模式直接编码推导模式，避免按共享设备或应用做表面聚类，使判据在异构语料上可显式复用（κ>.70 佐证可操作性）。
- 为每个模式归纳可操作策略，并给出模式可迁移/可组合的分析（如把 Proxy 映射补进 Clone 主导的系统以支持快速检视），使框架兼具描述与生成功能。

## 局限与风险
- （作者承认）检索可能漏检跨设备特征未体现在元数据中的工作（如 Friedl-Knirsch 2024）；排除 ≤4 页短文、手持 MR、空间 AR 与专用设备，框架不覆盖全部系统。
- （作者承认）维度开发含解释性判断，换团队或换 20% 初始样本可能得出不同但同样合理的维度，初始样本还可能使某些维度先验地更显著。
- （作者承认）三维度均二值化，压缩了本可能连续或随时间变化的中间状态与对应策略。
- （作者承认）只保留每篇论文「设计动机或贡献核心」的 episode，模式分布反映研究侧重而非真实行为流行度，次要模式与组合可能被低估。
- （我在正文发现）唯一实践验证是 n=6 形成性工作坊，无对照条件、无编码信度、无延迟后测，无法判断框架相对「无框架」或相对 Brudy/MR-HUI 维度的增益。
- （我在正文发现）Standby（6）与 Partition（3）样本过少，其策略归纳基本是单例外推；lift 共现分析虽用于纠偏，但正文未给具体 lift 数值，模式组合结论不可核验。

## 与文献库的关系
本文属跨设备交互框架脉络中的使用中心分支，与配置中心分支互补。它以 Brudy 2019（六维分类学）与 Hubenschmid 2026（MR-HUI 综述，增加 interaction dynamics 与 anchoring）为对照，指出后者解释「系统如何组装」而不解释「同一配置下的不同用法」，并以 HMD+手机的四种角色（Zhu 2025、Saidi 2021、Liang 2016、Chen 2019）为例。模式层面继承 Yuan 2022 的五模式与 Li 2025 的注意视角：Clone/Extend/Partition 对应 cloning/expanding/partitioning，但新增 Proxy 与 Complement 两个认知不对称模式，并把 attention 提升为第一维。方法上沿用 Nickerson 2013 与 Braun & Clarke。故本文是既有两条线在 MR 语境的合并与扩展。
