# 神经渲染编译器：把生成式视频模型当作可编程渲染器

## 一句话结论
把冻结视频模型当黑盒渲染后端：离线按 34 个语义控制维度分层探测能力、在线把每条要求编译到可靠的控制通道（提示 / 参考图 / 首帧 / 代理视频）——VComBench 要求满足率 Wan 46.8→52.3%、H3 66.5→69.3%，联合成功 8.4→11.8%，380 任务 / 1,617 条计分要求。

## 要解决的问题
生成式视频模型正成为强渲染器，却缺少 Blender 或 HTML/CSS 引擎那样可预测的控制接口：其能力隐式来自训练，难以判断哪些语义要求能可靠执行，且不同模型、不同条件模式（T2V/I2V/R2V）能力分布不均。现有 prompt enhancer 与 agentic pipeline 会不加区分地改写全部指令，既可能破坏模型本已擅长的要求，也无法识别何时需要换成参考图、首帧或代理视频等替代执行策略。在 VComBench 上，原生 Wan 的要求满足率仅 46.8%、全要求联合成功率仅 8.4%，说明「多要求同时成立」是主要缺口。

## 方法详解
把冻结视频模型视作黑盒渲染后端，先离线探测再在线编译。任务形式化为 $x=(p,A,m_0)$，解析成模型无关中间表示 $z=\operatorname{Parse}(x)$，其中每条语义要求 $r_i=(c_i,\ell_i,e_i,\theta_i)$ 记录控制类型、难度、原文 span 与可选参数；控制词表覆盖物体属性/计数、空间关系、事件、相机、外观、物理、视觉文本与参考条件，共 34 个语义控制维度。离线阶段在 T2V/I2V/R2V 三种模式下按难度分层探测，每条探针隔离一个目标要求，由视频裁判加任务专用测量打分，得到经验成功率 $\hat{p}_d(c,\ell,m)=s_d/n_d$，并标为 ok/weak/bad，未测为 unknown。在线编译查表得 $\sigma_i$，按决策规则：ok 或 unknown 则 keep；weak/bad 且存在满足前置条件的补救集合 $\mathcal{F}^{\lambda}_i$ 则 intervene；否则 unresolved 并保留原文。干预分两类：定向改写（澄清主体绑定、计数、事件顺序、相机行为、空间关系、时序）与六种外部算子（参考图锚定外观、首帧编码计数/视觉文本、布局图指定空间位置、代理视频提供运动/时序/相机、镜头拼接等），允许在执行时切换条件模式（如 T2V 先构造首帧再转 I2V）。执行前对生成的条件做有效性校验，不合格则丢弃并回退到文本计划；若编译后输入未变则直接复用原生输出，所有生成模型保持冻结。

## 实验与结果
- VComBench 要求满足率：Wan 46.8% → 52.3%，H3 66.5% → 69.3%（NeurCo T+O）
- 全要求联合成功率：Wan 8.4% → 11.8%，H3 28.2% → 25.3%（后者下降）
- Seedance 2.5：68.5% → 69.7%（NeurCo T），T+O 为 68.2%
- 与 TIDE 组合：H3 联合成功率 33.2% → 34.5%，Wan 要求满足 50.6% → 52.5%
- 基准规模：380 个组合任务、1,617 条计分要求、34 个语义控制维度
- 外部基准：VBench-2.0 取 17 个有效维度均值；Sci-VBench testmini 150 任务，H3 均值 2.668 → 2.724
- 模态细分：Seedance R2V 要求满足 66.1% → 69.9%，联合成功 20.7% → 28.9%
- T2V 细分：Wan 54.3% → 62.9%，联合成功 14.1% → 20.0%

## 创新点与贡献
- 相对 prompt enhancer（TIDE 等）只优化文字、相对 agentic pipeline 只做任务分解、相对控制条件模型只提供固定相机/运动接口，NeurCo 的新意是把「模型实际能可靠执行什么」变成可测量、可查表的能力手册，再据此逐条决定保留、改写或降级为外部条件
- 它不训练生成器、不引入统一控制接口，而是把每个后端的有效指令集当作经验发现的对象，这是编译器视角在生成式视频上的落地

## 局限与风险
- 能力手册是部署相关且探测成本高的：换 checkpoint、换推理配置都要重测，unknown 条目只能保守保留原文
- 编译依赖解析质量，VComBench 直接用标注 IR，真实用户 prompt 的解析误差未评估
- 收益幅度有限（2.8–5.5 点），且在 H3 上要求满足率上升同时联合成功率下降，说明干预会引入要求间干扰
- 算子带来的可控性提升还以牺牲照片级真实感为代价
- 多镜头、长时序与强物理约束仍未解决
