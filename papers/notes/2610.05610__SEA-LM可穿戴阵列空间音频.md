# SEA-LM：面向可穿戴麦克风阵列的自我中心空间音频理解

## 一句话结论

embodied 自我中心智能需要理解复杂环境中的空间音频。现有大型音频语言模型擅长单通道推理但缺乏空间感知，丢弃了声源定位与分离重叠声源的关键线索。SEA-LM 先提出 FOACoder——一个布局灵活的空间音频编码器，在源定位 + 自我中心语音活动检测目标上训练，把可变数量/位置的智能眼镜阵列经波束成形得到的 FOA（一阶环境声）编码；再训练一个 MLLM 通过两阶段课程（6 任务，含多说话人/重叠声下的声源定位与空间选择性转写）理解这些空间音频嵌入。为防转写输出主导下一 token 损失、淹没方向预测，引入时空加权交叉熵。评测集上方位角/仰角 MAE 更低、时间 IoU 更高、外部源幻觉与漏检率更低、多数转写任务 WER 更低，且在 1,211 种 4–9 麦克风智能眼镜阵列配置下鲁棒。

## 要解决的问题

机器听觉中，空间音频蕴含的空间线索（如声道间…）对声源定位与重叠声源解耦至关重要，但大型音频语言模型建立在单通道音频理解上，丢弃了空间信息。可穿戴智能眼镜阵列（多麦克风）能提供空间音频，但阵列数量/位置可变，需要布局灵活的编码器；且多说话人 + 重叠声下既要定位又要选择性转写，转写损失易淹没方向预测。

## 方法详解

(1) FOACoder：布局灵活的空间音频编码器，在源定位 + ego-centric VAD 目标上训练，把由可变数量/位置智能眼镜阵列经波束成形得到的一阶环境声（FOA）编码。(2) SEA-LM MLLM：双音频通路 + 可学习空间投影器 + LLM 注入，通过两阶段课程（6 任务：声源定位、多说话人/重叠声下的空间选择性转写等）理解空间音频嵌入。(3) Spatio-Temporal Weighted Cross-Entropy：防止转写输出主导下一 token 预测损失、淹没方向预测。(4) Spatial Audio Supervised Fine-Tuning + 时空加权交叉熵。

## 实验与结果

自有评测集上：方位角/仰角 MAE 更低、时间 IoU 更高、外部源幻觉与漏检率更低、多数转写任务 WER 更低；在 1,211 种 4–9 麦克风智能眼镜阵列配置下保持鲁棒。附课程消融、FOACoder 训练/评估、波束成形伪影与阵列选择、RIR 仿真等大量附录。

## 创新点与贡献

1. FOACoder：首个布局灵活、由可变阵列经波束成形得到 FOA 的空间音频编码器，适配真实眼镜硬件。
2. 把空间音频嵌入送进 MLLM 做 6 任务理解（含重叠声下空间选择性转写）的两阶段课程范式。
3. 时空加权交叉熵解决"转写淹没方向"的训练失衡。
4. 在 1,211 种阵列配置下验证鲁棒性，贴近可穿戴部署现实。

## 局限与风险

依赖仿真生成的 RIR/阵列传输函数与混合参数（真实噪声分布可能偏移）；FOA 仅一阶，空间分辨率有限；评测集为自建，与真实复杂声学环境差距待验证；多说话人极度重叠下性能上限未充分探索；未给端到端眼镜端侧延迟/功耗。
