# 面向低冗余三维重建的层级匹配稀疏注意力（LMSA）

## 一句话结论
按层统计「均值 token 的注意力质量亏空」逐层选估计器：弥散层用无偏 hub、匹配层保持精确，100 视角下 2.0× 加速仅损 1.38 AUC@5。

## 要解决的问题
VGGT 能一次前向从无位姿图像回归相机与几何，但其全局注意力随视角数 N 呈平方增长。于是出现一批免训练加速器，它们共同的前提是“跨视角信息高度冗余，多数跨视角 key 可以丢弃、合并或摘要”。这个前提在重叠视频上成立，在视角少且彼此远离时崩溃，本文称后者为低冗余（low-redundancy），用 ρ（一个点平均被多少个视角看到）度量。失效很严重：在 ETH3D courtyard（ρ≈7.7）上，AVGGT 保留每个 3×3 patch 单元一个 key（σ=9），把冻结 VGGT-1B 的位姿 AUC@5 从 58.3 打到 8.1、AUC@30 从 90.9 打到 34.8（五个帧子集平均）。逐层拆解可见三类失败原因不同：早期全局层（0–8）承载分布式跨视角上下文，AVGGT 把它们改成帧内局部会掉 33.1 AUC@5；中间层（10–16）依赖 query 特异的对应关系——在 TUM fr1_room 上，每 query 33,312 个 key 中仅 30 个对应 key 被移除就掉 17.7–49.2 AUC@5，而移除同样数量的“最重”其他 key 只掉 6.0–23.0（尽管后者注意力质量高 2.3–3.4 倍），随机移除则无损；第 9 与 17–23 层又是弥散求和，但均值 token 会系统性低估被丢质量（在冗余场景 TUM fr3_long_office 上，这三层占 AVGGT 22.1 点损失的 14.8）。因此问题本质是：同一种稀疏模式无法同时保住“分布式上下文”和“低质量但 query 特异的对应 key”，需要按层选择估计器。

## 方法详解
对象是冻结的 VGGT-1B（N 张图切成 P 个 patch token + 5 个特殊 token，T=P+5=1041@392×518；24 个帧块与 24 个全局块交替，16 头、头宽 64）。LMSA 只改全局块，把任意稀疏层写成统一形式：保留精确 key 集 K(t)，对被丢集合 D(t) 用少量替身 W(t) 及对数权重 b_u 表示，ô=(Σ_K w v+Σ_W e^{b_u} w v)/(Σ_K w+Σ_W e^{b_u} w)。AVGGT 的均值 token 即“一个替身 + 均值 key/value + b=ln|D|”，截断注意力即 W=∅，而 LMSA 的 hub 是带重要性权重的采样 key。成本以“一个帧的 T 个 key 对每个 query”为 1 unit，稠密全局层为 N unit。（1）一个统计量——均值 token 亏空：Γ_t=ln Σ_{u∈D} w_u - (ln|D|+l̄_D)，即被丢 key 的真实对数质量与均值 token 给出的对数权重之差；Γ=0 表示均值 token 恰好复现，Γ>0 表示只给出 e^{-Γ} 的比例。命题 1：(i) 精确地 Γ=½Var_{p_ξ}(l)≥0（logits 恒定时取等）；(ii) 小展布时 Γ≈½s²，其中 s²=Var_{p0}(l)=q^T Σ_K q/d_h 只需 key 协方差、不需要注意力行，故称 row-free。再用随机能量模型（REM）解释近似何时失效：把 D 上的 logits 视为方差 s² 的独立高斯，大 n 时在 2ln n 处出现冻结相变，Γ≈½s²（高温相）或 Γ≈sqrt(2s²ln n)-ln n（冻结相）。在 VGGT 上实测 Γ 在 s²≲10 内与 s²/2 相差 0.3 nat 以内（秩相关 0.986），之后向下弯，早于 REM 的 2ln n≈20.8，说明 REM 只提供动机、不设定阈值。（2）选择器：对每个全局层 ℓ，在 512 个随机 patch query 上算 Γ_t（D 取其他帧的全部 patch key），先对头取中位、再对 pilot query 与 pilot 场景取均值，得 Γ̄_ℓ。若 Γ̄_ℓ≥1.5 nats 判为 matching 层并保留精确注意力，否则为 diffuse 层用 hub。阈值在开发场景上、表 1 的析因实验之后选定并在任何测试前固定；实测 Γ̄_ℓ 在 11–16 层为 1.83–9.21，其余至多 1.00，row-free 代理给出同样划分（9–23 层中仅 11–16 层的中位 s²≥3）。1.5 nats 远低于冻结阈值，只有第 14 层处于冻结相——说明 matching 层需要的是 query 特异 key 而非“重”key。（3）diffuse 层：重要性采样 hub。每个输入做一次 hub pilot：512 个随机 patch query 算全注意力，估计每列质量 π̂_j（头平均）；在 patch token 上取提议分布 p_j∝π̂_j+ε/|C|（ε=1e-3 保证可达），独立抽 m 个得去重 hub 集 H 及重数 c_j；query 精确注意自身帧 F_i ∪ 特殊 token S，并以 H∖F_i 为替身，hub 对数权重 b_j=ln c_j-ln(m p_j)。命题 2：因 E[c_j]=m p_j，Σ e^{b_j}f(j) 的期望恰等于 Σ_{C∖F_i} f(j)，故被丢部分的分子与分母都无偏；输出是两估计之比故自身有偏，偏差为 O(1/m)，而均值 token 对每个 query 都固定少算 e^{-Γ}。因 H 共享，hub 层无需逐 query gather，N=32 时 m=256 约 1.6 unit、m=1024 约 2.4 unit，随 N 只通过特殊 token 增长。m 由开发集设定：0–8 层用 256，9、10、17–23 层用 1024（后期层用 256 会在 courtyard 掉 11.4 AUC@5）。（4）晚期墙的偏差解释：设 φ=Σ_D w/Z 为落在被丢 key 上的真实质量占比，则每个保留 key 被放大 κ=Z/Ẑ=[(1-φ)+φe^{-Γ}]^{-1}≥1；晚期 Γ 虽小，但放大是单向的且主要落在稠密参考帧上，因此预测的是系统性相机误差而非噪声。发现 1：给均值 token 的 logit 加二阶累积量项（上限 3 nats）、value 加 Cov_D(v,l) 一阶项，可找回 TUM fr3_long_office 15.0 点损失中的 9.7 点，并把相对稠密的旋转偏差从 1.01° 降到 0.22°；直接用“自身帧 + 1024 hub”替换参考帧/晶格/均值 token 后，五个开发场景损失至多 1.17 AUC@5、旋转偏差 0.12°。（5）matching 层保持精确：把注意力写成 A(t,j)=π_j L(t,j)（列质量=流行度，L=对 query 的特异度），在 10–16 层按 query 移除与对应 key 同数量的最高 lift key（仅占注意力质量 1–14%，其中只有 13% 落在对应窗口内），三个低冗余场景 AUC@5 直接崩到 0.05/0.13/0.59；而移除同等 7–11% 质量按注意力权重选出的 key 损失小得多。截断还会放大一切被保留的内容：Γ̄≈1.8 意味着均值 token 只代表约 17% 的质量，σ=9 晶格下保留 key 被放大约 2.0–3.8 倍，上游稀疏层传下来的误差也一并被放大。（6）成本模型：G(N)=2.02+0.004264(Σ_diff u_ℓ+6N) GFLOP/token，2.02 为全局注意力之外的开销，6 个精确层固定 6N，18 个 diffuse 层近似常数，故 N 增大时注意力成本趋于稠密的四分之一。全流程免训练、无需位姿，仅一次离线稠密 pass 得 Γ̄_ℓ。

## 实验与结果
- 13 个未见低冗余场景（ρ<10.5，ETH3D 8 + Tanks and Temples 4 + TUM 1，N=32，5 seeds）：LMSA 相对稠密仅损失 1.38 AUC@5（95% CI [0.71,2.01]）与 0.70 AUC@30
- GPA-VGGT 2.42、SAF3R 4.53、AVGGT(σ=4) 10.27、AVGGT(σ=9) 18.91、FastVGGT 16.42
- 相对 AVGGT 的增益：+8.89 AUC@5（CI [6.45,11.97]）对 σ=4，+17.54 对 σ=9
- 相对 GPA-VGGT 仅 +1.04（CI [-0.34,2.54]）且 FLOPs 为其 1.01×，未达预注册的 +5 目标
- Holm 校正后只有对 AVGGT 的增益同时通过两项场景级检验
- 8 个未见冗余场景：LMSA 损失 0.73，GPA-VGGT 为 0.08（更好），LMSA 相对 AVGGT(σ=9) 仍 +9.77
- 等成本对比：统计量选出的 6 个精确层（1.38）优于测试的四个平移窗口 9–14（8.51）、10–15（4.19）、12–17（2.72）、13–18（4.61），经 Holm 校正均显著更差
- FLOPs 与速度：2.99 GFLOP/token @N=32 vs 稠密 5.29（1.8× 更少），N=100 时 4.76 vs 12.25（3.1×），比例随 N 趋于 4×
- aggregator 在 N=100 时比稠密快 2.0×，比 GPA-VGGT 快约 2%，但比 AVGGT(4) 慢 13–18%（N=64–100）
- N=100（Tanks and Temples 5 场景）：LMSA 损失 1.90 AUC@5，aggregator 2.0× 加速
- AVGGT(4) 7.10、AVGGT(9) 12.61、SAF3R 5.65
- 长序列：7-Scenes 每 3 帧取帧（N=333，7 序列）损失 0.60 AUC@5、2.7× 加速（GPA-VGGT 反超稠密 0.82）
- N=800 时 3.3× 加速、各序列与稠密相差 ≤1.6，而 AVGGT 在 5.1–8.1× 加速下偏离最多 7.9
- 消融与迁移：去掉对数权重低冗余损失飙到 36 AUC@5
- 阈值取 2.0/3.0 nats 分别多损失 2.9/11.0
- 把该统计量事后用于改选 GPA-VGGT 保护的层（11–16 替代 13–16），多 5% FLOPs 换 +1.2 AUC@5（CI [0.4,2.1]）
- 直接套到 π³ 上损失 4.87（AVGGT(4) 13.81），但未达预注册的 ≤3 目标

## 创新点与贡献
- 把“稀疏化多少”换成“这一层该用哪种估计器”，是本文最本质的视角转换：既有工作（AVGGT、RegimeVGGT、GPA-VGGT、SAF3R）都在压缩率/模式上做文章，本文指出注意力近似是一个分两相的估计问题——弥散层是对大量可比项之和的估计，需要无偏采样
- 匹配层需要 query 特异的少数项，任何共享采样都取不到
- 为此提出可解释的层级判据：均值 token 的对数质量亏空 Γ，并给出精确形式 Γ=½Var 与 row-free 代理 s²=q^TΣ_K q/d_h（只需 key 协方差、不需注意力行），使判据可在一次离线稠密 pass 中算完并复用到新模型
- 第二个新意是把 diffuse 层从“摘要”改为“重要性采样”：hub 由 512 个 pilot query 的列质量抽样得到，并用 b_j=ln c_j-ln(m p_j) 同时校正抽样概率与重数，使被丢部分的分子分母双双无偏（命题 2），从原理上修掉了均值 token 对每个 query 固定少算 e^{-Γ} 的偏差
- 第三个新意是用同一统计量解释并修复 AVGGT 的“晚期墙”：κ=[(1-φ)+φe^{-Γ}]^{-1} 的单向放大主要落在稠密参考帧上，因此表现为系统性相机误差
- 负结果本身也有价值：matching 层任何激进稀疏化都掉精度，这一实证结论划定了解析加速的边界

## 局限与风险
- 作者自述：LMSA 相对同期 GPA-VGGT 没有显著更准，等 FLOPs 下低冗余优势仅 1.0 AUC@5，未达预注册的 +5
- 在冗余视角上 GPA-VGGT 更好
- 速度与 GPA-VGGT 相当，但比 AVGGT(4) 慢 13–18%（N=64–100）
- 6 个精确层把相对稠密的 FLOP 优势上界锁在 4×
- hub 采样存在 run-to-run 噪声，增加 hub 数可减小
- 对 π³ 的迁移只是初步，且未达预注册目标（损失 4.87 > 3）
- 从实验设计还能看出：低冗余测试场景只有 13 个、每场景 32 视角，N=100 仅 5 个 Tanks and Temples 场景且 5 个 strided seed 只产生 3–5 个不同子集，统计功效有限
- AVGGT 无官方代码，用重实现对比，作者承认其未必达到原文精度，因此“对 AVGGT 的大幅领先”部分来自基线复现质量
- 阈值 1.5 nats 虽在测试前固定，但源自开发场景的析因实验，属经验设定，π³ 上恰好漏掉第 7 层（该层用 hub 其实无损）暴露了判据的脆弱性
- 方法只处理全局注意力，帧内注意力与相机/深度头未动，端到端收益受限于聚合器占比
