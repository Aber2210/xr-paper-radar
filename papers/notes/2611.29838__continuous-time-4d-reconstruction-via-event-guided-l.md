# 基于事件引导潜在特征插值的连续时间 4D 重建

## 一句话结论
把插值位置从 RGB 或 pointmap 换到基础模型的 latent 特征上，同时保留几何先验与细粒度时间线索，并用「连续颜色预测 → 模拟事件 → 与真实事件流比对」做自监督：DSEC 平均 AbsRel 0.1594 对 TimeLens 0.1991，ATE 0.2242 m 对 0.6349 m。

## 要解决的问题
几何基础模型（DUSt3R、MASt3R、VGGT、DA3）能把视频转成配准的点云帧，但预测被输入帧的时间分辨率锁死，无法给出帧间任意时刻的 3D 结构与位姿。事件相机提供微秒级变化证据，却缺少「RGB-事件 + GT 几何」的配对数据，难以从零训练。两条朴素路线各有缺陷：输入空间插值（TimeLens/VDM-EVFI 合成中间帧再喂几何模型）按图像质量优化，在遮挡、运动边界与模糊区产生几何伪影；输出空间插值（Interp3R 插值已解码 pointmap）丢弃了多视图对应、上下文等内部表征。

## 方法详解
冻结 DA3-LARGE-1.1 的 encoder/decoder，只在 encoder 与 decoder 之间的 latent token 空间插值。Context Feature Extraction 把 K-bin 事件体素当作 K 帧视频处理，RGB 两帧按时间权重 $w_i=i/(K-1)$ 混合，模态专用 stem 编码后用 RVRT 式 recurrent 传播聚合，得 $F_{ctx}\in\mathbb{R}^{K\times H_f\times W_f\times C}$。Geometry Feature Fusion 以 $F_{ctx}$ 为 query、分别对端点特征 $F_s,F_e$ 做 cross-attention，用初始化为时间先验 $t$ 的内容感知门 $\alpha$ 混合并加残差：$F_{cp}=(1-\alpha)\odot CA(F_{ctx},F_s)+\alpha\odot CA(F_{ctx},F_e)+F_{ctx}$，得到 K 个 control point。INR 模块取 $t$ 相邻控制点混合，经 frequency embedding + FiLM 调制细化，并把输出投影零初始化、以线性插值为基线：$F(t)=F_{INR}(F_{cp},t)+F_{Lerp}(t)$，$F_{Lerp}(t)=(1-t)F_s+tF_e$，训练起点即退化为基线。几何监督用伪 GT：深度用 disparity 空间 scale-shift 不变 L1（每条序列拟合一组 $(s,b)$ 并跨中间帧共享以保时序一致）加多尺度梯度项；射线用 Sim(3) 对齐后的 Charbonnier 原点残差加方向项。外观代理任务并训一个连续颜色分支，共享 $F_{ctx}$、在 INR 各层以近零初始化的门互相注入；事件模拟损失把 $\Delta I(\mathbf{u},t)=\log I(\mathbf{u},t+\Delta t)-\log I(\mathbf{u},t)$ 与极性累计 $E(\mathbf{u})=\sum p_k$ 的容差带 $[C_{low},C_{high}]=[0.15,0.35]$ 比较，故可用于区间内任意 $t$ 而不仅是存在伪 GT 的帧。自监督训练用高帧率 RGB（Adobe240、SportsSloMo）模拟事件，并把冻结 DA3 在稠密帧上的预测蒸馏为伪 GT 位姿与深度，绕开真实事件-几何配对数据稀缺。总计 $K=20$、90 epoch、AdamW lr $1\times10^{-4}$。

## 实验与结果
- DSEC 平均（间隔 2/4/8/16 帧）AbsRel 0.1594 vs TimeLens 0.1991、Interp3R 0.1695、VDM-EVFI 0.1756、Ours w/o events 0.1834
- DSEC 平均 δ<1.25 0.8007 vs TimeLens 0.7432、Interp3R 0.7878；δ<1.05 0.3082 vs 0.2653
- DSEC 平均 ATE 0.2242 m vs TimeLens 0.6349、VDM-EVFI 0.4530、Interp3R 1.0563、w/o events 0.3972（间隔 2 时 TimeLens 的 0.0471 更低）
- 16 帧间隔 AbsRel 0.1965 vs Interp3R 0.2071、TimeLens 0.3010；δ<1.25 0.7308 vs 0.5907
- Sim4D-Sharp AbsRel 0.0160 vs TimeLens 0.0216、Interp3R 0.0215；δ<1.05 0.9543 vs 0.9282
- Sim4D-Blur（运动模糊）AbsRel 0.0408 vs TimeLens 0.0579、Interp3R 0.0492
- 外观：DSEC PSNR 24.18 vs TimeLens 23.97、VDM-EVFI 21.85；但 Sim4D-Sharp 上 29.97 vs TimeLens 32.44（作者承认干净合成数据上颜色落后）

## 创新点与贡献
- 插值位置本身是核心贡献：既不在 RGB 也不在 pointmap，而在基础模型的 latent 特征上，从而同时保留几何先验与细粒度时间线索
- 配套把「连续颜色预测 → 模拟事件 → 与真实事件流比对」做成代理任务，使外观约束转化为几何插值的时序正则
- 并用高帧率视频模拟事件 + 蒸馏伪 GT 绕开事件-几何配对数据的稀缺

## 局限与风险
- 只在相邻帧对之间独立插值，长间隔（16 帧）AbsRel 仍达 0.1965，未做跨区间一致性
- 依赖事件与 RGB 时间同步、已知相机内参与已定位的帧序列
- 颜色质量在干净合成数据上不如专用事件插值器（Sim4D-Sharp PSNR 29.97 vs 32.44），说明外观分支只是正则而非目标
- 正文未给推理时延、显存与实时性数据
- 训练数据全为真实高帧率 RGB + 模拟事件，真实事件域差异仅由 DSEC 一条链验证
