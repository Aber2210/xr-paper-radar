# EgoAlign：无情境描述的第一视角 3D 场景理解

> 批次：2026-10-19 补漏批次（公告日 2026-10-12，拉取日 2026-10-19，积压补漏非当日新提交）。

## 一句话结论
发现现有姿态条件 3D 语言模型的「姿态不敏感」失败模式（打乱数值位姿性能几乎不掉），提出 EgoAlign：agent-centric 点云表示 + 显式坐标融合（语义/坐标/RGB 三分支 1/√3 缩放注入 LLM 嵌入），仅凭数值位姿即可可靠做情境 3DQA。

## 要解决的问题
情境 3DQA 需要模型相对于智能体位姿解释场景；现有方法依赖自然语言情境描述（昂贵/常缺失），且数值位姿未被功能性地使用。

## 方法详解
点云转到 agent 中心坐标系；追踪编码器池化分配得到每 token 支撑点，坐标/颜色均值投影后与语义特征融合；固定场景位置的 egocentric 对齐监督。

## 实验与结果
位姿打乱评估 + 显著性检验；组件消融（对齐动力学）；模型规模与 yaw 噪声完整结果。
