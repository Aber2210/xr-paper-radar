## 批次要点

- **MoGe-4D：高效、灵活、统一的稠密运动与几何**（2611.32198，4.57 S）：把 4D 预测收敛成「一次 query 返回 allo/ego 成对点图」这一接口：几何、运动、相机位姿由同一组稠密坐标给出，位姿退化为闭式刚体对齐且不依赖参考帧——3D 跟踪全点 RelEPE 相机系 0.084 vs V-DPM 0.160（−47.5%）、世界系 0.077 vs 0.138，多视图重建全局点 AUC@25 79.26% vs 同数据同初始化训练的 π3 73.41%，Oxford-Spires 500 帧单次前向零样本仍比基线快 1.7–4.3×。
- **值得记住的网格：交互式视频世界中的持久外观**（2611.32445，4.40 S）：把 coarse mesh 当地址而不是画布：在物体自身坐标系按表面积分 cell 存渲染器自己的 K/V，使外观随物体移动与关节运动一起走、跨 agent 共享同一地址——动态场景 object permanence 91.5 vs 最强基线 34.7（HSSD）、94.1 vs 43.4（MutableWorlds），跨 agent 一致性 79.99 vs 42.60，720p 41.1 FPS 且 8,001 帧 rollout 峰值显存 <45 GiB。
- **AirLeg：鲁棒精确的自监督视觉—惯性—腿式 SLAM 系统**（2611.32523，4.38 S）：把 imperative learning 用于「仿真预训练本体感知模型 → 真机」的跨模态自适应：腿式里程计精化视觉地图，精化后的地图再以重投影而非位姿回归监督网络，并用稀疏伴随避免展开 BA——GrandTour 17 条序列常规 ATE 0.15 m / 困难 0.23 m，是唯一全部 17 条都 <0.4 m 的方法；Unitree Go2 上漂移 0.59% vs 最佳对手 OKVIS2 1.55%。
- **Xtream：面向大规模流式重建的显式度量状态**（2611.31757，4.08 A）：把「尺度」从隐变量提升为一等状态：每个窗口一个对数尺度比、闭环再带一个独立环路尺度，用度量深度先验或 IMU 因子给绝对锚点，从机制上阻断逐窗口 handover 误差累加——VBR 单目 ATE 5.40 m（AMB3R-SLAM 7.42、CLoSeR 11.15），KITTI 9.79 m（13.11），单张 RTX 5090 上 10–21 FPS。
- **LookAnything：面向整体注视跟随的基础模型**（2611.32351，4.07 A）：用三组可学习 gaze query 把 depth、head mask、target heatmap 三种先验内化进 VLM latent（训练时监督、推理时不需要任何外部输入），并把点/框/热图/语言统一进一个自回归输出空间——HoliGaze-Bench GTL-T2P L2 0.094 vs 同骨干 0.387，GTL-T2B mIoU 0.333 约为 Qwen3.8-27B 的 2.2 倍，而骨干只有 2B。
- **COHERE4D：免训练稠密表面配准的一致性度量 4D 人体—场景重建**（2611.32482，4.07 A）：免训练地利用「人体与场景基础模型其实重建了同一张可见人体表面」做稠密像素级 3D 配准，把序列级尺度与逐帧平移解耦、再用跨帧一致投票稳定尺度——3DPW HS-CF5 0.688 较 Human3R 1.079 降 36.2%，EMDB-2 全局人体运动较 HAC 降 40.7%/53.6%，只增加约 4 ms/帧。
- **DraftKV：用分层流式检索守护持久世界**（2611.31944，4.00 A）：training-free 的两级检索（相机位姿/视锥粗 grounding + draft attention 细选）配合 tile 级流式 attention，使取数沿 FlashAttention tile 粒度与计算重叠——ORBIA persistence 58.98 vs 56.67、5.49 FPS vs WorldKV 4.71、显存 18.56 vs 21.33 GiB，首次让 33B 级世界模型在单张 80 GiB H100 上做历史 KV 检索。
- **InitFree-SfM：当无初始化 Bundle Adjustment 遇上学习式 Structure-from-Motion**（2611.31516，3.92 A）：给 OSE 只加一项相对深度残差（保持 variable projection 可分性），并让 metric depth 贯穿对应过滤、随机初始化与联合精化——ETH3D 位姿 AUC@20° 85.81% vs pOSE 13.91%，去掉 joint metric refinement 即跌到 31.99%，说明「代理目标」并非精度主因。
- **HiGS：面向快速可微 3D Gaussian Splatting 的层次化架构**（2611.31918，3.88 A）：把 3DGS 的三个角色拆到不同粒度：8×8 tile 只做光栅化、64×32 macro-tile 做划分与排序、bounded batch 做独立工作与反向求导——1080p 2756 FPS / 4K 1533 FPS（相对 gsplat 5.1×/5.6×），负载不均视角上快 6.8×–20.0×，训练 61.5 s vs 194.4 s。
- **面向未见物体的可泛化前馈三维手-物重建与由粗到细接触估计**（2611.31812，3.85 A）：物体侧只用冻结位姿基础模型的内部几何特征、不学实例嵌入，接触则由「粗 token 逐关节预测 + 重建 SDF 区域距离细化到掌/背侧」两级落地——DexYCB 物体 AUC 92.88（比 SemiHand 高 10.25），OakInk 未见物体 AUC 93.29 vs SemiHand 40.50，接触 F1@3mm 74.97 vs HACO 68.09。

- **无目标注视标注训练轻量注视模型：什么样的教师才算好教师？**（2611.33014，2.92 C）：把「teacher 选择」本身变成受控实验（固定 student、数据、配方与 seed，只变监督源），并给出可在训练前用 10 个标注 clip 估计教师质量的判据（ρ=0.91）：Gaze-LLE 标签训出的 ViT-Small ADE 0.187 vs 人工标注 0.196（9/9 seed 全胜），同时量化了 prompt 内含候选答案导致的复制式伪能力。
- **PRC4D：物理关系约束的持久 4D 重建**（2611.32396，2.85 C）：把「关系是否持久」而非「关系是否存在」当核心问题：用序列级反证（分离接触片段、支持区间外独立运动、末端持续漂移）加图级一致性剔掉瞬时接触与同动，再用同一张图同时做观测位姿精化与遮挡运动传播——OmniGibson-Occlusion 平均 F 0.6092 vs 4DPM 0.5864。
- **面向移动机器人遥操作的 XR 空间态势感知增强系统**（2611.32584，2.53 C）：把「轻量 2D 占据栅格 + 左右分扇区振动触觉」作为视觉通道之外的空间感知替代通道，并以固定双相机 + 画面与头显解耦同时解决 360° 眩晕与单相机盲区：20 名被试三模态对照完成时间 56.0→44.7→41.9 s（−23%），碰撞 0.75→0.20→0.30。
- **ST-SfM：用于初始化 4D Gaussian Splatting 的时空 Structure-from-Motion**（2611.32231，2.42 C）：首次把动作识别里的 space-time interest point 当跨视角对应来用：同步标定多相机下同一瞬间的 STIP 即可三角化且自带时间戳，正好对上 4D 高斯的时间中心，因此先用极线+时间去筛候选、比值检验几乎冗余——N3DV 每场景 3.9–11.3 万动态点、重投影 0.65–0.83 px，三个场景 PSNR +0.61/+0.64。
- **Tornado4D：从稀疏单侧视频物理引导重建实验室龙卷风的 4D Gaussian**（2611.31435，2.27 C）：把「已知外力布局」变成可复用先验：从玻璃罩几何仿真出旋转主导的气流场并冻结，用可微平流让后续真实帧反向修正第 0 帧的隐藏几何，第二阶段把 CFD 大尺度输运与逐粒子可学残差解耦——held-out camera 7 上 PSNR 35.66 dB vs 逐帧 3DGS 29.72、4DGS 30.22。
