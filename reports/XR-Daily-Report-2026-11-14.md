## 三、逐篇深度解读

### 第 1 章 · MatrixSplat：面向 GPU 的矩阵并行、特征可扩展 3D Gaussian Splatting（3D 高斯泼溅）渲染（2611.15153，4.15 A，FULL）

- **赛道 / 场合**：渲染与显示 / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-13，拉取日 2026-11-14）
- **一句话结论**：Mip-NeRF 360 上端到端达 599.9 FPS（3DGS 156.0、3DGS+TC-GS 295.1），LERF 702.6 FPS、3D-OVS 510.9 FPS，最高为 3DGS 的 3.8×、TC-GS 的 2×；特征维 D=256 时渲染核时间降 36.7×；替换四个快速渲染器的混合核再获 1.69–2.84×，而 PSNR 30.35 dB 不低于 3DGS 的 30.12 dB。
- **要解决的问题**：3DGS 已成实时新视角合成与重建的主流表示，但其渲染流水线与现代 GPU 算力结构错配，在语义特征场景下被急剧放大。首先，深度排序的 alpha 合成引入强 per-pixel 串行依赖：透射率更新 T_{j+1}=T_j·(1−α_j) 形成 loop-carried 的 read-after-write 链，warp 内无法跨迭代重叠指令，wait stall 主导而 Tensor Core 完全闲置。其次，语义 3DGS 需在百万级 Gaussian 上累积高维特征，一旦维度超过 128，特征向量无法驻留 shared memory，只能回落 global memory，性能断崖下降。第三，已有加速各只覆盖流水线一段：FlashGS、Speedy-Splat 优化剔除/排序但每像素仍串行标量循环；Sort-Free、Duplex-GS 去掉排序却仍用标量 FMA；TC-GS、GEMM-GS 把 alpha 计算搬到矩阵单元但混合循环仍顺序相关。缺口是：尚无工作利用顺序无关把特征累积本身表达为矩阵乘法。
- **方法详解**：瓶颈定位（4.1）。剖析 LangSplat：渲染占 77% 延迟，RenderCUDA 核占 51.3%（排序 14.3%、解码 19.2%）；停滞以 wait 为主、short scoreboard 仅 10.2%，说明受依赖限制而非纯带宽限制。

顺序无关特征混合（OIEFB，4.2）。把 RGB、语义特征 f_i^l 与可选深度拼成统一嵌入 e_i^T = concat(c_i, f_i^l, [d_i])，维度 D = 3 + C [+1]（式 6）；不做深度序合成，而对每像素做归一化加权累积 E_p = (Σ w_{p,i} e_i + w_bg e_bg)/(Σ w_{p,i} + w_bg)（式 7）。权重用 LC-WSR 形式 w = α_i·max(0, 1 − d_i/σ)·v_i（式 2），σ、v_i、w_bg 可学并与高斯参数联合优化；附录 A 给出全梯度，论证端到端可微。加权累积可交换，故每个高斯贡献可独立求值——矩阵化的前提。

warp 级 MMA（4.3）。沿用 16×16 tile，再切 4×8 像素组、每组一个 warp（32 像素）。先算掩码 m = 1(α_{p,g} ≥ ε) 与 w̄ = m·w（式 9），32 像素上全零的高斯跳过；凑满 K_mma=16 个后构造 W ∈ R^{32×16} 与 E ∈ R^{16×D}，用 mma.m16n8k16（FP16）累加 Y = Σ_t W^(t) E^(t)（式 11）。同 warp 像素相邻、有效高斯集相似，零投票跳过率高；发射 MMA 时 warp 同时把后续高斯搬到寄存器，实现准备与执行重叠。

高维可扩展（4.4）。特征维按 8 通道切块（C_mma=8，与 MMA 输出 tile 对齐），第 q 块计算 Y_{:,8q:8q+7} = Σ_t W^(t) E^(t)_{:,8q:8q+7}（式 12）。每次 flush 只加载 8 维切片、下一片预取，故 shared memory 占用与 warp 占用率不随 D 增长。
- **实验与结果**：
    - 数据集与指标：Mip-NeRF 360（配 GAGS 分割标签，PSNR/SSIM/LPIPS）、LERF 与 3D-OVS（mIoU 与 LocAcc）；主实验在 RTX 4090、沿用 3DGS 原设置，另在 RTX 6000 Ada 与 H100 复验；FPS 用端到端协议（预热 + 前后 GPU 同步多次计时），与加速方法比较时用 FlashGS 的 kernel-isolated 协议。
    - 主结果：Mip-NeRF 360 上 599.9 FPS（3DGS 156.0、+TC-GS 295.1）、PSNR 30.35（30.12/30.14）、LPIPS 0.178（0.181/0.183）、mIoU 0.541（0.536）、LocAcc 0.730（0.698）；LERF 702.6 FPS（237.9/310.3）、mIoU 0.445（0.419）、LocAcc 0.679（0.632）；3D-OVS 510.9 FPS（162.0/294.8）、LocAcc 0.985（0.937）。
    - 与顺序无关方法比较（kernel-isolated，D=8）：3D-OVS/LERF/Mip-NeRF 360 上 521.8/891.9/660.0 FPS，为 3DGS 的 2.48×/2.50×/2.37×，比 Sort-Free（240.3/256.1/215.7）快 2.2–3.5×，比 Duplex-GS（319.1/332.9/127.9）快 1.6–5.2×；Duplex-GS 的 PSNR 最高（3D-OVS 25.40）但 MLP 求值带来开销。
    - 与快速渲染器组合：仅替换 FlashGS、GEMM-GS、Speedy-Splat、AdR-Gaussian 的混合核（保留其剔除/调度/排序）再获 1.69–2.84×，PSNR 变化不超过 0.24 dB；跨架构加速为 RTX 4090 2.37×、RTX 6000 Ada 2.36×、H100 2.33×。
    - 组件消融（两数据集场景平均，低分辨率）：D=8 时 253.8→OIEFB 423.5→+MMA 741.1→+warp packing 830.5→+lazy fetching 830.8；D=256 时 2.3→2.1→38.0→35.7→72.1；D=512 时 1.1→1.2→17.4→22.4→41.1。OIEFB 单独在 D=8 给 1.67× 但随 D 衰减，MMA 是主增益，warp packing 在 D≤64 加 12–22%，lazy fetching 在 D≥64 加 1.6–2.0×；整体 D≤128 比 3DGS 快 2.1–3.3×、D≥256 快 31–37×。
    - 特征维度可扩展性：混合核时间低维平均降约 3×、D=256 时降 36.7×；对照显示降精度不能解释——3DGS 改用 FP16 特征后速度变化不超过 17%，而本文核在相同场景仍快 2.2–4.8×（附录 D）。
    - 质量与代价：保真度依场景而变，teatime 上 PSNR 降 0.23 dB（多重半透明重叠需精确顺序），counter 升 0.73 dB（避开视角相关排序误差）；停滞分析显示 wait stall 与 barrier stall 各降约 10%。
- **创新点与贡献**：
    - 识别出「alpha 合成的顺序依赖」正是高维特征累积无法矩阵化的根因，并用顺序无关加权累积（式 7）把语义特征渲染改写为可交换求和，把计算原语从标量 FMA 换成稠密矩阵乘。
    - 给出 warp 级、像素×高斯的打包式 MMA 映射：W ∈ R^{32×16} 与 E ∈ R^{16×D} 两次矩阵乘（mma.m16n8k16，FP16），配合 warp 内有效性零投票跳过，把可见性不规则转为打包效率问题。
    - 提出 lazy channel-batched 特征取数（C_mma=8，与 MMA 输出 tile 对齐），只驻留当前 8 维切片并预取下一片，使 shared memory 占用与 warp 占用率不随 D 增长，这是 D=256/512 时 31–37× 增益的直接来源。
    - 证明该优化与流水线级加速器正交：只替换混合核即可在四个既有渲染器上叠加 1.69–2.84×，为「改混合原语」与「减少工作量」两类优化提供可组合范式。
- **局限与风险**：
    - （作者承认）顺序无关累积只是对深度序合成的近似，保真度依场景而变：极端多层半透明重叠会退化（teatime −0.23 dB），且为 alpha 合成调好的阈值需重新调参。
    - （作者承认）只加速前向渲染；训练也变快但幅度更小，因反向仍依赖 scatter 梯度更新与原子操作。
    - （作者承认）tile binning + radix sort、逐高斯预处理、warp 级打包扫描仍是非矩阵阶段，混合被加速后它们成为端到端加速的上界。
    - （作者承认）只针对 NVIDIA Tensor Core 的 warp 级 MMA，未评估 NPU 等其它矩阵单元。
    - （我在正文发现）正文仅承诺「will release our CUDA implementation and evaluation scripts」，抓取时无仓库链接，故 3.8×/36.7× 暂不可独立复现；Sort-Free 亦用第三方实现，基线的实现质量存在差异。
    - （我在正文发现）质量评估集中在 PSNR/SSIM/LPIPS/mIoU/LocAcc 均值，缺少对顺序无关近似在连续视角切换下是否引起闪烁/popping 的评估，而这正是该近似的典型风险。
- **与文献库的关系**：本文属 3DGS 渲染加速中「改计算原语」的一支，与「减少工作量」的流水线加速器互补。横向对照清晰：FlashGS（Feng 2024）、Speedy-Splat（Hahlbohm 2025）、AdR-Gaussian、HiGS 优化剔除/调度/排序但保留逐像素标量累积；TC-GS（Lee 2025）与 GEMM-GS 把 alpha 计算搬到 Tensor Core、ORANGE 搬到 NPU，但混合循环仍顺序相关；Sort-Free（LC-WSR）、StochasticSplats、Duplex-GS 去掉排序却仍以标量 FMA 累积——Table 1 把这三类与本文的「Accumulation (TC) / Order=None / Dim=Native」区分开。特征侧针对 LangSplat、LangSplatV2、Feature-3DGS 的「先压缩再渲染」路线，主张在原生维度直接渲染；本质是把 weighted-OIT（McGuire 2013）在语义 3DGS 上重新落地并硬件化。

### 第 2 章 · 面向第一人称视频的拓扑感知 4D Gaussian Splatting（Topo-4DGS）与 TopoEgo 基准（2611.16012，4.07 A，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-13，拉取日 2026-11-14）
- **一句话结论**：在自建 TopoEgo（24 段、4,618 帧、36 个动态物体、34 个拓扑事件）上，Topo-4DGS 在全部 8 个「数据集×事件族」分组中排名第一，相对各组最强基线最高提升 1.26 dB；拓扑物体整体 +0.92 dB，事件后帧从最强基线的 19.83 dB 提升到 24.30 dB（+4.47 dB），全场景 27.95 dB / SSIM 0.885 / LPIPS 0.179。
- **要解决的问题**：从单目第一人称视频重建日常操作物体是 embodied AI 与 AR 的基础，但现有 4DGS 依赖形变固定表示，在切割、装配、开合等拓扑事件下同时违反两个持续性假设：（1）运动结构会变——原本一起运动的区域在事件后各自独立，而 canonical 形变方法（Deformable 3DGS、4DGS）连续形变固定几何、EgoGaussian 给每物体单一刚体运动，都无法让部件在事件后分叉；（2）表面支撑集会变——表面被创建、暴露或遮盖时，持久 canonical 基元产生缺失几何或 ghosting。作者统计这类事件出现在 68.8% 的 Ego4D 与 80.0% 的 EPIC-KITCHENS 标注视频中。已有基准要么依赖同步多视角或深度的受控采集，要么只做运动分割（EPIC-Diff），没有基准系统评测真实第一人称视频中的 fission/fusion/open/close。
- **方法详解**：输入为单目第一人称视频、标定相机、物体与手部掩码及事件规格（事件族、事件时间 τ_m、终端件数 K、事件树）。Motion Bifurcation：每个物体 j 的终端件 k 各跟刚体轨迹 T_k(t)=(R_k(t),d_k(t))，每个 canonical 高斯带路由分布 P_{i,k}(t)，形变中心 μ_i(t)=Σ_k P_{i,k}(t)(R_k(t)μ_i^can+d_k(t))。路由由 Spacetime Clustering Field 给出：空间支路 z_i^sp=h_φ(γ(μ̄_i^can))∈R^K（低通位置编码 + K-means 热启动）；时间支路用事件门 g_m(t̄)=σ((t̄−τ̄_m)/β)，β=0.25；最终 P_i,k(t)=[Softmax((z_i^sp+B g(t̄))/λ)]_k，B 为可学事件偏置。时间只经事件门进入，路由在事件间稳定。Topological Boundary Resolution：件 p、q 分离时以互近邻找接触区、对匹配高斯中心拟合平面，投影后填二维凸包，生成绑定各自运动支路的新面；每个高斯带可微激活窗 W_i(t)，不透明度 α_i^t=α_i W_i(t)，新建或暴露面在事件时刻给激活边界、废弃或被遮表面给失活边界，最后小幅精修且约束 a_f≥a_s。优化：先按 EgoGaussian 逐物体估位姿、插值得粗轨迹，再联合精修 canonical 表示、运动、件轨迹与路由场；损失含掩码光度、轮廓与空间相干项，相干项对 canonical 位置加扰动后要求路由分布一致。最后联合精修只更新外观与不透明度。

### 第 3 章 · Kosmo-GFM：面向生产的几何基础模型（2611.16840，3.93 A，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（cs.CV），Kosmo Research 工业技术报告
- **公告类型**：new（公告日 2026-11-13，拉取日 2026-11-14）
- **一句话结论**：SpatialBench Sparse 上 AbsRel 降至 0.063（VGGT-Ω 0.077、π³-X 0.084）、AUC@5 达 0.741（0.695）；在 34 个共同场景、11,336 张图像上位姿 AUC@1/3/5 为 78.45/91.28/94.26（GLUEMAP 69.13/86.18/90.66），累计耗时 14.07 h 仅为 GLUEMAP 69.67 h 的约 20%，PoseEngine Flash 为 2.62 h（约 4%）。
- **要解决的问题**：从图像/视频恢复场景几何与运动长期依赖「特征匹配 + 位姿估计 + 几何优化」，但传统 SfM 在无纹理区、重复结构、大基线与动态场景下缺少可靠对应，且视图增加时维持场景一致性的代价迅速膨胀。几何基础模型（DUSt3R/MASt3R/VGGT/π³/DA3）通过大规模预训练提供可迁移空间先验，直接预测相机、深度、跨视图对应与动态几何；然而预测并不天然满足整场景的跨视图与时间一致性，尤其在长序列、大环境与动态观测下。作者据此指出系统层缺口：如何把学到的几何先验与场景级几何优化接起来，既用前者做初始化与稠密预测，又用后者把预测整合为一致结构；以及如何持续提升先验——公开 3D 训练数据稀缺，数据/模型/算力三轴的扩展行为缺乏经验证据。已有端到端系统与位姿系统通常被分开评估，缺少「先验质量如何转化为整系统精度与效率」的端到端度量。
- **方法详解**：三部分组成（Sec. 3）：GFM 给几何先验，PoseEngine 组织跨视图约束并精化相机，KosmoWorld 把真实场景重建转为训练监督。

GFM（3.1）。编码器沿用 Depth Anything 3：ViT-Giant、14×14 patch，视图内注意捕捉结构、跨视图注意建立几何上下文，另有 camera token 与 4 个 register token；取第 19/27/33/39 层特征拼成 3,072 维供深度解码，共 1,655.29M 参数。相机解码器用 4 个 block 解出平移、四元数旋转与水平/垂直视场（9 维），迭代精化 4 次并 detach 上次估计；深度解码器为 DPT 式由粗到细（256 通道、逐级上采样 + 跳连 + ResNet block），像素经 P̂_local = ẑ K^{-1} x̄、P̂_world = R^T(P̂_local − t) 投到公共系；动态点解码器沿用 UniQuery4R 的 query q=(u,v,s,t)，输出 3D 点、scene flow、对应与可见性；匹配解码器用 MVLoMa 的 STAR 组织。

损失（3.1.2）。相机项在第 k 次迭代上求平移与旋转 L1 均值并按下标加权：L_camera = Σ_k α_k [L_pose^(k) + λ_FoV⟨L_FoV,j^(k)⟩]（式 3–4）；深度项 L_depth = λ_geom⟨r/(|z|+ε)⟩ + λ_conf⟨c·r − β log c⟩（式 5），r = ‖P̂ − P‖₁、c = 1+exp(a)。

PoseEngine（3.2）。以 STAR（1 中心 + 邻居共 26 视图）为单元：无序集用 SALAD 检索 + Doppelgangers++ 校验，有序序列由时间相邻帧加少量 SALAD 补充。每个 STAR 内用 MVLoMa 一次前向完成中心到邻居的匹配，故一次前向同时给出先验与对应；≤26 张时回退 LoMa Large。原则是「GFM 越强，PoseEngine 可越简单」。Flash 版组合 FP8/FP16 与简化 BA。

KosmoWorld（3.3）。基于 HY-World 2.0 的 WorldNav：用 Recast 建导航网格按坡度/台阶/净空筛候选，探针位以 6 个立方体面覆盖视球，按 q_clarity = 0.4 s_n + 0.2 l_n + 0.2 a_n + 0.2 h_n（式 17）评估质量后规划轨迹并渲染。
- **实验与结果**：
    - GFM 静态几何：SpatialBench Sparse 上 AbsRel 0.063（VGGT-Ω 0.077、π³-X 0.084、π³ 0.092）、RMSE 0.621、δ1.03 0.670、AUC@5 0.741、AUC@30 0.823、TAcc5 0.739；Medium 上 AbsRel 0.059、AUC@5 0.745、ATE 0.508、RPE_t 0.145、RPE_r 1.088，均为所列方法最优（参数 1,655.29M，为表中最大）。

- **创新点与贡献**：
    - 把几何基础模型、位姿优化引擎与「重建派生监督」组成闭环：GFM 输出相机/深度/对应/动态点，PoseEngine 用它组织 STAR 并减少 BA 轮次，KosmoWorld 反过来用真实场景重建成训练数据改善 GFM，形成「先验越强 → 优化越简单 → 系统越快」的正反馈论证。

### 第 4 章 · 能重建多少就重建多少：无干扰物的 4D Gaussian Splatting（4D 高斯泼溅）（2611.16259，3.85 A，FULL）

- **赛道 / 场合**：神经渲染 / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-13，拉取日 2026-11-14）
- **一句话结论**：以形变场雅可比导出的形变敏感度作为路由信号，ReCan-GS 在 Bouncing Balls 上取得全表最佳 29.4 dB，在 Jeep 上把「干扰物被复现」的人评严重度从 DeformableGS 的 3.29 压到 1.09（检出率 0–11% vs 73–83%），烟雾场景相对最强基线在 Muscle Car、Hotdog 上分别提升 5.7 dB 与 6.2 dB；代价是 Squatting、Jeep 的 PSNR 比 DeformableGS 低 2.2 dB 与 1.9 dB。
- **要解决的问题**：从随意拍摄的单目视频做动态重建时，画面里同时存在应保留的主体运动与应剔除的瞬时遮挡物、阴影、反光、烟雾。已有做法分两类且各有硬伤：（1）静态干扰物去除方法（SpotLessSplats、WildGaussians、DeSplat、NeRF On-the-go）把一切运动当噪声，当运动主体就是重建目标时会破坏主体保真度；（2）动态重建方法（DeformableGS、4DGS）把所有观测联合建模，遮挡物被吸收进形变场，产生 ghosting 与不稳定几何。少数依赖预训练先验的方法（NeRF On-the-go 用 DINOv2、Robust 3DGS 用 SAM）引入外部模型依赖，且难处理慢速体积干扰物——烟雾在光度上稳定、几何上不一致。作者因此把干扰物重新定义为形变空间的不稳定性，而非物体身份、速度或外观。
- **方法详解**：场景拆成两层高斯：Core Gaussians 建模稳定内容（静态背景与主要动态主体），定义在 canonical 空间，用与 DeformableGS 同构的 8 层 256 宽 MLP N(μ_i,t)=(Δμ_i,Δq_i,Δs_i) 预测位置、旋转、缩放偏移；Distractor Gaussians 沿用 DeSplat 的 per-view 公式：每训练视角 n 维护独立集合，在相机对齐浅平面上初始化 K 个高斯，颜色为 RGB 向量并按视角计数做自适应密度控制。两层分别渲染后按 c_comp=c_dist+(1−α_dist)c_core 合成。核心是路由信号：对每个 Core 高斯算偏移对输入 (μ_i,t) 的雅可比 J_Δμ=∂Δμ/∂(μ,t)，以雅可比各行的样本协方差迹 U_Δμ=Tr(Cov(J_Δμ)) 度量该参数类型的不确定性，对位置/旋转/缩放求和得 U(g_i)，实现上用扰动时间 t′=t+ε 得稳健局部估计。用法有二：Variant 1 把 L_unc=Σ U(g_i)·α_core,i 加入 L_total=L_photo+L_alpha+λ_unc L_unc，惩罚既不确定又不透明的核心高斯，把不确定区域推向干扰层；Variant 2 训练时不算 L_unc，改用 EMA U_t=βU_{t−1}+(1−β)U_inst 累积，收敛后删除累积不确定性最高的 top-r% 核心高斯，用于严重杂波与分级剥离。
- **实验与结果**：
    - 数据：4 个含干扰物的动态场景（合成 Bouncing Balls、Squatting；iPhone 15 Pro 实拍 Jeep、Bottle）、4 个 SmokeSeer 合成烟雾场景（带无烟 GT）、以及 NeRF On-the-go 静态基准四场景。
    - 训练：合成 40k、真实 60k 迭代，单张 NVIDIA H200；K=1000（合成）/2000（真实）干扰高斯/视角，S=10 次访问后致密化，后处理剪除最不确定的 5–10% 核心高斯，λ_s=0.01、λ_unc=0.3、β=0.9；三个种子下 PSNR 标准差 Bottle 0.53 dB、Bouncing Balls 0.09 dB。
    - 主结果（Tab. 2）：Bouncing Balls 29.4 dB / SSIM 0.98 / LPIPS 0.03 为全表最佳；Bottle 23.0 / 0.78 / 0.22 为动态方法最佳；Squatting 29.3、Jeep 28.4，分别比 DeformableGS（31.5、30.3）低 2.2 dB、1.9 dB，但比 4DGS 高 1.6 dB、1.4 dB。
    - 干扰物残留（Tab. 3）：Jeep 人评严重度 1.09（0% 帧 ≥3）vs DeformableGS 3.29（72.7%）vs 4DGS 3.43（76.7%）；Bottle 1.33（9.3%）vs 3.37/3.41；三位标注者每方法 50 帧的一致性 κ=0.85、ρ=0.87（900 组配对），三个 VLM 评委盲评同向。
    - 烟雾去除（Tab. 4）：Muscle Car 16.8 dB vs 最强基线 DeSplat 11.2 dB（+5.7 dB），Hotdog 14.8 vs 8.6（+6.2 dB），Chair 10.9、Lego 12.5 亦领先；未与专用烟雾去除方法比较。
    - 定位与代价：Bottle 534 个含干扰帧上雅可比不确定性对 SAM 掩码的聚合 IoU 0.532、中位 0.483，运动幅值仅 0.284/0.071；训练 16.23 vs DeformableGS 9.22 min、显存 14.0 vs 2.8 GB、参数 9.70M vs 3.62M，推理 FPS 相同。
    - 静态基准反向结果（Tab. 5）：NeRF On-the-go 上 20.92/0.68/0.31，比 SLS-MLP（23.50/0.83/0.13）低 2.6 dB、SSIM 低 0.15、LPIPS 差 0.18，作者承认该区间非其适用场景。
- **创新点与贡献**：
    - 把「干扰物」从物体身份/速度/外观重新定义为形变场的局部不稳定性，用雅可比协方差迹给出无需 mask、无需预训练分割器、无需介质专属监督的解析路由信号。
    - 统一空间遮挡物、光度伪影与演化烟雾/雾：同一分数既可软正则路由到 per-view 干扰层，也可后处理硬剪枝，并按阈值分级剥离「手 → 运动阴影 → 细碎光度不一致」。
    - 首次把显式分解式干扰物去除从静态场景推进到完全动态场景（Tab. 1 中唯一同时具备动态重建、不确定性度量、烟雾去除且不需预训练模型者）。
    - 提出「保留干扰物几何」这一独立评价维度，用 3 人 + 3 个 VLM 盲评补足 holdout 帧不含干扰物导致 PSNR 无法反映残留的问题。
- **局限与风险**：
    - （作者承认）形变敏感度既非标定不确定性也非干扰物身份，观测充分的干扰物可能低分，观测不足的目标或正确但复杂的运动可能被误抑制。
    - （作者承认）仅 4 个动态场景（2 个真实）与 4 个合成烟雾场景，无专用烟雾基线，也缺少同一 Core–Distractor 架构内的受控路由消融。
    - （作者承认）静态干扰物基准明显落后（比 SLS-MLP 低 2.6 dB），且真实场景残留评分不能验证遮挡期间目标是否完整。
    - （我在正文发现）holdout 帧是人工挑选的 30–58 帧「干扰物完全缺席」子集且各方法共用，会系统性奖励「把干扰物吸收进形变场」的方法，主表仍偏向该失效模式。
    - （我在正文发现）训练时间翻倍（16.23 vs 9.22 min）、显存 5 倍（14.0 vs 2.8 GB）、参数 2.7 倍，且逐视角干扰层存储随视角数线性增长，长视频扩展性未评估。
    - （我在正文发现）K、λ_unc、剪枝比例 r 均按场景类型手工设定（合成 1000/真实 2000，剪 5–10%），未给跨场景自动选择准则。
- **与文献库的关系**：本文把 DeSplat（Wang 等 2025）的 per-view 干扰层从静态搬到动态 4DGS，并借用 DeformableGS（Yang 等 2023）的形变场与 alpha 正则，属改进某条线而非取代：相对 SpotLessSplats（Sabour 等 2024）依赖聚类嵌入、Robust 3DGS 依赖 SAM、NeRF On-the-go（Ren 等 2024）依赖 DINOv2，它去掉全部预训练先验；相对 4DGS（Wu 等 2024）与 DeformableGS 的联合建模，它引入显式第二层与解析路由；相对 Shape of Motion、MoSca 依赖点跟踪先验，它是正交的 prior-free 方案。作者承认与专用烟雾去除方法（SmokeSeer，Jain 等 2026）不构成竞争。新增方向是用形变场自身的可微结构做不确定性。
- **可复现性**：项目页 https://recan-gs.github.io 存在；正文称评测 holdout 帧列表与代码一同释放、VLM 提示词与逐标注者分数在项目网站。数据集为公开的 SmokeSeer 场景、NeRF On-the-go 与自采 iPhone 15 Pro 序列。正文未给仓库直链，许可未说明；依赖 COLMAP、PyTorch 与 3DGS 光栅化器，单卡 H200 训练，14.0 GB 显存可下探到消费级 GPU。

### 第 5 章 · TTB：面向 decoder-only 视角合成模型的测试时烘焙加速渲染（2611.17331，3.85 A，FULL）

- **赛道 / 场合**：神经渲染 / arXiv preprint（cs.CV）；NVIDIA 与阳明交通大学合作，正文未注明会议
- **公告类型**：new（公告日 2026-11-13，拉取日 2026-11-14）
- **一句话结论**：TTB 把 TTT 快速权重的内循环目标由「复现值 token」改为「拟合 cross-view attention 输出」，在 DL3DV 64 视角 960p 下以 30.20 dB PSNR、23 FPS 渲染，对照 DVSM 的 31.11 dB 但仅 1 FPS（60 s），实现最高 23× 加速；启用 local-duplicate 后达 31.33 dB，与 DVSM 持平。
- **要解决的问题**：Decoder-only 大型视角合成模型（LVSM/DVSM）用 KV-cache 作全局场景状态，质量最好，但每个 novel-view token 都要对 KV 做线性注意力，视角一多渲染即不可用：DL3DV 64 视角下 DVSM 仅 1 FPS。LaCT 用 TTT 层替换 cross-view attention，渲染降到 O(1)，代价是质量明显下降，即使从 DVSM 权重微调差距仍在。作者指出现有解释只把 TTT 当作线性注意力近似，未分析质量损失来源，也未意识到 context prefilling（图像加位姿）与 novel-view rendering（仅位姿）的模态错配，使烘焙出的 fast-weight MLP 需在两种分布间泛化。缺口：如何在保持 O(1) 渲染的同时，把 cross-view attention 的全局场景信息尽量无损写进固定容量 MLP。
- **方法详解**：沿用 DVSM 的 L 个重复块（IntraAttn、FFN、CrossAttn、FFN，式3），context 视图在每层 CrossAttn 预填 KV-cache，novel view 查询该 cache。输入用 Plücker ray 嵌入，context token 含位姿与 RGB，novel token 仅位姿（式4）。核心是把 TTT 的内循环目标换掉：TTT 为 θ←θ−η∇L(f_θ(W_k X), W_v X)（式6a），TTB 为 θ←θ−η∇L(f_θ(W_k X), g(X*))（式6b），取 g=CrossAttn，让 MLP 拟合注意力输出、与注意力协作而非取代。为消除模态错配，把每个 context 视图拆成 X⁰(ctx-gt)=LN(PE_ray+PE_rgb) 作映射目标、X⁰(ctx-rend)=LN(PE_ray) 作 TTB 输入（式7）；烘焙后的 MLP 共享给两路并回馈 ctx-gt。层内用单头 SwiGLU-MLP（隐维 3072）、per-token 学习率 0.01、Muon 加 weight normalization，T=3 步，损失为残差 MSE：θ_{t+1}=θ_t−Muon(∇‖f_θ(W_k X^{ctx-rend})−W_v(CrossAttn(X^{ctx-gt})−X^{ctx-rend})‖₂)（式8）。容量饱和用推理期 local-duplicate：按位姿 k-means 分 K=V/B 组（B=16），每组独立烘焙，novel view 路由到最近质心，渲染仍 O(1)。
- **实验与结果**：
    - DL3DV-10K（140 个 held-out 测试场景，960p）：16/32/64 视角下 Ours 为 27.00/28.92/30.20 dB，对应 DVSM 26.86/29.13/31.11 dB、LaCT 24.70/26.90/28.30 dB；渲染恒为 23 FPS，DVSM 为 4/2/1 FPS。
    - Re10K 两视角 512×512：Ours 31.28/0.926/0.127（PSNR/SSIM/LPIPS），DVSM 31.17/0.924/0.129，Decoder-only LVSM 29.53/0.904/0.141，Efficient-LVSM 29.86/0.905/0.147。
    - In-the-wild 64 视角 960p：MipNeRF360/Free/Hike 上 Ours(duplicate) 为 25.05/26.82/25.37 dB，DVSM 为 24.76/25.57/23.10 dB，均为 65 s 重建、23 FPS 对 1 FPS；对 LagerNVS 质量大幅领先且渲染快 3.1–9.5×。
    - 结构消融（表 4，DL3DV，V=32）：纯 TTT 替换 23.12 dB → 加 context pairing 23.78 → 加 MSE 与 T=3 为 24.22 → 目标换成 cross-view attention 24.84 dB；重建时间 0.439→1.998 s，渲染维持约 50 FPS。
    - 内循环消融（表 5）：TTT 的 dot-product 损失 23.12 → TTB– 改 MSE 提升 +0.44 dB（TTT 只 +0.27）；T 从 1 增到 5 单调但递减，取 T=3 为折中。
    - 层设计消融（表 6）：feedback 与 residual 各自贡献约 +0.43/+0.44 dB，合并 +0.52 dB（24.32→24.84）。
    - 训练配置：768 通道、12 个 decoder block、patch 8，从 DVSM checkpoint 初始化，DL3DV-10K 上 64 张 A100，340p 训 100K iter 后依次在 480p/720p/960p 各微调 10K iter，感知损失权重 λ=0.2。
- **创新点与贡献**：
    - 把 TTT 的 fast-weight 内循环目标从 value token 改为 cross-view attention 输出，使 MLP 与注意力协作而非替换，渲染复杂度仍为 O(1)。
    - 发现并显式解决 context prefilling 与 novel-view rendering 的模态错配，用 ctx-gt 与 ctx-rend 成对 token 让映射两端同分布。
    - 将烘焙内循环解释为潜空间光场优化，由此推出多步 MSE 加残差学习的收敛式配方。
    - 推理期 local-duplicate（k-means 分组加最近质心路由）在保持 O(1) 渲染的同时缓解固定容量饱和。
- **局限与风险**：
    - （作者承认）fast-weight MLP 容量固定，V 增大后质量饱和；local-duplicate 路由是启发式，训练期学习留作未来工作。
    - （作者承认）内循环中的 cross-view attention 使重建复杂度随 V 二次增长，单次或少次重建场景不划算。
    - （作者承认）方法基于重建而非生成，只在 context 视角之间插值，不能外推到未观测视角。
    - （我在正文发现）表 1 中 32/64 视角 PSNR 仍低于 DVSM（28.92 对 29.13；30.20 对 31.11），「持平」主要靠 16 视角与 duplicate 变体；且 64 视角重建耗时 65 s 反高于 DVSM 的 60 s。
    - （我在正文发现）23 FPS 与消融中约 50 FPS 出自不同设置（patch 8 与 patch 16），正文未在同一表内统一硬件与分辨率口径。

### 第 6 章 · HeadIO：面向头戴设备的体坐标系航向分解神经惯性里程计（2611.14895，3.63 A，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-13，拉取日 2026-11-14）
- **一句话结论**：在最大的头戴基准 Nymeria 上，HeadIO 把主指标 RTE-5s 由 EqNIO 的 0.260 m 降到 0.239 m（−8.1%）、ATE 由 3.577 m 降到 3.258 m（−8.9%），模型仅 0.97M 参数与 444 MFLOPs，比 EqNIO 少 7.8× 参数、2.8× 计算；纯 IMU 姿态下仍以 0.275 m 领先 7.4%，每 30 s 一次外部偏航修正可再提升 12.0%。
- **要解决的问题**：只用 IMU 的无相机头部追踪需在无视觉锚点时抑制积分漂移，现有做法有三处缺口。其一，主流神经 IO（RIDI、RoNIN、TLIO）把 IMU 旋转到重力对齐世界系，该约定源自手持手机的非刚性佩戴，但对刚性头戴 IMU 会丢弃隐含重力信号 R_t^T g，并使位移目标依赖航向。其二，yaw 增广（TLIO）只提升鲁棒性而不保证等变；EqNIO 用 Vector Neuron 学 O(2) 规范帧虽实现等变，却保留重力对齐前提，FLOPs 约为本文 3×。其三，原始体坐标系输入（AirIO）天然 yaw 不变，但头部俯仰/侧倾会把重力与运动信号重分配到设备三轴，同一动作在不同头姿下特征不同；人可朝任意方向看却向任意方向走，航向对头戴 IMU 是真正不可观测的 nuisance 变量，与无人机「倾斜与航向机械耦合」本质不同。
- **方法详解**：（III-A）IMU 刚固于头戴设备：a_t^B = R_t^T v̇_t^W + R_t^T g + b_a + n_a、ω_t^B = ω_t^true + b_g + n_g（式 1–2），R_t∈SO(3) 由设备滤波器给出。分解三步：①取 e_g = R_t^T ĝ，得 a_g = a_t^B·e_g 与 a_h = a_t^B − a_g e_g，陀螺同理得 ω_g、ω_h（式 3）；②把前向轴 f_b（视线）投影到 e_g 垂面，e_h1 = normalize(f_b − (f_b·e_g)e_g)、e_h2 = e_g × e_h1（式 4）；③投影得 6 维 x_t = [a_g, a_h·e_h1, a_h·e_h2, ω_g, ω_h·e_h1, ω_h·e_h2]。因 e_g = R_tilt^T ĝ，基只依赖 tilt；六标量等价于世界系比力与角速度在重力轴与水平视线的投影，yaw 从不参与变换，故同一动作同一视线在任意头姿下特征相同。近垂直视线用 fallback 轴。

（III-B/C）T=600（200 Hz、3 s）窗预测最后 1 s 位移；6 维标量经 kernel 7/stride 2 嵌入为 300 token×128 通道，接 3 个 pre-norm 残差双向 Mamba block（state 16、expansion 2，前向与时间反序相加），池化到 8 个时间位置后两 MLP 头输出位移均值与对角 log 标准差，共 0.97M 参数。推理用预计算基重建 d̂^B 再旋转 d̂^W = R_t d̂^B，基与姿态取窗口末样本——航向只在最后一步进入。训练前 10 epoch 用位移 MSE，其后改用对角高斯 NLL 联合训练不确定度头（Adam 1e-4、batch 256、50 epoch、单卡 A40）。
- **实验与结果**：

- **创新点与贡献**：

### 第 8 章 · IncR-3DSGG：基于有位姿 RGB 图像的增量三维场景图生成与特权深度监督（2611.15429，3.57 B，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（cs.CV）；Universität Augsburg，正文未注明会议

- **要解决的问题**：3D 场景图把物体实例与相互关系编码成图，是具身智能做任务规划、目标导航的紧凑表示。但现有方法几乎都把 3D 几何当作推理必需：3DSSG 在完整扫描的点云上跑 GNN；SceneGraphFusion、ConceptGraphs、Hydra、HOV-SG 在每帧用深度反投影维护体素或点云地图，靠点云重叠关联实例、靠几何规则算关系。这既限制部署到有深度传感器的平台，也把地图质量绑在深度噪声上。MonoSSG 去掉了深度传感器，但物体几何仍从 ORB-SLAM3 的稀疏关键点图读取，只有三角化点数足够多的物体才可表示。缺口是：能否把 3D 监督限制在训练阶段（privileged supervision），推理端只用有位姿 RGB 加全景分割，仍恢复度量可用的物体位置与关系，并保持增量式构建。
- **方法详解**：流程两段。输入 RGB 与位姿 T_t∈SE(3)：冻结 EoMT（DINOv3 主干，3RScan 上以 NYU40 微调）一次前向给出语义、实例与掩码，掩码平均池化得 f_i 作局部图节点。PRP 建边：f_i 经两层 MLP 投到 E 维并加类别 embedding，K 个 object token 过无位置编码的 transformer 自注意力得 h'_i；再构成 p_ij=MLP([h'_i;h'_j;h'_i−h'_j;h'_i⊙h'_j;g'_ij])（式1），g_ij∈R^10 为纯 2D 线索（中心位移、面积比、IoU、相对尺度、掩码重叠等）。四头：几何头 10 维（质心距离、方位、俯仰进 PGO，另 7 个接触特征）；关系头在 8 个 3DSSG 支撑谓词加 none 上分类，逆频权重加 focal；置信度头给 PGO 约束权重；extent 头预测尺度，大物体降权。训练用 masked 多任务损失（CE、focal、Huber、BCE），3D 目标由深度反投影得到。增量：新检测用匈牙利匹配加软类别一致性关联到全局节点；PRP 的相机系质心距离、方位、俯仰经 T_t 转成世界系位移 δ̂_ab 作位姿图约束；PGO 解 P*=argmin Σ ρ_H(√w_ab r_ab(P)) + w_a‖p_{a0}−p⁰‖²（式4），r_ab=(p_b−p_a)−δ̂_ab，w_ab=γ_ab/(1+e_a+e_b)，Huber 核加首节点锚定消规范自由度，每帧用 trust-region 重解；边标签按置信度加权投票跨视融合，距离与角度由 PGO 位置重算。
- **实验与结果**：

### 第 9 章 · 基于通用粒子系统的沉浸式视觉遮蔽碰撞预防（2611.15561，3.55 B，FULL）

- **赛道 / 场合**：交互与输入 / MUM '26（25th International Conference on Mobile and Ubiquitous Multimedia，Glasgow，2026-12-01/04，DOI 10.1145/3861188.3861241）
- **公告类型**：new（公告日 2026-11-13，拉取日 2026-11-14）
- **一句话结论**：在 253 次接近边界的事件中，粒子边界出现后被试平均再走 0.15 m 即停，与 Meta Guardian 网格的 0.14 m 无显著差异（p=.520），安全性相当；但粒子边界可见时长占比 37.0%，约为网格 12.6% 的三倍（p=.001，r_rb=1.00），SUSQ 临场感中位数 3 vs 1，7/11 偏好粒子方案。
- **要解决的问题**：VR 碰撞预防系统须在「及时提示重定向」与「不破坏临场感」间取舍，现有两类做法各有硬伤。网格化边界（Meta Guardian、Valve Chaperone）概念上与虚拟环境割裂、刻意突出，一旦可见就提醒用户身处模拟之中，易致 presence break；且因依赖视觉显著性，出现距离必须压晚（默认 0.5 m）以限制暴露。物理障碍的虚拟对应物（Sra 2016 等情境化方案）能融入场景，但依赖真实行走，一用传送，物理环境并未随之改变，对应物无法自洽。已有工作只研究烟雾对行进速度的减速（Davis 2023），任务本身仍要求穿越；视野限制类方案（Wu & Rosenberg 2019）提出机制却无情境化设计。作者据此指出缺口：尚无工作研究情境化的视觉遮蔽式 CPS。
- **方法详解**：设计依据与前研究（Sec. 3–4）。以气溶胶（雾/烟）为隐喻：不透明度与形态可随情境变化，不引入与场景冲突的刚性几何。前研究（N=10，Quest 2 + Air Link，2×5 m 房间，理论边界 3 m）比较 density/size/transparency 单参数、三者联合与 Meta GCPS 共五条件，按 0.25 m 步长调整出现距离。联合条件最早被察觉（Mdn=0.71 m，IQR 0.60–0.84）但最晚察觉仅 0.20 m；所有粒子条件下用户都把边界预期在理论边界之后，联合条件 Mdn=0.42 m。

系统（Sec. 5）。Unity 2023.1.18f1 标准粒子系统，粒子为 2D 贴图，发射体 1×1×0.5 m，中心前置 0.42 m 使预期边界对齐真实边界。按 HMD 到最近边界距离 δ 分三区：中性（δ>0.8 m 不显示）、渐显（0.4–0.8 m 线性上升）、临界（δ<0.4 m 完全不透明并覆盖全 FOV）。可见度 f=0（δ≥d_on）；f=1−(δ−d_full)/(d_on−d_full)（d_full≤δ<d_on）；f=1−θ/180°（δ<d_full），θ 为视线与边界法线的 yaw 夹角，故正对最强、转身减弱，以降低强度奖励重定向；三属性按 v_a = f·v_a^max 调制。最近边切换时瞬时重定位并从 f=0.05 淡入。

实验（Sec. 6）。被试内、4×5 m 物理空间、2×3 m 虚拟区，Quest 2 无线串流；收集 20 个球，球以步行速度漂移以强制真实行走；GCPS 用默认 0.5 m。量度含位置日志（约 134,000 样本、36 Hz）、碰撞、CAQ、SUSQ、两个 7 点安全题与 SEQ；日志用中位数 + Wilcoxon，问卷仅描述统计，安全性另用贝叶斯等价性检验。
- **实验与结果**：
    - 前研究 N=10（8 男 2 女，M=26.1，SD=1.91），五条件随机顺序各重复 5 次；联合条件首次察觉 Mdn=0.71 m（IQR 0.60–0.84），最晚 0.20 m；预期边界在理论边界之后 Mdn=0.42 m（IQR 0.23–0.45，SD=0.14），据此定 0.8 m 出现距离与 0.42 m 前置偏移。
    - 主研究 N=11（10 男 1 女，26–48 岁，M=30.08，SD=5.78），被试内、顺序平衡、每 trial 约 6 分钟；共 253 个 approach episode（GCPS 85 个，Mdn=4；PCPS 168 个，Mdn=17）。
    - 可见时间占比：PCPS 37.0%（SD=11.5）vs GCPS 12.6%（SD=8.4），V=0，p=.001，r_rb=1.00，即粒子边界可见时长约为网格三倍。
    - 转向距离 PCPS 0.65 m（SD=0.07）vs GCPS 0.36 m（SD=0.08），p=.001；作者明确该差异主要反映 PCPS 更早出现（0.8 m vs 0.5 m）。对齐到各自 onset 的反应距离为 0.15 m（SD=0.07）vs 0.14 m（SD=0.08），V=25，p=.520，r_rb=0.24，95% CI [−0.48, 0.82]；接近速度亦无差异（15.6 vs 16.3 m/min，p=.278），两条件都无逐渐减速，说明用户对「出现」而非「强度」反应。
    - 碰撞与安全：GCPS 平均 0.18 次（CI [−0.05,0.41]，SD=0.39）、PCPS 0.36 次（CI [−0.09,0.82]，SD=0.77），各仅 2 人越界，作者据此声明碰撞计数不足以支撑比较；主观安全 4.18（SD=2.27）vs 5.09（SD=2.07），贝叶斯等价性 BF∈∉=6.40（δ∈[−0.47,0.47]），后验中位 δ=0.24，95% CI [−0.30,0.79]，为等价的中等证据。
    - 临场感与偏好：SUSQ PCPS Mdn=3（IQR 0.5–5）vs GCPS Mdn=1（IQR 0–3）；CAQ 总体 Mdn 2.71（IQR 2.0–3.0）vs 3.0（IQR 2.96–3.62）；7/11 明确偏好 PCPS，6 人表示网格更常让他们想起真实房间。
    - 移动范围：两条件平均移动半径几乎相同（1.19 m vs 1.21 m），但 PCPS 下步行距离更短（Mdn 27.57 m vs 30.39 m）、传送略少（100 vs 117 次），部分被试报告主观空间被压缩。
- **创新点与贡献**：
    - 首次把视觉遮蔽作为情境化碰撞预防机制系统化：用标准粒子系统的雾状云替代网格，只表达方向与紧迫度而不表达精确几何，从原理上回避「暴露真实空间」与「传送后对应物不自洽」两个痛点。
    - 提出三段式邻近区（中性 0.8 m / 渐显 0.4–0.8 m / 临界 0.4 m）与视线相关可见度函数 f(δ,θ)，把强度与朝向解耦，使转身本身成为降低不适的手段。
    - 用前研究定量发现「用户预期边界位于可视化之后 0.42 m」这一系统偏移，并据此前置粒子中心，把定位偏差转成可补偿的设计参数。
    - 给出反直觉的设计结论：起效的是可视化的出现而非强度（云仅达约 40% 目标强度时用户已停下），故「更晚出现、更强刺激」不如「更早出现、更弱刺激」。
- **局限与风险**：
    - （作者承认）样本小（N=11）且性别严重失衡（10 男 1 女），问卷与碰撞计数只能作描述统计。
    - （作者承认）只测矩形 play area、无内部障碍，外部效度受限；碰撞仅以 HMD 位置判定，未捕捉手柄越界。
    - （作者承认）无线串流偶发掉帧可能影响粒子可视化的主观流畅度；任务可完全靠 micro-teleportation 完成。
    - （我在正文发现）PCPS 碰撞次数是 GCPS 的两倍（0.36 vs 0.18），虽区间重叠且样本极小，但作者未做检验即归因「故意越界」，缺少行为学证据（如越界前注视或延迟）。
    - （我在正文发现）只比较一种粒子配置与一种网格实现，未做粒子参数（颜色、密度曲线、发射体尺寸）消融，也未与 passthrough 或触觉/听觉提示对照。

### 第 10 章 · MRxD：混合现实跨设备交互的使用模式框架（2611.16171，3.17 B，FULL）

- **赛道 / 场合**：空间计算与UI / arXiv preprint（cs.HC），正文仍为投稿模板（DOI 为 XXXXXXX.XXXXXXX 占位，会议信息为模板默认值）
- **公告类型**：new（公告日 2026-11-13，拉取日 2026-11-14）
- **一句话结论**：从 4,857 条记录经 PRISMA 流程筛出 238 篇论文、284 个 usage episode：63%（180/284）为 Focused 注意、97%（275/284）任务相关，其中 53%（145/275）认知对称；由此得六个模式，Clone（90）与 Proxy（84）最多、Standby（6）与 Partition（3）最少；三作者两两 Cohen's κ 均 > .70，工作坊（n=6）显示框架能暴露设计盲点。
- **要解决的问题**：MR 跨设备（头显 + 笔电/平板/手机）设计困难，核心是用户须在角色异构的设备间协调工作流，而现有知识组织方式不足。其一，主流框架以设备与组件配置为中心：Brudy 2019 给出六维分类学，Hubenschmid 2026 的 MR-HUI 综述再加 interaction dynamics 与 anchoring，但描述的都是系统如何被组装，无法解释同一套硬件为何需要不同设计——HMD+手机既可是普通手机（Zhu 2025）、空间控制器（Liang 2016），也可是文本输入设备（Chen 2019）。其二，已有使用模式研究只覆盖非沉浸式生态：Yuan 2022 提炼 integrating/cloning/expanding/partitioning/migrating 五模式，Li 2025 用于跨设备学习，均未涉及沉浸式组合。其三，系统导向框架虽点出注意切换与知觉同步，但背后的使用模式未被明确化，设计者缺少「从预期活动出发」的中间层。
- **方法详解**：语料（Sec. 3）。检索 ACM DL、IEEE Xplore、Wiley、SpringerLink 得 4,857 条（2015–2025，检索日 2026-04-28），查询含 cross-device、hybrid user interfaces 与设备词、AR/VR/MR/XR。去 160 条重复与 1,206 篇短文余 3,491 条，摘要筛除 3,154 条、全文再排 99 篇，最终 238 篇。

框架（3.3）。沿 Nickerson 2013 迭代分类学，meta-characteristic 为「用户在一个 usage episode 内如何协调两类设备」，分析单元是 usage episode。维度须是用户侧推论、可从报告流程编码且互不重叠；演绎抽候选、归纳由三人对 20% 子集开放编码后归并。最终三维度二值化：User Attention（Focused/Fragmented，仅外显视觉注意）、Task Relatedness（Related/Unrelated）、Cognitive Symmetry（Symmetric/Asymmetric，源自 Hutchins 1985 的 semantic distance）。编码前三人对 15% 子集校准，两两 κ > .70；策略用 Braun & Clarke 主题分析。

结果与验证（4–5）。三维度交叉得六模式：Clone 90、Proxy 84、Extend 55、Complement 46、Standby 6、Partition 3；Cognitive Symmetry 对 Unrelated 不适用，故为 6 而非 8 种组合。每模式归纳策略（同步内容、扩展工作空间、输入重映射、互补表征协调）。形成性工作坊 n=6（23–29 岁，4 学术 + 2 工业），改编 design sprint：自选案例（VR 课堂 n=2、AR 家装 n=4），先自设计再引入 MRxD 重做，结尾访谈。
- **实验与结果**：
    - 语料流程：4,857 条 → 去 160 条重复与 1,206 篇短文 → 3,491 条摘要筛选（排除 3,154）→ 337 篇全文筛选（排除 99）→ 238 篇；检索日 2026-04-28，覆盖 2015-01 至 2025-12。
    - 维度分布（284 个 episode）：Attention Focused 180（63%）/Fragmented 104（37%）；Task Relatedness Related 275（97%）/Unrelated 9（3%）；Cognitive Symmetry 仅在 275 个相关 episode 上定义，Symmetric 145（53%）/Asymmetric 130（47%）。
    - 模式分布：Clone 90、Proxy 84、Extend 55、Complement 46、Standby 6、Partition 3，前两者合计约 61%，说明「聚焦注意 + 同任务」是主流形态。
    - 编码信度：三名作者在随机 15% 子集独立编码，两两 Cohen's κ 均 > .70（substantial agreement）；维度开发阶段另用随机 20% 子集做开放编码。
    - 工作坊 n=6（23–29 岁；两案例 n=2 与 n=4）：引入框架后被试补上初版缺失的多用户支持（P1、P2、P5、P6）与缺失的输入/输出组件（P1、P3、P4、P6）。
    - 工作坊行为转变：被试从整机角色分配（电脑编辑、AR 显示、手机记笔记）转为按能力（输入、输出、感知、传输）拆解设备；P1/P3 转向在 VR 内复用键盘输入，P6 从「手机记笔记」转为「手机作放置家具的代理控制器」。
    - 示例诊断：MaRginalia（Qiu 2025）的克隆平板界面属 Clone、笔到 MR 光标的重映射属 Proxy，据此指出其「笔按下激活按钮 vs 捏笔截屏」的映射不一致会带来局部摩擦（被试改用点击小圆点截取转录为旁证）。
- **创新点与贡献**：
    - 把「使用模式」视角从非沉浸式生态（Yuan 2022；Li 2025）扩展到 MR 跨设备，并以 238 篇语料给出首个面向 HMD + 非沉浸式设备的模式框架。
    - 提出第三维度 Cognitive Symmetry（源自 semantic distance），以「表征/动作-效果是否需重新解释」为独立设计轴，从而区分 Clone 与 Proxy、Extend 与 Complement——这是既有配置型分类学无法表达的差异。
    - 以维度组合而非模式直接编码推导模式，避免按共享设备或应用做表面聚类，使判据在异构语料上可显式复用（κ>.70 佐证可操作性）。
    - 为每个模式归纳可操作策略，并给出模式可迁移/可组合的分析（如把 Proxy 映射补进 Clone 主导的系统以支持快速检视），使框架兼具描述与生成功能。
- **局限与风险**：
    - （作者承认）检索可能漏检跨设备特征未体现在元数据中的工作（如 Friedl-Knirsch 2024）；排除 ≤4 页短文、手持 MR、空间 AR 与专用设备，框架不覆盖全部系统。
    - （作者承认）维度开发含解释性判断，换团队或换 20% 初始样本可能得出不同但同样合理的维度，初始样本还可能使某些维度先验地更显著。
    - （作者承认）三维度均二值化，压缩了本可能连续或随时间变化的中间状态与对应策略。
    - （作者承认）只保留每篇论文「设计动机或贡献核心」的 episode，模式分布反映研究侧重而非真实行为流行度，次要模式与组合可能被低估。
    - （我在正文发现）唯一实践验证是 n=6 形成性工作坊，无对照条件、无编码信度、无延迟后测，无法判断框架相对「无框架」或相对 Brudy/MR-HUI 维度的增益。
    - （我在正文发现）Standby（6）与 Partition（3）样本过少，其策略归纳基本是单例外推；lift 共现分析虽用于纠偏，但正文未给具体 lift 数值，模式组合结论不可核验。
- **与文献库的关系**：本文属跨设备交互框架脉络中的使用中心分支，与配置中心分支互补。它以 Brudy 2019（六维分类学）与 Hubenschmid 2026（MR-HUI 综述，增加 interaction dynamics 与 anchoring）为对照，指出后者解释「系统如何组装」而不解释「同一配置下的不同用法」，并以 HMD+手机的四种角色（Zhu 2025、Saidi 2021、Liang 2016、Chen 2019）为例。模式层面继承 Yuan 2022 的五模式与 Li 2025 的注意视角：Clone/Extend/Partition 对应 cloning/expanding/partitioning，但新增 Proxy 与 Complement 两个认知不对称模式，并把 attention 提升为第一维。方法上沿用 Nickerson 2013 与 Braun & Clarke。故本文是既有两条线在 MR 语境的合并与扩展。
- **可复现性**：部分公开：238 篇语料清单发布于 https://mrxd-paper.pages.dev/ ，检索式见附录 A，编码规则在 3.3 有描述，元数据分布放在 Supplementary Material；但未公开逐 episode 的维度编码表、lift 共现矩阵数值与工作坊原始记录，也无代码。论文仍用投稿模板（DOI 与会议信息为占位符），未见正式接收信息。复现的主要障碍是维度判定依赖解释性判断（作者自认不完全可复现），即便拿到清单也难以复现 284 个 episode 的边界与编码。
