## 三、逐篇深度解读

### 第 1 章 · EcoVGGT：面向长视频高效可流式前馈三维重建的固定键推理（Pinned-Key Inference）（2611.18099，3.93 A，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-13）
- **一句话结论**：用 31 个均匀分布帧作固定键集、并以 pin/attach 精确分解替代全帧注意力，使 VGGT 在 500 帧 ScanNet 上成功率由 70% 升到 82%（+12 点，相对 +17%）、ATE 由 0.111 降到 0.090（−19%）、速度快 8.5×；π³ 版本在 1,000 帧保持 94% 成功率而快 13.8×，单卡可重建 4,000 帧。
- **要解决的问题**：VGGT、π³、VGGT-Ω、DA3 这类前馈重建靠 global block 的全帧 self-attention，成本随帧数平方增长、显存随帧数线性增长：2,000 帧 518×392 需要 >80 GB 显存。即便装得下，精度也会掉——500 帧时完整 VGGT 只在 50 个 ScanNet 场景的 70% 里把 ATE 控制在 0.2 m 内，且其预测置信度区分成败的能力接近随机（AUROC 0.61）。现有补救各自让一步：流式方法（StreamVGGT、RetrieveVGGT、InfiniteVGGT）把到达帧的 token 冻结，早期错误无法修正，最多一半场景达标；分块管线（VGGT-Long 等）逐窗处理，无回环处必然漂移；token merging（FastVGGT）虽保持单次前向，但 2,000 帧多数场景 OOM；给每帧选少量 key 的方法要么按固定间隔、要么按内容（diverse views、retrieval、Good Token Hunting）。由此留下两个未答问题：长视频是否真的需要对所有帧做注意力？每帧的 key 是否必须依赖视频内容？
- **方法详解**：全帧注意力为 O_i = softmax(Q_i K^⊤/√d) V；网络交替 frame block F_{l+1} 与 global block G_l，联合前向 H_i^{(l+1)} = F_{l+1}(G_l(H_i^{(l)}; H^{(l)}))，用 KL(u‖a) = −log n − (1/n)Σ_j log a_j 度量注意力集中度。

观察一（对齐带）：7-Scenes 三条 100 帧序列上，KL 中位在 block 10 前 ≤1、block 14 达峰；每场景 31 个散布帧上，远距帧对的注意力份额与共视度的秩相关在 block 0–9 仅 ≤0.16、block 13–15 达 0.66–0.68。故 block 10–15 称 alignment band。

观察二（键可不看内容）：仅用 31–125 个均匀帧作 key 反而降低相对旋转误差；用全部 500 帧比 125 键差 7.2%（键数远超 24 帧训练上限后注意力被稀释）。键集取 p_k = 1 + round((k−1)(N−1)/(M−1))，M=31，注意力改为 O_i = softmax(Q_i K_P^⊤/√d) V_P，K_P、V_P 只留 pinned 帧。

Proposition 1（精确分解）：若所有 global block 都用上式，则 P 上的 pin pass 加其余帧分批的 attach pass，在精确算术下与联合前向逐帧相同。代价 M²T² + (N−M)MT² = NMT²，比 N²T² 低 N/M 倍（500 帧 16×、4,000 帧 129×）；Scene Cache 存 {H_P^{(l)}}，bfloat16 恒 1.5 GB。

Online Stream 每 κ 帧把最新帧作为候选，第 m 次 pass 在候选上均匀 pin ≤M_max=32 个，滞后 τ 个 pass 后输出其余帧；以深度中位比 s_m = median_k med(D̂_k)/med(D_k^{(m)}) 同缩放深度与平移，消除多 pass 尺度漂移（κ=32、VGGT τ=2、π³ τ=0）。

Alignment Refocusing 只微调 block 10–15（76M 参数）：pin 24 个散布帧 P、另取 24 个只读这些键的帧 A，最小化 L = λ L_cam(P∪A) + L_depth(R)，λ=5、R 为 6 个随机帧；195 个 ScanNet 扫描、2,000 步、3.6 GPU 小时。Alignment Score 取 block 13 上 2,048 个 query、全头的 KL 90 分位，借 KL(u‖a) = log Σ_j e^{z_j} − q^⊤k̄/√d − log n 直接算出。
- **实验与结果**：
    - 500 帧 ScanNet（50 场景）：完整 VGGT 成功率 70%、ATE 0.111 m、196 s、23.1 GB；EcoVGGT(VGGT)+refocusing 为 82%、0.090 m、23.1 s、10.0 GB（8.5×）。
    - 500 帧上 π³ 为 94%、ATE 0.054 m、138 s、24.4 GB；EcoVGGT(π³) 为 94%、0.052 m、19.9 s、9.9 GB（6.9×），无需任何微调。
    - 1,000 帧上 EcoVGGT(π³) 保持 94%、ATE 0.060 m、40.4 s、9.9 GB，对完整 π³ 的 94%/0.058 m/557 s/43.4 GB 快 13.8×；EcoVGGT(VGGT) 70%→82%、772→46.5 s（16.6×）、44.2→10.0 GB。
    - 2,000/4,000 帧：EcoVGGT(π³) 成功率 90–92%、ATE 0.060 m、40–41 ms/帧、9.9 GB；VGGT 版 82%、47 ms/帧；同条件下完整 VGGT、FastVGGT、StreamVGGT 在多数场景超过 80 GB 显存。
    - 能效（1,000 帧）：EcoVGGT 只有 π³/VGGT 的 7%/6%（11.5 vs 167.0 J/帧；13.7 vs 223.4 J/帧）。
    - 跨数据集（7-Scenes、NRGBD、TUM RGB-D、Replica）：EcoVGGT(π³) 与完整 π³ 的精度/完整度差 ≤2.4%，快 6.9–10.4×；对每个分块与流式方法 ATE 至少降 20%。
    - 消融（500 帧）：去掉 refocusing 成功率 −10 点、AbsRel +29.0%；去掉 Pinned Key Set 成功率 −4 点但算力 9.96×；16 键 −4 点，63 键仅 −2.4~3.4% 但吞吐降到 70%；MegaLoc 内容选键使 π³ 的 ATE +9.3%；额外读 8 个邻近键成功率 −12 点、Acc +110.4%。
    - Alignment Score：完整 VGGT 500 帧上 AUROC 0.91，对预测置信度 0.61、归一化注意力熵 0.52；在 pin pass 中 0.84、成本为逐帧打分的 1/16。
    - 在线：1,000 帧 18.6 FPS、每帧 6 s 内返回，在线 ATE 最低；对 StreamVGGT/RetrieveVGGT/InfiniteVGGT 的 ATE 降 51–83%，对 VGGT-SLAM 降 46–68%。
- **创新点与贡献**：
    - 提出并验证「长视频的 key 可以完全不看内容」这一反直觉假设：31 个均匀帧即可，而按内容选键（Good Token Hunting / MegaLoc 描述子）反而使 ATE +9.3%——相对流式的 cache/检索键与离线的内容选键是方向性反转。
    - Proposition 1 给出 pin/attach 的精确等价分解（精确算术下与联合前向逐帧一致），使流式实现不因近似而损失精度；相对分块与冻结 token 的流式方法，这是「无损」而非「近似」。
    - 发现 alignment band（global block 10–15 才把注意力与共视关联，秩相关 0.16→0.66），并据此把「对齐」抽成可复用模块：只调 6.5% 参数、3.6 GPU 小时就把 VGGT 成功率从 70% 拉到 82%。
    - Alignment Score 用 KL(u‖a) 的 90 分位做免训练、免 GT 的失败检测（AUROC 0.91 vs 自带置信度 0.61），且能在 pin pass 内提前给出，成本为全帧打分的 1/16。
    - Online Stream 的深度中位数重标定解决多 pass 尺度不一致：不做 rescaling 时点云精度误差 +189%、成功率 −12 点，是流式化必须补的一环。
- **局限与风险**：

### 第 2 章 · FOMOS：面向特征的有符号距离场网格化（2611.17458，3.85 A，FULL）

- **赛道 / 场合**：内容生成 / arXiv preprint（cs.GR）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-12）
- **一句话结论**：直接从 SDF 估计局部特征尺寸并按 ε-sampling 细化，FOMOS 在 512³ 网格上把 Chamfer 距离压到 7.5×10⁻⁴（正文口径，较 Structural MAT 低约 20.2%），并把网格化的时间/空间复杂度从立方降到平方，使 10240³ 的 TSDF 也能在内存中直接出网格。
- **要解决的问题**：Marching Cubes 与 Neural Dual Contouring 一类方法依赖均匀网格采样：要么输出稠密、含大量 sliver 的低质三角网，要么为稀疏性牺牲细节，且常需人工调参。无网格方法（RFTS、RFTA、MESC）又普遍过平滑，部分限制拓扑变化，在大网格上时间或内存不可承受（30 分钟上限下直接失败）。更关键的是，现有方法都只针对离散网格上的 SDF，且没有把「采样密度应当由局部特征决定」这件事真正落到细化判据里。
- **方法详解**：输入是隐式函数 φ:ℝ³→ℝ，零等值面 H={x:φ(x)=0}（内部为负）。核心量是局部特征尺寸 lfs(p)=|p,m|，m 为 p 在中轴 M 上的最近点；ε-sampling 要求对任意 p∈H 存在样本 s 使 |p,s|<ε·lfs(p)。FOMOS 分三步。
(1) 足点采样：只取 |φ(g)|<d 的网格角点（d=√3|e| 为单元对角线），沿梯度迭代 p←p−φ(p)∇φ(p)，平均 2.5–3.5 次收敛到 |φ(p)|<μ=10⁻²d，得到分布较均匀的曲面足点 P。
(2) 中轴骨架：对每个 p 沿 ±n 各拟合一个切球。FitBall 在 [0, ½diag(BB(H))] 上二分半径 r，球心 c=p+rv，最近点 q=c−φ(c)∇φ(c)；若 |φ(c)|<r 且 |p,q|≥d（球在别处碰到曲面）则收缩上界，否则放大下界，6–10 次迭代收敛；内外两球取半径较小者入 M̂。这一步不需要已知最近点，绕开了 sphere shrinking 的前提，且收敛性与采样密度无关。
(3) LFS 与网格化：对 M̂ 建 kd-tree，lfŝ(x)=|x,nn(x)|，单次查询 O(log|M̂|)。网格化沿用 Boissonnat–Oudot 的 restricted Delaunay：对每个三角形 t 求其对偶 Voronoi 边与 H 的交点 p，算 ε_t=r_t/lfŝ(p)，超过阈值 ε 即插入 p 并局部翻转细化，直到判据在整个曲面成立。体网格复用同一次 Delaunay 四面体化，并把四面体外接球半径与最短边之比限制在 2 以内以保证细化终止。
理论部分假设 lfs≤lfŝ≤(1+α)lfs，记 ε̃=(1+α)ε，借 LFS 的 Lipschitz 连续性与法向变化引理，把只在测试点成立的 ε 条件推广到整个 H（Theorem 5），从而保证输出流形且与目标曲面同胚。稀疏变体每 k 个单元取一个中轴点、网格化仍用完整 TSDF，复杂度由 O(单元数) 变为 O(三角形数)，这是即时预览的来源。实现为 CPU 并行 + CGAL 3D mesher，唯一参数 ε（主实验 0.1），预计算梯度可提速约 2× 但内存 ×4。
- **实验与结果**：
    - 主实验用 McGill 数据集随机选取的 100 个 SDF（含高亏格与薄壳），在 NVIDIA A100 + 64 CPU 核 / 64 GB 上跑，基线为 MC、NDC、RFTS、RFTA、MESC、McGrids，统一 30 分钟执行上限。
    - 512³ 上 CD 7.5×10⁻⁴、RMSE 0.00104，正文称较 Structural MAT 分别提升约 20.2% 与 14.8%；NC 98.16，F-score 99.99（Table 1 中 FOMOS 512³ 的 CD 记为 6.1×10⁻⁴）。
    - 分辨率扫描：CD 从 64³ 的 1.72×10⁻² 降到 512³ 的 6.1×10⁻⁴；32³ 时 F-score 仅 76.83，出现明显拓扑错误。
    - 64 核并行：512³ 的中轴骨架计算从 18.99 s 降到 2.96 s（6.41×，运行时减少 84.4%）；256³ 为 5.50×；64³/128³ 分别在 16/32 核后收益饱和。
    - 三角质量：shape ratio 0.4–1.0、最小角 15°–60°、长宽比 1–4；Figure 1 的对比中其他方法的缺陷 sliver 比例为 0.0–12.6%。

    - FEM 应用：兔模型用 ε=0.5 体网格得 15k 四面体、热仿真 0.65 s；等表面细节的均匀网格需 3810k 四面体、130 s。
    - 稀疏化：512³、ε=0.1 时 k 从 1 增到 32，运行时间降 80.5%、内存降 23.6%；ε=0.8 时 CD 从 6.37×10⁻⁵ 升到 3.54×10⁻²、HD 从 0.0258 升到 0.4333。
    - 巨型输入：1481×2609×1843 的 EMU 与 10240³ 的 Thai Statue TSDF，用 k=1/4/16 子采样中轴仍能出网格；作者称同期方法中只有 MC 能处理该量级。
- **创新点与贡献**：
    - 首个端到端「从 SDF 直接算中轴骨架、再据此做 LFS 采样与网格化」的流程，不依赖显式拓扑，也不假设形状类别。
    - 用切球二分（tangent-ball bisection）替代 sphere shrinking 求中轴点：只需 SDF 的距离与梯度，收敛性与采样密度无关，避免了投影到曲面的离散误差。
    - 把 ε-sampling 判据接到 restricted Delaunay 的每三角形细化上，并给出把测试点条件推广到全表面的证明（Theorem 5），同时把复杂度从 O(n³) 降到 O(三角形数)。
    - 稀疏中轴 + 全 TSDF 网格化的 output-sensitive 变体，使 10k³ 级 TSDF 与即时预览成为可能。
- **局限与风险**：
    - （作者承认）不适用于极低分辨率输入：64³ 时 CD 退化到 1.72×10⁻²，32³ 会出现 Betti 数不匹配的拓扑错误。

    - （我在正文发现）全部定量实验都是离线/合成 SDF 网格，真实扫描 TSDF 只出现在巨型输入的可视化里，没有精度评测；「即时预览」也只有运行时间，没有交互延迟或用户实验。

- **与文献库的关系**：与 Marching Cubes（Lorensen & Cline 1987；Chernyaev 1995）的均匀网格查表相比，FOMOS 不做体素级遍历而按 LFS 自适应布点，输出更少、形状更好的三角形；与 Neural Dual Contouring（Chen et al. 2022）依赖学习模板不同，它是纯几何方法，分布外形状上不会退化成非流形；与 Reach for the Spheres（Sellán et al. 2023）的梯度流 shrink-wrap 相比，它不限制拓扑变化；与 Reach for the Arcs（Sellán et al. 2024）相比，避免了大量坏三角形；与 Maximal Empty Sphere Contouring（Kohlbrenner & Alexa 2025）在每个体素求最大空球相比，它把内存与时间压到可处理 512³ 以上。细化框架继承 Boissonnat & Oudot（2005）的 restricted Delaunay + ε-sampling，但后者只对简单代数曲面能精确算 LFS，一般形状要退回 level-set thinning 或 λ-medial axis，FOMOS 用中轴骨架替换了这一环。

### 第 3 章 · 深度光束法平差（Deep Bundle Adjustment）（2611.18256，3.85 A，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-13）
- **一句话结论**：2.04M 参数的 GNN 把 BA 摊销成冷启动迭代细化：CO3Dv2 上 AUC@30° 78.6、RRA@15° 97.4，对最强 match-based 前作 GASfM(eLoFTR) 的 71.2/79.9 分别提升 10.4%/22.0%，参数量少 71×；DTU 结构 Acc@5cm 98.5% 对 GASfM 的 42.5%。
- **要解决的问题**：现代 SfM 与关键帧 SLAM 共用同一个求解器 bundle adjustment（BA），它在好的初始化下近最优，但非凸地形脆弱；增量 SfM 靠启发式与逐场景调参获得初始化，这些启发式在弱基线或平面结构上失效。另一方面，学习型半稠密/稠密匹配器已让匹配远比 SIFT 可靠，瓶颈从匹配转到求解器；然而把稠密匹配直接喂给 COLMAP 并不自动变好，因为其刚性 track building 会被匹配量淹没、初始化依旧脆弱。DUSt3R / MASt3R / VGGT 选择端到端回归几何，代价是丢掉「匹配器可替换」的模块化，且 VGGT 约 1.2B 参数、以第一帧为锚。缺口正是中间的空白：一个摊销 BA 本身、与匹配器解耦、可同时解任意视角数的学习型求解器。
- **方法详解**：DeepBA 把 BA 写成对视图图的学习式迭代细化。输入是 N 张无序图的成对 2D 匹配，构造 G=(V, E_pair, E_match)：E_pair 为匹配数 ≥50 的相机对，E_match 为全部匹配。场景状态 s := ({T_i^abs}, {T_ij^rel}, {φ_i}, {D_i})，φ_i 为 log-FOV，D_i 为 32×32 网格上的 log 深度；相对位姿解耦为 T_ij^rel = (t̂_ij^rel, ω_ij^rel)，t̂ ∈ S² 为单位平移方向、ω ∈ R³ 为旋转向量，只监督方向故无需度量尺度。

每次迭代从当前状态重算几何特征，隐状态不跨迭代传递（Markovian）。成对特征 f_ij^pair 为 14 维：相对位姿 6、两端内参 2、位姿图残差 6；匹配特征 f_e^match 为 12 维：两端像素 4、对极偏移 ε_e 2、重投影残差 ρ_e 2、log‖P_dst‖ 1、3D 一致性残差 δ_e^3D 3。隐状态统一 d_h=128；相机隐状态从共享嵌入 e_cam 起步。

细化网络为 L=4 个不共享权重的 Match–Pair–Camera（MPC）块，每块三步：相机→对/匹配广播（h_ij^pair += W_1^pair(h_i^cam‖h_j^cam)）、匹配→对按注意力池化聚合、对→相机注意力（前向状态送目标相机），4 头点积。四个头输出 ΔT_i^abs ∈ R⁶、Δφ_i、ΔT_ij ∈ R⁶ 与匹配隐状态散射到 32×32 网格再池化得到的 ΔD_i；相对位姿取反对称平均 ΔT_ij^rel = ½(ΔT_ij − ΔT_ji)；状态按 s_{k+1} = s_k ⊞ Δs_k 复合。

损失用尺度不变距离 d(T_a,T_b) = (1−cosθ_R) + (1−cosθ_t)，θ_R 为 SO(3) 测地角、θ_t 为平移方向夹角。r_ij^rel = d(T_ij^rel, T_ij^gt) 监督相对位姿；r_ij^abs = d(T_ij^abs, sg(T_ij^rel)) 借 stop-gradient 让绝对位姿跟随相对位姿，是学习版位姿图优化。几何项 L_2d、L_3d 用 smooth-L1 作用在 ρ_e 与 δ_e^3D 上，权重 w_e = γ²/(γ²+s_e²) 为按 GT 对极 Sampson 距离的 Cauchy 权重（γ=5×10⁻³），使损失只压内点；另有 L_fov 与不动点正则 L_fp = ‖Δs_k‖₁。训练 50,000 步 AdamW、lr 6×10⁻⁴，λ_2d=1、λ_3d=λ_fp=0.1，4×L40S；每步展开 K_train=100 次但只反传 24 次，视图图 ≤48 相机，状态从冷启动加高斯扰动开始。
- **实验与结果**：

### 第 4 章 · A·LoMa：超越局部图像块的仿射对应（Affine Correspondences）（2611.18170，3.80 A，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-13）
- **一句话结论**：在冻结的 LoMa 匹配器上加 3 层注意力仿射头，HPatches 中位 Frobenius 误差 1.50（×100）对 AffNet 26.9 与 Sun et al. 48.2 低约一个数量级（−94%），ScanNet1500 相对位姿 AUC@20° 70.2 对 Sun et al. 44.7 提升 25.5 点（相对 +57%）。
- **要解决的问题**：仿射对应（AC）比点对应（PC）多 4 个自由度，使最小解算器可用远少的样本（相对位姿 5 PC → 2 AC），但「AC 本身怎么估」长期停滞：传统路线是 Harris-Affine / Hessian-Affine 加 Baumberg 迭代细化，学习路线自 AffNet（2018）后几乎没进展，而 PC 侧已被 DKM、RoMa、SuperGlue、LoMa 的全局 + 跨视图上下文大幅改进。唯一的现代组合是 Sun et al.，但它仍只在每个匹配周围的小 patch 上预测，且 4 个自由度不联合回归——一个网络出 scale 与 orientation，另一个出 affine shape。缺口因此很具体：AC 估计没有吃到匹配器里已有的 image-wide 与 cross-view 信息，且四分量耦合使「从局部外观联合回归」被认为困难。
- **方法详解**：把 AC 表述为：给定匹配点 x_i^A、x_j^B，两图局部由 warp φ 联系，x_j^B = φ(x_i^A)，AC 即 φ 在 x_i^A 处的 Jacobian，φ(x_i^A+v) ≈ x_j^B + A_ij v，A_ij := ∂φ/∂x|_{x_i^A}，是 2×2 矩阵的 4 个自由度。

与「每对 patch 回归一个矩阵」不同，本文给每个关键点预测一个局部仿射帧 Â_i^A、Â_j^B ∈ R^{2×2}，可读作规范 patch 到各自邻域的线性映射；匹配的仿射由两者复合 Â_ij = Â_j^B (Â_i^A)^{-1}，逆一致性由构造保证。但该式只约束复合：对任意可逆 G，令 Â_i^A→Â_i^A G、Â_j^B→Â_j^B G 不改变损失，训练从不钉住单个帧本身，存在 gauge 自由度。为保证可逆，沿用分解 A = λ R(α) A′ = λ[[cosα, −sinα],[sinα, cosα]][[e^a, b],[0, e^{−a}]]，λ>0 为各向同性尺度（det A = λ²），R(α) 为平面旋转，A′ 为 det=1 的残差形状（拉伸 a、剪切 b）。

仿射头挂在冻结的 LoMa 上：对每个关键点取 LoMa 的描述子，过 K=3 层交替 self-/cross-attention 的 transformer，再由 per-keypoint MLP 回归 5 个数——尺度 1 个、朝向 2 个（归一化为单位方向向量，避开角度回绕）、形状 2 个（拉伸 a 与剪切 b）。为让 Â 及其逆条件数良好，λ = e^{Δ tanh(·)}、a = Δ tanh(·) 用固定 Δ=2 限幅，b 直接回归；预测头末层零初始化，每个关键点从单位仿射帧起步。由于头跨视图注意，帧以配对图为条件。

监督无需额外标注：由 GT 深度 D^A、内参 K^A,K^B 与相对位姿 (R,t) 写出 warp φ(x) = π(K^B(R D^A(x)(K^A)^{-1} x̃ + t))，再对 φ 在像素网格上做前向差分得 GT Jacobian，A_ij ≈ (1/h)[φ(x_i^A + h e_1) − φ(x_i^A) | φ(x_i^A + h e_2) − φ(x_i^A)]，h=1 px，结果写在归一化图像坐标。GT 匹配取深度 warp 的互为最近邻、且局部 Jacobian 有定义（避开遮挡边界）的点对。损失为 Charbonnier 鲁棒项 ρ(A,Â) = sqrt(‖A−Â‖_F² + δ²) − δ，δ=10⁻³，对匹配集取平均。训练 100K 步 AdamW、固定 lr 2×10⁻⁴、全局 batch 64、4×H200、560×560，约一天，放出 B/L/G 三个规模。

### 第 5 章 · VACO：面向单图稠密手部接触估计的顶点对齐解码（2611.17755，3.78 A，FULL）

- **赛道 / 场合**：化身与人体 / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-13）
- **一句话结论**：单一 checkpoint 在五个基准上全面超过 HACO：Hi4D F1 0.860 vs 0.653（+20.7 pp，相对 +31.7%）、DexYCB 0.693 vs 0.657（+3.6 pp）、RICH 0.840 vs 0.781（+5.9 pp），未见过的 HOT3D/HOCap 也 +5.5/+2.7 pp，并把下游 AGILE 的右手 Chamfer 距离从 23.11 mm 降到 12.46 mm（−46%）。
- **要解决的问题**：稠密手部接触（MANO 逐顶点二值标签）是灵巧操作策略、抓取重定向与 AR/VR 交互的基础原语，但两条主流路线都有具体缺口。reconstruct-then-query（Grady 2021、DECO、FollowMyHold）先重建手与物体再由几何近邻推接触，物体重建误差会级联，杂乱场景下脆弱，FollowMyHold 需约 9 分钟/图。直接预测（Tse 2022、Hu 2024、HACO）绕过物体重建，但把整个顶点集当作扁平 1D 目标：所有顶点输出都由同一个 shared contact query 交叉注意图像特征、再由一个共享线性头解码，网络从不知道每个顶点投影到图像何处，形成结构性盲区，产生「几何渗漏」——接触从真正受力的顶点扩散到相邻手指、指节与掌面。
- **方法详解**：骨干为 WiLoR 的 ViT-Huge 图像编码器（WHIM 预训练），联合优化重建与接触，输出特征金字塔 F_vit 与 MANO 网格 V；推理时 V 的投影即采样 scaffold，不需要额外重建器。逐顶点 token 构造：先把 F_vit 经轻量反卷积金字塔升到 S=3 个尺度（stride 1:8、1:4、1:2）；用同一 WiLoR 头预测的弱透视相机 π̂ 把顶点投影到像平面，双线性采样 f_v^s=Bilinear(F_vit^s, π(v;π̂))，拼接成 f_v=[f_v^1,…,f_v^S]。训练时在 GT 投影 π(V_gt) 上加 σ=0.02×crop 边长、截断 3σ 的高斯噪声再采样，以吸收姿态误差。token 化：t_v^(0)=MLP(f_v)+e_v，e_v 是按固定 MANO 顶点序索引的可学习嵌入，使 token 同时携带局部外观与「我是哪个顶点」的身份。解码：N=4 层 Transformer decoder（H=8 头，D=512），每层做两种互补读取——对 V 个顶点 token 的全局 self-attention（传播抓握结构：power grasp 全指相关，pinch 只涉指尖），以及对原 stride 特征图 F_vit 的 cross-attention（获取投影点之外的物体、对侧手、遮挡物上下文）。共享读出头逐 token 输出标量 logit ℓ̂=f_out(T)∈R^V，ĉ=σ(ℓ̂)。多粒度读出：标签由近邻启发式生成（多数数据集 10 mm）、逐顶点噪声大，直接监督 V 维输出不稳定，故用线性算子 R_r∈R^{n_r×V} 在四个分辨率聚合 ℓ̂_r=R_r·ℓ̂，r∈{V=778, V2=336, V3=84, J=21}（V2/V3 用 qslim 网格下采样矩阵，J 用 MANO 关节回归器，V 为恒等），顺带产出关节级与部件级接触。总损失 L_total=Σ_r L_VCB^r + λ_reg·L_reg + λ_smooth·L_smooth + λ_rec·L_rec，四路 VCB 等权、λ_reg=0.1、λ_smooth=1.0、λ_rec=1.0；VCB 按每个顶点的历史接触频率动态调制 BCE 惩罚，抑制全零坍缩；L_reg 为顶点均值先验，L_smooth 为网格邻接平滑，L_rec 为 WiLoR 重建目标以保住姿态。优化：AdamW（weight decay 1e-4，base lr 1e-5，encoder 用 0.5×），epoch 5 时两处学习率乘 0.9，共 10 epochs，8×RTX 4090、有效 batch 64、FP16，约 4 天（~768 GPU-hours）。推理阈值 τ_inf=0.52，左手镜像后重索引到左手拓扑。

- **创新点与贡献**：

### 第 6 章 · D2ToF：面向轻量单光子 LiDAR 波形的一步扩散深度超分（2611.18243，3.58 B，FULL）

- **赛道 / 场合**：系统与平台 / arXiv preprint（eess.IV）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-13）
- **一句话结论**：把 250 步条件扩散教师蒸馏成一步生成器并加入直方图重渲染一致性项，D2ToF 从 8×8×100 的 SPAD 直方图恢复 128×128 深度，Middlebury 干净场景平均 RMSE 11.7 mm（Marigold-DC 32.9 mm），单次前向约 83 ms。
- **要解决的问题**：低成本单光子阵列只有 8×8 或 16×16 个像素波形，空间信息极少，属于 16× 的极端超分。现有做法要么靠共配准的高分辨反射率图引导上采样（DELTAR、DVSR），要么用条件扩散（Marigold-DC），但前者需要多帧或把波形压成 (μ,σ)，后者要几十步迭代，推理开销大到无法上端侧。更根本的是，条件生成只保证「像」，不保证把预测深度代回前向模型后能复现实测直方图。
- **方法详解**：问题：由 H∈ℝ^{8×8×K}（K=100 bin）与 128×128 反射率 R 恢复 x∈ℝ^{128×128}，即 16× 超分。三路条件：H 给绝对深度但空间极粗；R 给结构但无深度；d_DA 由冻结的 DepthAnything V2（ViT-B）从 R 得到，只有相对视差，当未对齐引导用。
阶段一，条件扩散先验：cosine 调度、T=1000，前向 x_t=α_t x_0+σ_t ε，去噪分数匹配 L_teacher=E‖ε_θ(x_t,t,y)−ε‖²，采样用 250 步 DDPM。骨干为 ADM 条件 U-Net：128 基通道，五级宽度 (1,1,2,3,4)，最粗两级（16²、8²）加多头自注意力，共 140M 参数。非对称注入：H 经 3D 卷积编码器（两个 3×3×3 残差块，1→32→64），把每 4 个相邻 bin 相加（K:100→25）以提升稀疏光子下的 SNR，再展平到通道后加到最粗两级；R 与 d_DA 经并行 2D 残差编码器形成金字塔，在每个解码级 1×1 投影、拼接、3×3 残差融合后加入主解码流。
阶段二，一步摊销蒸馏：目标分布取 p̃_θ(x_0|y)∝p_θ(x_0|y)exp[−L_C(x_0;H)]，最小化 D_KL[q_φ‖p̃_θ]，展开得 L_student=E_q[L_C]+D_KL[q_φ‖p_θ]。数据一致性由可微前向实现：由预测深度 d_n 生成无缩放响应 u_{n,k}=c_n f(k−d_n)，c_n=R_n，f 为 σ=2 bin 的高斯（拟合 ST 冲激响应）；A 在超像素 Ω_m 上池化得 ū，H^est=g·ū+b_m，背景 b_m 取实测直方图每 bin 的中位数，增益 g 由总计数闭式匹配；L_C=(1/MK)Σ_mΣ_k(H^est−H)²。
数据空间 KL 在支撑不重叠时不稳定，改用积分 KL：L_IKL=∫w(t)D_KL(q_φ(x_t|y)‖p_θ(x_t|y))dt，w(t)=SNR_t^{-1}=√(1−ᾱ_t)/√ᾱ_t，梯度用教师-学生分数匹配估计，辅助网络 S_ψ 以去噪分数匹配跟踪生成分布。为跨噪声级稳健，引入扰动后验桥（PPB）：先用匹配滤波（σ=1 bin）从 H 得 8×8 粗深度 ỹ 并双线性上采样，训练时 y_a=(1−σ_a)ỹ+σ_a x_0+h·σ̄_a z，a~Beta(3,1)，h=0.1。
推理只有一次生成器前向 x̂_0=q_φ(ỹ+hz, a=1, y)，L_C 只在训练用。训练：教师 66k iter（Adam，1e-4，bs 48），学生 60k iter（AdamW，1e-4，wd 0.01，bs 6），w_con=12、w_rec=3，L_rec=‖x̂_0−x_0‖²；3×RTX 3090 训 14 h，DA 冻结。
- **实验与结果**：
    - Middlebury 12 个场景、8×8→128×128、7.65 mm/bin：干净条件（SBR 2.0、PPP 450）平均 RMSE 11.7 mm、SNE 20.1°；退化条件（SBR 1.0、PPP 300、反射率 Poisson γ=100 / 高斯 σ_r=0.02）为 21.7 mm / 28.0°。
    - 同表基线（干净/退化，RMSE mm）：DELTAR 43.6/43.3、Marigold-DC 32.9/45.9、DVSR 40.7/44.1、对齐后的 DepthAnything V2 33.0/61.1；本文教师 13.9/25.8，学生 11.7/21.7，学生每个场景都优于教师。

    - 一致性项消融：Noise 1 下 RMSE 21.26→20.16 mm（训练只用干净反射率）；重渲染直方图 MSE 干净场景 8.62→6.74，4 段真实明亮采集 19.70→16.12。
    - 条件消融（干净/Noise1/Noise2，RMSE mm）：仅 H+R 18.19/25.83/26.69，仅 H+d_DA 12.59/21.69/23.11，全模型 11.71/20.16/21.75；纯单目 33.0/61.2/61.1。
    - 模型规模：把 DA 换成 small，延迟 83→69 ms，RMSE 11.7→13.1（干净）、20.2→22.2（Noise1）。
    - 训练数据与增广：Hypersim 43,140 帧 + MPI Sintel 2,128 帧，128×128 patch，16× 下采样合成 8×8 直方图，Poisson 采样 SBR=2；训练时以 0.5 概率对 8×8 网格施加 ±10 px 平移（约 ±0.625 格）与 0.92–1.08 缩放，模拟 SPAD 与引导相机的配准误差。
    - 每个场景生成 50 次随机重建并对 GT 求均值，报告标准差（如 ±0.06 mm 量级）。
- **创新点与贡献**：
    - 把 DAVI 式摊销变分推断接到单光子前向上，使传感器域的数据一致性可以直接写进一步蒸馏目标（式 10–13），而不是训练后再做投影修正。
    - 用可微重渲染直方图做一致性：反射率作为响应幅度 c_n=R_n、增益 g 有闭式解、背景 b_m 用中位数估计，比图像域 L1/L2 更贴近物理观测。
    - 三路互补条件 + 非对称注入：低分辨 H 进编码器最粗两级，高分辨 R 与 d_DA 进每个解码级，并显式把 DA 当「未对齐」的先验而非深度输出。
    - 在 16× 单帧极端超分下同时拿到 11.7 mm 与 83 ms，精度优于其 250 步教师、速度快两个数量级。
- **局限与风险**：

    - （作者承认）真实数据量小，且反射率由旁边的 Kinect 提供，属于「外挂引导」，不是单传感器可独立工作的系统。
    - （我在正文发现）前向模型过于理想：假定每像素单次返回、高斯 IRF（σ=2 bin）、无多径、无 pile-up、无强环境光；真实 SPAD 在近距高反照率场景会明显违反这些假设，而训练数据全部是合成直方图。
    - （我在正文发现）基线输入被改造过：DVSR 用 10 帧峰值深度、Marigold-DC 只用 64 个稀疏锚点，信息量与本文（完整 100 bin 波形）不对等，速度对比也非同一硬件口径。

    - （我在正文发现）「实时」只在 RTX 3090 上成立，83 ms 中 39 ms 仍是 DA；没有功耗、内存、手机/嵌入式端的实测，而论文动机正是低成本模组与手机。

### 第 7 章 · MacroGS：宏像素共享 Gaussian 基元的任意倍率光场超分（2611.17957，3.57 B，FULL）

- **赛道 / 场合**：神经渲染 / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-13）
- **一句话结论**：在 EPFL/HCInew/HCIold/INRIA/STFgantry 五个基准上，MacroGS 作为即插即用解码器把 8 种编码器的 ×4 平均 PSNR 提升 0.34–0.70 dB（RASLF 32.69→33.04 dB），10 个编码器–倍率设置中 8 个取得最高 PSNR，相对逐视角 GSASR 解码提速 10–18×（0.30 s→0.03 s），解码器仅 0.37 M 参数（GSASR 2.57 M）。
- **要解决的问题**：任意倍率光场空间超分（LFSSR）要按任意倍率重建高分辨率子孔径图像，但现有两类解码器各有硬缺口：隐式坐标解码器（LIIF/LTE/DIIF/SEIIF）必须对每个视角的高分辨率网格逐点查询，延迟随倍率线性增长（×8 时 SEIIF 96.2 GFLOPs、0.16 s，CiaoSR 直接 OOM）；显式 2D Gaussian 解码器（GSASR）对每个 SAI 独立预测基元集，基元数为 UVKhw、随视角数增长，参数 2.57 M、×2 解码 0.30 s，且各视角基元不共享身份与几何参数，同一场景结构被重复参数化。固定倍率上采样器则只支持预定义倍率。
- **方法详解**：把生成单元从单视角像素改为宏像素：同一低分辨率空间坐标在 U×V 个视角上的样本集合。每个宏像素只生成 K=9 个基元，所有视角共用，基元数为 Khw，与视角数无关。基元参数 g=(μ̄,Σ,d,o,γ)：μ̄∈R²、Σ∈R²ˣ² 为中心与协方差（LR 像素单位），d∈R² 为每单位角坐标的水平/垂直视差，o 为基础不透明度 logit，γ=(γ^c,γ^α) 为二阶 SH 系数。跨视角位置 μ=μ̄+d⊙q_a（q_a 为归一化角坐标，中心视角为 0），协方差跨视角共享；不同基元可各自运动，给深度不连续处自由度。推断为 R=3 轮迭代跨视角读取：状态 z 初始由可学习 query e 加模板偏移嵌入 t_k 对 UV 个宏像素特征做 MHA 得到，并注入尺度嵌入 φ(s)；每轮先预测视差 d=d_max·tanh(ψ(z))（ψ 为两层 MLP），在 x_n+d⊙q_a 处双线性读取各视角特征 G，再由 Blk_r 四个残差子层更新（aggregate views：对自身读数做带视角嵌入的 MHA；exchange states：宏像素内 K 个状态互相注意；mix neighbours：3×3 depthwise 卷积；transform：FFN）。末轮由四个 MLP 头输出几何(δ,σ,o)、形状(κ,ρ)、颜色 SH、透明度 SH；中心 μ̄=x_n+τ_k+δ，δ 限制在 LR 像素的一小部分内；协方差 Σ=σ²[[κ²,ρ],[ρ,κ⁻²]]。渲染按请求倍率 S=diag(s_x,s_y) 缩放中心与协方差，权重 w=exp(−½Δᵀ(SΣSᵀ)⁻¹Δ)，归一化 splatting 聚合（不做深度排序）；颜色取 LR 图在 x_n+d⊙q_a 的采样值，再在 logit 域加 SH 视角修正，不透明度由 SH 修正。残差分支 Ĥ_a=Î_a+R([F_a↑,Î_a]) 逐视角共享权重细化细节。损失为所有 UV 视角 Y 通道的 ℓ1；视差头、SH 头、形状头、尺度条件与残差分支零初始化，不透明度 bias 使 K=9 初始不透明度之和约 0.8，训练起点等价于 LR 输入的归一化 splat；每编码器训练一个模型，倍率 1.5–4（步长 0.5），C=64。
- **实验与结果**：
    - 评测遵循 BasicLFSR 协议：EPFL、HCInew、HCIold、INRIA、STFgantry 五个基准，取中心 5×5 视角、bicubic 降质，仅超分 Y 通道，PSNR 按视角→场景→数据集逐级平均。
    - 8 个编码器（LF-InterNet、LF-DFnet、LF-IINet、LFT、DistgSSR、EPIT、LF-DET、RASLF）全部获得提升：×2 为 +0.10–0.54 dB，×4 为 +0.34–0.70 dB，且每个编码器在每个数据集上均提升。
    - ×4 平均：LF-InterNet 31.61→32.31（+0.70）、LF-DFnet 31.92→32.57（+0.65）、EPIT 32.42→32.92（+0.50）、RASLF 32.69→33.04（+0.35）。
    - 任意倍率对比（EPIT 编码器）：×2 39.58、×3 35.37、×4 32.92、×6 29.64、×8 27.77 dB，解码 0.03–0.05 s；SEIIF 为 39.60/35.25/32.76/29.61/27.68 dB，耗时 0.07–0.17 s；GSASR 为 39.31/35.30/32.56/29.49/27.64 dB，耗时 0.30–0.92 s、参数 2.57 M。
    - ×8 时比 SEIIF 快约 3×，比逐视角 GSASR 快 10–18×；参数 0.37 M 对 2.57 M。所有计时在单张 Tesla V100、输入 5×5×32×32。
    - RASLF 消融：K=4→39.42、K=9→39.60、K=16→39.62 dB（×2），9 个已饱和；R=1 降为 39.47（×8 27.67），R=5 仅 39.64/27.88，取 R=3。
    - 去掉残差分支：×2 由 39.60 降到 39.22 dB，×8 几乎不变（27.88 vs 27.85），而 ×8 的 FLOPs 从 132.2 G 降到 9.6 G。
    - 视差消融（RASLF，Zero/Macro-pixel/Primitive 三变体）：×2 上逐步提升且 STFgantry 收益最大，×4 与 ×8 三者接近，作者归因于视差 D 个 HR 像素只对应 D/s 个 LR 像素。
    - 学到的视差与几何强相关：×4 下 HCIold（真值视差）与 HCInew（SPO 估计）的 Pearson r 与 Spearman ρ 均 ≥0.85，跨 DistgSSR/EPIT/RASLF 三类编码器成立；×16 训练外倍率仍优于 GSASR/SEIIF。
- **创新点与贡献**：
    - 以宏像素为生成单元、跨视角共享同一组 Gaussian 基元，把基元数从 UVKhw 降到 Khw，从根本上解除基元数与视角数的耦合。
    - 每个基元独立预测视差，并让该视差同时驱动跨视角特征读取位置与跨视角渲染位移，形成「视差→采样→更新视差」的迭代闭环。
    - 视角条件外观：颜色先在 LR 图上按视差采样，再在 logit 域用二阶 SH 修正，零修正即退化为采样值，保证训练初期稳定。
    - 效率结构：基元推断与跨视角读取都在 LR 网格上完成，仅 splatting 与残差分支在 HR 网格，高倍率下可去掉残差分支而几乎不掉点。
- **局限与风险**：
    - （作者承认）学到的视差只保证与场景几何强相关（r、ρ ≥0.85），并不度量准确，不能当深度使用。
    - （作者承认）内容自适应的基元分配留作未来工作，固定预算下几何边界与细结构表示仍受限。
    - （我在正文发现）残差分支在高倍率占据绝大部分算力（×8 时 132.2 G 中约 122 G），去掉后 PSNR 不掉，说明该分支在高倍率下性价比很低。
    - （我在正文发现）增益随编码器本身的角度聚合能力增强而衰减：RASLF ×2 仅 +0.10 dB，窄基线 Lytro 数据集 ×2 收益也普遍更小。
    - （我在正文发现）正文只报 PSNR(Y) 与视差相关性，没有 SSIM/LPIPS 或感知/用户实验，画质结论证据单一。
    - （我在正文发现）训练时长、优化器、学习率、显存均未报告；也未与 LFGaussian、CVGS 这类同样跨视角共享 Gaussian 的方法做同协议定量对比。
- **与文献库的关系**：直接继承并改造 GSASR（逐视角可移动 Gaussian 基元的任意倍率解码器，本文的主要对照与加速对象）与 SEIIF（任意倍率隐式解码，精度与时延基线）；隐式族 LIIF/LTE/DIIF/CiaoSR/SAEIIF 提供「连续坐标解码」的问题设定，本文用显式 splatting 替换逐点查询；编码器侧复用 DistgSSR、EPIT、RASLF、LF-InterNet、LF-DFnet、LFT、LF-DET 七个公开骨干以验证即插即用；LFGaussian 与 CVGS 同样做跨视角 Gaussian 共享，但前者面向角度超分、后者是逐场景拟合，本文是前馈的空间超分解码器；2D Gaussian 图像表示源自 GaussianImage，视差引导采样受 RAFT/Deformable DETR 的迭代估计范式启发。
- **可复现性**：正文明确给出代码在 GitHub 可用，数据全部是公开光场基准（BasicLFSR 划分 + 五个公开数据集），因此复现门槛主要在训练算力而非数据。关键超参齐全：K=9、R=3、C=64、训练倍率 1.5–4、ℓ1 仅作用于 Y 通道、各头零初始化与 0.8 不透明度初始化。未给优化器、学习率、batch、训练时长与显存，需要自行试探；推理时间可在单张 V100 上对齐。许可为 arXiv perpetual non-exclusive license，商用需自行确认代码许可。
- **行动建议**：若在做光场相机/光场显示的 XR 管线，可把 MacroGS 当作与编码器解耦的上采样插件：0.37 M 参数、毫秒级、任意倍率，先在自己的编码器上做 ×2/×4 微调验证增益。复现时优先确认两点：对已强角度聚合的编码器（RASLF 类）增益是否仍 >0.3 dB；高倍率下直接关掉残差分支以省一个数量级 FLOPs。对外发表前建议补 SSIM/LPIPS 与真实采集光场的时延测量。

### 第 8 章 · TouchTwin：用实测触觉把人类演示重建成可扰动的仿真数据（2611.17619，3.55 B，FULL）

- **赛道 / 场合**：触觉与多模态 / arXiv preprint（cs.RO）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-13）
- **一句话结论**：用 880-taxel 手套测得的接触位置与握力驱动 MuJoCo 重建，TouchTwin 把策略握力从位姿模仿的 0.31×、视觉重放的 1.55× 修回 0.99×，并把接触漏检率从 32.2% 降到 13.1%。
- **要解决的问题**：现有 real-to-sim-to-real 管线只从视觉重建交互，能恢复手怎么动、物体怎么动，但接触力从未进入仿真——视频看不到力。手部位姿只说明手指停在哪，不说明闭合了多少，而闭合成败决定握力；接触还常被手自身遮挡，于是「哪几根手指、什么时候、用多大力」全部缺失。两种常规用法还会朝相反方向失败：位姿模仿只握到记录力的 0.31×，用视觉重放训练则过冲到 1.55×；而纯物理也恢复不了人类握力，记录值本身就是维持所需最小力的 1.6–3.7 倍。
- **方法详解**：输入是 TouchScale 的一段录制：头戴与腕部两路 RGB-D、一只 880 单元的触觉手套、以及标定信息。管线四步，核心是「触觉不是观测，而是驱动」。
(1) 物体：由编码智能体（coding agent）把物体写成 MuJoCo 程序，刚体之外显式建模活动件——抽屉闩、盖子铰链、滑块、喷嘴、移液器推杆等，并对每个资产做物理测试后才入库（论文给 10 类示例：马克杯、玻璃瓶、喷瓶、急救箱、工具箱、耳机、厨房秤、零件盒、收纳篮、钢杯、炒锅、移液器）。
(2) 手：按受试者拟合一个仿真手模型，从头/腕双相机跟踪手部（Potamias et al. 2024 一类方法），把 880 个 taxel 按真实手套的布局贴到仿真皮肤上，形成一条每铰链一个自由度的关节链；因此仿真力图可以直接和手套力图逐单元对齐。
(3) 触觉接地：回放时不用脚本驱动手指，而是让每根手指在「可见位姿」之外继续闭合，直到仿真 taxel 的读数与手套记录一致——这一步同时决定了接触位置、接触时刻和闭合力。论文强调物体从不被脚本化，只通过接触被带动（Figure 4）。回放后用仿真 taxel 力映射回手套 880 单元布局，与真实力图比对做校验（Figure 2(e) 的 check）。
(4) 数据引擎：对一条回放做单因子扰动——换抓握姿态但保持同等握力、加速/加抖动改变运动、按比例缩放每指力目标、给物体加质量或降摩擦；由物理引擎判定成败，于是得到带 per-taxel 触觉、接触与力标签的 N 条新演示。把某一因子扫到物体掉落，就量出原抓握的裕度。所有政策均在仿真资产上开环测试。
下游两用：一是训练接触预测器与手部策略（N0-VTLA）；二是把仿真渲染作为条件喂给 Wan2.2，沿记录的头相机轨迹生成写实视频，可换视角、换姿态、换场景，生成视频继承其回放的接触/力标签。论文正文未报告具体的损失函数形式、优化器设置与触觉闭合控制器的实现（是位置目标、力目标还是阻抗控制），这部分只有图注级描述。
- **实验与结果**：
    - 视频生成（同首帧、同提示、同种子）：以仿真为条件时 PSNR 18.89、SSIM 0.766、LPIPS 0.258、DINO 0.928，优于深度条件（18.55/0.759/0.276/0.914）与首帧+文本基线（15.36/0.663/0.489/0.854）。
    - 接触预测（held-out 人类自我视角录制）：触觉接地重放训练得 F1 0.890、漏检 13.1%、按压时长误差 0.61 s；视觉重放为 0.778 / 32.2% / 1.01 s。
    - 策略成功率：触觉接地重放在 held-out 录制上 20/20、在 36 个未见扰动上 35/36；视觉重放 15/20、33/36；位姿模仿 17/20、26/36（成功判据：滑移 ≤5 mm、放置偏差 ≤30 mm）。
    - 握力比：位姿模仿 0.31×、视觉重放 1.55×、触觉接地 0.99×（真值 1×）；而记录握力本身是维持马克杯所需最小力的 1.6–3.7×。
    - 扰动有效性：加 300 g 水后所需握力从 20.8 N 升到 27.4 N（+31%）；握力降到记录值的 22% 时杯子滑落；摩擦降到 0.12× 时滑落；4 Hz 横向抖动增至 ±60 mm（4.7 g）时脱手；12× 加速搬运使杯在手中滑移 19 mm。
    - 抓握姿态迁移：拇指-食指捏、顶抓、侧裹的杯中漂移分别为 3.8/2.1/1.9/5.1 mm；改用 rim-wall pinch 时杯在手中摆动 73°、落点偏 36 mm。
    - 手套未覆盖区：掌压扰动下（腕部沿掌法向推进 8 mm）手套掌部 taxel 读数为 0，仿真皮肤承力最高 22 N，说明仿真能补出传感器盲区。
    - 数据基础：基于 TouchScale 的 500 小时人类视觉-触觉数据；物体侧由编码智能体生成 10 类可交互 MuJoCo 资产。
- **创新点与贡献**：
    - 首次把「实测触觉」当作 real-to-sim 的驱动信号而非观测：用触觉闭合手指，从而同时决定接触位置、时刻与握力，而不是回归手套信号。
    - 建立触觉-物理的可校验闭环：taxel 布局一一对应，仿真力图可反投回手套 880 单元与真实力图逐格比对。
    - 单条录制 → N 条带标签扰动的数据引擎，由物理引擎判定成败，并可扫因子量出握力/摩擦/质量裕度。
    - 触觉条件下的视频生成：把物理解出的轨迹解码成新视角、新手势、新场景的写实视频，且继承接触与力标签。
- **局限与风险**：
    - （作者承认）所有策略只在仿真资产上开环测试，未做机械手迁移与真机实验，任务也仅限马克杯。
    - （作者承认）held-out 集小，且片段从手已接触物体开始，接触起始（contact onset）没有被测；双手回放仍有 12–23 mm 的滑移。
    - （作者承认）生成视频会继承仿真的误差，视频模型仍可能改动仿真未控制的细节。
    - （正文未报告）方法细节薄弱：没有损失函数、优化器、拟合误差阈值、触觉闭合控制器形式，也没有物体程序「物理测试」的判据与失败率。
    - （我在正文发现）0.99× 握力与 20/20 成功率都建立在单一任务、小样本上，未给置信区间；接触预测的提升只有一组 held-out 划分。
    - （我在正文发现）与同样使用仪器化人类交互的 ForceTwin、Touch2Robot 等只做了 related work 层面的区分，没有定量对比，难以判断触觉接地相对「力传感数字孪生」的净增益。
- **与文献库的关系**：与 X-Sim（Dan et al. 2025）、OmniHOI（Mao et al. 2026）、Grasp-and-lift（Choi et al. 2026）等从单目/自我视角视频重建手物交互的管线相比，TouchTwin 多了一路测得的接触力作为驱动，而不只是几何；与 MimicGen（Mandlekar et al. 2023）、DexMimicGen（Jiang et al. 2025）只扰动物体位姿与片段相比，它扰动的是一组被物理约束的量（握力、摩擦、质量、抖动），由引擎判成败；与从视频预测触觉的 Zhou et al. 2026b、Zhang et al. 2026a 相比，它不是回归手套信号，而是让触觉反过来决定仿真接触；与 TouchScale（Li et al. 2026）相比，它把数据从「可采集」推进到「可重放、可扰动」；与 ForceTwin（Engelbracht et al. 2026）的仪器化数字孪生相比，它强调触觉闭合手指并批量生成带标签演示。
- **可复现性**：数据依托 TouchScale（500 小时视觉-触觉，公开数据集），仿真器 MuJoCo 开源，项目页 touchtwin.github.io 提供可交互的物体资产；但论文未声明代码发布，管线中的编码智能体、手部拟合与触觉闭合控制器需要自行重建。依赖的外部模型较多：手部跟踪（Potamias et al. 2024）、视频生成 Wan2.2、策略 N0-VTLA，均需各自权重与许可。硬件为 Texas A&M 的 VISION 集群（AMD MI300X）。论文许可 CC BY 4.0，但资产与第三方模型的许可需逐个确认。

### 第 9 章 · DIRT：面向实时新视角合成的深度补全图像化渲染与双频带混合（2611.18340，3.51 B，FULL）

- **赛道 / 场合**：渲染与显示 / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-13）
- **一句话结论**：在 LiveNVS 手持 RGB-D 实时设定下取得 22.18 dB PSNR / 0.1959 LPIPS、69 ms capture-to-image，相比 On-the-fly NVS（18.86 dB / 0.3798 / 639 ms）PSNR 提升 17.6%、LPIPS 降低约 48%、时延降低约 9×，且全程无训练、无逐场景优化。
- **要解决的问题**：「边采集边看」的实时新视角合成有三类现有方案都不合身：逐场景优化的 NeRF/3DGS 需分钟到小时，无法在采集过程中给出反馈；通用化前馈网络（pixelSplat 类、Long-LRM、Depth Anything 3）依赖大规模多视图训练与对新数据集的泛化，且训练成本高；on-the-fly 预测加优化的 Gaussian（On-the-fly NVS）在实时约束下优化不收敛，画质与优化时长强耦合，小基线时尤其失败。纯学习型 IBR（Inovis、LiveNVS）还会用先验「美化」未观测区域，反而掩盖采集缺口，不适合作为覆盖引导。缺少一种无训练、确定性、能如实反映当前采集状态、并能直接吃 LiDAR/深度等多传感器数据的毫秒级方案。
- **方法详解**：三步管线，全部为几何与图像处理，无神经网络、无逐场景优化。输入为带位姿图像 {I} 与多传感器累积的非结构化点云 P（累积时区分静态/动态分量）。(1) 目标视角对齐的深度代理：把 P 投影到目标视角得稀疏深度 S，用递归图像空间补全（Alg.1）逐层填补。每层先用零均值高通核 K 估计邻域深度 N=(K*S)/(K*M)（M 为有效掩码），据此做遮挡点剔除：若 S(x,y) > N(x,y)·τ^l 判为被遮挡并置 0，τ^l=1+5^l·0.02 控制剔除灵敏度；随后 2×2 邻域有效值平均下采样得 S^{l+1}，递归补全；回程对上层做双边滤波抑制阶梯、双线性上采样，再与该层高频细节融合 D^l=S^l·¬M+D^l·M。数学上按线性深度定义，实现用逆深度以保证插值正确。与学习式补全不同，该过程锚定真实测量、不幻觉几何，可跨传感器零适配迁移。(2) 投影与去遮挡：把 D 反投影为点集 P_T 并连成三角网格，从每个辅助视角渲染得近似深度 D_A；把 P_T 再次投影到辅助视角得深度 d_p，做深度测试 P̃_A={p∈P_T : d_p−D_A(x_p,y_p)<ε}，ε 为与深度、法线相关的容差；只对通过测试的点取色，未通过处留洞，因此去遮挡是保守的（允许 false negative），但避免前景内容投到背景几何上产生错位。(3) 混合：每张候选图的权重 W 只用遮挡掩码 O_T 的近似平滑欧氏距离变换 softEDT 得到——靠近遮挡边缘权重低、远离处权重高，既压 seam 又偏向可信区域。再做 two-band blending（源自全景拼接的 Burt–Adelson 思路）：低频 L=G_σ*I_war（σ=0.95），高频 H=I_war−L；输出 I⊗(x,y)=H_{W_max}(x,y)+Σ_i L_i(x,y)*W_i(x,y)，即低频在所有候选中加权融合、高频只取权重最大的单张视图，从而保住细节不重影。最后用 PushPull 对未覆盖区域按邻近数据插值填充。辅助视角数 k 默认 4（覆盖与性能的折中），并用 temporal AA 抑制运动下的权重闪烁。
- **实验与结果**：
    - 统一评测环境：Intel i9-12900 CPU + NVIDIA A5000 GPU（24 GB 显存）+ 64 GB RAM；指标 PSNR 与 LPIPS（AlexNet backbone），主指标为 capture-to-image（最后一个输入视角数据到达至测试视角合成完成）。
    - 实时设定按时间窗喂数据：驾驶场景 5 s、手持 LiveNVS 15 s（该数据集约 1 fps 关键帧，每 16 帧取一帧测试）；仅评测前视相机，因为部分基线不支持多路视频流。
    - LiveNVS：本方法 22.18/0.1959/69 ms；On-the-fly NVS 18.86/0.3798/639 ms；Inovis 19.01/0.2736/157 ms；Long-LRM 19.93/0.2349/2686 ms；LiveNVS 方法本身 16.60/0.4495/49 ms；DrivingForward 不适用（需要深度以外的设定）。
    - nuScenes：23.47/0.2711/71 ms（On-the-fly 23.56/0.4622/439）；Waymo：24.79/0.2506/98 ms（On-the-fly 25.68/0.4270/693，PSNR 略低但 LPIPS 明显更好）；Argoverse 2：25.05/0.1802/135 ms（On-the-fly 18.19/0.5474/486）。
    - 离线（MipNeRF360 取 7 个场景 1/4 分辨率、Tanks and Temples 取 4 个场景全分辨率，COLMAP 稠密重建）：MipNeRF360 25.20/0.1486（Faster-GS 27.31/0.1420，On-the-fly 24.22/0.2659）；Tanks and Temples 22.10/0.2365（Faster-GS 22.38/0.2449）；热成像 RGBT-Scenes 24.37/0.1371（Faster-GS 24.36/0.1422）。
    - 深度来源消融（LiveNVS，LPIPS / 时间）：采集立体 0.1987 / 8.51 ms（预处理 0 ms）、单目估计 0.2725 / 8.51 ms、MVS-Former++ 0.1976 / 8.51 ms；目标深度融合改 nvblox TSDF 则 0.2438 / 74.39 ms，本方法在画质与速度上同时更优。
    - 参数消融：k=4 为覆盖与性能折中；σ=0.95 在无人工噪声时最优；τ^l=1+5^l·0.02；补充材料另有输入视角数、点云密度、补全与混合的消融。

- **创新点与贡献**：
    - 训练-free、确定性、可解释的 live NVS 管线：既无网络权重也无逐场景优化，采集中即可给出毫秒级反馈。
    - 测量锚定的分层深度补全：遮挡点剔除 + 由粗到细的高低频融合，不做生成式补全，避免幻觉几何。
    - 用 softEDT（平滑欧氏距离变换）直接由遮挡掩码构造混合权重，把权重设计与遮挡边界显式绑定，抑制 seam。
    - 把 two-band blending 从全景拼接迁移到多视图 IBR：低频加权混合、高频取最大权重单视图，兼顾无缝与细节。

### 第 10 章 · Zoom In, Scale Out：度量深度模型把数字变焦误判为靠近（2611.17903，3.12 B，PARTIAL）

- **赛道 / 场合**：评估与数据集 / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-13）
- **证据等级说明**：本篇 `PARTIAL`——arXiv HTML 404、ar5iv 仅返回摘要页，正文不可得，以下内容仅基于摘要与元数据，具体数值已标注「（摘要仅述，未在正文核实）」。
- **一句话结论**：提出免标注的数字变焦一致性检验，测得 Depth Anything V2 的深度按 s^−0.95 随缩放漂移（理想为 s⁰），即把变焦当成相机靠近；800 张 KITTI/NYUv2/DIODE 图像上，带相机预测的模型只降到 α≈0.31–0.36，而给出真值内参后 Depth Pro 与 DA3-Nested 的 α≈0（以上数值摘要仅述，未在正文核实）。
- **要解决的问题**：新一代单目模型声称能从一张照片给出以米为单位的距离，这要求它同时推断拍摄相机；但已有的评测都依赖 GT 深度，只能衡量「深度对不对」，无法把深度误差与内参误差分开。数字变焦（裁剪后放大回原尺寸）在几何上不移动任何场景点，正确模型对仍在画面内的像素应给出同一距离——这是一个免费、精确、无需标注的探针，但此前没有被系统用作诊断工具。
- **方法详解**：检验协议：对同一张图做裁剪并放大回原分辨率，缩放因子记为 s；场景几何未变，因此理想模型的深度应完全不变。用两个指数概括模型的反应：深度随缩放变化为 d ∝ s^{−α}（理想 α=0），焦距估计为 f ∝ s^{β}（理想 β=1）。α 与 β 通过对数域线性拟合得到。
诊断逻辑分三层。其一，若 α≈1，说明模型主要按「物体看起来多大」判断距离，把变焦读成靠近；其二，若在给定真值相机后 α 掉到 0，说明误差出在内参估计而非深度头——论文用 Depth Pro 与 DA3-Nested 验证了这一点；其三，若模型自带相机预测但 α 只降到 0.31–0.36，说明它的焦距估计随缩放增长得太慢（β<1）。
机理解释：变焦后的图在像素层面与「一张正常拍摄但深度被压扁的场景照片」不可区分，仅凭尺寸线索无法区分二者；而用回归训练的焦距估计器会停留在训练时见过的相机分布附近，遇到分布外的裁剪图像不会外推。
据此给出两类干预。免训练修正：不需要标签也不需要训练，直接校正焦距/尺度即可让 Depth Pro 通过检验（α=0.04），论文称在正常照片上几乎无代价。无标签微调：以自一致性为目标微调，并显式移除「图像模糊就意味着被变焦」这一捷径，之后 KITTI 上 α 降到 0.05、NYUv2 降到 0.07；论文同时报告这一改动在正常照片与未见照片上的代价。
对照实验包含真实光学变焦镜头，用以排除插值与模糊伪影。评估集为 KITTI、NYUv2、DIODE 共 800 张图（摘要仅述）。上述 α、β 与数值均为摘要级表述（摘要仅述，未在正文核实）；摘要亦未给出网络结构改动、损失函数形式、优化器与训练配置，正文不可得，故这些细节均无法核实。
- **实验与结果**：
    - 评测规模：KITTI、NYUv2、DIODE 三个数据集共 800 张图像（摘要仅述，未在正文核实）。
    - Depth Anything V2 的深度指数 α=0.95，即几乎按 s^−1 变化，把数字变焦当作相机靠近（摘要仅述，未在正文核实）。
    - 同样预测相机的模型只把 α 降到约 0.31–0.36，原因是焦距估计 f∝s^β 的 β 增长不足（摘要仅述，未在正文核实）。
    - 给定真值相机后，Depth Pro 与 DA3-Nested 的 α≈0，说明误差定位在相机/焦距估计而非深度网络（摘要仅述，未在正文核实）。
    - 免训练修正后 Depth Pro 的 α=0.04，且在正常照片上代价「几乎为零」（摘要仅述，未在正文核实）。
    - 无标签自一致性微调（移除「模糊即变焦」捷径后）：KITTI α=0.05、NYUv2 α=0.07（摘要仅述，未在正文核实）。
    - 对照实验包含真实光学变焦镜头，用以排除重采样与模糊造成的伪影（摘要仅述，未在正文核实）。
    - 摘要称报告了微调在正常照片与未见照片上的代价，但具体数值未在摘要中给出（正文不可得，无法核实）。
- **创新点与贡献**：
    - 把「数字变焦不变性」形式化为可证伪的双指数检验（α 衡量深度漂移、β 衡量焦距漂移），无需 GT 即可把深度误差与内参误差解耦。
    - 给出可解释的失效机理（变焦图在像素层等价于深度被压扁的正常图），并据此设计免训练修正。
    - 用真实光学变焦作为对照，正面排除「伪影导致误判」这一最常见质疑。
    - 把诊断扩展成训练目标：以自一致性做无标签微调，并显式处理「模糊=变焦」捷径。
- **局限与风险**：
