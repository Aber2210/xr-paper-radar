### 第 1 章 · Map2SLAM：从流式地图预测到实时 SLAM（2611.11169，4.57 S，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint
- **公告类型**：new（公告日 2026-11-10，拉取日 2026-11-11）
- **一句话结论**：把冻结的 streaming 3DFM 预测当作可修订的 SLAM 状态后，Map2SLAM 在 KITTI 上把平均 ATE 从次优非标定方法 ABot-Recon 的 13.56 m 降到 7.56 m（降幅超过 44%），VBR 上从 9.97 m 降到 5.15 m，Oxford Spires 上达 3.07 m，同时以 518×154 输入在 RTX 5090D 上保持 28 FPS 以上。
- **要解决的问题**：流式三维基础模型每帧输出几何预测，但预测一经发出即固定：长序列上漂移累积，即使重访已知地点，早先估计也无法修正，故替代不了 SLAM。已有组合要么按固定模式调用模型——预定义分块对齐或单次因果——而不是调度推理；要么把模型当前端塞进经典 SLAM；要么挂一个回环检测。作者主张：模型几何能力已够强，关键不在模型而在如何调度推理、如何把结果保存为可修订状态；正如 LLM agent 靠 harness 调度固定模型，三维基础模型也需类似机制决定哪些帧进入上下文、何时重观察历史、每次预测更新哪份状态。
- **方法详解**：建在冻结的流式模型上，利用其前缀因果结构提供的两种模式：双向前缀（多帧联合推理）与因果续写（逐帧自回归）。前端用因果续写处理实时流，后端用双向前缀重观察历史，两端异步跑在不同 GPU 上。前端在有界窗口内跟踪，每步因果续写视为一次关键帧探针：用预测位姿、内参与深度算投影运动，超过阈值即接受为关键帧并提交 KV 更新，否则回滚该更新。上下文达预算时接受帧触发重初始化：清空 KV，用接受帧与最近若干关键帧组成后继双向前缀；新前缀有自己的相似性基准，用重放关键帧的深度比定尺度、位姿定旋转与平移，把局部预测接回既有轨迹。后端先用缓存编码特征提回环候选（一个 180 万参数的聚合头，单帧约 0.94 毫秒），再用双视图前缀验证几何一致性，验证通过的约束进入增量位姿图优化在线纠偏；序列结束后用多视图前缀重观察顺序段与回环段做稠密几何精修，再把关键帧修正传播到非关键帧。所有调用共享每图一次的编码。

### 第 2 章 · FastGRT：加速 3D 高斯光线追踪的训练（2611.11586，4.17 A，FULL）

- **赛道 / 场合**：渲染与显示 / arXiv preprint
- **公告类型**：new（公告日 2026-11-10，拉取日 2026-11-11）
- **一句话结论**：把光线遍历与混合解耦并复用前向命中后，FastGRT 在 Mip-NeRF 360、Tanks and Temples、Deep Blending、Zip-NeRF 上训练比 3DGRT 快 1.9–4.97×，渲染质量持平（Mip-NeRF 360 PSNR 28.08 vs 27.88），且是首个开源的支持训练与渲染的 Vulkan GRT 实现。
- **要解决的问题**：光线追踪能表达光栅化 3DGS 难以做到的效果，如鱼眼等非针孔相机与镜面反射等二次光路，但高斯光线追踪的训练成本远高于 3DGS。作者剖析前向、反向与 BVH 更新三步后指出瓶颈不在遍历而在计算组织：反向会重新 trace 光线，尽管前向已找到每个像素的贡献高斯；但复用命中并不直接，每光线命中数事先未知且随像素与迭代剧变，在 kernel 内记录又增加访存、拖慢前向到抵消收益。相邻光线常更新同一高斯，产生大量全局原子累加与同步开销；BVH 每迭代重建，百万级场景下维护成本可观。
- **方法详解**：三条改动都保持“每个像素混合哪些高斯”不变，因此严格遵循原渲染公式。实现于 Vulkan，前向用多轮短遍历，推理仍用原单内核。其一，自适应多轮遍历：把 tracing 拆成若干短轮次，前向把每轮命中写入合并的逐像素归档，且不限制每光线轮数上限，从而在不过度拖慢前向的前提下记录全部命中；反向直接重放这些命中，不再遍历 BVH，彻底消除重复遍历。其二，快速梯度累加器：把更新同一高斯的相邻光线梯度先在片上子组内合并，再发全局原子操作，全分辨率下反向最多加速十倍。其三，混合 BVH 更新：高斯集合不变时原地重拟合，仅在数量变化（致密化或剪枝）或周期性时机重建。作者先用两个场景的训练时间分解定位各阶段占比，再逐项归因：全分辨率主要收益来自原子归约，标准分辨率下原子归约与 BVH 更新各占一部分。代价是需保存前向命中，显存随分辨率增长而高于基线。

### 第 4 章 · PLS-GS：概率激光雷达脚手架驱动的紧凑表面对齐高斯泼溅（2611.10699，4.14 A，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-10，拉取日 2026-11-11）
- **一句话结论**：在 GauU-Scene V2 五个大尺度室外场景上，PLS-GS 把平均 precision（几何精度）从 0.330 提到 0.484、Chamfer 距离从 0.820 m 降到 0.703 m，同时 anchor 少 2.8×、模型体积为基线 42%、帧率 1.7×，代价是平均 PSNR 从 27.10 降到 25.45 dB。
- **要解决的问题**：机器人/测绘平台同时给出相机与高精度 LiDAR，但主流 3DGS 只由图像监督：基元可以冗余、偏离真实表面，存储随场景尺度增长。已有两条路线各缺一半——Scaffold-GS/Octree-GS 用体素或八叉树提升紧凑度，但支撑结构离散、由光度梯度播种与生长，与实测几何无关，还存在单元边界的量化问题；LI-GS/GS-SDF/ARSGaussian 改善了与实测点的贴合，但每个 Gaussian 仍自带位置、协方差、透明度与球谐系数，基元在光度优化下仍可漂移，致密化与逐基元存储也不受约束。结果是尚无方法同时做到紧凑与锚定在实测表面上。
- **方法详解**：PLS-GS 把彩色点云拟合成连续的 6D 分层高斯混合（Hierarchical Gaussian Mixture Model, HGMM），并把这个混合模型本身当作渲染脚手架。构造：每点写作 [x, c] 属 R^6 并标准化，从单根节点起以分支因子 K=8 逐层 EM，节点内点数超阈才继续分裂，故分辨率随局部密度自适应而非固定网格；叶节点空间均值成为 anchor 位置，协方差作特征分解 Σ_j = U_j diag(λ_j) U_j^T，前两个特征向量张成局部切平面、最小者对齐法向，U_j 即「表面坐标系」，sqrt(λ) 初始化各向异性尺度，颜色均值初始化 anchor 颜色。几何与颜色联合拟合是关键：只拟合空间无法分开空间相邻但外观不同的表面（如路面标线与沥青）。渲染沿用 Scaffold-GS 的 anchor 解码 neural Gaussian，但把世界轴 offset 换成表面坐标系 offset：μ = x_v + U_v(o ⊙ s)，使两个大轴的铺展贴合切平面。约束为 Mahalanobis 支撑损失 L_support = (1/M) Σ δ̃²/(λ+ε)，位移沿高方差切向便宜、沿低方差法向昂贵，把基元压在表面薄层内；总损失 L = L_photo + λ_s·L_support，λ_s = 1e-3。生长：以视图空间位置梯度均值超阈的神经高斯为残差区，对其位置与颜色再拟局部 6D HGMM 并把叶节点实例化为 anchor，混合深度有上限、梯度随覆盖下降而自限，因此只长 1.1×（Scaffold-GS 为 2.6–2.7×）。初始 anchor 位置与坐标系在训练中固定，只优化特征、offset、尺度、颜色与共享 MLP。
- **实验与结果**：['数据集：GauU-Scene V2 五个室外场景——Campus（80M 点/670 相机）、Village（27M/424）、College（59M/1215）、Modern Building（94M/713）、Russian Building（28M/563），面积 0.8–1.56 km²；图像长边降到 800 px，每第 8 张作测试视图。', '基线：Scaffold-GS 分别用 SfM 点与 survey LiDAR 初始化（同一发布配置、同一 anchor 数），并额外设「匹配容量」对照：用 PLS-GS 最终 anchor 集初始化 Scaffold-GS 且关闭生长。', '主结果（Table 1 均值）：精度 0.484 对 LiDAR 基线 0.330、SfM 基线 0.312；Chamfer 0.703 m 对 0.820 m；anchor 460K 对 1308K（2.8× 少）；体积为基线 42%；帧率 190.4 对 114.4；PSNR 25.45 对 26.48/27.10，落后 1.03–1.65 dB。', '匹配容量（Table 2）：anchor 完全相同时精度 1.54×、recall 1.40×、F1 1.45×、Chamfer 降 40%，渲染差距由 1.03 dB 收敛到 0.21 dB，SSIM 差不超过 0.004、LPIPS 不超过 0.007；但帧率降到 190 对 272 FPS。', '消融（College，τ=0.333 m）：只加表面坐标系旋转而不加支撑损失几乎不改善（0.225 对 0.234），叠加支撑损失后精度 2.27×、Chamfer 2.95×；λ_s 由 1e-4 到 1e-3 同时提升 PSNR/SSIM/LPIPS 与精度；概率生长只增 1.06× 容量，同脚手架的光度生长增 3.23×（模型小 2.56×）。', '阈值鲁棒性：在每个 recall 与 τ 上都优于 LiDAR 基线，逐点误差分布整体更紧而非只在尾部。']
- **创新点与贡献**：['首次把 Eckart 等人的分层 GMM 从「几何表示」改造成「渲染脚手架」：混合分量既给 anchor 位置，又用特征向量给出表面坐标系，取代体素/八叉树的离散分区。', '在表面坐标系内解码 neural Gaussian 并配 Mahalanobis 支撑损失，使贴合实测表面成为优化中的约束，而非事后剪枝（对比 ARSGaussian 的距离阈值剪枝、GS-SDF 的神经 SDF 正则）。', '生长机制由离散网格上的克隆/分裂改为「对高残差神经高斯拟合局部 HGMM 并实例化叶节点」，容量有上界、触发自限，生长倍率从 2.7× 压到 1.1×。']

### 第 5 章 · 缓解 GPU 上 3D 高斯泼溅的 SM 级负载不均衡（2611.12319，4.08 A，FULL）

- **赛道 / 场合**：系统与平台 / arXiv preprint（Preprint，ICML 模板排版）
- **公告类型**：new（公告日 2026-11-10，拉取日 2026-11-11）
- **一句话结论**：在大尺度城市场景 Hier-3DGS 上把 alpha blending 平均加速 2.93×、最不均衡帧最高 5.64×（摘要写作 5.6×），24 个场景相对原渲染器的画质差最多 0.0015 dB PSNR，且无需重训练或改动场景表示。
- **要解决的问题**：3DGS 的 tile-based 光栅为每个 16×16 tile 分配一个 256 线程 CTA，但各 tile 的 Gaussian 数差异极大：标准基准最大/最小比 55–605×，大尺度场景超过 6,100×。硬件 CTA 调度器以 CTA 为粒度且不知 tile 负载，少数极重 tile 会在其他 CTA 早已结束后继续运行，形成长执行尾并让大量 SM 空转——测得 3DGS train 最重 tile 是每 CTA 均分份额 1.7× 时平均 SM 活跃度仅 49.2%，Hier-3DGS 达 6.8× 时降到 24.9%。已有工作集中在两端：算法层剪枝与预算致密化需重训练，难以用于已重建场景；专用加速器能效高但缺乏对 2DGS、3DGUT 等演进变体的灵活性，且仿真环境需 GPU 同时跑渲染与 VLA 推理。系统层软件优化几乎空白。
- **方法详解**：核心是把「何时执行」与「执行多久」分开处理，整体为软件定义 GPU 调度，不改场景表示也不改 alpha blending 公式。（1）LPT 加 persistent kernel：启动 K 个 CTA（K 为 GPU 可并发数）的常驻 kernel，每个 CTA 通过一次 atomicAdd 从软件队列 Q 取下一个 tile，队列按 tile 投影 Gaussian 数 N_t 做基数排序降序（不搬动 Gaussian 数据），计数与排序开销低于 alpha blending kernel 时间的 1%。（2）深度分块加 saturation signaling：把极重 tile 的按深度排序的 Gaussian 列表切成 k 个连续 chunk，各由独立 CTA 以单位初始透射率混合，得部分色 C_p 与透射率 T_p，再由 reduction kernel 按 C = Σ C_p Π_{q<p} T_q 合成——这是可组合性 C = C_A + T_m·C_B 的推广（类似 Flash-Decoding 的归约，但需逐像素色与透射率）。独立执行破坏了透射率阈值 1e-4 的 early termination，故用全局内存 flag 记录最早整体饱和的 chunk（atomicMin），后续 chunk 每 256 个 Gaussian 检查一次并停止；因透射率沿深度单调递减，跳过是安全的。（3）选择性分块加流共执行：只对最重的一小部分 tile 分块，其余仍走 LPT，两 kernel 放在不同 CUDA stream 由硬件调度器分配 SM，最后用 CUDA event 同步再 reduction。（4）每帧在线策略：用管线已有的 per-tile Gaussian 数构造启发式代价 T̂(h,k) = max((N_total + λhk)/K, ℓ) + βℓ，ℓ = max(N_1/k, N_{h+1})；在 k 属于 {2,4,8,16} 上递增 h 搜索最小 T̂，仅当估计代价比 LPT-only 低至少 ε=10% 才启用分块。

### 第 9 章 · Spaghetti Splatting：以卷积对曲线型狄拉克质量求导的可微泼溅（2611.12716，3.92 A，FULL）

- **赛道 / 场合**：神经渲染 / arXiv preprint（cs.CV）
- **公告类型**：new（公告日 2026-11-10，拉取日 2026-11-11）
- **一句话结论**：以线段与折线取代点支撑后，Spaghetti Splatting 在 Mip-NeRF 360 上以 Beta 核取得 28.78 dB PSNR（高于 DBS+SV8 的 28.71 与 3DGS-MCMC+SV8 的 28.39），在头发重建上比 Gaussian Haircut 高 2.7 dB PSNR、2 mm 阈值 F1 高 14.3 点（61.2 对 46.9），帧率与 3DGS-MCMC 相当。
- **要解决的问题**：生产级图形用点、线、三角形等基元，硬件为这些基元高度优化；但要用体渲染从图像反学这些基元很困难，因为它们是定义在无穷小位置上的 Dirac 质量，梯度无处作用。EWA splatting、Poisson 重建与 3DGS 的解法是把 Dirac 质量与低频核卷积，这一配方沿「核」与「基元」两个轴可推广：核这一轴已有 Deformable Beta Splatting，基元这一轴已有点、凸体、三角形与刚出现的直线。曲线基元仍是空白——3Doodle、SketchSplat 只面向稀疏草图或边缘抽象；并行的 Tojo 等人以固定屏幕空间宽度光栅化不透明线，随深度不变，无法建模真实场景（Mip-NeRF 360 上仅 8.66 dB）；头发路线（Gaussian Haircut、Neural Strands）依赖头发专用先验，产出分散高斯而非可仿真的连续发丝。
- **方法详解**：出发点是把 3DGS 基元重写为「Dirac 质量 ⊛ 核」：G(x) = [δ(·−μ) ⊛ N_Σ](x)，从而把基元支撑与核解耦。方法保留 3DGS 的核、把点支撑换成长度可学的有限线段：端点 a、b，v=b−a，x(u)=a+uv（u 在 0 到 1），其测度 m(x)=∫δ(x−x(u))du，基元 P = m ⊛ N_Σ；当 a=b 时退化为 3DGS 点核，故为 3DGS 的严格超集，也兼容 DBS 的 Beta 核。密度取 σ(x)=ρ∫N_Σ(x−x(u))du。沿射线的光学厚度可闭式求解：交换积分次序（Tonelli）后内层是高斯沿射线的积分，作为 u 的函数是均值 ū、方差 1/(2κ²) 的一维高斯，κ²=‖v‖²_{Q⊥}、ū = v^T Q⊥(o−a)/κ²，Q=½Σ⁻¹，Q⊥ 为沿视线的边缘化矩阵；最终 τ = ρ f(ū)√π/(2κ)[erf(κū)+erf(κ(1−ū))]，其中 f(ū)=√(π/(d^T Q d))·exp(−‖o−x(ū)‖²_{Q⊥})，只需 erf 而非 Owen's T 函数。折线按段独立求不透明度再沿射线合成，因积分可加，接头处不会重复计数。提速上每帧在中点算一次 EWA 并按逆深度沿段缩放，把逐像素计算降为几个屏幕空间量。抗锯齿沿用 Mip-Splatting 的三维加二维滤波，二者在 EWA 线性化下只加到投影核协方差上，闭式仍成立。优化沿用 3DGS-MCMC 种群控制并改造致密化：长段二分（子段继承父段密度时渲染不变）、短段克隆；折线合并加端点吸引损失 L_connect 促使段连成连续股。两处工程细节决定可用性：一是每段在屏幕空间只做一次中点 EWA 加沿段缩放，避免对每个基元与像素对都求闭式；二是滤波只改投影核协方差，使抗锯齿与闭式求值不冲突，从而在保持单样本每像素的前提下稳定远近尺度。
- **实验与结果**：['数据：23 个场景——Mip-NeRF 360（5 室外 4 室内）、Shelly（6 个含毛发/羊毛/薄叶的合成物体）、Fuzzy（8 个仙人掌刺/毛皮/刷毛实物）；Mip-NeRF 360 室内 2×、室外 4× 下采样，每第 8 张作测试，Shelly 用 1920×1080 白底，Fuzzy 4× 下采样。', '基线：3DGS-MCMC+SV8、DBS+SV8、Gaussian Frosting、Line Primitives（Tojo 等）、Gaussian Haircut。', 'Mip-NeRF 360 PSNR/SSIM/LPIPS：Ours(Beta) 28.78/0.838/0.193，DBS+SV8 28.71/0.837/0.189，3DGS-MCMC+SV8 28.39/0.834/0.190，Gaussian Frosting 26.93/0.804/0.209，Line Primitives 8.66/0.350/0.571。', 'Shelly 与 Fuzzy：Shelly 上 Ours(Gaussian) 37.38/0.962/0.048 对 DBS 37.22、3DGS-MCMC 37.10；Fuzzy 上 Ours 35.03/0.957/0.040 对 3DGS-MCMC 35.00、DBS 34.98、Line Primitives 33.64。', '头发：GeomHair 400 款中选 8 款加 Yuksel 卷发模型，每款 100 视角 1200×800 Blender 路径追踪，留出 1/8（88 训练 / 12 测试）；Ours 32.25 dB、F1@2mm 61.2，Gaussian Haircut 29.56 dB、46.9。', '消融（三数据集平均，PSNR / 平均连通分量大小）：完整 33.54/3.50；去中点分裂 33.13/3.26；去段克隆 32.54/4.00；去折线合并 33.59/1.00；去吸引损失 33.57/2.77。', '速度：在 RTX 4090 上于三个数据集均与 3DGS-MCMC 帧率相当。']

- **要解决的问题**：人形机器人要在人类环境中协调移动与操作，从人类演示学习需要「全身运动 + 第一视角视觉」配对，尤其下肢与足部落点在第一视角常不可见。现有第一视角数据集要么缺高保真光学动捕，要么对移动-操作行为覆盖不系统。而仅用头手稀疏跟踪或头戴相机推断全身存在根本歧义：相似头部轨迹可对应完全不同的步态，头部朝向也不等于身体朝向或行进方向，在转向、侧行/后退、动态姿态转换与搬运时尤其严重。缺少带度量真值的基准，就无法量化这些方法的真实差距。
- **方法详解**：采集系统：RoboCap 头戴平台（6 路硬件同步全局快门 RGB，1920×1080@30 Hz，含前视/下视鱼眼立体对 + 两路侧向广角；2 路 IMU 200 Hz + 磁力计 100 Hz），双腕 RoboWrist（广角 RGB + IMU + 磁力计），1 路第三人称相机，NOKOV 光学动捕（53 反光标记、120 Hz），头显上 4 个标记构成 Tracker0 做 6-DoF 头部位姿与时空配准基准；物体用 iPhone LiDAR 扫描 + 4 标记做 120 Hz 6-DoF 跟踪；另有麦克风。场地为 7×7 m 动捕棚，支持直线、转向、圆形、8 字、往返等连续运动。标注管线：30 fps 视频与 120 Hz 动捕时间对齐，局部手部姿态估计与腕部跟踪位姿融合，身体关节与刚体位姿由动捕重建，输出 SMPL-X 与标定相机观测。分类法为 8 类 291 个协议（移动原语 44、姿态动力学 60、移动-操作 86、静态操作 44、长时组合 11、动态恢复 15、人人协作 14、环境耦合全身 17）。
- **实验与结果**：['规模与质量：200+ 小时、14 人（中位 13.67 h，范围 9.79–21.95 h，最大贡献者占 11.4%），会话中位 127 s；动捕有效率 99.81% 骨架帧、99.74% 标记可见率，SMPL-X 拟合中位标记重投影误差 4.78 mm；移动原语+姿态动力学+移动-操作合计 161 h（≈80.6%）。', '第一视角全身重建（Table 3，均用官方预训练权重不微调）：EgoAllo 最低 MPJPE 80.8 mm、MPJVE 14.5 cm/s、加速度误差 214.5 cm/s²、抖动 72.06 m/s³；AGRoL 最低 W-MPJPE 95.4 mm 与 WA-MPJPE 64.9 mm；EgoEgo 最差（MPJPE 130.9 mm、头部位置 138.2 mm）。', '足部接触与落点（Table 6）：EgoAllo 接触 F1 90.5%、Footprint 85.1 mm、Step 154.1 mm、滑移 54.8 mm/s、穿透 8.5 mm；EgoEgo/AGRoL 滑移达 291.1/273.7 mm/s；GT SMPL-X 参考 F1 93.6%、滑移 43.6 mm/s。', '人到 Unitree G1 重定向（543 个测试会话 ≈18 h）：OmniRetarget 匹配关键体 34.8 mm、足 49.5 mm、手/腕 29.3 mm，但测地误差 0.470 rad、成功率仅 53.6%；GMR 足部滑移 12.3%、自碰 10.7%、成功率 7.4%；PHC 成功率 79.6% 但穿透帧占 20.9%、最大穿透 37.1 cm。', '标注链路校验：Tracker0 提供头显 6-DoF 参考，四类传感器流时间对齐后再融合，手部局部估计与腕部位姿对齐后写入 SMPL-X 表示。']
- **创新点与贡献**：['首个把「第一视角多相机 + 120 Hz 光学全身动捕 + 物体 6-DoF + 双手」在移动-操作场景系统配对的大规模数据集（200+ h / 291 协议）。', '以移动为中心的动作分类法，覆盖转向、侧行/后退、窄道、坡道楼梯、搬运越障、扰动恢复等第一视角难以推断的行为。', '建立三个可复现基准（第一视角全身重建、足部接触与落点、人到人形重定向），暴露「局部姿态准 ≠ 全局运动对 ≠ 足部物理合理」的三重落差。']
- **局限与风险**：['数据在装备化动捕棚内采集，环境与地形多样性远低于真实世界。', '标记遮挡与人体模型拟合误差仍影响标注（虽标记可见率 99.74%，仍有残余）。', '参与者、物体与交互场景数量有限，不能代表人类运动全分布。', '人与人形在形态、运动学与能力上差异大，动作无法直接迁移，需重定向与控制适配；下游真机执行效用未验证。']
- **与文献库的关系**：相对传统动捕数据集与以头手跟踪为主的第一视角人体数据集，本文补上「高保真全身 + 下肢可见真值」；与 EgoEgo/EgoAllo/EgoPoser/AGRoL 是提供评测基准的关系，与 GMR/PHC/OmniRetarget 是被评测对象。定位类似「第一视角版 AMASS + 人形学习试验台」，与 RoboCap/RoboWrist 硬件线同源。
- **可复现性**：项目页 https://bitrobot-foundation.github.io/robomocap/ ；数据集发布于 Hugging Face（genrobot2025/Gen-HumanWholeBody），硬件 RoboCap/RoboWrist 可购（shop.bitrobot.ai）。
