### 第 1 章 · World from Motion：单目视频生成式动态高斯重建（2607.01202，4.27 A，FULL）

- **赛道 / 场合**：神经渲染 / arXiv preprint（Stanford University + NVIDIA，v2 2026-10-23）
- **公告类型**：replace-cross（2026-07 投稿，2026-10 v2 再公告）
- **一句话结论**：用视频模型以「稠密像素对齐的动态 3DGS 渲染（外观/几何/沿输入与目标轨迹的运动）」为条件生成新视角，修正渲染伪影并补全缺失区域，再把生成蒸馏回单一一致动态 3DGS；DyCheck mPSNR（pose-opt covisible）20.38 超 WorldTree 19.75 / Shape-of-Motion 17.32，宣称 4D 重建新 SOTA。
- **要解决的问题**：单目视频动态 4D 重建的观测不完整（遮挡/未观测区域/运动）导致渲染伪影与场景运动估计错误。
- **方法详解**：动态 3DGS 条件化的目标视频生成（VACE 上下文嵌入 96 通道替换为吃 80 通道 buffer 的 3D 卷积）；生成结果蒸馏回 3DGS 再优化；150K 多视角视频对训练数据（SoM/WorldTree 重建合成，73 帧 512×384）；32×NVIDIA GB200 训练约 48 小时。
- **实验与结果**：DyCheck（静态相机 + per-frame pose 优化双协议，Full/Valid/Covisible 三区域）、NVIDIA-LS、MultiCamVideo 留出集、in-the-wild 定性；对比 Shape of Motion/MoSca/WorldTree/CAT4D/ViDAR/ReCamMaster/Vista4D；虚拟相机数消融（0/1/2/4/8/16，mPSNR 18.69→19.78）。
- **创新点与贡献**：① 生成模型与显式动态 3DGS 互为「条件-蒸馏」闭环；② 以初始重建的渲染（而非原始帧）作为视频模型条件；③ 大规模合成训练数据构建管线。
- **局限与风险**：训练成本极高（32×GB200×48h）；DyCheck 静态相机协议增益温和（PSNR 17.57 vs WT 17.08）；in-the-wild 主要为定性；依赖初始重建质量。
- **与文献库的关系**：与库内 ProDyGS（2609.32711，单目动态 3DGS）构成「生成式 vs 确定性」两条 4D 路线；蒸馏回显式表示与库内视频蒸馏线一致（门① max Jaccard 0.067）。
- **可复现性**：NVIDIA 项目页（research.nvidia.gov/labs/amri）；模型/数据释放摘要级未明示。
- **行动建议**：单目 4D 重建首选对比基线；关注其「生成-蒸馏」闭环的轻量化可能。

### 第 2 章 · RGS-SLAM：重思高斯 SLAM 致密化——静止采样视角（2601.00705，3.92 A，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（v2）
- **公告类型**：replace（2026-01 投稿，v2 再公告）
- **一句话结论**：用免训练 correspondence-to-Gaussian 一次性三角化初始化（DINOv3 描述子 + 置信度感知内点分类）替代残差驱动致密化，把「精化」与「容量增长」解耦：收敛加速约 20%，Replica ATE 0.61cm，建图 925 FPS。
- **要解决的问题**：GS-SLAM 残差驱动致密化耦合精化与表示增长——精度在中等基数饱和但内存沿轨迹持续增长、吞吐退化。
- **方法详解**：覆盖触发的高斯初始化 + 有界拓扑优化（stationary sampling 表述）；DINOv3 密集匹配 + 置信度内点分类生成结构感知种子；共视关键帧调度；联合建图与光度精化（每帧 30–60 梯度步）。
- **实验与结果**：TUM RGB-D + Replica：ATE 0.61cm（Replica r0–r2/o0–o4）、1.02cm（TUM fr1/desk、fr2/xyz、fr3/office）；925 FPS 超 MonoGS 769 FPS；较 SNI-SLAM 精度 +20.9%、完整度 +13.x%；较 Vox-Fusion 完整度误差 -42%；预算 200→1000 点跟踪误差陡降后于 2000 点附近平台化（约 0.6cm）。
- **创新点与贡献**：① 致密化范式从「残差驱动增长」转向「静止采样/覆盖触发」；② 一次性三角化种子稳定早期建图与收敛。
- **局限与风险**：依赖 DINOv3 描述子质量与匹配阈值 τ=5cm；室内 RGB-D 基准为主；无大规模室外验证。
- **与文献库的关系**：库内 GS-SLAM 家族（MonoGS/Cube-Splat 2609.21347 等）的致密化改进线；与「组合基元」线（SCION）构成不同优化范式。
- **可复现性**：含 Reproducibility and Code Release 章节（代码释放声明）。
- **行动建议**：实时 XR SLAM 系统可复测其「初始化+致密化解耦」；关注 DINOv3 匹配的失效场景。

### 第 3 章 · Vorch-Streamer：实时长时文本到音视频流式化身生成（2608.05663，3.85 A，FULL）

- **赛道 / 场合**：化身与人体 / arXiv preprint（v2）
- **公告类型**：replace（2026-08 投稿，v2 再公告）
- **一句话结论**：后训练框架把双向音视频模型改造为因果实时流式生成：混合 Teacher Forcing + Diffusion Forcing 训练因果生成器 + 长程 Self Forcing（DMD 蒸馏）+ LLM 25Hz 言语规划 token；27.12 FPS 实时、WER 7.92%（基线外推法 94–98%）。
- **要解决的问题**：实时长程化身音视频生成的两个两难——自回归复用生成块导致暴露偏差/误差与视觉漂移累积；全局语音文本无法指示因果生成器「下一段该说什么」。
- **方法详解**：80K 合成化身片段（12–21s，768×512@24FPS）；混合 TF+DF 训练；长程 Self Forcing + DMD 蒸馏保持教师质量；外部 LM 预测离散 25Hz（40ms 规划单元）言语规划 token 条件化音频扩散分支；四步去噪。
- **实验与结果**：对比 JoyAI-Echo/OmniForcing/Hallo-Live/LTX2：WER 7.92% 接近离线 LTX2；消融显示全程文本条件化 WER 184% → 短文本段 62.77% → 规划 token 7.92%；27.12 FPS、较 JoyAI-Echo 快 14.8×；长程身份保持与 Drift 分析。
- **创新点与贡献**：① 言语规划 token 显式控制语音进程；② 长程 Self Forcing 解决暴露偏差；③ 免参考首帧/免外部音频的纯文本驱动。
- **局限与风险**：合成数据训练（sim-to-real 差距未充分量化）；长程身份保持仍有 Drift；实时但非高保真路线；未给 VR 集成延迟数据。
- **与文献库的关系**：与库内 PixReenact（2610.05233，像素条件因果视频扩散流式）构成流式化身两条路线；补强实时化身生成（门① max Jaccard 0.038）。
- **可复现性**：摘要级未明示代码；训练细节附录齐全。
- **行动建议**：实时社交化身/虚拟主播可复测其规划 token 机制；关注 sim-to-real 迁移。

### 第 4 章 · LENS：边缘 FPGA 场景记忆——机器人定位与神经泼溅加速（2610.25068，3.65 A，FULL）

- **赛道 / 场合**：系统与平台 / arXiv preprint（v2）
- **公告类型**：replace-cross（2026-10 投稿，v2 再公告）
- **一句话结论**：AMD KR260 上的边缘场景记忆系统：INT16 场景坐标回归（SCR）加速器保持 DSAC* 定位精度（板载 25.42ms）+ 位精确定点有序 3DGS 渲染器（alpha 透射率 log-sum-exp 重写）；Cambridge 34.11dB（vs ACEsplat 33.20）、RE10K 27.84dB（vs 26.11）；每瓦性能超 Jetson Orin NX 1.9–5.7×。
- **要解决的问题**：资源受限机器人/自动驾驶需要无桌面 GPU 的场景记忆（定位+邻近视角渲染）；ACEsplat 类管线 GPU-centric——SCR 位姿敏感 + 3DGS 渲染不规则/容量敏感，难迁边缘 FPGA。
- **方法详解**：INT16 SCR 加速器 + 定点有序 3DGS 渲染器（重写 alpha 透射率为 log-sum-exp 递推、去除可证明无用的流式高斯）；全部延迟/功耗/质量指标板级实测。
- **实验与结果**：Cambridge、RealEstate10K、ShopFacade（25 次运行渲染均值 32.02ms）、十个 Wayspots；对比 ACEsplat 与 Jetson Orin NX（33ms）；片上训练达 ACEsplat 质量但时间/能量不及 GPU。
- **创新点与贡献**：① 定点有序渲染的 alpha 透射率 log-sum-exp 重写；② 位精确 INT16 SCR；③ 系统级 perf/W 全面板实测。
- **局限与风险**：面向机器人/自动驾驶（非 XR 头显）；片上训练仍是边界；单一 FPGA 平台。
- **与文献库的关系**：补强库内系统与平台/边缘渲染方向；与 XR 一体机渲染管线技术同源（3DGS 边缘化）（门① max Jaccard 0.037）。
- **可复现性**：摘要级未明示代码；板级数据完整。
- **行动建议**：XR 一体机/机器人 3DGS 边缘部署可评估其定点渲染方案；注意目标平台差异。

### 第 6 章 · STATIC：表面法线引导的双分支对齐与时序集成（视频单目深度一致性）（2412.01090，3.15 B，FULL）

- **赛道 / 场合**：感知与认知 / arXiv preprint（Yonsei University，v2 2025-11）
- **公告类型**：replace（2024-12 投稿，2025-11 v2 再公告）
- **一句话结论**：两帧输入 + 表面法线相似度模块（SNS）+ 掩码静态模块（MS）实现视频单目深度时序一致性：相对时序一致性（rTC）较此前最佳 +1.76%，RMSE 较 MAMo 改善约 0.60% 且仅用两帧（MAMo 用更多帧）。
- **要解决的问题**：单图 MDE 模型跨帧深度不一致；传统时序模块内存高、动态/不规则运动下退化。
- **方法详解**：差异掩码（静态/动态分离）+ 表面法线相似度跨帧对齐 + 掩码静态模块；KITTI/NYUv2/MPI-Sintel 训练评估（20 epochs，lr 4e-5 线性衰减）。
- **实验与结果**：KITTI、NYUv2（464 室内环境）、MPI-Sintel；rTC +1.76%；消融：去 MS 模块 RMSE -1.57%、去 SNS 模块 -0.61%。
- **创新点与贡献**：表面法线作为跨帧对齐的几何先验 + 差异掩码驱动的动静分离。
- **局限与风险**：增益幅度温和；两帧输入限制长程一致性；AR/VR 仅为列举应用之一（主战场自动驾驶）。
- **与文献库的关系**：补强库内视频深度/时序一致性薄处；与 3DGS/场景流方向互补（门① max Jaccard 0.042）。
- **可复现性**：实现细节附录齐全；代码释放摘要级未明示。
- **行动建议**：XR 场景深度流管线可评估其两帧轻量方案；注意其主战场为自动驾驶。

### 第 7 章 · 自由手牙科操作的双边触觉遥操作系统（2503.21288，3.15 B，FULL）

- **局限与风险**：临床前验证（bench+演示），无患者试验；牙科单一场景；量化指标单一（力降幅）。
- **与文献库的关系**：补强库内触觉遥操作医疗应用空白；与数据采集向触觉工作（ModPack 等）构成「操作执行 vs 数据采集」互补。
- **可复现性**：控制器参数化附录；硬件非开源。
- **行动建议**：遥操作医疗器械设计参考其「自由手力限制」策略；触觉保真度需主观测评补核。

### 第 8 章 · OccamView：对象条件化的帧预算主动 3DGS 重建视角选择（2608.16499，3.00 B，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（Harbin Institute of Technology / University of Sydney，v2）
- **公告类型**：replace-cross（2026-08 投稿，v2 再公告）
- **一句话结论**：用开放词汇检测维护在线对象记忆、以保守隐藏区域代理表示对象周边未解析占用，遮挡感知代理覆盖打分选视角；Geo-Floor 机制把对象重排序限制于几何竞争力候选；Replica/Matterport3D 五档帧预算下 Completion 与 Completion Ratio 一致改善（f40 时 Completion 28.52→16.x cm）。
- **要解决的问题**：几何信息增益驱动的主动 3DGS 把对象隐藏区与一般未探索区同等对待，紧帧预算下全局覆盖优先导致对象重建不完整。
- **方法详解**：对象记忆 + 隐藏区域代理 + 遮挡感知代理覆盖打分 + Geo-Floor 门控重排序（保留几何驱动探索行为）。
