### 第 1 章 HoloSplat：面向前馈人体重建的实时 token 流式传输（2611.31140 · 化身与人体 · 4.21 A）

**一句话结论**：把码率控制点从 Gaussian 属性前移到 Gaussian head 之前的 token 空间，并用零膨胀逆自回归熵编码：4×RTX 5090 上 32.2 FPS @ 50 Mbit/s，笔记本 3050 Ti 解码单帧 22.1 ms，Pro 档 208.2 kB/帧仅为未压缩 float32 的 1/22.8，是首个把「自由视点人体流式」三级 33 ms 预算全部跑满的端到端系统。

**要解决的问题**

人体自由视点视频直播要求每帧实时重建、在严格带宽内传输、并在轻量客户端 GPU 上解码。现有逐帧优化或前馈推理方法都会产生海量 3D Gaussian 载荷，远超实际流式带宽；激进压缩又会严重损害渲染质量。三级流水线各自有 33 ms（30 FPS）预算：服务器重建、100 Mbit/s 级下行、客户端解码为可渲染高斯。

**方法详解**

HoloSplat 在冻结前馈重建器（PointSplat）的 Gaussian head 之前切分网络，做多码率 token 流式编解码。服务器端：先用轻量 predictor $g_\phi$ 回归 16 个 slot 的 opacity logits，按 $q_i=\max_k\sigma(g_\phi(f_i)_k)\ge\delta$（$\delta=0.075$）做 opacity-guided token pruning；再对首帧 token 拟合会话级 PCA，$c_i=U_r^{\top}(f_i-\mu)$、$\hat{f}_i=\mu+U_r\hat{c}_i$，每帧传每维一个 range 并在其中均匀量化到 $b$ bit，按 component-major 顺序 Zstd 压缩，Lite/Pro/Ultra 分别为 $(r,b)=(32,4),(48,6),(80,6)$；anchor 坐标走无损体素编码（坐标表 + 3×3×3 occupancy 32-bit mask + slot index）。客户端：把逆 PCA 解析地折进 head 首层线性映射 $y=(WU_r)\hat{c}+(W\mu+b_0)$，避免显式展开 1024 维；再用残差 hypernetwork $\tilde{f}_i=\hat{f}_i+H_\theta(\hat{f}_i,X_i-\bar{X}_i,\frac18\sum_{j\in\mathcal{N}_i}\hat{f}_j;r,b)$ 恢复被丢弃分量，$H_\theta$ 直接以 $\|W(f_i-\tilde{f}_i)\|_2^2$ 对未压缩 token 训练，无需渲染，且用 tier embedding 生成 FiLM 参数使一个网络服务所有码率。Neural Session Calibration 在 warm-up 的 30 帧上用输入视角自监督微调 head，损失 $0.8\ell_1+0.2(1-\mathrm{SSIM})+0.1\mathrm{LPIPS}$，更新参数化为三层 per-slot MLP 的 rank-5 增量 $\Delta W_\ell=A_\ell B_\ell$（仅 20,480 个 FP16 参数），一次性下发，零每帧开销。帧间独立编码，服务器按帧并行、CUDA MPS 多 worker、reorder buffer 按采集序发包，支持随机接入与无误差传播。

**实验与结果**

- 4 张 RTX 5090 上平均 32.2 FPS @ 50 Mbit/s；1/6 张时分别为 8.0 / 51.3 FPS
- RTX 3050 Ti 笔记本 GPU 上每帧解码为 3D Gaussians 仅 22.1 ms
- Pro 码率 208.2 kB/帧 vs 未压缩 float32 4,753.1 kB/帧，数据量少 22.8×
- Pro PSNR 27.219 dB vs PointSplat512 26.169 dB；Lite 94.8 kB 仍有 26.840 dB
- 校准解码（hypernetwork + NSC）使 Pro 提升 1.050 dB；hypernetwork 单独恢复 80.4% 压缩损失（+0.483 dB）
- NSC 在 HiFi4G / ActorsHQ 上额外 +1.419 / +1.436 dB；12 参数颜色仿射仅 +0.076 / +0.119 dB
- opacity-guided pruning 去掉 23.6% token 组而不损 PSNR，Ultra 包减小 23.5%
- 最小 Gaussian 格式 Draco 需 723.0 kB/帧，是 Pro 的 3.47×；CodecSplat 最高 23.1 dB 且解码 199 ms

**创新点与贡献**

- 把码率控制点前移到 Gaussian head 之前的 token 空间：token 是低维、紧支撑的中间表示，对量化扰动远不如指数尺度的 Gaussian 属性敏感，因此同码率下质量显著更高
- 用「逆 PCA 折进首层 + 残差 hypernetwork 折进输出层」实现恢复过程零显式 token 展开，使客户端解码落在 22.1 ms
- NSC 只用 warm-up 一秒的输入视角、以 rank-5 低秩增量在线校准 head，解决新相机参数与采集条件漂移，且不增加每帧开销

**局限与风险**

- 作者承认：帧间不跟踪 Gaussian 身份，以放弃时序对应换取无栅栏并行、逐帧随机接入与零误差传播
- 会话建立需在四卡上 24 s 才能上线
- 从正文看，方法绑定单一前馈重建器（PointSplat）与固定 8 视角 rig，换 rig 需重新 warm-up 校准
- 在极低码率（低于一视图 token 量）质量快速下降而渲染时间几乎不降，因为每个 target token 仍要过完整 decoder
- 对带宽远低于 50 Mbit/s 的场景未给可用工作点

### 第 2 章 S-Mind：将多视图几何内化到空间智能（2611.28649 · 空间计算与UI · 4.07 A）

**一句话结论**：不新训空间 VLM，而是给模型一段可被注意力读写的场景 token 并冻结读出器解耦「感知」与「变换」：Qwen3.5-9B 四基准平均 74.03%（比最强微调基线高 6.76），跨视图点恢复率由基线最高 16.02% 提到 65.11%。

**要解决的问题**

MLLM 要在物理世界推理，必须把多视图融成一致三维场景，并随推理切换到新视角。作者用几何探针与视角探针发现：即使经过空间微调，模型仍只把各视图独立编码，跨视图 3D 点恢复率最高仅 16.02%，换视角后定位精度最高仅 37.28%，接近随机。外部几何方案（重建+渲染、挂接几何编码器）虽给显式几何，却未把能力内化且推理延迟高；空间微调方案又把场景变量混在全部 token 中，缺少专门承载「已定且可观测」交互的表示。

**方法详解**

在图像 token 之后追加 $K_sN+K_c$ 个空间 token（每视图 $K_s$ 个场景 token + 全视图共享 $K_c$ 个相机 token），其隐状态即融合场景 $\mathbf{z}_0\in\mathbb{R}^{(K_sN+K_c)\times d}$。用一个跨层加权的交叉注意力读出器 $\mathcal{R}_\phi$ 从 $\mathbf{z}_0$ 解码每个视觉 token 的全局/局部 3D 点与每台相机位姿，查询只带网格位置、不带图像内容，因此只能读取 $\mathbf{z}_0$ 已持有的几何；几何预训练损失 $\mathcal{L}_{geo}=\mathcal{L}_{global}+\mathcal{L}_{local}+\mathcal{L}_{cam}$，点用带置信度的 Huber 项，位姿用 Huber。视角变换阶段：推理链声明新视角 $v_k$ 时模型重新发射空间 token 得到 $\mathbf{z}_k$，冻结读出器从 $\mathbf{z}_k$ 解码点并回归到 $\mathbf{z}_0$ 的点经刚体变换 $\hat{\mathbf{T}}_{v_k}^{-1}$ 后的位置，$\mathcal{L}_{view}$ 对 $\mathbf{z}_0$ 一侧做 stop-gradient，从而只监督「如何变换」而不重复监督「场景是什么」。SFT 目标 $\mathcal{L}_{SFT}=\mathcal{L}_{CE}+\lambda(\mathcal{L}_{geo}+\mathcal{L}_{view})$，随后用 GRPO 以最终答案正确率做奖励；全程 LoRA，$K_s=2$、$K_c=4$、$\lambda=0.1$。

**实验与结果**

- Qwen3.5-9B 上四基准平均 74.03%，比最强微调基线高 6.76 分、比最佳开源空间推理模型高 11.76 分；4B 上 72.83%
- 相对 Qwen3.5 骨干最高提升 22.26 分；平均分超过 GPT-6-Astra（73.58%）、Kimi-K3.1-Pro（72.06%）
- 多视图融合探针：跨视图点恢复率 65.11% vs 基线最高 16.02%；单视图点 86.32% vs 60.62%
- 视角变换探针：82.17% vs 基线最高 37.28%；背后/左侧/右侧方向分别 77.38%/69.51%/85.29%，基线最高仅 10.29%/9.78%/40.69%
- 同一骨干上比工具式智能体 SpatialClaw 快 81×（MindCube-Tiny，精度高 31.05 分）与 115×（ViewSpatial，高 9.17 分）
- 推理时扣留全部空间 token 仅掉 2.37 分（72.83→70.46），仍比最强基线高 5.28 分

**创新点与贡献**

- 不是再训一个空间 VLM，而是给模型一段可被注意力读写的「场景 token」：$\mathbf{z}_0$ 承载融合场景，$\mathbf{z}_k$ 在每次声明视角时重表达，并用冻结读出器把「感知」与「变换」解耦监督

**局限与风险**

### 第 3 章 ViDiHand2：统一视频扩散先验与手部几何的野外 3D 手部运动重建（2611.30597 · 化身与人体 · 4.07 A）

**方法详解**

### 第 5 章 走得更远、看得更少：具有持久目标与选择性视图的主动多房间重建（2611.30802 · 重建与SLAM · 4.00 A）

**一句话结论**：把稀疏主动重建的决策对象从「单个 next-best-view」改为「持久目标 + 变长路径前缀」，让走廊通行折算为远端房间价值：HSSD Cov10 74.1%→93.3%，HM3D 47.2%→95.6% 且 PSNR +11.7 dB，training-free 可在 Habitat 在线闭环。

**要解决的问题**

主动 3D 重建需要在稀疏视图预算下恢复完整几何与高保真渲染，但现有方法在多房间住宅中急剧退化。稀疏视图规划器采用逐步 next-best-view 打分，走廊通行对远端房间的价值得不到任何 credit，且每步重规划，导致智能体反复打磨已重建的客厅而不去下一个房间。同时残差幅值高估了新视图能修复的内容，光滑或细节表面在优化停止后仍保持高渲染误差，使近处缺陷被过度追求、远处房间过早放弃。稠密建图方法虽能到达远房间，却需要流式传输数千帧。

**方法详解**

提出 ROAM-GS，一个 training-free 的主动多房间重建框架，把「去哪里」与「在哪里拍摄」解耦：每次决策选择一个 goal $g=(r_g,q_g)$（目标区域加观测视点）和通往它的变长路径前缀 $\pi$，智能体无感知地走完前缀，只在端点拍摄一次。核心是一个 3D Surface Reconstruction Memory $\mathcal{M}_t$，把每次拍摄反投影的深度点索引到表面 cell，每个 cell 记录已观测方向集合 $\mathcal{D}_s$ 以及更新后颜色残差与低不透明度指标的滑动平均；查询位姿只需几何投影即可得到 defect gain $a_s^{def}=w_s(q)\chi_s$ 与 angular gain $a_s^{ang}=w_s(q)\kappa(\theta_s(q))n_s$，无需 Gaussian 渲染。目标选择与路径前缀在统一打分 $S(\pi,g)=B(\pi,g)+V(\pi,g)$ 下联合优化，$B$ 奖励前缀自身可见内容，$V$ 奖励终点相对前缀的额外收益。Persistent goals 让被选目标跨决策保持 active，通行前缀继承其剩余价值，只有到达后测量到目标区域确实改善才释放。Selective views 用 variable-horizon prefix 在长走廊与局部巡检之间自适应。整个流程无离线策略训练、无逐场景调参。

**实验与结果**

- HSSD 平均 Cov10 由最强基线 ActiveGS 的 74.1% 提升到 93.3%，PSNR 提升 3.1 dB
- HM3D 平均 Cov10 由 47.2% 提升到 95.6%，PSNR 提升 11.7 dB，Chamfer distance 下降 26.9×
- 500 视图预算下 HSSD Large 组 Cov10 74.1%（33 房间住宅），所有基线均低于 20%
- HM3D Large 组覆盖 90.5%（15 房间住宅）
- 5 房间 HM3D：10 分钟达 83.75% Cov10；20 分钟 98.25% vs 90 分钟 TRACE 93.9%，PSNR 28.16 vs 27.3 dB
- 相对 90 分钟稠密建图 TRACE 使用 165× 更少图像、45× 更少 mapped frames（摘要口径 173×）
- Replica 200 帧预算：PSNR 36.75 dB、Cov10 99.94%、CM 2.076 cm，较 ActiveGS 高 0.43 dB / 0.34 点

**创新点与贡献**

- 把稀疏主动重建的决策对象从「单个 next-best-view」改为「目标 + 变长路径前缀」，用持久目标把走廊通行折算为远端房间的剩余价值，从而跳出局部贪心陷阱
- 用表面 cell 上记录的更新后缺陷与观测方向做免渲染的端点/路径/目标统一打分，使长距离 transit 也能在拍摄前被评估
- 并用到达后的可测改善作为目标释放条件，直接针对不可约残差

**局限与风险**

### 第 6 章 高斯泼溅中的互补几何（2611.29236 · 神经渲染 · 3.93 A）

**一句话结论**：把「新视角几何改进」重述为对冻结表示的选择性纠正：不重训、不需目标视角观测，只用跨视角误差互补性 + 期望绝对误差下降准则做准入，DTU AbsRel 0.0440→0.0180，动态骨干最高降 63.9%。

**要解决的问题**

高斯泼溅在新视角合成上视觉质量很高，但渲染深度的准确性存疑：深度由沿射线的原语深度按不透明度加权平均得到，当原语在深度上分散或半透明时，该值未必对应真实场景表面。因此模型可以在深度与空间关系上出错，却仍渲染出视觉可信的图像，限制其在机器人操作、空间推理等需要准确几何的场景中的使用。更关键的是，深度误差并非只由新视角外推造成——在 12 个已拟合相机上，深度误差与留出视角几乎一样差，说明问题出在深度读出方式本身。而直接用其他视角的深度做融合通常会引入额外错误，因为互补预测并不总是更准。

**方法详解**

冻结骨干，只精化渲染出的深度与颜色。候选构造：把每个源相机 $c\in\mathcal{O}$ 的深度估计（Reveal(Self-Depth) 用冻结骨干自身在其源视角渲染，共享坐标系与深度尺度；Reveal(DA3) 用冻结的 Depth Anything 3，并按已知相机中心恢复度量尺度）反投影为 3D 后用已知标定重投影到目标视角，硬 z-buffer 保留最近点，得配准深度 $D_c(u)$ 与颜色 $I_c(u)$。两趟中值做鲁棒共识：第一趟中值作为参考，剔除相对偏差超 $\tau_D$ 的估计；第二趟对 inlier 集 $\mathcal{V}(u)$ 取中值，得 $D_C(u)=\mathrm{median}_{c\in\mathcal{V}(u)}D_c(u)$，同法得 $I_C$。期望增益准入：定义替换带来的绝对误差降低 $\Delta(u)=|D_B(u)-D^\star(u)|-|D_C(u)-D^\star(u)|$，在 $L_1$ 目标下当 $\mathbb{E}[\Delta\mid\phi]>0$ 时替换才降期望误差；训练用代价加权 BCE $\mathcal{L}(p)=-\mathbb{E}[\Delta_+\log p+\Delta_-\log(1-p)\mid\phi]$，其总体最优 $p^\star=\mathbb{E}[\Delta_+]/ (\mathbb{E}[\Delta_+]+\mathbb{E}[\Delta_-])$，故 $p^\star>1/2$ 恰好等价于 $\mathbb{E}[\Delta\mid\phi]>0$，即零 logit 阈值与期望增益判据对齐。准入头输入 18 个逐像素通道（骨干深度与局部结构、候选深度及与骨干的差异与共识可靠性、深度一致指示、图像位置与距上次观测的帧数、两假设的表面朝向与跨视角光度一致性），用小 transformer + 局部窗口注意力在全分辨率输出 logit，是 Reveal 中唯一可训练部件（81K 参数）。选择性替换后对 $\log D_H-\log D_B$ 在修正像素邻域内、只用骨干深度一致（且候选一致）的邻居做平滑以消接缝；颜色用有界残差 $\hat{I}(u)=I_B(u)+\alpha(u)(I_C(u)-I_B(u))$，$\alpha$ 有上限且仅在深度一致、光度一致与最小支撑满足时非零。

**实验与结果**

- DTU（2 源视角，官方跨数据集协议）：MVSplat AbsRel 0.0440→0.0180（DA3）/0.0418（Self）；TranSplat 0.0341→0.0171；MonoSplat 0.0273→0.0170；平均降 4.1%
- RIG（95 留出 take，2,280 目标视角/骨干）：三个静态骨干平均 AbsRel 降 10.2%（Self）/53.4%（DA3），分别覆盖 98.8%/99.5% 的目标

**创新点与贡献**

- 把「新视角几何改进」重新表述为选择性纠正而非重建：不修改高斯表示、不重训骨干、不需要目标视角观测，只利用同一冻结表示在不同视角下的误差互补性构造候选

### 第 7 章 VeriTouch：可验证的视触觉世界模型及其对机器人策略学习的提升（2611.30572 · 触觉与多模态 · 3.93 A）

**一句话结论**：把触觉作为独立专家接入预训练视频 MoT 并用「触觉真实性 + 接触力合理性 + 视触时间对齐」联合验证器过滤 rollout：五个真实任务四种策略平均成功率 19.4%→33.8%，Bo3 30.8%→48.8%，去掉验证器即回落到与仅真实数据持平。

**方法详解**

### 第 8 章 作为保局部性锚点的 token：面向目标自适应 token 路由的可扩展新视图合成（2611.31156 · 神经渲染 · 3.93 A）

**一句话结论**：把光栅化的「只处理可见图元」迁移到无显式几何的 transformer 渲染器：router 在解码前预测目标视角会用到的 source token，24 源视图下比 LagerNVS 快 6.4× 而 PSNR 仅低 0.68 dB，固定预算下 82–87 FPS 与源视图数近乎脱钩。

**要解决的问题**

基于 transformer 的视图合成模型不依赖显式 3D 表示，能复现细节与视角相关效应，但 decoder 对每个目标视角都要 attend 全部 source token，渲染随源视图数线性变慢。光栅化通过剔除视角不可见图元避免这一点，而 source token 没有显式位置与范围，无法直接做视锥/遮挡剔除。另一难点是冗余：场景同一部分被多个源视图编码，按 attention 质量排序会把预算重复花在同一表面。现有压缩方案（固定 token 数）会牺牲精度。

**方法详解**

作者观察到 source token 是保局部性的空间锚点：每个 token 编码场景局部区域，decoder 对任一视角的 attention 只集中在少数 token 上（DL3DV 140 场景、24 源视图下，两视图量的 token 收到 85% attention，且随视角变化）。据此训练轻量 router，从 source token 与目标视角预测哪些 token 会被用到，decoder 只 attend 固定预算 $B\ll N$ 的 top-ranked token，渲染代价变为 $\mathcal{C}_{routed}=F+cB+c_sN$。router 分两支：scene branch 每场景跑一次，用四对 transformer block（视图内 + 跨视图，类似 VGGT 的 frame/global attention）为每个 token 产生 256 维 key $\mathbf{k}_i$ 并缓存；target branch 是三层 MLP，把 $3\times4$ camera-to-world 映射为 query $\mathbf{q}(g)$，score head 计算 $s_i(g)=h([\mathbf{k}_i;\mathbf{q}(g);\mathbf{k}_i\odot\mathbf{q}(g)])$。监督来自冻结 decoder 的 cross-attention：对每个 source token 算 attention mass $a_i=\sum_p A_{pi}$ 与 profile $\boldsymbol{\pi}_i=A_{:,i}/\|A_{:,i}\|_2$，用 Soft-NMS 式贪心选择 $\gamma_i(\mathcal{S})=a_i(1-\max_{j\in\mathcal{S}}\langle\boldsymbol{\pi}_i,\boldsymbol{\pi}_j\rangle)$，把选中时的 gain 作为回归目标 $y_i=\log(\bar{\gamma}_i+\bar{\gamma}_{\min})$，损失为 $1-\mathrm{corr}(s_i,y_i)$ 加一个把 head 外 token 压到最低目标以下的 hinge 项（$\lambda=0.25$）。gain 沿排序单调不增，所以一个分数服务所有预算。decoder 侧用低秩更新适配稀疏 token 子集，训练时每步随机抽预算，全部 token 时关闭更新，模型精确退化为 LagerNVS。

**实验与结果**

- 24 源视图、两视图量 token：比 LagerNVS 快 6.4×，PSNR 仅低 0.68 dB
- 固定预算下 82–87 FPS（任意源视图数），LagerNVS 全 token 为 13–70 FPS（256×256，RTX PRO 5000）
- 4→24 视图：LagerNVS PSNR +5.7 dB 但慢 5.5×；本方法 +5.1 dB 而帧率仅降 6%
- 预算降到 1/4 只损失 0.28 dB，而 LagerNVS 减到 8 视图损失 2.89 dB
- 24 视图、一视图量 token（B=1369，占 4%）：几何代价选 token 落后 1.62 dB，无 NMS 落后 1.51 dB
- 无位姿 RE10K 2 视图：PSNR 27.27 vs NoPoSplat 25.03、SPFSplatV2 26.16，LagerNVS 全 token 27.61
- CO3D 9 视图 B=4107：26.18 dB vs LagerNVS 26.43；Mip-NeRF 360：20.40 vs 20.65

**创新点与贡献**

- 把光栅化的「只处理可见图元」迁移到无显式几何的 transformer 渲染：用 router 在 decoder 之前预测目标视角会用到哪些 source token，使每帧成本与源视图数近乎脱钩，且一次排序服务所有预算、可在渲染时甚至帧间切换
- 用 cross-attention profile 上的 NMS 解决「同一表面被多视图重复编码」导致的预算浪费，这是单纯按 attention mass 排序无法处理的
- router 的 scene branch 每场景只跑一次并缓存 key，使额外开销压到每帧 1 ms 以内

**局限与风险**

- 作者在 Discussion 中承认：低算力/低带宽硬件上仍不合适，预算低于一视图量时质量快速下降而渲染时间几乎不降，因为每个 target token 仍要过完整 decoder
- 只加速渲染，不加速源视图编码，流式场景下编码时间仍随视图数增长
- 采用剪枝而非合并，未利用把多视图融合成一致表示来减少候选
- 缺少处理分辨率/尺度的优雅机制，远距离大场景会 attend 大量对目标图像贡献不足一像素的 token
- 从正文看，方法绑定 LagerNVS 的 encoder/decoder 与 1369 token/视图的 patch 化，换骨干需重训 router 与低秩适配

### 第 9 章 VG3R：面向前馈三维重建的视频生成模型（2611.28520 · 重建与SLAM · 3.92 A）

**一句话结论**：视频 DiT 内部已编码深度与相机，只是形式不对——用片段级 shift 修正归一化逆深度、多层特征直接回归相机，把迭代去噪式重建压成单次前向：7-Scenes 精度误差 0.047→0.018（−61.7%），比 Aether 快 4×、比 Geo4D 快 14×，单帧 74–84 ms。

**要解决的问题**

视频生成模型已被用作三维先验，但用于重建时有两条路都不理想：视频深度估计只给尺度/偏移未知的深度，相机需另配位姿估计与对齐；而联合生成几何与相机的方法（Aether、Geo4D、Sora3R、Gen3R）依赖多步迭代去噪，推理慢。与此同时，前馈重建被 VGGT、π³、MapAnything、Depth Anything 3 等几何基础模型主导，它们把视频当独立图像集合、用图像骨干逐帧编码，跨帧结构一致性弱。作者要回答：能否把视频生成模型直接变成一次前向的「深度+相机」联合重建器。

**方法详解**

以 Wan2.1-T2V-1.3B 为骨干，冻结 VAE 与 DiT 预训练权重，仅用 LoRA 在固定 timestep 上把噪声-free 视频 latent 确定性地回归为深度 latent，沿用 DVD 的解码路径得到归一化逆深度 $\hat{x}\in[0,1]$。第一个模块 ClipShift 解决归一化抹掉偏移的问题：用注意力池化最后一层 DiT 在全部 latent 帧上的 token，经 MLP 预测一个正的片段级 shift $\hat{c}$，深度取 $\hat{D}_i=1/\max(\hat{x}_i+\hat{c},\tau)$，并以 $\mathcal{L}_c=|\ln((\hat{c}+\epsilon)/(c^*+\epsilon))|$ 监督，从而只保留一个全局尺度歧义。第二个模块 LayerTap 是多层相机头：把中间层与最后层 transformer 特征拼接，将每个 latent 帧与第 0 帧配对，经自注意力并迭代 K 次细化旋转、平移与视场角，输出相对相机 0 的位姿。训练目标由点图 $L_1$、片段级仿射解码损失 $\mathcal{L}_{dec}$（整段共用一次仿射拟合，暴露跨帧漂移）与多视图一致性损失 $\mathcal{L}_{mv}$（用 GT 深度/相机建立跨帧对应）组成。长视频按窗口滑窗推理，片段间用重叠区对齐。

**实验与结果**

- ScanNet 与 TUM-dynamics 上 ATE 相对 GeometryCrafter/Aether/Geo4D 中最好者分别降低 55.1% 与 56.3%
- 7-Scenes 重建精度误差由 GeometryCrafter 的 0.047 降到 0.018，降低 61.7%
- ScanNet 上比 Aether 快约 4×、比 Geo4D 快约 14×；单帧 74–84 ms（GH200，含深度与相机）
- 相对 VGGT，Sintel/Bonn/KITTI 视频深度 AbsRel 降低 14.2%–32.7%，TAE 降低 13.4%
- Sintel ATE 0.142、RPE-r 0.360°；TUM-dynamics ATE 0.031、RPE-r 0.457°
- Sintel 深度 AbsRel 0.254、δ1.25 0.699；Bonn AbsRel 0.037、δ1.25 0.979

**创新点与贡献**

- 关键洞察是视频 DiT 已在内部编码深度与相机运动，只是「形式不对」：用片段级 shift 修正归一化逆深度，用多层特征直接回归相机，从而把迭代去噪式重建压成单次前向
- 相比只做深度的 DVD/GenCeption，它联合输出深度与相机
- 相比 Aether/Geo4D，它不做迭代采样

**局限与风险**

- 深度只恢复到全局尺度，绝对度量依赖额外对齐
- 相机精度仍逊于部分几何基础模型（作者自述）
- ClipShift 假设整个片段共享一个 shift 与尺度，长视频必须切窗，跨窗一致性依赖对齐
- 训练需 11 个数据集与 128 GPU，复现成本高

### 第 10 章 通过拓扑感知蒸馏与渐进运动学推理的包容性手部姿态估计（2611.29163 · 化身与人体 · 3.92 A）

**一句话结论**：把「结构性缺失」当一等设定并给出可复现基准（按解剖规则在 3D 上删 MANO 段再渲染），方法上把拓扑先验拆成拓扑感知蒸馏与渐进运动学推理：IncNYU E_avg 8.00 vs 11.49，完整手 NYU MPJPE 7.07 不牺牲，并有 3 名真实截指者参与的用户研究。

**要解决的问题**

多数手部姿态估计方法隐含假设手部运动学结构完整，遇到持续性解剖缺失（部分手指或指节不存在）时会产生不稳定甚至不合理的预测，导致下游 MR 系统失效。现有基准几乎都由完整手采集，隐含强制完整运动学监督，模型因此偏向预测全套关节。已有的遮挡方法把缺失当作暂时或噪声，依赖时序平滑、空间上下文或特征幻觉，这些假设在「要素被永久移除、无有效观测可依」时不成立。此外，多数方法只在特征聚合阶段使用手部拓扑，没有在预测阶段显式沿解剖链约束，导致远端关节证据弱时推理不稳。

**方法详解**

教师–学生双流：ResNet-50 编码深度图，另由深度反投影点云分支提供几何线索，融合后进渐进推理。拓扑感知蒸馏以成对完整/缺失样本为输入，教师冻结：$\mathcal{L}_{\mathrm{distill}}=\mathcal{L}_{\mathrm{global}}+\alpha\mathcal{L}_{\mathrm{joint}}+\beta\mathcal{L}_{\mathrm{topo}}$，其中关系对齐项 $\mathcal{L}_{\mathrm{topo}}=\frac{1}{K^2}\sum_i\sum_j\|\Delta\mathbf{f}_c^{ij}-\Delta\mathbf{f}_i^{ij}\|_2^2$，可证明等价于中心化特征匹配 $2\mathcal{L}_{\mathrm{joint}}-2\|\bar{\mathbf{r}}\|_2^2$，即折扣掉所有关节共享的偏移、不含显式骨架边权。渐进运动学推理沿树形链从腕到指尖：根节点 $\hat{\mathbf{p}}_1=\mathbf{W}_1\mathbf{z}+\mathbf{b}_1$，其后 $\mathbf{u}_k=\mathrm{GLI}_{\ell_k}(\mathbf{h}^k,\mathbf{z})$（concat + 两层 MLP 融合局部与全局），$\hat{\mathbf{p}}_k=\mathcal{G}_{\ell_k}(\hat{\mathbf{p}}_{\pi(k)},\mathbf{u}_k)$，同层级 MLP 共享以反映解剖对称。监督用链式损失 $\mathcal{L}_{\mathrm{root\text{-}tip}}=\frac{1}{|\mathcal{C}|}\sum_c\frac{1}{|c|}\sum_{k\in c}\|\hat{\mathbf{p}}_k-\mathbf{p}^\star_k\|_2^2$，总目标 $\mathcal{L}=\mathcal{L}_{\mathrm{pose}}+\lambda_1\mathcal{L}_{\mathrm{distill}}+\lambda_2\mathcal{L}_{\mathrm{root\text{-}tip}}$（$\lambda_1{=}0.01$、$\lambda_2{=}0.05$、$\alpha{=}\beta{=}0.01$）。训练两阶段：先只用蒸馏损失预训学生编码器 50 epoch，再与融合/推理模块联合微调 100 epoch 且保留蒸馏。IncNYU 的构造是对 NYU 拟合 MANO、按解剖规则从远端到近端递归删顶点并更新面片，再用原相机参数渲染深度。

**实验与结果**

- IncNYU 重训：$E_{\mathrm{avg}}$ 8.00 vs HandDAGT 11.49（$E_{\mathrm{com}}$ −32.1%、$E_{\mathrm{inc}}$ −29.9%、$E_{\mathrm{avg}}$ −30.4%）
- NYU：MPJPE 7.07 vs HandDAGT 7.12、IPNet 7.17（不牺牲完整手精度）
- NYU→IncNYU 不重训：$E_{\mathrm{avg}}$ 17.44 vs HandDAGT 18.47（−5.58%），但 $E_{\mathrm{inc}}$ 33.40 仍高于 HandR2N2 的 26.36
- MSRA：5.52 vs HandDAGT 6.38（−13.5%）；MSRA→IncMSRA 不重训 6.23 vs 6.79（−8.2%）；IncMSRA 重训 5.77 vs HandDiff 5.89
- 效率（RTX 4090，3 stack）：108.01M 参数、23.47 GFLOPs、29.43 ms/帧，vs HandDAGT 45.47 ms；1 stack 已 10.67 误差 / 18.12 ms
- 核心模块消融：去 TAD 使 $E_{\mathrm{avg}}$ +20%（9.56），三者全去 +44%（11.49）；仅换 flat 预测头 8.18、cascaded 8.50
- 父节点条件控制（3 个配对种子）：$E_{\mathrm{inc}}$ 13.55±0.35 → 14.08±0.28，$E_{\mathrm{com}}$ 几乎不变
- 受控用户研究 18 人：手势识别 +13.3（完整）/ +11.6（模拟缺失）百分点；真实截指 3 人试点 44.0%→58.7%

**创新点与贡献**

- 把「结构性缺失」作为一等设定并给出可复现基准：不是 2D mask 遮挡增广，而是按解剖规则在 3D 上删 MANO 段再按原相机渲染，并保留被删关节的参考位置用于受控评测
- 方法上把拓扑先验拆成两段——特征层的成对蒸馏（并用中心化特征匹配的等价形式说明它约束的是关节间相对组织而非骨架边）与预测层沿链的父–子条件推理，使「弱远端证据」由更可靠的近端锚点约束

**局限与风险**

- 作者承认拓扑感知蒸馏需要成对完整/缺失观测，这对真实截肢用户通常不可得，因此真实用户试点只提供下游证据而未消除该监督依赖
- 只处理结构缺失，未覆盖运动不稳与长期疲劳
- 模型参数多于轻量基线，且缺少边缘/可穿戴设备的端到端延迟评测
- IncNYU 由 NYU 派生，解剖多样性、传感条件与交互行为覆盖有限
