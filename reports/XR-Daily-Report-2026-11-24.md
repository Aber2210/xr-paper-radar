### 第 1 章 forth：以仅前向的代理-控制配对夯实触觉 VLA 执行（2611.26744 · 触觉与多模态 · 4.27 A）

**一句话结论**：把触觉 VLA 的适配与滑移门控全部压在纯前向路径上（Forward-Forward + 零阶），冻结 4-bit 骨干：LIBERO 97.6% 追平反传，峰值显存仅 334 MB（1/7.12）、延迟 58.8 ms（1/2），滑移门控夹持力 0.77 N 对 reflex ramp 22.43 N（1/29）。

**要解决的问题**

触觉 VLA 普遍假设「代理损失下降即意味着物理力接地」，该假设在三个部署层面失效：冻结视觉骨干丢弃接触几何、下游损失掩盖 token 级梯度对齐、离散指标触发优化崩溃。同时领域缺少把每层优化目标与其物理可观测量成对报告的评测约定。

**方法详解**

提出 forth 仅前向的测量与执行框架，三层各自配对「代理量-物理量」。表示层：两层 Forward-Forward 的层局部触觉 trunk，只让标量 goodness 跨块传递，不做端到端反传。更新层：token 并行的 zeroth-order 低秩（rank 8）adapter 挂在 action head，用对称差分方向导数在激活空间更新，16 次前向替代一次反传。控制层：SlipGuard 一类剪切比门控 ρ=F^s/F^n，阈值 τ=ρ̄+3σ_ρ、两步去抖、有界比例力修正。另给出 floor→readout→validity→mechanism 四步配对评测协议。

**实验与结果**

- LIBERO 平均成功率 = 97.6%（Spatial 99.3 / Object 98.6 / Long 94.8；OpenVLA-OFT 96.8）
- 峰值激活显存 = 334 MB（反传 2381 MB，7.12 倍）
- 单次前向延迟 = 58.8 ms（反传 117.5 ms，2.00 倍）；能耗 28.9 J（57.2 J，1.98 倍）
- SlipGuard 峰值夹持力 = 0.77 N（同一壳体的 reflex ramp 22.43 N，29 倍）
- 物体损伤降低 = 1.59–3.42 倍（相对手调 reflex ramp，N_crush=F_req 约定）
- 故障恢复 = 160/160 回合（恒力策略 68/160，给真值质量与摩擦的 oracle 145/160）

**创新点与贡献**

- 把「代理指标-物理量必须同向」提升为跨三层的评测约定，并用纯前向组合（Forward-Forward + zeroth-order）在冻结 4-bit 骨干上完成触觉适配与滑移门控，使每层都可测且可纠正

**局限与风险**

- 门限由经验标定而非物理推导，真实传感器上存在预触发误报（力级统计 0.024、比值统计 0.031）
- 部署需成对剪切/法向传感器、无故障标定集与策略不可抬升的力上限

### 第 2 章 EgoLAM：从手部与头部运动学习潜动作（2611.27290 · 具身交互 · 4.27 A）

**一句话结论**：用同参考系实测手腕位姿给潜动作瓶颈做监督、把头动作为独立条件交给前向模型，并用对抗与 warp 一致性把相机运动挤出码中：LIBERO 三套件 79.38%（比专家 BC 高 28.73 点），首次给出 AD/IC 两项可诊断「潜动作是否真装了运动」的第一视角指标。

**要解决的问题**

潜动作模型把相邻帧的变化当作训练目标，但在第一视角视频里，杯子在画面中移动既可能是手推的、也可能是佩戴者转头造成的；两者都能帮助预测下一帧，却只有前者描述操作。基于像素重建（LAPA）的目标可能省略手腕真实的平移/旋转，基于 slot 预测（LAPO-Slots）的目标仍会把单纯转头编码成动作。

**方法详解**

EgoLAM 分两阶段：先用冻结 DINOv2 特征与跨帧 patch 相似度自监督训练 object slots（slot attention + 特征重建 + 时间对应）；再冻结视觉前端，IDM 以每只手一个 query 在 slot 上池化特征，编码为 latent action z_t。关键在于监督拆分：动作瓶颈处用实测手腕运动（在较早的头部坐标系下表达平移与相对旋转）直接监督，head 运动 n_t 作为独立条件送入 FDM 预测未来 slots，另加梯度反转的相机对抗头与图像 warp 下的 view-consistency 损失，抑制 z_t 中可解码的相机运动。推理只需两帧 RGB。

**实验与结果**

- LIBERO 三套件平均成功率 = 79.38%（比专家 BC 高 28.73 points）
- Spatial / Object / Goal 成功率 = 81.40% / 77.33% / 79.40%（专家 BC 59.27% / 41.07% / 51.60%）
- 相对最强其他潜动作教师平均领先 = 9.76 points
- 手部运动解码 AD R² = 0.5343（GeoLAM 0.4312，LAOM 0.0564）
- 视觉敏感性 IC = 0.7673（相机 warp）/ 0.1699（光照），八模型中最低
- 参数量与延迟 = 90.89M 参数、0.85 ms/帧对（缓存 slot，LAOM 1.47 ms）

**创新点与贡献**

- 显式规定潜动作该保留谁的运动：以同一参考系下的实测手腕位姿作瓶颈监督、把头动作作为独立条件交给前向模型，并用对抗与 warp 一致性把相机运动从码中挤出

### 第 3 章 非穿透世界模型（2611.27963 · 世界模型与仿真 · 4.27 A）

**一句话结论**：首次把非穿透写成无几何世界模型上的约束问题，并证明生成器隐状态已含碰撞信息：六个模型平均违规率 74%→16%（LingBot 89%→4%），Pred 模式每条仅多 0.7 s 而原始后处理要 53.7 s。

**要解决的问题**

交互式视频世界模型按指令开环生成，相机可以穿墙或把障碍物抹掉。现有基准多用无碰撞轨迹，无法评估非穿透能力；提示词几乎无效，外部深度守卫又要逐帧解码且只能急停。

**方法详解**

提出 NoPeBench 三级基准。发现冻结 DiT 的中间隐状态在生成像素前已编码即将发生的接触，于是在冻结 DiT 上训练不足 2M 参数的预测头，读出候选动作是否安全及到障碍距离。推理时把不安全动作投影为最保留原意的停止或沿墙滑动，分 collision 模式（当前块内改并重跑 step 0）与 prediction 模式（用上一块预测下一块）。

**实验与结果**

- 六个模型平均违规率 = 16%（原始 74%）
- LingBot-World 2.0 违规率 = 4%（原始 89%）
- Task 1 漏检 = 0.6–11.5%（原始 100%）
- Task 1 判决分提升 = 17–33 分
- Pred 模式额外开销 = 每条约 0.7 s（原始 53.7 s/条）
- Coll 模式额外开销 = 每条约 9.9 s（外部深度 14.7 s）

**创新点与贡献**

- 首次把非穿透定义为无几何世界模型上的约束问题，并证明生成器隐状态已含碰撞信息、可用极小头读出且跨域跨视角零样本迁移

### 第 7 章 TouchBench：视觉语言模型能感知不可见的物理属性吗（2611.26883 · 触觉与多模态 · 4.07 A）

### 第 8 章 RoboCap-10k：面向机器人学习的度量精确自我中心数据集（2611.26916 · 评估与数据集 · 4.07 A）

### 第 9 章 PennyGS：在消费级 GPU 上数分钟完成全分辨率 3DGS 训练（2611.27525 · 神经渲染 · 4.00 A）

**一句话结论**：不靠单点 kernel 优化，而是逐阶段消除「冗余像素 / 冗余字节 / 冗余 pass」：RTX 3060 上全分辨率 Mip-NeRF 360 单场景 6m25s（LiteGS 34m08s，3.9–5.8×），平均峰值显存仅 1.04 GB。

- 不是单点 kernel 加速，而是识别出「冗余像素 / 冗余字节 / 冗余 pass」三种冗余并在每一步逐阶段消除，使 4K 全分辨率训练在消费级显卡上从半小时级压到分钟级

### 第 10 章 SparseHPS：跨深度相机与激光雷达的统一人体姿态与形状模型（2611.26730 · 化身与人体 · 3.92 A）

**一句话结论**：一套权重同时服务深度相机与 LiDAR 的体素级人体网格模型，单帧精度即超过已发表的 32 帧序列方法：SLOPER4D 关节误差 28.6 mm（BMLiCap 36.5 mm，降 22%）。

**要解决的问题**

点云人体姿态与形状估计方法各自绑定一种传感器：不同设备的点密度相差十倍以上，公开数据集标注的人体模型互不兼容，而 LiDAR 方法要靠长序列（多达 32 帧）弥补稀疏扫描。尚无用一套权重同时服务两类传感器的模型。

**方法详解**

用 LitePT 稀疏体素编码器处理 2 cm 体素化点云（细层卷积、粗层注意力）；24 个可学习查询 token（每关节一个 + 形状 + 平移）在两层最粗阶段与体素交替做自注意力与交叉注意力，所有关节 token 共享同一个线性头输出 6D 旋转。平移不直接回归，而由 stage-4 体素带偏移投票出骨盆位置，平移 token 加权投票。十二个解码块中三个带因果 token 记忆，可回看前 7 帧（0.2 s 间隔）。十个数据源统一到 neutral SMPL-X（16 形状系数）标签空间，用每源配额平衡采样并以保重力的 yaw–tilt 增强训练。

**实验与结果**

- SLOPER4D J-Err(L) = 28.6 mm（最强已发表 32 帧方法 BMLiCap 36.5 mm）
- FreeMotion J-Err(L) = 41.8 mm（BMLiCap 47.2 mm）
- HuMMan 留出被试关节误差 = 34.7 mm（PA-MPJPE 27.1 mm）
- 相对最强先前方法根节点关节误差降低 = 22% / 11%（SLOPER4D / FreeMotion）
- 九测试集平均 MVE 七步消融 = 43.3 → 36.0 mm（PA-MVE 25.0 → 23.1 mm）
- 模型规模与速度 = 50.0M 参数，单帧 10 ms（RTX 4090）

**创新点与贡献**

- 首个用一套权重同时服务深度相机与 LiDAR 的体素级人体网格模型
- 单帧精度即超过已发表的 32 帧序列方法

**局限与风险**

- 每帧只估一人且需预先把人体从场景分割出来
- 要求输入竖直轴误差在约 15° 内
- 不估手与脸
- 少于 50 点时经常失败
- 与已发表方法的比较不完全受控（训练源更多、256 点结果用未针对该输入训练的权重）
