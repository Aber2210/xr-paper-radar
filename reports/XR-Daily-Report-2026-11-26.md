### 第 1 章 MoGe-4D：高效、灵活、统一的稠密运动与几何（2611.32198 · 重建与SLAM · 4.57 S）

**一句话结论**：把 4D 预测收敛成「一次 query 返回 allo/ego 成对点图」这一接口：几何、运动、相机位姿由同一组稠密坐标给出，位姿退化为闭式刚体对齐且不依赖参考帧——3D 跟踪全点 RelEPE 相机系 0.084 vs V-DPM 0.160（−47.5%）、世界系 0.077 vs 0.138，多视图重建全局点 AUC@25 79.26% vs 同数据同初始化训练的 π3 73.41%，Oxford-Spires 500 帧单次前向零样本仍比基线快 1.7–4.3×。

**要解决的问题**

从 RGB 视频重建动态场景要同时推理几何与跨视角运动，但现有路线要么把重建与跟踪拆成碎片化管线（几何分支 + 独立跟踪模块），要么像 D4RT 那样把 4D 预测写成时空 query 却逐点解码，稠密化后算力不可承受；同时监督稠密 4D query 需要任意帧间的连续 3D 对应，逐像素存轨迹的存储开销不可行。

**方法详解**

对有序 query $(i,j)$ 同时预测一对点图：$\left(P^{\mathrm{allo}}_{i\to j},P^{\mathrm{ego}}_{i\to j}\right)=\left(P_{i\to j,i},P_{i\to j,j}\right)$，即以源帧 $i$ 的像素网格为准，把同一批 3D 点分别表达在源相机与目标相机坐标系下。两者在理想情形只差一个刚体变换，但归纳偏置互补：allocentric 图锚在源视角，能保住离开目标视野的静态背景；egocentric 图锚在目标视角，能精确跟住大位移前景，因此单次 query 就同时给出动态几何与相对位姿。为解耦焦距与尺度，先预测 affine-invariant 点图，再按 $P^{\mathrm{allo}}_{i\to j}=\alpha_i(\hat{P}^{\mathrm{allo}}_{i\to j}+\delta_i e_z)$、$P^{\mathrm{ego}}_{i\to j}=\alpha_j(\hat{P}^{\mathrm{ego}}_{i\to j}+\delta_j e_z)$ 还原。效率来自 context–query 双编码器：context encoder（ViT，占总参数 90% 以上，粗 token 网格）对整段序列只跑一次并缓存多层特征，轻量 query encoder（ViT-B）按任意分辨率重编码源图，在 conditioned block 里把帧 $i$、$j$ 的桥接特征作为额外 key/value 注入，因此输出分辨率与 token 预算可在推理时自由调整而不重算 context。解码端卷积头出成对点图、切向、逐点不确定度与可见性/天空/动态掩码，MLP 头从特殊 context token 直接回归度量尺度与成对共视度。推理时先用 self-query 解出光轴偏移与焦距，再对每个 query 用不确定度与动态掩码加权的 Umeyama 从稠密 3D-3D 对应闭式求相对位姿，长序列只在高共视对上建稀疏位姿图同步全局位姿。世界系融合按 $P^{\mathrm{world}}_{i\to j}=(1-M^{\mathrm{dyn}}_{i\to j})R_i^{\top}(P^{\mathrm{allo}}_{i\to j}-t_i)+M^{\mathrm{dyn}}_{i\to j}R_j^{\top}(P^{\mathrm{ego}}_{i\to j}-t_j)$，用软掩码取长补短。训练上以 ROE 尺度-平移对齐后施加全局/局部点图损失、边缘损失、全局/局部运动损失（对相邻目标时刻的点图差分做约束）以及切向/不确定度/掩码/度量尺度/共视度辅助损失，并从短 clip、小 token 预算逐步扩到全量混合数据。配套 RigIDTrack 数据管线把动态网格面片先拟合刚性正则化的逐面仿射轨迹，再按相对运动一致性聚成约 3.2K 个 affine body（2.3M 动态面片压缩 700× 以上），逐帧存 RGB、深度、内参、外参、body ID 与每 body 仿射变换，任意帧的对应按 $E_kA_{b,j}A_{b,i}^{-1}E_i^{-1}$ 以 $O(1)$ 复原，存储只比 RGB-D 视频多约 15%。

**实验与结果**

- 3D 跟踪全点 RelEPE：相机系 0.084 vs V-DPM 0.160（−47.5%）、世界系 0.077 vs 0.138（−44.2%）；世界系 AUC 72.65%→78.89%
- 遮挡精度 OA 88.75%，Open-D4RT 84.16%、Track4World 84.96%
- 多视图重建全局点 AUC@25 79.26% vs 同数据同初始化训练的 π3 73.41%，RD 0.079→0.063
- 度量尺度重建：|log s| 0.060 vs DA3 0.072，δ25 97.00% vs 89.34%
- Oxford-Spires 500 帧单次前向零样本，比基线快 1.7–4.3×；50 帧全对跟踪 8.5 s vs Open-D4RT 81.7 s（约 10×）
- 消融：去掉桥接预对齐 全局点 AUC 71.17%→62.65%；改用 camera token 直接回归位姿 ATE 0.057→0.125、AUC 71.17%→54.11%

**创新点与贡献**

- 概念上把 4D 预测收敛成「一次 query 返回 allo/ego 成对点图」这一接口：几何、运动、相机位姿三者由同一组稠密坐标给出，位姿退化为闭式刚体对齐而不再黑箱回归，且不依赖 privileged reference frame，因此能零样本外推到 500 帧
- 相对 D4RT 的逐点 query 与 V-DPM 的单参考帧锚定，它同时解决了语义统一与稠密解码成本

**局限与风险**

- 物体边界与细结构仍是弱项，token 预算有限时卷积解码会平滑掉突变的 3D 过渡，产生 flying point 或丢掉只有几个像素的结构

- 序列更长时收益递减：V-JEPA 变体在 100 帧后退化，全局注意力随长度二次增长，作者明说数百帧的前向推理只是泛化探针而非可用部署模式

### 第 2 章 值得记住的网格：交互式视频世界中的持久外观（2611.32445 · 世界模型与仿真 · 4.40 S）

**一句话结论**：把 coarse mesh 当地址而不是画布：在物体自身坐标系按表面积分 cell 存渲染器自己的 K/V，使外观随物体移动与关节运动一起走、跨 agent 共享同一地址——动态场景 object permanence 91.5 vs 最强基线 34.7（HSSD）、94.1 vs 43.4（MutableWorlds），跨 agent 一致性 79.99 vs 42.60，720p 41.1 FPS 且 8,001 帧 rollout 峰值显存 <45 GiB。

**要解决的问题**

视频世界模型能按用户动作合成照片级画面，但长时交互中一致性崩溃：记忆绑定在内容被观测的位置，物体被搬走后外观留在原处，重访时必须重新臆造。显式 3D 世界（coding agent 或 text-to-3D 生成）几何与状态天然持久，外观却远不及照片级；把二者结合时 proxy 只说明东西在哪，渲染器仍要即兴发明外观。量化上，720p 30 FPS 下把每 token 的 K/V 全存约 54 GiB/分钟，全历史 attention 在 8,001 帧 rollout 中 139 s 即 OOM，并发方法的 CPU 内存估计达 300 GiB/千帧。

**方法详解**

以 coarse、无纹理 mesh 作为地址而非画布：每步把当前 mesh 与各 agent 的 bounding box 从该 agent 相机光栅化成 flat-shading proxy video，经 zero-init patch embedding 加到噪声 latent 上，序列长度不变。Surface memory 的索引单位是 cell：光栅化给出每像素背后的物体 o(p) 与表面点 x(p)，按 c(p)=(o(p), floor(T_o(t)·x(p)/s)) 归到物体自身坐标系的 cell，并额外按朝向与四种 cell 尺寸切分，使远距表面也能填满粗 cell；cell 不依赖任何相机，因此所有 agent 用同一地址访问同一表面。写入时每个 token 的 K/V 只存一次、由 cell 指向它，每 cell 保留 first 与 latest 两个 observation，first 永不替换以防误差跨重访累积。存储侧丢弃已离开 temporal cache 且无 cell 指向的 token，其余按 LM KV 压缩思路投影到在自身 rollout 上拟合一次的 PCA 基、以 8-bit 存储，压缩 18 倍。读取时对新 chunk 的每个 token 查其覆盖 cell 的 first/latest，取多数像素指向的 chunk 与 token，做 attention 读取。底座为 Cosmos3-Nano，8 帧 chunk、2 步去噪，自研 FastVAE 替换原 VAE；训练在 Unreal Engine + Isekai3D 合成多 agent episode 上，用 rollout 训练改造成 few-step causal renderer，并加 memory distillation：学生在 1-chunk 窗口下必须用自己写出的记忆渲染重访，由看全历史的冻结 teacher 监督。

**实验与结果**

- 静态 ScanNet++：content persistence 91.37 vs AgentGarten 88.62、GEN3C 86.93；Replica 3D consistency 92.16 vs 92.06，persistence 92.27 vs 88.44
- 动态场景 object permanence 91.5 vs 最强基线 34.7（HSSD）、94.1 vs 43.4（MutableWorlds），moved objects 86.0 vs 58.1
- 多 agent cross-agent consistency 79.99 vs AgentGarten 42.60（2 agents）、77.12 vs 42.16（4 agents）
- 720p 实时：41.1 FPS、37.0 MP/s vs AgentGarten 34.1 FPS / 13.6 MP/s，吞吐为其 2.7×，其他基线 15× 以上
- 8,001 帧 rollout 峰值显存 <45 GiB，而 attending 全历史在 139 s 就耗尽显存
- 压缩把额外 K/V 存储从 3.70 GiB 降到 0.21 GiB（18×），一致性不降

**创新点与贡献**

- 把 mesh 当地址：在物体自身坐标系按表面积分 cell 存渲染器自己的 K/V，使外观随物体移动与关节运动一起走、跨 agent 共享，存储随已见表面而非帧数增长
- 记忆蒸馏让学生读取自己写出的、带自身误差的记忆，而非训练目标里的干净颜色，从而抑制长 rollout 的误差累积
- 仅用合成数据训练即可 zero-shot 迁移到真实室内扫描与 coding agent 生成的可执行世界

**局限与风险**

- 必须提供 coarse mesh 与 agent bounding box，纯视频或无几何输入不适用
- 训练数据全部合成，真实扫描只做 zero-shot，未在真实捕获上训练

### 第 3 章 AirLeg：鲁棒精确的自监督视觉—惯性—腿式 SLAM 系统（2611.32523 · 重建与SLAM · 4.38 S）

**一句话结论**：把 imperative learning 用于「仿真预训练本体感知模型 → 真机」的跨模态自适应：腿式里程计精化视觉地图，精化后的地图再以重投影而非位姿回归监督网络，并用稀疏伴随避免展开 BA——GrandTour 17 条序列常规 ATE 0.15 m / 困难 0.23 m，是唯一全部 17 条都 <0.4 m 的方法；Unitree Go2 上漂移 0.59% vs 最佳对手 OKVIS2 1.55%。

**要解决的问题**

腿式机器人视觉—惯性—腿（VIL）定位只比 IMU + 关节编码器多一个相机，成本极低，但学习式腿式里程计的监督来源两难：纯仿真训练存在 sim-to-real 差距（执行器动力学、接触、噪声无法精确建模），真实标注又需动捕或 LiDAR 等昂贵设备，或用视觉估计当伪标签——后者会让网络只复现视觉误差，视觉退化时无法互补。同时传统腿式里程计依赖「支撑脚静止」假设，在雪地陷落、冰面打滑、泥地等可变形地形上系统性失效，且既有系统只把腿信息当作相对运动约束，未利用脚与地形之间的几何关系。

**方法详解**

AirLeg 分三阶段训练腿式里程计网络（约 0.85 M 参数的 4 层 4 头 Transformer，输入 50 帧 IMU/关节位置速度/归一化足端力，输出机体线速度、6 维 twist 对数方差与陀螺残差修正），阶段间可训练参数递减。第一阶段在 Isaac Lab 中以步态条件策略与地形穿越策略采集约 80 h/机器人 数据，覆盖 μ∈{0.4,0.6,0.8,1.25}、砾石、软地、4 种步态及质量/增益/时延随机化，用异方差高斯 NLL 联合训练速度与不确定度。第二阶段用 imperative learning 做无真值 sim-to-real：下层是多传感器 BA L(μ;f_θ)=Σ‖π(T_i⁻¹X_l)−x_il‖²/α_v + Σ‖Log(ΔT_ij⁻¹T_i⁻¹T_j)‖²_{Σ_ij⁻¹}/α_l，权重 α 由方差分量估计（VCE，按冗余度 ν_g=m_g−tr(H⁻¹H_g) 解 S β̂=q，并做对数域阻尼更新）自标定；上层不回归位姿，而是把精化后的地图点用网络预测运动重投影 U=L_rep+λ_e L_epi+λ_g L_g，使梯度贴近原始图像证据。因上下层目标不同，间接梯度不消失，作者用可微腿式积分（误差状态 ϵ_{k+1}=A_kϵ_k+B_k[δv̂;δω̂]，同一线性化兼做协方差传播）加稀疏伴随求解 H w=(∂U/∂μ*)ᵀ 得到 g_ij，无需展开 BA，并用一阶代理目标 Ũ 修正轮内梯度漂移。部署阶段为双窗估计器：短窗跑腿辅助双目 VO 优化全部地图点，长窗只保留 ≤100 个长跨度 landmark（3D NMS 去冗余），其余点经 Schur 补边缘化为 6 维相对位姿因子 Ω_ij^v=H_εε−H_εX H_XX⁻¹H_εXᵀ。另引入形变感知足—地约束：超帧上用 Fast-FoundationStereo 重建地形子图，Huber 加权 PCA 拟合局部平面 (q,n)，残差 r^f_ij=nᵀ(T_j⁻¹T_i T_BC⁻¹f_i−q)−a+δ_b，其中接触偏移 δ_b 在 N_b 帧块内共享（否则与高度不可区分），并以零均值先验+随机游走正则；腿因子与足—地因子的权重由在线 VCE 分方向（α_R、α_xy、α_z、α_f）重标定，视觉与先验作为参考组固定 β=1 以回避不可辨识。网络在线只训练 rank-1 LoRA（约 1.3 k 参数），以融合位姿监督，并在留出帧对上做接受/回滚门控。

**实验与结果**

- GrandTour 17 条测试序列（19 种方法对比）：常规序列平均 ATE 0.15 m，困难序列 0.23 m；最佳对手分别为 0.21/0.22 m 与 2.08 m（IS）

- Unitree Go2 低成本平台：平均漂移 0.59%，优于最佳对手 OKVIS2 的 1.55%（不到其 40%），10 条序列中 8 条最优

### 第 4 章 Xtream：面向大规模流式重建的显式度量状态（2611.31757 · 重建与SLAM · 4.08 A）

**一句话结论**：把「尺度」从隐变量提升为一等状态：每个窗口一个对数尺度比、闭环再带一个独立环路尺度，用度量深度先验或 IMU 因子给绝对锚点，从机制上阻断逐窗口 handover 误差累加——VBR 单目 ATE 5.40 m（AMB3R-SLAM 7.42、CLoSeR 11.15），KITTI 9.79 m（13.11），单张 RTX 5090 上 10–21 FPS。

**要解决的问题**

3D foundation model 的跨视图注意力限制了可处理帧数，现有做法或按重叠窗口切块后做几何对齐，或用隐式 memory 递归更新，再叠加关键帧位姿图；但在纯单目下缺少 metric scale 可观测量，尺度漂移成为主要误差源，即使检测到闭环，局部优化也难以恢复全局一致性——表现为公里级序列 ATE 被尺度误差主导。

**方法详解**

输入图像流按窗口切分（$W=64$ 帧、重叠 $O=3$），冻结的 3DFM（DA3-Giant）对每个窗口一次性预测 up-to-scale 位姿 $\bar{T}^k_q$、逐像素深度 $D^k_q$ 与置信度，并用 DINOv2 SALAD 描述子做图稠密化与闭环。核心是为每个窗口引入未知对数尺度比 $\ell_k$，用重叠首帧的中位深度比 $r_k=\mathrm{median}_{u}D^{k-1}_{o_k}(u)/D^{k}_{o_k}(u)$ 把相邻窗口串起来，对应因子 $e^{\mathrm{s}}_k=\ell_k-\ell_{k-1}-\log r_k$。视觉因子写成 $e^{\mathrm{v}}_i=\mathrm{Log}(\Delta\bar{T}^k_{i,i+1}\,\mathrm{diag}(R_{i,i+1},e^{-\ell_k}p_{i,i+1}))$，噪声随 $e^{-\ell_k}$ 缩放，使残差表达在 3DFM 单位下、对全局尺度不变、防止尺度塌缩。单目设定再给每个 $\ell_k$ 加一个鲁棒一元因子 $e^{\mathrm{m}}_k=\rho((\ell_k-\log m_k)/\sigma_k)$，其中 $m_k=\mathrm{med}_f\,\mathrm{med}_u D^{\mathrm{m}}_f(u)/\mathrm{med}_u D^k_f(u)$ 是度量深度模型与窗口深度的中位比值，$\sigma_k$ 取残差 $1.4826\,\mathrm{MAD}$ 的 3 倍，且只在该窗口相机中心散布超过中位深度 1% 时插入。有 IMU 时不加度量先验，改由预积分因子与 bias 随机游走因子使 $\ell_k$ 可观，$\ell_0$ 由 VI3 的无 GT 初始化播种。中期/长期闭环各占一次 3DFM 前向，并引入独立的环路尺度 $\ell^{\mathcal{L}}_{i,j}$，用 Umeyama 对齐窗口内位姿得到 $s^{\mathcal{L}}_c$ 后约束 $\ell_c-\ell^{\mathcal{L}}_{i,j}-\log s^{\mathcal{L}}_c$；闭环用 Student-$t$ 权重 $w_{i,j}=\min(1,(\nu+p)/(\nu+d^2/\lambda))$ 降权或剔除。后端为 LM 因子图，每来一个窗口只走一步、闭环与收尾迭代至多 100 次，按 5 窗口一块剪枝并只保留每窗口 $K=8$ 个关键帧。

**实验与结果**

- VBR 单目 ATE 5.40 m，AMB3R-SLAM 7.42 m、CLoSeR 11.15 m；单目惯性 3.06 m，FoundationVIO 9.59 m
- Oxford Spires 单目 1.67 m（AMB3R-SLAM 2.32）；KITTI 9.79 m（AMB3R-SLAM 13.11、CLoSeR 12.79）
- EuRoC 单目 0.07 m 略优于 AMB3R-SLAM 0.08 m；ScaRF 0.08 m 略逊于 AMB3R-SLAM 0.07 m
- 消融：VBR 上仅 3DFM 流式 72.0 m → 加图+度量先验 39.2 → 加共视环 38.1 → 加闭环 5.40（相对误差 0.16）
- 关键帧从全帧降到 8 个/窗口：后端时间 0.26×，Oxford SE(3) ATE 2.262→1.107 m
- 运行：单张 RTX 5090 上 KITTI 21.0 FPS、Oxford 10.8 FPS，峰值显存 12.5–15.4 GB

**创新点与贡献**

- 把「尺度」从隐变量提升为一等状态：每个窗口一个对数尺度比、闭环再带一个独立环路尺度，并用度量深度先验或 IMU 因子给绝对锚点，从机制上阻断逐窗口 handover 误差的累加

**局限与风险**

- ScaRF/EuRoC 这类小场景上相对 AMB3R-SLAM 无优势

### 第 5 章 LookAnything：面向整体注视跟随的基础模型（2611.32351 · 感知与认知 · 4.07 A）

**一句话结论**：用三组可学习 gaze query 把 depth、head mask、target heatmap 三种先验内化进 VLM latent（训练时监督、推理时不需要任何外部输入），并把点/框/热图/语言统一进一个自回归输出空间——HoliGaze-Bench GTL-T2P L2 0.094 vs 同骨干 0.387，GTL-T2B mIoU 0.333 约为 Qwen3.8-27B 的 2.2 倍，而骨干只有 2B。

**要解决的问题**

专用注视方法依赖 head crop、depth map 等辅助输入，带来级联误差与额外推理开销，且多在单一域训练、只输出 heatmap，缺 instance 级语义，难以支撑下游交互与推理。把注视接入 VLM 的尝试任务范围窄、未充分利用注视先验。量化上，33 个领先 VLM 在几何 grounding 上普遍失败：Qwen3.8-27B 的 GTL-T2B mIoU 仅 0.152，GPT-5.6-Sol 0.257，而描述类 MCQ 却接近饱和。

**方法详解**

把 holistic gaze following 形式化为 instruction-conditioned 自回归生成 p(Y|I,P)=∏ p(y_t|I,P,y_<t)，输出统一为 token 序列，可含 point、box、heatmap 坐标与自然语言。骨干为 Qwen3-VL-2B，视觉端用 LoRA（rank 16、α=32）适配；在 multimodal embedding 后追加三组可学习 gaze-prior query Q=[Q^d,Q^h,Q^g]，分别承载 scene depth、source head grounding、target spatial geometry，由 LLM 输出上下文状态 H。三组轻量 MAE-style 辅助 decoder 把 query state 解成显式几何：D̂=D_d(H^d) 用 scale-invariant log 损失；M̂=D_h(H^h) 用 BCE+soft Dice；Ĥ=D_a(H^g,F_v) 用 KL+MSE，另加 point Huber 与 box GIoU 回归头；推理时可选择性跳过辅助分支。Structurally disentangled block-wise attention 用结构化 mask 让每组 query 只 attend 共享 prompt、彼此隔离，语言 token 再联合 attend 全部 gaze 表征，避免 depth 梯度或头部轮廓对注视表征形成 shortcut。数据侧 HoliGaze 引擎四阶段：把 8 个源数据集统一 schema，用 SAM3 / Depth Anything v3 / Gemini 补 head mask、scene depth、referring expression，用模板生成 openQA 与 MCQ（entity expansion、attribute perturbation、box permutation 造干扰项），最后四人全量视频核验。

**实验与结果**

- HoliGaze-Bench 全指标第一：GTL-T2P L2 0.094 vs 同骨干 Qwen3-VL-2B 0.387、Gemini-3.7-Flash 0.131
- GTL-T2B mIoU 0.333 vs Qwen3.8-27B 0.152，约为其 2.2 倍
- 5 个 native benchmark 平均 L2 0.109 / AUC 0.942，4 个数据集上 L2 与 AUC 均最佳（VAT、ChildPlay、GazeHOI、GOO-Real）
- OOD：GFIE 0.0464 vs Gaze-LLE 0.0518；4D-OR 0.076 vs 0.084，均无域内微调
- HoliGaze 规模 311K QA、171K 图像、187K 注视交互；Bench 8K（6,143 图，9 任务，openQA:MCQ=1:1），人工修改率仅 0.70%
- 相对各自 zero-shot 骨干提升 +12.65%（InternVL2.5-8B 类对照口径）与 +12.83%，本方法为 2B 规模

**创新点与贡献**

- 用可学习 query 把 depth、head mask、target heatmap 三种注视先验内化进 VLM latent，训练时监督、推理时不需要任何外部辅助输入，避开了 crop/depth 管线的级联误差

- HoliGaze 是目前唯一同时支持多种 referring type 与多种输出格式、覆盖 9 任务的注视语料与基准

### 第 6 章 COHERE4D：免训练稠密表面配准的一致性度量 4D 人体—场景重建（2611.32482 · 重建与SLAM · 4.07 A）

**一句话结论**：免训练地利用「人体与场景基础模型其实重建了同一张可见人体表面」做稠密像素级 3D 配准，把序列级尺度与逐帧平移解耦、再用跨帧一致投票稳定尺度——3DPW HS-CF5 0.688 较 Human3R 1.079 降 36.2%，EMDB-2 全局人体运动较 HAC 降 40.7%/53.6%，只增加约 4 ms/帧。

**要解决的问题**

单目 4D 重建中，人体基础模型能给出度量尺度的身体网格但缺乏场景落地，场景基础模型能给出全局一致的几何与相机轨迹却尺度模糊或漂移。两者其实重建了同一个前景人体表面，但既有方法没有直接利用这一共享表面：JOSH 依赖昂贵的离线接触优化，HAC 只用稀疏接触关节标定相机尺度，二者都要求可见的地面接触（跳跃、下肢遮挡即失效）；Human3R、UniSH、SHOW 则用数据驱动模块学习对齐，受限于稀缺的联合标注，分布外场景泛化差。

**方法详解**

COHERE4D 把独立的预训练人体分支（Multi-HMR2 / 3DB）与场景分支（DA3 / Pi3X / VGGT-Ω）在测试时冻结，仅做几何配准。场景侧先把长视频切成重叠 chunk，用共享帧建立像素对齐的 3D 对应，估计 Sim(3)（α_k 由重叠深度比的加权中位数 + MAD 剔除得到，A_k、d_k 用置信度加权 Procrustes + IRLS 求解），从而把各 chunk 与相机位姿串到首 chunk 坐标系。人体侧把相机系人体网格 M^c_t 用场景内参投影、z-buffer 光栅化得到可见区域 Ω^H_t，逐像素做透视校正重心插值得到表面点 m_t,i，同像素反投影场景深度得到 p^c_t,i，构成稠密对应集 C_t。核心是把对齐写成只含一个序列级尺度 s 与逐帧平移 γ_t 的最小二乘 min Σ‖s p^c_t,i − m_t,i − γ_t‖²，用 RANSAC 生成假设（阈值 τ_t 随人体尺寸自适应）并按内点支撑打分，再以跨帧一致投票选出共享尺度 s*（抑制深度引起的逐帧尺度抖动），统一作用于深度、点与相机平移。随后做场景落地平移精化：固定 s*，用 RobustMed 对 s* p^c_t,i − m_t,i 做迭代内点过滤 + 坐标中位数聚合得到 γ̂_t，只更新全局平移，不改姿态、形状与朝向。

**实验与结果**

- 3DPW 上 HS-CF5 0.688（Multi-HMR2+VGGT-Ω），较 Human3R 1.079 降低 36.2%；EMDB-1 上 0.470 vs 0.719，降低 34.6%
- Bonn 上以 Pi3X 为场景骨干，点误差最高降低 57.1%、ATE 降低 35.1%
- BEDLAM2 上 AbsRel 最高降低 44.9%、ATE 降低 37.7%（VGGT-Ω 原始归一化输出 111.87 m → 10.98 m）
- EMDB-2 全局人体运动 G-MPJPE：Multi-HMR2+DA3 1539.9、3DB+VGGT-Ω 1203.9，较 HAC 2594.9 降低 40.7%/53.6%，较 Human3R 4866.0 降低 68.4%/75.3%
- 仅增加约 4 ms/帧（初始化 10 ms/帧），在 RTX 4090 上端到端 6–14 FPS

**创新点与贡献**

- 首次把「人体与场景基础模型重建同一张可见人体表面」作为免训练配准的桥梁，直接做稠密像素对齐的 3D 表面配准，替代稀疏接触先验与学习式对齐网络
- 关键是把序列级尺度与逐帧平移解耦，并用跨帧一致投票稳定尺度，使插件式组合在多种骨干上一致受益，且无需任何联合训练数据

**局限与风险**

- 性能仍受场景重建质量约束：大视角变化或远距离人体会让前景几何退化，导致局部人体—场景错位或稀疏外点，虽有回退到原始相机系平移的兜底策略仍可能残留误匹配
- 不显式处理时序抖动与脚部滑动，近距多人交互时依赖的人体模型会出现身份关联错误与重建重叠

### 第 7 章 DraftKV：用分层流式检索守护持久世界（2611.31944 · 世界模型与仿真 · 4.00 A）

**一句话结论**：training-free 的两级检索（相机位姿/视锥粗 grounding + draft attention 细选）配合 tile 级流式 attention，使取数沿 FlashAttention tile 粒度与计算重叠——ORBIA persistence 58.98 vs 56.67、5.49 FPS vs WorldKV 4.71、显存 18.56 vs 21.33 GiB，首次让 33B 级世界模型在单张 80 GiB H100 上做历史 KV 检索。

**要解决的问题**

交互式视频世界模型靠历史 KV cache 维持重访一致性，但检索与全历史 attention 的延迟随历史线性增长，存储也很快不可承受；滑窗与 KV 压缩会丢掉未来重访必需的信息。两类检索信号各有缺陷：相机位姿粒度粗且受轨迹漂移影响，query–key 相似度缺空间约束、会取到长得像但位置错的区域。量化上，SolarWM-33B 的全历史 KV 超过单张 H100 的 80 GiB，CPU offload 方案（WorldKV）E2E 102 s、4.71 FPS、21.33 GiB。

**方法详解**

Training-free 两级检索。Draft Grounding 先用相机位姿/视锥把当前 query 投到历史观测上，做观测级空间对应，得到候选帧；Draft Refinement 再在这些帧内用低分辨率 draft attention 的 block 相关性做细粒度选择。存储上全分辨率历史 KV 放 pinned CPU 内存，只有紧凑的 Draft K Bank（带历史 RoPE 的描述子）常驻 GPU 供检索，全分辨率 key 保留原始时间分量并在被选中的 attention 位置重新施加 K-RoPE。理论上给出三条结论：draft relevance 精确等于 full-resolution block relevance 的 mean 分支，偏差只落在 β 加权的 max 分支；用实测 Top-K 选择重合度给出检索效用损失的上界；pooled descriptor 相近的 block 无论相机位姿如何 draft 都无法区分（aliasing bound），而静态场景下理想视锥共视规则不会丢弃共视历史，二者共同论证「先几何 grounding 再细化」。执行侧提出 SCG-Attention：按 FlashAttention 的 tile 粒度把选中的 KV 从 CPU 流式搬到 GPU，H2D 传输与 attention 计算重叠，用 bounded KV Reuse Buffer 循环复用，使 active KV 驻留只与 tile 数有关、与检索规模无关；每个 tile 先算 partial softmax 统计量，最后按 Eq.(6) 合并各 tile 的 partial 输出。因为选择依赖当前 query，取数必然落在每层关键路径上，该设计正是针对「selected-set readiness」这一暴露全部 H2D 延迟的瓶颈。

**实验与结果**

- ORBIA / LingBot-1.3B：persistence 58.98 vs baseline 56.67（+13.7%）、overall 65.29 vs 64.11（+5.0%）、Ctrl. 51.96 vs 49.38
- 同设定下 E2E 87.51 s vs WorldKV 102.00 s、5.49 vs 4.71 FPS、显存 18.56 vs 21.33 GiB（baseline 22.78 GiB）
- 相对其他 CPU-offload KV 检索方法：端到端 3.27× 加速、峰值显存降 42.2%
- VBench-Long（扩到 60 s）：Quality 82.08 vs baseline 82.07，Dynamic 42.42 vs 38.79，E2E 242.87 s vs 331.88 s、3.94 vs 2.88 FPS
- 单张 80 GiB H100 即可对 SolarWM-33B 做历史 KV 检索并生成，此前该规模需跨卡
- ShadowKV 1364.14 s / 0.70 FPS、FreeKV 5795.78 s / 0.17 FPS，均远慢于 DraftKV

**创新点与贡献**

- 把「检索什么」与「怎么取」拆成两层并各自给出可证的性质：几何 grounding + draft 细选负责相关性，tile 级流式 attention 负责延迟与显存
- draft 与全分辨率相关性的精确等价关系让近似检索的误差来源可解释，而非纯经验调参
- 整个方法 training-free，可直接套到不同 backbone 与不同 backbone 规模，且首次让 33B 级世界模型在单张 80 GiB GPU 上做历史检索

**局限与风险**

- 依赖相机位姿（pose-free 配置虽在附录给出，但 grounding 质量下降），轨迹漂移会污染空间对应
- 理论保证限于静态场景的共视性，动态物体与遮挡不在保证范围
- 33B 规模仍需要 CPU 侧大容量 pinned 内存，且每层取数落在关键路径上，最坏情况仍受 H2D 带宽约束

### 第 8 章 InitFree-SfM：当无初始化 Bundle Adjustment 遇上学习式 Structure-from-Motion（2611.31516 · 重建与SLAM · 3.92 A）

**一句话结论**：给 OSE 只加一项相对深度残差（保持 variable projection 可分性），并让 metric depth 贯穿对应过滤、随机初始化与联合精化——ETH3D 位姿 AUC@20° 85.81% vs pOSE 13.91%，去掉 joint metric refinement 即跌到 31.99%，说明「代理目标」并非精度主因。

**要解决的问题**

现有 initialization-free BA（pOSE/expOSE/pOSE+rot）在 $\mathbb{R}^{3\times4}$ 松弛相机矩阵上最小化代理 Object Space Error，目标值降得很低却给不出准确重建：ETH3D 上 pOSE 的位姿 AUC@20° 仅 13.91%、AUC@5° 11.43%，后续 metric upgrade 也不稳定。根因是 OSE 只约束方向（landmark 必须落在观测视线上），对沿视线的位置没有任何约束，几何信息不足，优化收敛与重建精度之间存在系统性缺口。

**方法详解**

把 OSE 残差写成 $r^{\mathrm{OSE}}_{ij}=P_{i,1:2}\tilde{X}_j-(p_{i,3}^{\top}\tilde{X}_j)m_{ij}$，并加一项相对深度残差得到 depth-augmented OSE：$\mathcal{L}_{\mathrm{dOSE}}=\sum_{(i,j)}c_{ij}\|r^{\mathrm{OSE}}_{ij}\|_2^2+\lambda_d\sum_{(i,j)}c_{ij}\rho\left(q_{ij}^{\top}y_{ij}/d_{ij}-1\right)$，其中 $y_{ij}=R_iX_j+t_i$，$q_{ij}^{\top}y_{ij}$ 是把 landmark 正交投影到观测射线后得到的深度，除以 $d_{ij}$ 使残差为相对量、$\rho$ 为 Huber，$\lambda_d=30$ 用 5%/25%/100% 三阶段 continuation 逐步加上。dOSE 保持可分结构，于是用 variable projection 闭式消去 landmark：$v^{*}(u)=G(u)^{\dagger}z(u)$，以 Ruhe–Wedin 近似 $J_u^{*}=(I-J_vJ_v^{\dagger})J_u$ 求位姿增量，并在 $SE(3)$ 上直接更新（大问题改用 Weber 等的 inverse-expansion 截断幂级数），因此完全不再需要 metric upgrade。前端用 MoGe-2 逐帧预测 metric depth 与内参；对每对图像把预测深度反投影成 3D 点集做 RANSAC 相似变换，再与本质矩阵给出的旋转交叉校验（$\tau_R=15^{\circ}$），只保留两者一致的对，随后把保留下来的对应拼成多视 track。最后做 joint metric refinement：给每帧一个深度尺度 $\alpha_i$，联合最小化归一化重投影残差 $r^{\mathrm{img}}_{ij}$、相对深度残差 $r^{\mathrm{depth}}_{ij}$，以及相对旋转/平移/对数尺度残差 $r^{\mathrm{rot}}_{kl},r^{\mathrm{t}}_{kl},r^{\mathrm{s}}_{kl}$，再加平滑 cheirality 罚与尺度正则，用 Levenberg–Marquardt（30 步 warm-up + 至多 120 步）求解。平移项先在 metric 形式下约束、后期切换为方向约束，以降低对单目深度绝对尺度误差的敏感性；所有相机位姿从随机初始化出发（旋转在 $SO(3)$ 均匀采样、平移零均值高斯 $\sigma=0.5$）。

**实验与结果**

- ETH3D 位姿 AUC@20° 85.81%，GLOMAP(LoMa) 77.18%、pOSE 13.91%
- LaMAR 位姿 AUC@20° 80.99%，GLOMAP(LoMa) 67.93%、pOSE 10.10%
- 低重叠 ETH3D Minimal 子集 AUC@20° 75.31%，专为该场景设计的 MP-SfM 为 76.55%，但运行时间显著更低
- 去掉 joint metric refinement：ETH3D AUC@20° 从 85.81% 跌到 31.99%
- 深度一致性过滤使 ETH3D AUC@20° 提升 10.30 个百分点（75.51%→85.81%）
- 三个随机种子 ETH3D AUC@20° 85.46±0.34、LaMAR 80.76±0.77

**创新点与贡献**

- 把 metric depth 贯穿对应过滤、初始化与精化三处，并给出 dOSE 这一最小改动（只加一项相对深度残差、保留 VarPro 可分性）
- 更关键的是结论层面的新意：仅靠几何约束的 joint refinement 从随机初始化就能得到可用重建，说明代理 OSE 目标并非精度主因，这直接挑战了此前 InitFree BA 以目标函数设计为中心的路线

**局限与风险**

### 第 9 章 HiGS：面向快速可微 3D Gaussian Splatting 的层次化架构（2611.31918 · 神经渲染 · 3.88 A）

**一句话结论**：把 3DGS 的三个角色拆到不同粒度：8×8 tile 只做光栅化、64×32 macro-tile 做划分与排序、bounded batch 做独立工作与反向求导——1080p 2756 FPS / 4K 1533 FPS（相对 gsplat 5.1×/5.6×），负载不均视角上快 6.8×–20.0×，训练 61.5 s vs 194.4 s。

**要解决的问题**

标准 3DGS 让同一个屏幕 tile 同时充当划分单元、光栅化单元与并行工作单元，三者对 tile 尺寸的偏好相互冲突：划分要大 tile 减少 (tile, Gaussian) 对，光栅化要小 tile 减少无效像素求值。结果是在 4K 下每帧要对数千万对做全局 radix sort，且帧时间由最密 tile 的尾部效应决定，而不是由该视角的实际工作量决定；训练侧反向传播的 atomic 竞争与 Adam 带宽成为主瓶颈（FP32 下每 Gaussian 708 字节优化器状态）。

**方法详解**

HiGS 把三个角色拆到不同粒度：以 8×8 渲染 tile 为光栅化单元，把 M=32 个相邻 tile 组成 64×32 像素的 macro-tile 作为划分与排序单元，再以「(macro-tile, batch)」为独立工作单元，每个 batch 至多 B_r=1024 个 Gaussian 并按深度排序。分箱时以 B_p=8192 为一批，在线程组本地存储维护每 macro-tile 的直方图（1080p 约 1000 项、4K 约 4000 项），用分层前缀和算出写偏移，再直接写入 (depth, Gaussian-id) 对；由于 segment 已隐含 tile 身份，排序键从 64-bit 复合键缩成 32-bit 纯深度，记录从 12 字节降到 8 字节。排序是六段无主机同步的流水：四级 block radix sort 按 segment 规模分档，超出最大档的 segment 先切成 8192 的 run 排序再用 merge path 归并。光栅化在每个单元内分两阶段：协同加载 batch 时用不透明度阈值椭圆对 M 个 tile 做重叠测试，得到 P×M 位矩阵后转置，使每个 tile 获得 P 位可见性掩码；随后 worker group 从共享 tile 队列动态认领 tile，经容量 2B_d 的调度缓冲以 B_d=64 为粒度排空到固定速率的混合核，并在每像素透过率饱和时一致投票提前退出。跨 batch 用前向 alpha 混合的结合性做合成：C=Σ F_i C_i，F_i=∏_{h<i}T_h，保持与 3DGS 完全一致的前到后精确合成。数值上以 Σ^{-1}=LL^T 的 Cholesky 因子替代 conic 系数避免抵消，位置相对 macro-tile 中心降到 FP16 避免溢出，SH 用 YCoCg + 非均匀量化压到 32 字节。训练复用同一批单元：合成阶段顺带产出每 batch 的 F_i 与后缀色 S_i=Σ_{h≥i}F_hC_h，反向单元只需本 batch 加这两个边界量即可独立求导；Adam 融进反向投影（每 Gaussian 一线程，梯度留在寄存器），参数除位置外存 FP16、两个矩存 BF16（708→360 字节）并采用随机舍入；对被视锥剔除的 SH 系数用稀疏在线学习的闭式惰性更新 Δθ=-ηmΦ/(√v+ε_AΦ/Ψ)，按 32 个 Gaussian 一组记录最后更新步。

**实验与结果**

- 渲染 2756 FPS @1080p、1533 FPS @4K；相对 gsplat 快 5.1×/5.6×，相对近年优化光栅器快 1.5×–5.6×
- 负载不均的 120 个驾驶视角上快 6.8×–20.0×；最均衡到最不均衡视角间 HiGS 帧时间仅涨 1.6×，基线涨 3.0×–5.9×
- 重建比次快方法快 2.3×–3.0×、比 gsplat 快 5.9×–7.3×，显存比最省方案少 1.9×（Mip-NeRF 360：49.3 s / 2.02 GiB，gsplat 309.4 s / 3.87 GiB）
- 1080p 平均仅 1.51M、4K 2.21M 对，比 gsplat 的 16×16 不透明度感知包围盒少 2.7×/4.3×
- 深度排序 0.03–0.06 ms，gsplat 全局 radix sort 在 4K 为 0.44–1.10 ms；比通用分段排序快 4.6×–6.0×
- 训练 61.5 s vs 起始配置 194.4 s（3.2× 加速，显存少 34%），PSNR 差 0.01 dB

**创新点与贡献**

- 用一次分解同时解决排序规模、尾部效应与训练反向三个问题：macro-tile 分箱让排序变成互不相关的 segment 并把 tile 位从排序键中彻底移除，bounded batch 让任意稠密列表都能驻留片上存储
- 把「一个 batch 既是渲染单元也是反向求导单元」落实为可实现机制，合成阶段顺带留下的边界状态使 batch 间可完全独立求导，无需 per-tile 梯度缓存
- 优化器侧把 Adam 融进反向、状态降精度配随机舍入、并对被剔除的 SH 做闭式惰性更新，使显存流量随「视角看到多少」而非场景规模增长

**局限与风险**

- 并行性以显存和带宽为代价：每个 batch 都要预留并写出自己的输出，且即使被不透明前景完全遮挡仍会被光栅化，在「所有 Gaussian 都覆盖全屏」的退化场景下开销随遮挡层数线性增长
- 方法针对 commodity GPU 的 CUDA 实现，未覆盖移动/XR 端芯片，也未验证超过单卡显存的大场景
- SH 打包与 FP16 路径引入约 55.6 dB 的重建一致性误差，虽在指标上不可见但非比特精确

### 第 10 章 面向未见物体的可泛化前馈三维手-物重建与由粗到细接触估计（2611.31812 · 化身与人体 · 3.85 A）

**一句话结论**：物体侧只用冻结位姿基础模型的内部几何特征、不学实例嵌入，接触则由「粗 token 逐关节预测 + 重建 SDF 区域距离细化到掌/背侧」两级落地——DexYCB 物体 AUC 92.88（比 SemiHand 高 10.25），OakInk 未见物体 AUC 93.29 vs SemiHand 40.50，接触 F1@3mm 74.97 vs HACO 68.09。

**要解决的问题**

单目图像中手与物体的三维位姿及接触是操作理解的基础，但现有方法只能部分满足需求：联合前馈估计器依赖预定义物体集合，遇到未见物体泛化差；把各实体基础模型独立组合虽能处理未见物体，却易造成手-物错位，且物体被手遮挡时位姿退化。接触方面，专用估计器（如 HACO）仅凭图像特征预测，缺少显式几何来判定“手指掌侧还是背侧接触”，密集接触预测与重建脱钩、可能自相矛盾。

**方法详解**

提出 Horcrux，一个统一前馈 transformer f(I,{I_h},V_o)=({θ_h,β_h,t_h,c_h},R_o,t_o)。用冻结底座编码器分词：DINOv3 提取场景 token，手部编码器从手裁剪图提取 token，物体侧不学实例嵌入，而是用冻结的物体位姿基础模型（PoseGAM）对输入网格 V_o 渲染参考视图并与图像聚合，取内部特征经可学习投影得到物体 token——因此不绑定训练集物体，且可直接吃图像重建的近似网格。构造序列 Z=[Z_img;{Z_h};z_o;{z_h}] 送入共享 transformer 做全局自注意力，缺手时该手不贡献 token，同一模型同时服务单手与双手。轻量头分别解码 MANO 参数、物体旋转与相对抓握手 a 的平移偏移 t_o=t_a+Δt_o（保证物体留在手中），以及 21 关节粗接触 c_h=σ(φ_c(pool(Ẑ_h)⊕ẑ_o))。细接触阶段把 103 个手部细区域（掌/背侧指段）的顶点经 SDF_o 求到物体距离 d=SDF_o(R_o^T(v-t_o))，汇聚为区域距离 u，与粗接触拼接后用一层 transformer 自注意力解析为 c̃_h。训练分两阶段：先训投影、共享 transformer 与位姿/粗接触头（L=L_h+λL_c+L_o+L_rel，L_rel 用 smooth-L1 监督相对平移以规避单目深度歧义）；再冻结主体训细头（BCE + 区域符号距离回归）。

**实验与结果**

- DexYCB：MJE 10.12、PA-MJE 4.95，物体 AUC 92.88（比最强联合估计器 SemiHand 高 10.25，比仅估物体的 MegaPose 高 8.68）
- DexYCB 联合指标：CDev 9.97，不到最低基线 42.44 的四分之一；SD 3.18、IV 14.15
- HO3D：MJE 23.93、VPE 23.20、PA-MJE 9.57，AUC 87.35（比 HFL-Net 高 8.92；仍低于零样本物体位姿法的 96.42）
- 跨数据集未见物体：OakInk AUC 93.29 vs SemiHand 40.50（+52.79），HOI4D 67.68 vs 15.57（+52.11）
- 接触 F1@3mm：DexYCB 74.97 vs HACO 68.09（+6.88）；OakInk 73.62 vs 59.15（+14.47）；标定 ECE 分别降低 3.4 与 3.1
- 双手：OakInk2 物体 AUC 65.22（比 HOPformer 高 12.77）、MJE 14.29；H2O AUC 97.95（+13.89）、MRRPE 28.03

**创新点与贡献**

- 把“基础模型特征”当作接口：物体只用冻结位姿基础模型的内部几何特征、不用其输出位姿，从而把未见物体泛化与手-物联合对齐统一在一个 transformer 里，且同一模型覆盖单手/双手
- 提出由粗到细的接触估计——粗头从潜在 token 预测逐关节接触以规避重建误差，细头用重建 SDF 区域距离把接触落到掌侧而非背侧，无需单独的接触估计器
- 这种“重建本身作为接触证据”的耦合方式此前未被前馈框架实现

**局限与风险**

- 物体几何以输入网格为前提，实际部署需依赖图像到三维模型（SAM 3D 使 Chamfer 距离从 19.01 升到 27.04，Hunyuan3D 升至 45.20），网格质量直接限制物体精度
- HO3D 上物体 AUC 仍落后零样本物体位姿专用方法（87.35 vs 96.42）
- 评测以抓取帧与离散接触标签为主，缺少长时序视频一致性、动态操作与真实机器人闭环验证
- 细接触的 103 区域划分沿用前人定义，粒度受限于该分区
