### 第 1 章 · PixGR：像素空间生成解码的快速前馈 3D 重建（2610.31908，3.85 A，FULL）

- **赛道 / 场合**：神经渲染 / arXiv preprint（Imperial College London / University of Tübingen）
- **公告类型**：new
- **一句话结论**：把轻量像素空间生成建模嵌入前馈 3DGS 重建：场景潜表示条件化噪声目标视图的生成解码，像素空间 flow matching 实现端到端可微优化，超最强竞品 MVSplat 1.13 dB PSNR。
- **要解决的问题**：前馈 3D 重建的 VAE 潜空间压缩累积误差、限制生成解码质量；确定性解码无法表达遮挡/未观测区域的场景不确定性。
- **方法详解**：上下文观测一次性编码为场景潜表示；以重建引导的去噪（reconstruction-based denoising）从噪声目标视图生成共享 3DGS；可微渲染直接像素空间生成监督，避免 VAE 潜空间；解码 tokenizer patch size 8（VGGT 为 14），条件图 resize 448 对齐 token 数。
- **实验与结果**：视角插值/外推标准基准 + ACID 域外评估：较 MVSplat PSNR +1.13 dB 且 SSIM/LPIPS/FID 同步提升；256×256 A100 训练，含效率分析。
- **创新点与贡献**：① 像素空间生成解码避免 VAE 潜压缩与误差累积；② 重建引导去噪；③ 前馈重建中显式建模场景不确定性。
- **局限与风险**：绝对 PSNR 水平仍受前馈范式制约；生成解码计算开销；附录 D 自述局限（域外与效率边界）。
- **与文献库的关系**：属库内前馈 3DGS 重建线（LINGO 2609.22849 / RLSplat 2610.27712 / VGGT 系）的生成式变体；与 budgeted 压缩线（Budgeted-GS 2610.03162 / RLsplat）互补。
- **可复现性**：摘要级未明示代码；PyTorch 实现细节附录齐全。
- **行动建议**：关注像素空间生成解码是否成为前馈重建新标配；与库内 RLSplat 做同口径复测。

### 第 2 章 · 什么被均值误差掩盖：三款 VR 头显眼动仪精度与设备时钟诊断（2610.32915，3.77 A，FULL）

- **赛道 / 场合**：评估与数据集 / arXiv preprint（Preprint）
- **公告类型**：new
- **一句话结论**：30 人在 Meta Quest Pro / VIVE Pro Eye / VIVE Focus Vision 同协议评测：随机扫视任务中位平均误差 1.04° / 1.50° / 2.41°（FV 线性重校准后仍最差）；首次暴露设备时钟缺陷——QP 暂停达 6.04s、FV 丢样本且样本正相关（离散度 9.8× 样本间 RMS）、闭眼时 QP 全部标记有效而眼球移动 9.74°。
- **要解决的问题**：VR 凝视研究需要已知误差的眼动仪；厂商/文献常用「均值误差」掩盖时间戳重复、丢失成分与闭眼有效性等信号质量问题。
- **方法详解**：随机扫视任务（RAN127/RAN63）+ 暗背景第二 block + 抬眉/闭眼协议；Hodges–Lehmann 配对估计 + bootstrap CI + Holm 校正；时间戳节律与丢失成分分解；门控验证（误差 ≤3° 且 ≥80% 有效样本）。
- **实验与结果**：30 名参与者 × 3 头显；空间精度/跨视场精度/系统误差与重校准/第二 block 变化/精度与时间结构/数据丢失与设备时钟/闭眼有效性多维评估。
- **创新点与贡献**：① 库内首个 VIVE Focus Vision 眼动仪评估；② 把「设备时钟丢失成分」（重复时间戳/丢失构成/闭眼有效性）纳入眼动数据质量报告规范。
- **局限与风险**：单实验室协议；未覆盖无线/多人场景；FV 时钟跳过机制受接口限制只能部分暴露。
- **与文献库的关系**：与库内 GazeDiT（2609.17814，眼动生成）形成「评估-生成」互补；为库内所有眼动实验提供选型依据。
- **可复现性**：协议与指标描述完整；数据/代码释放摘要级未明示。
- **行动建议**：XR 眼动实验选型：QP 精度最佳（1.04°）；所有眼动数据管线应加时间戳与闭眼有效性检查。

### 第 3 章 · AudioLift：音频驱动单图生成全头高斯化身（多视角视频生成中间表示）（2610.31747，3.70 A，FULL）

- **赛道 / 场合**：化身与人体 / arXiv preprint（Yale / UC Merced / CMU，项目页已发布）
- **公告类型**：new
- **一句话结论**：用生成式多视角视频作中间表示，把单张人像+音频提升为可 360° 自由观看的全头 3DGS 说话化身，无需 3DMM/FLAME 参数化人脸模型与逐实例优化。
- **要解决的问题**：参数化人脸模型的紧凑运动表示无法合成极端表情、无法建模头饰等配件；全头几何与配饰建模是既有 talking head 方法的盲区。
- **方法详解**：两阶段框架：Stage I 音频驱动多视角视频生成（2×2 网格联合生成 4 个斜视角+正视角，视频模型自注意力促跨视角一致）；Stage II 对不一致鲁棒的高斯重建（view-aware corruption 增强 + active-volume 正则化），从多视角视频恢复连贯全头几何。
- **实验与结果**：RenderMe-360（含新视角相机集）+ HDTF：FID 44.53 vs 基线 77.05–108.08；新视角相机集 PSNR/SSIM/LPIPS 全部最优；HDTF 正面 PSNR 13.98 / SSIM 0.653 / LPIPS 0.335 / FID 29.73 均最优，CSIM-ref 0.666 接近最佳 0.671；附 in-the-wild、长视频推理、时间一致性与多视角一致性评估。
- **创新点与贡献**：① 摆脱 3DMM/FLAME 参数模型与 per-instance 优化；② 以生成式多视角视频为中间表示桥接音频驱动与 3D 重建；③ 对生成视频不一致性鲁棒的高斯提升阶段。
- **局限与风险**：PSNR 增益温和（13.98 vs SDTalk 13.87），主要增益在 FID 分布匹配；依赖底层视频生成模型能力；两阶段推理的实时性未在正文明确；无用户研究。
- **与文献库的关系**：与库内 Kandinsky S2V 1.0（2610.19290，音频驱动化身视频）构成「2D 视频生成→3D 高斯化身」路线延伸；相对库内 Real3D-Portrait/SDTalk/NeRFFaceSpeech 基线全面提升（门① max Jaccard 0.065，非同质）。
- **可复现性**：项目页面已发布（zhuoyuanjiang.github.io/audiolift-page）；代码与数据释放情况摘要级未明示。
- **行动建议**：社交 XR 化身管线可关注其「生成式中间表示」范式；实时性与资源占用待后续复测。

### 第 4 章 · 基于 HEALPix 的球面隐式神经压缩（全景图像）（2610.32561，3.70 A，FULL）

- **赛道 / 场合**：渲染与显示 / arXiv preprint
- **公告类型**：new
- **一句话结论**：用 HEALPix 等面积分层球面像素化替代 ERP 全景投影做 INR 压缩，消除极点冗余采样与纬度相关感受野；BD-rate 较 VVC 省 16.3%、较 MLIC++ 省 5.5%、较 OSLO-IC 省 27.8%，低解码复杂度适配实时沉浸 VR。
- **要解决的问题**：ERP 投影引入非均匀球面采样与空间畸变（极点冗余、纬度相关感受野），限制过拟合式 INR 编解码器的全景压缩性能；实时解码是沉浸 VR 刚需。
- **方法详解**：HEALPix 球面网格上的轻量 INR 逐帧表示；球面结构选择消融（K 近邻 7.1% 代价、仅父格 +5.0%、Rt 变体 2.1%、非均匀性 1.5% 等）；±60° 外区域占 ERP 潜网格 1/3 样本却仅覆盖 13.4% 面积的定量刻画。
- **实验与结果**：公开全景图像数据集；BD-rate vs VVC / MLIC++ / OSLO-IC；视口内（viewport-based）指标同样节省 16.3%。
- **创新点与贡献**：① 库内首次将 HEALPix 等面积像素化引入 INR 图像压缩；② 极点冗余的定量刻画与球面结构代价分析。
- **局限与风险**：仅图像级（未涉及视频帧间/6DoF）；INR 过拟合编解码的编码成本；客观 BD-rate 未含主观 VR 用户体验。
- **与文献库的关系**：与库内 RDCompGS（2610.19538，3DGS 率失真压缩）构成「2D 全景 vs 3DGS」压缩互补；补强全景/球面表示缺口（门① max Jaccard 0.042）。
- **可复现性**：摘要级未明示代码；实现细节附录可复现。
- **行动建议**：VR 视频/全景内容管线关注其球面网格选择；后续追踪球面 INR 的视频与 6DoF 扩展。

### 第 5 章 · Present Drawing：化身中介绘画事件与物理痕迹探索（2610.32166，3.34 B，FULL）

- **赛道 / 场合**：交互与输入 / ACM UIST 2026（第 39 届用户界面软件技术研讨会）
- **公告类型**：new
- **一句话结论**：提出「化身中介绘画事件」概念与四元素设计空间（时间/场地/控制源/化身具身），以 HMD+自移动笔绘图仪 PoC 让远程化身的签名在物理世界留下痕迹；8 人 Likert 评估支持事件合理性。
- **要解决的问题**：常规绘画事件受物理约束（作者须在场、纸张与场地限制）；远程社交临场中化身的「物理行动」缺乏载体。
- **方法详解**：概念 + 组织者导向设计空间 + PoC（Meta Quest 3 HMD 观看化身，化身运动同步到定制笔式绘图仪机械结构）；5 个应用场景：现场签名会/时光消息胶囊/多地插画演出/吉祥物签名/系统角色签名。
- **实验与结果**：8 名参与者（5 女 3 男）Likert 7 级问卷（签名是否像化身本人所画/自然度/化身在场感）+ 定性讨论（滞后、机械线索、实时交互因素）。
- **创新点与贡献**：① 把「化身行动」落地为物理痕迹的新事件类别；② 四元素设计空间；③ 机制可见性与显示方式的诚实局限讨论。
- **局限与风险**：8 人初始评估规模小；机制可见性（用户看到绘图仪）影响 plausibility；仅签名笔触一种媒体；无现场评估。
- **与文献库的关系**：库内 MR 物理效果/社交化身方向的轻量补充；与物理输出类（ModPack）构成「数字→物理」不同路径。
- **可复现性**：PoC 硬件细节（470×470×220mm 铝框+白色亚克力面板、i9-14900HX+RTX4070 服务器）描述充分；无开源声明。
- **行动建议**：社交 XR/远程签名/实体纪念品场景可参考其设计空间；结论需更大样本复现。

### 第 6 章 · Gaze Under Strain：VR 中眼动行为如何追踪晕动症进程（2610.32019，3.27 B，FULL）

- **赛道 / 场合**：感知与认知 / ACM VRST 2026（第 32 届 VR 软件与技术研讨会）
- **公告类型**：new
- **一句话结论**：19 人 20 分钟 VR 会话 + 反复不适评级的眼动行为分析：注视稳定性随不适加剧渐进退化且效应随时间增强；视觉探索仅有不适×时间交互；注视分配随时间系统偏移——晕动症并非均匀破坏眼动。
- **要解决的问题**：晕动症如何随暴露时长改变眼动行为（用户主动采样环境的方式）缺乏过程性证据；既有研究多为前后测快照式。
- **方法详解**：120 Hz 眼动采集（2880×1600 双目 HMD）；注视稳定性/视觉探索/注视分配三类构念；线性混合效应模型检验不适、暴露时长及其交互；与 SSQ 眼动症状收敛性分析。
- **实验与结果**：19 名参与者在逼真虚拟环境中导航 20 分钟，全程反复不适评级；H1 注视稳定性、H2 视觉探索、H3 注视分配、H4 与 SSQ 眼动症状收敛逐项检验。
- **创新点与贡献**：① 过程性（重复测量）视角揭示「不同眼动侧面响应不同、仅随时间可见」；② 为更敏感的晕动症检测提供行为基础。
- **局限与风险**：样本 19 人、单一场景/单设备；相关性分析非因果；机制解释待验证。
- **与文献库的关系**：与库内 2609.25422（Early Eye Gaze Dynamics and Cybersickness）互补——该文关注早期预测、本文关注进程动态；门① max Jaccard 0.050，非同质取代。
- **可复现性**：数据集释放情况摘要级未明示；方法与指标体系描述可复现。
- **行动建议**：晕动症检测研究应纳入时间维度与多侧面眼动指标；检测模型设计参考其「不适×时间交互」发现。

- **创新点与贡献**：① 把安慰剂对照概念引入沉浸式媒介干预评估；② 对 IVR 效应膨胀的方法论警示。
- **局限与风险**：证据等级 PARTIAL，正文细节（检索式、纳排标准、PRISMA 流程）未能核实；范围综述本身不量化效应。
