## 三、逐篇深度解读（按重要性降序）

### 第 1 章　CVQPG：基于二次相位高斯泼溅的全息图表示　（`arXiv:2609.11434`，渲染与显示，A 级，总分 3.85）

- **原文标题**：Hologram Representation via Quadratic Phase Gaussian Splatting
- **证据等级**：FULL（抓取链路 L0）；**状态**：CURRENT（方法当期，无落后标记）
- **赛道**：渲染与显示　**标签**：全息显示, 3D Gaussian Splatting, 近眼显示, 光场

**一句话结论**：提出复值二次相位高斯（CVQPG），为每个 2D 高斯基元叠加可学习的二次相位（曲率）轮廓，首次把 3D Gaussian Splatting 拓展到全息图/近眼显示域，在同等或更少参数预算下提升全息图保真度（PSNR / CVVDP）。

**要解决的问题**：全息显示（CGH/SLM）需要既能被高效优化、又满足衍射物理的可渲染图元。传统 3DGS 的实数颜色/不透明度不足以表达光场相位与焦深；既有全息表示多依赖体素或 NeRF，缺少可学习的'焦距/曲率'自由度。

**方法详解**：1) Complex-Valued Planar Gaussian：把基元表示为复值；2) Complex-Valued Quadratic Phase Gaussian（CVQPG）：在 2D 高斯包络上叠加二次相位项，其曲率 c 为可学习参数，使每个基元天然表达一个局部焦面/波前；3) Scale-Adaptive Curvature Control：按基元尺度自适应约束曲率范围；4) Hologram Rendering & Optimization：将 GS 场景投影到 SLM 平面并优化相位；5) Curvature Warm-Up：训练初期先稳定几何、再放开曲率，避免优化陷入坏局部。

**实验与结果**：在 RGB 20%/10% 与灰度 20%/10% 多档比特率下，与 Baseline / Baseline+ 比较 PSNR/SSIM/LPIPS/FLIP/CVVDP（全息感知质量指标）。例：RGB 20% 时 CVQPG PSNR 29.450 vs 29.265（+0.185），SSIM 0.8364 vs 0.8307，CVVDP 9.203 vs 9.168，且参数更少（30,720 vs Baseline+ 33,280）；灰度 10% 时 PSNR 28.398 vs 28.076（+0.322），CVVDP 8.658 vs 8.548（+0.109）。附录含全息显示原型、运行时/显存、逐场景结果与可视对比。

**创新点与贡献**：① 把相位/焦深显式建模进高斯基元，而非事后用相位检索；② 尺度自适应曲率，让近/远基元自然落在不同焦面；③ 与现有 3DGS 优化/渲染管线兼容，可复用其基础设施。

**局限与风险**：仍依赖 SLM/衍射物理近似；计算随基元数上升；仅在受控场景验证，未见大规模复杂场景或视频时序（4D 全息）评估。

**与文献库的关系**：新增——库内 304 篇此前 0 篇真正全息/波导/近眼显示硬件表示，直接填补'硬件类渲染'长期缺口。

**可复现性**：作者来自 UCL/Swansea（Kaan Akşit 团队，全息方向权威），方法描述完整，预期释出代码；需全息显示原型才能复现 CVVDP 类指标。

**行动建议**：列为'硬件类渲染'方向种子论文，后续追踪其与 waveguided / varifocal / Maxwellian 显示的整合，以及动态全息扩展。

### 第 2 章　LiteReality-Agent：面向可交互 3D 室内场景重建的智能体系统　（`arXiv:2610.01863`，重建与SLAM，A 级，总分 3.85）

- **原文标题**：LiteReality-Agent: An Agentic System for Interactable 3D Indoor Scene Reconstruction
- **证据等级**：FULL（抓取链路 L0）；**状态**：CURRENT（方法当期，无落后标记）
- **赛道**：重建与SLAM　**标签**：real-to-sim, 智能体, 室内重建, 可交互场景, 逆向图形

**一句话结论**：从 RGB-D 扫描 + 检测结果出发，经布局智能体、物体重建与场景程序生成'可仿真（simulation-ready）'的可交互室内场景，并用证据工具 + 质量门控保证几何与支撑合理性。

**要解决的问题**：真实到仿真（real-to-sim）需要既视觉逼真、又具物体级可交互性与物理合理性的室内场景；现有重建多产出静态网格，缺物体级可交互性与物理元数据，难以直接用于仿真/VR 内容。

**方法详解**：输入 RGB-D 扫描 + 检测；场景初始化（Layout Agent 推断房间布局关系、Object reconstruction 生成带物理属性的网格、scene program 组装层级场景图）；Agentic Authoring：证据工具（三级图像选择、渲染对比、墙体缝合与测量、创作 harness）、预算控制（budgeted control，限制大模型调用成本）、几何与支撑门控（geometric & support gates，校验悬浮/穿插）；Simulation-Ready Export 导出可直接导入仿真器的场景。

**实验与结果**：10 个场景 vs Fable 5.1（RGB-only / +Scan）、GPT-6（RGB-only / +Scan）。几何一致性与合理性（表3，611 帧深度 MAE + 近接触支撑率）：LiteReality-Agent ours SSIM 0.6105 / PSNR 14.129 / RMSE 0.2033 / LPIPS 0.5392，优于 Fable 5.1 RGB-only（0.5307/10.681/0.3008/0.7197）与 GPT-6 +Scan（0.6004/12.967/0.2323/0.6250）；含人类与智能体感知评估、扫描数据对通用智能体影响的消融。

**创新点与贡献**：① 把'逆向图形（inverse graphics）'做成带证据工具与质量门的智能体循环，而非一次性前馈；② 物体级物理属性与碰撞几何，直接对接仿真；③ 预算/门控使大模型智能体可控、可审计。

**局限与风险**：依赖检测与扫描质量；物体重建仍需重试/拒绝；未见大规模多房间或动态场景；仿真导出格式有限。

**与文献库的关系**：新增——库内已有 3DGS/重建工作，但缺'可交互、仿真就绪'的智能体闭环。

**可复现性**：系统描述详尽（附录 B 实现细节，含捕获数据、布局修复、物体重建与物理元数据），预期释出代码。

**行动建议**：XR 内容生成 / 数字孪生方向重点跟踪；可作为 VR 场景自动重建流水线的参照架构。

### 第 3 章　GS-PQM：面向压缩高斯泼溅的参数域质量度量　（`arXiv:2610.00195`，神经渲染，A 级，总分 3.85）

- **原文标题**：GS-PQM: A Parameter-Domain Quality Metric for Compressed Gaussian Splatting
- **证据等级**：FULL（抓取链路 L1）；**状态**：CURRENT（方法当期，无落后标记）
- **赛道**：神经渲染　**标签**：3D Gaussian Splatting, 压缩, 质量度量, 率失真

**一句话结论**：提出 GS-PQM，首个在 3D 高斯泼溅参数域直接运算的全参考质量度量：用支持向量回归（SVR）从一组参数域失真误差估计感知质量，免去渲染预设视角，且比 25 个图像/视频/点云度量更准确高效。

**要解决的问题**：GS 压缩后需要客观质量评估来比较压缩方法、指导编解码器开发；现有评估依赖图像/视频质量度量，需渲染预设视角，质量估计随视角选择而变，且不反映'参数域'失真。

**方法详解**：在 GS 参数域计算失真误差集合（位置/尺度/旋转/不透明度/球谐系数等逐参数比对），用 SVR 将该组误差映射为单一质量分数（全参考，需原始与失真后 GS）。

**实验与结果**：与 25 个图像、视频、点云质量度量比较，在人类主观评分相关性上更优；计算高效（无需渲染），且质量估计与所选渲染视角无关。

**创新点与贡献**：首次把 GS 质量评估从'渲染后图像域'移到'参数域'；视角无关；为 GS 编解码器的率失真（rate-distortion）优化提供可直接优化的目标。

**局限与风险**：全参考（需原始 GS）；SVR 训练数据的分布外泛化待验证；未覆盖动态/4DGS 与无参考场景。

**与文献库的关系**：新增——库内 GS 压缩论文众多，但缺统一、视角无关的质量度量。

**可复现性**：度量方法描述清晰，预期释出代码/模型。

**行动建议**：作为 GS 压缩方向的评估标准候选，跟进其是否被社区采纳为基准度量。

### 第 4 章　DSSR-3D：3D 高斯中视角依赖指代的解耦推理　（`arXiv:2610.00040`，神经渲染，B 级，总分 3.55）

- **原文标题**：DSSR-3D: Decoupled Reasoning for View-Dependent Referring in 3D Gaussians
- **证据等级**：FULL（抓取链路 L0）；**状态**：CURRENT（方法当期，无落后标记）
- **赛道**：神经渲染　**标签**：3D 指代分割, 视角依赖, 3D Gaussian Splatting, 空间推理

**一句话结论**：面向 3D 高斯中'视角依赖指代'的解耦推理框架：拆成姿态不变语义定位与姿态条件方向打分，再做语义-空间融合。

**要解决的问题**：3D 场景里'从某视角看到的那个红色杯子'这类视角依赖指代，传统 3D 语义分割忽略观察姿态与方向，无法区分'你面前的'与'背后的'同一类物体。

**方法详解**：3DGS 预备；问题公式化；流水线概览；Pose-Invariant Semantic Localization（姿态不变语义定位，先定位'是什么'）；Pose-Conditioned Directional Scoring（姿态条件方向打分，再评估'从哪看/朝向'）；Semantic-Spatial Fusion（语义-空间融合，综合语义与几何方向得到最终指代掩码）。

**实验与结果**：主结果 + 消融：与 Grounding SAM 的时间对比（推理效率）、锚点定位策略比较、空间衰减鲁棒性分析。量化增益未在摘要显式给出，需以正文为准。

**创新点与贡献**：显式解耦'是什么（语义）'与'从哪看（姿态/方向）'，比端到端指代更可解释、对视角变化更鲁棒。

**局限与风险**：量化增益未在摘要给出；依赖 3DGS 重建质量；未见大规模基准与跨数据集验证。

**与文献库的关系**：新增——补充库内 3D 指代/分割方向。

**可复现性**：方法描述中等，代码待确认。

**行动建议**：与空间计算/指代分割方向关联，关注其是否给出公开基准与代码。

### 第 5 章　TANGO：基于全身视觉-语言-动作模型的人形机器人杂乱环境导航　（`arXiv:2609.09158`，重建与SLAM，B 级，总分 3.3）

- **原文标题**：TANGO: Humanoid Navigation in Cluttered Environments with a Whole-Body Vision-Language-Action Model
- **证据等级**：FULL（抓取链路 L0）；**状态**：CURRENT（方法当期，无落后标记）
- **赛道**：重建与SLAM　**标签**：具身导航, VLA, 人形机器人, 视觉-语言-动作

**一句话结论**：全身视觉-语言-动作（VLA）模型用于人形机器人在杂乱/狭窄环境中的导航，结合仿真数据生成、真实部署与多指标评估。

**要解决的问题**：人形机器人在杂乱/狭窄环境导航需全身协调与避障；现有 VLN 多为离散动作或轮式平台，缺乏全身 VLA 在真实杂乱场景的遍历验证。

**方法详解**：问题公式化；Simulation Data Generation（仿真数据生成，构造杂乱训练环境）；TANGO Architecture & Training（视觉-语言-动作端到端）；Deployment（部署到真实人形机器人）。

**实验与结果**：VLN 性能、杂乱环境遍历性能、真实世界实验、消融研究；指标含 Navigation Error (NE)、Success Rate (SR)、Oracle SR (OSR)、SPL、Collision Rate (CR) 及真实碰撞数。

**创新点与贡献**：把 VLA 扩展到人形全身导航并做真实部署，强调'杂乱/狭窄'这一真实难点。

**局限与风险**：XR 相关度中等（偏机器人具身）；仿真到真实差距；未见与 XR / teleoperation 直接结合。

**与文献库的关系**：新增——导航/具身方向补充，对 XR 直接价值有限但提供空间智能参考。

**可复现性**：有项目主页（tango-vla.github.io），预期释出代码。

**行动建议**：作为空间导航/具身方向参考；若后续出现与 XR 头显/遥操作结合版本再重点跟进。
