## 三、逐篇深度解读

### 第 1 章 · HEIR：利用自我中心意图的人机交互数据集与基准（2611.17238，4.07 A，FULL）

- **赛道 / 场合**：感知与认知 / arXiv preprint（cs.RO）
- **公告类型**：replace（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-11-12）
- **一句话结论**：发布 HEIR：17 名被试、300 个 session、38.56 小时、1836 个 episode、6416 个导航-操作子任务，把人的自我中心视频+注视+语音与机器人四路视角+遥操作轨迹按请求级配对；加入人视角与注视后意图理解 Plan EM 从 63.51 升到 78.11，但四组件串联的真实机器人端到端 episode 成功率仅 18.52%。
- **要解决的问题**：现有具身智能数据与基准基本是任务中心的：机器人执行给定指令，人是环境中的旁观者甚至障碍物。要研究「以用户为中心」的具身智能，就需要同时记录人如何感知、表达、与机器人交互的数据。已有的 HRI 数据集大多在受控桌面场景、短时程、只覆盖单一交互环节；自我中心视觉虽已被用于机器人学习，但很少有人研究人视角的意图线索（注视、指向、措辞）如何补充机器人自身观测。缺的是这样一个资源：真实家庭环境、长时程连续 session、人机双视角配对、并且把人的意图与机器人的导航-操作执行在标注层面打通。
- **方法详解**：采集硬件：人侧用 Pupil Labs Neon 眼动眼镜，记录自我中心视频、语音与实测注视；机器人为 Galaxea R1 Lite（2025 版）移动双臂平台，记录四路视频（两个顶部相机 + 两个腕部相机）、双臂与夹爪动作、以及臂/夹爪/躯干/底盘的状态量；场景用 MID-360 LiDAR 扫描作几何基准。底盘平面轨迹由 MapAnything 的视觉估计与遥操作时的时间戳轮式里程计融合得到，再与机器人视角视频、导航标注逐帧对齐；用刚性安装在机器人顶部的 HTC VIVE Tracker 做验证。
数据组织是三层嵌套：session（一次连续的 household 交互）→ episode（一次自然语言请求及其后续执行）→ subtask（连续的导航段或操作段；一个操作子任务可含多个物体或双臂）。同一 session 内的 episode 共享持续变化的物理环境，因此后续请求可以指代先前交互涉及的物体或位置——这正是长时程指代与状态跟踪的来源。任务场景覆盖日常生活、厨房活动、家庭办公三类，把取物、递物、搬运、协同操作编排成请求序列；同一场景重复录制时目标不变，但物体位置在同一大致区域内变动、措辞与时序也可变。
标注协议：人工标注者先基于录像做时间定位标注，再用 VLM 辅助丰富、精炼为结构化指令与子任务描述；标注内容含任务意图、目标物体、目的地、名义计划（nominal plan）、以及实际实现的导航/操作阶段。
评测被组织成四级层次：① 人的意图理解——输入文本指令 / 机器人视角 / 人+机器人视角 / 加 center prior / 加注视，输出 Slot F1（指代槽位）、Location Accuracy（目标位置）、Plan EM（计划完全匹配）、RV F1（机器人视角可见性）；同时消融交互历史（真值历史 / 无历史 / 用前序预测作历史）。② 子任务规划——给定机器人观测、意图标注与执行历史，判断「继续/切换」并预测下一子任务类型，指标为 Acc、Macro-F1、Next Type、Core、Completion F1（Completion F1 用独立的 Codex 复核做一对一终态事实匹配）。③ 导航——NaVid / StreamVLN / InternVLA-N1 用 LoRA（rank 32、α 64、dropout 0.05）微调，预测动作与 STOP。④ 操作——DreamZero、π0-FAST、π0、π0.5、FastWAM、Lingbot-VLA2 微调，报首步与 action chunk 的关节 MSE、末端位置/旋转误差。真实机器人系统里 planner 采用事件触发而非定频查询：当底盘 20 s 内移动 <0.01 m 且所有关节偏离 <0.05 rad 时判定静止，才重新查询规划器。
- **实验与结果**：
    - 数据规模：17 名被试、300 个 session、20 类日常任务、38.56 小时、1836 个 episode、6416 个执行子任务；平均每 session 7.71 min、6.12 个 episode、每 episode 3.49 个子任务；60 个 session 留作测试（导航划分 202/38/60，操作划分 220/20/60）。
    - 轨迹验证：HTC VIVE Tracker 参考记录 16,323 帧，融合轨迹的平面位置 RMSE 为 8.55 cm；76 个 1 s 窗口（净位移≥5 cm）局部端点误差均值 1.63 cm、95 分位 3.50 cm；105 个窗口的方向余弦相似度中位数 0.9992。
    - 意图理解输入消融（Gemma-4-31B，Slot F1 / Loc Acc / Plan EM / RV F1）：纯文本 59.52 / 20.47 / 30.27 / N/A；仅机器人视角 71.22 / 54.86 / 63.51 / 60.33；人+机器人 74.85 / 71.13 / 72.43 / 57.71；加 center prior 74.91 / 71.39 / 75.14 / 61.61；加注视（完整）77.18 / 77.69 / 78.11 / 64.09。
    - 交互历史消融：真值历史 81.25 / 80.31 / 82.70 / 64.88；无历史 76.69 / 77.17 / 76.22 / 63.13；用前序预测作历史 77.89 / 79.27 / 81.08 / 63.51，说明跨请求的状态依赖真实存在。
    - 子任务规划：微调后决策准确率提升 25–37 点、下一子任务类型准确率提升 25–55 点；Qwen3.5-4B 综合最佳（Acc 83.46、Macro-F1 84.33、Core 61.06、Completion F1 36.85）；Cosmos3-Nano 预训练几乎恒判 Continue（Next Type 0.00，Core 0.00）。
    - 导航：InternVLA-N1 微调后动作准确率 90.69、Macro-F1 91.00、STOP F1 76.98（原模型 49.08 / 45.41 / 31.48）；在 32 个导航子任务上子任务级成功率 81.25%。
    - 操作：六个 VLA/WAM 微调后 Lingbot-VLA2 最优（首步 joint MSE 0.000316 rad²、EEF 位置 0.310 cm、旋转 0.539°）；20 个 pick-and-place 任务×3 次真机试验成功率 68.33%（Lingbot-VLA2）、60.00%（FastWAM）、36.67%（π0.5），排序与离线动作预测一致。
    - 端到端真机：27 个 episode（含纯导航、取送、纯操作、与人协同铺床单等），由 2 名换装过的原被试发出请求；四个组件串联后 episode 级成功率仅 18.52%，暴露出长时程误差累积。
- **创新点与贡献**：
    - 首次把「人的自我中心视频 + 实测注视 + 语音请求」与「机器人四路视角 + 遥操作导航-操作轨迹 + 底盘/臂状态」在同一时间轴上按请求级配对，并保持跨请求的连续 session，使长时程指代与状态变化可被建模。
    - 给出会话→请求→子任务的三层结构与对应的细粒度标注（意图、目标物、目的地、名义计划、实际阶段），把「人的意图」与「机器人的执行」在同一标注体系里连接起来。
    - 设计并验证了一整套四级层次化基准（意图理解 / 子任务规划 / 导航 / 操作）+ 真机闭环，使「人视角线索是否真的被用上」这一问句可被定量回答。
    - 用输入消融把「人视角」和「注视」的边际价值单独量化：人视角相对纯机器人视角把 Location Accuracy 从 54.86 提到 71.13，注视再提到 77.69，且优于 center prior 这一常用替代。
- **局限与风险**：
    - （作者承认）所有 session 在同一间布置房间录制，训练与测试共享同一房间，只评估家具重摆、物体位置、措辞与时序的变化，不评估未见环境泛化。
    - （作者承认）端到端真实机器人 episode 成功率仅 18.52%，组件误差在长时程下累积严重。
    - （作者承认）真机评测只有 27 个 episode、2 名被试，规模不足以支撑细粒度结论。
    - （我在正文发现）机器人侧轨迹由「拥有全局场景视角的独立操作员」用手柄遥操作产生，策略偏置与该操作员的习惯绑定，与发出请求的人的真实意图之间存在系统性错配，正文未讨论这一混杂。
    - （我在正文发现）意图标注是「人工先标 + VLM 辅助丰富」，但正文未报告标注者间一致性（IAA）或 VLM 介入前后的一致率，无法判断标签噪声。
    - （我在正文发现）底盘轨迹是 MapAnything + 轮速融合的估计值，8.55 cm 平面 RMSE 对精细操作参考偏大；导航成功率的评估因此部分依赖估计轨迹而非独立真值。
- **与文献库的关系**：与 HRI / 具身数据集的差别可以按表 1 的七个维度看：Gaze2Act（653 段）有人机双视角、注视、语音与意图标注，但不覆盖长时程、也不含导航+操作；HABIT（38,412 子任务）规模大但只有机器人视角、无注视无语音；HARMONIC（480）有注视但无语音、无意图标注、非长时程；NatSGLD（1,143）有语音与配对演示但非真实长时程交互；RoboVQA（61,153）是机器人视角的中时程视频-文本推理数据，缺人视角与注视；RoboCasa365（55,000）与 TEACh（11,176）在仿真中做长时程家务，缺真实人机共处；EDITH（280）有人机双视角+注视+语音，但既不覆盖长时程也不含导航+操作。HEIR 是表中唯一在七个维度上全部打勾的条目。与自我中心视觉用于机器人学习的前作（[60,13]）相比，本文不把自我中心视频当作额外的观测源去训策略，而是把注视当作「人在指什么」的直接证据，接到意图理解与规划上。
- **可复现性**：数据集已公开（HuggingFace: Anonymous-HEIR123/HEIR-Dataset）并有项目页 https://heir-project.github.io/，含演示视频。硬件为商用件（Pupil Labs Neon、Galaxea R1 Lite 2025、MID-360、HTC VIVE Tracker），采集协议、标注协议与质量审查流程在附录 B，轨迹重建与验证的数值（8.55 cm / 1.63 cm / 0.9992）可核对。训练超参给得较全：LoRA rank 32 / α 64 / dropout 0.05、冻结主干与视觉编码器、5 epochs、30 Hz 动作流、seed 42，批大小见 Table 10。主要不可复现项是真机闭环（需同款 R1 Lite 与同一布置房间）以及标注者的人工判断。
- **行动建议**：适合作为「以用户为中心」的 HRI 评测基座：四层接口（意图 / 规划 / 导航 / 操作）清晰，能分别定位失效环节，尤其适合检验「加了人视角与注视到底有没有被模型用上」这类消融问题。使用时要注意三点：单房间、仅 2 名评测被试、端到端 18.52%，因此它是诊断工具而非泛化基准，跨场景结论需另建数据。做意图理解时建议把 center prior 作为必须的对照——本文显示注视优于 center prior，但差距不大（Plan EM 78.11 vs 75.14），若不控这个对照容易高估注视的贡献。

### 第 2 章 · 缺失的触觉：感知并显示局部接触几何，让遥操作更接近人类灵巧性（2608.19372，4.01 A，FULL）

- **赛道 / 场合**：触觉与多模态 / arXiv preprint（cs.RO）
- **公告类型**：replace（公告日 2026-11-16，拉取日 2026-11-17；提交日 2026-08-19）
- **一句话结论**：把机器人指尖的局部接触几何用 32 像素电渗泵触觉显示器以 30 Hz 回显到操作者指尖，可使按键任务的完成时间缩短 46%、轨迹偏离人类直接操作的程度（DTW）降低 77%，peg-rolling 任务分别改善 33% 与 28%，并让在其演示上微调的 π0.5 策略成功率从 63.2% 升到 92.3%、执行快 29%。
- **要解决的问题**：遥操作是采集人类演示以训练自主策略的主要途径，但即便有双边力反馈，操作者的表现仍显著低于直接用手的水平：他们能感到交互力，却感受不到指导操作的局部接触图样，行为上类似指尖被麻醉——动作更慢、过冲更多、需要反复试探。已有触觉反馈工作多把空间分布的接触信号压缩成一维力线索（振动、电触觉、皮肤拉伸、整体倾斜平台），并用任务级指标（时间、成功率、力调节）评估，无法说明反馈如何改变运动的「自然度」。要回答这个问题，需要既能高分辨率感知又能高分辨率显示的硬件，以及能把遥操作轨迹与直接用手的轨迹做逐点比较的度量。
- **方法详解**：硬件为自制 2-DoF leader-follower：水平/垂直两轴各由 Maxon EC 45 Flat 无刷电机经绳索传动驱动（减速比 33:1 与 30:1），位置由 14-bit 电容编码器 AMT212B-V 读取，每轴一片 Teensy 4.1 运行 SimpleFOC 做磁场定向换相，双边控制器以 10 kHz 运行以提供动觉力反馈。机器人「手指」是 GelSight Mini 视觉触觉传感器（30 fps，240×320 图像）；操作者指尖下是 Fluid Reality 的 32 像素触觉形状显示器，基于嵌入式电渗泵（EEOP）：像素按 3 mm 六边形排布、直径 1.8 mm、最大空载位移约 1 mm、密度 13 actuators/cm²，30 Hz 更新，加压后 200 ms 达 80% 位移、150 ms 复位。
传感-显示映射：初始化时存参考帧 I0，之后每帧做差分 I_d=I−I_0 并转灰度，3×3 高斯平滑；若 ‖I_d‖_F 低于噪声底 T_noise_floor 则全不充气；否则用 Otsu 自适应直方图阈值二值化。每个显示像素 i 对应图像坐标 (x_i,y_i)，若以该点为中心的 2r×2r 窗口内强度和范数超过接触阈值 T_contact，则该像素充气。四个实验条件据此定义：Off 全不充气；1D 任一像素触发即全体同相充气；2D 上/下半区各自同相；32D 仅触发像素充气。
行为学设计：每个条件 12 trials，共 48 trials，条件顺序随机，所有条件都保留动觉力反馈。按键任务要求无视觉地把手指移到间距 1 cm 的两枚按键之一并只按下目标键（球轴承键，需 0.25 mm 位移、2.7 N 峰值力），按键位置在两次试验间沿前后方向变动以防记忆。peg-rolling 任务要求把钢制齿条 peg 向前滚到硬限位再滚回起点，任务由一系列前滚行程与「loopback」复位组成。每个被试在正式试验前被蒙眼、把食指绑在跟随器末端直接用手指完成任务若干次，作为「直接操作」基线轨迹。
度量与统计：主指标是遥操作轨迹与该被试直接操作轨迹之间的二维 DTW 距离（按被试内均值归一化），统计用线性混合效应模型（Feedback Condition 为固定效应、Participant 为随机截距）做 ANOVA，再用 Holm-Bonferroni 校正的成对系数检验；方差比较用单尾 Wilcoxon 符号秩检验，跨操作者汇总数据用 Mann-Whitney U。策略侧用 π0.5 微调：输入触觉图像 + 外部相机 + 跟随器关节角 + 固定语言提示，输出 50 步 leader 位置 chunk，3000 步、batch 32、AdamW、峰值学习率 2.5e-5 余弦衰减。
- **实验与结果**：
    - 按键辨别任务：12 名被试（19–37 岁，7 男 5 女，平均 28.6 岁；5 人无遥操作经验、6 人有一些、1 人丰富），每人 48 trials（4 条件×12），两键间距 1 cm、键径 6.35 mm，触发需 0.25 mm 位移与 2.7 N 峰值力，全程无视觉、按键位置逐 trial 变动。
    - 32D 相对 Off / 1D / 2D 显著降低平均过冲距离（p<0.001，表 S1）与 switchback 次数（p≤0.007，表 S2）。
    - DTW 自然度：任一触觉反馈都显著优于 Off（p<0.001）；但只有 32D 相对 1D 有进一步提升（p=0.014，表 S3）；32D 的被试内 DTW 标准差显著低于 2D（p=0.013）、1D 与 Off（p<0.001）。
    - 按键任务完成时间：32D 相对 Off 平均快 46%、DTW 偏差低 77%；但 32D 与 1D 的时间差异经校正后不显著（p=0.025，p_adj=0.074），32D 与 2D 在自然度（p=0.244）与速度（p=0.237）上亦不显著，作者归因于按键尺寸相对 32 像素过小（feature size）。
    - peg-rolling 任务：10 名被试（19–31 岁，平均 25.9 岁，全右手），每人 48 trials；32D 显著减少滑脱（p≤0.039）、加长单次行程（p≤0.004）、减少行程数（p≤0.014）；32D 相对 Off 完成时间快 33%、DTW 偏差低 28%。
    - 多操作者数据一致性：把同一条件下所有被试轨迹汇总为「多操作者数据集」后，32D 的 trial 间 DTW 距离显著低于其它三条件（p<0.001，表 S18/S19，两个任务均成立）；被试内 trial 间 DTW 亦显著更低（p≤0.003）。
    - 主观负荷：NASA-TLX 子集 4 题（心理需求、难度、挫败感、自评表现，7 点量表）显示心理需求随反馈分辨率提高而单调下降，认知负荷降低与轨迹自然度提升同步出现。
    - 策略验证：用 Off 与 32D 的 peg 前滚演示分别微调 π0.5；32D 策略 13 次尝试取得 12 次成功（92.3%），Off 策略需 19 次（63.2%）；32D 策略平均完成快 29%、偏离人类行为少 31%（p<0.001）。
- **创新点与贡献**：
    - 首个把机器人指尖的局部接触几何实时（30 Hz）映射到人手尖的空间分布式触觉显示上的遥操作系统：32 像素、3 mm 间距、1 mm 行程的 EEOP 显示突破了针阵列「高分辨率必然笨重」的取舍。
    - 提出以 DTW 到「直接用手指同一任务」的距离作为自然度度量，把评价从任务级（时间/成功率）推进到运动学层面，从而分离出「速度」与「自然度」两个可独立改善的维度。
    - 用 Off/1D/2D/32D 四级空间保真度做受控消融，量化了「分辨率」这一连续设计变量的边际收益，并指出其依赖任务的空间信息需求与动觉冗余。
    - 把人类侧收益传导到机器侧：证明在 32D 演示上微调的 π0.5 在成功率、速度、类人度与一致性上同时优于 Off 演示训练的策略，打通「触觉回显 → 演示质量 → 策略质量」的因果链。
- **局限与风险**：
    - （作者承认）仅 2-DoF 单指平台与两个任务，未覆盖高自由度、多指、更复杂灵巧操作，外部效度有限。
    - （作者承认）触觉显示只支持二值驱动，未验证可变压深（indentation depth）是否带来额外收益。
    - （作者承认）所有条件都叠加了动觉力反馈，未验证去除动觉后收益是否保持；也未测试振动触觉等互补模态。
    - （我在正文发现）按键任务中 32D 相对 2D 在自然度与速度上均不显著，「分辨率越高越好」并不普遍成立；作者自己提出 8D 分区可能更优，但这只是事后推测，未做实验。
    - （我在正文发现）映射阈值 T_noise_floor、T_contact 与窗口半径 r 的具体取值未在正文报告（称见 Supplementary Methods），外部无法精确复算接触判定。
    - （我在正文发现）策略实验每条件仅 12 次成功试验，92.3% vs 63.2% 的置信区间很宽；且只微调了 peg 前滚一个阶段，未验证整段长时程任务。
- **与文献库的关系**：与使用低维触觉通道渲染力的前作相比，差异是信号维度而非仅仅器件：指尖均匀倾斜平台（sensory subtraction 系列，[24–26]）与振动/电触觉（[27–29]）、皮肤拉伸显示（[30–31]）都把空间分布的接触压成一维力线索，本文保留空间结构。与针阵列（[49]）相比，本文用 EEOP（[50,51]）与介电弹性体（[52,53]）路线把 32 个像素、3 mm 间距做到可集成到遥操作台，逼近指尖约 2 mm 的两点辨别阈（[54]）。与视觉触觉传感的自主操作工作（[39–46]）相比，那些工作把高分辨率触觉只喂给策略，本文第一次把它回显给人。评价方法上借鉴了手术技能评估中用运动学指标衡量灵巧性的传统（[33–38]），但把参照系换成了「同一被试直接用手指」的轨迹，并用 DTW（[55]）处理时间错位。策略侧接的是 π0.5（[58]），并呼应了「演示分布越紧凑越利于学习」的结论（[56,57]）。
- **可复现性**：硬件全部为可采购件：GelSight Mini、Fluid Reality 32 像素 EEOP 显示、Maxon EC 45 Flat、AMT212B-V 编码器、Teensy 4.1、BOOSTXL-DRV8301，论文给了减速比、编码器位数、控制频率与显示器的几何/时序参数，机械与电控可按文中参数重搭。算法侧只给了流程（差分、Otsu、窗口范数阈值），关键阈值 T_noise_floor / T_contact / r 未在正文给出，需查补充材料。统计流程（LME 随机截距 + ANOVA + Holm-Bonferroni、单尾 Wilcoxon、Mann-Whitney U）写得足够细，可照做。代码与原始数据未公开（「all data needed... in the main text or Supplementary Materials」），复现成本主要在硬件与 22 名被试的行为实验。
- **行动建议**：对做遥操作数据采集的团队，最直接的动作是把「触觉回显分辨率」提为采集端的设计变量，并用 DTW-to-human 作为数据质量指标，而不只看成功率与耗时；建议在上手前先做 1D 与 32D 的 A/B，成本低而信息量大。选型时注意两点：任务若含精细多点辨别（如按键），空间分辨率收益最大；若动觉已携带大部分信息（如 peg 滚动），1D 可能完全等价于 Off，别浪费通道。若 32 像素显示太贵，作者建议的 8D 分区（按行分区）是值得先试的折中。

### 第 3 章 · 基于栅格的子图拼接：同时优化全局占据地图与局部子图坐标的高效算法（2501.12764，3.87 A，FULL）

- **赛道 / 场合**：重建与SLAM / arXiv preprint（cs.RO）
- **公告类型**：replace（公告日 2026-11-16，拉取日 2026-11-17；提交日 2025-01-22）
- **一句话结论**：把栅格子图拼接写成同时优化全局占据图与子图坐标的 NLLS，并证明 GN 中位姿增量与地图占据值解耦，从而可用 pose-only GN 求解；在 2 个仿真 + 6 个实数据上误差比 Cartographer / SLAM Toolbox 小 3–12 倍，拼接仅需 0.6–5.2 s（Occupancy-SLAM 需 17138–27452 s 且在大规模场景直接失败）。
- **要解决的问题**：2D 激光占据栅格 SLAM 的主流做法是两步法：先用位姿图优化机器人位姿，再把优化后的位姿当作真值去建图（Cartographer、SLAM Toolbox 均如此），建图阶段丢弃了位姿不确定性，解是次优的。Occupancy-SLAM 证明同时优化位姿与占据图能显著提精度，但它把全部机器人位姿与全部栅格一起批优化，复杂度随轨迹长度与地图尺寸增长，在百米级场景既慢又易落入局部极小。因此需要一种在大尺度环境下既保留「位姿-地图联合优化」精度、又把计算量压到可接受范围的方案；子图拼接是自然选择，但已有的栅格类子图拼接只优化位姿、不优化栅格图。
- **方法详解**：输入是 n+1 个局部占据栅格子图 L={L0,…,Ln}，占据值以 log-odds 表示；与 Cartographer 不同，本文不保留子图内所有机器人位姿，只保留子图坐标系 X_i^r=[t_i^T, θ_i]^T∈SE(2)，并把第 0 个子图固定为全局坐标系。状态向量为 X=[(X^r)^T, M^T]^T，M 含 l_w×l_h 个全局栅格。全局栅格 m_j 通过 p_im_j=R_i(m_j·s−t_i) 投影到第 i 个子图的连续坐标（s 为栅格分辨率），目标函数取 f(X)=Σ_{i=0}^{n}Σ_{j∈obs_i}‖ω_im_j·M(m_j)−L_i(p_im_j)‖²，其中 L_i(·) 用双线性插值在离散子图上取值，obs_i 是被投影到子图 i 的全局栅格索引集合。权重 ω_im_j=N^{L_i}(p_im_j)/N^M(m_j) 用于消除各子图与全局图观测次数不同造成的 log-odds 尺度失配：N^{L_i} 为子图 hit map（每格观测计数），N^M 是把所有子图 hit map 按 {X_i^r} 投影叠加得到的全局 hit map，因此 ω 本身是位姿的函数而非常量。
核心是一条关于高斯-牛顿迭代的独立性命题：把雅可比分块为 J=[J_r J_M] 后，J_M 的非零元素恰为 ω_im_j，只依赖位姿（hit map 与占据值无关）；J_r 由投影关系与目标函数也同样的与 M 无关。对法方程做 Schur 补消去 Δ^M，得 (U−W V^{-1} W^T)Δ^r=b^r−W V^{-1} b^M；再把残差写成 ‖J_M M−H(X^r)‖² 的形式后，交叉项恒为零，故 Δ^r 与 M 完全解耦。据此提出的 pose-only GN 每步只解维度约 3n 的稀疏系统（满 GN 需 3n+l_w·l_h），位姿收敛后再用闭式 M̂=V^{-1} J_M H(X̂^r) 一次性恢复全局占据图；每次迭代后需按新位姿重算 N^M，因为 J_M 依赖它。作者强调：虽然迭代中不更新地图，但地图约束已通过 J_M 隐式进入位姿优化，因此与 pose-graph optimization 有本质区别。相较 Zhao 等在点特征 SLAM 中给出的同类独立性证明，这里既不需要已知数据关联，也不需要各向同性观测噪声假设。
- **实验与结果**：
    - 仿真设置：两个 50 m×50 m 环境（Simulation 1 为 3640 帧 / 117 s，Simulation 2 为 2680 帧 / 83 s），每帧 1081 束激光、−135°~135°（模拟 Hokuyo UTM-30LX），每束加 σ=0.02 m 零均值高斯噪声，里程计噪声 σ=0.04 m / 0.003 rad，每个环境生成 5 组不同噪声数据。
    - Simulation 1 位姿误差：本文 MAE 平移 0.0453 m / 旋转 0.0012 rad；Cartographer 0.2534 m / 0.0139 rad，SLAM Toolbox 0.1465 m / 0.0134 rad，Occupancy-SLAM 0.0238 m / 0.0008 rad；相对前两个 SOTA 基线误差小约 3–12 倍。
    - Simulation 2 位姿误差：本文 MAE 0.0151 m / 0.0011 rad，优于 Cartographer（0.1426 m / 0.0068 rad）与 SLAM Toolbox（0.0493 m / 0.0085 rad），仍略逊于 Occupancy-SLAM（0.0070 m / 0.0006 rad）。
    - 占据图质量（10 个仿真数据集，AUC / precision）：Simulation 1 本文 0.9751 / 0.9867，Cartographer 0.9088 / 0.9565，SLAM Toolbox 0.9550 / 0.9749，Occupancy-SLAM 0.9997 / 0.9973；Simulation 2 本文 AUC 0.9949 已接近 Occupancy-SLAM 的 0.9966。
    - 实数据：6 个公开 2D 激光数据集（Car Park 1642 帧、C5 3870 帧、Museum b0 1G 5522 帧、Museum b0 EG 22650 帧、Museum b2 51833 帧、C3 24402 帧），最大 250 m×200 m；与 Cartographer 相比物体边界更清晰，C3 右侧墙面更接近直线。
    - 拼接耗时（Intel Core i7-1370P）：三个常规尺度数据集 0.6–0.8 s，三个大规模数据集 1.7–5.2 s；含子图构建的总耗时 113.6–1250.4 s，多数数据集快于 Cartographer（152–1424 s），但在 C3 上 742.2 s 慢于 Cartographer 的 610 s。
    - 对比 full GN 的单次迭代加速（迭代次数相同）：Car Park 0.062 vs 0.174 s（281%）、b0 EG 0.157 vs 0.419 s（267%）、C5 0.036 vs 0.058 s（161%），六个数据集加速 161%–281%。
    - Occupancy-SLAM 在 b2、b0 EG、C3 三个大规模数据集上直接失败；在仿真中其耗时约为本文子图拼接的 20 倍，常规实数据上为 17138–27452 s。
- **创新点与贡献**：
    - 首次在栅格类子图拼接问题中同时把全局占据图与局部子图坐标系作为优化变量，而不是只对子图位姿做位姿图优化。
    - 证明了一条独立性命题：GN 每步的位姿增量与全局占据图的占据值无关，且证明不依赖已知数据关联与各向同性噪声假设（比点特征 SLAM 的同类结论更一般）。
    - 由此构造与 full GN 等价的 pose-only GN：每步线性系统维度只与子图数有关，位姿收敛后用闭式解一次性恢复全局占据图。
    - 把「位姿-地图联合优化」的精度带到百米级 2D 场景（250 m×200 m），同时把拼接耗时压到秒级，填补了 Occupancy-SLAM 无法规模化、Cartographer 无法联合优化栅格的中间空白。
- **局限与风险**：
    - （作者承认）实验只用了 3–10 个局部子图，最优子图数量与「如何划分激光数据以得到高质量子图」均未系统研究，明确留作未来工作。
    - （作者承认）方法仅限 2D 栅格，扩展到 3D 栅格 SLAM 留作未来工作。
    - （我在正文发现）精度仍低于 Occupancy-SLAM（Simulation 1 MAE 0.0453 vs 0.0238 m），「等价于 full GN」 只保证与本文 NLLS 目标一致，不等于达到全批优化的精度上限。
    - （我在正文发现）实数据无真值，定量精度只在 2 个仿真环境 ×5 组噪声上评估；6 个实数据仅做定性/可视化对比，没有位姿误差数字。
    - （我在正文发现）总耗时仍含子图构建（如 C3 737 s），所以「比 Cartographer 快」在 C3 上并不成立（742.2 vs 610 s），摘要级的效率结论需按数据集限定。
    - （我在正文发现）未讨论动态障碍、未输出位姿/地图不确定性（协方差），且全局图分辨率 s 固定为单一值，缺少多分辨率消融。
- **与文献库的关系**：与 Cartographer（Hess et al., ICRA 2016）和 SLAM Toolbox（Macenski & Jambrecic, JOSS 2021）的关键差异在于：这两者都是两步法，先用位姿图（稀疏位姿调整或 Ceres）优化位姿，再以位姿为真值建栅格图，建图阶段不考虑位姿不确定性；本文把栅格图本身放进目标函数。与 Occupancy-SLAM（Zhao, Wang & Huang, RSS 2022）相比，本文不再批优化全部机器人位姿与全部栅格，而是先把数据切成子图、只优化子图坐标系，从而把状态维度从「位姿数 + 栅格数」压到「子图数 + 栅格数」，使 250 m×200 m 场景可解。与 Linear SLAM（Zhao et al., IROS 2013）及点/面特征子图拼接（Wang et al., RAS 2019）相比，那些方法优化的是特征地图与局部坐标系，本文处理的是占据栅格这一非参数化表示，因而需要额外的 hit-map 加权来对齐 log-odds 尺度。理论侧最近的前作是 Zhao, Mao & Huang（RSS 2021）在点特征 SLAM 中证明「位姿增量与地图无关」，本文把该性质推广到栅格子图拼接，并去掉了已知数据关联与各向同性噪声两个前提。
- **可复现性**：代码已开源在 https://github.com/WANGYINGYU/Occupancy-Joining。实数据为公开 2D 激光数据集（Deutsches Museum b0 1G / b0 EG / b2 来自 Cartographer 配套数据，Car Park 与 C5 为社区常用集），仿真数据由作者按表 I 参数自建（1081 束、±135°、σ=0.02 m）。复现的前置依赖是先用 Occupancy-SLAM 生成局部子图与对应 hit map（本文所有实验均如此），这一步不在本仓库内，是主要门槛。耗时基线为 i7-1370P，更换硬件后表 IV / 表 V 的绝对秒数不可直接对比，但加速比可复现。
- **行动建议**：可直接作为 2D 栅格 SLAM 的后端拼接层，替换 Cartographer / SLAM Toolbox 的 pose-graph 拼接环节：保持秒级拼接的同时把栅格一致性纳入优化，适合仓储、室内平面导航图的离线重建或大尺度回环后的地图重铸。工程落地的关键是先有高质量子图与 hit map，建议直接复用 Occupancy-SLAM 前端；若已有 Cartographer 部署，则需额外导出每子图 hit map 才能用本方法。短期不建议用于需要在线增量输出的场景（本文是批处理），也不建议直接套到 3D。
