EgoAlign connects a pretrained point encoder to an LLM.
The encoder compresses the transformed cloud into M ≪ N M\ll N semantic tokens { 𝐳 j } j = 1 M \{\mathbf{z}_{j}\}_{j=1}^{M} .
Although the input cloud is expressed in the agent-centric frame, the compressed semantic tokens do not explicitly preserve the metric location of their supporting points. This information can be attenuated by point-cloud encoders designed to learn robust, translation and rotation invariant geometric representations ( Wu et al., 2025 ; Zhang et al., 2026 ) , yet it is essential for reasoning about the scene relative to the agent.
To address this problem, we infuse metric coordinates explicitly.
For token j j , we track the encoder’s pooling assignments to obtain ℐ j \mathcal{I}_{j} , the original input points contributing to that token.
We mean-pool the coordinates and colors of the points in ℐ j \mathcal{I}_{j} , then project them alongside the semantic feature into the LLM’s embedding space:
𝐞 j = 1 3 ​ [ f sem ​ ( 𝐳 j ) + f coord ​ ( avg i ∈ ℐ j 𝐩 ~ i ) + f rgb ​ ( avg i ∈ ℐ j 𝐜 i ) ] . \mathbf{e}_{j}=\frac{1}{\sqrt{3}}\left[f_{\mathrm{sem}}(\mathbf{z}_{j})+f_{\mathrm{coord}}\!\left(\operatorname*{avg}_{i\in\mathcal{I}_{j}}\widetilde{\mathbf{p}}_{i}\right)+f_{\mathrm{rgb}}\!\left(\operatorname*{avg}_{i\in\mathcal{I}_{j}}\mathbf{c}_{i}\right)\right].

We scale the sum by 1 / 3 1/\sqrt{3} to approximately preserve the feature variance when combining three independently projected branches.
The fused point cloud embeddings are then processed by the LLM’s attention layers together with the regular text embeddings.
