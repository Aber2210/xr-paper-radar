Affiliation:   Westlake University In this work, we present CoTL, a framework for learning a compact, view-scalable scene representation directly from unposed multi-view images via 3D Gaussian reconstruction. By compressing multi-view inputs into a concise set of view-wise tokens, CoTL establishes an explicit information bottleneck: the scene memory serves as the sole condition for a set of scene-agnostic queries, forcing it to retain only the essential scene tokens required for high-fidelity geometric and appearance reconstruction.
