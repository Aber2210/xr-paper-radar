III-F Hierarchical Scene Graph Construction III-A Overall
As illustrated in
Figure  2 , we employ SAM3-generated  [ 6 ] masks from posed RGB images as supervision, which may contain noisy
labels and inconsistent instance IDs across frames. We first augment the
Gaussians with semantic and instance features (Section  III-B ).
We jointly optimize the appearance, semantic, and instance branches. The prototype-based semantic learning predicts semantic categories (Section  III-C ),
while the association-based instance learning aligns view-local
instance masks with persistent instance identities
(Section  III-D ). The joint supervision strategy is
described (Section  III-E ). During panoptic decoding, stuff
predictions are obtained from the semantic branch, whereas object predictions
combine semantic and instance. The resulting
panoptic Gaussian representation supports novel-view 2D panoptic segmentation
and direct Gaussian-level panoptic decoding. Finally, the semantic-aware
hierarchical scene graph construction module organizes the learned panoptic
Gaussians into a floor–room–stuff–object hierarchy with containment
and spatial relations (Section  III-F ).

IV-A Experimental Setup
Datasets.
We evaluate on two public datasets,
ScanNet++  [ 31 ] and
Replica  [ 32 ] . In addition, we release NaviGS ,
a real-world dataset comprising RGB and semantic scenes. NaviGS is acquired
using two fisheye cameras and a handheld LiDAR device. LiDAR-assisted
acquisition provides accurate camera poses and a sparse point cloud for
Gaussian initialization. Both scene collections provide 3DGS models, meshes,
RGB, camera poses, and depth; semantic scenes additionally include
scene graphs.
To evaluate hierarchical scene graph construction, we select multi-room layouts from Replica and NaviGS that support of the floor-room-stuff-object hierarchy. Metrics.
Scene graph performance is evaluated by floor-, room-, and object-level
accuracy. All compared methods use the same SAM3-generated segmentation masks
as supervision. Since OP3DSG, BBQ, and ConceptGraphs do not support
floor-room recognition, they are evaluated only at the object level. For
KeySG, HOV-SG, and PanoGraphGS, floor, room, and object recognition are
manually verified under a hierarchical criterion: a room is correct only when
its floor and room identities and semantic category are correctly identified,
while an object is correct only when its floor, room, and object identities
are all correct. Panoptic segmentation is evaluated using mIoU for region
