Image differences mix physical changes with rendering artifacts and illumination shifts.
Our method uses generalised Bayesian inference to interpret these responses and accumulate change evidence.
For query image I t I_{t} , current-view evidence C t C_{t} is constructed from the initial difference response R t 0 R_{t}^{0} , while historical support H t H_{t} summarizes evidence from earlier observations in the query view.
We formulate change prediction as a generalised Bayesian update ( Bissiri et al., 2016 ) : current and historical evidence modify the prior odds of change, determined by an effective pixel prior π \pi .

However, the prior is unknown beforehand, and constructing C t C_{t} and H t H_{t} requires models that interpret image differences as change evidence and determine how this evidence contributes to history.
To obtain these components, we fit the effective pixel prior π \pi and four scene-specific models using supervision from automatic reference 3DGS edits and unchanged reference observations.
Of these four models, the response suppressor 𝒯 \mathcal{T} and log-likelihood-ratio mapping ℓ img \ell_{\mathrm{img}} construct C t C_{t} , while the unchanged-response model ( μ g , τ g 2 , c ) (\mu_{g},\tau_{g}^{2},c) supplies statistics for closed-form evidence accumulation underlying H t H_{t} .
The contour filter ℓ contour \ell_{\mathrm{contour}} supports subsequent mask refinement.
All five components are fitted offline and remain fixed during online inference.
Section  4.2 describes how they are used for prediction, history accumulation, and mask refinement (Figure  1 ), taking their fitted parameters as given.
Section  4.3 explains how automatic reference edits and unchanged observations are used to fit them (Figure  2 ).
4.2 Causal Online Change Detection
For each incoming query image I t I_{t} , we construct current-view evidence C t C_{t} , which supports both prediction and history accumulation. For prediction, C t C_{t} combines with historical support H t H_{t} from earlier frames; for accumulation, it provides the Gaussian responses used to compute local Bayes factors. The updated history is used only by subsequent queries.

Continuous sequence timing.
After initialization, synchronized wall-clock timing starts before the first query is retrieved and ends when the final mask is ready. Input prefetching starts during initialization for both methods; remaining input waits and all inter-frame work are included. O-SCD also waits for GPU work to complete at its stage synchronization points; these waits are included in the timed sequence. Mask export and metric evaluation occur outside timing. FPS is the total number of processed frames divided by summed sequence duration: 1,000 frames across two runs for each of our output modes and 500 frames for O-SCD(O). The pixel runs achieve 27.88 27.88 and 27.98 27.98  FPS; the full runs achieve 17.15 17.15 and 17.19 17.19  FPS.
Batch refinement timing.
O-SCD(R) first processes the query images sequentially, then jointly refines its change representation using all views and renders the final masks. Its timing covers this complete procedure, from the first input retrieval to the last refined mask, excluding initialization and file export.
