The system integrates a mask-guided visual perception frontend with a continuous kinematic factor graph that regularizes updates and generates multi-hypothesis pose forecasts. To ensure robustness against rapid dynamics, the pipeline routes refined candidates through a pose scoring module. If catastrophic tracking loss occurs, the failure-aware self-recovery module synthesizes a virtual CAD rendering and establishes 3D-2D correspondences with the incoming RGB frame, seamlessly healing the trajectory.
We present RoPT, a robust framework designed for continuous 6-DoF object pose tracking in monocular RGB-D video sequences.
Serving as a critical perception module for robotic manipulation, our pipeline explicitly prioritizes robustness against agile, high-acceleration inter-frame motions.
This architectural focus directly addresses a fundamental vulnerability in existing trackers, which frequently suffer from catastrophic tracking loss during dynamic robot-object interactions.
Given an input RGB-D video sequence 𝒱 = { I t } t = 1 N \mathcal{V}=\{I_{t}\}_{t=1}^{N} and a known object 3D CAD model ℳ \mathcal{M} , our objective is to sequentially estimate the trajectory of poses 𝒯 = { P t } t = 1 N \mathcal{T}=\{P_{t}\}_{t=1}^{N} .
Each pose P t ∈ SE ​ ( 3 ) P_{t}\in\text{SE}(3) represents the rigid transformation from the object-centric coordinate frame to the camera coordinate frame.
The system must infer these transformations in a sequential, online manner while simultaneously enforcing both temporal kinematics and geometric consistency.
The RoPT framework comprises five components that function in tandem to ensure tracking stability.
First, a baseline, render-and-compare pose refinement module iteratively aligns the CAD model to the current observation, starting from the previous frame’s estimate.
Second, a mask tracking module provides robust 2D segmentation that remains reliable under occlusion and fast motion, constraining the refinement search space.
Third, a kinematic factor graph maintains the object’s SE(3) state with a constant-velocity prior, enabling multi-hypothesis generation and best-pose selection via a spread-gate scorer.
Fourth, a global lighting optimization fits a spherical harmonics appearance model to bridge the domain gap between synthetic CAD rendering and real-world imagery.
Fifth, a self-recovery module detects tracking failures and triggers feature-based re-localization to re-anchor the tracker before drift becomes irrecoverable.
These five components form a closed loop to deliver robust 6-DoF tracking across challenging conditions.

【结论/局限】
 In this work, we presented RoPT, a resilient, closed-loop 6-DoF object pose tracking framework engineered to withstand rapid, high-acceleration dynamics in embodied systems. By tightly integrating visual perception with a continuous kinematic factor graph and a failure-aware active self-recovery module, RoPT systematically bridges the gap between fragile open-loop monocular pipelines and the rigorous demands of real-world robotic manipulation. .
