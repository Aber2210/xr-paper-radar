5.1 Baseline Models 5.1 Baseline Models
We compare ACTS with two action-conditioned visuo-tactile world
models, training both from scratch on React.
Among recent visuo-tactile world models, only
ContactWorld  ( Zhang et al., 2026 ) and
Dream-Tac  ( Lou et al., 2026 ) release training code;
VT-WM  ( Higuera et al., 2026 ) ,
OmniVTA  ( Zheng et al., 2026 ) , ViTacWorld  ( Huang et al., 2026b ) ,
FeelWorld  ( Ma et al., 2026 ) , and VT-WAM  ( Tian et al., 2026 ) had
not released model code at the time of writing.
ContactWorld is a decoder-free JEPA-style  ( Assran et al., 2023 ) model, which we
train with its official code, adapted to our observation and action
spaces.
VT-WM-style is our reimplementation of
VT-WM, preserving its
autoregressive latent predictor and action conditioning while
adapting its interfaces to our data.
We intended to compare with Dream-Tac but could not adapt it to
React: it generates actions jointly with future observations instead
of conditioning on given actions, and its released code expects a
robot camera layout and proprioception that React lacks.   per object are shown in bold.
Task Metrics Metrics
We compare ACTS with baseline models on future-frame prediction
using held-out human recordings and zero-shot transfer to robot episodes.
Video Generation Metrics.
Given eight observed frames (one for ContactWorld, its native context)
and recorded actions, each model predicts the next eight frames (0.53 s at 15 fps).
We evaluate only predicted frames, separately for the scene view,
two wrist cameras, and two GelSight streams.
We report PSNR for pixel-level fidelity,
SSIM  ( Wang et al., 2004 ) for structural similarity, and
LPIPS  ( Zhang et al., 2018 ) for perceptual distance.
Higher PSNR and SSIM and lower LPIPS indicate better results.
For both human and robot data, reference frames are decoded from
ground-truth latents using the frozen RGB and tactile VAEs.
All comparisons use identical test windows and seeds.
Appendix  B provides further details.
Robot Experiments.
We apply models trained on human data to held-out robot episodes
(Sec.  3 ) without fine-tuning.
Robot recordings are normalized to match the human data’s tactile
color and illumination and wrist-camera tone.
Actions are constructed from OptiTrack sensor poses and
GelSight-estimated force following Sec.  4.2 ,
as for the human data, rather than from robot joint readings.
Per-step translations from forward kinematics differ from the
OptiTrack ones by a median of 0.33 mm, about half the median
per-step motion, so OptiTrack keeps robot actions consistent with
the human training data
(Appendix  B ).
We use the same eight-frame observation and prediction protocol
on windows in which contact is made or broken, and report the same
