4.2 Participant Feedback Our techniques are implemented in Unity game engine 2021.3.16f1.
The techniques utilise forestry point clouds in a .las [ 28 ] file containing a high resolution point cloud of the forest plot.
For the purposes of our study, a LiDAR scan of a production Pinus radiata 1 1
1
Data is publicly available from \url https://osf.io/hqc9u. forest in the Green Triangle region of South Australia was capturedthe data from which is shown in Figure Immersive Focus+Context Techniques to Assist in Interpretation of High Density Forest Point Clouds a.
The context data is processed using FSCT as described in Section 3.2.2 . Once the focus and context point clouds are imported into Unity, Point Cloud Tools [ 31 ] is utilised to convert each cloud into a mesh.
A custom material shader is then used to selectively filter the mesh.
The shader takes as input the transformation matrix of the current focus object.
It then calculates if each vertex within the tree mesh is inside or outside of the focus area, storing this result in the vertex’s UV coordinates system.
The fragment shader then assesses the values stored in the UVs and discards fragments of the context mesh or focus mesh accordingly.
This results in the full point cloud being drawn within the focus area, and the synthetic data being drawn outside of it, as illustrated Figure Immersive Focus+Context Techniques to Assist in Interpretation of High Density Forest Point Clouds c.
A different version of this material exists for each of the selection states of the cloud, allowing subsets (in our case, individual trees) to be drawn in different colours reflecting their state.
